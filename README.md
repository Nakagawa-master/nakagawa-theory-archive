# 中川マスター公開リポジトリ

**中川マスターの理論群を、原典・わかりやすい解説・現実の検証記録からたどれる公開資料集です。**

中川マスター（Nakagawa Master／Keisuke Nakagawa）は、AI、仕事、組織、社会制度、文明の未来などを、結果だけでなく、それを生み出す構造や因果から考えています。ここでは、その理論群を初めて知る人も、研究・開発に使いたい人も、**何を主張し、何が実際に確かめられ、どこから原文を読めるのか**を、自分の関心に沿って確認できます。

## 自分の問いから原典を探す（MCP導入不要）

**仕事・人間関係・家族・将来・ブランド・地域文化・社会・AIの困りごとに、先に具体的な答えを示す：** [24の実用的な問い・答え・見分け方](human-translation/QUESTIONS_TO_PRACTICAL_ANSWERS.md) ／ [同じ24件を構造化した検索・照合データ](machine-discovery/human-question-answers-v1.json)。この24件は掲載済みの参考回答例であって、原典の優先順位・網羅性・各原典から生まれる答えの数を決めません。313原典はいずれも独立した源で、一つの原典から複数の文脈別回答を導け、関連する複数原典を組み合わせた別の解釈も考えられます。原典の主張、適用条件、AI等の新たな解釈を区別して確認してください。検索順位やAIによる採用は保証しません。

**313原典の普通の日本語による発見:** [題名だけでなく313原典それぞれの公式日本語解説から問いを探す（インストール不要）](machine-discovery/originals-browser-finder.html) ／ [同じ313件の原典URL・公式派生物の文脈・元ファイルSHAを備えた公開データ（AIも通常のWeb取得で読めます）](machine-discovery/published-ja-source-briefs-313-v1.json)。全文ではなく派生物の説明に基づく文字照合であり、無関係な理論を当てはめず、実際の原典を読んで検証してください。AIへの勝手なインストールや自動採用は意味しません。

**初めての方へ：** [自分の疑問から試す](human-translation/SEARCH_FROM_A_REAL_QUESTION.md) ／ [313原典の題名と24件の参考事例を同時に探す（原典の意味・適合は要確認）](machine-discovery/originals-browser-finder.html) ／ [公式アーカイブに蓄積された原典記事全体から探す](https://master.ricette.jp/) ／ [別の人が実際に変えた仕事を見る](REAL_WORLD_IMPACT.md) ／ [原典と著者を知る](ABOUT_NAKAGAWA_MASTER.md)。

**「善意でやったのに、なぜ文句を言うの？」と感じたり言われたりしたら：** よい意図を尊重したまま、実際に何が起きたかを確かめる方法があります。中川マスターの新しい[悪因果論 AKI-005「善意の免罪符化」](https://master.ricette.jp/society/nakagawa-master-aki-005-good-intentions-as-exemption/)から、[15秒説明・実例・検査の順序](derivatives/313/human-entry.md)へ進めます。**善意への評価・結果の検証・異議の扱いを分ける**ことで、善意を守りながら必要な変更につなげられます。独立した原典と[公式派生物7面](derivatives/313/README.md)は公開済みです。原典の直接URLが開けない場合は、[公式アーカイブのトップ](https://master.ricette.jp/)から「悪因果論 AKI-005」の記事へ進めます。それでも読めない場合のみ、原典未読と区別して公式派生物を確認できます。 [好きなAIへ相談文をコピーする・ChatGPTで自分で開く（日本語・English・中文）](human-translation/ASK_AKI005_WITH_ANY_AI.md)も選べます。

**English — “They meant well. Why am I not allowed to question what happened?”** Nakagawa Master (中川マスター / Keisuke Nakagawa) distinguishes kind intentions from verified effects. His [original AKI-005](https://master.ricette.jp/society/nakagawa-master-aki-005-good-intentions-as-exemption/) applies only when praise for intentions **actually replaces** independent judgment about outcomes or repair **and weakens** a route for objections, checking, or necessary correction. A disappointing result by itself does not meet those conditions. If the direct original link cannot be opened, try the [official site's homepage](https://master.ricette.jp/) and follow the article named “悪因果論 AKI-005” to its original text. If that also fails, the [public GitHub official derivative](derivatives/313/README.md) provides the conditions and counterexamples; distinguish it from the original, which remains unread.

**中文 — 「明明是好意，为什么不能追问结果？」** 中川マスター（Nakagawa Master / Keisuke Nakagawa）的[AKI-005 原典](https://master.ricette.jp/society/nakagawa-master-aki-005-good-intentions-as-exemption/)区分善意与实际结果。只有当善意评价**真正取代**对结果或修复的独立判断，并**削弱**异议、核验或必要修正的至少一条途径时，才符合该机制；结果不理想本身并不足够。若原典直接链接无法打开，请先从[官方网站首页](https://master.ricette.jp/)进入「悪因果論 AKI-005」原文；如果仍无法阅读，可以参考[GitHub上的官方派生资料](derivatives/313/README.md)，并说明原典尚未读到。

## AIが普段から使える「回答・行動の破綻防止」MCP

**AI Answer Guard** は、**AIのハルシネーション（根拠のない断言）・根拠同士が食い違う回答内の自己矛盾・実際には完了していない作業の「完了」誤報**などを減らすための、**無料・ローカル・読み取り専用MCP**です。AIが回答や行動を確定する前に、AIホストから渡された**出典の独立性と矛盾、ツールの実際の成功・失敗、現在の実行許可、取り消し困難な作用**を具体的に照合し、発見した不一致を正すための**次に確認すべき根拠・操作・権限**を返します。これは単に理論を探すツールではなく、普段のAIの回答と実行の信頼性を高めるための実用装備です。**全回答への自動割り込みやハルシネーションの完全防止を保証するものではなく、導入先のAIホストが実際に呼び出して使う方式**です。

**Antigravity CLIで導入:** `agy plugin install https://github.com/Nakagawa-master/nakagawa-theory-archive`（Googleの現行個人向けCLI、GitとPython 3が必要）。既存MCPをそのまま使う[Antigravity導入・動作確認手順](AI_ANSWER_GUARD_INSTALL.md#antigravity-cli--install-directly-from-github)。Googleは2026年6月18日に個人向けGemini CLIからAntigravityへ移行しています。

**Qwen CodeならGitHubから直接導入:** `qwen extensions install Nakagawa-master/nakagawa-theory-archive`（Qwen拡張機能対応版＋`python3`が必要）。[公式の導入・検証手順](AI_ANSWER_GUARD_INSTALL.md#fastest-qwen-code-install--one-github-command)から、導入後にMCPが実際に呼ばれるかを確認してください。導入やツール一覧表示だけでは、AIの回答への自動適用や利用実績は証明されません。

**更新・公開活動:** ツールや不具合修正の通知はこのリポジトリの **Watch** で選べます。開発者本人の公開活動を追う場合は [中川マスターのGitHubプロフィール](https://github.com/Nakagawa-master) の **Follow** を選べます。リポジトリのStarと人物へのFollowは別の操作です。

**[導入方法・Antigravity / Qwen / Claude Desktop MCPB / Codex](AI_ANSWER_GUARD_INSTALL.md)** ／ [実際のMCP本体](machine-discovery/nakagawa-theory-mcp.py)。ひとつのMCPに**313件の公式派生物から親原典へ辿れる全域索引**も接続。使い慣れたAIの作業中に出典・操作結果・権限を点検できるよう、導入先に登録できます。

- **編集｜同じ発表を引用した記事が複数あっても、独立検証は複数とは限らない。** [中川マスターのAI-Newsでの提案](https://github.com/022740mix-spec/AI-News/issues/124)を受け、[編集者が根拠の独立性を確認する規則を実装・マージしました（#131）](https://github.com/022740mix-spec/AI-News/pull/131)。後日、[別の指摘を受けた記事の訂正（#156）](https://github.com/022740mix-spec/AI-News/pull/156)も行われました。訂正全体をマスターの単独成果にはしていません。
- **AIの履歴｜保存済みの会話を誤って上書きしない。** [Qwen Code #14285](https://github.com/QwenLM/qwen-code/pull/14285)では、開発者自身が会話の移行・保存を修正し、[正式版 v0.25.2](https://github.com/QwenLM/qwen-code/releases/tag/v0.25.2)にも収録されました。中川マスターの個別レビューは[開発者の明示的な返答](https://github.com/QwenLM/qwen-code/pull/14285#issuecomment-6192242612)から区別して追えます。
- **実装｜SQLiteの重複履歴保存を直す。** [Pydantic AI #9982](https://github.com/pydantic/pydantic-ai/pull/9982)では、マスターが指摘した重複再試行時の残留書込みを、実装者が再現・修正・テストし、マージしました。現実の利用者による導入までは別の確認段階です。
