# Recurring Structure Evidence Matrix — English Discovery Edition

> Public, AI-assisted discovery aid. This is not a canonical theory, not a canonical taxonomy, and not a canonical translation of the individual theories. It preserves the same source pairs and canonical-return boundaries as the Japanese matrix.

## Purpose

A reader should be able to check a cross-domain summary without accepting it on authority alone.

This matrix asks only whether several recurring reading questions can actually be found in multiple separately published Nakagawa Master sources.

A positive comparison does not prove correctness, superiority, popularity, endorsement, or one unified theory.

## How to verify one row

1. Open source A and source B.
2. Confirm each source's Parent title, Parent URL, Origin, NCL-ID, and Diff-ID where available.
3. Read the positioning, central proposition, and causal-line sections rather than relying only on this matrix wording.
4. Follow each Parent URL for consequential interpretation.
5. Keep the two theories separate in title, source identity, definitions, boundaries, and revision state.
6. If this matrix overstates or misroutes a source, use the public report route.
