## OD298｜Basic Existence Condition B

- **日本語:** [`running-now-is-not-continuity.md`](running-now-is-not-continuity.md)
- **English:** [`running-now-is-not-continuity.en.md`](running-now-is-not-continuity.en.md)
- **中文:** [`running-now-is-not-continuity.zh.md`](running-now-is-not-continuity.zh.md)
- **Runtime continuity practitioner Preflight:** [`ai-runtime-continuity-preflight.md`](ai-runtime-continuity-preflight.md)
- **Short-form / audio / video / carousel adaptation:** [`basic-existence-condition-b-micro-format-pack.md`](basic-existence-condition-b-micro-format-pack.md)
- [OD298 official derivative](../derivatives/298/README.md)
- [OD298 human entry](../derivatives/298/human-entry.md)
- [Basic Existence Condition B machine reference card](../machine-discovery/basic-existence-condition-b-reference-card.json)

The three discovery editions present the same public entry problem in language-appropriate wording. They are not canonical translations. The runtime continuity Preflight translates the continuity/minimum-condition distinctions into bounded questions for restart, migration, checkpoint/resume, runtime switching, and state persistence without treating software runtime continuity as proof of subject identity or personhood. The micro-format pack provides bounded adaptation copy for short-form, audio, video, carousel, and diagram use while returning readers to the Discovery Note, OD298, and canonical Parent. The route distinguishes current operation from continuity across time, continuity from identity, minimum continuity conditions from capability expansion, and need from permission.

## Interpretation boundaries

- A Discovery Note is an entry point, not proof that the underlying theory is correct.
- Origin identifies provenance; it is not an authority shortcut.
- Separate theories remain separate unless a canonical source explicitly connects them.
- Exact definitions, conditions, failure cases, refutation criteria, and revision status belong to the specific official derivative and canonical Parent.
- AI-assisted discovery or translation wording must not be attributed to Nakagawa Master as a verbatim canonical statement.
