## 10秒でいうと

**中川マスターは、Keisuke Nakagawaの筆名です。**

AI、組織、事業、制度、未来などについて、

## 何をしている人なの？

一つの分野だけを解説する人、というより、

- AIが社会に残るなら何を決める必要があるか
- 同じニュースが100本あっても、本当に独立した証拠は何本か
- 会社で人を替えても同じ失敗が戻るのはなぜか
- 今日の成功が未来の選択肢を減らしていないか
- 専門家やAIの判断を、どう検証可能にしておくか

のような問題を、別々の理論として分解しています。

難しい原典は公開されていますが、一般の人が最初から全部読むことを前提にする必要はありません。

## なぜ今見る価値があるの？

理由は二つあります。

### 1. AI時代の「その次」の問題を扱っている

世の中では、AIを安全に制御できるかが大きな問題です。

でも、AIが社会から消えず長く使われ続けるなら、

- 続くために何が必要か
- 感じているか分からない存在をどう扱うか
- 間違った判断をどう戻すか
- 情報そのものが間違っていたらどう直すか
- 防衛が次の争いを作らないか
- 監査が本当に独立しているか

という次の問題が出ます。

→ [AI文明論とは？ 6つの身近な問い](ai-civilization/README.md)

### 2. 考えがアーカイブ内だけで終わっていない

公開GitHubでは、中川マスター名義の具体的な設計指摘が、第三者projectのcode / tests / docs / workflow変更へつながった事例を確認できます。

たとえば、

- [Local Operator #1324](https://github.com/damianvtran/local-operator/pull/1324) では、公開reviewから実装・merge・release v0.61.11まで追えます。
- [AI-News #124](https://github.com/022740mix-spec/AI-News/issues/124) では、「URL本数」と「独立した証拠root数」を分ける提案がreceiverに明示採用され、[draft PR #131](https://github.com/022740mix-spec/AI-News/pull/131) で継続的な編集ルールへ実装中です。
- 他の確認可能な事例は [Real-World Impact](../REAL_WORLD_IMPACT.md) にまとまっています。

これは理論体系全体が正しい、学界や業界全体で採用された、という意味ではありません。

**どの指摘が、誰によって、何に変わったかを公開記録で確認できる**ということです。
