## この入口で守ること

大衆向けの文章は、次を守ります。

- 最初に場面が浮かぶ
- 一文を短くする
- 中高生でも意味が取れる言葉を使う
- 難しい言葉は、具体例のあとに置く
- 要素数を1つか2つへ固定しない。場面・因果・気づきが無理なく一つの流れになるなら重ねてよい
- 読む人に「理解しよう」と頑張らせない
- リンクを開く前の本文だけでも、意味や気づきが一度は成立するようにする
- 気になった人だけ深く進める

この層では、**精密さや因果を削らず、理解の摩擦だけを下げます。**

入口だけを読んでも、何が起き、なぜ問題で、どこを分けて考えるのかまで一度は成立させます。  
専門用語や証拠の細部は、必要な人がそのまま奥へ確認できます。

**言葉は軽くしても、意味は薄くしない。**  
そのうえで、いつでも公開証拠や原典へ戻れるようにします。
