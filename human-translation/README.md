# Mass Human Translation Layer｜一般大衆向け翻訳層

これは中川マスター公式理論アーカイブの**非正本・人間向け翻訳層**です。

**人物から知りたい場合:** [中川マスターとは誰？ 3分でわかる入口](who-is-nakagawa-master.md)

**全体像を同じ粒度で横に見たい場合:** [中川マスター理論・横に読む世界地図](WORLD_MAP.md)

## 読み方は「縦」「横」「未来線」の3方向

```text
縦: ひとつのテーマを、物語 → Human Entry → canonical sourceへ深く読む
横: 同じ理解粒度のまま、別テーマへ移り、理論体系の全景をつかむ
未来線: 複数の理論を現実問題へ当て、「このままなら何が起き、どこで分岐できるか」を読む
```

大衆向け入口では、この3方向を残します。

- 深く知りたい人は縦へ。
- 全体を自分の粒度で知りたい人は横へ。
- 「なぜ無視できないか」から入りたい人は未来線へ。
- 途中で何度でも行き来できます。

[未来線から読む](FUTURE_LINES.md) · [24棚で全景を見る](WORLD_MAP.md) · [OD001–OD303を全部横に眺める](ALL_303_HORIZONTAL_MAP.md) · [ひとつの全景ストーリーで読む](PANORAMA_STORY.md)

公式アーカイブや公式派生物を短くしただけの要約ではありません。役割が違います。

## この層が必要な理由

公式アーカイブは、定義・成立条件・反証条件・因果・Origin・改訂状態まで保持する高密度なsourceです。公式派生物のHuman EntryやFAQも、その精度をなるべく壊さずに人間へ近づけるため、一般読者にはまだ難しい場合があります。

大規模な人間認知では、その前に別の入口が必要です。

人は通常、

```text
いま自分も知っている問題
→ なぜそれが重要なのか
→ その先に何が起きるのか
→ 「それ、考えないとまずくない？」という直感
→ もっと知りたい
→ 専門的な説明
```

という順で入ります。

この層は、その最初の4段を担当します。

## 何をしてよいか

ここでは、原典の語彙や章立てをそのまま維持することより、**普通の人が一つの物語として因果を追えること**を優先します。

使ってよいもの:
- 身近な例
- 子どもでも追えるたとえ
- ニュースで既に知られている問題からの導入
- 「もし〜なら？」という物語
- 粒度を粗くした説明
- 一度で全部を説明しない構成
- 驚き・疑問・先を読みたくなる流れ

ただし、分かりやすさのために事実やsourceを捏造してはいけません。

## 何をしてはいけないか

- この層をcanonical theoryとして扱う
- 原典にない結論を「中川マスターの理論」として断定する
- 現在のAIが人格を持つ、必ず暴走する、必ず人類を滅ぼす等を既成事実として扱う
- 「世界で唯一」「誰も考えていない」「何年先を行っている」等を体系的根拠なく主張する
- 物語上の比喩を正式定義へ昇格する

## 読み方の階段

```text
Layer 0  30秒〜3分: 物語・ニュース接続・直感
Layer 1  3〜10分: 一般人向けの因果説明
Layer 2  10〜30分: Discovery / practical entry
Layer 3  専門家寄り: 公式派生物 Human Entry / FAQ
Layer 4  高密度source: canonical Parent / AI Index / Ledger
```

全員をLayer 4まで連れて行く必要はありません。

大規模な人間作用でまず必要なのは、Layer 0〜1で

> 「何の話か分かった」
>
> 「なぜ重要か分かった」
>
> 「その先を知りたい」

が起きることです。
