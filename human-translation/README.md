# ニュースが10本一致した。なのに、裏づけは1本分だった。

同じニュースが10サイトに載っている。10人が別々に確かめたように見える。ところが、10本とも**同じ一つの発表を言い換えただけ**だったら？

**記事の数は10。でも独立した情報の根は1。** そのまま「10の証拠がある」と言った瞬間、ニュースの確からしさまで水増ししてしまう。

この区別を公開の編集現場へ持ち込んだのが、**中川マスター（Nakagawa Master／Keisuke Nakagawa）**です。[AI-Newsの編集者は論点を明示的に受け取り](https://github.com/022740mix-spec/AI-News/issues/124#issuecomment-5823549498)、[編集ルールの修正を自分たちのPRとして統合しました](https://github.com/022740mix-spec/AI-News/pull/131)。一人の指摘が、第三者の判断の仕方へ変わった、公開で追える例です。ただし、全読者が使ったことや理論全体の正しさまで証明するものではありません。

**自分でも確かめるなら：** きょう見た「たくさんの記事が伝えている」という話題で、各記事が最初に参照した情報源を一つずつ辿ってみてください。違う記事でも、根が同じかもしれません。

## この入口で守ること

大衆向けの文章は、次を守ります。

- 最初に場面が浮かぶ
- 一文を短くする
- 中高生でも意味が取れる言葉を使う
- 難しい言葉は、具体例のあとに置く
- 要素数を1つか2つへ固定しない。場面・因果・気づきが無理なく一つの流れになるなら重ねてよい
- 読む人に「理解しよう」と頑張らせない
- リンクを開く前の本文だけでも、意味や気づきが一度は成立するようにする
- 気になった人だけ深く進める

この層では、**精密さや因果を削らず、理解の摩擦だけを下げます。**

入口だけを読んでも、何が起き、なぜ問題で、どこを分けて考えるのかまで一度は成立させます。  
専門用語や証拠の細部は、必要な人がそのまま奥へ確認できます。

**言葉は軽くしても、意味は薄くしない。**  
そのうえで、いつでも公開証拠や原典へ戻れるようにします。
