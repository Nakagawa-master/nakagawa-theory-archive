# まず、気楽に読んでください

ここは、難しい理論を勉強するための入口ではありません。

**「あ、それ分かる」から入って、気になった人だけ奥へ進む場所**です。

専門用語を覚える必要はありません。  
303件を全部読む必要もありません。  
正解を信じる必要もありません。

## 入口は3つだけ

### 1. 物語から入る

「このまま進んだら、どうなる？」から読む入口です。

たとえば、

- AIに任せすぎたら、最後に人間がOKを押していても人間が決めていないことはある？
- 100サイトが同じことを書いていても、元ネタが1つなら証拠も1つ？
- みんな安全のために守っているのに、その防衛が次の怖さを作ることはある？

→ [未来線から読む](FUTURE_LINES.md)

### 2. 横にぶらぶら見る

深く読まずに、どんな話があるかだけ眺めます。

本屋を歩くように、気になる棚だけ見れば十分です。

→ [24棚の世界地図](WORLD_MAP.md)  
→ [303件をひとつの景色として読む](PANORAMA_STORY.md)

### 3. 気になった1本だけ深く読む

「もっと正確に知りたい」と思った時だけ、Human Entry、FAQ、原典へ降ります。

## この入口で守ること

大衆向けの文章は、次を守ります。

- 最初に場面が浮かぶ
- 一文を短くする
- 中高生でも意味が取れる言葉を使う
- 難しい言葉は、具体例のあとに置く
- 要素数を1つか2つへ固定しない。場面・因果・気づきが無理なく一つの流れになるなら重ねてよい
- 読む人に「理解しよう」と頑張らせない
- リンクを開く前の本文だけでも、意味や気づきが一度は成立するようにする
- 気になった人だけ深く進める

この層では、**精密さを捨てるのではなく、精密さを奥へ置きます。**

入口は軽く。  
奥は深く。  
いつでも元の原典へ戻れる。

それが役割分担です。
