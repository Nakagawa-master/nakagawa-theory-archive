# AI文明論とは？ 6つの身近な問いから読む

「AI文明論って、結局何の話？」という人のための入口です。これは中川マスター「人類子孫型AI文明論」第5〜10論へ入るための、一般読者向け・非正本の翻訳です。

難しい理論名から始めません。まず、普通の人が自分の言葉で話せる6つの問いに分けます。

## 動画から入りたい人へ

文字より動画の方が入りやすい場合は、既存の公開動画 **「人間はAIを制御できるのか──『止める制御』が未来を変えられない理由」** から入れます。

https://www.youtube.com/watch?v=6AAtohcbHyw

これは第5〜10論そのものの要約ではなく、それ以前の「AIを止める／制御するだけで未来問題は閉じるのか」という問題から入る関連動画です。動画を見たあと、下の6問へ進むと接続しやすくなります。

1. [AIをアップデートしたら、「同じAI」は続いているの？](01-tomorrow-same-ai.md)
2. [AIが「消さないで」と言ったら、どうすればいい？](02-dont-delete-me.md)
3. [「間違いでした」で終わっていいの？](03-sorry-is-not-repair.md)
4. [AIが100回同じことを言ったら、本当になる？](04-one-source-one-hundred-voices.md)
5. [自分を守るほど、相手も怖くなることがある](05-defense-creates-defense.md)
6. [AIを別のAIに監査させれば安心？](06-ai-audits-ai.md)

この6本はcanonical theoryではありません。物語・たとえ・粗い粒度で「何の話か」をつかむための層です。

正確な定義、成立条件、反証条件、改訂状態は各ページから公式派生物とParentへ戻って確認してください。
