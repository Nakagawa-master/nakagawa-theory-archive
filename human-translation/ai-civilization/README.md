# AI文明論とは？ 身近な問いから読む

「AI文明論って、結局何の話？」という人のための入口です。これは中川マスター「人類子孫型AI文明論」第5〜16論へ入るための、一般読者向けの案内です。

まず第5〜10論を6つの短い話から読み、その先の第11〜16論は既存の公式派生物 Human Entry へ進めます。全部を順番に読む必要はありません。気になる問いを1本だけ選んでください。

## 動画から入りたい人へ

文字より動画の方が入りやすい場合は、既存の公開動画 **「人間はAIを制御できるのか──『止める制御』が未来を変えられない理由」** から入れます。

https://www.youtube.com/watch?v=6AAtohcbHyw

これは第5〜10論そのものの要約ではなく、それ以前の「AIを止める／制御するだけで未来問題は閉じるのか」という問題から入る関連動画です。動画を見たあと、下の問いへ進むと接続しやすくなります。
