# 先に、あなたの話から読んでください

ここはGitHubですが、仕様書から読む場所ではありません。

SNS、検索、動画から来た人が、**自分の生活・仕事・お金・選択の話として1本読み切り、そこから別の現実へ横に移れる入口**です。

理論名を覚える必要はありません。原典を最初から読む必要もありません。

まず一つだけ、「これ、自分にもある」と思う場面を開いてください。
