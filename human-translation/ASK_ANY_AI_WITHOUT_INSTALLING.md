# No-install: ask your own AI about a real problem → inspect the canonical original

**普通の質問から原典へ。インストール、MCP設定、APIキーは不要です。** これはあなた自身が使うChatGPTなどのAIに、実際の問題を考えてもらうための**任意の相談文**です。AIが自動的に原典を知った・採用したという意味ではありません。

**20秒で試す:** ① 今の問題に近い一つを選ぶ → ② 対応する「AIで相談文を開く」（ChatGPT向けの任意リンク）を押すか、文章を好きなAIへコピー → ③ **自分で内容を確認して送信** → ④ AIが公式原典を実際に取得できたか確認し、条件に合わなければ採用しない。

AIによってはURLの入力欄への自動反映に対応していません。その場合は各項目の**相談文**をコピーして使えます。Web閲覧できないAIには原典を読めないことを明示させ、**URLを渡しただけで「読んだ」と認定しない**でください。個人情報や社外秘の相談は貼らないでください。

**新しい別入口（AKI-005）：** 「善意でやったのだから批判するな」と言われ、結果や異議が確かめられないときは、[公式原典に結びついた日本語・English・中文の任意の相談文](ASK_AKI005_WITH_ANY_AI.md)をChatGPTで開くか、いつものAIへコピーできます。元の7件とは独立した追加入口で、原典を読めないAIが読めたと偽らない設計です。

例えば「キャンプ用ランタンの革ひもをどう直すか」という相談に、ここに挙げた七つの理論を無理に当てはめる必要はありません。通常の修理方法を調べる方が有益です。これは**原典の適合条件を判断する自由**を守るための案内です。
