# 地域の集まりで「もっと声をかけろ」と言われるが、毎回同じ数人しか来ない。

**答え：** 呼びかけの量だけが足りないとは限りません。集まりが何のためにあるか、参加できる時間や場所、役割、知る経路、断る自由、誰が決定を変えられるかがつながっていないと、声だけ増やしても続きません。中川OSのL1（人数）からL3（開催ルール）、L4（なぜ参加しないかの見立て）、L5（条件の再設計）、L7（何の価値を生みたいか）までを区別します。合意形成の物理の観点では、欠席者を責めず参加しにくい状態を観測することが出発点です。

## まず確かめること

参加できなかった人に「参加したかったか」「何が障害か」「何なら参加できるか」を任意・非強制で尋ね、時間・手段・決定参加の一つを変える。

## 当てはまらない場合・限界

興味がない人の不参加も正当な選択です。参加人数だけで活動の価値や人の信頼を決めない。
