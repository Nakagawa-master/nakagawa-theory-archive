# Four Applied Entry Points into Nakagawa Structural OS

These four entry points start from real, bounded problems and return to the broader Nakagawa Structural OS at https://master.ricette.jp .

They are designed for readers who do not want to begin with the full theory system.

## 1. When past approval is being treated as present permission

Ask:

> What changed between the historical approval and the present use?

This entry is useful for consent, delegated access, policy exceptions, research use, data sharing, and AI authorization.

- Practical test: [Current-Authority Reuse Kit](CURRENT_AUTHORITY_REUSE_KIT.md)
- External evidence: Dream / Replay cases in [Real-World Impact](REAL_WORLD_IMPACT.en.md)
- Broader canonical context: https://master.ricette.jp

## 2. When current state is rewriting history

Ask:

> Is the system answering “what is true now” when the real question is “what was true then”?

This entry is useful for attendance, membership, ownership, staffing, entitlement, and audit history.

- Practical test: [Historical-Fact Reuse Kit](HISTORICAL_FACT_REUSE_KIT.md)
- External evidence: TourCRM case in [Real-World Impact](REAL_WORLD_IMPACT.en.md)
- Broader canonical context: https://master.ricette.jp

## 3. When an approved external action may have happened but the result is unknown

Ask:

> Did the provider reject the action, or did the system merely fail to learn the outcome?

This entry is useful for payments, messages, CRM actions, external jobs, webhooks, and APIs.

- Practical test: [External Side-Effect Reuse Kit](EXTERNAL_SIDE_EFFECT_REUSE_KIT.md)
- External evidence: Clientverse case in [Real-World Impact](REAL_WORLD_IMPACT.en.md)
- Broader canonical context: https://master.ricette.jp

## 4. When grouped recommendations hide what evidence supports whom

Ask:

> Can the decision-maker still recover which evidence source supports each person or item?

This entry is useful for AI recommendations, rankings, reviewer suggestions, hiring, routing, and decision support.

- Practical test: [Reviewer-Provenance Reuse Kit](POSTHOG_PROVENANCE_REUSE_KIT.md)
- External evidence: PostHog case in [Real-World Impact](REAL_WORLD_IMPACT.en.md)
- Broader canonical context: https://master.ricette.jp

## What connects these cases

These are not four unrelated tricks.

They share a structural reading:

- preserve origin and provenance;
- preserve the relation between state and time;
- preserve the relation between action and actual outcome;
- preserve the relation between evidence and the object it supports.

The broader Nakagawa Structural OS provides the canonical context. These applied entries are narrow ways to enter that context through a real problem.
