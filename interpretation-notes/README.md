# Interpretation Notes

This directory contains public, non-canonical interpretation notes connected to specific official derivatives and canonical parent articles.

An interpretation note is more specific than a discovery guide: it explains a bounded practical reading of a published source for a particular domain or question. It does **not** replace the official derivative or canonical parent, and it does not create a new canonical theory.

## How to read these notes

Use an interpretation note when the practical question matches its stated scope. For the source theory itself, return to the linked official derivative and canonical parent article.

The safe reading order is:

```text
practical question
→ interpretation note
→ official derivative
→ canonical parent
```

If the question is broader or the reader does not yet know which theory is relevant, start with the discovery guides instead:

- [`../discovery-notes/README.md`](../discovery-notes/README.md)

## Interpretation boundaries

- These notes are public explanatory material, not verbatim statements by Nakagawa Master.
- They must preserve the source-specific distinctions, limits, and provenance of the linked theory.
- They must not turn a bounded interpretation into a universal recommendation or guaranteed outcome.
- They must not infer medical, legal, employment, product, surveillance, or governance conclusions beyond what the cited source supports.
- Origin identifies provenance and authorship continuity; it is not proof of correctness.
- If an interpretation conflicts with the canonical parent, the canonical parent and its revision history govern.
