## 15秒説明
監査要旨は、長い文章を短くする要約ではありません。声量、人気、肩書、速度だけで正統性が決まらないよう、**因果・関係・反証・再合意条件**を、一次証拠へ戻れる形で見せる「読みの窓」です。決定を止めるのではなく、決定と監査を並行させます。

## なぜ必要になるのか
SNS、政治討論、企業評価などでは、内容より「誰が言ったか」「どれだけ拡散したか」「どれだけ速く決まったか」が先に評価されることがあります。こうした状態では、主張の因果や利害関係、反証、後から見直す条件が読まれないまま、決定だけが不可逆化しやすくなります。

監査要旨は、この問題に対して「もっと長く説明する」方法を採りません。読むべき構造を最小限の窓として外へ出し、必要なら一次証拠・構造ログ・Parentへ戻れるようにします。

## 四つの柱
1. **因果** — その主張・判断が何を原因とし、何を結果としているか。
2. **関係** — 誰と誰、何と何が利害・依存・責任で接続しているか。
3. **反証** — 何が起きれば主張を弱める、棄却する、改訂する必要があるか。
4. **再合意性** — どの条件で判断を見直し、再び合意形成するか。

## 二層合意
```text
量の合意
= 多数決・採決・速度など、決定を前へ進める層

正統性の合意
= 一次証拠・構造・反証・再合意条件を読み、妥当性を継続検証する層
```

監査要旨は前者を否定しません。量の合意だけで決定の妥当性まで確定したことにせず、正統性の監査流路を並行して残します。

## 実務工程
```text
判断・主張を特定する
→ 声量・人物・人気と内容を分ける
→ 中心因果を一行で固定する
→ 利害・依存・責任関係を整理する
→ 主要な反証を置く
→ 見直し・再合意条件を置く
→ 一次証拠・構造ログへのリンクを保持する
→ 決定は必要な速度で進める
→ 監査窓を開いたまま結果を観測する
→ 条件逸脱時に修正・撤回・再合意へ移る
```

## 適用例
**メディア。** 記事の結論だけでなく、因果、関係、主要反証、再検討条件を読み手が追える小窓を置く。

**教育。** 賛成・反対を書く前に、論の因果、反証、見直し条件を短く整理する。

**自治体・市民連合。** 採決を遅らせず、決定理由と後から見直す条件を公開しておく。

**企業・団体。** 重要判断に一次証拠、影響関係、反証、見直し条件を添え、将来の説明責任を残す。

## 成功判定
- 要旨からParentや一次証拠へ戻れる。
- 因果、関係、反証、再合意条件が別々に読める。
- 人気や肩書が妥当性の代替になっていない。
- 決定速度と監査可能性が両立している。
- 誤りが見つかった時に実際に修正できる。
- 単一KPIではなく複数軸で健全性を読む。
- 監査要旨そのものが新しい権威になっていない。

## 限界
監査要旨を付けても、一次証拠が不正確なら正統性は生まれません。また、反証条件や再合意条件を書くだけで、実際に改訂できない制度なら可逆性はありません。

すべてを公開すればよいわけでもありません。親原典は、束指標の軸・意味・読み方を公開しつつ、ゲーミングを招く重みや合成手順、閾値は非公開とする境界も示します。

## 誤読防止
- 監査要旨を単なる「要約」としない。
- 人物切断を、責任主体の匿名化と解釈しない。
- 量の合意を不要としない。
- 監査を理由にすべての決定を停止させない。
- 反対意見を置くだけで反証可能性があることにしない。
- 原典の指標例を固定的な普遍KPIへ変えない。
- 炎上・感情の流路と、正統性を読む構造流路を混同しない。
- 監査要旨を「最終的に正しい答えを出す装置」と扱わない。
