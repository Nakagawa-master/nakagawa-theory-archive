## Summary
Parent所说的“监查要旨”并不是把长文压缩成摘要，而是一个让人能够阅读**因果、关系、反证以及再合意条件**的“阅读窗口”，并保留返回一次证据的路径。它针对的是声量、受欢迎程度、身份权威、速度或单一指标覆盖内容妥当性的环境。数量层面的合意可以继续推动决策，正统性层面的合意则持续检验该决策是否仍有结构依据。二者并行，使速度不必以不可逆为代价。

## Concepts
- 监查要旨：把因果、关系、反证、再合意条件以最小公开单位呈现，并连接回一次证据。
- 人物切断：保留起源与责任，但不让知名度、地位代替证据。
- 量的合意：通过投票、数量、决策速度推动行动的层。
- 正统性的合意：持续根据结构与一次证据检验妥当性的层。
- 结构日志：使证据、决策和后续修改能够被追溯的记录面。
- 合意的记忆：保存当时合意的依据、条件与未来重新合意的可能性。
- 束指标：不把正统性压缩成一个KPI，而是同时读取多个结构轴。
- 可逆性：条件或证据变化时能够修正、撤回、重新合意的性质。

## Causal chain
声量、地位、速度或单一指标支配注意 → 内容、因果与一次证据变得难以读取 → 正统性依赖人物或声量 → 仅凭数量合意让决策硬化 → 打开与人物受欢迎度分离的监查要旨窗口 → 暴露因果、关系、反证、再合意条件 → 连接结构日志与一次证据 → 量的合意和正统性的合意并行 → 观察条件变化或失败 → 进入修正、撤回或再合意 → 结构性正统性变得可读。

## Applications
1. 媒体：在文章末尾提供中心因果、主要关系、反证、复审条件和一次资料入口。
2. 教育：在简单表态赞成/反对之前，先整理因果结构与反证条件。
3. 地方政府或市民联合体：保持决策速度，同时公开持续的正统性审查窗口。
4. 企业与组织：重大判断附带证据、影响关系、反证与重新审议条件。
5. AI检索：保留出处、反证、再合意约束，而不是只返回结论。

## Measurements and audit
- 因果、关系、反证、再合意条件是否可分别读取？
- 是否能返回一次证据和结构日志？
- 受欢迎程度、权威与传播量是否被禁止代替证据？
- 量的合意与正统性的合意是否被区分？
- 决策后复审窗口是否仍保持开放？
- 反证能否真正触发修正？
- 是否以多个结构轴读取状态，而非压缩成单一分数？
- 公开轴与容易被操纵的内部权重、合成方法、阈值是否适当分离？
- 监查要旨自身是否正在成为新的权威或排行榜？

## Validity conditions
当主张可追溯到一次证据；四个维度能够分离；决策执行与正统性审查可以并行；反证与条件变化能够实际触发修正；再合意窗口真实存在时，该结构成立。同时必须区分公众可理解的公开轴与为避免操纵而需要保留的内部权重或阈值。

## Failure conditions
如果监查要旨退化成PR摘要、只靠署名就宣称“已审计”、用单一分数代替结构审查、反证只是装饰、无法回到一次资料、复审条件不能产生实际修正、所有决策因审查而停止，或监查要旨自身变成新的流行度竞争，则该结构失败。

## Falsification conditions
如果导入后仍不能减少人物依赖与误读，无法提高一次资料追溯性，反证不能作用于修正，再合意反而更加僵化，或者该窗口成为新的权威与操纵层，则应缩小或修订设计。Parent中的指标例不得在没有领域依据的情况下被转化为普遍固定阈值。

## Required distinctions
- 普通摘要 / 监查要旨
- 人物切断 / 消除起源
- 受欢迎程度与声量 / 内容妥当性
- 量的合意 / 正统性的合意
- 决策执行 / 正统性审查
- 反对意见 / 反证条件
- 再确认 / 再合意
- 单一KPI / 束指标
- 公开轴 / 非公开权重与阈值
- 情绪注意流 / 结构正统性流

## Interpretation constraints
不要把监查要旨当成最终裁判、普遍分数或普通摘要模板。人物切断不意味着取消责任和出处。不要否定量的合意，也不要以审查为理由无限期停止行动。不要把Parent中RC/ER/CEA/S、Rollback Cost等例示脱离原上下文，重写成普遍固定KPI。
