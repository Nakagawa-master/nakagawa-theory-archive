## 15秒说明
审计要旨不是把长文缩短的摘要。为了不让声量、人气、头衔、速度单独决定正统性，它是一个“阅读窗口”：以能够返回一次证据的形式展示**因果、关系、反证、重新共识条件**。它不停止决策，而是让决策与审计并行。

## 为什么有必要
在SNS、政治讨论、企业评价中，“谁说的”“传播了多广”“多快作出决定”，有时会先于内容得到评价。在这种状态下，主张的因果、利害关系、反证以及之后重新审视的条件尚未被读到，决策本身就容易不可逆。

审计要旨不采用“说明得更长”的方法解决这个问题，而是把应读的结构作为最小窗口呈现出来，必要时能够返回一次证据、结构日志和Parent。

## 四个支柱
1. **因果** — 该主张或判断把什么作为原因、什么作为结果？
2. **关系** — 谁与谁、什么与什么通过利害、依赖、责任相互连接？
3. **反证** — 发生什么时，需要削弱、否定或修订该主张？
4. **重新共识性** — 在什么条件下重新审视判断并再次形成共识？

## 两层共识
```text
数量共识
= 通过多数表决、投票、速度等推动决定前进的层

正统性共识
= 阅读一次证据、结构、反证、重新共识条件，并持续验证妥当性的层
```

审计要旨不否定前者。不把仅有数量共识当成已经确定决策的妥当性，同时并行保留正统性审计的路径。

## 实务流程
```text
确定判断或主张
→ 将声量、人物、人气与内容分开
→ 用一行固定中心因果
→ 整理利害、依赖和责任关系
→ 放置主要反证
→ 放置复核和重新共识条件
→ 保留一次证据、结构日志的链接
→ 以必要速度推进决策
→ 在审计窗口保持开放的状态下观察结果
→ 条件偏离时转入修正、撤回或重新共识
```

## 应用例
**媒体。** 放置一个小窗口，使读者不仅能看到文章结论，还能追踪因果、关系、主要反证和重新考虑的条件。

**教育。** 在写赞成或反对之前，简要整理论证的因果、反证和复核条件。

**自治体・市民联合。** 不拖延表决，同时公开决定理由与日后复核的条件。

**企业・团体。** 给重要判断附上一次证据、影响关系、反证和复核条件，留下未来的说明责任。

## 成功判定
- 可以从要旨返回Parent或一次证据。
- 因果、关系、反证、重新共识条件可以分别阅读。
- 人气或头衔没有代替妥当性。
- 决策速度与可审计性并存。
- 发现错误时能够实际修正。
- 不是用单一KPI，而是用多个轴阅读健全性。
- 审计要旨本身没有成为新的权威。

## 局限
即使添加审计要旨，如果一次证据不准确，也不会产生正统性。而且即使写了反证条件和重新共识条件，如果制度实际上无法修订，也没有可逆性。

也不意味着一切都应公开。亲原典还展示了一个边界：公开束指标的轴、意义和读法，同时不公开会招致攻略的权重、合成步骤和阈值。

## 防止误读
- 不要把审计要旨当作单纯的“摘要”。
- 不要把切断人物解释为将责任主体匿名化。
- 不要认为数量共识是不必要的。
- 不要以审计为理由停止所有决定。
- 不要认为只放置反对意见就具有反证可能性。
- 不要把亲原典的指标例子变成固定的普遍KPI。
- 不要混同炎上、情绪流路与读取正统性的结构流路。
- 不要把审计要旨当作最终给出正确答案的装置。
