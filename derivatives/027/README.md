## 位置づけ

この公式派生物は親原典への公開入口であり、原典の代替ではない。

親原典の主題はインバックスやHOソイルの紹介そのものではなく、中川マスターがZEROICHI記事で、なぜ「残土活用」ではなく「土木の材料観を更新する実装OS」として構成したのかという構造読解である。

## 中心命題

建設現場の土は均一ではなく、水分、粒度、含有物、気候、施工条件によって状態が変わる。そのため、従来は使えない土を捨て、必要な材料を別に持ち込むことが合理的に見えやすかった。

しかし、土質確認、配合試験、混合、養生、品質確認、現場補正、検証、標準化を一つの運用体系として束ねられるなら、土は単なる処分対象ではなく、条件次第で建設資源として扱われ得る。

```text
不均一な土が発生する
→ そのままでは品質を保証しにくい
→ 捨てて別材料を持ち込む発想が合理化される
→ 土質確認・配合試験・混合・養生・品質確認を行う
→ 必要に応じて現場補正する
→ 検証可能な品質条件へ翻訳する
→ 属人的知見を標準化へ近づける
→ 「捨てる土」から「条件次第で使える材料」へ材料観が更新される
```

親原典でいう「実装OS」は単一技術の名称ではなく、この連続した判断・工程・検証を社会実装可能な形に束ねる構造を指す。

## 構造読解のメタ軸

ZEROICHI記事では「土はゴミか、資源か」という問いが入口として選ばれている。これは装飾的なキャッチコピーではなく、技術説明の前に読者を材料観の更新へ入れるための記事構成判断である。

親原典は、インバックスをどう読んだかだけでなく、その読解をどのような公開記事として成立させたかまでを記録する。

## 誤読禁止

単なる残土活用紹介、HOソイル性能紹介、環境配慮型土木、災害復旧美談、AI活用企業紹介、土木DX一般論へ縮約してはならない。

また、すべての土が資源になる、性能・安全性・法規適合・公共効果が保証される、といった原典を越える断定を加えてはならない。
