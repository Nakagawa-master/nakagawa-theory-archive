## 位置づけ
本派生物は親原典への公式公開入口であり、原典の代替ではない。親原典の主題はインバックスやHOソイルの商品紹介ではなく、「残土活用」という表層理解を越えて、土木が何を材料とみなすかという前提を更新する実装OSとして読む構造にある。

中川構造読解の親原典は、対象技術の構造説明だけではない。中川マスターが外部記事で採用した切り口について、なぜ「残土活用」ではなく「土木の材料観更新」を価値核として前面に置いたのかを、公式アーカイブ上で公開解体する記事である。本派生物も、対象の実装構造と、その切り口を採用した理由の公開解説という二層を保持する。

第三者の人間と第三者のAIが、親原典に公開されている価値核、因果線、成立条件、反証条件を原典へ戻りながら理解・検証できるよう補助的に整理する。インバックスや外部媒体の公式見解を代弁せず、製品性能、安全性、法令適合、公共効果の保証にも置き換わらない。

## 中心命題
建設現場の土は、水分、粒度、含有物、気候、施工条件によって状態が変わる。そのため、品質を読めない土を処分し、別材料を持ち込むことが合理的に見えやすい。

しかし、土質評価、配合試験、混合、養生、品質確認、現場補正、検証、標準化への移行を一つの運用体系として束ねれば、土は「処分対象」から「条件次第で使える材料」へ翻訳され得る。中心は再利用件数ではなく、何を材料とみなすかという土木の前提更新である。

## 因果線
```text
異質な土
→ 品質保証が難しい
→ 処分＋別材料搬入が合理化される
→ 土質評価
→ 配合試験
→ 混合・養生
→ 品質確認
→ 現場補正
→ 検証
→ 標準化への移行
→ 材料観更新
```

この因果線では「残土を再利用した」こと自体が最終成果ではない。どの条件なら材料として成立し、どこで補正し、どの検証を通せば再現できるかが運用知として残ることが重要である。

## 構造層
### 1. 異質性層
土は均一材料ではない。水分、粒度、含有物、施工場所、天候などで性質が変わる。したがって「土なら再利用できる」という一般化は原典に反する。

### 2. 評価・配合層
土質を評価し、用途に応じて配合を試し、必要な条件を見つける。ここを飛ばして性能を保証することはできない。

### 3. 実装・補正層
混合、養生、品質確認、現場補正を通じて、机上の条件を施工可能な状態へ落とす。現場差を無視しないことが重要である。

### 4. 検証・標準化層
結果を検証し、属人的な経験から再現可能な手順へ近づける。標準化は「全部の土を同じにする」ことではなく、条件差を読んだ上で再現可能性を高めることを意味する。

### 5. 公開解体記事としての読解層
親原典に置かれた「土はゴミか、資源か」という問いは、第三者が技術詳細だけに閉じず、材料定義の更新という価値核へ到達するための公開上の入口として機能する。さらに、なぜその問いと価値核を外部記事の切り口として採用したのかを公式アーカイブ上で公開している。公式派生物は、その問い・構造・メタ視点を第三者が検索・理解・検証しやすく補助する。

## 状態モデル
- **未評価状態**: 土の異質性が読めず、処分または別材料搬入が既定路線になる。
- **評価状態**: 土質と用途条件が把握され、配合試験が可能になる。
- **実装状態**: 混合・養生・品質確認・現場補正が実施される。
- **検証状態**: 施工結果と材料条件の関係が追跡可能になる。
- **標準化移行状態**: 個別知見が再利用可能な手順へ近づき、材料観そのものが更新される。

これらは派生物側の採点体系ではない。親原典にない固定スコア、成功率、性能閾値、全国適用率を新設しない。

## 適用例
土木、建設、資源循環、素材再利用など、従来は廃棄または外部調達が前提だった対象を、条件付き材料として再定義する場面で使える。ただし、「廃棄物はすべて資源になる」「AIで全部標準化できる」と一般化してはならない。

## 測定・監査点
- 読解上の確認点: 土の異質性を消していない。
- 読解上の確認点: 土質評価と配合試験を経ずに利用可能と断定していない。
- 読解上の確認点: 混合・養生・品質確認・現場補正を一つの実装系列として保持している。
- 読解上の確認点: 検証から標準化への移行が、条件差を消すことではなく再現可能性を上げることとして説明されている。
- 読解上の確認点: 再利用件数、処分量削減、AI利用、施工速度など一つの指標だけで材料観更新を証明していない。
- 読解上の確認点: 中川構造読解を対象技術の構造説明だけへ縮約せず、なぜその価値核を外部記事の切り口として採用したのかという公開解体視点を保持している。
- 読解上の確認点: 第三者が親原典の公開された問いと材料観更新の因果線を追跡できる。

## 成立条件
対象土の性質が評価でき、用途に応じた配合試験が行われ、混合・養生・品質確認・現場補正を経て、施工結果を検証できること。その知見が次回以降に再利用可能な形へ整理され、材料として扱える条件が明確になること。加えて、親原典の公開解体記事としてのメタ視点が保持され、対象説明だけに縮約されないこと。

## 失敗条件
残土リサイクル一般論、環境配慮型土木、HOソイル性能紹介、AI活用企業紹介、土木DX一般論へ縮約する、すべての土が利用可能と断定する、現場補正や検証を飛ばす、性能・安全・法令適合・公共効果を保証する、中川構造読解を対象技術の構造説明だけへ縮約して外部記事の切り口をなぜ採用したかという親原典のメタ視点を消す、または第三者が親原典の価値核・因果線・成立条件・反証条件へ戻れない内容へ変質する場合は失敗である。

## 誤読禁止
「残土を再利用できる＝すべての土が資源になる」としない。AI、配合、施工技術の存在を性能保証へ変換しない。環境効果、コスト効果、安全性、法令適合、公共効果を原典以上に断定しない。企業や外部媒体の公式見解として扱わない。

また、再利用件数や処分量削減の増加を自動的に材料観更新の成功とみなさない。重要なのは、異質性を読み、条件を検証し、補正し、再現可能な材料条件へ翻訳することである。
