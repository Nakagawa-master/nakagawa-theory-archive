## 要約

束指標は、単一KPI、人気、PV、ランキングなど一つの数値が複雑な現実を代表することで生じるゲーミング、短期最適化、声量偏重を避ける測定言語である。複数の異質な軸を総合点へ再圧縮せず、軸ごとの状態、欠落、偏り、緊張、時間変化を束の形として示す。因果整合、可逆性、再合意性、接続独立性、監査要旨整備、構造ログ連携、人物切断、公共圏適合などを例とし、各軸は一次証拠へ接続される。公開するのは軸名、意味、読み方、証拠対応、見直し条件であり、重み、閾値、合成手順、個別査定はゲーミング防止のため境界管理する。ただし非公開は無監査を意味せず、独立監査、差分記録、異議申立てが必要である。束指標は二層合意と構造的正統性をつなぐ測りの橋であり、量の合意による速度を保持しながら、正統性の合意を継続監査する。

## 中心命題

複数軸を一つの点へ戻さず、束の形と一次証拠を保持して読むことにより、数字・人気・人物の単独支配を避け、可逆・再合意可能な判断を成立させる。

## 因果線

単一指標化 → 指標攻略 → 実質との乖離 → 異質軸の分離 → 束表示 → 監査要旨・構造ログ接続 → 観測窓で更新 → 二層合意と構造的正統性の接続。

## 状態モデル

proposed / defined / evidenced / bundled / interpreted / applied / monitored / contested / reconsensus_required / revised / retired

## 適用

政策評価、組織判断、メディア評価、市民熟議、AI出力監査。

## 測定

一次証拠接続率、定義変更頻度、単一指標再圧縮件数、ゲーミング検出数、欠落軸、監査要旨不一致率、再合意時間、人物依存ドリフト。

## 成立・失敗・反証

成立には異質軸、一次証拠、束表示、公開境界、見直し条件が必要である。総合点化、恣意的定義、証拠なき採点、社会信用化は失敗である。ゲーミング増加、説明可能性低下、恒常的結論逆転、再合意停止、人物依存継続は反証となる。

## 必須の区別

束指標と総合点、多軸評価と指標乱立、公開透明性と攻略可能な査定公開、測定と裁定、比較と人格ランキングを区別する。

## 解釈制約

総合点化、人格ランキング、社会信用化、恣意的非公開、永続固定、証拠なき採点を禁止する。
