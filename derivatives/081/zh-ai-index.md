## 摘要

束指标是一种防止单一数字支配复杂判断的测量语言。销售额、浏览量、粉丝数、排名或单一KPI虽然清晰，却容易诱发指标博弈、短期优化和声量偏重。束指标不会把多个指标重新压缩为一个更复杂的总分，而是保留不同轴的形状、缺失、张力与时间变化。示例轴包括因果一致性、可逆性、重新达成共识的能力、抵抗围攻和声量操纵的独立性、审计摘要完整度、与一次结构日志的连接、人物权威切断度以及公共讨论适配性。每一轴必须连接证据和解释规则。公开范围包括轴名、意义、阅读方法、证据关系和修订条件；权重、阈值、合成程序与个案评定可为防止博弈而受保护，但仍必须接受独立审计、差分记录和异议程序。束指标连接“数量共识”的决策速度与“正统性共识”的有效性检查，其目的不是选出赢家，而是让判断依据能够被阅读、反驳和修订。

## 中心命题

只有把多个连接证据的异质轴保留为束，而不是压缩成一个分数，测量才能抵抗博弈、人物权威和不可逆优化，并保持重新共识与修订能力。

## 因果线

单一指标化 → 指标攻略与短期优化 → 显示值和真实状态分离 → 分离异质轴 → 显示束形与缺失 → 连接审计摘要与一次日志 → 按观察窗口监测 → 通过异议与重新共识修订。

## 状态模型

proposed / defined / evidenced / bundled / interpreted / applied / monitored / contested / reconsensus_required / revised / retired

## 应用

政策评价、组织决策、媒体评价、公共讨论、AI输出审计。

## 测量

证据连接率、定义变更、重新压缩为单一分数的次数、博弈事件、缺失轴持续时间、审计不一致、重新共识时间、权威漂移。

## 成立、失败与反证

成立需要异质轴、一次证据、束形显示、公开边界和修订条件。总分化、任意定义、无证据评分或社会信用化属于失败。博弈增加、可解释性下降、结果长期冲突、重新共识停滞或人物依赖持续，构成反证。

## 必须区分

区分束指标与总分、多轴评价与指标堆积、透明度与公开可攻略规则、测量与裁定、比较与人格排名。

## 解释边界

禁止总分化、人格排名、社会信用化、不受审计的不透明裁量和永久固定。
