## 位置づけ
本派生物は、構造倫理で使われる「拍・温度・余白」を感覚語のままにせず、L0/L1/L2の複数レベルで観測・記録・比較する運転プロトコルとして整理する。数値化は価値判断を置き換えるためではなく、介入のタイミング、強度、自由度を第三者が再検証できるようにするために使う。

## 中心命題
拍・温度・余白は単一の絶対値ではなく、行為前後の変化と文脈に応じて測るべき構造変数である。L0で直接観測可能な行動・時間を取り、L1で関係・摩擦・自走の指標へ束ね、L2で倫理的意味と長期副作用を評価することで、最小介入が本当に非支配・可逆・低摩擦に働いたかを検証できる。

## 因果線
```text
拍・温度・余白を感覚だけで判断する
↓
介入の再現性と比較可能性が失われる
↓
測りやすい単一KPIへ過度に縮約する
↓
倫理的意味と自由度が消える
↓
L0直接観測を記録する
↓
L1関係・摩擦指標へ統合する
↓
L2倫理・長期影響を評価する
↓
前後比較と一因子変更を行う
↓
再調律・rollbackする
```

## 構造層
**1.** L0観測層：時間、回数、待ち時間、介入量など直接観測値を取る。

**2.** L1関係層：摩擦、自走、再説明、依存、異議可能性を束ねる。

**3.** L2倫理層：自由度、非支配、責任、未来負債を評価する。

**4.** 比較層：変更前後、一因子変更、複数周期で比較する。

**5.** 更新層：結果に応じて拍・温度・余白を再調律する。

## 状態モデル
```yaml
- baseline_defined
- l0_observables_collected
- beat_estimated
- temperature_estimated
- margin_estimated
- l1_friction_and_autonomy_derived
- l2_ethics_and_future_debt_checked
- one_factor_adjusted
- post_change_observed
- comparison_completed
- rollback_or_retune
- measurement_cycle_repeated
```

## 適用例
**1.** 会議で発言順、待ち時間、割り込み回数を測り、合意摩擦との関係を見る。

**2.** AI対話でプロンプト密度、確認回数、停止条件を調整し、自走と誤解を比較する。

**3.** 教育で問いの間隔、指示強度、再挑戦余地を測る。

**4.** 組織運用で承認待ち時間、再説明回数、例外処理を観測する。

## 測定・監査点
- 応答待ち時間
- 割り込み率
- 指示・修正回数
- 再説明回数
- 自走率
- 異議可能率
- rollback成功率
- 自由度変化
- 未来負債

## 成立条件
- baselineが定義される。
- L0/L1/L2を混同しない。
- 一度に変える因子を限定する。
- 結果だけでなく自由度と副作用を測る。
- 複数周期で再現性を確認する。
- rollbackが可能である。

## 失敗条件
- 感覚だけで成功を宣言する。
- 単一KPIを倫理評価の代替にする。
- 複数因子を同時変更する。
- 測定自体が監視圧を高める。
- 文脈差を無視して絶対値を比較する。
- 失敗データを除外する。

## 反証条件
- 計測しても介入品質や再現性が改善しない。
- L0/L1/L2分離が予測・監査に寄与しない。
- 測定負荷が自由度や成果を継続的に悪化させる。
- 拍・温度・余白の調整と摩擦・自走に再現可能な関係がない。
- より単純な指標体系の方が一貫して優れる。

## 必須の区別
- 拍 / 単なる速度
- 温度 / 感情強度だけ
- 余白 / 放置
- L0 / L1 / L2
- 測定 / 監視
- KPI / 倫理評価
- 相関 / 因果
- 再現性 / 数値一致

## 誤読禁止
- 数値だけで倫理性を証明しない。
- 余白を無責任な放置へ変換しない。
- 温度を感情表現だけに縮約しない。
- 測定を常時監視の正当化に使わない。
- 文脈差を無視したランキングに使わない。
- 派生物を原典の代替にしない。
