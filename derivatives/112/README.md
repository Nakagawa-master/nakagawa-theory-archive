## 位置づけ

拍・温度・余白は、対話や共同運転の「雰囲気」を形容するだけの語ではない。親原典は三原則を、第三者が同じ観測窓から確認し、逸脱を検知し、最小介入で再調律できるL0/L1/L2計測セットへ翻訳する。目的は、倫理を感じの共有だけに依存させず検証可能にし、介入を強制から最小へ、運転を個人技から手順へ移すことにある。

ここで計測は、人物を格付けするための常時監視ではない。数値や記録は、再合意の窓、対話強度、未確定領域、是正履歴など、構造の状態を共同で観測するために使われる。指標が目的化するとGoodhart化が起きるため、原典は数値の意味、利用範囲、保存・公開条件まで運転仕様に含める。

## 中心命題

```text
拍・温度・余白を抽象語のまま運転する
↓
判断が個人の感覚へ依存し、再現性が落ちる
↓
L0 / L1 / L2で同じ観測窓を共有する
↓
過熱・過冷・余白消失を人ではなく事象として検知する
↓
冷却期間・反証窓・非干渉タグ・SQS等で最小介入する
↓
差分ID・監査束・起源署名で是正履歴を追跡可能にする
↓
構造倫理を再帰的に運転できるOSへ移す
```

## 拍・温度・余白

### 拍（Beat）

拍は、合意サイクルの周期と位相のずれを見る。重要なのは「速いほど良い」ことではなく、次の再合意の窓が見え、対話がそこへ律動的に戻れることである。位相のずれは、合意のタイミングが参加者間でどの程度ずれているかを見る観測対象であり、人物の能力評価へ転用する値ではない。

### 温度（Temperature）

温度は、対話の強度と粘性を見る。断語、割込、皮肉、追及の再帰欠如などの発熱イベント、応答間隔の乱れ、聴取状態などを、人ではなく事象として観測する。温度が高いこと自体を悪とせず、反証や再合意が機能しなくなる過熱と、対話が動かなくなる過冷の双方を見る。

### 余白（Margin）

余白は、未確定領域の可塑性を見る。保留項目、冷却期間、反証窓、まだ結論化しない領域が残っているかを確認する。余白は単なる未決定ではなく、異論・修正・再合意が滞在できる構造的な可動域である。

## L0 / L1 / L2 計測セット

### L0｜市民・一般観測

L0は、専門的な分析の前に、再合意窓が見えるか、異論への応答が過熱していないか、未確定領域が残っているかを即時に確認する。ここでの目的は精密な数値化ではなく、同じ問いを共有して早期の逸脱に気づけることにある。

### L1｜実務ログ・因果追跡

L1は、適用域タグ、冷却期間、反証窓、差分ID、監査束リンク、起源署名リンクなどを最小ログとして残し、位相ずれ、発熱イベント、保留状態の変化を継続的に追う。

原典はこのログにデータ倫理を付す。明示同意、匿名化、案件単位の集計、保存期間、外部公開範囲を伴わせる。**90日ローテーション**はL1ログの保存・ローテーション条件として示される具体的運転値であり、倫理性を証明する普遍的な「90日基準」ではない。測定対象はL1の運転ログ、運用主体は当該ログを扱う実務運転側、利用範囲は追跡・監査・再調律であり、人物評価や他領域への一般保証には使わない。

### L2｜専門監査・境界条件

L2はL1ログをサンプリングし、再現照合と境界条件の逸脱を確認する。原理域、非干渉領域、中間域を分け、各領域で許容される操作と避けるべき操作を照合する。L2はL0/L1より「偉い」階層ではなく、異なる解像度で同一運転を監査する層である。

## SQSと決定係数

**SQS（Silence–Question–Silence）**は、短い沈黙、検証可能な問い、再び沈黙という一周期である。即時反応の連鎖をいったん冷却し、問いの質を上げ、応答を強制しないために使う。

**決定係数**は、意思決定に必要な最小項目セットがどの程度満たされているかを見る比率である。これは「高いほど倫理的」という人格スコアではなく、過冷による停滞や、余白が消えて必要条件の確認なしに結論へ進む状態を識別するための運転指標である。項目集合と観測条件を明示せず、数値だけを独立して比較しない。

## 発熱イベント辞書

発熱イベント辞書は、断語、割込、皮肉、追及の再帰欠如など、温度を上げる出来事を共通語彙で記録するためのものだ。タグは人物へ貼るのではなく、観測された事象へ付す。これにより「誰が悪いか」ではなく「どの出来事が再合意を阻害したか」を監査できる。

## 是正プロトコル

### 過熱

冷却期間を延長し、反証窓を提示し、本文側の説明過多を減らして詳細を監査束へ移す。目的は議論を止めることではなく、反証可能性を回復することにある。

### 過冷

合意窓に時限を置き、決定係数を可視化し、Yes/Noだけではない検証可能な問いを再導入する。目的は決定を急がせることではなく、停滞の理由を観測可能にすることである。

### 余白消失

非干渉タグを再付与し、保留セクションを設け、SQSを導入する。未確定領域を再び構造へ戻し、結論化の圧力を下げる。

## Goodhart耐性

原典は、計測値が目標そのものへ変わる危険を明示的に扱う。各指標には「何を守るための数値か」を添え、指標を固定し続けずローテーションし、一部を観察記述へ戻す。ボーナスや人事評価へ直接連動させない。つまり、測定値は共同運転の診断材料であり、倫理的人格や組織価値の単一ランキングではない。

## 導入の流れ

1. L0点検で拍・温度・余白の状態を確認する。
2. 複数の逸脱が見える場合、冷却期間・合意窓・非干渉タグなどから最小介入を選ぶ。
3. L1ログ、差分ID、監査束、起源署名へ是正痕跡を接続する。
4. L2でサンプリング監査と境界条件を確認する。
5. 指標が目的化していないか、ログの同意・匿名化・保存・公開範囲が守られているかも再監査する。

## 成立条件と反転評価

この運転が成立するには、異なる観測者が同じ窓から近い判断へ到達でき、逸脱の理由と是正履歴を追跡でき、是正後に再合意・反証・余白が回復する必要がある。逆に、計測項目が増えても第三者が判断を再現できない、ログが人物評価や監視へ転用される、数値目標が目的化する、非干渉領域へ最適化を押し込む、差分ID・監査束・起源署名から是正履歴を追えない場合、運転仮説は弱まる。

## 必須の区別

- 拍 / 単なる速度
- 温度 / 感情の善悪
- 余白 / 放置
- L0 / L1 / L2 / 人の格付け
- 計測 / 常時監視
- 決定係数 / 人格スコア
- 90日ローテーション / 普遍的な倫理基準
- 最小介入 / 無介入
- Goodhart耐性 / 数値拒否
- 監査可能性 / 全面公開

## 親原典へ戻る理由

具体的なL0点検票、L1ログ列、同意・匿名化・保存期間・公開範囲、L2サンプリング監査、境界条件表、発熱イベント辞書、SQS、決定係数、是正手順、Goodhart耐性は一体の運転仕様である。特に数値・周期・比率を実装するときは、その測定対象、観測主体、利用範囲、非保証範囲をParent URLで確認し、数値だけを切り離さない。
