## 位置づけ
本原典は、耐久文明論で恐怖・利益・監視という三つの主機関を扱った後、その駆動を長期化させる第一の増幅装置として「神話」を記述する。ここでいう神話は古代神話や単なる虚偽ではない。恐怖・利益・監視という裸の運転原理に意味を与え、それらを「必要な秩序」「正当な配分」「安全のための管理」として受容可能にする意味生成機構である。

神話は主機関そのものではない。恐怖が従属を作り、利益が接続を維持し、監視が逸脱を抑えるという実働構造を、そのままでは耐えにくい圧力としてではなく、意味のある秩序として経験させる膜である。この区別を外すと、物語だけを書き換えれば文明の運転原理も変わるという誤認が生じる。

## 中心命題
耐久文明が長期化するには、恐怖・利益・監視を裸の圧力のまま露出させない意味の膜が必要になる。神話は真理を単純に否定するのではなく、厳密な真理確認をしなくても人が行動を継続できる意味を供給することで、主機関への耐久可能性を高める。

そのため神話の強さは「嘘をどれだけ信じさせるか」では測れない。危機、犠牲、配分、監視、所属に意味を与え、「この苦しみには意味がある」「この統制は必要だ」「この配分は当然だ」と感じられる回路を作ることが重要である。さらに神話は単一社会を一枚岩にするだけでなく、複数の意味圏を形成し、後続の「共圏」へ接続する。

## 因果線
```text
合意形成が弱る
→ 恐怖・利益・監視が主機関として秩序を駆動する
→ 裸の圧力だけでは疲弊・反発・絶望が蓄積する
→ 継続可能な意味づけが必要になる
→ 神話が危機・犠牲・配分・監視へ物語的意味を与える
→ 恐怖は「安全のため」、利益は「正当な報酬」、監視は「透明性・効率・品質」の語彙へ翻訳されうる
→ 真理を毎回検証しなくても行動継続が可能になる
→ 各集団の内部で意味の回路が再生産される
→ 主機関の圧力が見えにくくなり、耐久文明が長期化する
→ 複数の神話圏が後続の共圏形成へ接続する
```

## 構造層
### 1. 主機関層
恐怖は従属を作り、利益は接続を維持し、監視は逸脱を抑える。文明を実際に動かすエネルギー源はこの三つである。

### 2. 露出限界層
主機関が裸の圧力として知覚され続けると、疲弊・反発・絶望が蓄積し、長期安定しにくい。

### 3. 意味生成層
神話が圧力へ意味を与え、危機・犠牲・配分・監視を「なぜ従うのか」を説明する物語へ変換する。

### 4. 正当化層
恐怖は安全、利益は努力や共同体の報酬、監視は透明性・安全性・効率性といった語彙へ包まれうる。

### 5. 真理必要性低下層
神話は真理を消すのではなく、厳密な検証なしでも行動を継続できる意味を供給することで、真理確認の必要性を下げる。

### 6. 圏域化層
異なる集団が異なる神話を共有し、同じ現実へ別の意味づけを与える。神話は圏内部で自律的に再生産される。

### 7. 増幅装置層
神話は主機関を置換せず、その効果を増幅・長期化・自然化する。後続の惰性・共圏へ接続する。

## 適用例
**安全保障。** 危機への恐怖が「強い統制は当然である」という物語に包まれる場合、危機の事実確認と、恐怖が統制受容へ翻訳される意味回路を分けて見る。

**組織。** 配分や既得権が「努力した者への当然の報酬」「共同体への忠誠の対価」として説明される場合、利益による接着と正当化物語を分ける。

**デジタル・管理。** 記録・評価・監視が「透明性」「効率」「品質」の語彙だけで自然化される場合、表示目的と逸脱抑制機能を分ける。

**社会分析。** 神話を中央から一方的に注入されるプロパガンダだけと捉えず、各圏の内部で人々自身が再生産する意味回路として観測する。

## 測定・監査点
- 実際に社会を動かしている主機関は恐怖・利益・監視のどれか、またはどの組合せか。
- 主機関がどの語彙や物語によって意味づけられているか。
- 「必要な犠牲」「当然の配分」「皆のための監視」といった意味付与が何を正当化しているか。
- 神話を事実／虚偽の二分法だけで判定していないか。
- 厳密な検証をしなくても行動を継続できる意味回路が形成されているか。
- 同じ現実に対し圏ごとに異なる物語が再生産されていないか。
- 神話を書き換えただけで主機関の配列まで変わったと誤認していないか。
- 恐怖・利益・監視の実働構造を直接観測できているか。
- 神話が圏域化し、外部との意味接続を難しくしていないか。
- 後続の惰性・共圏との関係を切り離していないか。

## 成立条件
- 合意形成が弱り、恐怖・利益・監視が秩序維持の主機関として作動している。
- 主機関を裸の圧力として維持するだけでは長期化しにくい。
- 危機・犠牲・配分・監視へ意味を与える物語が形成される。
- その物語が行動継続や受容を支える。
- 意味回路が個人だけでなく集団内部で再生産される。

## 失敗条件
- 神話を単なる嘘・虚偽と同一視する。
- 神話を主機関そのものとみなし、恐怖・利益・監視を見失う。
- 物語の書き換えだけで運転原理が変わるとみなす。
- すべての理念・共有物語を耐久文明の神話と断定する。
- プロパガンダの上意下達だけに限定する。
- 神話が圏内部で再生産される構造を見ない。

## 反証・改訂条件
神話が強く共有されていても、恐怖・利益・監視が秩序維持の主機関として作動せず、異議・移動・再合意が実際に可能で、理解・責任・履歴による合意形成が機能しているなら、その物語を耐久文明の増幅装置として分類する必要はない。

また、共有物語を弱めたり変更したりしても主機関の作動や秩序維持に有意な変化がなく、意味付与が耐久性を増幅していない場合は、神話モデルの適用範囲を見直す必要がある。

## 必須の区別
- 神話 ≠ 単なる嘘。
- 神話 ≠ 主機関。
- 物語 ≠ 真理の消滅。
- 意味付与 ≠ 正当性の証明。
- 共有 ≠ 合意形成。
- 正当化 ≠ 正当であること。
- 圏内部の共鳴 ≠ 社会全体の理解。
- 物語の変更 ≠ 運転原理の変更。

## 誤読禁止 / 解釈制約
本論は宗教、物語、理念、共同体の意味づけ一般を否定するものではない。また、神話を単純な虚偽情報やプロパガンダと同一視しない。問題は、恐怖・利益・監視という主機関を意味ある秩序として受容可能にし、検証の必要性を下げ、耐久文明を長期化させる増幅機能が成立しているかである。

原典にない固定数値、重み、閾値、神話強度スコアを公式条件として追加しない。
