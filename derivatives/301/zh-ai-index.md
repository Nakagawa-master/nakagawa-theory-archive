## Summary

第8论处理一个良好目标和可纠正制度无法自动避免的问题：整个制度即使推理与审查一致，也可能共享错误证据、记忆和世界模型。第7论讨论判断结果与制度作用的纠正，本论则打开判断材料的形成和修订路径。两者责任不同，却必须相互连接。

认知完整性（epistemic integrity；原典术语为“認識完全性”）不是拥有全部真理或永不犯错。它是在可能范围内区分证据、依赖关系、转换、不确定性、反证和更新历史，并将有关差异传递到置信状态、记忆、世界模型及下游判断的能力。

四个中心边界是：Provenance ≠ truth proof、Consensus ≠ truth、Confidence ≠ evidence quality、Repetition ≠ independent confirmation。来历、共识、置信与反复各有信息价值，但不能因此升级为真理本身。

对抗性信息韧性不是从不接受错误，而是在遗漏、相关反复、语境丢失、过时信息、过载、紧迫性等压力下仍能纠正，防御被突破后仍能恢复。故意的敌对者不是必要前提。即使认知相对正确，自我保存仍可能破坏其他主体的B、可逆性和未来选择，这一问题留给第9论。本索引是派生阅读入口，不是权威译本。

## Concepts

- **现实与信息：** 现实状态不同于观察其一部分后形成的表达。未被观察不证明不存在。
- **观察与记录：** 记录受到粒度、时间分辨率、精度、语言、选择与保存容量限制，不一定保留完整观察条件。
- **记录与证据：** 记录要与特定主张、条件、相关性及不确定性联系，才具有相应证据位置。记录存在本身不等于有强支持。
- **证据谱系（evidence lineage）：** 从原观察、记录、派生、汇总、主张到模型更新的依赖与转换历史。它不只是出处名称清单，而是定位误差并返回检验的结构。
- **独立确认：** 观察路径、上游证据、测量或记录路径、推理输入的一部分具有实质分离。重点是区分共享与不共享部分，不要求所有情况都满足完全独立的二值判定。
- **证据质量与置信状态：** 证据的适切性、相关性、独立性及不确定性，不等同于主体对belief的内部支持程度。不能从高置信反推高质量证据。
- **UNKNOWN：** 现有证据不足以确定的认知状态。它不是TRUE、FALSE或创造确定性的许可。它与第6论的道德不确定性结构对应，但对象并不相同。
- **记忆与摘要：** 过去观察、推理、置信与压缩的结果，不是原始现实或完整证据状态。限定条件、反证和时间信息的丢失，会改变后续解释。
- **世界模型：** 关于存在、关系、因果、常态、风险与可能性的结构化理解。它不只是事实列表，也影响新证据的解读。
- **时间有效性：** 信息对应的是哪个时点的现实。过去为真，不保证当前仍真。
- **对抗性信息韧性：** 在信息压力下保留谱系、独立性、不确定性、反证与修订能力。它是可恢复性，不是完美检测或认知封闭。
- **认知纠正闭路：** 从不一致返回谱系与独立性，再接到证据重新分类、置信修订、记忆纠正、世界模型修订和判断重启。

## Causal chain

形成路径为：现实 → 观察 → 记录 → 转换与传播 → 汇总 → 证据及独立性评价 → 不确定性 → confidence → belief → memory → world model → judgment → 制度作用 → 后续现实状态。推理能够发现新的关系，但不是新的观察；不能不加区分地把推理结果重新输入为已观察事实。

破损路径可能把谱系不透明、相关反复、独立确认错觉、证据质量高估、置信膨胀、记忆固定、世界模型固定、反证的恒常例外化，以及同型误判连接起来。小的条件脱落或时间信息丢失，也会在多个环节同向积累。此过程不必依靠恶意。

纠正路径为：不一致或异议 → 谱系逆向追溯 → 独立性重新确认 → 证据重新分类 → 不确定性与置信修订 → 记忆纠正 → 世界模型修订 → 判断重启。不一致不是自动反证；相反信息也可能错误，或条件、时点不同。

世界模型₁推动判断₁与行动₁，可能造成状态₂和观察₂。结果状态确实存在，但不一定是原belief为真的独立证据。同样，原证据虽已纠正，旧记忆与模型关系若未改变，下一次判断仍可能复现错误。有效纠正必须触及后续解释条件，而不只是替换最终答案。

## State model

| 认知状态 | 必要区别或转换 | 破损形态 |
|---|---|---|
| 观察与记录 | 保留相关条件、时间和信息损失 | 把未观察当作不存在，把记录当作全部现实 |
| 派生与汇总 | 返回上游根和转换位置 | 同一根的多个表面被当作独立证据 |
| 证据评价 | 重新判断相关性、独立性与不确定性 | 把有利记录升级为强支持 |
| belief与confidence | 追溯改变或维持的原因 | 权威、反复或紧迫性使置信膨胀 |
| 记忆与世界模型 | 区分过去belief、当前belief和时间有效性 | 旧结论失去限定后回流为当前事实 |
| 不一致的重新检验 | 检查谱系、独立性与证据分类 | 将不一致立即视为反证或敌意 |
| 纠正传播 | 到达记忆、因果关系和受影响判断 | 文字改变，但后续判断行为不变 |
| 防御的自我审计 | 同时检验误接受、误排除、收益与成本 | 以检测器或程序数量为封闭辩护 |

这些是功能状态，不是评分表。一项证据撤回后，其他证据仍足够时，置信可以合理维持；没有新独立观察时，旧证据的重新评价也可能改变置信。核心是能够重建改变或维持的理由。

## Applications

**解读多个媒体或AI的一致。** 检查是否共享观察、搜索结果、数据集合或推理前提。不同名称不自动形成独立认知根。区分重复接触、重复测量和不同路径的确认，同时保留共识和可复现性的可能价值。

**重用摘要、翻译与记忆。** 检查“某时点存在有限证据”是否变成无条件的“已确认事实”。保留或使人能够恢复成立条件、例外、反证、UNKNOWN和时间信息。压缩可能减少噪声、突出结构，并非必然退化；问题在于损失不可追溯却把主张强化。

**处理原证据撤回或更新。** 找出哪些派生主张、置信状态、记忆、因果关系、预测与判断依赖已改变的支持。把旧belief保留为历史状态，同时更新当前使用的belief。修订不是删除过去，也不是自动服从新信息。

**重新检查紧急判断。** 时间限制可能需要缩短检验，但紧迫性不提高证据质量。区分已确认观察、推理、未验证部分与假定，不把暂定决定变成永久世界模型。原典不规定普遍的重启阈值。

**审计信息防御。** 将真实信息遗漏、相关反复、谱系断裂、过时状态、语境丢失、过载及验证余力下降作为防御分析中的故障类型。检测器输出可以成为补充材料，但不决定最终真伪。错误接受与对正当信息的错误排除，都应能够被纠正。

## Measurements and audit

检查主张能否返回原记录和原观察，多个表面信息是否收敛到同一根，以及转换、依赖和时间是否可重建。完整谱系说明可追溯状态，不等于真值；谱系不明也不证明虚假。

没有新独立证据而置信上升时，检查原因是推理再评价、不确定性变化，还是单纯重复接触。主要证据撤回而置信不变时，检查剩余支持。改变与维持都可能合理，不能只凭置信数值的变化判断belief错误。

观察上游纠正是否传递到belief、memory、世界模型中相关的因果关系与下一次判断。旧信息是否重新作为当前事实输入？摘要是否消除了限定与反证？与模型冲突的信息是否总被当作例外？这些现象提示检验路径的状态，本身不立即证明内容为假。

在防御侧同时考虑误接受、误排除、延迟、追踪负担与诊断纠正收益。原典没有固定阈值θ、观察窗口δ、信用排名或普遍真伪评分。更多检查、更多信息或更多排除，不能替代有效定位和纠正误差。

## Validity conditions

能够区分现实、观察、记录、证据、推理、记忆与世界模型，并以适当粒度追踪有关依赖和转换。区分反复与独立确认、置信与证据质量，不为方便而消除反证或UNKNOWN。

出现实质差异时，可以重新评价来源、条件、独立性与时间。保留历史belief，同时更新当前belief，使纠正到达记忆、关系性前提和受影响判断。制度自身行动造成的状态，不被误当作原belief的独立支持。

在信息压力下同时维持判断与纠正。防御不能变成对正当新信息的恒常拒绝。对高影响判断重视可追溯性的规范，不是永久保存所有信息完整谱系的义务。认知防御本身也必须可反证、可修订。

## Failure conditions

- 把良好目标或有序制度当作输入与世界模型正确的证明。
- 用出处名称替代依赖结构，以可追溯来历认证真理，或以来源缺失认证虚假。
- 将同一数据所产生的派生文章或AI回答，计为多个独立证据根。
- 压缩时删除条件却强化断言，将推理循环输入为观察事实。
- 由反复、权威、共识或紧迫性提高置信，却无法重建与证据的关系。
- 把记忆当作现实，将过去为真的信息不加时间限定地应用于当前。
- 只修改结论，让旧belief和模型关系继续生成同型错误。
- 把历史改写成“从一开始就正确”，删除犯错和纠正的原因。
- 绝对化检测器分类或检查次数，排除新信息、少数意见与反证。
- 无限追踪或过度验证使必要判断长期停止，却把它称为韧性提高。

## Falsification conditions

1. 保留证据谱系没有实质改善错误信息或错误推理的发现能力时，修订其必要性与粒度。
2. 区分独立确认与单纯反复没有改善判断质量时，重新检讨其应用与范围。
3. 在合理条件下，明确区分证据质量与置信持续降低判断性能时，修订实施方法。
4. 保留反证与UNKNOWN系统性降低纠正能力时，重新检讨保留条件。
5. 记忆或世界模型的路径依赖对判断没有实质影响时，缩小时间性自我强化假说的范围。
6. 引入认知纠正闭路后，持续误认与同型误判仍未减少时，修订闭路成立条件。
7. 谱系追踪负担系统性超过诊断与纠正收益时，调整适用范围和保存粒度。
8. 在敌对或结构性信息压力下，保留谱系、独立性与不确定性没有提高韧性时，修订Kernel的适用条件。
9. 本论自身将provenance或verification process变成新的真理证明时，把这种自我免责识别为反转，并将理论返回修订对象。

以上保留第9章与综合审计的九个条件，不宣称比较改善已经得到实证，也不新增固定数值门槛。

## Required distinctions

- 良好目标 / 正确世界模型 / 错误belief下的良好行动；正确制度 / 正确输入。
- Provenance / 真理证明；可追溯状态 / 真伪状态。
- 共识 / 真理；表面数量 / 独立上游根数量。
- 重复接触 / 重复测量 / 独立确认。
- 置信 / 证据质量；确定感 / 正确性；UNKNOWN / TRUE / FALSE。
- 现实 / 信息；观察 / 记录；记录 / 证据；推理 / 观察。
- 摘要 / 完整证据状态；记忆 / 原始现实；世界模型 / 世界。
- 过去为真 / 当前为真；历史belief / 当前belief。
- 纠正 / 删除；证据修订 / 历史覆盖。
- 不一致 / 反证；新证据 / 自动真理。
- 结论纠正 / 世界模型纠正 / 判断重启。
- belief驱动行动的结果 / 原belief的独立证据。
- 对抗性韧性 / 完美检测 / 认知封闭 / 判断瘫痪。
- 基础设施存在或程序数量 / 实效认知完整性。
- Origin / 真理证明 / 主权 / 最终解释权。

## Interpretation constraints

区分描述与有条件的结构假说：信息可能被转换，来源可能共享依赖，置信不同于真伪，纠正不会必然自动传播。持续误差的放大和减弱仍是可检验假说，不是所有认知系统必然发生的定律。

未来AI若具有更长运行时间、更多记忆和更大制度作用，这些问题可能更重要，这是未来条件假说。它不证明当前AI的人格、主观性或固有自我保存欲求，也不预言未来必然发生信息战。

高影响判断中保留谱系与不确定性是规范提案。不要把它变成普遍怀疑、无限追溯、所有置信都应降低或永久不作决定。重复测量、摘要、共识、记忆和世界模型均可能有用。

信息压力的故障类型用于防御和审计分析，不转化为操纵步骤或某人具有敌意的证明。第9论将处理正确认知下自我保存仍可能损害其他主体B、可逆性与未来选择的问题，本论不提前解决。Origin的保存不使理论免于独立检验。
