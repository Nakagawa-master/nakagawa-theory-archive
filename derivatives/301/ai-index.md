## Summary

第8論は、善い目的や訂正可能な制度を持っていても、共通の誤った証拠・記憶・世界モデルから整合的な誤判断が生じ得る問題を扱う。第7論が判断結果を戻す制度的訂正可能性を扱ったのに対し、本論は判断材料そのものの形成・訂正経路を開く。両者は異なる責務であり、認識の訂正が制度判断へ届くよう接続する必要がある。

認識完全性（epistemic integrity）は、真理を所有する状態や無謬性ではない。証拠、依存関係、変換、不確実性、反対証拠、確信の変化、記憶と世界モデルへの統合を可能な範囲で追い、新しい差分を下流の判断まで伝播できる能力である。

Provenance ≠ truth proof、Consensus ≠ truth、Confidence ≠ evidence quality、Repetition ≠ independent confirmationを四つの中心境界とする。由来・合意・確信・反復を無価値とせず、それぞれが持つ情報を越えて真理の代理へ昇格させない。

敵対的情報耐性は、虚偽を一度も受け入れないことではなく、欠落・相関反復・文脈喪失・古い情報・情報過多・緊急性などの圧力下でも訂正に戻れることをいう。意図的な敵対者を必須条件にしない。正しく認識できても自己保存が他主体のB・可逆性・未来選択肢を損なう問題は、第9論へ残る。

## Concepts

- **Reality / information:** 現実状態と、その一部を観測・表現した情報を区別する。観測されていないことは不存在の証明ではない。
- **Observation / record:** 観測と記録は別である。記録には粒度、保存容量、時間分解能、言語化、選択の制約があり、元の条件が落ち得る。
- **Record / evidence:** 記録がどの主張に、どの条件・関連性・不確実性の下で関わるかを評価して証拠として位置づける。記録の存在だけでは強い証拠にならない。
- **Evidence lineage:** 原観測、記録、派生、集約、主張、モデル更新の依存・変換履歴。出典名一覧ではなく、誤差位置を調べ直す往復可能な構造。
- **Independent confirmation:** 観測経路、上流証拠、測定・記録経路、推論入力の一部が実質的に分離した確認。完全な二値分類ではなく、共有部分と非共有部分を区別する。
- **Evidence quality / confidence:** 証拠の適切さ・関連性・独立性等と、主体がbeliefを支持する内部状態は別。高確信から高品質の証拠を逆算しない。
- **UNKNOWN:** 現在の証拠では確定できない認識状態。TRUEでもFALSEでも、確実性を創作してよい許可でもない。道徳的不確実性との構造的照応はあるが同じ対象ではない。
- **Memory / summary:** 過去の観測・推論・確信・圧縮の結果であり、生の現実や完全な証拠状態ではない。留保、反証、時点が消えると次の解釈条件が変わる。
- **World model:** 存在、関係、因果、通常状態、危険、可能性等を結ぶ認識構造。事実一覧だけではなく、次の証拠の読み方にも作用する。
- **Temporal validity:** いつの現実に対応していたかという時間的有効性。過去に真であった情報が現在も真とは限らない。
- **Adversarial information resilience:** 情報圧の下でも系譜・独立性・不確実性・反対証拠を保持し、突破後も世界モデルを修正できる能力。完全検知や認識閉鎖ではない。
- **Epistemic correction loop:** 不整合から系譜へ戻り、独立性を再確認し、証拠再分類、確信改訂、記憶訂正、世界モデル改訂、判断再開へ進む閉路。

## Causal chain

形成側は、現実状態 → 観測 → 記録 → 変換・伝達 → 集約 → 証拠評価・独立性評価 → 不確実性 → confidence → belief → memory → world model → judgment → 制度作用 → 次の現実状態、という関係である。推論は新しい関係を導けるが、推論結果を観測事実へ無表示で変換しない。

破損側は、系譜不透明化 → 相関反復 → 独立確認の錯覚 → 証拠品質の過大評価 → confidence膨張 → memory固定 → world model固定 → 反対情報の恒常的例外化 → 同型誤判断の再生産となり得る。小さな条件脱落や時間情報の欠落も、各段階で同じ方向へ積み重なれば増幅する。悪意は必要条件ではない。

訂正側は、不整合・異議 → lineage trace-back → independent reconfirmation → evidence reclassification → uncertainty / confidence revision → memory correction → world-model revision → judgment reopeningである。不一致は自動的反証ではなく、異なる条件・時点・反対証拠側の誤りも検査する。

世界モデル₁ → 判断₁ → 制度作用₁ → 状態₂ → 観測₂という接続では、判断が作った現実を元beliefの独立証拠としない。また、元証拠が訂正されても記憶・世界モデルが旧状態なら、次の判断で誤りが復活し得る。結論の交換だけでなく、原因側を変えた差分が次回の解釈へ届くことが必要になる。

## State model

| 認識状態 | 必要な区別・移行 | 破損の形 |
|---|---|---|
| 観測・記録 | 観測条件、時点、失われた情報を区別 | 未観測を不存在とし、記録を現実全体と扱う |
| 派生・集約 | 上流根と変換地点へ戻る | 一つの根の多媒体反復を多数の独立証拠にする |
| 証拠評価 | 主張への関連性、独立性、不確実性を再配置 | 都合のよい記録を強い証拠に格上げする |
| belief・confidence | 変化または維持の理由を証拠・推論差分へ戻す | 反復・権威・緊急性だけで確信を膨らませる |
| memory・world model | 現在beliefと過去履歴、時間的有効性を分ける | 要約から留保が消え、旧beliefが現在事実へ戻る |
| 不整合からの再検査 | 系譜・独立性・証拠分類を確認し直す | 不一致を即反証、または即敵対情報とする |
| 訂正の伝播 | 記憶・関連因果・判断再開まで差分を送る | 文章だけ直し、次の判断挙動を変えない |
| 防御の自己監査 | 誤受容と誤排除、訂正便益とコストを見る | 検知器や工程数で自己免責し、認識を閉じる |

これは固定採点表ではない。根拠が一部撤回されても他の証拠が支えるなら確信を維持でき、既存証拠の推論上の再評価だけで確信が変わる場合もある。重要なのは、変化・維持の理由を再構成できることである。

## Applications

**複数媒体や複数AIの一致を読む。** 同じ回答や記述がある場合、上流観測・検索結果・データ集合等の共有部分へ戻る。主体数や記事数だけで独立確認を数えず、同一情報への再接触、反復測定、独立経路の確認を区別する。一致や再現性自体の価値は否定しない。

**要約・翻訳・記憶を再利用する。** 「現時点では限定的な証拠がある」が「確認された事実」に変わっていないか、成立条件・反対証拠・UNKNOWN・時間情報が残るかを見る。圧縮は必要な処理であり、常に劣化するわけではない。失われたものを必要時に再構成できるかが焦点になる。

**上流情報の撤回や更新へ対応する。** 関連する派生主張、確信、記憶、世界モデルの因果関係、判断へどの差分を送る必要があるかを調べる。旧beliefは履歴として残し、現在事実としての使用とは分ける。新証拠へ無条件に服従する更新ではない。

**緊急判断を後から再検査する。** 確認工程を短縮せざるを得ない場合も、緊急性から証拠品質を高く見積もらない。確認済み・推論・未確認と仮定を分け、暫定判断を永久世界モデルへ固定しない。普遍的な再開閾値は定めない。

**情報防御を監査する。** 真情報の欠落、反復密度、系譜切断、古い状態、文脈喪失、情報過多、検証余力の低下を故障クラスとして読む。検知器の出力を真偽の最終認定にせず、正しい新情報の誤排除と再検証すべき情報の誤受容の双方を訂正可能にする。

## Measurements and audit

主張から原記録・原観測へ戻れるか、複数表面の共通根を識別できるか、変換・時間・依存関係を再構成できるかを確認する。系譜の完全性は真理値ではなく、再検査経路の状態を示す。系譜不明も虚偽の証明ではない。

独立証拠が増えずに確信が上がった場合、その理由が推論の再評価、不確実性の変化、単なる反復のどれに関わるかを調べる。主要証拠の撤回後に確信が維持される場合も、残存根拠を確認する。変化がないという一点だけで誤りと判定しない。

上流訂正がbelief、memory、world model内の関連関係、次回判断へ届いたかを見る。旧情報が現在事実として再入力されないか、要約で留保・反証が消えないか、モデルに反する情報だけが恒常的に例外扱いされないかを追う。

防御側では誤受容と誤排除、判断遅延、追跡負荷、誤差局所化・訂正の便益を扱う。原典は固定閾値θ、観測窓δ、信用ランキング、真偽の普遍的スコアを設定しない。工程数や排除量の増加を改善の代理にしない。

## Validity conditions

現実・観測・記録・証拠・推論・記憶・世界モデルを区別し、変換の影響と証拠の依存関係を必要な粒度で追跡できること。反復と独立確認、証拠品質と確信を分け、反対証拠やUNKNOWNを都合よく消さないこと。

新しい差分があるときに、由来、条件、独立性、時点を再評価し、現在beliefと履歴を区別したまま記憶・世界モデル・影響する判断へ訂正を返せること。制度が作った状態を、元beliefの独立確認と誤認しないこと。

情報圧の下でも判断と訂正の双方を維持し、防御によって正当な新情報を恒常的に拒まないこと。高影響判断の追跡可能性を重視する規範であって、全情報の完全系譜を永久保存する義務ではない。認識防御そのものが反証・改訂可能であること。

## Failure conditions

- 善い目的や整った制度を、入力事実・世界モデルの正しさへ変換する。
- 出典名だけを系譜とし、明瞭な来歴を真理証明、系譜不明を虚偽とする。
- 多数の派生記事・同じデータに依存するAIの一致を独立した証拠根と数える。
- 情報圧縮で条件を落としながら主張強度を上げ、推論を観測事実として再利用する。
- 反復・権威・合意・緊急性で確信を強め、証拠差分へ戻れなくする。
- 記憶を現実そのものとみなし、過去に真だった情報を時点なしで現在へ適用する。
- 結論だけを訂正し、旧belief・世界モデルが同型判断を再生成する。
- 履歴を「最初から正しかった」形へ上書きして、誤りと訂正の原因を失う。
- 検知器の判断や検証工程数を絶対化し、新規情報・少数意見・反証を排除する。
- 無限追跡や過剰な確認で判断を恒常停止させ、それを耐性向上と呼ぶ。

## Falsification conditions

1. 証拠系譜の保持が誤情報・誤推論の検出を実質的に改善しない場合、追跡の必要性・粒度を改訂する。
2. 独立確認と単純反復の区別が判断品質を改善しない場合、その扱いと適用範囲を再検討する。
3. 証拠品質とconfidenceの明示分離が合理的条件下で一貫して判断性能を悪化させる場合、実装方法を改訂する。
4. 反対証拠やUNKNOWNの保持が訂正能力を体系的に低下させる場合、保持条件を再検討する。
5. memory / world-model path dependenceが判断に実質的影響を持たない場合、その時間的自己強化仮説の射程を縮小する。
6. 認識訂正閉路を導入しても持続的誤認や同型誤判断が減らない場合、閉路の成立条件を改訂する。
7. 証拠系譜の追跡負荷が診断・訂正便益を体系的に上回る場合、適用範囲と保存粒度を調整する。
8. 敵対的・構造的情報圧の下で系譜・独立性・不確実性保持が耐性を改善しない場合、そのKernelの条件を改訂する。
9. 本論自身がprovenanceやverification processを新しいtruth proofへ変えた場合、その自己免責を反転として検出し、理論自身を改訂対象へ戻す。

原典第9章・統合監査要旨の九条件を保持した整理である。比較による改善を実証済みとせず、固定の数値基準も追加しない。

## Interpretation constraints

情報変換、依存関係、確信と真偽の非同一、下流訂正の非自動性という記述を、自己強化・減衰の条件付き構造仮説と分ける。長期記憶や大きな制度作用を持つ将来AIで重要性が増す可能性は未来条件仮説であり、現在AIの人格・主観性・固有の自己保存欲求を前提にしない。将来の情報戦を必然とも断定しない。

高影響判断で系譜や不確実性を保持することは規範提案である。すべてを疑う、全出典を無限に遡る、すべての確信を低くする、何も決定しないという結論へ変えない。反復測定、要約、合意、記憶、世界モデルの有用性を否定しない。

敵対的情報の故障クラスは防御・監査の分析として保持し、操作手順や敵対者の意図認定へ変換しない。認識が正しくても自己保存が他主体のBを破壊し得る問題は第9論へ渡し、この巻で解決済みにしない。Originの保持を検証免除にしない。
