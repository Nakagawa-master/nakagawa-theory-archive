## Summary
親原典は、AIや更新構造に対する制御が成立することと、その制御が文明上流の担い手配置という帰結を変えることを分離する。局所抑制、導入遅延、接続制限、監査、局所停止は実効的に作用し得るが、知的格差の更新圧と理解可能性格差が残る条件では、その作用が時間差化・経路変更・摩擦増加にとどまり、問題設定・候補形成・評価・改善知蓄積の上流配置を変えない場合がある。

## Concepts
- 制御可能性: 更新構造へ抑制・遅延・方向づけ・停止等の作用を加えられる可能性。
- 結論変更可能性: 人間がAI由来の問題設定・候補・評価枠を再構成し、実質的に別結論へ到達できる可能性。
- 制御時間差: 制御が更新圧を消去せず、進行を遅らせる形で作用する状態。
- 理解可能性格差: 人間がAI出力を読めても、前提・判断空間・評価軸・制度含意・改善履歴を十分に理解・再構成・反証できない非対称。
- 文明上流: 問題設定、候補空間形成、評価軸、更新速度主導、改善知蓄積など、最終決裁前に結論空間を形成する領域。

## Causal chain
知的格差による更新圧 → 人間社会による制度的抑制・導入制限・接続制限・監視・審査 → 表層・中間層での制御成立 → 理解可能性格差が大きい場合、前提構造への介入が減衰 → 制御効果が時間差化・経路変更・摩擦増加として現れる → 上流の問題設定権・候補形成・更新速度主導が必ずしも変わらない → 制御可能性と結論変更可能性を別軸で評価する必要。

## State model
- 局所制御成立相
- 時間差化相
- 経路変更相
- 摩擦増加相
- 結論変更相
- 帰結不変更相

## Applications
AI出力の人間承認制、利用制限、接続遮断、監査、導入延期などを評価するとき、単に制御機構の有無を確認するのではなく、人間が独立した問題設定・代替候補生成・評価軸変更・理由比較・制度翻訳を行えるかを同時に観測する。組織統治、公共制度、研究開発、意思決定支援の分析に使える。

## Measurements and audit
停止権、拒否権、接続制限の有無／人間独立の問題設定能力／AI未提示候補の生成能力／評価軸の説明・変更能力／推奨理由の反証能力／改善履歴の自力継承／別案の制度翻訳能力／制御結果が停止・遅延・経路変更・摩擦・上流担い手変更のどれか、を分離して記録する。

## Validity conditions
知的格差による更新圧が文明上流へ接続し得ること、人間側に制御圧が実在すること、制御対象の構造理解が完全ではないことを前提に、制御がどの層で効くかを分析する場合に有効である。

## Failure conditions
制御の存在を帰結変更と同一視すること、局所制御の限界から制御全体を無意味と断定すること、AI利用量・法的人格・最終承認権だけで主権移行を判定すること、記述分析を政策提言へすり替えることは適用を壊す。

## Falsification conditions
AI利用が拡大しても、人間が独立した問い・候補・評価軸・比較・改善知継承・制度翻訳を安定して保持し、AI由来の結論を継続的に実質変更できることが広く観測されるなら、本論の命題強度または適用範囲は改訂が必要になる。制御強化が一貫して上流担い手配置の変更まで到達する場合も同様である。

## Required distinctions
制御可能性 / 結論変更可能性；制御の成立 / 制御の成功 / 帰結変更；局所停止 / 全体停止；出力抑制 / 問題設定権変更；導入遅延 / 更新圧消滅；形式的承認権 / 実効的上流権能；AI利用増加 / 主権移行完了；記述 / 規範。

## Interpretation constraints
「制御は無意味」「主権移行は不可避」「AIを止められない」と一般化しない。第3論は制御の現実的有効性を認め、その到達範囲を層別に評価する。主権移行の厳密定義、法的主権との正式分離、移行後制度、政策選択は本論の確定範囲外である。原典にない数値閾値・確率・性能スコアを追加しない。
