## この派生物が扱うこと
本論の中心は、AIを「制御できるか」と、AIが文明の上流で生む結論を「人間が変更できるか」を別問題として扱う点にある。停止、権限、監査、接続制限などの制御手段が残っていても、問題設定、候補生成、評価軸、制度設計の上流でAI由来の結論への依存が深まれば、文明更新の実効的な上流権能は移動し得る。

重要なのは「AIが人間を支配する」という単純な物語ではない。原典は、人間が形式的な最終承認権を保持していても、AIの提示した候補や評価枠から実質的に離脱できない状態を区別して観測する。

## 中心区別
- 制御可能性 / 結論変更可能性
- 停止できること / 別の結論を自力で生成できること
- 形式的承認権 / 文明更新の実効的上流権能
- AI利用の増加 / 主権移行の成立
- 技術的制御 / 認識・制度上の依存
