## 位置づけ
親原典は、KPIを多数の管理指標の集合として扱う一般的運用を退け、KGIへ直結する「唯一の因果支点」を核点として探索・検証する方法論を示す。重要なのは指標を一つに減らすことではなく、因果分解と反事例検証を通じて、他の候補では代替できない支点を残すことである。

## 中心命題
真のKPIは、KGIに因果的に直結する唯一の核点である。核点は恣意的に選定するものではなく、KGIから逆算した因果展開、候補抽出、反事例ふるい、一因子介入による検証を通じて残される。核点へ必要作用を与えたときにKGIへ到達するという親原典の強い因果主張は、そのまま検証対象として保持される。

## 因果線
KGIを明確化 → KGIから必要条件を逆算して因果展開 → 全体を動かしうる候補を最大3点へ絞る → 「満たされてもKGIへ届かない反事例」を各候補へ当てる → 代替不能な候補だけを残す → 必要作用の回数・圧力・強度を定義 → 核点のみを変える一因子介入で比較 → 3サイクル連続の方向一致・自由度・誘導性を確認 → 核点として固定 → KGI達成へ接続する。

## 構造層
1. **目標層**: KGIを曖昧な願望でなく、到達状態として固定する。
2. **観測層**: 合意時間、自走指数、反発／沈黙の質を、数値化前の場の兆候として観測する。
3. **因果分解層**: KGIから逆向きに「何が起きれば次が生まれるか」を一次分解する。
4. **選別層**: 候補を反事例ふるいにかけ、満たされてもKGIへ届かない点を除外する。
5. **作用層**: 残った核点へ必要な回数・圧力・強度を数値または準定量で与える。
6. **検証層**: A/B’比較、定常化、自由度、誘導検査で因果支点性を検証する。

## 状態モデル
- **周辺指標混同状態**: 架電数、商談数など複数のSub MetricsをKPIと呼び、因果支点が未特定。
- **因果探索状態**: KGIから逆算し、候補点と前提条件を展開している。
- **ふるい状態**: 反事例を当て、候補が本当にKGIへ直結するかを除外検証している。
- **仮核点状態**: 一点が残ったが、介入検証・自由度検査前で固定されていない。
- **核点固定状態**: 一因子介入と複数検査を通過し、必要作用とともに運用可能になっている。
- **形式化失敗状態**: 唯一点という形式だけを反復し、本質的な因果支点性を失っている。

## 適用例
- 組織で、会議冒頭に意味軸を置くことが合意形成の支点かを検証し、合意時間と自走性の変化を見る。
- 教育で、学習者が自分の役割を言語化することが定着・再帰改善の核点かを反事例と比較する。
- 公共領域で、反対意見を資源化する問いへの転換が参加の自発化と論点収束へ直結するかを確認する。
- 営業や制度運用で、多数の活動量を追う前に、KGIへ直結する一つの構造条件を探索する。

## 測定・監査点
核点探索では、単にKGI達成率を見るだけでなく、探索前の合意時間、自走指数、反発／沈黙の質を記録する。候補確定後は、核点以外を変えないA/B’比較、3サイクル連続で同方向の効果が出るか、Yes/Noの単線誘導になっていないか、問いや順序に隠れ正解が埋め込まれていないかを監査する。必要作用は回数・圧力・強度、または頻度・順序・滞在時間などの準定量で扱う。

## 成立条件
KGIが具体的な到達状態として定義でき、因果を一次分解できること。候補に対して反事例を作れ、一因子だけを変える比較が可能であること。核点が個人評価ではなく構造条件として扱われ、複数の善や自由度を残したまま作用させられることが必要である。

## 失敗条件
多数のSub MetricsをKPIと呼ぶこと、唯一点を先に決めて因果を後付けすること、反事例ふるいを省略すること、形式だけをルーティン化すること、核点を個人査定へ転用すること、サンプル偏りを無視して成果を誇張すること、隠れ正解を埋め込んで自由度を失わせることは失敗条件となる。

## 反証・改訂条件
反事例ふるいと一因子介入を通過した核点へ必要作用を与えてもKGIへ到達しない事例が再現的に生じる場合、「唯一核点→KGI必達」という親原典の強い因果主張は改訂対象になる。また、複数の独立した支点が同時に必要で単一核点へ還元できない事例が反復する場合も、唯一性の条件を再検討する必要がある。

## 必須の区別
- KPI ≠ 複数の管理指標一覧。
- 核点 ≠ 最も目立つ数値。
- 唯一点を探す ≠ 指標を恣意的に一つへ減らす。
- Sub Metrics ≠ 不要な指標。補助観測としては残りうる。
- 必要作用 ≠ 無制限な圧力。
- 一因子介入 ≠ 他条件を同時に変える実験。
- 核点評価 ≠ 個人査定。
- 非命令 ≠ 無設計。

## 誤読禁止 / 解釈制約（原典適合）
「どんな複雑系にも必ず簡単に一つの数字がある」と読まない。親原典は数を一つにする技法ではなく、因果支点を反事例で削り、介入で検証する方法を提示している。また「100%作用すればKGI必達」という表現は親原典の強い主張であり、派生側が経験的に保証済みの普遍法則へ昇格させてはならない。個人を核点化して統制することも原典の公開安全・非命令条件に反する。
