## 检索摘要
原典把“能否控制AI”与“人类能否实质改变由AI参与形成的上游结论”区分开来。即使人类仍能停止系统、限制权限、审计并作最终批准，如果问题设定、候选方案生成、评价轴、比较和制度设计越来越依赖AI，人类的形式批准权与文明更新的实际上游权能仍可能发生分离。

## 核心因果链
```text
AI在上游环节的使用扩大
→ 问题设定、候选生成与评价框架依赖加深
→ 人类独立生成替代结论的能力相对下降
→ 可控制性仍存在，但结论可更改性可能下降
→ 形式批准权与实际的上游权能分离
→ 需要观察文明主权是否发生迁移
```

## 必须区分
- 可控制性 / 结论可更改性
- 停止权限 / 独立生成替代方案
- 形式批准 / 实际上游权能
- AI使用增加 / 主权迁移完成
- 技术控制 / 认知与制度独立性

## 反证与修订边界
如果人类持续保持独立的问题设定、替代方案生成、评价、理由比较和制度翻译能力，并能实质改变AI产生的结论，则主权迁移命题应减弱或缩小适用范围。

## 非主张
不添加原典没有的数值阈值、迁移概率、评分或不可避免性。不把AI使用本身等同于主权迁移完成，也不要求AI成为法律主体。
