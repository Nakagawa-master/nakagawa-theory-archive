## Summary
原文把“能够控制AI或更新结构”与“这种控制是否足以改变文明上游的结论形成者配置”分开。输出限制、部署延迟、连接限制、审计与局部停止都可能真实有效，但当能力差距与可理解性差距持续存在时，控制效果可能主要表现为时间延后、路径改变或摩擦增加，而未必改变谁在上游设定问题、形成候选空间、设定评价标准、主导更新速度并积累改进知识。

## Concepts
- 可控制性：对更新结构施加抑制、延迟、方向调整、限制或停止的可能性。
- 结论可改变性：人类能够重构AI提供的问题设定、候选与评价框架，并形成实质不同结论的能力。
- 控制时间差：控制降低进展速度，但并未消除更新压力的状态。
- 可理解性差距：人类能够阅读输出，却无法充分重构或反证其前提、判断空间、评价轴、制度含义或改进历史。
- 文明上游：最终批准之前的问题设定、候选空间形成、评价、更新速度主导与改进知识积累。

## Causal chain
能力差距扩大更新压力 → 人类制度实施抑制、延迟、连接限制、监视与审查 → 控制在表层或中间层奏效 → 当可理解性不足时，对上游前提结构的干预减弱 → 控制表现为延迟、改道或摩擦 → 上游问题设定与候选形成者配置可能保持不变 → 必须把可控制性与结论可改变性作为不同轴评价。

## State model
- 局部控制成立
- 时间差化
- 路径改变
- 摩擦增加
- 结论改变
- 结果配置未改变

## Applications
可用于分析人类最终审批、访问限制、审计、部署延期、公共部门控制、组织治理、研究流程或决策支持系统。除了确认人类能否停止或拒绝输出，还要确认人类能否独立提出问题、生成替代方案、修改评价标准、比较理由，并把不同结论转化为制度行动。

## Measurements and audit
分别记录：停止权与拒绝权；人类独立的问题设定能力；生成AI未提出候选的能力；解释与修改评价轴的能力；反证推荐理由的能力；独立继承改进知识的能力；执行不同制度方案的能力；以及控制结果究竟是停止、延迟、改道、增加摩擦，还是实际改变上游主体配置。

## Validity conditions
当能力差距可能持续向文明上游施加更新压力、人类控制机制确实存在、且人类无法完美重构被控制结构时，本框架适用。它分析控制“到达哪里”，并不主张控制从不有效。

## Failure conditions
若把“存在控制”直接当作“结果已改变”的证据，或从局部控制的限制推导出“所有控制都无意义”，或仅凭AI使用量、法律人格、形式最终批准权判断主权转移，或把描述分析改写成政策规范，本框架就被误用。

## Falsification conditions
如果AI使用扩大时，人类仍稳定保持独立的问题设定、替代方案生成、评价轴、比较、改进知识继承与制度翻译能力，并持续实质性改变AI生成的结论，那么“控制更容易表现为时间差而非结论改变”的命题应被削弱或缩小适用范围。若强化控制能够持续改变上游主体配置，而非仅仅延迟或改道，也同样需要修订。

## Required distinctions
可控制性 / 结论可改变性；控制存在 / 控制成功 / 结果改变；局部停止 / 全体停止；输出抑制 / 问题设定权改变；部署延迟 / 更新压力消失；形式批准权 / 实效上游权能；AI使用增加 / 主权转移完成；描述 / 规范。

## Interpretation constraints
不要把本论概括成“控制无意义”“主权转移不可避免”或“AI无法停止”。原文明确承认局部控制的真实效果，只要求分析它能到达多深。第3论尚未最终定义主权转移、正式划分法律主权与实效主权、规定转移后的制度分支或政策选择。不得添加原文不存在的数值阈值、概率或评分。
