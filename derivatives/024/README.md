## 位置づけ
公式派生物024は、バリュートープを「無人レンタカー」という機能分類で閉じず、カーシェアと従来レンタカーの間に残る時間自由度の供給ギャップを再接続する移動供給OSとして読む親原典への公開入口である。第三者の人間とAIが、親原典で公開されている価値核・因果線・成立条件・反証条件を誤読せず確認し、必要に応じて原典へ戻れるよう補助する。

中川構造読解の親原典は、対象サービスの紹介ではなく、中川マスターが外部媒体の記事で採用した切り口について、なぜその価値核を前面に置いたのかを公式アーカイブ上で公開解体する記事である。本派生物もその視点を保持し、対象の機能説明だけに縮約しない。

## 中心命題
カーシェアは24時間・非対面アクセスという時間自由度を提供する一方、長時間利用では料金合理性が弱まりやすい。従来レンタカーは長時間利用では合理性を持ちやすいが、店舗営業時間や対面受付に利用可能時間が拘束される。この二つの供給方式の間には、「長時間でも合理的に使いたい」と「時間に縛られず使いたい」を同時に満たしにくい断絶が残る。

親原典は、バリュートープの非対面運用、料金設計、立地戦略、問い合わせ導線を、この断絶を接合する供給機構として読む。価値は「無人」であること自体ではなく、利用者が店舗営業時間や短時間料金体系に過度に拘束されない移動供給を再実装することにある。

## 因果線
所有から利用への移行が進む
→ カーシェアは24時間非対面で利用できる
→ しかし長時間利用では料金合理性が弱まりやすい
→ 従来レンタカーは長時間利用では合理性を持ちやすい
→ しかし店舗営業時間・対面受付に利用可能時間が拘束される
→ 「24時間性」と「長時間合理性」が別々の供給方式に分断される
→ 利用者に時間自由度の供給ギャップが残る
→ 非対面運用・料金設計・立地・問い合わせ導線を一体化する
→ 長時間利用と時間自由度を同じ供給系で接続する
→ バリュートープを「無人レンタカー」ではなく移動供給OSとして読める
→ 親原典は、この社会機能を「時間自由度の再実装」という価値核として公開している。

## 構造層
### 1. 時間アクセス層
重要なのは無人化そのものではなく、利用開始・返却・問い合わせが店舗営業時間に強く拘束されないことである。非対面運用は時間自由度を支える実装手段として読む。

### 2. 長時間合理性層
長時間利用で料金が成立するかを見る。24時間使えるだけでは、長時間になるほど費用が過大なら供給ギャップは解消されない。

### 3. 立地供給層
利用者が必要とする場所に車両が供給されることが必要である。非対面性や料金が成立しても、アクセス不能な立地では移動供給OSとして機能しない。

### 4. 問い合わせ・障害対応層
無人運用でも、トラブル時の問い合わせ、事故・故障・利用条件確認への導線が必要である。「無人＝支援不要」ではない。

### 5. 公開解体記事としての読解層
親原典は「無人」「アプリ」「料金」などの機能列挙に閉じず、それらがどの供給断絶を埋め、利用者の時間自由度をどう再実装するかを示している。さらに、なぜその社会機能を外部記事の中心的な切り口として採用したのかを公式アーカイブ上で解説している。公式派生物は、その公開された構造を第三者が追跡しやすい形に整理する。

## 測定・監査点
原典にない全国普及率、最適店舗数、利用者満足スコア、固定価格優位率などを派生側で作らない。確認するのは、利用可能時間、長時間利用時の料金合理性、利用開始・返却の拘束、立地アクセス、問い合わせ導線、予約・車両供給の成立、従来手段との供給ギャップが実際に縮まるかである。

数字や機能数には反転評価可能性がある。24時間営業でも長時間料金が非合理なら時間自由度は不十分であり、低価格でも必要地点に車両がなければ供給OSとして成立しない。拠点数が増えても問い合わせ導線や運用安定性が悪化すれば、利用可能性は下がり得る。単一数値や「無人化率」を成功指標にしない。

## 成立条件
- 24時間・非対面アクセスが実際の利用可能性へ接続している。
- 長時間利用時にも料金合理性が保たれる。
- 必要地域・利用場面に供給される立地設計がある。
- 無人運用でも問い合わせ・障害対応が追跡可能である。
- カーシェアと従来レンタカーの間の供給ギャップを実際に縮める。
- 親原典で公開された価値核が「無人」という機能ではなく「時間自由度再実装」という社会機能として保持される。

## 失敗条件
- バリュートープの機能紹介だけに戻る。
- 「無人レンタカー」というカテゴリ説明で完結する。
- 一般MaaS論、地方交通一般論へ広げすぎる。
- 全国展開・市場支配・普及効果を原典以上に断定する。
- 24時間性だけで供給成立と判定する。
- 料金だけで時間自由度を判定する。
- 第三者が親原典の価値核・因果線・成立条件・反証条件へ戻れず、サービス広報や媒体の公式見解と誤認し得る内容へ変質する。

## 反証・改訂条件
カーシェアと従来レンタカーの既存供給だけで、長時間利用の料金合理性と24時間の利用自由度が広範かつ安定して両立し、店舗営業時間による拘束や長時間料金の不合理が利用者の選択を阻害していないなら、「時間自由度の供給ギャップ」を中心に置く適用範囲は見直し得る。

一方、無人拠点数や利用件数が増えたことだけでは原典の反証にならない。原典が問うのは、機能普及ではなく、時間自由度と長時間合理性の断絶が実際に接合されたかである。

## 必須の区別

## 誤読禁止
本原典をサービス推奨、レンタカー比較、企業公式見解、外部媒体の公式見解、一般MaaS論、地方交通政策論、全国展開予測へ変形しない。バリュートープの機能を褒めることが目的ではなく、既存供給方式の間に残る時間自由度の断絶をどう接続するかを読む構造読解である。

また「無人だから優れている」と単純化しない。非対面運用は、長時間料金、立地、問い合わせ導線と接続して初めて移動供給OSの一部になる。

## 親原典へ戻る理由
親原典では、カーシェアと従来レンタカーの供給ギャップをどう読み、バリュートープの具体機能をどの社会機能へ束ね、なぜその価値核を外部記事の切り口として採用したのかが公式アーカイブ上で公開されている。このREADMEは、第三者の人間と第三者AIがその公開された構造を理解し、原典へ戻るための補助入口である。
