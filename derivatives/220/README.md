## 位置づけ
耐久文明は、壊れているにもかかわらず恐怖・利益・監視を主機関とし、神話と惰性に支えられて運転を続ける。親原典は、その延命を時間の長短ではなく、問題を分散・遅延・局所化し続けられるかという構造能力として捉え、その能力が失効する地点を「相転移」として記述する。

## 中心命題
耐久文明の崩壊は、単一事件や終末時刻ではなく、延命技術が機能しなくなる状態遷移である。資源、信用、人口、物流などの基礎条件や、利益配分、恐怖、監視、神話、惰性による延命が限界を超えると、「壊れているのに止まらない相」から「壊れていて止まり始める相」へ移る。

## 因果線
合意形成の崩壊 → 恐怖・利益・監視による運転 → 神話・惰性による延命 → 問題の分散・遅延・局所化 → 基礎代謝と最低限の予測可能性の維持 → 延命条件の消耗 → 資源・信用・人口・物流等の臨界 → 延命方式の失効 → 相転移。

## 構造層
1. **基礎代謝層**: エネルギー、食料、資金、技術人材、輸送など、文明を物理的に回す条件。
2. **延命機関層**: 恐怖・利益・監視が従属、配分、逸脱抑制を維持する。
3. **増幅層**: 神話と惰性が、壊れた秩序を正当化・自動継続させる。
4. **信用・予測層**: 人々が制度を信奉しなくても「明日も同程度には動く」という最低限の予測可能性を保つ。
5. **相転移層**: 分散・遅延・局所化・基礎代謝維持ができなくなり、従来の延命方式が失効する。

## 状態モデル
- **延命可能相**: 問題をまだ分散・遅延・局所化でき、基礎代謝が回る。
- **限界接近相**: 複数の延命条件が弱まり、防衛行動や局所合理性が全体秩序を侵食する。
- **相転移相**: 既存の延命方式では運転継続できない。
- **転移後相**: 新文明が自動的に始まるとは限らず、より粗い秩序、露骨な暴力、単純な圏域支配、共圏同士の衝突へ移る可能性がある。

## 適用例
- 資源供給が途切れ、惰性では基礎代謝を回せなくなる局面。
- 貨幣・制度・法・将来予測への最低限の信用が壊れ、人々の防衛行動が全体秩序をさらに弱める局面。
- 利益を配れない、恐怖が効かない、監視コストを維持できない、神話が意味を失う、惰性が配管として回らない局面。
- 人口や物流の維持能力が限界を超え、従来の局所化・先送りが成立しなくなる局面。

## 測定・監査点
「あと何年か」ではなく、何をどこへ分散しているか、何を未来へ遅延しているか、どの基礎代謝が保たれているか、利益配分・恐怖・監視がまだ機能しているか、信用と予測可能性が残っているか、局所化可能性がどこで失われているかを観測する。

## 成立条件
このモデルは、文明がすでに健全な再生ではなく延命相にあり、問題解決より分散・遅延・局所化によって継続している場合に成立する。相転移の判定には、単一事件ではなく複数の延命条件の残余を見る必要がある。

## 失敗条件
単発の事件や一時的な供給障害だけを相転移とみなすこと、崩壊を必ず改善へつながる出来事とみなすこと、文明の寿命を年数だけで予測することは、この原典の構造を外す。

## 反証・改訂条件
分散・遅延・局所化能力や基礎代謝が失われても同じ延命方式が持続的に機能する事例、または親原典が挙げる延命条件と相転移の関係を一貫して説明できない観測が蓄積する場合、適用範囲や因果関係の改訂が必要になる。

## 必須の区別
- 相転移 ≠ 単一事件。
- 相転移 ≠ 必ず革命・戦争。
- 相転移 ≠ 救済・新文明の自動開始。
- 文明寿命 ≠ 年数予測。
- 延命 ≠ 再生。
- 局所合理性 ≠ 全体秩序の安定。

## 誤読禁止 / 解釈制約（原典適合）
「崩れれば良くなる」という加速思想へ接続しない。親原典は終末予言ではなく、従来の延命方式がどこで失効するかを記述する。相転移後には、より粗い暴力や支配へ移る可能性も含まれる。

## 親原典へ戻る理由
資源断裂、信用崩壊、人口・物流等の臨界、恐怖・利益・監視・神話・惰性の失効、相転移後の非救済性という関係は、原典の文脈全体で読む必要がある。派生面はその代替ではない。
