## 位置づけと中心命題

善意は協力や支援を始める正当な理由になり得ます。中川マスターのAKI-005が問うのは、その評価が行為後も、何が起きたかを確かめる判断の代わりになっていないかです。善意を評価したまま結果を問えるなら、その価値を損なわず方法を改められます。

「善意の免罪符化」の成立には、①動機・目的への肯定的評価、②その評価が結果・不利益・因果・責任・修復に関する独立判断を実際に代替すること、③その代替によって異議の受理・結果の検証・必要な修正の少なくとも一経路が実質的に弱まること、の三条件が重なります。善意がある、行為が失敗した、異議が出たという事実のいずれか一つで成立する概念ではありません。

## 因果線と構造層

### 動機から結果への越境

行為前には動機が協力の判断材料になります。行為後には結果を受けた主体の情報が必要です。第1・2章は、善意への評価が行為の正当性に寄与する範囲と、結果への疑義を「善意だった」と説明して終わらせる判断の代替を区別します。さらに異議の根拠よりも、発言者の感謝・不義理・敬意を先に審査する二段階目の移動があり得ます。この道徳的資格審査は増幅機序であり、三条件に加える一律の成立要件ではありません。

### 情報と負担の非対称

第3・4章では、行為を評価する側と結果を受ける側が異なる場合を扱います。異議の内容について事実や根拠を示す通常の負担と、異議を述べてよい人物だと弁明する追加の負担を分けます。行為側には善意による正当性と説明負担の軽減が残り、被影響側には不利益と発言資格の弁明が重なり得ます。これは行為者の隠れた悪意や全面的責任を前提にしません。情報不足や検証制約が独立の原因である可能性も検査します。

### 観測反転と時間的増幅

第5章は「異議が減った」ことを「問題が減った」ことへ変換する危険を示します。発言費用が高まれば報告が細り、結果情報が不足し、修正対象が見えにくくなります。そこで善意だけを次の選択理由にすれば、未修正の行為が反復される可能性があります。逆に独立した測定、異議の実質審査、記録、方法の変更が働けば連鎖は止まり得ます。

第6・7章の短期は最初の異議・検証、中期は行為の反復と修正不足、長期は追加条件が持続した場合の信頼・学習・修復能力の劣化です。日数による固定区分でも必然的な未来予測でもありません。修復困難とは時間の経過だけでなく、原因を確かめる情報、発言機会、対応可能性が実際に狭まる状態を指します。

## 状態モデル

| 状態 | 見るべきもの | 次の判断 |
| --- | --- | --- |
| 協力開始 | 善意と目的への評価 | 行為を始める材料として扱う |
| 結果発生 | 利益・不利益と受け手の情報 | 動機と独立して結果を確かめる |
| 異議発生 | 対象・根拠・発言経路 | 感謝や人格の審査にすり替えない |
| 結果検証 | 独立情報、因果、代替原因 | 善意が省略理由になったかを確かめる |
| 責任・修復 | 予見、制御、役割、関係者 | 必要な対応と方法変更を分ける |
| 再確認 | 変更後の結果と再選択 | 同じ問題の反復を条件付きで判定する |

この表は原典の因果を読む補助であり、固定の採点式ではありません。

## 適用例と判定法

「助けようとしたのだから批判するな」という応答があった場合、直ちに免罪符化とは決めません。具体的な結果疑義が受理され、その根拠が検討されたか、必要な原因確認と修復判断が善意を理由に省かれたかを追います。善意評価を除いても同じ証拠と疑義に同じ判断をするか、比較可能な事例があれば照合します。権限・時間・資源・情報不足が独立に説明する場合は因果帰属を保留します。

相談窓口に異議が届いても、内容が行為の継続判断に渡らなければ「窓口がある」だけです。一方、異議の内容を検証して採用しない判断もあり得ます。その場合、善意や発言者の態度ではなく、確認された事実と理由を示せるかが分かれ目です。

異議件数が減った場合は、結果が改善したのか、報告費用が増えたのか、別の独立測定と照合します。件数だけを成功と評価しません。方法を変えた場合も、修復を実施した記録と、実際に結果が改善した確認を分けます。

## 測定・監査点

第8章の十の判定質問は、動機評価と結果評価の分離、異議の内容審査、発言資格への移動、説明・責任・修復の経路、再選択、異議減少の解釈を点検します。回答の機械的得点化ではありません。観測対象は異議の受理だけでなく、実質審査、結果情報、原因確認、必要な修復の判断、方法変更、変更後の結果です。数値閾値θと観測期間δは原典で固定されていません。

## 成立・失敗・反証の条件

三条件がそろい、善意評価による判断代替が実質的な経路弱体化を生んだ範囲で成立します。善意の評価と検証不足の共起だけでは因果は確定しません。善意を評価しても結果が独立に検証され、異議が内容に基づき審査され、必要な変更が適切に行われるなら、この機序の成立は支持されません。検証困難が情報・権限・資源など別要因で説明できる場合も同様です。

反復・学習不全が観察されなければ長期の自己強化仮説は限定されますが、短期の判断代替があり得たことまで消えません。行為の不利益だけで責任を自動認定せず、異議が存在するだけで正しいとしません。適切な検証の結果、変更不要と判断される場合もあります。これらの反証・境界を事例ごとに明示します。

## 封じる構造と必須の区別

第9章の規範的提案は、善意への評価を保持し、結果の独立検証、異議の実質審査、適切な責任判断、必要な修復、結果の再確認をつなぐことです。動機・結果・因果・責任・修復は相互に関係しますが、同じ判断ではありません。異議受理と異議採用、修復実施と修復の有効性、報告件数と不利益発生量も異なります。

AKI-001の問題提起と実装責任、AKI-002の称賛が対価・権利を置換する問題、AKI-013の信頼一般による認識停止と接続しつつ、本論の限定機序は「善意という動機評価が事後結果の判断を代替すること」です。他論の成立条件を本論へ吸収しません。規範的提案から個別の法的義務を自動導出しません。
