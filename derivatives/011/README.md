## 位置づけ
本派生物は成立条件論第1論の公開入口である。第0論が「なぜ成立判定が必要か」を扱ったのに対し、第1論は「何をもって成立と呼ぶか」を固定する。

## 中心命題
成立は、一度動いたこと、数字が出たこと、制度や計画が存在すること、AIが整合的に要約したことではない。L1からL6までの縦因果が必要な因果粒度で構造流路として通り、過剰な外部圧力・属人対応・責任転嫁・例外処理の常態化に依存せず、現実の中で意味と機能を保つ状態が成立である。

## 原典の因果線
```text
成果・制度・数字・計画・AI要約がある
↓
見かけ上「成った」ように見える
↓
L1〜L6の縦因果、責任、導線、摩擦、履歴、再現性を検査する
↓
必要粒度の構造流路が通っているかを見る
↓
過剰圧力・属人対応・責任転嫁・恒常例外で欠落を補っていないかを見る
↓
条件が通っていれば現実成立、通っていなければ暫定稼働と判定する
```

## 原典固有構造
- **成立 / 成立条件**: 成立は成った状態、成立条件はその成りを成立と呼べるかを判定する条件。
- **L1〜L6の縦因果**: 局所結果ではなく、階層間の因果通過を見る。
- **因果粒度**: 条件、順序、例外、摩擦、責任、導線、時間、履歴、再現性を検証できる細かさ。
- **構造流路**: 現実成立に大きく作用する主要因果経路。
- **圧力依存の切断**: 過剰な命令・人間負荷・属人対応・責任転嫁・例外常態化で未成立を隠さない。
- **非物質構造設計図**: 組織・営業・教育・合意・ブランド・AI運用等の非物質構造にも、因果と責任を通す設計図が必要になる。

## 判定の焦点
1. L1〜L6の縦因果が実在しているか。
2. 因果粒度が粗く、欠落条件を隠していないか。
3. 数字・制度・計画・AI要約が現場因果へ接続しているか。
4. 通常調整を超える外部圧力に依存していないか。
5. 属人対応・責任転嫁・例外処理が恒常化していないか。
6. 再現時にも同じ構造流路が通るか。

## 非該当境界
通常の調整、判断、補正、軽微な例外が存在するだけでは未成立とは言えない。また、成果・数字・制度・計画・AI要約そのものを否定する理論でもない。それらが成立の結果・補助証拠になるには、現実因果への接続が必要だという区別を置く。

## 誤読防止
- 成功法則や自己啓発へ縮約しない。
- プロジェクト管理手法だけにしない。
- 「条件が大切」という抽象論へ薄めない。
- 摩擦ゼロを成立条件にしない。
- 一度の成功や高いKPIを成立証明にしない。
- AIの言語整合を現実成立の証明にしない。

## 親原典へ戻る理由
原典では、成立、成立条件、縦因果、因果粒度、構造流路、非物質構造設計図、圧力依存、構造的無為自然が一つの定義体系として配置される。第2論「理解とは何か」への接続も含め、厳密な理論位置はParent URLで確認する。
