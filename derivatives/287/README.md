## 位置づけ
本派生物は、中川式営業における初期接触を「短時間で売り込む場」ではなく、相手の現在地と境界を尊重し、次の対話が成立するための起点設計として整理する。

## 中心命題
初期接触の目的は成約ではない。相手に過剰な認知負荷を与えず、何者で何のために接触したかを明確にし、相手の反応を観測し、次に話す価値があるかを双方が判断できる状態をつくることである。

## 因果線
```text
接点が生まれる
→ 接触目的と立場を明示
→ 相手の時間・関心・境界を確認
→ 短い問いで現在地を観測
→ 説明しすぎず応答余白を残す
→ 反応から適合性を仮説化
→ 次の対話に進む条件を確認
→ 同意があれば継続接触
→ なければ摩擦を残さず終了
```

## 初期接触の構造
1. **起点の透明性**: 誰がなぜ連絡したかを隠さない。
2. **許可と帯域**: 相手が今話せるか、関心があるかを確認する。
3. **短い問い**: 説明量より相手の現在地を知る問いを優先する。
4. **余白**: 沈黙や保留を拒否と決めつけず、考える空間として扱う。
5. **次接点の合意**: 次回へ進む条件・時間・テーマを明確にする。

## 状態モデル
```yaml
- contact_created
- identity_and_purpose_disclosed
- permission_checked
- bandwidth_respected
- short_question_asked
- response_observed
- fit_hypothesis_formed
- next_step_explicitly_agreed_or_closed
- pressure_not_added
```

## 適用例
- 初回メールを長い商品説明にせず、接触理由・相手との関連・一つの問い・退出可能性を明示する。
- 電話で相手が忙しい場合、説明を続けず再接触の可否だけ確認する。
- 展示会等で名刺交換した後、即座に案件化せず、相手が話した論点を基点に次の対話を提案する。

## 測定・監査点
- 接触目的を偽装していないか。
- 相手の拒否・保留が実際に尊重されるか。
- 初回で情報を詰め込みすぎていないか。
- 次の接点が双方の合意になっているか。
- 初期反応をニーズ確定と誤認していないか。

## 成立条件
透明な接触目的、許可確認、低負荷な問い、反応観測、退出自由、次接点の明示的合意があること。

## 失敗条件
目的偽装、長文売り込み、返答強要、沈黙の勝手な解釈、接点獲得を購買意思とみなすこと。

## 反証・改訂条件
低負荷な初期接触設計でも次対話の質が改善せず、むしろ誤解・離脱・不信が増える場合、接触形式・問い・タイミングを改訂する。

## 必須の区別
- 接点 ≠ 購買意思
- 応答 ≠ 同意
- 初期関心 ≠ ニーズ確定
- 許可確認 ≠ 儀礼的な一言
- 次回合意 ≠ 囲い込み
