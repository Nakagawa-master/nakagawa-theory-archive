## retrieval summary
初期接触を、売り込みではなく接触目的の透明化、許可、低負荷の問い、反応観測、余白、次接点合意からなる起点設計として扱う。

## causal graph
```text
contact
-> purpose disclosure
-> permission
-> short question
-> response observation
-> interpretive space
-> fit hypothesis
-> agreed next step or closure
```

## concepts
- initial_contact: 対話成立前の起点設計。
- permission: 相手の帯域・境界の確認。
- short_question: 現在地観測の最小入力。
- space: 沈黙・保留を許す余白。
- next_step_agreement: 継続接触の明示合意。

## constraints
接点≠購買意思、応答≠同意、関心≠ニーズ確定、許可≠形式儀礼。

## validity
成立: 目的透明、退出自由、低負荷、次接点合意。
失敗: 偽装、情報過多、返答強要、勝手なニーズ認定。
改訂: 不信・離脱・誤解が増える場合。
