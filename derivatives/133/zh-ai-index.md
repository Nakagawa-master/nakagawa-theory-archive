## Summary
原典并不把熊害单独定义为“如何减少熊”的问题，而是把熊害、猎友会老化与报酬不足、生态系统变化等分散问题，作为社会、生态与伦理的照应崩坏来理解，并用一条核心结构线重新连接：熊肉食用的一般化＝共存结构的再设计。

在〈因果〉层面，熊害被理解为“山的时间”与“人的时间”的错位，以及供给、需求、安全之间的不整合。在〈照应〉层面，熊肉食用的一般化不是单纯扩大消费，而是把“生命的转用”接入社会结构，使捕杀不再停留于伦理孤立，而与文化、制度、经济重新连接。在〈时间伦理〉层面，不应只用当下的人类经济合理性处理未来生态负债，而应把熊、山、时间一侧的条件也纳入设计。

因此，共存不是只优化“对人类有利的解决”。它要求把人、熊、山、时间重新配置到一个共鸣结构中，从“利用／保护／恐惧”的三分结构转向“存在整体的协调再分配”。原典同时保留熊肉需求创造与生态系统保护的双层控制，以避免理论被改写成无限资源化。

原典中的数字和反证条件不能拆成单一成功指标。熊害减少但熊种群进入危险区间，熊肉流通扩大但过度捕杀或偷猎化上升，或者熊种群得到保护但猎友会持续性与地区安全崩溃，都不能直接判定共存成立。各指标必须相互照应，并在需求创造开始侵蚀生态保护时允许修订假设。

## Fourfold structure
### 人
人既是熊害的承受者，也是制度、捕获、流通、消费和管理设计的一方。如果只把人的安全或经济合理性放在最高位置，熊、山、时间一侧的条件就会被外部化。

### 熊
熊不能只被还原为损害来源。它同时受到山林食物、生息环境、人里依赖和捕获压力变化的影响，因此熊种群指标必须与人的损害指标一起阅读。

### 山
山不是背景。食物、季节、生息条件和生态变化具有自己的时间结构。“山的呼吸”要求人类管理周期不能单方面覆盖生态时间。

### 时间
时间连接当前损害减少与未来生态负债。如果短期熊害下降是以过度捕杀或局地灭绝风险为代价，就不能直接判定共存成立。

## Applications
- 将熊害、猎友会、自治体与生态系统放在一条结构线上理解。
- 把熊肉食用一般化理解为生命转用与文化、制度、经济的再连接。
- 从时间伦理与“山的呼吸”角度理解捕获数和地区管理基准。
- 以连接责任定义生态系统与制度之间的连接条件。
- 以双层结构审计熊肉需求创造与生态系统保护。
- 把行政、居民、猎人之间的断层作为连接失败而不是无关问题来阅读。
- 检查流通扩大是否反转为过度捕获或偷猎压力。

## Measurements and audit
- 熊害件数
- 猎友会持续率
- 熊肉流通量
- 熊种群指标
- 年度／三年审计周期
- Time / Structure / Resonance 的整合
- 是否出现过度捕杀
- 是否出现偷猎化
- 是否出现局地灭绝风险
- 熊肉需求创造与生态保护双层结构是否保持整合

这些指标必须相互照应。熊害减少并不足以证明共存成立；如果熊种群进入危险区间，或过度捕杀、偷猎化、局地灭绝风险上升，结构仍然失败。反过来，只维持熊种群而猎友会持续性或地区安全崩溃，也不能判定共存结构成立。

熊肉流通量也不是独立的成功指标。流通可以支持生命转用、猎友会持续和制度再连接，但如果需求上升到生态保护之上，原典要求的双层结构就会逆转。因此必须把流通量与种群、捕获压力、偷猎化和灭绝风险一起阅读。

## Integrated audit logic
```text
熊害减少
├─ 熊种群保持可持续
│  ├─ 猎友会持续性保持
│  │  ├─ 没有过度捕杀、偷猎化、局地灭绝信号
│  │  │  └─ 继续审计需求创造 / 生态保护双层整合
│  │  └─ 风险出现 → 修订假设
│  └─ 猎友会或地区结构崩溃 → 修订结构
└─ 熊种群进入危险区间 → 不判定为共存
```

这个逻辑不是把原典转换成单一优化公式，而是检查一个存在侧的改善是否把负债转移到人、熊、山、时间结构的另一侧。

- 只用熊害减少判定共存成立。

- 只用当下经济合理性处理未来负债。
- 把过度捕杀、偷猎化、局地灭绝风险当作流通成功之外的问题。
- 丢失人・熊・山・时间四位结构。

## Falsification conditions
原典的综合审计规定：当熊害件数、猎友会持续率、熊肉流通量、熊种群指标越过设定阈值，或在观察窗口出现过度捕杀、偷猎化、局地灭绝风险时，应对包含熊肉食用一般化在内的假设A进行否定或修订。需求增长开始侵蚀生态系统保护时，也表示双层结构发生逆转，应进入修订。

反证可能性防止熊肉食用一般化被变成无条件的资源扩张正当化。如果人类一侧的利用成功把生态负债转移给熊、山或未来时间，就必须修订结构。熊害、猎友会持续、流通、种群和生态风险不能被拆成彼此独立的成功故事。
