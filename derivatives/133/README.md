## 位置づけ
熊との衝突を「駆除か保護か」の二択に閉じず、山の生態、餌資源、人里の土地利用、個体数、猟、食文化、廃棄、地域経済、被害防止を一つの循環として捉える。熊食を単独解として推奨するのではなく、人と山の切断を再接続する一つの資源循環・関係設計として位置づける。

## 中心命題
野生動物との共存は感情的保護や一律排除では成立しない。生息環境の変化、人里への誘引、個体群管理、被害、捕獲後の扱い、地域の担い手不足が連鎖するため、捕獲の必要性を科学的に判断し、行う場合は命・資源・地域知を無駄にせず循環へ戻し、同時に餌環境・境界管理・予防・モニタリングを改善する必要がある。

## 因果線
山の餌・環境変化 → 人里接近増加 → 被害・恐怖増加 → 緊急捕獲増 → 捕獲後資源が廃棄 → 山と人の関係がさらに断絶 → 生態・境界・利用を統合 → 適切な個体群管理と資源循環 → 予防投資と地域担い手へ還流 → 共存構造を再監査。

## 構造層
1. 生態層：個体群、餌、季節、移動。
2. 境界層：人里誘引、農地、ゴミ、緩衝帯。
3. 安全層：被害予防、警戒、捕獲判断。
4. 循環層：食・皮・地域資源としての適切な利用。
5. 倫理監査層：必要性、苦痛低減、持続性、地域合意。

## 適用例
1. 熊出没地域で誘引物管理と緩衝帯整備を先行する。
2. 捕獲個体の利用可否を衛生・法令・地域能力で判断する。
3. ジビエ事業の売上だけでなく被害予防への還流を測る。
4. 個体数推定と住民被害データを同じ計画で更新する。

## 測定・監査点
出没頻度、被害件数、誘引物除去率、捕獲判断根拠率、資源利用率、地域還流率、個体群推定誤差。

## 成立条件
生態データを更新する。予防を先行する。捕獲基準を明示する。衛生・法令を守る。地域還流を確認する。保護・利用双方を再監査する。

## 失敗条件
熊食を万能解にする。逆に利用を一律に倫理違反とする。被害住民を無視する。個体群データなしに捕獲する。商業化が捕獲需要を逆生成する。予防投資を削る。

## 反証条件
資源循環を導入しても被害・廃棄・地域担い手問題が改善しない。商業利用が過剰捕獲を誘発する。予防施策だけで同等以上の共存効果が得られる。個体群への悪影響が増える。地域合意が持続しない。

## 必須の区別
共存/無干渉、捕獲/駆除感情、利用/乱獲、熊食/万能解、予防/事後対応、地域還流/商業収奪、保護/放置。

## 誤読禁止
野生動物利用を無条件推奨しない。捕獲を娯楽化しない。被害を軽視しない。保護側を非現実的と一括しない。衛生・法令を省略しない。派生を地域計画の代替にしない。
