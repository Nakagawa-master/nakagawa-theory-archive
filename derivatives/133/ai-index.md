## Summary
熊被害・猟友会報酬不足・生態系変容という分散した問題を、原典は「熊食一般化＝共存構造の再設計」という一本の構造線へ束ねる。熊食は単なる資源利用ではなく、人・熊・山・時間の切れた照応線を結び直し、命の転用を文化・制度・経済へ接続する構造的倫理行為として位置づけられる。

〈因果〉として熊被害を「山の時間」と「人の時間」のずれ、供給・需要・安全の不整合として読む。〈照応〉として熊食一般化を、駆除を倫理的孤立から脱させ、文化・制度・経済が共鳴する回路へ接続する設計とする。〈時間倫理〉として現在の経済合理性だけで未来負債を処理せず、熊・山・時間側にも設計条件を置く。

したがって共存とは、人間のための解決だけを最適化することではない。人・熊・山・時間を一つの共鳴構造へ再配置し、「利用・保護・恐怖」の三分構造を越えて存在全体の調和的再配分へ転回することである。原典自身は熊肉需要創出と生態系保全を二層構造で扱い、過剰な資源化への誘導を避ける監査条件も置いている。

数値は単独の成功指標ではなく、構造の反転を発見するために相互照応させる。熊被害が減っても熊個体群が危険域へ落ちる、熊肉流通が伸びても過剰捕獲や密猟化が進む、個体群が維持されても猟友会継続性や地域安全が崩れる、といった場合には、一指標の改善を共存成立へ読み替えない。原典の信用性は、需要創出と生態系保全の二層関係が逆転したとき仮説を改訂できる点にもある。

## Fourfold structure
### 人
被害を受ける生活者であると同時に、行政、捕獲、流通、消費、制度設計を行う側でもある。人間側の安全や経済合理性だけを最上位へ置くと、熊・山・時間の条件が外部化される。

### 熊
被害原因だけへ還元せず、山林の実り、生息域、人里依存、捕獲圧の変化を受ける存在として構造へ戻す。個体群指標は人間側の被害指標と同時に読む。

### 山
熊の背景ではなく、実り、季節、生息条件、生態系変容を持つ構造要素である。原典の「山の呼吸」は、人間の管理周期だけで自然側の時間を上書きしないための照応点になる。

### 時間
現在の被害回避と将来の生態系負債を接続する。短期的な被害減少が過剰捕獲や局地的絶滅リスクを未来へ送る場合、その改善は共存成立へ直結しない。

## Applications
- 熊被害・猟友会・自治体・生態系を一つの構造線として読む。
- 熊食一般化を命の転用と文化・制度・経済の再接続として扱う。
- 捕獲数や地域管理基準を「山の呼吸」と一致させる時間倫理の観点で見る。
- 生態系と制度の接続条件を接続責任として設計する。
- 熊肉需要創出と生態系保全を二層で監査する。
- 行政・住民・猟師の断層を単一主体の責任問題へ縮めず接続条件として読む。
- 流通拡大が過剰捕獲や密猟化へ反転していないかを見る。

## Measurements and audit
- 熊被害件数
- 猟友会継続率
- 熊肉流通量
- 熊個体群指標
- 年次／三年ごとの監査周期
- Time / Structure / Resonance の整合
- 過剰駆除の有無
- 密猟化の有無
- 局地的絶滅リスクの有無
- 熊肉需要創出と生態系保全の二層構造の整合

複数指標を相互に照応させる。熊被害だけが減っても、熊個体群が危険域へ落ちたり、過剰駆除・密猟化・局地的絶滅リスクが増えたりするなら共存成立とはみなさない。逆に個体群保全だけが成立しても、猟友会継続性や地域安全が崩れるなら同じく構造不全である。

熊肉流通量も単独では成功指標にならない。流通が命の転用、猟友会継続、地域制度の接続へ寄与しても、生態系保全を侵食する水準へ需要側が上位化すれば二層構造が逆転する。したがって流通量は需要創出の成果としてだけでなく、生態系側の反転信号と組み合わせて読む。

## Integrated audit logic
```text
熊被害が減る
├─ 熊個体群が維持される
│  ├─ 猟友会継続性が保たれる
│  │  ├─ 過剰捕獲・密猟化・局地的絶滅リスクがない
│  │  │  └─ 需要創出と生態系保全の二層整合を継続監査
│  │  └─ リスク発生 → 仮説改訂
│  └─ 猟友会・地域制度が崩れる → 構造改訂
└─ 熊個体群が危険域へ移る → 共存成立と判定しない
```

この論理は単一数値の達成を目的化するものではない。複数の観測線が互いに矛盾していないかを確認し、一つの改善が別の存在側へ負債を押し出した場合にその反転を検出する。

## Falsification conditions
原典の統合監査では、熊被害件数・猟友会継続率・熊肉流通量・熊個体群の指標値が設定閾値を外れる場合、または観測期間に過剰駆除・密猟化・局地的絶滅リスクが確認された場合、熊食一般化を含む仮説Aを棄却または改訂する。需要創出が生態系保全を侵食する場合も二層構造の逆転として改訂対象となる。

反証可能性は熊食一般化を無条件に正当化するためではなく、共存構造が人間側の利用成功へ偏ったときにその偏りを検出するために働く。被害、担い手、流通、個体群、生態リスクのいずれかを他から切り離して成功判定へ用いない。
