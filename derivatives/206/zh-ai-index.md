## Summary
NAOS是国家层级的合意形成OS，不是强化中央统制的系统。它把国家规模问题的根因从单纯的预算或能力不足，重新定义为缺少可负责说明、无法在理解数字与责任后形成合意。资产、负债、未来责任、风险、利益、时间、当事者与责任归属被放入共同的Transaction Unit。优化不是效率或单一“国富”指标最大化，而是通过最大化说明可能性来最小化后悔。为实现跨国输出，合意形成Core与各国制度Plugin分离。T/S/R为Transparency / Selectability / Responsibility。Audit Bundle、Deviation Ledger、当事者访问、理由说明、异议程序以及禁止过度收集和目的漂移，是其正当性条件。

## Concepts
- NAOS：National Asset Optimization System / 合意形成OS。
- Consensus Failure：缺少可负责说明而无法形成知情合意。
- Transaction Unit：当事者、对象、时间、风险、负担、利益、责任归属的共同单位。
- Optimization = Regret Minimization：以说明可能性减少后悔。
- Core：跨国不变的合意形成骨架。
- Plugin：各国制度差异层。
- Transparency：可比较的透明性。
- Selectability：强制前的选择可能性。
- Responsibility：AI／专业人员／当事者责任分离。
- Tension Equilibrium：不抹除冲突而管理张力。
- Deviation Defense：记录并修复结构逸脱。
- Audit Bundle / Deviation Ledger：审计与再合意结构。

## Causal chain
```text
把国家视为单一决策主体
→ 实际多主体责任分散
→ 责任归属模糊
→ 延迟、分裂、局部最优持续
→ 将根因重定义为合意形成失败
→ 用Transaction Unit表示可比较方案
→ 将优化重定义为后悔最小化
→ 分离Core与Plugin
→ 在强制前放置Transparency / Selectability / Responsibility
→ 保持张力均衡与逸脱防御
→ 以Audit Bundle、Deviation Ledger和权利程序审计
→ 说明、选择或责任恶化时修订NAOS
```

## Applications
- 用未来成本、利益、时间、负担和责任比较城市收缩方案。
- 把空置住宅作为继承、权利、税、维修、拆除、情感与邻里风险的再契约问题。
- 将灾后恢复、迁移、补偿与未来责任放在共同形式中比较。
- 将税与给付、基础设施、国土保护等转为Transaction Unit，而非单一口号。
- 保持合意Core不变，将各国登记、税、司法、隐私与金融制度作为Plugin接入。

## Measurements and audit
- 方案是否能以数字、时间和责任比较。
- 强制是否先于理解和选择。
- AI／专业人员／当事者责任是否分离。
- 国家制度Plugin是否改变Core。
- 无法说明的例外、拖延或局部最优是否增加。
- Audit Bundle是否与T/S/R一致。
- Deviation Ledger是否保存结构逸脱。
- 当事者是否拥有访问、理由说明与异议程序。
- 是否防止过度收集和目的漂移。

## Validity conditions
- 说明可能性与选择可能性必须先于强制。
- Transaction Unit包含时间、风险、负担、利益与责任。
- Core与Plugin保持分离。
- Transparency / Selectability / Responsibility同时成立。
- AI、专业人员、当事者责任保持分离。
- Audit Bundle与Deviation Ledger持续存在。
- 保持当事者访问、理由说明和异议程序。
- 默认禁止过度收集与目的漂移。

## Failure conditions
- 被还原为政府数字化或智能城市管理。
- 以监视、执法扩张、属性标签为中心。
- 将国富或效率作为单一目标函数。
- 在可理解选项之前实施强制。
- 国家制度改变合意Core。
- AI、专业人员与当事者责任混同。
- 一方向透明、黑箱判断或无法异议。

## Falsification conditions
NAOS必须持续可审计并可自我修正。需要保持与T/S/R一致且可公开的Audit Bundle。若说明不能持续增加、强制越来越先于理解、责任归属持续模糊，则NAOS假设必须被否定或修订。Core被Plugin吸收、被转用为监视或国富最大化、当事者失去访问、理由说明或异议权，也属于需要记录和修复的逸脱。

## Required distinctions
- 国家优化 / 国家统制。
- 合意形成 / 效率最大化。
- 后悔最小化 / 国富最大化。
- 说明可能性 / 单纯信息公开。
- Transaction Unit / 单一政策指标。
- Core / Plugin。
- Transparency / 单向监视。
- Selectability / 强制。
- Responsibility / 责任消失。
- Audit / 道德断罪。

## Interpretation constraints
- NAOS不是强化国家权力的装置。
- 政府DX、智能城市统制、监视、执法与属性标签不是目标。
- 世界可输出标准不等于世界统一法制度。
- 国富或效率不应成为单一目的函数。
- 合意形成不是压制异议直到所有人同意。
- 透明性要求生活者也能访问同一说明形式。
