## Summary
NAOSは国家を強く統制する仕組みではなく、国家規模の意思決定を「説明して決める」形式へ変換する合意形成OSである。国家課題の根因を能力・予算不足だけでなく、数字と責任を理解したうえで合意できない説明構造の欠如として捉える。資産・負債・将来責任をTransaction Unitに束ね、最適化を効率最大化でなく説明可能性最大化による後悔最小化として定義する。世界展開では合意形成のCoreを固定し、税・登記・司法・ID等をPluginへ分離する。T/S/RはTransparency / Selectability / Responsibility。Audit Bundle、Deviation Ledger、当事者アクセス、理由提示、異議申立て、目的外収集禁止が正当性条件となる。

## Concepts
- NAOS: National Asset Optimization System / Consensus-Formation OS。
- Consensus Failure: 説明可能な合意構造の欠如。
- Transaction Unit: 当事者・対象・時間・リスク・負担・便益・責任帰属の説明単位。
- Optimization = Regret Minimization: 説明可能性を高め後悔を減らす。
- Core: 世界共通の合意形成背骨。
- Plugin: 国家別制度の差し替え層。
- Transparency: 比較可能な透明性。
- Selectability: 強制前の選択可能性。
- Responsibility: AI / 専門家 / 当事者の責任分離。
- Tension Equilibrium: 対立を合意形成へ接続する張力管理。
- Deviation Defense: 逸脱の差分記録と修復。
- Audit Bundle / Deviation Ledger: 監査・再合意面。

## Causal chain
```text
国家を単一主体とみなす
→ 実態は多主体の関係束である
→ 責任帰属が曖昧になり誰も決められない
→ 先送り・分断・部分最適が続く
→ 根因を合意形成不全として再定義する
→ Transaction Unitで数字・時間・責任を比較可能にする
→ 最適化を後悔最小化へ置き換える
→ Core / Pluginを分離する
→ 強制前にTransparency / Selectability / Responsibilityを置く
→ 張力均衡と逸脱防御を維持する
→ Audit Bundle / Deviation Ledger / Rightsで監査・再合意する
→ 説明不能・強制先行・責任不在が増えれば仮説を改訂する
```

## Applications
- 都市縮退の維持・集約・撤退案を将来コスト・便益・負担・責任で比較する。
- 空き家を権利・税・修繕・解体・感情・近隣リスクの再契約問題として扱う。
- 災害復興を補償・再配置・時間・将来負担の比較可能な案へ変換する。
- 税・給付、国土保全、安全保障等を単一スローガンでなくTransaction Unitで説明する。
- Coreを維持し、国別税・登記・司法・プライバシー等をPluginとして接続する。

## Measurements and audit
- 選択肢が数字・時間・責任で比較可能か。
- 強制が理解・選択より先行していないか。
- AI / 専門家 / 当事者の責任が分離されているか。
- CoreがPluginによって変質していないか。
- 説明不能・先送り・部分最適が増えていないか。
- Audit BundleがT/S/Rと整合するか。
- Deviation Ledgerが逸脱差分を保持するか。
- 当事者アクセス、理由提示、異議申立てが機能するか。
- 過剰収集・目的外利用が抑止されているか。

## Validity conditions
- 説明可能性と選択可能性を強制より先に置く。
- Transaction Unitへ時間・リスク・負担・便益・責任を含める。
- CoreとPluginを分離する。
- T/S/Rを同時に満たす。
- AI・専門家・当事者の責任分離を維持する。
- Audit Bundle / Deviation Ledgerを保持する。
- 当事者アクセス・理由提示・異議申立てを維持する。
- 過剰収集・目的外利用を標準で禁止する。

## Failure conditions
- 国家DXやスマートシティ管理へ回収する。
- 監視・取り締まり・属性ラベリングを中心化する。
- 国富・効率の単一指標を目的関数にする。
- 選択肢より強制を先行させる。
- Coreを国別制度へ吸収する。
- AI・専門家・当事者の責任を混線させる。
- 一方向透明性、ブラックボックス判断、異議申立て不能を許す。

## Falsification conditions
NAOSは常時監査可能・自己修復可能でなければならない。T/S/Rに整合する公開可能なAudit Bundleを保持し、説明不能、強制先行、責任不在が継続的に増える場合はNAOS仮説を棄却・改訂する。CoreのPlugin化、国家DX・監視・国富最大化への逸脱、生活者のアクセス・理由提示・異議申立ての喪失も設計逸脱として記録・修復する。

## Required distinctions

- 後悔最小化 / 国富最大化。

## Interpretation constraints
- NAOSは国家権力を強化する装置ではない。
- 国家DX、スマートシティ、監視、属性ラベリングを主目的としない。
- 世界共通規格は世界共通法制度を意味しない。
- 国富や効率を単一の目的関数へしない。
- 合意形成は対立を排除して同意させることではない。
- 透明性は生活者側からも同形式へアクセス可能である必要がある。
