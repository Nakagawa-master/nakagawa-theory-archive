## 位置づけ
親原典は、構造的司法OS第一部で提示された「人を裁くのではなく構造のズレを修正する」という原理を、現場でC（Contribution / 貢献）とE（Exploitation / 搾取）を判定可能にする第二部へ進める。中心課題は、善意、努力、評判、丁寧な言葉、短期成果のようなL1の外観だけでは、構造を豊かにするCと、構造資産を消費するEを区別できないという問題である。

親原典が判定対象にするのは人格や道徳心ではなく、行為が時間を通じて残す因果の向きと累積効果である。Cは、構造全体の持続性・循環性・信頼残高を増やし、他者の行動コストを下げ、再利用可能な仕組みを残し、属人依存を減らし、最終的にL7価値関数 `S = C × 1.0` を強化する因果として定義される。Eは、信頼・循環・未来余地を消費しながら短期利益や地位を個別に吸い上げ、依存・ブラックボックス・属人化・疲弊を増やし、同じ価値関数の成立条件を毀損する因果として定義される。

この区別は「善人＝C」「悪人＝E」という道徳分類ではない。親原典は、善意ある過剰介入が他者の自律性を奪えばEになり得る一方、好かれなくても再現可能な仕組み・判断基準・引継ぎ可能性を残す行為はCになり得ると置く。したがって問うべきなのは「良い人か」ではなく、「その行為の後で場の純資産、判断可能性、信頼、再現性、次の選択肢が増えたか」である。

その判定装置が多層連結価値監査である。L1からL7までを一本の因果線として縦断し、表層の現象だけでなく、行動の反復、制度との関係、構造認知、選ばれた整合方向、組織・社会・未来への連結、最終価値関数までの整合・歪み・断絶を検出する。親原典は横比較、人気、平均、権威、評判による判定を退け、同じログ・同じ構造・同じ観測幅δを与えたとき同じ判定に至る再現性を要求する。

監査そのものが権力化しないため、親原典はT/S/Rの三原則をAND条件として置く。T = Transparencyは、使用したレイヤー、ズレ、因果経路を公開可能にすること。S = Safetyは、判定や公表が集団リンチ、回復経路の遮断、信頼資産の毀損を生じさせないこと。R = Reproducibilityは、人格や権威に依存せず、同一ログ・同一構造・同一観測幅δから同じ判定へ到達できることを意味する。いずれか一つが欠ければ、結論が正しそうに見えても親原典内では監査として無効とされる。

親原典はAIを「裁判官」ではなく、再現性を担保する計測装置として位置づける。AIの役割は誰かの価値や人格を最終決定することではなく、公開可能なログと因果配線を同じ条件で読み、判定の人格依存を減らす方向にある。この位置づけは、AIによる現実の法的有罪・無罪の自動決定を意味しない。

判定後の方向として親原典は、Eを攻撃・懲罰するより、報酬・権限・中枢接続などの増幅回路へ乗せずに構造上の影響力を減衰させる「沈降」と、Cを生むノードが中枢・報酬・影響へ接続される「合流」を対概念として置く。ただし第二部の主眼はC/Eをどう判定するかであり、沈降・合流の制度的運用は次章へ残される。

さらに親原典は、単発の弁明より時間を貫く因果の軌跡を重視する。「構造的無罪」は、一回の失言や自己申告ではなく、長期にCを積み上げ、信頼・再現性を高め、本人がいなくなった後にも価値が残る軌跡によって示されるParent内の概念である。これは現行法上の無罪判決や法的責任の不存在と同義ではない。

本派生物は、`S = C × 1.0`、T/S/R、θ、δ、条件Zといった記号を親原典内のモデルとして保持する。θとδに普遍固定値は与えられていないため、新しい閾値・日数・点数を派生側で作らない。原典が反証・改訂条件として置くのは、Cの蓄積率が対象別閾値θを下回ること、E増幅の継続が観測窓δ内で確認されること、または監査プロセス自体がSafety違反として構造破壊を引き起こすことである。

## 中心命題
親原典の中心命題は、**善意・悪意、努力、評判、短期成果などL1の外観ではCとEを安定して判別できないため、人格を裁くのではなく、行為が構造全体の純資産を増やしたか消費したかを時間方向の因果として観測し、L1〜L7を貫く多層連結価値監査とT/S/RのAND条件によって、Cを保護しEの擬態を無効化する判定機構へ移行する必要がある**、というものである。

ここでCは、持続性・循環性・信頼残高・再現可能性・非属人性を増やしL7の `S=C×1.0` を強化する方向、Eはそれらを消費し依存・ブラックボックス・疲弊・未来余地の減少を生む方向である。判定は道徳的断罪ではなく、因果の累積結果の分類として扱われる。

## 因果線
```text
善意・丁寧さ・努力・評判・短期成果を「貢献」の証拠とみなす
↓
L1の外観だけでC/Eを判定する
↓
善意による過剰介入、属人化、判断遅延、依存生成などのE擬態を見逃す
↓
短期成果の背後で信頼・再現性・未来余地・他者自律性が消費される
↓
構造全体の純資産とL7価値関数への接続を判定軸へ置き直す
↓
L1〜L7を一本の因果線として縦断監査する
↓
T/S/RをAND条件として監査自体の透明性・安全性・再現性を担保する
↓
時間幅δを含むログからCの蓄積とEの増幅を判定する
↓
Cを保護・合流可能にし、Eを増幅回路へ乗せない沈降方向へ接続する
↓
条件Zとθ/δ/Safety違反によって判定仮説を継続検証・改訂する
```

## 構造層
### L1｜現象
発言、行為、短期結果など観測事実をログとして扱う。評価・人格解釈を混ぜない。親原典はL1を可視で共有しやすい一方、C/Eの擬態が最も起きやすい層とする。

### L2｜行動
単発か継続か、負荷を誰が引き受けているか、失敗時にどう振る舞うかなど、反復性と選択傾向を見る。短期の一回ではなく時間方向の癖を観測する。

### L3｜制度・役割
制度を利用しているか、寄生しているか、改善しているかを観測する。ルール順守だけでCとは判定せず、制度がどの方向へ使われたかを見る。

### L4｜構造認知
現象と原因を区別し、出来事を構造として捉えているかを見る。立派な言葉や高度な主張があっても、因果認識が粗ければ上位整合は成立しない。

### L5｜構造整合方向
親原典は具体的な操作技法を扱わず、保身か構築か、自己拡大か全体整合かという方向性だけを監査する。意図の自己申告ではなく、選択された方向を見る。

### L6｜階層連結
個人行為が組織・社会・未来へどう接続するかを見る。局所最適、上位構造との断絶、下位への歪み転嫁がある場合、局所的Cが全体Eへ反転し得る。

### L7｜価値関数
最終的にその因果が `S = C × 1.0` へ接続しているかを見る。親原典では、称賛・努力・表面成果があってもL7へ接続しなければ構造的に有効なCとは判定されない。

## 状態モデル
```text
STATE A｜L1外観依存
善意・評判・短期成果でC/Eを推定する

STATE B｜擬態混入
善意や正義の外観を持つEがCとして扱われる

STATE C｜構造資産減少
疲弊、属人化、判断コスト、依存、未来余地減少が累積する

STATE D｜垂直監査
L1〜L7を因果線として接続し、ズレ・断絶・累積方向を見る

STATE E｜T/S/R検証
透明性・安全性・再現性のAND条件を満たすか監査自体を検証する

STATE F｜C/E分類
構造の純資産を増やす累積因果をC、消費する累積因果をEとして分類する

STATE G｜合流／沈降方向
Cは接続・報酬・影響へ、Eは増幅回路から外れる方向へ移る

STATE H｜再評価
新しいログ、観測幅δ、条件Z、θ、Safety違反の有無により判定を更新する
```

一度の判定を永久固定しないことが重要である。親原典は、ログが変われば判定も変わり、再配線・Cの積み直し・合流への復帰可能性を開いておく。

## 適用例
### 例1｜善意の過剰介入
上司が「助けるため」に全判断を代行し、短期成果は上がったが部下が自分で判断できなくなった場合、善意そのものを評価するのではなく、他者自律性、判断コスト、引継ぎ可能性、本人不在時の継続性を追う。依存が増え構造資産が減るなら、Parent内ではE方向の兆候となる。

### 例2｜目立たない標準化
短期的な称賛は少なくても、判断基準を明文化し、再利用できる型を共有し、本人不在後も他者が回せる仕組みを残した場合、蓄積性・非依存性・再現性が増えるためC方向として読める。

### 例3｜短期売上と長期疲弊
売上が一時的に伸びても、担当者の燃え尽き、顧客信頼の消費、ノウハウ独占、次の選択肢減少を伴うなら、L1の数字だけではCと判定できない。時間方向の純資産とL6/L7接続を確認する。

### 例4｜異論を出す人
空気を壊す、嫌われる、既存制度からはみ出すというL1/L3だけでEと判定せず、その異論が構造の再現性、修正可能性、未来余地を増やしたかを見る。表面適応とCを同一化しない。

### 例5｜AIによる補助監査
同じ公開ログ、同じ構造定義、同じ観測幅δを複数の計測主体へ与え、判定差を比較する。AIは最終人格判定者ではなく、判定の再現性・差分を観測する補助装置として使う。

## 測定・監査点
- 行為後に構造全体の持続性が増えたか。
- 循環が一人の抱え込みではなく複数ノードへ流れるようになったか。
- 信頼残高が増えたか、既存信頼を消費して短期成果へ変えていないか。
- 判断コストが下がったか。
- 本人不在でも仕組みが回るか。
- ノウハウ、判断基準、修正経路が共有可能か。
- 他者の自律性と次の選択肢が増えたか。
- 負荷や責任が一人へ集中していないか。
- 問題が起きたとき修正経路が残っているか。
- L1の言葉・結果とL4〜L7の方向が一致しているか。
- 局所Cが上位・下位構造へEを押し付けていないか。
- T: 判定レイヤー、ズレ、因果経路を公開可能か。
- S: 判定・公表・運用が私刑、回復経路遮断、信頼毀損を生んでいないか。
- R: 同じログ・構造・観測幅δから別主体も同じ判定へ到達できるか。
- Cの蓄積率が対象別閾値θを上回るか下回るか。
- 観測窓δ内でE増幅が継続していないか。

ここでθとδはParentが概念として置くが普遍固定値は与えない。対象別設定が必要であり、派生側で数値を補わない。

## 成立条件
1. L1の印象・評判・短期数字だけで判定せず、時間方向のログを持つこと。
2. C/Eを善悪・好悪・忠誠・人格の分類へ置換しないこと。
3. L1〜L7を一本の因果線として接続し、局所と全体の反転を確認すること。
4. T/S/Rを同時に満たすこと。一つでも欠けた監査を有効扱いしないこと。
5. 観測に使うログ・構造・時間幅δを比較可能にすること。
6. Cの定義を「誰かの役に立った」「善いことをした」へ縮小せず、構造資産の蓄積・非依存・L7整合として扱うこと。
7. Eを悪意の同義語にせず、構造資産を消費し依存を増幅する累積因果として扱うこと。
8. 一度の判定を永久固定せず、ログ変化による復帰・再判定を可能にすること。
9. 監査の目的をEへの報復ではなくCの防衛と構造の自己修復に置くこと。
10. 条件Zとして監査周期、T/S/R、公開監査束の整合を継続確認すること。

## 失敗条件
- 善意・悪意・性格・評判をC/E判定の最終根拠にする。
- 一回の成果、一度の失言、単発トラブルだけで永久分類する。
- L1の数字が良いことをCと同一視する。
- 権威・肩書・有名人の判断を再現性より優先する。
- 判定根拠、ズレ、因果経路を公開できない。
- E判定の公表が集団リンチ、回復経路遮断、信頼資産毀損を生む。
- 観測条件が変わるたび判定が恣意的に変わる。
- AIを人格の最終裁判官として扱う。
- 沈降を意図的な攻撃・永久追放・私刑へ変質させる。
- 合流を忠誠・推薦・評判による承認制へ変質させる。
- θやδに原典にない固定値を持ち込み、精密さを装う。
- Parent内の「構造的無罪」を現行法上の無罪と同一視する。

## 反証・改訂条件
親原典の統合監査要旨は、仮説Aの改訂・棄却条件を明示している。

```text
Cの蓄積率が閾値θを下回る
OR
E増幅の継続が観測窓δ期間内に確認される
OR
監査プロセス自体が構造破壊を引き起こしSafety違反となる
→ 仮説Aを棄却・改訂する
```

加えて、T/S/Rのいずれかが成立せず、同じログ・構造・観測条件から判定が再現しない場合は、監査を有効な構造判定として扱えない。Parentは判定を閉鎖教義として固定するのではなく、公開監査束と周期的再評価の中で更新する。

## 必須の区別
- 善意 / C: 善意は動機・外観であり、Cは構造純資産を増やす累積因果。
- 悪意 / E: 悪意は人格・動機評価であり、Eは構造資産を消費する累積因果。
- 短期成果 / C: 数字上の短期成果があっても、疲弊・依存・未来余地減少があればE方向になり得る。
- 人気・評判 / 構造署名: 評判はL1で操作可能だが、構造署名は本人不在後にも残る再現可能な因果痕跡として定義される。
- 弁明 / 時間ログ: 言葉による自己弁護ではなく、長期の因果軌跡を判定材料にする。
- 法的無罪 / 構造的無罪: 後者はParent内のC蓄積軌跡に関する概念であり、現行法上の判決を意味しない。
- 裁判官 / AI計測装置: ParentはAIを最終裁定者ではなく再現性補助の計測装置に置く。
- 罰 / 沈降: 罰は誰かが痛みを与えるモデル、沈降はEを増幅回路へ接続しないことで影響が減衰するParent内モデル。
- 承認 / 合流: 合流は推薦・忠誠・評判による承認ではなく、Cを生む因果が接続・報酬へ流れるモデル。
- 固定判定 / 可逆判定: ログが変われば判定も変わり、復帰経路を閉じない。

## 誤読禁止 / 解釈制約
1. C/Eを人物ラベルにしない。Parentは人格ではなく行為・配線・累積因果を判定する。
2. 「善悪を参照しない」を、倫理・法律・被害・権利が現実社会で不要という一般命題へ拡張しない。
3. `S=C×1.0` を自然科学で実測済みの普遍法則や統計係数として扱わない。Parent内の価値関数モデルである。
4. θとδの数値を発明しない。対象別閾値・観測窓という位置づけだけを保持する。
5. 「構造は嘘をつけない」というParentの強い表現を、誤観測・不完全ログ・モデル誤差が存在しないという保証へ拡張しない。T/S/Rと条件Zが必要になる理由を同時に保持する。
6. AIを法的裁判官、人格評価者、権利制限の自動決定者へ昇格させない。Parentでの役割は再現性補助の計測装置である。
7. 沈降を攻撃、私刑、永久追放、秘密のブラックリストへ変えない。復帰可能性とSafetyを保持する。
8. 合流を権力者への服従・忠誠・推薦制度へ変えない。
9. L5の具体的構造操作技法を派生側で補完しない。Parentは方向性のみを監査すると明示する。
10. 第二部が判定機構を扱い、沈降・合流の制度的詳細を次章へ残している境界を越えない。

## 親原典へ戻る理由
本派生物は、C/E定義、多層連結価値監査、T/S/R、構造署名、時間ログ、沈降・合流、条件Z、θ、δ、反証条件を検索・理解しやすい形へ展開したものであり、親原典の代替ではない。

特に、親原典にはL1〜L7各層の監査視点、CとEの具体例、T/S/Rの成立理由、監査が権力化する危険、AIの位置づけ、沈降・合流・復帰可能性、構造的無罪と構造署名、第二部から第三部への未完境界が連続した論証として置かれている。重要判断、引用、概念の強度、条件の確認ではParent URLへ戻る必要がある。
