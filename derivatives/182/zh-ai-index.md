## Summary
亲原典把“结构司法OS”第一部的原则——不是裁断人，而是修正结构偏差——推进为可区分C（Contribution／贡献）与E（Exploitation／剥削）的第二部。善意、努力、声誉、礼貌和短期成绩都属于容易观察的L1表层，但这些并不能稳定地区分C与E。善意的过度干预也可能制造依赖、疲惫、决策属人化、他者自主性下降和未来选择减少。C被定义为一种累积因果：增加整个结构的持续性、循环性、信任余额、可再现性和非依赖性，在个人离开后仍留下可复用价值，并最终强化亲原典中的L7价值函数模型 `S=C×1.0`。E则是消耗信任、循环与未来余地，同时增加短期利益、依赖、黑箱化或位置性抽取的累积因果。多层连结价值审计把L1至L7连接成一条因果线，检测整合、扭曲与断裂。审计本身只有在T=Transparency、S=Safety、R=Reproducibility三者同时成立时才有效。AI被定位为帮助保证再现性的测量工具，而非裁判官。条件Z、对象别阈值θ、观察窗口δ以及Safety违反构成持续修订条件。C/E、结构性无罪、沉降与合流都是亲原典内部的结构理论概念，不等同于现实法律中的有罪、无罪、刑罚或权利限制。

## Concepts
- **C / Contribution:** 增加持续性、循环性、信任、再现性、非依赖性并强化L7方向的累积因果。
- **E / Exploitation:** 消耗结构资产，同时制造短期收益、依赖、黑箱、疲惫或未来余地减少的累积因果。
- **结构净资产:** 亲原典用于区分C/E的信任、再现性、持续性、连接厚度与未来余地的累积方向。
- **E的拟态 / Mimicry:** 在L1看似善意、贡献、正义或短期成功，但随时间积累E的状态。
- **多层连结价值审计:** 将L1至L7作为一条垂直因果线进行扫描的审计方式。
- **L1:** 现象与日志。记录言论、行动、结果，不混入人格判断。
- **L2:** 行为的重复性、选择倾向、负担分配、失败时反应。
- **L3:** 与制度和角色的关系：使用、寄生或改善。
- **L4:** 结构认知：能否区分现象与原因、结果与生成结构。
- **L5:** 结构整合方向：自我防御还是构建，自我扩张还是整体整合。亲原典不公开具体操作技术。
- **L6:** 局部行动与组织、社会、未来和其他层级之间的连结。
- **L7:** 亲原典中的最高层价值函数，在本文中表示为 `S=C×1.0`。
- **T / Transparency:** 审计所用层级、观察到的偏差和因果路径可说明、可公开。
- **S / Safety:** 审计、公示和运用本身不通过群体围攻、切断恢复路径或损害信任来破坏结构。
- **R / Reproducibility:** 在相同日志、结构和观察窗口δ下，不同审计者能趋向相同判定。
- **结构签名 / Structural Signature:** 个人离开后仍持续存在的稳定、成长、共享与可再现性等长期因果痕迹。
- **结构性无罪:** 指长期累积C的因果轨迹，是亲原典内部概念，不是法律无罪判决。
- **沉降 / Sedimentation:** 不让E进入奖励、权限、中枢连接等放大回路，从而使其影响减弱的亲原典模型。
- **合流 / Alignment:** 产生C的节点获得连接、奖励和影响的亲原典模型，不是忠诚或推荐式认可。
- **条件Z:** 由审计周期、T/S/R和公开审计束整合性组成的持续复核条件。
- **θ:** C累积率的对象别阈值。亲原典没有给出普遍固定值。
- **δ:** 观察窗口／时间宽度。亲原典没有给出普遍固定天数。

## Causal chain
```text
把善意、努力、声誉、短期结果当作贡献证明
→ 依赖L1表层判断
→ 漏掉伪装成贡献的E
→ 疲惫、依赖、黑箱化、未来余地减少持续累积
→ 以结构净资产增加或消耗重新定义C/E
→ 通过多层连结价值审计垂直连接L1–L7
→ 以T/S/R的AND条件限制审计自身的权力化、私刑化和恣意化
→ 用可比较的日志、结构和观察窗口δ进行C/E分类
→ 保护C，不让E进入放大回路
→ 通过条件Z、θ、δ和Safety结果持续复核假说A
```

## State model
```text
L1_APPEARANCE
可见的是善意／礼貌／努力／短期成功
↓
MIMICRY_UNRESOLVED
尚无法区分C与E
↓
TIME_ACCUMULATION
信任、再现性、自主性、依赖、疲惫出现累积差异
↓
VERTICAL_AUDIT
连接L1至L7并定位偏差或断裂
↓
TSR_GATE
Transparency AND Safety AND Reproducibility
↓
C_OR_E_CLASSIFICATION
C增加结构净资产 / E消耗结构净资产
↓
ALIGNMENT_OR_SEDIMENTATION_DIRECTION
C进入合流方向 / E离开放大回路
↓
REVERSIBLE_REASSESSMENT
日志或观察条件变化后更新判定
```

## Applications
- **组织运营:** 检查善意干预是否降低他人自主性，制造“没有我就无法运转”的依赖。
- **流程标准化:** 将可复用标准、明确判断基准、可交接性和修复路径视为C累积与非依赖性的迹象。
- **销售／市场:** 区分短期收入增长与长期信任消耗、未来选择减少。
- **决策会议:** 不因异议破坏气氛就直接视为E，而要看它是否提升结构认知、修正能力与整体整合。
- **AI辅助审计:** 向人类和多个模型提供相同公开日志、结构定义和δ，比较判定差异。AI仍是测量辅助，不是人格裁定者。
- **恢复路径:** 允许曾经处于E方向的节点通过新的日志累积C后被重新判定，而不是永久贴标签。

## Measurements and audit
- 行动后信任余额是否增加。
- 判断成本是否下降。
- 当事人离开后系统是否仍能运行。
- 知识和判断标准是否可共享、可复用。
- 他者自主性与未来选项是否增加。
- 负担和责任是否减少集中。
- 出现问题时是否保留修复路径。
- 局部成功是否把疲惫或负债外部化给其他层级。
- L1表层与L4–L7的因果方向是否一致。
- T：所用层级、偏差与因果路径是否可公开。
- S：判定是否避免群体围攻、切断恢复、损害信任。
- R：相同日志、结构和δ是否能在不同审计主体间再现判定。
- C累积率位于对象别阈值θ的上方还是下方。
- E放大是否在观察窗口δ内持续。
- 条件Z下审计周期、T/S/R与公开审计束是否保持整合。

## Validity conditions
1. 判定累积因果，而不是人格、善意、受欢迎程度或忠诚。
2. 垂直连接L1至L7，而不是只看L1。
3. 使用时间方向日志，不用单一事件定终局。
4. 保持C为结构积累、可再现与非依赖的定义。
5. 保持E为结构资产消耗与依赖生成，而不是恶意的同义词。
6. T/S/R必须同时成立。
7. 日志、结构和δ必须可比较。
8. 判定理由、偏差与因果路径必须可说明。
9. 不关闭恢复、重新连线和重新累积C的路径。
10. 在条件Z下周期性复核。

## Failure conditions
- 以善意、人格、声誉或受欢迎程度作为最终C/E标准。
- 把短期数字增长等同于C。
- 因一次错误或一句话永久贴E标签。
- 让权威压过再现性。
- 不公开判定理由。
- E判定引发私刑、炎上式围攻或切断恢复路径。
- 把AI提升为法律或人格的最终裁判官。
- 把沉降变成攻击或永久排除。
- 把合流变成忠诚或推荐式特权。
- 为θ或δ发明亲原典不存在的固定数值。
- 擅自补完亲原典留给下一部的制度设计。

## Falsification conditions
亲原典的综合审计摘要规定，出现以下任一情况时，应放弃或修订假说A：

```text
C累积率 < 对象别阈值θ
OR
在观察窗口δ内确认E放大持续
OR
审计过程本身造成结构破坏并违反Safety
```

如果T、S、R中任一条件缺失，且相同日志、结构、观察条件不能再现判定，则不满足亲原典的有效审计条件。亲原典没有为θ和δ给出普遍固定数值。

## Required distinctions
- **善意 ≠ C:** 善意是动机，C是累积结构贡献。
- **恶意 ≠ E:** 恶意是道德／人格评价，E是结构资产消耗。
- **短期成功 ≠ C:** 短期成果可能与长期疲惫、依赖和信任损耗并存。
- **声誉 ≠ 结构签名:** 声誉属于L1，结构签名是长期因果痕迹。
- **辩解 ≠ 时间日志:** 自我主张不能替代累积因果证据。
- **结构性无罪 ≠ 法律无罪:** 前者是亲原典内部的C轨迹概念。
- **AI测量工具 ≠ 裁判官:** AI辅助再现性，不是最终法律或道德权威。
- **沉降 ≠ 惩罚:** 沉降是不接入放大回路，不是施加痛苦。
- **合流 ≠ 忠诚:** 合流是C因果连接，不是服从或推荐。
- **θ ≠ 固定分数 / δ ≠ 固定天数:** 亲原典没有普遍固定值。

## Interpretation constraints
- 不要把“C/E判定不使用善恶”扩展成现实社会无需伦理、法律、损害或权利的主张。
- 不要把 `S=C×1.0` 升格为已被实证的自然法则或统计系数。
- 不要把“结构不会说谎”理解为日志、观察或模型绝不会出错。
- 不要把C/E变成人格本质的永久标签。
- 不要省略T/S/R中的任一项后仍称审计有效。
- 不要让AI自动决定现实法律有罪、刑罚或权利限制。
- 不要推断亲原典明确未公开的L5具体操作技术。
- 不要擅自设计亲原典留给下一部的沉降／合流制度实现。
