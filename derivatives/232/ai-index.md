## Summary
本Parentは水素ポータブル電源の製品紹介ではなく中川構造読解である。水素燃料電池、燃料カートリッジ、交換、回収、再充填等の対象側事実と、Nakagawa Masterが抽出した「保存する電力／保存電源」という価値核を分離する。非常時需要は発生時期が不明であるため、出力性能だけでなく必要時までエネルギー利用可能性を保持し、必要場所で発電し、交換・補給・回収まで運用できることを価値として読む。なぜ水素技術の新規性ではなく生活防衛・防災・BCPへ接続するこの軸で外部記事を書いたのかも保持する。

## Concepts
- 対象側事実: 水素燃料電池、燃料カートリッジ、交換、回収、再充填等。
- 表層分類: 水素、脱炭素、ポータブル電源、次世代バッテリー。
- 時間不確実性: 非常時電力需要の発生時期が分からないこと。
- 燃料保存: 使用時点までエネルギー利用可能性を燃料として保持すること。
- 必要時発電: 必要な場所・時点で燃料から電力を得ること。
- 交換運用: 本体と燃料を分け、交換・補給で継続利用可能性を作ること。
- 保存電源: Nakagawa Masterが抽出した価値核。企業公式定義ではない。

## Causal chain
非常時電力需要 → 発生時期不明 → 長期保存性が重要 → 燃料保持 → 必要時発電 → 燃料交換・補給 → 供給・回収・再充填 → 保存可能な電力アクセス。

## State model
平時準備相 / 長期保存相 / 非常時起動相 / 燃料交換相 / 供給接続相 / 回収再充填相 / 保存電源運用相。

## Applications
防災・BCP・非常用電源を分析するとき、瞬間出力や技術方式だけでなく、長期保存、必要時発電、交換・補給、供給、回収・再充填、安全・制度条件を分けて観測する。他用途への比較は「必要時まで電力利用可能性を保存する」ことが価値になる範囲に限る。

## Measurements and audit
対象側事実／表層分類／対象用途の時間不確実性／長期保存性／必要時発電／本体・燃料分離／交換・補給／供給・回収・再充填／安全・制度適合／価値核／価値核選択理由／外部記事執筆理由／企業公式見解との境界を確認する。原典にない保存期間・価格・性能優位を追加しない。

## Validity conditions
長期保存性、必要時発電、交換可能性、供給・回収・再充填、安全・制度運用が対象用途で接続し、将来の電力アクセスを保存する価値が実質的に成立する場合に有効である。

## Failure conditions
水素技術・脱炭素・スペック・価格だけへ平坦化する、保存性を水素万能論へ変える、蓄電池との単純勝敗へ置換する、Nakagawa Masterの価値核を対象企業の公式定義へ誤帰属する、外部記事執筆理由を消す場合は失敗する。

## Falsification conditions
保存性・交換・供給・回収が対象用途で実質価値を生まず、別方式・別因果の方が非常時電力アクセスを継続的に説明する場合は適用範囲を狭める。安全・制度・供給条件で利用不能な場合も改訂する。

## Required distinctions
対象側事実 / Nakagawa Masterの読解；水素技術 / 保存電源；発電性能 / 電力アクセス保存；燃料保管 / 運用系成立；製品単体 / 交換・供給・回収系；保存性 / 水素万能性；価値核 / 企業公式見解；価値核選択理由 / 外部記事執筆理由。

## Interpretation constraints
水素が常に他方式より優位としない。保存できれば安全・供給問題が解決するとしない。「保存電源」を企業公式定義にしない。「社会翻訳」等の一般語で、未来技術を生活防衛の具体へ接続するという外部記事執筆理由を置換しない。
