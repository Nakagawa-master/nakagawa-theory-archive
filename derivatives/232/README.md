## 中川構造読解としてのメタ視点
このParentは水素ポータブル電源の製品紹介ではない。Nakagawa Masterは「水素で発電する」という技術説明から一段上がり、**その仕様によってどの新しい価値定義が成立するか**を読む。

## 位置づけ
四層は **対象側事実 / 表層「水素・脱炭素・ポータブル電源」 / Nakagawa Masterの構造読解 / 社会翻訳**。価値核は **必要な時までエネルギーの使用可能性を保存し、必要な場所で発電できる状態を生活圏へ置くこと**。軸は「保存電源」。

## 中心命題
**水素そのものではなく、時間を跨いで使用可能性を保持する“保存する電力”という事業定義。**

## 表層 → 価値核 → 社会翻訳
`水素発電・スペック → 本体と燃料の分離 → 長期保存・交換可能性 → 機器/燃料/運用/信用の四層 → 保存電源として社会翻訳`

## 因果線
`非常時電力需要 → 発生時期不明 → 長期保存性が重要 → 燃料を保持 → 必要時発電 → 交換/補給/回収 → 保存可能な電力アクセス`

## 構造読解の監査点
水素万能論にしない。蓄電池との単純優劣にしない。出力・容量だけで評価しない。供給・安全・制度・運用層を落とさない。L4以上を保持。

## 成立条件
長期保存性、交換性、供給・回収、安全・制度運用が用途に適合すること。
## 失敗条件
水素技術の新規性や脱炭素訴求だけへ縮小すること。
## 反証・改訂条件
保存性が対象用途で実質価値を生まない場合は改訂。
## 必須の区別
水素技術/保存電源; 出力容量/時間を跨ぐ使用可能性; ハード/供給運用; 事実/読解。
## 親原典へ戻る理由
「水素で発電」から「保存電源」へ価値定義を上げた理由はParentへ。
