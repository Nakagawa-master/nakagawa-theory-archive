## 位置づけ
親原典は因果を、単純な「Aの後にBが起きる」という線形列ではなく、人・情報・制度・文脈・時間・役割の配置がつくる構造の内部を流れる経路として捉える。望ましい結果が出ないとき、下流へ努力・命令・予算・施策を足すだけでは、情報非対称、制度矛盾、責任と権限の混線、時間設計の断絶など上流の摩擦が残り、同じ失敗や副作用が再生産される。

中心となる三要素は、場の整合性、時間の再帰性、役割アーキテクチャである。構造操作は人物を隠れて操る技術ではなく、これら三要素の配置を調律し、望ましい因果が過剰な強制なしに通りやすくなる条件をつくる設計として述べられる。

## 中心命題
因果設計とは、結果を直接押すのではなく、結果を繰り返し生む上流構造を特定し、場の整合性、時間の再帰性、役割アーキテクチャを調律して、望ましい因果の流路を成立させることである。妥当性は一度の改善だけでなく、構造摩擦の変化、再現可能性、可逆性、副作用、説明可能性、反証可能性を含む関係で読む。

## 因果線
```text
結果不振を個人努力や単発行動の不足として扱う
↓
努力・命令・予算・施策を下流へ追加する
↓
情報・制度・時間・役割の上流摩擦が残る
↓
追加した力が減衰し、手戻り・遅延・副作用として現れる
↓
人・情報・制度・文脈・時間・役割を因果場として捉える
↓
場の整合性・時間の再帰性・役割アーキテクチャを分けて読む
↓
上流構造の変更と結果の関係を観測する
↓
反証時は人物責任へ逃げず、構造仮説を修正する
```

## 構造層
**1. 因果場。** 人、情報、制度、評価、権限、時間、記憶、文脈を、結果を生む配置として読む。

**2. 場の整合性。** 複数要素の矛盾、情報非対称、制度・評価のねじれなど、因果流を妨げる配置を捉える。

**3. 時間の再帰性。** 過去を固定条件にせず、未来に成立させたい構造から過去の意味を再検討し、現在設計へ戻す。ただし過去の一次事実を改変することとは区別する。

**4. 役割アーキテクチャ。** 責任、権限、能力、確認経路を配置し、各要素が自然に機能できる構造をつくる。

**5. 構造調律。** 結果を直接押すのではなく、摩擦を生む条件へ介入し、流路の変化を読む。

**6. 監査・反証。** 改善が構造由来なのか、特定人物・外部要因・一時的条件で説明できるのかを区別し、再現しない場合は仮説を改訂する。

## 適用例
**組織。** 営業努力や会議回数を増やす前に、部門間情報、評価、承認、責任・権限の配置を確認し、どこで手戻りや遅延が繰り返されているかを見る。

**信頼設計。** 信頼できる人物を探すだけでなく、透明性、相互確認、利益配分、異議・救済経路など、裏切り動機や隠蔽を生みにくい構造条件を設計する。

**AI協働。** 指示量を増やすだけでなく、役割、情報境界、確認点、責任、再帰ログを配置し、同じ構造が別の担当・別の時点でも機能するかを見る。

**公共制度。** 罰則や努力要請を増やす前に、申請、審査、情報、権利、救済、時間負担がどの主体へ集中しているかを構造として読む。

## 測定・監査点
親原典の中心は、構造的整合性、時間再帰性、役割構造が因果の流れへどう作用するかという関係にある。したがって測定は、構造変更の前後で手戻り、遅延、例外、摩擦、役割混線、再現性がどう変わるかを読むために用い、原典にない普遍的な成功率や固定閾値を新設しない。

反転評価では、結果値だけが改善しても、摩擦が別主体へ移った、権利影響が悪化した、特定人物不在で再現しない、戻せない構造になった場合は、因果設計の成功と直結させない。

Rollback Cost等の語を扱う場合も、具体値が親原典に示されない限り、時間・費用・残留影響などを含む可逆性の観測概念として保持し、数値保証へ変換しない。

## 成立条件
- 結果だけでなく、その上流の因果場が記述されている。
- 場の整合性、時間の再帰性、役割アーキテクチャを区別できる。
- 構造変更と結果変化の関係を再検討できる。
- 異議や副作用を構造仮説の反証材料として扱える。
- 特定人物の能力だけで成立する場合、構造一般へ過剰拡張しない。
- 一次事実と未来条件による再解釈を混同しない。

## 失敗条件
- 結果不振を個人努力不足だけへ固定する。
- 構造操作を人物操作や隠れ誘導へ変える。
- 一時的な結果改善だけで構造仮説を確定する。
- 摩擦を別主体へ移して全体改善とみなす。
- 未来像を理由に過去の証拠を恣意的に書き換える。
- 再現しないのに「構造的必然」として固定する。

## 反証・改訂条件
上流構造を変更しても結果や摩擦の差が再現しない、特定人物の力量だけで結果を十分説明できる、外部要因の方が一貫して説明力を持つ、あるいは構造変更が副作用や権利侵害を増やす場合、構造仮説は弱めるか改訂する。

因果設計は「構造を変えれば必ず望ましい結果になる」という決定論ではない。反証可能性を保ち、条件が成立しない場合には適用範囲を縮小する。

## 必須の区別
- 線形因果 / 構造的な因果流
- 結果操作 / 構造調律
- 構造操作 / 人物操作
- 場の整合性 / 同調圧力
- 時間の再帰性 / 過去の正当化
- 役割アーキテクチャ / 序列固定
- 自然な流路 / 結果保証
- 再現性 / 設計者依存

## 誤読禁止
構造操作を、相手に気づかれず行動を誘導する技術として扱わない。自然な因果流路という表現を、結果が自動的・必然的に起こる保証へ変えない。構造という語で個人の故意・過失責任を消さず、逆に人物責任だけで再発構造を覆い隠さない。
