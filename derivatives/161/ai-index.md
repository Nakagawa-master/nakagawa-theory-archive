## Summary
親原典は、人類史の成功構造を文明監査し、複数の独立AIが `Success = Creation×0.1 + Exploitation×0.9` という同一評価関数へ収束したと報告する。原典自身はこれを意見や道徳的比喩ではなく、「最も再現性が高く誤差の少ない因果モデル」「統計的・構造的記述」「文明の物理法則」と強く位置づける。ここで0.1／0.9は人数比ではなく、親原典が成功（富・権力・地位）を説明する評価関数の係数として提示する値である。ただし本文中には外部データセット、標本設計、推定手順、信頼区間等は示されていないため、親原典のAI収束観測モデル係数として扱い、独立検証済み普遍統計や自然科学定数へ自動昇格させない。親原典はさらに、AIが旧文明の履歴から搾取的最適化を学ぶ危険を示し、時間倫理T0、逸脱レッジャ、起源署名を連動させることで `Success = Creation×1.0`、搾取係数0という新しい文明OS評価関数への転換を提案する。この新式は現状の実測統計ではなく、貢献と価値帰属を再接続する規範的・設計的目標である。

## Concepts
- 暗黒方程式: `Success = Creation×0.1 + Exploitation×0.9` として親原典が提示する旧文明の評価関数。
- Success: 親原典で監査対象となる富・権力・地位等の成功結果。
- Creation: 発明・創作・技術・善意・公共財等の価値生成因果。
- Exploitation: 情報非対称性、規模優位、価値吸収等により、価値生成者と価値回収者を分離する構造。
- 0.1 / 0.9: 親原典が複数AIの収束観測モデルとして提示する係数。人数比や普遍定数ではない。
- AI再生産リスク: 過去の成功履歴を最適化するAIが搾取的戦略を合理的に選ぶ危険。
- 時間倫理T0: 短期利得の背後に蓄積する未来負債を監査する時間軸。
- 逸脱レッジャ: 搾取サイクルや責任非対称を構造偏差として記録・追跡する機構。
- 起源署名: 誰がどこで何を生成したかという価値起点を追跡可能にする機構。
- 新文明方程式: `Success = Creation×1.0`, exploitation coefficient = 0 という設計目標。
- 価値帰属: 生成された価値が誰へ帰属・還元されるかという因果線。
- 構造的公共性: 評価関数・起源・逸脱・価値帰属が第三者から監査可能な状態。

## Causal chain
```text
人類史の成功履歴が蓄積
→ 貢献と価値帰属が分離
→ 情報非対称性／規模優位／価値吸収が成功へ接続
→ 親原典が複数AIの収束観測として
  Success = Creation×0.1 + Exploitation×0.9
  を提示
→ AIが旧履歴を成功戦略として学習
→ 搾取的最適化を効率的戦略として再生産しうる
→ 未来負債／責任非対称／起源消失が増大
→ T0で未来負債を可視化
＋逸脱レッジャで持続不能な搾取サイクルを記録
＋起源署名で価値生成点を追跡
→ 貢献と価値帰属を再接続
→ 設計目標として Success = Creation×1.0 / exploitation coefficient = 0
→ 貢献と成功の因果対称性を高める
```

## Applications
- AI学習・評価系で、成功ラベルが価値創造より価値捕捉・囲い込み・情報差利用を高く評価していないかを監査する。
- 企業・市場で、利益増加と価値生成者への還元、下請け負担、データ起源、未来負債を同時に比較する。
- 知識・創作領域で起源署名を維持し、生成点と再利用後の価値帰属を追跡する。
- 公共政策でGDP・効率等の短期指標と、未来負債・責任非対称・公共性を分離して評価する。
- 組織評価で地位・権限・売上と、実際の貢献・価値生成を因果的に分離する。


親原典は0.1／0.9を強く「物理法則」「統計的・構造的記述」と呼ぶ。この主張強度は保持するが、外部再現性の証拠が本文に明示されていないという情報状態も保持する。

新式 `Creation×1.0` / exploitation coefficient 0 は、旧式と同じ観測統計ではない。T0、逸脱レッジャ、起源署名によって実現を目指す設計評価関数であり、現在の社会が100%貢献だけで成功を説明するという観測主張ではない。

監査対象には、貢献と価値帰属の一致、価値吸収、情報非対称性、未来負債、起源追跡、逸脱ログ、AIの最適化戦略、搾取依存、貢献者への価値還元、公共性を含める。個別に数値化する場合は値、出典、測定主体、対象、尺度、期間、適用範囲、非保証範囲を明記する。

反転評価では、富・利益・地位・権限が増えても、価値生成者からの吸収、未来負債、起源消失、責任非対称が増えるなら文明的成功としない。短期利益率や価値捕捉率が下がっても、貢献者への帰属、起源追跡、未来負債削減、公共性が改善するなら、その低下のみを失敗とはしない。

## Validity conditions
- 0.1／0.9を親原典の複数AI収束観測モデル係数として扱う。
- 成功、貢献、搾取、価値帰属を分離して観測する。
- 搾取を個人悪意だけに限定せず、情報非対称性・規模優位・価値吸収等の構造として扱う。
- AI危機を文明履歴の評価関数再生産として扱う。
- T0・逸脱レッジャ・起源署名を連動させる。
- 新式1.0／0を現状統計ではなく設計目標として区別する。
- `θ`・`δ`・`M`による反証・改訂可能性を保持する。

## Failure conditions
- 0.9を成功者人数の90%と解釈する。
- 0.1／0.9を自然科学定数や外部検証済み普遍統計へ変える。
- 原典にないデータセット・誤差幅・信頼区間を発明する。
- 搾取を犯罪的悪意に限定し、構造的効率性を落とす。
- AI危機をAI人格の悪意へ還元する。
- `Creation×1.0` を現在の実測式として扱う。
- 起源署名を独占所有へ、逸脱レッジャを懲罰台帳へ縮約する。

## Falsification conditions
対象別の貢献と成功の関係、搾取構造と成功の関係、AIによる旧評価関数再生産、未来負債、起源追跡、価値還元等について、指標が設定された`θ`を越える／下回る、観測窓`δ`が閉鎖される、または現象`M`が確認され、暗黒方程式の説明力や新文明方程式への遷移仮説と整合しない場合、係数解釈・適用範囲・因果仮説を棄却または改訂する。

特に、明示的な独立データセットと推定手順で0.1／0.9が再現されない、貢献が成功を強く説明し搾取構造が説明力を持たない対象群が継続的に観測される、AIが旧成功履歴を学習しても搾取最適化へ収束しない、T0・逸脱レッジャ・起源署名を導入しても貢献と価値帰属の接続が改善しない場合は再審対象となる。

## Interpretation constraints
「搾取90％」を成功者人数の90％へ変換しない。0.9は親原典が成功評価関数へ置く係数である。親原典の「意見でも思想でもない」「物理法則」という強いモダリティは保持する一方、その語だけから自然科学の普遍定数や外部独立検証済み法則を推論しない。搾取は犯罪や悪意だけでなく、情報非対称性・規模優位・価値吸収等の構造的副作用を含む。新文明方程式は現在統計や利益保証ではなく、評価関数を書き換える設計目標である。起源尊重は知識専有化と同義ではなく、親原典は公共利用と起源保持を同時に要求する。
