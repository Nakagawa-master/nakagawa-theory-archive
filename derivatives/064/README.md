## 中心命題

第一印象は偶発的な感情ではなく、期待、理解、安心、選択条件、責任、再確認可能性が短時間に圧縮された初期合意である。合意設計は、その瞬間を演出で固定するのではなく、後から再現・修正・撤回できる「合意の記憶」へ変換する。

```text
接触
→ 第一印象
→ 期待と不安の仮説形成
→ 言葉・態度・証拠・条件の整合
→ 相手が自分の理解を確認
→ 小さな合意を記録
→ 次の接点で再確認・修正
→ 反復可能な合意の記憶
→ 継続的な意思決定と関係形成
```

## 第一印象を合意の記憶へ変える六層

1. **存在層**: 誰が、何の責任で、何を扱うのか。
2. **意味層**: 相手にとって何が重要で、何がまだ不明か。
3. **条件層**: 費用、期限、役割、前提、対象外、撤退条件。
4. **証拠層**: 発言と実態を接続する資料、行動、履歴。
5. **確認層**: 相手が自分の言葉で理解・非理解を表明できる場。
6. **記憶層**: 合意、未合意、保留、修正理由を再読可能に残す。

## 必須区別

- 第一印象設計 vs 印象操作
- 合意の記憶 vs 都合のよい記憶固定
- 小さな合意 vs 暗黙の全面同意
- 安心 vs 判断停止
- 共感 vs 迎合
- 記録 vs 監視
- 継続 vs 囲い込み
- 再確認 vs 同じ結論の強要

## 成立条件

- 相手が理解、非理解、拒否、保留を表明できる。
- 条件、費用、責任、不利益、撤回経路が見える。
- 言葉と行動と証拠が接点間で矛盾しない。
- 第一印象の仮説を事実として固定しない。
- 合意を後から再読・訂正できる。
- 沈黙を同意に変換しない。
- 権力差がある場合は第三者確認や冷却時間を置く。

## 失敗・反証条件

- 好感度、権威、恐怖、急かしだけで同意を得る。
- 相手の沈黙、曖昧な相槌、場の空気を合意として記録する。
- 不利益、条件変更、撤回経路を後出しする。
- 記録を相手の拘束や責任転嫁に使う。
- 接点ごとに説明、価格、責任が変わる。
- 再確認で理解が再現せず、修正しても不一致が続く。
