## 中川構造読解としての位置づけ
このParentはAlgaleXや「うま藻」の食品・素材紹介ではない。Nakagawa Master本人が、藻類食品・環境配慮・新素材という対象事実を材料に、なぜ「環境に良い素材」ではなく「味覚から食料供給の上流を再設計する構造」を価値核として読み、その価値核で外部記事を書いたのかを公開解体する記事である。

## 対象側事実と表層
表層では藻類食品、環境配慮、新素材、サステナブル食品に見える。

## Nakagawa Masterが読んだ構造
上流に環境・資源・生産課題があっても、「正しい」「環境に良い」だけでは生活者の継続選択が成立しにくい。味覚・おいしさを入口に反復需要を作り、その需要シグナルを素材・生産・供給側へ返すことで、上流構造を変える余地が生まれる。

## 抽出価値核
**味覚から食料供給の上流を再設計する構造。**

## なぜこの価値核で外部記事を書いたのか
環境配慮や新素材を主軸にすると、供給側の「正しさ」を生活者へ押し下ろす記事になり、継続需要が成立する条件が見えない。Nakagawa Masterは、味覚で需要を立ち上げ、その反復需要から上流へ変化を返す方向こそ外部読者に示すべき構造だと判断し、この価値核で外部記事を書いた。

## 因果線
`上流課題 → 正しさだけでは継続困難 → 味覚価値 → 日常選択 → 反復需要 → 需要シグナル → 素材/生産/供給変化 → 上流再設計`

## 境界
「味覚起点型上流再設計」はNakagawa Masterの構造読解であり、AlgaleX自身の公式企業定義ではない。味が良ければ自動的に食料問題が解決するという主張でもない。

## 成立・失敗・反証条件
味覚価値が反復需要を形成し、その需要が上流側の選択へ戻る場合に成立する。環境配慮・藻類・味の良さだけへ縮小した場合は失敗。需要が上流変化へ接続しない場合は適用範囲を改訂する。
