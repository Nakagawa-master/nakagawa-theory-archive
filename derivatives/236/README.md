## 中川構造読解としてのメタ視点
このParentはAlgaleXや「うま藻」の食品・素材紹介ではない。Nakagawa Masterは、環境配慮・藻類・新素材という供給側の説明から一段上がり、**生活者が実際に選び続ける理由を需要側に作り、その反復需要を食料供給の上流へ返すことで、上流構造そのものを変えられるか**という因果を読む。

四層を固定する。**対象側事実 / 表層「藻類食品・環境配慮・新素材」 / Nakagawa Masterの構造読解 / 社会翻訳**。価値核は **味覚・おいしさを入口に反復需要を作り、その需要シグナルを素材・生産・供給側へ返して食料供給の上流を再設計すること**。この「味覚起点型上流再設計」はAlgaleX自身の公式企業定義ではない。

## 位置づけ
Parentが問題にするのは、上流に環境・資源・生産課題があっても、「正しい」「環境に良い」だけでは生活者の継続選択が成立しにくいこと。味は販売上の装飾ではなく、供給側の変化を需要側の日常へ定着させる実装条件として読む。

## 中心命題
**供給側から正しさを押し下ろすのではなく、味覚で需要を立ち上げ、その反復需要から食料供給の上流へ変化を返すこと。**

## 表層 → 価値核 → 社会翻訳
```text
藻類食品・環境配慮・新素材
→ 正しさだけでは日常選択が続かない
→ 味覚・おいしさを入口にする
→ 反復需要をつくる
→ 需要シグナルを素材・生産・供給へ返す
→ 「味覚から食料供給の上流を再設計」と社会翻訳
```

## 因果線
`上流課題 → 正しさ訴求だけでは需要継続しにくい → 味覚価値 → 日常選択 → 反復需要 → 需要シグナル → 素材/生産/供給の変化 → 上流再設計`

## 構造読解の監査点
- 藻類・環境配慮・新素材の説明だけへ縮小しない。
- 「おいしい商品だから売れる」というマーケ一般論へ縮小しない。
- 味覚→反復需要→上流変化という方向を保持する。
- 味が良ければ自動的に食料問題が解決すると一般化しない。
- 企業公式定義とNakagawa Masterの読解を分離する。
- L4以上のメタ視点を保持する。

## 成立条件
味覚価値が実際の反復需要を形成し、その需要が素材・生産・供給側の選択へ戻ること。

## 失敗条件
環境配慮商品・藻類素材・味の良い食品へ縮小すること、需要から上流へ返る因果を消すこと。

## 反証・改訂条件
味覚価値が継続需要を生まない、または需要シグナルが上流変化へ接続しない場合は適用範囲を改訂する。

## 必須の区別
- 対象側事実 / Nakagawa Masterの構造読解
- 環境配慮 / 継続需要の設計
- 味の訴求 / 味覚起点型上流再設計
- 商品販売 / 上流供給構造の変化
- Parent / 社会翻訳
