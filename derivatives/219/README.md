## 位置づけ
本原典は、耐久文明が全体合意を回復できないまま長期化したとき、社会が単純な無秩序へ崩れるのではなく、複数の局所秩序へ縮退して持続する構造を「共圏」として記述する。恐怖・利益・監視という主機関、神話と惰性という増幅・持続機構が、文明全体ではなく局所圏内部へ再配置されることで、全体社会が壊れたままでも小さな秩序だけが維持される。

共圏は単なる分断、情報偏向、仲間集団、共同体ではない。原典が固定する定義は、合意形成を失った社会が全体を修復できないまま、局所秩序だけを自己正当化しながら維持する閉鎖圏である。閉鎖の本質は物理的隔離ではなく、意味・評価・責任・敵味方・利益配分・監視規範が圏内で自己完結し、外部との因果接続と意味互換性が細くなることにある。

## 中心命題
共圏の中心命題は、耐久文明が「一つにまとまっているから」続くのではなく、「まとまれないからこそ局所閉鎖の群れとして続く」という逆説にある。全体合意の形成コストが高まり、全員に通じる語彙や正当化を維持できなくなると、社会は全体秩序の修復より、狭い範囲で通じる説明・損得・規範・敵味方を使った局所安定を選びやすくなる。

局所秩序は広域合意より安く、速く、当面は安全である。そのため共圏は単なる悪意ある設計ではなく、劣化した全体接続環境への自己保存的適応として自然発生しうる。しかし局所安定が強まるほど、共通語彙、共通責任、共通制度を再構成する必要と能力は痩せ、文明全体の再起動可能性が削られる。共圏は文明を止めないが、文明を治さない。

## 因果線
```text
合意形成能力が劣化する
→ 全員に通じる語彙・正当化・共有現実を維持するコストが高騰する
→ 全体を説得・再接続する努力が弱まる
→ 秩序形成の単位が全体社会から局所圏へ縮小する
→ 圏内では語彙・感情・記憶・利害・敵味方・規範が高い互換性で循環する
→ 恐怖・利益・監視・神話・惰性が局所圏内部へ再配置される
→ 圏内の正当性が外部承認なしでも自己循環する
→ 外部異議は検討対象より雑音・妨害として処理されやすくなる
→ 語彙の意味互換性が低下し、責任・負荷が圏外へ外部化される
→ 共圏間の接続・再合意コストが上昇する
→ 局所安定は維持されるが全体再構成能力は低下する
→ 閉鎖ブロック間の摩擦・資源競合・責任不在・語彙不通約性が蓄積する
→ 次段階の相転移条件が準備される
```

## 構造層
**1. 全体合意断念層。** 異質な立場を一つの説明へ束ねるコストが高まり、社会全体を納得させる努力が弱くなる。

**2. 局所性縮退層。** 無秩序へ落ちるのではなく、狭い範囲で通じる小さな秩序へ秩序形成単位が縮小する。

**3. 自己正当化循環層。** 圏内の評価が圏内語彙で支えられ、語彙が圏内経験で補強され、経験が圏内評価で意味づけられる循環が安定装置になる。

**4. 五要素再配置層。** 恐怖・利益・監視・神話・惰性が局所圏の接着束として再統合される。

**5. 語彙閉鎖層。** 同じ言葉でも圏外との意味互換性が低下し、外部反論が圏内語彙へ翻訳されない限り意味を持ちにくくなる。

**6. 責任外部化層。** 内部の設計・判断・運用不整合が、圏外者・外部条件・妨害へ再局在化され、圏内中核が保護される。

**7. 局所安定／全体脆弱化層。** 圏内では当面の安定が得られる一方、共通語彙・共通責任・共通制度の再構築能力が痩せ、全体再起動可能性が低下する。

## 適用例
**組織間対立。** 各部門・組織が内部語彙と内部評価だけで自己正当化し、他部門の異議を情報ではなく妨害として扱い始めていないかを見る。

**公共的議論。** 同じ用語を使っていても意味・痛み・敵味方・正当性の基準が圏ごとに異なり、外部へ翻訳できない状態を「単なる意見差」から分ける。

**デジタル空間。** 推薦と高速反応が、既に反応した語彙・情動・評価圏を反復し、検証より所属確認を先行させていないかを見る。

**制度設計。** 局所安定を高める施策が、共通語彙・異議申立て・責任共有・外部説明可能性を削っていないかを同時に確認する。

## 測定・監査点
- 全体に通じる語彙・説明・異議処理の回路が残っているか。
- 秩序形成の対象が全体社会から局所圏へ縮小していないか。
- 圏内では通じるが圏外へ翻訳できない語彙が増えていないか。
- 圏内の正当性が外部検証・反論・修正なしで循環していないか。
- 恐怖・利益・監視・神話・惰性が局所秩序維持の束として作動していないか。
- 内部不整合の原因・責任が圏外者や外部条件へ一方向に流されていないか。
- 局所安定の上昇と同時に全体再接続・再設計能力が低下していないか。
- 推薦・反復・高速反応が語彙と所属確認の局所化を加速していないか。
- 共圏間の資源競合、意味不通約性、責任不在、摩擦が蓄積していないか。

## 成立条件
- 社会全体の合意形成・再接続能力が低下している。
- 全体へ通じる語彙・正当化を維持するコストが高い。
- 局所圏では狭い語彙・損得・規範・敵味方を共有する方が安く速く安定する。
- 圏内の意味・評価・責任・利益・監視規範が自己完結的に循環する。
- 恐怖・利益・監視・神話・惰性の五要素が局所秩序の維持へ再配置される。
- 外部異議や外部基準を圏内へ翻訳・再検討する回路が細くなる。

## 失敗条件
- 共圏を単なる「分断」「偏った情報」「似た意見の人の集まり」へ縮小する。
- 共同体・相互扶助・仲間集団と共圏を同一視する。
- 閉鎖を人の出入りだけで判断し、意味・評価・責任の自己完結を見ない。
- 共圏を悪意ある設計者だけが上から作るものとする。
- 圏内安定を社会全体の修復・合意再建と同一視する。
- 責任蒸発と責任の圏外外部化を区別しない。
- デジタル空間を単なる情報量やエコーチェンバー一般論へ置き換える。

## 反証・改訂条件
局所圏が内部の整合性だけでなく、圏外の異なる立場へ説明可能であり、外部反論を雑音化せず修正へ取り込み、共通語彙・共通責任・共通制度を再構成する能力を保持している場合、共圏を中心とする説明は弱まる。

また、局所秩序の強化が全体再接続能力を実際には低下させず、むしろ圏間翻訳・責任共有・再合意を安定的に増やすことが観測される場合、「閉じることで局所安定し全体再起動力を削る」という因果モデルは改訂対象となる。原典の統合監査要旨が置く反証・改訂可能性を超えて、派生側で独自の固定閾値を追加しない。

## 必須の区別
- 共圏 ≠ 単なる分断。
- 共圏 ≠ 情報偏向だけ。
- 共圏 ≠ 共同体。
- 共圏 ≠ 仲間集団・利害集団だけ。
- 閉鎖 ≠ 物理的隔離だけ。
- 圏内通用性 ≠ 普遍妥当性。
- 局所安定 ≠ 全体修復。
- 局所延命 ≠ 文明再生。
- 責任蒸発 ≠ 責任の圏外外部化。
- 高速接続 ≠ 意味互換性の拡大。

## 誤読禁止 / 解釈制約
共圏を「閉じた集団は悪い」という道徳論へ変えない。原典は、全体接続能力が低下した環境では閉鎖が自己保存的適応として自然発生しうることを記述している。問題は閉じたい人々の性格ではなく、閉じなければ秩序を維持しにくいほど全体社会の接続能力が劣化している構造にある。

また、「正しいかではなく通じるか」という記述を、圏内成員が虚偽を自覚しているという主張に変えない。原典は、圏内語彙・敵味方・痛み・利益配分が成員にとって現実的な世界表現として感じられるため共圏が強くなると論じる。特定の現実集団を根拠なく共圏と断定せず、原典にない共圏スコアや固定閾値も追加しない。

本派生物は、共圏を「全体合意の断念に対する局所秩序化」「閉じた自己正当化循環」「五要素の局所再配置」「局所安定と全体再起動力低下」という構造として検索・理解可能にする面である。語彙閉鎖、責任外部化、デジタル加速、共圏間摩擦、次論の相転移への接続は親原典本文へ戻って確認する必要がある。
