## Summary
“共圏”是指：当社会失去重建整体共识的能力后，并不会立刻坠入无秩序，而是收缩为多个局部秩序。在这些局部圈层内部，词汇、利益、规范、敌我、记忆与意义仍保持较高互通性；恐惧、利益、监视、神话、惰性也从文明整体层面被重新配置到局部圈层之中，使局部秩序能够继续存在。

其核心不是物理隔离，而是自我正当化循环：圈内评价由圈内词汇支撑，圈内词汇由圈内经验强化，圈内经验再由圈内评价赋义。这样的循环降低了局部稳定成本，却同时削弱圈外语义兼容性、共同责任、共同制度以及整体社会的重新设计能力。共圏可以让文明局部延命，却不能修复整体；圈层之间的摩擦、资源竞争、责任缺口与语义不可通约性会继续累积，并为后续“相转移”准备条件。

## Causal chain
```text
共识形成能力劣化
→ 维持全社会共同词汇、正当化与共享现实的成本上升
→ 说服与重新连接整体社会的努力减弱
→ 秩序形成尺度从整体社会收缩到局部圈层
→ 圈内词汇、情绪、记忆、利益、敌我与规范的兼容性提高
→ 恐惧、利益、监视、神话、惰性在局部圈层内重新配置
→ 圈内正当性无需外部认可即可自我循环
→ 外部异议更容易被视为噪声或干扰
→ 圈外语义兼容性下降，责任向圈外外部化
→ 圈层之间重新连接与再共识成本上升
→ 局部稳定维持，但整体重构能力下降
→ 摩擦、资源竞争、责任缺口、语义不可通约性累积
→ 相转移条件形成
```

## Applications
- 观察组织或部门之间是否形成只在内部互通、难以跨边界翻译的词汇与评价体系。
- 区分实质性意见分歧与“先判断你属于哪一边、再判断内容”的所属确认结构。
- 观察推荐、重复与高速反应机制是否强化既有词汇、情绪与敌我结构。
- 审核提升局部稳定的措施是否同时削弱外部可解释性、异议处理、责任共享与圈层间翻译。
- 追踪资源竞争、责任外部化、语义不可通约性是否逐步接近临界转变。

## Measurements and audit
- 是否仍存在跨整体社会的共同词汇、说明、异议处理与再共识路径。
- 秩序形成尺度从整体收缩到局部圈层的程度。
- 圈内通用性与圈外可解释性之间的差距。
- 外部异议能否引发修正，还是主要被视为噪声或干扰。
- 恐惧、利益、监视、神话、惰性是否在局部形成束化结构。
- 内部失败是否被持续归因于圈外主体或外部条件。
- 局部稳定与整体重新连接、重新设计能力是否出现反向变化。
- 推荐、重复与高速反应是否让所属确认先于事实验证。
- 圈层间摩擦、资源竞争、责任缺口与语义不可通约性的累积。

## Validity conditions
- 整体社会的共识形成与重新连接能力已经下降。
- 维持跨整体的共同词汇与正当化成本较高。
- 在局部圈层共享较窄的词汇、利益、规范与敌我模型更便宜、更快、更稳定。
- 圈内意义、评价、责任、利益分配与监视规范形成自我循环。
- 五要素被重新配置用于局部秩序维持。
- 将外部异议与外部标准翻译回内部并进行修正的路径变细。

## Failure conditions
- 把共圏缩减为一般“分裂”或信息偏向。
- 把共圏等同于共同体、朋友圈或利益集团。
- 只以物理隔离判断封闭。
- 认为共圏只能由恶意设计者自上而下制造。
- 把局部稳定等同于整体社会修复或再生。
- 混淆责任蒸发与责任向圈外外部化。
- 把数字环境论点替换成一般性“回音室”描述。

## Falsification conditions
如果局部圈层仍能向实质上不同的外部立场进行说明，把外部反论纳入修正，并能够重建共同词汇、共同责任与共同制度，那么以共圏为中心的解释会减弱。如果局部秩序增强反而稳定地提升圈层间翻译、责任共享与再共识，而不是削弱整体重新连接能力，那么“通过封闭获得局部稳定并削弱整体重启能力”的因果模型也需要修订。不得添加原典没有的固定数值阈值。

## Required distinctions
- 共圏 / 一般分裂
- 共圏 / 仅信息偏向
- 共圏 / 共同体
- 共圏 / 朋友圈或利益集团
- 封闭 / 物理隔离
- 圈内通用性 / 普遍可解释性
- 局部稳定 / 整体修复
- 局部延命 / 文明再生
- 责任蒸发 / 责任外部化
- 高速连接 / 语义兼容性提升

## Interpretation constraints
不要把共圏改写成“封闭群体就是坏的”这种道德判断。原典把封闭视为整体社会连接能力劣化后可能自然出现的结构性自我保存反应。“圈内能通用”也不能被解释为成员明知虚假。不要在缺乏独立事实依据时把现实中的特定群体直接判定为共圏，也不要自行创造共圏评分、固定KPI、阈值或持续时间。
