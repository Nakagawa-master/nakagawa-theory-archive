## Summary

连接对价社会把价值从“劳动时间→货币报酬”的单线评价扩展为贡献、信任与共鸣三个连接维度。贡献指改善共同结构，信任来自透明决策与长期履约，共鸣指概念或结构被他者自愿再参照并进入行动原理。三者不能压缩成永久社会评分；需要一次记录、束指标、同意、裁定、异议、再合意和回滚来保持可逆性。再访、介绍、再参照、持续协作可以作为支持证据，而指标游戏化、声誉暴走、强制同调和配分歪曲是副作用与反证线索。

## Concepts
连接对价；贡献；信任；共鸣；一次记录；束指标；同意；裁定；回滚。

## Causal chain
```text
劳动与报酬脱钩 → 价值起源空缺 → 多维连接记录 → 束化评价 → 同意与裁定 → 多层配分 → 长期审计
```

## State model
```yaml
- 记录
- 分类
- 束化
- 同意
- 配分
- 异议
- 再合意
- 回滚或继续
```

## Applications
开源、研究共同体、人类-AI共创、地方活动、公共配分。

## Measurements
再利用、再访、介绍、持续协作、同意失败率、再合意时间、配分歪曲、游戏化、回滚成本。

## Validity / failure / falsification
成立需要多指标、目的限定、同意、异议与退出。若变成人气竞赛、永久单一评分或无同意评价即失败。若不能改善长期协作反而增加排除，应修正假设。

## Interpretation constraints
不得理解为货币立即消失的预言、社会信用评分或AI决定论。
