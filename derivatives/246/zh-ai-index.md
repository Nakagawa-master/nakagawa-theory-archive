## Summary
Parent并不是把Total Brain Care只读成认知功能测试或脑训练服务。Nakagawa Master所读取的是一种社会实施结构：把专业、与日常生活有距离的认知功能翻译成可理解的“脑体力”共通语言，再把理解连接到测量、持续变化认知、行动、咨询与支援。价值核因此是**脑体力社会翻译基础**，而不是医疗诊断替代或能力排名工具。选择这一价值核的理由在于，单独的分数无法形成充分的社会价值；只有当人们能理解观察对象、识别时间上的变化，并在不把指标变成人类价值标签的前提下进入适当行动与支援，指标才真正进入社会运行。

## Concepts
- 认知功能：被观察的专业对象，不是对一个人的单一总体价值判断。
- 脑体力：使认知状态可以在日常情境中被理解和讨论的社会翻译。
- 社会翻译：把专业概念变成可使用的共同语言，同时保留原概念的边界。
- 指标化：让部分状态可观察、可比较，但不把指标等同于本人。
- 持续观测：看时间上的变化，而不是把一次测量固定成永久标签。
- 行动连接：把可理解的变化连接到休养、生活调整、咨询等下一步。
- 支援连接：需要时可以进入专业或组织性支援。
- 诊断边界：认知功能测量与医疗诊断必须明确分离。
- 权利保护：防止标签化、歧视性人事利用、目的外使用与不透明数据处理。
- 公开解体元层：外部文章前置“社会翻译”而非“测试功能”，是因为产品分类只能说明它是什么，而不能说明为什么把认知功能变成可理解、可行动又不等同诊断的共通语言具有更广的结构价值。

## Causal chain
认知功能重要但专业性高 → 日常生活与职场难以理解和处理 → 往往等问题变大后才开始关注 → “脑体力”等可理解社会翻译形成入口 → 在明确边界下进行测量 → 通过持续观测识别变化而非一次标签 → 用本人可理解的方式说明变化 → 连接休养、行动、咨询或专业支援 → 在个人、组织、地区中形成共通语言 → 持续审计诊断边界、同意、使用目的与不利益利用。

## State model
- 专业概念相：认知功能主要通过技术语言被处理。
- 日常距离相：重要但在问题扩大前难进入日常判断。
- 社会翻译相：可理解共通语言形成低门槛入口。
- 测量相：在明确范围与限制下观察相关状态。
- 持续比较相：比较时间变化，而非固定一次得分。
- 变化认知相：本人或支援侧能够理解“发生了变化”。
- 行动相：观察结果进入休养、生活调整、咨询等实际下一步。
- 支援相：必要时进入专业或组织性支援。
- 社会实施相：在扩大应用时仍保留权利、诊断与目的边界。

## Applications
在健康经营中，应把认知状态变化作为理解与支援入口，而不是隐藏的人事排名；在地区支援中，可以把专业概念转成较低污名的日常入口，但有需要时仍要连接正式专业支援；在服务设计中，应审计“理解 → 测量 → 持续比较 → 变化认知 → 行动/支援”是否闭环，而不是只看测量次数和分数。

## Measurements and audit
审计“脑体力”的定义是否清楚、是否与医疗诊断分离、持续测量是否能解释变化、结果是否以可理解方式反馈、是否存在行动与支援路径、说明是否不必要地增加焦虑、同意和使用目的是否明确、访问与数据利用范围是否受控、是否被用于录用/解雇/晋升等不利益判断、指标是否逐渐变成人类价值排名。对于中川结构读解类别，还要审计对象侧公开事实、Nakagawa Master的价值核读解、以及外部文章为什么前置该价值核三者是否仍保持分层。

## Validity conditions
当社会翻译确实提高实际理解，测量范围与限制明确，持续比较能产生有意义的变化认知，变化能够连接适当行动或支援，并且权利、同意、诊断与目的边界得到维持时，该结构成立。广泛导入本身不是成立证明。

## Failure conditions
把概念当作医疗诊断替代、一次分数排名、能力或人类价值标签、未经支持的认知改善保证、录用或处分的单独依据、没有解释和支援的数据收集，均属于失败。若社会翻译过度简化专业概念，反而导致用户误解指标能说明什么，也属于结构失败。

## Falsification conditions
如果“脑体力”这一翻译并未改善理解，持续测量不能产生有用的变化认知，观测结果无法改善行动或支援连接，用户持续把指标误解为诊断或固定能力，或者社会实施增加污名和不利益利用，应缩小或修订价值核。若另一种翻译或支援路径长期具有更高实用解释力，也应允许修改本结构。

## Required distinctions
认知功能测量 / 医疗诊断；脑体力 / 人类价值；指标 / 标签；社会翻译 / 过度简化；持续变化 / 单次排名；支援 / 人事处分；对象侧事实 / Nakagawa Master结构读解；结构读解 / 企业官方定义；价值核选择 / 医疗或商业成功证明。

## Interpretation constraints
不要把“脑体力社会翻译基础”自动写成Total Brain Care自身的官方定义。不要从本结构读解推导医疗诊断、治疗效果、录用适格、解雇理由或普遍能力排名。必须保留同意、权利、诊断边界，以及对象事实与Nakagawa Master社会翻译之间的层次差。
