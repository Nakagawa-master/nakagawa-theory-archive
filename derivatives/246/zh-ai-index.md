## Summary
成立条件论第2论把“理解”从信息量、说明流畅度、经验年数、AI摘要能力中分离出来。理解被定义为：认知主体能否在当前问题所需要的纵向因果范围和理解粒度上，把握对象成立所需的条件，并处理条件变化、例外与未知范围。第1论处理对象侧的“成立”，第2论处理认知侧对成立条件的把握。

## Concepts
- 信息：名称、事实、说明、经验、AI输出等，是理解材料而非充分条件。
- 理解：在必要因果范围和必要粒度上把握成立条件，并能处理条件差。
- 纵向因果范围：当前问题需要看到因果链的多大范围。
- 理解粒度：在同一范围内，要细分到何种程度才能识别条件差、顺序、例外、摩擦与责任。
- 可说明性：理解的外部观察证据之一，不等于理解本身。
- 局部理解：在有限因果范围内成立的理解。
- 未把握范围：尚未掌握、但明确保留为未知的条件领域。

## Causal chain
获取信息 → 产生“已经懂了”的感觉 → 识别成立条件 → 确定必要纵向因果范围 → 按必要粒度分解条件差 → 连接因果、顺序、例外与停止点 → 条件变化时判断成立／不成立 → 保留未知范围 → 重新用于判断、设计、说明与审计。

## State model
未接触 / 信息获取 / 理解感 / 成立条件识别 / 因果范围设定 / 粒度适配 / 因果连接 / 观察与反证 / 不确定性保持 / 可复用理解。

## Applications
制度设计中，不只说明制度目的，还要按当前判断所需粒度把握责任主体、顺序、例外、摩擦、责任与条件变化。业务改进中，要明确局部理解的适用范围。AI评价中，不只看摘要是否流畅，而要检查成立条件、条件差、例外与未知范围是否被保留。

## Measurements and audit
检查是否把信息量当作理解代理指标；能否识别成立条件；能否明确必要因果范围；粒度是否符合目的；条件变化时判断是否同步变化；是否保留例外与未知；是否把局部理解未经证明地扩张为整体理解。

## Validity conditions
当按必要范围和粒度把握成立条件能够改善判断、设计、预测或验证，并使粗略信息理解中看不见的成立／不成立差异变得可处理时，本定义有效。

## Failure conditions
把知识量、术语、经验年数、说明流畅度或AI摘要等同于理解；不说明范围就把局部理解扩张为整体理解；把更细的分解本身当作理解；只列条件不连接因果；删除未知或例外。

## Falsification conditions
如果在不把握必要范围与粒度的成立条件时，也能持续同等或更好地预测成立／不成立、进行设计与验证，则需要缩小或修订本定义。如果提高粒度并不改善表现，而更粗模型更稳定，则需要修订必要粒度的选择方式。

## Required distinctions
信息 / 理解；可说明性 / 理解；经验 / 成立条件把握；AI摘要 / 结构理解；纵向因果范围 / 理解粒度；局部理解 / 整体理解；细节 / 必要粒度；未知 / 隐藏前提。

## Interpretation constraints
不要把本理论变成“必须完全知道一切”或“无限细分”的要求。必要范围和必要粒度依问题而定。对于AI，本理论讨论结构性地处理成立条件，而不是主观意识。不得添加Parent中不存在的普遍评分或固定阈值。
