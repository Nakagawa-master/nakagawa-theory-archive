## Summary
本论把“理解”与信息量、表达流畅度、经验年数、AI生成摘要的能力区分开来。所谓理解，是指在当前目的所需要的范围和细致程度上，把握对象得以成立或运作所依赖的条件。

文章提出两个不同维度。第一是**因果范围**：能够看到与对象成立相关的因果链到什么程度。第二是**理解粒度**：能够多细地识别条件、顺序、例外、摩擦和依赖关系之间的差异。

看得很广并不代表看得足够细；对局部理解得很深，也不能自动等同于对整体的理解。说明、设计、运营、安全确认等不同目的，需要的范围和粒度并不相同。

## Concepts
- 信息：理解的材料，但不是理解本身。
- 成立条件：对象得以成立或运作所需要的条件与因果关系。
- 因果范围：能够把握到多大范围的相关因果。
- 理解粒度：能够多细地分辨条件差异。
- 局部理解：在有限范围内的深入理解，不等于整体理解。
- 可说明性：可能成为理解的证据之一，但不等于理解本身。
- 未知条件：尚未把握的因素，应作为未知因素明确存在。

## Causal chain
获得信息 → 产生“已经明白”的感觉 → 识别成立条件 → 连接条件之间的因果 → 确定所需范围与粒度 → 考察条件变化时结果如何变化 → 明示仍未知的条件 → 形成可用于判断、设计和验证的理解。

## State model
名称认知 / 概要理解 / 理解感产生 / 成立条件识别 / 因果连接 / 范围设定 / 粒度设定 / 条件变化预测 / 不确定性明示 / 可复用理解。

## Applications
可用于制度设计、业务运营、教育、安全确认和AI辅助分析等场景，帮助区分“能说得很顺”与“真正把握了决定结果的条件”。

## Measurements and audit
可观察的问题包括：是否能够指出成立条件；是否能够说明条件之间的因果；所观察的范围是否与目的相符；是否能在所需粒度上区分条件差异；条件改变后能否解释结果变化；未知条件是否被明确标示。信息量或语言流畅度本身不足以证明理解已经成立。

## Validity conditions
当可靠的预测、设计、判断或验证确实需要在适当范围和粒度上把握成立条件时，这一定义具有解释力。

## Failure conditions
如果把理解等同于信息量、表达流畅度、经验年数或AI语言自然度，就会偏离本论的定义。如果过度追求细节本身，反而失去“为了什么判断而需要这一粒度”的目的，也同样偏离本论。

## Falsification conditions
如果持续证据表明，即使不把握相关成立条件，也能够同样稳定地预测、设计、判断和验证对象是否成立，那么这一理解定义的适用范围需要重新评估。

## Required distinctions
信息量 / 理解；说明能力 / 理解；经验年数 / 理解；局部理解 / 整体理解；因果范围 / 理解粒度；AI流畅度 / 成立条件把握。

## Interpretation constraints
把理解简化为“知道更多细节”会失去本论所区分的两个维度。核心在于，在当前目的所需的范围和粒度上把握成立条件，并能够进行因果推理。条件或目的发生变化时，所需的理解范围和粒度也可能变化。
