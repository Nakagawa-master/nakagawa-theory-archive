## Summary
本Parentはトータルブレインケアを、認知機能テスト、脳トレ、ヘルスケア測定という表面分類だけで読むものではない。Nakagawa Masterは、認知機能が生活・仕事に重要であっても、専門用語や診断文脈に閉じると、本人・組織・地域が日常的な変化として理解し、行動や支援へつなぐ共通言語を持ちにくい構造を読む。価値核は、認知機能を「脳体力」という理解可能な概念へ社会翻訳し、測定、継続比較、変化認識、生活行動、相談、専門支援へ接続する**脳体力社会翻訳基盤**である。

価値核を「測定」ではなく「社会翻訳基盤」に置くのは、数値を出すだけでは本人の理解や支援接続は保証されず、逆に単純な能力順位・ラベルへ誤用される危険があるからである。外部記事でも、認知機能の専門解説や測定機能ではなく、「脳体力」という共通語によって認知状態を日常で扱える入口を作る構造を前面化した。この価値核と記事化理由はトータルブレインケア自身や外部媒体の公式理論ではなく、Nakagawa Masterの構造読解である。

## Concepts
- **認知機能**: 注意、記憶、遂行等を含む認知上の機能領域。単一の人間価値指標ではない。
- **脳体力**: 専門的認知概念を日常で理解しやすくする社会翻訳上の語。
- **社会翻訳**: 専門概念を一般利用者が理解・行動できる形へ変換しつつ、元の意味・境界を失わないこと。
- **基盤指標**: 単発の順位付けではなく、状態・変化を理解し支援へ接続するための観測入口。
- **継続測定**: 単発値の高低より、本人の通常状態からの変化を追うこと。
- **変化認識**: 数値をラベルではなく、生活・負荷・休養・相談を見直すシグナルとして扱うこと。
- **行動接続**: 結果を生活行動、休養、セルフケア等へつなぐこと。
- **支援接続**: 必要に応じ相談窓口・専門家・医療等へつなぐこと。
- **診断境界**: 測定・社会翻訳と医療診断を同一視しないこと。
- **権利保護**: 人事不利益、採用・解雇、能力ランキング、無断利用へ転用しないための同意・目的・アクセス管理。
- **価値核選択理由**: 測定精度だけではなく、理解→変化認識→行動・支援の社会接続が事例の価値差を説明すること。
- **外部記事化理由**: 認知機能の専門語を、日常で扱える「脳体力」へ翻訳する社会実装を読者へ示すこと。

## Causal chain
認知機能は生活・仕事へ影響する → 専門用語・診断文脈に閉じる → 一般利用者が日常で扱いにくい → 問題が大きくなるまで変化を認識しにくい → 「脳体力」という理解可能な共通語へ翻訳する → 測定の意味と診断境界を説明する → 単発値ではなく継続変化を観測する → 本人が変化を理解する → 生活行動・休養・相談へ接続する → 必要なら専門支援へつなぐ → 同意・利用目的・データ範囲を管理する → ラベリング・人事不利益を防ぐ → 支援後の変化を再観測する → 認知機能が日常的な社会実装対象として扱われる。

## State model
- **専門概念相**: 認知機能が専門家・診断の文脈で理解される。
- **日常距離相**: 本人が自分の状態と結びつけにくい。
- **社会翻訳相**: 「脳体力」という共通語で理解入口を作る。
- **境界説明相**: 測定と医療診断、人間価値を区別する。
- **測定相**: 状態を観測する。
- **継続比較相**: 単発値ではなく変化を追う。
- **変化認識相**: 本人が通常状態との差を理解する。
- **行動相**: 休養、生活改善、業務負荷見直し等へ接続する。
- **支援相**: 必要な相談・専門支援へつなぐ。
- **権利保護・再観測相**: 同意・目的を守り、支援後を継続確認する。

## Applications
1. **個人セルフモニタリング**: 単発の高低ではなく、自分の通常状態からの変化を理解し、休養・生活見直し・相談へ接続する。
2. **健康経営**: 組織導入時に測定結果を人事評価へ直結させず、本人支援・業務負荷・休養の入口として扱う。
3. **地域支援**: 問題発生後の診断だけでなく、本人・家族が変化へ気づく共通言語として使う。
4. **専門支援への接続**: 測定結果だけで疾病を決めず、必要時に専門家へ相談する判断材料とする。
5. **データガバナンス設計**: 同意、閲覧権限、保存期間、利用目的、禁止用途を先に設計する。
6. **他の健康指標**: 専門概念を社会翻訳する同型構造を比較できるが、認知機能の意味・倫理境界を無条件に移植しない。
7. **中川構造読解の再利用**: 対象事実、構造読解、価値核、選択理由、外部記事化理由を分離して保持する。

## Measurements and audit
- 「脳体力」の意味が利用者に理解可能か。
- 認知機能測定と医療診断の境界が明示されているか。
- 単発スコアを絶対評価・能力順位へ使っていないか。
- 継続変化を本人の通常状態との関係で見られるか。
- 結果が生活行動・休養・相談・支援へ接続しているか。
- 測定だけで健康効果を保証していないか。
- 同意、利用目的、閲覧範囲、保存範囲が明確か。
- 採用・解雇・人事不利益の単独根拠へ転用されていないか。
- ラベル化・不安増大・監視感などの副作用を確認しているか。
- 支援後の変化を再観測できるか。
- 対象側公開事実とNakagawa Masterの社会翻訳を混同していないか。
- 「なぜ測定ではなく社会翻訳を価値核にしたか」「なぜ外部記事で脳体力を主軸にしたか」が保持されているか。

## Validity conditions
専門的な認知機能概念が、意味を過度に損なわず「脳体力」という理解可能な入口へ翻訳されること。測定の意味と医療診断との境界が説明され、単発順位ではなく継続変化の把握に使われること。変化認識が本人の行動・相談・必要な専門支援へ接続し、同意・利用目的・データ範囲・不利益利用防止が保たれる場合に成立する。

## Failure conditions
「脳体力」を医療診断の代替にする、人間価値や能力順位へ変える、単発スコアを絶対視する、測定だけで健康効果を保証する、採用・解雇・配置・評価の単独根拠へ使う、本人同意や利用目的が不明確、測定結果が支援へ接続しない場合は失敗する。外部記事化理由を落として単なる認知測定サービス紹介へ戻すことも中川構造読解としての失敗である。

## Falsification conditions
「脳体力」という翻訳が利用者理解を改善せず、むしろ誤解・ラベル化・不安を増やす、継続測定が有用な変化認識につながらない、変化認識が行動・相談・支援へ接続しない、不利益利用や権利侵害が増える場合は適用範囲・用語・運用条件を改訂する。別の説明・指標の方が理解と支援接続に高い説明力を持つ場合も価値核を再検討する。

## Interpretation constraints
