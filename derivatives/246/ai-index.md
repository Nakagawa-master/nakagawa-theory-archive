## Summary
理解を語彙認知や流暢な説明から切り離し、「対象の成立条件を、目的上必要な粒度で把握し、因果として追跡・検証できる状態」と定義する。細かさの最大化ではなく、成立判断に足る必要粒度が中心である。

## Concepts
成立条件；必要粒度；理解；理解感；因果追跡；条件欠損；検証可能性；目的依存粒度；不確実性。

## Causal chain
対象接触 → 概要認知 → 理解感 → 成立条件抽出 → 目的設定 → 必要粒度へ分解 → 条件間因果接続 → 欠損/変更時の予測 → 検証 → 理解成立。

## State model
未接触相 / 名称認知相 / 概要理解感相 / 条件抽出相 / 必要粒度相 / 因果接続相 / 検証相 / 理解成立相。

## Applications
AI出力評価、制度設計、教育、契約、業務設計、暗黙知移転で、説明の流暢さではなく成立条件と因果追跡可能性を監査する。

## Measurements and audit
条件列挙；目的適合粒度；条件間因果；欠損時予測；未確定条件の明示；観測可能性；再検証可能性。

## Validity conditions
成立条件が必要粒度で把握され、その因果接続から設計・判断・予測・検証が可能な場合。

## Failure conditions
名称認知、要約、専門語、流暢な説明だけで理解済みと判定する場合。

## Falsification conditions
必要粒度の成立条件把握なしに同等以上の設計・予測・検証が継続的に可能なら定義または適用範囲を改訂する。

## Required distinctions
知識 / 理解；概要 / 成立条件；細かさ / 必要粒度；説明可能性 / 因果追跡；理解感 / 検証可能性。

## Interpretation constraints
完全知や無限分解を要求しない。必要粒度は目的依存。不明点を隠すことを理解とはしない。

## Search terms
