## Summary
成立条件論・第2論は、理解を情報量や説明の流暢さから切り離し、対象の成立条件を問いに必要な縦因果範囲と理解粒度で把握し、条件差・例外・未把握範囲を扱える状態として定義する。第1論が対象側の「成立」を扱うのに対し、第2論は認識主体側で成立条件がどこまで把握されているかを扱う。

## Concepts
- 情報: 名称、事実、説明、経験、AI出力等。理解の材料だが十分条件ではない。
- 理解: 成立条件を必要範囲・必要粒度で把握し、条件差を扱える状態。
- 縦因果範囲: 成立に関わる因果をどこまで把握対象とするか。
- 理解粒度: 同じ範囲で条件差、順序、例外、摩擦等をどの細かさまで判定できるか。
- 説明可能性: 理解を外部観測する証拠の一つ。理解そのものではない。
- 局所理解: 限定された因果範囲内で成立する理解。
- 未把握範囲: まだ把握していない条件を未知として保持する領域。

## Causal chain
情報取得 → 分かった感 → 成立条件識別 → 必要な縦因果範囲を定める → 必要粒度で条件差を分ける → 因果・順序・例外・停止点を接続 → 条件変更時の成立／不成立を判定 → 未把握範囲を保持 → 判断・設計・監査へ再利用。

## State model
未接触 / 情報取得 / 分かった感 / 成立条件識別 / 縦因果範囲設定 / 必要粒度適合 / 因果接続 / 観測・反証 / 不確実性保持 / 再利用可能。

## Applications
制度設計では理念や概要だけでなく、担当、順序、例外、摩擦、責任、条件変更を必要粒度で把握する。現場改善では局所理解の有効範囲を明示する。AI評価では要約の流暢さより、成立条件・条件差・例外・未把握範囲を保持できるかを見る。

## Measurements and audit
情報量を理解の代理指標にしていないか。成立条件を識別できるか。縦因果範囲を明示できるか。理解粒度を目的に合わせて調整できるか。条件変更時の結果差を予測できるか。例外と未知を保持できるか。局所理解を全体へ一般化していないか。

## Validity conditions
成立条件を問いに必要な範囲と粒度で把握することで、条件変更時の判断・設計・予測・検証が改善し、粗い情報把握では見えなかった成立／不成立の差を扱える場合に有効である。

## Failure conditions
知識量、専門語、経験年数、説明の滑らかさ、AI要約を理解そのものとみなす。範囲を示さず局所理解を全体理解へ拡張する。細分化そのものを理解とする。条件列挙だけで因果をつながない。未知・例外を削除する。

## Falsification conditions
必要範囲・必要粒度で成立条件を把握しなくても同等以上に成立／不成立を予測し、設計・検証できることが継続的に確認される場合、適用範囲を改訂する。粒度を上げても性能が改善せず粗いモデルの方が安定する場合は必要粒度の決定方法を見直す。

## Required distinctions
情報 / 理解；説明可能性 / 理解；経験 / 成立条件把握；AI要約 / 構造理解；縦因果範囲 / 理解粒度；局所理解 / 全体理解；細かさ / 必要粒度；未知 / 誤認。

## Interpretation constraints
完全知識や無限細分化を要求しない。必要範囲・必要粒度は問い依存である。AIについては意識の有無ではなく、成立条件を構造として保持できるかを扱う。Parentにない普遍スコアや固定閾値を追加しない。
