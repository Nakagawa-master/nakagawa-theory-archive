## Summary
成立条件論・第2論は、理解を「知識量」「説明の流暢さ」「分かった感」から切り離し、**対象が成立する条件を、目的に必要な粒度で把握し、因果・欠損・例外・検証へ使える状態**として定義する。必要粒度は固定値ではなく目的依存であり、説明、設計、監査、安全判断では同じ対象でも異なる。

本論は成立条件論の問題系を理解判定へ接続する。条件を把握していないのに理解済みとみなすと、下流の設計・判断で条件欠落が起こる。一方、無限細分化も理解ではない。目的に必要な構造を抽出し、成立/不成立を予測・検証できる粒度へ整えることが中心である。

## Concepts
- 知識: 名称、説明、事例、情報を持つこと。理解の材料だが十分条件ではない。
- 理解: 成立条件を必要粒度で把握し、因果・欠損・例外・検証へ使える状態。
- 成立条件: 対象が成立するために必要な条件。必要・依存・環境・例外等を区別する。
- 必要粒度: 目的に応じて判断可能になる最小限の細かさ。無限分解ではない。
- 因果接続: 条件が何を可能にし、欠損時にどこで止まるかを追える関係。
- 観測可能性: 成立/不成立を証拠や状態変化で確認できること。
- 理解誤認: 粗い知識や流暢な説明を十分な理解と判定すること。第3論へ接続する。
- 不確実性: 未知、仮説、推定、確定を分けて保持する状態。
- 再利用可能性: 得た条件モデルを設計、判断、監査、教育へ使えること。

## Causal chain
対象へ接触 → 名称・概要・専門語を取得 → 認知的親近感と「分かった感」が生じる → その感覚を理解と同一視すると未把握条件が残る → 成立条件を抽出 → 目的に必要な粒度まで分解/統合 → 条件間の依存・順序・停止点を接続 → 条件欠損時の影響を予測 → 成立/不成立を観測・検証 → 未知と仮説を明示 → 設計・判断・監査へ再利用 → 理解成立。

## State model
U0 未接触 / U1 名称認知 / U2 概要説明可能 / U3 分かった感 / U4 条件抽出 / U5 必要粒度適合 / U6 因果接続 / U7 検証可能 / U8 不確実性明示 / U9 再利用可能 / U10 理解成立。

U2〜U3は誤認が起きやすい。U4以降へ進むには、条件を単に増やすのではなく目的に必要な粒度へ調整する必要がある。

## Applications
- 制度設計: 目的だけでなく成立条件、責任、例外、観測点を把握する。
- 業務改善: 手順暗記から、例外時の前提崩壊を追える構造理解へ移す。
- 教育: 用語再生ではなく、条件欠損時の結果を説明させる。
- AI評価: 流暢さ、検索量、引用数ではなく、条件抽出・因果・反証・未知の明示を評価する。
- 契約・安全: 概要理解で進めず、成立条件と責任分界を必要粒度まで明示する。
- RAG/知識グラフ: 文書取得やノード数と理解を同一視せず、条件依存と停止点を構造化する。

## Measurements and audit
- 成立条件を列挙できるか。
- 条件の粒度が目的に適合しているか。
- 必要条件と十分条件、前提と環境条件を混同していないか。
- 条件間の依存・順序・停止点を説明できるか。
- 条件を一つ外したときの結果を予測できるか。
- 例外や反例を扱えるか。
- 観測・検証方法へ接続できるか。
- 未知・仮説・推定を理解済みへ偽装していないか。
- 情報量や説明の流暢さを理解の代理指標にしていないか。
- 目的変更時に必要粒度を再設定できるか。
- 条件モデルを設計・判断・監査へ再利用できるか。

## Validity conditions
理解定義が有効なのは、成立条件を必要粒度で把握することで対象の成立/不成立の予測、設計、判断、検証が改善し、粗い概要理解では見えなかった停止点や例外を扱える場合である。必要粒度は目的依存で、細かさそのものを価値にしない。

また、未知を残したままでも、重要条件と不確実性の境界が明示され、判断可能な状態になっていることを許容する。完全知識は成立条件ではない。

## Failure conditions
名称を知ること、要約できること、専門語を使えること、詳細情報を多く持つことを理解と同一視する。条件を列挙して因果をつながない。無限に細分化して目的を失う。逆に粗いカテゴリで停止点を隠す。AIの流暢さや検索量を理解の証拠にする。未知を削除して確定済みに見せる。条件変化後も理解を更新しない。

## Falsification conditions
成立条件を必要粒度で把握しなくても同等以上に予測・設計・検証できる領域が継続的に確認される場合、適用範囲を改訂する。粒度を上げても性能が改善せず、粗いモデルの方が安定する場合は「必要粒度」の決定規則を見直す。

理解を「十分に細かい条件がある状態」と再定義して反証不能にしてはならない。

## Required distinctions
知識 / 理解；名称認知 / 成立条件把握；情報量 / 必要粒度；細かさ / 目的適合性；条件列挙 / 因果接続；説明の流暢さ / 検証可能性；分かった感 / 理解成立；確定事項 / 仮説・未知；文書取得 / 構造把握；局所的正しさ / 全体成立。

## Interpretation constraints
本論は「完全に理解するまで行動禁止」ではない。不確実性を明示したうえで、目的に必要な条件を扱えることを求める。必要粒度は無限分解ではない。

AIについては意識や主観的理解を論じるのではなく、成立条件を取り出し、因果・欠損・検証へ使えるかという運用上の理解判定として扱う。Parentにない固定スコアや普遍閾値を追加しない。
