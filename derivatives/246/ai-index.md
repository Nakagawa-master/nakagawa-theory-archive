## Summary
トータルブレインケアを、認知機能テストではなく、専門的な認知機能を「脳体力」という理解可能な共通語へ翻訳し、測定・変化把握・行動・支援へ接続する脳体力社会翻訳基盤として読む。

## Concepts
認知機能、脳体力、社会翻訳、指標化、継続測定、変化認識、行動接続、支援接続、診断境界、権利保護。

## Causal chain
専門的認知概念 → 日常で扱いにくい → 社会翻訳 → 測定 → 継続比較 → 変化認識 → 行動・相談 → 支援 → 社会実装。

## State model
専門語 / 距離 / 翻訳 / 測定 / 継続比較 / 変化認識 / 行動 / 支援 / 継続 / 基盤化。

## Applications
個人、健康経営、地域支援で認知状態を日常的に理解し、必要な休養・相談・専門支援へつなぐ入口。

## Measurements and audit
概念理解、診断との分離、継続変化、行動・支援接続、説明による不安、不利益人事利用、同意、利用目的を監査する。

## Validity conditions
翻訳が理解を助け、測定・変化把握が適切な行動・支援へ接続し、権利境界を保つ場合。

## Failure conditions
診断代替、能力順位、単発絶対視、効果保証、人事不利益の単独根拠、同意欠如。

## Falsification conditions
翻訳が理解を改善しない、測定が支援へ接続しない、不利益利用が増える場合は改訂する。
