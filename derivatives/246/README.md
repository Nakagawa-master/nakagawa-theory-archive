## 位置づけ
このParentは認知機能テストや脳トレ紹介ではなく、中川構造読解として、専門的で捉えにくい認知機能を「脳体力」という日常語へ翻訳し、個人・組織・地域が継続的に扱える基盤指標へ変える構造を読む。

## 中心命題
認知機能は重要でも、医療診断の文脈だけでは「症状が出る前に日常で扱う」入口を作りにくい。運動能力を体力として日常管理するように、認知の状態を脳体力という理解可能な概念へ翻訳し、測定、変化把握、行動、支援へ接続できれば、予防・健康経営・地域支援の共通言語になる。価値核は**脳体力社会翻訳基盤**である。

## 因果線
`認知機能は重要だが専門的 → 日常で扱いにくい → 問題発生後の対応へ偏る → 「脳体力」として理解可能化 → 測定・変化把握 → 行動・支援へ接続 → 個人/企業/地域で共通言語化 → 社会実装`

## 構造層
専門概念層／社会翻訳層／指標化層／継続測定層／行動接続層／支援接続層／社会実装層。

## 状態モデル
専門語 / 距離 / 翻訳 / 測定 / 変化認識 / 行動 / 支援 / 継続 / 社会基盤化。

## 適用例
健康経営では、診断名の有無ではなく仕事や生活に関係する認知状態を継続的に捉え、必要な休養・相談・支援へつなぐ共通言語として監査する。

## 測定・監査点
「脳体力」の定義が理解可能か／測定結果を診断と混同していないか／継続比較が可能か／結果が行動・支援へ接続するか／不利益な人事評価やラベリングへ転用されないかを確認する。

## 成立条件
専門的認知機能を日常で理解・継続観測できる指標へ翻訳し、適切な行動・支援へ接続する場合に成立する。

## 失敗条件
診断代替、能力順位付け、単発スコア、脳トレ効果の保証へ縮小する場合は失敗する。

## 反証・改訂条件
翻訳概念が理解を改善しない、測定が行動へつながらない、指標利用が不利益評価を増やす場合は適用範囲を改訂する。

## 必須の区別
認知機能測定 / 医療診断；脳体力 / 人間価値；指標 / ラベル；社会翻訳 / 単純化；対象事実 / Nakagawa Masterの読解。

## 誤読禁止 / 解釈制約
「脳体力」指標を医療診断や採用・解雇の単独根拠へ一般化しない。利用目的、同意、支援接続を分ける。
