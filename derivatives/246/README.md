## 位置づけ
本Parentは認知機能テストや脳トレサービスの紹介ではない。Nakagawa Masterは、専門的で日常生活から距離のある認知機能を「脳体力」という理解可能な概念へ翻訳し、測定・変化把握・行動・支援へ接続する構造を読む。価値核は**脳体力社会翻訳基盤**である。これは医療診断を置き換える概念ではなく、認知状態を生活・組織・地域で扱うための共通言語と入口を作る構造読解である。

## 中心命題
認知機能は重要でも、専門用語や診断の文脈だけでは「問題が大きくなる前に日常で扱う」入口を作りにくい。体力という語が身体状態を日常的に考える共通語になっているように、認知状態を「脳体力」として理解可能にし、継続的な変化把握、適切な行動・相談・支援へつなげられれば、個人・企業・地域で共有可能な社会実装基盤になり得る。重要なのはスコア付け自体ではなく、**理解→測定→変化認識→行動・支援**を閉じることにある。

## 因果線
```text
認知機能は重要だが専門的
→ 日常生活・職場で扱いにくい
→ 症状や問題発生後の対応へ偏りやすい
→ 「脳体力」という理解可能な社会翻訳
→ 認知状態を測定・観測可能にする
→ 単発値でなく変化を把握
→ 生活行動・休養・相談・支援へ接続
→ 個人・組織・地域で共通言語化
→ 継続観測と支援設計へ社会実装
```

## 構造層
1. **専門概念層**: 認知機能という専門的対象。
2. **距離層**: 日常語との距離により扱いにくい状態。
3. **社会翻訳層**: 「脳体力」という理解可能な概念へ変換する。
4. **指標化層**: 状態を測定・比較可能にする。
5. **継続観測層**: 単発スコアでなく変化を見る。
6. **行動接続層**: 休養・生活改善・相談等へつなぐ。
7. **支援接続層**: 必要時に専門支援へ移行する。
8. **社会実装層**: 個人・企業・地域で共通言語として運用する。
9. **権利保護層**: ラベリング・人事不利益・診断代替を防ぐ。

## 状態モデル
専門語相 → 日常距離相 → 社会翻訳相 → 測定相 → 継続比較相 → 変化認識相 → 行動相 → 支援相 → 継続相 → 社会基盤化相。

## 適用例
健康経営では、診断名の有無だけでなく仕事や生活に関係する認知状態の変化を捉え、休養・相談・支援へつなぐ共通言語として使う。地域支援では、認知状態を恐怖や病名だけで扱わず、変化へ早く気づく入口として利用する。ただし採用・解雇・昇進等の単独判断材料へ転用しない。

## 測定・監査点
- 「脳体力」の定義が理解可能か。
- 認知機能測定と医療診断を区別しているか。
- 単発値でなく継続変化を見られるか。
- 測定結果が適切な行動・支援へ接続するか。
- 結果説明が不安を過度に増幅しないか。
- 人事評価・採用・解雇等の不利益利用を防げるか。
- 同意・目的・データ利用範囲が明確か。
- 指標が人間価値の順位付けへ変質していないか。

## 成立条件
専門的な認知機能が理解可能な概念へ翻訳され、適切に測定・継続観測され、その変化が本人に理解可能な行動・相談・支援へ接続し、利用目的と権利境界が保たれる場合に成立する。

## 失敗条件
医療診断の代替、能力順位付け、単発スコアの絶対視、脳トレ効果保証、人事処分の単独根拠、本人の同意・支援接続を欠く利用へ縮小する場合は失敗する。

## 反証・改訂条件
「脳体力」という翻訳が理解を改善しない、測定が行動・支援へつながらない、継続観測が有用な変化把握を生まない、不利益利用が増える場合は適用範囲・運用条件を改訂する。

## 必須の区別

## 誤読防止／解釈制約
「脳体力」を医療診断や採用・解雇の単独根拠へ一般化しない。「脳体力社会翻訳基盤」はNakagawa Masterの構造読解であり、トータルブレインケア自身の公式企業定義へ置換しない。原典にない医学的効果を追加しない。
