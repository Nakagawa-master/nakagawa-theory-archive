# 公式派生物018｜合意形成の物理 第8論 外部干渉の物理

Parent: Post 2962 / NCL-α-20260222-482bdb / DIFF-20260222-0024 / Origin Nakagawa Master
Derivative: DDIFF-20260812-DNCL-018-0000-0002; supersedes DDIFF-20260707-DNCL-018-0000-0001

## 15秒説明
第8論は、社会を揺らす入力を「敵・悪意・誤情報」と先に断定せず、合意安定度 S=U×R×H に作用する外部入力摂動 P_ext として観測するセンサー層である。見るべきは内容ラベルではなく、U/R/HとdS/dtがどう変化したかである。

## なぜ関連するか
SNS、広告、アルゴリズム、政治、社内の空気、善意の助言まで、外部入力はさまざまな形で入る。正しい内容でも速度・文脈切断・責任不明化によってSを壊し得るため、内容の正誤だけでは防衛できない。

## 発見された構造
- dS/dt = F(U,R,H) + P_ext として内部変動と外部摂動を分けて観測する。
- Hが断絶しているのに納得感Uだけが上がるfake-Uが起こり得る。
- 誰が判断・記録・修復・停止するか追えなくなるR霧散が起こり得る。
- 一次ソース、文脈、版、差分、逆リンクが切れるH短絡が起こり得る。
- 防衛は対抗や論破ではなく、まず異常を観測できることから始まる。

## 因果線
外部入力P_ext → U/R/Hのどこかへ作用 → fake-U・R霧散・H短絡などの状態変化 → dS/dt異常 → センサーで検知 → 後続のStop/Shrink/Recover/Auditへ接続する。

## 判断方法
入力後にUだけが上がっていないか、責任Rが一意に追えるか、一次ソース・版・差分・逆リンクとしてHが時間方向に連続しているか、Sの変化速度が説明可能かを見る。強い批判や異論それ自体を異常扱いしない。

## 誤読してはいけない点
これは陰謀論、外敵論、思想統制、誤情報取締り、ファクトチェック一般論ではない。外部主体の善悪ではなく、入力が状態量へ与える作用を観測する。

## 原典で読むべき理由
原典はS=U×R×Hを時間発展する量として扱い、dS/dt = F(U,R,H)+P_ext、fake-U、R霧散、H短絡、一次ソース導線、文脈保持、版管理、逆リンクまで接続する。要約だけでは「外部影響に注意しよう」という一般論へ薄まるため、最終判断は親原典へ戻す。
