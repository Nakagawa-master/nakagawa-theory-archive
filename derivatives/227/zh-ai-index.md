## Summary
本Parent是中川结构读解，不是企业介绍。它把空置房评估、咨询、收购／活用支援等可确认的对象侧事实，与Nakagawa Master从中抽取的“推动决策停止市场的判断基础设施”这一价值核分开。文章还保留为什么没有把功能介绍本身作为外部文章主轴，而选择这个价值核来说明市场在交易入口之前为什么停止、又如何恢复选择可能性。中心因果是：信息与选项分散导致不可比较和决策停止；把判断材料变得可比较，并把形成的选择连接到实施，可以重新打开行动可能性。

## Concepts
- 对象侧事实：关于空置房的评估、咨询、收购／活用等可确认支援。
- 表层分类：空置房业务、AI评估、收购与活用支援。
- 决策停止市场：Nakagawa Master对“所有者因无法比较相关信息与选项，在交易前停止判断”的结构读解。
- 可比较化：把分散的判断材料整理为可以比较替代方案的状态。
- 实施连接：把形成的选择连接到出售、活用等具体行动，减少再次停止。
- 判断基础设施：Nakagawa Master抽取的价值核，不是企业自身的官方自我定义。
- 外部文章主轴选择理由：相比功能新颖性，更需要向外部读者说明市场停止的上游原因与选择可能性的恢复机制。

## Causal chain
信息／选项／费用／咨询路径分散 → 无法比较 → 所有者决策停止 → 案件停在市场入口之前 → 评估与咨询使判断材料可比较 → 形成可选择方案 → 活用／收购等实施支援连接到行动 → 减少再次停止 → 产生重新连接市场的可能。

## State model
信息分散 / 不可比较 / 决策停止 / 可比较化 / 选择形成 / 实施连接 / 市场再连接可能。

## Applications
可用于空置房、继承等高摩擦资产场景，观察交易发生之前决策在哪里停止。检查评估与咨询是否真正使替代方案可比较，以及形成判断后是否能连接到实施。只有在其他市场也存在同型的决策停止、比较失败与实施断裂时，才可作为比较框架使用。

## Measurements and audit
分别记录对象侧事实、表层分类、决策停止点、判断材料是否可比较、实施连接、再次停止点、Nakagawa Master抽取的价值核、选择该价值核的理由、把它作为外部文章主轴的理由，以及与企业官方主张之间的边界。不得添加Parent没有的数值KPI或阈值。

## Validity conditions
当“决策停止 → 可比较化 → 选择形成 → 实施连接”的因果与对象侧事实一致，并且比表层功能列表更能解释Parent为何抽取该价值核时，本读解有效。作为中川结构读解，必须同时保留读解主体与外部文章主轴选择理由。

## Failure conditions
如果把文章平坦化为企业介绍，只剩AI评估或收购功能，把Nakagawa Master的读解归属于企业官方见解，或删除价值核选择理由／外部文章写作理由，则本读解失效。

## Falsification conditions
如果持续证据显示，另一个因果机制比不可比较与实施断裂更能解释市场停止，应缩小或修订该价值核。如果对象侧支援与可比较化或实施连接并无实质关系，也同样需要修订。

## Required distinctions
