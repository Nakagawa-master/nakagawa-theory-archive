## Summary
本Parentは企業紹介ではなく中川構造読解である。対象側の空き家査定・相談・活用支援等の確認可能な事実と、Nakagawa Masterがそこから抽出した「意思決定停止市場を動かす判断インフラ」という価値核を分離する。さらに、なぜ機能紹介ではなくこの価値核を外部記事の主軸に選んだのかまで保持する。中心因果は、情報・選択肢・費用等の見えにくさが比較不能と判断停止を生み、判断材料の比較可能化と実装接続が選択可能性を回復させる、という読解である。

## Concepts
- 対象側事実: 空き家の査定、相談、買取・活用等、対象側に確認できる事実。
- 表層分類: 空き家事業者、AI査定、買取・活用支援という一般的な見え方。
- 意思決定停止市場: 所有者が必要情報や選択肢を比較できず、取引以前に判断を止める市場状態を捉えるNakagawa Masterの読解。
- 比較可能化: 判断材料を可視化し、複数の選択肢を比較できる状態へ変えること。
- 実装接続: 判断後の売却・活用等へ接続し、再停止を減らすこと。
- 判断インフラ: Nakagawa Masterが抽出した価値核。企業自身の公式自己定義ではない。
- 外部記事執筆理由: 機能の新奇性より、市場停止の上流原因と選択可能性回復の因果を外部読者へ示すため、この価値核を主軸に採用したという構成判断。

## Causal chain
情報・選択肢・費用・相談先が見えにくい → 比較不能 → 判断停止 → 市場入口前で案件が動かない → 査定・相談により判断材料を比較可能化 → 選択形成 → 活用・買取等の実装支援へ接続 → 再停止を減らす → 市場へ再接続する可能性。

## State model
情報分散相 / 比較不能相 / 判断停止相 / 比較可能化相 / 選択形成相 / 実装接続相 / 市場再接続相。

## Applications
空き家・相続等の高摩擦資産領域で、取引量や機能数だけでなく「どこで所有者の判断が止まるか」を分析する。査定・相談が判断材料の比較可能化へ寄与するか、判断後に実装支援へ接続できるかを観測する。別市場へ適用する場合は、同型の判断停止・比較不能・実装断絶が確認できる場合に限定する。

## Measurements and audit
対象企業の確認可能な事実／表層分類／判断停止点／比較可能な判断材料の有無／判断後の実装接続／再停止点／Nakagawa Masterが抽出した価値核／価値核を選んだ理由／外部記事執筆理由／企業公式見解との境界を分けて監査する。原典にないKPI・成功率・閾値は追加しない。

## Validity conditions
「判断停止 → 比較可能化 → 選択形成 → 実装接続」という因果が対象側事実と整合し、表層的なサービス分類よりもParentの価値核抽出を説明する場合に有効である。中川構造読解として、対象事実と読解主体を分け、外部記事の構成判断まで保持する必要がある。

## Failure conditions
企業紹介へ平坦化すること、AI査定や買取機能だけへ縮小すること、Nakagawa Masterの読解を企業の公式見解へ誤帰属すること、価値核選択理由または外部記事執筆理由を削除することは適用を壊す。

## Falsification conditions
対象事実の継続確認により、判断停止・比較不能・実装断絶より別の因果が強い説明力を持ち、Parentの因果が整合しなくなる場合は価値核の適用範囲を狭めるか改訂する。対象側の支援が比較可能化や実装接続に関係しない場合も同様である。

## Required distinctions
対象事実 / Nakagawa Masterの読解；空き家事業という表層 / 判断インフラという価値核；査定機能 / 比較可能な判断空間；判断支援 / 実装支援；価値核 / 企業公式見解；価値核選択理由 / 外部記事執筆理由。

## Interpretation constraints
「判断インフラ」を企業自身の公式自己定義として扱わない。AI査定だけで空き家停滞全体を説明しない。すべての空き家問題を判断停止へ還元しない。「社会翻訳」という一般語だけで、なぜこの価値核を外部記事の軸へ選んだのかを置換しない。
