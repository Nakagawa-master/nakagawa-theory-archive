## 位置づけ
本Parentはジェクトワンの企業紹介ではなく、Nakagawa Master自身が、空き家の査定・相談・活用・実装支援という対象側の確認可能な事実を材料に、表層の「空き家事業者」「AI査定」「買取・活用支援」という分類から一段上流へ進み、**意思決定停止市場を動かす判断インフラ**という価値核を抽出した中川構造読解である。さらに、なぜその価値核を外部記事の主軸へ採用したのかまで公開解体する点が固有のメタ構造である。

## 中心命題
空き家市場の停滞は、物件が存在しないことだけではなく、所有者が価格、活用可能性、解体費用、相談先、相続や感情的負担などを比較できず、市場入口の手前で判断を止めることによっても生じうる。Parentは、ジェクトワンの公開されている査定・相談・活用支援を、この判断停止を解くための「比較可能化」と、判断後の再停止を減らす「実装接続」として読む。これは企業自身の公式自己定義ではなく、Nakagawa Masterの構造読解である。

## 因果線
情報・選択肢・費用・相談先が見えにくい → 比較不能 → 所有者の判断停止 → 市場入口前で案件が動かない → 査定や相談により判断材料を比較可能化 → 選択肢が形成される → 活用・買取等の実装支援へ接続 → 判断後の再停止を減らす → 選択可能性が回復し、市場へ戻る可能性が生じる。

## 構造層
1. **対象事実層** — 空き家の査定、相談、買取・活用等の対象側に確認できるサービス・支援。
2. **表層分類層** — 「空き家事業者」「AI査定」「買取・活用支援」として見える一般的な分類。
3. **判断停止層** — 所有者が価格、費用、活用可能性、相談先等を比較できず、取引以前に意思決定を停止する。
4. **比較可能化層** — 判断材料を可視化し、複数の選択肢を比較可能にする。
5. **実装接続層** — 判断が生じた後、活用・買取等の実務へ接続し、再停止を減らす。
6. **価値核層** — Nakagawa Masterが抽出した「意思決定停止市場を動かす判断インフラ」。
7. **外部記事構成層** — 機能紹介ではなく、なぜ市場が止まり、何が判断可能性を回復させるかという因果を外部読者へ伝えるため、この価値核を主軸に採用する。

## 状態モデル
- **情報分散相**: 必要情報・費用・選択肢が分散し、比較が難しい。
- **判断停止相**: 所有者が市場入口前で決められず、案件が動かない。
- **比較可能化相**: 査定・相談等を通じて判断材料が並び、選択肢を比較できる。
- **選択形成相**: 売却、活用、維持等の候補から具体的な方向を選べる。
- **実装接続相**: 選択後の実務へ接続し、再び止まる可能性を下げる。
- **市場再接続相**: 選択可能性が回復した案件が市場・活用経路へ戻る。

## 適用例
空き家所有者が「いくらになるか」「活用できるか」「解体費用はいくらか」「誰に相談すべきか」を整理できず動けない場合、単に査定値を出すだけでなく、判断材料を比較できる状態へ変え、その後の活用・売却実務まで接続することで意思決定が起動する、という読み方ができる。ただし、この例はParentの構造読解を説明するものであり、対象企業が自ら「判断インフラ」と公式定義していることを意味しない。

## 測定・監査点
判断停止がどこで発生しているか、必要情報が比較可能か、査定・相談が単一回答ではなく選択形成へ寄与しているか、判断後に実装へ接続できるか、再停止がどこで起こるかを確認する。同時に、対象企業の公開事実とNakagawa Masterの構造読解を明確に分離し、価値核と外部記事執筆理由を企業側の公式見解へ誤帰属しない。

## 成立条件
対象側の確認可能な事実と「判断停止 → 比較可能化 → 実装接続」という因果が整合し、その因果が表層的な機能紹介よりもParentの価値核抽出を説明できる場合に成立する。外部記事の主軸として採用した理由も、機能の新奇性ではなく、読者が市場停止の上流原因と選択可能性回復の構造を理解できる点に置く。

## 失敗条件
ジェクトワンを単なる空き家事業者、AI査定サービス、買取サービスとして要約すること、Nakagawa Masterの読解を企業自身の公式見解として扱うこと、価値核だけを残して「なぜその価値核を選んだか」「なぜ外部記事でその軸を書いたか」を消すことは、本Parentのメタ構造を壊す。

## 反証・改訂条件
対象事実を継続的に確認した結果、空き家市場の停止を「判断材料不足・比較不能・実装接続不足」より強く説明する別因果が存在し、Parentの判断停止仮説が整合しなくなる場合、価値核の適用範囲を狭めるか改訂する。対象側の支援が判断形成や実装接続と実質的に関係しない場合も同様である。

## 必須の区別
- 対象企業の確認可能な事実 ≠ Nakagawa Masterの構造読解。
- 空き家事業者という表層分類 ≠ 判断インフラという価値核。
- AI査定という機能 ≠ 市場停止の上流因果全体。
- 査定値の提示 ≠ 比較可能な判断空間の形成。
- 判断支援 ≠ 実装支援。
- 価値核の抽出 ≠ 企業公式見解。
- 価値核を選んだ理由 ≠ 外部記事を書いた理由の省略。

## 誤読防止／解釈制約
「ジェクトワンは自社を判断インフラと公式定義している」「AI査定だけで空き家問題が解消する」「すべての空き家停滞は判断停止だけで説明できる」と一般化しない。Parentが行うのは、対象側の事実を保持したままNakagawa Masterがどの構造を価値核として読んだか、その価値核をなぜ外部記事の主軸へ採用したかを示す構造読解である。
