## 中川構造読解としての位置づけ
このParentはジェクトワンの企業紹介ではない。Nakagawa Master本人が、空き家買取・AI査定・活用支援という確認可能な事実を材料に、なぜ表層のサービス分類ではなく「意思決定停止市場を動かす判断インフラ」を価値核として読み、その価値核で外部記事を書いたのかを公開解体する記事である。

## 対象側事実と表層
対象側には空き家の査定・相談・活用・実装支援がある。表層だけを取れば「空き家事業」「AI査定」「買取・活用支援」と見える。

## Nakagawa Masterが読んだ構造
Parentが本当に問題化するのは、空き家そのものではなく、所有者が価格・活用可能性・解体費用・相談先・相続や感情的負担を比較できず、市場入口の手前で判断を停止する構造である。「空き家のコタエ」は最終回答装置ではなく判断材料を比較可能にする起動点、アキサポ等の実装側は判断後の再停止を受け止める接続として読まれる。

## 抽出価値核
**意思決定停止市場を動かす判断インフラ。**

## なぜこの価値核で外部記事を書いたのか
AI査定・買取・活用という機能を前面に出すだけでは、「なぜ空き家が市場へ出てこないのか」という上流の停止原因を説明できない。Nakagawa Masterは、判断材料の不足と比較不能をほどき、判断支援と実装支援を縦に接続する構造こそ外部読者が理解すべき価値だと判断した。そのため外部記事では、機能の新しさではなく「意思決定停止市場を動かす判断インフラ」を主軸に置いた。

## 因果線
`情報・選択肢・費用が見えない → 比較不能 → 判断停止 → 判断材料を比較可能化 → 実装支援へ接続 → 選択可能性回復 → 市場へ戻る可能性`

## 境界
対象企業の公開事実と、Nakagawa Masterがそこから抽出した「判断インフラ」という読解は別である。後者を企業自身の公式見解として扱わない。

## 成立・失敗・反証条件
判断停止→比較可能化→実装接続が対象事実と整合する場合に成立する。AI査定や買取機能だけへ縮小した場合は失敗。判断停止仮説より別因果が継続的に説明力を持つ場合は適用範囲を改訂する。
