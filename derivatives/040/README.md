## 位置づけ

この公式派生物は親原典へ戻るための公開入口であり、原典の代替ではない。

親原典の主題は、逆因果整流理論と、意味収束理論・時間OS・未来負債論・バックキャスティング・量子論比喩との違いを明確にすることである。

## 保持すべき差異

```text
意味収束理論
→ 意味・認識・解釈の収束を扱う

逆因果整流理論
→ 採用された未来定義に照らして現在の行動・資源・関係・時間配分などを再整列する
```

```text
時間OS
→ 整えられた構造を時間上で運用する

逆因果整流理論
→ 現在構造を未来定義へ向けて整える
```

```text
未来負債論
→ 未来へ繰り延べられる歪みや修復コストを捉える

逆因果整流理論
→ 未来負債を生む選択を削り、現在構造を未来線へ整える
```

```text
バックキャスティング
→ 未来像から計画を逆算する

逆因果整流理論
→ 計画だけでなく、意味・行動・資源・関係・時間等を含む現在構造を整える
```

量子論比喩との関係では、逆因果整流理論を「未来が過去を物理的に書き換える理論」として読んではならない。本理論で未来定義が担うのは、現在を評価し再整列するための基準である。
