## 位置づけ
親原典はC系Vol.2であり、Vol.1で提示された「交換から共鳴へ」という一般理論を、実際に重力圏として成立・維持させるための実装プロトコルへ進める。中心課題は、旧市場の狩猟型セールス――追う、説得する、比較させる、広く集めて一部を成約へ変換する――から離れ、明確なL7と十分なCを、歪めずにSignalingし、適合する主体だけが自然に近づく誘引型接続へ移行することである。

親原典は重力を「市場の振る舞いを説明するモデル」とし、その最小式を `F = Mass × Purity` と置く。Massは長期間の知識、技術、経験、実績、思考体系、判断能力等として圧縮されたCの総量、Purityは金儲けの匂い、媚び、迎合、流行追随等の不純物が少ないことを指す。両者が揃うと、適合する相手が追わなくても近づくという構造を実装論として展開する。

Vol.2の射程は誘引だけで終わらない。Signalingによって重力方向を外部へ明示し、Filteringと検疫で非整合接続を内側へ入れず、Event Horizonで関係性の境界を設計し、Priceを単なる対価でなく覚悟と自己位置の境界として再定義し、重力圏へ新しいCを供給し続け、内部者同士の横断接続を増やし、E化を免疫反応として排出するところまでを一続きで扱う。結章では、売るという動詞が消え、自分のL7を一点に定めて歪めず立ち続けるGravity Masterへ主体像が移る。

## 中心命題
親原典の中心命題は、**共鳴市場を実装するには、狩猟型の確率論的セールスを強化するのではなく、提供可能なCをMassとして蓄積し、L7を歪めないPurityを保持し、その方向をSignalとして外部へ明示し、非整合主体をFilteringし、境界・Price・継続C供給・内部貢献・E排出まで一体設計することで、説得より誘引、顧客獲得より合流、保有より循環が一次現象になる重力圏を形成・維持できる**という実装命題である。

ここで `F = Mass × Purity`、高額Price、Event Horizon、Gravity等は親原典の構造モデルとして保持するが、派生側で自然科学上の普遍法則や固定売上式へ変換しない。特にPriceは、一般的な「高いほど正しい」規則ではなく、本稿の重力圏設計内部でL7・覚悟・境界・純度を固定する装置として提示されている。

また、Filtering、検疫、排出は人間の価値を格付けする一般理論ではない。本稿では、特定の重力圏とL7が整合するか、循環へCを出すか、E化していないかという接続構造の判定として扱われる。排出も怒り・説教・断罪ではなく「この重力圏とは整合しない」という構造結果として置かれる。

## 構造層
**1. Hunting / Sales OS。** 多く集めて少数を残し、追跡・説得・比較・成約によって接続する確率論型モデル。親原典は情報閉鎖時代には機能したが、透明化と選択肢過多で効力を失うと診断する。

**2. Gravity Formula。** `F = Mass × Purity`。Massは長期間の専門知、再現技術、実務経験、理論、代替困難な判断等として蓄積されたC。PurityはL7を歪める不純物の少なさ。片方だけでは重力が成立しないと原典は強く主張する。

**3. Signaling。** 自分が何を信じ、何を提供し、誰と接続し、誰とは接続しないかを外部へ明示する。全員に好かれる弱い表現ではなく、方向を固定することで適合主体には強く届き、非適合主体は離れる。

**4. Filtering / Quarantine。** 接続前にL7、行動、Cの出力、場への責任等の整合を観測し、内部へ入れる主体を分ける。目的は人数最大化でなく、重力圏内部の純度と低摩擦を保つこと。

**5. Event Horizon / Rite of Passage。** 外部者から内部者へ関係性が質的に変わる境界。支払いだけでなく、自分の位置を固定する行為、価値観・ルール・責任の受諾を通じて境界を越える。親原典は通過儀礼を「人を試す」より本人に覚悟を確認させる装置として説明する。

**6. Price as Boundary。** Priceは原価・相場の対価だけでなく、覚悟、L7、主権、内部／外部の境界を数値化する装置として再定義される。値引き乱発や相手ごとの曖昧化はPurityを下げるとされる。

**7. Living Gravity Zone。** 重力圏は貯水池でなく河川。共鳴は状態でなくプロセスであり、新しい視点・問い・仮説・実践というCが継続供給されなければ減衰する。囲い込みではなく流入・流出・更新を持つ生態系として維持する。

**8. Contribution / Network Amplification。** 提供者だけでなく内部者も知見、フィードバック、実践報告、橋渡し等のCを出す。内部者同士が中心を介さず横断接続すると、重力圏は場からネットワークへ進み、中心が弱まっても循環が継続する。

**9. E / Immunity / Expulsion。** 受け取るだけ、文句だけ、価値軽視、他者Cの消費等をE化の兆候とし、放置せず構造的に外へ出す。排出は怒り・説教・断罪でなく免疫反応として置かれる。

**10. Gravity Master。** カリスマや影響力の強さではなく、自分のL7を一点に定め、歪めず、薄めず、逃げずに立ち続ける姿勢。売る動詞が消え、存在と影響が接続を生む地点として結章に置かれる。

## 適用例
**1. セールス摩擦の診断。** 大量接触、追跡、説明、値引き、比較でしか接続が生まれない場合、話術だけでなくSignalの弱さ、Mass不足、Purity低下、対象境界の曖昧さを上流原因として見る。

**2. Signalingの明確化。** 「誰にでも役立ちます」ではなく、自分のL7、提供できるC、何を守るか、何には接続しないかを明示する。非対象が離れることを失敗ではなくFilterの一部として扱う。

**3. 接続前検疫。** 支払い能力だけで内部者を決めず、価値観、ルール、場への責任、Cを出す姿勢、行動整合を確認する。目的は優越性の格付けではなく内部摩擦を下げること。

**4. Event Horizon設計。** 参加前後で情報、責任、意思決定関与、C要求がどう変わるかを明確にし、「いつまでも様子見」の曖昧な内部者を作らない。

**5. Priceの固定。** 相場恐怖や拒絶恐怖だけで値下げせず、自分のL7と提供Cに対してどこへ価格を置くかを宣言する。値引きが場の純度・覚悟・期待をどう変えるかまで見る。

**6. 維持Cの更新。** 同じ情報を反復するだけでなく、新しい視点、問い、仮説、実践を出し続ける。人数やフォロワー増加より、一人あたりC出力と横断接続を見る。

**7. E化への免疫。** 受け取るだけ、他者Cを消費するだけ等の兆候を放置せず、怒りや説教でなく「この重力圏とは整合しない」という構造判定で接続を外す。

## 誤読禁止 / 解釈制約（原典適合）
親原典は「重力」「質量」「純度」「Event Horizon」等の物理語彙を、市場接続の実装構造を説明するために強く使用する。`F = Mass × Purity` はParent本文に明示されているため保持するが、自然科学として測定済みの市場法則、売上保証、接続確率の固定式へ変えない。

親原典はPriceを覚悟・主権・境界の装置として強く位置づけ、高額の構造意味や値引きの不可逆性まで論じる。この主張強度は保持する一方、派生側で「高価なら正しい」「低所得者は不適格」「全市場で値引きは悪」という別命題へ拡張しない。本稿の重力圏・L7・提供C・境界設計という文脈へ閉じる。

Filtering、検疫、排出も、特定重力圏との整合・C循環・E化を扱う接続機構であり、人間一般の尊厳・能力・価値を順位づける装置ではない。親原典自身が排出を怒り・説教・断罪ではなく構造的な非整合判定として置く点を保持する。

Event Horizonでは不可逆性が強調されるが、これを現実の強制的囲い込みや退出不能の正当化へ変えない。本文全体の多層境界、責任、純度、循環、免疫という構造内で読む。
