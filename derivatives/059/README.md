## 位置づけ
親原典は、共創を「複数人が同時に自由に話し合えば成立する活動」とみなさず、観測・翻訳・設計・検証という役割、Silence–Question–Silence（SQS）、役割切替、価値→便益→コストの順序、終端条件を組み合わせて再演可能にする秩序設計として示す。

共創の混乱は能力不足だけから生じるのではない。観測中に提案し、翻訳中に決裁し、設計中に価格を先出しし、検証中に追加設計すると、何を観測し、何を意味づけし、何を決め、何を反証しているのかが混線する。原典はこの混線を「一度に一役」と明示的な切替によって抑える。

沈黙も空白ではない。SQSでは、問いの前に前提・違和感・制約を観測し、問いで目的・仮説・媒介・制約を明示し、問いの後に合意・責任・未確定事項・次の切替を固定する。沈黙を威圧や情報隠しへ使うことは、この秩序から外れる。

## 中心命題
**再演可能な共創は、能力の総和ではなく、観測・翻訳・設計・検証を混線させず、沈黙と問い、順序、切替、終端条件によって意味・責任・合意を段階的に固定することで成立する。**

```text
同時発話・役割混線
→ 早熟な結論・価格先行・決定疲労・再作業
→ 観測 / 翻訳 / 設計 / 検証を分離
→ SQSで前提・問い・合意を位相化
→ 切替理由と次役割を明示
→ 価値→便益→コストの順序で設計
→ 終端条件・再合意条件を固定
→ 再演・反証・更新可能な共創秩序
```

## 因果線
```text
全員が同時に観測・提案・決定・検証する
↓
事実と解釈、設計と評価が混ざる
↓
価格先行、早熟な結論、決定疲労、再作業が増える
↓
四役を一度に一役へ分離する
↓
SQSで前提観測→問い→合意固定を行う
↓
違和感・飽和・決定疲労を切替サインとして扱う
↓
価値→便益→コストの順序で設計を進める
↓
終端条件・責任・未確定・再検討条件を明示する
↓
一次ログと語彙へ戻れる状態を保つ
↓
共創を再演・反証・訂正できる秩序へ変える
```

## 構造層
**1. 観測層。** 事実、沈黙、違和感、制約を採取し、解決案を先に置かない。

**2. 翻訳層。** 観測された事実を関係、因果、役割、構造へ写像し、まだ決裁しない。

**3. 設計層。** 関係価値、便益、コストの順に制度・仕組み・配線を構成する。

**4. 検証層。** 反証条件、終端条件、更新条件を固定し、検証中の追加設計を次の設計位相へ戻す。

**5. SQS層。** 最初の沈黙で前提を観測し、問いで構造を明示し、最後の沈黙で合意・責任・未確定を固定する。

**6. 切替層。** 違和感の増大、情報密度の飽和、決定疲労を、現在役割を終えて次へ移るサインとして扱う。

**7. 終端・再合意層。** 一旦の合意を永久確定とせず、何を確定し、何を保留し、いつ再検討するかを記録する。

## 適用例
**1. 会議。** 発散・構造化・選択・検証を同時に行わず、今どの役割かを明示して進める。

**2. 営業。** 価格へ直行せず、まず価値と便益の理解を作り、その後にコストを扱う。ただし価格を隠すための技法にはしない。

**3. 研究・制作。** 事実収集、解釈、案の生成、レビューを分け、検証中の変更を次版へ戻す。

**4. AI協働。** 要約、構造抽出、設計、反証、統合を役割として分け、出力のずれを人格的失敗ではなく役割・入力・切替の不一致として再検査する。

**5. 緊急時。** 長いSQSを置けなくても、責任主体・判断対象・終端条件を短く固定し、後から検証・再合意する。

## 測定・監査点
親原典は、合意到達率、再作業率、切替遅延、D-Gap、照応成功率、語彙整合率、位相安定S、合意到達時間T等を秩序仮説の観測対象として扱う。これらは人間の優劣や従順さを格付けする指標ではない。

- **四役**: 観測・翻訳・設計・検証という原典明示の4機能。4点満点等のスコアではない。
- **D0〜D5**: 問いの深度を区別する6段階分類。数値の大小を人や問いの優劣へ変換しない。
- **合意到達率**: 合意の形成を観測する候補だが、指示・服従・表面的同意を合意として数えない。
- **再作業率**: 秩序設計後にどの程度戻り作業が生じるかを観測する候補。低ければ常に良いとは限らず、必要な訂正まで抑止していないかを見る。
- **切替遅延**: 切替サインが出てから役割切替までの遅れを観測する候補。速度だけで良否を決めない。
- **D-Gap**: 設計深度と実際の到達深度の差。差が小さくても強制・過剰侵襲なら成功ではない。
- **位相安定S / 合意到達時間T**: 原典監査文脈の記号・観測語として保持し、具体値がない場合は固定閾値を作らない。

反転評価では、合意率が上がり、会議時間や切替時間が短くなっても、異論・拒否・訂正が出にくくなり、沈黙が抑圧として機能するなら改善とみなさない。再作業が減っても、誤りを訂正できなくなったなら成功ではない。

## 成立条件
- 共有主語、目的、対象、役割境界が明確である。
- 一度に一役が実質的に守られる。
- 切替理由と次役割が明示・記録される。
- 一次ログ、語彙、証拠へ戻れる。
- 価値→便益→コストの順序が理解のために使われ、価格隠しに使われない。
- 拒否、訂正、非合意、再合意が可能である。
- 終端条件、責任、未確定、再検討条件がある。
- 緊急時は即時責任を明示し、後から検証できる。
- 非強制・可逆・検証可能性が保持される。

## 失敗条件
- 役割名だけ付け、実際には複数役を同時遂行する。
- 沈黙を威圧、無視、情報隠し、同意圧力へ使う。
- 観測・翻訳より先に価格・結論・決裁を固定する。
- 価値→便益→コストを価格先延ばしや誘導へ転用する。
- 検証中に対象を変え続け、反証不能になる。
- 非合意を認めず、指示や服従を合意と呼ぶ。
- 一次ログがなく、再演・反証・訂正できない。
- 指標改善だけを成功とし、尊厳・自発性・可逆性の悪化を見ない。

## 反証・改訂条件
- 四役分離を行っても再作業・役割混線が反復して減らない。
- SQS導入後に異論や拒否が減り、沈黙が実質的圧力として働く。
- 切替規律が意思決定を不必要に遅らせ、目的適合性を損なう。
- D-Gapや合意到達時間を最適化しても合意内容の妥当性が下がる。
- 終端条件があっても未確定事項や責任が追跡できない。
- 緊急・安全・法的状況で役割設計が必要な即時判断を妨げる。

## 必須の区別
- 役割 / 固定身分
- 一度に一役 / 一人一職
- 沈黙 / 拒絶・威圧・無視
- SQS / 答えを迫る心理操作
- 合意 / 指示・服従・全員一致
- 価値→便益→コスト / 価格隠し
- 検証 / 追加設計
- 再演可能性 / 画一化
- 指標監査 / 人間格付け
- 非強制 / 無責任
- 終端 / 永久確定
- 速度 / 妥当性

## 解釈制約
共創秩序論を会議マナー、沈黙術、営業心理、静的な職務分担へ縮約しない。中心は、意味・責任・合意・訂正がどの位相で生成・固定・更新されるかを設計することにある。沈黙や順序を支配技法へ転用せず、役割を人格評価へ変えず、数値指標を人間価値のランキングへ変換しない。
