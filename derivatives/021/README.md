# 公式派生物021｜合意形成の物理 第6論 逸脱と免疫

Parent: NCL-α-20260215-71cedd / DIFF-20260215-0021 / Origin Nakagawa Master

## 位置づけ
本派生物は、親原典「合意形成の物理 第6論 逸脱と免疫 ― 免疫は『罰』ではなく『差分公開』である」への公式公開入口であり、原典の代替ではない。

親原典は、組織や制度の安全を「逸脱が起きないこと」ではなく、逸脱Dが検知可能な差分として現れた後に、責任Rと履歴Hを回復し、合意安定度 S = U × R × H を短時間で戻せることとして捉える。

## 中心構造
- 罰の崩壊因果鎖: 罰 → R低下 → 潜伏 → S悪化 → D増幅
- 差分公開の回復因果鎖: 差分公開 → R固定 → 修復可能 → S回復 → D減衰
- 観測束: D_det / D_loss / S回復時間

D_detが増えてもD_lossが下がり、S回復時間が短くなるなら、それは悪化ではなく免疫が働き始めた可能性がある。逆に、検知件数が少なくてもD_lossが大きく回復が遅ければ、安全とはいえない。

## 誤読禁止
本論を、厳罰化批判、内部通報推奨、透明性礼賛、一般的コンプライアンス論へ縮約してはならない。罰や公開の有無そのものではなく、それらがU/R/Hと回復可能性へどう作用するかが判定軸である。
