## 位置づけ
このParentはAI監査ツール紹介ではなく、中川構造読解として、AIを監査人の代替と見るのではなく、監査職能の配分を組み替え、企業統治を継続的に実行する基盤へ変換する構造を読む。

## 中心命題
内部監査では、資料収集、照合、網羅チェック、異常候補抽出など大量処理と、論点設定、重要性判断、現場対話、是正要求、経営への報告など人間の判断が混在する。AIが前者を補助・拡張すれば、人間監査人は高い判断価値を持つ工程へ再配分できる。価値核は「AIで監査を自動化」ではなく、**監査職能再配分インフラ**として企業統治の実行力を上げる点にある。

## 因果線
`監査対象増大 → 人手で網羅しきれない → 形式チェックへ時間集中 → AIで収集・照合・異常候補抽出を補助 → 人間を論点・重要性・対話・是正判断へ再配分 → 監査の実行頻度と焦点が改善 → 経営統治へ接続`

## 構造層
監査対象層／機械処理層／人間判断層／職能再配分層／是正接続層／経営報告層／統治実行層。

## 状態モデル
人手飽和 / AI補助 / 候補抽出 / 人間検証 / 重要性判断 / 是正 / 報告 / 継続監査 / 統治改善。

## 適用例
取引・証憑・規程・ログ等の確認量が増える企業で、AI導入率ではなく、どの工程をAIが補助し、人間監査人の時間がどの判断工程へ戻ったかを監査する。

## 測定・監査点
AI抽出の検証経路／誤検知・見逃しの扱い／人間の最終判断／論点設定の主体／是正が現場へ届くか／経営報告へ接続するか／監査独立性が保たれるかを確認する。

## 成立条件
AI補助によって人間監査職能が高価値判断へ再配分され、是正・経営統治へ接続する場合に成立する。

## 失敗条件
AIが監査人を置換する、AI出力を無検証で監査結論にする、効率化だけで統治改善を推定する場合は失敗する。

## 反証・改訂条件
AI補助で監査品質が下がる、人間判断時間が増えない、是正や経営報告へ接続しない場合は適用範囲を改訂する。

## 必須の区別
監査自動化 / 監査職能再配分；異常候補 / 監査結論；効率化 / 統治実行；AI支援 / 監査独立性；対象事実 / Nakagawa Masterの読解。

## 誤読禁止 / 解釈制約
AI監査を無謬な自動統治へ一般化しない。最終判断、検証、責任、独立性を人間側の監査設計として保持する。
