## 位置づけ
本Parentは、イルミメディカルを「光治療ベンチャー」「深部がん向け医療機器企業」「体深部へ光を届ける技術を開発する会社」という表層分類だけで読むと、事業が動かしている上流条件を取り逃がすと論じる中川構造読解である。対象企業・技術に関する確認可能な事実と、Nakagawa Masterによる構造読解は分離して扱う。

Parentが置く価値核は、**深部光医療の成立条件を更新する基盤インフラ**である。ここでいう基盤インフラは病院設備という意味ではなく、特定治療法や単一疾患に閉じず、治療・診断・研究用途が成立する前段の「光を必要部位へ届けられること」という下層条件を支える技術基盤を指す。

重要なのは、Parent自身が「なぜこの価値核を選んだのか」「なぜ外部記事でこの軸を前面化したのか」「何を前に出し、何を抑えたのか」まで公開解体している点である。したがって本派生物も、企業紹介や外部記事の要約へ縮めず、Parentが記録した構造読解の判断過程を意味軸として保持する。

ParentでNakagawa Masterが最初に置く違和感は、「これは本当に光治療の話なのか」である。ET-BLITを「体深部へ光を届ける技術」とだけ説明すれば機能説明としては成立するが、それでは「何を成立可能にする技術なのか」が見えない。Parentはこの差を、**何をする技術か／何を成立可能にする技術か**という区別として扱う。

## 中心命題
光を使う治療・診断・研究は、薬剤や作用機序が存在するだけでは成立しない。必要部位へ光が届かなければ、検討できる治療・診断・研究の範囲そのものが制約される。したがって、深部光医療の上流制約は「光が届くかどうか」という到達条件にある。

Parentは、イルミメディカルの構造的価値を「深く光を届ける装置性能」だけに置かない。血管内治療という既存医療文脈と、光医療が抱えていた到達制約が交差するところで、血管を光の到達路として再定義し、これまで光が届かないために成立しにくかった医療へ新しい入口を作ろうとしている点に価値核を置く。

ここで「血管を道路として使う」という比喩は装飾ではない。道路は目的地そのものではなく、目的地へ到達可能にする経路である。同じように、血管内光デリバリーは治療結果そのものではなく、治療・診断・研究を検討可能にする到達条件を置き直す構造として読まれる。

## 因果線
```text
光医療には治療・診断・研究上の可能性がある
→ しかし光が必要部位へ届かなければ作用を検討できる範囲が制約される
→ 「どの治療が優れるか」以前に「光をどう届けるか」が成立条件になる
→ 外部照射だけでは深部利用に構造的制約が残る
→ 血管内治療で既に存在する体内アクセス経路に着目する
→ 血管を光デリバリーの到達路として再定義する
→ 光が届かなかったため成立しにくかった医療・診断・研究に新しい検討入口が生まれ得る
→ 到達条件の更新を、装置性能ではなく医療実装条件の再設計として読む
→ 薬事・量産・共同研究・既存医療インフラとの接続を下流の成立条件として分離する
→ 治療成果や普及を断定せず「深部光医療の成立条件を更新する基盤インフラ」という価値核へ置く
```

## 構造層

2. **表層分類層**: 光治療ベンチャー、深部がん向け医療機器、深部照射技術という一般的な見え方。
3. **誤読層**: 技術の新規性・装置性能・疾患単位へ価値を縮めると、上流の成立条件が見えなくなる。
4. **違和感層**: 「これは本当に光治療の話なのか」「何をするかではなく、何を成立可能にするのか」という問い。
5. **制約層**: 光医療は「光が届く場所」に縛られる。
6. **到達路再定義層**: 血管を光を運ぶ経路として再定義する。
7. **価値核層**: 治療結果ではなく、治療・診断・研究が成立し得る場所を増やす到達条件の更新。
8. **実装条件層**: 研究、臨床、薬事、量産、共同開発、既存医療インフラとの接続を別条件として扱う。
9. **社会翻訳層**: 専門技術の列挙ではなく「血管を道路として使う」「深部光治療の新しい入口」という言葉で構造を読者へ通す。
