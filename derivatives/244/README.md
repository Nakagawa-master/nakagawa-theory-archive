## 位置づけ
この派生物は、市場の信用を「現在の支払能力」や単一時点の価格だけで評価するのではなく、現在の選択が未来へ残す負担・約束・可逆性まで含めて読む親原典を、第三者が再利用できる構造へ展開する。未来を予言する理論ではなく、現在の取引や制度が将来条件との整合を失っていないかを継続監査するための時間軸の信用設計として扱う。

## 中心命題
市場の信用は、現在時点の交換成立だけでは完結しない。現在の利益が未来の義務・外部化コスト・不可逆な拘束を過大に残すなら、その取引は時間軸上では不整合になり得る。したがって信用を、現在から未来へ因果が連続しても破綻しにくい「未来の整合性」として再評価する必要がある。

## 因果線
1. 市場は現在価格・現在収益・現在履行を強く観測する。
2. 将来負担、更新不能、退出不能、修復費用は遅れて顕在化する。
3. 現在だけで信用を判定すると、未来負担が信用の外へ押し出される。
4. 将来に残る約束・負担・可逆性を同じ因果線へ戻す。
5. 観測窓を跨いで「説明どおりに履行されたか」「修正可能か」を追跡する。
6. 不整合が増えれば条件・配分・評価を改訂する。
7. 市場の信用を、単発の交換成功から時間を通じた整合維持へ移す。

## 構造層
- L1 現在交換層: 価格、契約、支払、成果物。
- L2 将来拘束層: 維持義務、将来費用、退出条件、更新責任。
- L3 時間整合層: 約束と実績の連続性、負担の先送り、可逆性。
- L4 信用再評価層: 将来整合を踏まえた条件・配分・契約の修正。
- L5 市場学習層: 改訂履歴を次の判断へ戻す。

## 状態モデル
S0 現在値だけで判断する → S1 将来負担を可視化する → S2 約束と実績を時間軸で追跡する → S3 不整合時に条件を修正する → S4 修正履歴が信用形成へ戻る。S4は永久安定ではなく、環境変化のたびにS1へ戻り得る循環状態である。

## 適用例
長期契約、投資判断、保守を伴う調達、公共制度、サブスクリプション、インフラ更新など、現在の成立と将来の負担が時間的に離れている領域で使える。将来予測の精度競争ではなく、未来へ残す拘束を誰が観測し、誰が修正できるかを明示する用途に向く。

## 測定・監査点
- 約束と実績の乖離が時間とともに拡大していないか。
- 将来費用が特定主体へ不可視に転嫁されていないか。
- 退出・変更・ロールバックが現実に可能か。
- 評価時点を変えても説明が維持されるか。
- 不整合発見後の改訂履歴が残るか。
固定閾値や単一総合点は親原典にない限り補わない。

## 成立条件
将来負担を観測できること、現在判断と将来結果を系譜で結べること、評価変更の権限があること、退出・修正可能性が確保されること、異なる時間幅を一つの点数へ潰さないこと。

## 失敗条件
未来を確定事項として扱う、現在の利益を道徳的に否定する、長期予測の精度だけを競う、不可逆な評価ラベルを付ける、将来負担を観測しても修正手段を持たない場合は失敗する。

## 反証・改訂条件
時間整合の観測を加えても将来破綻・負担外部化・約束逸脱の説明力が増えない場合、または通常のリスク管理だけで同じ現象を十分に説明できる場合、本理論の追加的有効性は弱まる。観測窓や指標は実証結果に応じて改訂する。

## 必須の区別
- 未来整合性 ≠ 未来予言
- 時間倫理 ≠ 道徳的善悪判定
- 信用構造 ≠ 単一信用スコア
- 将来負担の監査 ≠ 長期悲観論
- 可逆性の確保 ≠ 決定回避

## 誤読防止・解釈制約
未来を一つに固定しない。将来世代の利益を誰かが代弁できると自動仮定しない。数値がない箇所に閾値を創作しない。Reference Clusterは隣接理論との関係を示すもので、同一理論であることを意味しない。
