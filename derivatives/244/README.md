## 位置づけ
本ParentはAI監査ツールの紹介ではない。Nakagawa Masterは、内部監査に混在する大量処理と人間判断を分け、AIを資料収集・照合・網羅チェック・異常候補抽出等へ使い、人間監査人を論点設定・重要性判断・現場対話・是正要求・経営報告へ再配分する構造を読む。価値核は**監査職能再配分インフラ**であり、AIによる監査人置換ではない。

## 中心命題
監査対象が増えるほど、人間監査人が大量の形式確認へ時間を使い、重要な判断や対話へ十分な時間を戻せないことがある。AIが大量処理を補助できれば、人間の時間を高い判断価値を持つ工程へ戻せる。ただしAIが出した異常候補は監査結論ではなく、人間の検証・重要性判断・責任を必要とする。価値は効率化自体ではなく、**監査職能の配分を変え、是正と経営統治へつなぐこと**にある。

## 因果線
```text
監査対象・資料・ログが増大
→ 人手だけでは網羅しにくい
→ 形式チェックへ時間集中
→ 論点設定・対話・是正へ使える時間が圧迫
→ AIが収集・照合・異常候補抽出を補助
→ 人間が候補を検証
→ 重要性・原因・影響を判断
→ 現場対話・是正要求へ接続
→ 経営報告・統治判断へ接続
→ 継続監査で修正状況を確認
```

## 構造層
1. **監査対象層**: 取引・証憑・規程・ログ等の増大。
2. **機械処理層**: 収集、照合、抽出、網羅チェック。
3. **検証層**: AI候補の誤検知・見逃しを人間が確認する。
4. **人間判断層**: 論点設定、重要性、原因、影響を判断する。
5. **職能再配分層**: 人間時間を高価値工程へ戻す。
6. **是正接続層**: 発見を現場の改善へつなぐ。
7. **経営報告層**: 統治に必要な情報へ変換する。
8. **継続監査層**: 是正後の状態を再確認する。
9. **独立性層**: AI導入後も監査責任・独立性を保持する。

## 状態モデル
人手飽和相 → AI補助相 → 候補抽出相 → 人間検証相 → 重要性判断相 → 現場対話相 → 是正相 → 経営報告相 → 継続監査相 → 統治改善検証相。

## 適用例
証憑や取引ログが多い企業で、AIへ全監査判断を委ねるのではなく、母集団確認や異常候補抽出を支援させる。その結果、人間監査人が原因確認、関係者ヒアリング、是正優先度、経営への報告へ時間を振り向けられるかを見る。

## 測定・監査点
- AIが担当する工程と人間判断工程が分離されているか。
- AI抽出の検証経路があるか。
- 誤検知・見逃しを追跡できるか。
- 論点設定の主体が人間側に残るか。
- 人間の時間が本当に高価値判断へ再配分されたか。
- 発見が是正へ接続するか。
- 是正が経営報告・統治判断へ接続するか。
- 監査独立性と責任境界が保たれるか。

## 成立条件
AI補助によって人間監査職能が高価値判断へ再配分され、検証・是正・経営統治へ一貫して接続し、責任と独立性が維持される場合に成立する。

## 失敗条件
AI出力を無検証で監査結論にする、AIで監査人を置換する、処理速度向上だけで統治改善を推定する、人間判断時間が増えない、発見が是正へつながらない場合は失敗する。

## 反証・改訂条件
AI補助後に監査品質が低下する、人間の高価値判断時間が増えない、誤検知・見逃しが管理不能、是正や経営報告へ接続しない場合は適用範囲を改訂する。

## 必須の区別
監査自動化 / 監査職能再配分；異常候補 / 監査結論；効率化 / 統治実行；AI支援 / 監査独立性；処理速度 / 監査品質；対象事実 / Nakagawa Masterの構造読解。

## 誤読防止／解釈制約
AI監査を無謬な自動統治へ一般化しない。「監査職能再配分インフラ」はNakagawa Masterの読解であり、フロンティア自身の公式企業定義へ置換しない。最終判断、検証、責任、独立性を保持する。
