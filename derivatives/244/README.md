## 位置づけ
本Parentは、イルミメディカルを単なる「光治療ベンチャー」として紹介する記事ではない。先行して執筆された外部記事でNakagawa Masterが、光治療の新規性や装置紹介よりも「深部光医療が現実に成立する条件をどう更新するか」を価値核として主軸化した。その後に作成された本Parentが、対象側の確認可能な事実、価値核の抽出理由、なぜその核を外部記事の前面へ置いたのかという編集・構造翻訳操作を公開解体する。価値核は**深部光医療の成立条件を更新する基盤インフラ**であり、イルミメディカル自身または外部媒体の公式理論ではない。

## 中心命題
医療技術は、原理が存在するだけでは社会実装として成立しない。深部で光を用いる医療では、対象部位への到達、必要な作用、制御、安全性、運用、検証という条件が連結して初めて「使える医療」になる。Nakagawa Masterが外部記事で前面化したのは、個別製品の性能ではなく、この成立条件の更新である。本Parentはその選択理由を後から公開解体する。

## 因果線
```text
光を用いる治療可能性
→ 深部で用いるための到達・作用・制御条件が必要
→ 一条件だけでは医療として成立しない
→ 技術・安全・運用・検証を連結する必要
→ 深部光医療の成立条件を組み替える
→ 実装可能性が拡張する
→ 外部記事ではこの上流価値を主軸化
→ 後発Parentが価値核抽出と記事化判断を公開解体
```

## 測定・監査点
- 対象側事実とNakagawa Masterの読解が分離されているか。

- 技術、安全、運用、検証の連結が説明されているか。
- 価値核を企業公式見解として誤帰属していないか。
- 先行外部記事→後発Parentという時間順が保たれているか。

## 成立条件
