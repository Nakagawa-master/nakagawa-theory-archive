## 位置づけ
本Parentは、イルミメディカルを単に「新しい光治療の会社」として紹介するものではない。対象企業・技術について確認できる事実と、Nakagawa Masterによる構造読解を分離したうえで、価値核を**深部光医療の成立条件を更新する基盤インフラ**として読む。

この価値核を選ぶ理由は、医療技術の社会的価値が新規性や単一性能だけでは決まらず、現実の医療利用へ到達するための複数条件が接続されて初めて成立するからである。外部記事でも、製品や企業の目新しさを主役にするのではなく、「深部で光を医療利用するために、どの成立条件が更新されるのか」を読者の判断軸として提示することに意味がある。

## 中心命題
深部で光を医療利用するには、原理が存在するだけでは足りない。到達、作用、制御、安全、運用、検証など複数の条件が、現実の医療利用へつながる一つの成立鎖として接続される必要がある。

イルミメディカルの構造的価値を読むときの焦点は、単一の性能や「光治療」という分類ではなく、これまで成立を止めていた条件のどこを更新し、医療として使える可能性をどこまで広げるかにある。
