## Summary
イルミメディカルを「光治療ベンチャー」という表層分類ではなく、深部光医療の成立条件を更新する基盤インフラとして読む。評価単位は技術の新規性ではなく、現実利用に必要な条件のどこを更新し、成立可能性をどう変えるかである。

## Concepts
深部光医療、成立条件、停止点、条件束、条件連結、成立可能性、基盤インフラ、構造読解、社会翻訳、原典回帰。

## Causal chain
深部光医療の目的 → 単一原理では不足 → 複数成立条件 → 条件欠損による停止 → 条件分解 → 依存関係確認 → 対象による条件更新 → 成立可能性評価 → 基盤インフラという価値核。

## State model
表層分類 → 原理期待 → 成立条件認知 → 条件分離 → 条件連結 → 停止点特定 → 条件更新 → 成立可能性評価。

## Applications

## Measurements and audit

## Validity conditions
複数条件が連結しなければ現実利用が成立せず、対象が条件鎖の一部を更新するという読解が対象価値を説明できること。

## Failure conditions

## Falsification conditions
