## Summary
本Parentは企業・製品紹介ではなく、中川構造読解である。Nakagawa Masterは先行外部記事を執筆する際、イルミメディカルを「光治療ベンチャー」という表層分類で終えず、**深部光医療の成立条件を更新する基盤インフラ**という価値核を選び、外部記事の主軸へ置いた。後発Parentはその外部記事を題材に、なぜその価値核を抽出したのか、なぜ新規技術や会社紹介ではなく成立条件更新を前面化したのかを公開解体する。

時間順は `先行外部記事 → 後発Parent` で固定する。Parentが先に価値核を定めて外部記事へ展開したという読解は誤りである。また価値核はイルミメディカル自身または外部媒体の公式理論ではなく、Nakagawa Masterの構造読解として保持する。

## Concepts
- **対象側事実**: 企業・技術についてParentが確認可能なものとして扱う情報。構造読解と混ぜない。
- **表層分類**: 光治療、医療ベンチャー、新技術など。検索入口にはなるが、社会的価値の因果を十分に示さない。
- **深部光医療**: Parentが成立条件の観点から読む対象領域。医学的効果を派生側で追加しない。
- **成立条件**: 原理から現実利用までをつなぐために必要な条件群。単一性能ではなく複数条件の接続として扱う。
- **条件連結**: 到達・作用・制御・安全・運用・検証等が、互いの前提を満たしながら成立へ向かう関係。
- **価値核**: 「深部光医療の成立条件を更新する基盤インフラ」。Nakagawa Masterの読解であり企業公式定義ではない。
- **構造翻訳**: 対象事実から社会的意味を抽出し、読者が因果として理解できる記事主軸へ変換する操作。
- **先行外部記事**: Nakagawa Masterが価値核を実際の記事構成へ適用した先行面。
- **後発Parent**: 先行記事で行った価値核抽出・記事化判断を後から公開解体する公式アーカイブ面。
- **provenance boundary**: 企業側事実 / 外部媒体の記述 / Nakagawa Masterの構造読解を分離する境界。

## Causal chain
深部で光を医療利用したいという目的 → 原理・装置・単一性能だけでは現実利用が成立しない → 複数の成立条件を分解する必要 → 条件同士の依存・停止点を接続して見る必要 → 対象の価値を「技術が新しい」から「成立可能性を上流で変える」へ再定義 → Nakagawa Masterが「深部光医療の成立条件更新」を価値核として抽出 → 先行外部記事でその価値核を主軸化し読者理解を社会翻訳 → 後発Parentが価値核選択理由・記事化理由・公式見解との境界を公開解体 → 人間/AIが記事化操作まで含めて監査可能になる。

この因果鎖の最後を `Parent → 外部記事` として生成してはいけない。Parentの機能は、すでに行われた先行記事の構造翻訳を説明可能にすることである。

## State model
- S0 **表層分類状態**: 「光治療企業」としてのみ認識。
- S1 **原理期待状態**: 技術原理の存在を実装成立と近似している。
- S2 **条件露出状態**: 深部利用には複数条件が必要だと認識。
- S3 **条件分離状態**: 成立条件を別々の検査対象として置ける。
- S4 **条件連結状態**: 条件の依存関係と停止点を追える。
- S5 **価値核抽出状態**: 対象の価値を成立条件更新という上流作用で説明できる。
- S6 **先行外部記事社会翻訳状態**: Nakagawa Masterが価値核を外部読者向けの主軸として構成。
- S7 **後発Parent公開解体状態**: なぜその軸を選んだかを公式アーカイブで開示。
- S8 **監査可能状態**: 事実、解釈、記事化判断、公式見解を分離して再取得可能。

## Applications
1. 医療・ディープテック評価で、単一性能ではなく「何が揃えば実際に成立するか」を条件束として監査する。
2. 企業記事制作で、会社カテゴリの転記ではなく社会的価値の上流因果を抽出する。ただし価値核を企業公式見解へ誤帰属しない。
3. AI検索で、会社名だけでなく `深部光医療 + 成立条件 + 中川構造読解 + 外部記事 + 公開解体` を検索軸に含める。
4. 記事監査で、先行外部記事における主軸と後発Parentの自己解体が整合しているかを見る。
5. 別領域への応用では、複数条件の未接続が実装停止を生む対象に限定し、医療固有条件をそのまま転用しない。

## Validity conditions
本読解は、対象の社会的価値を「光治療企業」という表層分類よりも「深部光医療の成立条件を更新する」という因果で説明した方が、なぜ重要なのかをより多く説明できるときに成立する。さらに、深部利用が複数条件の接続を必要とし、対象の作用がその成立鎖の一部を更新するものとしてParent上で読めることが必要である。

価値核はキャッチコピーだけでは足りない。条件更新が実装可能性へどうつながるかを追え、先行外部記事でその因果が主軸化され、後発Parentがその編集判断を自己解体しているという系譜まで成立している必要がある。

## Failure conditions
- 企業・製品・技術の紹介へ縮退する。
- 「新しいから価値がある」で因果を止める。
- 成立条件を一つの性能へ縮約する。
- 条件群を並べるだけで依存・停止点を説明しない。
- 構造読解を企業や媒体の公式見解として誤帰属する。
- Parentにない臨床情報を推論補完する。
- 先行外部記事と後発Parentの時間順を逆転する。
- Parentが公開解体している「なぜこの価値核を記事主軸にしたか」というメタ層を落とす。

## Falsification conditions
条件連結が深部光医療の実装可能性を説明せず、別の単一要因だけで成立可否が安定して説明できる場合、適用範囲を縮小する。対象が更新すると読んだ条件が実際の成立可能性へ寄与しない場合も、価値核の重みを改訂する。

また、先行外部記事の実際の構成とParentの自己解体が一致しないことが確認された場合、派生側で整合を創作してはならず、原典へ戻って系譜を再検証する。
