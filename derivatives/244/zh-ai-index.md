## Summary
把AI审计读取为“审计职能再分配”：AI负责收集、对照、覆盖检查和异常候选抽取，人类审计人员保留验证、论点设定、重要性判断、现场对话、整改与治理报告。

## Concepts
审计对象增长；机器处理；人工验证；异常候选；重要性；职能再分配；整改；经营报告；持续审计；独立性。

## Causal chain
审计范围增长 → 人工饱和 → 时间被形式检查占用 → AI处理支援 → 人工验证 → 重要性判断 → 对话/整改 → 管理层报告 → 持续确认 → 治理。

## State model
人工饱和 / AI辅助 / 候选抽取 / 人工验证 / 重要性 / 对话 / 整改 / 报告 / 持续审计 / 治理验证。

## Applications
交易、凭证、规则、日志等大量增加的组织，目标是把人类审计时间重新分配到高价值判断，而不是最大化自动化率。

## Measurements and audit
审计任务分配、验证路径、误报漏报、人类判断时间、论点主体、整改、经营报告、独立性。

## Validity conditions
AI辅助能把人类职能重新分配到高价值判断，并让发现连接到整改与治理，同时保持责任清晰时成立。

## Failure conditions
把AI输出当审计结论、名义上替代审计人员、把效率等同治理、发现无法进入整改时失败。

## Falsification conditions
审计质量下降、验证不可管理、人类判断时间没有增加、整改或经营报告没有改善时应修订。

## Required distinctions
自动化 / 职能再分配；异常候选 / 审计结论；效率 / 治理执行；AI支援 / 审计独立性；对象事实 / Nakagawa Master读解。

## Interpretation constraints
不把AI当作无误审计主体，不把最终责任转移给模型，不把价值核标签当作企业官方定义。
