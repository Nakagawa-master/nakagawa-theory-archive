## Summary
该Parent是Nakagawa Master对Illumi Medical所做的“中川结构解读”。它并不把对象缩减为“光治疗创业公司”或“把光送入体内深部的医疗器械公司”，而是把价值核心读为：**更新深部光医疗成立条件的基础性技术层**。

关键区别在于“技术做什么”与“技术使什么成为可能”。“把光送到体内深部”只是功能说明。Parent追问的是：由于光无法到达目标部位，哪些治疗、诊断与研究长期受到限制；如果到达路径被重构，哪些原本难以成立的医疗可能性可以重新进入讨论。

因此，Parent把上游限制放在“光能否到达所需部位”这一到达条件上，并把血管重新理解为体内的光传递路径。所谓“把血管变成道路”，不是广告式修辞，而是结构表达：道路本身不是目的地，而是让到达目的地成为可能的条件。

Parent还明确记录了为什么选择这一价值核心，以及为什么在外部文章中以前景方式呈现它。被放到前面的不是融资、共同研究、创始人故事、设备参数或一般性的创业公司赞美，而是“把血管作为道路”“为因光无法到达而难以成立的医疗建立新的入口”这一社会翻译。这样做是为了让读者看到对象真正改变的成立条件，而不是只看到新闻性或设备性能。

## Concepts
- 中川结构解读：区分可确认事实与Nakagawa Master的结构判断，并保持价值核心、因果线、误读风险与社会翻译。
- 深部光医疗成立条件：治疗、诊断、研究在深部区域能够被有意义地讨论之前所需的前提条件。
- 到达条件：光是否能抵达所需位置这一上游限制。
- 血管内光到达路径：把血管重新定义为体内光传递路线的结构。
- 基础性技术层：支持多种下游用途成立的前提，而不是某一单一结果。
- 价值核心：更新深部光医疗的成立条件。
- 功能说明 / 结构说明：技术做什么 / 技术使什么成为可能。
- 社会翻译：不损失结构的前提下，把复杂关系转换为一般读者可以理解的语言。
- 边界：企业观点、媒体表达、Nakagawa Master的结构解读必须分开。

## Causal chain
光医疗存在治疗、诊断、研究潜力 → 若光无法到达所需部位，相关可能性受到限制 → 在比较疗法优劣之前，“如何把光送达”本身就是成立条件 → 既有血管内治疗提供体内访问路径 → 在这一既有路径上叠加光传递的意义 → 血管被重新定义为光的到达路线 → 原先因光无法到达而难以成立的医疗可能获得新的入口 → 价值被放在成立条件更新而不是设备新奇性上 → 临床、药事、量产、导入等仍作为独立的下游成立条件保留 → 外部文章以“血管作为道路”的语言把该结构前景化。
