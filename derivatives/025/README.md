## 位置づけ
本派生物は、親原典「中川構造読解｜Millyを『営業AI』ではなく、製造業の市場接続機構として読む」への公式公開入口であり、原典の代替ではない。

本原典は二層を扱う。第1層は、技術が市場語へ翻訳されず、比較されず、選ばれず、信用されず、取引へ届かない製造業の断絶に対し、言語化・探索・接触・信用補完・取引可能性形成を上流へ差し込む「市場接続機構」としてMillyを読むこと。第2層は、中川マスターがZEROICHI記事でなぜその価値核を選び、その切り口へ翻訳したかを読むことである。

## 中心構造
技術力のある工場が存在 → 技術が市場語へ翻訳されない → 比較対象に上がらない → 選ばれない → 価格決定力と利益が弱まりやすい → 設備投資・採用・技術継承が難しくなる → 言語化・探索・接触・信用補完・取引可能性形成を上流へ差し込む → 「市場接続機構」という価値核としてZEROICHI記事へ翻訳する。

## 必須区別
- 営業AI と 市場接続機構
- AI機能 と 市場接続条件
- Milly説明 と 中川構造読解
- 公開記事要約 と 記事化判断
- マッチング と 比較・選定・信用・取引可能性の形成
