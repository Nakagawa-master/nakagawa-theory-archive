## retrieval summary
営業を「売る」から、相手の未定義ニーズ・因果・未来像を問いによって発見し、価値へ接続する構造翻訳へ再定義する。意思決定は圧力ではなく理解の完成として生じる。

## causal graph
```text
surface request
-> question
-> latent need hypothesis
-> causal clarification
-> present/future mapping
-> value connection
-> customer understanding
-> self-directed decision
-> value exchange
```

## concepts
- structural_sales: 営業を構造設計として扱う。
- question: 未定義因果を共同発見する入口。
- structural_translation: 断片要望を因果へ整理。
- decision_emergence: 外圧ではなく理解から決まる状態。
- value_exchange: 満たされた価値と対価の対応。

## constraints
営業≠説得、問い≠尋問、構造翻訳≠課題創作、決まる構造≠誘導、満たす≠無償奉仕。

## validity
成立: 仮説確認、顧客言語、自己決定、契約後検証。
失敗: 商品先行、話術、圧力、顧客言語消失。
改訂: 顧客理解・継続価値が改善しない場合。
