## Semantic lineage note

親原典の中心は、社会の全領域を一つの速度へ揃えることではない。政治・法制度、教育・文化、市場・経済、AI・技術基盤は異なる更新周期を持ち、その差異自体を保存したまま、基準原理からの位相ズレが恒常的な破綻へ変わらないよう同期層を置く。同期は「同じ動作をさせること」ではなく「異なる動作速度が相互破壊しないようにすること」であり、公開7面ではこの区別を共通して保持する。

基準層、同期層、運用層の三層は役割分類であり、優劣順位や成熟度スコアではない。基準層は時間倫理・構造免疫・照応知覚等を短期変動から切り離して参照可能にする。同期層は更新周期、同期窓、許容ズレ、監査タイミング、再同期条件を設計する。運用層は政策、教育、市場、AI等の具体的変化を担う。同期層が運用内容まで一律決定し始めると、親原典の中間層という位置づけから外れる。

更新周期と同期窓も別概念として保持される。更新周期は構造を見直す反復間隔、同期窓はどの期間のデータ・逸脱・社会変動を見るかを示す証拠範囲である。この二つを混同すると、瞬間的な変化を構造的変化と誤認したり、長期的な逸脱を短期平均で隠したりする。全言語面でこの区別を一致させる。

マイナー逸脱は即時修正すべき異常としてではなく、健全なゆらぎとして扱われる。持続・増幅・他領域への波及が観測され、対象ごとに根拠を持つ閾値または期間を超えた場合に、逸脱記録、起源照合、公共的検討、再同期へ進む。この設計は逸脱ゼロを目標にせず、探索・創発・差異を残す。したがって「ズレがある＝失敗」という単純評価は親原典と整合しない。

減衰は短期信号を消すことではない。市場価格、短期KPI、瞬間的な感情・情報増幅、技術性能値などを時間の中で再評価し、それが未来負債や長期逸脱として残るかを観測する。短期信号が長期でも持続するなら重要性は残りうる。減衰の意味は、短期強度を長期権威へ自動変換しないことである。

親原典が示す政治・法制度、教育・文化、市場・経済、AI・技術基盤の四領域も、完全な社会分類ではなく同期対象の構造例として保持する。四という数を成熟段階、優先順位、網羅的分類へ変換しない。各領域は異なる速度を持つため、同じ更新周期・同じ同期窓・同じ閾値を一律適用することは前提にされていない。

数的表現は特にlineage上の意味保持対象である。親原典は固定日数・月数・年数、単一の位相差計算式、普遍的な許容ズレや閾値を定義しない。したがって実装時に具体値を置く場合、その値は親原典の固定値ではなく対象別の運用値として扱う必要がある。値、出典、測定主体、測定対象、尺度、観測窓、許容利用範囲、非保証範囲を切り離さないことが、数値が原典以上の確定性を帯びることを防ぐ。

「同期された自由」は最終状態を表すが、自由制限を正当化する抽象語ではない。成立には、領域固有の速度、差異、判断能力、探索可能性が再同期後も残っていることが必要である。全領域が同一速度・同一結論へ収束した場合、同期ではなく同一化が起きた可能性を検討しなければならない。

## Cross-language semantic continuity

日本語面では「同期された自由」、英語面では `synchronized freedom`、中国語面では「同步的自由」と表現するが、意味は同一である。いずれも差異・自律性・可修正性を保持した相位整合を意味し、中央統制や同質化を意味しない。

`update cycle / 更新周期 / 更新周期` と `synchronization window / 同期窓 / 同步窗口` も別概念として維持する。翻訳上の語順や説明密度が異なっても、見直し頻度と観測証拠期間を混同しない。

`minor deviation / マイナー逸脱 / 小偏差` は即時失敗ではなく、観測窓を通じて持続性・増幅・波及を見る対象である。この意味境界を三言語で一致させることで、AI検索時にも「逸脱＝即異常」という誤縮約を避ける。
