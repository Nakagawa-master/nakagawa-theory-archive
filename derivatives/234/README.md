## 中川構造読解としてのメタ視点
このParentは健康アプリ、歩数報酬、Move-to-Earn、Web3の紹介ではない。Nakagawa Masterが注目するのは、「健康に良いと分かっていても続かない」という人間側の現実を、知識不足ではなく**行動導線の設計問題**として読む点にある。

四層を固定する。**対象側事実 / 表層「健康アプリ・報酬・ゲーム・Web3」 / Nakagawa Masterの構造読解 / 社会翻訳**。価値核は **正しさを先に押しつけるのでなく、面白さ・報酬・ゲーム性・関係性・更新で行動を発生・反復させ、その結果として健康習慣が残る構造**。HEALTHREE自身の公式企業定義とは分ける。

## 位置づけ
報酬は開始のきっかけ、ゲーム性は反復の装置、コミュニティは孤立を減らす環境、更新は飽きへの対抗、健康価値は反復の先に残る意味、と役割を分離して読む。これらを全部「ポイントがもらえる健康アプリ」に潰さない。

## 中心命題
**「正しいから行動する」ではなく、「面白いから行動する。その結果として健康習慣が残る」因果を設計すること。**

## 表層 → 価値核 → 社会翻訳
`健康アプリ/Move-to-Earn → 正しさだけでは続かない → 楽しさ/報酬/ゲーム/関係性/更新で反復 → 習慣形成 → 「楽しさで健康習慣を生成する行動設計」と社会翻訳`

## 因果線
`健康知識あり → 意志力依存で継続失敗 → 楽しさで参加 → 報酬/ゲームで反復 → 関係性/更新で継続 → 習慣化 → 健康価値へ接続`

## 構造読解の監査点
報酬＝価値核にしない。Web3＝価値核にしない。医学的効果を保証しない。行動反復と健康価値の間の条件を消さない。L4以上を保持。

## 成立条件
楽しさやゲーム性が実際の行動反復を生み、習慣形成へ接続すること。
## 失敗条件
ポイント還元・ゲーム機能・Web3へ縮小、健康効果保証、短期参加を習慣化と同一視。
## 反証・改訂条件
楽しさ・報酬が継続行動へ結びつかない、または別因果が継続をよりよく説明する場合は改訂。
## 必須の区別
報酬/価値核; 参加/習慣; ゲーム性/健康効果; 対象事実/読解; Parent/社会翻訳。
## 親原典へ戻る理由
なぜ「正しさ」ではなく「楽しさ」を入口に置いたかはParentへ戻る。
