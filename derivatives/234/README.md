## 位置づけ
親原典はHEALTHREEを、健康管理アプリ、歩数ポイント、Move-to-Earn、Web3、ゲームという表面分類だけで説明するものではない。対象側の公開材料として、歩行や運動をゲーム体験へ接続するヘルスケアゲーム、報酬設計、Web3要素、資金調達、ダウンロード実績、法人向け展開、海外展開構想等を扱う。その上でNakagawa Masterは、中心問題を「健康知識が足りないこと」ではなく、健康行動が面倒、飽き、忙しさ、忘却、孤立、成果の遠さといった日常摩擦に負けて継続しないことに置く。

価値核は**行動設計**である。健康を直接の義務として押し出すのではなく、楽しさ、参加、報酬、ゲーム性、コミュニティ、運営型更新を使って行動の入口と継続条件を変え、行動が反復され、習慣へ近づき、その結果として健康価値が残りうる順序へ組み替える。

外部公開記事で「健康は正しいだけでは続かない」「楽しいから続く」「報酬は入口、ゲーム性は継続装置」といった表現を前面化したことは、HEALTHREE自身の公式企業定義ではなく、Nakagawa Masterによる社会翻訳として分離して扱う。

## 中心命題
健康情報が十分に存在しても、行動は自動的には続かない。意志力と自己管理だけに依存すると、日常摩擦によって反復が止まりやすい。そこで、始めるきっかけと続ける理由を分け、報酬、ゲーム性、コミュニティ、更新を異なる役割として接続することで、行動発生と継続の条件を再設計する。

親原典が読む順序は、`健康だから努力する → 続ける` ではなく、`楽しいから参加する → 続けたくなる → 行動が反復される → 習慣へ近づく → 健康価値が結果として残りうる` である。この順序変更が構造の中心である。

```text
↓

↓

```

## 構造層
1. **対象事実層**: HEALTHREE、ヘルスケアゲーム、歩行・運動、報酬、Web3、法人展開等の公開材料。
2. **知識充足層**: 健康情報そのものは既に広く流通している。
3. **日常摩擦層**: 面倒、飽き、忙しさ、忘却、孤立、成果の遠さが行動を止める。
4. **入口設計層**: 楽しさ、参加、報酬によって最初の行動を起こしやすくする。
5. **継続設計層**: ゲーム性を、続けたくなる反復装置として置く。
6. **関係性層**: コミュニティで行動を孤立させない。
7. **更新層**: 運営型更新で飽きと固定化へ対抗する。
8. **反復層**: 行動が単発ではなく繰り返される。
9. **習慣層**: 反復が生活リズムへ近づく。
10. **結果価値層**: 健康価値を唯一の開始理由ではなく、反復の先に残りうる結果として置く。
11. **社会翻訳層**: 技術語・成長指標より、生活者の継続摩擦を理解可能な言葉へ変換する。
12. **適用境界層**: 医療効果保証や他領域への無条件一般化を避ける。
13. **反証層**: 役割束が反復を説明しない場合に構造仮説を修正する。

## 適用例
**1. 個人向け健康行動。** 歩数や運動量を記録するだけでなく、参加・反復・継続がどう生まれるかを見る。

**2. 企業ウェルビーイング。** 健康情報を配布するだけではなく、従業員が日常で行動へ参加する条件を設計する。

**3. 教育や学習。** 「大切だから続ける」だけでは反復しにくい領域で、入口・継続・関係性・更新を分けて考える。ただし健康領域の成功をそのまま移植しない。

**4. サービス設計。** 報酬を万能装置とせず、開始トリガー、継続装置、関係性、更新の役割を分離して設計する。

**5. 社会翻訳。** 技術・資金調達・実績を列挙するより、生活者が経験する「分かっていても続かない」問題から価値を説明する。

## 測定・監査点
- 行動参加への入口が実際に利用されているか。
- 報酬が開始トリガーとして機能し、価値全体を飲み込んでいないか。
- ゲーム性が単なる娯楽ではなく、現実行動の反復へ接続しているか。
- コミュニティが孤立を減らし、負担や競争圧力を過度に高めていないか。
- 更新が飽きへの対抗として機能しているか。
- 単発参加ではなく反復が生じているか。
- 行動反復と健康価値の接続を、医学的効果保証へ強度変更していないか。
- Web3や報酬経済への関心だけで行動が説明されていないか。

## 成立条件
- 楽しさや参加感が行動入口を作る。
- 報酬が開始を促すが、短期的な報酬依存だけに縮まない。
- ゲーム性が反復を支える。
- コミュニティや関係性が行動の孤立を減らす。
- 運営型更新が飽きへの対抗として機能する。
- 行動反復が習慣形成へ近づく。
- 健康価値との接続を保持しつつ、医学的効果保証を行わない。

## 失敗条件
- 報酬だけが中心となり、報酬が弱まると行動も止まる。
- ゲーム性だけが残り、現実の健康行動との接続が切れる。
- 健康訴求が強すぎて努力型自己管理へ戻る。
- Web3や投機性が生活者体験を覆う。
- コミュニティが過剰比較や負担へ反転する。
- 更新が継続条件として機能しない。
- 行動反復が観測できない。

## 反証・改訂条件
楽しさ、報酬、ゲーム性、関係性、更新を束ねても継続的な行動反復が生じない、報酬依存が強く自律的な継続へ移らない、現実行動との接続が弱い、より単純な機能説明の方が継続的に高い説明力を持つ場合は、行動設計という構造仮説を縮小・修正する。

## 必須の区別

- 行動反復 / 健康結果保証

本派生物はHEALTHREEの医学的健康効果、法人導入効果、事業成長を保証しない。「行動設計」「健康価値が結果として残りうる」という配置はNakagawa Masterの構造読解であり、HEALTHREE自身の公式企業定義へ置換しない。報酬・ゲーム・Web3を単独の因果へ縮約しない。他領域へ参照する場合も、各領域の摩擦・反復・関係性・更新条件を再確認する。
