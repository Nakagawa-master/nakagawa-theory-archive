## 摘要
原典把销售实务整理为三个观察：当前状态、决策阻力、希望到达的未来；以及两个编辑：从当前到未来的连续性、以及路径适合性的必然性。目标是通过理解形成诚实的价值交换，而不是用压力促成决定。

## 因果模型
```text
当前状态
-> 表面/潜在需求分离
-> 阻力映射
-> 希望的未来
-> 连续性编辑
-> 适合性确认
-> 方案匹配
-> 客户理解
-> 价值交换
```

## 区分
潜在需求≠制造问题；必然性≠操纵；满足≠服从；价值交换≠仅仅成交。

## 成立与失败
成立需要验证假设、明确阻力、连续的未来路径、自主选择与成交后的价值实现。隐藏选项、施压或只看成交会使结构失效。

## 返回原典
三个观察、两个编辑与销售框架的精确定义，以Parent正文为正本。
