## 位置づけ
本派生物は、中川式営業の共通骨格を「満たす／問い／価値交換」の三レンズで整理する。営業は相手を動かすことではなく、相手自身もまだ言語化できていない未充足を観測し、現在地から望む未来への道筋を編集して、誠実な価値交換を成立させる営みである。

## 中心命題
「売るのではなく満たす」は、要望へ無条件に従う意味ではない。現在地、阻害要因、欲求の形を観測し、連続性と必然性を編集することで、相手が価値の接続を自分で理解できる状態をつくる。

## 因果線
```text
相手の現在地を観測
→ 言語化された課題と潜在的未充足を分離
→ 意思決定の阻害要因を可視化
→ 語りたい未来像を把握
→ 現在地から未来への連続性を編集
→ なぜその経路が適合するかの必然性を確認
→ 商品・支援が未充足を満たすか検証
→ 相手自身が価値を認識
→ 正当な価値交換が成立
```

## 三つの観察
1. **現在地**: 表明課題と、沈黙・戸惑い等に現れる未充足を分ける。
2. **阻害要因**: 稟議、負荷、リスク知覚、優先順位など意思決定摩擦を具体化する。
3. **欲求の形**: 単一成果ではなく、相手が実現後にどうありたいかを把握する。

## 二つの編集
- **連続性**: 現在→変化→未来を飛躍なくつなぐ。
- **必然性**: 他の選択肢との比較を通じ、なぜこの経路が適合するかを明示する。

## 状態モデル
```yaml
- present_state_observed
- stated_and_latent_need_separated
- decision_friction_named
- desired_future_articulated
- continuity_path_built
- necessity_hypothesis_checked
- offering_fit_verified
- customer_understanding_formed
- value_exchange_established
```

## 適用例
- 導入が進まない案件で、価格・工数・稟議・リスク・目的不一致を分解する。
- 顧客の「便利にしたい」を、どの作業・誰の負荷・何の判断が変われば満たされるかまで具体化する。
- 選択肢を消すためでなく、各選択肢の成立条件を並べて適合性を比較する。

## 測定・監査点
- 未充足仮説を本人へ確認したか。
- 阻害要因が具体化されているか。
- 現在→未来の途中条件が抜けていないか。
- 必然性が圧力や選択肢隠しになっていないか。
- 契約後に実際の未充足が満たされたか。

## 成立条件
観測、仮説確認、摩擦の具体化、未来像、連続性、適合性、自己決定、価値実現が追跡できること。

## 失敗条件
沈黙を勝手にニーズ認定する、選択肢を意図的に隠す、必然性を心理操作へ変える、価値未実現でも成約だけを成功とする。

## 反証・改訂条件
三観察・二編集を用いても意思決定品質や価値実現が改善せず、誤認・摩擦・解約が増える場合は観察項目と編集手順を改訂する。

## 必須の区別
- 満たす ≠ 従属
- 潜在ニーズ ≠ 営業側の創作
- 必然性 ≠ 選択肢の排除
- 決断 ≠ 操作の成果
- 価値交換 ≠ 成約そのもの

## 原典回帰
「満たす／問い／価値交換」、三つの観察、二つの編集、決断＝理解の完成という位置づけはParent本文を正本とする。
