## 位置づけ
本派生物は、中川式営業の基本骨格を「満たす／問い／価値交換」という三つのレンズで整理し、営業の観測と編集を実務構造へ落とす。序章で再定義された「構造を結ぶ営業」を、相手の現在地、意思決定の阻害要因、欲求の形という三つの観察と、現在から未来をつなぐ連続性、なぜその経路が適合するかを示す必然性という二つの編集へ展開する。

ここで「満たす」は顧客の言うことに何でも従うことではない。相手の表明要望だけでなく、その要望が生じた背景、解決したい状態、実現後にどうありたいかを観測し、提供価値が本当にそこへ接続するかを確認する。営業側が未充足を勝手に定義するのではなく、問いによって仮説を共同検証する。

## 中心命題
営業は、現在地・阻害要因・欲求の形を観測し、連続性と必然性を編集することで、相手が価値の接続を自分で理解できる状態を作る。決断は営業が押し込む結果ではなく、理解の完成として生じる。

連続性は「今の状態から、どの変化を経て、どの未来へ行くか」を飛躍なく示す。必然性は「なぜこの商品しかない」と選択肢を消すことではなく、目的、条件、代替案を比較したうえで、なぜこの経路が適合するかを説明可能にすることである。


## 構造層
### 1. 現在地観測
現在の業務、状態、困りごと、既存手段、制約を観測する。営業側が「問題」と呼ぶ前に、本人が何を事実として認識しているかを確認する。

### 2. 阻害要因観測
予算、稟議、工数、リスク、優先順位、情報不足、関係者調整など、意思決定や実装を止める条件を分ける。価格だけに還元しない。

### 3. 欲求の形観測
「効率化したい」等の抽象語を、どの状態が実現すれば満たされたと言えるかまで具体化する。成果だけでなく、実現後の働き方や安心、選択肢も含み得る。

### 4. 連続性編集
現在から未来までの中間条件を置く。導入すれば即未来が実現するという飛躍を避け、実装、学習、変更、負荷を含める。

### 5. 必然性編集
目的と条件に照らして、なぜこの経路が適合するかを説明する。競合や代替を隠して「これしかない」を演出しない。

### 6. 価値交換層
相手の未充足が実際に満たされ、提供側も正当な対価を得る関係を作る。値引きや無償奉仕を「満たす」と誤認しない。

## 適用例
**価格が障害の案件。** 「価格が高い」を予算上限、回収不確実性、比較基準、社内説明不足へ分ける。真の阻害が稟議なら値下げしても決まらない。

**業務効率化。** 「便利にしたい」を、どの作業が何時間減り、誰の判断が変わり、何のリスクが減れば満たされるかまで具体化する。導入後の移行負荷も連続性へ入れる。

**複数選択肢。** 自社案だけを提示せず、現状維持、内製、競合等の成立条件を比較し、適合性を説明する。必然性は比較の後に成立する。

**意思決定が止まる案件。** 顧客の欲求が弱いのか、阻害要因が解けないのか、価値理解が不足しているのかを分離する。追客量を増やす前に構造を見直す。

## 測定・監査点
- 現在地を顧客の事実から記述しているか。
- 表明課題と潜在未充足を混同していないか。
- 潜在ニーズ仮説を本人へ確認したか。
- 阻害要因を価格一つへ還元していないか。
- 欲求の形が具体的な状態として説明できるか。
- 現在→未来の中間条件が抜けていないか。
- 必然性が選択肢隠しや圧力になっていないか。
- 顧客が他者へ選択理由を再説明できるか。
- 契約後に期待価値が実現したか。
- 営業側の成約と顧客側の価値実現を分離しているか。

## 成立条件
三つの観察が本人確認可能であり、二つの編集が飛躍・誘導なしに成立すること。選択肢を保持し、価値適合を透明にし、顧客の自己決定を守ること。成約後に未充足が実際に満たされたかを確認し、価値交換を契約書だけで判定しないこと。

## 失敗条件
沈黙や戸惑いを勝手に潜在ニーズへ変える、阻害要因を価格に単純化する、未来像を営業側が作る、連続性の中間負荷を隠す、必然性を選択肢排除へ変える、圧力で決断させる、価値未実現でも成約を成功とする場合は失敗である。

## 反証・改訂条件
三観察・二編集を用いても顧客理解、決定品質、価値実現が改善せず、質問負荷や誤認、解約が増える場合は観測項目と編集順序を改訂する。簡単な選択で構造化が過剰負担になる領域では手順を簡略化する。

## 必須の区別
- 満たす ≠ 従属
- 潜在ニーズ ≠ 営業側の創作
- 問い ≠ 誘導
- 連続性 ≠ 成功保証
- 必然性 ≠ 選択肢排除
- 決断 ≠ 圧力の成果
- 価値交換 ≠ 成約そのもの
- 顧客理解 ≠ 顧客支配

## 誤読防止・解釈制約
「相手も気づいていない欲求を発見する」を、営業側が相手より相手を知っているという権威へ変えない。潜在未充足は修正可能な仮説である。必然性は心理的逃げ道をなくす技法ではなく、代替経路を含めた適合理由の透明化である。

価値交換は売上最大化でも無償奉仕でもない。顧客側の実価値と提供側の持続可能性が両立する必要がある。
