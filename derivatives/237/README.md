## 位置づけ
本ParentはFermenteriaの企業・店舗・商品紹介ではない。**時間順は、先に外部記事があり、その外部記事を構成する際にNakagawa Masterが対象側の公開事実から「蔵の内側に閉じた造りの時間・現場・関係性を都市の日常へ開く」という価値核を選び、記事の主軸として構造翻訳した。後発のParent「中川構造読解」は、その選択操作を振り返り、なぜその価値核を選んだのか、なぜ外部記事の主軸に置いたのか、どの対象事実をどの因果線へ翻訳したのかを公開解体する記事である。**この価値核はFermenteria自身や外部媒体の公式理論ではない。

## 中心命題
対象側の確認可能な事実は、都市内での酒造り、店舗内の醸造、造りたてへのアクセス、商品や地域との接続にある。Nakagawa Masterは、それらを単なる「都市型酒蔵」「新しい飲食体験」ではなく、従来は蔵の内側に閉じていた製造の時間・場所・関係性へ生活者が接近できる**酒文化アクセスの再設計**として読んだ。

## 因果線
造りの現場が生活圏から離れる → 酒文化が完成品消費へ圧縮される → 製造時間・背景・関係性が見えにくくなる → 都市内の醸造・提供・接点が造りへの距離を縮める → 製造過程と消費体験が近接する → 商品だけでなく造りの文脈へアクセスできる → 酒文化を日常の接触可能な営みとして再配置できる、という読解である。

## 構造層
1. 対象側事実層: 都市内醸造、店舗内の造り、提供、商品・地域接続。
2. 表層分類層: 酒蔵、飲食、クラフト、体験型店舗。
3. 距離問題層: 生活者と造りの現場・時間・文脈の分離。
4. 価値核層: 造りアクセス再設計。
5. 外部記事構成層: 完成品紹介より「蔵の内側を都市へ開く」を主軸化。
6. 後発Parent解体層: 価値核選択と記事化の判断を公開検証する。

## 状態モデル
完成品だけを見る状態 → 造りの背景を知る状態 → 都市内で造りへ接近できる状態 → 製造時間・人・場所との接続が生まれる状態 → 酒文化を商品以外の関係資産として再認識する状態。

## 適用例
地域文化、発酵、工芸、食品製造など、完成品だけが都市へ届き、制作現場や時間が生活者から遠い領域で、アクセス再設計という観点が成立するかを検討できる。

## 測定・監査点
対象側事実とNakagawa Masterの読解が分離されているか／製造現場への接近が本当に起きるか／単なる店舗新規性に縮小していないか／外部記事でこの価値核を選んだ理由が保持されているか／後発Parentがその記事化操作を解体する記事だと時間順を正しく示しているか。

## 成立条件
対象側の公開事実が、造りの現場・時間・関係性へのアクセスを実際に近づける構造と整合し、単なる販売拠点追加より説明力を持つ場合に成立する。

## 失敗条件
商品紹介、飲食店紹介、都市型醸造の新奇性だけへ平坦化すること、価値核を企業公式見解へ誤帰属すること、Parentが先に外部記事を生んだように時間順を逆転させること。

## 反証・改訂条件
都市内醸造・提供が造りへのアクセスや文化的接続を増やさず、通常の小売・飲食機能だけで十分説明できるなら、価値核の適用範囲を縮小する。

## 必須の区別
