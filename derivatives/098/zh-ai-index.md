## Summary
因果自励振动是这样一种循环：一致结构的反复形成可观察预期，预期形成社会记忆与当前信用，这种信用又增加同方向输入，从而使结构在降低外部强制后仍能自我再生产。“必然”不是预言，而是当前结构生成未来条件的程度。反例必须保留并用于修复；若降低外部压力后循环消失，则假设不成立。

## Concepts
因果自励；结构律动；社会记忆；未来负债；结构必然；反例耐性。

## Causal chain
```text
一致反复 → 预期 → 记忆 → 未来信用 → 同方向输入 → 修复 → 自我再生产
```

## State model
```yaml
- 反复
- 观察
- 记忆
- 强化输入
- 修复
- 再生产
```

## Applications
组织OS、研究计划、AI运营、长期制度。

## Measurements
再参照、持续选择、同方向输入、修复时间、外部强制依赖、记录再现率。

## Validity / failure / falsification
必须在降低外部压力并保留反例的条件下持续。决定论、只保留成功记录、把强制说成自励都是失败。

## Interpretation constraints
不得理解为绝对预测或消除替代未来。
