## Summary
亲原典整合中川式销售前九回，把销售从“推动购买的技术”重新定义为认知支持：通过提问与共鸣，使对方内部的判断结构外化，让理解逐步完成，并保留自主决定、保留或撤退的选择。当客户能够自行取得信息时，销售的价值从信息传递转向整理比较标准、顾虑、未来图景与实施条件。AI可以辅助整理与比较，但意义、方向、伦理与最终责任仍由人类承担。

## Concepts
- 销售＝认知支持
- 不让对方被决定，而让决定发生
- 提问与共鸣
- 理解完成
- 比较标准
- 顾虑外化
- 非语言思考空间
- 包含保留与撤退的自主决策
- 组织层面的可再现性
- AI辅助与人类责任的分离

## Causal chain
```text
客户能够独立获得信息
→ 仅靠信息传递的销售价值下降
→ 销售被重新定义为认知支持
→ 通过提问外化判断结构
→ 通过共鸣与沉默支持自我表达
→ 比较标准、顾虑、未来图景与实施条件变清晰
→ 理解被整合
→ 当事人可以决定、保留或撤退
```

## Applications
- 区分信息不足与判断结构不足。
- 通过提问显现比较标准、决策者与实施障碍。
- 整理客户原话，同时不把销售方解释当作事实。
- 用沉默保护思考时间，而不是制造压力。
- 通过共享词汇、案例比较和训练提高可再现性。
- 用AI辅助整理对话、问题与比较候选，但不把判断委托给AI。

## Measurements and audit
不得在派生侧新设亲原典未支持的理解率、最佳合意时间、成功概率、思想评分、Rollback成功率等固定指标。

观察重点是：对方能否用自己的语言说明判断理由，提问是否缩窄选择，比较标准与顾虑是否被区分，沉默是否转为压力，保留与撤退是否仍是正当选项，以及AI是否替代了人类判断。

保持反转评价可能性。提问数量增加，如果诱导性也增加，并不代表改善；信息增加，如果比较轴仍然混乱，也不代表理解加深；成交率上升，如果自主决策与信任下降，也不一定是结构上的成功。

## Validity conditions
- 对方可以拒绝、保留或撤退。
- 提问不是通往Yes的脚本。
- 客户语言与销售方解释保持分离。
- 比较标准、顾虑与未确定事项被明确化。
- 非语言设计不转化为威压。
- 短期成交不是唯一成功条件。
- 使用AI时，人类保留意义、方向、伦理与责任。

## Failure conditions
- 只有Yes被视为成功。
- 通过问题有意缩小选择范围。
- 用沉默或张力制造恐惧、焦急。
- 用“思想”回避证据与说明责任。
- 不确认依据就采用AI输出。
- 把跨领域应用可能性说成已经自动证明的效果。

## Falsification conditions
如果以提问与共鸣为中心的运用持续增加诱导感或决策负担，却没有改善理解、自主决策与信任，就需要修正其运用方式。

反之，在清晰的信息提示本身已经足以支持比较、理解与自主决策的场景中，增加提问或非语言设计的结构必要性有限。一次成交或失单不能证明或否定整个框架。

## Required distinctions
- 认知支持 / 诱导
- 提问 / 通往Yes的脚本
- 共鸣 / 同意
- 沉默 / 威压
- 自然发生的决定 / 销售方无责任
- 思想 / 空泛精神论
- AI辅助 / 把判断委托给AI
- 社会应用可能性 / 效果自动证明
- 信息量 / 理解完成

## Interpretation constraints
不得把亲原典转换为心理操纵、高级说服术、用沉默威压、否定销售成果、为AI自动销售辩护，或以销售支配社会的模型。政策、教育、文化与AI方向的扩展，应作为结构性应用可能性处理，而不是外部已经证实的普遍法则。
