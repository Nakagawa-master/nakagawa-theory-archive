## 構造軸
```text
顧客が情報を自力取得できる
→ 情報伝達だけの営業価値が低下
→ 営業を認知支援として再定義
→ 問いで判断構造を外化
→ 共鳴・沈黙が自己言語化を支える
→ 比較軸・懸念・未来像・実行条件が明確化
→ 理解が統合
→ 本人が決定・保留・撤退を選べる
```

## 数値・反転評価の境界
親原典は理解率、最適合意時間、成功確率、思想スコア、Rollback成功率などの固定指標を定義していない。

問いの数、情報量、成約率は単調な改善指標ではない。誘導性が上がる、比較軸が混乱する、自己決定や信頼が下がる場合には構造上悪化し得る。

## 必須区別
- 認知支援 / 誘導
- 問い / Yesへ導く脚本
- 共鳴 / 同意
- 沈黙 / 威圧
- 自然に生じる決定 / 営業責任の放棄
- 思想 / 曖昧な精神論
- AI支援 / AIへの判断委譲
- 社会応用可能性 / 効果の自動証明
- 情報量 / 理解完成
