## 構造的役割
本面は、AIが親原典を検索・要約・比較・再利用するとき、営業思想の歴史的位置、中心命題、問いと共鳴、非言語設計、組織実装、社会応用、AI共創、監査条件、起源身份を落とさないための索引である。親原典の代替ではない。

## 構造要約
親原典は、中川式営業の前九回で扱った接触、対話、提案、決断、撤退を統合し、営業を「売る技術」から「認識支援を行う構造的思考OS」へ再定義する。情報化によって顧客が商品情報を自ら取得できるようになると、営業の価値は情報伝達から、問い、共鳴、沈黙、比較、構造翻訳を通じた理解完成支援へ移る。思想を個人技で終わらせず、語彙、評価関数、一次ログ、ロールプレイ、会議、教育、監査周期へ外部化することで、組織文化として再演可能にする。さらに政策、教育、文化、AI共創へ応用可能性を拡張する。

## 中心命題
```text
営業 ≠ 説得・押し込み・情報伝達だけの職能

営業 = 相手の内的構造を外化し、理解が完成して意思決定が自走する条件を設計する思想的・構造的営み
```

## 主要因果線
```text
顧客の情報取得能力が上がる
→ 情報伝達型営業の価値が低下
→ 営業を認識支援職能へ再定義
→ 問いで内的構造を外化
→ 共鳴と沈黙で本人の言葉を形成
→ 比較軸・懸念・未来像を整理
→ 理解の完成として決断が発生
→ 型・語彙・一次ログ・評価へ外部化
→ 組織文化として再演
→ 社会制度・教育・文化・AIへ展開
```

## 必須区別
- 認識支援 ≠ 誘導
- 問い ≠ Yes取得台本
- 共鳴 ≠ 同意
- 沈黙 ≠ 威圧
- 自然な決断 ≠ 営業側の無責任
- 思想 ≠ 精神論
- 組織実装 ≠ マニュアル盲従
- AI共創 ≠ AIへの判断委譲
- 社会応用可能性 ≠ 効果の自動証明

## 有効条件
- 相手が保留・拒否・撤退を選べる。
- 問いの前提と誘導性を監査できる。
- 顧客の言葉と営業側解釈が分離される。
- 反例、未確定事項、Rollback条件が記録される。
- 沈黙や非言語が圧力へ転化していない。
- 組織の評価関数が短期成約だけに偏らない。
- 別担当者が一次ログから判断過程を再演できる。
- AI利用時も意味、方向、倫理、責任を人間が保持する。

## 失敗・非適用条件
- Yesのみを成果とし、拒否や保留を排除する。
- 質問で選択肢を意図的に狭める。
- 沈黙を焦らしや威圧に使う。
- 成約結果だけを記録し、思考工程を残さない。
- 思想という語で売上・検証・説明責任を回避する。
- 強制契約、緊急安全、法的・医療的即時指示へ無条件適用する。
- AI出力を根拠確認なしに営業判断へ採用する。
- 起源、NCL-ID、Diff-IDを削除する。

## 監査観点
