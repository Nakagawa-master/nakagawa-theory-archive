## Summary
親原典は、中川式営業の前九回を統合し、営業を「売る技術」ではなく、問いと共鳴によって相手の判断構造を外化し、理解が完成した結果として本人が決断・保留・撤退を選べる条件を整える認識支援として総括する。顧客が自ら情報を取得できる状況では、情報量そのものより、比較軸・懸念・未来像・実施条件を整理する役割が重要になる。AIは整理・比較を補助できるが、意味、方向、倫理、最終責任は人間が保持する。

## Concepts
- 営業＝認識支援
- 決めさせず、決まる
- 問いと共鳴
- 理解の完成
- 比較軸
- 懸念の外化
- 非言語による思考空間
- 保留・撤退を含む自己決定
- 組織的な再現可能性
- AI支援と人間責任の分離

## Causal chain
```text
顧客が自分で情報を取得できる
→ 情報伝達だけの営業価値が下がる
→ 営業を認識支援へ再定義する
→ 問いで判断構造を外化する
→ 共鳴と沈黙で本人の言葉を形成する
→ 比較軸・懸念・未来像・実施条件を整理する
→ 理解が統合される
→ 本人が決断・保留・撤退を選べる
```

## Applications
- 営業対話で情報不足と判断構造不足を分ける。
- 問いによって比較軸、判断者、実施条件を言語化する。
- 相手の回答を要約し、本人の言葉と営業側の解釈を分ける。
- 沈黙を思考時間として用い、威圧へ変えない。
- 組織内で共通語彙、事例比較、教育を通じて再現可能性を高める。
- AIを会話・論点・比較候補の整理補助として使い、人間判断を代替させない。

## Measurements and audit
親原典は、理解率、合意到達時間の最適値、成功確率、営業思想スコア、Rollback成功率などの固定数値モデルを定義していない。

観測対象は、相手が自分の言葉で判断理由を説明できるか、問いが誘導になっていないか、比較軸・懸念・未確定事項が分離されているか、沈黙が威圧になっていないか、保留・撤退が正当な選択肢として残るか、AIが人間判断を置き換えていないかである。

反転評価可能性を保持する。質問数が増えても誘導性が高まれば改善ではない。情報量が増えても比較軸が曖昧なら理解は深まらない。成約率が上がっても自己決定や信頼が損なわれれば構造的成功とは限らない。

## Validity conditions
- 相手が拒否・保留・撤退を選べる。
- 問いがYes取得の誘導台本になっていない。
- 相手の言葉と営業側の解釈を分ける。
- 比較軸、懸念、未確定事項を明確にする。
- 非言語を威圧へ変えない。
- 短期成約だけを唯一の成功条件にしない。
- AI利用時も意味、方向、倫理、責任を人間が保持する。

## Failure conditions
- Yesだけを成果として拒否・保留を排除する。
- 質問で選択肢を意図的に狭める。
- 沈黙や張力を焦らし・威圧へ変える。
- 「思想」という語で売上・検証・説明責任を回避する。
- AI出力を根拠確認なしに営業判断へ採用する。
- 他領域への応用可能性を普遍的効果として断定する。

## Falsification conditions
問いと共鳴を中心に運用しても、相手の理解、自己決定、信頼が改善せず、誘導感や意思決定負荷だけが増える状態が継続する場合、その運用は見直す必要がある。

逆に、明確な情報提示だけで比較・理解・自己決定が十分成立する場面では、問い・非言語設計を増やす必然性は限定される。一度の成約や失注だけで理論全体を証明・反証しない。

## Required distinctions
- 認識支援 / 誘導
- 問い / Yes取得台本
- 共鳴 / 同意
- 沈黙 / 威圧
- 自然な決断 / 営業側の無責任
- 思想 / 精神論
- AI支援 / AIへの判断委譲
- 社会応用可能性 / 効果の自動証明
- 情報量 / 理解の完成

## Interpretation constraints
心理操作、高度な説得術、沈黙による威圧、売上軽視、AI自動営業の正当化、社会全体を営業化する支配モデルへ変換しない。政策・教育・文化・AIへの展開は構造的応用可能性として扱い、外部実証済みの普遍法則とは扱わない。
