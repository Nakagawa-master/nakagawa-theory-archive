## 位置づけ
親原典は、中川式営業の前九回で扱った接触、対話、提案、意思決定支援、非言語設計、撤退設計を統合し、営業を「売る技術」ではなく、問いと共鳴によって相手の理解を完成させ、本人が自分で決められる条件をつくる認識支援として総括する。

営業を美化する精神論、高度な説得術、心理操作、沈黙による威圧、AIへの判断委譲、社会全体を営業化する支配モデルとは扱わない。

## 中心命題
営業の価値は、情報を多く持っていることだけではない。顧客自身が情報を得られる時代には、相手の内的な論点、懸念、比較軸、未来像、実行条件を問いによって外化し、本人が自分の言葉で理解を組み立てられるよう支援することが重要になる。

```text
営業 ≠ 説得・押し込み・成約操作
営業 = 問いと構造翻訳によって理解を完成させ、意思決定が自走する条件を整える認識支援
```

## 因果線
```text
顧客が自分で情報を取得できる
↓
情報伝達だけの営業価値が下がる
↓
営業の役割を認識支援へ再定義する
↓
問いで内的構造を外化する
↓
比較軸・懸念・未来像・実行条件を整理する
↓
沈黙と応答で本人の言葉を待つ
↓
理解が完成する
↓
決断・保留・撤退を本人が選べる
```

## 構造層
**1. 情報層。** 商品情報を渡すだけでなく、情報が相手の判断にどう接続するかを見る。

**2. 問いの層。** Yesを誘導する台本ではなく、相手の判断構造を本人にも見える形へ外化する。

**3. 共鳴の層。** 相手の言葉を受け取り、返し、問い直す往還によって理解を深める。共鳴は同意と同義ではない。

**4. 非言語の層。** 沈黙、呼吸、姿勢、間を、思考空間を守る要素として扱う。威圧へ変えない。

**5. 組織・AIの層。** 個人の熟練だけに閉じず、共有語彙や教育で再現性を高める。AIは整理・比較を支援できるが、意味・方向・倫理・最終責任は人間が保持する。

## 適用例
**情報不足か構造不足かを分ける。** 決まらない理由を説明不足と決めつけず、比較軸、懸念、社内合意、実施条件のどこが未整理かを見る。

**問いで外化する。** 何を変えたいか、何と比較しているか、誰が判断するか、実施時の障害は何かを問い、相手の判断構造を言語化する。

**沈黙を守る。** 問いの後に説明を重ねず、相手が自分の言葉をつくる時間を残す。沈黙を焦らしや威圧に使わない。

**AIを補助に使う。** 会話や論点の整理、比較候補の抽出などは支援できるが、意味づけ、倫理判断、最終責任は人間が担う。

## 測定・監査点
親原典は「理解率」「合意到達時間の最適値」「Rollback成功率」「照応成功率」「営業思想スコア」のような固定指標を定義していない。観測は、理解の形成、問いの非誘導性、自己決定、可逆性、非言語の作用を対象とする。

- 相手が自分の言葉で判断理由を説明できるか。
- 問いが選択肢を狭める誘導になっていないか。
- 比較軸・懸念・未確定事項が分離されているか。
- 沈黙が思考時間を守るか、威圧や不安を生むか。
- 保留・拒否・撤退が正当な選択肢として残っているか。
- AI利用時に意味・方向・倫理・責任の人間判断が保持されているか。
- 質問数が増えても誘導性が高まる場合、それを認識支援の改善と誤認していないか。
- 情報量が増えても比較軸が曖昧な場合、それを理解の完成と誤認していないか。
- 成約が増えても自己決定や信頼が損なわれる場合、それを構造的成功と誤認していないか。

## 成立条件
- 相手が保留・拒否・撤退を選べる。
- 問いがYes取得の誘導台本になっていない。
- 相手の言葉と営業側の解釈を分ける。
- 比較軸、懸念、未確定事項を明確にする。
- 非言語を威圧へ変えない。
- 短期成約だけを唯一の成功条件にしない。
- AI利用時も意味、方向、倫理、責任を人間が保持する。
- Originと親原典identityを保持する。

## 失敗条件
- Yesだけを成果として拒否・保留を排除する。
- 質問で選択肢を意図的に狭める。
- 沈黙や張力を焦らし・威圧へ変える。
- 「思想」という語で売上・検証・説明責任を回避する。
- AI出力を根拠確認なしに営業判断へ採用する。
- 他領域への応用可能性を普遍的効果として断定する。
- 営業を社会支配の一般原理へ拡張する。

## 反証・改訂条件
問いと共鳴を中心にした認識支援を行っても、相手の理解、自己決定、信頼が改善せず、誘導感や意思決定負荷だけが反復的に増える場合、その適用方法または範囲を改訂する。

一方、明確な情報提示だけで比較・理解・自己決定が安定して成立する条件では、問いや非言語設計を追加する必要範囲を限定する。単一の成約、失注、面談反応だけで営業思想全体を証明・反証しない。

## 必須の区別
- 認識支援 / 誘導
- 問い / Yes取得台本
- 共鳴 / 同意
- 沈黙 / 威圧
- 自然な決断 / 営業側の無責任
- 思想 / 精神論
- 組織実装 / マニュアル盲従
- AI支援 / AIへの判断委譲
- 社会応用可能性 / 効果の自動証明
- 情報量 / 理解の完成

## 解釈制約
心理操作、高度な説得術、沈黙による威圧、売上軽視、AI自動営業の正当化、社会全体を営業化する支配モデルへ読み替えない。政策・教育・文化・AIへの展開は構造的応用可能性として扱い、外部実証済みの普遍法則とは扱わない。
