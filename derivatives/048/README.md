## この原典が定義するもの

本稿は、中川式営業の第一回から第九回までで扱われた接触、対話、提案、意思決定支援、非言語設計、撤退設計を統合し、営業を「売る技術」ではなく、人間の理解・意思・未来像を結び直す構造的思考OSとして総括する原典である。

```text
情報を渡して説得する営業
↓
顧客自身が情報を取得できる時代への移行
↓
営業の役割を情報伝達から認識支援へ再定義
↓
問い・共鳴・沈黙によって内的構造を外化
↓
理解が完成し、決断が自然発生
↓
型・記録・会議・教育へ埋め込み
↓
組織文化、社会制度、教育、AIへ展開
```

## 中心命題

```text
営業 ≠ 説得・押し込み・成約操作

営業 = 問いと構造翻訳によって相手の理解を完成させ、意思決定が自走する条件を設計する思想的営み
```

## 歴史的位置づけ

古典的弁論術や近代営業は、他者へ働きかける技術として発達した。しかし情報不足を前提とする販売モデルは、顧客が自ら情報を取得できる社会では役割を失う。本稿は、この転換を「押す営業」から「引き出す営業」への移行として捉え、営業を認識支援職能へ置き直す。

## 構造思想としての中川式営業

### 決めさせず、決まる

決断を外部から起こすのではなく、比較軸、懸念、未来像、実行条件が整理され、理解の完成として決断が生じる状態を設計する。

### 問いと共鳴

問いは誘導の道具ではなく、相手の内的構造を映す鏡である。答えを返し、さらに問い直す往還によって、本人が自分の言葉で未来像を形成する。

### 非言語・空気・張力

沈黙、呼吸、姿勢、間は、圧力ではなく思考空間を確保する装置として扱われる。営業は言葉を増やす者ではなく、言葉が生まれる条件を編集する者である。

## 組織への実装

思想は個人の熟練だけでは再現されない。親原典は、ロールプレイ、日報、定例会、語彙辞書、評価関数、一次ログ、監査周期を通じて、問いの文化を組織へ刻む必要を示す。

```text
個人の身体知
→ 型と言語への外部化
→ 一次ログによる観測
→ 会議と教育で比較
→ 反例・撤回・改善
→ 組織文化として再演
```

## 社会・AIへの展開

- 政策・制度: 説得ではなく透明な意思決定条件を整える。
- 教育: 教え込みから、問いと共鳴による学習へ移行する。
- 文化・メディア: 物語編集を通じて未来像を共有する。
- AI: AIが事例とパターンを整理し、人間が意味・方向・責任を与える。

## 成立条件

- 相手の意思決定主体性が保持される。
- 問いが誘導ではなく認識外化として機能する。
- 比較軸、反例、撤回条件が記録される。
- 非言語設計が威圧へ転化しない。
- 組織実装に一次ログと監査周期がある。
- AI活用時も人間が意味・方向・責任を保持する。

## 誤読禁止

この公式派生物を、次として扱わない。

```text
営業を哲学と呼べば何でも正当化できるという宣言
高度な説得術・心理操作の言い換え
沈黙や張力を使った威圧技法
売上指標を不要とする思想論
AIへ営業判断を全面委譲する構想
社会全体を営業化する支配モデル
```
