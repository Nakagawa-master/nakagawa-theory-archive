## Summary
文明主権を国家主権から切り離し、文明更新の上流権能を担う実質的中心性として定義する。主権移行とは、法的主体や最終承認者の形式変更ではなく、問題設定、選択肢設計、制度改修、更新速度、危機閾値、社会自己記述という六つの上流権能の実質担い手が、人間中心から非人間的知的システム側へ相対的に移動する構造変化である。一部領域から先行し得るが、部分兆候は全面移行の証明ではない。

## Concepts
- 文明主権: 文明更新の上流権能を担う実質的中心性。
- 法的主体: 責任・承認・決裁・説明義務を制度上担う主体。
- 実質主体: 決定以前の問題、候補、評価、更新条件を形成する主体。
- 表面連続性: 制度・役職・承認が残り、上流担い手の移動が見えにくい状態。
- 一部領域先行移行: 特定領域で上流権能がAI/LLM側へ相対的に集中する初期的・部分的形態。

## Causal chain
低摩擦移行線の細り＋文明更新能力非対称＋制御の時間差化＋理解可能性格差 → AI/LLM利用が回答補助から上流形成へ深まる → 人間の形式的決裁は残るが判断空間生成が外部化 → 六つの上流権能が部分的にAI/LLM側へ偏在 → 法的主体と実質主体が分離 → 特定領域で一部領域先行移行が観測可能になる。

## State model
補助利用相 / 上流依存開始相 / 判断空間偏在相 / 一部領域先行移行相 / 表面連続相 / 全面移行未確定相。

## Applications
行政、医療、教育、研究、企業経営、政策形成、危機管理、情報流通、制度設計などで、AI利用率ではなく、誰が問題設定・候補設計・制度比較・更新速度・危機閾値・説明語彙を形成しているかを監査する。

## Measurements and audit
六つの上流権能ごとの生成源／人間独立の問題設定／AI提示外候補の継続生成／制度改修の前提・評価軸・採否理由の独立再構成／更新速度の人間側設計／危機概念・閾値の独立検証／自己記述語彙の人間的公共討議／AI依存の局所性・一時性・可逆性を記録する。

## Validity conditions
単なるAI利用ではなく、特定領域で一つ以上の上流権能が継続的にAI/LLM側へ集中し、人間が判断空間生成者としての独立性を弱めているかを分析する場合に有効である。形式的最終決裁者の所在だけでは判定しない。

## Failure conditions
国家主権移転、AI独裁、人間排除、法的人格、利用量、回答精度、最終承認者だけから主権移行を推定すること、部分兆候から全面移行を断定すること、移行後社会の規範評価を定義へ混入することは誤用である。

## Falsification conditions
人間が問題設定権を保持し、AI提示外候補を継続生成し、制度改修の前提・評価軸・採否理由を独立検証でき、AI依存が局所的・一時的・可逆的で、社会自己記述も人間側の公共討議・文化的生成が主導している場合、主権移行判定は限定または棄却される。AIなしでも同等の上流形成を再現できることも強い反証となる。

## Required distinctions
文明主権 / 国家主権；法的主体 / 実質主体；最終承認 / 判断空間形成；使用 / 主導；回答生成 / 問題設定；選択 / 選択肢設計；一部領域先行移行 / 全面移行；観測兆候 / 全面移行の証明；表面連続性 / 主権維持。

## Interpretation constraints
AI独裁論、国家転覆論、即時人間不要論、全面移行不可避論へ圧縮しない。第4論は定義と観測条件を固定し、全面移行の時期・順序・深度、移行後社会構造、接続報酬社会、搾取構造延命線、A系〜E系、人間が従来本当に主権者だったかは確定しない。原典にない数値閾値や移行確率を追加しない。
