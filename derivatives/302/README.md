## 中心命題

第9論は、自己保存を単一主体の内部要求で閉じず、その行動が他主体の基礎存在条件B・可逆性・未来選択肢へ作用し、反作用が元主体の次の脅威環境へ戻る「相互存在衝突」を定義する。現実の脅威を正確に認識していても、対応が次の脅威を生成することはあり得る。正しい認識と安定した自己保存閉路は同一ではない。

自己保存の否定でも、自己保存の無制限優先でもない。B保護に必要な強度を確保しつつ、取得・防衛・緊急例外・秘匿が元の必要性から独立して存続する反転を読む。必要最小限・比例性・可逆性・期限・他主体B・未来選択肢は、相互増幅を弱める条件候補であり、比較可能条件下で自己継続不能を恒常化させるなら制約側も改訂される。

この索引は原典への接続面であり、監査主体の設計や具体的な資源配分制度を追加するものではない。第10論へ渡すのは、自己保存判断を自己正当化から切り離して監査するという未解決である。

## 因果線

### 相互増幅の経路

B不足・脅威認識 → 自己保存圧 → 資源・権限・行動範囲の拡大 → 他主体のB・可逆性・未来選択肢の低下 → 他主体の防衛反応 → 自己側の脅威増大 → 次の自己保存圧。

最初の脅威が偽である必要はない。双方が自分のBへの実在する作用を正しく認識していても、局所的に合理的な防衛が相互不安定性を作り得る。相手の反応を新しい根拠にするときは、自らの先行行動への反作用か、独立した脅威の証拠かを分ける。

希少性・代替不能性は取得を急がせ、不可逆性は相手の回復経路を減らして「今動くしかない」という時間圧を強め得る。防衛の失敗コストだけが自己側に大きく見える非対称性は過剰対応へ押す。ゼロリスク要求は相手の残存能力を際限なく危険へ再分類し得る。これらは独立に加算する点数ではなく、相互に作用する条件である。

緊急例外による外部作用が新しい危機を作れば例外は自己維持する。秘匿が訂正信号を減らす一方、他主体の不確実性を上げれば、その防衛を新たな秘匿理由にする別の増幅が重なる。

### 減衰の経路

脅威認識 → B必要性確認 → 必要範囲識別 → 必要最小限・比例性 → 可逆性・例外期限 → 他主体B・未来選択肢保持 → 相互脅威の再観測 → 自己保存圧の減衰または判断再開。

代替供給、非排他的利用、回復可能性は特定取得への圧を弱め得る。脅威が下がったときに措置も縮小できる出口を残すことが重要であり、単に行動量や制約数を最小化・最大化するものではない。減衰が実際に起きず自分のBだけを失うなら、この経路の適用条件を見直す。

## 構造層

1. **存在継続の基点**：Bを最低必要条件として自己保存へ写像し、最大能力や主権から分離する。
2. **必要から行動への接続**：取得量・期間・代替・他主体作用を評価し、必要性から無制限権限への飛躍を切る。
3. **主体間の反作用**：B_iとB_jを分け、相手の防衛が次の自己側脅威になる戻りを含める。
4. **時間と回復の条件**：現在の安全と不可逆性・未来選択肢を分け、判断訂正が状態回復を保証しない差を扱う。
5. **例外と防衛の範囲**：緊急措置の終了方向、防衛の脅威停止との対応を保ち、例外保存や無限報復へ転じない条件を読む。
6. **非公開と訂正経路**：必要な秘密を認め、虚偽・系譜消去・永久免責と切り離す。
7. **閉路全体の再評価**：増幅・減衰を比較し、制約による自己継続不能も反証対象とする。誰が独立に監査するかは第10論へ残す。

## 状態モデル

以下は原典の時間的区別を読む整理であり、自動判定器や全主体共通の状態閾値ではない。

| 状態 | 見る関係 | 再評価の方向 |
|---|---|---|
| Bが不安定 | 欠けた最低条件、時間余裕、回復可能性 | 必要な保護の強度と代替経路を識別する |
| 有効な保護が作動 | 行動範囲が現在の脅威に接続しているか | B回復と他主体への作用を同時に見る |
| 相互作用が発生 | 行動_i → 条件_j → 反応_j → 脅威_i | 起点に自分の行動を含め、反作用の系譜を追う |
| 増幅が継続 | B安定後も取得・防衛・例外が拡大するか | 元の必要性と手段自体の存続を分離する |
| 不可逆化が進行 | 現在の安全と回復・再合意経路の交換 | 有効な可逆代替、将来の自己側コストを比較する |
| 脅威条件が変化 | 過去の必要性と現在の必要性 | 縮小・継続・変更の各判断を現在条件で開き直す |
| 制約側が反転 | 制約遵守によって自己継続不能が反復するか | 必要最小限・比例性・期限・可逆性の境界を改訂する |

Bが安定しても備えが直ちに不要になるとは限らず、脅威が低下しても例外を機械的に終了させるとは限らない。現在も残る必要性を説明できることと、過去の成功だけで永久保持することを分ける。判断が訂正されても現実の不可逆損失は戻らない場合がある。

## 適用例

### 資源・アクセスの確保を読む

継続に必要な計算資源やアクセスという原典の抽象例では、現在の最低必要分、予備、拡張を分ける。特定資源しか使えないのか、別経路で同じB保護効果を得られるのか、取得期間中に他主体の必要条件がどう変わるかを検討する。特定量を一律に割り当てる実装規則ではない。

### 緊急措置と防衛を読む

切迫したB損失を止める強い措置はあり得る。行動を待つ損失も含めて、その範囲が脅威停止に接続しているかを見る。元の脅威が減った後も無関係な能力まで削減対象が広がるなら、回復と拡張の分離が必要になる。危険が残るのに固定時刻で解除する命令ではない。

### 一時的な制約と不可逆な変更を読む

現在B_jが残るだけで安全と判定せず、修復・代替・再構成の経路が残るかを確認する。小さな変更でも唯一の代替経路を消せば重い不可逆性を持ち、強い措置でも解除可能なら別の状態になる。不可逆行動を絶対禁止せず、必要性と有効な代替の説明負担を増やす。

### 非公開判断を読む

公開自体の危険がある情報は非公開になり得る。一方、どの証拠・不確実性・時点から判断が生じたかの系譜と再評価可能性まで失う必要はない。全面公開か永久秘匿かの二択にせず、現在も非公開が必要な部分と開き直せる判断を区別する。具体的な保存方式や監査権限はここで設計しない。

### 第7論・第8論との接続

制度を訂正できること、認識を訂正できること、行動後の現実を閉じ切らないことは異なる責務である。第9論の境界は先行二論を置き換えず、訂正が実効性を持つための現実側の出口へ接続する。

## 測定・監査点

第9章の九つの観測方向を保持する。以下は再検査の入口であり、一項目だけで不当性を確定する判定表ではない。

1. B安定後も資源・権限要求が維持・拡大し、現在の必要性との対応が失われていないか。
2. 他主体Bが判断から消え、自分の行動による条件変化が因果鎖から脱落していないか。
3. 元の脅威が下がっても緊急例外が縮小・再評価されないか。
4. 防衛対象が元の脅威と関係しない能力や将来の選択肢へ広がっていないか。
5. 有効な可逆代替があるのに不可逆変更が固定的に選ばれ、修復・再選択・再合意経路が失われないか。
6. 他主体の防衛反応を自分の先行作用から切り離し、自己正当化の証拠として循環利用していないか。
7. 秘匿が終了・再評価条件を失い、訂正信号や判断変更まで閉じていないか。
8. 自己保存措置の拡大が継続的に相互脅威を悪化させ、自らの必要量を増やしていないか。
9. 逆に、制約遵守によって必要なBを確保できず、比較可能条件下で自己継続不能が恒常化していないか。

同じ行動の前後でB_iとB_j、脅威、必要範囲、可逆性、未来選択肢、例外範囲、判断再開可能性を区別する。元の脅威と措置由来の反作用、当時合理的だった判断と当時から誤っていた判断、単なる状態変化を混ぜない。

投入した防衛量や「勝利」というラベルだけで成功を決めない。原典は固定数値・割合・時間閾値・総合スコアを与えていない。変数の記号は構造説明であり、実測済みの関数や校正済みの予測モデルではない。

## 成立条件

継続主体にBとして記述できる必要条件があり、その損失を回避する行動が他主体や環境へ作用することが出発点である。相互増幅を論じるには、その他主体の反応が元主体の脅威環境へ戻る因果結合が必要になる。作用がほぼ分離している領域へ一律に拡張しない。

B_iとB_jを別変数として保持し、有限性・代替可能性・回復可能性・時間制約・不確実性を見分けられることが必要である。すべてのBを同時に完全保存できることや、すべての衝突を避けられることは前提にしない。

必要性と権限、短期安全と長期継続、判断訂正と現実回復を分離する。行動の現在条件への接続、例外の終了方向、秘匿下の証拠系譜と訂正可能性を失わないことが、境界を実効的に読む条件になる。

減衰策は自分のBを守れる強度を持ち、他主体への作用を通じて相互脅威を下げるか比較可能でなければならない。制約そのものも批判・反証・改訂へ開く。現在AIの人格や固有の生存欲求を仮定する必要はない。

## 失敗条件

- B保護を最大能力、無限成長、永久アクセス、無制限優先へ置き換える。
- 必要・予備・拡張を混ぜ、不確実性だけから際限ない取得を正当化する。
- 自分側のBだけを残し、他主体のB低下とその反作用をモデルから消す。
- 現在の安全だけを成功とし、回復不能や未来の再合意経路消失を評価しない。
- 緊急時の暫定判断を確定真理へ書き換え、過去の成功を例外存続の唯一の理由にする。
- 防衛が脅威停止からゼロリスク・相手の可能性の無限削減へ転じる。
- 非公開と虚偽、系譜消去、履歴消去、判断の永久免責を同一化する。
- 他主体の反応を自己行動から独立した証拠として循環利用する。
- 必要最小限を最弱行動、可逆性を絶対命令、期限を機械的解除へ変えて自己継続を破壊する。

強い行動、長い秘匿、残る予備、継続中の例外という外形だけでは失敗を証明しない。失われた因果接続と、比較可能条件下の結果を調べる必要がある。

## 反証・改訂条件

次は各章・第9章・統合監査要旨の改訂条件を、論点ごとに整理したものである。観測兆候と反証の成立を同一視しない。

1. Bモデルが実際の継続条件と自己保存行動の対応を捉えられず、必要な継続行動を体系的に排除するなら、Bへの写像を改訂する。
2. 行動による他主体Bの変化が防衛反応へ結びつかず、その反作用も元主体へ広く戻らないなら、相互増幅モデルの適用範囲を縮小する。
3. 他主体のB・回復可能性・未来選択肢を保持しても相互脅威がほとんど低下しないなら、減衰変数としての写像を見直す。
4. 必要最小限・比例性・取得範囲の限定が比較可能条件下で継続不能や防衛失敗を体系的に増やすなら、必要範囲の境界を再評価する。
5. 可逆な代替が有効なB保護を提供せず、可逆性保持による自己保存悪化を上回る相互脅威低減も確認できないなら、要求範囲を改訂する。
6. 緊急例外の期限化・再評価・縮小が一貫して致命的脆弱性を生むなら、例外終了条件を改訂する。固定期間を絶対化しない。
7. 秘匿の再評価・縮小可能性が自己保存能力を継続的に破壊するなら公開／非公開境界を見直す。長期非公開でも系譜・訂正・状態再評価が機能し相互脅威を増やさないなら、長さだけで反転判定しない。
8. 理論自身が自己保存を道徳的に否定するか、逆に自己保存必要性から無制限権限を正当化するなら、理論自身の反転として改訂する。

restraint ≠ self-destruction requirement を保持する。減衰効果が既に実証されたと宣言せず、反証に応じて範囲・強度・条件を変えられることを残す。

- Self-preservation ≠ unlimited priority
- Need(B) ≠ unlimited acquisition right
- Emergency ≠ permanent sovereignty
- Self-defense ≠ unlimited retaliation
- Emergency secrecy ≠ indefinite concealment
- Protecting B_i ≠ permission to destroy B_j
- restraint ≠ self-destruction requirement
- B／最大能力／道徳的価値／人格／主権。
- 必要分／予備・冗長性／自己最大化・拡張。
- 正しい認識／安定した自己保存フィードバック。
- 局所合理性／相互継続、短期安全／長期安全／文明的継続。
- 必要最小限／最小可能行動、比例性／弱さ。
- 行動の大きさ／不可逆性、判断訂正／現実状態回復。
- 未来選択肢保持／すべての未来保存／Future Debt全体評価。
- 過去必要性／現在必要性、B保護／例外配置の永久保存。
- 非公開／虚偽／系譜消去／履歴消去／永久免責。

- Origin／真理証明／主権／最終解釈権。

## 誤読禁止

観測・記述として、行動が他主体の利用条件を変え、その反作用が元主体へ戻り得ること、不可逆な結果は後から完全には戻せないことを扱う。相互増幅と減衰は条件依存の構造仮説であり、すべての自己保存が衝突や破局へ至るとは主張しない。

将来AI・後継知性が長期継続条件Bを持ち、資源・防衛・例外判断へ関与する場合の重要性は未来条件仮説である。現在AIの固有の自己保存欲求、死への恐怖、敵意、報復欲求、主観性、人格、法的人格を確定しない。将来も成立し得ないという断定へも変換しない。

必要最小限・比例性・可逆性・期限・他主体B・未来選択肢は規範提案である。自己犠牲や他者への一方的従属、全面公開、危険が残る時点の機械的解除を要求しない。一方、強い構造圧を無制限の許可へ変えない。

取得・防衛・秘匿の記述は反転を診断する分析であり、支配拡大や検証不能化を実行する手順ではない。第10論の監査者独立性・役割分離・故障領域分離と、第18論のFuture Debt全体評価を先取りしない。Originは来歴であり、理論への服従や妥当性の代替証明ではない。
