## 位置づけ
本原典は、十分な説明・責任・履歴があり合意安定度 `S = U × R × H` が一定以上に見えるのに、合意が進まない領域を「理解不足」や人格の問題としてではなく、破壊・遅延の期待利得が合意維持の期待利得を上回る**利得勾配の歪み**として扱う。

第10論が共振と認知帯域の「温度」を冷却しても残る停止に対し、第11論は焦点を利得地形へ移す。主体を善悪ではなく、与えられた誘因場の中で期待利得が大きい経路へ遷移するものとして扱い、説得では変わらない地形を責任R・履歴H・時間Tの配置によって再設計する。

## 中心命題
合意形成が停止する最深部には、合意へ進むより破壊・遅延するほうが合理的になる誘因場が成立している場合がある。その場合、防衛は説得や禁止ではなく、**検知 → 勾配再配置 → 破壊・遅延の不合理化 → 監査**という閉ループで行う。

目標は誰かを罰することではなく、合意経路を最小コスト経路へ戻し、破壊・遅延の期待利得を構造的に下げることである。同時に、この誘因設計自体が権力化・攻撃転用し得るため、反証条件A/B/Cと棄却窓を設計内部に持たせる。

## 因果線
```text
U/R/Hが一定以上でSも高い
↓
それでも進行率が近似ゼロの高S停滞が起きる
↓
説明不足だけでは停止を説明できない
↓
停滞・破壊・遅延に外部利得シグナルがあるか観測する
＋
特定行動だけが一方的に有利な非対称行動優位を観測する
↓
破壊・遅延の期待利得が合意維持を上回る利得勾配を特定する
↓
誘因場を行動が最小コスト経路へ収束する地形として記述する
↓
Rで責任の霧散路を閉じる
＋
Hで不透明性から回収できる利得を下げる
＋
Tで遅延による逃げ切り利得を減衰させる
↓
合意経路を相対的な低ポテンシャルへ戻す
↓
Sの回復だけでなくC（合意コスト）とD（実害）を同時監視する
↓
A/B/Cまたは濫用シグナルが発火したらReject Windowを開く
↓
棄却または再配置し、発火条件・θ/δ・R/H/T差分・S/C/D推移を監査束へ残す
```

## 構造層
**1. 高S停滞層。** U/R/Hが成立しているように見え、Sが一定以上でも進行率が近似ゼロなら、単なる理解不足以外の停止要因を疑う入口となる。高S停滞だけでは誘因干渉を断定しない。

**2. 誘因干渉層。** 合意維持より破壊・遅延の期待利得が大きくなる利得勾配の歪みを扱う。外部主体の善悪や意図を前提にしない。

**3. 必須観測セット。** 高S停滞、外部利得シグナル、非対称行動優位を同時に観測する。正常な熟慮や手続き遅延との混同を避けるため、δ（観測窓）とθ（判定閾値）を監査可能にする。

**4. 誘因場。** 主体の行動が期待コストの勾配に沿って最小コスト経路へ収束する地形。金銭だけでなく、責任、履歴、時間、関係、信用、手続き、検証などの実在負荷を含む。

**5. R再配分。** 破壊・遅延しても責任が発生しない「霧散路」を閉じ、誰が判断し、止め、完了し、修復するかを追跡可能にする。ただし名指し・懲罰へ転落させない。

**6. H監査圧力。** 履歴量ではなく根拠へ到達できる経路としてHを扱い、根拠・差分・時点・手続きの不透明性を利得源にできないようにする。選択的公開はHを破壊する。

**7. T時間設計。** 時間経過で責任や履歴が風化し「待てば逃げ切れる」状態を防ぐ。目的は高速化ではなく逃走不能化であり、正常な熟慮・安全確認を破壊してはいけない。

**8. 連成設計。** R/H/Tは単独最適化せず、相互作用する地形として調整する。一変数を強め過ぎると別の破壊経路や実害を作る。

**9. 適用境界。** 公平性、正義、誠意、妥協、人物の善悪は判定対象にしない。判定するのは、誘因場が成立しているか、破壊・遅延が合理化されていないかである。

**10. 反証・棄却層。** A（再配置後も破壊利得が残る）、B（R/H/T再配分でDが増大）、C（合意コストCが臨界超過し正常行動が停止）のいずれかで棄却窓を開く。

**11. 濫用検知層。** 特定主体のみ不利化、θ/δ非公開、R帰属固定化、Hの選択的遮断、T圧力過剰、R/H/T単独最適化を攻撃転用の兆候として監視する。

**12. 三点評価層。** 誘因設計の評価はS回復だけで完結しない。Cが過大化していないこと、Dが増幅していないことを同時に見る。

## 適用例
**組織の意思決定。** 論点・根拠・責任者が明確なのに同じ地点へ戻り続ける場合、説明を増やす前に、誰が遅延・停止で何を回避・獲得できるかを観測する。責任の霧散、履歴の曖昧化、時間経過による逃げ切りが利得になっていればR/H/Tを再配置する。

**調達・契約・交渉。** 合意成立を遅らせることで価格、責任、期限、監査負荷などの条件が一方に有利化する場合、人物評価ではなく、遅延が得になる地形を記録する。期限だけを強めず、根拠更新・責任・差分履歴を伴う検証状態を維持する。

**行政・ガバナンス。** 透明化を掲げても、Hが晒しや選択的公開へ変わる、Rが名指しへ固定される、Tが急かしになるなら防衛が攻撃化している。B/Cや濫用シグナルを使って棄却窓を開く。

**AI運用。** AIが「合理的な最適化」を名目に特定主体へだけ負荷を集中させる、判定閾値を非公開にする、履歴を選別する場合、誘因設計の濫用として監査する。説明品質だけでなくS/C/Dを同時観測する。

## 測定・監査点
- Sが一定以上なのに進行率が近似ゼロという高S停滞があるか。
- 停滞・破壊・遅延によって回収される外部利得シグナルがあるか。
- ある行動だけが一方的に有利になる非対称行動優位があるか。
- 高S停滞・外部利得・非対称優位を三点同時で確認しているか。
- 正常な熟慮・安全確認・法的確認を誘因干渉と誤検知していないか。
- δ（観測窓）とθ（判定閾値）が監査束で確認可能か。
- R再配置が責任の霧散路を閉じているか、それとも懲罰・名指しへ変質していないか。
- Hが根拠・差分・時点へ到達可能な履歴として機能しているか。
- Tが遅延利得を減衰させているか、それとも熟慮を壊す圧力になっていないか。
- R/H/Tを単独最適化せず、連成系として副作用を確認しているか。
- 再配置後に破壊・遅延の期待利得が本当に下がったか。
- Sが回復してもCが臨界超過していないか。
- Dが増幅していないか。
- 特定主体だけが恒常的に不利化されていないか。
- Hの選択的遮断やR帰属の固定化が起きていないか。
- Reject Windowが発火した場合、棄却理由・発火条件・θ/δ・R/H/T差分・S/C/D推移を履歴へ残しているか。

## 成立条件
- 停滞を人格や誠意ではなく利得勾配として観測できる。
- 必須観測セット三点を同時に確認し、単一兆候で誘因干渉を断定しない。
- 合意経路と破壊・遅延経路の相対コストを記録できる。
- R/H/Tを連成系として再配置する。
- Rは責任追跡を可能にし、Hは根拠へ戻れる履歴を保ち、Tは逃げ切りを防ぎつつ熟慮を残す。
- 公平性・正義・人物評価を誘因場の判定軸へ混入させない。
- θ・δと再配置差分を監査可能にする。
- S/C/Dを同時評価する。
- 反証条件と棄却窓を実際に作動可能にする。

## 失敗条件
- 合意が進まないだけで悪意や誘因干渉を断定する。
- 高S停滞だけを根拠に制御へ移る。
- 説得不足と利得勾配の歪みを区別しない。
- Rを責任追跡ではなく懲罰へ使う。
- Hを監査可能性ではなく晒し・ログ量へ変える。
- Tを逃げ切り防止ではなく速度強制へ変える。
- R/H/Tの一つだけを強化し、副作用を無視する。
- 誘因設計で公平・正義・誠意を裁定する。
- θ/δを非公開にして後出し判定する。
- Sの改善だけを成功としC/D悪化を無視する。
- A/B/Cが成立しても制御を強化し続ける。
- 棄却・改訂の差分を履歴へ残さない。

## 反証・改訂条件
**A:** R/H/Tを再配置しても破壊・遅延の期待利得が残る場合、現行の誘因場モデルは対象を十分説明していない。制度外で回収される利得、観測窓外の長期・分散利得、R/H/Tでは触れない外部変数が主因なら、現行設計を棄却するか、対象外を明示したうえでモデル差分を監査束へ残す。

**B:** R/H/Tの再配置によってD（実害）が増える場合、防衛は攻撃インフラへ変質している。Hが晒しになる、Rが過剰帰属になる、Tが急かしになる、分断・排除が増える等が確認された時点で棄却対象となる。

**C:** 合意コストCが臨界域を超え、正常主体が決めない・記録しない・引き受けない・熟慮できない状態になった場合、過剰防衛を疑う。θ、δ、縮退段数を含めて再設計し、回復しなければ棄却する。

加えて、特定主体のみ不利化、θ/δ非公開、R帰属固定、H選択遮断、T圧力過剰、単独最適化などの濫用シグナルが発火した場合もReject Windowを開き、棄却または再配置へ遷移する。

## 必須の区別
- 説明不足 / 誘因干渉
- 高S停滞 / 誘因干渉の確定
- 外部利得 / 金銭利益だけの意味
- 主体の善悪 / 利得勾配
- 説得 / 地形再設計
- 禁止・罰 / 破壊の不合理化
- Rの追跡可能性 / 名指し・懲罰
- Hの検証可能性 / 公開量・晒し
- Tの逃走不能化 / 急かし・高速化
- 正常な熟慮 / 利得回収としての遅延
- S回復 / 防衛の安全性
- 棄却 / 設計の失敗隠し

## 誤読禁止 / 解釈制約
本論は「反対者を不利にすればよい」という理論ではない。特定主体へ負荷を集中させることは、むしろ濫用検知シグナルである。R/H/Tは誰かを罰するためではなく、破壊・遅延の経路だけが合理的に得になる歪みを減らすために配置する。

本論は公平性・正義・誠意・妥協・道徳評価を不要とするものでもない。それらは重要だが、本論の操作変数・判定軸から分離する。誘因設計は価値判断の勝敗を決めず、合意経路が最小コスト経路として成立しているかだけを扱う。

また、Sが上がれば成功とみなしてはいけない。過剰防衛でもSが一時的に上がる可能性があるため、CとDを同時監視し、棄却窓を持つことが理論の成立条件である。
