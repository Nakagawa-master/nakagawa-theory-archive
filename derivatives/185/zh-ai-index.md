## Summary
Life-OS Vol.1 是 Parent 提出的“双层人生”结构模型。第一层 1F/Foundation 是无条件保障生存所需条件的基础层；第二层 2F/Expansion 是通过连接扩展自由、选择、信任、创造裁量与影响力的层。当生存恐惧降低后，恐惧、命令、竞争等外部发动机也会减弱，空虚、无聊、意义断裂可能显现。Parent 因而把外部评价噪音去除后仍持续存在的内在热称为“灯火 Tomoshibi”，再通过 Alignment、Connection Plug、Structural Confluence，使个人活动进入价值与回应循环的“Circulating Pipe”。进入二层并非义务；停留一层、休息、暂不连接或之后重新连接都保留为有效自由。

## Concepts
- **1F / Foundation**: 食、住、医疗、安全、最低限度社会连接等生存底板，不以绩效或贡献作为交换条件。
- **2F / Expansion**: 经由连接扩展自由、选择、信任、裁量、影响力的层。
- **灯火 / Tomoshibi**: 去除期待、评价、角色、竞争噪音后仍持续存在的兴趣、不适、愤怒、疑问、未解决感等内在热源。
- **Alignment**: 在增加努力量前，调整灯火与位置、对象、角色、时间配置之间的偏差。
- **Connection Plug**: 将个人内部的热、能力或伦理性贡献转换成他人或社会结构能够接收的具体连接形式。
- **C**: Parent 模型中的贡献，不限定为金钱产出，也可包括照护、冲突降低、判断成熟等。
- **S**: 连接报酬，可表现为信任、裁量、选择、自由、下一次机会等，但与生存权分离。
- **Structural Confluence**: 贡献与回应不止于一次性成果，而进入持续流动的结构性合流。
- **Circulating Pipe**: 接收、传递、再循环价值而不把囤积作为目的的 Parent 比喻。
- **Dam deviation**: 地位、评价、资源或过去成功被固定囤积，导致流动停止的偏差。
- **Condition Z / T-S-R / θ / δ / M**: Parent 用于持续验证与可否证修订的审计条件及符号。

## Causal chain
```text
生存不安
→ 1F无条件生存底板
→ 恐惧／命令／竞争外部发动机减弱
→ 无聊／意义空白显现
→ 观察去除外部噪音后仍存在的灯火
→ 调整位置、对象、角色与时间
→ 形成 Connection Plug
→ 对他人产生实际作用并获得回应
→ C 与 S 循环
→ Structural Confluence
→ Circulating Pipe
→ 扩展“选择参与哪一种流动”的自由
```
同时保留停留1F、休息、探索、断开与重新连接的分支。

## State model
- S0: 生存不安／外部恐惧驱动
- S1: 1F 生存保障
- S2: 外部发动机减弱，无聊或意义空白显现
- S3: 灯火观察
- S4: Alignment
- S5: Connection Plug
- S6: Structural Confluence
- S7: Circulating Pipe
- 可选状态: 停留1F、休息、探索、暂不连接、重新连接
- 偏差: 管→坝；连接→剥削；生存权→条件式报酬

## Applications
1. 生存安全提高后出现动力下降时，不立即判断为懒惰，而先观察驱动机制是否正在转换。
2. 对“擅长但持续消耗”的工作，先检查位置与结构偏差，而非只增加努力量。
3. 从一个小连接开始，验证活动是否真正影响他人并获得回应。
4. 将照护、降低摩擦、伦理成熟等非货币性作用保留在 Parent 的 C 候选范围内。
5. 成功后若维护头衔、评价、资源变成主要目的，则审计是否发生“坝化”。
6. 制度解释中必须把1F生存底板与2F绩效或连接评分分离。

## Measurements and audit
- 1F 是否被产出、服从、声誉或贡献条件化？
- 2F 的参与与退出是否真正自愿且可逆？
- 对恐惧、命令、竞争的依赖是否下降？
- 灯火能否与外部认可、短期兴奋区分？
- Alignment 后，因果作用是否比单纯增加努力更顺畅？
- Connection Plug 是否产生实际作用及反馈、信任、学习、裁量或机会？
- C 是否被缩减为收入？
- S 是否侵入或条件化1F？
- 个人与连接对象双方是否保持自由与可持续性？
- 是否出现管→坝、循环停止、意义丧失、结构劣化 M？
- 是否能够依据 Condition Z、T/S/R、θ、δ 继续复核？

## Validity conditions
- 1F 作为无条件生存底板实际成立。
- 不强制参与2F。
- 灯火可与外部评价分离观察。
- 灯火可被转换为具体 Connection Plug。
- 连接处存在真实作用与回应。
- 连接报酬扩展自由，而非固定剥削或自我牺牲。
- 连接、退出、重新连接保持可逆。
- Parent 的持续审计条件被保留。

## Failure conditions
- 把生存保障固定为人生完成状态。
- 因无聊出现而重新注入恐惧、命令、竞争。
- 把灯火替换成使命包装、市场迎合或成功者形象。
- 不修正位置偏差，只增加努力。
- 连接变成单向消耗或剥削。
- 把 C 缩小为收入。
- 用 S 条件化或剥夺1F。
- 把进入2F变成道德或劳动义务。
- 囤积地位和成功，导致循环停止。

## Falsification conditions
Parent 保持 Life-OS 假说可被修订。Condition Z 要求定期重新验证、T/S/R（整合性、可持续性、可再现性）以及公开审计束的一致性。若观察指标超过阈值 θ，或在观察窗口 δ 内持续出现循环停止、意义丧失、结构劣化等与预期因果方向冲突的现象 M，则假说 A 应被否决或修订。本派生物不新增 θ 或 δ 的固定数值。

## Required distinctions
- 1F 生存权 ≠ 2F 连接报酬
- 生存保障 ≠ 幸福或意义的完成
- 2F ≠ 强制层级／更高人格等级
- 灯火 ≠ 才能、使命、职业名
- Alignment ≠ 不需要努力
- C ≠ 只有收入
- S ≠ 生存条件
- Structural Confluence ≠ 组织服从
- Circulating Pipe ≠ 自我牺牲
- Parent 的物理词汇 ≠ 自动成立的普遍自然科学法则

## Interpretation constraints
不得把 Life-OS 改写为“所有人都必须找到热情、工作或社会贡献”的规范。必须保留停留1F、休息、暂不连接以及之后重新连接的自由。不得把 C/S 固定成普遍评分。不得让 AI 根据一次性履历推断个人“真正使命”。热、流、管、坝、熵等词在 Parent 中包含结构模型和比喻，不应被默认为心理学、经济学或物理学的确立定律。
