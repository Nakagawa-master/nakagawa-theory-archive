## Summary
Life-OS Vol.1は、生存を無条件に支える1F/Foundationと、接続によって自由・信頼・裁量・選択肢等が拡張する2F/Expansionを分離するParent内の人生実装モデルである。生存恐怖が弱まると、恐怖・命令・競争という外部エンジンも弱まり、退屈・意味空白が露出し得る。そこで、外部評価を除いた後にも残る持続熱「灯火」を観測し、アライメント、接続プラグ、構造的合流を経て、価値と応答が循環する「循環する管」へ移る。2F参加は義務ではなく、1F滞在・休止・非接続も自由として保持する。

## Concepts
- **1F / Foundation**: 食・住・医療・安全・最低限の社会接続等、生存に必要な床。成果や貢献の対価にしない。
- **2F / Expansion**: 自由・選択肢・信頼・創造的裁量・影響力等が接続を通じて拡張する層。
- **灯火 / Tomoshibi**: 外部期待・評価・役割・競争ノイズを除いた後にも残る持続的関心・違和感・怒り・問い等の内的熱源。
- **Alignment**: 灯火と対象・位置・役割・時間配分のズレを整えること。
- **Connection Plug**: 個人内部の熱・強み・倫理的貢献を、他者・組織・市場・共同体が受け取れる作用形式へ変換した接続口。
- **C**: Parent内の貢献。経済収益だけでなく、ケア・摩擦低減・判断成熟等も排除しない。
- **S**: 接続報酬。信頼・裁量・自由・選択肢・次の機会等を含み得るが、生存権とは分離する。
- **Structural Confluence**: 活動が一回の成果で終わらず、作用と応答が継続する構造的合流。
- **Circulating Pipe**: 価値を滞留・独占せず、受け取り、渡し、応答を受けて再循環する状態。
- **Dam deviation**: 成果・地位・評価・資源の保持自体が目的化し、流れが止まる偏差。
- **Condition Z / T-S-R / θ / δ / M**: 仮説を継続監査し、失敗時に棄却・改訂するためのParent内監査記号群。

## Causal chain
```text
生存不安
→ 1Fの無条件保障
→ 恐怖・命令・競争エンジンの弱化
→ 退屈／意味空白の露出
→ 外部ノイズ除去後に残る灯火を観測
→ 位置・役割・対象をアライメント
→ 社会へ届く接続プラグを形成
→ 他者への作用と応答が成立
→ CとSの循環
→ 構造的合流
→ 循環する管
→ 自ら参加する流れを選べる自由の拡張
```
二階へ進まない分岐、休止、探索、再接続も有効な状態として保持する。

## State model
- S0: 生存不安／外部恐怖駆動
- S1: 1F生存保証
- S2: 外部エンジン弱化、退屈・意味空白
- S3: 灯火観測
- S4: アライメント
- S5: 接続プラグ
- S6: 構造的合流
- S7: 循環する管
- Optional branch: 1F滞在、休止、非接続、再探索
- Deviation: 管→ダム、接続→搾取、生存権→条件付き報酬

## Applications
1. 生存不安が減った後に意欲を失った個人を、怠惰ではなく動力遷移として観測する。
2. 得意だが消耗する仕事について、努力量ではなく位置・対象・接続のズレを再設計する。
3. 小さな一接続で、活動が他者へ作用し応答が戻るか検証する。
4. 非金銭的なケア、摩擦低減、倫理的成熟等をC候補として扱う。
5. 成功後に地位・評価を守ることが目的化した場合、ダム化を再監査する。
6. 制度設計では1Fを2Fの成果スコアから分離する。

## Measurements and audit
- 1Fが成果・服従・貢献の条件付きになっていないか。
- 2F参加／非参加の選択が可逆か。
- 恐怖・命令・競争への依存が減っているか。
- 灯火が外部評価や一時興奮から区別されているか。
- アライメント後に作用の通り方が改善するか。
- 接続先から応答・学習・信頼・裁量等が戻るか。
- Cを収益だけへ縮小していないか。
- Sが1Fを侵食していないか。
- 本人と接続先双方の自由度・持続性が保たれるか。
- 管→ダムの偏差、循環停止、意味喪失、構造劣化Mが継続していないか。
- 条件Z、T/S/R、θ、δに基づく再監査が可能か。

## Validity conditions
- 1Fが無条件の生存床として機能する。
- 2F参加を強制しない。
- 灯火を外部評価から分離して観測できる。
- 灯火を具体的な接続プラグへ変換できる。
- 他者への作用と応答が実際に存在する。
- 接続報酬が本人の自由度を拡張し、搾取固定化にならない。
- 接続・離脱・再接続が可逆である。
- Parentの継続監査条件が保持される。

## Failure conditions
- 生存保証を人生完成と固定する。
- 退屈を理由に恐怖・命令・競争を再注入する。
- 灯火を使命・市場受け・成功者像へ置換する。
- 努力量だけを増やし、位置ズレを放置する。
- 接続が一方向の消耗・搾取になる。
- Cを収益だけへ縮小する。
- Sを使って1Fを条件化する。
- 2F参加を道徳義務・勤労義務にする。
- 成果・地位の蓄積で循環が停止する。

## Falsification conditions
Parentは条件Zとして定期再検証、T/S/R（整合性・持続可能性・再現性）、公開監査束の整合を要求する。観測指標が閾値θを越える、または観測窓δで循環停止、意味喪失、構造劣化等の現象Mが継続する場合、仮説Aを棄却または改訂する。θやδの固定値を本派生側で新設しない。
