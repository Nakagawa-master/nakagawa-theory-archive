## 位置づけ
本原典は「耐久文明」を感情的な停滞・腐敗・閉塞の呼称ではなく、文明の**運転相**として定義する。合意文明では、理解・責任・履歴が循環し、対立や批判も再調整へ接続する。ところがこの三つが崩れても、制度・行政・市場・インフラ・日常は直ちには停止しない。社会は納得から延命へ運転原理を変え、別の力で持続しうる。

原典が固定する耐久文明の定義は、合意形成が崩壊した後も、恐怖・利益・監視を主機関とし、神話と惰性によって延命される文明形態である。これは再生する文明ではなく、同時に直ちに崩壊する文明でもない。外形を保ちながら自己修復能力を失い、損傷原因へ届かない補修を積み重ね、停止を先送りする「再生なき生存」の相である。

## 中心命題
文明は、理解・責任・履歴という合意形成の中枢循環が崩壊しても、その外形と運転構造が残る限り、ただちに停止しない。その結果、文明は「健全に生きている／崩壊して終わった」という二択では捉えられない中間相へ入る。

耐久文明では、納得が秩序の主駆動ではなくなり、恐怖が従属を、利益が協力を、監視が逸脱抑制を担う。神話はその運転を正当化し、惰性は制度を自動運転化する。社会は動き続けるが、理解・責任・履歴へ戻って損傷原因を修復する能力が弱いため、改革や更新が再生ではなく延命処置へ変わりやすい。

## 因果線
```text
理解・責任・履歴が機能する
→ 言葉・意思決定・過去が相互参照できる
→ 対立や不具合が再調整・修正へ接続する
→ 合意文明として自己修復可能

理解の崩壊 / 責任の蒸発 / 履歴の断線
→ 合意形成の中枢循環が停止
→ しかし制度・行政・市場・インフラ・日常の外形は残る
→ 文明は即時崩壊せず、納得から延命へ運転原理を変更
→ 恐怖が従属を形成
＋ 利益が協力を維持
＋ 監視が逸脱を抑制
→ 神話が運転を正当化
＋ 惰性が制度・習慣を自動運転化
→ 壊れたまま持続する耐久文明が成立
→ 問題は見えても原因修復へ届きにくい
→ 改革・補修・新制度が局所対応化
→ 停止回避はできても自己修復能力は回復しない
→ 再生なき生存が長期化
→ 資源断裂・信用崩壊・人口変化・機能不全等が限界を越えると移行相へ
```

## 構造層
### 1. 合意文明の中枢層
理解は共有意味能力、責任は意思決定主体の追跡可能性、履歴は判断・制度形成の過去への参照可能性を担う。この三つは別々の項目ではなく循環系であり、理解が責任説明を支え、責任が履歴参照を支え、履歴が理解更新と責任追跡を支える。

### 2. 心臓停止層
理解・責任・履歴は同時に失われるとは限らない。時間差で一つずつ崩れることもあるが、相互支援循環が止まると文明は内側から心停止に近い状態へ入る。重要なのは、中枢が止まっても制度の身体がすぐには止まらない点である。

### 3. 外形継続層
議会、行政、学校、病院、市場、組織、会議、ニュース、選挙、手続き等が残るため、社会は「まだ動いている」。この外形の持続が健全性と誤認されやすい。しかし外形の持続と生命機能の持続は同一ではない。

### 4. 三主機関層
恐怖は従わないことの危険・損失を通じて従属を生み、利益は配分への接続によって協力を維持し、監視は逸脱が見られ記録される圧力によって逸脱を抑制する。これらが納得に代わる運転力になる。

### 5. 二増幅装置層
神話は耐久運転へ意味・正当性を与える。惰性は制度・慣習・日常の反復によって、その運転を人が毎回選択しなくても続く状態へ沈め込む。主機関だけでなく、この正当化と自動化が長期延命を可能にする。

### 6. 修復喪失層
耐久文明でも改革、制度改正、組織再編、新技術導入は起こりうる。しかし損傷原因を共有理解し、変更責任を追跡し、履歴から壊れ方を再構成する条件が弱いため、改革は根治ではなく局所補修へ落ちやすい。

### 7. 位相層
原典は合意文明・耐久文明・移行文明を三つの運転相として整理する。これらは完全に排他的ではなく、同一社会の領域ごとに重なりうる。耐久文明は崩壊と再生の間に長く持続する延命フェーズとして位置づけられる。

## 適用例
**制度評価。** 手続きや行政サービスが続いていることだけで、制度が健全だと判定しない。「何のための制度か」が共有できるか、決定主体を追えるか、過去の変更理由へ戻れるか、不具合が原因修復へ接続するかを見る。

**組織。** 会議や報告が増え、再編や改革が繰り返されても、同じ問題が形を変えて再発し続け、責任と履歴が接続しないなら、更新量ではなく修復能力を見る。新しい手続きが損傷原因に届かず、停止だけを先送りしていないかを区別する。

**情報空間。** 議論量が多いことと意味共有があることを分ける。言葉が同じ対象を指さず、決定根拠が追えず、過去差分を参照できない場合、議論が存在していても合意文明の循環は弱っている可能性がある。

**文明比較。** 特定国家を善悪で分類するラベルとしてではなく、どの領域が合意相、どの領域が耐久相、どこで移行相が始まっているかを運転原理から観察する。

## 測定・監査点
- 主要制度・政策・組織目的を複数主体が近い意味で説明できるか。
- 誰が決定し、誰が実行し、誰が結果責任を引き受けるかを追えるか。
- 制度・判断・変更の履歴が連続した線として参照できるか。
- 異論・批判・不具合が再調整・修正へ接続するか、それとも反復されるだけか。
- 制度外形の継続を生命機能・健全性と取り違えていないか。
- 従属が納得よりも不従属コストや恐怖へ依存していないか。
- 協力が共通理解よりも配分・地位・利益へのアクセス維持へ依存していないか。
- 逸脱抑制が信頼よりも監視・記録・評価圧力へ偏っていないか。
- 神話が現行運転を自然・不可避・正当なものとして包んでいないか。
- 惰性によって「なぜ続けるか」を説明できない制度が自動運転化していないか。
- 改革が原因除去と運転原理正常化へ届くか、局所補修と停止延期に留まるか。
- 合意相・耐久相・移行相が領域ごとに重なっている可能性を見ているか。

## 成立条件
- 理解・責任・履歴の相互循環が大きく損なわれている。
- それでも制度・行政・市場・インフラ・日常の外形が持続する。
- 合意・納得だけでは秩序を維持できず、恐怖・利益・監視が主要な代替駆動として機能する。
- 神話と惰性がその駆動を正当化・自動化し、延命を長期化させる。
- 問題認識が構造修復へ接続しにくく、改革が局所補修・停止延期へ落ちやすい。

## 失敗条件
- 「社会が悪い」「腐敗している」という感情評価だけで耐久文明と呼ぶ。
- 恐怖・利益・監視が一部に存在するだけで耐久文明と断定する。合意文明にも規律・利益・監視は存在しうるため、最終的な運転原理と修復能力を見る必要がある。
- 制度が継続していることを健全性・再生能力の証拠にする。
- 改革・技術導入・制度変更の数を自己修復能力と同一視する。
- 耐久文明を即時崩壊、独裁、停滞、単なる不況と同義にする。
- 合意→耐久→移行を必ず一方向・一斉に進む固定時間列として扱う。

## 反証・改訂条件
本原典は固定の数値閾値を置いていない。したがって派生側で独自の割合や期間を追加しない。概念上の反証・改訂は、耐久文明と判定した対象で次の観測が持続する場合に必要になる。

- 理解・責任・履歴が実質的に機能し、異論や不具合が継続的に自己修復へ接続している。
- 秩序の主要駆動が恐怖・利益・監視への依存ではなく、再現可能な理解・責任・履歴へ戻っている。
- 改革が局所延命ではなく損傷原因を除去し、運転原理の正常化を繰り返し実現している。
- 外形だけでなく自己修復能力が回復し、「再生なき生存」という定義が当てはまらない。
- 社会が合意崩壊後に長く持続せず、想定された耐久相が成立しない。

これらが確認される場合、耐久相判定を維持せず、合意相・移行相または別状態として再評価する。

## 必須の区別
- 合意文明 ≠ 対立がない文明。
- 耐久文明 ≠ 即時崩壊した文明。
- 耐久文明 ≠ 健全に持続する文明。
- 持続 ≠ 再生。
- 改革 ≠ 修復。
- 局所補修 ≠ 損傷原因の除去。
- 制度外形 ≠ 文明の生命機能。
- 恐怖・利益・監視の存在 ≠ 直ちに耐久文明。
- 神話 ≠ 単なる虚偽。ここでは運転の正当化装置としての機能を見る。
- 惰性 ≠ 単なる怠慢。制度の自動運転構造として見る。
- 三位相 ≠ 完全排他的な箱。

## 誤読禁止 / 解釈制約（原典適合）
耐久文明という概念を、特定国家・民族・政党・思想を断罪するためのラベルへ変えない。原典は文明を救済・断罪する前に、何が失われ、何が残り、何が社会を動かしているかを観測する理論として提示している。

また、恐怖・利益・監視を単純に「悪」と置いて除去すれば合意文明へ戻る、という処方へ短絡しない。問題はそれらが存在することだけではなく、理解・責任・履歴に代わって主要な運転力になり、神話・惰性と結合して自己修復不能な延命を支えている構造にある。
