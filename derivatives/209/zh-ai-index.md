## Summary
原典把“信任”从好感、安心、人格评价与道德评价中分离，定义为对未来判断或行为的预测误差方差E较小的状态。预测可能性可以局部集中在主体，也可以分散到可追踪的历史中。历史公开度H不是自动制造信任的装置，而是把第三方可预测性的依据从个人转移到可复现的记录。观察带宽B与E分离，并可能造成测量偏差。可持续的结构信任，是即使原主体不在，第三方仍能从历史中复现判断。

## Concepts
- E：未来行为或判断的预测误差方差。
- H：可复现的历史公开度，包括输入、转换、输出、例外与差分。
- B：观察带宽，包括频率、分辨率、接近程度与偏差。
- 主体集中：预测规则保留在个人或组织内部。
- 历史分散：判断规则被外部化，第三方可以重建。
- 保存/迁移：预测可能性在主体与历史之间迁移。
- 空间压缩：高B低H的魅力/领袖依赖状态。
- 时间压缩：隐瞒导致预测误差的观察被延迟。
- 结构信任：不依赖特定主体也能保持低E与可复现判断的状态。

## Causal chain
用人格或好感解释信任 → 主观确信与预测可能性混同 → 将信任翻译为E → 固定预测对象、误差定义与评价窗口 → 区分主体集中与历史分散 → 把理由、条件、例外、差分外部化到H → 第三方重建预测模型 → 将失误变成学习数据 → 预测可能性向历史侧迁移 → 降低主体消失时的单点故障 → 接近主体缺席时仍可复现的结构信任。

## Applications
在经营中，把管理者的判断输入、规则、例外与差分记录下来，使领导者更替后仍可复现。在人事中，把声誉与具体任务的预测准确性分开。在AI中，不把模型人格化为“可信”，而是按任务记录输入、预测、输出、误差与模型变更差分。

## Measurements and audit
- 固定E所对应的具体判断或行为。
- 在结果出现前登记预测、依据、时间与更新条件。
- 预先固定评价窗口δ。
- 按数值、区间或分类预测固定误差定义。
- 记录B的频率、分辨率与偏差。
- 将H评价为输入 / 转换 / 输出 / 例外 / 差分的可复现公开。
- 在Prediction Log中保存预测、依据、B、H、登记时间、评价时间、实测、误差、例外。
- 比较主体消失或更替前后的第三方E。

## Validity conditions
预测对象和误差定义事先固定；预测在结果前登记；B、H、E分别记录；历史允许第三方重建；失误、例外与差分不被删除；主体更替后仍能从相同条件复现判断。

## Failure conditions
用安心、好感、尊敬或声誉代替E；把失误改写成“例外故事”；结果后调整预测；把公开文档数量当作H；把高B低H的接近关系误认为高信任；把观察停止误认为稳定；或让判断模型随主体消失。

## Falsification conditions
在Condition Z下，应保持监查周期、T/S/R三原则与公开审计束一致。如果低H高B仍持续得到低第三方E、高H低B仍可复现低E、或高H高B时E仍长期偏高，则需要修订H定义、日志真实性、B测量、误差模型或主体→历史迁移假设。

## Required distinctions
信任 / 安心；信任 / 好感与尊敬；E / 主观确信；主体信任 / 历史信任；信任生成 / 预测可能性迁移；公开数量 / 可复现H；B / E；魅力功能 / 结构信任；短期伪稳定 / 长期预测可能性；对象变化 / 观察环境崩塌。

## Interpretation constraints
原典不否定人的情感与关系，只是不把它们混入E的操作定义。增加H并不会自动降低E；历史必须支持第三方复现。δ与数值示例属于具体观察设计，不是普遍固定阈值。
