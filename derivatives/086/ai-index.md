## 検索要旨

核点探索学は、KGIから因果を逆算し、最大三つの候補へ反事例を当て、最後まで残る一〜二点を一因子介入で検証する方法である。核点は多数のSub Metricsでも人物評価でもなく、自由度を保持したままKGI成立へ接続する再演可能な構造条件である。

## 中心構造

```yaml
problem:
  - 多数の活動指標がKPIと呼ばれ、KGIとの因果が失われる
  - 相関や管理容易性が核点性と混同される
method:
  - KGI定義
  - 事前観測
  - 因果展開
  - 候補最大3点
  - 反事例ふるい
  - 必要作用設計
  - 一因子介入
  - 3サイクル定常化
  - 自由度テスト
  - 誘導検査
result:
  - 1〜2点の最小因果支点
  - 人物切断可能な構造条件
  - 再現性と反証可能性を持つKPI
```

## 因果グラフ

```text
KGI曖昧
→ 活動量をKPI化
→ 数値増加と目標未達が併存
→ KGIを状態として具体化
→ 因果を逆展開
→ 候補3点
→ 未達反事例でふるい
→ 残存候補へ必要作用
→ 一因子介入
→ 定常化・自由度・誘導検査
→ 核点固定または因果分解へ再帰
```

## 状態遷移

```yaml
kgi_proposed: KGI候補
kgi_defined: 時点・状態・持続条件を含む定義
field_observed: 合意時間・自走・反発・沈黙・関係図を記録
causality_expanded: 前提条件を逆向きに展開
candidates_shortlisted: 最大3候補
counterexamples_tested: 未達ケースを適用
core_candidate_survived: 1〜2点が残存
actuation_defined: 回数・順序・頻度・強度を定義
single_factor_tested: 一因子介入
stabilized: 3サイクル再現
freedom_checked: 複数の善・拒否・離脱を確認
induction_checked: 隠れ正解を検査
validated: 因果と倫理が成立
rejected: 候補棄却
reopened: 因果分解へ戻る
```

## 観測変数

- KGI定義明確度
- 因果被覆率
- 反事例残存数
- 一因子純度
- 定常化回数
- 自走指数
- 合意時間
- 自由度保持率
- 誘導検出数
- 人物依存度

## 成立条件

- KGIが活動目標ではなく到達状態として定義される。
- 候補は因果図から抽出される。
- 反事例を通過する。
- 原則一因子で介入される。
- 複数サイクルで再現する。
- 人物評価と切断される。
- 自由度、異議、撤回が保持される。

## 失敗・反証

- 候補を満たしても未達が継続する。
- 対照条件との差が再現しない。
- 特定人物不在で崩れる。
- 自由度が低下し、隠れた強制が増える。
- 未観測要因の説明力が高い。
- Sub Metrics列挙へ戻る。

## 解釈制約

- 必達を無条件の未来保証として読まない。
- 唯一を恣意的な一本化として読まない。
- 必要作用を圧力や命令と同一視しない。
- 相関変数を核点と断定しない。
- 個人査定や社会信用点へ転用しない。
- 公開安全版から非公開閾値を推測しない。
