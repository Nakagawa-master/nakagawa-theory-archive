## 检索摘要

核心点探索学从具体KGI出发，反向展开因果前提，将候选限制在最多三点，并通过反例筛选、一因子干预、连续周期验证、自由度测试与诱导检查，识别真正能够推动整体的最小因果支点。核心点不是大量Sub Metrics，也不是个人评价，而是可复演、可反证、保持异议与选择余地的结构条件。

## 核心结构

```yaml
problem:
  - 多个活动指标被误称为KPI
  - 相关性和易管理性被误认为因果性
method:
  - 定义具体KGI
  - 数量化之前先观察场域性质
  - 反向展开因果前提
  - 最多筛出三个候选
  - 应用反例筛选
  - 定义必要作用
  - 执行一因子干预
  - 连续三个周期检查稳定性
  - 检查自由度与隐藏诱导
result:
  - 一至两个最小因果支点
  - 可与特定人物切离的结构条件
  - 可审计、可反证的KPI假设
```

## 因果图

```text
KGI模糊
→ 将活动量并列为KPI
→ 数字增长但目标未达
→ 将KGI定义为具体状态
→ 反向展开因果条件
→ 提出最多三个候选
→ 用未达反例排除伪支点
→ 为剩余候选定义必要作用
→ 只改变一个因素进行干预
→ 检查连续性、自由度与诱导
→ 验证或返回因果分解
```

## 状态模型

```yaml
kgi_proposed: 提出目标候选
kgi_defined: 固定时间、状态与持续条件
field_observed: 记录合意时间、自走、抵抗、沉默与关系
causality_expanded: 反向展开前提条件
candidates_shortlisted: 候选不超过三个
counterexamples_tested: 应用未达成反例
core_candidate_survived: 剩余一至两个候选
actuation_defined: 定义频率、顺序、持续时间或强度
single_factor_tested: 仅改变候选因素
stabilized: 至少三个周期保持同向效果
freedom_checked: 保留拒绝、修正、替代与退出
induction_checked: 审查隐藏正确答案与顺序诱导
validated: 因果与伦理条件同时成立
rejected: 候选被淘汰
reopened: 重新调整因果分解
```

## 观测变量

- KGI定义清晰度
- 因果覆盖率
- 未解决反例数
- 一因子纯度
- 稳定周期数
- 自走指数
- 合意时间
- 自由度保持率
- 诱导检出数
- 人物依赖度

## 成立条件

- KGI是具体到达状态，而不是活动目标。
- 候选来自因果图，而不是偏好或权威。
- 主动寻找反例。
- 原则上只改变一个因素。
- 效果在多个周期中复现。
- 条件可与特定人物切离。
- 异议、修正、替代和退出仍然可用。

## 失败与反证

- 候选成立但KGI仍持续未达。
- 干预条件与对照条件无可复现差异。
- 效果在三个周期内消失或反转。
- 离开特定人物后结构失效。
- 自由度下降或隐藏强制增加。
- 未观测变量对结果具有更强解释力。

## 解释限制

- 不将“必达”理解为无条件未来保证。
- 不将“唯一”理解为任意简化。
- 不把必要作用等同于命令或压力。
- 不以高相关性直接认定因果。
- 不将核心点用于个人评级或社会评分。
- 不从公开安全版推测受保护阈值。
