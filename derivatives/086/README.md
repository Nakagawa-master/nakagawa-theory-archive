## 位置づけ

本派生物は、KPIを多数の管理数値として並べる実務から離れ、KGIを動かす唯一または最小数の因果支点を発見するための思考・検証構造を整理する。核点は先に選ぶ標語ではなく、KGI同定、因果展開、候補抽出、反事例ふるい、必要作用設計を経て残る構造条件である。

## 中心命題

核点探索とは、最終到達状態から因果を逆算し、「それが満たされてもKGIに届かない反事例」を候補ごとに当て、最後まで残る因果支点を一因子介入で検証する方法である。真の核点は、人物評価や命令の道具ではなく、自由度と複数の善を残したまま全体の成立確率を高める構造条件として扱われる。

## 因果線

```text
多数の管理数値をKPIと呼ぶ
↓
活動量は増えるがKGIとの因果が曖昧になる
↓
KGIを具体的な到達状態として定義する
↓
KGIから前提と要因を逆向きに因果展開する
↓
全体を動かし得る候補を最大3点に絞る
↓
各候補へ「満たされても未達となる反事例」を当てる
↓
残った1〜2点へ必要作用を定義する
↓
一因子介入・定常化・自由度・誘導検査で核点性を確認する
↓
再現しない場合は固定せず、因果分解へ戻る
```

## 構造層

**1. KGI定義層**：売上増加などの抽象語ではなく、時点、状態、持続条件を含む到達状態を定義する。

**2. 事前観測層**：数える前に、合意時間、自走指数、反発や沈黙の質、主語、時点、関係図を観察する。

**3. 因果展開層**：KGIから逆算し、「何が起きれば次が成立するか」を一次分解して矢印で記述する。

**4. 反事例ふるい層**：候補が満たされても未達となる経路を探し、偽の核点を除外する。

**5. 必要作用層**：回数、順序、頻度、滞在、強度など、核点に必要な作用を数値または準定量で置く。

**6. 検証・倫理層**：一因子介入、3サイクル定常化、自由度テスト、誘導検査、人物評価からの切断を行う。

## 状態モデル

```yaml
- kgi_proposed: 最終目標の候補が示された。
- kgi_defined: 時点・状態・持続条件を含むKGIが固定された。
- field_observed: 合意時間、自走、反発、沈黙、関係図が記録された。
- causality_expanded: KGIから前提条件が因果分解された。
- candidates_shortlisted: 全体を動かし得る候補が最大3点に絞られた。
- counterexamples_tested: 各候補へ未達反事例が適用された。
- core_candidate_survived: 反事例を越えた1〜2点が残った。
- actuation_defined: 必要作用の回数・順序・頻度・強度が定義された。
- single_factor_tested: 他条件を保ち、核点候補だけを変更した。
- stabilized: 3サイクル以上、同方向の効果が確認された。
- freedom_checked: 複数の善、拒否、修正、離脱が保持された。
- induction_checked: 隠れた正解や順序誘導が検査された。
- validated: KGIとの因果と倫理条件が同時に成立した。
- rejected: 反事例または再現性不足により候補が棄却された。
- reopened: 因果分解の粒度を変えて探索が再開された。
```

## 適用例

**1. 組織会議**：会議回数や発言数をKPIにせず、合意時間を短縮する核点として「評価基準を冒頭で共有する」条件を一因子で検証する。

**2. 営業**：架電数や提案数を並べず、受注成立へ直結する顧客側の意思決定条件を特定し、その条件が満たされても未受注となる反事例を調べる。

**3. 教育**：学習時間だけを追わず、学習者が自分の役割や問いを言語化することが定着と再説明へ因果的に接続するかを検証する。

**4. 公共政策**：賛成率を核点とせず、反対意見を資源化する問い、異議経路、影響境界のどれが参加の自発化と論点収束へ接続するかを比較する。

**5. AI支援**：AIに核点を決定させず、因果候補、反事例、未観測変数、自由度侵害を可視化させ、人間が検証責任を持つ。

## 測定・監査点

- KGI定義明確度：時点・状態・持続条件が曖昧でないか。
- 因果被覆率：KGIまでの主要前提が因果図に含まれる割合。
- 反事例残存数：候補ごとに未解消の未達経路がいくつ残るか。
- 一因子純度：検証時に同時変更された他要因の少なさ。
- 定常化回数：同方向の効果が連続して観測されたサイクル数。
- 自走指数：追加命令なしに行動が継続・再演された度合い。
- 合意時間：判断基準の共有から合意形成までの時間。
- 自由度保持率：拒否・修正・代替・離脱が実際に利用可能な割合。
- 誘導検出数：問い、順序、評価に隠れた正解が発見された件数。
- 人物依存度：特定人物不在時に効果が失われる度合い。

## 成立条件

- KGIが具体的な到達状態として定義されている。
- 数値化より先に場の性質と関係構造を観測している。
- 候補が因果図から抽出され、好みや権威で選ばれていない。
- 各候補へ未達反事例を当て、残存経路を確認している。
- 検証は原則一因子で行い、同時変更を抑えている。
- 3サイクル以上の再現性を確認している。
- 核点を人物査定、命令、罰則の道具へ転用していない。
- 複数の善、異議、撤回、再設計の余地が保たれている。

## 失敗条件

- 多数のSub MetricsをKPIと呼び、因果を確認しない。
- 最初から唯一点を決め、反事例を探さない。
- 成功事例だけを集め、未達例や対照条件を除外する。
- 複数要因を同時に変え、何が効いたか識別できない。
- 特定人物の努力や能力を核点とみなし、構造条件へ置換しない。
- 短期改善を恒常因果として固定する。
- 自由度を下げる命令や評価圧力を「必要作用」と呼ぶ。

## 反証条件

- 核点候補を満たしてもKGI未達が継続する。
- 一因子介入と対照条件で差が再現しない。
- 効果が3サイクル以内に消失または逆転する。
- 人物を外すと成立せず、構造として再演できない。
- 自由度や異議可能性が低下し、隠れた強制が増える。
- 因果図にない未観測要因の方がKGIを強く説明する。

## 必須の区別

- 核点とSub Metrics
- KGIと活動目標
- 唯一点の発見と恣意的な一本化
- 必要作用と命令・圧力
- 一因子介入と同時多発変更
- 定常化と一時的成功
- 構造条件と個人能力
- 自走と服従

## 誤読禁止

- 核点を必勝法や未来保証として扱わない。
- 一つの指標で人間や組織の価値を序列化しない。
- 「100%作用」を無制限な圧力や反復と解釈しない。
- 相関が高いだけの変数を核点と断定しない。
- 公開安全版から非公開の閾値や操作手順を推測しない。
- AIの提案を反事例検証なしに採用しない。
