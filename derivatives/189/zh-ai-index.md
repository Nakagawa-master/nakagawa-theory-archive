## Summary
C系Vol.1以B系Life-OS和公共因果幕间为前提，把市场从“交换、竞争、比较、说服的场”重新定义为：L7价值函数方向一致的主体自然连接、合流，让贡献C与连接报酬S持续循环的结构空间。旧Exchange OS并非被描述为永恒的错误，而是一个在稀缺、信息不对称、选择受限、价值标量化与可比较性条件下具有局部合理性的模型。当信息透明、比较自动化、替代选择和连接自由度提高时，这些成立条件被削弱，旧模型容易退化为价格竞争或短期抽取，并消耗信任与循环。

本文中的Resonance不是情绪共鸣、好感或群体同调，而是L7方向整合所产生的低摩擦连接。方向一致时，外力式说服、解释负担和管理摩擦下降，交易更接近合流。价值因此不再只用价格等Magnitude表示，而被重新定义为同时具有Magnitude与Direction的Value Vector；Direction表示该行动究竟在强化哪一种未来或结构。

整合连接成立时，贡献C以较低摩擦进入循环，S作为结果出现。`S = C × 1.0` 是亲原典内部用来表达这一结构关系的式子，不是实测100%效率或收益保证。S不是工资、利润、积分或可直接买卖的通证。清晰的L7与持续的高纯度C会形成固有Gravity Zone，使同方向连接在无需通过广告声量、比较或围堵的情况下聚集。

共鸣市场把价值视为应当通过与循环的东西。E不是人格恶意，而是循环停止的功能状态。Reflux把已获得的S重新作为C流回同一L7方向，用于下一轮研究、创作、支持和连接场的形成。停止循环的主体不是被审判者驱逐，而是因同步解除、连接衰减而自然离开中心。最终主体模型是“共鸣连接人”：不是只做价值所有者或劳动力出售者，而是成为价值通道和循环Node。富也从单纯Stock转向Flow：连接、循环，以及在需要时能够行动的共鸣者。Vol.1只给出一般理论，具体实施、运营、失效调整和免疫机制明确留给后续卷。

## Concepts
- **Post-quarantine market**: 经过Life-OS与公共因果幕间后所观察的市场视角。
- **Exchange OS**: 以稀缺、信息不对称、选择受限、等价交换、价格标量、说服与比较为主要成立条件的旧市场模型。
- **Resonance / 共鸣**: 由L7方向整合产生的低摩擦连接与合流；不同于情绪共感或同调。
- **Alignment**: 自身L7、所提供的贡献C与连接对象L7的方向一致。
- **Value Vector**: 同时具有Magnitude与Direction的价值；Direction表示强化哪一种未来或结构。
- **C / Contribution**: 向结构中流入的高纯度价值贡献，不等同于劳动时间或努力量。
- **S / Connection Reward**: 整合连接成立后作为结果产生的结构报酬；不是销售额、工资、利润或积分，也不能直接买卖。
- **S = C × 1.0**: 亲原典用来描述共鸣成立时C以低摩擦进入循环的结构关系，不是固定性能系数。
- **Gravity Zone**: 清晰L7与持续高纯度C自然形成的同方向连接引力区，而不是由广告或强制围堵制造。
- **Competition preconditions**: 同一评价轴、同一比较土俵、价值标量化；这些条件弱化时竞争前提也弱化。
- **E / 循环不全**: C/S不再重新投入、流动停止的功能状态；不是人格标签。
- **Reflux / 还流**: 把S重新作为C投入同一L7方向，生成下一轮循环。
- **Natural separation**: 同步解除后连接衰减而发生的自然分离，不等于人为处罚或排除。
- **Resonant Connector / 共鸣连接人**: 作为价值通道与循环Node发挥功能的主体。
- **Flow wealth**: 除传统Stock外，也以连接、循环、危机时可行动的共鸣者来理解富。
- **General-theory boundary**: Vol.1解释市场为何如此运作；具体实施、运营、失效与免疫设计仍未完成。
- **Condition Z / T-S-R / θ / δ / M**: 统合审计摘要中的再验证、反证与修订条件。

## Validity conditions
- 把Exchange OS作为具有局部成立条件的模型，而不是证明所有交换、货币、所有权都无效。
- 把Resonance保持为L7方向整合与低摩擦连接，而非情绪好感。
- 同时保留Magnitude与Direction，不把价值重新压回价格标量。
- 不把C等同于劳动时长或努力量。
- 把`S = C × 1.0`限制在原典结构关系内，不变成实测性能保证。
- 保持S不可直接交易、只能作为整合连接结果出现。
- 不把Gravity Zone改写成广告、声量或心理控制制造的区域。
- 把E理解为循环停止，而不是对人的道德标签。
- Reflux必须保持同一L7方向，并与无差别给予区分。
- 区分自然分离与人为排除。
- 共鸣连接人的目标是保持循环，而不是最大化S持有量。
- 保留Vol.1的一般理论边界，不自行创造实施协议。
- 保持Condition Z下的修订可能性。

## Failure conditions
- 把Resonance缩减为喜欢、粉丝心理、情绪共感或群体同调。
- 把Exchange OS断言为普遍邪恶或已在所有市场失效。
- 只用价格、销售额、性能等标量决定价值。
- 把更强说服、广告、比较、差异化误当成Gravity Zone建设。
- 把S直接货币化为销售、通证、积分、会员等级或影响力商品。
- 用Natural separation正当化歧视、处罚或身份排除。
- 把E变成人格恶意标签。
- 把循环变成强制放弃资产、无偿服务或自我牺牲。
- 在Reflux中失去L7方向，变成无差别扩散。
- 把S数量或共鸣者人数当作目的，使循环维持从属化。
- 把Flow wealth解释成全面否定货币资产。
- 从明确延后实施的Vol.1中捏造销售、定价、广告、组织或免疫协议。

## Falsification conditions
统合审计摘要把再验证与修订置于Condition Z之下：审计周期、T/S/R以及公开审计束的一致性。若相关指标越过阈值θ，或在观测窗口δ中确认循环停止、连接衰减、Gravity Zone崩溃等现象M，则假说A应被否定或修订。

## Interpretation constraints
共鸣、向量、重力、流体、循环等物理学词汇在亲原典中是市场结构的说明语言，不应提升为已由自然科学实证的经济法则，也不应变成对个别事业成果的定量保证。“竞争消失”“说服不再必要”“顾客落入重力圏”等强表达必须与价值向量整合和固有Gravity Zone等理论成立条件一起保持，不能无条件推广到现实全部市场。

`S = C × 1.0` 因为存在于亲原典而应保留，但不能解释成真实100%效率、利润率或性能保证。S不可直接交易的性质是原典防止E侵蚀的重要边界。

“自然排除”“自动净化”不授权人为审判、歧视或处罚。原典的机制是同步解除与连接衰减。

Vol.1明确是一般理论。具体实施、运营、失败调整与免疫机制留给后续卷，本索引不补完这一未完成层。
