## Summary
C系Vol.1は、B系Life-OSと公共因果の幕間を前提に、市場を交換・競争・説得の場から、L7価値関数の方向が整合した主体が自然に接続・合流し、C（貢献）とS（接続報酬）を循環させる構造空間へ再定義する一般理論である。旧Exchange OSは欠乏、情報非対称、限定選択肢、スカラー価値、比較可能性によって一定の合理性を持っていたが、透明化、比較自動化、選択自由度上昇によって成立条件が崩れ、価格競争または短期搾取へ劣化し、信頼と循環を消耗すると論じる。

共鳴は情緒的共感ではなく、L7方向の整合によって説得・説明・管理摩擦が下がり、取引が衝突ではなく合流として成立する構造である。価値は価格等のMagnitudeだけでなく、どの未来・構造を強化するかというDirectionを併せ持つValue Vectorとして扱われる。方向が逆なら大きなMagnitudeでも接続しない。

整合接続ではCが摩擦損失を抑えて循環へ乗り、その結果としてSが生じる。`S = C × 1.0` はこの構造関係を示す親原典内の表現であり、実測効率や利益保証ではない。Sは売上・給与・ポイントではなく、直接売買できない接続報酬である。明確なL7と高純度Cの継続は固有重力圏を形成し、比較・差別化・競争より方向整合による接続を優位にする。

共鳴市場では価値は通過・循環するものとして扱われ、Eは人格的悪意ではなく循環停止という機能状態として定義される。得たSを同じL7圏へCとして戻すRefluxが循環を増幅し、循環しない主体は審判による制裁ではなく接続減衰によって自然に中心から外れる。最終主体像は、価値所有者より循環のNodeとして機能する共鳴的接続人であり、富もストック中心から接続・循環・危機時に動く共鳴者というFlowへ再定義される。ただし本巻は一般理論であり、具体実装・運用・免疫設計は後続巻へ留保される。

## Concepts
- **Post-quarantine market**: B系Life-OSと公共因果の幕間を経た視点から観測される市場。
- **Exchange OS**: 欠乏、情報非対称、限定選択肢、等価交換、価格スカラー、説得、比較を主要条件とする旧市場モデル。
- **Resonance / 共鳴**: L7方向整合によって外力的説得を減らし、低摩擦で接続・合流が成立する構造。情緒的共感とは区別。
- **Alignment**: 提供者L7、提供価値C、接続先L7の方向整合。
- **Value Vector**: MagnitudeとDirectionを持つ価値。Directionはどの未来・構造を強化するかを表す。
- **C / Contribution**: 投入時間量そのものではなく、純度の高い価値をどれだけ構造へ流し込んだかという貢献概念。
- **S / Connection Reward**: 整合接続が成立した結果として生じる構造的報酬。売上・給与・ポイントではなく直接売買不可。
- **S = C × 1.0**: 共鳴成立時にCが摩擦損失を抑えて循環へ乗ることを示す親原典内の関係表現。
- **Gravity Zone / 固有重力圏**: 明確なL7と高純度Cの継続から自然に形成される、同方向の接続が集まる領域。
- **Competition preconditions**: 同一評価軸、同一比較土俵、価値のスカラー化。これらが崩れると競争の前提も崩れる。
- **E / 循環不全**: C/Sを再投入せず流れが停止する機能状態。人格悪ではない。
- **Reflux / 還流**: 得たSを同じL7方向へCとして戻し、次の研究・創作・支援・場へ再投入すること。
- **Natural separation**: 同期が解け、接続が減衰することで市場中心から外れる構造。人為的制裁とは区別。
- **Resonant Connector / 共鳴的接続人**: 価値の所有者・労働力販売者だけでなく、価値の通過点・循環Nodeとして機能する主体。
- **Flow wealth**: 保有ストックだけでなく、接続、循環、危機時に動く共鳴者等で捉える富。
- **General-theory boundary**: Vol.1は市場がなぜそう振る舞うかを示す一般理論。具体実装・運用・免疫設計は未完。
- **Condition Z / T-S-R / θ / δ / M**: 統合監査要旨に置かれた再検証・反証・改訂条件群。
