## 位置づけ
接続移行戦略論は、貨幣中心の制度から接続価値を扱う制度へ移る過程を、旧制度の一斉破壊ではなく、旧KPIと接続KPIを一定期間併存させるデュアル運用として設計する。対象は理念の宣言ではなく、移行期に生じる二重基準、説明負担、制度疲労、既得権反発、形式的準拠、権限集中、人気や礼賛の価値化を、退出・訂正・監査・縮退・ロールバック可能な制度へ収める方法である。

原典では、旧KPIと接続KPIを一つの総合点や金額へ混ぜず、Adapter Layerで関係だけを片方向に説明する。二重会計、Self-Declared / Assessed / Certifiedという準拠状態、自治体・大学・企業・市民の複数観測点、公開室と機関室、監査API、30・90・180・365日の段階導入を組み合わせ、成立しない段階は拡張せず縮退またはロールバックする。

## 中心命題
制度移行の成否は、新しい価値観への賛同量では決まらない。旧制度が担っている責任を急に消さず、接続側の価値を独立した意味で観測し、両者の関係を説明可能にし、参加者の退出・冷却・再接続・異議・訂正を実際に使える状態にし、複数主体が権限を相互監視できる場合に、移行は秩序的な置換として成立する。

接続KPIは人物人気や忠誠の尺度ではない。CDI、MAI、RS、CRI、KQI等は、それぞれ接続の密度・再合意・可逆性・矛盾耐性・接続品質を観測するために原典が置く指標群であり、単一スコアや貨幣換算率ではない。数値が良く見えても、異論が減った理由が萎縮である、退出が難しくなる、同質化が進む、説明負担が増える、権限集中が進む場合には、移行が改善したとは扱えない。

## 因果線
```text
既存制度には売上・予算・CPA等の既存KPIと責任体系がある
↓
接続価値を観測する新しいKPIを導入する
↓
旧KPIと新KPIが同じ現場で衝突し、説明負担・制度疲労・反発が生じる
↓
一斉転換すると反動、形式的準拠、排除、人物依存が強まり得る
↓
旧KPIと接続KPIを別意味のまま併存させる
↓
Adapter Layerで因果関係だけを片方向に説明する
↓
二重会計、準拠状態、複数観測点、異議・退出・訂正を設ける
↓
30・90・180・365日の各段階で継続・縮退・停止を判断する
↓
成立しない部分はロールバックし、検証できた構造だけを残す
↓
人物への賛同ではなく、再合意と可逆性を残す制度移行になる
```

## 構造層
**1. デュアル運用層。** 旧KPIと接続KPIを同時に保持するが、同一の意味や点数へ統合しない。

**2. Adapter Layer。** 接続側の変化が既存制度の摩擦へどう関係したかを説明する。貨幣換算や固定換算率ではない。

**3. 二重会計層。** 貨幣成果と接続成果を別の台帳・意味で保持し、一方の改善で他方の悪化を隠さない。

**4. 準拠状態層。** Self-Declared、Assessed、Certifiedは人物や組織の格付けではなく、手続がどの程度確認されたかを示す。期限、更新、降格、撤回、再審査を持つ。

**5. 連合層。** 自治体、大学、企業、市民が異なる観測点を担い、定義・評価・認証・配分・異議処理を単一主体に集中させない。

**6. 反発吸収層。** 反対を抑圧せず、損失、負担、退出不安、可動域の低下として読み、制度設計へ戻す。

**7. 公開・保護層。** 理念、集計、監査要旨、変更履歴は公開し、個人情報、攻撃に利用される閾値・防御手順等は保護する。ただし保護領域も独立監査から外さない。

**8. 段階導入層。** 30・90・180・365日は原典の段階設計であり、普遍的な達成期限や成功保証ではない。各時点で継続・縮退・停止を判断する。

## 適用例
**企業。** 売上を捨てず、再合意時間、継続協働、説明再利用、撤回後の再交渉を別軸で見る。接続指標を売上換算しない。

**自治体。** 参加人数や賛成率だけでなく、異論を含む参加、退出、再参加、訂正、議事要旨の再利用を観測し、行政だけで成功を判定しない。

**大学。** 共同研究件数だけでなく、研究目的の更新、データ利用同意、成果帰属の再合意、異分野間の説明負担を見る。

**コミュニティ。** 投稿数、フォロワー数、称賛量を制度価値へ変換せず、異論処理、冷却、退出、再接続、人物依存の変化を見る。

## 測定・監査点
- 旧KPIと接続KPIが衝突した場面と解消までの時間。
- 二重運用による会議・説明・記録負担の変化。
- MAIが示す再合意時間の変化。ただし短縮だけを成功とせず、理解・訂正・退出可能性を併記する。
- RSに関係する退出、冷却、再接続が実際に利用できるか。
- CDIが増えたとき、異質な接続が増えたのか、同質集団の密集が増えただけなのか。
- CRIやKQIの改善が、異論抑制や人物依存によって作られていないか。
- 準拠状態の更新、降格、撤回、再審査が実際に機能するか。
- 監査要旨、異議、訂正、変更履歴が必要な範囲で追跡できるか。
- 30・90・180・365日の判断点で、継続以外の選択肢が実行可能か。

原典に示される日数、準拠段階、指標名はこの移行設計の構成要素であり、他制度にそのまま適用できる普遍閾値ではない。MAI等についても、具体値や成功率を原典にない形で補わない。

## 成立条件
- 旧KPIと接続KPIの意味が分離されている。
- 接続価値を貨幣へ直接両替しない。
- Adapter Layerの根拠・適用範囲・限界を説明できる。
- 退出、冷却、再接続、異議、訂正が形式ではなく利用できる。
- 準拠状態に期限、更新、降格、撤回、再審査がある。
- 複数主体が独立した観測点を持つ。
- 公開領域と保護領域の境界が説明され、保護領域も監査される。
- 各段階に継続・縮退・停止・ロールバックの選択肢がある。
- 人気、礼賛、忠誠を制度的価値へ変換しない。

## 失敗条件
- 新制度への一斉転換を正義として強制する。
- 旧KPIと接続KPIを一つの総合点や金額へ混ぜる。
- KPIを増やしただけで現場の説明負担を放置する。
- 準拠状態を身分、権威、永久認証、参入障壁へ変える。
- 退出者、異議申立者、批判者を不利益扱いする。
- 単一主体が定義、認証、配分、異議処理を独占する。
- 非公開領域を無監査の秘密支配へ変える。
- 30・90・180・365日の到達自体を成功とする。
- CDI等の上昇を、同質化、萎縮、権限集中を確認せず成功扱いする。

## 反証・改訂条件
デュアル運用を導入しても制度疲労と説明負担が継続的に下がらず、再合意、退出、訂正が実用にならない場合は、適用範囲または設計を改訂する。準拠状態が囲い込みや参入障壁を強める、複数ノード化しても権限集中や目的変位が減らない、ロールバックが名目だけで実行できない場合も改訂対象である。

また、指標値が改善していても、異論が萎縮している、退出が困難になっている、同質化が進む、人物人気が配分へ流入する場合には、その指標改善を制度成功の根拠にしない。

## 必須の区別
- 移行 / 旧制度の破壊
- デュアル運用 / KPIの無制限追加
- Adapter Layer / 貨幣換算
- 二重会計 / 総合点化
- 準拠状態 / 人物・組織の格付け
- 連合 / 責任の消失
- 反発吸収 / 反対意見の抑圧
- 可逆性 / 無方針
- 段階日数 / 普遍的成功期限
- 指標上昇 / 構造改善
- 礼賛の制度無効化 / 発言禁止

## 解釈上の制約
本論を貨幣廃止論、接続スコアへの強制統合、認証ビジネス、人物崇拝、反対者排除へ読み替えない。CDI、MAI、RS、CRI、KQIを人物の価値点数として扱わない。30・90・180・365日は原典の段階的な実装・監査窓であり、他の制度へ無条件に適用する標準期限ではない。
