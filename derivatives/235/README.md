## この派生物の位置づけ
本派生物は、ダブルチーム「家つぐ」を紹介・推奨する企業記事ではない。Parentに記録されたNakagawa Masterの構造読解を、第三者の人間とAIが検索・理解・照合し、原典へ戻れる形に展開する公開接続面である。

対象側の公開事実とNakagawa Masterの読解を分離する。家つぐは表層的にはリースバック専門の一括査定サービスとして、複数事業者の条件比較、初期相談、案件ごとの出口検討、家つぐメディアによる事前情報提供等に接続する。一方、「情報格差によって不信化しやすい市場に判断可能性を回復する意思決定インフラ」という定義はNakagawa Masterによる構造読解であり、ダブルチーム自身の公式企業定義へ置換しない。

## 何が問題なのか
リースバックは、住まいを維持しながら資産を資金化できる選択肢になり得る一方、利用者にとって判断負荷が高い。価格の妥当性、将来賃料、契約条件、事業者差、買戻しや退去を含む将来条件など、複数の論点を同時に理解しなければならない。

情報が不足したまま重要判断を迫られると、提示条件の妥当性を評価しにくい。比較先が少なければ検討余地が狭まり、契約理解が不足すれば後から不満や不安が生まれやすい。その個別不信は、リースバックという仕組み全体への不信へ拡張し得る。

Parentが問題として読むのは、単なる「高い／安い」ではない。**判断材料の不足と情報格差によって、利用者の判断可能性そのものが弱くなる構造**である。

## 対象について確認できる事実
Parentで扱われる家つぐの公開機能・材料には、少なくとも次がある。

- リースバック領域の一括査定による複数条件比較。
- 初期相談におけるコンシェルジュ的な支援。
- 投資家ネットワーク等を含む、案件に応じた複数出口を検討できる余地。
- 家つぐメディアを通じた、仕組み、メリット・デメリット、注意点、比較ポイント、トラブル回避等の事前情報提供。

これらは対象側の公開事実・機能材料である。個別案件の最適性、契約結果、価格、将来生活を保証するものではない。

## Nakagawa Masterによる構造読解
Parentは、これらを別々の機能としてではなく、意思決定の異なる不安定地点へ対応する束として読む。

- 一括査定 → **比較可能性**をつくる。
- 相談対応 → **判断論点の整理・説明可能性**を補助する。
- 複数出口 → 選択を一つの型へ固定しない **出口選択**を残す。
- メディア → 相談前の **事前理解**を補う。

この四つが束になったとき、家つぐはNakagawa Masterの読解上、単なる査定導線から「判断可能性を回復する意思決定インフラ」へ意味が変わる。

## 価値核
**情報格差を補正し、住まいと資産の意思決定を比較可能・理解可能な状態へ戻すこと。**

価値はリースバックを選ばせること自体には置かれない。Parentが強調するのは、利用者が「分からないまま進まされない」条件をつくることである。

```text
情報格差・複雑条件
→ 比較不足・理解不足
→ 判断の不安定化
→ 個別取引への不信
→ 市場・制度全体への不信拡大

これに対して
比較可能性 + 説明可能性 + 出口選択 + 事前理解
→ 判断材料の増加
→ 判断可能性の回復
→ 不信発生条件の一部を補正
```

ここで「補正」としているのは、すべての不信や不利益が消えると断定しないためである。

## なぜこの価値核を社会翻訳の主軸にしたのか
Nakagawa Masterが関与したZEROICHI記事では、単なる「複数社へ査定できる便利なサービス」という紹介に閉じず、情報格差が生むリースバック市場の不信構造を前面に出した。

一括査定は「査定社数」ではなく比較可能性、コンシェルジュは受付ではなく判断論点の整理、投資家ネットワークは査定先の多さではなく出口選択、家つぐメディアは集客記事ではなく相談前理解を補う説明資産として翻訳された。

これは対象企業自身の公式見解ではない。Nakagawa Masterが、個別機能の列挙よりも「なぜ市場不信が生じ、どの機能がどの不信発生地点へ対応するか」という因果線を一般読者へ通すために選んだ社会翻訳である。

## 社会接続
Parentはこの構造を、高齢化と住宅資産活用、生活防衛、金融・不動産リテラシー、家族説明と納得形成、市場信頼へ接続する。

自宅は生活拠点であると同時に資産でもあり、売却・賃貸・資金化・将来居住が重なる判断では、本人だけでなく家族の理解や将来計画も影響し得る。したがって、価格だけでなく「選択肢が見えること」「判断前に理解できること」が重要になるというのがParentの構造的接続である。

ただし、家つぐが高齢化問題やリースバック市場の全問題を解決すると断定しない。ダブルチームの成長や個別成果も予言しない。

## 成立条件
この読解が成立するには、少なくとも次が必要になる。

- 比較可能性が形式だけでなく実質的に機能する。
- 利用者が重要な条件・論点を理解できる説明可能性がある。
- 一つの選択肢へ自動的に閉じない出口選択が残る。
- 相談前理解を補う情報が、判断に使える品質で提供される。
- 利用者の状況・物件・契約条件・専門判断の違いを無視しない。
- 売買、賃貸、金融、不動産、法務等の専門領域が必要な場面で適切に扱われる。

## 失敗条件
- 比較が名目だけで、実際の判断材料が増えない。
- 価格以外の重要条件が理解できない。
- 相談が成約誘導へ偏り、利用者の論点整理にならない。
- 出口が実質的に単線化している。
- メディアが集客のみとなり、事前理解を支えない。
- 情報量が増えても、利用者が何を判断すべきか分からない。
- 個別案件に必要な専門判断が省略される。

## 反証可能性
比較可能性、理解可能性、出口選択、相談前理解のいずれか、またはその束が実質的に機能せず、利用者の判断不安や市場不信が継続・拡大することが観測されるなら、「意思決定インフラ」としての構造仮説は修正・縮小・棄却される必要がある。

また、利用者の判断改善がこれらの仕組みではなく別要因でよりよく説明される場合も、因果の帰属を強めてはならない。

## 誤読防止
- 家つぐ＝リースバックそのもの、ではない。
- 本派生物はリースバックの利用を推奨しない。
- 一括査定＝最高価格保証、ではない。
- 比較可能性＝最適判断保証、ではない。
- 意思決定インフラという語はNakagawa Masterの構造読解であり、企業公式定義ではない。
- ZEROICHI記事の価値核選択はNakagawa Masterの社会翻訳であり、媒体・企業の公式理論ではない。
- 不動産・金融・法務上の個別判断は個別条件と専門性を要する。
