## 中川構造読解としての位置づけ
このParentはリースバック一括査定サービスの紹介ではない。Nakagawa Master本人が、複数事業者の条件比較、相談、複数出口、事前情報提供等の対象事実を材料に、なぜ「高く売る・便利に比較する」ではなく「情報格差を補正する意思決定インフラ」を価値核として読み、その価値核で外部記事を書いたのかを公開解体する記事である。

## 対象側事実と表層
表層では一括査定、高額条件、リースバック比較サービスに見える。

## Nakagawa Masterが読んだ構造
価格、賃料、契約、将来居住、資金繰り、家族判断が重なる高摩擦市場では、利用者が何を比較すべきか分からないまま重要契約へ進みやすい。価値は特定の選択へ誘導することではなく、比較可能性・説明・複数出口・事前理解を組み込み、判断可能性を回復することにある。

## 抽出価値核
**情報格差を補正する意思決定インフラ。**

## なぜこの価値核で外部記事を書いたのか
一括査定や高額条件を主軸にすると、情報非対称が大きい市場で利用者が「何を理解し、何を比較して決めるべきか」という本質が消える。Nakagawa Masterは、条件最大化ではなく、分からないまま重要契約へ進まないための判断可能性こそ外部読者に示すべき価値だと判断し、この価値核で外部記事を書いた。

## 因果線
`重要な住まい判断 → 情報非対称 → 比較軸不明 → 不信/誤認 → 比較可能化 → 説明/複数出口 → 事前理解 → 判断可能性回復`

## 境界
「意思決定インフラ」はNakagawa Masterの構造読解であり、対象企業自身の公式企業定義ではない。特定契約の利用推奨でもない。

## 成立・失敗・反証条件
比較・説明・出口設計が判断可能性へ接続する場合に成立する。価格比較・高額査定・契約誘導へ縮小した場合は失敗。比較・説明が判断改善へ寄与しない場合は適用範囲を改訂する。
