## 中川構造読解としてのメタ視点
このParentは公開記事の要約でも、リースバック一括査定サービスの紹介でもない。Nakagawa Master自身が、家つぐを**どう読むべきか、どの表層に回収すると価値核を失うか、なぜ外部記事でその軸を前面化したか**を公開解体する中川構造読解である。

四層を固定する。**対象側事実 / 表層「リースバック一括査定・高額査定・比較」 / Nakagawa Masterの構造読解 / 社会翻訳**。価値核は **情報格差で歪みやすい住まい・資産判断に、比較可能性・説明・複数出口・事前理解を組み込み、利用者が分からないまま重要契約へ進まない状態をつくる意思決定インフラ**。ダブルチーム自身の公式理論ではない。

## 位置づけ
Parentが読むのは「どこが一番高いか」ではなく、価格・賃料・契約・将来居住・資金繰り・家族判断が重なる高摩擦市場で、利用者が何を比較すべきかを理解できないまま決めさせられる構造の補正である。

## 中心命題
**情報格差によって不信化・誤判断しやすい住まいの意思決定を、比較・説明・出口設計・事前理解で補正し、判断可能性を回復すること。**

## 表層 → 価値核 → 社会翻訳
`一括査定/高額条件 → 条件だけでは判断できない → 比較軸・説明・複数出口・事前理解 → 情報格差補正 → 意思決定インフラとして社会翻訳`

## 因果線
`重要な住まい判断 → 情報非対称 → 比較軸不明 → 不信/誤認 → 比較可能化 → 説明・複数出口 → 事前理解 → 判断可能性回復`

## 構造読解の監査点
高額査定＝成功にしない。リースバック利用推奨にしない。比較だけでなく説明・出口・事前理解を保持する。契約判断を代行する装置としない。L4以上を保持する。

## 成立条件
複数条件が比較可能で、利用者が重要条件と出口を理解し、判断可能性が高まること。
## 失敗条件
価格比較だけへ縮小、高額条件を価値核化、特定契約への誘導、企業公式理論への誤帰属。
## 反証・改訂条件
比較・説明・出口設計が判断可能性改善へ結びつかない場合は改訂。
## 必須の区別
価格比較/意思決定インフラ; 情報提供/判断代行; リースバック選択肢/利用推奨; 対象事実/読解; Parent/社会翻訳。
## 親原典へ戻る理由
「家つぐをどう読むべきか」「どの誤読を避けるか」「なぜその社会翻訳を選んだか」はParentへ戻る。
