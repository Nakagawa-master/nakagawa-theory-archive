## 位置づけ
本派生物は、親原典が扱う「未来定義検証なき努力強制」の悪因果を、努力一般の否定、高い目標の否定、管理職批判、KPI批判へ縮約せず、原典の因果線・責任線・反証可能性を保持したまま検索・理解・監査可能にする。

第2論の焦点は、努力量の多寡それ自体ではない。上位側・設計側が「目標値を置くこと」と「その未来が成立し得ることを検査すること」を混同し、成立条件、現在から未来までの因果線、検証条件、修正条件、責任配置を十分に設計しないまま、下流の現場へ実行継続だけを要求したとき、どこへ未検証性のコストが移るかを扱う。

目標値は未来の到達点である。未来定義は、その到達点が現在構造、資源、時間、主体、環境、制度、因果線を通って成立し得るように、成立条件と検証可能性、修正可能性、責任配置まで含めて設計された成果定義である。目標値が存在するだけでは未来定義は成立しない。

上流で省略された成立検査は消滅しない。現場が曖昧な目標解釈、資源不足の補填、因果探索、試行錯誤、追加調整、失敗説明を引き受けることで、成立検査コストが下方移転する。成果が出なかった際に設計・仮説・条件を再検査せず、「努力不足」だけを原因化すると、その移転は見えなくなり、努力要求が責任転嫁装置へ反転する。

原典は、実行者の責任を消さない。同時に、設計責任、資源確保責任、実行責任、評価責任を一つの「現場の頑張り」へ圧縮しない。努力を未来成立へ接続するためには、何を検証する実行なのか、どの観測で仮説を維持・修正・撤退するのか、誰がどの責任を持つのかが開かれている必要がある。

## 中心命題
未来に数値・到達点・理想像を置くことと、その未来が成立可能であることは別である。目標値だけを未来定義として扱うと、成立条件と因果線の検査が省略され、未検証な設計の空白が実行者の努力によって埋められる。

このとき現場は、与えられた作業を遂行するだけでは済まない。何を意味する目標なのかを解釈し、足りない資源を補い、現実に合わない因果仮説を現場で探り、権限不足を調整し、失敗理由を説明しながら、それでも継続を求められる。つまり実行負荷と成立検査負荷が同じ場所へ重なる。

成果不成立時に、目標の妥当性、資源、前提、因果仮説、検証方法、評価軸を再検査せず、努力不足だけを原因化すると、現場から上流へ返るべき観測情報が遮断される。疲弊・不信・沈黙は単なる感情問題ではなく、観測情報が更新に戻らなくなる構造結果として位置づけられる。

その状態が続けば、失敗は仮説修正の材料ではなく「もっと頑張るべきだった」という道徳評価へ変わる。現場は新しい試行で学ぶより、失敗責任を避けることを合理的に選びやすくなり、学習停止・挑戦回避が起きる。努力要求が未来成立のための実行設計ではなく、上流の未検証性を下流へ移す装置になる、というのが第2論の悪因果である。

ただし、不確実性が存在すること自体は失敗ではない。未知の条件を行動で確かめることも否定しない。重要なのは、その行動が何を検証するのか、どの結果なら仮説を更新するのか、探索の設計責任を誰が持つのかが明確であることである。「まずやる」ことと「検査責任を放棄してやらせ続ける」ことを区別する。

## 構造層
**1. 目標値設定層。** 売上、件数、到達水準、成長目標、成果像等が未来の到達点として置かれる。ここまでは通常の目標設定であり、原典は目標を置くこと自体を否定しない。

**2. 未来定義誤認層。** 目標値を決めたことをもって、その未来へ至る成立可能性の検査まで済んだように扱う。到達点と成立設計の区別が失われる層である。

**3. 成立条件未検査層。** 資源、時間、主体能力、権限、環境、制度、依存関係等、未来が成立するための条件が十分に検査されない。条件不足は後で現場へ現れる。

**4. 因果線未設計層。** どの行動がどの中間変化を通って成果へ接続するかが仮説化されない。行動量だけが指示され、何を確かめる行動かが不明になる。

**5. 検証・修正未設計層。** どの観測で仮説を支持・棄却するか、どの時点で方法・資源・目標を変更するかが定義されない。未達が出るたびに努力量だけを増やしやすくなる。

**6. 責任配置曖昧層。** 設計責任、資源確保責任、実行責任、評価責任が区別されず、結果責任が一括して実行者へ流れやすくなる。

**7. 成立検査コスト下方移転層。** 上流で省略された目標解釈、条件補填、因果探索、調整、試行錯誤、失敗説明を現場が吸収する。省略されたコストは消えるのではなく、別主体へ移る。

**8. 努力不足単因化層。** 成果不成立時に、設計・仮説・資源・評価軸を同時に検証せず、努力量・姿勢・根性だけを原因として固定する。これにより上流の未検証性が見えにくくなる。

**9. 疲弊・不信・沈黙層。** 現場が実行と成立検査と失敗説明を重ねて負い、観測を伝えても設計が変わらない状態が続くと、負担と不信が蓄積する。異議を言わないことが自己防衛として合理化される。

**10. 学習停止層。** 失敗が仮説更新へ戻らず努力不足評価へ固定されるため、組織が失敗から因果を学ぶ回路を失う。データがあっても解釈が固定されれば学習は起きない。

**11. 挑戦回避層。** 新しい試行が学習機会ではなく追加責任リスクとして認識される。未知へ踏み込むより、責任が増えない行動を選ぶ方が合理的になる。

**12. 責任転嫁反復層。** 上流が未来定義検証を行わず、下流が努力で吸収し、失敗が努力不足へ戻される循環が固定される。努力という肯定的な語が、設計責任の不在を覆う外観として機能する。

## 適用例
**1. 売上・営業目標。** 売上額や件数を置いた後、顧客構造、供給能力、商材適合、価格、チャネル、担当範囲、検証期間を設計せず、未達のたびに架電量・訪問量だけを増やしていないかを見る。目標数値そのものではなく、その数値へ至る因果線と修正可能性を監査する。

**2. 教育・育成。** 到達水準や成績目標だけを提示し、前提知識、学習時間、教材、支援、評価方法、つまずき条件を設計せず、結果を本人の努力不足だけへ還元していないかを見る。高い期待を否定せず、成立条件の設計責任を残す。

**3. 制作・プロジェクト。** 納期・品質・成果物だけが固定され、必要人数、権限、依存関係、レビュー条件、変更条件が不足したまま、現場が「工夫」で埋めていないかを観測する。実行者の工夫が価値を生むことと、設計不足を恒常的に吸収させることを区別する。

**4. 新規事業。** 不確実性が大きいからこそ、最初から正解を知る必要はない。しかし、何を仮説とし、どの行動で何を検証し、どの観測で継続・修正・撤退するかは設計できる。探索の不確実性を理由に無限定な努力継続を正当化しない。

**5. AI導入。** 利用件数、生成回数、導入部署数だけを未来定義とせず、どの業務因果を変えるのか、誰の時間・品質・判断をどう変えるのか、どの条件で失敗と判定するのかを明確にする。AIを使えば因果が完全に可視化されるとは扱わない。

**6. 研究・実験。** 実験回数を努力量として評価するだけでなく、各実験がどの仮説を識別するのか、結果によって次の仮説空間がどう変わるのかを見る。失敗を「もっと回数を増やせ」に固定すると学習回路が止まり得る。

**7. 個人目標・自己改善。** 個人が自分へ高い目標を課す場合も、睡眠、時間、資源、環境、習慣、因果仮説を無視して意志力だけを原因化すると同じ構造が起こり得る。人物批判ではなく、自己設計にも適用可能な構造として読む。

## 測定・監査点
親原典は普遍的な「努力不足率」「疲弊率」「成功確率」「成立検査スコア」等の数値指標を定義していない。派生側で独自の割合、点数、閾値、ランキングを創作しない。測定は、原典が置く構造条件が存在するか、因果線がどちらへ進むか、反対条件で結果が変わるかという反転評価可能性に限定する。

- 目標値と未来定義が言語上・運用上区別されているか。
- 到達点だけでなく、資源・時間・主体・環境・制度等の成立条件が共有されているか。
- 現在の行動から成果までの因果線が、検証可能な仮説として示されているか。
- 各実行が何を確かめるためのものか説明できるか。
- 成功・失敗・保留をどう判定するかが定義されているか。
- 結果が外れたとき、方法、資源、前提、目標、評価軸をどの条件で修正するか開かれているか。
- 設計責任、資源確保責任、実行責任、評価責任が一人・一部署の努力量へ圧縮されていないか。
- 現場が曖昧な目標解釈や資源不足を暗黙に補填していないか。
- 成立検査に必要な時間・注意・試行錯誤・調整・説明の負担がどの階層に置かれているか。
- 成果不成立時に設計・仮説・条件側も同時に検査されるか。
- 疲弊・不信・沈黙が観測されたとき、それが個人姿勢だけで処理されず設計修正へ戻るか。
- 失敗情報が次の仮説・条件へ戻り、学習が続くか。
- 新しい挑戦が追加責任だけを生む状態になっていないか。
- 成立条件を明示した場合としない場合で、責任転嫁・学習停止・挑戦回避の構造が変わるか。

ここでの反転評価は「条件を整えれば必ず成功する」という保証ではない。条件設計・因果仮説・修正可能性・責任配置が存在しても同じ疲弊構造が継続するなら、本論の適用仮説を限定する材料になる。逆に、それらが欠けても持続的な信頼・学習・挑戦が広範に維持されるなら、接続仮説は再検討される。

## 成立条件
- 目標値と未来定義が区別され、到達点だけで成立済みと扱わない。
- 資源、時間、主体、環境、制度等の成立条件が検討される。
- 現在から未来までの因果線が仮説として共有される。
- 実行が何を検証するための行為か明示される。
- 成功・失敗・保留の判定条件がある。
- 方法、資源、前提、目標、評価軸の修正・撤退条件がある。
- 設計責任と実行責任が分離され、設計側も検証対象に残る。
- 成果不成立時に仮説・条件・資源・評価軸が再検査される。
- 現場から返る失敗情報・異議・観測が次の設計へ接続される。
- 努力要求が無限定継続ではなく、検証可能な実行として位置づけられる。

## 失敗条件
- 目標値だけで未来定義が成立したと扱う。
- 成立条件を検査せず、資源不足や制度制約を現場の頑張りで補填させる。
- 行動量は指定されるが、何を検証する行動か説明されない。
- 因果線が示されず、未達のたびに同じ努力量だけを増やす。
- 修正・撤退条件がなく、失敗しても目標・方法・前提を固定する。
- 設計側が検証対象から外れ、実行者だけが結果責任を負う。
- 現場が実行、条件補填、因果探索、試行錯誤、失敗説明を同時に背負う。
- 疲弊・不信・沈黙が起きても「姿勢」の問題として処理し、設計を変えない。
- 失敗情報が学習へ戻らず、挑戦回避が合理化される。
- 努力という肯定的語によって、責任配置の不整合が不可視化される。

## 反証・改訂条件
成立条件、因果線、検証条件、修正条件、責任配置を明確にし、成果不成立時に設計・仮説も再検査する運用へ変えても、疲弊・不信・沈黙・学習停止・挑戦回避・責任転嫁が同程度の構造で持続するなら、「未来定義検証不足から現場疲弊へ」という接続仮説は限定・改訂される。

また、これらの条件を明示せず、設計側の成立検査が弱い状態でも、広い観測範囲で現場の信頼、学習、異議表明、挑戦が持続し、失敗情報が継続的に上流へ戻る事例が再現するなら、本論が想定する悪因果の適用範囲を狭める必要がある。

努力量の増加だけで、条件・仮説・設計の再検査なしに持続的な成果と学習が成立し、現場への成立検査コスト移転や責任単因化が生じない状態が広範に確認される場合も、本論の説明範囲を再検討する。

一方で、個別の成功例だけをもって反証とはしない。原典が扱うのは、未検証設計のコストがどこへ置かれ、失敗時に何が検査され、学習回路が維持されるかという構造である。派生側は反証条件を独自の発生率・閾値・統計式へ変換しない。

- 努力要求 / 努力強制

- 実行責任 / 設計責任
- 資源確保責任 / 現場の自己補填
- 評価責任 / 努力量への単因化
- 不確実性 / 不確実性の現場転嫁

- 高い目標 / 未検証の目標
- 実行による検証 / 設計不備の吸収
- 失敗 / 努力不足という単一説明
- 挑戦 / 追加責任の押し付け
- 観測情報 / 姿勢評価

## 誤読禁止
- 努力不要論へ変えない。
- 高い目標そのものを否定する理論へ変えない。
- KPI、営業、教育、管理職一般の批判へ縮約しない。
- 上位者という語から特定人物・職位を自動的に加害者分類しない。
- 実行者の実行責任・報告責任・改善責任を消すために使わない。
- 不確実性が存在すること自体を設計失敗とみなさない。
- 「まずやってみる」を否定しない。何を検証する実行か、どの結果で修正するかを問う。
- 事前に全条件を確定できなければ行動してはいけないという理論へ反転させない。
- AIやデータを使えば因果が完全に可視化できると仮定しない。
- 疲弊を個人の心理状態だけへ縮約せず、成立検査負荷と責任線との接続を保持する。
