## 位置づけ
接続公共圏OSは、接続価値会計、接続ガバナンス、CXP、接続裁定、接続基本権を、自治体・大学・企業・市民コミュニティが役割を分けて共同運転する公共制度基盤として構成する。単一の行政DX、企業プラットフォーム、地域データ統合ではなく、接続を測る・守る・つなぐ・回復する機能を、公共目的、同意、可逆性、独立観測、異議・救済とともに常駐させる設計である。

自治体は正統性と既存法・行政手続への接続、大学は知識・研究・長期検証、企業は技術実装と適用拡張、市民は独立観測を担う。役割分散は責任消失を意味せず、評価、配分、監査、裁定、救済ごとに責任主体を識別できることが必要になる。

接続公共圏OSは接続を最大化する装置ではない。接続する権利だけでなく、接続しない権利、範囲限定、説明、異議、訂正、退出、忘却、再接続を扱い、弱者アクセスと合理的配慮を含める。相互運用も無制限なデータ共有ではなく、目的、範囲、期限、責任、撤回を保持した最小開示として設計される。

## 中心命題
接続価値を公共財として運転するには、ID、同意、評価、配分、監査、裁定を一つの自治体、企業、プラットフォームへ集中させず、自治体・大学・企業・市民が異なる責任と観測点を持つ連合として運用する必要がある。

CXPが目的・同意・合意の記憶・可逆性・責任を保持し、接続会計が関係状態を観測し、ガバナンスが権限集中と指標歪みを監査し、裁定が被害を救済し、基本権が参加・拒否・異議・退出・再接続を保障する。この束が同じ公共原則で接続され、縮退・停止・ロールバックが実行可能な場合に、接続価値は囲い込みや強制に依存せず公共制度として循環できる。

```text
↓

↓
接続会計で観測し、ガバナンスで守り、裁定で修復する
↓

```

## 構造層
**1. 社会API層。** CXPがIDだけでなく、目的、同意、合意の記憶、期限、責任、撤回、再接続を状態として扱う。相互運用では必要な状態だけを最小開示し、全データの中央集約を前提にしない。

**2. 会計・配分層。** CDI、MAI、RS等の指標束と一次証拠を用い、接続の状態・再合意・継続可能性等を観測する。これらを単一の人格スコアや社会信用スコアへ統合せず、貨幣と直接両替しない。

**3. ガバナンス層。** 公共目的、禁止用途、権限分離、利益相反、監査、異議、変更履歴を扱う。公開可能な要旨と保護すべき個人情報・詳細条件を分け、保護領域も独立監査の対象にする。

**4. 裁定・復権層。** 強制接続、同意外利用、指標ハック、ログ改ざん、集団圧力に対し、暫定保護、調査、比例的裁定、救済、段階的復権、再審を接続する。

**5. 基本権・包摂層。** 接続、非接続、範囲限定、説明、異議、訂正、退出、忘却、再接続を実行可能な手続として持ち、子ども、障害者、言語支援が必要な人等への合理的配慮を制度条件に含める。

**6. 連合ノード層。** 自治体、大学、企業、市民が異なる責任・専門性・観測点を持つ。専門性や資源提供を最終決定権へ自動変換せず、利益相反に応じて回避・委任できる。

**7. 段階実装・都市OS層。** 限定PoC、準拠ラベルβ、限定相互運用、常設化検討を段階的に行い、各段階で権限集中、弱者排除、情報漏洩、囲い込みを見直す。進行だけでなく縮退・停止・ロールバックを正式な状態として持つ。

## 適用例
**教育・大学連携。** 共同研究や地域学習で、研究目的、同意、成果帰属、撤回、再利用範囲をCXPで保持する。共同研究件数だけでなく、再合意に要する時間、説明の再利用、異分野摩擦、学生・研究協力者の退出可能性を見る。

**医療・介護。** 本人、代理人、医療機関、自治体、委託事業者の目的と権限を分け、利用範囲、期限、訂正、削除、異議、緊急停止を扱う。相互運用を理由に全情報を中央集約しない。

**防災。** 地域内の多様な接続・資源経路を把握し、高齢者、障害者、外国語話者等への情報到達、誤情報訂正、離脱・再参加が実際に可能かを見る。

**文化・観光。** 訪問者数や売上だけでなく、地域住民の同意、文化資源の帰属、継続協働、撤回可能性、外部事業者への囲い込みを観測する。

**公共調達。** Self-Declared、Assessed、Certifiedという準拠分類を手続要件の一部として扱う場合、期限、更新、降格、異議、小規模団体への支援を組み込み、永久資格や参入障壁へ変えない。

## 測定・監査点
**段階レビュー点。** 親原典はD+90、D+180、D+365、D+730を、限定PoC、準拠ラベルβ、限定相互運用、常設化検討へ進むための段階的な実装参照点として示す。sourceは親原典、measurement actorは公共圏OSを運用する連合、measurement objectは実装開始から各レビュー段階までの経過日数と各段階の成立・撤退条件、source modalityは実装ロードマップ上のレビュー目安、permitted use scopeは継続・縮退・停止・常設化の検討、non-guarantee scopeは普遍的な導入期限、成熟度順位、成功保証、必ず順方向へ進む工程ではないことである。

**CDI・MAI・RS。** 親原典が用いる指標束であり、sourceは親原典、measurement actorは各領域の運用・監査主体、measurement objectは接続構造、再合意、関係状態等の原典上の観測対象、source modalityは複数指標を併用する観測枠、permitted use scopeは公共制度の状態・歪み・改善の検討、non-guarantee scopeは単一総合点、人格順位、社会信用スコア、貨幣換算、普遍合格閾値ではないことである。原典にない固定重み・算式・閾値は前提にしない。

**準拠ラベル。** Self-Declared、Assessed、Certifiedは公共調達等で用いる準拠状態の分類であり、市民・組織の価値順位ではない。更新、降格、撤回、異議、支援が伴い、Certified到達を恒久資格や自動成功とみなさない。

そのほか、目的・同意・来歴・責任が制度間で保持されるか、独立観測点による偏向・改ざん・ブリゲーディング検出、異議・訂正・救済・復権の処理、合理的配慮の利用可能性、公開領域と保護領域の境界違反・再識別・漏洩、ノード間の権限集中、公共調達の囲い込み・談合・参入障壁、縮退・停止・ロールバックの実行可能性を観測する。親原典はこれらに普遍的な固定合格率を定義していない。

反転評価では、CDI・MAI・RSが改善しても極化、排除、制度疲労、退出困難が悪化するなら成功ではない。相互運用が増えても中央集約、目的外利用、撤回困難が増えるなら改善ではない。Certifiedが増えても参入障壁や特定事業者優遇が強まれば失敗である。市民参加数が増えても異議が制度変更へ接続しないなら公共性は高まっていない。D+90/D+180/D+365/D+730へ到達しても成立条件を満たさなければ前進の証拠にならず、縮退・ロールバックが適切な場合がある。

## 成立条件
- 自治体、大学、企業、市民が異なる責任と観測点を持つ。
- 判断、配分、監査、救済ごとの責任主体を識別できる。
- CXPが目的、同意、記憶、可逆性、責任を保持する。
- 接続会計、ガバナンス、裁定、基本権が同じ公共原則で接続される。
- 貨幣と接続価値を直接両替しない。
- 公開領域と保護領域の境界が説明可能で、保護領域も独立監査を受ける。
- 参加、非参加、異議、訂正、退出、救済、再接続が実際に利用できる。
- 弱者アクセスと合理的配慮が形式ではなく利用可能である。
- 準拠ラベルに期限、更新、降格、異議、支援がある。
- 各実装段階に縮退、停止、ロールバック条件がある。

## 失敗条件
- 一つの自治体、企業、プラットフォームがID、同意、評価、配分、裁定を独占する。
- 相互運用を理由に全データを中央集約する。
- CDI、MAI、RS等を人格スコア、社会信用スコア、人気、貨幣換算へ変える。
- 準拠ラベルを永久資格や特定事業者の参入障壁へ変える。
- 退出者や異議申立者を公共サービスで不利益扱いする。
- 市民ノードを形式的な賛同役にする。
- 大学の専門性や企業の技術提供を最終権限へ自動変換する。
- 保護領域を無監査の秘密行政へ変える。
- 接続調達が囲い込み、談合、内部評価、特定事業者優遇へ変質する。
- 既存法・基本権より低い保障を新OSの名で導入する。

## 反証・改訂条件
連合化、CXP、会計、ガバナンス、裁定、基本権を整えても、極化、排除、制度疲労、権限集中、目的外利用、退出困難が反復して減らず、同意・訂正・退出・救済が制度間で保持されない場合、公共圏OSとしての適用範囲は改訂対象になる。

独立観測点が権限集中や改ざんを訂正へ接続できない、合理的配慮が形式化する、公共調達が参入障壁・囲い込みを増やす、公開・保護境界が秘密支配または情報漏洩を生む、縮退・停止・ロールバックが実際には利用できない場合も見直し条件になる。

D+90、D+180、D+365、D+730は進行義務ではない。段階の成立条件が満たされないのに日数だけを理由に次段階へ進むなら、このロードマップの運用は原典の可逆性から外れる。

## 解釈制約
中央集権的な行政管理、地域データの企業囲い込み、社会信用スコア、形式的市民参加、大学権威による自動正当化、認証利権へ変換しない。既存法・基本権より低い保障を新しいOSの名で正当化しない。

D+90/D+180/D+365/D+730は制度設計上の段階レビュー点、CDI/MAI/RSは指標束、Self-Declared/Assessed/Certifiedは準拠分類である。いずれも単調な成熟度ランキングや成功スコアではない。
