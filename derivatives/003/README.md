## 位置づけ
本派生物は、成立条件論の詳細定義へ入る前に「なぜ成立判定理論が必要なのか」を示す第0論を、原典の意味強度を変えずに検索・理解・監査可能な形へ展開する。原典が問題にするのは、人々が何も見ていないことではない。現場、制度、経営、思想、技術、AI等の各主体が、自らの観測可能な局所を部分的には正しく理解しながら、その局所理解を本人内部で全体として扱ってしまう認識運動である。

原典はこれを「局所全体化」と呼ぶ。局所全体化が複数主体に分散して並立すると、各人が異なる局所を全体として語り、全員が部分的には正しいまま全体像が分散する「分散的全体誤認」が成立する。ここでは局所的正しさの総和が、そのまま全体成立を保証しない。

成立条件論・第0論が必要とするのは、単なる「もっと広く見よう」という注意喚起でも、全知的な一人を置くことでもない。L1事象、L2行動、L3制度、L4構造認知、L5構造操作、L6階層連結が縦因果として通り、局所判断が現実の全体成立へ接続しているかを判定できる視座である。

## 中心命題
社会の不成立は、全員が間違っているから起きるとは限らない。むしろ各局所が部分的に正しいために、その判断が検査をすり抜け、局所正解の集合が全体不成立を生むことがある。

現場は現場条件を正しく語り、制度は制度整合を正しく語り、経営は数字や戦略を正しく語り、技術は実装可能性を正しく語り、AIは言語上の整合を高く保つことができる。それでも、層と層の接続、責任配置、資源、時間、履歴、意味軸、例外処理が未検査なら、全体として成立しているとは言えない。

したがって本論の中心は「誰が正しいか」ではなく、「どのレイヤーでは正しく、その正しさがL1〜L6を因果として通って全体成立へ接続しているか」を問うことにある。

## 因果線
```text
各主体が自分の観測可能な局所を部分的に正しく理解する
↓
局所理解が本人内部で全体として扱われる
↓
他レイヤーとの接続条件が未検査のまま残る
↓
異なる局所正解が社会内に分散して並立する
↓
分散的全体誤認が形成される
↓
L1〜L6の縦因果が誰にも成立判定されない
↓
制度・経営・教育・言論・AI出力・現場判断が局所正解のまま流通する
↓
現場負荷・責任転嫁・制度疲労・例外処理・履歴喪失・意味軸の細りが残る
↓
言語上または制度上は整っていても現実成立が保証されない
↓
成立条件論による縦因果の成立判定が必要になる
```

## 構造層
**1. 局所観測層。** 各主体が、自らの専門、役割、現場、制度、数値、技術、言語等の観測可能範囲を理解する。この局所理解は部分的に正しい場合がある。

**2. 局所全体化層。** 局所で成立する説明が、本人内部で問題全体・原因全体・現実全体として扱われる。「理解した」という感覚を伴うため、単純な知識不足より固定されやすい。

**3. 分散的全体誤認層。** 現場、制度、経営、思想、技術、AIが異なる局所を全体として語り、部分正解が複数並立する。全員が完全には間違っていないため、全体不成立が見えにくくなる。

**4. 縦因果未判定層。** L1事象からL6階層連結までの接続が、因果として通っているか検査されない。分類が存在することと、縦因果が成立することは別である。

**5. 不成立残存層。** 接続未判定のまま判断が流通すると、現場負荷、責任転嫁、制度疲労、例外処理の堆積、履歴喪失、意味軸の細り等が残る。

**6. 言語整合増幅層。** AIや文書は、局所正解を高い言語整合性で統合したように見せられる。そのため、整った説明が縦因果の実在を隠すことがある。

**7. 成立判定視座層。** 誰か一人が全部を見るのではなく、各局所がL1〜L6を通って現実成立へ接続しているかを判定可能にする構造が必要になる。

## L1〜L6を使う理由
L1〜L6は単なる抽象度分類ではない。本論では、局所的正しさが現実成立へ接続しているかを検査する縦因果座標として扱う。

- **L1 事象**：現実に何が起きているか。
- **L2 行動**：主体がどのように行動し、どこへ負荷が生じているか。
- **L3 制度**：規則、役割、配分、責任がどう設計されているか。
- **L4 構造認知**：何を原因・全体・問題として認識しているか。
- **L5 構造操作**：認識した構造へどのような介入を行うか。
- **L6 階層連結**：複数層の操作が時間・責任・履歴・意味を含めて接続するか。

局所では正しい判断でも、下位層へ実装されない、上位層の意味と接続しない、責任が層間で消える、時間条件が欠ける等があれば、全体成立は保証されない。

## AI時代で増幅する理由
AIは大量の情報を短時間で統合し、言語上は全体を見ているような説明を生成できる。しかし、文章の一貫性、要約の網羅性、論理の滑らかさは、L1〜L6の縦因果が現実に通っていることの証明ではない。

AIが現場情報、制度条件、責任主体、資源制約、時間条件、履歴、意味軸と接続しないまま整った説明を生成すると、局所全体化を解消するどころか、局所正解を「全体らしい説明」として再流通させる増幅器になり得る。

したがってAI利用では「説明が整っているか」だけでなく、「その説明がどの層では正しく、どこで縦因果が切れ、現実条件へどう戻れるか」を監査する必要がある。

## 適用例
**制度設計。** 手続きや規則が制度上は整っていても、現場で例外処理や未処理負荷が増え続ける場合、L3の正しさとL1・L2の成立を分けて見る。

**経営判断。** 数字・戦略上は合理的でも、責任・資源・時間・現場行動へ接続せず、実行時に負荷が転嫁される場合、局所正解／全体不成立を監査する。

**教育・言論。** 説明が理念的・論理的に正しくても、受け手が再参照できず、履歴や意味軸が切れるなら、理解可能性と成立を分離する。

**AI導入。** 高品質な出力でも、誰が最終判断し、どの制度へ入り、どの現場負荷を生み、どの履歴を残すかが未検査なら、言語整合と現実成立を同一視しない。

**分業。** 分業それ自体を問題にせず、各局所の責任と接続条件が明示され、縦因果として全体成立へ接続しているかを見る。

## 測定・監査点
親原典は派生側独自の一般KPI、成立率、成功確率、数値閾値を定義していない。したがって数字を創作せず、反転評価可能性は次の構造観測に限定する。

- 対象判断がどのレイヤーでは正しいか
- L1〜L6のどこで接続が途切れるか
- 現場負荷や例外処理が別レイヤーへ転嫁されていないか
- 責任主体が層間で蒸発していないか
- 制度整合と現場成立が一致しているか
- 言語整合と現実成立が一致しているか
- 判断履歴・変更履歴・再参照経路が保持されているか
- 意味軸が時間の中で保持されているか
- 分業の責任と接続条件が明示されているか
- 局所正解だけで全体成立を推定していないか

ここでの監査は、局所正解を否定するためではなく、その正しさが全体成立へ接続しているかを反転評価可能にするために行う。

## 成立条件
- 各主体の局所理解が部分的に正しい。
- その局所理解が本人内部で全体として扱われる。
- 他レイヤーとの接続条件が未検査である。
- 複数の局所正解が分散して並立する。
- L1〜L6の縦因果が成立判定されない。
- 局所正解が流通しても、現場負荷・責任転嫁・制度疲労・履歴喪失・意味軸の細り等の全体不成立兆候が残る。

## 失敗・非該当条件
- 局所判断が全体成立条件まで検査されている。
- 分業の責任と層間接続条件が明示されている。
- L1〜L6の縦因果が実際に通る分散システムである。
- 問題が単純な知識不足だけで、局所理解を全体化する認識運動を伴わない。
- 言語整合と現実成立の差が継続的に解消されている。

この場合、複数主体が分業していることや、一人が全体を直接観測していないことだけでは本論の問題構造は成立しない。

## 反証・改訂条件
L1〜L6の接続判定を行わなくても、局所理解だけで責任特定可能性、履歴公開、現場負荷、制度持続性、意味軸、理解可能性が長期的かつ広範に安定し、局所判断が継続的に全体成立へ接続するなら、本論の「成立判定視座が必要である」という仮説は限定または改訂される。

逆に、単に局所判断が誤っていた事例を示すだけでは、本論の反証にはならない。本論の対象は局所的な誤りではなく、局所的には正しい理解が全体化され、層間接続未判定のまま流通する構造だからである。

## 必須の区別
- 局所的正しさ / 全体成立
- 視野の広さ / 成立判定
- 分業 / 分散的全体誤認
- 情報不足 / 局所全体化
- 言語整合 / 現実成立
- AIの統合的説明 / 縦因果の実在
- 全体最適の標語 / 成立条件の検査
- 多面的説明 / 層間接続の成立
- 一人が全体を見ること / 全体を判定できる構造

## 誤読禁止
- 「視野が狭い人が悪い」という人物批判へ変えない。
- 「全部見ればよい」という全知要求へ変えない。
- 一般的なサイロ批判やシステム思考だけへ縮約しない。
- L1〜L6を単なる抽象度分類として扱わない。
- 局所正解そのものを否定しない。
- AIの文章整合を現実成立の証明にしない。
- 原典にない一般KPI、成立率、閾値を追加しない。
- 派生側の説明便宜を親原典の追加主張へ昇格させない。
