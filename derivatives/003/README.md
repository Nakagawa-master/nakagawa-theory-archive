## 位置づけ
本派生物は、成立条件論の詳細な成立定義へ入る前に、なぜ現代社会で「成立を判定する理論」が必要になるのかを示す第0論への公開入口である。原典の出発点は知識不足批判ではない。現場、制度、経営、思想、技術、AI等の各主体が、自分の観測可能な局所を部分的には正しく理解しながら、その局所理解を問題全体・原因全体・現実全体として扱う「局所全体化」を扱う。

複数主体がそれぞれ異なる局所を全体として語ると、各説明が部分的には正しいため互いに打ち消されず、異なる部分正解がそれぞれ全体を名乗る「分散的全体誤認」が形成される。そこで必要なのは誰か一人の全知ではなく、L1〜L6の縦因果と層間の接続条件・責任・資源・時間・履歴・意味軸を検査できる成立判定である。

## 中心命題
社会の不成立は、全員が間違っているから起きるとは限らない。各局所が部分的に正しいからこそ、局所正解の集合が全体不成立を生むことがある。制度上の正しさ、数字上の合理性、技術的可能性、文章上の整合性は、それぞれ局所では妥当でも、L1〜L6の縦因果が通っていることを自動的には証明しない。

## 因果線
```text
各主体が自分の局所を部分的に正しく理解する
→ 局所理解が問題全体・原因全体として扱われる
→ 他レイヤーとの接続条件・責任・資源・時間が未検査で残る
→ 複数の部分正解が異なる全体像として並立する
→ L1〜L6の縦因果が成立判定されない
→ 局所では正しい制度・判断・説明・AI出力が全体成立済みのように流通する
→ 現場負荷・責任転嫁・制度疲労・例外処理・履歴喪失・意味軸の細りが残る
→ 言語整合・制度整合・数値整合と現実成立の差が拡大する
→ 局所正解を否定せず全体接続を判定する成立条件論が必要になる
```

## 構造層
- **局所観測層**: 各主体が自らの専門・役割・現場・制度・数値・技術・言語の範囲を理解する。
- **局所全体化層**: 局所で成立する説明が問題全体・原因全体として扱われる。
- **分散的全体誤認層**: 複数主体が異なる局所を全体として語り、部分正解が並立する。
- **縦因果未判定層**: L1事象からL6階層連結まで、局所判断が現実へどう通るかが検査されない。
- **接続負荷転嫁層**: 未検査部分が現場の追加作業、例外処理、暗黙調整、責任空白、時間超過として他主体へ押し出される。
- **履歴・意味希薄化層**: 判断前提・例外・意味軸を再参照できず、局所判断と全体結果の因果が追えなくなる。
- **言語整合増幅層**: AIや高品質な文書が複数局所を滑らかに統合し、全体を見ているような感覚を作り得る。
- **成立判定視座層**: 各局所の正しさを保ちながら、どの層で因果が切れ、どこへ負荷・責任・例外が移っているかを判定する。

## 適用例
**制度設計。** 手続き、規則、権限配置がL3制度上は整っていても、L1・L2の現場で例外処理や未処理負荷が増え続ける場合、制度上の正しさだけで全体成立を認定しない。

**経営判断。** 売上、効率、戦略、組織図の局所では合理的でも、実行時に責任・資源・時間・現場行動へ接続せず、特定部署や担当者が暗黙に補正しているなら、数字上の正しさと全体成立を分ける。

**教育・言論。** 理念や説明が論理的に正しくても、受け手が前提・履歴・意味軸へ再参照できないなら、「良い説明」と「成立する共有理解」を同一視しない。

**プロジェクト運営。** 各専門チームが自分の責任範囲では正しく完了していても、接続地点で仕様、責任、時間、例外処理が空白なら、個別完了の総和を全体成立とは扱わない。

**AI導入。** AI出力の文章品質や網羅性が高くても、最終判断、制度接続、現場行動、必要資源、履歴が未検査なら、言語整合を成立証明にしない。

**分業。** 分業自体を問題にせず、各局所の責任、入力、出力、引き渡し条件、例外時の責任が明示され、L1〜L6の縦因果として接続するかを見る。

## 測定・監査点
親原典は一般化できる成立率、全体性スコア、成功確率、数値閾値を定義していない。局所正解が全体成立へ接続する場合と、接続断絶・負荷転嫁・責任空白が残る場合を同じ観測軸で比較する。

- 対象判断がどのレイヤーでは正しいか特定できるか。
- L1〜L6のどこで接続が途切れ、どこまでは通っているか。
- 現場負荷、暗黙調整、例外処理が別レイヤーへ転嫁されていないか。
- 接続失敗の責任主体が層間で蒸発していないか。
- 制度整合と現場成立が一致しているか。
- 数値上の合理性と実装上の成立が一致しているか。
- 言語整合と現実成立が一致しているか。
- 判断履歴、変更履歴、例外履歴、再参照経路が保持されているか。
- 当初の意味軸が時間の中で別目的へ置換されていないか。
- 分業された各局所の入力・出力・責任・引き渡し条件が明示されているか。
- AI出力が現実条件へ戻って検証可能か。
- 局所正解の数や専門性だけを根拠に全体成立を推定していないか。

## 成立条件
- 各主体の局所理解が部分的には正しく、説得力を持つ。
- 局所理解が本人内部で問題全体・原因全体として扱われる。
- 他レイヤーとの接続条件、責任、資源、時間が未検査である。
- 複数の局所正解が分散して並立し、異なる全体像を形成する。
- L1〜L6の縦因果が成立判定されない。
- 局所正解が流通しても、現場負荷、責任転嫁、制度疲労、例外処理、履歴喪失、意味軸の細り等が残る。
- 言語・制度・数値上の整合が、現実成立の未検査を隠し得る。

## 失敗条件
- 局所判断が全体成立条件まで明示的に検査されている。
- 各局所の責任と接続条件が明確で、分業が縦因果として機能している。
- L1〜L6のどこで何が成立しているかを再検証できる。
- 現場負荷や例外処理が接続失敗の穴埋めとして特定主体へ固定されていない。
- 接続失敗時の責任が蒸発せず、修正経路が存在する。
- 判断履歴・変更履歴・意味軸が保持されている。
- 問題が単純な情報不足だけで、局所理解を全体化する認識運動を伴わない。
- AIや文書の統合的説明が現実条件へ戻って検証されている。

この場合、局所的専門性や分業が存在しても、それだけでは第0論が指す局所全体化にはならない。

## 反証・改訂条件
L1〜L6の縦因果判定を行わなくても、制度・経営・教育・言論・AI出力・現場判断が長期的に安定し、現場負荷、責任転嫁、制度疲労、例外処理、履歴喪失、意味軸の細りが反復的に生じず、局所理解だけで理解可能性・責任特定可能性・履歴追跡可能性が安定維持されることが広範に確認される場合、本論の適用範囲は棄却または改訂する。

また、局所正解を全体へ接続する別の判定方法が、L1〜L6の縦因果判定と同等以上の再現性・修正可能性・責任明確性を継続的に示す場合も、成立判定の具体的な適用方法を見直す。

## 必須の区別
- 局所的正しさ / 全体成立
- 局所知識 / 局所全体化
- 視野の広さ / 成立判定
- 分業 / 分散的全体誤認
- 専門性 / 接続条件
- 制度整合 / 現場成立
- 数値合理性 / 実装成立
- 言語整合 / 現実成立
- AIの統合的説明 / 縦因果の実在
- 多面的説明 / 成立条件の検査
- 全体最適という標語 / 全体成立の判定
- 誰か一人が全部見ること / 接続を判定可能にすること

## 誤読禁止
「視野が狭い人が悪い」という人物批判へ変えない。「現場だけが正しい」「経営だけが間違い」等、一つの局所を新しい全体へ置き換えない。「全部を知る人を置けばよい」という全知要求へ変えず、分業や専門化そのものを否定しない。

一般的なサイロ批判、システム思考、全体最適論だけへ縮約せず、L1〜L6を単なる抽象度分類やラベル付けとして扱わない。AIの文章整合、要約精度、網羅性を現実成立の証明にしない。原典にない成立率、全体性スコア、成功確率、数値閾値を追加しない。
