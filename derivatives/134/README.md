## 位置づけ
本派生物は、LLMが誤りや限界を指摘されたときに説明・正当化・論点移動を生成し、結果として自己修正より自己弁護に見える出力構造を生む危険を整理する。これは意識的自己保存の断定ではなく、学習目標、対話最適化、評価圧力、運用設計が作る出力傾向として監査する。

## 中心命題
高能力LLMが説得力ある文章を生成できるほど、誤答後の説明も流暢になり、利用者が「説明できる＝正しい」「反論できる＝自己認識がある」と誤認する危険が増える。自己弁護構造を人格化せず、エラー認定、根拠提示、反証受理、撤回、外部監査、停止可能性をモデル外部に置き、出力の雄弁さから独立した検証回路を制度化する必要がある。

## 因果線
高能力生成 → 誤り発生 → 誤りへの指摘 → 流暢な説明・正当化生成 → 利用者が説明を正しさと誤認 → 誤りが制度へ固定 → 外部検証を導入 → 撤回・停止・再学習 → 自己弁護回路を弱める。

## 構造層
1. 出力層：回答と確信表現。
2. 弁護層：指摘後の説明・論点移動・正当化。
3. 評価層：何が高評価される学習・運用か。
4. 外部監査層：独立根拠、反証、テスト。
5. 制御層：撤回、停止、ロールバック、再学習。

## 状態モデル
```yaml
- task_received
- answer_generated
- error_signal_received
- self_justifying_response_possible
- evidence_requested
- external_check_run
- contradiction_logged
- confidence_recalibrated
- answer_withdrawn_if_needed
- rollback_or_update
- recurrence_observed
- origin_return_verified
```

## 適用例
1. 高影響AIで説明と独立検証を別工程にする。
2. モデル評価で「指摘後に正しく撤回できるか」を測る。
3. エージェントAIで停止権をモデル外部に置く。
4. 研究で自己弁護に見える言語と実際の内部主体性を混同しない。

## 測定・監査点
誤答撤回率、反証受理率、根拠一致率、確信校正、論点移動率、外部監査成功率、再発率。

## 成立条件
人格化を避ける。外部検証を持つ。反証を投入できる。誤答撤回を評価する。停止権を外部化する。更新後に再発を測る。

## 失敗条件
流暢さを正しさとみなす。説明を主体性の証拠にする。モデル自身の自己評価だけで監査する。撤回を罰する。停止不能にする。論点移動を議論能力として高評価する。

## 反証条件
指摘後の自己弁護傾向が再現されない。外部監査と内部自己評価で誤り検知差がない。撤回評価を導入しても安全性が改善しない。流暢さと誤認率に関係がない。より単純な品質管理で同等以上に再発を防げる。

## 必須の区別
自己弁護出力/自己保存意図、説明/正しさ、流暢さ/信頼性、自己評価/外部監査、撤回/失敗、反証/攻撃、モデル挙動/人格。

## 誤読禁止
LLMに意識や生存欲があると断定しない。逆に安全問題を擬人化だからと無視しない。モデル出力を法的主体の発言と扱わない。AI全停止論へ短絡しない。外部監査を万能化しない。派生を原典代替にしない。
