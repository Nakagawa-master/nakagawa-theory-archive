## 位置づけ
本原典は、不動産市場OS Vol.1が提示した「理解して選べる市場」の前提を受け、透明化が必然的に生む摩擦を避けるのでなく、市場を壊さず循環させるための力学として扱う理論編である。市場を一枚の平面や一つの正義で支えるのでなく、所有者のFear、投資家・業者・購入希望者のGreed、公共性を担うJusticeが互いに反対方向へ力をかけながら均衡するアーチとして捉える。

張力均衡は「誰も怒らない状態」を目標にしない。摩擦、反発、クレーム、ヘイトを、均衡点のずれや仕様欠陥を知らせる観測信号として受け止め、出口、アクセス境界、説明責任、公共目的、対話回路を設計して循環へ戻す。Fear / Greed / Justice / Ethical Shieldのいずれかだけを切り出す部分実装は、圧力、略奪、理想論、監視・搾取への転化を起こしうるため、全体の力学として運用する必要がある。

## 中心命題
親原典の中心命題は、**不動産市場の透明化は摩擦を消す施策ではなく、隠れていた恐怖・欲望・公共的正当性の衝突を可視化する操作であるため、その摩擦を失敗として抑圧せず、Fearをブレーキ、Greedを推進力、Justiceを存在理由と境界、Ethical Shieldを批判・悪用・対話の振り分け構造として同時に配置し、Exitを含む選択可能性と継続的な均衡調整によって、反発を市場OSの修正信号と循環エネルギーへ変換しなければならない**、というものである。

これは自由市場を放任へ戻す理論でも、統制市場へ一極化する理論でもない。市場参加者の対立を消さず、単独最適を禁じ、互いの力が崩落しない範囲で拮抗し続ける第三の市場OSとして張力均衡を置く。

## 構造層
**1. Transparency Paradox。** 透明化は善悪そのものではなく、隠れていたリスク・選択・責任を可視化するため、防衛反応と摩擦を同時に発生させる。

**2. Market as Arch。** 市場は一枚の平面で自然均衡するのではなく、反対方向の力が押し合うことで形を保つアーチとして扱う。一つの力が抜ける、弱すぎる、強すぎる場合に全体が崩れる。

**3. Fear。** 所有者の恐怖・防衛は非合理ノイズとして除去せず、軽率な決定を止めるブレーキとして設計へ組み込む。Fearへ圧力を加える場合はExitを同時に用意する。

**4. Exit / Choice。** 売却だけでなく、賃貸、改修・建替え、相談・保留、合理的保有等を出口として並べる。数値は正解を命じるのでなく、どの条件なら各選択が成立するかを示す。

**5. Greed。** 投資家・業者・購入希望者の利益欲求・機会探索を市場の推進剤として認める。ただし無制御にせず、需要・条件・利害を可視化し、説明責任の下へ置く。

**6. Justice。** 公共性はFearやGreedを道徳的に押さえ込むためでなく、なぜ透明化と市場OSが社会に許容されるのかを説明する上位目的である。原典は防災、国土保全、地域持続、社会コスト等を例示する。

**7. Hate / Friction Sensor。** 反発・怒り・拒絶は、領域侵犯、変化抵抗、説明不足、出口不足、均衡ずれを示すセンサーとして扱う。クレームを仕様欠陥検出信号へ再定義する。

**8. Ethical Shield。** 不当な攻撃と正当な批判を分離し、覗き見・冷やかし・悪意の侵入を構造的に防ぎ、正当な問いを対話可能な回路へ送る防御構造。批判を消す壁ではない。

**9. Full-System Dependency。** Fear / Greed / Justice / Ethical Shieldを部分的に切り出さない。Fearだけなら圧力、Greedだけなら略奪、Justiceだけなら理想論となり、アーチが成立しない。

**10. Equilibrium Governance。** 張力均衡は固定値でなく、世論、災害、景気、制度変更等に応じて観測・調整し続ける運用状態である。「完成」を固定した時点で現実とのずれが蓄積する。

**11. Private / Public Boundary。** 民間OSは情報可視化、選択肢提示、判断材料、合意形成補助を担えるが、登記・税務・本人確認の国家保証、不参加者への義務、公共安全上の強制介入などは行政・法制度側の領域として分離する。

**12. Condition Z / T-S-R。** 再合意条件として定期監査、Transparency / Stability / Responsibility、公開監査束の整合を置き、閾値θ・観測窓δ・現象Mにより棄却・改訂可能性を保持する。

## 適用例
**所有者へのリスク可視化。** 老朽化、災害、税、修繕、相続等のリスクを示す際、危険だけを強調せず、売却、賃貸、改修、相談・保留、合理的保有等のExitを同時に提示する。

**需要・投資家側の設計。** 利益を求めること自体を隠さず、希望条件、価格、利回り、リスク等を可視化し、説明責任とアクセス条件の下で市場の推進力として使う。

**クレーム対応。** 「なぜ公開するのか」「勝手に価値を決められたくない」等を単なる感情処理へ送らず、公開範囲、説明、出口、公共目的のどこに設計ずれがあるかを検査する。

**公共目的の実装。** 防災・国土保全・地域持続などを広告文句として掲げるだけでなく、閲覧権、本人確認、説明、ログ、アクセス境界等へ反映し、透明化の正当性を実装面で支える。

**行政接続。** 民間が強制力を持たず、本人確認、登記、税務、公共安全等で必要な強制・国家保証は行政・法制度との接続点として明確に分離する。

## 測定・監査点
- 透明化による反発を異常扱いせず観測できているか。
- Fearが単なる圧力や脅しへ変わっていないか。
- Fearと同時に複数のExitが提示されているか。
- Greedが地下化せず、条件・利益・利害として可視化されているか。
- Greedが無制御の買い叩き・搾取へ転じていないか。
- Justiceの上位目的が具体的な実装境界へ落ちているか。
- 透明化が覗き見・情報搾取へ転化していないか。
- クレームから公開範囲、説明、出口、責任の設計欠陥を抽出できているか。
- Ethical Shieldが正当な批判まで遮断していないか。
- Fear / Greed / Justice / Ethical Shieldの一部だけを模倣していないか。
- 所有者側の不安・離脱、事業者側の粗いオファー、社会側の正当性理解等を均衡調整入力として観測しているか。
- 「完成」として均衡点を固定していないか。
- 民間と行政・法制度の強制力境界が明確か。
- Condition Zの監査周期、T/S/R、公開監査束が整合しているか。

## 成立条件
- 透明化が摩擦を生むことを前提にする。
- 市場を単一正義で支えず、複数の対立力を同時に扱う。
- Fearを排除せず、Exitとセットで制御する。
- Greedを否定せず、可視化・制御・説明責任の下へ置く。
- Justiceを公共的存在理由と境界の座標として実装する。
- ヘイトを抑圧対象だけにせず設計信号として読み取る。
- Ethical Shieldで悪意侵入と正当批判を区別し、対話回路を保持する。
- Fear / Greed / Justice / Ethical Shieldを一体で運用する。
- 均衡点を固定せず継続調整する。
- 民間OSに国家的強制力を持たせない。
- Condition Z / T/S/R / 監査束の整合を維持する。

## 失敗条件
- 「透明性は善だから」で反発を無視する。
- Fearだけを実装し、出口なしの危険訴求で所有者を追い込む。
- Greedを否定して地下化させる、または無制御に放置する。
- Justiceをきれいごとの広告文句にしてアクセス・説明・責任へ実装しない。
- 透明化を覗き見・冷やかし・買い叩きの情報源へする。
- ヘイトを論破・削除・沈静化だけで消そうとする。
- クレームを面倒な感情反応として捨てる。
- Ethical Shieldを批判封鎖や免責装置へ変える。
- Fear / Greed / Justice / Ethical Shieldの一部だけを模倣する。
- 均衡を完成済みの固定値として扱う。
- 民間主体が登記・税務・本人確認・不参加者への義務等の強制力を私的に持つ。

## 反証・改訂条件
原典の統合監査要旨は、構造設計・翻訳・束化・定義によって、恐怖・欲望・正義の摩擦を制度的循環へ変換する因果を置く。再合意条件Zは、定期的監査周期、T/S/R（Transparency / Stability / Responsibility）、公開監査束の整合である。

主要指標値が閾値θを下回る／上回る、または観測窓δに社会的逸脱、制度不全、信頼崩壊等の現象Mが確認された場合、仮説Aは棄却または改訂対象となる。親原典はすべての運用へ共通する固定θ・δ値を示していないため、派生側で普遍閾値を発明しない。

## 誤読禁止 / 解釈制約（原典適合）
- ヘイトを「機能している証拠」とする記述を、暴言・嫌がらせ・脅迫・差別・暴力の容認へ拡張しない。原典の対象は市場摩擦を観測し、対話・設計修正へ変換する構造である。
- Greedを市場燃料とすることを、買い叩きや搾取の免責へ変えない。原典は可視化、制御、説明責任を同時に要求する。
- Justiceを上位目的とすることを、公共目的を掲げれば個人資産への無制限アクセスが許されるという主張へ変えない。
- Ethical Shieldを異論排除、批判者攻撃、正当な問いの遮断に使わない。
- Exitを「売れ」という誘導へ縮約しない。相談・保留・保有を含む選択可能性がFear制御の条件である。
- 行政・法制度接続を、民間主体による本人確認・登記・税務・義務付けの私的強制へ一般化しない。
- アーチ比喩を物理法則として実証済みの自然法則へ変えない。市場構造を説明する理論モデルとして扱う。
