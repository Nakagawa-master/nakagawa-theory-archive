## 構造軸
```text
現場に不調の早期兆候が生じる
→ 個人の忍耐・自己管理に閉じる
→ 組織が早期に観測・共有・判断できない
→ 欠勤・休職・離職・事故などの遅行結果で初めて見える
→ 低負担で反復可能な接点を置く
→ 時間変化として観測する
→ 確認・配慮・支援・再観測へ使える判断材料になる
→ 現場不調が先行指標化される
```

## 数値・反転評価の境界
親原典は健康スコア、離職予測率、事故防止率、診断精度、危険確率、固定閾値を定義していない。

回答回数、回答率、アラート数、欠勤・離職件数は単調な改善指標ではない。負担増加、機械回答、監視不安、重要差分の埋没、申告抑制が生じれば悪化し得る。
