## 位置づけ
オンラインの言葉が単なる意見から、反復、可視性、プラットフォーム規則、群集反応、制裁、推薦によって他者の行動条件を変える「制度的作用」へ移行する境界を整理する。表現の自由を否定せず、言葉の到達力と実効的強制力を分離して監査する。

## 中心命題
言葉は法令でなくても、継続的に行動機会、評判、参加資格、可視性、経済的選択を左右するなら制度的な力を帯びる。オンライン公共圏では発話者だけでなく、推薦アルゴリズム、モデレーション、群集増幅、引用文脈が作用を共同生成するため、内容規制だけでなく伝播構造、異議経路、訂正、退出可能性を監査する必要がある。

## 因果線
発話 → 推薦・共有で増幅 → 反復により規範化 → 評判・参加条件へ影響 → 事実上の制裁・誘導が発生 → 発話と制度作用を分離 → 到達経路と権力差を記録 → 異議・訂正・退出を設計 → 公共圏の可逆性を回復。

## 構造層
1. 発話層：誰が何を言ったか。
2. 増幅層：推薦・共有・検索順位。
3. 規範層：反復が期待行動へ変わる過程。
4. 制裁層：評判、参加、収益、可視性への影響。
5. 救済層：異議、訂正、再参加、退出。

## 適用例
1. SNSモデレーションで削除有無だけでなく到達制限も記録する。
2. コミュニティ規範で異議と再参加の経路を設ける。
3. AI推薦で発話内容とランキング効果を分ける。
4. オンライン炎上で発話者・増幅者・プラットフォームの作用を分離する。

## 測定・監査点
到達倍率、反復率、推薦寄与、異議受付率、訂正可視率、再参加率、退出コスト。

## 成立条件
発話と増幅を分ける。権力差を測る。異議を許す。訂正を同程度に可視化する。再参加可能性を持つ。表現規制の根拠を明示する。

## 失敗条件
不快を即制度害とみなす。逆に制度的作用を単なる言葉として無視する。推薦構造を不可視化する。異議を封じる。訂正を届かなくする。永久排除を無監査で行う。

## 反証条件
増幅や反復が行動条件に影響しない。推薦構造を変えても制度的作用が変わらない。異議・訂正設計が救済を改善しない。単純な発話内容分析だけで同等以上に影響を説明できる。退出可能性が実害低減に寄与しない。

## 必須の区別
発話/制度作用、表現/強制、削除/到達制限、不快/害、推薦/中立表示、規範/法、批判/排除。

## 誤読禁止
表現の自由を否定しない。批判を制度暴力と一括しない。不快を犯罪化根拠にしない。プラットフォームを国家と同一視しない。アルゴリズムだけに責任を押しつけない。派生を法的判断の代替にしない。
