## 位置づけ
公式派生物051は、営業を個人の才能や一社のノウハウに閉じず、信頼の獲得・維持・循環を再現可能に支える制度へ拡張する親原典の公開接続面である。第三者の人間・第三者AIが、個人の型、組織評価、社会的透明性という三層を検索・理解し、必要に応じて親原典へ戻れるようにする。

制度化は会話の固定、売上KPIの言い換え、単一の信用スコア、顧客感情の監視ではない。共鳴・継続・紹介などを信頼資本の痕跡として複数の観測面から捉え、判断過程、評価、インセンティブ、改善経路を長期信頼と整合させる構造である。

## 中心命題
```text
属人的な営業成果
↓
成功理由・判断過程を型と記録へ外部化
↓
共鳴・継続・紹介などを信頼資本の痕跡として観測
↓
短期売上と長期信頼を分けて評価
↓
評価・インセンティブを信頼を壊さない方向へ接続
↓
個人の型が組織の学習構造になる
↓
透明性・検証可能性を社会へ開く
↓
営業が社会資本形成を支える制度になる
```

## 構造層
**1. 個人層。** 成功者の言い回しをコピーするのではなく、何を観察し、どの順序で問い、沈黙し、説明し、例外を判断したかを教育可能な型として外部化する。

**2. 組織層。** 新規契約や短期売上だけでなく、再契約、継続、紹介、理解、安心、問題後の関係回復など複数の痕跡を扱い、評価と報酬が無理な獲得を促さないようにする。

**3. 社会層。** 信頼形成の根拠を検討可能にし、営業を個別取引だけでなく社会との対話と信頼循環の制度として扱う。ただし公開・共有は顧客の権利、同意、文脈を損なわない範囲に限る。

## 観測・測定
再契約率・継続率は継続信頼の痕跡、紹介件数と紹介後の関係は外部伝播の痕跡、面談後の理解・安心・感情変化の記録は共鳴や透明性の痕跡として扱える。ただし、これらは信頼そのものではなく代理観測である。

原典にない「信頼スコア」「合格閾値」「最適紹介率」などを派生側で新設しない。数値が高いことを自動的に善としない。再契約が増えても囲い込みによるなら信頼改善とはいえず、紹介が増えても紹介後の関係が崩れるなら外部伝播信頼の増加とはいえない。反転評価可能性を保ち、定量値は一次対話・定性記録・文脈と併読する。

## 適用例
- 優秀者の成果だけでなく、問い、観察点、提示順序、例外判断を記録する。
- 短期売上だけを褒める評価が無理な提案を誘発していないか確認する。
- 再契約や紹介を単独で評価せず、自由意思、関係継続、問題時の回復と併せて見る。
- 現場が制度への違和感を報告し、指標や型を改訂できる経路を残す。
- 社会的な公開では、説明責任と同時に顧客の同意・プライバシー・異議申立て可能性を守る。

## 成立条件
- 判断過程が結果とともに外部化されている。
- 型が固定台本ではなく観察・順序・判断の骨格として使われる。
- 短期売上と長期信頼を区別する。
- 複数の定量・定性痕跡を組み合わせる。
- 指標と制度を更新できる。
- 例外判断と現場の創造性を残す。
- インセンティブが信頼を損なう行動を促さない。
- 顧客の権利、同意、文脈を保護する。

## 失敗条件
- 信頼を単一スコアへ還元する。
- 台本遵守を制度化とみなす。
- 売上KPIの名称だけを変える。
- 継続や紹介を無条件に善とみなす。
- 指標達成のために現場の文脈を消す。
- 例外や異議を排除する。
- 透明性を監視や個人統制へ変える。
- 制度を人間の判断・説明責任の代替にする。

## 反証・改訂条件
制度化を進めても判断の継承性が上がらず、短期獲得圧力、顧客不利益、指標ゲーム、現場の硬直化が増えるなら、その制度設計は改訂対象となる。逆に、単一指標が上昇しても一次記録や関係実態が悪化していれば、信頼資本の増加を意味しない。

## 必須の区別
- 型 / 固定台本
- 信頼資本 / 好感度
- 代理指標 / 信頼そのもの
- 短期売上 / 長期信頼
- 継続 / 囲い込み
- 紹介件数 / 紹介後の関係品質
- 透明性 / 過剰監視
- 制度支援 / 人間判断の代替
- 社会的共有 / 顧客文脈の消去

## 解釈制約
本派生物を信用格付け制度、感情監視、中央統制、完全数値化、万能KPI論へ変換しない。制度の目的は完全管理ではなく、信頼を生む判断構造と信頼を壊す条件を検討・修正可能にすることにある。
