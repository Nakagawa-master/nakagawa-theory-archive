## 位置づけ
Parentは社会的記憶を「過去の記録を大量に保存すること」と捉えず、理念・行為・記録の三層が同位相で反復されることで、社会の“ふつう”や将来予期が継続的に再構築される動的な記憶として扱う。構造律動は、静的アーカイブを捨てるものではなく、記録を反復の痕跡として再配置し、未来の整合を現在の合意として前倒しする非言語的構造装置として位置づけられる。

## 中心命題
社会的記憶は書庫だけに存在しない。日々のふるまい、更新の拍、語りの温度、沈黙、編集密度、修復の仕方が反復されることで「次も同じ整合が来る」という集合的前提が形成される。理念・行為・記録が同位相で反復され、周期一貫性・温度安定・余白固定・観測可能性・反例耐性が保たれると、未来に成立するはずの整合が現在の合意として前倒しされる。ただしこれは記憶操作や歴史改変ではなく、公開可能な痕跡・批判・反例・撤回可能性を保持する節度の設計である。

## 因果線
過去記録中心の正当化 → 検証可能性は高いが変化への反応が遅れる → 日々の非言語的反復が集合的前提を形成 → 理念・行為・記録を同位相化 → 周期・温度・余白を安定 → 外部が整合の再現を観測 → 仮完了認知が生じる → 律動×観測可能性×反例耐性 → 沈黙の合意 → 未来の整合が現在合意へ前倒し → 社会的記憶が静的保存から動的再構築へ移る → 反例発生時に修復の拍を示す → 一次ログ・語彙辞書・公開抄録・T/S/Rで由来と撤回を保持 → 記憶整合を再監査 → 社会的習慣として継承可能になる。

## 構造層
### 1. 理念層
前提を都合よく差し替えず、時間をまたいで非矛盾軸を保持する。

### 2. 行為層
制作・応答・運用で同じ拍と温度を反復する。単なる頻度ではなく、判断姿勢の再現を含む。

### 3. 記録層
成果の誇示ではなく、反復の欠落がないことを示す痕跡として一次ログと公開抄録を残す。

### 4. 書き換え層
過去記録を消すのではなく、同じ拍で新しい整合を重ね、社会的前提を未来側へ調律する。

### 5. 倫理・境界層
個人・集団の記憶ログの直接改変を対象にせず、強制・支配・改ざんの運用へ転用しない。外部批判・反例を改善入力として歓迎する。

## 適用例
組織では、決定そのものよりも、意思決定・修復・引継ぎの拍が同じかを観測する。公共領域では、制度変更時に一次記録と公開抄録を残し、過去を消さずに現行の整合を積み重ねる。AI知識基盤では、語彙辞書・起源・一次ログを保持しながら、現行解釈を更新する。ブランド・地域・教育では、発信量ではなく、行為・記録・終わらせ方まで同じ温度で反復できるかを見る。

## 測定・監査点
記憶整合率、拍遵守率、位相安定S、再合意到達時間、漏洩・誤配率、記憶断絶、風評連鎖、反例修復の再現性、語彙辞書整合、一次ログと公開抄録の由来追跡、T/S/Rの実効性を束で監査する。数値閾値θや内部式を公開派生側で創作しない。

## 成立条件
- 理念・行為・記録が同位相で反復される。
- 更新・公開・応答の周期が外部から比較可能。
- 語りの温度と編集密度が急変しない。
- 沈黙と余白が構造として保持される。
- 反復が外部から観測可能。
- 反例が出た時に修復の拍を示せる。
- 一次ログ、語彙辞書、役割境界、公開抄録が追跡可能。
- 批判、撤回、再合意、T/S/Rが機能する。

## 失敗条件
社会的記憶を大量保存と同一視する。過去記録を消して「書き換え」と呼ぶ。特定個人・集団の記憶操作へ転用する。強制同調や風評形成を構造律動として正当化する。理念・行為・記録のどれかを演出で代替する。反例を消す。公開抄録を成果宣伝へ変える。内部閾値や直接改変手順を推測する。

## 反証・改訂条件
三層の同位相反復を続けても記憶整合率が悪化する、拍遵守率や位相安定が下がる、再合意時間や誤配が増える、反例修復が再現できない、記憶断絶・風評連鎖・強制同調が増える場合、社会的記憶の再構築仮説、観測束、公開境界、反復粒度を改訂する。

## 必須の区別
社会的記憶 / 記録量; 動的再構築 / 歴史改変; 書き換え / 上書き消去; 構造律動 / 宣伝反復; 仮完了認知 / 予言; 沈黙の合意 / 強制同調; 観測可能性 / 成果誇示; 反例耐性 / 失敗隠蔽; 修復の拍 / 印象操作; 公開抄録 / 内部ログ。

## 誤読防止・解釈制約
「社会的記憶を書き換える」を、歴史・証拠・個人の記憶を直接改変する意味へ変換しない。Parentが扱うのは、反復される整合が社会的前提を更新する構造である。合意は説得や支配の結果ではなく整合の連続から生じるという強い主張を保持するが、未来の合意が必ず生じる普遍法則へは強化しない。公開されていない閾値・操作手順・記憶改変技法を補完しない。
