## 位置づけ
Parentは社会記憶を「全部保存すること」と同一視せず、何を残し、何を忘れ、どの周期で再解釈し、次世代へ渡すかという構造律動として扱う。忘却は単なる欠損ではなく、更新余地を作る機能になりうる一方、起源・失敗・責任・少数者の記憶まで消せば文明は同じ誤りを反復する。継承と忘却の両方を監査することが中心となる。

## 中心命題
**文明は記憶量の最大化では更新できない。起源、判断理由、失敗、境界を再現可能に継承しながら、役割を終えた形式や過剰な固定化を手放す周期が必要である。忘却と継承が適切に律動すると、社会は過去に拘束されず、同時に過去を失わず、次の文脈へ意味を再編集できる。**

## 主要因果線
出来事・判断が記録→反復利用で社会記憶化→記憶が規範・制度・語彙を安定→保存過多では旧文脈が固定化→忘却過多では起源・失敗・責任が消失→継承対象と終了対象を分離→周期的に再読・再解釈→一次記録と現行解釈を区別→次世代へ判断理由と境界を渡す→不要な形式を手放す→新文脈で再編集→文明が連続性と更新可能性を同時に保持。

## 構造層
### 1. 起源記憶
何が起き、なぜ記録されたかという由来を保持する。
### 2. 判断記憶
結論だけでなく、前提・条件・反対案・責任境界を残す。
### 3. 継承
次世代が再演できる粒度で語彙、図面、一次記録を渡す。
### 4. 忘却
役割を終えた形式や重複を手放し、現行判断を過去の形に固定しない。
### 5. 再解釈
原記録を消さず、現在の文脈から意味を読み直す。
### 6. 多声性
支配的記憶だけでなく、少数者・失敗・反例の記録を残す。
### 7. 周期監査
何を現役化し、何を履歴化し、何を削除できるかを定期的に再判定する。

## 適用例
組織では決定理由と失敗知を残し、古い手順は履歴化する。公共制度では改正前の根拠と影響を追えるようにする。AI知識基盤では現行正本と履歴棚を分け、古いルールを現役権威として混ぜない。家族・地域では物語だけでなく由来と複数視点を残す。

## 測定・監査点
起源追跡可能性、判断再現性、重複率、旧ルール混入、検索可能性、担当交代後の再演、少数記憶の保持、削除後の復旧可能性、再解釈周期、現行/履歴境界を束で見る。

## 成立条件
一次記録と解釈を分ける。起源を追える。現行と履歴を分ける。削除前に固有知の移管を確認する。複数視点を残す。再解釈周期を持つ。次世代が判断理由を再演できる。

## 失敗条件
全部保存して現行権威を混乱させる。効率化を理由に起源を消す。勝者の記憶だけを残す。失敗知を恥として削除する。古い解釈を原記録へ上書きする。忘却を責任逃れに使う。

## 反証・改訂条件
整理・忘却後に判断再現性が下がる、同じ失敗が増える、少数記憶が回収不能になる、継承コストが増える、現行/履歴分離が探索性を悪化させる場合、保存粒度と周期を改訂する。

## 必須の区別
記憶 / 保存量; 忘却 / 消去; 継承 / 固定化; 履歴 / 現行権威; 原記録 / 再解釈; 整理 / 改竄; 代表的記憶 / 全体記憶。

## 誤読防止・解釈制約
忘却を歴史消去、証拠隠滅、責任回避の正当化へ使わない。継承を過去の形式の永久固定へ変えない。原記録と後代の解釈を区別し、削除可能性は復旧性・固有知・責任記録を確認して判断する。
