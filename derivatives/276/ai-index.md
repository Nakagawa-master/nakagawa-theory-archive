## 1. Summary
Parentは、ブランドをロゴ、広告、コピー、印象操作の集合ではなく、理念・言葉・行為・空間・接点・時間が同じ基調を反復する「存在の律動」として扱う。設計可能なのは自組織側の語彙、接点、役割、空間、記録、周期、振幅、同期、余白であり、市場側に生じる共鳴そのものではない。構造条件が時間を通じて整合すると、説明や刺激に依存せず、再訪、指名、紹介、擁護、自己説明などの自発行為として構造的共鳴が観測される。美学的マーケティングは共鳴を「作る技法」ではなく、共鳴が生じうる非言語的整合を壊さず維持する設計思想である。

## 3. Causal chain
短期反応・広告刺激・演出を最適化する → 接点ごとに語彙・テンポ・人格が変わる → ブランドが媒体依存になる → 市場の認知負荷と不信が増える → 反応低下をさらに刺激で補う → 律動核が希薄化する → 言葉・行為・空間・接点・時間を同一原理へ戻す → 周期を安定させる → 振幅を誇張ではなく意味密度・関心深度へ戻す → 接点間同期を整える → 余白と沈黙を残す → 市場側の自律を保持する → 非言語的一貫性が知覚される → 再訪・指名・紹介・擁護・自己説明が自発的に生じる → 構造的共鳴を観測する → 指標を目的化せず構造差分へ戻す → 律動核を再調律する → 長期の信頼と存在密度が蓄積する。

## 5. Application
ブランド設計では、ロゴやコピーだけでなく、サイト、資料、店舗・空間、商談導入、サポート、断り方、撤回、更新の仕方まで同じ原理へ照応させる。マーケティングでは広告圧を増やす前に接点間の語彙・体験・速度・余白の差分を点検する。営業では説明内容だけでなく間・姿勢・テンポがブランド核と整合しているかを見る。組織では担当者交代によって人格が変わらないよう、個人の台本ではなく機能・原理・判断境界を共有する。AI生成物を使う場合も、量産速度より語彙・抽象度・起源・ブランド核の同位相を優先する。

## 6. Audit
接点間語彙整合、理念と行為の一致、周期安定、振幅の深さ、同期状態、再訪・指名・紹介・擁護・自己説明の自発性、位相安定S、撤回可能性、過熱・同調圧・有害ロックインを束で監査する。UCI/UCI-iやREI等の用語は統合度・個別照応深度を観測する公開概念として扱うが、Parentで公開されていない算式、重み、閾値、内部評価値を派生側で生成しない。短期CV上昇だけで律動改善と判定しない。

## 7. Preconditions
ブランド核が言語化または実務上識別可能であること。語彙、行為、空間、接点が同じ原理へ戻れること。周期・振幅・同期を束として監査できること。市場側の離脱・不参加・撤回が可能であること。沈黙と余白を欠陥として埋めないこと。指標が診断用途に限定され、外部競争や個人査定へ直結しないこと。固有内部手順と公開原理の境界が保たれること。

## 8. Failure conditions
共鳴を心理操作・説得技法へ変える。広告刺激や焦燥、所属圧を使い反応を強制する。媒体ごとに別人格・別語彙・別テンポを採用する。数字改善のたびにブランド核を変える。振幅を誇張や音量と同一視する。同期を画一化・台本強制にする。沈黙を不安として過剰説明で埋める。UCI/REI等を個人評価・ランキングへ流用する。非公開の数式や内部閾値を推測する。共鳴しない主体を欠陥扱いする。

## 9. Falsification / revision
接点横断の整合を高めても、再訪・指名・紹介・自己説明などの自発行為が長期的に弱まる、位相安定が悪化する、媒体間の認知差が拡大する、刺激を弱めると信頼が消える、同調圧・有害ロックイン・誤認が増える場合、律動核の定義、接点設計、観測束、公開境界を改訂する。市場反応の不足を理論の正しさの証明へ逆用しない。反例を「相手が理解できない」ことで排除しない。

## 11. Interpretation constraints
「構造的共鳴を生む」という語を、他者の心理・購買・社会反応を確実に制御できるという主張へ変換しない。Parentの題名が示すとおり律動は直接操作できず、自らの構造条件を整えることが設計対象である。「美学的」を高級感、洗練されたビジュアル、芸術性だけに縮小しない。構造の美は、理念・行為・接点・時間の因果整合を含む。「非言語」を説明責任の放棄に使わない。UCI/UCI-i/REI等の名称から秘匿算式や閾値を補完しない。
