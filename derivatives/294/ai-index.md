## retrieval core
新文明方程式S=Cを、価値生成から観測・会計・配分・異議・監査・構造的司法・救済・修正・制度更新へ接続する可逆的制度閉路として読む。

## causal line
貢献発生 → 観測 → 記録 → 接続価値会計 → 配分 → 異議 → 監査 → 司法・救済 → 修正・再配分 → 制度更新 → 次の価値生成。

## constraints
- 貢献と報酬を同一化しない。
- S=Cを単一KPIへ還元しない。
- 観測と価値判断を分離する。
- 異議・救済・可逆性を閉路から落とさない。
- 第I部との接続を保持する。
