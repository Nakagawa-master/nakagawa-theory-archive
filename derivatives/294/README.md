## 位置づけ
本派生物は、第I部で提示された文明Kernelを、価値循環、接続価値会計、構造的司法OS、監査、救済、可逆性まで含む制度閉路へ展開し、「S=C」を実運用へ接続するParentの構造を公開接続面へ展開する。

## 中心命題
貢献Cを文明の成功Sへ接続するだけでは制度は動かない。価値が観測され、記録され、配分され、異議を受け、誤配分が修正され、被害や外部化が救済され、制度自体が監査・改訂される閉路が必要である。

## 因果線
```text
貢献・接続価値の発生
→ 観測・記録
→ 接続価値会計
→ 配分・報酬
→ 異議・監査
→ 構造的司法・救済
→ 修正・再配分
→ 制度更新
→ 次の価値生成へ還流
```

## 構造層
1. 価値生成層
2. 観測・記録層
3. 会計層
4. 配分層
5. 監査層
6. 司法・救済層
7. 可逆・制度更新層

## 必須の区別
- 貢献と報酬を同義化しない。
- 観測と価値判断を分離する。
- 配分と司法を混同しない。
- 制度維持と制度正当化を同一視しない。
- S=Cを単一数値KPIへ縮約しない。

## 成立条件
一次ログ、複数観測、異議、救済、再配分、可逆性、監査、制度更新が閉路として接続されること。

## 失敗条件
価値観測の独占、報酬固定、外部化損失の脱落、異議不能、司法の形式化、制度更新不能。

## 反証・改訂条件
制度閉路を導入しても貢献と成功の接続が改善せず、外部化・不信・誤配分が継続する場合、会計・配分・司法・監査各層の因果仮説を再検証する。
