## Summary
第II部把新文明方程式 `S=C` 从文明Kernel转化为可持续运作的制度闭环。它不把贡献测量与报酬分配当成一次性计算，而是连接价值生成、观察、连接价值会计、分配、异议、审计、结构性司法、救济、修复和规则更新。

结构性司法不是只负责惩罚。它追踪错误结果背后的因果、权力配置、程序和外部化损失，再把责任连接到更正、再分配、救济和防止复发。

## Concepts
- **S=C**: 成功S与贡献C正确连接的规范Kernel。
- **价值循环**: 价值、资源、纠错和学习返回系统的循环。
- **连接价值会计**: 不单一货币化的指标束观察语言。
- **分配**: 报酬、资源、权限或机会的制度性配置。
- **异议**: 把漏掉的贡献或损害送回制度的输入。
- **独立审计**: 不由原评价／分配主体单独完成的复核。
- **结构性司法OS**: 对因果与程序进行纠错的制度层。
- **救济／修复**: 更正、再分配、恢复、说明、防复发。
- **制度闭环**: 修订后回到再观察和再合意。

## Causal chain
```text
价值生成
→ 分散观察
→ 连接价值会计
→ 分配
→ 异议
→ 独立审计
→ 结构性司法
→ 责任 / 救济 / 再分配
→ 规则更新
→ 再合意与再观察
→ S=C持续运作
```

## Applications
可用于贡献报酬制度、人机协作、公共资源分配、组织评价和纠纷处理。重点不只是“谁贡献了”，还要问“漏掉了什么、谁承担了外部成本、错误如何修正、规则如何学习”。

## Audit points
检查是否把贡献压缩成收入或职位，观察是否由单一主体控制，是否自动用总分发放报酬，异议是否被阻断，是否自我审计，损失是否被外部化，司法是否只剩惩罚，再分配是否不可用，以及规则是否无法从失败中学习。

## Preconditions
贡献因果、分散观察、连接价值会计、可说明分配、可用异议、相对独立审计、救济、可逆性和规则更新必须连成闭环。程序强度应与影响程度相适应，同时不能让责任消失。

## Failure modes
把S=C变成简单绩效工资，把会计指标直接换成金钱或地位，让同一主体评价／分配／审计，压制异议，用结构分析否定个人责任，或在外部化损失返回前就关闭制度，均属于失败。

## Falsification / update conditions
如果闭环没有改善价值回流、错误分配纠正、救济和制度学习，只增加程序成本，就应简化。如果贡献指标被攻略或产生新的权力集中，测量与治理层需要重新设计。

## Required distinctions
- S=C ≠ 简单绩效工资
- 贡献 ≠ 收入／所有权／职位
- 会计 ≠ 自动报酬计算
- 观察 ≠ 判决
- 结构性司法 ≠ 只处罚
- 救济 ≠ 抹去历史
- 可逆性 ≠ 无责任
- 修订 ≠ 任意改规则

## Misreading constraints
第II部不是自动分红机器。只有当观察、异议、因果责任、救济和修订持续运作时，文明Kernel才能成为制度。结构分析补充个人责任，而不是删除个人责任。
