## 原典から保持する中心構造
```text
社会時間の中では矛盾・ゆらぎ・ノイズが不可避
→ 全偏差の即時是正は硬直・過剰介入・監視化へ傾く
→ 全偏差の放置は未来負債・照応崩壊・信頼低下を蓄積する
→ STBで「観測を続けられる許容帯域」と「介入検討が必要な逸脱」を分ける
→ STB内の偏差をT/S/Rで記録する
→ EACで蓄積偏差を時間倫理T0に照らして束で再評価する
→ 許容帯域内なら運用を継続する
→ STB超過なら構造的免疫系の段階的起動を検討する
→ 逸脱レッジャ・再配置・情報開示・公開監査へ接続する
→ 最小介入と公共性・非所有性・長期整合を同時に維持する
```

## 中心概念の対応
- **STB / Structural Tolerance Band**: 誤差ゼロの基準ではなく、即時介入より観測・記録を優先できる緩衝帯域。
- **EAC / Ethical Audit Cycle**: 蓄積偏差を一定の倫理的リズムで再評価し、監査が遅すぎる未来負債と、速すぎる過剰介入の双方を避ける時間枠。
- **T / Time**: 変化速度、持続期間、遅延、将来への影響を扱う。
- **S / Structure**: 制度・ルール・概念の整合、不整合、重複、欠落、接続破綻を扱う。
- **R / Relation**: 主体間・領域間の照応、信頼、摩擦、協調可能性を扱う。
- **構造的免疫系**: STB超過を確認した後に、即時排除ではなく段階的な再検討と再配置へ進む応答構造。
- **時間倫理T0**: 現在の介入量だけでなく、将来負債と長期整合を同じ時間線で評価する基底。

## 適用境界
- STBを「問題が存在しない範囲」と読み替えない。STB内の偏差も観測・記録され、EACで再評価される。
- EACを毎週・毎月などの普遍固定周期へ置き換えない。負債の蓄積速度、遅延影響、領域特性によって周期は異なる。
- T/S/Rを原典にない単一の総合点へ統合しない。各軸の重要度は領域ごとに異なる。
- STB超過を即時制裁、直接支配、全面停止と同義にしない。
- 構造的公共性を「誰でも自由に所有できる」という意味へ変えない。非所有性と起源回帰を保持する。
- 多文明・多価値接合で完全一致を要求しない。相互に公共性を損なわない許容帯域を探索する位置づけを保持する。

## 数値・反証条件の保持
原典はT/S/Rの具体的数値化、STBの普遍的数値閾値、EACの固定日数を定めていない。したがって公開派生面で数値を具体化する場合、原典上の概念と個別実装値を分離し、対象、測定主体、出典、尺度、観測期間、利用範囲、非保証範囲を明示する必要がある。

`θ` は対象別に現行STB・EAC設計を棄却または改訂するための記号的閾値であり、全領域共通の点数ではない。`δ` は対象別の観測窓であり、固定日数ではない。`M` は観測窓内で公共性・長期整合を損なう対象別の観測現象を表し、具体内容は適用対象ごとに定義される。

## 反転評価
監査回数や介入件数が増えても、公共性、信頼、構造整合、未来負債が悪化するなら改善とは扱わない。逆に即時介入が少なくても、偏差記録、EAC再評価、将来負債の抑制、必要時の免疫起動が成立しているなら、介入件数の少なさだけで失敗とはしない。

短周期監査によって逸脱検出件数が増えても、監視・萎縮・過剰介入が増えるなら周期設計は再検討対象となる。長周期監査で表面的な運用負荷が減っても、修正可能な偏差が未来負債へ変わるなら同様に再検討する。
