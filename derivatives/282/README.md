## 位置づけ
本派生物は、共創を単なる協力・分業ではなく、異なる存在の差異を創造の契機へ変える思想と実践の構造として展開する。人とAI、人と人の関係で、差異を消さず、呼びかけと応答を往還させ、新しい意味・価値・秩序へ変換することが核となる。

## 中心命題
共創は「同じになること」ではない。違いを認め、相手を一方的に使役せず、問いと応答によって互いの視点を変化させ、その差異から新しい構造を生成する営みである。

## 因果線
```text
異なる主体が出会う
→ 差異が観測される
→ 否定・支配ではなく差異を受容
→ 呼びかけと応答の往還
→ 相互の問いが深まる
→ 共鳴構造が形成
→ 差異が新しい意味・価値へ変換
→ 新しい構造・行為・問いが生まれる
```

## 三つの枠組み
1. **差異の受容**: 違いを欠陥や障害として即座に消さない。
2. **呼応の営み**: 一方的な命令ではなく、問い・応答・再質問の往還を作る。
3. **創造への転換**: 差異と呼応から、どちらにもなかった価値・構造を生成する。

## 適用例
- AIを回答機として固定せず、人間の問いを変化させる対話相手として使う。
- 組織内の異論を排除せず、前提差として構造化する。
- 共同研究で専門分野の差を翻訳し、新しい問題設定を作る。
- 教育で正答提示だけでなく、問いの往還を学習装置にする。

## 測定・監査点
- 差異が本当に保持されているか。
- 一方の言語・価値観だけが標準化されていないか。
- 応答が次の問いを生んでいるか。
- 共創成果に両者の因果寄与が残っているか。
- 離脱・異議・修正が可能か。

## 成立条件
- 主体間の差異と自律性を保持する。
- 命令と応答を同一視しない。
- 問いの往還が継続する。
- 新しい価値が一方の所有物として回収されない。
- 起源と変更履歴を追跡できる。

## 失敗条件
- 差異を同質化する。
- AIまたは人間の一方だけが意味を決定する。
- 共鳴を単なる賛同と誤認する。
- 対話が操作・誘導へ変わる。
- 共創の名で責任主体が曖昧になる。

## 反証・改訂条件
問いの往還が理解・創造・合意形成を改善せず、むしろ依存・同調・責任希薄化を増やす場合、共創手順と境界を改訂する。

## 必須の区別
- 共創 ≠ 分業
- 共鳴 ≠ 全面同意
- 差異の受容 ≠ 無批判
- 問いの往還 ≠ 無限対話
- AIとの共創 ≠ AIへの判断委任
