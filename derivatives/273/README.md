## 位置づけ
ParentはOD272で定義されたAI自己監査原理を人間組織へ翻訳する。組織の失速原因を外部環境や人材優劣だけに求めず、語彙粒度・責任境界・合意単位の不整合から生じる「構造的矛盾」として捉え、問いと沈黙を使って矛盾を再配置し、可逆な実験と短い記録によって組織自身が更新可能になる共進化プロトコルを示す。

## 中心命題
**組織の矛盾を個人や部署の罪として扱うと、告発と沈黙が増え、学習可能性が失われる。矛盾を語彙・前提・評価軸・責任境界・合意単位の構造差分として対象化し、停止→観測→翻訳→再配置の沈黙監査、対象化→差分化→発火条件→再帰の問い型、可逆性→二重構文→測定→記録の進化プロトコルを反復すれば、失敗を局所差分として扱いながら再現可能な構造更新へ移行できる。**

## 主要因果線
組織内の自己矛盾を放置→同じ言葉の定義がずれる→責任が人名依存になる→目的/方法/資源の合意単位が混線→正しい人同士が正しく衝突→矛盾を人ではなく条件差分として検出→沈黙監査で即結論を止める→語彙・前提・責任境界を観測→感情を消さず二重構文へ翻訳→A/B/Cを同一平面へ対象化→定義・前提・評価軸の差を短文化→十分条件を明示→辞書更新を優先して再帰→小さな巻き戻し単位で実験→方向性を測定→結論・根拠・次手を三行記録→情報対称性・説明可能性が上がる→撤回コストが下がる→組織学習が人物依存から図面依存へ移る。

## 構造層
### 1. 構造的矛盾
矛盾は排除対象ではなく、次の構造へ移るための圧縮エネルギーとして扱う。まず「誰が悪いか」より「どの条件が噛み合っていないか」を問う。

### 2. 沈黙の監査
停止→観測→翻訳→再配置を挟み、善意の拙速を抑える。沈黙は賛否保留ではなく解像度調整である。

### 3. 問いの型
主張A、主張B、場の条件Cを同一平面へ置く。A/Bの定義・前提・評価軸差を列挙し、合意成立の十分条件を記述し、一度で整わない場合は用語辞書更新へ戻る。

### 4. 進化プロトコル
可逆性→二重構文→測定→記録。失敗を罰に直結させず、巻き戻せる単位で試行し、感情と構造を分離記述し、方向性を測り、再現可能な最小記録を残す。

### 5. 公開ミニマムセット
一枚図に目的・制約・役割・期限・合意単位を置く。辞書更新日に日付を付ける。合意単位を先出しし、巻き戻し単位を実験スロットとして持ち、会議冒頭に沈黙スロットを設ける。

### 6. リスク境界
順位化、告発、万能鍵化を避ける。資源・時間・権限制約を消さず、公開対象は姿勢・枠組み・観測変数に限定する。固有名・内部手順・閾値は推測公開しない。

### 7. 三つの帰結
辞書と図面共有による情報対称性上昇、機能責任と仮説差分による摩擦コスト低減、適用領域評価と図面依存による学習再現可能化。

## 測定・監査点
語彙整合率、境界明瞭度、合意反復の減衰度、撤回コストを公開変数として方向で観測する。加えて合意単位・十分条件・可逆性の明文化、沈黙スロット、三行記録、辞書更新日の存在、人物名でなく機能名の責任線、資源・時間・権限制約の保持を監査する。

## 成立条件
- 構造的矛盾を人格評価へ還元しない。
- 合意単位を目的/方法/資源から明示する。
- 用語定義と更新日を共有する。
- 責任境界を機能名で描く。
- 沈黙監査を会議・判断へ組み込む。
- 感情と構造を二重構文で記録する。
- 十分条件を先に明文化する。
- 小さな巻き戻し単位を確保する。
- 三行記録で再現可能性を残す。

## 失敗条件
- 誰が正しいかの順位化へ戻る。
- 矛盾を個人告発へ変える。
- 目的・方法・資源を一つの合意として混ぜる。
- 用語辞書を更新せず同じ言葉の意味差を放置する。
- 沈黙を無駄として即答・即決を強制する。
- 感情を削除するか、感情だけで構造判断する。
- 不可逆な大規模変更を一度に行う。
- 固有内部手順や閾値を公開安全版から推測する。

## 反証・改訂条件
語彙整合率・境界明瞭度が改善しない、同一論点の再燃が減衰しない、撤回コストが上がる、合意単位や十分条件が明示されても攻撃性・責任混線・不可逆性が増す、三行記録から判断を再演できない場合、共進化プロトコルの構成・問い型・沈黙運用を改訂する。

## 必須の区別
構造的矛盾 / 人格欠陥; 沈黙 / 遅延; 問い / 詰問; 二重構文 / 感情否定; 可逆性 / 無責任; 機能責任 / 人名責任; 合意単位 / 会議参加; 正速 / 拙速; 図面依存 / ヒーロー依存; 公開枠組み / 秘匿内部手順。

## 誤読防止・解釈制約
「矛盾は資源」という表現を、対立を意図的に増やすべきだという主張へ変換しない。Parentは既に存在する不整合を安全に可視化し、再配置する設計を述べる。「沈黙スロット1〜3分」は公開例であり、全場面に固定適用する普遍閾値ではない。組織の権力差、資源差、法的責任を無視して万能手順化しない。
