## 1. Summary
Parent把OD272中的AI自我审查原理翻译为组织的自我进化协议。组织停滞不被简化为人员能力或努力不足，而被看作词汇粒度、前提、评价轴、责任边界和合意单位错位所形成的结构性矛盾。矛盾不作为人格罪责处理，而作为可重新配置的差分。通过沉默审查、结构化提问、可逆性、情绪/结构双重句法、方向性测量和三行记录，组织学习从英雄依赖转向可再现的图面依赖。

## 2. Concepts
结构性矛盾; 共进化协议; 提问与沉默; 词汇粒度; 责任边界; 合意单位; 目的/方法/资源; 沉默审查; 停止; 观察; 翻译; 重新配置; 对象化; 差分化; 触发条件; 递归; 词汇表更新; 可逆性; 实验槽; 双重句法; 情绪; 结构; 词汇一致率; 边界清晰度; 合意反复衰减; 撤回成本; 三行记录; 一页图; 词典更新日; 沉默槽; 信息对称性; 摩擦成本; 正速; 图面依赖。

## 3. Causal chain
内部矛盾被放置 → 同一个词具有不同定义 → 责任固定到个人 → 目的/方法/资源被混在一个模糊合意中 → 善意的人彼此冲突 → 先问“哪些条件没有咬合”而不是“谁错了” → 中断发言到结论的直连 → 观察词汇、前提、责任边界 → 把情绪热度翻译为结构配置 → 把主张A、主张B和场景条件C放在同一平面 → 明示定义、前提、评价轴差分 → 写出充分条件 → 未达成合意时回到词汇表更新 → 用可逆小单元试验 → 分开记录情绪和结构 → 测量方向性变化 → 用结论/依据/下一步三行保存 → 提高可再现性与信息对称性 → 降低撤回成本 → 组织学习从人物依赖转为图面依赖。

## 4. State model
`contradiction_visible -> vocabulary_difference_detected -> functional_boundary_drawn -> consensus_unit_declared -> silence_window_opened -> emotion_structure_separated -> claims_context_objectified -> differences_explicit -> sufficient_conditions_declared -> glossary_updated -> reversible_experiment_run -> observables_checked -> three_line_record_saved -> replayability_rises -> withdrawal_cost_falls -> learning_becomes_diagram_dependent`

## 5. Application
会议开始先声明当前讨论的是目的、方法还是资源分配。把目的、限制、角色、期限、合意单位放到同一张图。重要词语附上更新时间。冲突时把情绪内容和结构内容分开记录，责任用功能名而不是个人名。决策拆成可回滚的实验槽。记录不追求数量，只保留结论、依据和下一步，使未来的人能够重演判断。

## 6. Audit
公开观测包括词汇一致率、责任边界清晰度、同一论点的再次燃起次数、撤回成本。还要检查合意单位是否在开头声明、充分条件是否明确、沉默是否真正形成观察窗、责任是否按功能表达、词汇更新是否有日期、三行记录能否重演判断，以及资源、时间、权限限制是否仍然可见。

## 7. Preconditions
不能把矛盾还原为人格缺陷。必须能检查定义差异。责任边界需要按功能表达。合意单位要区分目的、方法与资源。沉默能作为观察窗。情绪被保留但与结构判断分离。充分条件先于承诺。决策可拆为可逆单元。最小记录保持可再现性。

## 8. Failure conditions
重新回到“谁正确”的排序；把矛盾变成告发；放置定义差异；责任固定到个人；把目的、方法和资源混为一个模糊合意；只奖励立即发言与立即决定；压抑情绪或仅凭情绪进行结构判断；实施大规模不可逆变更；把公开例子固定为万能模板；推测未公开阈值或内部流程。

## 9. Falsification / revision
如果词汇一致率和边界清晰度不改善、同一论点反复不衰减、撤回成本增加、明确合意单位和充分条件后攻击性或责任混乱反而上升、三行记录无法重演判断、所谓可逆试验实际无法回滚，就应修订提问格式、沉默审查和进化协议。

## 10. Required distinctions
结构性矛盾 / 人格缺陷; 提问 / 逼问; 沉默 / 放弃; 可逆性 / 无责任; 情绪/结构双重句法 / 情绪否定; 功能责任 / 人格责任; 合意单位 / 参会; 正速 / 美化迟缓; 图面依赖 / 英雄依赖; 公开例子 / 固定阈值; 结构更新 / 全面破坏。

## 11. Interpretation constraints
不要把“矛盾是压缩能量”理解为应主动制造冲突。Parent处理的是已经存在的不整合。公开例中的1～3分钟沉默槽不是普遍固定时间。不要把提问格式用于人事审讯或操控。不能从图面中删除组织内部权力差、法律责任、资源限制与心理安全。不要推测未公开的内部手顺和具体阈值。
