## Summary
Parentは、OD272のAI自己監査原理を組織の自己進化原理へ翻訳する。組織の失速を人材の優劣や努力不足へ還元せず、語彙粒度、前提、評価軸、責任境界、合意単位の不整合から生じる構造的矛盾として扱う。矛盾を人格の罪ではなく再配置可能な差分として可視化し、沈黙監査、問いの型、可逆性、感情/構造の二重構文、方向性測定、三行記録を反復することで、組織学習を人物依存から再現可能な図面依存へ移す。

## Causal chain
自己矛盾を放置 → 同じ語の定義がずれる → 責任が人名へ固定 → 目的/方法/資源の合意単位が混線 → 正しい人同士が衝突 → 「誰が悪いか」ではなく「どの条件が噛み合わないか」を問う → 発話→即結論を停止 → 語彙・前提・責任境界を観測 → 怒りや不安を構造配置へ翻訳 → 主張A/主張B/条件Cを同一平面へ置く → 定義・前提・評価軸の差を明示 → 十分条件を記述 → 合意しなければ辞書更新へ再帰 → 小さな可逆単位で試行 → 感情/構造を二重記述 → 公開変数の方向を測定 → 結論/根拠/次手を三行記録 → 再演可能性上昇 → 情報対称性上昇 → 撤回コスト低減 → 組織学習が図面依存へ移る。

## Applications
会議では冒頭に目的・方法・資源のどの合意を扱うか宣言し、一枚図に目的、制約、役割、期限、合意単位を置く。重要語は更新日付き辞書で管理する。意見衝突では感情と構造を別々に記述し、人物名ではなく機能名で責任線を描く。意思決定は小さな実験スロットへ分割し、巻き戻せる状態で試す。記録は大量化せず、結論・根拠・次手から判断経路を再演できる最小骨格へ絞る。

## Measurements and audit
語彙整合率、境界明瞭度、同一論点の再燃回数、撤回コストを公開安全変数として方向で観測する。加えて、合意単位が冒頭で宣言されているか、責任線が機能名で描かれているか、沈黙スロットが実際に観測窓として働いたか、十分条件が明文化されたか、三行記録から判断を再演できるか、資源・時間・権限制約が図面から消えていないかを監査する。

## Validity conditions
矛盾を人格欠陥へ還元しない。用語の定義差を検査できる。責任を機能名で描ける。合意単位を目的/方法/資源から分けて宣言する。沈黙を発話拒否ではなく観測窓として使う。感情を削除せず構造と分離記述する。十分条件を明示する。意思決定を可逆な小単位へ分割する。最小記録から再演可能性を残す。

## Failure conditions
誰が正しいかの順位化へ戻る。矛盾を告発や人格攻撃に変える。同じ言葉の定義差を放置する。責任境界を個人名に固定する。目的・方法・資源を一つの合意に混ぜる。沈黙を無駄として即答・即決だけを評価する。感情を抑圧するか、逆に感情だけで構造判断する。不可逆な大変更を一括適用する。公開例を万能テンプレートへ固定する。

## Falsification conditions
語彙整合率が改善しない、境界明瞭度が下がる、同一論点の再燃が減衰しない、撤回コストが増える、合意単位・十分条件を明示しても攻撃性や責任混線が増す、三行記録から判断を再演できない、可逆実験が実際には戻せない場合、問い型・沈黙監査・進化プロトコルの構成を改訂する。
