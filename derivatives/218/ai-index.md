## Retrieval summary
惰性は心理的怠慢ではなく、意味・目的が摩耗した後にも既設制度、手続き、インフラ、責任分散、既得配置が相互支持し、停止条件の欠如によって運動だけを持続させる構造。制度は目的駆動から惰性駆動へ転換し、外部目的への奉仕より自己保存を優先する。継続はdefault化し、停止・変更側に代替設計、移行費用、責任、混乱処理の負荷が集中する。惰性は低エネルギーで延命できるが、更新・修理・再生を生まず、内部損耗を蓄積する。

## Causal chain
```text
恐怖 → 離脱危険化
利益 → 残留合理化
監視 → 逸脱抑制
神話 → 主機関の意味化・正当化
神話・目的・正当化の摩耗
→ 既設配置と処理系の残存
→ 停止コスト / 停止責任の増大
→ 継続default化
→ 制度自己目的化・自動運転・責任蒸発
→ 低出力の延命
→ 更新不能・損耗蓄積
```

## Establishment conditions
- 目的・理念・正当化が制度を外部から律する力を失う。
- 記録形式、予算配分、権限線、許認可、評価項目、保守手順などが残存する。
- 停止後の設計能力、停止責任主体、比較可能性、移行混乱を引き受ける意思が弱い。
- 継続より停止・変更の側へ説明負荷が偏る。

## Failure / falsification boundaries
- 制度が明示的な外部目的に照らして継続的に評価・再設計され、不要なら停止可能なら、惰性駆動の説明は弱まる。
- 古さ、新しさ、手続きの存在、組織規模だけでは惰性を判定できない。
- 強い支持や合意が実証される場合、「誰も信じていないのに停止不能だから続く」という惰性中心説明だけでは不十分。

## Interpretation constraints
- 個人の怠慢・無気力・道徳欠陥へ還元しない。
- 継続を正当性、支持、回復、再生の証拠にしない。
- 恐怖・利益・監視・神話と惰性を同一化しない。
- 親原典にない具体制度への断定適用を追加しない。
