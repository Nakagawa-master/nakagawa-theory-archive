## Retrieval summary
这里的“惰性”不是个人懒惰、消沉或道德缺陷，而是一种结构性持续方式：当意义、目的和正当化已经变薄，既有制度、程序、基础设施、分散责任和既得配置仍相互支撑，使运动本身继续存在。制度不再主要因为外部目的而运行，而是因为“已经在运行”而继续；继续成为默认状态，停止或改变的一方反而承担替代设计、转移成本、责任主体和过渡混乱的证明负担。惰性能以较低能量延命，却不能产生修理、更新和再生。

## Causal chain
```text
恐惧 → 离开变得危险
利益 → 留下被合理化
监视 → 偏离被抑制
神话 → 为这些机制提供意义与正当化
意义与目的继续磨损
→ 既有程序和配置残留
→ 停止成本 / 停止责任上升
→ 继续成为默认
→ 制度自我目的化 / 自动驾驶 / 责任蒸发
→ 低能量延命
→ 无再生的内部损耗累积
```

## Establishment conditions
- 外部目的已难以实际约束制度运动。
- 记录格式、预算分配、权限线、许可、评价项目、维护程序等仍互相咬合。
- 缺少停止后的设计能力、承担停止责任的主体、可比较的评价条件，或承受过渡混乱的意愿。
- 继续几乎无需说明，而停止和改变承担不对称的说明负担。

## Failure / falsification boundaries
- 如果制度持续接受外部目的的评价，在无效时能够重构，在不必要时能够真正停止，那么以惰性为中心的解释会减弱。
- 制度古老、存在官僚程序或组织规模大，本身不能证明惰性。
- 若存在可验证的积极同意与支持，不能把一切持续都解释为“无法停止”。

## Interpretation constraints
不要把惰性还原为个人道德问题；不要把持续等同于正当性、支持、恢复或再生；不要把惰性与恐惧、利益、监视、神话混为同一机制；不要添加原典没有针对具体制度作出的断言。
