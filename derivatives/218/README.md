## 位置づけ
本原典は、耐久文明を長期化させる増幅装置としての「惰性」を扱う。ここでいう惰性は個人の怠慢や無気力ではなく、意味・目的・正当化が摩耗した後にも、制度・手続き・インフラ・責任配置・既得配置が相互支持し、「すでに動いている」という事実によって運動だけが継続する構造である。

恐怖が離脱を危険化し、利益が残留を合理化し、監視が逸脱を抑え、神話がそれらへ意味を付与した後、その意味供給すら弱まってもなお制度が止まらない段階が惰性として現れる。惰性は新しい目的や正当化を供給せず、既設回路の残存によって耐久文明を低エネルギーで延命する。

## 中心命題
惰性の中心は「信じられているから続く」のではなく、「止める条件・主体・比較基準・移行能力が失われているため続く」という点にある。制度の外側にあった目的が弱まり、制度自身の存続が継続理由へ反転すると、目的駆動から惰性駆動への転換が起こる。

この転換では、継続は無説明で許されやすい一方、変更・停止側だけが代替案、移行費用、責任主体、混乱処理を求められる。結果として制度は自己目的化し、責任が蒸発し、運動は維持されても更新・修理・再生は生まれず、内部損耗が蓄積する。

## 因果線
```text
恐怖が離脱を危険化する
→ 利益が残留を合理化する
→ 監視が逸脱を抑える
→ 神話が主機関へ意味と正当化を与える
→ 時間経過で意味・目的・正当化が摩耗する
→ それでも制度・手続き・予算・権限・インフラ・責任配置が残る
→ 継続がdefault化する
→ 停止・変更側へ代替設計・移行費用・責任・混乱処理が集中する
→ 制度が外部目的より自己存続を優先する
→ 自動運転・責任蒸発・自己目的化が進む
→ 低エネルギーで運動だけが残る
→ 更新・修理・再生が起きず損耗が蓄積する
```

## 構造層
**1. 意味摩耗層。** 制度を支えていた理念・目的・神話が弱まり、強い納得や信念が継続条件ではなくなる。

**2. 既設回路残存層。** 手続き、予算、権限、許認可、保守、記録、評価項目などが相互接続したまま残る。

**3. 継続default層。** 「すでに動いている」ことが事実上の継続理由になり、停止だけが特別な説明を要求される。

**4. 停止負荷集中層。** 代替設計、移行費用、責任、比較基準、混乱処理が停止・変更側へ偏る。

**5. 自己目的化層。** 本来の外部目的より組織・予算・権限・手続きの維持が優先される。

**6. 責任蒸発層。** 個々の主体が既存処理の継続へ接続され、誰も停止判断を引き受けにくくなる。

**7. 低エネルギー延命層。** 新しい熱狂や正当化を作らなくても昨日の回路が残ることで運動が続き、しかし再生能力は回復しない。

## 適用例
**制度運用。** 本来の目的達成度より「前年と同じ予算・手順・権限を維持すること」が中心になっていないかを見る。

**組織。** 成果が弱くても「止める理由がない」「変更すると責任が発生する」という理由だけで活動が継続していないかを見る。

**行政・公共制度。** 継続側には説明が求められず、見直し側だけが完全な代替案と移行責任を要求されていないかを分ける。

**社会分析。** 制度が動いている事実を、支持・正当性・回復・再生の証拠と誤認していないかを見る。

## 測定・監査点
- 制度の外部目的と現行運用を比較できる基準が残っているか。
- 「何のために続けるか」より「なぜ止めるのか」が中心問いになっていないか。
- 継続と停止で説明責任が非対称になっていないか。
- 変更側にだけ代替案・移行費用・責任・混乱処理が集中していないか。
- 成果より組織・予算・手続き・権限の維持が優先されていないか。
- 制度が無効でも停止・再設計できる実効的経路があるか。
- 「動いていること」と「機能していること」を区別できているか。
- 継続が修理・更新・再生と誤認されていないか。

## 成立条件
- 制度を外部から律していた目的・理念・正当化の力が弱まっている。
- 手続き・予算・権限・インフラ・責任配置など既設回路が残っている。
- 継続が事実上のdefaultとなっている。
- 停止後の設計能力、停止責任主体、比較可能性、移行混乱を引き受ける意思が弱い。
- 継続より停止・変更の側へ説明負荷が偏っている。

## 失敗条件
- 惰性を個人の怠慢や無気力へ還元する。
- 古い制度であることだけで惰性と判定する。
- 新しい制度なら惰性ではないとみなす。
- 継続を支持・正当性・回復・再生の証拠にする。
- 恐怖・利益・監視・神話と惰性を同一化する。
- 停止コストを金銭だけに限定する。
- 制度が目的に照らして実際に更新・停止可能である事実を無視する。

## 反証・改訂条件
制度が明示的な外部目的に照らして継続的に評価され、成果が弱い場合には実際に再設計され、不要なら停止でき、継続側にも停止側と同等の説明責任が課されているなら、惰性駆動を中心とする説明は弱まる。

また、制度継続が実証可能な強い支持・目的適合・更新能力によって支えられている場合、「止められないから続く」というモデルだけでは不十分であり、適用範囲を改訂する必要がある。

## 必須の区別
- 惰性 ≠ 個人の怠慢。
- 継続 ≠ 正当性。
- 継続 ≠ 支持。
- 運動 ≠ 機能。
- 延命 ≠ 再生。
- 古さ ≠ 惰性。
- 手続きの存在 ≠ 惰性。
- 停止コスト ≠ 金銭コストだけ。
- 惰性 ≠ 恐怖・利益・監視・神話。

## 誤読禁止 / 解釈制約
本論は古い制度、官僚制、手続き、組織一般を否定するものではない。観測対象は、制度が外部目的から切れ、継続自体を目的化し、停止・変更側だけへ負荷を集中させ、更新・修理・再生なしに運動を残しているかである。

「誰も信じていない」という表現を全員の心理状態の実測値として扱わず、強い信念や共有された正当化が継続条件でなくても制度運動が残る構造として読む。原典にない固定数値、閾値、惰性スコアを公式条件として追加しない。

## 親原典へ戻る理由
本派生物は「目的駆動から惰性駆動への転換」と「停止条件を失った制度運動」を検索・理解可能にする面である。惰性が耐久文明シリーズのどこに位置し、恐怖・利益・監視・神話からどう接続し、次の共圏へどう進むかは親原典へ戻って確認する必要がある。
