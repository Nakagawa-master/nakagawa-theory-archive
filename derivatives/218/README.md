## この派生物の役割
本派生物は、親原典が定義する「惰性」を、単なる怠慢や信念の残骸ではなく、意味・目的が痩せた後にも既設制度、手続き、インフラ、責任分散、既得配置が相互支持して運動だけを残す構造として再利用可能にする入口である。

親原典では、恐怖が離脱を危険化し、利益が残留を合理化し、監視が逸脱を抑え、神話がそれらを意味へ翻訳した後、神話すら摩耗した段階で「信じられていないのに続く」惰性が露出する。惰性は秩序を正当化せず、未来を約束せず、更新も生まない。それでも「止める条件が失われている」ため、壊れた制度を壊れたまま持続させる。

## 中心構造
```text
目的・意味・正当化の摩耗
→ 既設制度・手続き・インフラ・責任分散・既得配置が残存
→ 継続がdefault化し、停止側へ説明責任・移行費用・代替設計負荷が集中
→ 目的駆動から惰性駆動へ転換
→ 制度の自己目的化 / 自動運転 / 責任蒸発
→ 低エネルギーで運動は残る
→ 更新・修理・再生は生まれず損耗が蓄積
→ 見かけの安定と実際の延命が乖離
```

## 読解上の固定点
- 惰性を個人の怠慢・無気力・道徳的欠陥へ還元しない。
- 「続いている」ことを正しさ・合意・再生の証拠にしない。
- 古い制度であること自体を惰性とみなさない。目的に照らして更新可能なら惰性駆動とは異なる。
- 新しい制度でも、継続自体を目的化し停止側だけへ過大な立証負荷を置けば惰性駆動になりうる。
- 恐怖・利益・監視・神話との直列関係を保ち、惰性をそれらの単純な同義語にしない。

## 観測ポイント
1. 制度評価の外部基準が残っているか。
2. 「何のために続けるか」より「なぜ止めるのか」が支配していないか。
3. 継続には説明不要、変更・停止だけに代替案、移行費用、責任負担が集中していないか。
4. 成果より組織・予算・手続き・権限の維持が中心化していないか。
5. 運動の継続が更新・修理・再生と誤認されていないか。
