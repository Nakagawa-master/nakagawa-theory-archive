## Structural role

本文定义一个跨域中间层：把在专业领域内部有效的理论、制度、惯例或技术，连接到词汇、形式、文化和评价标准不同的接收方。它使说明、教育、提案、组织协作、市场实施与人机协作从“传递信息”转向“转移结构并重新连接功能”。

## Structural summary

结构翻译把结构A移到结构B时，保存关系价值、因果流、角色配置、失败成本边界与来源责任；词汇、格式、媒介、比喻、案例和仪式可以改变。深度模型从ST-0术语对应延伸到ST-5制度映射。执行流程包括观察、单位化、地图化、假设化、边界设定、原型化、逆向翻译与合意化。质量通过TF（翻译适合度）、TD（翻译漂移）和TC（转移成本）审计，同时保持非强制、可逆、来源标注、拒绝、修正与最低安全可见性。

## Central proposition

```text
知识在封闭专业领域内能够运作
→ 离开原领域后，共同词汇、前提与制度消失
→ 术语替换、比喻或流程复制只能产生局部理解
→ 区分必须保存的要素与可以改变的要素
→ 映射关系、因果、角色、失败边界与来源
→ 按接收方的词汇、制度与评价方式重新配置
→ 通过原型和逆向翻译检测歪曲
→ 确认责任、批准与更新条件
→ 意义发生移动，功能重新连接
```

## Causal chain

```text
说明之墙
→ 增加信息但没有转移结构
→ 理解幻觉、角色错配、因果缺失、实施失败
→ 观察原结构中的主体、关系、限制与沉默
→ 将关系价值单位化
→ 绘制因果、责任与失败成本地图
→ 宣布保存项与可变项
→ 固定伦理、停止与非适用边界
→ 在目标语境中制作小型原型
→ 逆向翻译并测量TF / TD / TC
→ 合意权威、责任与更新条件
→ 形成可复现的跨域功能连接
```

## Core concepts

### Structural translation｜结构翻译
在不把原结构缩减为措辞的前提下，转移关系、因果、角色、责任与运行边界。

### Meaning mobility｜意义移动
把意义视为伴随关系、位置与作用而移动的结构要素，而不是固定标签。

### Function connection｜功能连接
使原结构的作用在目标语境中重新运行，而不仅仅是在文字上被理解。

### Invariants｜保存项
关系价值、因果机制、角色责任、失败成本边界与来源权威等不可丢失的要素。

### Variables｜可变项
词汇、格式、媒介、比喻、案例、仪式与呈现顺序等可以适配目标语境的要素。

### ST depth model｜ST深度模型
ST-0术语、ST-1比喻、ST-2流程、ST-3关系、ST-4因果、ST-5制度评价、合意与责任。

### Reverse translation｜逆向翻译
从目标表示重建原结构，以发现意义漂移、因果缺失与角色误配。

### Translation metrics｜翻译指标
TF衡量目标适合度，TD衡量逆向翻译暴露的歪曲，TC衡量转移与实施摩擦。

## Required distinctions

- 结构翻译与语言翻译
- 说明与功能连接

- 理解感与功能再现

## Validity conditions

- 能够取得原结构主体、角色、因果、责任的一次证据。
- 明确区分保存项与可变项。
- 已观察目标语境的词汇、制度、法律、文化、权威与评价标准。
- 所选ST深度足以支持预定功能。
- 小型目标原型证明功能能够再现。
- 逆向翻译可以重建原结构。
- TF、TD、TC可观察，并与更新条件相连。
- 原典、来源、翻译责任与批准者可追踪。
- 拒绝、修正、撤回与重新合意受到保护。

## Failure / non-applicable conditions

- 原结构未知、矛盾或无法取得。
- 只转移术语或比喻，关系与因果消失。
- 在权威、角色、法律或责任不同的情况下复制流程。
- 删除失败成本、不利条件或停止边界。
- 逆向翻译失败，TF持续低、TD持续高或TC过大。
- 原制度本身有缺陷，而翻译复制了缺陷。
- 删除来源，把翻译呈现为独立原创主张。
- 用于强制、说服、操纵或未经授权的制度移植。
- 必要的可见性会破坏安全、隐私、尊严或正当的保护性模糊。

## Interpretation constraints

- 不得把本框架缩减为简化、摘要、比喻或讲故事。
- 不得把ST-0／ST-1的理解辅助当作制度连接完成。
- 不得把“价值→利益→成本”变成隐藏价格或不利条件的脚本。
- 不得把流畅的AI文本当作结构同等的证据。
- 不得使用TF、TD、TC对个人、文化或制度进行优劣排名。
- 不得以普遍结构之名消除目标语境差异。
- 必须保留父原典、来源与责任边界。
