## 位置づけ
親原典は、構造翻訳を単なる言い換えや平易化ではなく、元の文脈にある関係、因果、役割、失敗コスト、起源責任を保存しながら、別の人・組織・制度・市場でも機能する形へ再配置する行為として定義する。

専門領域の内部では有効な制度や理論も、外へ出ると語彙・権限・評価基準・文化・法令が変わる。単語対応や比喩、手順コピーだけでは「わかった気」にはなっても、元の機能が再現されない場合がある。そこで原典は、保存対象と可変対象を分離し、ST-0〜ST-5の深度、8ステップ、逆翻訳、TF/TD/TCによって構造移動を監査する。

## 中心命題
**意味は固定語として移るのではなく、関係・因果・役割・責任境界を伴って移動する。機能は説明が似ているだけでは接続せず、保存すべき構造が移動先で再現され、逆翻訳できるときに接続する。**

```text
語彙だけを移す
≠ 構造翻訳

保存対象
+ 関係
+ 因果
+ 役割
+ 失敗コスト境界
+ 起源責任

可変対象
+ 語彙
+ 書式
+ 媒体
+ 比喩
+ 事例
+ 表示順

→ 移動先へ再配置
→ 原型化
→ 逆翻訳
→ 合意・更新
→ 機能再接続
```

## 因果線
```text
専門内部では機能する
↓
外部では語彙・前提・制度が共有されない
↓
単語対応・比喩・手続コピーへ寄る
↓
理解感は生まれるが、関係・因果・責任が移らない
↓
保存対象と可変対象を分ける
↓
元構造の主体・役割・因果・失敗境界を地図化する
↓
移動先の語彙・制度・権限・評価へ再配置する
↓
小さな原型で機能再現を試す
↓
逆翻訳で意味漂流・役割誤配・因果欠落を検査する
↓
TF / TD / TCを観測し、責任・承認・更新条件を合意する
↓
異なる文脈で機能が再接続する
```

## 構造層
**1. 原構造観測層。** 主体、関係、因果、役割、失敗コスト、起源責任を一次資料から取得する。

**2. 保存対象層。** 関係価値、因果、役割責任、失敗境界、起源を翻訳中に失わない要素として固定する。

**3. 可変対象層。** 語彙、書式、媒体、比喩、事例、儀礼、説明順を移動先に合わせて変更する。

**4. ST深度層。** ST-0用語対応、ST-1比喩、ST-2手続、ST-3関係、ST-4因果、ST-5制度へと写像対象を拡張する。

**5. 原型化層。** 移動先の小さな場で、理解ではなく機能が再現するかを試す。

**6. 逆翻訳層。** 移動先の構造から元へ戻し、意味漂流・因果欠落・役割誤配を検出する。

**7. 合意・責任層。** 誰が何を承認し、どの条件で更新・撤回・再合意するかを固定する。

## 適用例
**1. 部署間移植。** 手順書だけでなく、誰が判断し、例外時に誰へ戻し、何を失敗とするかを移す。

**2. 営業。** 機能→価格の羅列ではなく、関係価値→便益→コストへ再配置する。ただし価格を隠すためには使わない。

**3. 教育・研究。** 専門用語を平易語へ置き換えるだけでなく、概念関係、因果、役割、失敗例を移す。

**4. AI協働。** 単語列ではなく、目的、役割、因果、制約、証拠、停止条件を関係地図として渡し、文章の流暢さではなく構造写像で検証する。

**5. 制度・市場接続。** 他制度をコピーせず、役割、評価、責任、合意形式、撤退条件をST-3〜ST-5で写像する。

## 測定・監査点
- **ST-0〜ST-5**: 原典明示の6段階分類。数字の大小は翻訳者や文化の優劣を意味しない。
- **8ステップ**: 観測→単位化→地図化→仮説化→境界設定→原型化→逆翻訳→合意化という原典明示の工程列。8点満点や固定成功式ではない。
- **TF（Translation Fit）**: 移動先で構造・理解・機能がどの程度適合するかを観測する概念。
- **TD（Translation Drift）**: 逆翻訳時に生じる意味・因果・役割の歪みを観測する概念。
- **TC（Transfer Cost）**: 移動先で機能を再稼働するための摩擦・費用・学習負荷を観測する概念。

TFが高いだけ、TDが低いだけ、TCが低いだけで成功とは判定しない。たとえばTCを下げるために失敗境界や責任を削れば、翻訳の忠実性は失われる。TFを上げるために受け手へ迎合し原構造を改変しても成立しない。

反転評価では、説明が簡単になり、導入時間やコストが下がっても、因果・役割・責任・起源が失われるなら改善とみなさない。逆に文章量が増えても機能再現が改善しないなら成功ではない。

## 成立条件
- 原構造の一次資料、主体、役割、因果、責任境界を取得できる。
- 保存対象と可変対象を明示する。
- 移動先の制度、語彙、文化、法令、権限、評価基準を観測する。
- 用途に必要なST深度を選ぶ。
- 小さな原型で機能再現を検証する。
- 逆翻訳で原構造へ戻れる。
- TF、TD、TCを更新条件とともに観測する。
- 出典、起源、翻訳責任、承認者が追跡可能である。
- 拒否、訂正、撤回、再合意を保持する。
- 可視化が安全・尊厳・正当な保護境界を壊さない。

## 失敗条件
- 原構造が不明・矛盾・取得不能である。
- 用語・比喩だけを移し、関係と因果が消える。
- 手続だけをコピーし、権限・役割・責任が一致しない。
- 失敗コストや不利条件を削る。
- 逆翻訳できない。
- TF低下、TD高止まり、TC過大が続くのに設計を改訂しない。
- 元制度自体の欠陥を忠実に移植する。
- 出典・起源を消し、翻訳者の独自主張として流通させる。
- 説得・強制・無断制度移植に用いる。
- 過剰可視化で安全・尊厳を損なう。

## 反証・改訂条件
- ST-3〜ST-5まで進めても移動先で機能が再現しない。
- 逆翻訳で同じ因果・役割・失敗境界へ戻れない。
- TF改善のために原構造の重要条件を削らなければならない。
- TDが反復して高く、語彙変更だけでは修正できない。
- TCが高く、移動先の制度・権限との不一致が構造的に解消できない。
- 原型で安全・法令・尊厳上の問題が生じる。

- 構造翻訳 / 言葉の翻訳
- 説明 / 機能接続

- TD / 文化評価

- ST深度 / 優劣順位

## 解釈制約
構造翻訳を平易化、要約、比喩、ストーリーテリングへ縮約しない。ST-0やST-1は入口として有用でも、制度接続の完了を意味しない。ST-5が常に必要なわけでもなく、用途に必要な深度を選ぶ。TF/TD/TCを人・文化・制度のランキングへ使わず、AI文章の流暢さを構造一致の証拠にしない。
