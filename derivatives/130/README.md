## 位置づけ
防衛費拡大を賛否二択で扱わず、脅威認識、装備調達、抑止、同盟、財政機会費用、エスカレーション、民生レジリエンスを一つの因果束として監査する。安全保障を弱める議論でも軍備拡大を自動正当化する議論でもなく、「何を守るために、どの費用とリスクを引き受けるか」を可視化する。

## 中心命題
安全保障は装備量だけで増えない。脅威評価が調達を拡大し、相手側の警戒と軍備を誘発し、それが再び脅威認識を強める自己強化回路がある一方、装備不足も実害を生む。したがって抑止効果、脅威根拠、財政機会費用、維持費、外交余地、民生インフラ、エスカレーションリスクを同じ監査面に置き、追加支出の限界効果を検証する必要がある。

## 因果線
脅威認識上昇 → 防衛調達拡大 → 抑止力増加の期待 → 相手側警戒・対応 → 地域軍備増加 → 追加脅威認識 → 財政・維持負担増 → 外交・民生レジリエンスと比較 → 限界効果を再評価。

## 構造層
1. 脅威層：能力・意図・不確実性を分ける。
2. 抑止層：装備がどの攻撃をどの程度抑止するか。
3. 相互作用層：相手側の反応とエスカレーション。
4. 資源層：財政、維持、人材、民生機会費用。
5. 倫理監査層：守る対象、比例性、代替手段を確認する。

## 適用例
1. 大型装備調達で購入費と維持・更新費を同時評価する。
2. 防衛計画で装備とサイバー・避難・インフラ耐性を比較する。
3. 同盟政策で負担分担と自律性を分けて監査する。
4. 国会・公共議論で脅威根拠と代替案を同じ資料に載せる。

## 測定・監査点
脅威根拠更新頻度、装備稼働率、ライフサイクル費、抑止仮説検証数、エスカレーション指標、民生レジリエンス投資比、代替案比較率。

## 成立条件
脅威を証拠で更新する。購入費だけでなく維持費を測る。相手の反応を含める。外交・民生の代替案を比較する。比例性を監査する。決定後も再評価する。

## 失敗条件
脅威を固定前提にする。装備数を安全そのものとみなす。相手の反応を無視する。維持費を隠す。民生防護を切り捨てる。批判を非愛国とみなす。

## 反証条件
追加装備が一貫して抑止・被害低減へ高い限界効果を持つ。相手側反応が軍備拡大に影響しない。民生・外交代替が同等の安全を提供しない。機会費用が安全保障能力に影響しない。自己強化回路が観測されない。

## 必須の区別
防衛/軍備量、脅威能力/脅威意図、抑止/安心感、購入費/総保有費、同盟/依存、批判/防衛否定、平和志向/無防備。

## 誤読禁止
軍備を全面否定しない。大型調達を自動的に無駄としない。脅威を架空と決めつけない。平和を無防備と同一視しない。軍事費を唯一の安全指標にしない。派生物で具体的調達の適法性を確定しない。
