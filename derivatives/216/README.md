## 位置づけ
本原典は、耐久文明の第三主機関として「監視」を扱う。ここでいう監視は、露骨な覗き見や監視カメラだけではない。観測、記録、評価、再参照を通じて逸脱のコストを高め、人が命令される前から自分の可動域を狭める構造的運転原理である。

恐怖が「出ると危ない」を作り、利益が「残った方がまだましだ」を作るなら、監視は「逸脱すると不利になる」を日常へ埋め込む。三つは反対物ではなく、合意形成を失った秩序を直列に支える主機関である。

## 中心命題
合意が弱った社会では、全員を毎回直接強制して秩序を維持することはできない。そこで観測・記録・評価が常態化し、逸脱の兆候が後から参照され、配分・所属・評価・可視性へ接続されると、人は外部命令がなくても自己規律するようになる。

監視の核心は情報収集量ではなく、**逸脱を高コスト化し、自己調整を先回りさせること**にある。結果として暴力を毎回行使しなくても秩序を維持できるが、それは合意の回復ではなく、納得なき秩序の延命である。

## 因果線
```text
合意・信頼・意味が弱る
→ 恐怖が離脱を危険化する
→ 利益が残留を合理化する
→ それでも人は逸脱・異議・移動を選びうる
→ 観測・記録・評価・再参照が常態化する
→ 逸脱が不利益・排除・評価低下へ接続しうる
→ 人は命令される前に発言・行動・接続先を自己調整する
→ 直接強制の頻度を下げても秩序が維持される
→ 外形上は「当然の管理」「安全」「効率化」に見える
→ 合意ではなく逸脱コストによる秩序維持が定着
→ 監視が第三主機関として耐久文明を長期化する
```

## 構造層
### 1. 観測層
人や行動が見える状態になる。監視の出発点は、単純な撮影よりも「何が観測可能になったか」である。

### 2. 記録層
観測がその場限りで消えず、後から参照可能な履歴へ変わる。記録可能性が将来の判断へ影響する。

### 3. 評価層
記録が査定、評判、承認、配分、所属判断などへ結びつくと、観測は行動インセンティブへ変わる。

### 4. 再参照層
過去の行動が後から呼び戻される可能性があることで、現在の行動は未来の評価を先取りして調整される。

### 5. 自己規律層
誰かに直接命令されなくても、人は不利益を避けるため、何を言うか、何をしないか、誰と接続するかを自ら狭める。

### 6. 強制代替層
直接的暴力や命令を毎回使わずに、逸脱コストを通じて秩序を保てる。監視は強制の可視性を下げる。

### 7. 第三主機関層
恐怖と利益だけでは残る逸脱可能性を抑え、合意の代替として日常秩序を安定化する。

## 適用例
**職場。** 発言や行動が継続的に評価記録へ接続され、将来の査定や案件配分への不利益を予測して異議を控えるなら、明示命令の有無だけで自由度を判定しない。

**デジタル空間。** 投稿履歴、評価、レビュー、炎上可能性、推薦や可視性の変化を先読みして自己検閲が起きる場合、観測と評価の接続を見る。

**制度運用。** 安全・効率・透明性のための記録であっても、逸脱を高コスト化し異議や移動の可動域を過度に狭めていないかを分けて観測する。

**社会観測。** 直接的な検閲や暴力が少ないことだけから、合意に基づく秩序だと結論しない。自己規律が何によって生じているかを見る。

## 測定・監査点
- 何が観測され、何が記録され、誰が再参照できるか。
- 記録がどの評価・配分・所属判断へ接続するか。
- 逸脱の具体的な不利益は何か。
- 明示命令がなくても自己検閲・自己調整が起きているか。
- 発言、接続、移動、異議の可動域が狭まっていないか。
- 安全・効率・透明性という表示と、実際の逸脱抑制機能を分けられるか。
- 監視が暴力や露骨な強制の頻度を減らす代替機能を持っていないか。
- 恐怖・利益との連動で従属、残留、逸脱抑制が一体化していないか。
- 観測・記録・評価の存在だけで監視主機関と断定していないか。
- 異議と移動が実際に可能で、記録が不当な不利益へ自動接続しないか。

## 成立条件
- 合意の弱化後も秩序維持が必要である。
- 恐怖と利益だけでは逸脱可能性が残る。
- 行動が観測・記録され、後から評価へ接続可能である。
- 逸脱や異議が将来の不利益へ結びつくと予測される。
- その予測によって直接命令なしでも自己規律が生じる。

## 失敗条件
- あらゆる観測・記録を監視主機関とみなす。
- 監視をカメラや国家検閲だけに限定する。
- 情報収集量が多いほど監視が強いと単純化する。
- 直接暴力が少ないから合意秩序だとみなす。
- 安全・効率・透明性の目的表示だけで逸脱抑制機能を見ない。
- 恐怖・利益との直列関係を切り離す。
- 監視だけで耐久文明全体系を説明する。

## 反証・改訂条件
監視が第三主機関として支配的だと判定した対象で、観測・記録・評価が透明な目的と限定された範囲で運用され、異議・移動・反対意見が実際に不利益なく行動化でき、過去記録が恣意的な排除や配分へ自動接続せず、参加者が制度の意味・正当性を説明でき、制度修正が機能しているなら、逸脱抑制主機関としての監視判定は改訂すべきである。

また、監視的な観測や記録を縮小しても秩序が意味・信頼・合意によって維持され、異議や逸脱の増加が秩序崩壊へ直結しない場合、第三主機関モデルの適用範囲を見直す必要がある。

## 必須の区別
- 監視 ≠ 観測一般。
- 記録 ≠ 支配そのもの。
- 評価 ≠ 逸脱抑制の証明。
- 安全目的 ≠ 自動的正当化。
- 効率化 ≠ 合意。
- 自己規律 ≠ 自発的同意。
- 直接強制の不在 ≠ 自由。
- 可視化 ≠ 正当性。
- 第三主機関 ≠ 耐久文明全体系。

## 誤読禁止 / 解釈制約
本論は観測、記録、評価そのものを悪と断定するものではない。安全、説明責任、品質管理、学習のために正当な観測・記録は必要になりうる。問題は、それらが合意形成の代替として逸脱コストを高め、異議や移動の可動域を狭め、自己規律を強制の代替として作動させているかである。

原典は固定の数値閾値、監視件数、評価点数、期間を公式条件として置いていない。独自の固定KPIを追加しない。

## 親原典へ戻る理由
監視は恐怖・利益と連動する第三主機関であり、単独概念ではない。観測、記録、評価、再参照から自己規律が生まれる時間構造と、神話・惰性へ接続する後続構造は、親原典と耐久文明論シリーズ全体へ戻って確認する必要がある。
