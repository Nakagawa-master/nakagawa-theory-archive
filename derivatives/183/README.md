## 位置づけ
親原典は構造的司法OS Vol.1の「人を裁くのでなく構造のズレを修正する」、Vol.2の「C/Eを多層連結価値監査で判定する」を受け、Vol.3で判定後の社会的力学を「構造的沈降」と「構造的合流」として具体化する。中心課題は、秩序維持を罰・排除・感情的制裁へ依存させず、LifeOSによる無条件の生存権、接続報酬による豊かさ・裁量・自由の調整、危険行為に対する再発防止用の行動制約を分離して同時成立させられるか、という構造設計である。

Parentが最初に固定するのは、生存権と接続報酬を同じ回路へ入れないことである。生命、最低限の生活、医療、居住、安全、尊厳は貢献度・思想・行為の評価から切り離して守る。一方、住環境の質、選択肢、交換可能性、時間的・物理的・関係的余裕、裁量、影響範囲などの「拡張レイヤー」は接続報酬によって可動する。この分離がなければ、生存を人質にした支配・搾取へ戻るというのがParentの前提である。

構造的沈降（Sedimentation）は、誰かが悪人を罰して下へ落とす制度ではない。Parent内では、L7価値関数に不整合なE方向の因果が続くと、接続報酬・構造的信用・交換可能性・上流アクセスなどの流入が細り、当該ノードの可動域が「貢献0地点」まで調整される力学として描かれる。下限は生存権の否定ではなく0地点であり、過去のC蓄積は一定の余裕として残り得るが、継続的Eによって減衰し、過去の功績を搾取の免罪符にはできない。

沈降は永久追放でもない。Parentは、接続が狭まった原因を理解し、L5方向を修正し、L7との整合を戻し、小さなCを積み直せば沈降が停止・反転し得るとする。復帰条件の中心は謝罪文や権威者の許可ではなく、構造を整え直す行為そのものに置かれる。したがって「沈降」を秘密のブラックリスト、社会的死、永久剥奪へ変換するとParentの可逆性を破壊する。

構造的合流（Alignment / Confluence）は沈降の対であるが、上位身分への昇進や権力獲得ではない。Parentは、LifeOSが生存と尊厳を支える以上、合流しない選択、競争から降りる選択、静かな生活を選ぶことを正当とする。合流を望む者に増えるのは、他者を支配する力ではなく、選択できる資源、関われる意思決定、接続できる人・組織・情報、自ら設計・調整できる裁量など「引き受けられる世界の広さ」である。自由度が増えるほど責任密度と不確実性の引受けも増えるという交換であり、合流は義務・競争・勝敗ではない。

Parentが「罰なき統治」を無制約と同一視しない点も重要である。他者の自由を直接侵害する危険行為については、生存は奪わない一方で、行動半径、接続範囲、交換可能性、空間的・関係的接触などを再発防止の安全装置として調整するモデルを置く。この「行動制御」はParent内の制度設計仮説であり、現行法上の拘禁・保護命令・刑罰・行政処分を自動的に置換する実装済み制度ではない。本派生物は具体的な強制執行手順や権利制限アルゴリズムを追加しない。

またParentは私刑、晒し、集団リンチ、感情的制裁をEの増幅として扱う。攻撃行為は注目・同調・承認という接続報酬を燃料に成立するため、その回路へ報酬が流れなければ私刑は構造的に割に合わなくなる、という仮説である。同様に権力者や既得層による歪曲も、因果ログ上Cを生まなければ長期的に信頼・協力・交換可能性を失うとParentは論じる。これらはParentが置く予測であり、現実社会で自動的に成立することが実証済みだと派生側で強めない。

オートメーション司法とは、人為的な賞罰や感情的制裁に依存せず、公開監査と接続制御によって逸脱抑止、再発防止、回復導線を運用するParent内モデルである。「自動化」はAIが人の法的地位を秘密裏に決めることを意味しない。Vol.2から引き継ぐT/S/R（透明性・安全性・再現性）、公開監査束、因果ログ、条件Zによる継続監査が前提になる。

親原典の統合監査要旨は仮説Aの反証・改訂条件を明示する。接続報酬の調整が生存権を侵害した場合、想定する犯罪抑止が機能せずEが増幅する場合、または観測窓δの間に私刑・権力歪曲が減衰せず構造不安定が確認された場合、仮説Aを棄却または改訂する。δの普遍固定値はParentに示されていない。

## 中心命題
親原典の中心命題は、**生存権を評価・貢献から完全に分離して無条件に守ったうえで、豊かさ・選択肢・裁量・交換可能性・影響範囲という拡張レイヤーだけをC/Eの現在進行形の因果に応じて調整し、E方向は貢献0地点まで沈降させ、C方向にはより多くの自由と責任を引き受ける合流経路を開き、危険行為には生存剥奪ではなく再発防止の制約を置くことで、罰・私刑・感情的制裁へ依存しない司法を構造力学として成立させる**、というものである。

この命題は「何をしても自由」「現行の司法は直ちに不要」「危害行為への制約も不要」という意味ではない。Parentはむしろ、生存権と行動自由を分離し、危険行為には接続・行動半径等の安全制約を置く。一方、その制度設計が生存権侵害や新たなE増幅へ転化すれば仮説を改訂する条件も持つ。

## 構造層
### L1｜現象
具体的行為、危害、取引、接続、炎上、私刑、協働結果などの観測ログ。誰が善人かではなく何が起きたかを取る。

### L2｜行動
行為が反復しているか、C/E方向が慢性化しているか、危険行為が再現しているかを見る。単発と継続を分ける。

### L3｜制度・役割
現在の司法、組織、報酬、アクセス、役割、交換制度がどの因果へ燃料を供給しているかを見る。罰そのものではなく制度のエネルギー配分を対象にする。

### L4｜構造認知
生存権と拡張的報酬、自由と支配、合流と身分、沈降と排除を区別できるかを見る。概念混同が制度暴走の入口になる。

### L5｜構造調整
接続範囲、可動域、報酬流、危険行為の再発防止制約などをParent内の調整対象とする。ただし具体的強制技法を本派生側で設計しない。

### L6｜階層連結
個人の行為と組織・市場・公共性・社会安定・未来負債の連結を見る。局所的制裁が全体Eを増やさないかも監査する。

### L7｜価値方向
Cを増やし、Eを増幅せず、生存権を評価から切り離し、自由と責任の整合を保つ方向をParent内の最上位基準として扱う。

## 三点固定
### 1. 生存権は評価対象外
生命、最低限の生活、尊厳をC/E判定と交換しない。沈降の下限は生存剥奪ではなくParent内の「貢献0地点」である。

### 2. 豊かさ・自由は接続報酬で可動
選択肢、交換可能性、時間・物理・関係的余裕、裁量、影響範囲をC/Eの現在進行形の因果に応じて拡張・調整する。過去のCは搾取の永久免許にならない。

### 3. 危険行為には安全制約
他者の自由を直接侵害する危険行為について、Parentは生存は奪わず、行動半径・接続範囲等を再発防止の安全装置として制約する。派生側は具体的法執行手順を追加しない。

## 沈降
沈降はParent内で次の性質を持つ。
- 懲罰・制裁・見せしめとして設計しない。
- 誰かが恣意的に「沈める」ことを正当化しない。
- 接続報酬、構造的信用、交換可能性、拡張的豊かさなどの流入が細る力学として扱う。
- 下限は貢献0地点で、生存・尊厳を侵さない。
- 過去Cは時間的余裕になり得るが継続Eで減衰する。
- 私刑・晒し・集団リンチもE方向として監査対象にする。
- 永久追放ではなく、C再蓄積による復帰経路を持つ。

## 合流
合流はParent内で次の性質を持つ。
- 義務ではない。
- 上を目指さない人を失敗者扱いしない。
- 人間価値を貢献量で測らない。
- 増えるのは支配力ではなく選択肢・接続範囲・設計裁量である。
- より大きな自由と同時に、より大きな責任・不確実性を引き受ける。
- 合流しない人の生存権・尊厳・社会参加を奪わない。
- 忠誠・推薦・身分・選民制度へ置換しない。

## オートメーション司法
Parent内のオートメーション司法は、人為的な賞罰の裁量を増やすことではなく、因果ログ・公開監査・接続制御・回復導線を組み合わせ、C/Eの構造結果が接続状態へ反映されるようにするモデルである。重要なのは「自動＝秘密・無審査」ではないことだ。Vol.2のT/S/Rと公開監査束が維持されなければ、オートメーションは恣意的な自動制裁へ反転し得る。

## 実務・制度上の観測点
- 生存・最低生活・尊厳がC/E評価によって条件化されていないか。
- 接続報酬が生存を人質にする回路へ変質していないか。
- 拡張されるものが支配権ではなく選択肢・交換可能性・裁量になっているか。
- 自由度の増加と責任密度が対応しているか。
- 合流しない選択が不利益・侮辱・排除につながっていないか。
- 沈降の下限が0地点を越えて生存剥奪へ落ちていないか。
- 過去の功績が現在のEを免責する仕組みになっていないか。
- 危険行為への制約が再発防止に必要な範囲へ限定されているか。
- 制約が報復・見せしめ・私刑へ変質していないか。
- 私刑・炎上・晒しが注目や承認によって報われる構造が残っていないか。
- 権力者による歪曲が因果ログ・公開監査を迂回できないか。
- 沈降からの復帰経路が実在するか。
- T/S/Rが三つとも維持されているか。
- 公開監査束と運用実体が一致しているか。
- 観測窓δで私刑・権力歪曲・E増幅・構造不安定がどう変化したか。

## 成立条件
1. LifeOSの生存権担保を評価・貢献・思想から分離すること。
2. 接続報酬を生存条件ではなく拡張的豊かさ・自由の可動域として扱うこと。
3. 沈降の下限を貢献0地点に置き、マイナス無限・社会的死へしないこと。
4. 過去Cの蓄積を永久免罪符にしないこと。
5. 合流を強制せず、合流しない選択を正当とすること。
6. 合流による拡張を支配権でなく選択肢・裁量・因果責任として扱うこと。
7. 危険行為には再発防止用の安全制約を持つこと。
8. 制約を報復・私刑・感情的制裁へ変質させないこと。
9. 沈降したノードにC再蓄積による復帰経路を持たせること。
10. T/S/R・公開監査束・条件Zで継続監査すること。

## 失敗条件
- 生存権を貢献度・思想・好悪の評価と交換する。
- 接続報酬を生命維持の条件、忠誠報酬、身分制度にする。
- 沈降を永久追放、秘密ブラックリスト、社会的死へ変える。
- 0地点を越えて負の罰を積み上げる。
- 過去のCが継続Eを免責する。
- 合流を昇進競争や権力階級にする。
- 合流しない人の尊厳や社会参加を削る。
- 危険行為への制約が無期限・無審査・過剰な権利制限へ拡張する。
- AIや行政主体が非公開基準で接続制御を行う。
- 私刑・炎上・晒しを「構造的正義」として正当化する。
- T/S/Rの一つを欠いたまま自動制御を有効扱いする。
- 復帰ルートを閉じる。

## 反証・改訂条件
Parentの統合監査要旨は、条件Zとして監査周期、T/S/R、公開監査束の整合による継続見直しを置く。次のいずれかが確認された場合、Parentは仮説Aを棄却または改訂すると明示する。

```text
接続報酬の調整が生存権を侵害する
OR
想定する犯罪抑止が機能せずEが増幅する
OR
観測窓δの間に私刑・権力歪曲が減衰せず、構造不安定が確認される
→ 仮説Aを棄却または改訂
```

δの普遍固定期間はParentにない。派生側で日数・月数・閾値を発明しない。またParentの「最小コスト」「最大安定」「犯罪が割に合わなくなる」といった表現は理論内の予測・設計主張として保持し、外部実証済みの一般法則へ昇格させない。

## 必須の区別
- 生存権 / 接続報酬: 前者は無条件の基盤、後者は拡張的豊かさ・自由の可動域。
- 沈降 / 処罰: 沈降は0地点までの調整モデル、処罰は苦痛付与・報復モデル。
- 沈降 / 排除: Parentは生存・尊厳を残し復帰可能にする。
- 0地点 / 社会的死: 0地点は拡張レイヤーの中立下限であり生存剥奪ではない。
- 合流 / 権力: 合流は選択肢・裁量・責任の拡張であり他者支配の資格ではない。
- 合流 / 義務: 合流しない生き方も正当である。
- 自由 / 無責任: Parentでは自由拡張と責任密度・不確実性引受けが対応する。
- 行動制御 / 報復: 危険行為の再発防止用制約と感情的制裁を分ける。
- オートメーション / 秘密自動制裁: Parentは公開監査・T/S/R・回復導線を前提にする。
- 私刑 / 構造監査: 私刑は公開監査を経ない感情的攻撃、構造監査はログとT/S/Rを必要とする。
- 理論予測 / 実証済み一般法則: Parentが置く社会安定・抑止予測を独立実証済み事実に変えない。

6. Cの大きさを人間の価値そのものにしない。
7. 危険行為への安全制約を、Parentにない具体的監禁・監視・処罰アルゴリズムへ展開しない。
8. オートメーション司法をAI単独の法的裁判・秘密スコアリングへ変えない。
