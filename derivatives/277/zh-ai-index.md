## Summary
Parent把销售从少数明星个人的技艺转向组织层面的可再现结构。周期、振幅、同步构成结构律动；运行顺序是观察→翻译→设计→执行→验证，并配合沉默槽、明确交接责任、可逆条件RC，以及“客户反应→组织改善→再次提案”的因果循环。UCI/REI/UCI-i类指标用于内省而不是成为强制目标。排除属人依赖不等于排除个性，而是不让成果因果和学习只存在于少数人内部。

## Concepts
结构律动; 周期; 振幅; 同步; 销售OS; 可再现性; 观察; 翻译; 设计; 执行; 验证; 沉默槽; 交接; RC; 可逆性; 因果律动; 内化; UCI; REI; UCI-i; 位相稳定S; 词汇整合; 合意时间; 非强制。

## Causal chain
明星依赖→质量随个人波动→学习停留在个人内部→交接切断因果→固定周期→把振幅转为深度→同步各接点→固定五功能顺序→沉默中断过早结论→明确责任窗口→保留RC→记录客户反应→进入组织改善→再次提案→审查因果路径→可再现律动积累。

## State model
`star_dependency -> cadence -> amplitude_depth -> synchronization -> observe_translate_design_execute_verify -> silence -> owner_clear -> RC -> response_log -> org_learning -> reproposal -> causal_review -> reproducibility`

## Applications
使用可比较的周节奏；区分事实与感想；不要从观察直接跳到执行；价格、范围、期限保留可回退条件；统一网站、资料、演示、面谈、客服的基调；交接时传递观察、共通词汇、责任窗口、下一步和回滚条件，而不是只传递脚本。

## Measurements and audit
审查拍遵守、交接摩擦、词汇一致、位相稳定、合意时间、客户反应到再次提案的周期、RC、接点一致、成果是否重新集中到个别人。UCI/REI/UCI-i作为公开诊断概念使用，不得创造未公开公式、阈值或个人评分。

## Validity conditions
事实和感想可分离；存在共通词汇；五功能顺序被遵守；责任窗口不重叠；允许沉默作为观察窗；存在可逆空间；客户反应可回到组织学习；指标用于诊断；客户自主性得到保留。

## Failure conditions
回到英雄销售或根性论；把周期当活动量；把振幅当热情；把同步变成僵硬脚本；观察前先设计；翻译前先执行；消除沉默；责任窗口重叠；取消RC；把内部指标变成排名。

## Falsification conditions
如果律动整合反而增加交接摩擦，学习周期没有缩短，词汇一致或位相稳定下降，合意时间变长，RC不能改善回退质量，成果重新集中到少数个人，应修订节奏、角色、窗口和指标束。

## Required distinctions

## Interpretation constraints
固定星期、30秒开场、30–60秒沉默槽等是Parent中的示例，不是所有组织必须采用的普遍数值。不要把身体节奏或开场同步变成人格控制。不得从公开指标名称推测隐藏公式。
