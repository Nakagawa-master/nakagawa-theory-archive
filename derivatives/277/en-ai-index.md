## Summary
The Parent moves sales from individual artistry toward organizational reproducibility. Periodicity, amplitude, and synchronization are treated as a structural rhythm. The operating order is observation -> translation -> design -> execution -> verification, with silence slots, clear handoff ownership, reversible conditions, and a customer-response -> organizational-learning -> reproposal loop. UCI/REI/UCI-i-like indicators remain diagnostic rather than targets. Removing person-dependence does not mean removing personality; it means preventing causal knowledge and results from being locked inside a few individuals.

## Causal chain
star dependency -> variable quality -> learning remains personal -> handoff breaks causality -> cadence fixed -> amplitude becomes depth -> touchpoints synchronized -> five-function order fixed -> silence interrupts premature closure -> ownership clarified -> RC preserved -> customer response logged -> organizational improvement -> reproposal -> causal path reviewed -> reproducible rhythm accumulates.

## State model
`star_dependency -> cadence -> amplitude_depth -> synchronization -> observe_translate_design_execute_verify -> silence -> owner_clear -> RC -> response_log -> org_learning -> reproposal -> causal_review -> reproducibility`

## Applications
Use comparable weekly cadences; separate facts from impressions; do not jump from observation directly to execution; keep reversible conditions in price, scope, and timing; align website, documents, demo, meeting, and CS tone; hand off observations, vocabulary, ownership, next action, and rollback conditions rather than only scripts.

## Measurements and audit
Audit beat adherence, handoff friction, vocabulary coherence, phase stability, agreement time, response-to-reproposal cycle, RC, touchpoint consistency, and concentration of performance in individuals. Treat UCI/REI/UCI-i as diagnostic public concepts without inventing unpublished equations, thresholds, or personal scoring.

## Validity conditions
Facts can be separated from impressions; shared vocabulary exists; function order is respected; ownership is unambiguous; silence is allowed as an observation window; reversible space exists; customer response reaches organizational learning; metrics are diagnostic; customer autonomy remains intact.

## Failure conditions
Return to hero-sales or grit; confuse cadence with activity volume; confuse amplitude with enthusiasm; turn synchronization into rigid scripting; design before observation; execute before translation; eliminate silence; duplicate ownership; remove RC; externalize internal metrics as rankings.

## Falsification conditions
Revise if rhythm alignment increases handoff friction, does not shorten the learning loop, reduces vocabulary alignment or phase stability, lengthens agreement time, fails to improve rollback quality, or causes performance to re-concentrate in a few individuals.

## Required distinctions
person-dependence removal / removal of humanity; reproducibility / scripting; periodicity / workload; amplitude / enthusiasm; synchronization / uniformity; observation / impression; silence / neglect; RC / timidity; causal review / result appraisal; metric / objective.

## Interpretation constraints
Examples such as fixed weekdays, 30-second openings, or 30–60 second silence slots are examples, not universal mandatory values. Do not convert embodied rhythm into personality control. Do not infer hidden formulas from public indicator names.
