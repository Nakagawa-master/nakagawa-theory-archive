## 位置づけ
Parentは営業成果をスター人材の才覚や根性から切り離し、営業組織そのものに「再現されるリズム」を埋め込む。構造律動を周期・振幅・同期の三変数として営業へ翻訳し、観測→翻訳→設計→実行→検証の役割順序、沈黙スロット、可逆性RC、接点同期、UCI/REI/UCI-i等の観測によって、自律学習型の営業OSを構成する。

## 中心命題
**営業の再現性は個人の話術を複製することではなく、周期・振幅・同期、役割の順序、責任窓口、沈黙、可逆性、一次ログを構造として反復可能にすることで生まれる。顧客反応→組織改善→再提案の因果律動を切らず、結果ではなく因果の通り道をレビューすると、成果は個人の熱意ではなく組織の学習リズムから立ち上がる。**

## 主要因果線
スター依存→接点品質が人によって変動→学習が個人内部に閉じる→組織再現性が低下→周期を固定→振幅を関心・編集密度として標準化→サイト/資料/面談/CSを同期→観測→翻訳→設計→実行→検証の順序を固定→沈黙スロットで早すぎる結論を止める→責任窓口を一拍ごとに明確化→RCを残して踏み込む→結果ではなく因果経路をレビュー→顧客反応を組織改善へ戻す→再提案→律動の乱れを月次修正→属人性が減り再現性が上がる。

## 構造層
### 1. 周期
同じ曜日・時間・形式など反復の拍を固定し、学習の比較可能性を上げる。
### 2. 振幅
テンションではなく、顧客関心、仮説精度、議事圧縮、提案編集などの深さを仕組みで再現する。
### 3. 同期
サイト、資料、デモ、面談導入、CSを同じ基調へ揃え、組織を単一人格として知覚可能にする。
### 4. 役割順序
観測→翻訳→設計→実行→検証を分離し、会議内での順序逆流を防ぐ。
### 5. 沈黙スロット
短い発話停止によって未発言の違和感を回収し、誤学習と早すぎる確定を防ぐ。
### 6. RCと因果学習
価格・スコープ・期日等に戻れる条件を残し、失敗を小さくして学習速度を上げる。
### 7. 指標と倫理
UCI/REI/UCI-iは内省用の傾向観測とし、外部競争・個人評価・数字ゲームへ変えない。

## 適用例
週次レビューを同一フォーマットで比較可能にし、商談準備では観測と仮説を分ける。提案時は価格・スコープ・期日の戻り幅を残し、サイト・資料・デモ・面談・CSの語彙とテンポを揃える。担当交代では台本だけでなく、顧客観測、共通語彙、責任窓口、次の一手、撤回条件を引き渡す。

## 測定・監査点
拍遵守、ハンドオフ摩擦、語彙整合、位相安定S、合意到達時間、接点一貫性、UCI/REI/UCI-iの傾向、RC保持、再提案までの学習循環、過熱・押し売り・同調圧を監査する。内部数値や個人評価は公開派生側で推測しない。

## 成立条件
周期・振幅・同期を束で運用する。観測と感想を分ける。役割順序を守る。責任窓口を重複させない。沈黙を設計する。戻れる条件を残す。結果だけでなく因果をレビューする。指標を内省用に保つ。

## 失敗条件
根性論・属人技へ戻る。接点ごとに局所最適する。順序を飛ばして実行する。沈黙をなくす。RCを臆病さとして削る。数字を外部公開・個人査定へ使う。導入テンポの統一を人格統制へ変える。顧客の自律を損なう。

## 反証・改訂条件
拍を整えてもハンドオフ摩擦が増える、語彙整合や位相安定が悪化する、学習循環が短縮しない、RC保持が合意品質を改善しない、再現性が特定個人へ再集中する場合、役割・周期・同期・指標束を改訂する。

## 必須の区別
再現性 / 台本化; 周期 / 忙しさ; 振幅 / テンション; 同期 / 画一化; 沈黙 / 放置; RC / 臆病; KPI / 目的; 因果レビュー / 結果査定; 身体規範 / 人格統制。

## 誤読防止・解釈制約
「属人性を排除」は人間性や個性の排除ではなく、成果再現の因果を特定個人だけに依存させない意味。導入30秒や沈黙スロットなどParent内の例を、全組織で固定すべき普遍値へ昇格させない。公開されていないUCI/REI/UCI-i算式や閾値を生成しない。
