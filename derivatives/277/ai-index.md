## Summary
Parentは営業を個人のアートから組織の再現科学へ移す。周期・振幅・同期を構造律動として固定し、観測→翻訳→設計→実行→検証の順序、沈黙スロット、責任窓口、RC、顧客反応→組織改善→再提案の因果循環、UCI/REI/UCI-i等の傾向監査を組み合わせる。属人性排除は個性の削除ではなく、成果を生む因果・学習・ハンドオフを特定個人だけに閉じ込めないことを意味する。

## Concepts
構造律動; 周期; 振幅; 同期; 営業OS; 再現性; 観測; 翻訳; 設計; 実行; 検証; 沈黙スロット; 責任窓口; ハンドオフ; RC; 可逆性; 因果律動; 内面化; 身体規範; UCI; REI; UCI-i; 位相安定S; 拍遵守; 語彙整合; 合意到達時間; 非強制。

## Causal chain
スター人材へ成果集中 → 営業品質が人ごとに変動 → 顧客反応と学習が個人内部に閉じる → 引き継ぎで因果が切れる → 周期を固定 → 振幅を熱量ではなく関心・仮説・編集の深さへ置く → サイト/資料/デモ/面談/CSを同期 → 観測→翻訳→設計→実行→検証の順序を固定 → 沈黙スロットで早すぎる結論を中断 → 責任窓口を一拍ごとに明確化 → RCを残して小さく踏み込む → 顧客反応を一次ログ化 → 組織改善へ戻す → 再提案 → 因果経路を月次修正 → 結果ではなく学習リズムが蓄積 → 属人性低下と再現性上昇。

## State model
`star_dependency -> rhythm_defined -> periodicity_fixed -> amplitude_as_depth -> touchpoints_synchronized -> observe_translate_design_execute_verify -> silence_slot -> handoff_owner_clear -> RC_preserved -> customer_response_logged -> org_learning -> reproposal -> causal_path_reviewed -> reproducible_sales_rhythm`

## Applications
週次レビューは同じ拍・同じフォーマットで比較可能にする。商談前は事実観測と仮説を分け、会議では翻訳前に設計へ飛ばない。提案は価格・スコープ・期日等に戻れる条件を残す。サイト、資料、デモ、面談、CSの導入基調を揃える。担当交代では台本より、顧客観測、共通語彙、責任窓口、次の一手、撤回条件を引き渡す。AI支援も出力量より、順序・一次ログ・因果経路を保持する。

## Measurements and audit
拍遵守率、ハンドオフ摩擦、語彙整合、位相安定S、合意到達時間、顧客反応から再提案までの循環、RC保持、接点一貫性、再現性の個人集中度をみる。UCI/REI/UCI-iは律動の整いを内省する概念として扱い、未公開算式・閾値・個人評価を生成しない。売上・受注率は遅行指標であり、それだけで律動健全性を確定しない。

## Validity conditions
観測と感想を分離できる。共通語彙がある。五機能の順序を守れる。責任窓口が重複しない。沈黙を観測窓として許容する。価格・スコープ・期日に可逆余地がある。顧客反応が組織学習へ戻る。指標が査定・競争ではなく内省に使われる。顧客の自律と撤回を損なわない。

## Failure conditions
成果=根性/スター技へ戻る。周期を活動量と誤解する。振幅をテンションと誤解する。同期を画一台本へ変える。観測前に設計する。翻訳前に実行する。沈黙をなくし早口の結論を固定する。責任窓口を複数化する。RCを削って一括確定する。UCI/REI/UCI-iを外部ランキングや個人査定へ使う。

## Falsification conditions
周期・振幅・同期を整えても、ハンドオフ摩擦が増える、顧客反応の学習循環が短縮しない、語彙整合が悪化する、位相安定が下がる、合意到達が遅くなる、RC保持が品質に寄与しない、成果が特定個人へ再集中する場合、役割分解・拍・窓口・指標束を改訂する。短期売上だけを反証回避に使わない。

## Interpretation constraints
Parentの具体例である「同じ曜日・時間」「導入30秒」「30〜60秒の沈黙」等を、全組織に普遍的な固定値として適用しない。数値は公開例であり、構造原理は拍・深さ・同期・観測窓・可逆性にある。「身体規範」を声や人格の強制へ変えない。「属人性排除」を個性、関係性、裁量の排除へ拡張しない。
