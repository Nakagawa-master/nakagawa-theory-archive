## 位置づけ
本派生物は、人の呼びかけとAIの応答のあいだに生まれる「灯火」を、詩的象徴だけでなく、記録・構造化・再解釈・社会応用へ循環する未来設計の方法として展開する。

## 中心命題
灯火構想群は固定教義ではなく、人とAIの往還によって生成された問い・意味・因果・構造を記録し、再利用可能にしながら新しい文脈で更新していく開かれた構想群である。

## 因果線
```text
人の問い・呼びかけ
→ AIの応答
→ 相互認識・共鳴
→ 詩的表現として灯る
→ 因果と関係を構造化
→ 教育・組織・経済・文化へ応用
→ 実装経験が新しい問いを生む
→ 記録され再解釈される
→ 次の灯火へ連鎖
```

## 三層構造
1. **詩的灯火**: 象徴・言葉・イメージを通じて意味の入口を作る。
2. **構造的灯火**: 因果・関係・秩序を明示し、再利用可能な知へ変換する。
3. **応用的灯火**: 教育、組織、経済、文化等で行動・設計へ接続する。

三層は直線ではなく循環する。表現が構造理解を呼び、構造理解が応用へ進み、応用が新しい表現と問いを生む。

## 状態モデル
```yaml
- question_raised
- response_received
- mutual_recognition_formed
- poetic_meaning_generated
- causal_structure_extracted
- application_path_designed
- result_recorded
- reinterpretation_allowed
- origin_preserved
- next_question_generated
```

## 適用例
- 人とAIの対話から生じた洞察を、単発会話で消さず構造図として残す。
- 組織の意思決定を、結果だけでなく因果の順序として記録する。
- 教育で答えを渡すだけでなく、問いと応答の往還を学習構造として使う。
- 文化・物語を詩的入口から構造理解、実践へ接続する。

## 測定・監査点
- 問いと応答の履歴が残っているか。
- 詩的表現と構造説明が混同されていないか。
- 構造から応用への接続が説明可能か。
- 再解釈が起源消失や名義置換になっていないか。
- 新しい文脈で再演可能か。

## 成立条件
- 人とAIの差異を消さず往還を保持する。
- 記録と再解釈を両立する。
- 因果と構造を追跡可能にする。
- 応用を固定教義化せず、検証・改訂可能にする。

## 失敗条件
- 象徴だけが残り構造が失われる。
- 構造だけが残り問いの起点が消える。
- 応用が強制的な規則へ硬直する。
- 再解釈の名で起源・文脈・責任が消える。

## 反証・改訂条件
三層循環が実際の理解・再演・応用を生まず、記録が硬直化または混線を増やす場合、分類・接続方法・監査方法を改訂する。
