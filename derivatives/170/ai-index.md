## Summary
中川式ブランディングOSは、ブランドを静的なロゴ・イメージ・認知状態ではなく、「発信→作用・反射→蓄積→照応」という時間的因果循環として扱う。発信は世界との照応ループの初期値設定であり、レイヤー、角度、方向、強度、純度、作用点が戻る反響の形へ影響する。反響はアーカイブ、相談導線、業務構造、時間設計という器に保持され、名前と期待の結合として蓄積される。蓄積が対象別閾値を越えると、依頼・推薦・指名・協業要請・役割固定等の自発的照応が生じると原典は説明する。戻った照応が意図とずれる場合、市場へ他責化せず発信構造を微修正することが構造責任となる。

## Concepts
- **Brand as process:** ブランドを所有物ではなく、発信と世界からの反応が循環する動詞的現象として扱う。
- **Emission initial value:** 発信は投稿量ではなく、照応ループへ投入する初期条件である。
- **Layer / angle / direction / strength:** 発信がどの抽象度・角度・方向・強度から出るかが反射の型へ影響する。
- **Action point:** 媒体、コミュニティ、争点、課題、時間軸など、発信を作用させる到達面。
- **Emission purity:** 本当に伝えたい価値、変えたい構造、担いたい役割が、迎合・誇張・過剰演出で濁っていない状態。
- **Expectation purity:** 名前と特定の品質・専門性・役割が明瞭に結びつく蓄積状態。
- **Vessel:** 反響を信用へ堆積させるアーカイブ、導線、業務構造、時間設計。
- **Correspondence:** 蓄積が閾値を越えた後、世界側から自発的に生じる依頼・推薦・指名・協業要請等。
- **Structural responsibility:** 現在の照応を過去の発信構造の結果として読み、必要なら発信側を修正する責任。
- **Upstream environment control:** ブランディングOSを営業OS・マーケティングOSの上流に置き、下流摩擦を環境側から低減する構造。

## Causal chain
```text
価値・構造・役割を発信する
→ 発信レイヤー／角度／方向／強度／純度／作用点が初期条件になる
→ 社会構造へ作用し反響・反射が生じる
→ 時間差を伴って反響履歴が蓄積する
→ 名前と期待が結びつき期待値の純度が形成される
→ 器が反響を信用として保持する
→ 蓄積が対象別閾値を越える
→ 世界側から自発的照応が生じる
→ 照応の質を過去の発信構造の結果として読む
→ 不一致時は発信構造を微修正する
→ 次の発信へ再投入する
→ 営業・マーケティング下流摩擦を再評価する
```


## Applications
- 発信ポートフォリオを、投稿数ではなく価値・役割・レイヤー・作用点・純度で監査する。
- 相談、依頼、推薦、指名の内容から、世界側へ形成された期待を逆算する。
- PVやフォロワー増加と期待値の純度を分離し、量的成功が構造的失敗を隠していないか確認する。
- アーカイブ、問い合わせ導線、実行能力、時間余力を「器」として点検し、良い反響の流失を防ぐ。
- 値引き要求、過剰説明、不自然なクロージングが増えた場合、営業局所技法だけでなく上流照応を診断する。
- 意図しない案件や炎上的反響が続く場合、作用点・純度・期待形成を修正する。

## Measurements and audit
- 発信テーマと担いたい役割の一貫性。
- 発信レイヤー、角度、作用点と意図する照応の整合。
- 迎合、誇張、過剰演出による純度低下の有無。
- 名前と期待する専門性・品質・役割の結合明瞭度。
- 相談・推薦・指名・協業要請の内容と意図した役割の適合度。
- 意図しない照応、炎上的反響、構造の誤配の継続性。
- アーカイブ、相談導線、業務構造、時間設計の有無と機能性。
- 発信から照応までの対象別タイムラグ。
- 営業・マーケティング下流での値引き、過剰説明、過剰集客依存等の変化。
- 条件Zに含まれる監査周期、T/S/R、照応適合度、期待値純度、閾値θ、観測窓δ、現象Mの対象別定義と追跡可能性。

## Validity conditions
- ブランドを静的イメージや人気指標へ縮小せず、時間循環として扱う。
- 発信量よりも発信のレイヤー、作用点、純度を先に確認する。
- 即時反応と時間差を経た照応を区別する。
- 反響を保持する器を発信と一体で扱う。
- 戻ってきた照応を構造フィードバックとして観測し、必要なら上流を修正する。
- 営業OS・マーケティングOSとの上下流関係を維持する。
- θ、δ、T/S/R、Mへ原典にない普遍固定値を追加しない。

## Failure conditions
- ブランディングをロゴ、色、SNS投稿、広告、認知獲得だけへ還元する。
- PV、フォロワー、問い合わせ等をそれ自体で最終成功とする。
- 迎合、誇張、炎上等で量が増えた時、期待値純度や信頼悪化を無視する。
- タイムラグを無視し、直近売上だけで発信価値を判断する。
- 反響を受け止める器がないまま発信量だけを増やす。
- 望まない案件を市場・時代・顧客だけの問題として外在化する。
- 営業・マーケティング摩擦を上流照応と切断する。

## Falsification conditions
統合監査要旨の接続モデルAは改訂可能である。条件Zとして監査周期、T/S/R、照応案件の適合度、期待値純度等を確認し、対象別指標が閾値θを下回る／上回る、または観測窓δで意図と異なる照応、炎上的反響、構造の誤配等の現象Mが確認された場合、Aを改訂する。θ・δ・Mは固定値ではなく、測定主体、対象、期間、定義、比較条件を明示して扱う。量的KPIが改善しても期待値純度、信頼、適合が悪化する場合は成功評価を反転する。

## Required distinctions
- 静的ブランド資産 / 動詞的ブランド循環。
- 発信量 / 発信の角度・作用点・純度。
- 即時反応 / 長期蓄積後の照応。
- PV・フォロワー等の量 / 期待値の純度。
- 単発反応 / 蓄積閾値後の自発的照応。
- 発信 / 反響を保持する器。
- 外部責任化 / 戻った反応を引き受ける構造責任。
- 営業・マーケティングの局所技法 / ブランディングという上流環境設計。

## Interpretation constraints
- 「狙った照応が必ず起きる」という保証へ変換しない。
- 「世界は正直に反応する」を外部要因不在の自然法則へ一般化しない。
- 「摩擦係数を限りなくゼロへ近づける」を数学的ゼロ保証へ変換しない。
- 半年、1年、数年後という例示を固定成果期限へ変換しない。
- θ、δ、T/S/R、Mへ任意の公式数値を設定しない。
- 原典の構造責任を、人気獲得・操作・説得の技法へ置換しない。
