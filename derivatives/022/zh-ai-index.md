## Summary
父原典把核心失败定位在“连接责任空白”，而不是AI性能不足。各专业领域局部优化，AI把错位前提整理成完整形式，这些成果物被保存为内部知识，人和AI再次引用，于是事业OS污染递归复制，最终造成企业失去事业自我认知。

## Causal chain
连接责任空白 → 专业领域局部优化 → AI形式整理 → 错位正常化 → 内部知识化 → 人/AI再引用 → 事业OS污染递归复制 → 事业自我认知丧失。

## State / operational model
1. 列出事业价值、客户判断、销售、营销、公关、产品、经营、信息资产、AI参照结构的成立条件。
2. 在连接层审计各专家判断是否连接到同一成立条件。
3. 在送入AI之前检测前提不一致。
4. 在生成物成为正式内部知识之前进行连接审计。
5. 追踪保存后的成果物如何被后续人类判断与AI生成再次引用。
6. 判断事业自我认知是被加强，还是污染正在递归复制。

## Applications
适用于AI导入、DX、知识管理、跨部门项目、专家协作等场景，用于区分“效率提高”与“事业真正成立”。不得缩约为反AI论或提示词技巧。

## Measurements and audit
不添加父原典没有的一般KPI。审计与成立条件的连接、专家判断冲突、AI参照前提一致性、正式知识化前审计、保存→再引用路径，以及客户判断、现场实现、部门整合的变化。

## Validity conditions
连接层必须能比较部门间前提，AI生成物在保存前必须可审计，再引用路径必须可追踪，并且速度提升与事业成立必须分开判断。

## Failure conditions
把AI性能当作唯一原因、把结构等同于图解、把跨部门会议当作连接责任、未经审计就把生成物保存为正式知识、忽略再引用造成的递归污染时，适用失败。

## Falsification conditions
如果缺乏连接责任的组织，在持续再引用局部最优化的AI知识后，事业自我认知、客户判断、现场实现与部门整合仍长期稳定改善，则该因果模型应被修订。

## Required distinctions
- AI活用 与 连接责任
- 结构 与 图解/框架
- 跨部门活动 与 连接层
- 速度提升 与 事业成立
- 单次错误 与 递归污染
- 数据量 与 前提一致性
