## 位置づけ
親原典は、接続価値への移行が風評・規範乗っ取り・ログ改ざん・抜け道設計・監査妨害・指標流用などによって骨抜きにされる可能性を前提リスクとして扱う。そこで、人格や思想を処罰するのではなく、**設計を破壊・歪曲・流用・妨害する限定集合の構造的行為**だけに作用する「マイナス接続（Negative eXposure: NX）」を、短期・限定・可逆・公開・反転可能な防護として設計する。

## 中心命題
**移行防護は、批判者や反対者を排除する制裁体系では成立しない。対象を構造破壊行為の限定集合へ閉じ、注意→制限→遮断→隔離を期限付き・記録付き・非人格的に適用し、二段審級、48〜72時間の冷却窓、反証提出、是正・再合意による必須減衰、監査の監査、制度側rollbackを備えることで、妨害を高コスト化しながら誤適用も修復可能にする。**

## 主要因果線
接続価値への移行→既存利害・短期換金圧・規範乗っ取りが設計を骨抜きにするリスク→思想や人格への制裁はディストピア化を生む→対象を破壊・歪曲・流用・妨害という行為集合へ限定→NXを注意/制限/遮断/隔離へ段階化→二段審級＋冷却窓＋反証→是正・再合意で必ず減衰→行為ログのみ・時間減衰・人格烙印禁止→監査人/監査モデルも監査→制度側rollback→妨害下でも誤配を減衰→移行を自走可能にする。

## 構造層
### 1. 価値領域の入れ替え
原典は、重要な合意スロット、監査優先帯域、情報アクセス窓、評価参照権などの中枢価値を、貨幣だけで買える領域から切り離す未来設計を提示する。これはParentの条件付き移行像であり、現行制度の既成事実として扱わない。

### 2. NX対象の限定集合
- 破壊型: 監査ログ改ざん、同意トークン不正生成、参照履歴消去。
- 歪曲型: 閾値恣意操作、可逆性条項封殺、評価モデル恣意重み付け。
- 流用型: 接続報酬指標の私的ポイント化、排他的条件への転売。
- 妨害型: 監査ノード圧力、根回しによるルール変更、抜け道設計。
政策批判・思想表明・交渉は対象外であり、「制度の骨抜き」に当たるかが境界になる。

### 3. 制裁レイヤ
注意層＝差分通知・公開要旨、制限層＝帯域/合意スロットの一時縮小、遮断層＝対象インターフェースの限定期限遮断、隔離層＝再教育・再合意を前提とするプロトコル隔離。人格評価には接続しない。

### 4. 手続保障
一次判断は自動監査＋複数監査人の合議。異議申立には48〜72時間の冷却窓を置き反証提出を認める。二次判断は別監査面が行い、公開ログには抄録を残す。是正・再合意・再発防止設計の提出によってNXは減衰する非永続原則を持つ。

### 5. 可逆性の三原則
人格的ブラックリスト等の不可逆保存を排除し、行為ログは時間減衰させる。改善案が成立すれば再合意を優先する。さらに監査人・監査モデルの重み、根拠、不確実性も公開要旨化し、誤判断時には制度側をrollbackできるようにする。

### 6. Phase 0–3
SubjectID / ConsentToken / Connection Ledger / Audit APIを準備し、限定ドメイン試験、中核機能移行、重要意思決定の監査通過条件へ段階化する。これはParentの未来設計であり、現行社会に既実装と断定しない。

### 7. 倫理の三つの封印
目的限定、非人格、比例・最小。NXは設計防護だけに用い、思想・言論・交渉・競争に適用せず、対象は行為とする。制裁強度は被害期待と再発可能性に応じ最小限とし、反転経路を常時開く。

### 8. 実装骨格と監査
ConsentToken v2、Connection Ledger、Audit API、NX Hook、Public Summaryを束ねる。RC、ER、CEA、Sを監査候補とし、妨害検知遅延、撤回成功、位相安定、再合意到達時間、ロックイン健全度も観測する。原典の具体数値・式は文脈付きで扱い、別制度へ普遍化しない。

## 適用例
公共では試行条例→期限施行→再審査、NXは抜け道設計等の構造違反へ限定。企業では機能フラグ・段階展開・ダークローンと前後監査。教育では不当流用を対象にしつつ改稿・再提出で反転。AI運用では多層フィルタ＋rollback、人間の二段審級を必須とする。

## 測定・監査点
- NX対象が限定集合を越えて思想・批判・交渉へ拡張されていないか。
- 制裁が期限付き・記録付き・反転可能か。
- 48〜72時間の冷却窓と反証提出が実際に使えるか。
- 是正後にNXが減衰するか。
- 人格スコア・永久ブラックリストへ変質していないか。
- 監査人/監査モデル自身の根拠・不確実性を監査できるか。
- RC、ER、CEA、S、妨害検知遅延、撤回成功、位相安定、再合意時間を複数軸で追えるか。

## 成立条件
対象行為を限定集合へ閉じる。思想・批判・交渉を対象外にする。期限・記録・反転可能性を持つ。二段審級と反証提出を保証する。人格評価へ連結しない。監査の監査を持つ。比例・最小を守る。制度側rollbackを実装する。

## 失敗条件
NXを反対者排除へ使う。人格点数化・永久烙印を行う。冷却窓を形式化して反証を受け付けない。監査側だけを無謬化する。反転経路を閉じる。政策批判や交渉を妨害扱いする。強度を被害と無関係に引き上げる。

## 反証・改訂条件
妨害検知遅延、撤回成功、位相安定、再合意到達時間、ロックイン健全度が悪化する、風評連鎖・規範攪乱が観測窓で増える、誤適用が修復できない、思想・批判へNXが拡張される場合、防護設計を改訂または棄却する。

## 必須の区別
設計防護 / 報復; 構造的行為 / 人格; NX / 社会信用スコア; 制限 / 永久排除; 冷却窓 / 手続遅延による封殺; 監査 / 無謬な権威; 反転 / 無責任免責; 政策批判 / 制度骨抜き; 比例最小 / 見せしめ。

## 誤読防止・解釈制約
原典には強い移行主張があるが、これを現実の人・団体へ制裁を実施する一般許可へ変換しない。NXはParent内部でも限定集合・短期・可逆・公開・非人格・手続保障付きでのみ成立する。最大72時間、48〜72時間、80%信頼回復、四半期〜半期等の数値はParentの設計例・定義文脈であり、他制度へ無条件移植しない。
