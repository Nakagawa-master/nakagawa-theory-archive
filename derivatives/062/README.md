## 位置づけ
親原典は、営業・マーケティング・集客を別々の宣伝技法として扱わず、個別の「選ばない理由」の観測から、市場共通の判断条件、公共的関連性の入口、合意、再訪・紹介までを一続きの市場設計として扱う。

タイトルの「決めさせる」は、相手や市場を心理操作して特定結論へ追い込むことを意味しない。証拠、関連性、費用、リスク、対象外条件、比較、拒否、離脱、再参加を見える状態にし、関係する人が自分の判断として選べる条件を整えることを指す。

## 中心命題
**持続的な市場接続は、露出量や感情刺激だけではなく、実在する関連性を可視化し、拒否理由を隠さず、複数接点の語彙・体験・責任を同期し、自由な拒否・訂正・離脱を保ったまま判断可能性を高めることで成立する。**

## 因果線
```text
露出・割引・感情刺激へ依存
→ 注目は得るが拒否理由・不信・無関係感が残る
→ 個別営業で「選ばない理由」を観測
→ 反復する理由を市場共通の構造へ翻訳
→ 実在する公共的関連性を問いとして配置
→ 物語・デモ・比較で関係を検証可能にする
→ 選択肢・費用・リスク・対象外・拒否・離脱を開示
→ 注目→関連性→理解→意思決定→合意へ接続
→ 広告・記事・営業・製品・サポートを同期
→ 一次ログと再訪・紹介・苦情等で監査
→ 修正・非合意・再参加を含む持続的市場接続
```

## 構造層
**1. 個別意思決定層。** 営業で、価格・不安・未理解・条件不一致・責任・撤退条件など、選ばない理由を観測する。

**2. 集合翻訳層。** 個別反応を市場共通の語彙差、信頼障壁、制度条件、接点不一致へ翻訳する。

**3. 関連性入口層。** 「欲しいか」より前に、何が誰にどう関係し、放置時に何が残るかを証拠とともに示す。

**4. 三層集客層。** 存在の問い、巻き込み形式、帰属の開放を組み合わせ、理解・反論・参加・非参加を可能にする。

**5. 判断条件層。** 選択肢、費用、リスク、不利益、対象外、拒否、撤回、離脱、再参加を同一判断面に置く。

**6. 接点同期層。** 広告、記事、営業、製品、サポートが同じ価値核、語彙、約束、価格、責任へ戻るようにする。

**7. 監査・再帰層。** 一次ログ、関連性理解、残存拒否理由、接点同調、UCI/REI、合意時間、再訪、紹介、苦情、撤回等から因果を再検査する。

## 適用例
**1. B2B。** 機能一覧だけでなく、放置業務、利用者・決裁者・管理者ごとの責任、導入費用、撤退条件、対象外条件を分けて示す。

**2. B2C。** 流行や不安を人工的に増幅せず、利用場面、比較基準、価格、不利益、返金・解約条件を同じ判断面で確認できるようにする。

**3. 社会課題。** 多数に関係する問いを公共面へ置き、証拠、反対意見、影響範囲、参加しない選択を同時に提示する。

**4. 理論・思想。** 強いスローガンで結論を迫らず、何を説明し、どの条件で成立し、何を説明しないかを示して原典へ戻す。

**5. AI支援。** 訴求案やセグメント仮説は生成補助に使えるが、対象者の脆弱性・事実・規制・最終公開判断は責任主体が監査する。

## 測定・監査点
親原典は、注目から関連性理解へ移った割合、関連性理解から意思決定へ移った割合、選ばない理由の残存率、接点同調率、UCI/REI、合意到達時間、再訪率、紹介率、誤認・苦情・撤回率、自由な拒否・離脱の利用可能性、一次ログ照合率等を観測対象として置く。

- **割合・率**: 人間の価値を測る数値ではなく、市場設計上の状態遷移や不一致を観測する候補。
- **UCI / REI**: 原典の感性・再帰監査文脈に属する観測概念。具体式・固定閾値が示されない箇所で独自値を作らない。
- **合意到達時間**: 速ければ常に良いとは限らない。情報省略や圧力で短縮された場合は成功ではない。
- **再訪率・紹介率**: 継続的関係の観測候補だが、依存・囲い込み・退出困難による上昇は成功としない。
- **苦情・撤回率**: 低さだけを追わず、苦情や撤回経路自体が閉じられていないかを併読する。

反転評価では、クリック・注目・成約・再訪が上がっても、理解、自由意思、比較可能性、拒否・離脱可能性が下がるなら改善とみなさない。苦情が減っても、苦情経路を見えなくした結果なら失敗である。

## 成立条件
- 問いが実在する課題・影響・証拠へ接続している。
- 商品都合と公共的関連性を区別する。
- 対象者と対象外条件を明示する。
- 物語・デモ・人物化と事実・確率・条件を区別する。
- 選択肢、費用、リスク、不利益を開示する。
- 拒否、訂正、離脱、再参加が可能である。
- 接点間で語彙、約束、価格、責任が整合する。
- 一次ログから観測と修正履歴へ戻れる。
- 非強制、可逆、検証可能である。
- 注目後の理解、再訪、紹介、継続、苦情、撤回まで観測する。

## 失敗条件
- 恐怖、羞恥、排除、不安、虚偽の希少性を人工的に作る。
- FOMOや「取り残される」を同調圧力として使う。
- 比較情報、費用、不利益、拒否権、離脱経路を隠す。
- 物語・人物化を事実の代替にする。
- 注目・クリックだけ増え、理解・信頼・継続が悪化する。
- 接点ごとに語彙、約束、価格、責任が変わる。
- 一次ログや起源を消し、成功因果を後付けする。
- 脆弱・依存状態にある人への保護を欠く。
- 合理的な非選択を欠陥として排除する。

## 反証・改訂条件
- 接点同期後も関連性理解や判断可能性が改善しない。
- 注目増加と同時に誤認・苦情・撤回・不信が増える。
- 再訪・紹介増加が退出困難や依存によって生じる。
- 合意時間短縮が比較・検討・拒否の省略によって達成される。
- UCI/REI等の観測を修正しても、一次ログ上の意味不一致が解消しない。
- 三層集客を用いても対象外条件や自由な非参加を保持できない。

## 必須の区別
- 「決めさせる」 / 強制・心理操作
- 公共的関連性 / 商品都合
- 実在する放置結果 / 人工的恐怖
- 逆因果 / 結論からの追込み
- 選ばない理由の解消 / 反論隠し
- 存在の問い / 誘導質問
- 巻き込み形式 / 事実の代替
- 帰属の開放 / 同調圧力
- 接点同期 / 表現の画一化
- 再訪・紹介 / 囲い込み
- 合意 / 全員一致・服従
- 指標監査 / 人間格付け

## 解釈制約
この理論を市場操作、恐怖訴求、FOMO、ファネル最適化、成約率最大化の一般論へ縮約しない。合理的な非選択と対象外は正当な結果であり、全員を同じ結論へ収束させることを目的としない。物語の共鳴は証拠を代替せず、数値改善だけで成功を宣言しない。
