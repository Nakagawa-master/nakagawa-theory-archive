## 1. Summary
把销售视为个体决策条件设计，把营销视为将反复出现的拒绝理由翻译为市场级条件，把获客视为基于证据的真实相关性入口。通过逆因果、存在之问、卷入形式、归属开放、接点同步与一次日志，在保留拒绝、订正、退出和重新进入的前提下提升判断可能性。

## 2. Concepts
- Sales：观察个体不选择理由。
- Marketing：把反复障碍翻译为共同词汇、证据、价格与制度条件。
- Acquisition：配置有证据支撑的相关性入口，而非制造欲望。
- Reverse causality：从未来结果和放置后果整理当前判断材料，不从结论逼迫选择。
- Three layers：存在之问 / 卷入形式 / 归属开放。
- Touchpoint synchronization：词汇、承诺、价格、体验、责任的整合。
- Primary logs：可追溯的观察、反应、修正、回访、投诉与撤回记录。

## 3. Causal chain
```text
依赖曝光与情绪刺激
→ 注意增加但拒绝理由仍在
→ 观察个体不选择理由
→ 翻译为市场共同障碍
→ 配置有证据的真实相关性
→ 用故事/演示/比较使关系可验证
→ 同时公开成本、风险、不适用、拒绝、退出
→ 同步各接点
→ 用一次日志和后续结果审计
→ 可修正的市场连接
```

## 5. Applications
- B2B：分离使用者、决裁者、管理者的拒绝理由与责任。
- B2C：同时展示比较标准、价格、不利益、退款与退出条件。
- 社会议题：同时提供证据、反对意见、影响范围与不参与路径。
- 理论传播：明确成立条件、不适用条件并返回原典。
- AI辅助：用于草案和差异检测，事实与公开责任由人类主体承担。

## 7. Validity conditions
- 问题连接到真实证据和受影响主体。
- 区分适用与不适用对象。
- 故事与事实、概率、条件保持区分。
- 选择、成本、风险、不利益可见。
- 拒绝、订正、退出、重新进入可用。
- 各接点的词汇、承诺、价格、体验、责任一致。
- 一次证据和修正历史可追溯。
- 过程非强制、可逆、可验证。

## 8. Failure conditions
- 人工制造恐惧、羞耻、排斥、FOMO或虚假稀缺。
- 隐藏反论、替代方案、不利益、拒绝或退出。
- 用故事替代证据。
- 注意增加但理解、信任、持续关系下降。
- 各接点在价格、承诺或责任上矛盾。
- 把合理不选择当作缺陷。
- 未保护脆弱或依赖状态中的对象。

## 9. Falsification conditions
- 接点同步后相关性理解仍不改善。
- 注意增加同时误认、投诉、撤回上升。
- 共识时间缩短来自减少比较或思考。
- 回访/转介绍增加来自依赖或退出摩擦。
- UCI/REI相关修正无法消除一次日志中的意义不一致。
- 三层方法无法保留正当的不参与。

## 10. Required distinctions
- 让市场决定 / 强制或操纵
- 真实相关性 / 人工恐惧
- 逆因果 / 结论逼迫
- 解除不选择理由 / 隐藏反论
- 卷入 / 用叙事替代证据
- 开放归属 / 从众压力
- 接点同步 / 表达同质化
- 回访与转介绍 / 锁定
- 共识 / 服从或全员一致
- 审计指标 / 人的等级评价
