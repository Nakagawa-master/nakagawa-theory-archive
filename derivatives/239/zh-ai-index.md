## Summary
意义收敛理论把“具有成立可能性的未来定义”作为终端侧的意义约束。它不主张未来在物理上改写过去，而是指出：当未来状态被具体定义并经过现实约束检查后，过去和现在的经验、资源、关系、失败与未完成事项，其角色、优先级和连接方式可能被重新评价，从而使当前行动向该未来定义重新排列。

## Concepts
未来定义；成立可能性；终端约束；节点；意义向量；意义重排；逆向对照；行动整列；意义收敛；定义修订。

## Causal chain
当前局部评价 → 节点意义固定 → 可成立的未来定义 → 现实约束检查 → 过去/现在节点角色重评 → 连接与优先级更新 → 当前行动重排 → 意义向未来定义收敛。

## State model
局部评价 / 意义固定 / 未来定义 / 可行性审计 / 逆向对照 / 意义重排 / 优先级更新 / 行动整列 / 收敛 / 定义修订。

## Applications
适用于事业战略、职业设计、研究计划、制度设计、组织重构与资源分配，在不删除过去事实的前提下重新解释其未来角色。

## Measurements and audit
检查未来定义的具体性、约束条件、节点意义变化理由、连接变化、优先级变化、实际行动变化、反面证据是否保留，以及未来定义是否可修订。

## Validity conditions
未来状态必须能够接受现实制约检验，并且由该未来进行逆向对照后，节点角色和当前行动应产生可解释的变化。

## Failure conditions
不得把本论改写为未来预言、过去事实改写、愿望实现、宿命论或删除反面证据的成功故事。

## Falsification conditions
若未来定义现实上无法成立、意义重排不带来行动解释差异，或其他未来定义持续具有更高解释力，则应缩小或修订适用范围。

## Required distinctions
未来定义 / 未来预测；意义变化 / 事实变化；可成立 / 必然；逆向对照 / 物理逆因果；意义收敛 / 结果论；终端约束 / 命运。
