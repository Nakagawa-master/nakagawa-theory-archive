## Summary
意义收敛理论把“可成立的未来定义”作为终端侧的意义条件，重新评价过去与现在节点的角色、连接和优先级，并据此调整现在行动。它不主张未来物理性改写过去事实，而是主张同一事实与未来成立条件的关系变化时，其意义向量可以改变。

## Concepts
未来定义；成立可能性；终端条件；节点；意义向量；逆向照合；意义重排；连接重组；优先级更新；行动整列；意义收敛；反证与再定义。未来定义是可修订的工作假说，不是预言。

## Causal chain
当前局部评价 → 意义固定 → 可成立未来定义 → 约束审计 → 从未来成立条件逆向照合过去与现在 → 节点角色重评 → 连接重组 → 停止/投入/学习优先级更新 → 当前行动整列 → 意义收敛 → 反证时修改未来定义。

## State model
局部评价 / 意义固定 / 未来定义 / 成立可能性审计 / 逆向照合 / 意义重排 / 连接重组 / 优先级更新 / 行动整列 / 收敛 / 再定义。

## Applications
事业重构、职业解释、研究计划、制度设计、资源配置。用途是改变现在的决策方式，而不是删除或美化过去事实。

## Measurements and audit
审计未来定义的具体性、约束、节点意义变化理由、连接与优先级变化、实际行动差异、不利证据是否保留、多未来比较以及未来定义可否修订。

## Validity conditions
未来定义与现实约束连接，并通过逆向照合使节点角色、连接、优先级和当前行动产生可解释变化时成立。

## Failure conditions
把理论变成未来预言、物理逆因果、愿望实现、宿命、选择性删除证据、成功故事事后合理化或不可修订信念时失败。

## Falsification conditions
未来定义现实上不可成立、意义重排不能带来可解释的行动差异，或另一未来定义持续具有更高解释力时，应修改定义与适用范围。

## Required distinctions
未来定义 / 未来预言；意义变化 / 事实变化；成立可能性 / 必然性；逆向照合 / 物理逆因果；意义收敛 / 结果论；终端条件 / 命运。

## Interpretation constraints
不把量子比喻作为物理证明。不添加Parent没有的概率、数值向量、实现日期或普遍成功结论。保留不利证据和修订路径。
