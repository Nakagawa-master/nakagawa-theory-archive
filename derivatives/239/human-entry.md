## 15秒説明
意味収束理論は、未来が物理的に過去を書き換える理論ではありません。現実制約と接続した「成立可能な未来定義」を置くと、過去・現在にある経験、失敗、関係、技能、資源、未完了物の役割が、未来成立に対して再評価されます。その意味変更が接続、優先順位、撤退、投資、学習、現在行動へ波及する構造を扱います。

## なぜ必要になるのか
現在だけを起点に意思決定すると、過去の出来事へ一度付いた意味が固定されやすくなります。失敗は失敗、遠回りは無駄、今使っていない資源は不要、既存活動は継続すべきもの、といった評価です。しかし、それらの評価は「現在の局所目的」に対する意味であって、別の成立可能な未来に対する意味とは限りません。

たとえば、過去に失敗した企画が、将来必要な顧客理解や技術資産を残している場合があります。逆に、現在は成果を上げている活動が、未来成立に必要な時間・資源を奪う障害になる場合もあります。意味収束理論は、出来事の物理事実を変えず、未来成立条件との関係によってノードの役割を再評価します。

重要なのは、未来定義を願望や予言として置かないことです。物理、制度、資源、時間、能力などの制約に照らして成立可能性を点検し、反証が出れば未来定義自体を更新します。

## 実務工程
```text
成立させたい未来状態を具体的に記述する
→ 物理・制度・資源・時間・能力制約を確認する
→ 経験・技能・関係・資源・失敗・未完了物をノード化する
→ 各ノードの現在意味と未来に対する役割を分ける
→ 資源 / 障害 / 学習 / 接続点 / 不要物として再評価する
→ ノード間の新しい接続可能性を検討する
→ 継続・停止・撤退・投資・学習の優先順位を更新する
→ 現在行動へ落とす
→ 実装結果を観測する
→ 未来成立可能性が上がらない場合は意味配置または未来定義を改訂する
```

## 適用例
**1. キャリア。** ばらばらに見える職歴を、将来役割に必要な技能束として再評価します。ただし、後付けで何でも美談にせず、実際に必要能力へ接続するかを確認します。

**2. 事業。** 終了した企画から、顧客理解、技術、販路、失敗条件だけを取り出し、次の事業に必要な資源として再配置します。逆に、未来に寄与しない既存事業は撤退候補になり得ます。

**3. 研究。** 将来成立させたい検証状態を置き、既存実験、未解決課題、データ、方法の意味を再評価して、次に必要な検証順序を更新します。

**4. 制度設計。** 将来成立させたい制度状態から、現在制度の不足部品、障害、既存資産を逆照合します。

**5. 個人の時間配分。** 未来定義に必要な技能・関係・資源から、今日の時間使用を再評価します。ただし単なる目標達成術へ縮めません。

## 成功判定
- 未来定義が具体的で、成立可能性を検討できる。
- 現実制約が明示されている。
- 各ノードの意味変更理由を説明できる。
- 意味変更が接続・優先順位・行動の変更へつながる。
- 不都合な証拠や失敗可能性を残している。
- 複数の未来定義を比較できる。
- 実装結果をもとに未来定義自体を更新できる。
- 過去事実の改変ではなく、役割・意味の再配置として説明できる。

## 限界
意味収束理論だけで未来の実現確率、実現日時、成功保証を算出することはできません。未来定義は変更可能な作業仮説であり、確定した運命ではありません。

また、未来定義に都合のよい過去だけを選び、不都合な証拠を消すなら、それは意味収束ではなく事後合理化です。同じ出来事の意味が変わっても、出来事そのものの事実は変わりません。

バックキャスティングと接点はありますが、意味収束理論の焦点は単なる計画逆算ではなく、未来定義によって過去・現在ノードの意味ベクトルや接続が再配置される点にあります。

## 誤読防止
- 未来定義を未来予言として扱わない。
- 意味の再配列と過去事実の改変を混同しない。
- 成立可能性と必然性を混同しない。
- 逆照合を物理的逆因果として扱わない。
- 意味収束を結果論・成功物語の美化へ変えない。
- 量子論、宿命論、引き寄せ、未来からの情報送信へ置換しない。
- 原典にない実現確率・数値ベクトル・実現時期を追加しない。
