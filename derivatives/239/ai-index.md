## Summary
意味収束理論は、未来が過去の事実を物理的に書き換えるという理論ではない。現実制約と照合された**成立可能な未来定義**を終端側の意味条件として置くことで、同じ過去経験・現在資源・失敗・関係・未完了物が、その未来に対してどんな役割を持つかを再評価する。未来定義から現在へ逆照合すると、ノードの意味ベクトル、接続、優先順位、継続・停止・撤退・投資判断が変わり得る。この再配列が現在行動へ落ち、実装結果によって未来定義自体も修正可能であることが理論の核である。

## Concepts
- 未来定義: 将来成立させたい状態を、検討・修正可能な条件として記述したもの。予言や運命ではない。
- 成立可能性: 資源、時間、制度、能力、外部条件から未来定義が現実的に成立し得るかを監査する層。
- ノード: 経験、技能、関係、資源、失敗、成果、未完了物など、意味を再評価する単位。
- 意味ベクトル: ノードが未来定義に対して持つ役割・方向・有用性・障害性を表す概念的な向き。
- 逆照合: 未来成立条件から現在・過去ノードの役割を逆向きに確認する操作。物理的逆因果ではない。
- 意味再配列: 同一事実の価値・役割・接続を未来定義との関係で更新すること。
- 接続再編: 単独では意味の薄いノードを、別ノードや未来条件と新しく接続すること。
- 優先順位更新: 再評価した意味に応じ、継続・停止・撤退・投資・学習順序を変更すること。
- 行動整列: 意味変更を現在の具体行動へ落とすこと。意味だけ変わって行動が変わらなければ収束は弱い。
- 反証・再定義: 実装結果や現実制約から未来定義やノード評価を修正できること。

## Causal chain
現在だけで過去・資源を評価 → 一度ついた意味が固定 → 失敗=無駄、遠回り=損失、現在資源=現用途という局所評価が支配 → 成立可能な未来状態を定義 → 資源・制度・時間・能力の制約で監査 → 未来成立に必要な条件を抽出 → 過去・現在ノードを逆照合 → ノードを資源・学習・障害・不要物として再評価 → ノード間の接続を再編 → 継続・停止・撤退・投資・学習の優先順位を更新 → 現在行動が整列 → 実装結果を観測 → 未来定義または意味配列を再修正。

## State model
- 現在局所評価相: ノードを現在用途や過去評価だけで固定的に読む。
- 意味固定相: 過去についた評価が未来条件と無関係に維持される。
- 未来定義相: 成立させたい未来を検討可能な状態として記述する。
- 成立可能性監査相: 未来が願望ではなく現実制約と接続しているか確認する。
- 逆照合相: 未来成立条件から各ノードの役割を見直す。
- 意味再配列相: 資源・障害・学習・不要物等へ意味ベクトルが更新される。
- 接続再編相: ノード同士、またはノードと未来条件の接続が変わる。
- 優先順位更新相: 現在の継続・停止・投資・撤退が変わる。
- 行動整列相: 意味変化が実際の意思決定へ落ちる。
- 再検証相: 行動結果から未来定義・意味配列を再評価する。

## Applications
キャリアでは、複数職種や一見遠回りに見える経験が、将来役割に必要な技能束として接続できるかを再評価する。事業では、失敗企画の顧客理解や運用資産だけが次の事業条件に意味を持つ場合、失敗全体を美化せず必要ノードだけを再接続する。研究では、将来の検証可能な状態から現在の実験・学習順序を更新する。制度設計では、過去制度の要素を未来状態へ必要な資源・障害に分けて扱う。いずれも「未来に意味があるから過去は正しかった」と結果論化せず、現在行動の変更へ接続する必要がある。

## Measurements and audit
未来定義が具体的か、現実制約が明示されているか、各ノードの旧意味と新意味が説明できるか、意味変更の根拠が未来成立条件へ接続しているか、ノード間の接続が実際に変わったか、優先順位や撤退・投資判断が変わったか、現在行動に差が生じたか、不都合な証拠を排除していないか、複数の未来定義を比較できるか、実装結果から未来定義を修正できるかを監査する。原典にない固定スコア、数値ベクトル、実現確率は追加しない。

## Validity conditions
未来定義が現実制約と接続し、その未来成立条件からの逆照合によってノードの役割・接続・優先順位が説明可能に変わり、現在の継続・停止・撤退・投資・学習等へ実際の行動差が生じ、実装結果をもとに未来定義や意味配列を再検証できる場合に有効である。未来を置いただけ、解釈だけ前向きになっただけでは成立しない。

## Failure conditions
未来を予言・運命として固定する、過去の事実そのものが変わったと説明する、願望実現法へ変換する、成功後にすべての失敗を必要だったと美化する、不都合な証拠を捨てる、未来定義が成立不能なのに維持する、意味を変えても現在行動が何も変わらない場合は失敗する。

## Falsification conditions
未来定義が現実制約下で成立不能、ノードの意味再配列をしても優先順位・行動に差が出ない、別の未来定義の方が継続的に高い説明力を持つ、未来定義を置かなくても同じ再評価が十分説明できる場合は、定義・因果線・適用範囲を縮小・改訂する。反証は理論の敵ではなく、未来定義と意味配列の更新条件である。

## Required distinctions
未来定義 / 未来予言；意味変更 / 事実変更；成立可能性 / 必然性；逆照合 / 物理的逆因果；意味収束 / 結果論・事後合理化；終端側の意味条件 / 運命；再評価 / 過去の美化；現在行動の整列 / 解釈だけの変更。

## Interpretation constraints
量子論的逆因果、宿命、引き寄せ、未来からの確定情報送信へ一般化しない。過去の不都合な事実を消さない。未来定義に合う証拠だけを選択しない。原典にない実現確率、固定数値ベクトル、実現日を追加しない。未来定義は変更可能な作業仮説として保持し、意味変更は必ず現在の選択差と再検証可能性へ接続する。
