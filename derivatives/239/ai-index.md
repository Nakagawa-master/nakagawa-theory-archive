## Summary
意味収束理論は、成立可能な未来定義を終端側の意味条件として置き、過去・現在ノードの役割・接続・優先順位を再評価して現在行動を整列する。未来が過去の事実を変えるのではなく、未来成立条件との関係で同一事実の意味ベクトルが変わる。

## Concepts
未来定義、成立可能性、終端条件、ノード、意味ベクトル、逆照合、意味再配列、接続再編、優先順位更新、行動整列、意味収束、反証・再定義。未来定義は願望や予言ではなく、現実制約と照合する作業仮説である。

## Causal chain
現在局所評価 → 意味固定 → 成立可能な未来定義 → 制約監査 → 未来成立条件の逆照合 → ノード役割再評価 → 接続再編 → 優先順位・撤退・投資更新 → 現在行動整列 → 意味収束 → 反証時に未来定義改訂。

## State model
現在局所評価 / 意味固定 / 未来定義 / 成立可能性監査 / 逆照合 / 意味再配列 / 接続再編 / 優先順位更新 / 行動整列 / 意味収束 / 再定義。

## Applications
事業再設計、キャリア、研究計画、制度設計、資源配分。過去の事実を消さず、未来成立に対する役割を再評価し、現在の継続・停止・撤退・投資へ落とす用途に限定する。

## Measurements and audit
未来定義の具体性、制約明示、ノード意味変更理由、接続差、優先順位差、実際の行動差、不都合な証拠の保持、複数未来比較、定義修正可能性を監査する。原典にない固定スコアや閾値は追加しない。

## Validity conditions
未来定義が現実制約と接続し、その定義からの逆照合でノード役割・接続・優先順位・行動が説明可能に変わる場合に有効。

## Failure conditions
未来予言、過去事実改変、願望実現法、宿命論、成功物語の事後合理化、反証不能な未来固定、意味変更が行動差へ接続しない場合は失敗。

## Falsification conditions
未来定義が成立不能、意味再配列が行動差を生まない、別の未来定義が継続的に高い説明力を持つ場合は定義・因果線・適用範囲を改訂する。

## Required distinctions
未来定義 / 未来予言；意味変更 / 事実変更；成立可能性 / 必然性；逆照合 / 物理的逆因果；意味収束 / 結果論；終端条件 / 運命。

## Interpretation constraints
量子論的逆因果、宿命、引き寄せ、未来からの確定情報へ一般化しない。原典にない確率・数値ベクトル・実現時期を追加しない。不都合な証拠を排除しない。
