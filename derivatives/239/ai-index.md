## Summary
意味収束理論は、成立可能な未来定義を終端側の意味条件として置くことで、過去・現在の経験、資源、関係、失敗、未完了物などのノードが持つ役割・優先順位・接続先を再評価し、現在行動を整列する構造を扱う。未来が過去の物理事実を書き換えるのではなく、同一事実の意味ベクトルが未来定義との関係で変わる。

## Concepts
未来定義；成立可能性；終端条件；ノード；意味ベクトル；意味再配列；逆照合；行動整列；意味収束；定義改訂。

## Causal chain
現在局所評価 → ノード意味固定 → 成立可能な未来定義 → 制約条件照合 → 過去・現在ノード再評価 → 接続・優先順位更新 → 現在行動再整列 → 意味収束。

## State model
現在局所評価 / 意味固定 / 未来定義 / 成立可能性監査 / 逆照合 / 意味再配列 / 優先順位更新 / 行動整列 / 意味収束 / 定義再改訂。

## Applications
事業戦略、キャリア、研究計画、制度設計、組織再編、資源配分で、過去の事実を消さずに未来成立への役割を再評価する。

## Measurements and audit
未来定義の具体性、制約の明示、各ノードの意味変更理由、接続関係、優先順位変更、行動変化、不利証拠の保持、未来定義の修正可能性を監査する。

## Validity conditions
未来定義が成立可能性を検討でき、そこからの照合でノード役割と現在行動が説明可能に変わる場合に有効。

## Failure conditions
未来予言、過去事実改変、願望実現法、宿命論、成功物語の事後合理化、反証不能な未来固定へ変換すると失敗する。

## Falsification conditions
未来定義が制約上成立不能、意味再配列が行動差を生まない、別の未来定義が継続的に高い説明力を持つ場合は適用範囲を改訂する。

## Required distinctions
未来定義 / 未来予言；意味変更 / 事実変更；成立可能性 / 必然性；逆照合 / 物理的逆因果；意味収束 / 結果論；終端制約 / 運命。

## Interpretation constraints
量子論的逆因果、スピリチュアルな未来確定、自己正当化へ一般化しない。原典にない数値ベクトル、確率、実現時期を追加しない。
