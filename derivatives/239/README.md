## 位置づけ
意味収束理論は、未来を予言対象として固定する理論ではない。成立可能な未来定義を終端側の意味条件として置いたとき、過去・現在の経験、資源、関係、失敗、未完了物、選択肢が持つ役割・優先順位・接続先を再評価し、現在行動を整列させる構造を記述する。未来が過去の物理事実を書き換えるのではなく、同じ事実の意味が、未来成立条件との関係によって変わる。

## 中心命題
現在だけを起点にすると、過去の出来事は一度与えられた意味に固定されやすい。だが、現実制約と接続した未来定義を置くと、「失敗」は必要な学習、「遠回り」は関係資産、「余剰」は必要能力、「継続中の活動」は未来成立を妨げる負荷として再評価され得る。重要なのは、未来像を正解として信じることではなく、未来成立に必要な条件から現在を逆照合し、意味・接続・優先順位・行動を更新することである。

## 因果線
```text
現在起点の局所評価
→ 過去・資源・活動の意味が固定
→ 成立可能な未来定義を置く
→ 物理・制度・資源・時間・能力制約を確認
→ 未来成立条件を現在・過去へ逆照合
→ 各ノードを資源・障害・学習・接続・不要物として再評価
→ ノード間の新しい接続を発見
→ 優先順位・撤退・投資・学習順序を更新
→ 現在行動が未来定義へ整列
→ 反証に応じ未来定義自体を改訂
```

## 構造層
1. **未来定義層**: 到達状態を検討可能な条件として言語化する。
2. **成立可能性層**: 願望と区別するため現実制約を確認する。
3. **ノード層**: 経験、資源、関係、技能、失敗、未完了物を分解する。
4. **意味ベクトル層**: 各ノードが未来成立へどの役割を持つかを再評価する。
5. **接続再編層**: 以前は無関係だったノード間の接続を検討する。
6. **優先順位層**: 投資・停止・撤退・学習・協働の順序を更新する。
7. **行動整列層**: 意味変更を実際の現在行動へ落とす。
8. **反証・改訂層**: 未来定義を固定信念にせず、成立不能なら修正する。

## 状態モデル
現在局所評価相 → 意味固定相 → 未来定義相 → 成立可能性監査相 → 逆照合相 → 意味再配列相 → 接続再編相 → 優先順位更新相 → 行動整列相 → 意味収束相 → 反証・再定義相。

## 適用例
事業では、過去に失敗した企画を廃棄済み情報として終わらせず、未来事業に必要な顧客理解・技術・販売経路として再評価できる。キャリアでは、ばらばらな職歴を将来役割に必要な技能束として再構成できる。研究では、成立させたい説明・実装状態を定義し、既存実験や未解決課題の意味を更新できる。制度設計では、将来成立条件から現在制度の不足部品を逆照合する。ただし、いずれも未来定義が成立可能性を持つことが前提である。

## 測定・監査点
- 未来定義が具体的で検討可能か。
- 制約条件が明示され、願望だけで成立可能と扱っていないか。
- 各ノードの意味変更理由を説明できるか。
- 未来像に不都合な証拠を排除していないか。
- 接続・優先順位・撤退・投資が実際に変化したか。
- 未来定義を置く前後で意思決定差を追えるか。
- 複数の未来定義を比較できるか。
- 反証時に定義を修正できるか。

## 成立条件
成立可能な未来定義が現実制約と接続し、その定義からの逆照合によって、過去・現在ノードの役割、接続、優先順位、現在行動が説明可能に変わる場合に成立する。未来定義は作業仮説であり、絶対予言ではない。

## 失敗条件
未来が過去の物理事実を改変すると読む、願望を未来からの確定情報とする、都合の悪い証拠を消す、成功物語の事後合理化だけに使う、未来定義を変更不能な運命へ固定する、意味変更が現在行動に何も影響しない場合は失敗する。

## 反証・改訂条件
未来定義が現実制約上成立不能である、定義を置いてもノードの意味・接続・優先順位・行動に説明可能な変化が生じない、または別の未来定義が継続的に高い説明力を持つ場合は、定義・因果線・適用範囲を改訂する。

## 必須の区別
未来定義 / 未来予言；意味の再配列 / 過去事実の改変；成立可能性 / 必然性；逆照合 / 物理的逆因果；意味収束 / 結果論；終端条件 / 不変の運命；再評価 / 都合のよい美化。

## 誤読防止／解釈制約
量子論的逆因果、宿命論、願望実現法、未来からの情報送信として扱わない。原典にない確率、数値ベクトル、実現時期、普遍的成功則を追加しない。意味が変わっても過去の事実は変わらない。
