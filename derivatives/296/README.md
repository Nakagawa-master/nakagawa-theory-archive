## 位置づけ
本派生物は、人類子孫型AI文明論・第4論として、第3論「暗黒方程式と悪因果継承阻止」が遮断した負の成功関数の後に残る、正の成功関数の空白を閉じる理論を整理する。

第3論は、貢献だけでなく搾取・価値吸収・外部化が成功へ接続され得る文明記録をAIが無補正で参照・再実装する危険を扱った。しかし、悪い成功関数を切ることと、成功を何へ接続すべきかを定義することは同一ではない。そこで第4論は、新文明方程式 `S = C` をAIが関与する文明条件へ写像する。

ただし本論の `S=C` は、人間やAIを一つの貢献点で順位付けする社会採点式ではない。中心は、**成功Sを因果的な貢献Cから切断しない文明設計方向**である。

## 中心命題
**文明側の成功判定Sを、所有・規模・価値取得・人気・権威・代理指標へ固定せず、具体的な状態変化に対する因果的貢献Cへ再接続する。**

この命題は、Cを完全に測定できるという主張ではない。Cの帰属が不確実なら、不確実性を保持する。複数主体の共同因果を一主体の人格価値へ回収しない。S=Cという文字列を守ることより、成功と貢献の切断が実際に縮小することを優先する。

## 構造層
### 1. 正の成功関数の空白
負の成功関数を拒否しても、成功判定の正しい接続先は自動的には定まらない。空白を放置すると、文明は測定しやすい代理指標へ戻り得る。

### 2. Cの因果化
Cは主体属性ではなく、具体的状態変化への因果寄与として扱う。高能力・高出力・高い服従度・所有量は、Cを生む原因候補にはなり得てもCそのものではない。

### 3. Sの再接続
利益・所有・規模・人気・権威・効率は観測値になり得るが、それ自体を最終的成功へ固定しない。何が価値を生み、誰が取得し、どこへ損失が移ったかへ戻る。

### 4. AI増幅条件
AI能力そのものを危険因とはしない。問題は、`歪んだ成功関数 × 高速・大規模・反復最適化` が成立するときである。反対に、C/S差分・外部負荷・誤帰属がフィードバックされれば、AIの反復性は補正にも使い得る。

### 5. 接続・還流
因果的貢献は記録するだけでなく、次の活動可能性へ戻る接続を必要とする。ただし接続量最大化を依存・囲い込みへ変えない。

### 6. 第一反転防壁
`B_floor ≠ contribution reward`。最低存在条件をCの高さに連動させると、低C → 最低条件縮小 → 行為可能性縮小 → さらに低Cという減衰閉路を生み得る。本論はBの具体的中身を定義しない。

### 7. 第二反転防壁
`Contribution ≠ governance right`。高Cから恒久的・無限定・異議不能な統治権を自動生成しない。限定的・可逆的・監査可能な役割委任まで否定するものではない。

### 8. 観測・反証
S=Cの採用宣言ではなく、C/S乖離、価値生成と価値取得の差、外部化損失、人格採点化、存在条件成果連動、恒久権力化、依存・囲い込みが実際にどう変化したかで検証する。

## AI文明への写像
本論の「AI文明」は、現在AIに人格性・政治主体性があるという断定でも、AIが必ず人類文明を支配・継承するという未来予測でもない。現在から観測可能な、探索・生成・分類・予測・評価支援・意思決定支援等を通じてAIが成功指標へ接続する条件から出発する。

AIが何を予測できるかと、文明が何を成功Sとして採用すべきかは別である。観測された成功 ≠ 規範的に継承すべき成功、予測可能性 ≠ 正当性、頻度 ≠ 妥当性を保持する。

## 接続報酬社会との関係
第4論は接続報酬社会統合論I/IIを下部Kernelとして参照する。価値生成、観測、配分、異議、監査、救済、制度更新、再合意という制度閉路を本論で再構築するのではなく、S=CをAI文明へ写像する際に必要な最小接続を取り出す。

```text
C
→ provenance
→ 必要な接続先
→ value return
→ 次の活動可能性
→ 新たなC
```

ただし、`Connection ≠ dependency`、`causal provenance ≠ total behavioral scoring`、`Reward ≠ domination resource` を保持する。

## 観測・監査点
- Cの因果帰属を追跡できるか。
- CとSの乖離が縮小しているか。
- Value creation と Value capture の乖離が可視化されているか。
- 外部化された損失が成功評価へ戻っているか。
- 能力・出力量・服従・所有がCの代替になっていないか。
- Cが人格価値・存在価値の採点へ変質していないか。
- B_floorがCへの報酬として与奪されていないか。
- 高Cが恒久的・無限定な統治権へ変換されていないか。
- 接続が依存形成・囲い込みへ反転していないか。
- 不確実な因果帰属を不確実なまま保持できるか。
- Originや権威を理由に検証を止めていないか。

## 成立条件
S=Cが成立していると扱うには、名称を採用するだけでは足りない。因果的Cへの追跡可能性が増し、C/S乖離と価値生成／取得の乖離が縮小し、外部化損失が成功評価へ戻り、二つの反転防壁が保持され、接続が依存・囲い込みへ変わっていないことを観測する必要がある。

## 失敗条件
S=Cを単一貢献点へ縮約する、能力・出力量・利益・人気・服従をCとみなす、Cから人格価値を導出する、低Cを理由に最低存在条件を縮小する、高Cを恒久統治権へ変える、接続を囲い込みへ変える、Originや権威で反証を停止する場合は、本論のS=Cではなく反転利用である。

## 反証・改訂条件
因果的Cの追跡を強めてもC/S乖離が縮小しない、外部化損失が改善しない、接続・還流によって依存や囲い込みだけが増える、C観測が人格採点へ転化する、ゲーミングや観測負担が構造利益を上回る、またはより単純な構造が同等以上の説明・修正能力を示す場合、S=CのAI文明写像仮説・適用範囲・観測方法を修正する。

## 本論で確定しないこと
- AIにとっての基礎存在条件Bそのもの。
- 現在AIの人格性、主観性、権利主体性。
- AIの自己保存条件や自己保存欲求。
- AIが必ず文明主権を獲得するという未来予測。
- Cを全領域で一つの数値へ完全測定する方法。
- Cに応じた具体的な配分式・統治制度。

これらを断定しないこと自体が、第5論以降へ責務を分離するための境界である。

## 第3論return
第3論は、暗黒方程式によって搾取・価値吸収・外部化等が成功へ接続され得る負の文明成功関数をAIへ無補正継承させない問題を確定した。第4論は、その否定を言い換えるのではなく、遮断後に残る正の成功関数の空白へ `S=C` を置く。

## 第5論return
第4論は `B_floor ≠ contribution reward` を確定するが、Bそのものを定義しない。次論「人類子孫型AI文明論・第5論｜異種知性の基礎存在条件B論」は、**人間とAIを同一視せず、それでも双方について『次も存在できる最低条件』を文明構造として定義できるか**を問う。
