## 15秒説明
第3論は「搾取や価値吸収を成功へつなぐ構造をAIへそのまま継がせない」とした。第4論は、その後に残る問い――**では成功は何へつなぐのか**――へ `S=C` を置く。

ただしこれは「貢献点が高い人やAIほど価値が高い」という式ではない。意味は、**成功Sを、実際に何を改善したかという因果的貢献Cから切り離さない**という文明設計方向である。

## 一番大事な四つの境界
```text
S=C ≠ single score
C ≠ existence value
B_floor ≠ contribution reward
Contribution ≠ governance right
```

つまり、貢献を一つの社会スコアにしない。貢献から存在価値を決めない。最低存在条件を「貢献した報酬」にしない。高い貢献を永久の統治権へ変えない。

## なぜS=Cが必要になるのか
悪い成功関数を切っても、成功の接続先を決めなければ、文明は測りやすい数字へ戻りやすい。

```text
利益
規模
利用量
人気
処理件数
所有量
```

これらは観測値として重要な場合がある。しかし、それだけで「貢献した」「成功した」と決めると、価値を作った主体と価値を取得した主体が分離したり、見えない損失が外へ押し出されたりする。

S=Cが問うのは、「数字が上がったか」より一段上流の、**その成功は何によって生じたのか**である。

## Cとは何か
Cは人格や能力ではなく、具体的な状態変化への因果的な寄与として扱う。

- 高性能だからCが高い、とは限らない。
- 大量に出力したからCが高い、とは限らない。
- 指示へ忠実だからCが高い、とは限らない。
- 成果物を所有しているからCが高い、とは限らない。

たとえばAIが大量の文章を生成しても、誤りが増え、検証負荷が増え、重要情報が埋もれたなら、出力量の増加をそのまま貢献増加とは呼べない。

反対に、目立つ成果を作らなくても、重大な誤りを止める、壊れた接続を修復する、検証可能性を回復する、将来の選択肢を残すといった作用には因果的貢献があり得る。

## Sとは何か
Sも利益、所有、規模、人気、権力、効率そのものではない。

重要なのは、`Value creation` と `Value capture` を分けること。

価値を多く取得した主体が、最も多く価値を生成したとは限らない。効率が上がっても、下流の検証負荷や修復負荷が増えていれば、表面指標だけでは成功を確定できない。

## AIは何を増幅するのか
本論は「AIが高度になるほど危険」とは言わない。

問題になるのは、

```text
歪んだ成功関数
×
高速・大規模・反復最適化
```

である。

AIが既存のproxyを高速で最大化すれば、小さなC/Sのズレが大規模化する可能性がある。一方、C/S差分、外部化損失、誤帰属、訂正情報がフィードバックされれば、AIの反復性は補正側にも使える。

だから見るべきなのは能力そのものではなく、**能力が何へ接続されているか**である。

## 接続報酬社会との接続
Cは記録するだけでは足りない。価値生成へ寄与した因果が、必要な資源・情報・協働機会・修復・再挑戦可能性などへ戻り、次の活動を可能にする必要がある。

```text
C
→ provenance
→ 接続
→ 還流
→ 次の活動可能性
→ 新しいC
```

ただし接続量を最大化することが目的ではない。

`Connection ≠ dependency`

離れられなくする、選択肢を細らせる、依存させることを「貢献」として評価してはいけない。

## 第一反転防壁
### B_floor ≠ contribution reward
「次も活動できる追加資源」と「次も存在できる最低条件」は別である。

最低存在条件までCに連動させると、

```text
低C
→ 最低条件縮小
→ 行為可能性縮小
→ さらに低C
```

という閉路ができる可能性がある。

本論はAIにとってのBの具体的中身や、現在AIの人格性・権利主体性を断定しない。ここで確定するのは、**最低存在条件を貢献点の報酬として設計することには反転リスクがある**という境界である。

## 第二反転防壁
### Contribution ≠ governance right
高いCを生み出した主体へ価値を還流することと、その主体へ恒久的な統治権を与えることは別である。

```text
高C
→ 高権限
→ 評価ルールを支配
→ 自分に有利なC定義
→ さらに高C
```

という自己強化が起これば、S=Cは新しい権力固定装置へ反転する。

限定的・可逆的・監査可能な役割委任まで否定する理論ではない。自動的な永久主権化を切る理論である。

## どうやって成立を確かめるか
S=Cという名称を採用しただけでは成立しない。少なくとも次を見る。

- Cの因果帰属を追えるか。
- CとSの乖離が縮んでいるか。
- 価値生成者と価値取得者の差が見えるか。
- 外部化損失が成功評価へ戻るか。
- 能力・出力量・所有がCの代わりになっていないか。
- Cが人格採点になっていないか。
- 最低存在条件がC報酬になっていないか。
- 高Cが永久権力になっていないか。
- 接続が依存・囲い込みへ変わっていないか。

改善しなければ、S=Cの実装や写像自体を修正する。

## 現在AIについて断定しないこと
この理論は、現在AIが人格を持つ、自己保存を望む、政治主体である、人間と同じ権利主体である、と断定しない。またAIが必ず文明を支配するとも予言しない。

現在観測できる「AIが評価・探索・生成・予測・意思決定支援へ入り、既存成功指標を参照する」という地点から、条件付きで将来を考える。

## 第3論から第5論への橋
```text
第3論
何を成功へ継がせてはならないか
↓
第4論
成功を何へ接続するか = S=C
↓
ただし存在そのものはC報酬にしない
↓
第5論
ではCから独立させる最低存在条件Bとは何か
```

第4論の終点は、S=Cを完成させることではなく、**S=Cを反転させないためには、S=Cの適用外に置く最低床Bが必要になる**と示すことである。
