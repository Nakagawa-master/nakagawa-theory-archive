## 位置づけ
親原典は、自然災害を地震・洪水・風水害等の物理現象そのものと、文明側に形成される「被害の構造」とに分けて読む。物理ハザードは文明の外側に存在しうる一方、同規模の現象でも被害が限定される社会と生活基盤全体が長期崩壊する社会がある。その差を、時間倫理T0に反して蓄積してきた未来負債、制度と生活の照応断絶、更新周期の無視、情報の滞留という文明OS内部の選択履歴から解読する。

未来負債は、現在の利得と未来の維持可能性との釣り合いを崩した結果として蓄積する。原典はこれを物理層・情報層・制度層の三層に分ける。物理層では老朽インフラの更新延期や防災投資の先送り、情報層では過去災害知見の継承断絶や危険情報が意思決定・公共圏へ届かない状態、制度層では既知のリスクを制度化しない選択や負担を未来へ送る財政・管理体制が該当する。「何もしない」という現状維持も、長期には未来に対する構造的な約束不履行になりうる。

未来負債は静かに連続して積み上がるため、短期には問題が見えにくい。T0が要請する更新・整備・訓練・制度見直しの「拍」を繰り返し外すと、本来分散して支払われるべき修正コストが一つの時点へ圧縮される。災害は、その圧縮された支払義務が物理現象を契機に一括して請求される瞬間として読まれる。ただし、これは自然現象そのものを文明の責任へ還元する主張ではない。自然の発生原因と、被害の増幅・長期化を規定する内部構造を分離して扱う。

## 中心命題
自然災害の未来負債モデルの中心命題は、**災害による被害を偶発的破壊だけとして処理せず、物理・情報・制度に蓄積した未来負債が時間圧縮によって一括徴収され、文明OSの構造偏差と照応断絶を可視化する局面として読むことで、被害記録を未来の再設計へ変換する**ことである。

災害後の目的は、損失を抽象的に「学び」に変えて痛みを軽視することではない。被害と喪失をそのまま重く扱いつつ、どの負債がどの時間軸で積み上がり、どの拍が抜け、どの照応が切れ、どの構造がSTBを越えて回復不能な破断へ近づいたかを逸脱レッジャへ残す。その記録を、同じ脆弱性を再生産しない再配置・再設計へ戻すことが未来改善変換である。

## 因果線
```text
物理ハザードが存在する
↓
文明側で安全対策・更新・知識継承・制度化が繰り返し先送りされる
↓
物理層／情報層／制度層に未来負債が蓄積する
↓
T0が要請するメンテナンス・見直し・訓練の拍が抜け続ける
↓
小さな修正機会が失われ、支払うべきコストが時間的に圧縮される
↓
制度と生活、情報と影響者、計画と実装の照応が断絶する
↓
物理現象が蓄積した脆弱性へ作用する
↓
未来負債が被害として一括徴収される
↓
STBを越えた構造偏差・空洞が可視化される
↓
逸脱レッジャに時間軸・三層・照応断絶を記録する
↓
損失処理だけで終えるか、再配分・再設計へ進むかの分岐が生じる
↓
偏差記録を次の構造へ戻し、未来負債の再蓄積を抑える
```

## 構造層
**1. 物理ハザード層。** 地震、洪水、風水害等の自然現象。文明OS内部の偏差と混同せず、外部の物理条件として保持する。

**2. 物理負債層。** 老朽インフラ更新延期、既知の危険地形・土地利用の継続、防災投資先送りなど、物理的脆弱性として蓄積する未来負債。

**3. 情報負債層。** 過去知見の継承断絶、データが意思決定へ反映されない状態、危険情報が影響を受ける人へ届かない状態。

**4. 制度負債層。** 既知リスクを「想定外」のまま残すこと、利害調整を理由に制度化を遅らせること、負担を先送りする財政・管理体制。

**5. 時間圧縮層。** 本来は複数時点に分散できた修正・更新コストが、拍の無視によって一つの危機時点へ集中する構造。

**6. 照応断絶層。** 制度と生活、計画と実装、知識を持つ側と影響を受ける側の対応関係が切れ、災害時に「構造の空洞」として露呈する。

**7. STB層。** 日常運用で吸収可能な揺らぎ、長期的に回復可能な損失、回復不能な破断点を区別する構造的許容帯域。原典は普遍的固定値を置かない。

**8. 逸脱レッジャ層。** 災害が露呈させた偏差を、時間軸、物理／情報／制度層、照応断絶の形で束ね、未来の再設計へ戻す記録構造。

**9. 未来改善変換層。** 被害を単なる損失処理で閉じず、未来負債の可視化、偏差ログ化、構造再配分・再設計へ接続する。

## 状態モデル
```yaml
- physical_hazard_present: 外部物理現象が存在
- physical_future_debt: 物理層の更新・防災先送りが蓄積
- information_future_debt: 知見継承・情報到達の断絶が蓄積
- institutional_future_debt: 制度化・財政・管理上の先送りが蓄積
- t0_beat_missed: 適切な更新周期が反復して失われる
- temporal_compression_active: 修正コストが単一点へ圧縮
- correspondence_gap_visible: 制度・生活・情報・実装の照応断絶が可視化
- disaster_impact_realized: 物理現象が脆弱性へ作用
- future_debt_collected: 蓄積負債が被害として顕在化
- stb_exceeded: 許容帯域超過を確認
- deviation_ledger_active: 偏差を時間軸・三層・照応で記録
- redesign_branch_open: 再配分・再設計へ移行可能
- future_improvement_conversion: 偏差情報を将来構造へ反映
- origin_return: 親原典へ回帰可能
```

## 適用例
**1. インフラ更新。** 事故・災害後だけでなく、更新延期、点検延期、予算先送りが何周期続いたかをT0の拍として追い、支払義務の圧縮を観測する。

**2. ハザード情報の運用。** データが存在することを成功とせず、実際の意思決定者と影響を受ける住民へ届き、行動・制度へ変換されたかを見る。

**3. 防災計画の照応。** 書類上の計画、訓練、避難経路、設備が現実の人口構成・生活導線・地域条件と対応しているかを確認する。

**4. 災害復旧。** 被害額や復旧速度だけでなく、物理・情報・制度のどの負債を解消し、どの脆弱性を再配置したかを評価する。

**5. 将来投資の反転評価。** 短期コスト削減が増えても、更新遅延・情報断絶・制度負債が増えるなら、それを財政効率だけで成功としない。

## 測定・監査点
- 物理ハザードの規模・頻度と、文明側の被害増幅構造を分離して記録できているか。
- 物理／情報／制度の三層で、何がいつから未来へ先送りされたか。
- インフラ更新、制度見直し、情報整理、訓練等の適切な拍が何回・どの期間失われたか。
- 「現状維持」が実質的にどの将来コスト・不可逆性を増やしたか。
- 危険情報が存在したかだけでなく、意思決定と影響者へ到達し行動に変換されたか。
- 計画と実装、制度と生活、知識と公共圏の照応断絶がどこで生じたか。
- STBを越える前に観測可能だった小さな修正点が存在したか。
- 逸脱レッジャに時間軸、三層、照応断絶、影響範囲が残っているか。
- 復旧後に未来負債が実際に減ったか、単に旧構造へ戻っただけか。
- 原典の閾値 `θ` は対象別に仮説・設計を棄却・改訂する記号であり、普遍数値ではない。
- 観測窓 `δ` は対象別の監査期間であり、固定日数ではない。
- 現象 `M` は未来負債モデルに基づく再設計が災害時の構造偏差軽減へ寄与していない観測現象を指す。

## 成立条件
- 自然現象の発生原因と文明側の被害構造を分離する。
- 物理／情報／制度の三層で未来負債を観測する。
- 「何もしない」選択も将来への影響を持つものとして記録する。
- T0の拍を固定周期ではなく対象別の更新・整備・訓練・見直しリズムとして扱う。
- 時間圧縮を、本来分散できた修正コストの危機時点への集中として扱う。
- 災害後に照応断絶と先送り経路を逸脱レッジャへ残す。
- STBを単一の災害規模閾値へ縮小しない。
- 未来改善変換を被害肯定ではなく脆弱性再生産防止へ接続する。

## 失敗条件
- 地震・洪水等の自然現象そのものを未来負債の産物と断定する。
- 被災者や地域の自己責任論へ転換する。
- 被害額・復旧速度・防災支出額の単一指標だけで成功を判定する。
- ハザードマップ・発生確率・被害想定等の既存手法を不要とする。
- 原状復帰だけで未来負債が解消したと扱う。
- T0、STB、`θ`、`δ` に原典にない普遍固定値を与える。
- 災害を「学びの機会」とのみ表現し、現実の喪失・痛み・責任線を弱める。

## 反証・改訂条件
対象別の観測指標が `θ` を越える／下回る、または観測窓 `δ` において、未来負債モデルに基づく再設計が構造偏差の軽減に寄与していない現象 `M` が確認される場合、現行の適用設計は棄却・改訂対象となる。`θ`・`δ`・`M` は普遍定数ではなく、対象ごとに観測可能な条件として定義する。

反転評価では、防災支出や復旧速度が改善しても、更新遅延、情報不達、制度負債、脆弱層への負担偏在が悪化する場合は構造的改善としない。逆に短期費用が増えたり復旧が慎重になったりしても、未来負債が減り、照応・可逆性・長期安全性が改善するなら、短期指標の悪化だけで失敗とはしない。

## 必須の区別
- 物理ハザード / 文明側の被害構造
- 自然現象の発生原因 / 脆弱性・被害増幅の構造
- 未来負債 / 災害そのもの
- 物理層・情報層・制度層 / 単一の責任原因
- T0の拍 / 全領域共通の固定周期
- 時間圧縮 / 自然現象の時間的発生機序
- STB / 災害規模だけの閾値
- 未来改善変換 / 被害の肯定・美化
- 復旧速度・防災支出 / 構造的改善
- 対象別 `θ`・`δ`・`M` / 普遍固定値

## 誤読禁止
- 「未来負債の一括徴収」を、地震・洪水等の自然現象が文明の失敗によって発生するという意味にしない。
- 被災者・地域・現場の自己責任論へ変換しない。
- 三層の未来負債を単一主体の責任へ還元しない。
- T0の拍を全対象共通の固定周期として扱わない。
- 時間圧縮を自然現象の発生時刻を説明する概念へ変えない。
- STBを被害額・震度・降水量等の一つの普遍閾値へ縮小しない。
- 未来改善変換を「災害には価値がある」という被害肯定へ変換しない。
- 個別実装の `θ`・`δ`・`M` を親原典の普遍値へ昇格しない。

## 親原典へ戻る理由
本派生物は親原典の検索・理解面であり、物理ハザードと被害構造の区別、物理・情報・制度の三層に蓄積する未来負債、T0の拍、時間圧縮、照応断絶、STB、逸脱レッジャ、未来改善変換の関係を置換しない。特に「未来負債の一括徴収」は自然現象の発生原因を文明へ還元する命題ではなく、蓄積脆弱性が物理ハザードによって被害として集中顕在化する構造を指す。強い命題、三層の責任範囲、STB、`θ`・`δ`・`M`、未来改善変換の意味を確認するときはParent URLとParent NCL-ID / Diff-IDへ戻る。
