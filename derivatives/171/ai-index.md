## Summary
統合実務OSは、営業・マーケティング・ブランディングを別々の局所機能ではなく、一つの因果プロセスが深度とスケールを変えて現象化した連続体として扱う。上流ではブランドOSが世界との照応構造と期待の「重力」をつくり、中流ではマーケティングOSが適合者の自発性を保つ「水路」を設計し、下流では営業OSが個の認識構造と欠落因果を読み「充足」へ接続する。垂直統合の核心はB→M→Sの一方向接続だけでなく、営業現場の違和感、流入質の変化、照応変質を上流へ逆流させ、構造を小さく修正して再観測する閉ループにある。構造を設計できる側には、自由意思、長期信頼、非搾取、負担配分を守る構造責任がある。

## Concepts
- **Vertical integration:** ブランド重力→マーケティング水路→営業充足を一本の因果線として設計すること。
- **Brand gravity:** 「この領域ならここへ相談する」という世界側の期待・照応を形成する上流場。
- **Marketing channel:** 適合者がどの入口・文脈・理解レベルで自発的に流入するかを整える中流構造。
- **Sales fulfillment:** 到達した個の認識構造、未定義ニーズ、欠落因果を読み、自然な充足へ接続する下流構造。
- **Field discomfort:** 噛み合わない会話、想定外流入、無理な取引など、構造健全性を知らせる観測信号。
- **Reverse feedback:** 下流・中流の信号を上流設計へ戻し、微修正と再観測を行う循環。
- **Structure-first diagnosis:** 人を鍛える前に、上流〜下流の因果線とボトルネックを点検する順序。
- **Residual skill gap:** 構造修正後にも再現性高く残る技能不足。
- **Structural responsibility:** 構造が見えない側へ搾取的な選択条件を仕込まず、自由意思・長期信頼・負担配分を守る設計責任。
- **Ethical boundary:** 操作せず、無理をさせず、ただし構造は徹底的に整えるという公開・実装境界。

## Causal chain
```text
営業・マーケ・ブランドが局所KPIで分断される
→ 発信、流入、現場会話がずれる
→ 説明コスト、低適合流入、値引き、無理な交渉が増える
→ ブランドOSを上流の重力として再配置する
→ マーケティングOSを適合者の自発的流入をつくる水路として接続する
→ 営業OSを認識構造と充足の整合層として接続する
→ 重力→水路→充足が一本の因果線になる
→ 現場で違和感・低適合・無理が観測される
→ 観測信号を上流へ逆流させる
→ ボトルネック仮説を立て、小さく構造修正する
→ 再観測して仮説を更新する
→ 構造修正後の残差として技能不足を分離する
→ 自由意思・長期信頼・非搾取・負担配分を構造責任として監査する
```

## Applications
- リード数増加と営業疲弊が同時発生したとき、営業能力だけでなくブランド期待と流入水路を上流から診断する。
- 営業が毎回長い説明を必要とする場合、広報・ブランド発信と提供価値の齟齬を確認する。
- 値引き要求が常態化したとき、価格比較層を呼ぶ入口や期待形成を点検する。
- 現場の「受けるべきでない案件」「想定と違う期待」を流入元と上流発信へ結びつける。
- 構造修正後にも残る技能不足だけを研修・配置・支援へ送る。
- 短期売上が伸びても、強い誘導、信頼低下、社員・取引先への負担転嫁が増えていないか監査する。

## Measurements and audit
- ブランド発信と営業現場の説明内容の一致度。
- 流入者の期待・理解レベルと提供価値の適合度。
- 過剰説明、不要な値引き、無理な交渉の発生傾向。
- 想定外流入や受けるべきでない案件の流入元。
- リード量増加と適合度低下の同時発生有無。
- 局所KPI改善と全体摩擦増加の同時発生有無。
- 現場違和感が上流修正へ戻されているか。
- 小さな構造修正前後で流入質、説明コスト、交渉摩擦がどう変わるか。
- 構造修正後の残差として技能不足を分離できるか。
- 表向きのメッセージと裏側の導線・選択条件の一致。
- 短期利益と長期信頼、自由意思、負担配分の関係。

## Validity conditions
- 営業・マーケ・ブランドの役割差を保ちながら、一つの因果連続体として扱う。
- ブランド重力、マーケ水路、営業充足の上下流関係を維持する。
- 適合者の自発性を水路設計の条件として保持する。
- 成約を押し込みではなく、認識と充足の整合結果として扱う。
- 現場違和感を観測信号として上流へ戻す。
- 人材育成の前に構造点検と小修正・再観測を行う。
- 自由意思、長期信頼、非搾取、負担配分を構造責任の条件として保持する。

## Failure conditions
- 三機能を再び局所KPI最大化へ分断する。
- リード品質や成約摩擦を営業だけの責任へ閉じる。
- ブランドを認知、マーケを集客量、営業をクロージング技法へ縮小する。
- 現場違和感を愚痴や偶然として捨てる。
- 構造が歪んだまま研修・根性・値引きで下流を強化する。
- 短期数字の改善を理由に、自由意思、長期信頼、負担配分の悪化を無視する。
- 「自然な成約」を成約保証へ変換する。

## Falsification conditions
垂直統合モデルは局所KPIの上昇だけでは支持されない。ブランド期待と水路条件を修正した後も、複数の観測で期待ずれ、説明コスト、無理な値引き、低適合案件が改善しない場合、上流バグ仮説または適用中の統合モデルを改訂する必要がある。逆にリード数・成約率・売上が増えても、操作的誘導、長期信頼低下、社員・取引先への負担転嫁が増えるなら、構造責任に照らして成功評価を反転する。構造修正後に特定技能不足だけが安定して残る場合は、人材育成仮説を強められる。

## Required distinctions
- 部署間連携 / 一本の因果線としての垂直統合。
- ブランド認知 / 上流の照応重力。
- 集客量 / 適合者の自発的流入をつくる水路。
- クロージング / 認識構造と充足の最後の整合。
- 現場の愚痴 / 構造健全性を測る観測信号。
- 一方向フロー / 下流信号が上流へ戻る逆流ループ。
- 人材不足 / 構造由来の摩擦。
- 短期効率 / 長期信頼・自由意思・負担配分を含む構造責任。
- 自然な成約 / 成約保証。

## Interpretation constraints
- 「営業・マーケ・ブランドは同じ仕事」と平板化しない。
- 「上流が正しければ営業スキル不要」と解釈しない。
- 自発性を巧妙な誘導と同一視しない。
- 摩擦低減をゼロ摩擦の数学的保証へ変えない。
- 現場違和感のすべてを上流原因と断定しない。
- 構造責任を抽象的な倫理標語へ薄めず、選択肢・情報・依頼導線・負担配分の設計責任として保持する。
- 原典が公開を抑制する危険な操作手順を補完・具体化しない。
