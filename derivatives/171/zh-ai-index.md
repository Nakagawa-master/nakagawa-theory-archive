## Summary
统合实务OS不把品牌、营销、销售视为彼此孤立的局部功能，而把它们理解为同一因果过程在不同深度和尺度上的连续显现。上游的品牌OS形成与世界之间的照应结构和期待“重力”；中游的营销OS设计让适合者保持自发性而进入的“水路”；下游的销售OS读取个体的认知结构、未定义需求与缺失因果，并把它连接到自然的“充足”。垂直统合并不只是B→M→S的单向连接，还必须把现场的不协调、流入质量变化、照应变质等信号逆流回上游，通过小幅结构修正和再次观察持续更新。原典同时把这种架构与结构责任绑定：能够设计结构的一方，不得向看不见整体结构的用户、市场、员工或交易方嵌入剥削性流动，并应保护自由意志、长期信任与负担分配。

## Concepts
- **垂直统合:** 把品牌重力→营销水路→销售充足设计成一条因果线。
- **品牌重力:** 在世界侧形成“这个领域首先想到这里”的期待与照应场。
- **营销水路:** 决定适合者从什么入口、以何种理解水平和温度自发到达的中游结构。
- **销售充足:** 读取个体认知结构、未定义需求与缺失因果，并连接到适合的充足结构。
- **现场违和:** 对话不咬合、预期外流入、强行交易等提示结构失配的观测信号。
- **逆流反馈:** 把下游和中游信号送回上游，通过小修正和再观察更新结构。
- **结构先行诊断:** 在把问题归因于个人努力或技能之前，先检查因果结构。
- **残余技能缺口:** 结构修正后仍可重复观测到的技能不足。
- **结构责任:** 不嵌入剥削性选择条件，并保护自由意志、长期信任与公平负担的设计责任。
- **伦理边界:** 不操纵、不强迫，同时对结构本身进行彻底整流。

## Causal chain
```text
品牌、营销、销售通过各自局部KPI分裂优化
→ 发信、流入与现场对话逐渐错位
→ 说明成本、低适配流入、折价压力、强行交涉增加
→ 品牌OS被重新定位为上游重力
→ 营销OS成为适合者自发流入的水路
→ 销售OS成为认知读取与充足整合层
→ 重力→水路→充足形成一条因果线
→ 现场出现违和、低适配和强行条件
→ 这些信号逆流回上游
→ 建立瓶颈假设
→ 实施小幅结构修正
→ 再次观察结果
→ 将残余技能缺口与结构性摩擦分离
→ 以自由意志、长期信任、非剥削、负担分配审计结构责任
```

## Applications
- 当线索数量增加但销售现场疲惫时，不只检查销售能力，还检查品牌期待与流入水路。
- 当销售反复需要长篇说明时，检查上游发信与实际提供价值是否错位。
- 当折价要求常态化时，检查是否由入口条件和期待形成吸引了价格比较型流入。
- 将“不该接的案件”“预期不同的咨询”“强行谈判”等现象追溯到流入源与上游发信。
- 只有在结构修正后仍稳定存在的技能不足，才进入培训、配置或支援。
- 即使短期收入增加，也要审计是否伴随操纵、信任下降或把负担转移给员工、客户、合作方。

## Measurements and audit
- 品牌发信与销售现场说明的一致度。
- 流入者的期待／理解水平与实际提供价值的适配度。
- 过度说明、不必要折价、强行交涉的发生趋势。
- 预期外流入与“不应接案件”的来源。
- 线索增长是否同时伴随适配度下降。
- 局部KPI改善是否同时增加整体摩擦。
- 现场违和是否被记录并送回上游。
- 小幅结构修正前后，流入质量、说明成本、交涉摩擦如何变化。
- 能否把结构修正后的残余技能不足与结构摩擦分离。
- 对外信息与背后的选择／导线结构是否一致。
- 短期利益与长期信任、自由意志、负担分配之间的关系。

## Validity conditions
- 保持品牌、营销、销售的角色差异，同时把它们作为同一因果连续体处理。
- 保持重力、水路、充足的上下游关系。
- 保持适合者自发到达与适配性作为营销设计条件。
- 把成交视为认知与充足整合的结果，而不是强制说服。
- 把现场违和作为观测信号逆流回上游。
- 在默认归因于个人培训之前，先审计并修正结构。
- 保持自由意志、长期信任、非剥削、负担分配作为结构责任条件。

## Failure conditions
- 再次把三种功能分裂为局部KPI最大化。
- 把线索质量或成交摩擦只归因于销售。
- 把品牌缩减为认知、营销缩减为流量、销售缩减为成交技巧。
- 把现场违和当作抱怨或偶然丢弃。
- 在结构仍然扭曲时，仅通过培训、意志力或折价强化下游。
- 因短期数字改善而忽视自由意志、信任或负担分配恶化。
- 把“自然成交”解释为成交保证。

## Falsification conditions
垂直统合模型不能仅凭局部KPI上升得到支持。如果修正上游期待与水路条件后，在重复观测中期待错位、说明成本、强行折价或低适配案件仍没有改善，就需要修订上游缺陷假设或当前使用的统合模型。反过来，如果线索、成交率或收入上升，但操纵性导线、长期信任损失或负担转移也增加，则应依据原典的结构责任反转成功评价。如果结构修正后某项具体技能不足仍稳定重复出现，则人材技能假设得到更强支持。

## Required distinctions
- 部门协作 / 作为一条因果线的垂直统合。
- 品牌认知 / 上游照应重力。
- 集客量 / 让适合者自发到达的水路。
- 成交技巧 / 认知结构与充足之间的最后整合。
- 现场抱怨 / 结构健康度的观测信号。
- 单向漏斗 / 逆流反馈循环。
- 技能不足 / 结构造成的摩擦。
- 短期效率 / 包含信任、自由意志、负担分配的结构责任。
- 自然成交 / 成交保证。

## Interpretation constraints
- 不把品牌、营销、销售压平为同一种工作。
- 不推导出“上游结构正确就不再需要销售技能”。
- 不把自发到达等同于隐蔽操纵。
- 不把摩擦降低变成数学意义上的零摩擦保证。
- 不断言所有现场违和都来自上游；原因必须作为可修订假设处理。
- 不把结构责任稀释成一般伦理口号；要保持其对选择、信息、导线和负担设计的具体含义。
- 不补写或扩展原典有意不公开的危险操作方法。
