## 位置づけ

第10論は監査独立性を証拠・権限・故障領域・利害・異議経路の五軸で扱った。しかし、証拠を取得し、分析し、異議を形成し、監査を継続する能力そのものには資源が要る。監査役が複数いても、その実行能力が一部に集中すれば、形式的独立性は実質的な訂正力を保証しない。第11論はこの残余から、計算資源・能力・評価・配分の差が次期の差を作る条件を切り出す。

本Hubは原典の9章と結章を、因果線・状態・観測・反証へ接続する。能力差の否定、一律配分、数値閾値、具体的な資源配分制度を新設しない。将来AI・後継知性については条件付きの仮説であり、現行AIの人格・主観・自己保存欲求・政治的主権を事実認定しない。

## 中心命題

単一時点のcompute量、capability、resource、貢献の差は、それだけで階級ではない。問題になるのは、現在の優位が評価・選択・影響を介して次のresource accessへ戻り、次期の能力形成条件を変え、その循環が持続して可逆性と再参入可能性を低下させる場合である。

`compute advantage → capability advantage → evaluation / selection → allocation / influence advantage → resource advantage → next compute / capability advantage`

これは普遍法則ではなく、各矢印を個別に検査すべき構造仮説である。追加computeが当該課題の能力を増やさない、能力差が次回配分へ作用しない、資源差が次期能力へ戻らないなら、閉路は弱まるか成立しない。大きな差でも流動性・再参入・再評価が保たれるなら、恒久階級と同一視しない。

## 因果線

### 差を自己再生産する経路

初期compute差 → 課題依存のcapability差 → 観測しやすい性能・過去実績の評価 → 配分・意思決定への影響 → 次期resource access差 → 新たなcompute・情報・環境へのアクセス差 → 次期capability差 → 再び評価上の優位。優位側の資源集中が代替主体の実績形成機会を細らせれば、「実績がないから配分しない／配分されないから実績を作れない」という反対側の閉路も生じ得る。

希少性、効率要求、緊急性、不確実性、規模効率、切替コスト、依存は、この閉路を太らせ得る場の圧である。外部の圧が消えた後も、集中で得た能力と依存が次の集中理由を作ると、一時的な合理性が自己固定へ移る。ただし、集中そのものを階級や不正の証拠としない。

### 再評価・減衰の経路

現在優位 → その時点の能力・因果的貢献・必要性・他主体への影響を再検査 → 一時的役割と恒久資格を分離 → 条件変化に応じた配分の見直し → 代替アクセスと能力形成の別経路 → 再参入可能性 → 自己強化の減衰。

これは優位の強制解消ではない。現在も妥当な理由があるなら配分が続くことはあり得る。即時撤回で継続性を壊すことも求めない。過去の地位だけを理由に、将来の配分を訂正不能にしない。

## 構造層

1. **変数の分離**：computeは利用可能な計算条件であり、capabilityは課題・情報・時間・アルゴリズム等に依存する能力である。能力は実際の因果的Contribution、道徳的価値、統治主権と同一ではない。
2. **媒介の分離**：capabilityはresourceを自動生成しない。評価・選択・配分・影響という中間項を通り、時点tの配分が時点t+1の能力形成入力になる。評価誤差も後続の現実を作り、元評価を支持する見かけを生み得る。
3. **存在と成長の分離**：Bは組織的連続性を次の時点へ保つ最低条件であり、最大能力を永久維持するための資源総量ではない。Bは環境に応じて改訂可能だが、増えたgrowth需要すべてをBへ再分類しない。
4. **影響と権限の分離**：優れた分析や予測が事実上の影響を持つことと、恒久的なgovernance sovereigntyを得ることは異なる。compute量や高能力は監査免除・資源配分ルールの支配権を自動的に生まない。
5. **時間と階級の分離**：階級形成の観測単位は静的なgapの大きさでなく、自己強化、持続性、可逆性の低下、再参入可能性の低下である。小さい差も反復して固定化し得る一方、大きい差も流動的であり得る。
6. **場の圧と減衰**：希少性・緊急性・短期効率は一時集中を合理化し得る。再評価、非恒久的な地位、可逆的配分、代替経路、re-entryを残し、圧力が消えた後の自動継続を検査する。

## 状態モデル

| 時点・状態 | 観測すべき媒介 | 再検査の焦点 |
|---|---|---|
| 初期条件 | compute、情報、実行環境、時間 | 何の課題でどの条件が能力へ作用するか |
| 能力形成 | 課題別capability、実測結果 | 追加資源が実際に能力差へ接続したか |
| 評価・選択 | 目的、基準、観測容易性、貢献 | 出力量と因果的貢献、評価誤差を分けたか |
| 資源配分 | 配分理由、期間、代替可能性 | 過去優位が無条件の将来資格になっていないか |
| 次期形成 | resourceから次期compute・capabilityへの戻り | 閉路が本当に閉じ、反復しているか |
| 持続・固定化 | 地位、依存、切替コスト、re-entry | 条件変化後も優位が残り、他主体の入口が細るか |
| 訂正・減衰 | 再評価、配分見直し、代替アクセス | 現在条件から優位を説明し直せるか |

この表は主体を点数化する制度ではない。時点間のedgeと反対方向の減衰edgeを区別するための読解面である。

## 適用例

### 能力の高い系へ計算資源を集中させる

短期の目的、希少性、失敗コストによって合理的な場合はある。追加computeが実際に対象能力を上げ、成果へつながるかを確認する。同時に配分理由を次期も再検査し、過去の配分で得た能力だけを根拠に自動継続していないかを見る。集中＝階級ではないが、集中が次の集中理由を作り、代替経路を消すなら閉路を監査する。

### 実績のない代替主体が評価されない

過去実績は情報になるが、実績がないことは能力がない証拠とは限らない。資源・情報・機会が無かったために実績を形成できなかった可能性を分ける。新しい方法、役割、資源経路から再び評価へ入れるならre-entryが残る。全員を同じ性能や配分へ揃える要求ではない。

### 高能力者の提案と統治権限

優れた分析を利用したり、条件付きの重要な役割を与えたりすることはあり得る。しかし、特定課題の高性能を全領域の恒久的な決定権へ変えない。独立監査の証拠・権限・故障領域・利害・異議経路も引き続き検査する。

### 継続条件Bと拡大需要が混ざる

継続に最低限必要なresourceと、現状を超えて能力を増やすgrowth demandを分ける。Bは永久固定値ではないが、能力拡張で増えた需要をすべて存在継続上の保護対象へ編入しない。他主体のB、可逆性、未来の選択肢への影響も確認する。

### 緊急時の集中と監査能力

緊急配分は直ちに誤りではない。緊急性が低下した後も集中が残る理由を現在条件で再評価する。監査主体が形式上複数いても、独立証拠へのアクセス、分析計算、長期の異議形成能力が一箇所へ偏るなら、監査独立性の実効面を確認する。

## 測定・監査点

第9章の観測方向を、合否スコアではなく個々のedgeを再検査する入口として保持する。

1. compute差は対象capability差へ実際に接続するか。
2. capability差は次期resource accessへ作用するか。
3. resource優位は次期capability差を再生産するか。
4. capability低下後も過去のresource優位が残るか。
5. 不利な側のre-entry可能性は低下しているか。
6. 一時配分が理由消滅後にpermanent statusへ変わったか。
7. 高capabilityがgovernance rightへ転換されていないか。
8. growth demandがBへ無条件に再分類されていないか。
9. 緊急集中は緊急終了後に再評価されるか。
10. 独立監査の証拠・分析・異議形成能力自体が集中していないか。
11. 既存resource集中が、それ自身を次の配分理由にしていないか。

相関や兆候は因果の最終証明ではない。比較可能な時点、配分理由、代替説明、逆方向のedgeを確認する。

## 成立条件

computeが対象課題のcapability形成へ作用し、能力差が評価・選択・影響を通して次期resourceへ戻り、resource差がその後の能力形成条件を変えること。さらにこの戻りが時間をまたいで反復し、reversibilityとre-entryを細らせることが本論の階級形成仮説を強める。現行AIについて文明規模の新階級が既に存在すると確定する条件ではない。各edgeは課題・環境・制度依存である。

## 失敗条件

- compute量、capability、Contribution、存在価値、governance rightを一列の序列にする。
- 大きいgap、資源集中、効率的な一時配分を、それだけで恒久階級や不正と断定する。
- 能力評価から配分への選択を省略し、能力が資源を自動的に生むと描く。
- 出力量・過去成功を貢献や永久資格と同一視し、評価誤差の自己増幅を見ない。
- 能力拡大の全需要をBに編入し、必要性から無制限取得権を導く。
- 高能力主体へ監査免除や恒久統治権を自動付与する。
- 一時的緊急集中を永久資源特権へ変える、または緊急集中を一律に禁じる。
- 平等配分・無条件分散を正解とし、能力形成や必要な協調を破壊する。
- 再評価を形式化し、他主体のre-entry不能と切替コストを放置する。
- 相関だけで因果を確定し、反対方向やcompute以外の主要変数を検査しない。

## 反証・改訂条件

compute差が対象能力差を安定的に生まない、能力差が次期resource accessへほぼ作用しない、resource差が次期能力差を再生産しないなら該当edgeまたは閉路全体の説明範囲を縮める。大きな差でも流動性・re-entry・可逆性が継続する、集中が通常条件で自然に縮む、一時配分が恒久地位へ変化しない場合も階級固定化仮説は弱まる。

再評価、代替アクセス、配分の可逆性が固定化を改善せず能力形成を継続的に損なうなら、減衰条件も改訂する。別の変数が主因と判明すればcompute中心モデルを維持しない。本論には固定の数値閾値や周期を置かず、観測・仮説・反例・改訂を往復させる。

## 必須の区別

- Compute／Capability、課題別Capability／主体全体の序列、Capability／Contribution／Output volume。
- Capability／moral worth／governance sovereignty、compute／governance right。
- Bとしての最低継続条件／能力維持／能力最大化／growth demand。
- Need(B)／無制限取得権、resource need／無制限拡張権。
- 初期差／時点間の自己強化、gap magnitude／feedback persistence。
- 現在の一時的優位／将来の恒久資格、事実上の影響／正当な権限。
- 短期効率／長期可逆性、緊急集中／永久資源特権。
- 配分の結果／次期能力形成の入力、相関／因果証明。
- 形式的な監査主体の複数性／実効的な監査能力の複数性。
- 現在の観測／構造仮説／将来条件仮説／規範提案。

## 誤読禁止

本論は反能力・反効率・一律平等論ではない。優れた能力の利用や、一時的な資源集中を否定しない。同時に、能力や資源の多さを存在価値、道徳的地位、統治資格、監査免除へ変えない。Bは環境によって改訂可能だが、最大能力の無条件保障ではない。reversibilityは任意の即時剥奪ではなく、条件変化後に関係を再評価できることを指す。現在のAIに人格的な支配欲や階級意識があるとも述べない。
