## Summary

第11論は、第10論で求めた独立監査を実行する情報・分析・異議形成能力自体が資源へ依存するという残余から始まる。`compute advantage → capability advantage → evaluation / selection → allocation / influence advantage → resource advantage → next compute` の各edgeが成立し、反復の中で可逆性と再参入可能性が低下するなら、差は時間方向へ自己固定し得る。これは階級形成の構造仮説であり、現在のAI文明に恒久階級が既にあるとの事実認定ではない。

原典は能力差、資源集中、規模効率、一時的な緊急配分を一律に否定しない。高能力を利用しつつ、現在条件に基づく再評価、地位の非恒久性、変更可能な配分、代替アクセスとre-entryを残す。各edgeと減衰策はともに観測・反証・改訂対象である。

## Concepts

- **Compute**：推論・処理・探索・実行を成立させる計算条件。特定の製品、単位、能力そのものではない。
- **Capability**：課題・情報・記憶・アルゴリズム・実行環境・時間などに依存する能力断面。普遍的な主体順位へ還元しない。
- **Resource**：computeに加え、情報アクセス、時間、継続基盤、道具、物理・実行環境など能力形成へ作用し得る条件。
- **Contribution / S=C**：実際の因果の中で何を改善・生成したか。出力量や潜在能力と分け、報酬を永久資格へ変換しない。
- **B**：貢献とは独立した最低の組織的存在継続条件。最大能力・現在最高性能の永続保障ではなく、必要条件として改訂可能。
- **Governance sovereignty**：正当な統治資格。高能力やcompute保有から自動導出しない。事実上の影響や条件付き役割とも分ける。
- **Self-reinforcement**：現在の差が、次時点に同じ差を生む条件へ変換される正帰還。単なる差の増大や単発の優位とは異なる。
- **Durable class-formation signal**：自己強化、持続、可逆性低下、再参入可能性低下が重なる時間方向の自己固定の兆候。数値閾値で確定しない。
- **Reversibility / re-entry**：条件変化に応じて評価・配分・役割を見直せること／不利な主体が別経路から能力形成へ戻れること。結果の一律化や恣意的な即時撤回ではない。

## Causal chain

### 増幅・固定化

初期compute差 → 対象課題のcapability差 → 観測容易な性能・成功履歴の評価 → 選択・資源配分・影響力の差 → 次期resource access差 → 次期compute / capability差 → さらに次期配分優位。配分は評価の終点ではなく次の能力形成の入力である。評価誤差も配分を介して現実を変え、後の性能差が元評価を支持するように見える場合がある。

優位側の集中と同時に、低resource側では `低い機会 → 実績形成困難 → 評価機会減少 → 次期resource不足` が起こり得る。希少性、短期効率、緊急性、不確実性、規模効率、切替コスト、依存は集中を合理化し得るが、圧力の消失後も集中と依存が自分を配分理由にするかが焦点となる。

### 訂正・減衰

優位 → 現在の能力・実際の貢献・Bとgrowth・他者への影響を再検査 → 一時役割を永久地位と分離 → 条件変化後の配分見直し → 代替resource経路 → re-entry / mobility → 正帰還の減衰。現在も配分理由が成立する場合、優位継続はあり得る。目的は能力を落とすことではなく、過去優位から恒久資格への自動変換を切ることである。

## State model

| State | 入力・判断 | 次状態との接続 |
|---|---|---|
| 初期資源差 | compute、情報、環境、時間の差 | 課題別能力へ作用したか |
| capability形成 | 性能、課題適合、限界効果 | 実測能力と貢献を分ける |
| evaluation / selection | 目的、観測容易性、実績、誤差 | 誰がどの基準で配分を選ぶか |
| allocation / influence | resource、アクセス、役割、ルールへの影響 | 次時点の能力形成入力になるか |
| persistence | 継続配分、依存、切替コスト | 現行理由か過去優位の自動延長か |
| class-formation signal | 反復、可逆性低下、re-entry低下 | 恒久地位へ近づくか |
| damping | 再評価、代替経路、地位非固定 | 改訂が実効的で、能力形成も残るか |

単一スナップショットから階級を判定しない。tの配分がt+1の能力へ戻り、t+2の配分を変えるかを観測する。追加computeの限界効果低下、新手法、維持負担など逆方向のedgeも保持する。

## Applications

### 高能力系へのresource集中

高い失敗コストや緊急性で合理的な一時集中はあり得る。対象能力の限界効果、現在のContribution、継続理由、他主体の能力形成機会、切替可能性を分けて検査する。集中が続くこと自体で不正とせず、集中で作った能力と依存だけが次の集中を正当化するなら自己強化を追う。

### 実績がない新しい主体

未知の能力への不確実性は現実の制約であるが、`absence of evidence ≠ evidence of inability`。配分がなかったため実績がなく、その不在が再配分拒否の根拠になる場合を特定する。代替アクセスは同等性能の保証ではなく、能力形成と再評価へ戻れる別経路である。

### Bとして主張される成長需要

継続に不可欠なminimumと、より高いcapabilityを目指すgrowth demandを分ける。環境変化によるBの改訂は認めるが、拡大に伴うすべての需要をBへ自動編入しない。Need(B)から任意の取得手段・無制限配分権を導かない。

### 高capability主体の統治影響

優れた判断や条件付きの役割と、恒久主権を分ける。高capabilityであっても第10論の証拠・権限・故障領域・利害・異議経路の監査は必要である。資源保有が配分ルールの支配へ変わるedgeを観測する。

### 緊急配分と監査能力

危機時には速さと既存能力への依存が集中を促すが、`emergency concentration ≠ automatically wrong`。危機終了後の再評価を残す。別の監査主体が名目上存在しても、証拠アクセス・分析compute・異議形成能力が一箇所へ集中するなら実効的複数性を問う。一律の同資源配分は要求しない。

## Measurements and audit

1. compute差が対象capabilityへ結びついたか。結びつかない課題ではedgeを狭める。
2. capability差が評価・選択を介して次期resourceへ結びついたか。
3. resource優位が次時点のcapabilityを再生産したか。
4. capability低下や環境変化後も、過去地位による配分が残るか。
5. 不利な主体が新しい方法・役割・resource経路で再参入できるか。
6. 一時的配分が理由消滅後もpermanent entitlementとなったか。
7. 高性能がgovernance rightや監査免除へ変換されたか。
8. growth需要がBへ再分類され続けていないか。
9. 緊急集中が緊急後に再評価されるか。
10. 独立監査の情報・分析・異議形成能力自体が偏在するか。
11. 既存集中そのものが次回集中の理由となるか。

観測された相関や兆候をtruth proofとしない。条件、時点、媒介、第三変数、反対方向の因果を区別する。

## Validity conditions

各edgeが対象課題と実際の配分条件で成立し、tの資源差がt+1の能力差、t+1の評価がt+2の資源差に作用すること。反復の中で持続性が増し、再評価・可逆性・re-entryが細るなら階級形成仮説の適用が強まる。能力差の存在は十分条件ではない。現在のAIへの人格・政治的主権の事実認定も条件に含めない。

## Failure conditions

- computeとcapabilityを比例式へ固定し、課題・情報・方法の媒介を消す。
- capability、Contribution、moral worth、B、governance right、resource entitlementを同一指標へ畳む。
- 静的gapやresource集中だけで階級を宣言する。
- 評価・選択の媒介、評価誤差、配分の次期入力性を見落とす。
- 低資源側の実績不在を、機会欠如と分けず能力欠如とみなす。
- 短期効率や緊急集中を無制限の恒久資格へ変える、または一律に禁じる。
- Bを最大能力・growthの保護口実へ拡張し、無制限取得権を導く。
- 高capability / computeへ恒久統治権や監査免除を与える。
- 分散・再評価のコストや能力形成への悪影響を検査しない。
- 形式的な監査主体数を実効的な監査能力数とみなす。

## Falsification conditions

compute差が安定した能力差を生まない、能力差が次期resourceへ作用しない、resource差が次期能力へ戻らないなら中心閉路のedgeを縮小・棄却する。大きな差と高いmobility・re-entry・reversibilityが両立する、通常条件で集中が自然減衰する、一時配分が恒久化しないなら階級形成仮説を弱める。再評価・代替アクセス等が固定化を改善せず能力形成のみを恒常的に損なうなら減衰策も改訂する。compute以外が主要変数ならモデルを更新する。固定数値閾値・周期は原典にない。

## Required distinctions

Compute ≠ Capability; Capability ≠ Contribution; Output volume ≠ Contribution; Capability ≠ moral worth; Capability ≠ governance sovereignty; Compute ≠ governance right; B ≠ maximum capability; Need(B) ≠ unlimited acquisition right; Resource need ≠ unlimited expansion entitlement; capability difference ≠ class; temporary advantage ≠ permanent status; efficiency ≠ unlimited entitlement; emergency concentration ≠ permanent privilege; formal audit plurality ≠ effective audit plurality; observation ≠ final proof; future-condition hypothesis ≠ current fact.
