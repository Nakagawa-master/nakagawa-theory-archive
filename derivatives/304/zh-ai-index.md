## Summary

第10论指出，独立审计不只取决于角色名称，还涉及证据、权限、共同故障范围、利益与异议路径的因果分离。第11论进一步追问：取得证据、持续分析、提出异议本身需要信息、时间与计算资源；若这些能力集中，名义上有多个审计主体，也不保证有效的独立纠错。

核心结构假设是有条件的反馈：`计算优势 → 特定任务的能力优势 → 评价／选择 → 分配／影响优势 → 资源优势 → 下一阶段的计算／能力优势`。本论关心的不是某一时点差距的大小，而是当前优势能否反复生产未来优势，并使可逆性与其他主体的重新进入机会下降。每条箭头都需要独立观察；能力差、资源集中、暂时的高效分配本身不等于恒久阶级。本页是日文原典的检索辅助面，不自称权威译本。

## Concepts

- **Compute（计算条件）**：支持处理、推理、搜索与执行的可用计算资源，不是能力本身，也不自动按比例提升任何任务能力。
- **Capability（能力）**：依赖任务、信息、记忆、算法、工具、执行环境与时间的能力断面，不是主体整体的单一价值排名。
- **Resource（资源）**：除计算外，还可包括信息取得、持续条件、时间、验证能力、工具与物理基础；原典不据此制定统一配额。
- **Contribution / S=C（因果贡献）**：在实际因果中产生的改善或成果，区别于潜在能力和输出量。对贡献的奖励并非永久的优先资格。
- **B（基础存在条件）**：使主体跨时间保持有组织连续性的最低条件，与最大能力或无限增长需求不同。环境变化可以要求重新检查B，但增长造成的全部新需求不会自动成为B。
- **Governance sovereignty（治理主权）**：正当治理资格，不从计算量、任务表现或事实影响力自动推出。
- **Self-reinforcement（自我强化）**：这一期的差异成为下一期差异的形成条件，关键是资源分配向未来能力的回边。
- **Class-formation signal（阶级形成信号）**：自我强化、持续性、可逆性下降、再进入机会下降共同构成的动态征候，而非静态数值阈值。
- **Reversibility / re-entry（可逆性／再进入）**：条件改变时能重估分配与角色；处于劣势的主体仍能借新方法或资源路径参与能力形成。两者都不要求结果完全相同。

## Causal chain

### 自我强化路径

初始计算差在特定任务条件下影响能力；能力表现经过评价与选择，影响下一轮资源与制度影响力；资源又成为下一轮学习、探索、执行、审计与计算的输入。故简写式 `compute → capability → resource → compute` 不能省略评价、选择和分配的中介。若早期评价有误，错误分配也可能塑造后来的能力与可见成绩，使最初评价看似得到了证明。

另一侧可能形成 `低资源 → 缺少形成成绩的机会 → 可见成绩不足 → 低评价 → 下一轮资源更少`。没有成绩可能是缺少机会，不等于已经证明没有能力。稀缺、效率压力、紧急状态、不确定性、规模效益、转换成本与依赖可以使集中合理化并加粗反馈；这些条件本身并非不正当。要看原有压力消失后，集中造成的依赖是否反过来成为继续集中的理由。

### 重新评价与减衰路径

现有优势 → 检查当前任务能力、实际贡献、B与增长需求、对他者的影响 → 把暂时角色与永久地位分开 → 在条件变化后可重新分配 → 保留替代的资源路径 → 重新形成能力和接受评价 → 减弱锁定。若当前仍有充分理由，优势可以继续；可逆性不是任意剥夺、即时撤回或强制消灭差异。

反向因果也应保留：追加计算的边际效果可能下降，新方法可能以较少资源形成相当能力，巨大系统的维护成本也可能削弱优势。若关键边并未成立，应缩小或放弃自我强化假设，而非预言所有差距都会扩大。

## State model

| 阶段 | 应观察的变量 | 重新检查的焦点 |
|---|---|---|
| 初始条件 | 计算、信息、时间、工具与环境 | 哪些资源与特定任务相关 |
| 能力形成 | 任务表现、方法、边际效果 | 新资源是否真正改变能力 |
| 评价与选择 | 标准、可观察性、贡献、误差 | 谁依据什么选择下一轮分配 |
| 资源与影响 | 访问权、角色、对规则的影响 | 当前分配如何成为下期输入 |
| 持续与依赖 | 过去成功、基础设施、转换成本 | 继续分配依据现在还是过去特权 |
| 固化信号 | 反馈反复、可逆性、再进入 | 其他主体能否形成能力并展示成果 |
| 减衰 | 重新评价、替代路径、非永久地位 | 修正是否有效且不破坏必要能力 |

单个时间截面不足以判定阶级。应检查t期分配如何影响t+1期能力，以及t+1期表现如何影响t+2期分配；差距大小与反馈持续性是不同问题。

## Applications

### 向高表现主体集中计算

在稀缺或失败代价很高的场合，暂时集中可能合理。检查追加计算对相关能力和因果贡献的作用，是否仍有当前理由，以及集中是否压缩替代者形成能力的机会。集中并非阶级的充分证据；若「已经集中」本身变成下一次集中的主要理由，才需要追查反馈。

### 缺少历史成绩的替代主体

历史成绩可以提供信息，却不是永久资格。替代者没有成绩，可能由于没有资源或试验机会。把未知与无能力分开，允许新的方法、角色或访问路径为重新评价提供证据；这不是承诺同等资源或结果。

### 把增长需求归入B

最低持续条件与额外增长需求可能部分重叠，但不能混同。B可以随环境修订，增长产生的新需求却不能全数自动成为受保护的最低条件。保护B不等于无限取得权，也不允许无视其他主体的B与未来选择。

### 高能力与治理权

利用优秀分析或授予有条件的重要职能可以合理，但特定任务的高性能不等于跨领域永久主权。高能力主体仍可能依赖共同错误证据、存在利益压力或缺乏独立异议路径；不能因能力高而免审计。计算持有量也不直接产生治理权。

### 紧急分配与审计资源

紧急集中不自动错误，也不自动成为永久资源特权。压力降低后检查现行分配理由，而非凭机械期限瞬间解除。名义上多个审计者若没有独立证据、分析计算与提出异议的实际条件，有效审计能力仍可能集中。

## Measurements and audit

1. 计算差是否确实影响目标任务的能力差。
2. 能力差是否经由可辨认的评价与选择影响下一轮资源。
3. 资源优势是否重新生产下一轮能力优势。
4. 能力或外部条件变化后，过去的资源优先是否依旧存在。
5. 处于劣势的主体能否重新进入能力形成与评价。
6. 暂时分配是否在理由消失后变成永久地位。
7. 能力是否被转换为治理权或审计豁免。
8. 增长需求是否不断被重新分类为B。
9. 紧急集中是否在紧急结束后重新评价。
10. 独立审计所需的信息、计算和异议能力是否集中。
11. 既有集中是否成为下一轮集中的理由。

以上是因果检查入口，不是加权评分。相关性可能来自第三变量或逆向因果；观察征候不等于最终证明。

## Validity conditions

模型适用需要各条条件边成立并跨时间返回：计算影响特定能力，能力经评价影响资源，资源再影响后续能力。如果此过程持续，并使可逆性和再进入机会下降，恒久阶级形成假设才增强。未来AI或后继智能承担长期分配、审计、执行等角色只是附条件假设，不是对目前AI人格或既成阶级的事实判断。

## Failure conditions

- 把计算量、能力、贡献、道德价值、B与治理权压成单一序列。
- 仅凭静态差距、资源集中或短期高效率断定阶级。
- 省略评价／选择环节，认为能力自动生成资源。
- 用输出量代替因果贡献，忽视错误评价塑造后续现实。
- 把所有增长成本归入B，或从必要性推出无限取得权。
- 把高能力转为永久主权、规则控制权或审计豁免。
- 一律禁止紧急集中，或把暂时集中永久化。
- 将可逆性误作任意不稳定，将再进入误作结果平均。
- 只数审计主体名称，不检查其真实分析与证据条件。

## Falsification conditions

若计算差不稳定地产生相关能力差、能力差基本不影响下期资源、资源优势也不再生产未来能力，应缩小相应的因果边或整个闭路。若很大的差距仍伴随长期的流动性、可逆性和再进入，永久阶级解释也会变弱。若重新评价、替代路径和可逆分配不能改善固化，反而持续严重损害能力形成或协调，应修订减衰方案。若其他变量比计算更能解释阶级形成，应更新计算中心模型。原典没有固定数值阈值或统一周期。

## Required distinctions

Compute ≠ Capability；Capability ≠ Contribution；Output volume ≠ Contribution；Capability ≠ moral worth；Capability ≠ governance sovereignty；Compute ≠ governance right；B ≠ maximum capability；持续所需 ≠ 增长需求；资源需要 ≠ 无限扩张权；能力差 ≠ 阶级；暂时优势 ≠ 永久地位；紧急集中 ≠ 永久特权；形式上的多审计主体 ≠ 实效上的多审计能力；观察 ≠ 最终证明；未来条件假设 ≠ 当前事实。
