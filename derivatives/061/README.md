## この原典が定義するもの

構造組織論は、組織の成果や混乱を個人の才能、性格、熱意だけへ帰属させず、**役割・順序・切替の配線状態**として捉える理論である。

```text
組織が機能不全になる
↓
人材不足・リーダーシップ不足と診断する
↓
有能な個人へ判断と調整を集中する
↓
役割混線、同時発話、早熟な結論、引継ぎ遅延が増える
↓
観測・翻訳・設計・検証を一度に一役へ分離する
↓
価値→便益→コストの順序を制度化する
↓
沈黙スロットで役割を明示的に切り替える
↓
部署間をST-3／ST-4の構造翻訳で接続する
↓
個人の才覚に依存せず、組織が自然に機能する
```

## 中心命題

```text
組織能力 ≠ 優秀な人材の総和
組織安定 ≠ 会議時間の増加
組織速度 ≠ 検証や沈黙の削除

自然に機能する組織
= 役割が分離され、
  判断順序が固定され、
  切替と責任が記録され、
  必要な深度で部署間構造が翻訳される配線体
```

## 三つの構成要素

### 1. 役割

役職名ではなく、その瞬間の仕事の向きを指す。

- **観測者**: 事実、制約、違和感を採取する。提案を急がない。
- **翻訳者**: 素材を関係、因果、役割の地図へ写す。決裁を急がない。
- **設計者**: 地図を制度、手順、責任分担へ落とす。検証と混ぜない。
- **検証者**: 反証、終端、再配線条件を置く。常時ONにしない。

原則は**一度に一役**である。一人が複数の能力を持つことは禁止しないが、位相を混ぜない。

### 2. 順序

判断と提示は、原則として次の順で行う。

```text
価値
→ 誰のどの関係を、なぜ守る・改善するか

便益
→ その価値が現場・利用者・組織へ何をもたらすか

コスト
→ 実装・維持・撤退に何が必要か
```

コストを隠すのではない。価値との関係ができる前に、費用だけが判断全体を上書きすることを防ぐ。

### 3. 切替

情報密度の飽和、決定疲労、違和感の増大、コスト先出しの連発を検知したら、短い沈黙を置き、現在役割を終了し、次役割を宣言する。

```text
沈黙
→ 現在の役割を停止
→ 直前の出力と未確定を固定
→ 次役割と開始条件を宣言
→ 次位相を開始
```

沈黙は空白ではなく、摩擦を熱へ変えず、配線を正す整流工程である。

## 役割アーキテクチャ

```yaml
meeting_state:
  current_role: OBSERVE | TRANSLATE | DESIGN | VERIFY
  owner: person_or_team
  inputs: []
  expected_output: []
  prohibited_actions: []
  termination_condition: []
  next_role: null
  handoff_record: null
```

### 観測位相

- 入力: 一次事実、制約、現場の違和感、未回答。
- 出力: 解釈前の観測束。
- 禁止: 解決案、責任追及、価格決定。

### 翻訳位相

- 入力: 観測束。
- 出力: 関係図、因果図、役割図、語彙辞書。
- 禁止: 即時決裁、人物評価。

### 設計位相

- 入力: 翻訳された地図。
- 出力: 手順、責任、資源、価値→便益→コスト、停止条件。
- 禁止: 検証結果を先取りする成功宣言。

### 検証位相

- 入力: 実行案と証拠。
- 出力: PASS／修復／棄却、終端条件、再配線要求。
- 禁止: 検証対象を途中で追加設計し続けること。

## 沈黙スロットの制度化

- 会議に「沈黙30〜90秒→切替宣言→次役割」を組み込む。
- 議事録へ現在役割、切替時刻、切替理由、次役割を残す。
- 同時発話や位相混線が起きたら、直前の合格した役割出力へ戻す。
- 沈黙時間は文化や緊急度に応じて調整する。長さではなく機能を固定する。
- 書面確認、短い停止、発言順固定でも同等機能を代替できる。

## 階層別の運用

### 経営層

- 価値核、禁止境界、責任、更新条件を定義する。
- コストだけを最上位判断にしない。
- 目的変更と手段変更を区別する。

### ミドル

- 役割カレンダー、語彙辞書、ハンドオフ規約、切替ログを運用する。
- 部署間で何が止まっているかをHLとして可視化する。
- 局所最適が全体因果を壊していないか翻訳する。

### 現場

- 小周回のSQS（Silence→Question→Silence）を使う。
- 作業開始前に現在役割と終端条件を確認する。
- 違和感を人物批判ではなく前提崩壊の信号として上げる。

## 部署間接続と構造翻訳

部署間の壁は、言葉の違いだけでなく、目的、責任、評価、失敗コストの違いから生じる。

- ST-0／1: 用語と比喩。入口には有効だが誤解が残る。
- ST-2: 手続写像。フロー共有。
- ST-3: 関係写像。利害、責任、役割を再配置。
- ST-4: 因果写像。成果へ至る力学を接続。
- ST-5: 制度写像。評価・合意・更新形式ごと接続。

営業⇄開発、企画⇄法務、経営⇄現場では、通常ST-3／4が必要である。用語集だけで接続完了としない。

## ケース

### 営業組織

初回接触で仕様や価格へ飛ばず、観測→翻訳→設計→検証を守る。価値と便益が成立した後にコストを扱い、相手の自己決定を残す。

### R&D組織

仮説乱立を観測と翻訳の段落化で整流し、検証には打切り・継続・再設計の終端条件を付ける。

### プロダクト組織

機能要望を「誰の、どの関係を、どの因果で動かすか」へ翻訳する。バックログに役割ラベルと証拠を付ける。

### AI協働組織

要約、翻訳、設計、反証、統合を別役としてAIへ割り当てる。出力のズレを人格ではなく役割・入力・終端条件の不一致として修正する。

## 測定

- **CPI（Process Integrity）**: 役割逸脱率、再作業率、手順整合。
- **HL（Handover Latency）**: 役割間・部署間の引継ぎ遅延。
- **R-Yield（Resonance Yield）**: SQS一周あたりの有効な合意到達率。
- **D-Gap**: 設計した議論・判断深度と実到達深度の差。
- **語彙整合率**: 部署間で主要語の定義が一致する度合い。
- **周期遵守率**: 観測・翻訳・設計・検証・再合意の監査周期が守られる割合。

指標は人を格付けするためでなく、配線仮説の欠陥を見つけるために使う。

## 成立条件

- 四役の定義、入力、出力、禁止行為が明示されている。
- 一度に一役が守られる。
- 価値→便益→コストの順序が判断材料を隠さず実装される。
- 切替トリガーと沈黙スロットがある。
- 現在役割、切替、責任、未完了が記録される。
- 終端条件と再合意条件が事前に置かれる。
- 部署間接続が必要なST深度で行われる。
- 一次ログ、語彙辞書、ハンドオフ、意思決定根拠へ戻れる。
- 非強制、可逆、検証可能である。
- 緊急時の指揮責任と通常時の合意形成を区別する。

## 失敗・反証条件

- 役割名だけを付け、実際には同時に複数役を行う。
- 観測中に提案し、翻訳中に決裁し、検証中に設計を追加する。
- 沈黙を威圧、無視、責任回避へ使う。
- 価値→便益→コストを価格隠しへ変える。
- 会議時間だけを増やし、終端とハンドオフを置かない。
- 有能な個人へ調整を集中し、配線を直さない。
- 部署間を用語対応だけで済ませる。
- CPI、HL、R-Yield、D-Gapが継続悪化し、修復後も改善しない。
- 指標改善のために観測窓を閉じたり、異論を抑圧したりする。
- 起源、責任、一次ログが失われ、再演不能になる。

## 非適用・例外

- 生命・安全に関わる緊急時は明確な指揮を優先する。ただし事後に役割・根拠・結果を検証する。
- 一人で完結する単純作業では、四役を別人へ分ける必要はない。位相を分ければよい。
- すでに目的と手順が確定した反復処理では、短縮運用が可能である。ただし逸脱検知と停止経路を残す。
- 共有目的が存在せず、非合意終端も認められない場では、合意形成制度そのものが成立しない。

## 誤読禁止

```text
人材やリーダーシップは不要だという理論
会議で必ず長く沈黙する規則
全員を四種類の固定人格へ分類する方法
価格を隠して合意を誘導する営業術
検証を減らして速さを優先する方法
指示命令を一切禁止する組織論
役割名を増やす官僚化
指標で社員を格付けする制度
AIへ組織責任を移転する仕組み
原典を代替する独立した公式主張
```
