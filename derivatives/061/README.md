## 位置づけ
親原典は、組織の機能不全を人材・性格・熱意だけへ帰属させず、役割・判断順序・切替・ハンドオフ・責任の配線状態として捉える。観測・翻訳・設計・検証を一度に一役へ分離し、価値→便益→コストの順序、沈黙スロット、部署間構造翻訳、一次ログ、終端条件を組み合わせることで、特定の有能者へ調整負荷を集中させず再演可能な組織機能を作る。

## 中心命題
**自然に機能する組織とは、優秀な人材の総和ではなく、誰が何を観測し、どう翻訳し、何を設計し、どこで検証し、いつ誰へ渡すかが明示され、切替・責任・終端・再合意が追跡できる配線体である。**

## 因果線
```text
組織不全
→ 個人能力の不足として処理
→ 調整が有能者へ集中
→ 役割混線・引継ぎ遅延・再作業
→ 四役を一度に一役へ分離
→ 価値→便益→コストの順序を固定
→ 沈黙スロットと切替記録
→ 必要なST深度で部署間を接続
→ CPI / HL / R-Yield / D-Gap等で配線を観測
→ 終端・再合意・再配線
→ 人が替わっても機能する組織
```

## 構造層
**1. 役割層。** 観測、翻訳、設計、検証を別機能として定義し、同一位相で混ぜない。

**2. 順序層。** 価値→便益→コストを判断の配置順として用い、コストを隠さず、費用だけが目的を上書きすることも防ぐ。

**3. 切替層。** 情報飽和、決定疲労、違和感、同時発話等を切替信号として扱い、沈黙スロットで役割を切り替える。

**4. ハンドオフ層。** 現在役割、出力、未完了、責任、次役割、根拠を記録し、引継ぎを追跡可能にする。

**5. 階層層。** 経営は価値核・禁止境界・責任を、ミドルは語彙・ハンドオフ・切替を、現場は短いSQSと終端確認を担う。

**6. 部署間翻訳層。** ST-0〜ST-5を使い、用語対応だけでなく関係・因果・評価・責任を必要深度で接続する。

**7. 監査・再配線層。** CPI、HL、R-Yield、D-Gap、語彙整合率、周期遵守率等を人物評価ではなく配線仮説の反証に用いる。

## 適用例
**1. 営業⇄開発。** 顧客要望を機能名だけで渡さず、利用者、価値、因果、制約、失敗条件、責任へ翻訳して引き継ぐ。

**2. 企画⇄法務。** 企画の価値・便益と法務上の成立条件を別位相で整理し、単なる賛否ではなく条件付き設計へ接続する。

**3. R&D。** 観測・仮説・設計・検証を分け、検証前に打切り・継続・再設計条件を置く。

**4. AI協働。** 要約、構造化、設計、反証を役割として分離し、AI出力を最終責任判断へ自動転換しない。

**5. 緊急対応。** 生命・安全に関わる場面では明確な指揮を優先し、責任・根拠・結果を事後に検証する。

## 測定・監査点
- **四役**: 観測・翻訳・設計・検証という原典明示の4機能。4点満点や人格分類ではない。
- **沈黙30〜90秒**: 原典の実装例。固定必須値ではなく、文化・緊急度に応じて短い停止・書面確認等で機能代替できる。
- **ST-0〜ST-5**: 部署間翻訳の6段階分類。数値の大小を部署や人物の優劣に使わない。
- **CPI**: 役割逸脱、再作業、手順整合等を通じてProcess Integrityを観測する概念。
- **HL**: 役割間・部署間のHandover Latencyを観測する概念。
- **R-Yield**: 一周の対話・検討から有効な合意へ進めたかをみる観測概念。
- **D-Gap**: 設計した議論・判断深度と実到達深度の差。
- **語彙整合率 / 周期遵守率**: 部署間定義整合や監査周期の実施状況を観測する候補であり、人事評価の固定スコアではない。

反転評価では、HLが短縮しR-Yieldが上昇しても、異論・拒否・訂正が抑圧され、沈黙が威圧として機能するなら改善とみなさない。CPIや周期遵守率が上がっても、手続遵守そのものが目的化し、現場の意味・安全・責任が失われれば失敗である。

## 成立条件
- 四役の入力、出力、禁止行為、終端条件が明示される。
- 一度に一役が実質的に守られる。
- 価値→便益→コストで不利条件も含めて提示される。
- 切替トリガーと沈黙スロットが機能する。
- 現在役割、切替理由、次役割、未完了が記録される。
- 終端・保留・打切り・再合意条件がある。
- 部署間接続で必要なST深度が使われる。
- 語彙辞書、一次ログ、ハンドオフ、意思決定根拠へ戻れる。
- 非強制、拒否、訂正、可逆性が保持される。
- 緊急時の指揮例外と事後検証が区別される。

## 失敗条件
- 役割名だけ付け、複数機能を同時遂行する。
- 観測中に提案し、翻訳中に決裁し、検証中に対象を設計し続ける。
- 沈黙を威圧、無視、責任回避へ使う。
- 価値→便益→コストを価格・不利条件隠しへ変える。
- 会議時間や承認段階を増やすだけで終端・ハンドオフがない。
- 有能者への調整集中を配線修復と誤認する。
- 部署間接続をST-0/1で完了とする。
- 指標を人事評価へ直結し、異論・失敗証拠を隠す。
- 緊急時に責任ある指揮を回避する。

## 反証・改訂条件
- 役割分離後も再作業・責任混線が反復して改善しない。
- HL短縮が引継ぎ品質や証拠保持を悪化させる。
- R-Yield改善が表面的同意や異論抑圧によって生じる。
- D-Gap縮小が必要な深度検討の省略によって達成される。
- CPI改善が形式遵守だけを増やし、実質的な組織機能を改善しない。
- 沈黙スロットが意思決定を不必要に遅らせ、緊急責任を妨げる。
- ST-3〜ST-5を用いても部署間の因果・責任・評価が接続しない。

## 必須の区別

## 解釈制約
構造組織論を人材不要論、リーダー不要論、会議マナー、静的な職務分担へ縮約しない。四役は固定人格ではなく位相機能であり、沈黙30〜90秒は固定義務ではない。CPI・HL・R-Yield・D-Gap等は組織配線の仮説を検査するための観測概念であり、人物格付けや普遍的閾値へ変換しない。
