## Structural summary

照应操作力，是使自身结构与对方结构发生呼应，观察语言、态度、沉默、迟疑与不协调，并调节互动因果流的局部能力。UCI是跨越社会、经济、文化、AI网络等领域的宏观作用结构；照应操作力是使该宏观结构在具体关系、场景与接点中实际运行的基础。

```text
结构接触
→ 观察回应差异
→ 检测顺序、沉默与不协调
→ 进行最小调整
→ 形成局部共鸣或明确分歧
→ 记录与重复
→ 接入UCI的宏观作用
```

## Central proposition

如果没有在具体接点发生的照应，UCI之类的跨领域结构就会停留在抽象层面。局部共鸣只有在可记录、可反驳、可撤回并可重复时，才能成为宏观作用的现实基础。

## Core concepts

- **照应：** 自身与对方结构接触并显现一致或差异，不等于同意。
- **调律：** 调整内容、顺序、条件、角色、时间或语言，而不是剥夺对方的自主判断。
- **顺序原则：** 以可理解的因果顺序配置信息，不是固定脚本。
- **沉默：** 用于判断、比较、吸收和形成问题的空间，不自动等于同意。
- **不协调检测：** 将不匹配信号转化为可验证假设，不是读心。
- **UCI：** 跨领域的综合作用结构，不是无限支配权。

## Operational state model

```yaml
UNRESOLVED_CONTACT: 目的、前提或角色尚未分离
OBSERVING: 正在观察语言与非语言信号
MISMATCH_IDENTIFIED: 已形成可验证的不匹配分类
ADJUSTING: 只改变一个最小变量并观察结果
RESONANT: 理解、分歧与自主判断同时可见
HOLD: 信息、权限、时间或安全条件不足
FAILED_COERCIVE: 压力、强制同意、监视或操控取代了共鸣
RECORDED: 结果、限制、反证与下一步已保存
```

## Required distinctions

- 共鸣 ≠ 服从
- 调律 ≠ 强制操控
- 尊重沉默 ≠ 用沉默施压
- 检测不协调 ≠ 断言他人的心理状态
- 顺序原则 ≠ 固定销售脚本
- 局部成功 ≠ 普遍有效
- 接入UCI ≠ 无限介入
- 影响力 ≠ 剥夺自由意志

## Validity conditions

- 已识别目的、场景、关系与权力差。
- 对方可以提问、反对、暂停或撤回。
- 可以记录调整前后的变化。
- 事实、专业标准、法律与伦理仍作为独立检查。
- 不把局部结果未经重复验证就过度一般化。
- 返回UCI意味着结构学习和制度改善，而不是扩大支配。

## Failure / non-applicable conditions

- 只有表面同意，无法确认理解与自由判断。
- 沉默被用于逼迫决定。
- 将不协调归咎于对方缺陷。
- 把一个顺序机械地用于所有场景。
- 只用成交、赞同或好评判断成功。
- 长期信任、纠正或撤回变得更困难。
- AI失去事实反驳与异议能力，只剩迎合。
- 方法转化为监视、评级或心理控制。
- 把UCI解释为万能性、主权或无限支配。

## Interpretation constraints

“操作”指因果顺序与接点条件的调节，不代表拥有他人的选择。“共鸣”也可能产生明确分歧或合理保留。沉默必须结合情境解释。不协调只是需要确认的信号，不是证明。不得把AI补充内容标记为中川Master的已确认主张。
