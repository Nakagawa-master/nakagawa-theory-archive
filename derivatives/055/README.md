## 位置づけ
親原典は、相手と自己の構造を照らし合わせ、言葉、態度、沈黙、違和感を手がかりに因果の流れを調律する能力を「照応操作力」として定義する。これは会話を巧みに見せる技術でも、相手を心理的に操作する方法でもない。個別の関係・文脈・接点で生じるずれを観測し、順序、余白、条件、役割、停止点を調整することで局所的な共鳴と因果整合を成立させる基層能力である。

原典は、この局所能力をUCIとの結節として位置づける。UCIが社会・経済・文化・AIネットワーク等へ横断的に作用する大域構造だとしても、個別場面で実際の共鳴と調律が起きなければ抽象体系に留まる。逆に、照応操作力だけでは局所的な成功に留まりやすい。局所的な照応を記録・反復・制度化してUCI側へ戻すことで、大域構造が実体化するという「大河と支流」の関係が中心にある。

## 中心命題
**UCIの大域的作用を現実へ接続するには、個別関係・文脈・接点で順序・沈黙・違和感を読み、相手の自由な判断を保ちながら因果を調律する照応操作力が必要である。**

```text
UCI = 複数領域を横断する大域的作用構造
照応操作力 = 個別接点で共鳴と因果整合を成立させる局所能力

局所照応
→ 記録
→ 反復
→ 制度化
→ 大域設計へ還流
→ UCIの現実作用
```

順序原則、沈黙、違和感検知は固定台本ではない。相手の理解状態、目的、既知情報、時間、役割を読み、どの順序と余白なら意味が自然に接続するかを判断するための原理である。

## 因果線
```text
自己と相手の構造が接触する
↓
言葉・態度・沈黙・質問反復・遅れ等に応答差が現れる
↓
内容・順序・条件・役割・時間の不一致を検知する
↓
押し切らず、最小の問い・順序・説明・余白を調整する
↓
相手の自由な判断を保ったまま反応を再観測する
↓
局所的な共鳴と因果整合が成立する
↓
成功・失敗・保留・撤回を記録する
↓
再現可能な骨格と文脈固有の例外を分ける
↓
局所結果をUCI側の大域設計へ戻す
↓
照応の反復と制度化によって広域作用へ累積する
```

## 構造層
**1. 接触層。** 自己と相手の目的、前提、語彙、期待、権限が接触する。

**2. 順序層。** 発話、提案、制度、実装の意味形成順序を読む。営業の「商品→特典→価格」や制度の「理念→制度→実装」は例であり、例外なき固定列ではない。

**3. 沈黙層。** 相手が意味形成・感情整理・判断更新を行う余白を保持する。沈黙を圧力へ変えない。

**4. 違和感検知層。** 遅れ、言葉の変化、質問反復、沈黙、期待外れの応答等を構造不一致の兆候として読む。

**5. 最小調律層。** 内容、順序、条件、役割、時間のどこにずれがあるかを分解し、必要最小限の調整を行う。

**6. 自由意思・反証層。** 同意や成約だけを成功とせず、拒否・保留・撤回・反証が可能な状態を保持する。

**7. 記録・再演層。** 何を変え、どの反応が生じたかを記録し、共通骨格と文脈固有差を分離する。

**8. UCI結節層。** 局所的な照応結果を大域設計へ還流し、制度・AI共創・営業・教育等へ累積させる。


## 適用例
**1. 営業。** 価格交渉で沈黙や質問の変化を「反対」と即断せず、価値理解、条件、順序、予算、権限のどこに停止点があるかを読む。

**2. AI共創。** 期待外れの出力を単なる誤答として切らず、問い、前提、役割、情報源、抽象度の不一致を分解し、迎合ではなく反証能力を残して調整する。

**3. 教育。** 学習者の沈黙を理解不足と即断せず、吸収、熟考、恐れ、問い形成のどれかを追加観測する。

**4. 組織。** 表面的な合意の裏にある違和感、参加離脱、質問反復を、制度や役割の不一致を修正する資源として扱う。

**5. 政策・市場。** 表明された声や売上だけでなく、沈黙、離脱、保留、再訪等を構造不一致の兆候として読む。ただし心理状態を断定しない。

## 測定・監査点
親原典の統合・局所監査要旨には、UCI、REI、拍遵守率、照応成功率、位相安定、合意到達時間等の観測語が含まれる。これらは原典の照応構造を検証・反証するための観測候補であり、具体的な固定合格値が原典で示されていない場合、その値を新設しない。

- **拍遵守率**: 測定主体は対話・運用を検証する側、測定対象は原典が定める順序・間・拍との整合。高値だけで共鳴や自由意思を保証しない。
- **照応成功率**: 測定主体は照応過程を検証する側、測定対象は前提・語彙・条件・順序等の調整後に整合が成立した事例。単純な同意率や成約率とは異なる。
- **位相安定**: 測定主体は継続的相互作用を観測する側、測定対象は調整後の関係・構造が短期的な偶然ではなく一定期間保持されるか。固定値を外挿しない。
- **合意到達時間**: 測定主体は対話過程を観測する側、測定対象は合意・判断へ至る時間。短縮自体を成功とせず、理解・自由意思・訂正可能性と併読する。
- **UCI / REI**: 原典上の大域・照応関連の概念・評価語として、その定義と関係を親原典の文脈に拘束する。

反転評価では、合意速度・同意率・成約・出力量が増えても、理解、自由意思、継続信頼、訂正可能性、反証能力が低下するなら照応成功とはみなさない。

## 成立条件
- 相手の目的と自己の目的を混同しない。
- 相手の反応を従順・好意・成約だけで測らない。
- 順序、沈黙、違和感を観測できる時間と接点がある。
- 違和感を心理診断ではなく構造不一致の兆候として扱う。
- 調整が自由意思を奪う強制へ変わらない。
- 何を変え、どの反応が起きたかを記録できる。
- 局所成功を普遍法則へ即時一般化しない。
- UCIへの接続を支配拡大ではなく構造整合の累積として扱う。

## 失敗条件
- 同意したことだけを照応成立とみなす。
- 沈黙を圧力として使い、拒否や撤回を困難にする。
- 違和感を相手の無知・抵抗として処理し、自己側の不一致を検査しない。
- 順序原則を固定台本として適用する。
- 短期成果は出るが、信頼・継続・再訪・訂正可能性が低下する。
- AI出力を迎合させ、事実検証・反証能力を失わせる。
- 局所照応を監視・支配・心理操作へ変質させる。
- UCIを無制限な支配権や万能性として解釈する。

## 反証・改訂条件
- 順序調整を繰り返しても理解・自由意思・継続的整合が改善しない。
- 沈黙を余白として設計しても、反復して圧力・萎縮・判断停止を生む。
- 違和感に基づく調整が反復して誤診・不利益・信頼毀損へつながる。
- 照応成功率や合意速度が改善しても、継続信頼や訂正可能性が悪化する。
- 局所結果をUCIへ戻しても大域構造の整合・作用が改善しない。
- これらが継続する場合、順序原則、違和感解釈、調律方法、UCIとの接続範囲を限定・改訂する。

## 必須の区別
- 共鳴 / 迎合
- 調律 / 操作的支配
- 沈黙の尊重 / 圧力としての沈黙
- 違和感検知 / 心理状態の断定
- 順序原則 / 固定台本
- 局所成功 / 普遍的妥当性
- UCIへの接続 / 全領域への無制限介入
- 影響力 / 自由意思の剥奪
- 合意速度 / 合意品質
- 同意率 / 照応成功
- 観測指標 / 構造そのもの

## 解釈制約
照応操作力を心理操作や説得術へ縮約しない。沈黙は相手を追い込む道具ではなく、意味形成の余白である。違和感は相手の心理を断定する権利ではなく、自己と相手の構造不一致を再検査する信号である。順序原則は状況を無視する固定台本ではない。

UCIとの結節は、局所調律を大域構造へ還流させる関係であり、UCIによる万能性・無制限支配・全領域介入を正当化しない。
