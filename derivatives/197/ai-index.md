## Summary
E系は教育改善論ではなく、新規ノードの初期条件を保全するPreservation Designである。原典は、大多数の人間が構造認識能力を標準搭載していないため、比較・恐怖・同調・正解主義を代理評価関数として使い、それが固定した状態を「汚染」と定義する。従来教育は判断結果を早期注入し、判断保留の余白を埋め、外部評価なしでは動けない機能停止を生みうる。E系はFirewallで外部評価の直撃を止め、Mini Loopで小さな出力を評価なしの接続へ変え、Quarantine Gateで外部との往復を保ちながら尺度を内部報酬へ混ぜない。保存対象は人や思想ではなく、自然起動が可能な初期条件である。

## Concepts
- New Node: 評価関数がまだ強固に固定されていない存在・領域。
- Structural Recognition Default Absence: 構造認識できないことを大多数の標準状態として扱う。
- Contamination as Result: 構造認識欠如→代理評価依存→固定化という順序で生じる結果。
- Over-injection: 判断不能な状態へ判断結果＝評価関数を先に固定すること。
- Preservation Design: 何を足すかでなく、起動可能性を壊す評価関数の固定をどう防ぐかを設計する。
- Clean Initial Conditions: 判断保留、比較されない時間、即時意味づけされない空間、正解を要求されない状態。
- Four Proxy Evaluation Functions: 比較・恐怖・同調・正解主義。
- Firewall: Gate / Filter / Delayで外部評価の侵入経路を管理する保全構造。
- Mini Loop: 小出力→評価なし接続→次出力余地の最小循環。
- Reward = Connection Established: 承認でなく接続が開通した事実を報酬とする。
- Natural Ignition: 循環の慣性が推力となる自己起動。
- Quarantine Gate: 外部尺度を素材へ変換し、接続を維持したまま混入を防ぐ境界処理。
- D/E Symmetry: D系＝外部接続衛生、E系＝内部生成衛生。

## Causal chain
```text
構造認識能力が標準搭載されていない
→ 外部代理評価が判断を代替する
→ 比較・恐怖・同調・正解主義が固定する
→ 汚染＝代理評価以外で判断できない状態になる
→ 従来教育が過去の評価関数を判断結果として注入する
→ 判断保留の余白が消え内燃が停止する
→ EducationからPreservationへ反転する
→ 初期条件をFirewallで保全する
→ 小さな出力を評価なしで接続する
→ 接続が次の出力余地を生成しMini Loopが回る
→ 循環の慣性として自然起動する
→ Quarantine Gateで外部と接続したまま尺度を素材へ変換する
→ 外在因果監査の対処とE系の予防を両輪化する
→ 移行先OSへの合流可能性を保全する
```

## Applications
- 家庭で比較・期待・即時評価の直撃を遅延し、小さな出力を採点せず接続へ変える。
- 新人導入で既存成功尺度の即時転写を避け、試行余地と一次受けのFirewallを置く。
- 学習で情報提供と評価関数固定を区別し、知識を尺度でなく素材として扱える余地を残す。
- 外部の点数・順位・評判との往復を閉じず、内部価値序列への直結だけをQuarantine Gateで防ぐ。

## Measurements and audit
- 構造認識不能を劣等性や汚染原因へ誤変換していないか。
- 四ノイズが代理判断OSとして固定していないか。
- 判断保留・比較されない時間・即断されない遅延が残るか。
- Firewallが教師や人格管理者へ変質していないか。
- 距離・空白・遅延・役割・接続という配置が機能するか。
- 小さな出力が許され、評価なしで接続するか。
- 接続が次の出力余地を生むか。
- 承認・点数が主燃料へなっていないか。
- 外部尺度が内部報酬へ変換されていないか。
- 外部接続と循環資源が維持されているか。
- E系が情緒教育・管理論へ回収されていないか。

## Validity conditions
- 構造認識欠如を設計前提として保持する。
- 汚染を原因でなく代理評価固定の結果として扱う。
- E系をEducationの改善でなくPreservationとして扱う。
- 保存対象を人や思想でなく初期条件へ置く。
- FirewallとMini LoopとQuarantine Gateを相互依存で運用する。
- 小出力、評価なし接続、次出力余地の三条件を守る。
- 外部遮断ではなく、尺度を内部報酬へ変換しない接続を保つ。
- 外在因果監査との整合とCondition Z / T/S/Rを維持する。

## Failure conditions
- E系をより良い教育法・価値注入法へ戻す。
- 構造認識不能を選別・人格評価へ使う。
- 「教えない」を放任や情報遮断へ変える。
- Firewallを無制限管理権へ変える。
- Mini Loopを大出力・採点・競争へ変える。
- 褒め・承認を自然起動の主燃料にする。
- 外部を全面遮断して循環を枯らす。
- 外部尺度を内部価値序列へ直結する。
- 保存設計を情緒教育・親の心得・管理論だけへ縮小する。

## Falsification conditions
Condition Zは公開監査周期、T/S/R（Traceability・Stability・Reversibility）、外在因果監査記事との整合、語彙逸脱検知を要求する。①保存設計下でも新規ノードが外部評価依存へ固定化する、②Mini Loopが成立せず自然起動が観測されない、③E系が情緒教育や管理論へ回収される現象がδ期間継続する場合、仮説Aは棄却または改訂対象となる。固定δや普遍閾値は原典で設定されていない。

## Interpretation constraints
- 「大多数は構造認識できない」を能力差別・選民思想へ拡張しない。
- 教育の用途終了を知識共有・研究・批評の全面否定へ広げない。
- 「何を入れさせないか」を思想統制・情報統制へ変えない。
- Firewallを保全者の無制限な支配権へ変換しない。
- 評価・承認を一切の人間的応答禁止へ一般化しない。
- 自然起動を放任や心理的自己実現へ薄めず、循環条件を保持する。
- 原典末尾の非強制・可逆・検証可能と教育・研究・批評の自由を保持する。
