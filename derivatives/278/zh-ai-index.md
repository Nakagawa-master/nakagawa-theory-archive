## Summary
Parent把获客从注意力、曝光和说服的强化，移向组织结构律动与市场沉默能够发生整合的条件设计。周期、振幅、同步需要在理念、行动、接点与时间上保持一致，并按“伦理不可侵性→结构必然性→感官共鸣性”的顺序构成。当这一顺序成立时，沉默不必只被理解为拒绝，也可能成为等待整合的时间窗，并通过再访、咨询、介绍、自我说明等自发行为表现出来。设计对象是组织自身的结构，而不是他人的心理。

## Concepts
沉默共识；结构律动；周期；振幅；同步；惰性周期；内部阈值；无意识整合；伦理不可侵性；公共性；透明性；可逆性；结构必然性；因果整合；束指标；分阶段扩展；感官共鸣；间；拍；自我编辑余地；律动日记；接点同步；UCI；REI；UCI-i；公开摘要；非强制获客；T/S/R；位相稳定S；RC；CEA；自发再访。

## Causal chain
注意力竞争 → 短期反应优化 → 把沉默误读为拒绝 → 增加刺激 → 接点之间失去一致 → 结构律动变薄 → 恢复周期/振幅/同步 → 先建立伦理不可侵性 → 形成因果整合、束指标、分阶段扩展 → 保留间与余白 → 与市场时间感形成同步点 → 沉默成为整合窗口 → 自发行为出现 → 束审计 → 过热/同调压力/误配时以T/S/R冷却、撤回、再共识 → 重新形成长期沉默共识。

## State model
`attention_competition -> rhythm_misalignment -> periodicity_amplitude_sync_restored -> ethical_integrity -> structural_necessity -> aesthetic_resonance -> silent_alignment_window -> voluntary_response -> bundle_audit -> TSR_reagreement -> durable_silent_consensus`

## Applications
让公开内容的周期、篇幅和语气保持可比较；对齐网站、资料、销售与客服的词汇和开场节奏；把沉默作为观察窗而不是自动填满；用轻咨询→小规模验证→正式合作等阶段导线保留撤回；公开因果通路和趋势，但把内部阈值与私有日志分离。

## Measurements and audit
把跨接点一致性、自发再访、咨询、介绍、自我说明、共识到达时间、位相稳定S、RC、CEA、撤回成功、过热、同调压力、有害锁定作为束来观察。UCI/REI/UCI-i只保持公开概念意义，不推测未公开公式、权重、阈值。点击、曝光、短期转化不能单独证明成功。

## Validity conditions
设计对象限定在组织自身结构；不参与与撤回真实可用；伦理先于结构与感官层；透明性与可逆性可运行；因果通路可说明；指标以束使用；实施分阶段；沉默和余白不被自动视为缺陷；公开摘要与内部程序分离。

## Failure conditions
把沉默固定解释为拒绝或同意；把理论转为心理操纵或强制收敛；先优化感官再补伦理与结构；局部接点优化破坏整体律动；指标变成人员排名；编造隐藏公式或阈值；阶段导线变成不可逆漏斗。

## Falsification conditions
如果结构一致性提高后，自发再访或咨询长期下降，共识时间、位相稳定、RC、CEA持续恶化，同调压力或有害锁定增加，或不同接点的认知差扩大，应修订沉默共识假设、律动核心、观测束和公开边界。不能把反应不足归咎于受众，以逃避反例。
