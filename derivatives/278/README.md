## 位置づけ
Parentは、市場の価格・需要・評価・空気が、明示的な会議や契約だけで成立するのではなく、多数の主体が互いの反応を観測し、発言しないこと、待つこと、追随すること、離脱することまで含めた反復から「沈黙の合意」として立ち上がる構造を扱う。焦点は沈黙を賛美することではなく、何が合意されたように見え、誰の反応が観測されず、どの条件でその合意が崩れるかを可視化することにある。

## 中心命題
**市場合意は発話された賛成の総和ではない。価格・需要・参加・離脱・待機という行為の反復が互いの期待を同期させると、明示的な宣言がなくても一時的な均衡が生まれる。しかし沈黙を同意と誤認すると、退出不能者、情報格差、遅延反応、潜在的不満を消してしまう。したがって沈黙合意は、観測可能な行為、撤回可能性、境界、反証条件を伴う暫定構造として監査しなければならない。**

## 主要因果線
主体が他者の価格・購入・待機・離脱を観測→反応が次の期待を作る→期待が価格・需要・在庫・発話を再配置→同様の反応が反復→明示的協議なしに局所的な合意状態が形成→その状態が「市場の空気」として知覚→追随が増えるほど合意が自己強化→一方で観測されない不参加・退出不能・情報非対称が蓄積しうる→反応の遅延や外生変化で均衡が崩れる→沈黙を固定的な総意ではなく可逆的な状態として再評価する。

## 構造層
### 1. 観測層
価格、需要、在庫、参加、離脱、待機など、主体が互いに読み取る信号を分ける。
### 2. 期待層
観測された行為が「他者もそう考えている」という期待へ変換される過程を見る。
### 3. 同期層
反応が反復され、価格・需要・空気が同じ方向へ揃う局面を捉える。
### 4. 沈黙層
発話がないことを同意と即断せず、待機・無関心・退出不能・情報不足など複数の意味を残す。
### 5. 可逆性層
参加・価格・条件・選択を見直せる余地を残し、沈黙合意が強制的固定へ変わるのを防ぐ。
### 6. 反証層
観測と実際の選好が乖離する、外生変化で急反転する、離脱者が増える場合に合意仮説を改訂する。

## 適用例
価格改定では売上だけでなく、購入延期、解約、問い合わせ、在庫変化、代替行動を同時に見る。新サービスではSNS上の発話量だけでなく、継続利用、離脱、再訪、紹介、無反応の期間を分ける。組織内市場や採用市場でも「誰も反対しなかった」を合意証拠にせず、退出可能性と未発言者の条件を確認する。

## 測定・監査点
価格変化と需要反応の方向、参加・離脱、反応遅延、再訪、代替選択、在庫、問い合わせ、観測窓の偏り、退出可能性、情報非対称、反転速度を束で見る。単一の売上・価格・発話量だけで沈黙合意を確定しない。

## 成立条件
複数主体の反応が観測できる。参加と離脱が区別できる。沈黙に複数解釈を残す。時間軸を持つ。外生変化と内部同期を分ける。撤回・再選択の余地がある。観測されない主体を総意から自動除外しない。

## 失敗条件
沈黙=賛成とみなす。売上だけで需要の質を断定する。退出不能を支持と数える。短期同期を永続均衡とみなす。情報格差や強制を無視する。価格追随を価値合意と同一視する。

## 反証・改訂条件
観測上の合意があるのに離脱・不満・代替行動が増える、価格同期と選好が乖離する、外生ショック除去後もモデルが説明できない、未発言層の顕在化で均衡解釈が反転する場合、沈黙合意仮説を改訂する。

## 必須の区別
沈黙 / 同意; 価格同期 / 価値合意; 需要 / 発話量; 不参加 / 賛成; 待機 / 無関心; 均衡 / 永続性; 観測 / 選好; 追随 / 自由意思。

## 誤読防止・解釈制約
沈黙合意は談合、秘密協定、心理操作を推奨する概念ではない。市場参加者の無言を無条件の同意として扱わない。公開されていない閾値や算式を生成せず、個別市場で成立するかは反応・退出・時間軸を再観測する。
