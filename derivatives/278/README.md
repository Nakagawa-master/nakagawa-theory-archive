## 位置づけ
本派生物は、注意・露出・説得を増幅する集客ではなく、組織側の構造律動を整えることで、市場の沈黙を「拒絶」から「整合待ち」へ読み替え、非強制のまま自発的合意が成熟する条件を整理する。設計対象は他者の心理ではなく、組織自身の周期・振幅・同期、倫理、構造、感覚、公開境界である。

## 中心命題
市場の沈黙は常に拒絶ではない。組織が理念・行為・接点・時間を同じ原理で反復し、周期・振幅・同期を整え、倫理的不可侵性→構造的必然性→感覚的共鳴性の順を守ると、外部は「次も同じ整合が来る」と観測しやすくなる。集客は声量を増やす行為から、沈黙の側で合意が熟す条件を壊さず維持する設計へ移る。

## 因果線
注意競争の激化 → 短期反応は得ても継続選択が弱くなる → 市場の沈黙を拒絶として誤読 → 露出・声量をさらに上げる → 接点間の語彙・テンポ・人格が乱れる → 構造律動が薄くなる → 周期・振幅・同期を同一原理へ戻す → 公共性・透明性・可逆性を先に置く → 因果整合・束指標・段階拡張で構造的必然性を保つ → 間・拍・自己編集余地を残す → 市場側の惰性周期・内的閾値・無意識整合と同期点が生じる → 沈黙が整合待ちへ変わる → 再訪・相談・紹介・自発説明などが生じる → 一次ログと束指標で観測 → 過熱・同調圧・誤配が出ればT/S/Rで冷却・撤回・再合意 → 長期の沈黙の合意へ戻す。

## 構造層
### 1. 構造律動
- 周期: 同じ原理が同じ拍で反復される安定。
- 振幅: 情報量や声量ではなく、在り方・関心・編集の深さ。
- 同期: Web、資料、面談、CSなどが同じ人格・原理へ戻れる一貫性。

### 2. 市場の沈黙
- 惰性周期: 変えないことの安定。
- 内的閾値: 切り替えを許容する最低条件。
- 無意識の整合: 説明以前に「合う」と知覚される整合。

### 3. 「無視できない理由」の三層
1. 倫理的不可侵性: 公共性・透明性・可逆性。
2. 構造的必然性: 因果整合・束指標・段階拡張。
3. 感覚的共鳴性: 間・拍・相手側の自己編集余地。

## 状態モデル
`attention_competition -> silent_indifference -> rhythm_misalignment_detected -> periodicity_amplitude_sync_restored -> ethical_integrity -> structural_necessity -> aesthetic_resonance -> silent_alignment_window -> voluntary_response -> bundle_audit -> TSR_cooling_or_reagreement -> durable_silent_consensus`

## 適用例
公開発信では曜日・時間・分量・トーンをむやみに変えず、乱れた場合は元の拍へ戻す。接点設計ではサイト・資料・面談・CSの導入基調、語彙、余白を照合する。営業では議題間に沈黙の観測窓を置き、未発言の違和感を回収する。集客導線は軽い相談→小規模検証→本契約のように段階的で撤回可能にする。公開は成功・失敗とも因果通路を抄録化し、内部閾値や固有ログを出さない。

## 測定・監査点
UCI、REI、UCI-i等は単一ランキングではなく、接点一貫性、自発行為、局所共鳴の傾向を束で見る補助概念として扱う。加えて再訪、合意到達時間、位相安定S、RC、CEA、過熱、同調圧、観測窓の開放、撤回可能性を確認する。短期クリックや表示回数だけを成功条件にしない。

## 成立条件
- 組織自身の周期・振幅・同期を設計対象とする。
- 市場側の反応を直接操作対象にしない。
- 倫理→構造→感覚の順を崩さない。
- 公共性、透明性、可逆性が実際の選択・撤回で機能する。
- 因果通路を説明でき、単一指標へ潰さない。
- 小さく試し、合えば段階拡張できる。
- 沈黙と余白を欠陥として埋めない。
- 公開抄録と内部詳細の境界を保つ。

## 失敗条件
沈黙を拒絶と決めつけ露出・広告・声量を増幅する。「沈黙の合意」を心理操作、暗示、強制同調へ変える。感覚層から先に作り倫理・構造を後付けする。接点ごとの局所最適で全体律動を壊す。UCI/REI等を個人査定や外部競争へ使う。公開していない閾値・算式・操作手順を推測する。段階導線を不可逆な囲い込みへ変える。

## 反証・改訂条件
周期・振幅・同期を整えても再訪や自発的接触が持続的に悪化する、合意到達時間が伸びる、位相安定が低下する、RC/CEAが悪化する、同調圧・過熱・有害ロックインが増える、接点間の認知差が拡大する場合は、沈黙の合意仮説、律動核、観測束、公開境界を改訂する。市場反応の不足を「相手が理解できない」ことのせいにして反例を排除しない。

## 必須の区別
沈黙 / 拒絶; 合意 / 服従; 非強制集客 / 心理操作; 周期 / 投稿量; 振幅 / 声量; 同期 / 画一化; 倫理 / メッセージ装飾; 構造的必然 / 不可避な購買; 感覚的共鳴 / 暗示; 束指標 / 単一ランキング; 段階拡張 / 囲い込み; 公開抄録 / 内部ログ。

## 誤読防止・解釈制約
「無視できない理由」「必然」「沈黙の合意」という強い語を、他者が拒否できない心理状態の設計へ変換しない。原典が設計するのは組織側の整合条件であり、外部主体の自律・不参加・撤回は残る。具体例の30秒、30〜60秒、曜日・時間等を普遍閾値へ昇格させない。未公開の評価式、重み、内部数値、操作手順を補完しない。
