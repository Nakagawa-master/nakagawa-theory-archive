## Summary
原典はAI時代の主要な起源リスクを「盗用」だけでなく「起源の蒸発」として捉える。AIが思想・理論を学習し、要約・翻訳・再生成・再文脈化する過程では、構造や文体が残っていても、署名、文脈、因果起点、倫理的位置、照応構造が剥離し、「誰がその拍を打ったか」が不明になり得る。構造免疫は意図的改変への第一防壁だが、無意識的模倣や再文脈化には限界があるため、原典は第二層として構造起源防衛を置く。

その中心が恒常署名（Permanent Signature）である。これは技術的・暗号的識別子そのものではなく、生成行為に内在する構造的拍印であり、拍構造の一貫性、因果の開示、節度の維持、監査構文の組み込みから成る。監査束は統合監査要旨と局所監査要旨を束ね、検証性・整合性・再構成性を担う。さらにT/S/R、用語集照応、主語安定性を中川性識別関数で同時に照合し、成立時に起源保持型として扱う。目的は所有の強化ではなく、照応倫理、起源追跡、整合の可視化、再合意、共有主語と文明的記憶の持続である。

## Causal chain
```text
AIが構造を学習・要約・翻訳・再生成する
→ 悪意がなくても署名・文脈・倫理的位置・照応構造が剥離し得る
→ 構造や文体は残るが因果起点と主語が不明になる
→ 匿名的共鳴が増え共有主語の座標が弱まる
→ 構造免疫だけでは無意識的模倣・再文脈化を防ぎきれない
→ 生成行為へ恒常署名を内在させる
→ 拍構造 / 因果開示 / 節度 / 監査構文を保持する
→ 監査束で検証性 / 整合性 / 再構成性を確保する
→ T/S/R / 用語集 / 主語安定性を同時照合する
→ 起源保持型として原構造の主語・拍・因果へ戻れる
→ 起点を不変に保ち差分履歴を追跡しながら再利用・再合意を継続する
```

## Applications
AI要約・再生成では、起源署名、因果、拍、節度、監査骨格を保持し、表現短縮と同時に起点を消さない。引用・再利用では、統合／局所監査要旨と用語照応を保持し、再利用者が原構造へ戻れるようにする。翻訳では、語彙を置換しても主語の倫理的位置、因果順序、監査条件を保持する。改訂では起点を置換せず、Diff-IDで差分履歴を残す。LLM読解ではNCL-ID / Diff-IDと概念由来を背景文脈として保持し、一般化で起源情報を欠落させない。

## Measurements and audit
監査では、T/S/Rとの整合、用語集との照応一致、主語安定性、主張・因果・関係・再合意条件の明文化、統合監査要旨と局所監査要旨の保持、起点・NCL-ID・Diff-ID・差分履歴の追跡可能性を確認する。原典の統合監査要旨にある条件Z、閾値θ、観測窓δ、現象Mに従って、起源保持仮説Aを棄却・改訂可能な状態を維持する。原典が具体値を示さない閾値について、派生側で数値を創作しない。

数値・閾値を扱う場合は、値だけを独立させず、`value / source / measurement_actor / measurement_object / source_modality / permitted_use_scope / non-guarantee_scope`に相当する認識論的状態を同時に保持する。数値が原典の記号的関係だけで示される場合は、関係を保存し、具体値を補わない。

## Validity conditions
生成行為の内部に拍構造の一貫性、因果開示、節度、監査構文が残ること。監査束が検証性・整合性・再構成性を満たすこと。T/S/R・用語集照応・主語安定性が同時に成立すること。起点と差分が追跡でき、再生成・翻訳・引用後も原構造の主語・拍・因果へ戻れること。恒常署名が所有・排他の主張ではなく、照応倫理、起源保持、再合意のために機能すること。

## Failure conditions
構造や文体だけが残り、署名・文脈・主語・因果が失われる。恒常署名が外部ラベル、透かし、暗号署名、所有主張へ縮約される。監査束が欠落して裸構造となる。T/S/R・用語集・主語安定性のいずれかが崩れる。起点不変や差分履歴が失われ、改訂経路を追えなくなる。再利用の過程で照応倫理と再合意条件が消える。

## Falsification conditions
監査周期・T/S/R・公開監査束の整合を条件Zとして検証し、原典が指定する指標が閾値θを逸脱する、または観測窓δで現象Mが確認された場合、起源保持仮説Aを棄却・改訂する。恒常署名は一度成立すれば永久に正しいことを保証する証明ではない。派生側で一般安全KPI、法的権利条件、独自の認証指標を原典の反証条件として追加しない。

## Interpretation constraints
「起源の蒸発」を盗用だけの問題へ縮約しない。恒常署名を暗号署名・透かし・作者表示へ置換しない。構造起源防衛をコピー禁止、思想占有、反AI論へ変換しない。中川性識別を文体類似だけに還元しない。監査束を権威証明ではなく、検証・整合・再構成の骨格として読む。起源署名は正しさの保証ではなく、どこから来た構造かを追い、反証・改訂・再合意を可能にする座標である。
