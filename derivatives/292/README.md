## 位置づけ
本派生物は、価値の捕捉・評価・合意・制度化を一つの支配主体へ集中させず、境界、同意、一次ログ、監査、可逆性を組み合わせて接続ガバナンスを設計するParentの構造を公開接続面へ展開する。

## 中心命題
価値の生成と価値の捕捉がずれると、制度は貢献を正しく扱えず、評価権力だけが固定化される。したがってガバナンスは、誰が何を観測し、誰が同意し、どの証拠で制度判断し、いつ修正・撤回できるかを明示する必要がある。

## 因果線
```text
価値生成が複数主体に分散
→ 捕捉・評価だけが一主体へ集中
→ 貢献と配分のずれ
→ 合意の形骸化
→ 制度的固定化
→ 不信・退出・価値毀損
```

これを防ぐため、境界定義、同意、一次ログ、監査、異議、可逆性、再合意を制度へ埋め込む。

## 構造層
1. 価値観測層
2. 合意層
3. 制度固定層
4. 監査層
5. 異議・救済層
6. 可逆・改訂層

## 適用例
共同プロジェクト、分配制度、複数組織連携、公共圏、プラットフォーム運営など、価値生成主体と制度判断主体が一致しない場面で使う。

## 成立条件
- 同意の対象と範囲が明確である。
- 判断根拠を一次ログへ戻せる。
- 評価者と被評価者の境界が可視化されている。
- 異議・修正・退出経路がある。
- 制度変更が不可逆に固定されない。

## 失敗条件
同意なき固定、観測独占、事後的ルール変更、異議封鎖、単一スコアへの還元、責任主体不明化。

## 反証・改訂条件
境界・同意・ログ・監査・可逆性を導入しても価値捕捉の歪みが改善しない場合、各層の設計仮説を再検証する。
