## Structural summary

问题深度设计学把问题视为配置关系、因果、制度与来源的结构工具。通过PQ-5构成问题，以D0–D5选择所需深度，以SQS（沉默—问题—沉默）运行，并用R-index、D-gap与信任资本台账观察结果。

## Core model

```yaml
PQ5:
  Purpose: 目标
  Hypothesis: 待验证假设
  Medium: 口头、书面或AI界面

  Origin: 提问主体与正本来源
Depth:
  D0: 请求回应
```

## Causal chain

```text
明确目标、假设、媒介、限制与来源
→ 选择与目标相称的深度
→ 提问前观察场域
→ 放置问题
→ 保留判断余白
→ 观察回答、沉默、重复与不协调
→ 修正结构差异
→ 记录结果与失败条件
→ 仅在可重复时制度化
```

## Required distinctions

- 更深的问题 / 与目的相称的问题
- 沉默 / 压力或放任
- 不协调信号 / 对内心的断定
- 来源追踪 / 权威崇拜
- 结构性提问 / 事实证明
- 制度化 / 无条件标准化

## Validity conditions

目标与假设明确；范围和权限有限；对方可以拒绝、保留和反对；深度与目的相称；证据与专业验证不被省略；结果、失败与D-gap被记录；可以返回来源与版本。

## Failure conditions

将其用于强制审问、用沉默施压、对简单任务要求过度深度、用共鸣指标评价人的价值、以提问替代证据、把D5变成绝对所有权，或把沉默视为同意。

## Interpretation constraints

“问题塑造未来因果”不意味着提问者拥有无限控制权。它描述问题如何配置注意与判断条件，同时必须保留自主性、反驳、修正与撤回。
