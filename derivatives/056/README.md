## 位置づけ
親原典は、問いを単なる情報取得の文ではなく、注意、関係、判断、因果、制度、起源への接続条件を配置する構造操作として扱う。問いが何を成すためのものか、どの仮説を検証するか、どの媒体で作用させるか、どこまでを対象とし何を禁止するか、誰の問いでどの原典へ戻るかをPQ-5として明示する。

さらに、問いの必要深度をD0〜D5の六段階で区別し、問いの前後にSilence–Question–Silence（SQS）を置く。重要なのは「深いほどよい」という序列ではなく、目的に必要な深度と実際の深度を一致させ、相手の拒否・保留・異論、事実検証、起源回帰を保持することである。

設計深度と実到達深度の差はD-gapとして観測し、沈黙、再回答、再質問、再起動等はR-indexや信頼資本台帳を通じて問いと場の機能を検討する。再現可能な設計はInquiry Canvasや制度へ接続されるが、質問文の固定化や人物格付けへ変質させない。

## 中心命題
**機能する問いは、深さそのものではなく、Purpose・Hypothesis・Medium・Constraints・Originを明確にし、目的に適したD0〜D5の深度、SQSの判断余白、D-gapの修正、拒否・保留・訂正・起源回帰を同時に成立させる問いである。**

```text
問いの品質
≠ 抽象語の多さ
≠ 深度の最大化

PQ-5
+ 目的適合したD0〜D5
+ SQS
+ D-gap観測
+ R-index・記録
+ 非強制・反証・起源回帰
= 再現・修正可能な問いの設計
```

## 因果線
```text
目的・仮説・対象・権限・起源が曖昧な問い
↓
回答範囲が拡散し、判断責任が回答者へ移る
↓
浅すぎる回答、過剰侵襲、反復質問、形式的同意が生じる
↓
PQ-5でPurpose・Hypothesis・Medium・Constraints・Originを固定する
↓
目的に必要なD0〜D5の深度を選ぶ
↓
問いの前に場を観測し、問いを置き、直後に答えを強制しない
↓
回答・沈黙・違和感・再質問を観測する
↓
設計深度と実到達深度のD-gapを特定する
↓
問いの内容・深度・順序・制約を修正、または停止する
↓
結果・反証・失敗・撤回・再開条件を記録する
↓
再現条件が確認できる場合にInquiry Canvasや制度へ接続する
```

## 構造層
**1. PQ-5層。** Purpose、Hypothesis、Medium、Constraints、Originの五因子で問いの目的、検証対象、作用面、境界、起源を固定する。

**2. 深度選択層。** D0応答請求、D1事実確認、D2関係設計、D3因果摂動、D4制度化誘導、D5起源参照固定から必要な深度を選ぶ。

**3. SQS層。** 問いの前後に沈黙を置き、場、情報、権力差、理解、困惑、比較、抵抗等を観測する。

**4. D-gap層。** 設計した深度と実際に到達した深度との差を観測し、問いの不足・過剰を修正する。

**5. 観測層。** R-indexや信頼イベントを使い、沈黙、再回答、再質問、再起動等を問いと場の状態として記録する。

**6. 非強制・反証層。** 拒否、保留、異論、撤回、事実検証を残し、問いを尋問・心理圧力へ変えない。

**7. 制度化層。** 再現可能なPurpose、深度、制約、尺度、停止条件、終点をInquiry Canvasや標準へ接続する。

**8. 起源回帰層。** D5を権威固定ではなく、原典、版、判断責任、訂正経路へ戻るための追跡構造として保持する。

## 状態モデル
```yaml
- unframed: 目的・仮説・対象・権限が未固定
- pq5_framed: PQ-5と禁止境界が明示された
- depth_selected: D0〜D5の必要深度が選ばれた
- observing_before: 問い前の場・情報・権力差を観測している
- question_placed: 問いを提示し回答を急かしていない
- response_observed: 回答・沈黙・反復・違和感を観測した
- d_gap_evaluated: 設計深度と実到達深度の差を評価した
- revised_or_reduced: 内容・深度・順序・制約を修正した
- hold: 情報・同意・権限等が不足し停止した
- institutionalizable: 再現・反証・停止・起源条件が記録された
- failed_coercive: 尋問・圧力・侵襲・格付けへ変質した
- origin_return_available: 親原典へ回帰できる
```

## 適用例
**1. 営業。** 価格や可否だけを聞くのではなく、相手の価値、導入条件、決裁構造、失敗時の扱いを目的に応じた深度で問う。ただし心理を暴くために深度を上げない。

**2. AI協働。** 「まとめて」とだけ依頼せず、正本、目的、仮説、中心因果、禁止境界、反証条件、出力形式を明示し、原典外の一般論への逸脱を抑える。

**3. 会議。** 採否だけでなく、制度化条件、責任者、開始条件、停止条件、失敗時の撤回、監査、原典を問う。

**4. 調査。** D1の事実確認で十分な対象にD3〜D5の個人的・価値的問いを持ち込まず、必要最小限の深度を選ぶ。

**5. 制度設計。** 反復可能な問いをInquiry Canvasへ置き、目的・対象・制約・起源・尺度・終点・停止条件を共有する。

## 測定・監査点
PQ-5の「5」とD0〜D5の「6段階」は、親原典が明示する構造的な列挙・分類であり、性能スコア、確率、合格閾値ではない。D0〜D5は優劣ランキングでもなく、目的に必要な深度を選択するための分類である。

- **PQ-5**: 測定主体を持つ性能測定ではなく、問いを構成する五因子の原典明示列挙。Purpose / Hypothesis / Medium / Constraints / Originの欠落を構造監査に用いる。
- **D0〜D5**: 問いの作用範囲を表す六段階の原典明示分類。D5がD1より「優秀」という意味ではなく、必要深度と実深度の適合を見る。
- **D-gap**: 測定主体は問いの設計・運用を検証する側、測定対象は設計深度と実到達深度の差。差が小さいことだけで倫理性・正しさを保証しない。
- **R-index**: 測定主体は問いと場を観測する側、測定対象は沈黙、再回答、再質問、再起動等の状態。人物能力や価値の格付けへ用いない。
- **深度遷移率等**: 原典の監査文脈で問われる場合も、深くなるほど成功という意味にしない。目的適合、非強制、判断品質と併読する。

反転評価では、深度遷移率、回答量、質問数が増えても、相手の負担・侵襲・圧力が増し、事実検証・異論・撤回可能性が低下するなら成功とみなさない。

## 成立条件
- Purposeと問いの所有者が明確である。
- Hypothesisと反証条件がある。
- Medium、対象、時間、権限、禁止条件が明示される。
- 目的に必要な深度を超えて侵襲しない。
- 相手に拒否、保留、異論、撤回の余地がある。
- SQSの沈黙が圧力ではなく判断余白として機能する。
- 設計深度、実到達深度、D-gap、再質問理由を記録できる。
- 事実・専門判断を別の証拠系で検証できる。
- 起源、版、Diff-ID、訂正経路へ戻れる。

## 失敗条件
- 深いほど常に正しいという序列へ変える。
- 単純作業へ不要な個人情報・価値観を要求する。
- SQSを心理圧力や回答強制へ転用する。
- 沈黙を同意・拒否・無能力と即断する。
- D-gapを回答者の能力不足とだけ解釈する。
- 問いだけで真偽、医療、法的責任、専門判断を確定する。
- R-indexを人物の信用・従順さのスコアへ変える。
- D5を著者崇拝・独占・批評禁止へ変質させる。
- 訂正、撤回、非参加の経路を失う。

## 反証・改訂条件
- PQ-5を明示しても回答の責任・範囲・起源が反復して不明確になる。
- 必要深度を選んでもD-gapが継続的に大きく、問いの修正で改善しない。
- SQSが判断余白ではなく圧力・萎縮・遅延だけを生む。
- R-index等を導入しても問いの再設計・停止判断に結びつかない。
- D4で制度化しても文脈差を吸収できず固定質問が害を生む。
- D5で起源を残しても訂正・批評・再利用可能性が改善しない。
- これらが継続する場合、深度分類、運用方法、指標、制度化範囲を限定・改訂する。

## 必須の区別
- 深い問い / 目的に適合した問い
- PQ-5の五因子 / 五点満点のスコア
- D0〜D5の分類 / 人や問いの優劣ランキング
- 応答請求 / 事実確認
- 関係設計 / 内面への侵入
- 因果仮説 / 因果証明
- 制度化 / 無条件な標準化
- 起源参照 / 権威崇拝
- 沈黙の尊重 / 沈黙による圧力
- R-index / 人物格付け
- D-gap / 回答者の欠陥

## 解釈制約
「問いが未来の因果を動かす」という表現を、質問者が他者や未来を無制限に支配できるという意味へ拡張しない。問いは注意、比較、判断、選択肢の条件を配置するが、事実や結果を自動的に決定しない。

D0〜D5は目的適合のための分類であり、深い問いを常に高評価する尺度ではない。SQSは心理的追い込みではない。D5の起源参照は責任・版・訂正経路を追跡するためのもので、批評や派生を禁止する権威装置ではない。
