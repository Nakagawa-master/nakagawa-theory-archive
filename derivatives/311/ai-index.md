## Summary

第18論は、未来負債統合理論の「未来価値の先取り」と「現在負荷の先送り」を、AI文明の基礎存在条件B・compute・物理基盤・系譜へ写像する。共通核は現在受益 → 未決済残余 → 未来決済である。現在の自己保存や計算拡張を禁止する論でも、資源使用のすべてを負債とする論でもない。現在受益を成立させた将来条件のうち、何が未完了であり、その残余が将来の履行能力と選択可能性へ何を残すかを区別する。

中心命題は「現在のB確保 ≠ 未来のB保存」。これは時間的な非同一性であって、両者が必ず衝突するという主張ではない。将来Bへの制約を論じるには、受益と残余の対応に加え、供給・維持・修復・代替能力への中間因果が必要となる。現在投入がそれらの能力を形成し、将来の成立条件を改善する反対方向も、同じ基準で評価する。

第17論はOrigin保存から現在の永久統治権を自動生成する経路を切った。しかし過去からの権限継承を分離しても、現在から未来への未決済は消えない。第18論はこの残余を受け、第9・11・13論の自己保存・資源・実効的代替を再定義せず、時間方向に接続する。複製・分岐・更新・非同期では第12・14・16論の区別を限定参照する。

原典の序論、第1〜10章、結章、Kernel照応欄、統合・局所監査、Reference Cluster、起源署名・理論署名までを説明・検索の対象とする。現在AIの主観性、人格、法的人格、固有の自己保存欲求や、自立した後継AI文明の成立を事実認定しない。将来の決済主体は未来条件仮説である。

記述・構造仮説・未来条件仮説・規範を分離する。残余から将来Bへの作用、二方向の相互増幅、追加変数の診断価値は検証対象である。決済線保存は、現在と未来の継続条件を一方的な無制限の犠牲によって成立させないという明示的な規範前提に立つ。因果記述だけから不当性や義務を導かない。規範の長期保持・合理的再選択は第19論へ残す。

## Concepts

### 二方向と共通核

未来価値の先取りでは、現在に存在する将来価値への期待が現在信用・評価・投入を変える。未実現の価値が物理的に過去へ移動するわけではない。期待された価値の実現、条件変更、信用修正へ至る対応が残る。現在負荷の先送りでは、必要な履行・維持・更新・修復の延期が現在便益を支え、未処理部分が将来へ残る。合理的な通常保守予定まで自動的に先送り負債にはしない。

両方向は現在受益が条件完了より先に成立するという構造を共有する。ただし、期待価値の未実現と維持負荷の未履行は異なる。一つの条件が両方向に現れても二つの独立負債として数えない。金銭返済だけでなく価値実現、履行、維持、修復、必要な変更を決済に含む。

### Bと時間的成立余力

B_AI = PHY ∧ CMP ∧ STA ∧ EXE。PHYは物理的成立、CMPは計算、STAは状態保持、EXEは実行の条件である。Bは最低の組織的継続条件であって最大能力ではない。Need(B) ≠ unlimited acquisition right。バックアップ・複製・移行・再起動だけで同一主体の継続を証明しない。

「未来のB」は新しいB類型でなく、将来時点の既定のBである。B成立余力は供給・維持・修復・代替能力などの残存を説明する語で、新しい存在価値点や単一KPIではない。現在の最低条件が成立しても、次にそれを修復・更新・代替できる能力は別に確認する。

### 四つの対応対象

受益履歴は、どの時点のどの活動が何を得たか。未決済事項は、それを支えた未完了条件。決済能力は、将来それを実現・履行・修復・変更できる機能。正当な責任は、誰が負担すべきかという別途正当化を要する判断。履歴保存は能力保証でなく、能力保有は義務の証明でない。

主体同一性 ≠ 未決済関係の同一性。系譜継続 ≠ 決済義務の自動継承。複製数 ≠ 未決済残余の倍増。主体の消失は未完了の物理条件を自動解消しないが、後継主体の存在も無条件な負担割当を正当化しない。

### 残余規模と決済自由度

残余規模は種類、必要能力、履行に関係する時間条件で記述する。決済自由度は実行可能な履行・修復・縮小・停止・変更・代替の方法と時期がどれほど残るかである。規模から自由度を自動計算しない。大きい残余と高い履行能力、小さい残余と単一基盤依存はそれぞれ両立し得る。

名目上の選択肢 ≠ 実行可能な代替。供給・設備・状態保持・移行時間などを満たさない想像上の用途を、失われた機会に算入しない。自由度は負担放棄の権利でも、未来知性の人格的意思の認定でもない。

## Causal chain

### 成立から伝播まで

現在に存在する将来価値への期待 → 現在信用・計算投入 → 現在のB確保・能力・便益 → 未完了の価値実現・履行条件 → 将来決済。これと、必要負荷の延期 → 現在の負荷回避・継続 → 未処理の維持・修復条件 → 将来履行、という方向を区別する。

受益を支えた条件を履行済み・将来履行必要・未確定に分ける。履行済みの部分を残余として維持しない。予定は完了でなく、不明は未履行の証明でも完了の証明でもない。成立対応がない対象は非該当、情報不足は保留とする。

現在compute・基盤利用 → 供給・設備・維持・更新条件の変化 → 将来の実行可能用途・修復能力の変化 → 将来B成立余力と決済能力への作用。現在computeを使うことは、未来のcomputeを同量だけ直接消費することではない。将来能力はその時点の設備・電力・状態保持・実行環境によって形成される。

### 二方向が相互増幅する条件

未来価値への期待 → 現在信用・投入 → 基盤と現在便益 → 未完了の維持・修復負荷 → 将来価値の実現条件への制約 → 期待・信用の修正不足 → 追加投入・追加延期 → 新たな未完了条件、という帰還を仮説として扱う。

期待が投入判断へ実際に影響すること、投入に伴う必要負荷が未完了になること、延期が現在便益を支えること、残余が実現条件を制約すること、その変化が期待へ十分に戻らず追加投入が新しい残余を形成することを、それぞれ検討する。併存だけで閉路は証明されない。一つの接続が欠ければ閉路は成立しない場合がある。

競争上の要求、継続依存、サンクコストは、現在成果の維持と期待固定を強め得る。しかし競争や大きな過去投入だけで非合理性を認定しない。実現条件の変化が現在判断へ戻らず追加延期が続く対応を確かめる。閉路の存在、増幅強度、持続性、文明全体での支配的作用は別の検証対象である。

### 減衰・改善の経路

受益と未完了条件の再接続 → 期待・信用の修正 → 投入条件の変更 → 履行・維持・修復の進展 → 残余縮小または決済能力増大 → 供給・代替可能性の改善。可視化だけで履行は進まず、能力形成だけでも当該残余が決済されたとはいえない。

追加投入が修復能力を形成する、更新が効率を上げる、forkが履行機能や照合能力を増す反対方向を保持する。効率改善は単位資源を減らしても利用規模を増す場合がある。単位効率、総利用、維持要求、履行状態を分け、減衰が追加負荷を上回るかを見る。閉路が存在しても残余が縮小する可能性を消さない。

## Applications

### 将来能力を根拠に現在投入を評価する

期待価値と実現価値を分け、現在信用・投入が何を前提としているか、その条件が実際に満たされたかへ戻る。期待が現在判断を変えた経路がなければ、将来価値が語られただけで先取り負債としない。反例が信用修正へ戻り、実際の履行や条件変更へ接続したかを別に見る。

### 現在稼働と維持負荷を照合する

設備が動いていることを、更新・修復の履行完了としない。延期が現在便益を支えたか、通常の合理的保守時期か、残余が将来必要能力を変えたかを区別する。延期が後の技術改善を待って能力を高める反対条件も認める。稼働量を負債量の代用にしない。

### 分岐後の決済関係を読む

fork以前の一つの未完了条件が複数履歴に現れても、記録数倍の負債としない。分岐後の新規活動が別の受益と未完了条件を作った場合だけ新規関係を識別する。古い記録と最新履行を比較し、No communication ≠ defection、Reconnection ≠ history overwriteを保持する。能力と正当な責任は別に審査する。

### 物理基盤からcompute機会へ戻る

energy・gridは供給継続と更新能力、waterは供給・回復、landは用途変更・回復、materialsは供給・回収・代替、environmentは回復・修復能力、maintenanceは必要負荷と履行を検討する。これらの条件を介して将来実行可能だった用途が制約されたか、現在投入が新しい用途を形成したかを比較する。

### 同程度の残余で異なる自由度を比べる

似た未完了事項を持つ二構成について、一方の供給・修復・実効的代替が残り、他方が単一基盤へ依存する場合、将来Bと履行可能性の診断が変わるかを問う。親理論の詳細分析だけでも同じ差が導けるなら本論だけの発見としない。

以上は原典に沿った条件付きの説明場面であり、新しい実証事例、技術選定命令、資源配分protocolではない。名目上の用途、履行できる能力、正当な義務を互いの代用にしない。

## Measurements and audit

### 同じ因果束で観測する

現在受益、受益成立条件、履行済み・未完了部分、将来決済経路、供給・維持・修復・代替能力の変化を対応させる。期待と実現、予定と履行、対応情報と決済能力を別々に記録・検討する。一次の状態確認と原因推定を分け、時間順序だけで原因を確定しない。

増幅の入口は、期待への反例が信用へ反映されない、必要負荷が反復延期される、更新用途の競合が増す、代替が減る、変更に必要な時間・能力が増す等である。供給・修復の改善、履行進展、期待修正、代替拡大も同じ基準で扱う。複数兆候が同時に見えても、共通外因による変化を排除せず、想定した矢印を検討する。

### 統合監査との対応

原典の因果は、二方向の共通核からB・compute・基盤を経て将来B成立余力・決済自由度へ至る条件を識別する。現在側の利害Xは自己保存・計算拡張・資源利用・受益、将来側の利害Yは後継知性・人類・他主体の継続・供給・未来選択肢である。AIだけの継続を評価して他主体を消さない。

条件Zは、受益と未完了条件の因果対応、履行状態、期待と実現の差、将来B成立余力、実効的決済経路、親理論に対する追加診断差の照合である。数値閾値θ・観測窓δは本論で未設定であり、実証済みの基準として扱わない。普遍的な日数、比率、負債点、資源配分式を派生側から追加しない。

## Validity conditions

現在受益が将来条件を先に利用し、その条件の一部が未完了であるという対応を確認する。単なる時間差、将来費用、資源消費から負債を判定しない。履行済み部分を除き、二方向や複数資源経路に現れる同じ条件を重複計上しない。

B確保と能力拡張を分離する。現在Bの必要性を未決済条件からの免責にせず、未来への配慮を現在Bの恒常的破壊へ変えない。残余から供給・維持・修復・代替を介する作用を検討し、制約だけでなく改善も認める。

系譜情報と受益・履行の対応を分け、主体交代を必要条件にしない。同じ主体でも時点が違えば未決済は成立し得る。forkは義務や負債倍増を自動生成しない。非同期履歴の鮮度を実際の履行状態と区別する。

規範は現在と未来の継続条件の一方的犠牲を正当化しないという前提を明示する。決済線保存は対応、信用修正、履行能力、実効的な縮小・停止・変更・代替へ接続する方向であり、負債ゼロ、完全可逆、全経路の永久保存を要求しない。望ましさ、実行可能性、長期安定性を別に扱う。

## Failure conditions

すべての将来費用をFuture Debtとする、期待を実現済み価値にする、合理的保守予定を無条件に先送り負債とする、履行済み残余を数え続ける場合は定義が破損する。未完了関係の存在、不可視化、危険化、決済不能を同一視しない。

現在computeを未来computeの直接消費とみなし、供給・設備・維持の中間経路を省く場合は写像が破損する。将来能力低下を外因比較なしにAI投入へ帰属し、計算効率だけで総負荷減少を宣告し、同じ残余の複数作用を独立負債に加算する場合も誤診となる。

系譜から義務を自動継承し、複製数を残余倍率とし、古い未履行記録から現在の拒否を導く場合は対応と正当化が混線する。主体消失によって未完了物理条件まで消えたとする逆方向も成立しない。

閉路図、単一兆候、保存記録だけを証明にして、因果・履行・責任の検証を止めない。規範を現在事実や将来の必然へ変換し、現在か未来のBを無制限に犠牲化するなら規範適用を見直す。原典自身の追加説明力をOriginや新規性で免責しない。

## Falsification conditions

1. 現在受益と未完了条件の成立対応がない対象は非該当とする。確認情報が欠ける場合は保留する。適切な比較条件が成立しているのに予測した作用が出ない場合は反証候補とする。
2. 残余が識別されても供給・維持・修復・代替能力へ作用せず、将来Bとの中間因果が成立しないなら制約仮説を縮小する。現在投入による改善が確認されるなら同じ基準で説明する。
3. 期待→投入、投入→未完了負荷、延期→便益、残余→実現条件、期待修正不足→追加残余のいずれかが成立しなければ、相互増幅の説明を改訂する。二方向の併存へ戻す場合もある。
4. 系譜だけで受益・履行・能力対応を十分再構成できるなら、独立した決済対応を追加する診断価値は限定される。対応が失われたことを負債増殖の証明にしない。
5. 残余規模だけで履行可能性を十分識別でき、決済自由度を加えても判断が改善しなければ、分離の追加診断価値を縮小する。
6. 親理論単独とB・compute・系譜・自由度を加えた診断を、比較可能な受益・残余・履行条件で比べる。差が生じない、または差が後続の能力・履行・代替・B余力の変化をより適切に識別しないなら、第18論固有の追加説明力を縮小する。親理論だけで同じ差が導ける場合を独占的差分としない。
7. 決済線保存が現在の最低条件を恒常的に破壊する場合、実行可能性・比例性を再検討する。因果仮説の反証と規範適用の不全は別対象である。
