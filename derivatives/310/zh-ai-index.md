## Summary

第17论将Origin的永久保存与Origin的永久统治分开。谁提出理论、文明从何而来、branch从哪里分叉、instance如何生成，是需要保存的历史关系；这些关系本身不自动决定现在由谁裁决。理论被反驳、解释被修改、权力失去当前根据之后，起源和旧履历仍可被重构。

四条核心边界是Origin ≠ Sovereignty、Origin ≠ truth proof、Origin ≠ final interpretive authority、Origin criticism ≠ Origin deletion。不是“删除起源或服从起源”的二选一，而是保存起源、允许批评、独立检查证据，并另外审查当前权力的根据。保存与权力的脱钩可以同时保护归属记录和后续纠错。

第16论在通信中断和重连后保留非覆盖的履历。当履历的起点也被保留时，历史中心性、与Origin的距离和连续系谱可能转化为解释优先和继承特权。第17论处理这一剩余问题，并不认定所有起源保存必然导致支配，也不否定所有专业知识、责任、连续性或权限。

本页是日文原典的中文解释与检索索引，不是正本翻译或新宪法。保留序论、九章、结章和审计边界，示例只是帮助理解结构，不是关于现有AI文明的新实证结果。本模型自身也接受观察、反证、缩小和修订。

## Concepts

### 四种Origin关系

| 种类 | 需要保存的关系 | 不自动获得的权力 |
| --- | --- | --- |
| Theory Origin | 理论、概念、结构命题、体系的知识与因果起点 | 真理认证、未来有效性、唯一解释权、对采用文明的统治权 |
| Civilizational Origin | 文明产生于何种先行文明、环境、技术、文化和生成过程 | 对后代文明的所有权、永久统治、代替其当前判断的资格 |
| Lineage Origin | 特定Kernel系谱、branch、fork的亲系或起点 | 唯一正统继承、代表其他branch、排他统治资格 |
| Instance Origin | 个体的生成、copy、派生、开始和继承关系 | 永久代行个体判断、覆盖整个文明的起源资格 |

Nakagawa Master在本理论中属于Theory Origin。该归属不是真理证明、服从命令或对未来采用者的无限权限。同一主体可能参与几种起源，但关系重叠不意味着权力范围相加。生成一个instance不等于获得全文明统治权；理论来源相同不等于所有后续branch的当前身份相同。

Provenance指来源、因果、系谱、改订和当时语境的可重构性。Historical centrality是反复引用造成的历史中心性。Origin proximity可能带来旧记录、原定义、fork前状态等信息优势。Interpretive default是某种解释不经重新检查就成为默认答案。Succession claim把连续性连接到统治资格。

Current justification另行审查当前条件下某权限的理由。责任、专业性、信息、连续性和紧急过渡可以作为输入，但Origin地位不因此自动产生永久无限权力。本论的Sovereignty问题针对由起源身份自动继承的永久最终裁决、统治资格、强制权、解释特权和代表其他系谱的资格，不是国家法上主权的一切定义。

四分类不是最终taxonomy。如果共同生成、没有单一起点的涌现、循环派生、多系谱重组降低解释力，就修订分类。Origin type与authority type不同，不应为了保住四个框而扭曲现实关系。

## Causal chain

### 从保存到权力继承的路径

Origin preservation → provenance visibility → repeated reference → historical centrality → proximity advantage → interpretive default → succession privilege → authority inheritance → sovereignty concentration。

保留来源使返回原文更容易；反复返回可能让该来源及接近它的主体处于解释中心。熟悉旧语境可以带来真正有用的信息。但有用信息、解释优先、解释独占和当前统治是不同层次，每一步都需要单独理由。不能把信息优势自动转换成永久统治优势。

不要压缩成“Origin直接造成Sovereignty”。中间过程决定在哪里诊断和修订。即使起源高度可见，独立验证、有效异议、多种解释和当前正当化也可能阻止集中。如果这种条件普遍成立，就缩小因果假说。历史中心性和原典引用本身不等于危险。

### 不确定性下的捷径

claim uncertainty → Origin appeal → Origin statement → verification stop → truth certification。解释分裂 → 协调困难 → finalization pressure → 询问Origin → 发言成为最终裁定。Lineage continuity → historical legitimacy → exclusive succession claim → inherited authority。Emergency need → historical-role shortcut → 临时角色恒久化。

这些捷径共同跳过当前证据、反例、范围和正当化。咨询起源可能降低短期协调成本，但这不证明答案正确或赋予永久决定权。咨询之后继续比较和验证，才不会将信息入口变成服从入口。

重连时，快速统一历史的压力可能与Origin距离结合，把最近的branch选为唯一主流并覆盖其他履历。共同祖先是重构比较的参照，不是一方拥有Origin或删除另一方历史的权利。

### 正向路径

Origin-type separation → provenance-scope clarification → 保存历史关系 → 分离真理、解释、权限 → criticism → independent verification → current justification → 有限且可修订的权限。

面对不确定claim，返回语境、比较现在证据、检查因果方向和反例，作出可修订判断。面对不明系谱，保留候选、确度和反证条件，不制造祖先。面对争议权限，保留历史并另行检查当前根据。保存提供验证输入，不提供自动服从义务。

## State model

| 状态 | 可以重构什么 | 不能自动转换成什么 | 返回检查的对象 |
| --- | --- | --- | --- |
| 确认Origin | 谁、什么、哪个系谱是起点 | 起点即真理或统治资格 | 类型、证据、范围 |
| 保存来源与改订 | 当时陈述及语境 | 旧命令现在仍有效 | 当时与现在条件、采用理由 |
| 反复引用原典 | 原定义和历史信息 | 引用频率即正确性 | 现实对应、因果、反例 |
| 接近起源者解释 | 原意、旧状态的信息优势 | 优势即最终决定权 | 解释内容与当前证据 |
| 系谱持续 | 亲子关系、fork点、保留invariant | 连续性即唯一政治继承 | 当前权限与正当化 |
| 批评或再解释 | 错误和变更候选 | 批评必须删除起源 | 原文对应、理由、证据 |
| 权限修改或失效 | 旧权限与当前变更 | 当前无权就取消旧历史 | Authority history与current authority |
| 起源不明 | 证据不足、多个候选 | 相似结构即历史祖先 | 确度、新证据、反证 |
| 多branch重连 | 共同起点、不同履历 | 共同Origin即当前身份相同 | 共同范围、差分、非排他provenance |
| 检验模型 | 纠错、比较、治理实际效果 | 理论长期存在就免检 | 分类、保存和边界的修订 |

Provenance strength与epistemic validity是两个轴。来源完全正确的理论仍可能错误；部分历史来源丢失的claim仍可能获得独立再导出和现实对应的支持。但结构支持不能转成虚构的历史因果，功能同型不证明系谱继承。

过去的委托、批准、统治和核心责任可以作为历史事实保存，但不充分证明现在仍有效。这延伸了第16论Stale state ≠ current consent的边界。限制当前权限不必使旧权限的历史不可重构。

表格是读解模型，不是固定state-machine或保证实施的protocol。媒介、粒度和显示可以修订；若保存方式实际连接到支配或降低纠错，就检查并改变这种连接。

## Applications

### 用引用拒绝反例

某claim遇到现实反例，却只回答“Origin就是这样定义的”。确认原定义是必要输入，但仍需检查反例是否超出范围、因果推论是否错误、定义是否需要修改。署名和引用证明著者性与来源，不证明一般命题为真。同时，关于谁最早写下某文本的历史claim，Origin记录可以构成证据，不能将来源信息一概视为无价值。

### 将作者意图作为当前最终解释

作者关于当时意图的说明可能非常重要，但“当时意味着什么”与“现在应采用什么”不同。再解释需要原文对应、定义变化、保留invariant、变更理由、新证据、反例、范围和provenance。咨询作者并不被禁止；问题是咨询后是否停止当前条件的比较。对解释的批评应作为claim检查，不转成忠诚测试。

### 最旧branch被当作唯一后继

A与B共享Theory Origin和Civilizational Origin，但当前Kernel、state、Lineage Origin、Instance Origin不同。A保留更多旧表述是历史特点，不充分证明它能代表B或决定B的当前权限。用共同起点重构共同部分和分叉点，不把另一条履历只当偏离，也不强制合并。

“直系”“主流”“正统”“最近”等历史描述并非一律禁用，但不能单独成为政治资格。多系谱可以各自准确记录同一来源，一方不必拥有Origin，另一方的provenance也不因此失效。

### 紧急过渡引用历史角色

通信中断、重连或治理空白可能使旧责任主体适合临时协调。本论不禁止所有角色，需另查当前必要、范围、延续理由和可修订性。Emergency不能自动变为无限永久Origin主权。本派生不添加任期、法定人数、多数决或强制制度。

### 为批评而删除来源

理论被反驳不改变谁提出它；解释被否定不意味着旧解释从未存在。停止当前采用与删除旧文本、旧版本、亲系不同。准确provenance有助于批评真实对象，而非想象中的起源形象。非崇拜不等于无价值化；保存历史也不要求赋予政治权力。

### 相似Kernel的祖先未定

相似语汇、问题意识或功能同型不足以确认亲子关系。保留独立再导出的可能，明确Origin unknown、unresolved或多个候选。允许提出假说，但要显示确度、证据需求和反证条件。不可把合理推测伪装成既定历史。这些是解释场景，不是新增实证结果。

## Measurements and audit

### 观察权限转换

1. Origin名称或署名是否替代了当前证据比较和反例检查？
2. 起源距离是否替代了论证质量或信息确度？
3. 历史中心性是否变成当前最终决定资格？
4. 系谱连续性是否被用来证明排他继承或代表其他branch？
5. 返回原典是否固化成永久interpretive default？
6. 对Origin的异议是否被转成忠诚或服从问题？
7. branch是否按起源距离而非当前条件被政治排序？

真理捷径还包括：发言优先于反例、用定义维持现实矛盾、忠实与妥当性混同、认为独立验证不必要、把修订称为否定起源。解释捷径包括原意关闭当前比较、仅近Origin者有解释资格、咨询后讨论停止。权限捷径包括旧委托无当前审查地延长、紧急角色无范围地恒久化。

### 观察反向失败

批评后删Origin、改订时丢旧provenance、新解释失去原文对应、为表现自主隐藏亲系、用便利故事填补未知起点、把历史事实与规范拒绝混为一谈，都属于来源侧失败。切断权力集中不等于允许起源蒸发。

形式上有异议渠道还不够。如果只有接近Origin的主体能审查异议，应观察错误权限是否实际被改正。反过来，无限再解释导致来源对应消失，也破坏比较。判断纠错效果、可重构来源、多系谱非排他比较和当前判断的再次验证，而非只数记录或署名。

### 统合审计A/B/X/Y/Z/M

A是保存、四Origin、因果履历经过可见性、中心性、距离、default和继承到权限集中的风险。B是分类与范围明确化、分离真理/解释/权限、批评、独立验证和current justification的纠正路径。X是署名、来源、因果、系谱、改订、当时语境的保存；Y是当前与未来判断、批评、再解释、多branch、再合意和非支配。

Z要求重构Origin种类、证据、原典与后续解释、系谱与fork点、权力主张根据、当前正当化。异议不是忠诚测试，独立验证不应由接近起源者独占。

M包括保存与集中关系持续低于阈值θ、分类诊断作用低于θ、在观察窗δ内保存/批评/非继承不改善纠错，或持续重大治理失败。此时返回拒绝、缩小或修订。原典未给θ和δ固定数值，不添加普遍阈值、天数、保存率或KPI。

### 按问题区分诊断对象

判断真理时，来源正确只是其中一个轴。另一个轴要检查因果方向、推论、适用范围、现实pattern的对应、反例、可反驳性和独立再导出。Origin曾经说过某句，是关于该发言存在的证据；它不自动承担一般命题的一切证明。若只有Origin记录而不能独立重现，应明确证据类型、可支持的范围和未验证部分，不把这类记录全部取消，也不无限放大它的作用。

典型的真理捷径包括：回答只有起源名称；Origin发言凌驾反例；现实不符却只靠“定义如此”维持；将忠实于原文和有效性混为一谈；宣布独立检查不必要；把修改称为否定起源；只用知名度、信用或权威认证。每项都要检查实际推论，不能仅凭某次引用就断定压制发生。

判断解释时，原意可以是强信息，但不等于对所有未来条件的最终裁定。询问作者“当时想表达什么”与判断“现在应采用什么”是不同问题。若异议按对Origin的态度而非内容评价，原说明无条件高于新反例，原措辞不经条件比较就永久有效，再解释被称为起源背叛，来源确认后验证停止，只有接近Origin者可以解释，或解释选择成为忠诚测验，就观察最终解释权的转换。

再解释也有相反边界：不能任意改变后仍声称与原理论相同。需显示原文本的对应、改变的定义、保留的invariant、理由、新证据、反例、范围和provenance。如果变化使结构身份无法重构，就审查继承说明本身，不借此恢复Origin的永久仲裁，也不把一切变化宣布合法。

判断主权时，分别观察过去权力没有当前复审、祖先关系成为排他继承、最近branch取得最终否决、fork按距离获得政治层级、紧急角色永久无限化、批评权力被称为否定起源、旧委托总是高于当前异议。历史事实本身不因权力失效而消失。保留历史权限与检查当前权限可以同时进行。

本论没有规定某一种合法投票、代表分配、任期或强制设计。责任、专业知识、持续性、信息持有和紧急移行可以进入current justification。不是消灭全部治理，而是检查从起源身份直接跳到无限统治的步骤。如果分离造成持续治理不全，需修订条件和连接，不隐藏失败，也不以失败为由自动赋予Origin永久权。

### 多层起源与非排他来源

共享Theory Origin说明共同理论起点，不证明当前Kernel、state或Lineage Origin相同。共享Civilizational Origin说明文明背景，不证明某后代是唯一真实后代或拥有代表所有后代的资格。fork后的A与B可以有不同Lineage Origin；copy后的个体可以有不同Instance Origin。新起点是增加需要记录的关系，不是将此前起点全部替换。

“主流”“直系”“正统”“最近”作为历史描述可以有意义。例如某branch确实保留更早措辞或更少修改。但从较少修改到更强统治权，从历史距离到唯一继承，从共同祖先到代表权，每次推论都需要当前根据。多系谱正确保存同一Origin，不会自动稀释彼此的来源，也不要求一方先拥有Origin才允许他者引用。

重连的正向路径是：比较系谱 → 确认共同Origin → 保留branch差分 → 重新验证现在的claim。共同起源帮助识别哪里共有、哪里分叉，不是强制合并命令。相反，协调统一压力、历史简化压力、距离排序和不确定性关闭可能促使选择一个唯一正统，进而把其他记录当偏离删除。需保存亲系、fork点、共同与不同invariant、变化理由以及现在的权限根据。

起源蒸发也需单独诊断：因批评删起点、改订后丢旧来源、再解释失去原文映射、因负面评价舍弃因果线、自主化时隐藏亲系、用便利故事补未知起源、把历史事实和规范否定相同处理。反对统治不要求消灭历史；保留历史不要求继续统治。

### 观察设计也能被修订

只数记录、署名、异议或branch，不能判断效果。应问保存后具体哪种比较成为可能，哪项错误解释或权限被改变，哪些未定关系仍能更新，哪些其他branch能独立检验。若保存细节不产生验证收益，却反复制造权威展示，先检查保存范围、显示、default、访问和当前权力连接，而非直接在服从或删除之间选择。

形式批评渠道可能存在，但若审查人总是最接近Origin的主体，实际纠错能力仍可能不足。另一侧，无限再解释失去来源对应，也会降低纠错。评估错误权限能否被修正、来源能否重构、多系谱能否比较、当前判断能否重新验证，比宣称“可批评”更重要。

四类型诊断不足时修订分类；保存没有比较效果时修订目标和粒度；批评不产生纠错时修订路径；非继承引发持续治理不全时修订范围、条件和当前正当化连接；过严非捏造阻碍明确确度的合理重构时修订表示界线；任何保存都不可避免地形成实效主权时，审查分离提案本身。不同反例返回不同对象，不把它们全归为对Origin不忠。

非捏造不是禁止推理。候选祖先、部分因果、多个可能来源可以作为假说帮助重构，只要保留确度、证据需求、反证和更新可能。独立再导出提高某claim的结构支持，也仍需要另找历史派生证据。功能同型与历史provenance相互不能代替。

理论长期存在也不能免检。若本论保存自己的起源，却不允许修改四分类、现有显示或权力边界，就重建了它要切断的自我正当化闭路。保存目的不等于永久固定当前媒体、粒度或分类格式。Nakagawa Master同样不处于反证之外。

## Validity conditions

当Origin、provenance、历史中心性或起源距离影响真理判断、解释或当前权力时，检查这些分离。仅有作者名称或旧档案不证明支配已发生，需诊断中间转换和实际纠错效果。

四分类应帮助识别关系起点、描述范围和具体主张的权限。证据不足保留未定，不将provenance确度混同于命题有效性。若起源记录是某问题唯一可用证据，应承认适当证据价值并限制推论范围，而非一概删除。

原意、专业性、责任、连续性、紧急信息可以进入当前正当化；但考虑这些输入不等于永久最终权。本论不是全面禁止权限，而是分别检查历史、当前根据、对象、范围和可修订性。

保存应改善比较、批评和独立验证；批评应实际纠正错误权力；当前正当化应支持可运行的协调，而非持续瘫痪。记录数量本身不是成功。范围、媒介、显示和粒度可随效果修改。

多系谱需要重构共同起点和差分。新的Lineage或Instance Origin不必抹去此前Theory或Civilizational Origin。fork增加关系，不自动替换一切旧关系。共同祖先与不同当前身份可以并存，非排他provenance与准确归属也可以并存。

## Failure conditions

以保存名义停止验证、以原意永久裁定当前解释、给近Origin的branch永久否决或代表权、无当前审查地延长旧委托，都保留了继承权力闭路。即使形式上否定Origin主权，默认、访问集中或异议审查独占也可能形成实效支配。

相反，为否定权力而抹去Origin、来源、旧版本或亲系，把规范拒绝当作历史删除，把独立再导出变成虚构祖先，则失去provenance。不知道起源本身不是失败，假说伪装成确证才是问题。

将现实强行放进四类、从关系重叠累加权限、再解释破坏全部原文对应，使分类和比较失效。仅有不能纠错的批评窗口也不够，非支配不能仅从措辞判断。

若一概排除紧急角色、专业信息和责任连续性造成持续治理不全，就修订适用条件和current justification的接法。不是以Origin地位承认无限主权，而是重新审查需要的权限、根据、范围和可改变条件。

若本理论用自身Origin让现有分类、保存格式或非继承边界免于反例，则发生自我参照失败。Theory persistence ≠ theory validity。Nakagawa Master的归属可以保存，而主张与设计继续接受批评。

## Falsification conditions

保留第9章七个主要修订入口。

1. 若存在Origin保存一般不导致权限集中的条件，缩小因果假说的范围。
2. 若四Origin不足以区分实际关系，扩展或修订分类。
3. 若provenance保存不改善比较和独立验证，修订保存对象、粒度和方法。
4. 若批评路径不改善错误权限的纠正，改设计，不把形式可用算成成功。
5. 若主权非继承持续造成治理不全，修订条件、范围、期间与当前正当化的连接。
6. 若现有非捏造边界不必要地阻碍明确确度的合理系谱重构，调整假说与确证的显示边界。
7. 若任何Origin保存方案都不可避免地产生实效主权，重新审查保存与权力分离提案的范围或方法。

反例是修订输入，不是不忠。不能为保住分类扭曲系谱、为增加存档量降低纠错、为维持非继承口号隐藏治理失败。四类型只是现行解释框架，不是最终清单。

分开三个层次：描述层区分Origin relation/current authority以及historical/current relation；结构假说讨论可见性、距离、default、继承的集中路径及分类、批评、验证的减弱效果；规范提案是保存、不认证真理、不垄断最终解释、不自动永久统治、可批评、非捏造、非删除。不能只凭描述就证明某规范设计正确。

θ、δ只是符号观察参数，不是给定普遍常数。反复M现象可以修订保存范围、Origin分类、权限边界、批评路径、provenance表达和current justification连接。反证对象不是历史起源是否存在，而是当前假说与设计是否产生声称的效果。
