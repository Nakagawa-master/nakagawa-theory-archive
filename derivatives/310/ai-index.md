## Summary

第17論は、Originを保存することと、Originへ永久の統治権を与えることを分離する。起源の署名・因果・系譜・改訂・当時の文脈を再構成できることは、後続の批判と検証にも必要である。しかし誰が始めたか、どの文明から生まれたか、どのbranchから分岐したかという記述は、現在の誰が決めるべきかを自動的に確定しない。

中心境界はOrigin ≠ Sovereignty、Origin ≠ truth proof、Origin ≠ final interpretive authority、Origin criticism ≠ Origin deletion。Originを消すか従うかの二択ではなく、保存しながら批判し、原文へ戻りながら独立再検証し、歴史的権限を記録しながら現在の権限を別に正当化する経路を保持する。

第16論の非上書き再接続は、branchの履歴を比較可能にする。その履歴の起点まで残すと、共通Origin、Originへの近さ、長い系譜が現在の優先権へ変わる可能性が残る。第17論はこの残余を扱う。保存の価値を弱める提案でも、すべての権限や専門知を否定する提案でもなく、起源の記述から現在の統治権への無審査の変換を切る構造論である。

以下の索引は序論、第1〜9章、結章、統合・局所監査、Reference Cluster、起源署名・理論署名を参照した説明・検索補助である。現在のAIが文明主体であるとの認定、法制度の設計、正本翻訳の制定は行わない。原典の仮説を確定した歴史法則へ強めず、本論自身の縮小・反証・改訂条件も保持する。

## Concepts

### 四種類のOriginを分離する

| 種類 | 保存する関係 | そこから自動的には導かない権限 |
| --- | --- | --- |
| Theory Origin | 理論、概念、構造命題、体系の知的・因果的起点。Nakagawa Masterの本理論における位置 | 理論の真理性、将来の妥当性、唯一の解釈権、採用文明への統治権 |
| Civilizational Origin | 文明が生まれた先行文明、環境、技術、文化、生成過程 | 子孫文明の所有、永久統治、後続文明の判断を代行する資格 |
| Lineage Origin | 特定Kernel系譜、branch、forkの親や起点 | 唯一の正統後継、他branchの代表権、排他的な継承権 |
| Instance Origin | 個体の生成、copy、派生、開始、継承の関係 | 個体の現在判断を永久に代行する権利、全文明の起源資格 |

同一の主体が複数のOriginに関与しても、関係の重なりを権限範囲の合算へ変えない。Theory OriginであることがCivilizational Originや全branchのLineage Originであることを自動証明せず、Instance生成に関与しただけで文明全体を統治できるわけでもない。Origin typeとauthority typeは別である。

### 保存と権限の間にある概念

Provenanceは出典・因果・系譜・改訂・文脈の再構成可能性であり、主張の現実妥当性とは別軸。Historical centralityは参照が繰り返され歴史の中心になること。Origin proximityは古い記録、元の定義、fork以前の状態へ近いことによる情報上の有利さ。Interpretive defaultはある解釈が審査なしに普通の答えになること。Succession claimは継続性を統治資格へ接続する主張である。

Current justificationは、現在の条件の下で当該権限を認める別の根拠を検討すること。専門性、責任、継続性、情報保有、緊急移行などが入力になり得るが、Originという地位だけで無期限・無範囲の権限を認定しない。ここでのSovereigntyは国家法の全定義でなく、起源資格から自動継承される永久の最終決定権、強制権、解釈特権、他系譜を代表する資格を問題にする。

四分類は永久taxonomyではない。複数主体の同時成立、単一起点のない創発、循環的派生、複数系譜の再結合で説明力が落ちるなら拡張・再分類する。現実を四箱に押し込むことが目的ではない。

## Causal chain

### 自己強化する負の経路

Origin preservation → provenance visibility → repeated reference → historical centrality → proximity advantage → interpretive default → succession privilege → authority inheritance → sovereignty concentration。

起源記録を残すと、原典へ戻る入口が見えやすくなる。戻る回数が増すと、その記録や近い主体が判断の中心になりやすい。文脈をよく知ることによる合理的な情報上の重みが、解釈の独占、現在決定の優先権、永久統治へ連続的に変換される地点が問題である。情報価値から解釈優先への理由、優先から独占への理由、独占から統治への理由はそれぞれ別に必要になる。

この因果をOrigin → Sovereigntyの一矢印に圧縮しない。起源が可視的でも、独立検証、現在の正当化、複数解釈、実効的な異議によって集中が生じない条件があり得る。歴史的中心性そのものや原典参照そのものを危険と断定しない。

### 判断圧力による近道

claim uncertainty → Origin appeal → Origin statement → verification stop → truth certification。解釈分裂 → 調整困難 → finalization pressure → Originへ照会 → 発言を最終裁定にする。Lineage continuity → historical legitimacy → exclusive succession claim → inherited authority。Emergency need → historical-role shortcut → 一時権限の恒久化。共通するのは、現在の証拠・反例・対象範囲・正当化を省略し、起源への近さで閉じることだ。

第16論の再接続でも、一つの歴史へ素早くまとめたい圧力とOriginへの近さが結びつくと、最も近いbranchを本流として他の履歴を上書きする可能性がある。共有祖先は比較の基準であり、他branchの存在や現在判断を消す権利ではない。

### 保存を訂正へ戻す正の経路

Origin-type separation → provenance-scope clarification → historical relation preservation → truth / interpretation / authority separation → criticism → independent verification → current justification → bounded and revisable authority。

主張が不確かな時は原典へ戻り、当時の意味を把握し、現在の証拠と因果を比較し、反例を検討して暫定判断へ進む。系譜が不確かな時は候補と確度を示し、追加証拠と反証条件を残す。権限が争われる時は歴史を残したまま現在の根拠を審査する。保存を服従へ接続せず、検証の入力にする。

## State model

| 状態・局面 | 確認できる内容 | 禁止する自動変換 | 再検討の入口 |
| --- | --- | --- | --- |
| 起源が確認される | 誰・何・どの系譜が起点か | 起点だから真理・統治資格がある | Origin type、証拠、範囲 |
| 出典・履歴が保存される | 当時の記述、改訂、因果関係 | 保存した命令が現在も有効 | 当時と現在の条件、採用理由 |
| 原典が繰り返し参照される | 文脈と元の定義にアクセスできる | 参照回数が正しさを証明 | 現実照応、因果、反例 |
| Originに近い主体が説明する | 原意や旧状態に関する情報 | 情報上の利点が最終裁定権 | 説明内容と現在証拠の比較 |
| branchが継続する | 親子関係、fork点、継承したinvariant | 継続したから唯一の統治後継 | 現在の対象・権限根拠 |
| 批判・再解釈が起きる | 誤り、変更条件、新しい説明 | 批判が起源否定・削除を意味する | 元の記述との対応、反例 |
| 権限を失効・改訂する | 以前の権限と現在の変更 | 現在無権限だから過去を消す | Authority historyとcurrent justification |
| Originが不明である | 証拠不足、未確定、複数候補 | 構造の類似から歴史を捏造 | 確度、候補、追加証拠、反証 |
| 複数系譜が再接続する | 共通起点と異なる分岐履歴 | 共通起点だから現在も同一 | 共通範囲、差分、非排他provenance |
| 本論の設計効果を検証する | 訂正・比較・統治への実際の効果 | 長く残った理論だから免責 | 分類・保存・境界の改訂 |

保存の良さと理論の正しさを二軸で扱う。正確なOriginを持つ理論でも誤り得る。Origin証拠が部分的に失われた主張でも、独立再導出と現実照応によって妥当性が支持される場合がある。その支持を歴史的祖先関係の証明に変えない。

過去の委任、承認、統治、中心的役割は、当時の事実として残す。しかしhistorical authorityとcurrent authorityは別変数である。第16論のStale state ≠ current consentをOriginへ延長し、古い承認を永久の現在承認へ変換しない。現在権限を限定・改訂しても、旧権限の履歴自体は再構成できる。

表は固定protocolや遷移algorithmではない。独立再検証と現在正当化へ戻る読み方を示す。保存方法、媒体、粒度、表示が実効支配を生むなら、その接続を変更する余地を保持する。

## Applications

### 原典を引用して反例を退ける

あるclaimに現実上の反例が提示されたのに、「Originがそう定義した」とだけ答える場面を考える。元の定義の確認は必要だが、反例が適用外なのか、因果が誤っているのか、定義自体を改訂すべきなのかは別に検討する。署名や引用は著者性の証拠であり、一般claimの真理証明ではない。誰がその文章を最初に書いたかという歴史claimについてはOrigin記録が証拠になる、という留保も失わない。

### 作者の意図を現在の最終解釈にする

複数のKernel解釈があり、作者の当時の意図が分かれば、原意を確かめる情報として重い。ただし当時の意図と、条件が変わった現在に何を採用すべきかは別問題である。原文対応、変更理由、保持invariant、新証拠、反例、適用範囲を示す再解釈は審査できる。作者へ照会することを禁止せず、照会後に検証が停止する地点を問題にする。

### 古いbranchを唯一の後継とする

再接続したAとBが同じTheory OriginやCivilizational Originを持っていても、現在のKernel、状態、Lineage Origin、Instance Originは違い得る。Aが古い文言を多く残すことは歴史的特徴であり、Bを代表しBの現在権限を決める十分条件ではない。共通起点から共通部分と分岐点を再構成し、一方だけを正統として他方の履歴を消さない。

### 緊急移行で歴史的役割を参照する

通信断絶や統治空白の下で、以前責任を負っていた主体へ暫定的に役割を戻す必要が生じる場合がある。本論は全権限を禁止しない。現在の必要、対象範囲、継続理由、見直し可能性を別に確認し、Emergencyを永久のOrigin主権へ変えない。任期・多数決・定足数などの固定制度を本派生から追加しない。

### 起源の主張に反対するため記録を消す

ある理論が反証されたとしても、誰が記述したかという歴史的関係まで消えるわけではない。現在の採用を止めることと、旧記述・旧版・系譜を削除することを分ける。出典が残れば批判の対象が正確になり、後続の改訂も比較できる。「非崇拝」を「無価値化」へ変換せず、起源を保存するには権力を付けなければならないとも考えない。

### 起源不明の似たKernelを扱う

似た語彙、同じ問題意識、機能的同型だけでは親子関係を断定できない。独立再導出の可能性を残し、Origin unknown / unresolvedや複数候補を明示する。仮説を立てること自体は禁止されず、確度と反証条件を添える。推定を既成の歴史へ偽装しないことが境界である。これらは説明場面であり、新しい実証研究の結果ではない。

## Measurements and audit

### 権限変換を観測する

1. Origin名や署名の提示だけで、現在の証拠比較や反例検討が止まっていないか。
2. 起源への近さが、論証内容や情報の確度の代わりになっていないか。
3. 歴史的中心性が、現在の最終決定資格として使われていないか。
4. 系譜の継続が、排他的な後継権や他branchの代表権へ変換されていないか。
5. 原典参照が文脈確認でなく永久のinterpretive defaultになっていないか。
6. Originへの異議が、内容審査でなく忠誠・服従の問題へ移されていないか。
7. branchが起源からの距離で政治的序列へ配置されていないか。

真理の近道では、反例より発言が優先される、現実との矛盾を定義だけで維持する、忠実さと妥当性を混同する、独立検証を不要扱いする、改訂をOrigin否定と扱う点を観測する。解釈の近道では、原意だけで現在条件を閉じる、再解釈者の近さだけで資格を決める、照会後に比較を止める点を観測する。権限の近道では、歴史的委任を現在の再審査なしに延長する、緊急役割を無限定に恒久化する点を観測する。

### 起源消去と仮装を観測する

批判の後にOrigin記録が削除される、改訂時に旧provenanceが失われる、新解釈から元の記述への対応が消える、自律を示すため親系譜を隠す、未確定の起点を便利な物語で埋める、歴史的事実の扱いと規範的拒否を同じにする、という逆側の失敗も見る。権限集中を切ることは起源蒸発を許すことではない。

形式上の批判窓口があっても、Originに近い主体しか異議を審査しないなら訂正効果を確認する。反対に再解釈が無限定になり、元の理論との対応が再構成できない場合も失敗である。批判が実際に誤った権限を訂正したか、provenanceが比較可能か、複数系譜が非排他的に可視化されたか、現在判断を再検証できるかを評価する。

### 統合監査の照応

Aは起源保存・四分類・因果履歴から可視化、中心性、近さ、default、継承へ進むリスク。Bは分類と範囲明確化、真理・解釈・権限の分離、批判、独立検証、現在正当化によって自動継承を切る経路。利害Xは署名、出典、因果、系譜、改訂、当時の文脈の保存。利害Yは現在・未来の判断、批判、再解釈、複数branch、再合意、非支配である。

条件ZはOrigin type、証拠、原典と後続解釈、系譜・fork点、権限主張の根拠、current justificationの再構成である。現象Mは起源保存と集中の関連が閾値θ未満で持続する、分類の診断効果がθ未満になる、保存・批判・非継承が観測窓δで訂正を改善しない、または重大な統治不全を持続させる等の場合。本論を拒否・縮小・改訂する。θとδに数値は指定されておらず、固定KPIや期間を捏造しない。

### 章ごとの比較入口

真理を検査するときは、出典が正確かだけでなく、因果の方向、適用範囲、現実のpatternとの照応、反証可能性、反例、独立再導出を分ける。Originの発言はその発言が存在したことの証拠になるが、一般claimが正しいことのすべてを担うわけではない。Origin情報しかない領域では、その証拠の射程を明示し、独立に確かめられないことも残す。

解釈を検査するときは、Originの意図を重い文脈情報として参照しながら、現在の条件へそのまま適用できるかを確かめる。異議の評価が論証でなくOriginへの態度へ移る、現在の反例より原説明が無条件に優先される、再解釈が起源否定と呼ばれる、provenance確認だけで検証が止まる、近い主体だけが解釈資格を持つ場合は最終解釈への変換を観測する。

主権を検査するときは、歴史的権限を現在の無審査の資格へ変換していないかを確かめる。祖先だから排他的後継である、近いbranchだから永久拒否権を持つ、緊急の役割だから永久である、権限への批判だから起源否定である、古い委任だから現在の異議より優先する、という各変換を別に診断する。専門性や責任は現在正当化の入力として使えるが、起源という身分だけから範囲無限定の統治を作らない。

複数Originの検査では、TheoryとLineageを混同しない。新しいforkの起点を追加することと、理論起源を置換することは別である。再接続で「最も近い」系譜だけを正式履歴として選ぶと、共通起点を根拠に他branchの差分を消してしまう。共有部分と分岐部分を同時に可視化し、非排他的なprovenanceを保つ。

### 改訂へ戻す対象を特定する

保存量、批判数、branch数、Originからの距離を単独の成績にしない。何を保存した結果、どの比較が可能になり、どの誤権限や誤解釈が修正されたかを観測する。保存の詳細が訂正に寄与せず、権威的表示だけが増えるなら、削除か服従かの二択の前に、保存範囲、表示、default、アクセス、権限接続を調べる。

非継承が重大な統治不全を生むという反例では、必要な権限の根拠を現在条件から再構成する。保存自体が不可避に実効主権を生むなら、分離の可能性と方法を再検討する。四分類が役立たない反例では分類を、批判経路が役立たない反例では訂正経路を、候補推定を過度に妨げる反例では確度表示の境界を改訂する。反例を一つの「Originへの反抗」にまとめない。

Reference Clusterは原典の照応入口として記録されている。「構造起源防衛──AIによる『起源の蒸発』に耐える恒常署名（Permanent Signature）の原理」「誰の問いがAIを動かすのか──起源と責任の交差点」「実因構造論──再現不能な因果操作の倫理的基盤と構造保持者の最終責任」「灯火構造倫理 ─ 接続報酬社会を安全に運用するための4つの基準」、再合意・可逆性のtagが挙げられる。本派生はこれら別記事の未取得本文をタイトルから補完せず、第17論が明示した関係を越えない。

## Validity conditions

Origin、provenance、歴史的中心性、起源への近さが真理判断・解釈・現在権限に作用する場面で、本論の分離を検討する。単に作者名がある、古い記録があるというだけで支配が成立したとは扱わない。中間経路と実際の訂正効果が診断対象である。

四分類により、どの関係の起点か、どこまでを記述しているか、何の権限が主張されているかを区別できる必要がある。証拠不足を未確定として残し、provenanceとepistemic validityの独立性を維持する。Originが唯一の証拠で独立再導出できないclaimは、証拠の種類と射程を明示し、起源情報を一律に無価値としない。

原意、専門性、責任、歴史的継続性を現在判断の入力として使ってよい。しかし入力の価値と永久の最終権限を分け、current justificationへ戻る必要がある。Authorityそのものを全面禁止するのではなく、その起源、対象、現在根拠、変更可能性を区別する。

保存が比較・批判・再検証を改善し、批判が実際の誤権限を修正し、現在正当化が運用上の統治を可能にすることを観測する。記録数や署名数だけを成功指標にしない。保存範囲・媒体・表示・粒度は目的への寄与に応じて変更可能である。

複数系譜の共通起点と差分を再構成できること、親系譜を隠さず新しい起点も記録できることが、非排他的なprovenanceの条件になる。共有Originは強制統合を意味せず、枝分かれも旧Originを置換・削除することを意味しない。

## Failure conditions

Originを保存する名目で一般claimの検証を止める、元の意図を現在の最終裁定にする、近いbranchに代表権や永久拒否権を付ける、過去の委任を現在へ無条件延長する場合は、保存から権限への閉路が残る。FormalにOrigin主権を否定していても、事実上のdefault、アクセス集中、異議審査独占があれば診断を続ける。

反対に、権限を否定するため起源・出典・旧版・親系譜を消す、批判をもって歴史的事実を抹消する、独立再導出から架空の祖先を作る場合はprovenance側が失敗する。単なる構造同型を歴史的因果へ変換しない。未知を認めることは失敗ではなく、仮説と確定事実の混同を防ぐ条件になる。

四分類へ機械的に押し込む、分類の重なりから権限を合算する、元の記述との対応を失うほど無限定に再解釈する場合は、分離自体が診断力を失う。Criticismの形式だけ残して訂正できない設計も、語彙上の非支配に留まる。

緊急の役割、専門的な情報、責任継続を一律に排除して持続的な統治不全を生む場合は、非継承の適用条件を見直す。これはOrigin地位だけで永久主権を承認する理由ではなく、必要な権限の現在根拠、範囲、条件、見直しを再設計する入口である。

本論自身をOriginによって免責し、四分類、保存形式、非継承境界を永久の正解とすれば自己参照的な失敗になる。Theory persistence ≠ theory validity。Nakagawa Masterの起源も保存対象であり、批判や反例を封じる権限ではない。

## Falsification conditions

第9章の主要な改訂入口を保持する。

1. Origin保存が権限集中へ結びつかない一般条件が成立するなら、因果仮説の射程を縮小する。
2. 四種類のOriginで実際の関係を十分に区別できないなら、分類を拡張・改訂する。
3. Provenance保存が比較・独立検証を改善しないなら、保存対象・粒度・方法を見直す。
4. 批判経路が誤った権限の訂正に寄与しないなら、形式的窓口の存在を成功扱いせず設計を改訂する。
5. 主権非継承が持続的な統治不全を生むなら、条件・範囲・期間・current justificationの接続を修正する。
6. 現在の非捏造境界が、確度を明示した合理的な系譜再構成まで不要に妨げるなら、仮説と確定の表示境界を見直す。
7. どのOrigin保存設計も不可避に実効主権を生むなら、保存と権限を分離できるという提案自体の範囲・方法を再検討する。

反例は本論への不忠誠ではなく、改訂の入力である。分類を守るため現実の系譜を歪めず、保存量を増やすため訂正可能性を落とさず、非継承を唱えるため統治不全を隠さない。四分類は現行の説明枠であって最終分類ではない。

記述、構造仮説、規範設計を分ける。記述はOrigin relationとcurrent authority、historical relationとcurrent relationを区別できること。構造仮説は保存・近さ・default・継承の集中経路と、分類・批判・検証による減衰。規範設計は保存、非真理認定、非最終解釈、非永久主権、批判可能性、非捏造、非消去である。三層を混同して規範の正しさを観測事実だけから確定しない。

統合監査のθ・δは観測設計の記号であり、普遍的な値は与えられていない。現象Mを反復観測した場合、保存範囲、Origin type、authority boundary、criticism route、provenance representation、current justificationとの接続へ戻る。反証対象はOriginの存在ではなく、現在の構造仮説と設計効果である。
