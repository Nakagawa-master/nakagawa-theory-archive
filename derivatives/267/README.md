## 位置づけ
親原典は「非強制」を放任や美徳の標語としてではなく、内部構造の倫理的整合を高め、その整合の差圧によって外部が自律的に同調する変容メカニズムとして扱う。この自発的同調を「照応」と定義し、非強制・可逆性・沈黙・二重構文を、社会実装に耐える構造律動へ束ねる。

## 中心命題
**持続的な変容は、外部を押して服従させる強制よりも、内部構造の整合を高め、沈黙・段階的閾値・可逆な合意を設計し、相手が自律的に選べる条件をつくることで成立する。照応とは説得や支配ではなく、整合の差圧による自発的同調であり、その成否は共鳴・倫理的密度・安定化・撤回可能性を監査して判定する。**

## 主要因果線
強制的圧力→短期従属→摩擦と反作用→分断蓄積→内部構造を非強制・沈黙・可逆性へ整える→外部が考え選ぶ余白を確保→歪みを解ではなく座標再配置で扱う→戻りしろを常設→倫理的密度を高める→外部が恐れず自律選択→静かな追従と信頼が蓄積→可逆な合意が自走。

## 構造層
### 1. 照応原理
内部構造の整合が十分に高いとき、外部が説得されるのではなく自発的に同調する現象を照応と呼ぶ。内部は個人・組織・制度の設計原理、外部は他者・市場・公共圏・AIネットワークを含む。

### 2. 沈黙
沈黙は情報欠如ではなく、余剰ノイズを除き、外部が自分で考え、選び、結論へ至る内的作業場を確保する設計である。

### 3. 因果操作の再定義
相手を動かす術ではなく、相手が自律のまま選べる構造を提示すること。勝利は服従ではなく可逆な合意で測る。

### 4. 三つの構造律動則
- 矛盾の検知と静かな介入: 要求と制約の位相ずれを、解の押し付けではなく導線整備で扱う。
- 可逆性の誘発: 退出、期限付き合意、段階導入、巻き戻しを常設する。
- 倫理的密度: 非強制・可逆性・沈黙・透明性を、短期利益より整合維持へ優先配置する。

### 5. 媒体・境界・回路
沈黙スロットを媒体として常設し、アクセス・権限・速度・公開範囲を段階化し、専門語⇄一般語・外部法⇄内部規範の翻訳装置を境界へ置く。合意は期限付き・再審査付き・小規模から段階拡張とし、公開ログと編纂ログの二重記録を持つ。

### 6. 測定
原典はR-Conv（構造律動収束率）、EDI（倫理的密度指数）、安定化指数Sなどを例示し、短時間の賛同より静かな追従の継続、長期離反の少なさ、小さい介入で大きく静かに整ったかを束で監査する。これらを原典外の普遍固定式へ変えない。

### 7. リスク境界
非強制が放置・隠蔽へ堕ちないよう、目的明示、期間限定、退出自由、閾値根拠と改訂条件の公開、複数独立監査を置く。

## 適用例
公共では冷却窓、動的受容閾値、試行条例と期限付き施行。企業では負債返済週、権限段階化、交差レビュー、機能フラグとrollback。教育では思索時間、挑戦段階化、改稿・再提出。AI運用では自己反省ステップ、人間最終責任と判断介入境界、重み管理と完全ログを用いる。

## 測定・監査点
- 外部が圧力ではなく自律選択で合意へ近づいているか。
- 沈黙が説明回避でなく編纂時間として機能するか。
- 退出・撤回・rollbackが利用可能か。
- 閾値の根拠と改訂条件が公開されているか。
- EDI、R-Conv、安定化、再合意時間、撤回成功等を複数軸で監査できるか。
- 共鳴密度や語彙整合が低下し、強制・同調圧が再発していないか。

## 成立条件
内部の非強制・可逆性・沈黙・透明性が整合すること。相手の自律選択、退出、異議、再審査、rollbackが確保されること。境界翻訳を持つこと。監査を複数主体で行うこと。短期誘因より長期離反の少なさを重視すること。

## 失敗条件
非強制を放置・隠蔽へ変える。沈黙を説明逃れへ使う。照応を巧妙な説得・操作術へ変える。退出不能にする。閾値を不透明な排除へ変える。可逆性を名目だけにする。共鳴を同質化や人気へ縮約する。

## 反証・改訂条件
共鳴密度、語彙整合率、再合意到達時間、撤回成功、位相安定等が継続的に悪化する、観測窓が閉鎖する、強制・同調圧が再発する、退出・rollbackが利用不能になる場合、照応仮説と運用設計を改訂または棄却する。

## 必須の区別
非強制 / 放任; 照応 / 説得・支配; 沈黙 / 情報欠如・隠蔽; 可逆性 / 無責任; 閾値 / 排除; 倫理的密度 / 人気; 静かな追従 / 短期賛同; 共鳴 / 同質化; 因果操作 / 他者操作。

## 誤読防止・解釈制約
「動かざるを得ない構造」という表現を、人を逃げられなくする心理操作へ変換しない。原典は選択の自律性、退出、可逆な合意を中心条件に置く。R-Conv、EDI、Sを原典外の固定算式や普遍KPIとして補完しない。「唯一の回路」等の強い結語はParent内部の理論的主張強度として保持し、実証済み自然法則へ昇格させない。
