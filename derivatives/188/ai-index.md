## Summary
ParentはLife-OS B系から共鳴市場C系へ移る前の公共倫理検疫として、公共域における沈黙・不行為を含む全操作を因果入力として扱う。公共意思決定は可視化された抵抗・保留・離脱等を参照して進行するため、沈黙は「何もない状態」ではなく、既存流に抵抗を追加しない入力となり得る。その結果、反対が可視化されず、「誰も反対しなかった」という承認生成、判断の外注化によるSelf-Deactivation、判断高度の集団的低下としてのCollective Sedimentationへ連鎖し得る。

Parentは沈黙を道徳悪として断罪せず、例外的沈黙の四条件をAND条件で置く。影響が個人内に閉じ、可逆性があり、正当化に利用されず、保留・条件提示・離脱等の代替入力が明示されていることが必要である。条件を満たさない公共域では、保留宣言、条件提示、離脱表明、感情の構造翻訳が最低限プロトコルとなる。倫理は声量でなく配置として評価され、能力を持つ者ほどその選択・不行為の伝播範囲が大きくなる。Parentは条件Zと反証条件を備え、この構造法則を改訂可能な仮説としても監査する。

## Concepts
- 公共域: 多数の意思決定・行動・評価が相互影響する因果空間。
- 中立不存在: 公共域で影響を完全にゼロにする操作は成立しないというParentの強い構造主張。
- 沈黙: 無入力ではなく、既存流に抵抗を加えない因果入力。
- 承認生成: 「反対が可視化されなかった」ことが「反対なし」「合意」の材料へ変換される過程。
- Self-Deactivation: 認識L4・判断L5を空気や周囲へ委譲し、意味ある入力生成が停止する機能状態。
- Collective Sedimentation: 判断を引き受ける集団基準高度が徐々に低下し、異議コストが上昇する状態。
- 四条件: 個人内完結性、可逆性、正当化非利用、代替行為明示の同時成立。
- 保留宣言: 判断不能理由を構造へ返し、silentとundecidedを分離する操作。
- 条件提示: 同意可能な前提・未検証点を返す修正可能入力。
- 離脱表明: 意思決定系列への非参加を明示する境界入力。
- 翻訳: 感情を前提破綻・因果歪み・未評価リスクへ変換する操作。
- 背中の倫理: 正しさの宣言ではなく、どの因果系列のどの位置に立つかで評価される倫理。
- 条件Z: 監査周期、T/S/R、公開監査束の整合による再検証条件。

```text
→ Self-Deactivation
→ 集団で反復

→ 異議コスト上昇・沈黙自己強化
→ 四条件検査

→ 承認化位置からずれる
→ 結果を引き受けられるPositionを選択
→ C系参加前の公共安全規格を満たす
```

## State model
- `PRIVATE_ONLY`: 影響が自己内に閉じる。
- `PUBLIC_CAUSAL_INPUT`: 公共域接続により行為・不行為が入力化。
- `ZERO_RESISTANCE`: 沈黙が既存流への抵抗なしとして処理される。
- `APPROVAL_GENERATION`: 反対不在が承認材料へ変換される。
- `SELF_DEACTIVATION`: 認識・判断の外部委譲が継続する。
- `COLLECTIVE_SEDIMENTATION`: 集団の判断高度が低下し異議コストが増大する。
- `EXCEPTIONALLY_VALID_SILENCE`: 四条件すべて成立時の限定沈黙。
- `EXPLICIT_INPUT_RETURN`: 保留・条件・離脱・翻訳で明示入力を返す。
- `ACCOUNTABLE_POSITION`: 結果を引き受けられる配置を選ぶ。
- `C_SERIES_ENTRY`: 共鳴市場へ進む前の検疫条件を満たす。

## Applications
- 会議: 情報不足を黙って吸収させず、判断未確定を明示する。
- 制度設計: 条件付き支持を無条件同意へ丸めず、条件として記録する。
- 組織統治: 反対なし・未回答・保留・離脱を別状態として扱う。
- リスク管理: 感情的違和感を未評価リスクや前提破綻へ翻訳する。
- 多重接続者: 複数組織へ伝播する沈黙の影響も接続能力の一部として監査する。
- 公共参加: 正義の発言量ではなく、どの因果系列へ残るか／離れるかを明示する。

## Failure conditions

- 私的沈黙まで公共責任へ無制限に拡張する。
- 常時発言・同調・告発を強制する。
- hold/conditional/exitをsilentへ潰す。
- 集団的沈降を一人の悪意だけで説明する。
- 感情翻訳を感情抑圧へ変える。

## Falsification conditions

1. 沈黙が承認へ変換されないことが継続的に実証される。
2. Self-Deactivationが因果へ組み込まれない設計変更が成立する。
