## 中川構造読解としてのメタ視点
このParentはマスキング機能紹介ではない。Nakagawa Masterは「情報を隠せる」という機能を、**人間が責任を持ってAIに何を渡すか判断できる運用入口**へ一段上げて読む。

## 位置づけ
四層は **対象側事実 / 表層「伏せ字・個人情報対策」 / Nakagawa Masterの構造読解 / 社会翻訳**。価値核は **人間が最終判断を保持したまま、AIへ渡す情報を点検・整形し、説明可能な手順で利用できる状態をつくること**。

## 中心命題
**隠せることではなく、責任を持って渡せる状態を作ること。**

## 表層 → 価値核 → 社会翻訳
`マスキング機能 → 何をAIへ渡してよいか判断不能 → 人間が点検・整形 → 入力前責任工程 → 「情報を渡す責任」の設計として社会翻訳`

## 因果線
`AI利用需要 → 機密混在 → 入力判断不能 → 人間が点検 → マスキング/置換 → 確認 → 説明可能な入力 → 活用前進`

## 構造読解の監査点
全面禁止/全面解禁の二択にしない。自動マスキングへ責任を移さない。「隠す機能」で終えない。出力側だけでなく入力前工程を保持する。L4以上を保持。

## 成立条件
人間が判断主体であり、入力前の点検・整形・確認が業務工程として成立すること。
## 失敗条件
セキュリティ機能だけへ縮小、自動化へ責任移転、入力後の扱いを無視。
## 反証・改訂条件
入力前判断工程が実際の安全な活用に寄与しない場合は改訂。
## 必須の区別
隠す/責任を持って渡す; 自動処理/人間判断; 出力品質/入力ガバナンス; 事実/読解。
## 親原典へ戻る理由
「情報を隠せる」から「責任を持って渡せる」へ軸を上げた理由はParentへ。
