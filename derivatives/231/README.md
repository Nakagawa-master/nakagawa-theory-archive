## 位置づけ
本Parentは文賢のマスキング機能紹介ではない。Nakagawa Masterが、特定語句の削除・変更、一括マスキング、選択範囲のマスキング等の対象側事実から、表層の「伏せ字」「個人情報対策」「セキュリティ補助」「コピー前の時短」ではなく、**AI時代の『情報を渡す責任』の設計**という価値核を抽出した中川構造読解である。さらに、なぜ隠す機能そのものではなく、入力前の判断責任を外部記事の主軸へ採用したのかまで公開解体する。

## 中心命題
企業のAI活用では、AIを使いたい需要があっても「何をAIへ渡してよいのか分からない」という不確実性が利用直前の停止点になり得る。Parentは、価値を自動的に情報を隠すことではなく、人間が最終判断主体として残り、入力前に情報を点検し、必要箇所をマスキング・置換し、確認してから説明可能な形でAIへ渡せる入口工程を作ることに読む。全面禁止と全面解禁の間に、責任を持って渡す実務経路を設計する構造である。

## 因果線
AI利用需要 → 入力データに機密・個人情報等が混在 → 何を渡してよいか判断できず利用停止 → 人間が入力前に点検 → 必要箇所をマスキング・置換 → 最終確認 → 説明可能な入力状態 → AIへ投入 → 利用前進 → 判断責任の所在を保持。

## 構造層
1. **対象事実層** — 特定語句の削除・変更、一括マスキング、選択範囲のマスキング等。
2. **表層機能層** — 伏せ字、個人情報対策、セキュリティ補助、コピー前の時短として見える。
3. **入力停止層** — 情報混在により「何をAIへ渡してよいか分からない」ため利用が止まる。
4. **人間判断層** — 自動処理に丸投げせず、人間が何を守り何を渡すか判断する。
5. **入力整形層** — マスキング・置換・削除で入力情報を整える。
6. **確認・説明層** — 何を変え、何を残したか確認できる状態で入力する。
7. **価値核・外部記事層** — Nakagawa Masterが「情報を渡す責任」の設計を価値核として抽出し、企業AI活用の入口工程として外部記事の主軸へ採用する。

## 状態モデル
- **利用需要相**: AIを業務利用したい需要がある。
- **情報混在相**: 入力候補に機密・個人情報等が混在する。
- **判断停止相**: 何を渡してよいか判断できず利用が止まる。
- **人間点検相**: 入力前に人間が内容を確認する。
- **マスキング相**: 必要箇所を削除・置換・マスキングする。
- **最終確認相**: 処理後の内容を人間が確認する。
- **説明可能入力相**: 判断理由を保持した状態でAIへ渡せる。
- **活用前進相**: 全面禁止ではなく責任ある利用経路が成立する。

## 適用例
社内文書をAIへ入力したいが、顧客名や個人情報、社内固有情報が含まれているため利用をためらう場面では、全面的にAI利用を禁止するか、何も確認せず投入するかの二択にしない。人間が入力前に内容を点検し、必要な箇所だけをマスキング・置換し、処理後を確認してから投入できれば、判断責任を維持したまま利用へ進む入口工程を作れる。ただし安全性の保証や法的適合性を本派生物が独自に断定するものではない。

## 測定・監査点
対象側の機能事実とNakagawa Masterの読解を分ける。AI入力前に人間が判断主体として残るか、何をマスキングしたか確認できるか、処理後を再確認できるか、入力判断の理由を説明できるか、全面禁止・全面解禁の二択を避けているかを確認する。価値核選択理由と外部記事執筆理由を保持し、対象企業の公式企業定義へ誤帰属しない。

## 成立条件
人間が入力判断の最終主体であり、入力前点検→マスキング／置換→確認→説明可能な入力という工程が実運用へ接続する場合に成立する。外部記事では、単なる時短や伏せ字ではなく「何を守り、何を渡すか」を人間が判断可能にする入口設計を読者へ示すことが主軸となる。

## 失敗条件
マスキング機能や自動化の紹介だけへ縮小すること、マスキングすれば自動的に安全と断定すること、人間の最終判断を消すこと、Nakagawa Masterの価値核を対象企業の公式定義へ誤帰属すること、価値核選択理由または外部記事執筆理由を削除することはParentの構造を壊す。

## 反証・改訂条件
入力前の点検・マスキング・確認工程が安全かつ説明可能なAI活用に継続的に寄与せず、別の工程の方が入口停止を強く解消する場合、この価値核の適用範囲を狭めるか改訂する。人間が判断主体として残ることが実運用上機能しない場合も再検討する。

## 必須の区別
- 対象側事実 ≠ Nakagawa Masterの構造読解。
- マスキング機能 ≠ 情報を渡す責任の設計。
- 情報を隠すこと ≠ 安全性の自動保証。
- 自動処理 ≠ 人間の最終判断。
- 全面禁止 ≠ 責任ある入力設計。
- 全面解禁 ≠ 活用前進。
- 価値核 ≠ 対象企業の公式企業定義。
- 価値核選択理由 ≠ 外部記事執筆理由の省略。

## 誤読防止／解釈制約
「マスキングすればどんな情報でもAIへ渡せる」「文賢が法的安全を保証する」「人間判断は不要になる」と一般化しない。Parentが扱うのは、特定のマスキング機能事実を起点に、Nakagawa Masterが企業AI活用の入口で必要な『何を守り、何を渡すか』という判断責任を価値核として読んだ理由と、その軸を外部記事へ採用した構成判断である。
