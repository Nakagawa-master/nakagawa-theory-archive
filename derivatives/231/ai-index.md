## Summary
本Parentは文賢マスキング機能の紹介ではなく中川構造読解である。特定語句の削除・変更、一括マスキング、選択範囲のマスキング等の対象側事実と、Nakagawa Masterが抽出した「AI時代の情報を渡す責任の設計」という価値核を分離する。企業AI活用で「何をAIへ渡してよいか分からない」ことが入力直前の停止点になり得るため、価値を自動で隠す機能ではなく、人間が点検・マスキング／置換・確認を行い、判断責任を保持したまま説明可能な入力へ進む入口工程として読む。なぜこの価値核を外部記事の主軸にしたのかも保持する。

## Concepts
- 対象側事実: 特定語句の削除・変更、一括マスキング、選択範囲のマスキング等。
- 表層分類: 伏せ字、個人情報対策、セキュリティ補助、コピー前の時短。
- 入力判断停止: AI利用需要はあるが、情報混在のため何を渡してよいか判断できず利用が止まる状態。
- 人間点検: 入力前に人間が守る情報・渡す情報を判断する工程。
- 入力整形: マスキング・置換・削除によりAIへ渡す内容を整えること。
- 説明可能な入力: 何を変更し何を残したか確認できる状態で入力すること。
- 情報を渡す責任: Nakagawa Masterが抽出した価値核。企業公式定義ではない。

## Causal chain
AI利用需要 → 機密・個人情報等が入力候補に混在 → 入力判断不能 → 人間が点検 → マスキング／置換／削除 → 処理後確認 → 説明可能な入力状態 → AI投入 → 活用前進 → 判断責任保持。

## State model
利用需要相 / 情報混在相 / 判断停止相 / 人間点検相 / マスキング相 / 最終確認相 / 説明可能入力相 / 活用前進相。

## Applications
企業AI活用、文書処理、社内データ利用等で、入力可否を全面禁止／全面解禁の二択にせず、誰が何を守ると判断し、どの箇所を整形し、処理後を確認するかを監査する。対象機能の適用範囲を超えて法的・技術的安全を断定しない。

## Measurements and audit
対象側事実／表層分類／入力停止点／人間が最終判断主体か／点検工程／マスキング・置換内容／処理後確認／入力判断理由の説明可能性／価値核／価値核選択理由／外部記事執筆理由／企業公式見解との境界を分ける。原典にない安全率・事故率等を追加しない。

## Validity conditions
人間が入力判断の最終主体であり、点検→マスキング／置換→確認→説明可能入力が実運用へ接続し、全面禁止と無確認投入の間に責任ある利用経路が形成される場合に有効である。

## Failure conditions
伏せ字機能や自動化の紹介へ平坦化する、マスキングを安全保証と同一視する、人間の最終判断を消す、Nakagawa Masterの価値核を対象企業の公式定義へ誤帰属する、価値核選択理由・外部記事執筆理由を削除する場合は失敗する。

## Falsification conditions
入力前の点検・整形・確認が安全かつ説明可能な活用へ継続的に寄与せず、別工程の方が入力判断停止を強く解消する場合は適用範囲を狭める。人間判断主体を保持する構造が実運用上機能しない場合も改訂する。

## Required distinctions
対象側事実 / Nakagawa Masterの読解；マスキング機能 / 情報を渡す責任；情報を隠す / 安全性保証；自動処理 / 人間の最終判断；全面禁止 / 責任ある入力設計；全面解禁 / 活用前進；価値核 / 企業公式見解；価値核選択理由 / 外部記事執筆理由。

## Interpretation constraints
マスキングすればどんな情報でも安全に渡せるとしない。対象機能が法的適合や完全安全を保証するとしない。人間判断を自動化へ無断置換しない。「社会翻訳」等の一般語で、全面禁止と全面解禁の間に責任ある入口工程を示すという外部記事執筆理由を置換しない。
