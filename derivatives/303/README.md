## 位置づけ

第9論が「自己保存の行動が相互の脅威を作り得る」閉路を示した後に残る問いは、その判断を誰が、どの経路から検査できるかである。本第10論は、評価者・被評価者・実行者・監査者という役割名だけを分けても、判断と監査の因果が同じなら自己正当化閉路は残ると述べる。独立監査は別の肩書きではなく、異なる証拠・権限・故障可能性・利害・異議経路から判断を再開できる構造である。

このHubは、原典の問題設定、5軸、緊急時の圧縮、観測可能性、反証条件を7面へ案内する。特定の監査組織・法的権限・人数・閾値・資源配分制度を新たに定めるものではない。

## 中心命題

判断が実行されると、資源配置、アクセス、記録、関係主体の反応が変わる。次の監査が読むのは、判断前の世界だけでなく、その判断によって変化した後の証拠環境である。元判断がその環境を形づくり、その環境が元判断を支持する証拠として読み直されると、判断は自らの正当性の条件を部分的に作る。

`判断 → 実行 → 観測環境の変化 → 変化後の証拠 → 元判断との整合確認 → 実行継続`

この構造は、主体の悪意や意図的な虚偽を必要としない。既投入コスト、制度慣性、同じ情報源、同じ失敗原因、監査者自身の継続条件だけでも、追認へ向かう圧力が発生し得る。反対に、追認が続くことだけで判断が誤っているとも証明されない。問うのは、異なる証拠や条件が来たとき結論が変わり得るかである。

## 因果線

### 自己参照・自己正当化の経路

元判断 → 実行 → 証拠環境と対象状態を変える → 変化後の記録で元判断を評価する → 同じ基準・同じ主体が整合を確認する → 権限・例外・実行を維持する → 維持の履歴が次の追認根拠になる。

例外を自ら発動し、自ら証拠を選び、自ら緊急性を認定し、自ら継続を承認する場合、緊急性は監査経路を細らせると同時に、例外の履歴を増やし得る。監査結果が常に肯定でも常に否定でも、それだけでは独立性を判定できない。監査者の否定権限自体が無制限の主権へ変わる危険も含む。

### 訂正・判断再開の経路

元判断 → 自己監査 → 異なる証拠経路 → 独立した異議 → 別の故障領域・利害からの再検査 → 判断再開 → 必要に応じて修正・縮小・解除 → 新しい条件で再評価。

別の結論が正しいと先に決めず、差分がどの証拠・基準・条件・故障原因から生じたかを追う。不一致は真理票ではないが、単一経路では見えなかった違いを再検査へ戻す信号になり得る。

## 構造層

1. **証拠の独立性**：監査者は元判断と異なる観測・記録・取得経路へ到達できるか。資料数や反復数を独立確認数と取り違えない。出典系譜を追えることも真理の証明ではない。
2. **権限の独立性**：監査出力が、必要に応じて再検査・判断再開・一時停止・例外見直しへ作用できるか。監査者が常に最終決定者になることや、無制限の拒否権を持つことを意味しない。
3. **故障領域の独立性**：共通設計、入力、記憶、評価基準、依存先、更新経路、障害により全員が同時に誤る範囲を把握する。コピー数や多数一致は独立判断数ではない。
4. **利害の独立性**：結論が監査者自身の継続、権限、成功条件、評価、制度の存続へどう戻るかを観測する。利害は悪意・腐敗と同義ではなく、完全な無利害を条件にしない。
5. **異議経路の独立性**：反対意見が元判断主体だけに提出され、その主体だけで受理・却下・終了されない経路を持つか。沈黙は合意を意味せず、異議の数も正しさではない。

五軸は合計点を作るチェックリストではない。一つの軸の強さで別の軸の欠落を相殺できない。どの経路が分かれ、どこで共有され、差分が判断へ届くかを個別に見る。

## 状態モデル

| 状態 | 観測する関係 | 再評価の焦点 |
|---|---|---|
| 元判断の形成 | 根拠、条件認識、不確実性、基準 | 何を判断前から知り、何が不明だったか |
| 実行・環境変化 | 資源、アクセス、記録、他者反応 | 元判断が次の証拠環境に何を加えたか |
| 自己監査 | 同一主体、基準、証拠系譜 | 自己監査の価値を残しつつ独立監査と混同しない |
| 独立照応 | 5軸の差分と共有点 | 主体数ではなく因果経路がどこで独立しているか |
| 異議・不一致 | 到達性、取扱い、却下権、再開履歴 | 異議が真理票にならずに判断を開けるか |
| 緊急縮退 | 時間圧、証拠縮小、権限集中、秘匿 | どの軸が圧縮され、後から何が戻るか |
| 結論再開 | 証拠、基準、利益、結果の変化 | 修正・縮小・解除が実際に可能か |

この表は自動判定器、合意手続、段階評価ではない。緊急時に通常時と同じ監査密度を保てないことはあり得るが、一時的圧縮と恒久的崩壊を分け、後続検証可能性を残す。

## 適用例

### 複数のAI・監査主体が同じ結論を出す

主体数、モデル数、記録数、票数だけで独立性を判断しない。共通入力、同じmemory、同じ要約、同じ評価基準、同じ故障原因から回答が複製されていないか、異なる証拠経路へ戻れるかを見る。同じ根拠を共有することには比較可能性と効率の利点がある。問題は共有そのものではなく、異なる差分が一切入らない場合である。

### 異議が出ても判断が変わらない

異議が記録されることと、判断を再検査できることは異なる。異議の受理・根拠評価・却下・再審がすべて被監査主体の単独支配下にあるなら、異議は形式的に存在しても訂正力を持たない。権限は最終決定者を新設するのではなく、条件に応じて閉じた判断を開き直す作用として観測する。

### 緊急対応と秘匿

切迫性、短い時間、公開による危険がある場合、独立性が一時的に圧縮され得る。記録には判断、根拠、範囲、不確実性、再検査を起動する条件を残し、圧力低下後に証拠経路・異議・権限の差分が復元するかを見る。秘匿は虚偽ではなく、緊急は監査免除ではない。固定期間での機械的解除も、例外の永久化も命じない。

### 監査主体自身が結論から利益を得る

利害の存在だけで不正を断定しない。監査者の継続、権限、評価が肯定・否定のどちらの結論と結びつくか、その圧力を別の条件にある主体から観察できるかを見る。監査主体もまた監査対象であり、その権限は新しい無制限主権ではない。

### 高度な独立性が協調を損なう

完全分離を目標に固定しない。標準化は相互運用性を高める一方、共通故障領域を拡大し得る。分離による情報断絶、遅延、訂正性能の変化も比較する。目的は分離そのものではなく、共有と独立差分を両立し、誤りから判断を戻せる状態を残すことにある。

## 測定・監査点

第9章の十方向を保持する。これは独立性の合否を計算する点数表ではなく、再検査の入口である。

1. 監査者が元判断とは異なる証拠へ到達できるか。
2. 元判断に反対する結論が制度上だけでなく、実際に生じ得るか。
3. 反対結論によって、判断が過去に再開されたことがあるか。
4. 複数監査主体が同一の故障原因で同時停止・誤認・追認していないか。
5. 被監査主体が、監査者のアクセス・存続・権限・証拠範囲を一方的に制御していないか。
6. 異議が元判断主体以外の再検査経路へ到達できるか。
7. 緊急状態の終了後、一時圧縮された独立性が復元しているか。
8. 監査結果が長期間ほぼ常に元判断を追認していないか。
9. 新しい証拠・条件変化によって監査結論が変わり得るか。
10. 自己監査と独立監査が、概念名だけでなく因果構造として区別されているか。

追認率だけでも否定率だけでも判定しない。独立証拠の有無、結論変更可能性、異議経路の実効性、監査者側への利益の戻り、緊急後の復元を区別する。

## 成立条件

元判断、実行、後続観測の間に因果関係があり、監査者が判断の根拠や結果を再検査できることが出発点である。五軸の共有・分離と相互依存を観測でき、異なる証拠または異議が判断を再開する経路が必要となる。全主体が常に独立できる、完全な無利害が得られる、全ての証拠が公開できるとは置かない。主体数と独立性を混同せず、判断の可逆性・時間条件・協調コストを文脈ごとに評価する。

## 失敗条件

- 役割名の違いだけで独立監査が成立したとする。
- 同じ証拠・memory・故障原因に依存する多数を、独立確認として数える。
- 出典の明示、記録の存在、反復一致を真理証明と扱う。
- 異議を記録するだけで、被監査主体が単独却下できる構造を残す。
- 利害を悪意や腐敗と同一視し、完全な無利害を前提にする。
- 緊急時の一時圧縮を永久化する、または圧力低下後の復元を見ない。
- 独立監査を無制限の拒否権、新しい主権、全判断の停止へ変える。
- 異議の不在を合意、異議数や多数一致を正しさとみなす。
- 分離を絶対化して必要な協調・情報共有・期限内の判断を壊す。
- 第10論の監査構造を監査不能なものに固定する。

## 反証・改訂条件

1. 五軸の実質分離によって誤り検出・訂正性能が改善しないなら、五軸の定義・適用を再検討する。
2. 同一故障領域でも、独立監査と同等以上の誤り検出・訂正が体系的に成立するなら、故障領域軸の必要性を狭める。
3. 権限分離が訂正能力を高めず、比較可能条件で致命的遅延だけを恒常的に増やすなら、権限配置を改訂する。
4. 利害構造と監査方向の安定した関連が確認できないなら、利害軸の強さを改訂する。
5. 異議経路の分離が判断再開・訂正に寄与しないなら、その経路要件を再評価する。
6. 共有と分離の調整を変えても証拠独立性が判断品質へ影響しないなら、証拠軸を縮小する。
7. 緊急後の復元条件が逆効果となり重大な脆弱性を継続的に作るなら、暫定圧縮と復元条件を見直す。
8. 五軸の要求が無限後退、判断不能、恒常的な権力集中のいずれかを生むなら、適用範囲と手続の境界を改訂する。

独立監査者を監査免除にする結論へ反転させない。観測上の兆候と反証成立を区別し、比較可能な条件と実際の訂正結果に基づいて改訂する。

## 必須の区別

- 自己監査／独立監査、役割分離／実質的独立性。
- 主体数／因果経路数、コピー数／独立判断数、多数一致／独立確認。
- 出典系譜／真理証明、監査出力／訂正力、異議／真理票。
- 不一致／誤り、沈黙／合意、追認／監査失敗。
- 証拠／権限／故障領域／利害／異議経路の五軸。
- 利害／腐敗、独立性／無利害、協調／共通故障。
- 一時的緊急縮退／恒久的独立性崩壊、秘匿／虚偽。
- 異議経路／無限拒否権、独立監査／新しい無制限主権。
- 現在のAIの事実／将来AIに関する条件仮説。
- Origin／理論妥当性の証明、観測兆候／反証成立。
- 監査者の分離／監査能力の非対称化。後者は第11論へ残る。

## 誤読禁止

本論は、現在のAIに人間型の欲望、恐怖、自己意識、自己保存動機があると確定しない。主体が誠実でも、同じ因果系だけから判断を監査するなら自己確認へ閉じ得るという構造を扱う。独立性の五軸は単一スコアでも、すべてを完全分離すべきという規則でもない。反対者へ最終権限を渡さず、多数決で真理を決めず、あらゆる異議で実行を無期限停止しない。緊急時の圧縮や秘匿はあり得るが、恒久化・監査免除・訂正不能を自動承認しない。第11論の監査能力・情報・アクセス・資源の非対称性は本論で解決したと主張しない。
