## Summary

第10论把独立审计视为能够重新开启判断的因果结构，而不是不同的职务名称或更多审查者。一个判断被执行后，会改变后续审计所面对的环境；如果仍由相同主体、证据和路径检查这个已改变的环境，原判断就可能参与制造用于证明自己的证据。本文区分五个维度：证据、权限、故障域、利益和异议路径。主体数量、重复报告和多数一致不能证明独立确认。分歧不等于真理，但可能提示需要追踪的差异。紧急压力和保密可能暂时压缩五个维度，但不构成永久审计豁免。本文是可修订的结构假说，不规定具体机构、数值评分或固定程序，也不认定当前AI具有欲望、恐惧、意识或人格。

## Concepts

- **自我参照审计**：判断执行后改变证据环境，改变后的环境又返回并参与评价原判断。
- **角色分离**：区分评价者、被评价者、执行者和审计者。它有助于辨明职责，但不能证明因果独立。
- **证据独立性**：能够通过不同的采集路径获取证据，并看见其上游系谱。来源可追踪不等于事实为真。
- **权限独立性**：审计结果在必要时可以触发复查、重启判断、暂停请求或例外复审；不等于无限否决权。
- **故障域**：一个缺陷、输入、依赖、记忆、标准或更新路径可能同时影响多个审查者的因果范围。
- **利益独立性**：检查审计结论如何反馈到审计者自身的持续、权限、成功条件、评价或制度存续；不要求利益为零。
- **异议路径独立性**：异议不只经过原决策者，并由其单独接收、判断和终止。
- **多主体照应**：不同因果路径上的复查，不是简单相加票数。
- **紧急压缩**：时间、证据、访问或质疑渠道暂时收缩；须与永久崩塌相区别。
- **可反证性**：预先给出需要修改五轴定义、适用范围或因果关系的结果。

## Causal chain

### 自我确认路径

原判断 → 执行 → 改变对象、记录、资源、访问或他人反应 → 将改变后的环境作为证据 → 用原标准确认原判断 → 延续权限、例外与执行 → 累积的延续历史成为下一轮确认依据。

如果审计者的持续、权限或成功也受结论影响，即使没有恶意，也可能产生方向压力。共同输入可能生成相关复制结果；表面共识随后形成第二层自我确认闭路。

### 重新开启路径

判断 → 自我审计 → 不同证据路径 → 独立异议 → 从不同故障域和利益条件复查 → 重新开启判断 → 必要时修正、缩小或撤销 → 在变化后的条件下再评估。

分歧不能证明谁正确，但可提示追查差异。审计者本身也应可受审计，重新开启判断的能力不应变成无限主权。

## State model

| 状态 | 观察关系 | 复查焦点 |
|---|---|---|
| 判断形成 | 证据、标准、不确定性 | 恢复当时已知与未知条件 |
| 执行改变环境 | 对象、记录、资源、访问 | 判断如何塑造后续证据环境 |
| 自我审计 | 主体、标准、证据重叠 | 保留内部检查，但不称为独立审计 |
| 多主体照应 | 五轴的共享与差异 | 追踪哪些路径真正不同 |
| 异议或分歧 | 访问、驳回权、重启历史 | 检查异议能否启动复查 |
| 紧急压缩 | 时间、保密、权限集中 | 压缩了什么，压力下降后恢复了什么 |
| 判断重启 | 新证据、条件、结论 | 保留修正、缩小和撤销的可能 |

这不是通用状态机或二元合格测试。独立性不是单一分数，五轴之间的依赖关系很重要。

## Applications

### 多个模型得出同一答案

不要只数模型名称或运行次数，而要追踪输入来源、记忆、摘要、标准、依赖和共同故障原因。共享证据有助于比较，也要确认是否存在其他证据路径。

### 异议被记录，但执行没有变化

检查报告是否实际触发过复查、判断重启、范围缩小或例外复审。如果被审查方独占驳回每个异议的权力，审计输出与纠正能力就彼此分离。

### 紧急复查与保密

时间压力或披露风险可能暂时压缩证据路径、参与、质疑或权限。保留足以重建判断、依据、范围、不确定性及后续复查条件的系谱。紧急不等于审计豁免，保密不等于虚假；本文不指定机械的到期时间。

### 审计者从结论中获益

梳理持续、权限、成功或评价如何关联赞成或反对的结论。存在利益本身不能证明腐败；应让其他复查路径能够观察这种反馈。

### 标准化与协作

共享基础设施会提高互操作性，但也可能扩大共同故障域。将相关错误与隔离造成的信息损失、延迟和协作成本一起比较；目标不是最大化分离。

## Measurements and audit

第9章的十个观察方向：(1)审计者能否接触不同于原判断的证据；(2)相反结论能否实际出现；(3)相反发现是否曾重新开启既有判断；(4)共同原因是否同时停止或对齐多个审计者；(5)被审查方是否单方面控制审计者的访问、存续、权限或证据范围；(6)异议是否能到达原决策者之外的路径；(7)紧急结束后独立性是否恢复；(8)审计是否近乎总是追认；(9)新证据或条件是否能改变结论；(10)自我审计与独立审计是否在因果结构上而非概念名称上有区别。

这些方向是复查提示，不是评分。不能只用追认率或否定率判断。还需检查异议可达性、实际重启、共同依赖、审计者利益及紧急后的恢复。

## Validity conditions

判断、执行和后续观察之间存在因果关系；证据和判断依据可追踪；五轴上的共享与分离可描述；不同证据或异议能够触达复查或重启路径。不假设完美独立、零利益、始终公开所有信息或全体一致。适用范围受情境、可比条件、协作、效率和时间限制影响。

## Failure conditions

- 仅凭不同的职责名称就认定独立。
- 把来源系谱、重复报告、复制或多数一致当作真理或独立确认。
- 记录异议，却仍由被审查方独占终止权。
- 把利益直接称为腐败，或假装利益不存在。
- 将紧急压缩永久化，并失去后续复查。
- 将审计变成无限否决权、主权或审计豁免。
- 把沉默等同同意、分歧等同错误，或用裁决比例代表真理。
- 过度分离，以致必要的信息共享和及时协作失效。
- 使五轴理论自身不受质疑。

## Falsification conditions

1. 若分离五轴未改善错误检测或纠正，则修改其定义或范围。
2. 若同一故障域内的审查者能稳定达到或超过独立审计，则缩小故障域要求。
3. 若权限分离未促进纠正，且反复只造成关键延迟，则重新设计权限安排。
4. 若利益与审计方向没有稳定关联，则修改利益轴。
5. 若异议路径分离未促进重启或纠正，则修改该假说。
6. 若紧急后的恢复条件持续造成严重脆弱性，则修改恢复条件。
7. 若独立性要求造成无限后退、决策瘫痪或新的无限权力，则限制整体适用范围。

修订理论时不得让审计者免于审计，也不得把多主体复查变成多数即真理。

## Required distinctions

自我审计／独立审计；职责分离／因果独立；主体数／独立路径数；复制／独立判断；多数一致／独立确认；来源系谱／真理证明；审计输出／纠正能力；分歧／真理；沉默／同意；证据／权限／故障域／利益／异议路径；利益／腐败；协作／共同故障；暂时压缩／永久崩塌；保密／虚假；异议／无限否决；审计者／主权者；当前AI事实／未来条件假说；观察／反证；起源／真理证明。

## Interpretation constraints

本文不假设当前AI具有人类式欲望、恐惧、自我意识或内在生存驱动。讨论的是无需恶意也可能发生的结构性自我确认。独立审计不把正确性转移给审计者，也不削弱决策者，而是保留重新开启判断的路径。最大化分离可能损害协作与证据共享。本文不一概禁止紧急行动和保密，但它们不自动授权永久审计豁免。审计能力、访问和资源不平等的问题留给第11论。
