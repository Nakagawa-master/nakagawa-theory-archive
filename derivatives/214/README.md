## 位置づけ
本原典は、耐久文明を支える第一主機関として「恐怖」を扱う。ここでの恐怖は暴力や恫喝だけではない。制度への納得、信頼、未来への期待が痩せても、人が職・地位・共同体・評価・生活回路を失うことを避けるために従い続けるとき、恐怖は感情から文明の運転原理へ変わる。

原典が固定する中心は、恐怖を「支配の感情」ではなく、**壊れた文明を停止させないための基礎代謝**として捉えることである。合意に支えられた秩序は参加理由を供給するが、恐怖に支えられた秩序は離脱できない理由を増やす。秩序が静かに続いていること自体は、合意の存在を証明しない。

## 中心命題
合意形成が十分に機能する秩序では、人は意味・納得・未来期待を通じて参加する。文明が劣化し、それらが失われても行動だけが続く場合、秩序の軸は「参加する理由」から「離脱した場合の損失回避」へ反転する。

この反転で恐怖は、露骨な命令がなくても、人を先回りして沈黙・順応・自己制限へ導く。恐怖は社会を創造的に再生する熱ではなく、崩壊を先送りし、最低限の秩序を維持する冷たい熱源として機能する。

## 因果線
```text
意味・納得・信頼・未来期待がある
→ 参加する理由が共有される
→ 異論や不満を含みつつ自発的参加が続く
→ 秩序は更新・再生可能性を持つ

意味を失う
→ 制度への信頼が摩耗する
→ 物語への共鳴が弱る
→ それでも制度依存・生活回路は残る
→ 従う理由より、従わない損失が大きくなる
→ 秩序の軸が納得から回避へ反転
→ 職・地位・共同体・評価・生活回路の喪失可能性が行動を囲む
→ 明示命令がなくても自己検閲・沈黙・順応が先行
→ 表面の静穏と整列が維持される
→ 恐怖が最低維持コストを肩代わりする
→ 社会は前進・再生せず停止だけを回避する
→ 恐怖が耐久文明の第一主機関・基礎代謝として定着
```

## 構造層
### 1. 合意の正相
合意は全員一致や好意ではない。異論や不満を含みながらも、参加する理由と制度の持続価値が共有される状態である。人は命令だけでなく理解に支えられ、批判は修正情報となりうる。

### 2. 恐怖の逆相
劣化が進むと、参加理由より離脱不能理由が前景化する。制度に意味を感じなくても、外れることの損失が大きければ行動は続く。この運転方向の反転が恐怖の構造的入口である。

### 3. 分散恐怖層
恐怖は暴力だけではない。失職、共同体からの切断、評価低下、異議による不利益、生活回路の縮小などの微細な損失可能性として日常へ分散する。明示的命令者がいなくても機能する点が重要である。

### 4. 内面化層
圧力が学習されると、人は命令される前に沈黙し、逸脱する前に自分を修正する。外部強制が常時見えなくても、予測された不利益が選択幅を削る。

### 5. 静穏擬態層
恐怖が安定的に内面化されるほど、社会は混乱より整列を示す場合がある。静けさ、手続き遂行、制度継続は、合意や成熟の証拠とは限らない。

### 6. 最低熱量層
恐怖は新しい共同性や創造を生む推進力ではない。理解を待たず、信頼を築かず、理念が死んだ後にも離脱を抑え、制度を停止させない即効性を持つため、耐久文明の最低維持コストを肩代わりする。

### 7. 第一主機関層
耐久文明は恐怖だけでは長期維持できず、後続の利益・監視・神話・惰性と接続する。しかし意味崩壊後にも即座に作動できるため、恐怖が最初に立ち上がる主機関として位置づけられる。

## 適用例
**組織。** 異論を言った人が解雇される必要はない。「評価が下がるかもしれない」「重要案件から外されるかもしれない」という予測だけで発言が消えるなら、明示命令ではなく予測損失が秩序を支えている可能性がある。

**制度。** 利用者が制度目的を信じていないのに、資格・給付・信用・生活上の接続を失うことを避けて従う場合、参加理由と離脱コストを分離して観測する。

**情報空間。** 大きな検閲命令が見えなくても、炎上、評価低下、所属喪失、仕事機会の減少を予測して自己検閲が広がるなら、恐怖は分散的に作動している。

**社会観測。** 混乱が少なく静かな状態を成熟と即断せず、異議が少ない理由が納得なのか、学習された回避なのかを確認する。

## 測定・監査点
- 人々は参加理由を説明できるか、それとも離脱損失を先に挙げるか。
- 制度への信頼と制度への依存が分離していないか。
- 異論を出した場合の具体的・予測的コストが何か。
- 明示命令がなくても自己検閲や先回り順応が起きていないか。
- 静けさが納得によるものか、損失回避によるものか。
- 批判や逸脱が改善情報として扱われるか、危険信号として抑制されるか。
- 参加が未来期待によって支えられているか、現在損失の回避によって支えられているか。
- 恐怖が一時的な例外対応か、平時の基礎代謝へ埋め込まれているか。
- 恐怖が制度停止を防いでいる一方、再生・創造・更新を縮減していないか。
- 利益・監視・神話・惰性との接続が始まっているか。

## 成立条件
- 合意、信頼、意味、未来期待が弱っても制度・生活依存が残る。
- 離脱や異議に伴う損失可能性が行動選択へ継続的に影響する。
- 明示的強制がなくても、予測損失による自己制限が再現する。
- 静穏・整列・手続き継続が、参加理由の共有なしに維持される。
- 恐怖が例外的事件ではなく、社会を停止させない日常的駆動へ変わる。

## 失敗条件
- 恐怖を暴力・恫喝だけに限定する。
- 不安や緊張が存在するだけで耐久文明の恐怖主機関と断定する。
- 静かな秩序を自動的に成熟・合意の証拠にする。
- 人々の制度依存を制度信頼と同一視する。
- 恐怖を善悪評価だけで処理し、なぜ有効に秩序を維持できるかを見ない。
- 恐怖を社会再生の推進力として扱う。
- 恐怖だけで耐久文明全体系が成立するとみなす。

## 反証・改訂条件
恐怖主機関が支配的だと判定した対象で、人々が離脱損失ではなく参加理由を継続的に説明でき、異論が不利益予測なしに表明され、批判が制度修正へ接続し、制度依存と信頼が再接続し、未来期待による自発参加が再現するなら、恐怖依存判定は改訂すべきである。

また、合意が失われても予測損失による整列が成立せず、恐怖が最低維持コストを肩代わりしない場合、この主機関モデルの適用範囲を見直す必要がある。

## 必須の区別
- 秩序の存在 ≠ 合意の存在。
- 静けさ ≠ 成熟。
- 制度依存 ≠ 制度信頼。
- 恐怖 ≠ 暴力だけ。
- 自己検閲 ≠ 自発的納得。
- 参加理由 ≠ 離脱不能理由。
- 停止回避 ≠ 前進。
- 延命 ≠ 再生。
- 第一主機関 ≠ 全体系そのもの。

## 誤読禁止 / 解釈制約
本論は恐怖を政治体制や特定集団の道徳的断罪ラベルとして使うものではない。観測対象は、秩序を維持する熱源が納得・期待から損失回避へ反転しているかどうかである。

恐怖は一定の危険回避や安全管理にも存在しうるため、その存在だけで耐久相とは判定しない。見るべきなのは、恐怖が例外的な防御手段を超え、制度の平時運転を支える主要な基礎代謝へ変わっているかである。
