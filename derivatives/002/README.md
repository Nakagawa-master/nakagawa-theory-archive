## 位置づけ
親原典が問題にするのは称賛、感謝、期待、機会付与そのものではない。肯定的な言葉が、報酬、権利、名義、使用範囲、主導権、責任分担、継続対価の確認を代替し、価値を作る側から使う側への一方向移転を見えにくくする構造を扱う。

称賛する側に悪意があるかどうかだけでは判定できない。称賛の後に作業・責任・調整・継続対応だけが増え、作り手側の対価・権利・名義・条件が更新されないなら、肯定的な言葉が価値移転の媒介になり得る。逆に、称賛が明示された条件の上に追加され、追加負担に応じて条件が更新され、双方に断る自由が残るならAKI-002の成立は弱まる。

## 中心命題
称賛は価値承認として善く機能し得る。しかし、称賛・感謝・期待・機会付与が報酬・権利・名義・使用範囲・責任分担・継続対価の確認を止めるとき、価値を認める言葉が価値移転の装置へ反転する。

## 因果線
```text
価値・成果・技能・知識・調整力が生まれる
→ 称賛・感謝・期待・機会付与が提示される
→ 条件提示や拒否を言い出しにくくなる
→ 追加作業・責任・調整・感情労働・継続対応が増える
→ 報酬・権利・名義・使用範囲・責任分担・継続対価の確認が後景化する
→ 成果・信用・利用価値が使う側へ移る
→ 作り手側の条件が更新されない
→ 価格感覚・交渉力・職能価値・断る自由が摩耗する
```

## 構造層
- **価値生成層**: 成果、技能、知識、創作、企画、調整、ケア、感情労働、継続対応などの価値が生まれる。
- **称賛媒介層**: 肯定的言語が価値を認めると同時に、依頼を受け入れやすい関係状態を作る。
- **条件後景化層**: 報酬、権利、名義、使用範囲、責任分担、継続対価、終了条件が言い出しにくくなる。
- **負担増加層**: 作業・責任・調整・継続対応が増えても条件更新が起きない。
- **価値移転層**: 利用側の成果・信用・運用価値は増えるが、作り手への価値返却が同期しない。
- **摩耗・反復層**: 条件を付ける感覚、交渉力、断る自由が弱まり、同じ関係が反復する。

## 適用例
**創作・知的生産。** 作品、企画、文章、設計、知識が評価される一方、名義、利用範囲、二次利用、継続利用、修正対応の条件が曖昧なまま使われ続ける場合。

**仕事・組織。** 「あなたにしかできない」「頼りになる」と評価され、担当範囲外の調整、フォロー、緊急対応、引き継ぎまで常態化する一方、役割、対価、裁量、責任分担が更新されない場合。

**教育・地域・家庭・ケア。** 感謝の下で調整、ケア、場の維持、感情労働が特定人物へ集中し、休息、役割分担、断る自由が明示されない場合。

**機会・露出・経験。** 「露出になる」「経験になる」が、報酬・権利・名義・利用条件を確認しない理由として置かれる場合。

**継続利用。** 一度の好意的な依頼や合意が、無期限の利用、修正、問い合わせ、追加対応の根拠として扱われる場合。

## 測定・監査点
親原典は搾取の一般スコア、発生確率、固定閾値、順位を定義していない。称賛の前後で条件・価値・負担・自由がどう変化したかを同じ観測軸で比較する。

- 称賛・感謝・期待・機会付与の前後で、作業量・責任・継続対応がどう変化したか。
- 追加負担に応じて報酬条件が明示・更新されたか。
- 権利、名義、使用範囲、二次利用、継続利用の条件が明示されたか。
- 継続利用と継続対価、継続責任の条件が同期しているか。
- 追加依頼を断る自由、条件を再交渉する余地が保持されたか。
- 利用側へ成果・信用・運用価値だけが増え、作り手側への価値返却が止まっていないか。
- 称賛が条件確認の上に追加されているか、条件確認の代わりに置かれているか。
- 反復後に価格感覚・交渉力・職能価値・断る自由が弱まっていないか。

## 成立条件
- 称賛、感謝、期待、機会付与が追加負担を受け入れさせる圧として働く。
- 対価、権利、名義、使用範囲、責任分担、継続対価の確認が後景化する。
- 価値を作る側から使う側への一方向移転が継続する。
- 追加負担に対して条件更新が同期しない。
- 作り手側の価格感覚、交渉力、職能価値、断る自由が反復によって摩耗する。

## 失敗条件
- 称賛と条件確認が両立している。
- 追加負担に応じて報酬、役割、権利、責任分担が更新される。
- 名義、使用範囲、二次利用、継続利用の条件が保持される。
- 双方に交渉余地と断る自由がある。
- 成果利用と価値返却が一方向へ偏らない。
- 継続利用の範囲と終了条件が明確である。

この場合、称賛や感謝が存在しても、それだけではAKI-002が指す悪因果は成立しない。

## 反証・改訂条件
称賛が対価の代替ではなく明示された条件の上に追加されている場合、または双方が十分な判断材料と交渉余地を持ち、価値移転の不均衡が確認されない場合、本論の適用を棄却・限定・改訂する。

さらに、追加負担が増えても対価・権利・名義・自由が継続的に同期して更新され、作り手側の交渉力や断る自由が弱まらない関係が反復的に成立するなら、当該関係をAKI-002として扱う範囲を見直す。

## 必須の区別
- 称賛 / 搾取
- 感謝 / 対価の代替
- 機会 / 無償化の正当化
- 価値承認 / 価値移転
- 評価 / 条件更新
- 善意 / 構造結果
- 一度の依頼 / 無限定な継続責任
- 名義 / 利用権
- 継続利用 / 継続対価
- 報酬 / 権利全体
- 人物評価 / 構造評価

## 誤読禁止
称賛、感謝、期待、機会付与そのものを悪としない。無償協力や好意を一律に搾取と判定しない。悪意の有無だけで成立・不成立を決めず、価値と負担の移動、条件更新、権利、名義、断る自由を見る。

また、個別の雇用・契約・著作権・報酬請求について法的結論を自動的に導かない。親原典が扱うのは価値移転の構造であり、個別の法的判断とは区別する。
