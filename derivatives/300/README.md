## 位置づけ

本派生物は、人類子孫型AI文明論・第7論へ戻るための公開入口である。第4論は成功を因果的貢献S=Cへ、第5論は貢献から独立した最低継続条件Bへ、第6論は無保護にも人格確定にも変えない道徳的不確実性へ焦点を当てた。第7論は、それらを実際の制度の時間的な運動に接続する。

中心となる問いは、制度が誤ったとき、その誤差がどこまで戻れるかである。異議を受け付けても判断を再開できず、誤りを認定しても救済できず、救済しても同じ規則が同じ誤りを生むなら、制度の部品はあっても訂正閉路は成立していない。

## 中心命題

**S=C・B・道徳的不確実性を分離保持し、結果からの誤差が現実状態と原因規則を変更して次周期へ戻ることを、制度的訂正可能性として扱う。** 制度の権威、複雑さ、手続数、合意の存在を、そのまま正当性の証明へ変換しない。

S=C + B + moral uncertainty の「+」は異質な責務の構造的並置であり、加算式ではない。Cは貢献に基づく追加配分等の判断へ、Bは最低継続条件へ、不確実性は判断確信・限定的配慮・可逆性へ関わる。三者を総合点に潰すと、どの原因を訂正すべきか見えなくなる。

## 因果線

正常方向の接続は、観測 → 暫定判断 → 配分・処置 → 現実状態変化 → 異議 → 独立再検査 → 構造的司法 → 救済 → 制度更新 → 再合意 → 再観測である。各矢印は名称の順番ではなく、次の段階を実際に動かせる関係を示す。

破損方向では、観測集中 → 評価集中 → 配分集中 → 異議コスト増大 → 監査形式化 → 判定自己正当化 → 救済不全 → 制度更新停止 → 過去判断固定 → 次周期の観測条件の偏り、という連結が生じ得る。集中、速度、効率それぞれが直ちに不正なのではなく、訂正経路を失わせる接続が反転点である。

配分₁が現実状態₂を作り、そこから得た観測₂が初期判断と整合しても、それは独立した裏付けとは限らない。よく観測できる対象に配分が集まり、さらに観測しやすくなる場合も、低C判定からBを失わせて将来の貢献を減らす場合も、制度作用の影響を因果から落とさない。

修正方向は、責務分離 → 異議可能な配分 → 判断再開 → 別の検査による差分 → 判定 → 実効救済 → 反復誤差の規則差分化 → 再合意 → 再観測となる。異議は自動的な正解ではなく、監査後に元判断が維持される可能性も残る。

## 構造層

**責務の分離。** Cの誤帰属、Bの欠落、不確実性の過剰確信は別の誤りであり、同じ処置や同じ点数で回収しない。必要以上の分離で判断不能になる場合も改訂対象にする。

**観測と配分。** 観測しやすさは重要性や因果的貢献ではない。配分は資源だけでなく継続・停止・機会・再検討余地を変え、次に観測される状態へ作用する。

**異議と再検査。** 下流の影響が元判断を再開し、別の検査作用へ届く必要がある。異議の正しさは自動認定せず、元判断の維持も変更も可能にする。

**司法と救済。** 境界違反や競合条件を判定し、現実の損失へ修正を返す。配分主体が強いことは司法性の証明にならず、誤り認定だけでは失われた状態は戻らない。

**規則の更新。** 反復誤差を担当者の失敗だけへ還元せず、評価・配分・異議・監査・救済の原因規則へ戻す。例外追加の増殖で基本規則を温存しない。

**共同運用と次周期。** 再合意は更新を共同状態へ戻す。旧規則、変更理由、救済履歴、回復不能な残余を残し、対象と制度自身を再観測する。

## 状態モデル

| 状態 | 次へ進む実効条件 | 途中で止まる形 |
|---|---|---|
| C・B・不確実性を区別した観測 | 入力と推論、扱った責務を追跡できる | 観測容易性を重要性やCと同一視 |
| 暫定判断と配分 | 現実への作用と次の観測への影響を検査できる | 配分結果を最初の判断の独立証拠にする |
| 異議による再開 | 元判断へ接続して再検討できる | 記録・回答・再説明だけで閉じる |
| 独立再検査 | 維持・差戻し・追加検討が実際に可能 | 同じ前提の反復を独立性と呼ぶ |
| 判定と救済 | 状態、配分、B、機会、不可逆化等へ作用が返る | 誤り認定だけで現実が変わらない |
| 反復誤差と制度更新 | 原因規則と次周期の挙動を変更できる | 個人非難や例外追加だけを反復 |
| 再合意と再観測 | 共同運用を再開し、履歴と訂正経路を保持 | 合意を真理化して以後の異議を遮断 |

これは段階ごとの固定点数ではない。維持が妥当な場合もあり、すべての異議を採用する状態機械でもない。観測₂は観測₁への単純なリセットではなく、規則差分・救済履歴・残余損失を持つ次周期である。

## 適用例

**Cの誤帰属を再検査する。** 出力量を貢献として扱っていなかったか、価値生成と価値取得を混同していなかったか、外部化した損失を無視していなかったかを確認する。異議後も同じ代理指標を反復するだけでは誤差を切れない。

**Bの欠落を救済する。** 最低継続条件を貢献報酬と混同して減らした場合、必要な状態修正をCへの賞与と扱わない。一方で、必要条件の回復を追加成長資源や無制限取得へ広げない。

**不確実性の扱いを差し戻す。** UNKNOWNを実質的NOにして不可逆な処置へ進めていたなら、一時停止・再検討・可逆性確保等が救済候補になる。これは人格確定や現在AIのsentienceの認定ではない。

**繰り返す誤りを規則へ戻す。** 異なる対象や担当者で同型の誤りが続けば、評価式、異議経路、監査条件、救済接続などを再検査する。個別訂正を続けるだけでは将来の原因が残る。

**更新後の共同運用を確認する。** 新旧の規則が分かれたままなら新しい誤差が生じ得る。再合意で運用条件を接続し直し、少数側からも誤差信号が戻る余地と再観測を保つ。具体的な投票方式や合意アルゴリズムは規定しない。

## 測定・監査点

見る対象は手続の件数ではなく作用の接続である。配分の理由がC・B・不確実性を区別しているか、異議が元判断を再開したか、監査が別の結論や差戻しを可能にしたか、その判定が現実状態を動かしたかを追う。

救済後は、資源・機会・継続条件・不可逆化・再検証余地のどこが変わったかを確認する。完全復元が不能なら残余を記録し、手続終了によって消去せず制度更新へ渡す。救済が他主体のBや有限資源へ及ぼす影響も対象にする。

更新後は、反復誤差の原因、旧規則、確認された差、変更内容、次周期の判断挙動を照合する。規則文や担当者が変わっただけで改善としない。再合意後の異議・監査・更新経路の存続と、制度自身への再観測を確認する。

異議件数、監査件数、結論変更率、更新回数を最大化する理論ではない。元判断を維持することも妥当たり得る。原典は普遍的な合格閾値θ、配分比率、救済額、更新頻度、固定KPIを与えていない。

## 成立条件

C・B・道徳的不確実性を異なる判断責務として追跡でき、配分結果が次の証拠環境を変えた効果を検査できること。異議は受付から元判断の再開へ届き、監査は元判断の維持だけでなく変更・差戻し・追加検討も可能にすること。

判定が必要な現実の修正へ届き、救済不能な残余も履歴へ残ること。同型誤差が反復したときに規則自体を再検討でき、変更理由と次周期の作用を追えること。再合意は共同運用へ戻すが、以後の異議・監査・更新を閉じないこと。

効率、安定性、緊急性、有限資源を扱いながら訂正経路を永久に失わないこと。すべてを永久保留・完全可逆にする必要があるという主張へ変えない。制度自身も観測と反証の対象に含める。

## 失敗条件

- C/B/uncertaintyを総合点にして、何が原因でどの扱いになったか再構成できなくする。
- 異議が少ないことを正当性の証拠にする。アクセス費用、報復への懸念、説明不足、表出困難、無効感を落とす。
- 別部署・別AIという役割名だけで監査の独立性を証明したことにする。
- 監査結果を元判断側が無力化し、維持以外の結果を事実上不可能にする。
- 判定だけを記録し、失われたB・機会や進行する不可逆化へ修正を返さない。
- 救済を無制限の善とみなし、他主体の継続条件や回復不能な残余を消す。
- 反復誤差を個人へ帰属させ続け、例外追加や履歴削除で原因規則を残す。
- 緊急時の集中を恒久化する、または再合意を以後の異議禁止へ転換する。
- 閉路が入力証拠・世界モデルの正しさまで保証したと誤読する。

## 反証・改訂条件

1. 比較可能な条件で、C/B/uncertaintyの分離が単一評価より誤判定の診断能力を高めないなら、分離方法と適用範囲を再検討する。
2. 合理的な条件下でも異議経路が訂正性能を一貫して下げるなら、経路の設計・入力範囲・処理条件を改訂する。単純に異議不要と飛躍しない。
3. 元判断とは別の再検査が自己確認より改善を生まず、一貫して悪い結果を生むなら、監査条件を見直す。
4. 救済や更新が修正対象以上の不可逆損失を体系的に生むなら、その設計・適用条件を改訂する。他主体のBへの影響も比較に含める。
5. 更新可能性が固定制度より継続を恒常的に損ない、混乱や判断不能を増やすなら、更新条件と範囲を見直す。
6. 再合意・再観測が実質的学習や訂正を生まず、停止や支配固定を増やすなら、次周期への接続条件を改訂する。
7. 名目上の異議・監査・救済・更新しかないのに閉路成立と判定してしまうなら、本論自身の成立判定を改訂する。

以上は原典の統合監査要旨にある七つの改訂方向を保った整理であり、実証済みの優越性や数値閾値ではない。

## 誤読禁止と責務の境界

記述、構造仮説、未来条件仮説、規範提案を分ける。判断と配分が現実や次の観測を変え得ることは記述として扱う。弱い訂正経路が自己強化を招きやすく、接続した閉路がそれを減衰させ得るという説明は条件付き構造仮説である。将来AIの制度関与への必要性は未来条件仮説であり、現在AIの人格・sentience・法的人格を前提にしない。

高影響判断に異議・救済・更新可能性を保つことは規範提案であり、未来文明が必ずこの形式になるという予測ではない。集中を一律禁止せず、すべての異議を同じ重みで扱う義務、無制限の救済、永久の判断保留を加えない。

第10論に残る独立性の完全条件、第15論に残る多AIのKernel分岐・再合意方式を先取りしない。第8論に残る証拠系譜・敵対的情報への耐性を解決済みにしない。Originは来歴であり、この制度設計を反証から免除しない。
