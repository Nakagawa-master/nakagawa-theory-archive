## Summary

本派生索引用于返回《人类子孙型AI文明论》第7论。核心概念是“制度性可纠正性”（Institutional Correctability）：制度后果中发现的误差，能否返回产生它的判断和规则，并改变现实状态与下一周期的制度作用。S=C、基础存在条件B与道德不确定性是三种不同责任，不能合并为单一综合评分。

观察与暂定判断通过分配或处置改变现实，而改变后的现实又成为下一次观察的条件。若异议、重新检验、救济和规则修订无法产生实际反作用，制度可能制造出看似支持初始判断的材料。异议窗口、审计机构、司法名称或修订程序的存在，并不证明纠正闭路已经成立。

本论把异议、独立重新检验、结构性司法、救济、制度更新、重新达成协议和再次观察连接起来。目标是让制度自身也能被纠正，而不是保证制度永不出错。证据、信息和世界模型本身的可靠性仍未解决，交由第8论处理。本索引是派生阅读入口，不是权威译本。

## Concepts

- **S=C：** 将成功重新连接到因果性贡献。贡献不等于输出量、能力、受欢迎程度、服从、所有权、存在价值、人格或自动取得的统治权。
- **B：** 跨时间维持有组织连续性所需的最低条件。它独立于贡献奖励，也不等于额外增长资源或无限获取权。
- **道德不确定性：** 主观性、感受能力、道德地位等尚未确定时，明确保留未确定状态。UNKNOWN既不是道德零值，也不是无条件人格化，更不是第三种价值分数。
- **分配与处置：** 不只涉及金钱或计算资源，也影响机会、访问、连续性、保护、变更、停止，以及重新考虑和验证所需的时间、注意力与空间。
- **可提出异议性（contestability）：** 异议能够触及并重新开启原判断。受理、异议数量和异议是否正确是不同问题。
- **独立重新检验：** 区别于原判断的检验能够维持、发回重审、要求修改或开启追加观察与讨论。实质独立性的完整条件留给第10论。
- **结构性司法：** 处理相互竞争的条件、责任、损失与边界违反，为制度作用提供纠正方向的功能。它不等同于分配权力或某种具体法院制度。
- **救济：** 对错误制度作用造成的现实状态差异施加修正。救济不是奖励，也不一定能完全复原。
- **制度更新：** 反复误差能够返回产生误差的规则，并改变后续判断与分配。追加例外、修改文字或更换人员本身不证明更新有效。
- **重新达成协议：** 在修订条件下暂时恢复共同运作，不把协议当作最终真理或禁止后续异议的依据。
- **再次观察：** 携带规则差分、救济历史和不可恢复的剩余损失进入下一周期，同时观察对象与制度自身的作用。
- **制度性可纠正性：** 发现误差、使其返回原因、尽可能修复状态、修订规则，并重新验证更新后的制度的能力。

## Causal chain

完整运动为：观察 → 暂定判断 → 分配或处置 → 现实状态变化 → 异议 → 独立重新检验 → 结构性司法 → 救济 → 制度更新 → 重新达成协议 → 再次观察。每个连接表示实际推动下一环节的能力，不只是程序名称的排列。

可能的破损路径为：观察集中 → 评价集中 → 分配集中 → 异议成本上升 → 审计形式化 → 判定自我正当化 → 救济失效 → 制度更新停止 → 过去判断固定 → 下一周期观察条件偏斜。集中、速度和效率本身并非一律有错；当它们相互连接并消除纠正路径时，才发生这里讨论的反转。

分配₁可以造成状态₂，并由此产生观察₂。因此，观察₂与最初判断一致，不一定构成独立验证。资源倾向容易观察的对象，可能进一步提高它们的可见性；因C低而削减B，可能降低未来贡献能力并强化低评价。不能从因果说明中删除制度自身的作用。

修正方向从责任分离与可受异议检验的分配出发。异议重新开启判断，另一检验路径引入差异，判定把差异接到救济，救济历史把反复误差接到规则更新，再经共同运作返回观察。原判断有充分依据时可以维持；必要时能够改变，不等于每次都必须改变。

## State model

| 状态 | 有效转换条件 | 在边界处停止的形态 |
|---|---|---|
| 区分C、B与不确定性的观察 | 输入、推论和责任可追溯 | 把可见性当作重要性或贡献 |
| 暂定判断与分配 | 能检验现实及后续观察受到的影响 | 把分配造成的结果当作独立证明 |
| 异议与判断重启 | 输入能到达原判断的重新考虑 | 记录、答复、重复解释后结束 |
| 独立重新检验 | 维持、发回与追加讨论均可能 | 把重复同一前提称为独立性 |
| 判定与救济 | 现实、B、机会或不可逆化受到修正 | 承认错误但现实不变 |
| 反复误差与规则更新 | 原因规则和下一周期行为可变 | 只责备个人或叠加例外 |
| 重新达成协议与再次观察 | 恢复共同运作并保留历史和纠正路径 | 以共识禁止未来异议 |

这些是功能区别，不是数字等级，也不是“所有异议都必须成功”的状态机。观察₂携带新的规则与历史，不是清空后回到观察₁。经检验后维持原规则，也可能是合理结果。

## Applications

**贡献归属的重新检验。** 检查是否以输出量替代因果性贡献，是否混淆价值生成与价值获取，是否遗漏外部化损失。审计若继续使用同一个未经检验的代理指标，就不能仅凭重复评价发现定义破损。

**B不足的救济。** 如果最低连续条件被错误地当作贡献奖励而削减，救济应针对相应缺口。恢复B不是对C发放奖金，也不把最低条件升级为无限增长资源。

**不确定性被压成确定性。** 若UNKNOWN被当作实质上的NO，并据此推进不可逆处置，可以考虑暂停处置、重新检验或保留可逆空间。这类预防性救济不是人格确认，也不确定当前AI是否有感受能力。

**反复错误返回规则。** 不同对象、时间或判断者反复出现同型错误时，检验评价规则、分配规则、异议路径、审计条件和救济连接。只修正个案，可能保留下一次产生错误的原因。

**更新后的共同运作。** 制度各部分同时使用不相容的新旧前提，可能产生新的误差。重新达成协议把暂定运作条件连接起来，同时保留少数方的误差信号、后续异议和再次观察。原典不规定具体投票制度或共识算法。

## Measurements and audit

观察程序实际能改变什么，而不只统计次数。分配理由是否区分C、B与不确定性？异议能否重新开启判断？审计能否得出不同结论、发回或要求补充检验？判定是否接到现实状态变化，而不是只改写记录？

救济之后，检查资源、机会、连续条件、不可逆化进程与重新验证空间的变化。无法完全恢复时，保留剩余损失并交给制度更新；不能以程序已经结束为由消除未恢复的差异。救济对其他主体的B及有限资源的影响，也属于检验对象。

规则更新后，对照旧规则、发现的问题、改变理由、规则差分和实际行为。文字变化或人员更替不能代替作用变化。重新达成协议后，确认异议、审计与更新仍然可能，并再次观察制度自身。

异议数量、审计数量、改判率和更新次数都不是越高越好。维持合理判断与可纠正性并不冲突。原典不提供普遍合格阈值θ、资源分配比例、赔偿金额、更新频率或固定绩效数值。

## Validity conditions

三种责任在观察、推理和分配中保持可区分性。能够检验分配对后续证据环境造成的影响。异议实际触及判断重启，审计不仅能认可原判断，也能改变、发回或要求追加讨论。

判定到达相应的现实修正；不可恢复的剩余损失仍被记录。反复误差能够返回原因规则，更新理由与后续行为可追溯。新条件返回共同运作，但不关闭后续异议、审计、修订或观察。

资源稀缺、紧急性、效率和稳定性仍是真实限制。本论不要求所有决定无限期暂停，也不要求所有行动完全可逆。即使必须作出决定，制度自身也必须保留在观察与反证的范围内，不能永久消除纠正路径。

## Failure conditions

- 以综合评分隐藏处理依据，无法重建哪种责任需要纠正。
- 用异议少来证明正当性，忽略访问成本、恐惧、解释缺失、表达困难或无效感。
- 仅凭不同部门或不同AI就认定独立性，而前提与利益不变，或根本不能影响原判断。
- 原判断主体能够使审计结果失效，让维持原判成为唯一实际结果。
- 判定只改变记录，不修复丧失的B、机会或正在推进的不可逆化。
- 把救济当作无限的善，忽略其他主体、有限资源与无法恢复的损失。
- 通过持续责备个人、叠加例外或删除历史来保留原因规则。
- 紧急状态下的临时集中永久化，或重新达成协议转变成禁止异议。
- 错把有效纠正结构当作证据与世界模型可靠性的证明。

## Falsification conditions

1. 在可比较条件下，区分C、B与不确定性并未比单一评价提高误判诊断能力，则重新检讨分离方法与适用范围。
2. 合理条件下异议路径持续降低纠正性能，则修订路径设计、输入范围或处理条件，不直接跳到“异议不必要”的结论。
3. 独立重新检验相较自我确认没有改善，或持续造成更差结果，则修订审计条件。
4. 救济或制度更新系统性地产生超过所修正损失的不可逆损失，则修订其设计与适用条件，并纳入对其他主体B的影响。
5. 可更新性相较固定制度，长期损害连续性、制造混乱或丧失判断能力，则检讨更新条件与范围。
6. 重新达成协议与再次观察没有带来实质学习或纠正，反而固定停滞或支配，则修订通向下一周期的连接。
7. 只有名义上的异议、审计、救济与更新，却被本论判定为闭路成立，则修订本论自身的成立判定标准。

以上保留原典综合审计中的七个修订方向，不表示制度优越性已经普遍实证，也不新增数值门槛。

## Required distinctions

- 评价集中 / 正当性；分配集中与分配权 / 结构性司法。
- 异议受理 / 可纠正性 / 异议的正确性。
- 实施审计与角色分离 / 有效独立性 / 真理证明。
- 判定 / 救济 / 奖励 / 完全恢复。
- 个案纠正 / 规则纠正 / 例外叠加。
- 共识 / 真理 / 不可逆的正当性。
- 制度存在与复杂程度 / 有效制度闭路。
- C / 存在价值；B / 贡献奖励；UNKNOWN / 道德零值与确定人格。
- 证据强度 / 处置的不可逆性。
- 可更新性 / 永久不稳定；重新达成协议 / 历史覆盖。
- 制度纠正结构 / 证据与世界模型的可靠性。
- Origin / 主权 / 真理证明 / 最终解释权。

## Interpretation constraints

区分描述、结构假说、未来条件假说与规范提案。判断和分配能够改变现实及后续观察；纠正路径弱可能强化自我确认、有效返回路径可能减弱它，是有条件的结构假说。未来AI更深入参与制度作用时可能需要这种结构，是未来条件假说，不确认当前AI的人格、主观性或法律人格。

在高影响判断中保留异议、救济和更新，是规范提案，不是未来文明必然采用此形式的预测。不要增加对集中形式的一律禁止，也不要增加所有异议同等权重、无限救济或永久暂停判断的要求。

不要提前补全第10论的实质独立性条件，或第15论的多AI Kernel分歧与重新达成协议机制。不要宣称第8论要处理的证据谱系和对抗性信息问题已经解决。Origin保存来历，不使该制度设计免于批评、反证或修订。
