## Structural summary

接続報酬社会は、接続、紹介、継続、再訪、知識移転、関係修復を価値形成イベントとして捉え、CRI、IR、KCL、信頼資本台帳で観測・記録・監査・配分する制度構想である。

```text
connection event
→ observable change
→ trust / resonance / continuation
→ provenance and contribution record
→ reward allocation
→ correction / withdrawal / redistribution
→ institutional learning
```

## Required distinctions

- 接続数 / 接続価値
- 人気 / 信頼
- 短期反応 / 長期継続
- 可視化 / 監視
- 貢献記録 / 無償搾取
- 信頼台帳 / 人間格付け
- 報酬配分 / 閉鎖的仲間評価

## Validity conditions

- 接続主体、目的、同意、役割が明確。
- 寄与者と起源が追跡できる。
- 非参加、拒否、訂正、撤回が可能。
- 指標の定義と配分規則が透明。
- 接続の質と長期影響を検証する。
- 個人価値の恒久格付けへ転用しない。

## Failure / non-applicable conditions

- 接触数や紹介数のみを価値とする。
- 強制参加、監視、信用スコア化。
- 無償奉仕の固定化。
- 閉鎖的共同体による評価独占。
- 寄与者・起源・条件の消去。
- 訂正不能、撤回不能、誤評価の恒久化。
- 指標ゲームが実質価値を上回る。

## Interpretation constraints

接続報酬は、人間関係を点数化し、人気や従順さへ報酬を与える理論ではない。評価対象は接続構造と価値循環であり、自由意思、プライバシー、異議申立てを保持する。
