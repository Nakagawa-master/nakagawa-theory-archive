## Summary
本原典は二層を扱う。第1層は、Fundsの修繕積立金運用を投資商品ではなく、将来修繕実行可能性・住民合意・説明可能性・生活基盤維持へ接続する「共同体資金防衛」として読むこと。第2層は、中川マスターが外部媒体記事でなぜその価値核を選び、どの誤読を避け、どの構成で読者へ翻訳したかという記事化判断を読むことである。

## Causal chain
デフレ前提の長期修繕計画 → インフレ・建築費・人件費・資材費上昇 → 修繕費超過 → 預金中心では実質修繕可能性低下 → 一時金・借入・延期圧力 → 共同体資金ゆえ高リスク運用は自由にできない → 説明可能・合意形成可能・制度適合な守りの運用が必要 → その社会機能を共同体資金防衛として記事化する。

## State / operational model
1. 資金の所有主体と目的拘束を確認する。
2. 名目額ではなく将来修繕実行可能性を見る。
3. リスク・制度・合意形成・説明可能性を同時に確認する。
4. 表面的な商品機能から社会機能の価値核を抽出する。
5. 誤読されやすい「投資」「利回り」中心の切り口を避ける。
6. 外部媒体記事で価値核が伝わる構成へ翻訳する。

## Applications
金融、不動産、制度産業、BtoBサービスなど、表面的な商品説明では価値が誤読されやすい対象の構造読解と記事設計に使う。投資助言や商品比較へ縮約しない。

## Measurements and audit
原典にない一般KPIは追加しない。監査対象は資金目的、将来修繕実行可能性、説明可能性、合意形成可能性、制度適合、価値核保持、記事化後の誤読リスク、原典への逆リンクである。

## Validity conditions
共同体資金としての目的拘束があり、将来維持機能への接続が観測でき、記事化において投資推奨ではなく社会機能として読めること。構造読解と記事化判断の二層が保持されること。

## Failure conditions
Fundsの商品説明だけに戻る、利回り優位性を中心にする、投資推奨や安全性保証に見せる、掲載媒体や企業の公式見解に見せる、記事化判断を消す場合は失敗である。

## Falsification conditions
Fundsの取り組みが実際には共同体資金防衛として機能せず、将来修繕実行可能性・説明可能性・合意形成への接続が観測できない場合、この読解は改訂対象となる。記事が継続的に投資推奨としてしか受け取られない場合も記事化判断の再設計が必要である。

## Required distinctions
- 投資商品 と 共同体資金防衛
- 個人資産 と 目的拘束された共同体資金
- Funds説明 と 中川構造読解
- 公開記事要約 と 記事化判断
- 利回り評価 と 将来修繕実行可能性
- 企業公式見解 と Nakagawa Masterの読解

## Interpretation constraints
投資助言、商品比較、利回り評価、安全性保証、マンション管理マニュアル、Funds公式見解へ縮約してはならない。二層構造と価値核抽出を保持する。
