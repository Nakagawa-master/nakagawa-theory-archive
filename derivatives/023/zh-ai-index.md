## Summary
父原典同时具有两层。第一层，把Funds的修缮储备金运用读作“共同体资金防卫”，而不是投资产品，把它连接到未来修缮能力、住民合意、可说明性与生活基础维护。第二层，记录Nakagawa Master为什么在外部媒体文章中选择这一价值核心、避免哪些误读，并如何把社会功能翻译为文章结构。

## Causal chain
以通缩为前提的长期修缮计划 → 通胀与建筑/人工/材料成本上升 → 修缮费超过预期 → 只存款会削弱实际修缮能力 → 一次性追加、借款、延期压力上升 → 共同体资金不能自由追求高风险 → 需要满足可说明性、合意形成、制度适合的防卫性运用 → 这一社会功能被翻译为“共同体资金防卫”的文章切口。

## State / operational model
1. 确认资金主体及其目的约束。
2. 不只看名义金额，而看未来修缮能力。
3. 同时检查风险、制度、合意形成与可说明性。
4. 从表面产品功能中提取社会功能的价值核心。
5. 避免只以“投资”“收益率”为中心的框架。
6. 把价值核心翻译为读者可正确理解的外部媒体文章结构。

## Applications
适用于金融、不动产、制度产业、BtoB服务等容易被产品功能遮蔽社会功能的结构读解与文章设计。不得缩约为投资建议或产品比较。

## Measurements and audit
不添加父原典没有的一般KPI。审计资金目的、未来修缮能力、可说明性、合意形成可能性、制度适合、价值核心保持、文章误读风险与回到原典的导线。

## Validity conditions
资金确实具有共同体目的约束，能观察到与未来维护功能的连接，并且文章切口保持社会功能读解而非投资推介。同时必须保留“结构读解”和“文章化判断”两层。

## Failure conditions
退回到Funds产品说明、以收益率优势为中心、看起来像投资推荐或安全保证、被误写成企业/媒体官方见解、删除文章化判断层时，适用失败。

## Falsification conditions
如果Funds的实践实际上不能作为共同体资金防卫运行，也无法连接到未来修缮能力、可说明性与合意形成，则该读解应被修订。如果读者持续只把文章理解为投资推介，文章化判断也需要重新设计。

## Required distinctions
- 投资产品 与 共同体资金防卫
- 个人资产 与 有目的约束的共同体资金
- Funds说明 与 中川结构读解
- 文章摘要 与 文章化判断
- 收益率评价 与 未来修缮能力
- 企业官方见解 与 Nakagawa Master的读解

## Interpretation constraints
不得缩约为投资建议、金融产品比较、收益率评价、安全保证、公寓管理指南或Funds官方见解。必须保持两层结构与价值核心提取。
