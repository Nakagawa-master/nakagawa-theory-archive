## 位置づけ
親原典は、修繕積立金を単なる投資対象ではなく、共同住宅の将来修繕能力を守る目的拘束された共同体資金として読む。Fundsの商品説明ではなく、なぜ「投資」ではなく「共同体資金防衛」という価値核を前面に置くのかという構造読解である。

親原典には、修繕積立金の社会構造と、Nakagawa Masterが外部記事でなぜ「共同体資金防衛」を切り口にしたのかを公開解体するメタ視点の二層がある。Fundsや外部媒体の公式見解、個別商品推奨とは区別される。

## 中心命題
修繕積立金は、個人が収益最大化を目指す余裕資金とは異なる。将来の修繕を実行し、建物の安全・資産価値・生活基盤を維持するための共同資金であり、収益性だけでなく、元本毀損リスク、流動性、説明可能性、合意形成、制度適合、将来修繕の実行可能性が同時に問題になる。

預金中心であってもインフレ・建築費・人件費・資材費上昇によって実質的修繕能力が低下し得る一方、高リスク運用も共同体資金の性質上自由には選べない。この二重制約を「共同体資金防衛」として読む。

## 因果線
デフレ・低インフレ前提の長期修繕計画
→ 建築費・人件費・資材費・工事費上昇
→ 同じ積立額では同じ修繕内容を実行しにくくなる
→ 名目残高が維持されても実質修繕能力が低下する
→ 一時金・借入・延期・仕様削減の圧力
→ 共同体資金なので高リスク運用へ自由に振れない
→ 元本保全・流動性・制度適合・説明可能性・住民合意を束で扱う
→ 金融商品選択ではなく将来修繕実行可能性の防衛として再定義される

## 構造層
### 1. 目的拘束資金
修繕積立金は将来修繕という目的に拘束され、個人投資資金と同じリスク許容度や撤退自由度を前提にしない。

### 2. 実質修繕能力
口座残高ではなく、その資金で予定修繕を実際に実行できるかが中心となる。名目残高が維持されても実質能力は低下し得る。

### 3. 共同体合意
管理組合資金は共同財産であり、何を守るための運用か、どのリスクを取るか、なぜその方法なのかを説明し、合意可能にする必要がある。

### 4. 制度適合
法令、管理規約、意思決定、商品特性、資金拘束期間との整合が必要であり、高い収益期待だけでは成立しない。

### 5. 公開解体
親原典は、Nakagawa Masterがなぜ「共同体資金防衛」を外部記事の価値核として採用したのかまで公開している。

## 測定・監査点
期待利回り、推奨配分、元本保証確率、安全スコアは親原典に定義されていない。現在の積立残高と将来修繕費、費用前提の更新、必要時流動性、元本変動、説明可能性、合意手続、制度適合、責任線が観測対象となる。

名目残高が増えていても工事費上昇がそれを上回れば実質修繕能力は低下し得る。高利回りでも流動性・元本・制度・合意条件が悪化すれば共同体資金防衛としては悪化し得る。単一の利回りや残高だけでは成立を判定できない。

## 成立条件
- 修繕積立金が目的拘束された共同体資金として扱われる。
- 費用前提が現実の工事費・物価変化に応じて更新される。
- 元本保全・流動性・制度適合・説明可能性・合意可能性が両立する。
- 将来修繕実行可能性が中心となる。
- 「共同体資金防衛」を価値核とした理由の公開解体層が保持される。

## 失敗条件
- Fundsの商品紹介や会社紹介だけでは原典の構造を表さない。
- 利回り比較や金融商品ランキングは共同体資金防衛と同義ではない。
- 高利回りは良い共同体資金運用の十分条件ではない。
- 預金残高だけでは修繕能力を表さない。
- 対象サービスの構造説明だけでは公開解体のメタ視点が欠ける。

## 反証・改訂条件
親原典の統合監査要旨では、「Fundsの投資商品紹介」「管理組合向け投資推奨」「企業称賛記事」「外部記事の要約・再構成」として読まれる割合が閾値θを上回る、または共同体資金防衛という読解軸が観測窓δ内に読者理解として成立しない現象Mが確認された場合、仮説Aを棄却・改訂する。

## 必須の区別
- 投資商品 ≠ 共同体資金防衛
- 個人余裕資金 ≠ 目的拘束された共同資金
- 名目残高 ≠ 実質修繕能力
- 高利回り ≠ 良い共同体資金運用
- Fundsの説明 ≠ 中川構造読解
- 企業・外部媒体の公式見解 ≠ Nakagawa Masterの構造読解
- 対象構造 ≠ 公開解体のメタ視点

## 解釈境界
親原典は投資助言、金融商品推奨、利回り保証、安全性保証、Fundsまたは外部媒体の公式見解ではない。「預金は悪い」「投資すべきだ」という単純な二択でもなく、共同体資金が将来修繕能力を維持する条件を扱う。
