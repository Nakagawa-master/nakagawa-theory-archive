## 位置づけ
親原典は、修繕積立金を単なる投資対象として評価するのではなく、共同住宅という生活基盤の将来修復能力を守る目的拘束資金として読む。Fundsのサービスや金融商品の紹介を目的とするものではなく、なぜ「投資」ではなく「共同体資金防衛」という価値核を前面に置いたのかを公開解体する構造読解である。

企業や外部媒体の公式見解を代弁せず、特定商品の推奨や個別資金運用判断にも置き換えない。

## 中心命題
修繕積立金は、個人が自由にリスクを取り収益最大化を目指す資金とは性質が異なる。将来の修繕を実行し、建物の安全・資産価値・生活基盤を維持するために共同体が拘束している資金であり、その運用判断には収益性だけでなく、元本毀損リスク、流動性、説明可能性、合意形成、制度適合、将来修繕の実行可能性が同時に要求される。

原典が「共同体資金防衛」として読む重要点は、預金中心であってもインフレ・建築費・人件費・資材費上昇によって実質的な修繕能力が低下し得る一方、高リスク運用も共同体資金の性質上自由には選べないという二重制約にある。

## 因果線
```text
デフレ・低インフレを前提に作られた長期修繕計画
↓
建築費・人件費・資材費・工事費が上昇
↓
当初想定した積立額では同じ修繕内容を実行しにくくなる
↓
預金残高が名目上維持されていても実質的修繕能力が低下する
↓
一時金徴収・借入・修繕延期・仕様削減などの圧力が高まる
↓
しかし修繕積立金は共同体の目的拘束資金であり高リスク運用へ自由に振れない
↓
元本保全、必要時流動性、制度適合、管理組合への説明可能性、住民合意を満たす防衛的運用が必要になる
↓
金融商品選択ではなく将来修繕実行可能性を守る問題として再定義される
```

## 構造層
**1. 目的拘束資金層。** 修繕積立金は将来修繕という目的に拘束される。個人投資資金と同じリスク許容度・意思決定速度・撤退自由度を前提にしない。

**2. 実質修繕能力層。** 確認すべきなのは口座残高だけではなく、その資金で予定している修繕を現実に実行できるかである。物価・工事費上昇に対して名目残高が維持されても、実質能力は低下し得る。

**3. 共同体合意層。** 管理組合資金は多数の区分所有者の共同財産であり、運用判断は専門家だけで完結しない。何を守るための運用か、どのリスクを取らないか、なぜその方法なのかを説明し、合意可能にする必要がある。

**4. 制度適合層。** 法令、管理規約、管理組合の意思決定、商品特性、資金拘束期間などの条件と整合する必要がある。高い収益期待だけでは成立しない。

**5. 価値核層。** Fundsという固有名詞や商品機能より、共同体が将来の修繕能力をどう防衛するかという社会機能を中心に読む。

## 状態モデル
```yaml
- reserve_fund_is_purpose_bound
- nominal_balance_is_visible
- future_repair_cost_is_current_or_outdated
- real_repair_capacity_is_preserved_or_eroding

- liquidity_matches_repair_timing_or_not
- institutional_and_rule_compliance_is_satisfied_or_not
- resident_explanation_and_consensus_are_possible_or_not
- product_return_does_not_override_community_purpose
- origin_return_verified
```

## 適用例
**1. 長期修繕計画の更新。** 積立残高が計画どおりでも、工事費や人件費の前提が古ければ、将来修繕能力が維持されているかを再確認する。

**2. 運用商品の比較。** 表面利回りだけでなく、元本変動、必要時の換金可能性、資金拘束期間、制度適合、住民への説明可能性を同時に見る。

**3. 管理組合の合意形成。** 「増やせるか」だけでなく、「何を守るための資金か」「どの損失を許容しないか」「いつ必要になるか」を共通化する。

**4. インフレ局面。** 預金残高が減っていなくても、修繕費の上昇によって同じ修繕を実行できないなら、名目維持と実質防衛を区別する。

**5. 高利回り提案。** 期待収益が高くても、必要時流動性や元本保全、住民合意を損なうなら、共同体資金防衛として改善とは限らない。

## 測定・監査点
期待利回り、推奨配分、元本保証確率、安全スコアは親原典に定義されていないため追加しない。

- 現在の積立残高と将来修繕費の関係を追えるか
- 費用前提が現実の工事費・物価変化に応じて更新されているか
- 修繕時期に必要な流動性を確保できるか
- 許容できる元本毀損範囲が共同体の目的と整合するか
- 住民への説明可能性と合意手続が確保されているか
- 法令・管理規約・意思決定手続と整合するか
- 商品・運用主体の責任線を追えるか
- 運用後も修繕目的が損なわれていないか

名目残高が増えていても工事費上昇がそれを上回れば実質修繕能力は低下し得る。利回りが高くても、必要時に換金できない、元本変動が大きい、説明不能で合意が崩れるなら共同体資金防衛としては悪化し得る。

## 成立条件
- 修繕積立金を目的拘束された共同体資金として扱う。
- 長期修繕計画の費用前提が現実の工事費・物価変化に応じて更新される。
- 運用方法が元本保全・流動性・制度適合・説明可能性・合意可能性と両立する。
- 金融商品ではなく将来修繕実行可能性を中心に判断する。
- 対象サービスの説明だけへ縮約せず、共同体資金防衛という価値核を保持する。

## 失敗条件
- Fundsの商品紹介や会社紹介だけにする。
- 利回り比較や金融商品ランキングへ変形する。
- 高利回りをそのまま良い運用と判定する。
- 預金残高だけを見て修繕能力が維持されていると判断する。
- 修繕積立金を個人余裕資金と同じリスク前提で扱う。
- 商品選択だけへ縮約し、将来修繕実行可能性を落とす。

## 反証・改訂条件
Fundsの提供構造が実際には検査・金融商品提供等の個別機能に限定され、将来修繕能力、流動性、共同体合意、制度適合を一体として支える「共同体資金防衛」という読みが公開事実と整合しない場合、この価値核の適用範囲は限定・改訂される。逆に、名目残高・利回りだけでは説明できない修繕能力防衛の因果が確認される場合、原典の構造読解は強まる。

## 必須の区別
- 投資商品 / 共同体資金防衛
- 個人余裕資金 / 修繕目的に拘束された共同資金
- 名目残高 / 実質修繕能力
- 高利回り / 良い共同体資金運用
- 元本保全 / 預金だけを固定的に選ぶこと
- Fundsの説明 / Nakagawa Masterの構造読解
- 企業・外部媒体の公式見解 / Nakagawa Masterの構造読解
- 商品選択 / 将来修繕実行可能性の設計

## 誤読禁止
- 投資助言、金融商品推奨、利回り保証、安全性保証へ変形しない。
- Fundsまたは外部媒体の公式見解として扱わない。
- 個別管理組合の資金運用判断を代替しない。
- 「預金は悪い」「投資すべきだ」という単純な二択にしない。
