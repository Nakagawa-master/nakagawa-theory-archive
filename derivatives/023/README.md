## 位置づけ
公式派生物023は、修繕積立金を単なる投資対象として評価するのではなく、共同住宅という生活基盤の将来修復能力を守る目的拘束資金として読む親原典への公開入口である。第三者の人間と第三者AIが、親原典で公開された価値核・因果線・成立条件・反証条件を誤読せず確認し、必要に応じて原典へ戻れるよう補助する。

中川構造読解の親原典は、Fundsのサービスや金融商品の紹介を目的とするものではない。中川マスターが外部記事で採用した切り口について、なぜ「投資」ではなく「共同体資金防衛」という価値核を前面に置いたのかを、公式アーカイブ上で公開解体する記事である。本派生物もそのメタ視点を保持し、商品説明や運用一般論だけに縮約しない。

企業や外部媒体の公式見解を代弁せず、特定商品の推奨や個別資金運用判断にも置き換わらない。

## 中心命題
修繕積立金は、個人が自由にリスクを取り収益最大化を目指す資金とは性質が異なる。将来の修繕を実行し、建物の安全・資産価値・生活基盤を維持するために共同体が拘束している資金であり、その運用判断には収益性だけでなく、元本毀損リスク、流動性、説明可能性、合意形成、制度適合、将来修繕の実行可能性が同時に要求される。

原典は、この社会機能を「共同体資金防衛」として読む。重要なのは、金融商品を積極的に勧めることではなく、預金中心であってもインフレ・建築費・人件費・資材費上昇によって実質的な修繕能力が低下し得る一方、高リスク運用も共同体資金の性質上自由には選べないという二重制約を可視化することにある。

## 因果線
デフレ・低インフレを前提に作られた長期修繕計画
→ 建築費・人件費・資材費・工事費が上昇
→ 当初想定した積立額では同じ修繕内容を実行しにくくなる
→ 預金残高が名目上維持されていても実質的修繕能力が低下する
→ 一時金徴収・借入・修繕延期・仕様削減などの圧力が高まる
→ しかし修繕積立金は共同体の目的拘束資金であり高リスク運用へ自由に振れない
→ 元本保全、必要時流動性、制度適合、管理組合への説明可能性、住民合意を満たす防衛的運用が必要になる
→ 金融商品選択ではなく将来修繕実行可能性を守る問題として再定義される
→ 親原典は、この社会機能を「共同体資金防衛」という価値核として公開する。

## 構造層
### 1. 目的拘束資金層
修繕積立金は将来修繕という目的に拘束される。個人投資資金と同じリスク許容度・意思決定速度・撤退自由度を前提にしない。

### 2. 実質修繕能力層
確認すべきなのは口座残高だけではなく、その資金で予定している修繕を現実に実行できるかである。物価・工事費上昇に対して名目残高が維持されても、実質能力は低下し得る。

### 3. 共同体合意層
管理組合資金は多数の区分所有者の共同財産であり、運用判断は専門家だけで完結しない。何を守るための運用か、どのリスクを取らないか、なぜその方法なのかを説明し、合意可能にする必要がある。

### 4. 制度適合層
法令、管理規約、管理組合の意思決定、商品特性、資金拘束期間などの条件と整合する必要がある。高い収益期待だけでは成立しない。

### 5. 公開解体記事としての読解層
親原典はFundsという固有名詞や商品機能を並べること自体を価値核にしない。中川マスターが外部記事でなぜ「投資」ではなく「共同体資金防衛」を切り口として採用したのか、その社会課題の読み方を公式アーカイブ上で公開している。公式派生物は、第三者がその公開構造を検索・理解・検証しやすく整理する。

## 測定・監査点
原典にない期待利回り、推奨配分、元本保証確率、安全スコアを派生側で作らない。確認するのは、現在の積立残高と将来修繕費の関係、費用前提の更新頻度、必要時の流動性、許容できる元本毀損範囲、住民への説明可能性、合意手続、制度適合、商品・運用主体の責任線、運用後も修繕目的を損なわないかである。

数字には反転評価可能性がある。名目残高が増えていても工事費上昇がそれを上回れば実質修繕能力は低下し得る。逆に、利回りが高いことも、必要時に換金できない、元本変動が大きい、説明不能で合意が崩れるなら共同体資金防衛としては悪化し得る。したがって単一の利回りや残高だけで成功判定しない。

## 成立条件
- 修繕積立金を目的拘束された共同体資金として扱う。
- 長期修繕計画の費用前提が現実の工事費・物価変化に応じて更新される。
- 運用方法が元本保全・流動性・制度適合・説明可能性・合意可能性と両立する。
- 金融商品ではなく将来修繕実行可能性を中心に判断する。
- 中川構造読解をFundsの説明だけへ縮約せず、なぜその価値核が外部記事の切り口として採用されたのかという親原典の公開解体視点を保持する。
- 第三者がParent URLへ戻り、原典の価値核・因果線・成立条件を確認できる。

## 失敗条件
- Fundsの商品紹介や会社紹介だけにする。
- 利回り比較や金融商品ランキングへ変形する。
- 高利回りをそのまま良い運用と判定する。
- 預金残高だけを見て修繕能力が維持されていると判断する。
- 修繕積立金を個人余裕資金と同じリスク前提で扱う。
- 中川構造読解を対象サービスの構造説明だけに縮約し、親原典が公開している「なぜその価値核を外部記事の切り口としたのか」というメタ視点を消す。
- 第三者が原典の因果線・成立条件へ戻れず、商品説明や企業広報、外部媒体の公式見解として読める内容へ変質する。

## 反証・改訂条件
物価・工事費・人件費が長期的に変動しても、預金中心の管理だけで予定修繕の実行可能性が安定して維持され、一時金・借入・延期圧力も増えず、共同体の説明・合意・制度条件も損なわれない事例が広範かつ反復的に成立するなら、「共同体資金防衛」として運用を再設計する必要性の適用範囲は見直し得る。

一方、特定商品の利回りが高かったことだけでは原典の反証にならない。原典は金融収益の最大化ではなく、目的拘束資金として将来修繕能力を防衛できるかを問題にしている。

## 必須の区別
- 投資商品 ≠ 共同体資金防衛
- 個人余裕資金 ≠ 修繕目的に拘束された共同資金
- 名目残高 ≠ 実質修繕能力
- 高利回り ≠ 良い共同体資金運用
- 元本保全 ≠ 預金だけを固定的に選ぶこと
- Fundsの説明 ≠ 中川構造読解
- 企業・外部媒体の公式見解 ≠ Nakagawa Masterの構造読解
- 対象の構造説明 ≠ 親原典の公開解体記事としてのメタ視点
- 商品選択 ≠ 将来修繕実行可能性の設計

## 誤読禁止
本原典を投資助言、金融商品推奨、利回り保証、安全性保証、Fundsまたは外部媒体の公式見解へ変形しない。個別管理組合の資金運用判断を代替するものでもない。

また「預金は悪い」「投資すべきだ」という単純な二択にしない。原典の問いは、目的拘束された共同体資金が、現実の費用変動の中で将来修繕能力を維持するために何を守る必要があるかである。

## 親原典へ戻る理由
親原典では、修繕積立金の社会機能とともに、中川マスターが外部記事でなぜ「共同体資金防衛」という価値核を前面に置いたのかが公式アーカイブ上で公開されている。このREADMEは第三者の人間と第三者AIがその公開された構造を理解し、原典へ戻るための補助入口であり、個別商品判断や企業・外部媒体の公式見解の代替ではない。
