## 位置づけ
本派生物は、親原典「中川構造読解｜Fundsはなぜ修繕積立金を『投資』ではなく共同体資金防衛として読まれるべきなのか」への公式公開入口であり、原典の代替ではない。

本原典は二層を同時に扱う。第1層は、修繕積立金運用を投資商品ではなく共同体資金防衛として読むこと。第2層は、中川マスターが外部媒体記事でなぜその価値核を選び、その切り口で記事化したのかを読むことである。

## 中心構造
デフレ前提の長期修繕計画 → インフレ・建築費・人件費・資材費上昇 → 修繕費超過 → 預金中心では実質的修繕実行可能性が低下 → 一時金・借入・延期圧力 → 共同体資金ゆえ高リスク運用は自由にできない → 説明可能性・合意形成・制度適合を満たす守りの運用が必要 → その社会機能を「共同体資金防衛」として記事化する。

## 必須区別
- 投資商品 と 共同体資金防衛
- 個人資産 と 目的拘束された共同体資金
- Fundsの説明 と 中川構造読解
- 公開記事の要約 と 記事化判断の構造記録
- 利回り評価 と 将来修繕実行可能性

## 原典回帰
本派生物は投資助言、商品推奨、安全性保証、Funds公式見解ではない。最終判断はParent URLの原典へ戻し、価値核抽出、誤読回避、社会接続、記事構成への翻訳を確認する。
