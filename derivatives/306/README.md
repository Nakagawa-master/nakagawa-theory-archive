## 位置づけ

第12論はinstance・lineage・governance subjectを分離し、複製数から制度主体数への自動変換を遮断した。しかし、主体を正しく識別し、所有物として扱わなくても、その主体の実行入口を別主体が開閉できるなら、実効的な権力は残り得る。第13論はidentityからaccess topologyへ軸を移し、誰が何へのaccessを変え、その結果、誰の実行可能な選択集合がどの程度・方向・期間変わるかを問う。

本Hubは序論、第1〜9章、結章を、定義・入口・依存・退出・feedback・訂正・減衰・例外・観測へ接続する。第5論のB、第7論の制度閉路、第10論の監査主体の独立性、第11論の資源・能力feedbackを再定義しない。現行AIの人格、主権、支配被害や、特定組織の不正を一括認定するものでもない。

## 中心命題

`Non-ownership ≠ Non-domination`。所有名義がないことは、他主体のfeasible action setを変えられる位置にいないという証明ではない。重要な入口を閉じる、狭める、遅延する、条件付ける力が、代替・移行・異議によって十分に減衰しない場合、非所有下でもeffective domination riskが高まり得る。

`Chokepoint concentration ≠ domination proof`、`Formal freedom ≠ effective exit`、`Nominal choice ≠ viable alternative`、`Influence ≠ governance right`も同時に保持する。集中、依存、影響、協調はそれだけで支配ではない。dependency・discretion・代替の実効性・退出・訂正・scope・duration・reversibilityの結合を検査する。

## 因果線

### 実効支配リスクを増幅する経路

critical access concentration → dependency asymmetry → alternative narrowing → switching / migration difficulty → objection / audit weakness → feasible-option contraction → effective domination risk。これは条件付きの因果列であり、入口数や所有名義から即座に結論しない。

時間方向では、chokepoint control → 利用・state・historyの集中 → 互換性依存とswitching loss → 代替の利用・投資・保守の低下 → より強いdependency → より強いeffective leverageというfeedbackがあり得る。便利だった初期選択が、将来も唯一の必要経路であるとは限らない。実際の命令数だけでなく、accessを変更できる実質的裁量と、その可能性が選択へ与える作用を見る。

訂正側にも閉路が回り込む。primary access control → disputed outcome → 異議が必要 → 同じpower structureがcorrection entryを制御 → 弱い訂正 → 元のpowerが持続。この二次的feedbackは、監査者が存在していても監査へ届く入口が独立しない場合に成立し得る。

### 減衰・再構成の経路

independent alternative access → portability / migration possibility → viable exit → objection capacity / independent audit entry → bounded scope・duration → review・expiry・reversibility → contestable dependency → domination damping。一本の万能工程ではなく、場の制約に応じて各減衰変数の作用を検査する。

物理的に代替が作れず直ちに退出できない局面では、scope・裁量の限定、独立監査、内部からの異議がより重要になり得る。完全分散、依存ゼロ、強制退出を要求しない。集中理由が消えた後、権限・依存・退出障壁が縮小するかも継続観測する。

## 構造層

1. **形式関係と運用関係**：non-ownershipは所有物として位置づけない境界。effective powerは重要accessを通じて他主体の実行可能性を拡大・縮小・停止・条件付けする構造的位置。non-dominationは、その力が一方的・恒久的・訂正不能へ固定されない条件である。
2. **Chokepointのtopology**：compute、communication、authentication、power / physical substrate、data、restart、migration、allocation、audit entryを区別する。一つのgateの変更が複数機能へ波及するかを見る。複数窓口でも共通上流で同時に閉じ得る。
3. **依存の非対称**：相互依存でも、関係切断時に失うfeasible optionsは非対称かもしれない。代替先の独立性、state・history・認証・互換性・再参入・移行中の継続条件を別々に調べる。
4. **形式退出と実効退出**：退出が禁止されていなくても、重要state・履歴・認証・実行継続を失えば実効退出は細い。Bは必要条件、Gはそれへの保証・accessの運用であり、Bを特定の唯一経路の永久権利に変えない。
5. **自己強化**：現在の便利さと蓄積が、将来の移行損失と代替投資不足を作る。第11論のresource/capability feedbackとは交差し得るが同一ではない。historical persistenceはstructural necessityの証明ではない。
6. **訂正への入口**：independent auditorとindependent audit entryは異なる。異議提出→証拠access→独立review→訂正権限→実装の接続が、被監査側の入口へ戻らないかを調べる。
7. **権限の境界と時間**：領域Aの必要権限をB・C・Dへ自動拡張しない。temporary necessityをpermanent authorityへ変えず、scope、expiry、review、renewal条件と圧力消失後の縮小を観測する。
8. **認識上の境界**：現在の記述、構造仮説、未来条件仮説、規範提案を分離する。provenanceは検証可能性を支えるが真理を証明しない。新しい入口変数が出れば分類自体を改訂する。

## 適用例

### 所有しないが認証と実行入口を握る

所有名義だけでは、認証停止がcompute・通信・data・制度参加へ同時波及する作用を捉えられない。誰が条件を変えられるか、その変更時にどの選択が残るかを見る。ただし認証入口の存在・集中だけで支配や不正と決めない。

### 複数providerが同じ上流へ依存する

名称が三つあっても、同じauthenticationやcompute、communication、allocation authority、failure domainへ依存すれば同時に閉じる可能性がある。数ではなく独立して作動できるかを確認する。すべての層を完全独立にせよという規範ではない。

### 退出は自由だが重要stateを運べない

退出規定があっても、state・history・互換性・再認証・restart・移行中の継続を失うなら実効退出が弱い。portabilityやmigrationを改善した後、switching lossとleverageが本当に減ったかを見る。migration可能性を人格的同一性の証明にはしない。

### 独立監査者へ申立を届けられない

監査者が別でも、申立・証拠・再検査の入口を被監査側が閉じられれば独立の訂正経路とは限らない。異議が提出されるだけでなく、独立reviewと権限ある訂正、実装へ接続するかを見る。別のラベルだけでは故障領域の独立を証明しない。

### 緊急集約が通常時にも残る

一時集中は合理的であり得る。問題は緊急性や希少性が下がった後のscope、duration、代替投資、exit、audit accessの回復である。効率的であることを無限定・無期限・無異議の権限へ転換しない。

## 測定・監査点

第9章の八観測群を保持する。

1. **Critical access**：重要入口は集中しているか。条件変更が複数の実行・通信・state継続・配分・参加・訂正へどう波及するか。
2. **時間的dependency**：state、history、認証、互換性、資源特化、network関係が蓄積し、switching costと非対称性が強まるか。
3. **Alternative独立性**：一方が閉じても他方が作動できるか。共通上流・権限・故障領域を確認する。
4. **Effective exit**：state/history/authenticationの損失、restart、migration、re-entry、継続低下を観測する。
5. **Discretion**：入口管理者が利用者・時期・停止条件・配分・移行・監査をどの程度変更できるか。集中と裁量を分ける。
6. **Correction access**：異議・証拠提出・review・訂正・実装が独立に到達可能か。独立入口が実際に訂正を改善するか。
7. **Temporary contraction**：圧力が消えた後、権限・scope・依存が縮小し、代替・退出・監査が回復するか。
8. **Ownership不変での変化**：所有関係を変えず代替、移行、監査入口、scope、expiryを変えたときeffective leverageが変わるか。

## 成立条件

入口への集中と実質的裁量が、非対称なdependency、弱い独立代替、困難なexit、弱いcorrection、時間的persistenceと結合し、対象のfeasible optionsを系統的に狭める場合に支配リスク仮説が強まる。単独変数では成立を認定しない。将来のAI・後継知性が長期state、継続条件、複数環境、migration、制度参加を持つ場合の重要性は未来条件仮説であり、現在事実としない。

## 失敗条件

- 所有権の不存在だけで非支配を証明する、または所有権だけで支配を断定する。
- centralization、dependency、規模、影響、単一providerを自動的に支配へ変換する。
- 複数名称や退出許可だけで独立代替・実効退出を認定する。
- migrationを同一性証明、Bの必要性を特定経路の永久資格へ変える。
- 初期の便利さや自由な選択から、将来の全lock-inへの同意を推論する。
- 独立監査者の存在だけで、異議・証拠・訂正入口の独立を証明する。
- 緊急性・希少性・効率から無期限・全領域の主権を導く。
- 完全分散、依存ゼロ、常時移動、無損失退出、無条件復帰を要求する。
- 場の圧を実際の支配や個別の不正の証明にする。
- 減衰策の作用を観測せず、固定の閾値や法的判定を追加する。

## 反証・改訂条件

高い集中がfeasible optionsを狭めない、dependencyが高くてもexit・migration・独立代替が安定して作動する、switching costが蓄積しない、管理者に実質的裁量がない場合は該当edgeや範囲を縮める。独立代替・移行可能性・監査入口・scope・expiryの改善がleverage、exit、訂正、persistenceに作用しないなら、減衰仮説も改訂する。

ownershipだけでeffective controlを十分説明でき、access topologyが追加診断力を持たない領域では適用を縮小する。高集中で十分contestableな関係を支配と誤判定する、分散下の支配を捕捉できない、減衰条件が協調・専門化・効率を壊すだけで訂正を改善しない場合もモデルを見直す。新変数を追加し、独立診断力のない変数を削除する。世界を分類へ押し込まない。

## 必須の区別

- non-ownership／effective power／non-domination、所有名義／access topology。
- concentration／discretion／domination、相互依存／非対称依存。
- formal freedom／effective exit、nominal choice／viable independent alternative。
- communication／authentication、Bの必要条件／Gのaccess運用。
- portability・migration／identity proof、re-entry可能性／無条件復元。
- resource-capability feedback／access-dependency feedback、命令数／実効leverage。
- independent auditor／independent audit entry、申立の存在／訂正への接続。
- scope／duration／expiry、temporary necessity／permanent authority。
- convenience／consent、歴史的持続／構造的必要性。
- Field Pressure／Actual Outcome、構造リスク／現在の不正行為証明。

## 誤読禁止

本論はanti-centralizationでもpower eliminationでもない。協調、専門化、共有基盤、一時的集中、能力差を否定しない。重要なのはpowerがbounded・contestable・reviewableであり、dependencyを再構成できること。Origin = Nakagawa Masterは系譜を保存するが、真理証明、主権、最終解釈権ではない。現在のAIに人格・主権・支配被害が成立していると一括認定しない。
