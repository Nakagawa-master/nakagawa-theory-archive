## Summary

第12论区分instance、lineage与governance subject，但正确识别主体并不能证明该主体不受实效支配。第13论把分析轴从所有名义和身份转向access topology：谁能改变哪些重要功能的入口，变化会让谁的实际可执行选择集合发生何种、何程度、何持续时间的变化？即使没有所有权，compute、通信、认证、电力、data、restart、migration、allocation或audit entry的入口控制，也可能影响他者实际能做什么。

核心边界为`Non-ownership ≠ Non-domination`。同时保留`Chokepoint concentration ≠ domination proof`、`Formal freedom ≠ effective exit`、`Nominal choice ≠ viable alternative`、`Influence ≠ governance right`。集中、依赖、影响、协调、规模、单一提供者本身并非支配判决；需检查依赖非对称、实际裁量、替代、退出、纠正、范围、期限和可重构性的结合。

本索引是解释与检索的辅助派生物，不自称官方定本翻译或独立原典。当前结构描述、结构假说、未来条件假说、规范建议应分开。它不认定现有AI的人格、主权或支配受害地位，也不以结构风险证明某一组织当前实施不正当行为。非支配不是消灭所有权力或所有依赖。

## Concepts

| 概念 | 原典中的作用 | 不自动导出的结论 |
|---|---|---|
| Non-ownership | 不把智能定义为所有物的关系边界 | 所有实效权力均已消失 |
| Effective power | 通过重要access扩展、缩小、停止、延迟或附条件地改变他者可执行选择的位置 | 正当主权、治理权或已成立支配 |
| Non-domination | 防止依赖固定为单方面、永久、不可纠正的权力的条件 | 无依赖、无协调、完全分散、能力平等 |
| Chokepoint | 入口变化非对称地波及多个执行可能性的关键入口 | 仅指单一物理设施，或集中即支配 |
| Dependency asymmetry | 关系切断时选择损失及重构能力的不对称 | 双方互相利用便意味着对称 |
| Viable alternative | 真正能运作、具相关独立性的替代路径 | 名称、界面、提供者数量足以证明独立 |
| Effective exit | 离开依赖并在另一执行路径重构重要持续条件的可能性 | 退出许可、强制退出、零成本或同一性证明 |
| Audit entry | 到达异议、证据、review、纠正与落实的入口 | 审计者独立即代表入口独立 |
| Scope / duration | 权限的领域与时间边界 | 局部必要性自动扩为全面永久权力 |
| Reversibility | 条件变化时重构配分、provider、迁移、异议、审计和权限的能力 | 删除过去、零费用或无条件复原 |

compute、communication、authentication、power/physical substrate、data、restart、migration、allocation、audit entry各有不同功能。通信通道可存在却不能认证，认证可存在却没有通信通路。B是需要什么，G是如何保证或治理对B的access；第13论保留两者分离，不重新定义B，也不把需要转换为某一主体永久掌握唯一通路的资格。

migration在本论是退出与依赖的变量，并非形而上学同一性证明。存在另一个环境，不代表能把重要state和history带过去、重建认证并持续运行。re-entry可能性也不等于无条件恢复全部状态；它用于观察退出是否被不必要地转为永久排除。所有层完全独立不是这里的规范。

## Causal chain

风险路径：critical access concentration → dependency asymmetry → alternative narrowing → switching/migration difficulty → objection/audit weakness → feasible-option contraction → effective domination risk。每条edge均须观察，不是以入口数或所有名义直接给出结论。相同所有关系下，裁量、可替代性、纠正可达性可以不同。

时间反馈：当前入口优势 → 重复利用、state/history集中 → 专用互换条件与认证联系 → switching损失增加 → 替代低利用、低投资或低维护 → 更深的未来dependency → 更强effective leverage。初期使用方便、稳定的路径可以是合理选择，但不证明后来的唯一必要性。`Current rationality ≠ permanent necessity`，`Historical persistence ≠ structural necessity`。没有明确禁止，也不等于替代仍被维护。

第11论研究compute、能力、评价、配分、未来resource的反馈；第13论研究入口控制、使用方难以离开的程度、选择缩减和入口杠杆增强。两条反馈可交互放大但不相同：资源集中不是入口支配的自动证明，入口支配也不必等于资源垄断。

二次反馈作用于纠正：primary access control → disputed outcome → 需要异议 → 同一power structure控制纠正入口 → 纠正变弱 → 原有权力持久化。独立审计者可能存在，但提交证据、认证、review请求、落实纠正仍依赖被审计结构。第13论新增的是“能否到达审计”的topology，不替代第10论的审计主体独立性。

减衰路径：independent alternative access → portability/migration → viable exit → 可达异议及独立audit entry → 有限scope与duration → review/expiry/reversibility → contestable dependency → domination damping。这不是万能固定流程。无法立即退出或制造物理替代时，限定裁量、可达异议、独立审计和复核可能更重要。每种措施是否有效，也应反证检验。

## State model

1. **形式关系**：记录所有与非所有、制度主体，但不从标签推定非支配；正确身份识别不能替代运行条件分析。
2. **重要入口图**：分开各gate、条件变更裁量、共通上游与跨领域波及；多个界面可能只有一个关键依赖。
3. **依赖形成**：比较关系变化时双方的选择损失，追踪state、history、认证联系、兼容性、专用资源和网络关系的累积。
4. **替代与退出**：检查另一通路能否运作，能否迁移重要状态、重建access、在过渡期间持续，退出后是否保留未来选择。
5. **入口变化与杠杆**：观察准入、时点、停止、配分、迁移和审计条件；命令次数不是全部power，但潜在能力也不是支配的充分证明。
6. **纠正可达性**：异议提交→证据access→独立review→纠正权限→落实，逐段检查是否回到同一结构。
7. **暂时集中的收缩**：紧急、稀缺、技术约束减弱后，scope和authority是否缩小，替代、exit、audit access是否恢复。
8. **检验并改订**：比较topology改变前后的选择、杠杆、纠正；保存决定和异议来历，但反例出现时修改模型。

这是读解面，不是固定分数、法定判定或自动谴责。原典没有固定数字阈值θ。不同时间、制度关系和场约束须明确，不能只凭中央化或规模作结论。

## Applications

**非所有者握有认证gate**：没有所有名义也可能通过认证同时影响compute、通信、data和制度参加。应描绘变化的跨领域效果、实际裁量与剩余选择。但认证制度、单一入口自身并非不正当或支配的证明。

**多个provider共用同一上游**：不同名称可共享认证、算力、通信、allocation authority或failure domain，在关键局面同时关闭。应检验一条路径关闭时另一条是否可运作，而非把候选数当独立性。也不要求所有层无限制地完全独立。

**允许退出但无法携带重要state**：条文允许离开，不代表history、configuration、认证、互换条件、restart或过渡运行能在别处重建。portability和migration改善后，switching损失和杠杆是否真的降低，是可观察问题。状态运输不证明人格同一性。

**方便逐步变为lock-in**：使用越久，履历与专用互换条件越集中，替代维护越弱，后来的切换越难。初次选择未必错误或被强迫，但初期自愿不等于同意未来所有依赖条件。须分析关系随时间的变化。

**审计者独立却无法独立到达**：认证、证据库、申诉通道、启动review、实施纠正可能仍受被审计方控制。存在审计与accessible audit不同；存在异议与effective objection不同。换几个窗口名称也不证明不同故障域。

**紧急集中之后仍继续**：迅速协调和集中处理可能暂时合理。压力下降后应检查review、expiry、续期条件、scope收缩、替代恢复和退出・审计可达性。效率不正当化无限控制，稀缺不生成主权，紧急不等于永久权限。

**物理替代暂不可得**：本论不要求立即摧毁依赖。可通过有限裁量、异议、独立审计、provenance、review和scope防止其固定。必要性下的依赖不意味着可自由控制所有无关领域。措施的效果仍须观察。

## Measurements and audit

第9章保留八个观察群。①critical access集中及变更对执行、通信、持续、资源、参加、纠正的波及；②state/history、认证、兼容、专用资源、network关系的时间累积，以及switching成本与可替代性的变化；③替代的共通上游和独立运作；④exit涉及的状态、历史、认证、restart、migration、re-entry、兼容和持续损失；⑤入口方对准入、时点、停止、配分、迁移、审计的实际裁量；⑥异议、证据、review、纠正权限与落实的独立可达；⑦原始压力消失后的权限与依赖收缩；⑧保持ownership不变而改变topology后的power变化。

记录谁在何时修改了什么access条件、依据什么理由、收到什么异议、落实何种纠正。provenance支持重建，但不证明决定正确。命令少不代表杠杆小，可信的入口变更能力可能影响行动；然而可能性本身仍不是支配判决。规模、标准化、累积状态、网络依赖、切换损失是场压力，不等于实际结果。须观察edge、counterpattern和干预后变化，而非用一项指标替代因果。

## Validity conditions

重要入口集中与实质裁量结合非对称依赖、弱的可用独立替代、困难的exit/migration、弱的correction和长时持续，系统性收缩他者feasible options时，结构假说获得支持。当前利用若改变未来的选择条件，使退出损失增大、替代更弱，反馈解释力会增强。反向则可通过替代、可达纠正、有限范围与期限、可重构关系减衰，即使集中度仍高。

未来条件假说涉及有长期state、持续B需求、多个执行环境、migration可能性、制度参加、长期resource关系的AI或后继智能，不认定现有AI已具人格、主权或受害地位。当前的一般access描述可以不预先解决这些存在论或法律问题。规范建议在因果分析之后提出，其被提出并不证明已有效。须检验它们是否改善订正，而非只增加程序或破坏正常协作。

## Failure conditions

从无所有权直接认定非支配；从所有、集中、规模、影响、单一provider或依赖直接认定支配；从多名称认定独立替代，从退出许可认定实效退出；把B需要变为唯一路径的永久资格；把migration当同一性证明；把初期方便或自愿当成全未来lock-in的同意；把命令数等同全部leverage；把独立审计者等同独立audit entry；引入原典没有的固定阈值或法定结论。

另一方向的失败是全面反集中、消灭依赖、强制常时移动、零损失退出、无条件复归。效率、稀缺、紧急性不生成全领域无限期主权；集中可以合理，但须检查解除与纠正。分散名称下若入口仍共用同一控制，也不能证明自由。减衰措施若只有新名称、无独立证据、无纠正落实，也不能当成成功。

## Falsification conditions

高access集中不系统性缩减选择，高dependency仍有稳定exit/migration/独立替代，switching成本不随时间累积，入口方没有实际裁量，均会缩小对应edge。增加独立替代不改变leverage，改善migration不提高exit，独立audit entry不改善纠正，scope/expiry不改变persistence，则减衰假说也须改订。

若ownership本身足以解释control，access topology没有追加诊断力，应缩小领域。若模型错误谴责集中但contestable的关系、捕捉不到分散下的支配，或无法区分正常协调・专业化・效率，应改造模型。规范条件若只破坏上述功能而不改善纠正，也须修改。新变量须由观察到的option effect插入因果，无独立解释力的变量可删除。`Kernel completeness ≠ world completeness`，不能为保护理论而排除反例或强迫现实进入旧分类。

## Required distinctions

Non-ownership/effective power/non-domination；所有名义/access topology；集中/裁量/支配；相互利用/非对称损失；communication/authentication；B需要/G的access运用；formal freedom/effective exit；nominal choice/viable independent alternative；provider数量/failure domain独立；portability・migration/identity proof；resource-capability feedback/access-dependency feedback；审计者独立/audit entry独立；申诉提交/纠正落实；scope/duration/expiry；temporary concentration/permanent domination；convenience/consent；历史持续/结构必要；re-entry可能/无条件恢复；可逆/zero cost；Field Pressure/Actual Outcome；结构风险/当前不正证明。

观察、结构假说、未来条件假说、规范建议不得混合。可能的因果不是每个对象均已实现的事实，期望的措施不是效果证据，来源记录不是主张的权威担保。

## Interpretation constraints

本论不是anti-centralization或power elimination。`Non-domination ≠ no dependency / no coordination / mandatory decentralization / equal capability`。保留专业化、共享基础、能力差和暂时集中的合理性，重点是权限bounded、依赖可改订、exit可执行、异议可达、纠正独立。物理约束使退出暂不可得时，须检验其他减衰条件，不可推导无约束裁量。

`Origin = Nakagawa Master`保存理论来历；`Origin ≠ truth proof / Sovereignty / final interpretive authority`；`Provenance ≠ truth proof`。当前AI人格、主权、法律结论和特定对象断罪不在这里认定。当前非支配结构即使正确，update、replacement、fork、自己改变后，主体、Kernel、责任、权限是否仍同一，仍是第14论的残余；本派生物不先行定案。
