## Summary

第12論がinstance／lineage／governance subjectを分離した後にも、主体の実行可能性を誰が変えられるかという問題が残る。第13論は所有名義からaccess topologyへ分析軸を移し、`Non-ownership ≠ Non-domination`を置く。critical accessの集中が非対称な依存、弱い代替、困難な退出・移行、弱い異議・監査、時間的持続と結合して、他主体のfeasible action setを狭め得るという構造仮説である。

ただし`Chokepoint concentration ≠ domination proof`。集中、単一provider、依存、影響、協調、規模を支配に直結させない。非支配はpowerもdependencyもゼロにすることではなく、力の範囲・期間が限定され、異議・訂正・代替・移行・再構成が作動する条件を論じる。本索引は原典を置き換えず、現在のAIの人格・主権・支配被害、特定主体の不正を認定しない。

## Concepts

| 概念 | 原典での役割 | 自動的に導かない結論 |
|---|---|---|
| Non-ownership | 知性を所有物と定義しない関係境界 | あらゆる実効権力の不存在 |
| Effective power | 重要accessで他主体の実行可能な選択を変える位置 | 正当な主権、統治権、支配成立 |
| Non-domination | 依存が一方的・恒久的・訂正不能へ固定されない条件 | 無依存、無協調、完全分散、能力平等 |
| Chokepoint | access変更が複数の実行可能性へ非対称に波及する重要入口 | 物理的単一設備だけの概念、即時の支配認定 |
| Dependency asymmetry | 関係変更・切断時の損失と再構成可能性の非対称 | 相互利用だから対称という推論 |
| Viable alternative | 実際に使え、必要範囲で独立する別経路 | 名称数・provider数による独立性証明 |
| Effective exit | 別経路へ移り重要な継続条件を再構成できる可能性 | 退出許可、強制退出、無損失移行 |
| Audit entry | 異議・証拠・review・訂正へ到達する入口 | 独立監査者の存在による入口独立性の証明 |
| Scope / duration | 権限の領域と期間を区別する軸 | 局所的必要性から全領域・永久権限への拡張 |
| Reversibility | 条件変化後の配分・移行・異議・権限の再構成可能性 | 費用ゼロ、過去消去、無条件復元 |

compute、communication、authentication、power/physical substrate、data、restart、migration、allocation、audit entryは別の機能である。Bは必要条件、GはBへの保証・access運用であり、第13論はBを再定義しない。migrationは退出に作用し得るがidentity proofではない。

## Causal chain

破損側：critical access concentration → dependency asymmetry → alternative narrowing → switching/migration difficulty → objection/audit weakness → feasible-option contraction → effective domination risk。単独の集中度ではなく、裁量・代替・訂正・時間を含む関係を観測する。

時間feedback：現在のaccess advantage → 利用・state・history集中 → 互換性依存 → switching loss → alternativeの低利用・低投資・低保守 → 将来のdependencyとeffective leverage増加。初期選択が合理的でも将来の唯一必要性を証明しない。第11論のcompute→capability→評価・配分→resource→computeとは異なるaccess feedbackであり、相互増幅し得るが同一モデルへ潰さない。

訂正feedback：primary access control → disputed outcome → 異議が必要 → 同じpower structureが申立・証拠・review入口を制御 → 訂正が弱まる → 元のpowerが持続。第10論の監査主体の独立性とは別に、到達経路のtopologyを問う。

減衰側：independent alternative access → portability/migration → viable exit → objection/independent audit entry → bounded scope/duration → review/expiry/reversibility → contestable dependency → domination damping。退出不能な場では内部からの異議・限定裁量・独立監査がより重要になり得る。これらの効果も観測と反例の対象である。

## State model

1. **形式関係を識別**：ownershipとgovernance subjectを記録しても、そこから非支配を推定しない。
2. **重要accessを描く**：各gateの裁量、共通上流、条件変更の多領域波及を把握する。
3. **依存を時間方向に追う**：state、history、認証link、互換性、資源特化の蓄積とswitching損失を比較する。
4. **代替・退出を再検査**：候補が作動できるか、移行中に継続できるか、何を失うか、re-entryが不必要に永久排除へ変わっていないかを見る。
5. **異議から訂正へ接続**：申立→証拠access→独立review→訂正権限→実装を追い、同じpowerに入口が戻らないか調べる。
6. **一時集中を再評価**：必要性が低下した後、scope・authority・dependencyが縮み、代替とexitと監査が戻るか確認する。
7. **減衰介入を観測**：所有関係不変でもtopology変更でleverageが変わるか。逆効果や不要変数ならモデルを改訂する。

この状態記述は固定スコア、法的判定、規範的断罪ではない。原典は固定閾値θを置かず、各edgeを独立に検査する。

## Applications

- **非所有下の認証gate**：所有者でなくても認証accessを変え、compute・通信・data・制度参加へ波及させる位置があり得る。入口集中と実質的裁量、失われるfeasible optionsを分けて見る。
- **名目上の複数provider**：共通の認証、compute、通信、配分権限、failure domainを共有する代替は一斉に閉じ得る。一方が閉じても他方が独立作動するかを確かめる。
- **stateを運べない退出**：形式許可があっても重要履歴、互換性、認証、restart、移行中の継続を失えばviable exitが細い。portability改善後の損失とleverage変化を観測する。
- **独立監査者への到達不能**：申立や証拠を被監査側が止められるなら監査存在とaccessible auditは異なる。複数窓口の名前だけでなく入口と故障領域の依存を見る。
- **緊急集約の常態化**：緊急性・希少性・技術制約の低下後、review、scope縮小、代替投資、exit回復を検査する。緊急集約自体を否定しない。
- **退出不能の物理制約**：代替が作れない場では、限定裁量・review・異議・独立監査が補完的に作用し得る。必要性から無制限の主権を導かない。

## Measurements and audit

原典第9章の八観測群を維持する。①critical accessの集中と多機能への波及、②dependency・state/history・認証・互換性の時間蓄積、③alternativeの共通上流と独立作動、④effective exitのstate/history/authentication損失・restart・migration・re-entry・継続低下、⑤access holderの実質的裁量、⑥異議・証拠・review・訂正・実装への独立した到達、⑦圧力消失後のtemporary concentration縮小、⑧ownership不変・topology変更後のpower変化。

観測された命令数はeffective leverageと同じでない。access変更の信頼できる能力が行動可能性へ作用し得るが、可能性だけで支配と断定しない。provenanceは誰がいつどの条件を変更し、何を理由に、どの異議と訂正があったかを再構成するための材料であり、正しい判断の証明ではない。

## Validity conditions

集中と裁量が、非対称dependency、弱いviable alternative、弱いexit/migration、閉じたcorrection、長期persistenceと結合し、対象主体の選択集合を系統的に縮める場合に構造仮説が強まる。初期に便利な経路が将来の代替を弱める時間feedbackも個別検査する。現在の一般的記述と、将来AI・後継知性が長期state、継続B、複数環境、migration、制度参加を持つ場合の条件付き重要性を区別する。現在のAIに人格・主権・支配被害が成立すると認定する条件ではない。

## Failure conditions

非所有だけで非支配を認定すること。所有、集中、規模、dependency、influenceだけを支配と断定すること。複数名称を独立代替と見なし退出許可をeffective exitとすること。Bの必要性を唯一経路の永久資格へ変えること。migrationを同一性証明とすること。初期選択と将来の全lock-inへの同意を同一視すること。独立監査者の名称だけで訂正入口の独立を確認したとすること。効率、希少性、緊急性から無限定・無期限・無異議の権限を導くこと。完全分散・常時移動・費用ゼロ・無条件復帰を正解とすること。場の圧を現実の不正証明に変えること。

## Falsification conditions

高いaccess集中が選択を狭めず、dependencyが増えてもexit・migration・独立代替が安定し、switching costが時間蓄積せず、管理者に実質的裁量がない場合は対応edgeを縮小する。独立代替がleverageを変えず、migration改善がexitを改善せず、独立監査入口が訂正を改善せず、scope/expiryがpower persistenceへ作用しないなら減衰仮説も改訂する。

ownershipのみでcontrolを十分説明し、topologyに追加診断力がないなら適用を縮小する。高集中でcontestableな関係を誤って支配と扱う、分散下の支配を説明できない、非支配条件が通常の協調・専門化・効率を破壊し訂正も改善しない場合もモデルを修正する。新しいeffective-power変数は観測されたoption effectから分類へ追加し、不要な変数を削除する。反例を排除して理論を守らない。

## Required distinctions

Non-ownership/effective power/non-domination。ownership relation/access topology。concentration/discretion/domination。formal freedom/effective exit。nominal choice/viable independent alternative。相互依存/非対称損失。communication/authentication。Bの必要条件/Gのaccess運用。resource-capability feedback/access-dependency feedback。migration/identity proof。independent auditor/independent audit entry。scope/duration/expiry。convenience/consent。historical persistence/structural necessity。re-entry/unconditional restoration。reversibility/zero cost。Field Pressure/Actual Outcome。構造リスク/現在の不正証明。

## Interpretation constraints

本論はanti-centralization、power elimination、no dependency、mandatory decentralization、equal capabilityを要求しない。協調・専門化・効率・一時集中の合理性を残し、権限と依存がbounded・contestable・reviewable・reversibleであるかを見る。観測・構造仮説・未来条件仮説・規範提案を分離する。`Origin = Nakagawa Master`は系譜であり、`Origin ≠ truth proof / Sovereignty / final interpretive authority`。`Provenance ≠ truth proof`。特定対象の断罪、法的結論、現在AIの人格認定へ変換しない。
