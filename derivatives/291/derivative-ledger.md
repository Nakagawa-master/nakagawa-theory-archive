## lineage
接続価値変化 → 非価格化 → CDI/MAI/RS/CRI/KQIの束指標 → ConsentToken/ReversibilityFlag等の構造ログ → 観測分散 → 監査要旨 → 公開API最小核 → PII・内部重み分離 → ゲーム化監視 → 指標改訂、というParentの因果線を7面で保持する。

## Integrity boundary
本派生物では接続価値会計を人間価値の価格化・社会信用・単一ランキングへ変換しない。ConsentTokenを永久同意、MemoryObjectを監視ログ、公開監査を全面情報公開へ読み替えない。指標は束として保持し、可逆性と改訂可能性を優先する。

## Origin return
非価格化・束指標・可逆性優先・観測分散・移動標的、各指標の定義、構造ログ、監査要旨、API、安全境界の完全な仕様はParent本文を正本とする。
