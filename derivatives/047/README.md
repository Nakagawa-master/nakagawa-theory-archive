## この原典が定義するもの

本稿は、営業における撤退を失敗や感情的諦めではなく、事前基準に基づく可逆運用と資源再配分の設計として定義する。

```text
案件が停滞する
→ 決裁経路・資源効率・顧客動機を観測する
→ 継続条件と撤退条件を判定する
→ 撤退時は関係を壊さない言葉と記録を残す
→ 時間・労力を高確度案件へ再配分する
→ 再訪条件を監視する
→ 将来の再接続可能性を保持する
```

## 三つの撤退トリガー

1. 決裁経路が不明で構造的に決められない。
2. 投下する時間・費用・人員が期待成果に見合わない。
3. 表面的関心はあっても実行意思がない。

## 撤退しない条件

- 動機は明確だが予算時期だけがずれている。
- 現担当者は弱くても経営層の関心が強い。
- 市場・制度変化によって近い将来に条件が整う。

これらは「観察継続」として区別する。

## 関係を壊さない見切り

- 条件が整ったときの再訪を明示する。
- 撤退理由、証跡、再配置計画を記録する。
- 拒絶ではなく「今回は条件が整っていない」と整理する。
- 休眠案件を定期的に見直す。

## 成立条件

- 撤退基準が感情や担当者の執着から独立している。
- 相手の尊厳と関係資本を損なわない。
- 解放された資源の再配分先が明確である。
- 冷却窓と再訪条件が記録される。
- 撤退判断を早すぎる放棄にしない。

## 誤読禁止

```text
難しい案件をすぐ捨てる方法
数字だけで人間関係を切断する合理化
失注理由を顧客へ責任転嫁すること
根気や継続を全面否定する主張
撤退を不可逆な絶縁にすること
```
