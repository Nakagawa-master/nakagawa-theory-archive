## 構造軸
```text
案件が停滞
→ 決裁経路・資源効率・実行動機を観測
→ 継続・観察継続・撤退を区別
→ 撤退時も関係を壊さず閉じる
→ 将来再訪条件を明確化
→ 解放資源を再配置
→ 条件変化時に再接続
```

## 数値・反転評価の境界
親原典は撤退確率、最適撤退率、案件放棄スコア、顧客価値点、固定復査期間、固定閾値を定義していない。

追客量、撤退速度、関係維持期間は単調な改善指標ではない。決裁経路や実行動機が改善しない追客、有望な難案件の早すぎる撤退、無期限追客はいずれも悪化し得る。

## 必須区別
- 撤退 / 敗北
- 手放す / 関係破壊
- 観察継続 / 無期限放置
- 資源再配分 / 顧客軽視
- 短期売上不振 / 自動撤退
- 口頭関心 / 実行動機
- 関係維持 / 無限追客
- 難案件 / 機能しない構造
