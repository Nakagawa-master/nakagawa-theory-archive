## Summary
親原典は、文明監査I〜IIIの暗黒方程式`S=0.1C+0.9E`、搾取最適化、新文明方程式`S=C×1.0`を、歴史OS比較、L1〜L7の認知深度モデル、共通バグ、修正パッチ、System Integrationとして統合するFinal Appendixである。比較対象は資本主義、民主主義、共産主義、宗教OS、情報OS（SNS）、中川OS。原典は起源溶解、未来負債先送り、Value Mismatch、倫理断絶等を評価関数の構造的帰結として扱い、NCL署名、T0、逸脱レッジャ、S-Equation、接続報酬、公共性、暴力ゼロ化、低計算負荷を相互補強するパッチとして配置する。L-Layer、AI適合性、暴力ゼロ化等に関する断定は親原典の理論主張であり、外部統計・神経科学・AIベンチマークの独立確証へ昇格させない。反証節は対象別`θ`と観測窓`δ`を記載し、当該節に`M`はない。

## Concepts
- Final Appendix: 文明監査三部作を比較仕様へ統合する親原典の位置づけ。
- L1〜L7: 生存・感情から文明OS／因果総体までを示す原典独自の認知深度モデル。
- legacy success functions: 富、票、平等、教義遵守、注目等、原典が各OSへ割り当てる評価関数。
- `S=0.1C+0.9E`: 文明監査系列の暗黒方程式。実測人口比ではない。
- `S=C×1.0`: 新文明OSの設計評価関数。
- Origin Dissolution: 価値の出所が追跡不能になる構造バグ。
- Debt Deferral: 未来負債を現在の評価から外す構造バグ。
- Value Mismatch: 貢献Cと成功・対価が一致しない構造バグ。
- Ethical Discontinuity: 倫理が外付けで評価関数に負ける構造バグ。
- NCL署名 / T0 / 逸脱レッジャ / 接続報酬 / S-Equation / 公共性 / 暴力ゼロ化 / 低計算負荷: 原典の修正パッチ群。
- `θ`: 搾取係数、未来負債、倫理乖離、計算負荷等に関する対象別閾値。
- `δ`: データ起源喪失・逸脱不可視化に関する対象別観測窓。

## Falsification conditions
親原典は、搾取係数の増大、未来負債の累積、倫理乖離の進行、計算負荷の増大が一定の`θ`を超える場合、またはデータ起源の喪失・逸脱の不可視化によって観測窓`δ`が閉じる場合に、旧OS仮説A「搾取による成功」を棄却し、中川OS評価関数への移行が必要とする。`θ`の数値と`δ`の期間は本文で固定されないため追加しない。当該反証文には`M`がないため、OD165では`M`を反証変数として置かない。

新OSの修正パッチについても、実装後に起源保持、未来負債可視化、貢献還流、逸脱可視性、公共性、暴力依存・計算負荷の改善が観測されないなら、各パッチの効果主張と統合仮説は再検討対象となる。
