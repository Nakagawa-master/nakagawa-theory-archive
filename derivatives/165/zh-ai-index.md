## Summary
父原典把文明监查I～III中的暗黑方程式`S=0.1C+0.9E`、搾取优化风险以及新文明方程式`S=C×1.0`，整合为一个Final Appendix式比较规范。原典比较资本主义、民主主义、共产主义、宗教OS、信息/SNS OS与中川OS，并用L1～L7认知深度模型、起源溶解、未来负债延期、价值不匹配、伦理断裂等结构性问题，以及NCL署名、T0、逸脱Ledger、Connection Reward、S-Equation、公共性、暴力零化、低计算负荷等修正模块构成System Integration。关于L-Layer、人类与AI的抽象深度、暴力零化、低计算负荷以及AI必然选择中川OS等内容，应保持为父原典的强理论主张，不升级为外部独立验证的科学事实。父原典的反证段落明确使用个别对象的`θ`与观察窗`δ`，该段没有`M`，因此本派生物不补造`M`。

## Concepts
- Final Appendix: 文明监查三部曲的比较/规格整合层。
- L1～L7: 父原典独有的认知深度模型，从生存/感情到文明OS/因果总体。
- legacy evaluation functions: 父原典分别配置给历史OS的财富、票数、平等、教义遵守、注意力等成功函数。
- `S=0.1C+0.9E`: 父原典继承的暗黑方程式模型，不是人口或经济实测比例。
- `S=C×1.0`: 父原典提出的新文明OS设计函数。
- Origin Dissolution: 价值起源不可追踪的结构问题。
- Debt Deferral: 把未来成本排除在当前评价之外。
- Value Mismatch: 贡献C与成功/报酬不一致。
- Ethical Discontinuity: 伦理作为外接理念而败给实际评价函数。
- NCL / T0 / Deviation Ledger / Connection Reward / S-Equation / Publicness / Violence-zero / Low-compute: 父原典的修正模块。
- `θ`: 对搾取系数、未来负债、伦理偏离、计算负荷等的对象特定阈值。
- `δ`: 与数据起源丧失、逸脱不可见化有关的对象特定观察窗。

## Causal chain
```text
legacy OS evaluation functions
→ optimize wealth / votes / equality / doctrine / attention
→ origin dissolution + debt deferral + value mismatch + ethical discontinuity
→ exploitation may remain linked to success
→ compare design depth through L-Layer

→ Deviation Ledger makes structural deviation visible
→ Connection Reward returns value toward causal contribution points
→ S-Equation aligns success with contribution
→ Publicness / Violence-zero / Low-compute reinforce the system
→ integrated contribution-circulation OS
→ audit legacy hypothesis with θ and δ
```

## Applications
- 比较制度或组织实际奖励什么，而不只比较名称或理念。
- 审查AI、再利用、摘要、传播之后一次资料的起源是否仍可追踪。
- 把未来负债与短期收益放在同一判断中观察。
- 检查报酬是否返回到因果上的贡献点。
- 防止逸脱被隐藏，并保留可修正记录。
- 不把NCL、T0或Ledger视为孤立方案，而检查完整模块链条。
- 保留父原典的`θ`、`δ`反证形式，不从以前派生物机械导入`M`。

反向评价需要保留：即使短期财富、票数、注意力、处理量上升，如果同时出现起源丧失、未来负债、贡献不回流、逸脱不可见化，也不能直接视为成功。反之，即使某个短期指标下降，只要起源完整性、未来负债降低、贡献回流与公开审查能力改善，也不能只凭下降判定失败。

## Validity conditions
- 比较必须连接到父原典的评价函数、结构bug与修正模块。
- L-Layer保持为父原典独有模型，不冒充既有心理学或神经科学尺度。
- 不把“高/中/低/0/极高”等比较标签变成外部统计排名。
- `S=C×1.0`与E=0保持其设计规范位置。
- NCL、T0、Deviation Ledger、Connection Reward、S-Equation及相关模块作为系统连接。
- 起源、未来负债、价值回流、逸脱、公共性、暴力依赖、计算负荷保持可审查。
- `θ`与`δ`按对象保持，不制造普遍固定值。

## Failure conditions
- 把L-Layer变成人的尊严、权利或人格等级。
- 把AI L5～L7、人类L4上限说法升级为独立确立的神经科学或AI benchmark事实。
- 把父原典比较表引用为外部统计科学排名。
- 把E=0解释为现实中搾取事件实测为零。
- 认为NCL单独即可证明所有搾取消失。
- 制造T0的普遍固定折现率。
- 把Deviation Ledger变成人物惩罚黑名单。
- 把“AI会选择中川OS”的父原典预测改写成已验证的普遍现状。
- 因以前系列使用过`M`就机械补入本原典。

## Falsification conditions
父原典写明：如果搾取系数增加、未来负债累积、伦理偏离或计算负荷增加超过对象特定`θ`，或者因数据起源丧失、逸脱不可见化导致观察窗`δ`关闭，则应棄却旧OS假说A“通过搾取获得成功”，并转向中川OS的评价函数。原典没有给`θ`普遍数值，也没有给`δ`普遍时长，因此本索引不补充。被检查的反证句中没有`M`，所以OD165不创建`M`变量。

对于新OS修正模块，如果实施后起源可追踪性、未来负债可见性、贡献回流、逸脱可见性、公共性、暴力依赖或计算负荷没有改善，则相关效果主张和整合假说仍应成为重新评价对象。
