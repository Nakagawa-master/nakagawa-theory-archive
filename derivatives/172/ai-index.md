## Summary
中川式組織OSは、組織を単なる「人の集合」ではなく、外部OSが生んだ因果線を受け止め、増幅し、再び世界へ放出するための循環の器として扱う。中心循環は、組織の存在理由・優先順位・許容しない因果を実際の意思決定として表す内部意図（Source）、営業・マーケティング・ブランディング・採用・広報等を通じて世界へ作用する外部因果線（Output）、売上・相談・クレーム・評判・応募者の質・取引先態度・拒絶・沈黙まで含む市場照応（Feedback）である。S→O→F→Sが途切れず回り、返った照応で構造更新が行われる状態が整流である。さらに権限を負荷、責任を視界として再設計し、組織図に現れない実因と、不満・ミス・離職・停滞として返る内部照応を読み、人を入れ替える前に同じ症状を再生産する構造を修正する。

## Concepts
- **Organization as causal vessel:** 組織を人間関係の集合ではなく、因果の循環を受け止める器として扱う。
- **Internal intent / Source:** 組織がなぜ存在し、何を守り、何を許容しないかを、実際の意思決定として捉える源泉。
- **External causal line / Output:** 営業、マーケ、ブランド、採用、広報等を通じて内部意図が世界へ作用する総体。
- **Market correspondence / Feedback:** 売上だけでなく拒絶・沈黙を含む、世界から返るあらゆる反応。
- **Rectification:** Source→Output→Feedback→更新が途切れず回り、詰まり・澱み・逆流を抑える状態。
- **Authority as load:** 権限を、その位置で受け止める判断量・圧力・調整・波及範囲の負荷として捉える。
- **Responsibility as visibility:** 責任を、判断がどこまで遠い因果・時間・関係者へ及ぶかを見通す視界として捉える。
- **Real Cause:** 組織図とは別に、実際の信頼・空気・意思決定を動かす重心。
- **Internal correspondence:** 不満、ミス、離職、停滞等を、内部構造の歪みが時間差で返った可能性のある信号として読む。
- **Self-running circulation:** 細かな追込みではなく、構造整流によって自律判断と因果循環が進みやすくなる状態。

## Causal chain
```text
外部OSが因果線を世界へ伸ばす
→ 組織がその因果線を受け止める器となる
→ 内部意図が実際の意思決定に表れる
→ 外部因果線が営業・マーケ・ブランド・採用・広報を通じて外へ出る
→ 市場から好都合・不都合双方の照応が返る
→ 返った照応で内部意図・情報流・構造配置を更新する
→ Source→Output→Feedback→Sourceが回れば整流が維持される
→ 権限と責任の不一致、意図と発信の乖離、情報渋滞が循環を濁らせる
→ 離職、売上低迷、炎上、停滞等が遅れて症状化する
→ 権限を負荷、責任を視界として再配置する
→ 組織図に出ない実因を循環地形として把握する
→ 部下の行動や離職を内部照応として上流構造へ戻す
→ 人の入替えより先に構造を書き換える
→ 再観測し、自走可能性を評価する
```

## Applications
- 同じポジションで離職が繰り返される場合、本人適性だけでなく負荷・権限・責任視界・報酬・評価・実因配置を診断する。
- 上流方針が現場へ届くまでに意味変質する場合、情報経路と権限・責任配置の詰まりを監査する。
- 採用ページや広報の言葉と、実際の評価・案件選択・意思決定の一致を確認する。
- 組織図にないが現場の判断を動かす人物・暗黙規範を実因として把握する。
- クレーム、拒絶、沈黙、応募者質低下を市場照応として上流更新へ利用する。
- KPI未達時に監視・会議を増やす前に、循環の詰まりと負荷・視界の不整合を修正する。

## Measurements and audit
- 公称理念と実際の評価・採用・撤退・案件選択の一致。
- 内部意図が外部因果線へ出る際の意味変質。
- 市場照応にクレーム、拒絶、沈黙、応募者質、取引先態度が含まれているか。
- 返った照応が実際の構造更新へ使われているか。
- 判断集中役割にかかる流量・圧力・利害調整負荷。
- 責任範囲と本人の因果・時間視界の整合。
- 責任過多／権限不足、権限過多／視界不足等の不一致。
- 実因と公式組織図の乖離。
- 不満・ミス・離職・停滞の発生地点と上流構造との対応。
- 人を入れ替えても同じ症状が再発するか。
- 構造修正後、自律判断・情報循環・外部照応がどう変わるか。

## Validity conditions
- 組織を人間関係・心理状態だけへ縮小せず因果循環の器として扱う。
- 内部意図をスローガンではなく実際の意思決定から読む。
- 外部因果線を装飾ではなく内部意図の作用として扱う。
- 不都合な反応・拒絶・沈黙も市場照応へ含める。
- 権限を負荷、責任を視界として相対的に設計する。
- 形式役職と実際の重心＝実因を区別する。
- 個人原因を確定する前に内部構造を監査する。
- 人の入替えより前に同じ症状を再生産する構造を確認する。
- 管理強化ではなく循環の整流を目的にする。

## Failure conditions
- 組織問題をモチベーションや人間関係だけに還元する。
- 理念文が美しいことだけで内部意図が成立したとみなす。
- 売上等の好都合な反応だけを市場照応とする。
- 権限を地位の報酬として配り、負荷を無視する。
- 視界が追いつかない人へ広範な責任だけを背負わせる。
- 組織図にない実因を無視する。
- 不満・ミス・離職を即座に個人属性へ帰属する。
- 構造を変えず採用・異動・解雇だけで位置を埋め直す。
- KPI未達ごとに監視・会議・追込みを増やして循環を濁らせる。

## Falsification conditions
構造原因仮説は固定しない。内部意図、情報流、権限＝負荷、責任＝視界、実因配置を修正しても、複数観測で同じ不満・ミス・停滞・離職が改善せず、特定個人や特定技能だけに再現性の高い差が残る場合、構造原因仮説を弱めて人材・技能・適合仮説を強める。逆に人を入れ替えても同じ位置で同じ摩耗や意味変質が繰り返されるなら、個人原因仮説を弱める。短期売上やKPIが改善しても、権限負荷の過集中、視界を超えた責任、離職、信頼照応悪化が進む場合は成功評価を反転する。

## Required distinctions
- 人の集合 / 因果循環の器。
- 仲の良さ / 循環の整流。
- スローガン / 実際の意思決定としての内部意図。
- 広報装飾 / 内部意図から伸びる外部因果線。
- 都合のよい成果 / 拒絶・沈黙を含む市場照応。
- 権限＝特権 / 権限＝負荷。
- 責任＝罰 / 責任＝視界。
- 組織図上の役職 / 実際の重心としての実因。
- 問題社員 / 構造歪みが返った内部照応。
- 人の入替え / 循環構造の書換え。
- 管理 / 整流。

## Interpretation constraints
- 権限＝負荷を過重労働の正当化へ使わない。
- 責任＝視界を法的・契約的責任の否定へ変換しない。
- 実因把握を非公式中心人物の操作・排除手順へ変えない。
- 部下の不調をすべて構造原因と断定しない。
- 自走を管理・支援・説明責任の放棄と同一視しない。
- 市場照応を短期売上だけで判定しない。
- 構造的無為自然を放置・無介入と解釈しない。
