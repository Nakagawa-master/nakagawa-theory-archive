## Summary
中川式组织OS并不只把组织视为“人的集合”，而把它理解为承接、放大并重新向世界释放因果线的循环容器。核心循环由内部意图（Source）、外部因果线（Output）与市场照应（Feedback）组成。内部意图不是口号，而是通过实际的评价、取舍、拒绝、承担等决策显现；外部因果线通过销售、营销、品牌、招聘、媒体等作用于世界；市场照应不仅包括销售与利润，也包括咨询、投诉、评价、应聘者质量、合作方态度、拒绝与沉默。S→O→F→结构更新持续循环且没有堵塞、淤积、逆流时，原典称之为“整流”。同时，原典把权限重新定义为负荷，把责任重新定义为视界，并把组织图之外真正影响信任与决策的重心称为“实因”。不满、错误、离职、停滞等也应先作为可能的内部照应来观察，而不是直接归因于个人。

## Concepts
- **组织作为因果容器:** 承接、传递、放大并重新释放因果循环的内部结构。
- **内部意图 / Source:** 组织为何存在、保护什么、优先什么、拒绝什么，通过真实决策显现的源头。
- **外部因果线 / Output:** 销售、营销、品牌、招聘、媒体等把内部意图送向世界的作用总和。
- **市场照应 / Feedback:** 包括正面结果、投诉、拒绝与沉默在内的世界侧反馈。
- **整流:** Source→Output→Feedback→结构更新持续循环，降低堵塞、淤积与逆流。
- **权限＝负荷:** 决策位置承接的流量、压力、协调量与波及风险。
- **责任＝视界:** 能够看见自身判断向多远的因果、时间、组织和客户扩散的范围。
- **实因 / Real Cause:** 形式职称之外，实际影响信任、空气与决策的重心。
- **内部照应:** 不满、错误、离职、停滞等可能是内部结构扭曲延迟返回的信号。
- **自走循环:** 不是依赖持续施压，而是通过结构清晰提高自主判断和信息流动。

## Causal chain
```text
外部实务OS把因果线伸向世界
→ 组织成为内部承接与循环这些因果线的容器
→ 内部意图通过实际决策显现
→ 外部因果线经由销售、营销、品牌、招聘、传播向外流动
→ 市场返回正面与负面的照应
→ 反馈用于更新内部意图、信息流与结构配置
→ Source → Output → Feedback → Source持续循环时维持整流
→ 权限责任失配、信息拥堵、言行不一致造成淤积与逆流
→ 离职、低迷、冲突、停滞等在之后以症状出现
→ 把权限按负荷重新配置，把责任按视界重新配置
→ 识别组织图之外的实因重心
→ 在归责个人之前，把内部照应追溯到上游结构
→ 先改写结构，再观察是否仍需更换或训练人员
→ 再次观察循环与自走能力
```

## Applications
- 同一岗位反复出现离职时，在个人适配之外检查负荷、权限、责任视界、报酬、评价、信息流与实因配置。
- 上游方针到达现场时意义发生变化时，追踪信息路径和权限责任配置中的堵塞。
- 比较招聘／品牌文案与实际评价、案件选择、决策，确认内部意图与外部输出是否一致。
- 识别没有正式头衔却实际影响决策的人员或暗默规范，并把真实地形纳入结构设计。
- 把投诉、拒绝、沉默、应聘者质量变化、合作方态度作为Feedback，而不是只选择有利销售数据。
- KPI未达时，在增加会议、监视、压力之前先检查循环堵塞与负荷／视界失配。

## Measurements and audit
- 公称价值观与实际评价、招聘、退出、案件选择、承担损失之间的一致性。
- 内部意图转化为外部因果线时的语义扭曲程度。
- Feedback是否包含投诉、拒绝、沉默、应聘者质量、合作方态度。
- 返回的Feedback是否真的进入结构更新。
- 高权限岗位承接的决策流量、协调压力与波及风险。
- 责任范围与个人因果／时间视界之间的整合度。
- 高责任低权限、高权限低视界等失配。
- 正式组织图与实际实因重心之间的偏差。
- 不满、错误、离职、停滞与上游结构条件之间的对应。
- 更换人员后同一症状是否重复出现。
- 结构修正后自主判断与信息循环是否增加。

## Validity conditions
- 不把组织缩减为人际关系或心理状态，而作为因果循环容器处理。
- 从真实决策而非口号读取内部意图。
- 把外部输出视为内部意图的作用，而非装饰。
- 把不方便的负面反应与无反应也纳入市场照应。
- 把权限作为负荷、责任作为视界进行相对设计。
- 区分正式职称与实际实因重心。
- 在固定个人原因为主因之前审计内部结构。
- 更换人员之前先测试是否同一结构会复制同一症状。
- 目标是让循环更清澈，而不是单纯加强管理。

## Failure conditions
- 把组织问题只归结为动力、性格或心理氛围。
- 把漂亮的价值观文案当作内部意图成立的证据。
- 只选择销售和利润作为市场反馈，忽略拒绝、投诉与沉默。
- 把权限当作地位奖励而忽略其负荷。
- 让视界不足的人承担过大的责任范围。
- 因实因不在组织图上就忽略它。
- 立即把不满、错误、离职贴上个人缺陷标签。
- 保留相同的负荷、权限、信息与矛盾结构，只更换人员。
- KPI未达时不断增加监视和压力，从而让循环更浑浊。

## Falsification conditions
结构原因假设必须可以修订。如果内部意图、信息流、权限＝负荷、责任＝视界、实因配置得到修正后，在重复观察中相同的不满、错误、停滞或离职仍持续，而且差异稳定集中在特定个人或技能，则应削弱结构原因假设并加强人员／技能／适配假设。反过来，不同人员在同一位置和同一条件下反复磨损，则个人原因假设变弱。即使短期KPI或收入上升，只要负荷过度集中、责任超出视界、离职或信任照应恶化，也应反转成功评价。

## Required distinctions
- 人的集合 / 因果循环容器。
- 关系融洽 / 循环整流。
- 口号 / 通过实际决策显现的内部意图。
- 传播装饰 / 从内部意图伸出的外部因果线。
- 有利结果 / 包括拒绝与沉默的市场照应。
- 权限＝特权 / 权限＝负荷。
- 责任＝惩罚 / 责任＝视界。
- 正式职称 / 作为实际影响重心的实因。
- 问题员工 / 结构扭曲返回的内部照应。
- 更换人员 / 改写循环结构。
- 管理施压 / 整流。

## Interpretation constraints
- 不用“权限＝负荷”正当化单方面过劳；负荷、裁量、报酬、视界必须保持整合。
- 不用“责任＝视界”否定法律、合同或职业责任。
- 不把实因识别变成操纵或排除非正式领袖的技术。
- 不断言所有员工问题都来自组织结构；要通过修正与再观察比较竞争假设。
- 不把自走循环解释成放弃管理、支援或问责。
- 不仅通过短期收入判断市场照应。
- 不把结构性无为自然解释成放任或不介入。
