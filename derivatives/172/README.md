## 位置づけ
親原典は、組織を単なる「人の集まり」ではなく、営業・マーケティング・ブランディング等が外部へ伸ばした因果線を内部で受け止め、増幅し、世界へ再放出するための「器」として再定義する。良い組織とは仲の良さや管理の厳格さで測るのではなく、内部意図、外部因果線、市場照応が澱まず循環し、その戻りを構造更新へ使える組織である。

中心となる循環は、組織の存在理由・優先順位・許容しない因果を示す「内部意図（Source）」、営業・マーケティング・ブランディング等を通じ世界へ流す「外部因果線（Output）」、売上・相談・クレーム・評判・応募者・取引先の態度・沈黙まで含む「市場照応（Feedback）」の三点である。このループが途切れず、意図が歪まず外へ流れ、返ってきた照応を読み構造を更新する状態を原典は「整流」と呼ぶ。

さらに原典は、組織内部の詰まりを権限・責任・実因の配置として読み解く。権限は「偉さ」や特権ではなく、その位置で受け止める流量と圧力の総量＝負荷であり、責任は罰ではなく、自分の判断がどこまで遠くの因果・時間・関係者へ波及するかを見通す視界である。負荷と視界が釣り合わない配置は、事故、燃え尽き、意味の変質、現場の澱みを生む。

また、形式的な役職とは別に現場の意思決定や空気を実際に動かす重心を「実因」として捉える。部下の不満、ミス、離職、停滞も個人属性だけに帰属させず、内部意図、権限配置、情報流、実因と公式方針の乖離が時間差で返ってきた「内部照応」として読む。人を入れ替える前に、同じ負荷と矛盾を再生産する構造そのものを修正することが組織OSの主題である。

## 中心命題
親原典の中心命題は、**組織を人を管理する装置から、因果の循環を澄ませる器へ転換し、内部意図→外部因果線→市場照応の循環、権限＝負荷と責任＝視界の整合、組織図に現れない実因と内部照応を読みながら構造を整流すること**にある。

この枠組みでは、採用難、離職、売上低迷、炎上、現場停滞等を一次原因として扱わない。それらは循環のどこかで起きた詰まり・澱み・逆流が、時間差を伴って表面化した症状かもしれない。内部意図が実際の意思決定に反映されているか、外向けの言葉と行動が一致しているか、返ってきた照応を都合よく選別せず読めているか、権限と責任の負荷・視界が整っているか、実際の重心が制度設計へ反映されているかを遡って診断する。

「人を変える」のではなく「循環を変える」という順序が重要である。同じ位置に同じ負荷を置き、同じ矛盾を残したまま人だけを入れ替えれば、同じ摩耗が繰り返される。構造的無為自然は何もしないことではなく、因果が自然に収束できるよう上流条件を整えることだから、組織OSは人を細かく押して動かす管理から、流量・視界・重心・意図を整えて自走可能な循環を作る整流へ移る。

```text
↓
内部意図が、存在理由・優先順位・許容しない因果として意思決定に現れる
↓
外部因果線が、提案・発信・採用・広報等を通じて世界へ出る
↓
市場から売上・相談・クレーム・評判・応募・沈黙等の照応が返る
↓
返った照応を読み、内部意図・外部因果線・構造配置を更新する
↓
三点循環が途切れなければ整流が維持される
↓
権限と責任の不一致、意図と発信の乖離、情報流の詰まりがあると循環が澱む
↓
意味変質、現場混乱、離職、売上低迷、炎上等が遅れて症状化する
↓
権限を負荷、責任を視界として再設計する
↓
形式役職とは別の実因を把握し、実際の地形に沿って水路を引き直す
↓

↓

↓

```

## 構造層
**1. 器層。** 組織を人間関係の集合ではなく、外部OSが生んだ因果線を内部で受け止め、増幅し、再放出する循環装置として扱う。

**2. 内部意図層。** 「なぜ存在するか」「何を守るか」「何を優先し、どの因果を許容しないか」を、スローガンではなく評価、採用、撤退、案件選択、不利益の引受け等の実際の意思決定として観測する。

**3. 外部因果線層。** 営業提案、メディア発信、採用ページ、SNS、プレスリリース等を、内部意図から世界へ伸びる作用として扱う。装飾ではなく、内部構造の外部化である。

**4. 市場照応層。** 売上や利益だけでなく、相談、クレーム、評判、応募者の質、取引先の態度、拒絶、無反応までを、外へ流した因果が形を変えて戻ったフィードバックとして読む。

**5. 整流層。** 内部意図→外部因果線→市場照応→構造更新が途切れず回る状態。詰まり・澱み・逆流を除去し、循環の透明度を高める。

**6. 権限＝負荷層。** 権限を特権ではなく、水門の位置で受け止める判断量、圧力、利害調整、波及範囲の負荷として設計する。

**7. 責任＝視界層。** 責任を罰の大きさではなく、自分の判断がどこまで遠くの因果・時間・組織・顧客へ波及するかを理解できる視界として設計する。

**8. 実因層。** 役職名とは別に、実際に現場の空気・信頼・意思決定を動かす人物や暗黙規範を、循環の地形・重心として把握する。

**9. 内部照応層。** 不満、ミス、離職、停滞、解釈ばらつき等を、個人問題へ即時還元せず、内部意図・権限・情報・実因の歪みが遅れて返った信号として読む。

**10. 自走層。** 細かな監視と追込みで人を動かすのではなく、構造を整え、因果が自然に流れることで、管理依存を下げながら自律的循環を高める。

## 適用例
**1. 離職が続く部署の診断。** 退職者の性格や採用ミスだけを疑わず、その役割にかかる負荷、与えられた権限、要求される視界、評価基準、実因との関係を点検し、同じ位置で同じ人が壊れる構造になっていないかを見る。

**2. 方針が現場で変質する組織。** 上流で決めた意図が中流で渋滞し、現場へ届く時には「よく分からないが従う」に変わっている場合、情報経路、権限配置、責任視界の不一致を監査する。

**3. 採用メッセージと実態の監査。** 採用ページで語る価値と、実際に評価される人・断る案件・引き受ける不利益が一致しているかを確認する。言葉と実行がずれていれば市場照応や採用後の内部照応に歪みが出る。

**4. 非公式リーダーの把握。** 組織図では管理職でないが、現場がその人の反応で動く場合、その存在を排除対象ではなく実因として捉え、公式権限・情報流・役割との整合を設計する。

**5. クレームや沈黙の再解釈。** 都合のよい売上だけをフィードバックとせず、拒絶、無反応、応募者の質低下、取引先態度の変化も外部因果線への照応として読み、上流の内部意図と発信を更新する。

**6. 管理強化前の構造点検。** KPI未達や停滞に対して監視・会議・チェックを増やす前に、循環の詰まり、負荷と視界の不整合、情報流の矛盾を修正する。

## 測定・監査点
- 組織の公称理念と、実際の評価・採用・撤退・案件選択の一致
- 内部意図が外部メッセージへ出る際の意味変質の有無
- 市場照応を売上等の好都合な反応だけに限定していないか
- クレーム、拒絶、沈黙、応募者質、取引先態度を構造更新へ使えているか
- 判断が集中する役割の流量・圧力・利害調整負荷
- 与えられた責任範囲と、その人が見通せる因果・時間範囲の整合
- 責任が重いのに権限が少ない、権限が大きいのに視界が狭い等の不一致
- 実際に現場の意思決定を左右する実因と公式組織図の乖離
- 不満、ミス、離職、停滞の発生地点と上流構造との対応
- 人を入れ替えた後も同一症状が再現していないか
- 管理・監視を増やした結果、循環の透明度が上がったか逆に濁ったか
- 構造修正後に自律的な判断と情報循環が増えたか

## 成立条件
- 組織を人間関係や心理状態だけへ縮小せず、因果循環の器として扱う。
- 内部意図をスローガンではなく実際の意思決定から読む。
- 外部因果線を装飾・広報だけとせず、内部意図の作用として扱う。
- 市場照応に不都合な反応、拒絶、無反応も含める。
- 権限を負荷、責任を視界として相対的に設計する。
- 形式的役職と実際の重心＝実因を区別する。
- 部下の行動や離職を個人原因へ直結させる前に、内部構造を監査する。
- 人の入替えより前に、同じ症状を再生産する構造の有無を確認する。
- 管理強化ではなく、循環を澄ませる整流を目的にする。

## 失敗条件
- 組織問題を人間関係、モチベーション、心理的安全性だけに還元する。
- 理念文面が美しいことを内部意図の成立とみなす。
- 売上や利益だけを市場照応とし、拒絶・クレーム・沈黙を無視する。
- 権限を地位の報酬として配り、負荷を説明しない。
- 視界が追いつかない人に広範な責任だけを負わせる。
- 組織図にない実因を無視して制度を直線的に設計する。
- 不満、ミス、離職を即座に「問題社員」の属性へ帰属する。
- 構造を変えずに採用・異動・解雇だけで同じ位置を埋め直す。
- KPI未達のたび管理・チェック・追込みを増やし、循環の詰まりを悪化させる。

## 反証・改訂条件
組織OSの診断は、すべての不調を構造原因と確定するものではない。内部意図、情報流、権限＝負荷、責任＝視界、実因配置を修正しても、複数の観測期間で同一の不満・ミス・停滞・離職が改善せず、特定個人や特定技能にのみ再現性の高い差が残る場合は、人材・技能・適合の仮説を強める必要がある。

逆に、人を入れ替えても同じ位置で同じ摩耗や意味変質が繰り返される場合、「個人原因」仮説は弱まり、構造原因仮説が強くなる。また短期KPIや売上が改善しても、権限負荷の過集中、視界を超えた責任、離職、信頼照応の悪化が進むなら、組織循環の成功評価を反転する。

市場照応についても、売上増だけでは整流成立を証明しない。外向けメッセージと内部意思決定の乖離、クレーム・拒絶・沈黙、採用後の内部照応が悪化している場合、内部意図→外部因果線→市場照応という接続仮説を再点検する。

## 必須の区別
- 人の集合 / 因果循環の器
- 仲の良さ / 循環の整流
- スローガン / 実際の意思決定としての内部意図
- 広報装飾 / 内部意図から伸びる外部因果線
- 都合のよい成果 / 拒絶・沈黙を含む市場照応
- 権限＝特権 / 権限＝負荷
- 責任＝罰 / 責任＝視界
- 組織図上の役職 / 実際の重心としての実因
- 問題社員 / 構造歪みが返った内部照応
- 人の入替え / 循環構造の書換え
- 管理 / 整流
- 何もしない / 構造を整えて自然収束を可能にする無為自然

## 誤読禁止 / 解釈制約
- 権限を「負荷」と呼ぶことを、権限者への一方的な過重労働の正当化に使わない。負荷、裁量、報酬、責任視界の整合が必要である。
- 責任を「視界」と呼ぶことを、罰や法的責任が存在しないという意味へ変換しない。原典は組織構造上の役割設計を論じている。
- 実因の把握を、非公式権力者を操作・排除する技法へ変えない。実際の地形を無視せず構造設計へ反映するための観測である。
- 部下の不調をすべて組織構造の責任と断定しない。構造修正と再観測によって個人・技能仮説と分離する。
- 「自走」を管理・説明責任・支援の放棄へ変えない。
- 市場照応を短期売上だけで判断しない。
- 「構造的無為自然」を放置や無介入と同一視しない。
