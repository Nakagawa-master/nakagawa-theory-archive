## 位置づけ

本派生物は、正統性を人物、肩書、人気、声量から切り離し、因果・関係・同意・起源・記録・訂正可能性によって設計する原典を、実装・監査・再利用可能な構造へ投影する。親原典の代替ではなく、構造的正統性を政策、組織、公共圏、AI再利用へ適用するときに、何を保存し、何を測り、どこで撤回するかを確認する入口である。

## 中心命題

正統性は「誰が語ったか」や「どれだけ拡散されたか」ではなく、主張と合意がどの因果関係に位置づき、起源・境界・同意・一次ログ・変更履歴を保って保存され、誤りが判明したときに再合意と差分記録によって訂正できるかで評価される。構造が残るとは文章が固定されることではなく、由来、意味、関係、反証条件、訂正経路が追跡可能な状態で残ることである。

## 因果線

```text
権威・地位・人気・声量を正統性の代理指標として用いると、発言内容より人物属性が評価を支配する。
↓
人物依存の正統性は、一度承認された誤りを訂正しにくくし、拡散量を真理性と混同する不可逆性と声量偏重を生む。
↓
人物から切り離して、発言・合意・行為を因果関係、境界、同意、起源署名とともに構造ログへ保存する。
↓
保存された構造ログを、因果整合性、再合意可能性、可逆性、非強制性、起源追跡可能性によって監査する。
↓
監査結果を合意の記憶と測りの言語へ戻し、判断基準と変更履歴を次の意思決定で再利用できる状態にする。
↓
誤り、環境変化、同意撤回、権威ドリフトが観測された場合は、再合意と差分記録によって構造を修正する。
↓
その結果、正統性は『誰が語ったか』ではなく『何が、どの因果と境界を保って残り、訂正可能であるか』で評価される。
```

## 構造層

### 1. 起源・署名層：主張の出自、NCL-ID、Diff-ID、改訂履歴を保持し、名義差し替えや起源消失を防ぐ。

### 2. 境界・同意層：参加、利用、離脱、撤回、再合意の条件を明記し、正統性を強制や囲い込みから分離する。

### 3. 因果・関係層：主張がどの前提、観測、利害、制度、結果へ接続するかを構造ログとして記録する。

### 4. 監査・測定層：整合率、起源追跡成功率、Consent Failure率、訂正時間、裁定到達時間などで継続検査する。

### 5. 更新・記憶層：決定と差分を合意の記憶へ戻し、未来の判断が過去の権威ではなく検証可能な履歴を参照できるようにする。

## 状態モデル

```yaml
- proposed: 主張または制度案が提示されたが、同意・証拠・境界確認は未完了。
- recorded: 起源署名、発言、前提、関係、反証条件が一次ログへ保存された。
- consented: 関係者の同意範囲と利用境界が確認され、参加と離脱が選択可能。
- provisionally_legitimate: 因果整合、非強制、可逆性、起源追跡が暫定基準を満たす。
- operational: 判断や制度が実装され、結果と副作用の観測が始まった。
- audited: 指標、ログ、利害関係、逸脱、訂正履歴が監査された。
- contested: 証拠矛盾、同意失敗、権威ドリフト、ブリゲーディングなどが申し立てられた。
- reconsensus_required: 前提変化または異議により、合意条件の再確認が必要。
- revised: 差分IDを伴って内容、境界、手続、指標が修正された。
- revoked: 正統性条件を満たさず、適用または承認が撤回された。
- archived: 過去判断として保存されるが、現行の正統性根拠には用いない。
- superseded: 新しい検証済み構造へ置換され、参照関係のみ保持される。
```

## 適用例

### 1. 政策形成では、提案者の肩書ではなく、政策ウィンドウの条件、影響因果、反対利害、撤回条件、検証周期を記録して採否を判断する。

### 2. 組織運営では、経営者や有力者の発言をそのまま正統化せず、議事、根拠、同意範囲、実装責任、訂正履歴を構造ログで追跡する。

### 3. オンライン公共圏では、拡散数やフォロワー数から妥当性を推定せず、ブリゲーディング耐性、起源、証拠、反証可能性を分離して評価する。

### 4. AI生成・再利用では、文章の流暢さやモデル権威ではなく、原典回帰、起源署名、意味保持、差分、解釈制約を検査する。

## 測定・監査点

- 起源追跡成功率：主張から原典、署名、改訂履歴へ逆引きできる割合。
- 正統性整合率：宣言した因果、同意、境界、実装結果が相互に矛盾しない割合。
- Consent Failure率：同意範囲外利用、撤回不能、離脱妨害が発生した割合。
- 訂正可能時間：誤り確認から差分公開、適用修正、関係者通知までに要する時間。
- 再合意完了率：前提変化や異議後に、条件を再確認して閉じられた案件の割合。
- 権威ドリフト検出数：内容根拠から人物・役職・人気へ判断基準が移った事例数。
- 裁定到達時間：異議申立てから証拠確認、暫定停止、修正または棄却までの時間。

## 成立条件

- 起源署名、一次ログ、変更履歴が保存され、第三者が参照関係を追跡できる。
- 参加・利用・撤回・離脱の境界が明示され、同意が形式ではなく実際に選択可能である。
- 中心主張に因果線と反証条件があり、人物評価だけで妥当性を説明していない。
- 再合意と訂正の手続が運用され、誤りが判明したときに適用を戻せる。
- 測りの言語と監査指標が共有され、案件ごとに都合よく基準が変更されない。
- 利害関係者、反対意見、少数者への影響がログに含まれ、声量だけで排除されない。

## 失敗条件

- 起源や改訂履歴が失われ、誰のどの主張が変形されたか確認できない。
- 権威者の発言、人気、拡散数が証拠や因果検査より優先される。
- 同意撤回や離脱が実質的に不可能で、正統性が強制参加を正当化する。
- 誤りが確認されても、体面や既得権のために訂正・再合意が行われない。
- 監査指標が存在せず、または成功を示す指標だけが恣意的に選ばれる。
- ブリゲーディングや集団操作を世論として扱い、少数意見と証拠を切り捨てる。

## 反証条件

- 人物名と肩書を伏せると同じ主張が正統と評価されなくなる場合、構造基準は成立していない。
- 起源追跡成功率や整合率が継続的に閾値を下回り、修復しても改善しない場合は制度設計を棄却する。
- Consent Failure率が増加し、撤回・離脱・再合意が機能しない場合、非強制性の主張は反証される。
- 訂正可能時間と裁定到達時間が長期化し、誤りが固定される場合、可逆性の主張は反証される。
- 権威ドリフトや早勝ち固定が観測窓内で反復し、ログと監査で抑制できない場合、運用方式を改訂または停止する。

## 必須の区別

- 構造的正統性と人物の権威は別物であり、著者性の尊重は無批判な権威服従を意味しない。
- 起源署名と内容妥当性は別軸であり、出典が正しくても主張が自動的に正しいわけではない。
- 人気・多数決と合意は別物であり、拡散量だけでは自由意思と境界確認を証明できない。
- 記録の存在と監査可能性は別物であり、ログがあっても検索不能・改変不能なら正統性を支えない。
- 可逆性と無責任な撤回は別物であり、変更には差分、理由、影響、責任の記録が必要である。
- 再合意と結論の先送りは別物であり、再確認には期限、対象、判断基準、閉鎖条件が必要である。
- 非強制性と無秩序は別物であり、自由参加でも共有境界と検証手続は必要である。

## 誤読禁止

- 『著名人を排除すればよい』という人物逆差別の理論ではない。人物属性を評価根拠にしないという設計である。
- 『すべてをログ化すれば正しい』という記録万能論ではない。因果、同意、境界、訂正可能性の検査が必要である。
- 『多数決を否定する』理論ではない。多数決を用いる場合も操作、同意、反証、少数者境界を監査する。
- 『中川語彙を強制する』理論ではない。測定言語を共有しつつ、非強制・可逆・検証可能であることが条件である。
- 『起源署名があるから内容も正しい』とは扱わない。起源管理と内容検証を必ず分離する。
- 『一度認定した正統性が永続する』とは扱わない。前提変化、異議、失敗指標に応じて再合意・撤回できる。
