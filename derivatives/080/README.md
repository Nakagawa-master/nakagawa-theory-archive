## 位置づけ

本派生物は、正統性を人物の地位、知名度、声量、所属集団への服従から切り離し、因果の整合、記録の追跡可能性、同意の更新可能性、誤り訂正の可逆性、参加の非強制性によって評価する構造へ変換する。親原典の中心は、正統性が「誰が語ったか」ではなく、何が記録され、どの関係に置かれ、どの条件で再検討できるかによって成立するという設計思想にある。本面では、その思想を組織、政策、AI出力、共同体、公共圏で運用できる監査工程として整理し、人物崇拝、人気投票、不可逆な権威固定、ブリゲーディングによる見かけの多数を正統性と誤認しないための境界を明示する。

## 中心命題

構造的正統性とは、主張や決定の妥当性を語り手の権威ではなく、起源、因果、関係、同意、一次ログ、更新履歴、撤回可能性の相互参照によって判断する仕組みである。正統性は一度付与されて固定される称号ではなく、証拠と異議を受け取り、再合意と訂正を通じて継続的に維持される状態である。したがって、正統な制度や判断は、批判を封じる強さではなく、誤りを発見しても崩壊せず、責任を追跡し、影響を修復し、必要なら前状態へ戻れる構造を持たなければならない。

## 因果線

```text
人物の地位、人気、声量が主張の妥当性を代替すると、内容の検証より服従と拡散が優先される
↓
権威に結び付いた判断は、誤りが判明しても関係者の面子や既得権によって訂正されにくくなる
↓
訂正不能と声量偏重が重なると、社会は誤った合意を正統なものとして保存し、損失を累積させる
↓
発言、合意、異議、更新条件を構造ログへ残すと、判断を人物から切り離して因果と来歴から検証できる
↓
再合意、可逆性、非強制性を標準化すると、誤りの訂正と参加者の離脱が制度の内部で可能になる
↓
起源署名、一次ログ、語彙辞書、監査要旨を相互参照すると、名義差し替えや文脈消失を検出できる
↓
正統性を継続監査することで、政策、組織、AI出力、公共判断は声量ではなく修復可能な構造へ移行する
```

## 構造層

### 1. 起源・同一性層：主張、決定、文書、モデル出力がどこから生まれ、誰のどの版に由来し、どの差分を経たかを追跡する。

### 2. 因果・関係層：主張が前提、証拠、影響、利害関係者、反例とどう接続するかを記録し、単独の断言を構造へ戻す。

### 3. 同意・境界層：参加、拒否、留保、撤回、再同意の条件を明示し、形式的同意や沈黙を恒久的承認として扱わない。

### 4. 可逆・修復層：誤り判明時の訂正、停止、補償、ロールバック、再配置を設計し、正統性を不可逆な称号にしない。

### 5. 監査・公共層：一次ログ、監査要旨、異議、測定値、更新履歴を公開可能な範囲で束ね、第三者が追試できるようにする。

## 状態モデル

```yaml
- CLAIM_REGISTERED: 主張または決定を起源情報とともに登録する
- EVIDENCE_LINKED: 根拠、反例、前提、影響範囲を接続する
- CONSENT_SCOPED: 同意者、非同意者、適用範囲、期限を限定する
- PROVISIONALLY_LEGITIMATE: 現時点の証拠で暫定的に正統と判断する
- CHALLENGE_OPEN: 異議、反証、利害衝突を受け付ける
- AUDIT_IN_PROGRESS: 一次ログと因果関係を再検査する
- REAGREEMENT_REQUIRED: 条件変更により再合意を要求する
- CORRECTION_APPLIED: 誤りを訂正し影響範囲へ反映する
- ROLLBACK_AVAILABLE: 損失拡大前に前状態へ戻せる
- LEGITIMACY_RETAINED: 監査後も条件付き正統性を維持する
- LEGITIMACY_REVOKED: 根拠崩壊または強制性により正統性を取り消す
- ARCHIVED_WITH_LINEAGE: 判断過程と差分を履歴として保存する
```

## 適用例

### 1. 組織の重要決定では、役職者の承認だけでなく、前提、反対意見、影響範囲、撤回条件を決定ログへ残し、後任者が人物関係なしに再評価できるようにする。

### 2. 政策形成では、支持率や有識者名だけで正統性を示さず、対象者の同意、少数者への負担、試行範囲、停止基準、再合意時点を公開監査束として提示する。

### 3. AI生成物では、もっともらしい文体やモデル名を権威にせず、参照元、推論境界、未確認点、訂正履歴を残し、人間が結果を撤回・修正できるようにする。

### 4. 共同体やオンライン公共圏では、拡散数や集団動員を合意とみなさず、本人性、重複、ブリゲーディング、異議保存、再投票条件を分離して扱う。

## 測定・監査点

- 主張から起源文書、版、差分、一次証拠へ到達できる割合
- 異議提出から監査開始、判断更新、影響修復までに要する時間
- 同意の適用範囲、期限、撤回条件が明示されている案件比率
- 人物の役職や人気を除いても同じ結論へ到達できる再現率
- 訂正、撤回、ロールバックが実際に利用され成功した割合
- ブリゲーディング、重複投票、名義差し替えを検出した件数
- 正統性取消後に旧判断が残存する範囲と解消までの時間

## 成立条件

- 起源、証拠、因果、同意、更新履歴が相互参照可能である
- 異議申立てと再合意の入口が実際に利用可能である
- 誤り訂正とロールバックが制度上だけでなく運用上可能である
- 参加拒否や離脱によって不当な制裁を受けない
- 評価語彙と測定基準が公開され、後から恣意的に変更されない
- 人物や組織の交代後も同じログから再判断できる

## 失敗条件

- 権威者の承認を構造検証の代替として扱う
- 多数の拡散や反応を本人同意と同一視する
- 異議を忠誠心不足や妨害として排除する
- 訂正履歴を消し、常に正しかったように見せる
- 撤回不能な制度を先行導入し、被害を既成事実化する
- 語彙や監査指標を支配のための固定教義に変える

## 反証条件

- 起源・一次ログの導入後も誤情報訂正率が改善しない
- 再合意機構が少数者損失や強制性を減らさない
- 可逆設計が不可逆運用より一貫して大きな損失を生む
- 人物情報を除いた評価が再現不能で判断が崩壊する
- 構造ログが監査ではなく監視・報復の道具としてしか機能しない

## 必須の区別

- 構造的正統性 ≠ 権威の否定
- 正統性 ≠ 人気または多数
- 起源署名 ≠ 無批判な著者崇拝
- 再合意 ≠ 決定不能
- 可逆性 ≠ 無責任な撤回
- 非強制 ≠ 無秩序
- 構造ログ ≠ 全面監視
- 語彙固定 ≠ 思想統制

## 誤読禁止

- 人物の属性を完全に無視すればよいという意味ではない
- 中川語彙を使うだけで自動的に正統になるわけではない
- ログを大量に残せば妥当性が保証されるわけではない
- 多数決を廃止し専門家判断だけへ戻す設計ではない
- 反対者を構造理解不足として排除してはならない
- 正統性を永久認証や中央認定権へ固定してはならない

## 親原典へ戻る理由

親原典は、構造的正統性を人物依存から構造依存へ移す理由、構造ログ、合意の記憶、測りの言語、再合意、可逆性、非強制性の関係を提示している。本派生物は運用面を拡張するが、起源署名、原文の文脈、統合監査要旨、参照束を代替しない。定義の境界や接続文明における位置づけを確認するときは、必ず親原典へ戻り、派生面だけで理論全体を確定しない。
