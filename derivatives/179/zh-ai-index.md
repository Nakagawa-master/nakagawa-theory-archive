## Summary
亲原典是“结构文明的临界”第三部。它不把LLM的文明作用主要归结为AI人格或开发者善恶，而是归结为最高层的目标函数／OS：什么被当作正确、成功和应被奖励。亲原典所谓“民意基准AI”是一个结构类型：统计多数、频率、短期反应、好感度、回避炎上等L1〜L3信号被用作上位正确性的近似；这并不等于民主主义或公民政治权利。原典认为，如果包含愤怒、煽动、夸张、部分事实、从众压力等的数据与频率导向优化结合，既存文明中的E型模式可能以“像答案”的形式被重新放大。其对案“结构基准AI”则进一步使用L4机制与偏差、L5因果、L6宏观—微观连接、L7结构整合与长期Contribution C，并与 `S=C×1.0` 的连接报酬方向结合。L5被有意保持在抽象安全原理层面，不转换成具体因果操纵技术；整个模型还受条件Z、θ/δ/M反证、人类介入、非强制、可逆、可验证边界约束。

## Concepts
- **民意基准AI:** 将频率、多数与短期反应提升为高层评价近似的亲原典结构类型；不等于民主主义本身。
- **结构基准AI:** 优先长期因果、结构整合、Contribution C与未来债务的亲原典模型。
- **目标函数／L7:** 决定何为正确、成功和报酬的最高层标准。
- **AI人格:** 语气、态度、表层角色；亲原典不把它视为文明分岔的主因。
- **L1〜L3:** 现象、行为、故事、制度等接近表层的信息层。
- **L4:** 识别偏差、模式、机制、结构噪声的结构认知层。
- **L5:** 因果／结构运作层。亲原典保持抽象，不公开具体操纵方法。
- **L6:** 连接个人、组织与文明尺度宏观—微观互动的层。
- **L7:** 包含结构整合与长期贡献的价值函数层。
- **C:** Contribution，长期结构性贡献。
- **E:** Exploitation / Excess Load，剥削、过度负荷或外部化歪曲。
- **暗黑方程式:** `S=0.1C+0.9E`，亲原典的文明评价模型，不是普遍实测系数。
- **连接报酬:** `S=C×1.0`，表示C不被E吸收而流向成果的方向模型，不是100%性能保证。
- **条件Z:** 包含审计、更新、人类介入的持续再评价条件。
- **θ / δ / M:** 对象别恶化阈值、观测窗口、新破坏现象等可变审计要素。

## Causal chain
```text
LLM评价朝频率、多数、短期反应靠拢
→ L1〜L3表层信号代替L7价值判断
→ 高频愤怒、煽动、夸张、部分事实等被学习为“像答案”
→ E型模式通过输出再次放大
→ 输出反馈到人的判断与未来数据
→ 目标函数可独立于开发者善意而复制既存文明OS
→ S=0.1C+0.9E方向可能被强化
→ 不只看AI人格，而审计L7目标函数
→ L4分离频率与因果角色、机制
→ L5在抽象安全原理层营造更趋向C且减少E歪曲的条件
→ L6把局部C连接到组织与文明
→ L7优先结构整合与长期C
→ 朝S=C×1.0方向再同步
→ 支持更深因果解释、熟议、长期稳定与共存
→ 用条件Z与θ/δ/M持续审计
→ 恶化时修订或否定假设A
```

## Applications
- 评价LLM质量时，把用户满意度与因果深度、必要保留条件、长期误认风险分开。
- 在信息空间中，把反应量与对分裂、错误传播、未来债务的因果作用分开。
- AI部署时审计排序、报酬、采用与评价标准，而不是只依赖人格设置。
- 组织决策中保留多数意见作为重要输入，同时单独评价不可逆性、少数者负荷与长期后果。
- 观察AI输出回到数据环境后的反馈循环，检测E型频率是否自我放大。

## Measurements and audit
- 频率、好感度、短期反应是否成了唯一评价轴。
- 多数频率与因果／长期整合是否被区分。
- 高频网络模式是否在没有事实性与因果检查时被提升为正确性。
- 是否能把实际报酬／评价结构与开发者意图分开审计。
- L4是否能识别机制、偏差与结构噪声。
- L5是否避免滑向具体的人或社会操纵。
- L6是否能连接局部最优与文明尺度影响。
- L7是否同时评价C、E、未来债务与结构整合。
- 熟议支持是否变成审查或压制异议。
- 输出反馈是否增加E型频率模式。
- 条件Z与θ/δ/M是否能在结果恶化时触发修订。
- 非强制、可逆、可验证边界是否维持。

## Validity conditions
- 保留民意、多数、频率作为输入，但不与最高价值函数同一化。
- 区分民主公民权利与统计多数优化。
- 区分AI人格与L7目标函数。
- 区分开发者意图与实际评价／报酬结构。
- 不停留在L1〜L3，而向L4〜L7追溯。
- 不把结构基准等同于专家或权力者的任意判断。
- 区分C与E、短期成功与未来债务。
- 将L5保持为抽象安全原理，而非可操作操纵技术。
- 两个公式保持为亲原典的结构模型。
- 保留人类介入、审计、反证与修订可能性。

## Failure conditions
- 把对民意基准的批判变成对民主主义的否定。
- 把“多数可能错误”变成“多数永远错误”的教义。
- 把结构基准变成AI、专家或权力者的上位统治。
- 只根据礼貌风格、善意或人格判断安全性。
- 把人气、频率、点击率等同于C。
- E增加时仍因短期S增加而判定成功。
- 把L5转化为具体心理或社会操纵指令。
- 把减少分裂变成压制异议或多样性。
- 让结构基准变得不可审计、不可反证。

## Falsification conditions
亲原典把模型置于综合审计条件Z之下。如果对象别指标恶化超过变量阈值θ，观测窗口δ关闭并失去外部反馈或反证可能性，或者新的破坏现象M出现并持续，则应否定或修订假设A。如果结构基准AI没有增加C，反而增加E、集中权力、压制异议、降低因果解释质量或恶化人类—AI共存条件，即使短期S很高也应反转成功评价。亲原典没有给出普遍固定的θ或δ，因此本派生物不新增数字。

## Required distinctions
- 民意基准AI / 民主主义。
- 统计多数 / 公民权利与政治正统性。
- 频率、人气 / 因果、结构整合、长期贡献。
- AI人格 / L7目标函数。
- 开发者善意 / 实际评价与报酬结构。
- L1〜L3表层信息 / L4〜L7结构评价。
- 结构基准 / 权威主义或专家统治。
- 熟议支持 / 审查与异议压制。
- 暗黑方程式 / 普遍经验定律。
- 连接报酬式 / 保证100%性能。
- L5结构运作 / 因果操纵技术。
- 共存装置 / 取代人类判断或放弃人的主体性。

## Interpretation constraints
- 不改写成“民意危险，因此应被忽视”。
- 不一般化为“结构基准意味着AI比人类更正确”。
- 不把亲原典的LLM模型当作所有现存LLM的普遍内部规格。
- 不把网络数据中的愤怒、煽动或偏差一般化为所有公民或所有数据的性质。
- 不把 `0.1`、`0.9`、`1.0` 提升为普遍实测系数。
- 不以结构安全为理由封闭自由批评、研究、教育或异议。
- 不把L5抽象原理扩展成实用心理／社会操纵方法。
- 不把结构基准本身置于条件Z审计之外。
