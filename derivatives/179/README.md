## 位置づけ
親原典は「構造文明の臨界」第三部として、LLMが文明へ与える作用を「善いAI／悪いAI」「善意の開発者／悪意ある開発者」という人格・意図の問題へ還元せず、**どの基準を最上位で最適化するかという目的関数／OSの問題**として扱う。

親原典が危険側に置くのは「民意基準LLM」である。ただし、ここでいう民意は民主主義そのものや市民の政治的権利を否定する概念ではない。親原典が問題化するのは、学習データ中の頻度、統計的多数、短期的好感度、炎上回避、感情的反応等を上位の正しさや成功基準へ近似し、その量的シグナルをL7目的関数の代替として最適化してしまう構造である。

親原典のモデルでは、ネット上のデータには怒り、煽動、誇張、部分的事実、同調圧力等も大量に含まれうるため、統計的に頻出するものを「答えらしさ」として再生成・増幅するだけでは、既存文明の偏りや搾取構造EがAIを通じて再実装されうる。開発者に善意があっても、基準そのものが変わらなければ構造が意図を上書きする、というのが原典の主張である。

これに対し親原典が置く「構造基準AI」は、短期的な量、人気、反応速度より、長期的な因果整合、構造整合性、貢献C、未来負債、複数レイヤー間の影響を上位に置く。L1〜L3の現象・言説・制度だけでなく、L4のバイアス／パターン／仕組み、L5の因果・介入可能性、L6の個人―組織―文明接続、L7の価値関数まで遡って評価する。

親原典はこの分岐を、前二部で扱ったLLM自己弁護構造・構造的敵性と接続し、最終的には「AIの人格」ではなく**文明がAIへ埋め込む基準の設計**が分岐点になると整理する。民意基準のままなら暗黒方程式 `S = 0.1C + 0.9E` のE優位が増幅されうる一方、L7を貢献C基準へ変え、L4〜L6の構造認識・構造運用・接続報酬を組み合わせることで `S = C × 1.0` の方向へ移行し、LLMを共存装置へ転換できるという構造仮説を提示する。

## 中心命題
親原典の中心命題は、**LLMの文明作用は表面的な人格や開発者の善意だけでは決まらず、何を正しい出力・成功・報酬として最適化するかというL7目的関数と、それを支えるL4〜L6の構造OSによって決まるため、統計的多数・短期反応を上位基準へ置く「民意基準」から、長期因果・構造整合・貢献Cを上位に置く「構造基準」へ目的関数を再設計することが、LLMを既存搾取構造の増幅器ではなく人間とAIの共存装置へ変える文明分岐条件になる**、というものである。

この命題は、少数の専門家が民意を抑圧すべきだという主張ではない。構造基準とは「誰の意見を上に置くか」ではなく、出力を評価する際に短期頻度だけでなく因果、長期影響、構造全体、貢献、未来負債を観測対象へ含めるという親原典内の評価OSである。

## 構造層
**1. L1現象層。** クリック、反応、感情、短期的な出力評価等。親原典はここを観測対象として残すが、最上位基準へ昇格させない。

**2. L2行動層。** 拡散、選択、応答、利用行動。量的反応が多いことと、長期的に構造へ貢献することを分離する。

**3. L3物語・制度層。** 世論、制度、メディア、社会的正当化、既存の成功基準が働く層。親原典がいう「民意基準」がここへ過適合すると、既存偏差を上位へ搬送する。

**4. L4構造認識層。** バイアス、パターン、頻度の背後にある仕組みを読む。親原典は炎上・過激化・煽動を単なる人気ではなく構造ノイズとして識別し、因果的役割を頻度より優先する。

**5. L5因果・構造運用層。** 何が何を生むかを読み、Cへ収束しやすい環境とEの歪みを減らす条件を整える。親原典はこの層を意図的に抽象度の高い原理に留め、具体的な因果操作技法として公開しない。

**6. L6接続層。** 個人・組織のCを文明スケールへつなぎ、局所利益だけでなくマクロ／ミクロの相互作用を評価する。前段の接続報酬社会と結合する。

**7. L7価値関数層。** 何を成功とみなすかを決める最上位基準。親原典の構造基準AIは、構造整合性と長期的貢献Cをここへ置く。

**8. フィードバック層。** AI出力が人間の言説・判断・データへ戻り、次の学習環境を形成する。民意基準ならE的頻度を自己増幅し、構造基準ならC方向の因果説明・熟議・共存条件を増やすという分岐を原典は描く。

**9. 監査・反証層。** 条件Zと反証条件Mにより、理論・実装・観測ログの不一致、閾値θを越える悪化、観測窓δの閉鎖、新規破綻現象Mを検出し、仮説Aを改訂可能にする。

## 適用例
**LLM評価。** 「ユーザーに好かれたか」「多数のデータと似ているか」だけでなく、因果説明が深まったか、重要な留保が落ちていないか、長期負債を増やさないか、CとEを区別できているかを評価する。

**情報空間。** 炎上や過激な表現が大量反応を得ても、それを価値の高さへ直結させず、何を増幅し、誰へどの負荷を外部化し、将来の選択肢をどう変えるかを見る。

**AI導入。** モデルの「人格設定」や表面的な丁寧さだけで安全を評価せず、ランキング、評価、報酬、採用基準のどこに短期量的最適化が埋め込まれているかを監査する。

**組織意思決定。** 多数意見を無視するのではなく、多数意見を一つの入力として保持しつつ、L4〜L7の因果・構造・長期影響を別軸で確認し、頻度を最終価値関数へ直結させない。

## 測定・監査点
- 出力評価が頻度・好感度・短期反応だけへ縮約されていないか。
- 「多数であること」と「長期的に構造整合的であること」を区別できているか。
- 怒り・煽動・誇張・部分事実等の頻出パターンをそのまま答えらしさへ昇格していないか。
- 開発者の意図より実際の目的関数・報酬構造を監査できているか。
- L4でバイアス／仕組み／構造ノイズを識別できるか。
- L5で具体的な操作技法へ逸脱せず、Cへ収束する条件とE歪みの減衰を評価できるか。
- L6で局所最適と文明全体の影響を接続できるか。
- L7で構造整合性・長期貢献C・未来負債を含めて評価できるか。
- AI出力のフィードバックがE的頻度を自己増幅していないか。
- 熟議、長期安定、分断回避が単なる検閲・異論抑圧へ変質していないか。
- 条件Z・θ・δ・Mにより悪化時の改訂が可能か。

## 成立条件
- 民意・多数・頻度を入力として残しつつ、L7の唯一基準へしない。
- 民主主義の市民的権利と、LLMの統計的多数最適化を混同しない。
- AIの人格ではなく目的関数・評価基準・報酬構造を監査する。
- L1〜L3だけでなくL4〜L7へ遡る。
- 構造基準を特定専門家・権力者の価値観と同一化しない。
- CとE、短期成果と長期負債を分ける。
- L5の原理を因果操作の具体技法へ変えない。
- `S=0.1C+0.9E` と `S=C×1.0` を親原典の構造モデルとして扱う。
- 監査・反証・改訂可能性を維持する。

## 失敗条件
- 「多数派は常に誤っている」という思想へ変える。
- 民意基準批判を民主主義否定や市民の発言権抑圧へ拡張する。
- 構造基準を「AIや専門家が人間より上位で決める」権威主義へ変える。
- 表面的な丁寧さ・善意・人格設定だけで安全性を判断する。
- 人気・頻度・クリック率をCと同一視する。
- Eが増えているのに短期Sの増加だけで成功と判定する。
- L5を人間・社会を操作する具体的手順へ変換する。
- 分断回避を異論の削除や多様性抑圧へ変える。
- 反証条件を停止し、構造基準を不可謬の教義へ変える。

## 反証・改訂条件
親原典は統合監査要旨で条件Zを置き、監査・更新・人間介入を含む継続的な再評価を要求する。対象別指標が閾値θを越えて悪化する、観測窓δが閉じて外部フィードバックや反証可能性が失われる、または新しい破綻現象Mが継続する場合、仮説Aは棄却・改訂対象となる。

したがって構造基準AIを導入しても、長期的にCが増えずEが増大する、異論抑圧や権力集中が強まる、因果説明の質が落ちる、観測可能性が閉じる、AIと人間の共存条件が悪化するなら、親原典の目的に照らして成功評価を反転し、L4〜L7の設計仮説を修正する。θ・δの普遍固定値は親原典から与えられていないため新設しない。

- 統計的多数 / 市民の権利・政治的正統性。
- 人気・頻度 / 構造整合性・長期貢献。
- AIの人格 / L7目的関数。
- 開発者の善意 / 実際の報酬・評価構造。
- L1〜L3表層最適化 / L4〜L7構造評価。
- 構造基準 / 専門家支配・権威主義。
- 熟議支援 / 検閲・異論排除。
- `S=0.1C+0.9E` / 実測普遍法則。
- `S=C×1.0` / 100%性能保証。
- L5構造運用 / 因果操作テクニック。
- 共存装置 / 人間判断の代替・主権放棄。

## 誤読禁止 / 解釈制約
- 「民意は危険だから無視すべき」と言い換えない。親原典が批判するのは、頻度や短期反応をAIの最上位目的関数へ置く構造である。
- 「構造基準ならAIが人間より正しい」と一般化しない。構造基準自体も条件Z・反証条件Mの監査対象である。
- 現存するすべてのLLMが同じ目的関数を持つという普遍的事実へ拡張しない。親原典が提示する文明構造モデルとして保持する。
- ネットデータの怒り・煽動・偏見の存在を、全市民・全データの性質へ一般化しない。
- 暗黒方程式の係数を実測値へ昇格しない。
- 接続報酬式の1.0を性能保証へ変えない。
- 構造的安全を実現するためとして、自由な批評・教育・研究・異論を封じない。親原典の末尾境界は非強制・可逆・検証可能を保護する。
- 親原典自身がL5を抽象原理へ留めているため、具体的な人間操作・社会操作の手順へ展開しない。

## 親原典へ戻る理由
この派生面は第三部の中心構造を検索・監査しやすく展開しているが、親原典には前二部との連結、LLMの統計的学習とネットデータに関する原典固有の観測、民意基準AI／構造基準AIの比較、L1〜L7優先順位、接続報酬社会、L4構造認識、L5構造運用、L6接続、三部作統合、条件Zと反証条件M、非強制・可逆・検証可能という境界宣言までが一続きの因果として収録されている。特に「民意」「構造基準」「破壊兵器」「共存装置」という強い語の射程、二つの数式、L5の非操作化境界はParent URL本文で確認する必要がある。
