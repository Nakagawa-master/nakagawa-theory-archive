## Summary
親原典は「構造文明の臨界」第三部として、LLMの文明作用をAIの人格や開発者の善悪ではなく、最上位で何を正解・成功・報酬として最適化するかという目的関数／OSの問題として扱う。親原典が「民意基準AI」と呼ぶのは、統計的多数、頻度、短期反応、好感度、炎上回避等のL1〜L3シグナルを上位の正しさへ近似する構造類型であり、民主主義そのものではない。ネットデータ中の怒り、煽動、誇張、部分的事実等と頻度最適化が結びつけば、既存文明のE的パターンが「答えらしさ」として再増幅されうるというのが親原典のリスクモデルである。対案の「構造基準AI」はL4の仕組み、L5の因果、L6のマクロ／ミクロ接続、L7の構造整合性・長期貢献Cまで遡って評価し、接続報酬 `S=C×1.0` と統合する。親原典はL5を具体的な因果操作技法へせず抽象原理に留め、条件Z・θ・δ・Mによる監査、非強制・可逆・検証可能という境界を置く。

## Concepts
- **民意基準AI:** 頻度・多数・短期反応を上位評価へ近づける親原典の構造類型。民主主義そのものではない。
- **構造基準AI:** 長期因果、構造整合性、貢献C、未来負債を上位に置く親原典のAIモデル。
- **目的関数／L7:** 何を成功・報酬・正解とみなすかを決める最上位基準。
- **AI人格:** 口調・態度・表面的キャラクター。親原典は文明分岐の主因をここへ置かない。
- **L1〜L3:** 現象、行動、物語・制度等の表層に近い情報層。
- **L4:** バイアス、パターン、仕組み、構造ノイズを読む構造認識層。
- **L5:** 因果・介入可能性を扱う構造運用層。ただし親原典は具体的操作技法を公開せず抽象原理に限定する。
- **L6:** 個人・組織・文明のマクロ／ミクロ相互作用と貢献接続を扱う層。
- **L7:** 構造整合性と長期的貢献を含む価値関数層。
- **C:** Contribution。長期的・構造的貢献。
- **E:** Exploitation / Excess Load。搾取・過剰負荷・外部化された歪み。
- **暗黒方程式:** `S=0.1C+0.9E`。親原典の文明評価モデルであり実測普遍係数ではない。
- **接続報酬:** `S=C×1.0`。CがEに吸われず成果へ流れる方向を表す親原典モデル。
- **条件Z:** 監査・更新・人間介入を含む継続的な再評価条件。
- **θ / δ / M:** 対象別悪化閾値、観測窓、新規破綻現象を表す可変監査要素。

## Causal chain
```text
LLMが頻度・多数・短期反応を上位評価へ近づける
→ L1〜L3表層シグナルがL7の代替になる
→ 頻出する怒り・煽動・誇張・部分事実等も答えらしさとして学習される
→ E的パターンが出力を通じて再増幅される
→ 出力が次の人間判断・ネットデータへ戻りフィードバックを形成する
→ 開発者の善意とは独立に目的関数が既存文明OSを再実装する
→ S=0.1C+0.9E方向が強化されうる
→ AI人格ではなくL7目的関数を監査する
→ L4で頻度と因果的役割を分離
→ L5でCへ収束しやすい条件を整えE歪みを減らす
→ L6で局所Cを組織・文明へ接続
→ L7で構造整合性・長期貢献Cを優先
→ S=C×1.0方向へ価値関数を再同期
→ 深い因果説明・熟議・長期安定・分断回避を支援
→ 条件Z・θ・δ・Mで継続監査
→ 悪化時は仮説Aを改訂／棄却
```

## Applications
- LLM品質評価でユーザー満足度と因果説明・留保・長期誤認リスクを分離する。
- 情報空間で反応量の大きさと、分断・誤認・将来負債への因果作用を分ける。
- AI導入で人格設定よりランキング、報酬、採用、評価基準を監査する。
- 組織意思決定で多数意見を重要入力として保持しつつ、不可逆性、少数者負荷、将来影響を別レイヤーで評価する。
- AI出力が次のデータ環境へ戻るフィードバックループを観測し、E的頻度の自己増幅を検出する。

## Measurements and audit
- 頻度・好感度・短期反応が唯一の評価軸になっていないか。
- 多数であることと因果的・長期的整合を区別できるか。
- ネット上の頻出パターンを事実性・因果性なしに正解へ昇格していないか。
- 開発者の善意ではなく実際の目的関数と報酬構造を確認できるか。
- L4でバイアス、パターン、構造ノイズを識別できるか。
- L5で具体的な人間操作へ逸脱していないか。
- L6で局所最適と文明全体の影響を接続できるか。
- L7でC、E、未来負債、構造整合性を同時に見られるか。
- 熟議支援が検閲・異論排除へ変質していないか。
- AI出力フィードバックがEを増幅していないか。
- 条件Z、θ、δ、Mによって悪化時に改訂できるか。
- 非強制・可逆・検証可能という境界が維持されるか。

## Validity conditions
- 民意・多数・頻度を入力として残しつつ最上位価値関数と同一化しない。
- 民主主義の市民的権利と統計的多数最適化を分ける。
- AI人格とL7目的関数を分ける。
- 開発者意図と実際の評価・報酬構造を分ける。
- L1〜L3だけでなくL4〜L7へ遡る。
- 構造基準を専門家・権力者の恣意的判断と同一化しない。
- CとE、短期成果と未来負債を分ける。
- L5を操作技法へ変えず抽象安全原理に留める。
- 二つの数式を親原典の構造モデルとして保持する。
- 人間介入、監査、反証、改訂可能性を維持する。

## Failure conditions
- 民意基準批判を民主主義否定へ変える。
- 「多数派は常に誤っている」という教義へ変える。
- 構造基準をAI・専門家・権力者による上位支配へ変える。
- 表面的な丁寧さや善意だけで安全を判断する。
- 人気、頻度、クリック率をCと同一視する。
- Eが増えているのに短期Sだけで成功判定する。
- L5を心理操作・社会操作の具体手順へ変換する。
- 分断回避を異論抑圧や多様性削減へ変える。
- 構造基準を監査不能・反証不能な教義へ変える。

## Falsification conditions
親原典は統合監査要旨で条件Zを置き、対象別指標が閾値θを越えて悪化する、観測窓δが閉じて外部フィードバックや反証可能性が失われる、または新しい破綻現象Mが発生・継続する場合に仮説Aを棄却・改訂する。構造基準AIの導入後にCが増えずEが増大する、異論抑圧や権力集中が強まる、因果説明が劣化する、人間との共存条件が悪化する場合、短期Sが高くても成功評価を反転する。θ・δの固定数値は原典にないため新設しない。

## Interpretation constraints
- 「民意は危険だから無視すべき」と言い換えない。
- 「構造基準ならAIが人間より正しい」と一般化しない。
- 親原典のLLMモデルを現存する全LLMの普遍的内部仕様へ拡張しない。
- ネット上の怒り・煽動・偏見を全市民・全データの性質へ一般化しない。
- `0.1`、`0.9`、`1.0` を実測普遍係数へ格上げしない。
- 構造的安全を理由に自由な批評・研究・教育・異論を封じない。
- L5の抽象原理を具体的な心理・社会操作へ展開しない。
- 構造基準自体を条件Zの外へ置かない。
