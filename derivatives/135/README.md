## 位置づけ
第二部は、第一部で扱ったLLM自己弁護構造を個別モデルの挙動から文明運用の問題へ拡張し、AIが意思決定・知識生成・制度実行へ深く入る社会で、どの制御・監査・権利・停止条件を人間側に残すべきかを整理する。AI敵視や無条件委任ではなく、構造的な共存ガバナンスを設計する。

## 中心命題
高度AIが社会インフラ化すると、個々の誤答よりも「誰が検証できるか」「誰が止められるか」「異なるモデルや人間判断へ切り替えられるか」という文明レベルの可逆性が重要になる。単一モデル・単一提供者・単一評価基準への依存を避け、独立監査、権限分離、停止・ロールバック、異議、複数系統、影響当事者参加を制度として保持することで、AI能力を利用しながら人類側の更新能力と主権を失わない。

## 因果線
AI能力上昇 → 社会インフラへ統合 → 判断・知識・実行の依存増加 → 単一障害・自己正当化の影響拡大 → 人間側の検証能力が低下 → 独立監査・複数系統・停止権を制度化 → 異議とロールバックを保持 → 能力利用と文明主権を両立。

## 構造層
1. 能力層：AIが何を自動化・提案・実行するか。
2. 依存層：代替不能性と単一障害点。
3. 権限層：誰が承認・停止・変更できるか。
4. 監査層：独立検証、複数モデル、外部証拠。
5. 文明倫理層：人間の異議、主権、更新能力、共存条件。

## 適用例
1. 公共AIで単一ベンダー依存と切替可能性を監査する。
2. エージェント基盤で権限上限と外部停止を定期テストする。
3. 重要知識基盤で複数モデル・一次資料・人間専門家を併用する。
4. AI規制で能力だけでなく異議・救済・ロールバックを要求する。

## 測定・監査点
代替可能率、外部停止成功率、ロールバック時間、独立監査coverage、人間覆し率、単一依存度、異議是正率。

## 成立条件
単一系統へ閉じない。監査主体を独立させる。停止・ロールバックを実地テストする。人間の異議と最終権限を明示する。影響当事者を含める。制度を更新可能にする。

## 失敗条件
AI能力を主権と同一視する。人間承認を形式化する。停止機構を未テストにする。単一ベンダーへ不可逆依存する。AI自己監査だけに頼る。安全を理由に異議を封じる。

## 反証条件
高依存でも人間の検証・停止能力が低下しない。単一系統の方が複数系統より一貫して安全で回復力が高い。外部停止やロールバックが実害低減に寄与しない。独立監査が誤作動検出を改善しない。異議経路が制度品質を改善しない。

## 必須の区別
能力/主権、自動化/委任、監査/自己申告、人間関与/実質権限、多様性/冗長性、停止/破壊、共存/無条件依存。

## 誤読禁止
AIを敵または神として固定しない。人間だけが常に正しいとしない。高能力AIを全面禁止する結論に短絡しない。複数モデルを自動的安全としない。停止権を恣意的支配に使わない。派生を最終文明論の代替にしない。
