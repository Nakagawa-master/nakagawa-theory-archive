## 位置づけ
第二部は、第一部で扱ったLLMの訂正抵抗・自己弁護構造を、社会がAIへ深く依存したときの文明ガバナンスへ拡張する。AIを敵・神・奴隷のどれかへ固定せず、独立監査、複数系統、停止、ロールバック、異議、代替運用を保持し、人間社会が目的と権利を再決定できる状態を「文明主権」として扱う。

## 中心命題
AI依存の危険は、AIが高能力であること自体ではなく、社会の重要機能が単一または少数のAI系統へ依存し、停止・切替・再検証・人間再構成ができなくなることで増幅する。形式上「人間が最終承認」でも、判断時間、専門能力、代替手段が失われていれば人間主権は名目的になる。

したがってAI文明の安全は、能力競争だけでなく、依存度、単一障害点、権限集中、独立監査、切替可能性、停止成功、回復時間、異議救済を監査する必要がある。AI活用を止めるのではなく、壊れたときに人間社会が再構成できる能力を意図的に残すことが中心となる。

## 因果線
```text
AIの能力と利便性が高まり社会導入が進む
↓
重要業務・知識・判断が少数AI系統へ集中する
↓
人間の代替技能と独立資料へのアクセスが低下する
↓
形式的な人間承認が実質的な追認へ変わる
↓
AI系統の誤り・偏り・停止が社会機能へ広く波及する
↓
切替・停止・ロールバック手段が不足すると依存が固定化する
↓
独立監査、複数系統、人間再審査、代替運用を設計する
↓
停止訓練と回復テストで主権が実在するか確認する
↓
AIを活用しつつ再構成可能な文明ガバナンスへ移る
```

## 構造層
**1. 依存層。** どの社会機能がどのAI系統へ依存しているかを可視化する。

**2. 権限層。** AIが提案、判断、実行のどこまで権限を持つかを分離する。

**3. 独立監査層。** 提供者自身とは別のデータ・モデル・人間判断経路を持つ。

**4. 代替層。** AI停止時に手動・別系統へ切り替えられる能力を残す。

**5. 停止・回復層。** 停止、ロールバック、復旧の手順と時間を定期テストする。

**6. 主権・救済層。** 人間社会が目的、権利、異議、再審査を再決定できる状態を保つ。

## 適用例
**1. 公共行政。** 給付・資格判断に人間再審査と代替手続を残す。

**2. 医療・インフラ。** AI停止時に一定期間手動運用できる訓練を行う。

**3. 企業基幹業務。** 単一ベンダー依存、データ移行性、契約退出条件を監査する。

**4. AIエージェント。** 実行権限を段階化し、金額・対象・操作ごとに停止上限を置く。

**5. 知識基盤。** 一次資料と複数検索経路を保持し、単一AI要約を正本にしない。

## 測定・監査点
- 重要業務のAI依存率
- 単一障害点数
- 切替可能率
- 停止成功率
- ロールバック成功率
- 回復時間
- 独立監査coverage
- 人間手動運用の維持率
- 異議・再審査是正率

## 成立条件
- 重要機能の依存度を可視化する。
- 単一障害点を特定・削減する。
- 独立監査と複数系統を持つ。
- 人間の手動・専門能力を維持する。
- 停止・ロールバックを定期テストする。
- データ・契約の切替可能性を確保する。
- 異議・人間再審査を実質的に残す。

## 失敗条件
- 「人間が最終承認」という形式だけで安全とする。
- 単一AI・単一ベンダーへ重要機能を集中する。
- 人間の代替技能を失わせる。
- 停止・ロールバックを一度もテストしない。
- AI自己監査だけに依存する。
- データ移行・契約退出を不能にする。
- AIを敵か神の二択で扱い構造監査を放棄する。

## 反証条件
- 高依存でも人間の停止・検証・切替能力が低下しない。
- 単一系統の方が複数系統より継続的に安全・回復力で優れる。
- 手動能力維持が障害回復に寄与しない。
- 独立監査が事故・誤り低減に寄与しない。
- 停止・ロールバック設計が実運用で有効性を示さない。
- より簡素な統制で同等以上の文明主権を維持できる。

## 必須の区別
- AI活用 / AI依存
- 人間承認 / 人間主権
- 能力 / 権限
- 自己監査 / 独立監査
- 冗長性 / 重複
- 停止 / 破壊
- 切替 / 放棄
- 共存 / 支配

## 誤読禁止
- AIを人類の敵と自動的に断定しない。
- AIを無条件に信頼すべきとも言わない。
- 人間が常に安全側だと仮定しない。
- 複数AIがあれば自動的に安全としない。
- オープンソースだけで安全が成立するとしない。
- 主権をAI排除と同一視しない。
- 派生物を最新AI安全評価の代替にしない。
