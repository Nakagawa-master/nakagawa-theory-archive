## 位置づけ
親原典は、恐怖・利益・監視と神話・惰性の圧力によって判断基準、履歴、責任、言葉の意味まで汚染されやすい耐久文明の内部で、それでも再起動可能性を失わないための局所空間を「D系クリーンルーム」として定義する。D系は理想郷でも完全切断でもなく、レガシー文明と接続しながら腐敗構造に回収されないための「接続された隔離」である。

## 中心命題
D系クリーンルームは、レガシー文明の内部に接続したまま、判断基準・履歴・責任痕跡・構造記述・接続技術を汚染から隔離して保存し、相転移後の再起動可能性を残す局所領域である。成立には「接続していること」と「汚染されないこと」の両方が必要で、切断だけでも埋没だけでも移行回路にならない。

## 因果線
耐久文明の延命 → 恐怖・利益・監視・神話・惰性による基準汚染 → 相転移だけでは改善が保証されない → 崩壊前から再起動座標を保存する必要 → レガシー文明内部に局所的な非汚染領域を設置 → 接続を維持しながら判断基準・履歴・責任・構造認識を隔離 → 相転移後に次の秩序へ橋を架ける再起動可能性を保持。

## 構造層
1. **外部接続層**: レガシーOSの制度、資源、情報、人間関係、現実の摩擦と完全には切断しない。
2. **隔離境界層**: 外部の恐怖・利益・監視・神話・惰性が内部の判断基準を書き換えることを抑える。
3. **保存層**: 構造記述、履歴の連鎖、判断基準、責任痕跡、接続技術を保持する。
4. **自己照合層**: 利益への回収、神話化、監視コードの内面化、惰性化による内部腐敗を定期的に点検する。
5. **移行層**: 保存された核を相転移後の新しい秩序へ接続するための橋として機能する。

## 状態モデル
- **接続・非汚染相**: 外部と接続しつつ内部基準が保持され、D系として機能する。
- **切断相**: 汚染を避けるため外部との接続まで失い、移行回路として無力化する。
- **回収相**: 外部と接続する過程で利益・権威・監視・神話へ内部基準が書き換えられ、耐久文明の末端部品になる。
- **内部劣化相**: 当初の形式だけが残り、意味を失った反復や自己正当化によって小さな耐久文明へ変質する。
- **再起動接続相**: 保存された記述・履歴・基準・接続技術が、相転移後の秩序形成へ利用可能になる。

## 適用例
- 個人が外部制度に従いながらも、判断基準と記録基準を別に保持する思考上のクリーンルーム。
- 小規模組織が外部資源に依存しつつ、内部の記録、責任、照合、判断形式を汚染させない運用。
- 公的制度や情報流通が神話化しても、改ざんされにくい履歴を残し続ける記録系・公開ログ・分散保存。
- 現実の配管や資源に触れながら、内部の意思決定基準だけは外部の腐敗論理へ回収させない局所領域。

## 測定・監査点
外部との接続が残っているか、内部の判断基準が利益や権威によって書き換えられていないか、履歴の因果連鎖が再現可能か、責任の痕跡が消えていないか、構造記述が神話へ置換されていないか、内部監視や自己検閲が外部と同型化していないか、形式が惰性化していないかを観測する。

## 成立条件
D系は、耐久文明の外へ完全離脱できない現実の中で、それでも再起動可能性を保存する必要がある場合に成立する。十分に小さく局所的であってもよいが、外部と接続し、かつ内部の保存対象と判断基準を汚染から隔離できる必要がある。

## 失敗条件
完全切断によって現実更新の配管を失うこと、利益や影響力のため内部基準を外部論理へ譲ること、「自分たちだけが正しい」という神話へ閉じて新たな共圏になること、内部で監視・自己検閲を再生産すること、形式だけを惰性反復することはD系の失効である。

## 反証・改訂条件
外部接続を維持した局所非汚染領域が原理的に成立しないことが反復して示される場合、または構造記述・履歴・判断基準・責任痕跡・接続技術を保存しても相転移後の再起動可能性へ寄与しないことが一貫して確認される場合、D系の適用範囲や保存対象の再検討が必要になる。

## 必須の区別
- D系クリーンルーム ≠ 理想郷。
- D系クリーンルーム ≠ 完全切断・隠遁。
- 非汚染 ≠ 外部と無関係であること。
- 接続 ≠ 外部基準への従属・回収。
- 保存 ≠ 何でも残すこと。
- 責任痕跡 ≠ 断罪のための責任追及。
- D系 ≠ 希望の象徴・英雄譚。
- 局所的であること ≠ 無意味であること。

## 誤読禁止 / 解釈制約（原典適合）
D系を「純粋な人々が文明を救う」物語にしない。世界全体の一括浄化や即時勝利を目的化せず、耐久文明が長く続くことを前提に、相転移後へ渡す再起動条件を局所的に保存する構造として読む。また、非汚染を完全無接続と同一視しない。

## 親原典へ戻る理由
接続と隔離の同時成立、個人・小組織・記録系・公開ログという配置、内部腐敗の四類型、保存すべき構造記述・履歴・判断基準・接続技術、相転移後の再起動可能性との関係は、親原典の連続した文脈で確認する必要がある。派生面は原典の代替ではない。
