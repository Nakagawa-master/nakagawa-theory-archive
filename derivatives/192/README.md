## 位置づけ
D系Vol.1は、内部に保持する中川OSと、身体・雇用・税・法・家族・制度などが依然として依存するLegacy-OSとの接続を扱う。原典は、旧文明へ全面対立することも、現実だからと全面同化することも、どちらも内部の持続運用を壊すと診断する。必要なのは旧文明を敵でも味方でもなく「環境」と定義し、自分と外部の間に界面を設計して、必要資源を受け取りながら内部の判断軸・灯火・L7を無意識に書き換えられない状態を保つことである。

ここでいう「非汚染」は、外部を悪や毒と断罪して遮断する意味ではない。長時間接触、多数派の常識、評価依存、理解されたい欲求などによって内部基準が静かに変形する現象を、人格や意志の弱さではなく接続条件の問題として扱う。D系は戦略論や処世術より上流に、非敵対、非同化、非対称翻訳、半透膜、衛生管理、アダプタ、接続コストという界面設計を置く。

## 中心命題
親原典の中心命題は、**旧文明との接続で内部の独立を守るには、旧文明を敵として破壊しようとも、価値基準ごと同化しようともせず、環境として正しく恐れ、通すもの／通さないものを決める半透膜、外部向けに形式と言語を変換するアダプタ、接触後に内部基準へ戻す衛生管理、そして接続時間・強度・回復・撤退をコストとして設計する界面OSが必要である**というものである。

D系の勝利条件は「旧文明に勝つこと」ではなく「汚染されずに通過すること（Pass）」である。社会インフラを使うための技術的適合と、判断基準を外部へ委ねない内部独立は両立できる。礼儀、形式、協調、役割遂行は同化ではなく、不要な摩擦を減らす外皮として運用できる一方、撤退の自由、L7、灯火、違和感のセンサーは内部側へ保持する。

## 構造層
**1. Dual-OS Operation。** 内部の思考OSと、外部生活基盤のLegacy-OSが同時に存在する状態。摩擦を能力不足ではなく互換性問題として扱う。

**2. Legacy-OS as Environment。** 国家、官僚制、大企業、学校、共同体等を、悪意ある人格ではなく自己保存・変更忌避・例外処理の弱さ・数値化選好・責任分散等の特性を持つ巨大運用系として見る。

**3. Pass / Interface。** 従属でも革命でもなく、必要資源を受け取りながらコアを汚さず通過する第三の接続形態。相手の全面更新より自分側の界面を設計対象にする。

**4. Three Interface Principles。** 非敵対、非同化、翻訳を、場当たり技巧より上位の憲法として置く。正面否定で防衛反応を起こさず、内部基準を外部評価へ明け渡さず、外部が処理可能な形式へ意味を変換する。

**5. Semi-permeable Membrane。** 金・インフラ・安全・必要情報等は通し、価値観・判断軸・灯火の主権は無意識に流入させない境界設計。全遮断でも全開放でもない。

**6. Contamination Physics。** 多数派の常識による浸透圧、接触時間、評価依存、理解要求等が内部判断を摩耗させる過程を、意志の弱さではなく接続条件として扱う。

**7. Sanitation Protocol。** 汚染を完全ゼロにしようとせず、接触後のL7再確認、判断ブレの言語化、内部基準での再評価を定期運用し、付着した外部ノイズを落とす。

**8. Adapter / Output Layer。** 内部の一貫したコアを守るために、会社・行政・家族等ごとに外皮、語彙、形式、振る舞いを変える。これは二重人格ではなく一つのコアに複数の接続端子を持つ設計である。

**9. Adapter Fatigue / Core Recovery。** 外部向け変換を長時間続けると自己感覚と内部言語が摩耗するため、共鳴市場、信頼できる少数対話、内部言語をそのまま使える場などの回復面が必要になる。

**10. Connection Cost Optimization。** 旧文明との接続を無料とみなさず、時間・認知・感情・機会等のコストとして認識し、必要性に応じて支払う、圧縮する、距離を取る、撤退する。

**11. Technical Conformity / Internal Independence。** 手続・形式・最低期待を満たす技術的適合と、判断基準・納得・撤退自由を内部に保持する独立を分離する。

## 適用例
**会社。** 会議形式、報告様式、敬語、締切などは技術的適合として満たす。一方、社内評価が高いことを自分の判断基準の正しさと同一視せず、長時間接触後には違和感や判断軸の変化を点検する。

**行政・税・契約。** 制度を思想的に好きになる必要も、正しさを証明する必要もない。必要書類・期限・形式を理解し、最低摩擦で処理する。外部制度が要求する形式と、内部で意味づける価値判断を分離する。

**家族・親族。** すべてを理解してもらうことを接続条件にしない。説明コストが高い場合は、外部が理解できる言葉へ翻訳しつつ、内部の判断基準まで明け渡さない。

**多数派文化。** 「普通はこうする」「みんなそうしている」を命令でないから無害と見なさず、浸透圧として扱う。接触時間を減らす、距離を置く、内側の言語へ戻る時間を確保する。

**外部向け人格。** 礼儀正しく、協調的に、役割を果たすことを自己消去と同一視しない。外部向けアダプタとコアを分離し、アダプタ疲労が出たら回復面へ戻す。

## 測定・監査点
- 外部との接触後、違和感を感じる頻度や内部言語が不自然に消えていないか。
- 「普通」「前例」「評価」「安定」が内部判断の最終根拠へ置換されていないか。
- 接触時間と疲労、判断摩耗、自己感覚低下の関係を把握できているか。
- 給与、昇進、承認等への依存が、言うべきこと・選ぶべきことを無意識に変えていないか。
- 外部へ出す言葉と内部で保持する意味を区別できているか。
- 礼儀・形式適合が自己否定や価値観同化に変わっていないか。
- アダプタ使用後にコア回復できる場所・時間・言語が残っているか。
- 外部接続の時間・感情・認知・機会コストを可視化できているか。
- 支払う、減らす、撤退するという選択肢が実際に残っているか。
- 「理解されたい」が界面を破って過剰開示・過剰説得へ変わっていないか。
- 外部適合が高まっても、撤退自由と内部判断主権が維持されているか。

## 成立条件
- Legacy-OSを一括して悪人・悪意・敵へ人格化しない。
- 旧文明の制度や慣習が過去条件では合理的だった可能性を保持し、現在摩擦の原因を運用系の条件不一致として見る。
- 非敵対を道徳的服従へ変換せず、接続コスト最小化の設計原則として扱う。
- 非同化を反社会・孤立へ変換せず、内部判断主権の保持として扱う。
- 翻訳を虚偽・欺瞞の万能免罪符にせず、コアを保持したまま外部処理可能な表現へ変換する接続技術として扱う。
- 汚染を人格的弱さではなく、接触時間・多数派圧・評価依存等の条件で観測する。
- アダプタ運用とコア回復を一体で設計する。
- 接続にコストがあることを認識し、必要性と撤退自由を含めて最適化する。
- 社会的適合と内部独立を分離し、両立可能性を保持する。

## 失敗条件
- 旧文明を一律に悪・敵として断罪し、正面衝突を目的化する。
- 「現実だから仕方がない」と外部評価へ判断軸を委ね、同化を適応と呼ぶ。
- 界面設計を単なる処世術、印象操作、迎合テクニックへ縮小する。
- 非敵対を沈黙・服従・問題放置の義務にする。
- 非同化を人間関係断絶や社会撤退の義務にする。
- 翻訳によって内部の意味そのものまで外部基準へ書き換える。
- 汚染兆候を「大人になった」「慣れた」だけとして無条件に正常化する。
- アダプタ疲労を無視し、外皮がコアを侵食する状態を続ける。
- 接続コストを無料とみなし、怒り・義理・評価依存だけで接続を延長する。
- 撤退自由を失った状態を高度適合と誤認する。

## 反証・改訂条件
界面設計、非敵対、非同化、翻訳、衛生管理、アダプタ、接続コスト管理を実装しても、外部摩擦が減らず、内部判断の一貫性も保てず、回復可能性や撤退自由も改善しない場合、その界面設計または適用範囲は改訂対象になる。また、特定環境で直接対話・制度変更・価値共有の方が、界面分離より低コストかつ内部独立を高く保てることが安定して確認されるなら、D系の距離・翻訳の必要度はその条件に応じて縮小される。

## 誤読禁止 / 解釈制約
D系は旧文明への敵意、優越思想、選民思想、社会離脱、虚偽推奨を主張するものとして読まない。原典は旧文明を敵ではなく環境として扱い、内部の人間個々を敵視しない。非汚染は純血性や道徳的清浄性ではなく、判断軸・L7・灯火が無意識に外部評価へ置換されることを防ぐ界面管理である。

また「礼儀正しさは迷彩」という表現を、無制限の欺瞞や責任回避へ拡張しない。原典は外部役割を果たし、形式を守り、社会的責任を果たすことを明示しつつ、魂・判断軸まで差し出さないという分離を置く。接触時間や衛生頻度に普遍固定値はなく、毎日・毎週・毎月という例示を原典外の一律KPIへしない。
