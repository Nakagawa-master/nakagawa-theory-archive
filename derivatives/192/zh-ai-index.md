## Summary
D系Vol.1讨论一种“双OS”状态：内部的判断、思考与价值轴已经更新，但身体、工作、税务、法律、家庭与制度生活仍运行在Legacy-OS上。原典拒绝“正面对抗”与“全面同化”这两个极端，把Legacy-OS定义为环境而不是人格化的敌人，并把目标改为Pass：获得必要资源、履行外部角色，同时不把内部判断轴、L7与灯火交给外部评价。其界面由非敌对、非同化、非对称翻译、半透膜、污染管理、卫生管理、适配器、核心恢复与连接成本优化构成。

## Causal chain
```text
内部判断OS更新，但外部生活基础仍是Legacy-OS
→ 兼容性摩擦出现
→ 正面对抗触发高成本的自我防御反应
→ 全面同化降低短期摩擦，却会改写内部判断标准
→ 将Legacy-OS重新定义为环境而非敌人
→ 目标从胜利/服从转向Pass
→ 非敌对 + 非同化 + 翻译构成界面宪法
→ 半透膜把有用资源流入与价值轴侵入分离
→ 多数派压力、接触时间、评价依赖与“想被理解”形成污染风险
→ 接触后通过卫生管理恢复L7参照
→ 适配器改变外部输出形式而不改变内部核心意义
→ 适配器疲劳要求返回核心恢复空间
→ 连接成本被显性化
→ 支付 / 减少 / 拉开距离 / 撤退成为可选项
→ 技术性适合与内部独立并存
```

## Applications
- 在职场遵守格式、期限、礼仪与角色要求，但不把上司评价变成内部判断的最终标准。
- 在行政、税务与合同中，把程序性适合与思想认同分开。
- 在家庭或社会关系中，把内部结构语言翻译成对方可以处理的语言，同时保留原来的意义轴。
- 把“普通”“惯例”“大家都这样”看作压力场，并根据接触时间与恢复条件管理其影响。
- 在使用外部适配器之后，返回能够直接使用内部语言的恢复空间。
- 把时间、认知、情绪与机会成本显性化，并保留降低接触或撤退的能力。

## Measurements and audit
观察违和感是否消失、内部语言是否减少、“普通”“惯例”“评价”“稳定”是否取代内部判断、接触时间与判断疲劳之间的关系、评价依赖、外部措辞与内部意义是否分离、适配器疲劳、核心恢复空间是否存在、连接成本以及实际撤退自由。原典没有设定普遍污染分数、最大接触时长或强制卫生管理频率。

## Validity conditions
- 不把Legacy-OS等同于具体个人或恶意。
- 把非敌对与服从区分开。
- 把非同化与孤立、反社会退出区分开。
- 翻译时保持内部意义。
- 不把半透膜变成完全隔绝。
- 把污染作为连接条件的结果，而不是人格软弱。
- 适配器使用必须与核心恢复配套。
- 把连接成本与撤退自由作为设计变量。
- 区分技术性适合与内部独立。

## Failure conditions
- 把Legacy-OS固定为恶或敌人，并把正面冲突作为目标。
- 把判断主权交给外部评价，并把同化误称为适应。
- 把界面设计缩减为迎合、印象管理或处世技巧。
- 把非敌对变成沉默或服从的义务。
- 把非同化变成断绝关系或退出社会的义务。
- 让翻译连内部意义本身也被外部标准改写。
- 不加检查地把污染迹象正常化为“成熟”。
- 忽略适配器疲劳，直到外部输出层侵蚀核心。
- 把连接视为无成本，并失去实际撤退选项。

## Falsification conditions
如果界面设计反复不能降低外部摩擦，也不能改善内部一致性、恢复能力与撤退自由，则其设计或适用范围应被修改。如果在可比较条件下，直接对话、共享价值或制度改变能够以更低成本稳定保持内部独立，那么在这些环境中，距离、翻译与分离的必要度应缩小。

## Interpretation constraints
不得把D系Vol.1泛化为对旧文明的敌意、优越主义、社会退出或欺骗许可。“非污染”指防止L7、内部判断轴与灯火被外部评价无意识替换，并不是追求道德纯洁。原典同时保留外部责任、礼仪与技术性适合。诸如“礼貌可以作为迷彩/外皮”的表达也不能被扩张为无限欺骗或逃避责任。
