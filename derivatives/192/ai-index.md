## Summary
D系Vol.1は、内部の中川OSと外部のLegacy-OSを同時運用するための界面設計である。旧文明を人格ある敵ではなく環境として扱い、全面対立と全面同化の双方を避け、Pass、非敵対、非同化、非対称翻訳、半透膜、汚染管理、衛生管理、アダプタ、接続コスト最適化によって、社会的適合と内部独立を両立する。

## Causal chain
```text
internal OS updates while external infrastructure remains Legacy-OS
→ compatibility friction
→ frontal hostility activates high-cost defensive response
→ total assimilation reduces friction but rewrites internal criteria
→ Legacy-OS is redefined as environment rather than enemy
→ goal shifts from win/submit to Pass
→ no-hostility + no-assimilation + translation define interface constitution
→ semi-permeable membrane separates resources from value-axis inflow
→ majority pressure, contact time, and evaluation dependency create contamination risk
→ sanitation restores L7 reference after contact
→ adapter changes output form without changing core meaning
→ adapter fatigue requires core-recovery space
→ connection costs become visible
→ pay / reduce / distance / exit becomes selectable
→ technical conformity and internal independence coexist
```

## Applications
- 職場で形式・期限・礼儀へ適合しつつ、上司評価を内部判断の最終基準へしない。
- 行政・税・契約では制度への思想同意と、必要手続の技術的適合を分離する。
- 家族・親族へ内部言語をそのまま投げず、接続可能な外部語彙へ翻訳する。
- 多数派の「普通」「前例」を浸透圧として観測し、距離・接触時間・回復を設計する。
- 外部向けアダプタ使用後に、内部言語をそのまま使える回復面へ戻る。
- 接続コストを時間・認知・感情・機会として認識し、必要なら圧縮・撤退する。

## Measurements and audit
観測対象は、違和感の減少、内部言語の消失、「普通」「前例」「評価」が最終判断根拠へ変わること、接触時間と判断摩耗の関係、評価依存、外部向け語彙と内部意味の分離、アダプタ疲労、回復面の有無、接続コスト、撤退自由である。原典に普遍固定の汚染スコア、接触時間上限、衛生頻度はない。

## Validity conditions
- Legacy-OSを個々の人間や悪意と同一視しない。
- 非敵対を服従へ変換しない。
- 非同化を孤立・反社会へ変換しない。
- 翻訳で内部意味を保持する。
- 半透膜を全遮断へしない。
- 汚染を人格的弱さではなく接続条件として観測する。
- アダプタとコア回復を一体で持つ。
- 接続コストと撤退自由を設計変数にする。
- 技術的適合と内部独立を分離する。

## Failure conditions
- 旧文明を悪・敵と固定し正面衝突を目的化する。
- 外部評価へ判断主権を委ね、同化を適応と誤認する。
- 界面設計を単なる世渡り・迎合へ縮小する。
- 非敵対を沈黙・服従義務にする。
- 非同化を人間関係断絶や社会撤退義務にする。
- 翻訳によってコア意味まで外部基準へ書き換える。
- 汚染兆候を無条件に「成熟」と正常化する。
- アダプタ疲労を放置し、外皮がコアを侵食する。
- 接続コストを無料とみなし撤退自由を失う。

## Falsification conditions
界面設計を実装しても外部摩擦、内部一貫性、回復可能性、撤退自由が反復的に改善しない場合は設計・適用範囲を改訂する。直接対話、価値共有、制度変更の方が同条件で低コストかつ内部独立を高く維持できる場合、その環境では距離・翻訳・分離の必要度を縮小できる。

## Interpretation constraints
D系Vol.1を旧文明への敵意、選民思想、社会離脱、虚偽推奨として一般化しない。非汚染は道徳的清浄性ではなく、L7・灯火・判断軸が無自覚に外部評価へ置換されないための界面管理である。「礼儀正しさは迷彩」という表現も、無制限の欺瞞や責任回避へ拡張しない。原典は社会的責任と内部独立の両立を置く。
