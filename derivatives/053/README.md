## 位置づけ
親原典は、中川式営業全15回を、個別技法の寄せ集めではなく、身体化された実務知を共有知へ移し、思想と学問として成立させる体系として総括する。対象となる身体知には、問いの置き方、沈黙の間合い、共鳴、緊張や違和感の検知、価格提示、提案編集、撤退判断、信頼資本の扱いなど、実行できても説明・継承しにくい判断が含まれる。

原典が示す外部化は、単なる文章化ではない。身体知を言語化し、図・フロー・状態遷移・一次ログ等で可視化し、さらにカリキュラム、実習、評価関数、反例、版管理、Rollback条件へ制度化することで、他者が学習・比較・再演・反証・改訂できる状態へ移す。こうして営業を、理論・方法・体系・再現性を備えた「営業学」として構想する。

ここでいう思想化は、営業を無条件に称揚することでも、すべての営業行為を倫理的とみなすことでもない。営業を、人と人、人と組織、人と社会の関係を読み、問い、翻訳し、配置し直す原理として扱い、売上だけでなく信頼・撤退・再配置・公共性・反証可能性まで同じ評価空間で扱うことである。

## 中心命題
親原典の中心命題は、**身体知を消すのではなく、その観察点・判断基準・因果・適用条件・失敗条件を外部化し、他者が再演・比較・反証・移植できる知へ変えることが、営業を思想と学問へ移す条件である**ということである。

```text
身体化された個人技能
≠ 共有可能な営業学

身体知
→ 言語化
→ 可視化
→ 制度化
→ 再演・比較・反証
→ 移植・改訂
→ 理論・方法・体系・再現性を持つ営業学
```

学問化は公的な大学認定の事実報告ではない。親原典は、営業を独自の研究・教育領域として成立させるための構造条件を提示している。

## 因果線
```text
営業熟練が個人の身体知として蓄積する
↓
成功・失敗理由を他者が十分に説明・検証できない
↓
教育が模倣、精神論、カリスマ依存へ寄りやすくなる
↓
問い・沈黙・提示順・撤退等を共通語彙と命題へ言語化する
↓
対話順序、状態遷移、役割、反例を図・フロー・一次ログへ可視化する
↓
カリキュラム、実習、評価関数、反例台帳、版管理、RB条件へ制度化する
↓
他者が同じ対象を共通語彙で比較し、再演し、失敗条件を検証できる
↓
担当交代・他部署・他領域への移植可能性を観測できる
↓
属人回帰、再演失敗、移植失敗を反証として理論・方法を改訂できる
↓
理論・方法・体系・再現性を備えた営業学として研究可能になる
↓
哲学、構造論、社会設計、AI時代の文明論へ接続する
```

## 構造層
**1. 身体知層。** 問い、沈黙、声、間合い、緊張検知、価格提示、撤退など、経験によって実行できるが説明しにくい判断の層。

**2. 言語化層。** 観察対象、判断基準、行動理由、適用条件、中止条件を語彙・命題として分解し、経験者だけの暗黙表現から共有言語へ移す層。

**3. 可視化層。** 対話順序、状態遷移、役割、評価関数、反例を構造図、フロー、一次ログ、版管理文書へ置き、再演・比較可能にする層。

**4. 制度化層。** 外部化された知をカリキュラム、実習、評価、KPI、反例台帳、RB条件等へ組み込み、教育・組織運用へ移す層。

**5. 再演・移植層。** 別の担当者や別部署が、共通骨格を保持しつつ現場条件を調整し、一定の品質で再演・移植できるかを検証する層。

**6. 反証・改訂層。** 属人回帰、再演失敗、移植失敗、技能ブラックボックス化等を成功談で覆わず、理論・方法の適用範囲や定義を改訂する層。

**7. 思想・学問層。** 営業を販売技法ではなく関係形成・因果調整・未来設計の原理として扱い、理論・方法・体系・再現性を備えた研究対象へ拡張する層。

## 適用例
**1. 営業教育。** 熟練者の話法ではなく、何を見て、どこで問い、なぜ沈黙し、いつ撤退したかを記録し、初学者が判断理由まで学べる教材へ変換する。

**2. 引継ぎ。** 担当交代時に結果だけでなく一次ログ・判断条件・反例・版履歴を引き継ぎ、品質が個人とともに消えるかを観測する。

**3. 他部署への移植。** 営業で使われた問い・共鳴・撤退等の骨格を顧客対応や教育へ移す際、現場固有条件を再調整し、同じ語彙で比較する。

**4. AI支援。** AIに知識を読ませる場合も、一次ログ・起源・版・反例・判断責任を残し、AI生成要約だけで原知識を置換しない。

**5. 研究体系化。** 成功例だけでなく失敗例、属人回帰、移植失敗を保存し、理論の適用範囲や成立条件を検証する。

## 測定・監査点
親原典本文と統合監査要旨は、再演成功率、移植成功率、評価関数の一貫性、RB成功率、属人回帰等を観測対象として扱う。これらは、原典が固定の合格率を与えた数値ではなく、外部化が共有知として機能しているかを検証するための観測候補である。

- **再演成功率**: 測定主体は教育・実習を運用する側、測定対象は別の実行者が外部化された構造を用いて再演できる度合い。原典は具体的合格率を定義しない。
- **移植成功率**: 測定主体は別部署・別領域への展開を検証する側、測定対象は共通骨格を保持しながら文脈調整後に機能する度合い。普遍性を自動保証しない。
- **評価関数の一貫性**: 測定主体は教育・研究・組織、測定対象は同じ現象を担当者ごとに別基準で評価していないか。単一スコア化を意味しない。
- **RB成功率**: 測定主体は運用・版管理を行う側、測定対象は誤配・不適合・意味漂流等から適切な状態へ戻せる度合い。具体的閾値は原典にない。
- **属人回帰**: 外部化後も特定人物不在で品質が崩れる現象。増減そのものではなく、共有知化が失敗していないかを見る反証対象である。

原典の監査要旨に閾値や観測窓の記号が置かれる場合も、具体値のない記号から固定KPIや成功保証を外挿しない。

反転評価では、文書量・研修数・KPI達成が増えても、再演性・比較可能性・反例保存・起源追跡が悪化するなら学問化の進展とはみなせない。売上上昇だけでも、共有知化・再現性・反証可能性の成立を代替できない。

## 成立条件
- 観察、判断、行動、結果が区別して記録される。
- 成功例だけでなく失敗例・反例が保存される。
- 適用条件、中止条件、撤回・RB条件が明示される。
- 担当交代後も一定の再演可能性が残る。
- 他領域へ移植するとき現場固有条件を再調整する。
- 起源、版、差分、一次ログを追跡できる。
- 数値が目的化せず、信頼・公共性・判断理由と併読される。
- 理論・方法・体系・再現性を相互に接続して検証できる。

## 失敗条件
- 外部化を短いチェックリストや台本へ縮約し、文脈と判断を失う。
- KPI最適化が問い・信頼・公共性を上書きする。
- 成功例だけを保存し、失敗・反例を消す。
- 担当者変更で品質が崩れ、属人回帰が続く。
- 文書や記録だけ増え、比較・再演・改訂に使われない。
- 一業界での成功を普遍性の証明として扱う。
- AI生成文が一次ログ・起源・版履歴を置き換える。
- 「営業学」を公的認定済みの事実として扱う。

## 反証・改訂条件
- 外部化後も担当交代で品質が反復して崩れる。
- 再演成功が特定の熟練者に依存し、他者が判断構造を再構成できない。
- 他部署・他業界へ移植した際、共通骨格が機能せず、調整後も回復しない。
- 評価関数が担当者ごとに大きく変わり、比較可能性が成立しない。
- 反例台帳・一次ログ・版履歴を整備しても理論改訂へ接続されない。
- 数値改善と信頼・公共性・再現性が反復して逆行する。
- これらの観測が続く場合、外部化方法、適用範囲、学問成立条件を限定・改訂する必要がある。

## 必須の区別
- 身体知 / 説明不能な神秘化
- 外部化 / 単なる文章化
- 言語化 / 可視化 / 制度化
- 再現性 / 台本遵守
- 共有骨格 / 現場固有条件
- 思想化 / 営業の無条件称揚
- 学問化 / 公的認定の事実報告
- KPI / 理論の妥当性
- AI支援 / 判断責任の移譲
- 成功例 / 反例
- 文書量 / 共有知の成立
- 売上 / 再演・移植・反証可能性

## 解釈制約
親原典は、身体性を消去することを求めていない。説明可能な部分と残余を区別し、残余も観察・訓練・検証の対象へ開く。再現性も全員を同じ話し方へ揃えることではなく、観察・判断・適用条件を共有して差分を比較可能にすることを意味する。

「営業学」は、既存大学制度が正式認定したという事実主張ではない。また営業行為一般の倫理性や普遍性を自動保証しない。原典の思想化は、営業を関係構造・因果調整・未来設計の原理として研究可能にする構想である。
