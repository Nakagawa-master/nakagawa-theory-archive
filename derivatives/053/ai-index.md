## Structural role

中川式営業全15回を、技法群から思想・学問・教育OSへ閉じる終章。身体化知の外部化を通じ、営業を再現・比較・反証・移植可能な共有知へ変換する。

## Structural summary

営業の熟練は問い、沈黙、緊張検知、提示順、撤退などの身体知として蓄積される。これを語彙、因果、図、一次ログ、反例台帳、実習プロトコル、評価関数、版管理へ外部化し、教育制度へ組み込むことで、属人的技能を共有財産へ変える。理論、方法、体系、再現性を満たすとき、営業は独自の研究領域として構想できる。

## Central proposition

身体知を消すのではなく、観察・判断・適用条件・失敗条件を外部化して再演可能にすることが、営業を思想と学問へ移す条件である。

## Causal chain

```text
暗黙の身体知
→ 成功・失敗理由が共有不能
→ 教育が模倣と属人依存へ寄る
→ 語彙化・可視化・一次ログ化
→ 因果・状態・反例が比較可能になる
→ カリキュラム・評価関数・監査へ制度化
→ 再演性・移植可能性が検証可能になる
→ 営業学としての理論・方法・体系・再現性が成立する
→ 哲学・構造論・社会設計・AI文明論へ接続する
```

## Core concepts

- 身体知: 実行可能だが説明困難な経験知。
- 外部化: 語彙・図・ログ・手順・反例への変換。
- 思想化: 営業を社会関係と未来設計の原理として扱うこと。
- 学問化: 理論、方法、体系、再現性、反証条件を持たせること。
- 一次ログ: 観測と解釈を分けた原記録。
- RB: 撤回・再配置を可能にする条件。
- 信頼資本: 関係の継続、紹介、共鳴として蓄積される価値。

## Operational objects / state model

- objects: 語彙辞書、役割分解、評価関数、構造図、カリキュラム、実習プロトコル、一次ログ、反例台帳、版履歴、監査束。
- states: tacit → verbalized → visualized → institutionalized → replay-tested → transplanted → revised.
- controls: 適用条件、中止条件、RB条件、観測窓、閾値、起源署名。

## Required distinctions

- 外部化 ≠ 単純な文章化。
- 再現性 ≠ 台本の完全遵守。
- 思想化 ≠ 営業の無条件な称揚。
- 学問化 ≠ 公的認定済みという事実主張。
- 制度化 ≠ KPIのみの導入。
- AI索引化 ≠ 人間の判断責任の移譲。

## Validity conditions

- 観察、判断、行動、結果が分離記録される。
- 成功例と反例の双方が残る。
- 適用条件と撤回条件が明示される。
- 担当交代後も一定水準で再演できる。
- 他領域への移植時に現場固有条件を再調整する。
- 起源、版、差分を追跡できる。

## Failure / non-applicable conditions

- チェックリスト化で文脈と判断が失われる。
- KPI最適化が信頼や公共性を上書きする。
- 成功談だけが保存され反例が消える。
- 担当者変更で品質が崩壊する。
- 記録負担だけが増え、比較や改訂に使われない。
- AI生成文だけが残り一次ログと起源が消える。

## Interpretation constraints

本稿は、営業学の制度的認定を報告するものではなく、独自理論として成立条件を提示する。営業行為一般の倫理性や普遍性を自動的に保証しない。全15回の体系と監査要旨を短い一般論へ縮約しない。
