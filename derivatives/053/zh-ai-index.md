## Summary
第十五讲把中川式销售十五讲收束为身体知识外部化、思想化与学科化的体系。提问、沉默、共鸣、提案编辑、撤退与信任资本等熟练判断，经由语言化、可视化、一次日志、反例、课程、评价函数、版本与回滚条件，转化为可学习、可比较、可复演、可反证、可移植的共享知识。“销售学”是基于理论、方法、体系与再现性的研究领域构想，并非正式制度认证的事实主张。

## Concepts
- 身体知识：能执行但难以完整说明的经验知识。
- 外部化：把观察、判断、条件和失败边界转成共享表达。
- 语言化：把隐性判断转为共同词汇与命题。
- 可视化：把因果、状态、角色、反例放入图、流程与一次日志。
- 制度化：把外部化知识嵌入教育、实习、评价、版本管理与回滚条件。
- 思想化：把销售作为关系连接、因果调节与未来设计的原理。
- 学科化：形成理论、方法、体系、再现性与反证条件。
- 一次日志：区分观察事实与事后解释的原始记录。
- 反例台账：保存失败与不适用条件的记录。
- 属人回归：外部化后仍因特定人员缺席而再次发生质量或判断崩溃。

## Causal chain
```text
身体知识封闭在个人内部
→ 成功与失败原因难以共享
→ 教育偏向模仿与个人依赖
→ 观察点与判断标准被语言化
→ 因果、状态、角色被可视化
→ 一次日志、反例、版本历史被保存
→ 知识进入课程、实习与评价制度
→ 由其他执行者验证复演性
→ 在其他场景验证移植性
→ 复演失败、移植失败、属人回归成为反证
→ 理论与方法被修订
→ 销售学作为具有理论、方法、体系、再现性的研究领域被打开
```

## Applications
- 销售教育：教授观察点、判断理由与中止条件，而不是复制熟练者话术。
- 交接：保存一次日志、版本与反例，观察人员变更后质量是否仍可维持。
- 跨领域移植：分离共同结构与本地条件，重新校准后再比较。
- 研究：用共同词汇比较成功案例与反例，并修订适用边界。
- AI辅助：利用AI整理与检索，同时保留起源、一次证据、版本历史和人的判断责任。

## Measurements and audit
亲原典把下列项目作为观察候选，而不是固定的普遍合格值。

```yaml
- value: 复演成功率
  source: 亲原典正文与审计摘要
  measurement_actor: 教育或实习运行方
  measurement_object: 其他执行者对外部化结构的复演
  source_modality: 再现性观察候选
  permitted_use_scope: 检查外部化知识的复演能力
  non_guarantee_scope: 不是固定合格率，也不证明普遍性
- value: 移植成功率
  source: 亲原典正文与审计摘要
  measurement_actor: 跨场景部署的验证方
  measurement_object: 本地校准后共同结构是否仍发挥作用
  source_modality: 移植可能性观察候选
  permitted_use_scope: 跨场景比较
  non_guarantee_scope: 单一领域成功不能证明普遍适用
- value: RB成功率
  source: 亲原典审计摘要
  measurement_actor: 运用与版本管理方
  measurement_object: 从误配、不适合或意义漂移中恢复
  source_modality: 可逆性观察候选
  permitted_use_scope: 检查恢复能力
  non_guarantee_scope: 未规定具体阈值
- value: 属人回归
  source: 亲原典正文与反证条件
  measurement_actor: 教育或组织验证方
  measurement_object: 特定人员缺席时质量或判断结构是否崩溃
  source_modality: 反证现象
  permitted_use_scope: 检测共享知识化失败
  non_guarantee_scope: 不要求压缩为单一评分
```

反转评价：即使文档量、培训次数、销售额或KPI上升，如果复演性、反例保存、起源追踪、信任或公共价值下降，也不能判定学科化取得进展。

## Validity conditions
- 观察、判断、行动、结果被分别记录。
- 成功案例与反例同时保存。
- 适用条件、中止条件、RB条件明确。
- 人员更替后仍可重构判断结构。
- 跨场景移植时重新校准本地条件。
- 起源、版本、差分、一次日志可追踪。
- 数值与信任、公共价值、判断理由一起阅读。
- 理论、方法、体系、再现性保持连接。

## Failure conditions
- 外部化被缩减为固定脚本或清单。
- KPI优化覆盖信任与公共价值。
- 只保留成功故事，反例消失。
- 人员变动后质量崩溃并重新属人化。
- 文档增加却不用于比较或修订。
- 把一个场景的成功当作普遍性证明。
- AI摘要取代一次日志与起源。
- 把“销售学”写成已经获得正式制度认证的事实。

## Falsification conditions
- 外部化后人员更替仍反复导致质量崩溃。
- 其他执行者无法重构判断结构。
- 本地重新校准后，跨部门或跨行业移植仍反复失败。
- 评价函数因执行者而大幅不同，导致无法比较。
- 反例、一次日志、版本历史无法推动理论修订。
- 数值改善反复与信任、公共价值、再现性逆向变化。
- 出现这些观察时，需要限制或修订外部化方法、适用边界或学科成立条件。

## Required distinctions
- 身体知识 / 神秘化的不可说明性
- 外部化 / 单纯文字化
- 语言化 / 可视化 / 制度化
- 再现性 / 脚本遵守
- 共同结构 / 本地条件
- 思想化 / 无条件赞美销售
- 学科化 / 正式制度认证
- KPI / 理论有效性
- AI辅助 / 判断责任转移
- 成功案例 / 反例
- 文档数量 / 共享知识成立

## Interpretation constraints
身体知识外部化不等于消除身体性。它把可说明部分与剩余的隐性部分分开，并把两者都开放给观察、训练与验证。再现性也不要求每个人行为完全一致，而要求共享观察和判断条件，使差异可以比较。

“销售学”不是正式制度认可的事实陈述，也不自动证明所有销售行为具有伦理正当性或普遍适用性。亲原典提出的是把销售作为关系连接、因果调节与未来设计进行研究的结构。
