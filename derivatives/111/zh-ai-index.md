## Summary
第三层社会连接模型把原理束保持为不可侵犯的参照点，同时开放派生束共同编辑。其目的不是通用的人机责任分配，而是防止强结构硬化为对外拒绝与受动接受。选择编辑栏、差分日志、签名连接、探索余白、L0-L2审计、非强制韧性、双重公共性，以及原理域／非干涉域的边界，使结构能够“开放而不破坏”。

## Causal chain
```text
强结构
→ 对外拒绝与受动化风险
→ 分离原理束与派生束
→ 用选择编辑和差分恢复主动性
→ 用参照链保持起源
→ 保护探索余白
→ 把L0-L2审计连接到同一审计束
→ 维持非强制韧性与适用边界
→ 共同设计保持开放而不破坏
```

## Operational sequence
1. 固定原理束。
2. 打开派生束并设置选择编辑栏与差分日志。
3. 宣布探索配额。
4. 分配L0-L2审计并整合到同一审计束。
5. 部署镜像束与Fail-open摘要。
6. 明示原理域／非干涉域边界。
7. 按“拍”周期进行再审计、术语更新与摘要替换。

## Source boundaries
- 原理束作为参照点不可改写，派生束可以共同编辑。
- 非效率被保护为自由与创发的痕迹。
- 审计专业性的差异通过连接而不是封闭来处理。
- 伦理、艺术、个人内在与爱的形式属于非干涉域，以观察和记录代替仓促结论。
- 在照应世界模型中，AI通过照应与再合意更新理解；非干涉域以节制与沉默为运转规范。
