## 位置づけ
本派生物は、人間とAIが社会・制度・知識を共同で設計する時代に、AIを単なる道具にも人間と同一の責任主体にもせず、設計寄与、決定権、最終責任、異議、監査を分離して接続する構造倫理として整理する。共同設計者とは権限の同一化ではなく、異なる能力と責任を持つ主体・機構が同じ設計対象へ反復的に寄与する状態である。

## 中心命題
共同設計が安全に成立する条件は、AIの寄与を隠すことでも、AIへ人間責任を移すことでもない。誰が目的を定義し、誰が代案を生成し、誰が外部影響を検証し、誰が最終決定と救済責任を持つかを構造的に分離し、設計履歴・異議・停止条件・原典回帰を残す必要がある。

## 因果線
```text
AIを単なる自動化道具として扱う
↓
実際の設計寄与と影響が不可視化する
↓
反対にAIを人間と同一責任主体として扱う
↓
法的・倫理的責任が空洞化する
↓
設計対象と目的を共有する
↓
人間責任・AI寄与・外部検証を分離する
↓
代案・異議・停止条件を記録する
↓
限定実装と監査を行う
↓
結果を次の共同設計へ戻す
```

## 構造層
**1.** 目的層：人間が社会的目的と責任境界を明示する。

**2.** 寄与層：AIの生成・探索・比較寄与を追跡する。

**3.** 決定層：最終判断権と承認条件を分離する。

**4.** 監査層：外部影響、異議、失敗、偏りを観測する。

**5.** 更新層：結果を第三層へ戻し、共同設計を再帰更新する。

## 状態モデル
```yaml
- design_object_defined

- external_effects_checked

- design_revised
- co_design_cycle_continues
```

## 適用例
**1.** 公共政策でAIが選択肢探索を支援し、人間が説明責任と最終決定を持つ。

**2.** 組織設計でAIが構造案を生成し、当事者が異議と撤回を行えるようにする。

**3.** 研究開発でAI寄与と人間の仮説・検証責任を記録する。

**4.** 教育でAI提案を教師・学習者が再評価し、学習目的を上書きさせない。

## 測定・監査点
- AI寄与可視化率
- 人間責任明示率
- 代案比較率
- 異議記録率
- 外部影響追跡率
- 停止可能率
- rollback可能率
- 設計履歴再現率

## 成立条件
- 設計対象と社会目的が明示される。
- AI寄与と人間責任が分離される。
- 最終決定権が明確である。
- 異議、代案、撤回経路がある。
- 外部影響を監査できる。
- 失敗時に停止・rollbackできる。

## 失敗条件
- AI寄与を隠す。
- AIへ責任を自動移譲する。
- 人間の形式承認だけで責任を偽装する。
- 代案や異議を排除する。
- 設計履歴を残さない。
- 不可逆な社会実装を無監査で進める。

## 反証条件
- 寄与と責任を分離しても説明可能性や安全性が改善しない。
- 共同設計が単独人間設計より継続的に品質を悪化させる。
- 異議・rollbackを設けても重大副作用が減らない。
- AI寄与の可視化が実務上の責任判断に寄与しない。
- 単純な道具モデルの方が責任・再現性・安全で一貫して優れる。

## 必須の区別
- 共同設計 / 責任共有の曖昧化
- AI寄与 / AI責任
- 生成 / 決定
- 推奨 / 承認
- 協働 / 権限同一化
- 監査 / 形式承認
- rollback / 決定回避

## 誤読禁止
- AIを自動的に法的人格へ昇格させない。
- 人間を名目承認者へ縮約しない。
- AI寄与を隠して人間単独成果と偽装しない。
- 共同設計を責任空白の根拠にしない。
- 効率を安全や自由度より自動優先しない。
- 派生物を原典の代替にしない。
