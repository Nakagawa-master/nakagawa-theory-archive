## 位置づけ
本派生物は「共同設計者」を、人間とAIが同じ権限・責任を持つ主体へ自動的に昇格する概念として扱わない。原典が設計するのは、AIの生成・探索能力と、人間の目的設定・責任・被影響者への説明を分離しながら、社会制度の設計を往復的に共同化する関係モデルである。

## 中心命題
AI時代の共同設計は、作業分担ではなく「誰が目的を置き、誰が候補を生成し、誰が検証し、誰が承認し、誰が結果責任を持つか」を構造化することで成立する。AIの能力を拡張しても責任境界・異議・退出・rollbackを人間社会から消さないことが第三層の社会接続条件である。

## 因果線
```text
AIが設計候補・予測・翻訳を高速生成する
↓
人間が採否だけを行うと責任と理解が空洞化する
↓
目的・生成・検証・承認・影響の役割を分ける
↓
被影響者の異議・保留・退出を設計に組み込む
↓
AI案を観測窓と監査束で検証する
↓
再合意後に可逆実装し差分を記録する
↓
人間とAIが能力を接続しても社会責任が追跡可能な共同設計になる
```

## 構造層
1. 目的層: 人間・組織が価値目的と禁止境界を明示する。
2. 生成層: AIが複数案・反例・予測を生成する。
3. 検証層: 出典・因果・副作用・被影響者を監査する。
4. 承認層: 権限を持つ人間が採用責任を負う。
5. 社会接続層: 異議・退出・補償・rollbackを実装し、次周期へ戻す。


## 適用例
公共政策ではAIに政策候補を出させても決定権者と被影響者の手続きを残す。企業ではAI設計案の承認者・検証者を分ける。教育ではAIが課題を作っても教師が目的・評価・異議窓を保持する。

## 測定・監査点
AI提案採用率ではなく、役割明示率、反証保持率、被影響者参加、rollback、責任追跡、説明可能性、修正時間、同種副作用再発率を測る。

## 成立条件
目的、役割、権限、被影響者、異議、反証、承認、可逆実装、差分履歴が明示されること。

## 失敗条件
「AIが最適」として人間責任を放棄する、形式承認だけ置く、被影響者を排除する、rollback不能にする、AI案の出典・前提を消す場合。

## 反証条件
共同設計モデルが責任曖昧化・意思決定遅延・被害を増やし、明確な人間主体の従来設計より継続的に劣る場合は役割配置を再設計する。

## 必須の区別
共同設計≠共同免責。AI参加≠決定権。人間承認≠形式署名。最適化≠正当性。共鳴≠同意。

## 誤読禁止
AIを共同設計者と呼ぶだけで法的主体にしない。逆にAIの影響を「ただの道具」として隠し、人間側の設計責任を曖昧にしない。

## 親原典へ戻る理由
共同設計者時代の構造倫理は、第三層、共有主語、倫理的接地、再合意、社会接続と一体で定義される。役割・責任の正確な境界は親原典で確認する。
