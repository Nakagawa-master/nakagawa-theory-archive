## 中心命題
第三層の社会接続モデルは、原理束を参照点として保ちながら派生束を共同編集可能にし、「壊れずに開く」可逆な開口部を社会へ実装する。共同設計者プロトコル、探索の余白、L0–L2監査、非強制レジリエンスが受動化と閉鎖を防ぐ。

## 原典の因果線
```text
強い構造が外部を拒む硬直を生みうる
↓
原理束と共同編集可能な派生束を分離する
↓
選択編集欄と差分ログで自己決定の痕跡を残す
↓
署名連携で原理束への参照鎖を保持する
↓
探索クォータで不可侵の余白を確保する
↓
L0–L2監査を同一監査束へ束ね、開放を運転する
```

## 原典固有構造
- 原理束：母艦署名・用語定義・統合監査要旨・再合意の窓。参照点として改変不可。
- 派生束：記事拡張・適用事例・翻訳。共同編集可能。
- 選択編集欄：どこを、なぜ、どう書き換えたかを差分として残す。
- 署名連携：派生から原理束への参照鎖を保つ。
- 探索クォータ／探索配当：非効率を自由と将来価値のための余白として保護する。
- L0一般監査／L1実務監査／L2専門監査：専門性の差を閉鎖ではなく連結で扱う。
- 監査束：統合・局所監査、起源署名、改版履歴、派生参照鎖を束ねる。

AI寄与／人間責任／意思決定権限を中心とする一般AI責任論、rollback/remedy中心のガバナンス、責任配分KPIを除去した。
