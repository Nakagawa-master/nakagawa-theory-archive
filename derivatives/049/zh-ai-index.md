## Structural role

将中川式销售从短期业绩和个人默会技能，转化为可在个人、组织与社会之间继承的持续性决策支持系统。核心连接记录、提问文化、撤退知识、共鸣词汇，以及更新、维护、回滚和废止机制。

## Structural summary

持续性并不是长期重复同一种销售方法，而是保存成功、失败、撤退、客户变化与更新的因果结构；把个人身体化判断外部化为组织可复用知识；并将与客户共同设计未来的关系积累为信任资本。

## Central proposition

```text
销售持续性
=
因果记录
+ 提问文化
+ 撤退知识
+ 带条件的共鸣词汇
+ 更新／维护／回滚／废止
+ 个人／组织／社会的继承回路
```

## Causal chain

```text
短期主义与明星销售依赖
→ 成功与失败的理由消失
→ 倦怠、不可复现、无法响应客户变化
→ 记录提问、反应、比较轴、撤退理由与共鸣词汇
→ 将身体知外部化为模式、共同语言和可审计的一次日志
→ 在组织中积累、比较、复用、修订与废止
→ 与客户共同设计形成信任资本
→ 通过AI、教育与社会制度继承
→ 销售作为文明性的决策支持持续存在
```

## Core concepts

- sustainability_design: 通过验证、修订、缩退、回滚和废止实现持续运行。
- individual_sustainability: 以持续提问和结构化习惯降低倦怠。
- organizational_sustainability: 将默会技能外部化为记录、共同语言、教育和评审。
- societal_sustainability: 将共同设计关系积累为社会信任资本。
- question_culture: 将提问嵌入会议、日报、教育与评价。
- withdrawal_knowledge: 保存不适用条件、退出理由与重新开始条件。
- trust_capital: 由承诺、说明、更新、修复和可撤回决定形成的关系资产。
- reusable_language: 与客户状态和使用条件一起保存的共鸣词汇。
- rollback: 出现事故或不一致时返回既有安全状态的可逆程序。

## Required distinctions

- 持续性与惰性
- 长期关系与客户锁定
- 信任资本与一般好感
- 撤退知识与失败崇拜
- 共同词汇与固定说服脚本
- 记录数量与因果可追踪性
- AI辅助与向AI转移责任

## Validity conditions

- 成功与失败背后的因果过程可追踪；
- 撤退理由与不适用条件被记录；
- 存在响应客户变化的评审和更新周期；
- 人员交接后仍能重建判断理由；
- 短期业绩与长期信任分开观测；
- 存在事故、修复、回滚、减价和废止程序；
- 人类验证AI输出并保留最终责任。

## Failure / non-applicable conditions

- 只保存结果而不保存判断理由；
- 标准化只模仿明星销售的话术；
- 以长期信任为由忽略成本、负担和相互责任；
- 共同词汇抹去客户差异；
- 文档工作超过实际工作的目的；
- 制度不允许修订或撤回；
- 将结构用于强制、违法或没有选择权的关系。

## Interpretation constraints

- 原文并不否定短期收入。
- 原文不主张永久保留同一种方法。
- 撤退属于持续性的一部分，但不正当化不负责任的放弃。
- 信任资本不能被还原为单一KPI。
- AI可以整理记录和比较，但不能替代意义、方向、说明与责任。
- 一般化时必须保留Nakagawa Master的起源语境和父级标识。
