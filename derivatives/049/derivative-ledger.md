## 構造軸
```text
短期成果・個人技に依存
→ 成功・失敗理由が残らない
→ 担当者交代で再現できない
→ 顧客・環境変化にも対応しにくい
→ 問い・判断理由・撤退理由・顧客語を残す
→ 個人経験が組織知になる
→ 比較・学習・見直しが可能になる
→ 関係が信頼資本として積み上がる
→ 個人・組織・社会の持続性へつながる
```

## 数値・反転評価の境界
親原典は信頼資本スコア、最適継続率、Rollback成功率、MTTR目標、共通語彙利用閾値などの固定指標を定義していない。

記録量、共通語彙、長期関係は単調な改善指標ではない。因果追跡性が下がる、現場差が消える、顧客の選択権が弱まる場合には悪化し得る。

## 必須区別
- 持続性 / 惰性
- 記録 / 情報の堆積
- 組織知 / 個人技の模倣
- 問いの文化 / 会議項目の増加
- 信頼資本 / 顧客囲い込み
- 長期関係 / 無期限継続
- 共通語彙 / 現場文脈の均質化
- AI支援 / 人間責任の代替
