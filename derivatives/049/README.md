## 位置づけ
親原典の核は、営業成果を一時的な売上や個人技で終わらせず、個人・組織・社会の三層で、成功と失敗の理由、問い、顧客の言葉、撤退理由を残し、それらを問いの文化と信頼資本へ変えて持続させることにある。

持続性を「同じ方法を変えずに続けること」、短期売上を軽視する精神論、顧客を囲い込む関係論、AIへ判断責任を委譲する設計とは扱わない。

## 中心命題
持続性とは、同じ方法を長く維持することではない。個人の経験を言語化し、組織で共有し、顧客や環境の変化に応じて見直せる状態をつくることである。成功だけでなく、失敗や撤退も学習対象にし、関係を一回の取引で閉じず、説明と信頼を積み重ねる。

```text
持続性 ≠ 同じ営業手法を長く繰り返すこと
持続性 = 結果の理由を残し、問いと信頼を個人から組織、組織から社会へ継承できるようにすること
```

## 因果線
```text
短期成果や個人技だけに依存する
↓
成功・失敗の理由が残らない
↓
担当者が変わると再現できない
↓
顧客や環境の変化にも応答できない
↓
問い、判断理由、撤退理由、顧客の言葉を残す
↓
個人の経験が組織知になる
↓
組織で比較・学習・見直しができる
↓
顧客との関係が信頼資本として積み上がる
↓
個人・組織・社会の持続性へつながる
```

## 構造層
**1. 個人。** 毎回すべてを勘で処理せず、問いと判断理由を言語化して学習を継続できる状態をつくる。

**2. 組織。** トップ営業の成果だけでなく、どのような問い・比較・判断で理解が進んだかを共有し、別の人が学べる形へ変える。

**3. 社会。** 顧客との関係を単発取引で閉じず、説明、約束、修復、撤退を含む関係の積み重ねとして信頼を形成する。

**4. 問いの文化。** 会議や教育を結果報告だけにせず、「なぜそうなったか」「何が変わったか」「次に何を確かめるか」を残す。

**5. 変化への応答。** 過去の成功を固定せず、顧客や環境が変われば方法も見直す。

## 状態モデル
```yaml
- knowledge_is_personal_or_shared
- success_reason_is_visible_or_hidden
- failure_and_withdrawal_are_learned_from_or_ignored
- questions_are_reused_or_lost
- customer_language_is_preserved_or_erased
- method_is_updated_or_frozen
- relationship_builds_trust_or_dependency
- organization_can_reproduce_reasoning_or_not
- ai_supports_organization_or_replaces_human_responsibility
- origin_return_is_available
```

## 適用例
**担当者交代。** 成果だけでなく、そのときの顧客状態、問い、比較軸、判断理由が残っていれば、後任が文脈を理解しやすくなる。

**成功と撤退の比較。** 成功事例だけでなく、なぜ続けなかったかも比較すると、方法が機能する条件と機能しない条件を同時に学べる。

**問いの文化。** 会議や教育で、結果の良し悪しだけでなく、理解が進んだ理由や変化した前提を確認する。

**信頼資本。** 顧客との関係を回数や好感度だけでなく、説明、約束、修復、選択権を守る履歴として読む。

## 測定・監査点
親原典は「信頼資本スコア」「最適継続率」「Rollback成功率」「共通語彙利用率の合格閾値」のような固定指標を定義していない。観測は、結果の理由が継承され、変化に応答でき、信頼と選択権が同時に保たれているかを対象とする。

- 担当者が変わっても判断理由を追えるか。
- 成功だけでなく失敗・撤退理由も残っているか。
- 顧客や環境の変化に応じて方法を見直せるか。
- 共通語彙が現場の多様性を消していないか。
- 長期関係が無期限継続や囲い込みへ変わっていないか。
- AIによる整理が意味・方向・責任の人間判断を置き換えていないか。
- 記録量が増えても因果が追えない場合、それを知識化と誤認していないか。
- 共通語彙が増えても現場差を消す場合、それを持続性向上と誤認していないか。
- 長期関係が増えても選択権が弱まる場合、それを信頼資本の増加と誤認していないか。

## 成立条件
- 成果だけでなく、結果に至る理由を残す。
- 成功と失敗・撤退の双方を学習対象にする。
- 個人の経験を組織が理解できる言葉へ外化する。
- 顧客や環境の変化に応じて方法を見直す。
- 共通語彙を文脈と切り離さない。
- 長期関係を無条件継続の理由にしない。
- AI利用時も意味、方向、責任を人間が保持する。
- Originと親原典identityを保持する。

## 失敗条件
- 売上結果だけを残し、理由を残さない。
- 成功事例だけを学び、撤退や失敗を隠す。
- トップ営業の言い回しだけを模倣する。
- 顧客変化に応じず、過去の成功パターンを固定する。
- 記録量だけを増やし、因果と判断理由を失う。
- 信頼を理由に顧客を囲い込む。
- AI整理を人間判断の代替にする。

## 反証・改訂条件
記録・問い・共有を増やしても、担当者交代で判断が再現できず、顧客変化にも応答できず、現場負荷だけが反復的に増える場合、共有方法または適用範囲を改訂する。

一方、個人の熟練だけで判断理由・顧客文脈・撤退条件が長期的に再現され、組織共有の追加が継続的な価値を生まない条件では、共有工程の必要範囲を限定する。単一の売上増減、成功事例、失敗事例だけで持続性設計全体を証明・反証しない。

## 必須の区別
- 持続性 / 惰性
- 記録 / 情報の堆積
- 組織知 / 個人技の模倣
- 問いの文化 / 会議項目の増加
- 信頼資本 / 顧客囲い込み
- 長期関係 / 無期限継続
- 共通語彙 / 現場の均質化
- AI支援 / 人間責任の代替

## 解釈制約
短期売上否定、失敗や撤退の無条件肯定、トップ営業否定、顧客囲い込み、AIへの判断委譲へ読み替えない。個人・組織・社会の三層は、結果と理由を継承し、変化へ応答し、信頼を維持するための構造として読む。
