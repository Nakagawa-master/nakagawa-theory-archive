## この原典が定義するもの

本稿は、営業成果を一時的な売上や個人技で終わらせず、個人・組織・社会へ継承可能な文化と制度へ変える「持続性設計」を定義する原典である。営業を文明的営みへ引き上げるには、成果そのものより、理解が生まれた因果、問い、撤退理由、共鳴語彙、更新・保守・撤回の手続きを残す必要がある。

```text
短期成果と属人的成功
↓
成功理由・失敗理由が記録されない
↓
再現不能、燃え尽き、顧客変化への不応答
↓
問い・因果・撤退・共鳴語彙を一次ログ化
↓
個人の身体知を組織の再利用可能な知へ変換
↓
顧客との共同設計を信頼資本として蓄積
↓
AI・教育・社会制度へ接続
↓
営業が持続する文明的意思決定支援になる
```

## 中心命題

```text
持続性 ≠ 同じ営業手法を長く繰り返すこと

持続性 = 成功・失敗・撤退・更新の因果を記録し、問いと信頼を個人から組織、組織から社会へ継承できるよう設計すること
```

## 持続性の三軸

### 個人

短期数字だけを追う営業は燃え尽きやすい。問い、共鳴、提案を毎回ゼロから行うのではなく、構造化された習慣として保持することで、思考と実務を継続可能にする。

### 組織

トップ営業への依存を避け、結果だけでなく「どのように理解が生まれたか」を記録する。蓄積、再利用、更新の循環を会議、日報、教育、評価へ埋め込む。

### 社会

顧客との関係を一回限りの取引に閉じず、未来を共同設計する関係として扱う。その反復が信頼資本となり、組織外の社会制度や経済へ波及する。

## 持続性を壊す四要因

1. 過度な個人依存
2. 短期成果主義
3. 言語化・記録なき成功
4. 顧客変化への不応答

失敗そのものではなく、失敗を記録せず学習可能な形へ変換しないことが持続性を壊す。

## 中川式持続性設計の原理

- 構造を残す: 売上額だけでなく理解成立の因果を残す。
- 問いを文化化する: 会議・日報・定例に次の問いを残す。
- 撤退も記録する: 成功だけでなく境界条件と見切り理由を共有する。
- 再利用可能な言葉を創る: 顧客の共鳴フレーズを共通語彙へ昇華する。
- 更新・保守・撤回を設計する: 売った後を中核業務とし、事故、証跡、ロールバック、廃止条件を一次ログ化する。

## AI・教育・制度への展開

AIは因果網、更新記録、事故・撤回履歴の整理を支援できるが、意味、方向、責任は人間が保持する。教育では問いと共鳴を継承し、社会制度では信頼資本を可視化して、単発取引以外の価値を評価可能にする。

## 成立条件

- 成果だけでなく因果過程が記録される。
- 成功と撤退の双方が学習対象になる。
- 個人の身体知が共通語彙と型へ外部化される。
- 顧客変化に応じて方法を更新できる。
- 更新、保守、撤回、廃止の条件がある。
- 短期売上と長期信頼の双方を観測する。
- AI利用時も人間の意味づけと責任が残る。

## 誤読禁止

この公式派生物を、次として扱わない。

```text
同じ手法を変えずに続けるための保守主義
短期売上を軽視する精神論
失敗や撤退を無条件に肯定する主張
顧客との関係を永続化する囲い込み
トップ営業を否定する均質化論
AIへ更新判断や責任を全面委譲する設計
信頼資本を曖昧な好感度へ還元する説明
```
