## Summary
父原典不首先以真假或阵营善恶来定义宣传与煽动，而是把它视为集体认知带宽K被单一波形占有的共振现象。当Occ(K)超过阈值、议题多样性V下降、极性集中度P上升、反证接受率A下降时，对U/R/H的访问也会减弱，形成Res共振状态。防卫通过Damping、Cooling、Degeneration、重新连接H、重新分配R与重新测量True-U来恢复带宽。

## Concepts
- 合意形成的物理
- 认知带宽 K
- Occ(K) 带宽占有率
- Res 共振状态
- V 议题多样性
- P 极性集中度
- A 反证接受率
- Damping / Cooling / Degeneration
- H重新连接 / R重新分配
- True-U

## Causal chain
强烈话题/情绪/故事 → 反复传播 → 注意资源集中于单一波形 → V下降 / P上升 / A下降 → 历史H与责任R参照下降 → Occ(K)越过阈值 → Res成立 → 可验证性下降。

## State / operational model
1. 观察K与Occ(K)。
2. 把V/P/A的联合变化作为Res_Alert。
3. Damping降低反复输入与过度占有。
4. Cooling降低反应速度，恢复验证时间。
5. Degeneration把巨大争点拆成可验证的小单元。
6. 重新连接H到一次来源与历史。
7. 重新分配R并重新测量True-U。

## Applications
适用于政治、社交媒体、职场、社区、家庭、运动团体等单一话题、敌人、情绪或故事可能占有验证带宽的场景。不得简化为特定阵营批判或一般事实核查。

## Measurements and audit
不引入父原典未定义的通用KPI。观察K、Occ(K)、V、P、A、U/R/H参照、一次来源可达性、责任可追踪性、历史参照、反证入口，以及Damping/Cooling/Degeneration后的带宽恢复。

## Validity conditions
必须能够观察多个议题、反例、历史与责任入口；V/P/A必须作为组合而不是孤立分数来读取；恢复操作必须恢复验证带宽，而不是压制意见。还必须区分“相同结论上的收敛”与“共振”。

## Failure conditions
若Damping或Cooling被用于审查，必要警告或受害申告被压制，仅凭V/P/A判定恶意或思想正误，或H/R没有恢复，则属于失败。

## Falsification conditions
若Occ(K)看似很高，但V/P/A与U/R/H长期稳定，多个反例、历史、责任和可修正性持续存在，则阈值或观察组合需要修订。若恢复操作反而提高极性P或合意成本，也需要修订。

## Required distinctions
- 合意/收敛 与 Res
- 内容真假 与 带宽占有
- 强烈主张 与 占有状态
- Damping 与 审查
- Cooling 与 强制沉默
- Degeneration 与 议题抹除
- 主观认同 与 True-U

## Interpretation constraints
不得把本原典简化为反宣传运动、特定阵营批判、一般事实核查或社交媒体礼仪。任何立场只要出现K占有与U/R/H参照下降，都可能发生共振。
