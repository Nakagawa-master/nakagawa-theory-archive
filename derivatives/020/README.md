# 公式派生物020｜合意形成の物理 第10論 共振とプロパガンダの流体力学

Parent: Post 3027 / NCL-α-20260225-1f258d / DIFF-20260226-0020 / Origin Nakagawa Master
Derivative: DDIFF-20260812-DNCL-020-0000-0003; supersedes DDIFF-20260707-DNCL-020-0000-0002

## 15秒説明
第10論は、プロパガンダや扇動を内容の真偽や陣営の善悪ではなく、集団の認知帯域Kが単一波形へ占有される共振現象として扱う。Occ(K)が閾値を超え、Vが低下し、Pが上昇し、Aが低下すると、U/R/Hへの参照が失われResが成立する。

## なぜ関連するか
政治だけでなく、SNS、職場、家族、コミュニティでも、一つの話題・感情・敵・物語が場を占有すると、反例・履歴・責任・一次ソースへ戻る余白が消える。重要なのは同意の数ではなく、検証可能な帯域が残っているかである。

## 発見された構造
- K: 集団が同時に保持できる論点・仮説・反例・履歴・責任・検証経路の帯域。
- Occ(K): 単一波形による帯域占有率。
- Res: Occ(K)高騰とU/R/H参照低下を伴う共振状態。
- V: 論点多様性、P: 極性集中度、A: 反証受付率。
- 防衛は対抗言説ではなくDamping、Cooling、Degeneration、H再接続、R再割当、True-U再計測で帯域を回復する。

## 因果線
強い話題・感情 → 反復 → 注意資源の単一波形集中 → V低下 / P上昇 / A低下 → H参照とR追跡低下 → Occ(K)閾値超過 → Res成立 → 検証可能性喪失。

## 判断方法
複数論点と反例が保持されているか、一次ソース・履歴・責任へ戻れるか、V/P/Aが同時に悪化していないかを見る。同じ結論に収束していても、修正可能性が残るなら共振とは限らない。

## 誤読してはいけない点
これは特定陣営への政治批判、反プロパガンダ運動、ファクトチェック一般論、SNSマナー論ではない。DampingやCoolingを都合の悪い意見の検閲や被害申告の抑圧に転用してはならない。

## 原典で読むべき理由
原典はK、Occ(K)、Res、V/P/Aを用いて共振を観測し、検知→減衰→冷却→縮退→H再接続→R再割当→True-U再計測までを運用系として接続する。要約だけでは「強い言葉に注意」に薄まるため、最終判断は親原典へ戻す。
