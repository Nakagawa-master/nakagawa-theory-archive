## Summary

力の構造論は、権力を法・資金・地位・命令・露出など現象面の出力、構造を情報流路・役割・責任・インセンティブ・時間・境界という因果回路として区別する。出力を上げても回路矛盾が残れば摩擦は遅延・形骸化・離反・再説明費用として返る。上位制約は情報非対称性、役割アーキテクチャ、時間構造であり、調律では評価軸・境界・順序・沈黙・配置を一因子ずつ編集する。圧力を下げても自走・責任・合意が維持され、長期費用込みで摩擦が再現的に低下するかを検証する。

## Causal chain
```text
power output → short-term gain → residual structural contradiction → friction/retaliation → identify upper constraints → one-factor tuning → autonomous operation → long-term audit
```

## Applications
組織統治、制度設計、AIガバナンス、市場の短期施策、合意形成。

## Measurements
指示・承認・例外処理・遅延・離反、情報到達時間、役割衝突、長期維持費用、自走度、再参照率。

## Validity / failure / falsification
構造条件を観測し一因子変更できることが成立条件。摩擦データを圧力で消す、短期成果だけを見る、責任を曖昧にする運用は失敗。構造調律が複数条件で長期費用を改善しない場合は反証側の証拠となる。

## Interpretation constraints
権力全面否定、構造決定論、隠れた支配、緊急安全措置の否定へ縮約しない。
