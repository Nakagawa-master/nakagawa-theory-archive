## Summary

本理论把权力定义为法律、资金、地位、命令、强制与曝光等可见输出，把结构定义为信息、角色、责任、激励、边界与时间组成的因果回路。输出可以制造短期成果，但若回路矛盾未被解决，阻力会以延迟、形式服从、离反、返工和维护成本上升的方式返回。上位制约包括信息不对称、角色架构和时间结构。可持续的操作不是继续增加压力，而是逐一调整评价轴、边界、顺序、沉默与配置，并观察降低压力后自走、责任和合意是否仍然成立。

## Concepts
权力输出；因果结构；信息不对称；角色架构；时间结构；摩擦成本；构文调律；自走。

## Causal chain
```text
权力输出 → 短期成果 → 残余矛盾 → 摩擦累积 → 结构诊断 → 单因素调律 → 降压后的自走 → 长期审计
```

## State model
```yaml
- 输出介入
- 摩擦检测
- 上位制约映射
- 单因素调整
- 降低压力
- 自走检查
- 长期成本审计
```

## Applications
组织治理、制度设计、AI治理、市场激励与合意形成。

## Measurements
命令/审批/例外处理数量、延迟、信息到达时间、角色冲突、离反、长期维护成本、自走度与再参照率。

## Validity / failure / falsification
需要能观察结构制约并进行可逆比较。若用“结构”掩盖强制、压制摩擦数据或只看短期成果，则失败。若结构调律不能在多周期降低总成本，应修正假设。

## Interpretation constraints
不得理解为全面否定权威、否定紧急强制或结构决定论。
