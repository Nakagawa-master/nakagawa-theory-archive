## 位置づけ
親原典は共鳴市場OS（C系）の完結編である。Vol.1が「交換から共鳴へ」という原理、Vol.2が「狩猟から誘引へ」という実装を扱ったのに対し、Vol.3は成功した市場をどう死なせず、腐敗・固定化・擬態・サンクコスト・過剰拡大をどう循環へ戻すかという維持・継承を扱う。

原典は、成功を終点ではなく腐敗開始の臨界点として捉える。人・金・影響力が集まるほど接続報酬が増え、理念への表面的賛同と実際の出力が乖離する「擬態状態」が発生しやすくなる。そのため、善悪や人格で裁くのではなく、L7と現在の出力の整合を観測する構造的免疫、役割を終えた接続を循環から外す新陳代謝、最大化ではなく適正規模を選ぶ収縮、固定形ではなく動的平衡を保つ継承が必要になる。

## 中心命題
親原典の中心命題は、**成功した共鳴市場を永続させるには、拡大・獲得・最大化を続けるのではなく、L7と出力の整合を継続観測する構造的免疫、不整合を攻撃せず循環から外す代謝、Originの灯火が温度と解像度を保って届く適正規模、拡張と収縮を往復する拍動、そしてL7と実装構造を人から切り離して継承する動的平衡を一体設計しなければならない**というものである。

ここで「擬態」は人格ラベルではなく可逆的な状態であり、「免疫」は攻撃ではなく識別、「切断」は追放ではなく流路制御、「縮小」は敗北ではなく純度と未来を守る拍動として定義される。原典は排外主義と無秩序の双方を拒み、過去の功績・年数・善意ではなく「今この瞬間、L7と出力が整合しているか」を基準に置く。

## 構造層
**1. Success / Entropy。** 成功は人・金・影響力・接続報酬を増やし、秩序を固定化する。その固定化が変化拒否・摩擦・澱を生み、内部エントロピーを高めるという診断。

**2. Mimicry。** 掲げるL7と実際の行動・貢献・負荷耐性が乖離したまま接続報酬を受け続ける状態。固定的人格属性ではなく、誰もが時間差で入りうる可逆状態として扱う。

**3. Structural Quarantine / Immune System。** 意図や人格で裁かず、L7と現在出力の整合を観測する。自己／非自己の識別、異物検知、必要時の無害化・排出を静かに行う構造。

**4. Structural Checkpoint。** 忠誠テストではなく、変化と負荷を引き受けられるかを行動で確認する定期的チェック。入会時一回ではなく時間と状態変化に応じ更新される。

**5. Metabolism / Graduation。** 過去の貢献や恩義を尊重しつつ、現在の不整合を免罪しない。切断を追放・制裁でなく循環の流路制御とし、理想形を「卒業＝L7の分岐」として扱う。

**6. Optimal Scale / Systole。** 最大規模ではなく、Originの灯火が温度と解像度を保って届く限界を適正規模とする。募集停止、価格引上げ、人数削減、提供範囲縮小を次の拡張のための収縮として位置づける。

**7. Dynamic Equilibrium。** 同じ形を固定して守るのでなく、守るべきL7を維持するために人・役割・制度・実装を入れ替え続ける。永続を「変わらないこと」ではなく「変わり続けながら全体を保つこと」とする。

**8. Structural Succession。** 継承対象を後継者の人格ではなくL7と実装構造へ移す。Origin固有の問い・違和感・美意識を抽出・構造化・参照可能にし、創始者不在でも判断がブレない状態を目指す。

**9. Pulsation Point。** 支配者・救世主でなく、流れを止めず、詰まりを見逃さず、必要時に収縮・手放しを行う拍動点としての役割。拡大だけにも縮小だけにも固定しない。

## 適用例
**成功後のコミュニティ。** 人数・売上・参加率が伸びても、L7が言葉だけになり、実際の負荷を担う少数へコストが集中しているなら「成長」とせず擬態・免疫不全を確認する。

**古参・功労者の扱い。** 過去の貢献は記録として尊重するが、それだけで現在の整合を保証しない。肩書・年数・功績を免疫判定から切り離す。

**参加条件の更新。** 初回入会条件だけでなく、役割・環境・時間の変化に合わせ、行動や負荷を伴うCheckpointを更新する。ただし思想検査や忠誠テストへ変えない。

**卒業設計。** 接続終了時に、過去の接続への感謝、現在の方向分岐、互いに別の場所で生きる自由を明示し、善悪・上下を持ち込まず循環から離す。

**適正規模への収縮。** 数値が伸びていてもOriginのL7が届かず、免疫・代謝が鈍るなら、募集停止、提供範囲縮小、人数削減等を後退ではなく拍動として選択する。

**継承。** 「次のリーダーは誰か」だけでなく、創始者不在時にも判断基準、学習、是正、免疫、代謝が動くかを確認し、人から構造への継承を進める。

## 測定・監査点
- L7が行動指針として機能しているか、装飾的スローガンへ落ちていないか。
- 接続報酬を受ける一方で、行動・貢献・負荷耐性が継続的に乖離していないか。
- 貢献者だけに負荷が偏り、疲弊・離脱が起きていないか。
- 新規の高整合主体が内部の空気に違和感を持ち、参入をやめていないか。
- 免疫判定が人格・年数・功績・思想へ逸脱していないか。
- Checkpointが行動・変化対応を見る装置として機能し、忠誠テスト化していないか。
- 過去の貢献や恩義が、現在の不整合を固定するサンクコストになっていないか。
- 切断が攻撃・制裁・恥辱でなく、循環の流路制御として実行されているか。
- 市場規模がL7・免疫・代謝と整合しているか。
- 数字の増加だけを健全性と誤認していないか。
- 収縮可能性が実際に残っているか。
- 創始者不在時にも判断・学習・是正・免疫・代謝が機能するか。
- L7を守るために、その他の構造を更新できるか。

親原典は固定の人数上限、売上閾値、擬態率、免疫スコアを普遍値として定義していない。適正規模も人数の固定値ではなく、Originの灯火が温度と解像度を保って届く限界として定義される。

## 成立条件
- 成功後にも腐敗可能性を通常状態として観測する。
- 人格・善悪でなくL7と現在出力の整合を見る。
- 擬態を固定属性でなく可逆状態として扱う。
- 免疫を攻撃ではなく識別として運用する。
- 過去の功績・年数・肩書を現在整合の免罪符にしない。
- 代謝・卒業・切断の経路が実在する。
- 最大化より適正規模を選べる。
- 必要時に収縮できる。
- 継承対象をL7と実装構造へ移す。
- Origin固有性を消去せず、固定的権威化もしない。

## 失敗条件
- 腐敗を悪人探しへ還元する。
- 善意を理由に状態不整合を観測しない。
- 免疫を監視・思想検査・忠誠テスト・古参支配へ変える。
- Checkpoint自体を目的化する。
- サンクコストで役割終了・非貢献関係を永久固定する。
- 切断を制裁や見せしめにする。
- 人数・売上・影響力の最大化を唯一の成功指標にする。
- 収縮不能になる。
- 初期メンバーや創始者人格を不変の正義として固定する。
- 「仕組みが回っている」という慣性を共鳴循環と誤認する。

## 反証・改訂条件
構造的免疫・代謝・適正規模・動的平衡を実装しても、L7と出力の整合、貢献者の持続性、新規参加の純度、循環、継承可能性が反復的に改善しない場合、各装置の定義・適用範囲・観測方法を改訂する。

逆に、固定的な成長・最大化・人依存の継承でも長期にわたり同等以上の整合、循環、腐敗回避、創始者不在時の判断安定が再現する条件が確認されるなら、本稿の必要範囲は限定される。単一の離脱・縮小・売上減少を直ちに失敗とみなさず、原典が置く目的である市場の長期生存と循環で評価する。
