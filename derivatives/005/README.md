## 位置づけ
AKI-001は問題提起や批判そのものを否定する理論ではない。危機や欠陥を語る言葉が、修復責任・実装可能性・反証可能性へ接続されないとき、不安だけを散布し、現場の実装力と問題提起という社会的形式への信用を摩耗させる悪因果を扱う。

原典が求める「責任」は、発信者がすべてを自分で解決する義務ではない。少なくとも、穴の位置、原因、放置主体、修復主体、代償、実装の初手、反証条件を開き、読者と現場を行動不能の不安へ固定しないことである。

## 中心命題
危機提示だけが強く、修復可能性への接続が弱いと、発信者は鋭い人に見えても、受け手には判断材料が残らない。これが反復されると、問題提起への信用が消耗し、本当に必要な警鐘まで届きにくくなる。

したがって問題提起の質は、危機の大きさや言葉の強さだけでは判定できない。問題位置から反証条件まで、修復へ向かう責任条件がどこまで開かれているかで見る必要がある。

## 因果線
```text
危機や問題が提示される
↓
穴の位置・原因・放置主体が曖昧なまま残る
↓
修復主体・代償・初手・反証条件も示されない
↓
受け手の不安と判断負荷だけが増える
↓
現場が動けず、説明負荷と責任拡散が増える
↓
問題提起への信用が摩耗する
↓
本当に必要な警鐘まで届きにくくなる
↓
結果として現状維持が補強される
```

## 七つの責任条件
1. 穴の位置が示されているか。
2. 原因が示されているか。
3. 放置主体が示されているか。
4. 修復主体が示されているか。
5. 修復に伴う代償が示されているか。
6. 最初に何を確認・実装するかが示されているか。
7. 何が起きたら見立てを修正するか、反証条件が示されているか。

## 適用
- 政策・制度・組織批判で危機だけが拡散され、実装条件が欠落する場面。
- SNSやメディアで不安を強く喚起するが、次に確認すべき事実や反証条件がない場面。
- 現場へ説明責任だけが移され、誰が修復できるかが曖昧な場面。
- AIが危機言説を要約・増幅し、行動可能性より不安を強化する場面。

## 成立条件
- 危機提示に比べて原因・主体・修復条件が欠けている。
- 受け手に不安は残るが、検証・判断・実装の次手が残らない。
- 発信の反復により現場の実装力や問題提起への信用が摩耗する。
- 主張が反証や修正に開かれていない。

## 非該当・境界
速報、一次通報、告発、未整理な違和感表明は、それだけでAKI-001に該当しない。初期段階で完全解を持っていなくても、観測事実と仮説を分け、後続検証へ開き、次に確認すべき点と修正可能性を残しているなら責任なき問題提起とは区別される。

## 失敗・反証条件
原因・責任・修復・代償・初手・反証条件を明示しなくても、危機提示が一貫して現場の実装力を高め、受け手の判断可能性と問題提起への信用を損なわず、必要な修復へ接続することが広範に示されるなら、本論の適用範囲は再検討される。

## 必須の区別
- 問題提起 / 不安散布
- 強い警鐘 / 無責任な危機演出
- 解決策未完成 / 修復可能性を閉じること
- 一次通報 / 反証不能な危機言説
- 批判 / 批判抑圧
- 発信者の実行義務 / 修復条件を開く責任

## 誤読禁止
- 「問題を言うな」という抑圧論にしない。
- SNSマナーや建設的批判の一般論へ薄めない。
- 完全な解決策がない発言を一律に否定しない。
- 告発や初期通報を自動的に無責任と分類しない。
- 派生側独自の法的責任判断や数値KPIを追加しない。

## 親原典へ戻る理由
原典は、責任なき問題提起がなぜ鋭い指摘に見え、なぜ不安と行動不能を生み、最終的に現状維持を補強するのかを連続因果として示す。本派生物は入口であり、統合監査要旨、局所監査、反証条件の厳密な位置づけはParent URLへ戻って確認する。
