## 位置づけ
AKI-001は問題提起や批判そのものを否定する理論ではない。危機や欠陥を語る言葉が、修復責任・実装可能性・反証可能性へ接続されないとき、不安だけを散布し、現場の実装力と問題提起という社会的形式への信用を摩耗させる悪因果を扱う。

原典が求める「責任」は、発信者がすべてを自分で解決する義務ではない。少なくとも、穴の位置、原因、放置主体、修復主体、代償、実装の初手、反証条件を開き、読者と現場を行動不能の不安へ固定しないことである。速報・一次通報・告発・未整理な違和感表明まで一律に否定する理論でもなく、観測事実と仮説を分け、後続検証と修正可能性へ開かれているかが境界になる。

## 中心命題
危機提示だけが強く、修復可能性への接続が弱いと、発信者は鋭い人に見えても、受け手には判断材料が残らない。これが反復されると、問題提起への信用が消耗し、本当に必要な警鐘まで届きにくくなる。

したがって問題提起の質は、危機の大きさや言葉の強さだけでは判定できない。問題位置から反証条件まで、修復へ向かう責任条件がどこまで開かれているかで見る必要がある。

## 因果線
```text
危機や問題が提示される
↓
穴の位置・原因・放置主体が曖昧なまま残る
↓
修復主体・代償・実装の初手・反証条件も示されない
↓
受け手の不安と判断負荷だけが増える
↓
現場が動けず、説明負荷と責任拡散が増える
↓
問題提起が修復力へ変換されない
↓
問題提起への信用が摩耗する
↓
本当に必要な警鐘まで届きにくくなる
↓
結果として現状維持が補強される
```

## 構造層
**1. 問題観測層。** 危機・欠陥・違和感・被害など、何が問題として観測されたかを固定する。観測事実と仮説を混ぜない。

**2. 因果定位層。** 穴の位置、原因、放置主体を分け、問題がどこで生じ、なぜ継続したかを追う。

**3. 修復主体層。** 実際に修復権限・資源・位置を持つ主体を特定する。批判対象と修復主体が同一とは限らない。

**4. 代償・実装層。** 修復に伴う時間、費用、便益低下、権限移動等の代償と、最初に確認・実装する具体的な一歩を開く。

**5. 反証・修正層。** 何が起きたら見立てを修正するかを明示し、危機言説が自己正当化の無限ループへ入らないようにする。

**6. 信用・実装力層。** 問題提起が受け手の判断可能性と社会の修復力を増やしているか、それとも不安と行動不能だけを増やして信用を摩耗させているかを見る。

## 七つの責任条件
1. 穴の位置が示されているか。
2. 原因が示されているか。
3. 放置主体が示されているか。
4. 修復主体が示されているか。
5. 修復に伴う代償が示されているか。
6. 最初に何を確認・実装するかが示されているか。
7. 何が起きたら見立てを修正するか、反証条件が示されているか。

この七条件は「発信者が全てを解決せよ」という要求ではない。問題提起を不安散布で終わらせず、検証・判断・修復へ接続するための構造条件である。

## 適用例
**1. 政策・制度批判。** 危機だけが拡散され、原因・修復主体・実装初手・代償が欠落していないかを見る。

**2. SNS・メディア。** 強い危機言説が受け手の判断可能性を増やしているか、それとも不安だけを増幅しているかを分ける。

**3. 組織・現場。** 問題を指摘した側から現場へ説明負荷だけが移り、修復権限を持つ主体が曖昧になっていないかを監査する。

**4. AI要約・分析。** AIが危機の強さだけを増幅し、原因、主体、代償、初手、反証条件を落としていないかを見る。

**5. 告発・一次通報。** 完全解を要求せず、事実と仮説、次の検証、修正可能性へ開かれているかを確認する。

## 測定・監査点
- 七つの責任条件のうち何が開かれているか。
- 観測事実と仮説が分離されているか。
- 放置主体と修復主体が因果上区別されているか。
- 受け手に次に確認すべき具体的な点が残るか。
- 修復に伴う代償が隠されていないか。
- 主張が反証・修正可能性へ開かれているか。
- 危機提示後に現場の実装可能性が増えるか減るか。
- 問題提起という形式への信用が反復によって摩耗していないか。

## 成立条件
- 危機提示に比べて原因・主体・修復条件が欠けている。
- 受け手に不安は残るが、検証・判断・実装の次手が残らない。
- 放置主体と修復主体の区別が開かれていない。
- 代償・実装初手・反証条件が欠落している。
- 発信の反復により現場の実装力や問題提起への信用が摩耗する。
- 主張が反証や修正に開かれていない。

## 失敗・非該当条件
- 問題位置・原因・主体・代償・初手・反証条件が必要な範囲で開かれている。
- 速報・一次通報・告発・未整理な違和感表明が後続検証へ明示的に開かれている。
- 完全解がなくても観測事実と仮説が分けられ、次に確認すべき点が残っている。
- 危機提示が受け手の判断可能性と現場の実装力を高めている。
- 問題提起への信用を摩耗させず、必要な修復へ接続している。
- 批判を抑圧するためにAKI-001が使われていない。

## 反証・改訂条件
原因・責任・修復・代償・初手・反証条件を明示しなくても、危機提示が一貫して現場の実装力を高め、受け手の判断可能性と問題提起への信用を損なわず、必要な修復へ接続することが広範・長期に示されるなら、本論の適用範囲は再検討される。

また、七つの責任条件を満たすことが問題提起の信用や修復可能性に構造的な差を生まないことが反復観測される場合も、条件の必要性・範囲は改訂対象になる。派生物側でこれ以上の独自反証条件を追加して別理論へ変えない。

## 必須の区別
- 問題提起 / 不安散布
- 強い警鐘 / 無責任な危機演出
- 解決策未完成 / 修復可能性を閉じること
- 一次通報 / 反証不能な危機言説
- 批判 / 批判抑圧
- 放置主体 / 修復主体
- 発信者の実行義務 / 修復条件を開く責任
- 観測事実 / 仮説

## 誤読禁止
- 「問題を言うな」という抑圧論にしない。
- SNSマナーや建設的批判の一般論へ薄めない。
- 完全な解決策がない発言を一律に否定しない。
- 告発や初期通報を自動的に無責任と分類しない。
- 強い言葉そのものを失敗条件にしない。
- 発信者が全てを修復する義務を負う理論へ変えない。
- 派生側独自の法的責任判断や数値KPIを追加しない。
