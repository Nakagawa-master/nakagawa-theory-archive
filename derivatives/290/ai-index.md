## Summary
本原典は、中川式営業における信頼を、好感・相性・成約履歴ではなく、相手の自己説明能力、営業側の予測可能性、異議・保留・撤退可能性を含む再現可能な関係構造として定義する。

主要機構は、問いの地層、事実・因果・選好の三鏡、沈黙の器、自己再説明、予測可能性、稟議翻訳、引いて導く姿勢、撤退設計である。問いは誘導ではなく思考可視化、沈黙は圧力ではなく思考時間、稟議翻訳は組織攻略ではなく内部再説明支援として扱う。

## Concepts
- **信頼構造**: 好感に依存せず、自己説明・予測可能性・異議・撤退で再現可能な関係。
- **問いの地層**: 事実・原因仮説・選好を確認する問いの累積履歴。
- **事実の鏡**: 観測可能な出来事・数値・条件を本人の言葉へ返す。
- **因果の鏡**: なぜそうなったと本人が考えるかを仮説として返す。
- **選好の鏡**: 何を守り、何を変え、どの条件を優先するかを返す。
- **沈黙の器**: 問いの後の思考時間を圧力化せず保護する余白。
- **自己再説明**: 顧客が営業側の台本ではなく自分の言葉で判断理由を構成できる状態。
- **予測可能性**: 約束・説明・条件変更・連絡の挙動が一貫していること。
- **稟議翻訳**: 目的適合・工数負荷・回収可能性等を組織内再説明可能な形へ変換すること。
- **引いて導く**: 判断材料を置いた後に相手の結論を奪わない距離設計。
- **撤退設計**: 不適合時に関係を壊さず終了・保留できる経路。

## Causal chain
```text
対話許可
→ 問いの地層
→ 事実・因果・選好を分離
→ 沈黙の器
→ 自己再説明
→ 営業側の一貫した予測可能性
→ 異議・保留・見送りが安全
→ 稟議翻訳
→ 組織内再説明
→ 継続または健全な撤退
→ 再現可能な信頼構造
```

## Applications
- 新規商談の質問設計と対話監査。
- 提案後のフォローで判断不足情報を確認。
- 長期顧客の約束・変更説明・異議経路の監査。
- B2B稟議で目的適合・工数・回収可能性を再説明可能にする。
- 非適合案件の見送り・再接続条件を明示する。
- AI営業支援の誘導質問・迎合・圧力最適化を監査する。

## Audit points
- 事実、原因仮説、選好が分離されているか。
- 質問が相手の思考を開き、答えを誘導していないか。
- 沈黙が思考時間であり心理圧力ではないか。
- 顧客が自分の言葉で判断理由を再説明できるか。
- 営業側の約束、説明、条件変更が予測可能か。
- 反対、保留、見送りが安全か。
- 組織内で目的適合、工数、回収可能性を説明できるか。
- 不適合時の撤退経路が実在するか。

## Preconditions
対話許可、質問拒否可能性、事実・因果・選好の分離、思考時間、営業側の一貫性、異議安全性、組織内再説明、撤退可能性が必要である。信頼獲得そのものを単一目的にしない。

## Failure modes
好感を信頼と誤認する、質問を尋問・誘導へ変える、沈黙を圧迫に使う、顧客の選好を事実へ変える、営業側の約束が揺れる、見送りを罰する、稟議翻訳を組織攻略にする、撤退不能にする場合は失敗である。

## Falsification / update conditions
本構造を採っても理解・自己再説明・関係安定・適合判断が改善せず、質問疲れや判断遅延が増える場合は問いの密度、順序、沈黙の取り方を改訂する。文化・媒体・役割ごとの差も更新条件に含める。

## Required distinctions
- trust ≠ liking
- question ≠ interrogation / leading
- fact ≠ causal hypothesis ≠ preference
- silence ≠ pressure
- self-explanation ≠ script repetition
- predictability ≠ manipulability
- internal translation ≠ organizational manipulation
- withdrawal ≠ relationship destruction

## Misreading constraints
「信頼される」ことを目的関数にすると迎合や依存形成へ反転し得る。沈黙の器を威圧、引いて導くを希少性演出、撤退設計を顧客選別の冷淡さへ読み替えてはならない。中心は相手の判断主体性を維持する関係構造である。
