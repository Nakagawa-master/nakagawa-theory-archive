## Summary
本原典把销售中的“信任”从好感、相性、个人魅力或成交经历中分离出来，定义为一种可复现的关系结构：客户能够用自己的语言思考、反对、暂停、在组织内部重新说明，也能够在不适合时退出；与此同时，销售方的承诺、说明、联络和边界保持可预测。

核心机制包括问题的地层、事实／因果／偏好的三面镜、沉默之器、自我再说明、可预测性、内部审批翻译、“退一步引导”以及退出设计。它们不是操控成交概率的心理技术，而是保护对方决策主体性的结构。

## Concepts
- **问题的地层**: 通过连续提问保留判断依据，而不是用一个“关键问题”逼出目标答案。
- **事实之镜**: 返回可观察的事件、数据与条件。
- **因果之镜**: 把“为什么发生”作为客户的因果假设，而不是直接升级为事实。
- **偏好之镜**: 确认客户想保护、改变以及优先的条件。
- **沉默之器**: 提问后保护思考时间，不把无言变成压力。
- **自我再说明**: 客户能不用销售话术，而用自己的语言重新构成判断理由。
- **可预测性**: 承诺、未知事项、联络频率和条件变更保持一致并可追踪。
- **内部审批翻译**: 把目的适配、工作量、回收可能性、风险与实施条件变成组织内部可说明的语言。
- **退一步引导**: 给出判断材料后，不夺走对方的结论。
- **退出设计**: 不适合时可以暂停或结束，而不破坏关系。

## Causal chain
```text
确认对话许可
→ 累积问题地层
→ 分离事实 / 因果假设 / 偏好
→ 保护思考沉默
→ 客户自我再说明
→ 销售方行为可预测
→ 反对与保留安全
→ 内部审批翻译
→ 组织内部可再说明
→ 继续选择或健康退出
→ 超越个人魅力的可复现信任
```

## Applications
可用于初次商谈、提案后的跟进、长期客户复核、销售负责人交接、B2B内部审批支持、不适配案件退出以及AI销售助手。重要测试是：原销售人员不在场时，判断理由是否仍然能被重新说明。

## Audit points
检查问题是否诱导；事实、因果假设与偏好是否分开；沉默是否被用作压力；客户能否独立说明理由；销售承诺是否一致；反对、保留和不成交是否安全；内部审批支持是否越界为组织操控；退出路径是否真实可用。

## Preconditions
必须允许拒答、不确定、反对、延迟与退出。销售方也必须愿意暴露不适配，而不是把“被信任感”或成交概率作为唯一目标。

## Failure modes
把受欢迎当成信任、把提问变成审讯、用沉默制造不安、把偏好写成事实、承诺反复变化、惩罚拒绝、把审批翻译变成组织攻略、让退出成本过高，均属于失败。

## Falsification / update conditions
如果问题地层、沉默、自我再说明、可预测性与退出权并未提高理解、稳定合作和适配判断，反而增加提问疲劳或决策拖延，就应调整问题密度、顺序与节奏。文化和媒介差异也属于改订条件。

## Required distinctions
- 信任 ≠ 好感
- 提问 ≠ 审讯／诱导
- 事实 ≠ 因果假设 ≠ 偏好
- 沉默 ≠ 压迫
- 自我说明 ≠ 复读销售脚本
- 可预测性 ≠ 可操控性
- 审批翻译 ≠ 操控客户组织
- 退出 ≠ 关系破坏

## Misreading constraints
不能把“让客户信任我”设成单一优化目标，否则可能走向迎合、依赖形成与策略性信息控制。“退一步引导”不是稀缺性演出，退出设计也不是冷酷筛选客户。中心始终是保护对方的判断主体性。
