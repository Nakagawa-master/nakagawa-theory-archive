## 位置づけ
本派生物は、営業における信頼を感情的な好感や相性ではなく、問いの連続、沈黙の器、組織内再説明、境界と撤退によって再現可能にする持続関係の構造として展開する。

## 中心命題
信頼は「答えをたくさん与えた結果」ではない。相手の思考を尊重する問いが連続し、その問いに答える時間が守られ、相手自身が自分の言葉で再説明できる状態が積み重なることで、予測可能性と尊重の持続が生まれる。

## 因果線
```text
対話許可
→ 問いを連続させる
→ 事実・因果・選好を本人の言葉で確認
→ 問いの後の沈黙を守る
→ 自己説明能力が高まる
→ 営業側の言動が予測可能になる
→ 尊重が継続して観測される
→ 担当者が社内で再説明できる
→ 一人の理解が組織理解へ広がる
→ 信頼が持続関係として結晶化
→ リピート・紹介・長期関係を支える
```

## 三つの構造
1. **問いの地層**: 答えを押し付けず、相手の思考を尊重する問いを積み重ねる。
2. **沈黙の器**: 問いのあとに考える時間を残し、焦って埋めない。
3. **稟議翻訳**: 目的適合、工数負荷、回収可能性を相手が社内で語れる言葉へ変える。

## 撤退設計
相互の問いが続かず、予測可能性・尊重・適合性が失われたときは、関係を無理に維持しない。撤退は失敗ではなく、双方の境界を守り長期的な信頼を毀損しないための設計である。

## 状態モデル

```yaml
- reciprocal_questions_continue

- trust_reproducible
```

## 測定・監査点
- 顧客が自分の言葉で再説明できるか。
- 質問が相手の思考を開くか、誘導していないか。
- 沈黙が不自然な圧力になっていないか。
- 営業側の約束・連絡・説明が一貫しているか。
- 不適合時に撤退できるか。
- 担当者から組織へ理解が移せるか。

## 成立条件
問いの継続、沈黙、再説明能力、予測可能性、尊重の一貫性、稟議翻訳、撤退可能性があること。

## 失敗条件
好かれることを信頼と誤認する、相手の望む答えだけを返す、沈黙を圧迫に使う、約束が一貫しない、撤退不能な囲い込みを行う。

## 反証・改訂条件
この構造を採っても継続率・再説明能力・信頼維持が改善せず、質問疲れ、圧迫感、不適合案件の長期化が増える場合は問いの密度・間合い・撤退条件を改訂する。

## 必須の区別
- 信頼 ≠ 好感
- 問い ≠ 回答拒否
- 沈黙 ≠ 圧迫
- 予測可能性 ≠ 操作可能性
- 撤退 ≠ 関係破壊
