## Summary
The Parent defines trust as a reproducible structure rather than liking or chemistry. Repeated questions respect the other party's thought process; silence protects reflection; self-explanation and consistent behavior create predictability; internal translation carries understanding into the organization; clean withdrawal protects boundaries when fit disappears.

## Causal model
```text
questions
-> fact/cause/preference mirrors
-> silence
-> self-explanation
-> predictable respectful behavior
-> internal translation
-> durable trust
-> repeat/referral or clean withdrawal
```

## Distinctions
Trust != liking. Questions != withholding answers. Silence != pressure. Predictability != manipulability. Withdrawal != relationship destruction.

## Validity
Requires self-explanation, consistency, respect, organizational re-explainability, and a real withdrawal boundary. It fails through ingratiation, pressure, inconsistent promises, or lock-in.
