## Summary
The Connection Exchange Protocol (CXP) defines the minimum social API needed to make connection portable across organizations without losing consent, memory, reversibility, auditability, or privacy. Its core objects are SubjectID, RelationID, ConsentToken, MemoryObject, ReversibilityFlag, and VisibilityClass. It standardizes discovery, intent exchange, consent, memory creation, metric readout, exit, cooling, and reconnection.
