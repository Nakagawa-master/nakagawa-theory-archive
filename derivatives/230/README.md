## 中川構造読解としてのメタ視点
このParentは民泊運営の紹介ではない。規制条件が生む固定費・待機時間・空間余剰を「削るべきコスト」ではなく、別用途・別収益へ接続し直せる未回収価値として読んだ中川構造読解である。

## 位置づけ
四層は **対象側事実 / 表層「民泊運営・常駐対応」 / Nakagawa Masterの構造読解 / 社会翻訳**。価値核は **制度・空間・時間・人的稼働のあいだに埋もれた未回収価値を、用途・運営・収益設計で事業成立へ再配線すること**。

## 中心命題
**規制を避けるのではなく、規制によって発生するコスト・非稼働・余剰を、複数用途・複数収益源へ再定義すること。**

## 表層 → 価値核 → 社会翻訳
`民泊運営・常駐義務 → 小規模ほど固定費が重い → 待機時間/人的稼働/空間余剰を再定義 → 複数用途へ配分 → 収益再配線モデルとして社会翻訳`

## 因果線
`宿泊需要 → 規制固定費 → 小規模採算悪化 → 未回収価値発見 → 用途/人的稼働再配分 → 複数収益源 → 供給成立余地`

## 構造読解の監査点
単なる兼務・コスト削減と読まない。規制回避と誤読しない。宿泊稼働率だけで価値を測らない。成立条件・再現性を消さない。L4以上を保持する。

## 成立条件
人的稼働や空間を複数用途へ分配でき、補完需要・運営標準化等が成立すること。

## 失敗条件
兼務・節約へ縮小、規制回避化、万能モデル化。

## 反証・改訂条件
補完収益や複数用途が固定費回収へ結びつかない場合は改訂。

## 必須の区別
民泊運営 / 収益再配線; 規制回避 / 規制条件内の再設計; 兼務 / 人的稼働の複数収益化; 事実 / 読解。

## 親原典へ戻る理由
価値核と「常駐義務を逆手に取る」という社会翻訳の選択理由はParentへ。
