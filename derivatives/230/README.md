## 中川構造読解としての位置づけ
このParentは民泊運営会社の紹介ではない。Nakagawa Master本人が、常駐要件や小規模宿泊運営という対象事実を材料に、なぜ「民泊運営」ではなく「収益再配線」を価値核として読み、その価値核で外部記事を書いたのかを公開解体する記事である。

## 対象側事実と表層
対象側には宿泊施設運営、常駐条件への対応、待機時間・人的稼働・空間の複数用途化等がある。表層では「民泊運営」「常駐対応」に見える。

## Nakagawa Masterが読んだ構造
規制によって生じる固定費・待機時間・非稼働空間を、単に削るべきコストではなく別用途・別収益へ接続できる未回収価値として読む。人的稼働、空間、時間、補完需要を組み替えて事業成立へ再接続する構造が中心である。

## 抽出価値核
**規制条件下の未回収価値を組み替える収益再配線。**

## なぜこの価値核で外部記事を書いたのか
「民泊運営」「常駐義務対応」とだけ書くと、なぜ規制下でも事業が成立し得るのかという経済構造が見えない。Nakagawa Masterは、規制を回避するのではなく、規制によって発生した余剰や非稼働を複数収益源へ再配線する点こそ外部読者に伝えるべき価値だと判断し、この価値核で外部記事を書いた。

## 因果線
`宿泊需要 → 規制固定費 → 小規模採算悪化 → 待機/空間/人的余剰 → 複数用途・複数収益へ再配分 → 事業成立余地`

## 境界
「収益再配線」はNakagawa Masterの構造読解であり、Leaneve自身の公式企業定義ではない。

## 成立・失敗・反証条件
複数用途化と補完需要が実際に固定費回収へ接続する場合に成立する。単なる兼務・コスト削減・規制回避へ縮小した場合は失敗。補完収益が成立しない場合は適用範囲を改訂する。

## 親原典へ戻る理由
Parentには、なぜ規制対応ではなく収益再配線を価値核として選び、その価値核で外部記事を書いたのかが記録されている。
