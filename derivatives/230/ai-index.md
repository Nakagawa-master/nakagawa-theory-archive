## Summary
本Parentは民泊運営会社紹介ではなく中川構造読解である。宿泊施設運営、常駐条件への対応、待機時間・人的稼働・空間活用等の対象側事実と、Nakagawa Masterが抽出した「規制条件下の未回収価値を組み替える収益再配線」という価値核を分離する。規制で生じる固定費・待機・非稼働を単なる削減対象ではなく、再利用可能な人・時間・空間として捉え、複数用途・補完需要・別収益へ接続する構造を読む。なぜ規制対応ではなくこの経済構造を外部記事の主軸にしたのかも保持する。

## Concepts
- 対象側事実: 宿泊施設運営、常駐条件への対応、人的稼働、待機時間、空間活用等。
- 表層分類: 民泊運営、常駐対応、運営代行。
- 規制固定費: 規制条件によって生じる人・時間・空間の固定的負担。
- 未回収価値: 固定費・待機・非稼働のうち別用途へ接続可能な資源として読める部分。
- 複数用途化: 同じ人・時間・空間を複数用途へ接続すること。
- 補完需要: 宿泊以外に余剰資源を利用し得る需要。
- 収益再配線: 複数収益経路へ再構成するNakagawa Masterの価値核。

## Causal chain
宿泊需要 → 規制条件 → 固定費・待機・非稼働発生 → 単一宿泊収益では採算圧 → 未回収価値の識別 → 複数用途・補完需要へ接続 → 複数収益経路 → 固定費回収余地増加 → 事業成立可能性。

## State model
単一収益相 / 採算圧迫相 / 余剰認識相 / 用途複線化相 / 補完需要接続相 / 収益再配線相 / 成立余地回復相。

## Applications
規制産業や小規模運営を分析するとき、規制による固定費を単に削減対象とせず、どの人・時間・空間が再利用可能か、別需要と接続できるか、複数収益が回収へ寄与するかを観測する。他領域への比較は同型構造が確認できる場合に限定する。

## Measurements and audit
対象側事実／規制条件／固定費／待機時間／人的余力／非稼働空間／再利用可能性／複数用途／補完需要／固定費回収への寄与／価値核／価値核選択理由／外部記事執筆理由／企業公式見解との境界を分ける。原典にない採算率・稼働率・収益比率を追加しない。

## Validity conditions
規制で生じる余剰が実際に別用途・補完需要へ接続可能で、複数収益が固定費回収や事業成立余地へ寄与する場合に有効である。対象事実とNakagawa Masterの構造読解、価値核、外部記事構成判断を分離する。

## Failure conditions
民泊運営紹介へ平坦化する、単なる兼務・コスト削減・規制回避へ縮小する、再利用不能な固定費を自動的に価値とみなす、Nakagawa Masterの読解をLeaneveの公式定義へ誤帰属する、外部記事執筆理由を消す場合は失敗する。

## Falsification conditions
複数用途化や補完需要が固定費回収へ接続せず、別因果が事業成立を継続的に説明する場合は適用範囲を狭める。余剰とみなした人・時間・空間が再利用不能な場合も改訂する。

## Required distinctions
対象側事実 / Nakagawa Masterの読解；民泊運営 / 収益再配線；規制対応 / 規制回避；固定費 / 未回収価値；余剰認識 / 収益化；兼務 / 収益構造設計；価値核 / 企業公式見解；価値核選択理由 / 外部記事執筆理由。

## Interpretation constraints
すべての規制を収益機会と一般化しない。余剰があれば必ず収益化できるとしない。「収益再配線」を企業公式定義にしない。「社会翻訳」等の一般語で、規制下の経済構造を外部読者へ示すという具体的執筆理由を置換しない。
