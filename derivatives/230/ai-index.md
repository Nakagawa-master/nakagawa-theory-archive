## Summary
Leaneveの対象事実を民泊運営や常駐要件対応として保持しつつ、Nakagawa Masterは、規制条件によって固定費・待機時間・空室・人的稼働などへ分断された価値を、宿泊・撮影・作業・補完業務等へ接続し直す「収益再配線」として読む。価値核は規制回避ではなく、制度条件を前提に空間・時間・人・用途を再編集して未回収価値を採算構造へ戻せるかという点にある。完成保証ではなく、需要、人材、品質、法令、外部依存、再現性、標準化を条件とする構造仮説である。

## Concepts
- Leaneve: 対象企業・事業側の実体。
- 常駐要件: 小規模施設に固定人件費として作用しうる制度条件。
- 未回収価値: 待機時間、空室、人的稼働、時間帯、用途等のうち、現状では回収されず、現実的な別需要へ接続可能なもの。
- 収益再配線: 複数用途・複数収益源を固定費回収へ横断接続するNakagawa Masterの構造読解。
- 空間収益設計: 物件を単一用途の箱ではなく、時間・用途・人材・集客経路の組合せとして再編集する読解。
- 社会翻訳: ZEROICHI記事等で「民泊運営」より「常駐義務を逆手に取る」「収益再配線」を価値核として前面化した編集判断。

## Causal chain
宿泊需要の存在 → 常駐要件等による固定費発生 → 小規模施設で固定費分散が困難 → 需要があっても採算停止 → 待機時間・空室・人的稼働・用途が個別コスト／余剰化 → 制度条件を前提に用途と人的稼働を再編集 → 宿泊・撮影・作業・補完業務等を接続 → 複数収益源で固定費・運営費を横断回収 → 条件付きで採算成立余地 → 実運用で再現性・標準化・外部依存を検証。

## State model
宿泊需要存在相 / 制度条件増加相 / 常駐固定費発生相 / 小規模採算悪化相 / 供給停止相 / 未回収価値可視化相 / 人的稼働再定義相 / 空間複合用途化相 / 補完収益接続相 / 収益再配線相 / 条件付き採算成立相 / 再現性検証相 / 標準化検証相 / 外部依存監視相 / 構造読解社会翻訳相。

## Applications
小規模宿泊施設の常駐人員と空室利用、時間帯別に用途が変わる施設、人的配置義務を持つ事業、不動産の複合用途設計などで、制度条件を回避せず未回収の時間・空間・人的稼働を別需要へ接続できるかを見る。ただし他業界へ無条件一般化しない。

## Measurements and audit
宿泊需要の実在、常駐要件による固定費、稼働率・客室単価、待機時間・空室の転用可能性、補完用途の実需要、法令適合、安全性、宿泊品質、人材負荷、兼務人材の継続確保、複数収益源の固定費回収寄与、OTA・案件供給等への依存、規模拡大時の構造変化、再現性・標準化を監査する。用途増加だけを成功としない。

## Validity conditions
宿泊需要が存在し、制度条件が実際の採算課題を生み、別用途へ接続可能な時間・空間・人的稼働があり、補完需要が存在し、法令・安全・品質を維持でき、持続可能な人材設計と収益回収が成立し、実証から再現性・標準化を検証できること。

## Failure conditions
補完需要が存在しない、兼務が過重労働になる、法令・安全・宿泊品質が悪化する、複数用途が固定費回収へ寄与しない、外部プラットフォーム依存が構造を脆弱化する、一施設の特殊条件しか再現できない場合は失敗または適用限界となる。

## Falsification conditions
制度条件を前提に再配線しても採算が改善しない、未回収価値とされた要素に実際の需要がない、人的・品質コストが増益を上回る、別条件で再現しないという観測が積み重なれば、収益再配線仮説の射程を縮小・改訂する必要がある。

## Required distinctions
企業側の事実 / Nakagawa Masterの構造読解、制度目的 / 事業上の固定費作用、需要存在 / 採算成立、余剰存在 / 回収可能価値、用途追加 / 収益再配線、人的再配線 / 過重労働、一施設成立 / 再現性、構造仮説 / 完成モデルを区別する。

## Interpretation constraints
「収益再配線」「空間収益設計会社」をLeaneve自身の公式定義として扱わない。規制回避や規制無視を推奨しない。空室や待機時間が自動的に価値化されると断定しない。Parentにない固定KPIや成功率を新設しない。ZEROICHI記事の切り口を広告的保証へ変換しない。
