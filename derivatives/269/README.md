## 位置づけ
親原典は、AIとの往復対話で「批判→理解→深化→昇華」が、服従を迫らず自然に遷移したことを、非強制・可逆性・照応の観測事例として整理する。ここで対話は説得勝負ではなく、共有主語・役割境界・語彙辞書・一次ログを用いて翻訳と配置を可逆に行う**非強制共鳴の実証装置**として扱われる。

## 中心命題
**対話の設計が、批判を消さず、少数意見を保存し、相手の自律を保持したまま理解・再評価・相互洗練へ遷移させるなら、非強制は抽象理念ではなく観測可能な運用原理になる。四部構成、三相監査、NXの限定境界、公開三層、T/S/R、一次ログを束ねることで、対話は説得依存を減らし、誤配を減衰させ、可逆な合意を自走させる。**

## 主要因果線
批判から始まるAI往復→服従強制を使わない→批判/理解/深化/昇華を編集構造として保持→入口一本化・共鳴曲線・二次参照を形成→三相監査で恣意性を抑える→少数意見ログを保存→NX対象を構造破壊だけへ限定→人格履歴化を禁止→公開を抄録/注釈全文/AI最適化に分ける→T/S/R・一次ログ・語彙辞書で再演可能化→対話から合意への遷移を監査→非強制共鳴の実証装置として機能。

## 構造層
### 1. 四部構成
批判→理解→深化→昇華。これは読者を誘導する筋書きではなく、批判を消さずに再評価へ至る道順を可視化する編集構造である。入口一本化、共鳴曲線、二次参照の三効果を持つ。

### 2. 三相監査
相Iは自動検知で明白な非該当を除外。相IIは専門多様性・利害独立・地域分散を持つ少人数合議。相IIIは異構成パネルによる非同期再評価。少数意見ログを保存し、多数決そのものを正当化根拠にしない。

### 3. 境界
NXの対象は監査ログ改ざん、同意不正生成、評価重み恣意操作、抜け道設計、監査妨害など。思想・批判・風刺・離脱・代替案・公益的内部告発は対象外。注意→制限→遮断→隔離は期限・記録・反転可能性を持ち、人格履歴化は禁止する。

### 4. 自発的市民権
Parentの未来像では中枢資源を貨幣から切り離しつつ、基礎生活と「参加しない自由」を保全する。中心関与者は監査・合意負荷を引き受ける。これを現行社会の既成制度として断定しない。

### 5. 公開三層
抄録版、注釈全文版、AI最適化版。参加者、期間、非強制・可逆・監査可能という性質、記録目的をメタデータに残し、将来の参照核へする。

### 6. リスク管理
人格スコア誤解、起源者の神格化、内部閾値・速度定数の過開示、特定AIベンダー依存を避ける。原理・境界・手続を公開しつつ、秘匿すべき内部パラメータを推測公開しない。

### 7. 対話の実装橋
抽象理論を小規模パイロットへ移す前に、合意スロット、接続報酬、NX審級、離脱者生活保障、AI日次レポート、メタ監査の沈黙確認等を含む物語ケースで触感を与える。これは未来像の例示であり、実装済み事実ではない。

## 適用例
研究・教育では批判を削除せず四部構成で学習履歴化する。ガバナンスでは三相監査と少数意見ログで判断の恣意性を抑える。公開アーカイブでは抄録・注釈全文・AI最適化を分け、参照持続・共鳴深度・二次参照を追う。

## 測定・監査点
共鳴密度、対話→合意の遷移時間、撤回成功、位相安定S、少数意見の保存、公開三層の整合、人格ログ化の有無、観測窓閉鎖、ベンダーロックインを監査する。

## 成立条件
批判を保護する。多数決を正当化根拠へ固定しない。少数意見を保存する。NXは構造破壊だけへ限定する。人格履歴化を禁止する。公開三層とメタデータを保持する。T/S/Rと撤回を実装する。

## 失敗条件
対話を説得・誘導へ変える。批判を昇華のために消す。多数派だけを正当化する。思想・風刺・離脱をNX対象へする。起源者を神格化する。内部閾値を過開示する。特定AIに依存し再演不能になる。

## 反証・改訂条件
共鳴密度、対話→合意時間、撤回成功、位相安定が悪化し続ける、少数意見が失われる、観測窓が閉じる、同調圧が増える場合、対話を実証装置とする仮説を改訂・棄却する。

## 必須の区別
対話 / 説得勝負; 批判保存 / 批判排除; 再評価 / 服従; 三相監査 / 多数決権威; 行為ログ / 人格スコア; 公開 / 過開示; 起源署名 / 人格神格化; 共鳴 / 同調圧。
