## 位置づけ
本派生物は、初期接触の次にある営業対話を、説明量を増やす場ではなく、相手の事実・因果・選好を問いと沈黙で映し返し、相手自身の言葉から共鳴と理解を形成する構造として展開する。

## 中心命題
対話は「こちらが正しい答えを与える」ことではない。相手が自分の現状、放置した場合の因果、望む未来を自分の言葉で確認できるよう、問い・要約・沈黙・照応を設計する。共鳴は賛同ではなく、相手の意味構造が相手自身に見える状態である。

## 因果線
```text
初期接触で対話許可が成立
→ 相手の語りを遮らず観測
→ 事実を鏡のように返す
→ 因果を問い返す
→ 望む未来・選好を問い返す
→ 沈黙で内省の時間を確保
→ 相手自身の言葉が整理される
→ 営業側の理解仮説を照合
→ 共鳴点と非適合点が見える
→ 提案へ渡せる構造が形成
```

## 三つの問いの鏡
1. **事実鏡**: 現在何が起きているかを本人の言葉で確認する。
2. **因果鏡**: この状態が続くと何が起きるか、原因・結果を本人に考えてもらう。
3. **選好鏡**: 何が実現したら望ましいか、判断基準と未来像を言語化する。

## 沈黙の器
沈黙は営業側が埋めるべき失敗ではない。相手が情報を統合し、自分の言葉を生成するための帯域として扱う。ただし不安や拒否のサインを無視して沈黙を利用し続けない。

## 状態モデル
```yaml
- dialogue_permission_active
- customer_narrative_observed
- fact_mirror_returned
- causal_mirror_returned
- preference_mirror_returned
- silence_preserved
- customer_language_clarified
- seller_hypothesis_checked
- resonance_and_mismatch_separated
- proposal_inputs_ready
```

## 適用例
- 顧客が「効率化したい」と言うとき、現在のどの作業が止まり、誰に負荷があり、改善後何を実現したいかを三鏡で整理する。
- こちらの解決策を即提示せず、相手が自分で因果を言語化できるまで待つ。
- 非適合が見えた場合、無理に共鳴を作らず提案しない判断も残す。

## 測定・監査点
- 営業側の発話比率が過大でないか。
- 顧客の言葉を要約時に意味改変していないか。
- 因果問いが恐怖喚起へ変わっていないか。
- 沈黙を圧迫手段にしていないか。
- 非適合点が記録されているか。

## 成立条件
対話許可、傾聴、三鏡、沈黙、仮説照合、非適合保持、相手の自己言語化が成立すること。

## 失敗条件
質問攻め、誘導質問、恐怖による因果提示、沈黙圧力、相手の言葉の改変、共鳴＝賛同の誤認。

## 反証・改訂条件
三鏡と沈黙を使っても理解・信頼・提案適合性が改善せず、対話負荷や誘導感が増える場合、質問順序・深度・間合いを改訂する。

## 必須の区別
- 対話 ≠ 説明
- 共鳴 ≠ 賛同
- 問い ≠ 誘導
- 沈黙 ≠ 圧力
- 因果鏡 ≠ 恐怖訴求
