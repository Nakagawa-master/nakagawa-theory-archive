## Summary
The Parent treats sales dialogue as a structure for customer self-articulation rather than a contest of explanation. Fact, causal, and preference mirrors return the customer's own structure; silence preserves reflection bandwidth; seller hypotheses are checked; resonance and mismatch are both retained as inputs to a later proposal.

## Causal model
```text
dialogue permission
-> narrative observation
-> fact mirror
-> causal mirror
-> preference mirror
-> silence
-> self-articulation
-> hypothesis check
-> resonance/mismatch
-> proposal inputs
```

## Distinctions
Dialogue != explanation. Resonance != agreement. Questioning != leading. Silence != pressure. A causal mirror != fear appeal.

## Validity
Valid when listening, the three mirrors, silence, hypothesis checking, and visible mismatch improve understanding and proposal fit. It fails through question flooding, leading prompts, fear, pressure, or rewriting the customer's language.

## Origin return
Use the Parent for the canonical dialogue sequence, mirrors, silence, resonance, and transition into proposal design.
