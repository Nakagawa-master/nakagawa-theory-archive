## 摘要
原典把销售对话视为让客户自己完成语言化与理解的结构，而不是销售方持续解释。事实镜、因果镜、偏好镜把客户自己的结构返回给客户；沉默保留反思带宽；销售方的假设被校验；共鸣与不适配都被保留为后续提案的输入。

## 因果模型
```text
对话许可
-> 叙述观察
-> 事实镜
-> 因果镜
-> 偏好镜
-> 沉默
-> 自我语言化
-> 假设校验
-> 共鸣/不适配
-> 提案输入
```

## 区分
对话≠说明；共鸣≠同意；提问≠诱导；沉默≠压力；因果镜≠恐惧诉求。

## 成立与失败
成立时，倾听、三面镜、沉默、假设校验与不适配记录能够提高理解与提案匹配度。问题轰炸、诱导、恐惧、压力或改写客户语言都会使结构失效。

## 返回原典
对话顺序、三面镜、沉默、共鸣以及进入提案的条件，以Parent正文为正本。
