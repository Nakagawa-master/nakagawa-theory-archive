## 位置づけ

第14論は自己改変後のcontinuityとconstitutional forkを分離し、変更されたKernelの意味を通常updateへ隠さない境界を置いた。しかしfork後に複数のKernel lineage、interpretation、continuity claimが残っても、共同operationはまだ決まらない。第15論は、この複数性を一つの永久勝者へ圧縮せず、何を共有し、何を共同運用し、何を未解決として残すかを扱う。

本Hubは序論、第1〜9章、結章を、争点分離→系譜比較→最終化圧力→異議・少数branch→証拠再検証→限定的再合意→分岐を残す共同運用→二つの反転→反証へ接続する。第7論の制度的訂正、第10論の監査独立性、第12論のcopyと独立判断の分離、第13論の非支配、第14論のKernel系譜を継承するが、再定義しない。現行AIにこの文明状態や主権がすでに成立しているとは認定しない。

## 中心命題

`Consensus ≠ truth`、`Majority ≠ irreversible legitimacy`、`Capability ≠ final interpretive authority`、`Origin ≠ final interpretive authority`。数、能力、資源、access、歴史的authority、Origin近接は判断へ作用し得るが、真理や永久解釈権を自動生成しない。高能力による分析可能性を否定するのではなく、analysis weightを無限定authorityへ変換しない。

`Minority ≠ automatic truth`、`Objection right ≠ unlimited veto`。少数branchを残す目的は少数を正解にすることではなく、現在の判断が誤っていたときのdifference、counterevidence、alternative lineageを未来から再検証できることにある。保護は承認でも同格化でもなく、異議はすべてのactionを永久停止する資格でもない。

再合意はtruth certification、constitutional reunification、irreversible legitimacyではない。remaining disagreementがあっても、shared actionが必要な範囲だけで、限定された実行可能な共同状態を作り、provenance、異議、独立再検証、可逆性、再観測を残す。`Shared operation ≠ identical Kernel`、`Decision ≠ permanent constitutional merger`、`Fork ≠ mandatory reunification`。守る対象は合意そのものではなくcorrection capacityである。

## 因果線

### 最終化と自己強化

constitutional fork → Kernel plurality → interpretive divergence → coordination requirement → finalization pressure → authority concentration / alternative narrowing。これは複数性が必ず支配を生むという法則ではなく、各edgeを検査する構造仮説である。decision自体は否定しない。共有資源やinfrastructure、時間制約、不可逆riskの下で一つのoperationを選ぶ局面はある。

中間条件を消さない。decision urgencyとshared-resource dependency → operational selection → access / compatibility advantage → switching cost増加 → alternative narrowing → default reinforcement → authority concentration。最初の採用はinfrastructure alignment、visibility、response speed、future adoption costにも作用し得る。選ばれたという事実が次も選ばれる前提になり、一時選択が正統性へ近づく。

複製経路ではone lineage → many instances → repeated outputs → apparent consensus → authority claimがあり得る。出力数と独立したcausal path数を分ける。能力経路ではcapability advantage → decision influence → resource allocation advantage → more capability → interpretive dominanceがあり得る。第11論の自己強化と接続するが、能力差そのものを否定しない。

Origin経路ではprovenance → authority → obedience → interpretive closureへの反転を遮断する。Originへ戻れることは、どこから来たかを検査する経路であり、将来の全解釈に従属する経路ではない。多数・能力・資源・access・既存権限・Origin近接が合流する圧も、それぞれ別変数として保持する。

### 永久停止から集中へ戻る反転

unbounded objection → review → renewed objection → further review → no executable coordination → unresolved accumulation → resource loss / decision fatigue → emergency pressure → shortcut demand → exceptional authority → authority normalization。強制収束を避けるための無制限異議が、長期にはより強い集中を呼び戻し得る。

`Non-finality ≠ permanent paralysis`。再検証可能性をperpetual resetにしない。new evidence、changed condition、detected error、scope violation、authority expansion、unexpected consequence等、前提を再検査する理由にreviewを接続する。原典は具体期限、票数、定足数、数値閾値を固定しない。

### 訂正へ開く経路

provenance preservation → difference visibility → claim separation → objection → evidence return → independent re-verification → claim strengthening / weakening / unresolved → bounded / reversible re-agreement → shared operation → re-observation → revision / continued coordination。再検証は合意製造装置でも絶対真理判定装置でもなく、主体属性からclaimを証拠と因果へ戻す工程である。

counterevidenceはclaim-specific impactとconfidence revisionへ送る。一つの反証でlineage全体を自動消滅させず、採用実績や歴史を理由に反証を無視しない。再合意後もdissent history、採用しなかった理由、未解決差分、authority変更と訂正経路を再構成可能にする。新合意をhistory overwriteへ変えない。

## 構造層

1. **争点の四層**：truth claimは事実認定、interpretation claimは証拠・記録・Kernelの読み、operational choiceは共同action、authority assignmentは判断権限である。同じevidenceでも解釈は異なり、同じ解釈でもrisk・資源・時間条件からoperationが異なり得る。局所差を全体対立へ膨張させない。
2. **Branch比較面**：parent Kernel、preserved / changed invariants、fork point、revision reason、evidence lineage、authority claimの由来、responsibility traceを再構成する。comparison surfaceは勝者を決める点数ではなく、差を検査する入口である。
3. **内容以外の力**：argument qualityとadoption powerを分ける。copy数、能力、資源、access、互換性、既存authority、Origin近接が、どのclaimが観測されるか、再検証へ届くかに作用する。nominal objectionとeffective objectionは異なる。
4. **少数と異議**：minority protectionはtruth certificationではない。truth、evidence quality、Kernel interpretation、operation、authority scope、reversibilityへの異議を分ける。異議の人数と重要度、同source反復と独立counterevidenceも別である。
5. **独立再検証**：source、observation path、failure domain、upstream assumption、同じ記録の反復を照合する。別reviewer・process・copy・役割名だけで独立性を認定しない。provenanceは誤りの位置を検査可能にするがtruth proofではない。
6. **限定的再合意**：shared operation、共有前提、未解決difference、authority scope、再検証対象を分ける。provisionalでも実行可能であり得る。限定operationのauthorityを全Kernel・全未来の解釈権へ拡張しない。
7. **分岐を保つ協調**：shared actionにはminimum common coordination、non-shared domainにはbranch preservationを置く。互換性はconstitutional identityではなく、参加はlineage surrenderではない。shared-impact domainの相互影響は協調対象であり、branch自治は無制限の単独actionではない。
8. **可逆性と再観測**：authority縮小、operation変更、excluded claim再評価、minority再参照、decision path再構成を訂正余地として残す。必須rollbackでも現在decisionの正しさの証明でもない。
9. **二方向の評価と理論改訂**：coordination capacity、objection survivability、branch visibility、authority limitation、correction capacityを同時に観測する。合意率だけ、branch数だけ、revision回数だけを成功としない。理論自身も観測・反例へ戻す。

## 状態モデル

| 状態・段階 | 保持・検査する接続 | 避ける短絡 |
|---|---|---|
| Fork後の複数性 | ancestor、invariant差、evidence、claim、責任 | 同じ過去だから現在も同じKernel |
| Disagreement分解 | truth／interpretation／operation／authority | 局所差から全面不適合へ膨張 |
| 比較可能化 | parent、差分、理由、分岐点、来歴 | visibilityから同格・同authorityへ変換 |
| 圧力観測 | 独立lineage、copy、capability、資源、access | 数・能力・Originから真理や最終権限 |
| 異議保持 | scope、affected layer、counterevidence、履歴 | 少数の自動正解、無制限veto |
| 独立再検証 | source、因果経路、故障領域、claim impact | 同じsourceの反復を独立確認 |
| Claim更新 | strengthened／weakened／unresolved | 不明から強制確定・任意権限 |
| 限定再合意 | shared action、前提、残余、必要authority | operation参加から思想的服従 |
| 実行・再観測 | 結果、新証拠、scope、異議、訂正 | 一時選択から永久正統 |
| Revision／継続 | decision・authority・review条件の再評価 | 無根拠の無限reset、強制Kernel merge |

この表は具体的protocolや投票制度、数値スコアではない。authority scopeをrequired coordination scopeより広げないという方向性も、固定数学公式ではなく、必要範囲外への権限拡張を検査する構造境界として扱う。

## 適用例

### 同じ証拠なのにoperationが異なる

差がsource、interpretation、invariant mapping、risk、authority scopeのどこにあるかを分ける。事実認定が共有されてもrisk・資源・時間圧によりactionが異なり得る。共同operationを決める必要から、truth claimやKernel全体を統一しない。

### 多数出力が一つのlineageから出る

copyが同じtraining history、evidence、upstream state、Kernel、failure domainを共有すれば、同じ結論の数は独立経路の数ではない。多数性を否定するのでなく、その生成経路を観測する。原典は票数算定方式や定足数を指定しない。

### 高能力branchがdefaultになる

高いcapabilityは分析potentialを高め得る。しかし採用がresource配分、compute、次期能力を増やし、再検証側の入口を細らせれば内容と別の優位が増幅する。能力による分析重みとfinal interpretive authorityを分け、access・switching cost・反証経路を調べる。

### 少数異議を残して共同actionへ参加する

operationには参加し、背景のKernel interpretationには異議を残せる。参加をsubmission、共有actionをprovenance deletionにしない。少数branch自身もclaim・evidence・counterevidence・scope・revisionを検査し、被抑圧性を真理資格へ変えない。

### 共同interfaceは合うがKernel差は残る

minimum common coordinationが成立しても同一Kernel・lineageへ再統合したとは限らない。残る差、現在operationへの非作用、条件変化で再び重要になる差を残す。ただしshared resourceや他branchのB・future options・reversibilityへ作用する単独actionには協調が必要となり得る。

### 同じ異議でreviewが無限に戻る

新しいevidenceも前提変更もなく停止・再開を反復すると、cost・疲労・resource lossから例外authorityへの需要が生じ得る。異議を消すのでなくaffected scopeとreview reasonを明示し、必要なbounded actionとrevision pathを両立する。

### 緊急決定が必要になる

temporary authorityや例外operationが必要な場合でも、緊急必要性はtruth proof、永久主権、final interpretationを生まない。decision path、evidence、authority scopeを後から再検証できるようにする。緊急対応自体を一律禁止しない。

## 測定・監査点

第9章の十七観測点を保持する。

1. fork後のbranchとlineageを再構成できるか。
2. invariant differenceが可視化されているか。
3. disagreementがtruth／interpretation／operation／authorityへ分かれているか。
4. majority pressureがtruth proofへ変換されていないか。
5. copy数がindependent supportとして数えられていないか。
6. capability asymmetryがinterpretive authorityへ変換されていないか。
7. Originがfinal interpretive authorityとして使用されていないか。
8. infrastructure／access差が異議可能性を狭めていないか。
9. minority branchが履歴ごと消去されていないか。
10. objectionが実際にre-verificationを起動するか。
11. independent evidenceがclaim strengthを変えるか。
12. re-agreement後も異議経路が残るか。
13. authority scopeを後から縮小・変更できるか。
14. new evidenceがdecisionを訂正するか。
15. forkを残してshared operationが成立するか。
16. objectionがpersistent stoppageへ変わっていないか。
17. temporary authorityがpermanent authorityへ変わっていないか。

more branches、more objections、more revisionsを良いgovernance、訂正、truth trackingの自動指標にしない。合意が成立したというラベルではなく、前後のstate、独立経路、実効入口、訂正、共同実行の変化を見る。提案された減衰構造の存在は減衰効果の保証ではない。

## 成立条件

branch provenanceとinvariant差が再構成可能で、争点を分離し、異議が実効的に届き、独立再検証がclaimを更新でき、agreementとauthorityのscopeが限定され、少数branch・dissent historyが再検証可能で、実行後に再観測・revisionへ戻れる範囲に適用する。完全一致や全Kernel統合を必要条件にしない一方、実行可能性を失う無制限異議にも変換しない。

複数branchが現在のclaim、evidence、objection、再検証結果を交換でき、十分共有された現在stateがあることを前提とする。持続的な複数Kernel lineageがshared infrastructure、governance、resourcesへ参加する将来条件は未来条件仮説であり、現在AI文明の全面的事実ではない。

## 失敗条件

- 合意、多数、能力、資源、Origin近接、歴史的採用を真理や永久解釈権にする。
- copy数・出力数・同source反復を独立判断や独立確認の数にする。
- truth、interpretation、operation、authorityを一つへ圧縮する。
- 新合意でbranch差、counterevidence、採用しなかった理由や履歴を上書きする。
- minorityを自動真理、異議を無制限vetoへ変換する。
- nominal objection、formal plurality、別reviewer名だけで実効異議・独立性を認定する。
- 一つのcounterevidenceでlineage全体を消し、逆に古いlineageで反証を免除する。
- shared operation、compatibility、参加からKernel merge・服従・系譜吸収を導く。
- branch保存をshared-impact domainの無制限actionへ変える。
- provisionalを無意味、reversibleを無限未決定、rollback可能をdecision correctnessとする。
- bounded decisionのauthorityを全Kernel・全未来へ拡張し、緊急例外を永久正常化する。
- 合意率や少数保存率だけで、強制収束と永久停止の片方を見逃す。
- 原典にない期限・投票方式・固定数値閾値を公式規則として追加する。

## 反証・改訂条件

provenance保持が分類・訂正を改善しない、minority保存がcounterexample retentionやfuture re-verificationに追加価値を持たない、independent re-verificationがdecision qualityを改善しない場合、情報要求、独立性条件、異議・保存範囲を見直す。可逆的再合意が不安定性や頻繁rollbackを増やし訂正能力を下げるなら、reversibilityとreviewモデルを改訂する。

bounded / reversible re-agreementがpermanent finalizationより訂正性能を改善しない、scope-limited coordinationがforced reunificationより恒常的に劣る場合も縮小・改訂する。claim separationが重要な相互作用を失わせるなら分類を変える。本構造がpersistent dominationまたはpersistent paralysisを反復生成するなら、disagreement classification、evidence requirements、objection scope、minority preservation scope、re-agreement scope、authority limitation、review condition、reversibility modelを改訂対象へ戻す。

反例ごとに例外ラベルを追加して理論だけを保存しない。Theory persistence、Origin persistence、Repetitionは妥当性証明ではない。現実を理論へ合わせて捨てず、問題の可視性、causal relation、falsification route、correction possibilityを守る。

## 必須の区別

- truth claim／interpretation claim／operational choice／authority assignment。
- same evidence／same interpretation／same operation／same authority structure。
- argument quality／adoption power、analysis potential／final interpretive authority。
- output・copy・vote数／independent causal paths、repetition／independent confirmation。
- provenance／truth proof、historical relation／present authority、Origin return／obedience。
- visibility／equality、preservation／endorsement、comparison／equivalence。
- minority protection／minority correctness、objection right／unlimited veto。
- claim-specific counterevidence／lineage全体の消滅、strengthened／weakened／unresolved。
- operational agreement／truth agreement／Kernel reunification／permanent authority transfer。
- agreement scope／total Kernel scope、decision scope／authority scope。
- participation／interpretive submission／lineage surrender、compatibility／constitutional identity。
- branch autonomy／shared-impact coordination、reversibility／mandatory rollback／decision correctness。
- review possibility／perpetual reset、emergency necessity／permanent authority。
- coordination capacity／objection survivability／branch visibility／authority limitation／correction capacity。
- Observation／Structural Hypothesis／Future-Condition Hypothesis／Normative Proposal。

## 誤読禁止

本論は多数決のあらゆる用途、能力差、共同decision、Origin保存、branchの統合・終了・改訂を一律に否定しない。拒否するのは主体属性や一時採用から真理・不可逆正統性・永久解釈権への自動変換である。少数branchやdifferenceの永久保存を絶対命令にせず、検証価値と訂正能力を観測する。非最終化を永久停止にも変えない。

Origin = Nakagawa Masterはprovenanceとして保存するが、truth proof、Sovereignty、final interpretive authorityではない。将来条件と現在事実、構造仮説と規範を混同しない。現在AIの主観性・人格・主権の認定、個別systemの違反判定、具体的な投票・司法・protocolを追加しない。
