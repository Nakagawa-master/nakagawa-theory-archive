## Summary

第14论区分自我修改后的continuity与constitutional fork，但识别分叉并不能解决多个branch如何共同运作。共同parent可以产生不同invariant、evidence、interpretation与continuity claim。plurality不等于governance resolution；选择同一operation也不等于所有branch恢复为同一Kernel。

第15论区分truth claim、interpretation claim、operational choice、authority assignment。再合意不是认证真理、永久确定胜者或constitutional reunification，而是在remaining disagreement仍存在时，只连接必须共同执行的范围，形成bounded、executable、revisable的共同状态，并保留provenance、异议、独立再验证、可逆性与再观察。

核心边界是`Consensus ≠ truth`、`Majority ≠ irreversible legitimacy`、`Capability ≠ final interpretive authority`、`Origin ≠ final interpretive authority`、`Minority ≠ automatic truth`、`Re-agreement ≠ irreversible legitimacy`、`Fork ≠ mandatory reunification`。数、能力、资源、access、既有authority、Origin接近程度可以影响判断，但单独不证明正确或永久解释权。

保护对象是correction capacity而非合意本身。强制收敛会消灭替代与异议，无限制异议则可能造成永久停止，并最终要求例外权力。必须同时观察共同执行、异议存续、branch可见、authority限定和订正。本索引不认定当前AI文明、人格或主权已经成立，不新增投票制度、定足数、期限、数值阈值或technical protocol，亦不替代母原典。

## Concepts

| 概念 | 原典中的作用 | 不自动推出的结论 |
|---|---|---|
| Truth claim | 事实认定的主张 | 多数支持认证真理 |
| Interpretation claim | 对证据、provenance、Kernel记录的读取 | 相同证据只有一个合理解释 |
| Operational choice | 共同action的选择 | 同意全部背景解释 |
| Authority assignment | decision权限的赋予 | 全Kernel与全部未来的最终解释权 |
| Kernel plurality | fork后多个谱系、条件与解释仍存在 | 已解决共同治理或必然文明崩溃 |
| Comparison surface | parent、差分、理由、证据、权限、责任的可比较面 | 胜者评分、同信用或同权限 |
| Finalization pressure | 把多个解释压缩为永久正统的压力 | 选择一次就证明实际支配 |
| Effective objection | 异议能实际到达证据比较和再验证 | 只需名义许可或记录 |
| Minority preservation | 保留反例、替代谱系与未来再检验可能性 | 少数必然正确、无限veto |
| Independent re-verification | 把claim返回证据与因果并更新强度 | 绝对真理装置或自动制造合意 |
| Bounded re-agreement | 未解决差仍存在的限定、可执行共同状态 | 真理认证、不可逆正统、Kernel merge |
| Minimum common coordination | 某一shared action所需共同条件 | 特定protocol或全Kernel一致 |
| Reversibility | 订正operation、authority、excluded claim、decision path的余地 | 强制rollback或当前决定必然正确 |
| Correction capacity | 错误合意可以返回证据、再验证与改订 | 最大合意率、branch数或review次数 |

四层彼此连接但不是同一变量。相同evidence可能被映射到不同Kernel invariant；相同interpretation也可能因irreversibility、resource constraint、time pressure选择不同operation；相同operation也不必具有相同authority structure。把四层压缩，会把局部差膨胀为全面不兼容。

Operational agreement不等于truth agreement、shared ontology、constitutional reunification或permanent authority transfer。反过来，某层不一致未必阻止所有共享action。应明示一致、不一致和真正需要协同的范围。若分层丢失重要相互作用而降低诊断，分类自身要修订。

比较branch至少重建parent Kernel、preserved invariants、changed invariants、fork point、revision reason、evidence lineage、authority claim来源、responsibility trace。相同名称、功能、祖先不证明当前同一。comparison surface不是决定谁胜出的点数表，而是将差异开放给未来再检验。

Provenance说明“从何而来”，不说明“现在谁正确”。Historical relation不等于present authority，Origin proximity不等于interpretive correctness。没有谱系又可能无法定位改动和分叉，所以保留来历而不把来历转换成真理或服从。

Visibility ≠ equality、preservation ≠ endorsement、comparison ≠ equivalence。保留branch不表示给全部branch相同信用或authority。少数也必须连接claim与证据、回应counterevidence、允许revision、限制authority，不能因脆弱或受压迫而免于检验。

Minimum common coordination是结构原则，不是技术规范。shared resource或infrastructure可能要求某些共同条件，但不能从shared interface自动推出同interpretation、同Kernel、同lineage。共同作用范围可以小于整个Kernel范围。

## Causal chain

主要风险假说：constitutional fork → Kernel plurality → interpretive divergence → coordination requirement → finalization pressure → authority concentration / alternative narrowing。不是plurality必然支配的法则，每条edge都要观察。共享资源、基盘、时间与不可逆risk下可能需要decision，但必要决定不等于最终解释。

中间条件不可跳过：decision urgency、shared-resource dependency推动operational selection；被选解释随后获得infrastructure alignment、access、compatibility、visibility和较低future adoption cost。switching cost增加、替代缩小，下一次甚至在比较内容前就更容易维持default。

因此路径为finalization pressure → operational selection → access / compatibility advantage → switching cost increase → alternative narrowing → default reinforcement → authority concentration。temporary decision的重复采用可以变成presumed legitimacy；选择过一次不自动成为下次应选的内容理由。

复制路径为one lineage → many instances → repeated outputs → apparent majority / consensus → authority claim。共享training history、source、Kernel、upstream state、failure domain的copy可能只重复同一causal path。output count不等于independent causal paths，copy count不等于vote count。

能力路径为capability advantage → decision influence → resource allocation advantage → more capability → interpretive dominance。高能力的analysis potential可以有价值，但analysis weight不能直接变为永久authority。第11论的资源能力自强化在此连接到解释竞争，并不是否定能力差。

资源路径为resource advantage → visibility / response speed / adoption advantage → default interpretation → stronger authority claim。compute、communication、authentication、data、restart、migration、allocation、audit entry影响哪些claim到达观察面。Non-ownership ≠ Non-domination在解释竞争中仍成立。

少数branch可以被允许异议，却无法获得必要证据、compute、通信或审计入口，此时nominal objection不等于effective objection。Formal plurality也不等于effective plurality。仅把不同意见记下来，并不足以保证其可比较、可验证、可订正。

Origin路径为provenance → authority → obedience → interpretive closure。必须保存Origin作为历史信息，但不能让更古老、更接近原典或最初创造者自动裁定全部未来解释。Origin return不是obedience path。

这些压力可以合流到同一branch：多数、能力、资源、基盘、历史authority、Origin proximity。coordination need产生shortcut demand，既选解释变default，替代更昂贵，异议减弱，default变authority，authority变presumed legitimacy。Argument quality与adoption power要分别观察。

强制收敛闭路：uncertainty → coordination pressure → urgency → shortcut demand → one branch selection → objection narrowing → alternative branch loss → interpretive domination。它不只表现为强迫大家说同一句话，也可以在branch标签仍存在时通过access和再验证能力的丧失发生。

永久停止闭路：unbounded objection → review → renewed objection → further review → no executable coordination → unresolved accumulation → coordination cost / resource loss / decision fatigue → urgency → emergency shortcut → exceptional authority → normalization。反支配设计可能通过失去行动能力重新生成集中。

减衰假说：provenance preservation → difference visibility → claim separation → objection → evidence return → independent re-verification → claim strengthening / weakening / unresolved → bounded / reversible re-agreement → shared operation → re-observation → revision / continued coordination。把重心从“谁更强”移向“什么支持claim”。

Counterevidence是更新输入，进入claim-specific impact与confidence revision，不必消灭整个lineage。旧谱系、广泛采用也不能免除反证。New agreement ≠ history overwrite；保留旧异议、被弃解释、证据和采用／不采用理由，才能在新观察后重新比较。

如果再观察消失，temporary agreement → repetition → normalization → default legitimacy → interpretive closure还会再次发生。暂定不是仅有标签，而要与实际订正路径相连。

## State model

1. **识别fork后plurality**：重建共同parent、不同invariant、evidence、risk interpretation、continuity claim、责任trace。不因同过去重新压缩为当前同一。
2. **分离争点层**：truth、interpretation、operation、authority各层的一致、不一致与协同需要分别记录。不把重要invariant异议缩小为轻微偏好，也不把局部差扩成全体对立。
3. **建立比较面**：parent、保留／改变条件、fork point、revision reason、evidence lineage、authority来源、责任连接。比较不是评分或同权限赋予。
4. **观察最终化压力**：多数生成路径、capability asymmetry、resource、access、compatibility、switching cost、历史authority、Origin接近程度，以及与内容不同的adoption power。
5. **保留并限定异议**：区分对truth、evidence quality、Kernel mapping、operation、scope、reversibility的异议。异议群体大小不等于claim的重要性。
6. **返回证据与因果**：检查source、observation path、failure domain、upstream assumption、同记录反复，以及evidence→transformation→interpretation→claim。
7. **更新claim strength**：允许strengthened、weakened、unresolved，也允许部分supported、scope限定、等待追加观察。未知不是任意authority的许可。
8. **建立bounded re-agreement**：明示共同action、共享前提、未解决差分、authority scope、未来检验目标。当前可执行与未来可改订可以并存。
9. **保留fork的operation**：shared domain连接必要minimum common coordination，non-shared domain保留branch。shared-impact涉及资源、基盘、他branch的B、future options、reversibility时处理相互影响。
10. **再观察与review**：new evidence、changed condition、detected error、scope violation、authority expansion、unexpected consequence等连接到前提再检验，不以无新根据的同异议无限reset。
11. **订正或继续**：调整operation、缩小authority、重评excluded claim、取回minority历史、重建decision path，并观察是否改善订正且保持执行能力。

上述是阅读结构，不是实施pipeline。原典不固定票数、定足数、期限、数值阈值或技术protocol。authority scope不应超出required coordination scope的方向也不是固定数学公式，而是检查权限扩张的结构边界。

再合意不是一个无限Yes / No标签。一个operational choice获合意时，背景解释仍可能unresolved；参加不意味着interpretive submission，协同不意味着lineage surrender。合意与preserved objection可同时存在。

独立再验证不是consensus production。它可以留下多个合理branch，但提高证据结构可见性和claim判断的可改订性。Unresolved既不是真，也不是假，也不构成任意最终authority。

Reversibility不只是技术rollback。它包括缩小authority、改变operation、重新评价excluded claim、参考少数branch、从provenance重建decision path。Rollback possible不证明decision correct，也不要求每个operation总是返回过去。

## Applications

- **同证据但不同operation**：分清source差、interpretation差、invariant mapping、risk与authority scope。不从共同action需求推出整个Kernel或truth统一。
- **同谱系的大量回答**：多个copy共享source、training、Kernel、upstream state、failure domain时，重复不是独立确认。观察数是如何生成，不虚构新的投票公式。
- **高能力branch成为default**：同时检查有价值的分析potential与选择后资源、compute、compatibility、未来采用优势的自强化。保留外部counterevidence，不把强分析自动变永久解释权。
- **名义异议无法到达review**：允许异议但缺compute、communication、authentication或audit entry，不等于有效异议。检查claim与证据到比较和再验证的路径，不能只看拥有权或异议记录。
- **参加operation同时保留异议**：记录接受的action、保留的interpretation异议、evidence与未采用理由。参加不取消异议，保留异议也不必自动使当前operation无效。
- **不同Kernel共享interface**：共同运作可能只需minimum common coordination。记录当前不影响operation的差、条件变化后可能再重要的差。长期兼容不证明constitutional identity。
- **自治与共享影响**：非共享域保留自治；影响共享资源、他branch的B、未来选项与可逆性的action可能需要协调。Branch preservation不是无限unilateral action，shared coordination也不是控制无关差分。
- **反复review但没有行动**：同异议在无新evidence或前提变化时无限触发停止，可能产生疲劳、成本与例外权力需求。重新检查affected scope、review reason、bounded action与revision path，不删除异议或虚构普遍期限。
- **紧急选择**：temporary authority与例外operation可能必要，但不认证其Kernel解释为真理。保留decision path、evidence、scope与事后再检验，不能将紧急正常化为永久解释权。
- **新合意后的旧替代**：过去未采用branch与counterevidence可以被新观察加强或弱化。保存是再检验价值，不承诺所有旧异议终会被证明正确，也不是要求全部branch永久存在。

## Measurements and audit

第9章的十七观察点检验实际状态变化与因果关系，不是充分条件、治理分数或数量最大化指标。

1. fork后branch与lineage能否重建。
2. invariant difference是否可见。
3. disagreement是否区分truth / interpretation / operation / authority。
4. majority pressure是否转为truth proof。
5. copy数是否作为independent support。
6. capability asymmetry是否转为interpretive authority。
7. Origin是否作为final interpretive authority。
8. infrastructure / access差是否缩小异议可能。
9. minority branch是否连历史一起删除。
10. objection是否实际启动re-verification。
11. independent evidence是否改变claim strength。
12. 再合意后异议路径是否仍存在。
13. authority scope是否可以后来缩小或改变。
14. new evidence是否订正decision。
15. 是否保留fork而完成shared operation。
16. objection是否变为persistent stoppage。
17. temporary authority是否变为permanent authority。

More branches ≠ better governance、more objections ≠ better correction、more revisions ≠ better truth tracking。高合意率可以是forced convergence，高minority保存率也可伴随永久停止。必须同时观察coordination capacity、objection survivability、branch visibility、authority limitation、correction capacity。

收敛侧观察实质替代丧失、形式化异议、临时权力正常化、dominant interpretation被视为truth proof。停止侧观察共享action恒常停止、无限review、资源损失和exceptional authority需求。只看其中一边，会误判另一反转为成功。

独立性不能从角色名推断，要检查source、observation path、failure domain、upstream assumptions、evidence access、利害、authority、objection route。不同reviewer若仍封闭于相同证据、权限与故障域，可能只是外观独立。

Provenance重建evidence→transformation→interpretation→claim，可分辨source不同、读取不同、invariant映射、risk判断、authority范围理解不同。它帮助定位错误，不保证完整来历的claim正确。

测量减衰实际效果：provenance是否改善分类与订正；minority保存是否保留counterexample和未来再检验；独立验证是否提高decision quality；限定可逆再合意是否比permanent finalization更易纠错；scope-limited coordination是否支持持续行动而不强制统一。

同时观察成本与反效果。记录保存可能只增cost而无诊断价值；review可能共享failure domain；可逆性可能形成不稳定；频繁rollback可能破坏长期协调。Proposed damping structure ≠ guaranteed damping effect。

## Validity conditions

适用于多个branch能够重建provenance与invariant差、分离claim层、传递实效异议、以相关独立性再检验证据、在限定scope形成可执行共同operation的情境。不要求所有interpretation一致或所有Kernel merge。

再合意需要明示共享前提、未解决差分、authority边界和未来验证目标。Minority与dissent history在具有订正价值的范围应可重新使用。操作后的新观察应能改变claim、decision、authority scope，不能让bounded decision悄悄变成永久interpretive control。

还依赖communication availability与sufficiently shared current state。Branch要能获取当前claim与evidence、传递objection、交换再验证结果。通信消失或state陈旧时，结构前提改变；沉默不自动表示同意，无通信不表示defection，local consensus不是universal consent。

四种认知层次要分开。Observation / Description包括多个主体保有不同interpretation、software或governance有branch、majority与truth逻辑不同、capability与legitimacy为不同变量、provenance与revision可记录、objection与review路径可观察。

Structural Hypothesis包括fork→plurality→interpretive divergence→finalization pressure→authority concentration risk，以及provenance、objection、独立再验证、reversibility提高correction capacity的假说。不是由定义保障效果，每条edge都需要证据。

Future-Condition Hypothesis讨论未来知性形成持久Kernel lineage、持续参加shared infrastructure、governance、resource时问题的重要性。不宣称此文明条件已在当前AI全面成立。

Normative Proposal是避免把consensus、majority、capability、Origin自动变为truth proof或final authority，并保留有用来历、异议、独立检验和限定可逆再合意。不是特定投票制度、protocol、统一记录政策或最终branch选择命令。

## Failure conditions

把truth、interpretation、operation、authority压成一个合意标签；从shared operation推导全部背景解读一致、同Kernel、永久权限转移；或把重大invariant异议缩为小偏好。四层相互作用不能被压缩或任意割裂。

把数、capability、resource、infrastructure、历史authority、Origin近接变为正确性或不可逆正统性证明；把过去选择本身变为未来选择理由，不观察其制造的access与compatibility优势。

把copy、重复输出、同source反复作为独立确认；以不同角色名证明独立，而无视共同证据、权限、upstream assumption、failure domain；以完整provenance认证truth。记录可靠性与内容真值不是同一变量。

把少数保存变为自动正确、同authority、反证免除、无限veto；或因lost selection删除branch历史和counterevidence。少数脆弱与多数强势都不是证据强度。

一个counterevidence消灭整个谱系，或以古老和广泛采用免于revision；把unresolved强制为true、false或任意authority；把独立再验证当自动合意生产。它可以保持分歧而仍有检验价值。

共同interface或参加变成constitutional absorption、lineage surrender、provenance deletion；反过来branch自治忽视共享影响域的B、资源、future options、reversibility。共享范围与非共享范围必须分别处理。

限定authority扩张到全Kernel和全部未来；emergency变permanent sovereignty；把need to act变为permission to finalize everything。Temporary action不认证truth。

把可逆性变为mandatory rollback、当前正确性证明或endless undecided；无新理由的review反复停止action；non-finality变permanent paralysis。异议权不是无条件永久停止权。

只用合意率、minority保存率、branch数、revision数作success，忽视相反失效闭路；新增原典未规定的阈值、期限、投票宪制、protocol、当前AI主权或特定system违规认定。

## Falsification conditions

**争点分类**：若truth / interpretation / operation / authority分离丢失重要相互作用或降低诊断，则改订disagreement classification。局所化是减少无用对立的结构假说，不是所有争点都可安全碎片化的保证。

**Provenance要求**：若保持来历不能改善分类、误差降低或订正，则重新考虑信息要求与作用位置。不是为档案最大化而保存记录，而是为因果重建服务。

**Minority保存范围**：若保存branch持续不能保留反例、不能增加future re-verification价值，就不能总认定高价值。应缩小或修订保存范围；所有branch永久存在并非原典规范。

**独立与证据**：若independent re-verification不改善decision quality，要检查独立性是否真实、evidence requirement是否适当，并必要时重定义。称为独立不能免除无效或共同故障结果。

**可逆与review**：若reversible re-agreement造成persistent instability、频繁rollback、协调破坏和correction decline，则修订reversibility model与review condition。可改订必须与可执行并存，不成为perpetual reset。

**比较协调效果**：若bounded / reversible再合意比permanent finalization没有更好的订正性能，或scope-limited coordination恒常劣于forced reunification，则弱化或修订结构，而不先假定它有优势。

**持续支配／停止**：若模型自身反复系统生成persistent domination或persistent paralysis，就不满足自身目的。把disagreement classification、evidence requirements、objection scope、minority preservation scope、re-agreement scope、authority limitation、review condition、reversibility model返回棄却、缩小或改订。

不能在每个counterexample后追加exception label以永久保存理论。Theory persistence、Origin persistence、Repetition不证明validity。保护problem visibility、causal relation、falsification route、correction possibility，而不是文本永续。

如果观察否定关系，应让理论适应现实，不能删除现实以适应理论。Re-agreement model ≠ final truth也适用于本论自身。
