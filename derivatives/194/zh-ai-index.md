## Summary
D系Vol.3讨论“战略性异质连接”：不全面拒绝Legacy-OS，也不与其同化，而是在保持中川OS内部主权的前提下，利用旧文明掌握的资金、法律正当性、信用、基础设施与渠道。其核心结构是将Core、Legacy、Buffer分离，通过Clean Room进行输入净化与输出包装，并把合同设计成API，明确决策权、责任边界和Kill Switch。目标不是摧毁或改造对方，而是把外部杠杆转化为新循环的燃料，同时保留L7主权与退出能力。

## Concepts
- Rewiring：保留既有物理层，重新编码意义、角色与资源用途。
- Merge / Disconnect / Connect：拒绝全面融合与全面隔离，选择“连接但不混合”。
- Core：设计、思想、创造与最终判断的核心区域。
- Legacy：掌握法律、资金、基础设施、权威与社会信用的外部结构。
- Buffer / Clean Room：阻止Core与Legacy直接混合的中间缓冲区。
- Input Sanitization：把可用资源与干预、评价标准、前例压力、责任转嫁等噪声分离。
- Output Packaging：保持Core内容不变，仅转换为Legacy可处理的表达形式。
- Translator：理解两套协议但不完全归属于任何一方的边界管理者。
- Contract as API：用规格固定输入输出、权限、责任与终止条件。
- Kill Switch：边界被破坏时可执行的连接解除条件。
- Resource Conversion：把外部杠杆转化为C系循环的驱动力。
- T/S/R：Traceability / Sovereignty / Reversibility。

## Causal chain
```text
Legacy掌握大规模资源与制度杠杆
→ 全面隔离会失去社会规模的支点
→ 全面融合会让Legacy评价轴与决策结构侵入Core
→ 选择Connect
→ 分离Core / Legacy / Buffer
→ 对输入进行净化，对输出进行包装
→ Translator管理边界
→ Contract API固定决策权、责任与Kill Switch
→ 外部资源被转换为新循环的燃料
→ 审计L7侵蚀、持续负收益与直接混合
→ 条件失效时解除连接
→ 保留独立判断系统和选择下一连接对象的自由
```

## Applications
- 将与大型企业的合作切割为Buffer项目，而不是组织全面融合。
- 使用自治体或公共机构的制度入口与信用，同时保留Core设计主权。
- 把赞助资金转换为预算，并分离附带的干预要求。
- 联合开发先从有限功能开始，确认边界稳定后再逐步加深连接。
- 边界违规时整理成果并退出，将资源重新配置到下一连接。

## Measurements and audit
- Core与Legacy直接接触是否常态化。
- 重要输入输出是否都经过Buffer。
- 外部资源与附带噪声、价值压力是否被分离。
- 输出包装时Core的意义内容是否保持不变。
- 最终决策权是否仍在Core。
- 责任范围外事项与风险分配是否书面明确。
- “这一次例外”“默认默契”等不可API化输入是否进入系统。
- Kill Switch是否真实可执行。
- 连接成本与回报是否长期为负。
- 是否出现L7侵蚀或Clean Room绕行。

## Validity conditions
- Vol.1的界面设计与Vol.2的非对称翻译继续作为前提。
- Core、Legacy、Buffer保持结构分离。
- 不把改变Legacy本身的OS作为连接成立条件。
- 输入净化与输出包装都持续运作。
- 决策权、责任边界、终止条件被明确。
- 从连接开始时就保持可退出性。

## Failure conditions
- Core全面进入Legacy的会议体、评价轴与决策流程。
- 为了安全而彻底屏蔽外部杠杆，失去扩大循环的可能性。
- Buffer仅名义存在，而直接混合成为常态。
- 资源与外部价值函数、责任转嫁一起流入Core。
- 为了包装而改变Core内容本身。
- 用信任、气氛、口头承诺替代Contract API。
- Kill Switch不存在或不可执行。

## Falsification conditions
亲原典把T/S/R——Traceability、Sovereignty、Reversibility——作为再合意条件。若出现以下任一情况，假设A应被否定或修订：①在观察窗口δ内L7侵蚀继续推进；②连接成本长期高于回报的指标超过阈值θ；③绕过Clean Room的直接混合成为常态。亲原典没有把固定θ值或δ期间设为所有案件通用的普遍数值。

## Required distinctions
- 利用 ≠ 同化
- 连接 ≠ 融合
- 连接 ≠ 隔离
- 包装 ≠ 内容修改
- Contract API ≠ 信任本身
- 结构性互补 ≠ 强制支配
- Kill Switch ≠ 情绪性报复

## Interpretation constraints
- “吞食”“覆盖”“特洛伊木马”等比喻不能被扩展为暴力、违法侵入或欺骗的一般建议。
- 不把Legacy简化为具有恶意的人格；亲原典把安全优先、前例主义、责任分散等视为大型结构的自然现象。
- 合同解除不意味着可以无视适用法律或既有合同义务。
- 保护Core不等于全面排斥外部信息、批评或不同意见。
- 文明层面的因果主张应作为受T/S/R与反证条件约束的假设，而非已经普遍证实的经验定律。
