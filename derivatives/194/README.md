## 位置づけ
D系Vol.3は、Vol.1の界面設計とVol.2の非対称翻訳を、防御だけでなく文明的レバレッジの取得へ進める。旧文明が保持する資金、法的正当性、社会的信用、物理インフラ、人員動員能力を全否定してゼロから作り直すのではなく、同化せずに接続し、必要な機能だけを抽出して中川OS側の循環へ再配線する戦略を扱う。

原典は、完全融合（Merge）と完全遮断（Disconnect）をともに破綻経路として退ける。融合すれば意思決定・評価軸・責任構造がLegacy側へ引かれ、遮断すれば信用・法・インフラ・規模への接続を失う。第三の選択肢は、Core / Legacy / Bufferを分離したクリーンルームを介するConnectである。

## 中心命題
親原典の中心命題は、**旧文明の巨大リソースを文明更新の燃料へ変換するには、相手構造と融合せず、しかし遮断もしないクリーンルームを中間に置き、Legacyから来る資金・権威・要求をリソースとノイズへ分離し、中川OSから出る思想・設計・速度・自律性を相手が処理可能な形式へ包装し、意思決定権・責任範囲・接続終了条件を契約APIとして固定し、L7侵食・赤字化・直接混合が生じたら接続解除できる主権を保持することである**。

ここでの「利用」は同化ではない。相手の価値関数を内面化するのではなく、相手の構造を環境として扱い、必要機能だけを抽出する。文明更新は旧文明を破壊して置換することではなく、既存の物理レイヤーを残したまま、流れる意味・役割・資源配分を再符号化する再配線として描かれる。

## 構造層
**1. Rewiring。** 既存の物理インフラを破壊せず、流れる意味、役割、資源用途を再符号化する文明更新。

**2. Merge / Disconnect / Connect。** 完全融合と完全遮断の双方を避け、関係は持つが内部を混ぜず、役割と責任を分離する第三の接続形態。

**3. Core。** 中川OS側の設計・思想・創造・判断を行う中核領域。Legacyの価値関数や意思決定を直接入れない。

**4. Legacy。** 国家、企業、自治体、巨大資本など、法・金・インフラ・権威を持つ外部構造。OS自体の変更を前提にせず環境として扱う。

**5. Buffer / Clean Room。** CoreとLegacyの間に置く緩衝地帯。双方を直接触れさせず、異質接続の入出力をここへ集約する。

**6. Input Sanitization。** 資金、ブランド、権威、案件、正当性等に付随する介入、評価軸、前例主義、責任転嫁等を分離し、利用可能な資源へ変換する。

**7. Output Packaging。** Coreの思想・設計・速度・自律性の内容を変えず、Legacyが処理できる商品・改善・効率・専門性等の形式へ包装する。

**8. Translator / Boundary Manager。** D系Vol.2の非対称翻訳を理解し、双方に所属し切らず、Buffer内で境界を管理する職能。

**9. Contract as API。** 感情や善意でなく、入出力・権限・責任・終了条件を仕様として固定する接続面。

**10. Decision Rights / Responsibility Boundary。** 設計・思想・表現・採用等の最終判断をCore側へ残し、責任範囲外とリスク負担を先に明示する。

**11. Kill Switch。** 理念に反する要求、クリーンルーム迂回、意思決定介入等が生じた時、再交渉や感情交渉を必須化せず接続を解除できる条件。

**12. Graduated Connection Depth。** 小さな機能から限定役割、より深い設計関与へ段階的に接続し、一気に内部を混ぜない。

**13. Exit / Resource Reallocation。** 離脱時に業務と成果物を整理して価値を残し、内部判断系、自前資源、次の接続先選択の自由を保持する。

## 適用例
**大企業との協業。** 相手のブランド、販路、信用、予算をそのままCoreへ入れず、限定プロジェクトをBufferとして切り出す。成果物、承認範囲、決定権、責任範囲、終了条件を契約で固定する。

**自治体・公共機関との接続。** 法的正当性、制度アクセス、公共インフラを利用しつつ、Core側の設計判断を会議体や前例へ移譲しない。必要な外部説明は翻訳官が制度語彙へ包装する。

**資金提供。** 資金そのものと、資金に付随する評価軸・介入要求を分ける。資金は予算として利用しても、設計思想やL7の最終判断権を譲渡しない。

**共同プロジェクト。** まず小さな機能で接続し、境界が守られるかを観測してから深度を上げる。最初から組織・人材・意思決定を全面統合しない。

**離脱。** クリーンルーム迂回や判断介入が継続する場合、感情的対立や相手の改心を必要条件にせず、仕様違反として接続を終了し、成果物を整理して資源を次へ再配置する。

## 測定・監査点
- Legacyの資源と、その資源に付随する価値観・介入要求を分離できているか。
- CoreとLegacyの直接接触が常態化していないか。
- 全入出力がBufferを通っているか。
- 金・権威・要求が内部で予算・看板・仕様等へ変換されているか。
- Coreからの出力が内容を変えず、外部処理可能な形式へ包装されているか。
- 設計・思想・表現・採用等の最終決定権がCore側に残っているか。
- 責任範囲外とリスク負担が書面で明確か。
- 口約束、空気、「今回だけ」等がAPI外入力として侵入していないか。
- Kill Switchが実際に行使可能か。
- 接続深度が段階化されているか。
- Legacyとの接触によってL7判断が希釈していないか。
- 接続リターンと調整・遅延・回復・機会コストの収支が恒常赤字になっていないか。
- 離脱後にも独立した判断系と次の接続先を選ぶ自由が残るか。

## 成立条件
- Vol.1の界面設計とVol.2の非対称翻訳を前提として保持する。
- 完全融合と完全遮断を避け、Core / Legacy / Bufferを構造的に分離する。
- LegacyのOS自体を変えることを接続成立条件にしない。
- Input SanitizationとOutput Packagingを両方向で運用する。
- 意思決定権・責任範囲・接続終了条件を明示する。
- 接続解除可能性を開始時から保持する。
- 資源利用と価値関数同化を区別する。

## 失敗条件
- 相手の会議体・評価軸・意思決定プロセスへCoreを全面統合する。
- 安全のためという理由で外部レバレッジをすべて遮断し、循環の拡張可能性を失う。
- クリーンルームを名目だけ置き、CoreとLegacyが直接混ざる。
- 資金・権威と一緒に評価軸・前例・責任転嫁を内部へ流す。
- 外部向け包装のためにCoreの内容そのものを改変する。
- 善意・信頼・口約束を契約APIの代わりにする。
- Kill Switchを持たない、または行使不能な接続を継続する。
- 離脱を敗北とみなし、再汚染を避けるための不可逆性を失う。

## 反証・改訂条件
原典の局所監査では、Traceability / Sovereignty / Reversibility（T/S/R）を再合意条件とする。①中川OS側のL7侵食が観測窓δ期間内に進行した場合、②接続コストがリターンを恒常的に上回る指標値が閾値θを超えた場合、③クリーンルームを介さない直接混合が常態化した場合、界面設計・翻訳・クリーンルーム・接続解除による仮説Aは棄却または改訂対象となる。

原典は全案件に共通する固定θ値やδ期間を普遍値として提示していない。したがって派生物側で独自の数値閾値を追加しない。

## 必須の区別
- **利用 / 同化。** 利用は相手構造から必要機能を抽出すること。同化は相手の価値関数を内面化し判断軸を失うこと。
- **接続 / 融合。** 接続は関係を持ちながら内部を混ぜない。融合は意思決定・評価軸・責任構造まで一体化する。
- **接続 / 遮断。** 遮断は外部レバレッジも失う。接続は境界を維持して必要資源を通す。
- **包装 / 内容改変。** 包装は外部形式の変換であり、Coreの意味・設計内容を書き換えることではない。
- **契約API / 信頼関係。** 信頼を否定するのではなく、境界の代替にしない。
- **構造的補完 / 支配。** 原典が扱う依存は機能補完として記述され、強制的支配や搾取の正当化とは区別される。
- **Kill Switch / 感情的決裂。** 接続解除は仕様違反への運用処理であり、相手への報復や焼き畑を意味しない。

- 「旧文明を喰う」「上書きする」等の比喩を、暴力・破壊・違法な乗っ取りの推奨へ拡張しない。原典は構造的・非敵対的な資源変換と再配線を扱う。
- 「トロイの木馬」等の原典語を、欺瞞・侵入・秘密工作の一般的推奨へ変換しない。親原典自身も主権維持のための提携設計として位置づけている。
- Core保護を、外部情報の全面遮断や異論排除と同一視しない。必要な資源・情報・成果はBufferを通じて流す。
- 契約上の終了条件は、現実の法令・契約義務を無視して一方的に破棄できるという意味ではない。実際の接続では適用法・契約条件に従う。
- Legacyを悪意ある人格として一括断罪しない。原典は巨大構造の安全第一、前例主義、責任分散等を構造的自然現象として扱う。
