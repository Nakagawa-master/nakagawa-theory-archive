## 位置づけ
親原典は「耐久文明論」全体を総括し、壊れた文明を長く持たせること自体には正統性がなく、耐久が限定的に意味を持つのは、次相を起動できる核を守るための時間として機能する場合に限られると定義する。文明再起動は旧秩序の否定や勝利宣言ではなく、保存された核から別の運転原理を発火させるための構造転換である。

## 中心命題
文明は延命によって再生しない。再起動に必要なのは、思想・記録・責任・判断が相互接続した最小の運転可能な束として保存され、その局所核が再現可能性・翻訳可能性・接続可能性を持って外部へ伝播できることである。耐久はこの核を保存する猶予としてのみ限定的な意味を持つ。

## 因果線
合意形成の喪失 → 恐怖・利益・監視による代用運転 → 神話・惰性による延命 → 損耗・責任蒸発・意味空洞化 → 相転移接近 → 次相初期条件の断絶リスク → 思想・記録・責任・判断を再起動核として保存 → 局所核の運転可能性を維持 → 再現・翻訳・接続を通じた発火 → 恐怖・利益・監視中心から、納得可能性・責任追跡可能性・接続可能性・公開監査性・再選択可能性を中核とする新たな運転原理へ移行。

## 構造層
1. **延命運転層**: 恐怖・利益・監視と神話・惰性が、壊れた文明を「死なせず、活かさず」持続させる。
2. **保存猶予層**: 延命が再起動核を保存する時間として機能する場合にのみ、最低限の移行価値を持つ。
3. **再起動核層**: 思想・記録・責任・判断の四要素が、単独資産ではなく相互制約・相互補完された運転束として残る。
4. **発火層**: 局所核が再現可能性・翻訳可能性を備え、命令中心ではなく接続増殖によって外部へ広がる。
5. **主機関転換層**: 秩序接続の根本を、恐怖・利益・監視から、納得可能性・責任追跡可能性・接続可能性・公開監査性・再選択可能性へ書き換える。

## 状態モデル
- **耐久相**: 壊れた秩序が代用運転で継続し、再生ではなく停止を先延ばしする。
- **保存相**: 延命の時間を用いて再起動核を参照可能な形で保持する。
- **核失効相**: 思想・記録・責任・判断の連鎖が切れ、延命が未来負債の増加へ変わる。
- **局所発火相**: 最小運転束が現実へ接地し、外部に再現・翻訳・接続可能な単位として作動する。
- **再起動相**: 保存核から別の主機関を持つ秩序が起動し、接続増殖によって次相へ広がる。

## 適用例
- 理念だけでなく、判断履歴・責任連鎖・実際に選択できる主体まで一体で保存する小規模な運転核。
- 失敗と判断の因果を追跡でき、同じ失敗を反復しないための参照可能な記録系。
- 外部が模倣・翻訳・接続できる形で、局所的に新しい運転原理を実装する組織・制度単位。
- 旧制度の全面復元ではなく、保存された最小束から新しい主機関を持つ秩序を起動する移行設計。

## 測定・監査点
何年延命できるかではなく、思想が翻訳可能か、記録が参照可能か、責任の判断→結果連鎖が追跡可能か、判断主体が現実に止める・切る・選ぶ・移す判断を行えるか、四者が互いに接続した運転束になっているかを観測する。さらに、局所核が外部に対して再現可能・翻訳可能・接続可能であるか、保存が単なる倉庫化・教義化・懲罰化・恣意化へ崩れていないかを確認する。

## 成立条件
文明が健全な再生ではなく延命相にあり、その停止前に次相の初期条件を保存する必要がある場合に成立する。再起動核は全体保存ではなく、思想・記録・責任・判断が相互接続した最小運転束として残り、外部へ再現・翻訳・接続できる必要がある。

## 失敗条件
延命そのものを目的化すること、思想だけを教義化すること、記録だけを遺物化すること、責任だけを懲罰機構へ変えること、判断だけを恣意へ寄せること、保存核をカリスマ的主体へ集中させること、局所核が外部に翻訳・再現できず閉じることは再起動条件を失わせる。

## 反証・改訂条件
思想・記録・責任・判断が運転可能な束として保持されなくても持続的な文明再起動が成立する事例、または四束を保存し局所核を再現・翻訳・接続可能にしても再起動へ一貫して寄与しない事例が反復する場合、再起動核の条件や因果関係の改訂が必要になる。

## 必須の区別
- 耐久 ≠ 再生。
- 延命 ≠ 正統性。
- 保存 ≠ 全体保存。
- 再起動 ≠ 革命・勝利宣言。
- 再起動核 ≠ 知識の集積・記念碑。
- 責任追跡 ≠ 断罪。
- 判断主体 ≠ カリスマ支配者。
- 発火 ≠ 動員・一斉命令。
- 希望 ≠ 感情・楽観。

## 誤読禁止 / 解釈制約（原典適合）
「崩壊すれば自動的に良い文明が始まる」「延命は長いほど良い」「思想さえ残れば再起動できる」「強い指導者が現れれば発火する」と読まない。親原典が扱うのは、保存された四束が最小でも運転可能な関係にあり、局所核が外部へ再現・翻訳・接続できることによって、別の運転原理が起動しうる条件である。

## 親原典へ戻る理由
耐久の限定的な役割、思想・記録・責任・判断の四条件、各要素が単独では失効する理由、局所核の発火条件、希望を保存事実として定義する論理、旧主機関から新主機関への転換は、シリーズ総括として連続した本文で確認する必要がある。派生面は親原典を置換しない。
