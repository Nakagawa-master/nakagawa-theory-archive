## 位置づけ
本原典は、不動産市場OS Vol.1の意思決定インフラとVol.2の張力均衡を、実際に計算可能なExecutable Logicへ変換する数値設計編である。中心は「価格を当てる」ことではなく、不動産の未来を全分岐・全時点・全主体で比較し、税後手取り、TCO、必要資本、期間、リスクを同じ盤面へ置いて、売り手・買い手・業者・専門家が同じ根拠から条件差を説明できる状態を作ることにある。

既存の原価法・取引事例比較法・収益還元法等を否定せず出発点の言語として接続する一方、AIが「鑑定」を代替したり、単一のそれらしい価格をブラックボックスで出す構造を拒む。AIは根拠整理・分岐計算・レンジ提示を担い、鑑定、税務、権利、境界、建物、仲介、管理、金融等の責任は専門家へ接続する。

## 中心命題
親原典の中心命題は、**不動産の合理的意思決定と合意形成を成立させるには、単一の査定額を出すのではなく、「全分岐×全時点×全主体」を計算可能にし、各分岐を税後手取り・TCO・必要資本・期間・リスクで比較できる共通盤面を作り、入力根拠と前提を追跡可能にし、確率・レンジ・未確定を区別し、AIの計算結果を責任ある専門家へ接続する必要がある。価格は結果であり、構造が根拠である**、というものである。

この設計では、相続は重要なイベントだが唯一の軸ではない。現在、任意年、相続・贈与・退去・金利変動・大規模修繕・災害・規制変更等をイベントエンジンとして任意時点へ差し込み、個人・資産管理法人・一般法人・一般社団等の主体差も含める。未来を断言するのではなく、不確実性を確率とレンジで比較可能にする。

## 構造層
**1. 全分岐シミュレーション。** 売却、保有、賃貸、改修、建替え、解体更地、共同開発、贈与・承継等を一本道でなく別の未来として計算する。

**2. 全時点 / Event Engine。** 現在、任意年、相続・退去・修繕・金利・災害・規制変更等を分岐へ差し込み、複数パターンを並列に走らせる。未来予測ではなく、任意仮定と確率・レンジによる比較である。

**3. 全主体。** 個人だけを前提にせず、資産管理法人、一般法人、一般社団等を含め、税務・イベント・出口の差を共通OS上で扱う。

**4. Tax-after Cash Flow。** 比較基準を売値から税後手取りへ移す。売却税・費用、保有費、空室、修繕、投資回収等を含める。

**5. TCO。** 保険、税、管理費、修繕、空室、原状回復等、保有に伴う不可避コストを通期で束ねる。

**6. Existing Valuation Methods as Inputs。** 既存3手法を否定せず、市場OSの根拠入力へ接続する。AIの独自ブラックボックス価格で置換しない。

**7. Risk-to-Cost Translation。** 災害、地形、擁壁、高低差、接道、保険、融資条件等を単一危険スコアで終わらせず、分岐ごとの必要資本・維持費・出口ディスカウント・期間へ変換する。

**8. Condition Range。** 不確実な未来を断言せず、起きた場合の費用と手取り幅をレンジで示す。

**9. Shared Decision Board。** 売り手と買い手が同じ分岐・同じ根拠を共有し、価格を条件差の結果として扱う。

**10. White-box AI。** 入力、前提、計算規約、根拠を追跡可能にする。AIは判断主体・鑑定主体ではない。

**11. Responsibility Routing。** 鑑定士、税理士、司法書士、土地家屋調査士、建築士、宅建業者・管理会社、金融機関等へ領域ごとに責任を接続する。

**12. Non-quantifiable / Uncertain State。** 境界未確定、紛争、心理的瑕疵等を「低精度係数」で薄めず、未確定・要調査として表示する。

**13. Condition Z / T-S-R。** T=Traceability、S=Safety、R=Reproducibility。入力根拠、AI限界と専門家責任、同一条件での再現性を監査する。

## 適用例
**売却 vs 保有。** 現在売却、5年後売却、10年保有を、売値ではなく税後手取り、固定資産税、保険、修繕、残債、金利等で比較する。

**賃貸化。** 賃料だけでなく空室、原状回復、修繕、賃料下落、保険、金利を含め、複数期間の税後CFで比較する。

**改修・建替え。** 工事費、造成、擁壁、搬入、用途変更、回収期間等を必要資本へ変換し、現状売却との差を同じ盤面で見る。

**災害・地形。** ハザードを「危険だから安い」と単純化せず、保険、修繕、再建築費、売却期間、価格ディスカウント、融資条件へ分解する。

**相続・法人。** 相続前後だけでなく、主体が法人で相続が主軸にならない場合も同じOSで扱い、主体差を条件として可視化する。

**専門家接続。** 税務値は税理士、境界未確定は土地家屋調査士、建物状態は建築士等へ接続し、AI出力を責任の空白にしない。

## 測定・監査点
- 全分岐が定義され、二択へ縮退していないか。
- 現在・任意年・イベント時点を同一ロジックで比較できるか。
- 個人・法人等の主体差が反映されているか。
- 比較指標が売値でなく税後CF・TCO・必要資本・期間・リスクになっているか。
- 既存価格算出手法の根拠を追跡できるか。
- 地形・災害等が分岐別コストへ変換されているか。
- 不確実性を確率・レンジで扱い、断言していないか。
- 売り手と買い手が同じ盤面・同じ根拠を見られるか。
- AIの回答領域と数値化不能域が分離されているか。
- 未確定事項を係数で隠さず赤旗として示しているか。
- 数字ごとの責任領域と専門家導線があるか。
- 同一入力・同一条件で結果が再現されるか。
- 合意形成の往復回数、想定外コスト発生率、成約後クレーム率、入力補正率、価格乖離幅を監査できるか。

## 成立条件
- 価格を目的化せず、分岐と手取りを中心に置く。
- 全分岐・全時点・全主体を計算対象へ含める。
- 既存の専門家領域と価格算出手法を破壊せず接続する。
- 入力根拠・前提・変数定義を追跡可能にする。
- 不確実性はレンジと複数パターンで表す。
- 同じリスクを全分岐へ同じ係数で雑に適用しない。
- 未確定は未確定として検査・調査へ送る。
- AIを鑑定・判断・責任主体にしない。
- 領域ごとに責任を引き受ける専門家へ接続する。
- 売り手・買い手・専門家が共通盤面を共有する。
- T/S/Rと反証条件を継続監査する。

## 失敗条件
- 単一査定額を万能な正解として提示する。
- AIが「鑑定」を名乗る、または責任主体になる。
- 税・修繕・空室・金利・災害等を価格から切り離す。
- 相続だけを全所有者の中心軸にする。
- 個人以外の主体差を捨てる。
- リスクを一括危険スコアや一律値引きへ潰す。
- 不確実な未来を確定未来として断言する。
- 未確定事項を低精度係数で埋めて判断可能に見せる。
- 買い手と売り手が別の根拠盤面を使う。
- AI出力の外側に責任者が存在しない。
- 計算規約が同一条件で再現できない。

## 反証・改訂条件
原典は条件ZとしてT/S/Rを明示する。T=Traceabilityは修繕ログ、税・保険、賃貸条件等の入力根拠が追跡可能であること、S=SafetyはAIの回答領域と数値化不能域の境界および専門家責任導線が明示されること、R=Reproducibilityは同一条件で同一結果が再現される計算規約の整合である。

指標例として、合意形成の往復回数、想定外コスト発生率、成約後クレーム率、入力補正率、価格乖離幅が置かれる。これらが閾値θを許容方向から外れる、または観測窓δで入力閉鎖・透明性喪失等の現象Mが確認された場合、仮説A、変数定義、計算規約、責任導線を棄却・改訂し、公開監査束を更新する。原典は普遍固定のθ値・δ期間を提示していない。

## 必須の区別
- 価格 ≠ 根拠
- 査定額 ≠ 税後手取り
- AI推定 ≠ 不動産鑑定評価
- 計算可能性 ≠ 数式の多さ
- 全分岐 ≠ 売る/持つの二択
- 全時点 ≠ 現在価格の延長
- 相続 ≠ 唯一のイベント
- 個人所有 ≠ 全市場主体
- リスク表示 ≠ 恐怖ラベル
- 確率・レンジ ≠ 確定予測
- 未確定 ≠ 低精度の確定値
- AI説明可能性 ≠ AI責任
- 共通盤面 ≠ 同一結論

## 誤読禁止 / 解釈制約（原典適合）
- 「完全定義」を、未来や価格を完全に予測できるという意味へ拡張しない。
- 「AI査定」を法的・専門的な不動産鑑定評価の代替と読まない。
- 「数値化」を、数値化不能域を無理にスコア化することへ変えない。
- 災害・地形リスクを恐怖喚起や一律価格ディスカウントへ単純化しない。
- 相続を重要イベントとして扱うことと、全主体へ相続中心モデルを強制することを混同しない。
- 税後手取りを単一の金銭最大化目的へ変えない。原典は期間、リスク、責任、条件差を同じ盤面で比較する。
- 専門家接続を「AIの免責文」として扱わない。責任を実際に引き受けるUI導線まで含む。
