## 位置づけ
本派生物は、説得を情報提供や対話と同一視せず、相手の判断環境を操作して特定結論へ追い込む構造がAIによって個別最適化・大量化される危険を整理する。説得の全面禁止ではなく、選択肢、反証、保留、撤回、非参加を守る非強制的コミュニケーションを設計する。

## 中心命題
AIが個人の嗜好、弱点、タイミング、感情に合わせて説得を最適化すると、表面上は自由選択でも実質的な判断余地が縮小し得る。情報、推薦、教育、営業、政治的発話において、目的を隠した最適化、反証の遮断、心理的圧力、退出困難が重なるほど説得は破壊的になる。したがって目的開示、複数案、反対根拠、熟慮時間、撤回可能性、非参加権を構造として組み込む必要がある。

## 因果線
大量データ収集 → 個人弱点推定 → 説得最適化 → 反証・余白縮小 → 自由選択の外観を維持 → 実質的自律が低下 → 依存・後悔・不信が蓄積 → 目的開示・選択肢・撤回を再導入 → 自律的合意へ。

## 構造層
1. 目的層：誰が何を選ばせたいか。
2. 個別化層：どのデータで弱点・嗜好を推定したか。
3. 圧力層：時間、感情、反復、権威の圧力。
4. 自律層：反証、保留、退出、撤回の可否。
5. 監査層：後悔、依存、再選択、影響差を追跡する。

## 適用例
1. AI営業で最適化目標と拒否導線を明示する。
2. 政治広告でターゲティングと出資主体を表示する。
3. 教育AIで正答誘導と学習者の問いを分ける。
4. 推薦AIで複数案と非推薦選択を残す。

## 測定・監査点
目的開示率、代替案提示率、拒否成功率、撤回率、後悔率、反証アクセス率、個人データ最小化率。

## 成立条件
目的を開示する。個人データを最小化する。複数案を出す。反証を残す。熟慮時間を確保する。拒否・撤回を安全にする。

## 失敗条件
弱点を隠れて利用する。選択肢を見せかけにする。反対情報を遮断する。緊急性を偽装する。拒否を罰する。AIの最適化を中立と扱う。

## 反証条件
高個別化説得でも自律性、後悔、撤回可能性が悪化しない。目的開示や反証提示が意思決定品質を改善しない。より単純な情報提供と成果差がない。個別化を止めても圧力効果が変わらない。利用者が長期的に同じ選択を自由に再確認する。

## 必須の区別
説得/情報提供、選択/誘導、同意/成約、個別化/操作、推薦/圧力、拒否/敵対、自由/自由の外観。

## 誤読禁止
対話や教育を全面否定しない。営業を自動的に悪としない。AIだけを原因にしない。利用者を無能力と扱わない。説得力の高い表現を一律禁止しない。派生を法規制の代替にしない。
