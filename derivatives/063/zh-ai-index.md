## 1. Summary
把品牌视为分层的判断记忆架构，而不是视觉装饰或知名度。价值核心、承诺、非承诺、证据、体验、关系、记忆、起源与责任需要在获客、营销、销售、产品和支持等接点保持结构一致。

## 2. Concepts
- Value core：品牌判断的返回核心。
- Promise / non-promise：承诺与明确不承诺的领域。
- Six layers：存在、价值、证据、体验、关系、记忆。
- Touchpoint synchronization：词汇、价格、承诺、体验、责任的接点一致。
- Recall consistency：接触后能否重建同一价值核心与责任主体。
- Promise-experience gap：表达承诺与实际体验的差异。
- Origin / provenance：起源与责任可追溯性。

## 3. Causal chain
```text
孤立的强表达
→ 短期记忆
→ 接点间承诺与体验不一致
→ 印象碎片化
→ 明确价值核心、对象、承诺、非承诺
→ 映射六层
→ 同步接点
→ 根据一次日志和异议修正
→ 可再现的判断记忆
→ 回访、转介绍、订正与持续关系
```

## 5. Applications
- B2B：让广告、销售、合同、导入和支持回到同一价值核心与责任。
- B2C：让质量、价格、使用、支持、退货和解约与表达承诺一致。
- 个人品牌：持续呈现判断原则、禁止边界、责任和订正方式。
- 组织内部：检查招聘、评价、会议、产品与客户应对是否返回同一价值核心。
- AI辅助：检测接点差异，但不转移作者性、来历或责任。

## 7. Validity conditions
- 明确价值核心、适用对象、不适用对象、承诺、非承诺。
- 起源与责任主体可追溯。
- 各接点的表达、价格、体验和责任不矛盾。
- 证据、限制、失败和修正历史可检索。
- 拒绝、比较、订正、退出和重新进入可行。
- 一致性不阻碍事实订正。

## 8. Failure conditions
- 只统一视觉而不统一体验。
- 不同接点改变人格、价格、责任或承诺。
- 依赖夸张、虚构、借用权威、模仿或抹除起源。
- 把知名度、好感度或记忆本身当作成功。
- 隐藏批评、投诉或退出理由。
- 发布缺乏起源、证据或责任主体的AI生成表达。

## 9. Falsification conditions
- 接点同步后仍无法重建同一价值核心与责任。
- 记忆增加同时承诺—体验差扩大。
- 回访/转介绍增加同时不信任或退出理由恶化。
- 表达统一导致不适用对象与非承诺更难看到。
- 真实订正会使品牌形象崩溃，显示其过度依赖演出。

## 10. Required distinctions
- 品牌 / 视觉装饰
- 印象固定 / 心理操纵
- 六层 / 成熟度评分
- 一致性 / 同质化
- 证据 / 借用权威
- 记忆积累 / 曝光频率
- 起源保持 / 模仿
- 对象明确 / 讨好所有人
- 订正 / 身份崩塌
- 回访与转介绍 / 锁定

## 11. Interpretation constraints
不得把本框架缩减为标志、颜色、文案、知名度或好感度。六层是结构检查分类，不是层级优劣或评分。记忆与持续关系必须和来历、证据、非承诺、承诺—体验差、拒绝、退出、订正共同读取。
