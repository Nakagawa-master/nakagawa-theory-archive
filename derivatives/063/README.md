## 位置づけ
親原典は、ブランディングをロゴ・配色・知名度・好感度の設計へ縮約せず、価値核、約束、非約束、証拠、体験、責任、再訪理由を複数接点で同じ方向へ積層し、受け手の中に再現可能な判断記憶を形成する構造設計として扱う。

印象を「固定する」とは、誇張や反復露出で印象を押し込むことではない。接点を変えても、何者で、何を約束し、何を約束せず、どの証拠があり、実際にどの体験があり、どの責任主体へ戻れるかが矛盾しないことで、判断理由が記憶として残る状態を指す。

## 中心命題
**強いブランドは、強い表現の反復ではなく、存在・価値・証拠・体験・関係・記憶の各層が同じ価値核・起源・責任へ戻り、営業・マーケティング・集客・製品・支援の各接点で約束と実体験が照合可能な状態から形成される。**

## 因果線
```text
単発の強い表現・露出
→ 一時的な想起
→ 接点ごとに約束・価格・責任・体験が変わる
→ 印象が分断され、判断記憶が形成されない
→ 価値核・対象・非対象・約束・非約束を明示
→ 存在 / 価値 / 証拠 / 体験 / 関係 / 記憶へ層分解
→ 語彙・価格・体験・責任を接点同期
→ 一次ログ・苦情・離脱理由から差分修正
→ 同じ判断理由へ戻れる記憶が蓄積
→ 再訪・紹介・継続・訂正可能性が形成
```

## 構造層
**1. 存在層。** 何者で、誰に対して何の問題・機能・責任を持つかを定義する。

**2. 価値層。** 何を可能にするか、何を変えないか、何を約束しないかを明示する。

**3. 証拠層。** 実績、一次ログ、比較条件、失敗記録、限界、修正履歴を保持する。

**4. 体験層。** 記事、営業、購入、導入、利用、問い合わせ、解約等で実際に何が起きるかを約束と照合する。

**5. 関係層。** 相談、拒否、比較、訂正、離脱、再参加、異論が可能な関係境界を設計する。

**6. 記憶層。** 接点を離れた後に何が理由として残り、何を根拠に再訪・紹介・非選択するかを観測する。

## 適用例
**1. B2B。** 広告・営業・契約・導入・サポートが同じ価値核、対象条件、責任、非約束へ戻るようにする。

**2. B2C。** 雰囲気や視覚だけでなく、品質、価格、利用条件、問い合わせ、返品・解約まで同じ約束と一致させる。

**3. 個人ブランド。** 肩書きや見た目より、何を観測し、どう判断し、何をしないか、誤りをどう訂正するかを一貫させる。

**4. 組織内。** 採用、評価、会議、製品、顧客対応が同じ価値核と禁止境界へ戻るかを監査する。

**5. AI支援。** 接点差分や語彙不一致の抽出には使えるが、起源、証拠、著者性、責任主体をAIへ移転しない。

## 測定・監査点
- **六層**: 存在・価値・証拠・体験・関係・記憶という原典明示の6分類。6点満点や成熟度順位ではない。
- **想起一貫性**: 同じ価値核・主体・責任として再現されるかを見る観測概念。
- **約束体験差**: 表現上の約束と実際の体験のずれを観測する概念。
- **再訪率・紹介率**: 記憶と実体験から関係が続くかを見る候補。依存・囲い込みで上がる場合は成功ではない。
- **苦情率・離脱理由**: 低さだけを追わず、苦情・離脱経路が閉じていないか、正当な不一致が見えるかを併読する。

反転評価では、知名度・想起・再訪・紹介が上がっても、約束体験差が拡大し、比較・拒否・訂正・離脱が難しくなるなら改善とみなさない。苦情が減っても、苦情経路を隠した結果なら失敗である。

## 成立条件
- 価値核、対象、対象外、約束、非約束が明示される。
- 起源と責任主体を追跡できる。
- 表現、価格、体験、責任が接点間で矛盾しない。
- 証拠、限界、失敗、修正履歴へ戻れる。
- 拒否、比較、訂正、離脱、再参加が可能である。
- 再訪・紹介が圧力や退出困難ではなく、実体験と判断記憶から生じる。
- 一貫性を理由に事実訂正を妨げない。

## 失敗条件
- 見た目だけを統一し、約束と体験が一致しない。
- 接点ごとに人格、価格、責任、対象条件が変わる。
- 誇張、虚偽、権威借用、模倣、起源消去に依存する。
- 好感度・知名度・想起だけを成功とみなす。
- 苦情、批判、離脱理由を観測対象から外す。
- AI生成表現を証拠・起源・責任なしに公開する。
- ブランド一貫性を理由に訂正・撤回を拒む。

## 反証・改訂条件
- 接点同期後も受け手が同じ価値核・約束・責任を再現できない。
- 想起が増えても約束体験差が拡大する。
- 再訪・紹介が増えても苦情・離脱理由・不信が悪化する。
- 表現統一を進めるほど対象外条件や非約束が見えなくなる。
- 起源・証拠・責任を保持すると成立しない表現に依存している。
- 訂正を行うとブランドが崩壊するほど、実体ではなく演出へ依存している。

## 必須の区別
- ブランディング / 視覚装飾
- 印象固定 / 心理操作
- 一貫性 / 画一化
- 証拠 / 借用権威
- 記憶蓄積 / 露出回数
- 起源保持 / 模倣
- 対象明確化 / 全員への好感
- 訂正 / アイデンティティ崩壊
- 再訪・紹介 / 囲い込み
- 想起 / 信頼
- AI支援 / 著者性・責任移転

## 解釈制約
ブランディングをロゴ、色、コピー、知名度、好感度へ縮約しない。六層は優劣スコアではなく、どこで約束と体験が分断されたかを観測する分類である。想起や再訪の増加だけで成功を宣言せず、起源、証拠、非約束、拒否・離脱可能性、訂正可能性と併読する。
