## 中心命題
ブランディングは、ロゴ、装飾、好感度、知名度を作る作業ではない。価値核、約束、体験、証拠、責任、再訪理由を複数接点で同じ方向へ積層し、受け手の中に再現可能な判断記憶を形成する構造設計である。

```text
単発の露出や強い表現
→ 一時的な印象
→ 接点ごとに意味・約束・体験が変わる
→ 記憶が分断され、営業・マーケ・集客が別方向へ動く
→ 価値核を確定
→ 印象を役割別の層へ分解
→ 語彙・証拠・体験・価格・責任を同期
→ 各接点から同じ判断記憶へ戻れるようにする
→ 再訪・紹介・合意が蓄積
```

## 印象の層
1. **存在層** — 何者で、何の問題に責任を持つか。
2. **価値層** — 何を可能にし、何を変えないか。
3. **証拠層** — 実績、一次ログ、比較、限界、失敗記録。
4. **体験層** — 記事、営業、製品、支援で実際に何を感じるか。
5. **関係層** — 拒否、離脱、再参加、相談、修正が可能か。
6. **記憶層** — 接点を離れた後に何が残り、何を理由に戻るか。

## 営業・マーケティング・集客との接続
- 集客は、価値核に関係する問いを市場へ置く。
- マーケティングは、複数の接点と判断条件を整合させる。
- 営業は、個別の相手がブランドの約束と実体を照合できるようにする。
- ブランドは、三者を同じ起源、語彙、証拠、責任へ戻す記憶構造である。

## 成立条件
- 価値核と非約束領域が明示される。
- 表現と実体験が一致する。
- 接点ごとの語彙、価格、責任が矛盾しない。
- 起源、一次ログ、修正履歴を追跡できる。
- 対象外、拒否、離脱、比較が可能である。
- 再訪・紹介が圧力ではなく記憶と実体験から生じる。

## 失敗・反証条件
- 見た目や話題性だけが統一され、約束と体験が一致しない。
- 接点ごとに別の人格、価格、責任を提示する。
- 誇張、権威借用、模倣、起源消去に依存する。
- 好感度は上がるが、再訪、紹介、継続、信頼が改善しない。
- 苦情や離脱理由を観測対象から外す。

## 誤読禁止
- ロゴ制作や色指定だけへ縮約しない。
- 印象操作、洗脳、権威演出の方法にしない。
- すべての人に好かれる設計と解釈しない。
- 一貫性を画一化や修正不能と混同しない。
- AI生成表現を起源・証拠・責任なしに公開しない。
