## 1. Summary
ブランディングを表層表現ではなく、価値核、約束、非約束、証拠、体験、関係、記憶を複数接点で同じ起源と責任へ積層する構造として扱う。営業・マーケティング・集客・製品・支援を同期し、判断記憶と訂正可能性を形成する。

## 2. Concepts
- Value core: 判断の戻り先となる中心機能。
- Promise / non-promise: 約束する領域と約束しない領域。
- Six layers: 存在 / 価値 / 証拠 / 体験 / 関係 / 記憶。
- Touchpoint synchronization: 語彙・価格・約束・体験・責任の整合。
- Origin / provenance: 起源と責任主体の追跡可能性。
- Recall consistency: 同じ価値核として正しく想起される状態。
- Promise-experience gap: 約束と実体験のずれ。

## 3. Causal chain
```text
単発の強い表現
→ 一時的想起
→ 接点間の約束・体験不一致
→ 印象分断
→ 価値核・対象・約束・非約束を固定
→ 六層へ分解
→ 接点同期
→ 一次ログから差分修正
→ 判断記憶・再訪・紹介・訂正可能性
```

## 5. Applications
- B2B: 広告・営業・契約・導入・支援を同じ価値核と責任へ接続する。
- B2C: 品質、価格、利用、問い合わせ、返品・解約を同じ約束へ接続する。
- 個人ブランド: 判断原理、禁止境界、訂正方法を一貫して示す。
- 組織内: 採用・評価・会議・顧客対応を同じ価値核へ戻す。
- AI支援: 接点差分を補助し、起源・著者性・責任は人間が保持する。

## 7. Validity conditions
- 価値核、対象、対象外、約束、非約束が明示される。
- 起源と責任主体が追跡可能である。
- 接点間で表現、価格、体験、責任が矛盾しない。
- 証拠、限界、失敗、修正履歴へ戻れる。
- 拒否、比較、訂正、離脱、再参加が可能である。
- 一貫性を理由に事実訂正を妨げない。

## 8. Failure conditions
- 見た目だけ統一し、実体験が一致しない。
- 接点ごとに人格、価格、責任、約束が変わる。
- 誇張、虚偽、借用権威、模倣、起源消去に依存する。
- 知名度・好感度・想起だけを成功とする。
- 苦情・批判・離脱理由を隠す。
- AI生成物で起源・証拠・責任を消す。

## 9. Falsification conditions
- 接点同期後も同じ価値核・責任として想起されない。
- 想起増加と同時に約束体験差が拡大する。
- 再訪・紹介増加と同時に不信・離脱理由が悪化する。
- 表現統一により対象外・非約束が見えなくなる。
- 訂正するとブランドが崩れるほど演出依存である。

## 11. Interpretation constraints
ロゴ、色、コピー、知名度、好感度へ縮約しない。六層を優劣順位へ変換しない。想起・再訪・紹介の改善だけで成功を宣言せず、起源、証拠、非約束、約束体験差、拒否・離脱・訂正可能性と併読する。
