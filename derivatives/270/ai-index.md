## Summary
親原典は、前提・語彙・目的・評価軸・役割・時間軸・責任境界の不整合から生じる遅延と誤解を「構造的摩擦」と捉え、客観視座を自分を含む全員・主張・条件を同一図面へ戻す操作として定義する。感情は排除せずセンサーとして保存し、感情→観測→翻訳→構造配置→行動へ回路を延長する。対象化、時間差の吸収、目的の再定義、問いと沈黙、一枚図、三行記録、合意単位、語彙辞書、T/S/R、撤回可能性を束ね、人格対立を設計差分へ変換する。

## Causal chain
主観が自己物語へ閉じる → 未翻訳の感情が解釈と行動へ直結 → 前提・語彙・目的・役割・責任のズレが人格摩擦として現れる → 観測の一拍を置く → 感情を構造情報へ翻訳 → 自分・相手・場を同一図面へ対象化 → 過去/現在/次手を分離 → 勝敗から合意成立条件へ目的を再定義 → 語彙と責任境界を整合 → 合意単位と十分条件を宣言 → 三行記録で骨組みを保存 → 失敗を罪ではなく設計差分として扱う → T/S/Rと撤回で過熱・固定化を制御 → 合意再燃と誤配を減衰 → 合意形成と実装を再同期する。

## State model
`subjective_signal_preserved → observation_pause → structural_translation → shared_map → vocabulary_alignment → temporal_separation → consensus_unit_declared → responsibility_boundary_drawn → replayable_record → friction_as_design_difference → TSR_reversibility → disagreement_decay → consensus_execution_resync`

## Applications
AI共創では意図・前提・制約を公開可能な図面へ落とし、失敗ログを設計差分として残す。組織では目的・KPI・責任境界・制約を同一図面に置き、部署ごとの正しさを構造妥当性へ翻訳する。教育では学習者が目標・現状・次の一手を設計し、教師を裁定者ではなく伴走者として置く。市民サービス、医療連携、プロダクト優先度のParent内ケースは公開安全な抽象例として扱い、一般効果の実証事実へ変えない。

## Measurements and audit
語彙の整合率、責任境界の明瞭度、同じ論点が再燃する反復回数、摩擦指数、位相安定S、再合意到達時間、撤回成功率、観測窓の開放、三行記録からの再演可能性、合意単位の明示、秘匿境界の維持を監査する。速度だけで成功判定せず、十分条件が揃ったか、人格攻撃が減ったか、撤回・再編集が可能かを同時に見る。

## Validity conditions
感情をセンサーとして保護する。自分も観測対象として同一図面へ置く。用語と前提の粒度を合わせる。過去/現在/次手を分ける。勝敗ではなく合意成立条件を明文化する。責任を人物属性ではなく機能境界として描く。十分条件なしの拙速な合意を避ける。三行記録・語彙辞書・T/S/R・撤回経路を保持する。

## Failure conditions
客観を冷淡、無感情、多数派、万能第三者とみなす。感情をノイズとして削除する。誰が正しいかの順位化に戻る。個人告発で構造問題を代替する。資源・時間・権限制約を隠す。合意単位が異なるまま議論を続ける。記録量だけを増やして骨組みを失う。秘匿された内部手順や閾値を推測公開する。

## Falsification conditions
客観視座の導入後も摩擦指数や論点再燃が改善しない、語彙整合率が低下する、責任境界が曖昧になる、位相安定が崩れる、再合意時間が伸びる、撤回成功率が低下する、観測窓が閉じる、同一図面が人物評価装置へ変質する場合、仮説を改訂または棄却する。
