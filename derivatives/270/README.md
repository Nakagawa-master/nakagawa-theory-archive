## 位置づけ
親原典は、努力不足や悪意として処理されがちな衝突を、前提・語彙・目的・評価軸・役割・時間軸・責任境界の不整合から生じる**構造的摩擦**として捉え直す。そのうえで客観視座を「中立の仮面」や「上から裁く視線」ではなく、自分を含む当事者・主張・条件を同一図面へ戻し、感情を消さず構造情報へ翻訳する操作として定義する。

## 中心命題
**主観や感情を排除するのではなく、感情→観測→翻訳→構造配置→行動という回路へ置き直し、対象化・時間差の吸収・目的の再定義を行えば、人格対立を条件整合の問題へ変換できる。共有図面・語彙辞書・責任境界・合意単位・三行記録を用い、T/S/Rと撤回可能性を保持することで、摩擦を観測可能な信号へ変え、誤配を減らし、合意形成と実装を同期させる。**

## 主要因果線
主観が自己物語へ閉じる→未翻訳の感情が判断へ直結→前提・語彙・役割・責任の不整合が人格衝突として表出→いったん観測して止まる→感情を構造情報へ翻訳→自他と場の条件を同一図面へ対象化→過去/現在/次手で時間差を吸収→勝敗から合意成立条件へ目的を再定義→語彙・責任境界・合意単位を整合→三行記録で再現可能性を残す→摩擦を罪ではなく設計差分として扱う→T/S/Rと撤回で過熱・固定化を抑える→合意再燃を減らし誤配を減衰→合意形成と実装が同期する。

## 構造層
### 1. 構造的摩擦
能力不足ではなく、前提・語彙・目的・評価軸、さらに役割定義・時間軸・責任境界などの不一致から生じる遅延と誤解として扱う。摩擦を個人の罪へ還元せず、観測可能な信号として再配置する。

### 2. 主観の檻と翻訳回路
感情は重要なセンサーだが、出力がそのまま解釈と行動へ直結すると増幅と誤配が起きる。感情→観測→翻訳→構造配置→行動へ回路を延長し、熱を消さず置き場を変える。

### 3. 客観視座の三操作
対象化では自分・相手・場の条件を同一平面に置き、用語と前提の粒度を揃える。時間差の吸収では過去/現在/次の一手を分ける。目的の再定義では勝敗・優劣から合意成立条件へ主語を移す。

### 4. 問いと沈黙
問いは相手を詰める道具ではなく構造の輪郭を出す道具。沈黙は同意でも拒絶でもなく、解像度が合うまで待つ操作。具体的な秘匿アルゴリズムを推測して補わない。

### 5. 公開ミニマムセット
一枚の図に目的・制約・役割・期限・合意条件を置く。結論・根拠・次の一手を三行で残す。何への合意かを先に定義し、十分条件、用語辞書、速度の閾値を明示する。

### 6. 応用
AI共創では意図・前提・制約を公開可能な図面へ落とし、失敗を設計差分として残す。組織では目的・KPI・責任境界を同一図面化する。教育では学習者自身が目標・現状・次手を設計し、教師を裁定者ではなく伴走者として置く。

### 7. 公開安全境界
特定組織・個人、秘匿技術手順、過度に強い操作は公開対象外。共有は姿勢・枠組み・観測変数に限定し、要求が公開可能域を越えるときは抽象度を上げる。客観視座を万能鍵や監視・評価装置へ変えない。

## 適用例
市民サービスでは「申請件数」から「不便の種類ごとの平均解決日数」へ合意単位を変え、数字の責任から構造の責任へ移す。医療連携では語彙を先に整え、患者状態→必要行為→責任者→時間で並べ替える。プロダクト開発では部門ごとの正しさを争わず、失敗コスト×発生頻度のような共通軸へ優先度を写像する。これらはParent内の抽象ケースであり、実証済み一般効果へ昇格させない。

## 測定・監査点
語彙の整合率、責任境界の明瞭度、同じ論点が再燃する反復回数、摩擦指数、位相安定S、再合意到達時間、撤回成功率、観測窓の開放、三行記録からの再演可能性、秘匿境界の保持を監査する。

## 成立条件
感情を否定しない。自分も同じ図面に置く。合意単位を先に定義する。役割・責任を人格ではなく機能で記述する。用語と前提を揃える。十分条件がないまま速度を優先しない。記録を再演可能な骨組みに絞る。T/S/Rと撤回を保持する。

## 失敗条件
客観を冷淡・多数派・万能第三者と同一視する。感情をノイズとして削除する。誰が正しいかの順位化へ戻る。個人告発で構造問題を代替する。資源・時間・権限制約を書かない。合意単位を曖昧にしたまま議論を加速する。秘匿内部手順を推測公開する。

## 反証・改訂条件
摩擦指数が改善しない、語彙整合率が下がる、責任境界が曖昧になる、合意再燃が増える、位相安定が崩れる、再合意時間が伸びる、撤回不能になる、観測窓が閉じる場合、客観視座による構造調律仮説を改訂・棄却する。

## 必須の区別
客観視座 / 冷淡; 客観視座 / 多数派; 構造情報 / 感情否定; 摩擦信号 / 個人の罪; 合意条件 / 勝敗; 機能責任 / 人格評価; 十分条件を待つこと / 単なる遅延; 再現可能性 / 記録量; 公開枠組み / 秘匿アルゴリズム。

## 誤読防止・解釈制約
「普遍原理」というParentの表現を、全状況で必ず有効な科学的普遍則として扱わない。Parentは共創現場から抽出した公開安全な設計思想とケースを提示する。客観視座は主観の消去ではなく文脈への再配置であり、外部者による人物採点や監視の正当化ではない。内部手順・閾値・固有情報を推測補完しない。
