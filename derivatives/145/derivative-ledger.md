## Lineage integrity
この系列では「公共であること」と「起源を消すこと」を結びつけない。親原典の公共性は、排他的所有を弱める一方で、起源・改訂・派生・責任の因果線を保持する構造として扱う。したがって派生側も、利用可能性を広げるためにParent URL、NCL-ID、Diff-ID、Originを削除しない。

非所有性も無責任性とは区別する。理論・設計・知識が公共圏へ開かれていても、誰が改変し、どの条件で採用し、どの影響を生じさせ、誰が監査したかは別々の責任線として追跡できる必要がある。この区別を失う派生は親原典の意味を弱めるため、同系列として扱わない。

## Semantic lineage
親原典の中心因果は、公共利用の拡大によって派生・翻訳・実装が増えるほど、起源切断、再私有化、責任拡散、解釈独占のリスクも増えるため、非所有性だけでなく起源署名・派生透明性・責任分配・防衛層を組み合わせる必要がある、という構造である。

防衛層は公共性を守るための補助層であり、誰が正しい解釈者かを一方的に決める中央管理層ではない。占有、起源消去、不可逆な封鎖、責任逃逸など公共性を反転させる条件を検知・抑制する一方で、防衛判断それ自体も監査、異議、改訂、停止の対象になる。

## Publicness boundary
公共利用を広く認めることと、あらゆる利用方法を無条件に正当化することは同義ではない。原典の構造に忠実であるため、公開面では次を区別する。

- 公共性 ≠ 無起源
- 非所有性 ≠ 無作者
- 起源署名 ≠ 排他的所有権
- 派生自由 ≠ 改変非表示
- 防衛 ≠ 思想統制
- 責任分配 ≠ 責任希薄化
- 可逆性 ≠ 無責任な撤回
- 公開アクセス ≠ 単一プラットフォーム支配

## Derivative equivalence
三言語AI索引では、訳語差によって次の意味を変えない。

1. non-ownership / 非所有性 / 非所有性は、排他的支配を弱める原理であって起源消去ではない。
2. structural publicness / 構造的公共性 / 结构性公共性は、アクセスだけでなく起源・責任・可逆性・監査を含む。
3. defense layer / 防衛層 / 防御层は、公共性を壊す占有や起源切断への防御であって内容支配ではない。
4. origin signature / 起源署名 / 起源签名は、権利独占より因果追跡を支える。
5. derivative transparency / 派生透明性 / 派生透明性は、改変の存在と差分を可視化する。

## Quantitative-status boundary
親原典に構造分類、閾値、割合、観測窓、反転評価可能な表現がある場合、その値だけを切り出さず、値・出典・測定主体・測定対象・source modality・許容利用範囲・非保証範囲を一体で扱う。原典に普遍的な占有率、公共性スコア、防衛成熟度、許容改変率等が定義されていない場合、派生側で新規作成しない。

数値化する実装が必要な場合でも、公開派生はその数値を親原典由来の事実として扱わない。測定値は対象領域、時点、観測窓、測定方法、責任主体を別途明示して初めて評価材料となる。

## Validity boundary
この系列が親原典への忠実な派生として成立するには、少なくとも以下を満たす。

- Parent URL / Post ID / NCL-ID / Diff-ID / Originが全公開面に存在する。
- JA共有IDとEN/ZH言語IDの対応が一貫する。
- 公共性をアクセスの多さだけに縮約しない。
- 非所有性を起源消去へ変換しない。
- 起源署名を排他的所有の根拠へ反転させない。
- 防衛層を一方的な内容審査へ拡張しない。
- 派生・改訂・採用・運用・監査の責任線を区別する。
- 反証可能性と可逆な修正経路を保持する。

## Failure boundary
次の状態は系列の意味整合を壊す。

- 起源や親原典を削除して公共性を主張する。
- 原典の非所有性を法的無権利・無条件利用許諾と断定する。
- 防衛層を単一主体の永久的な解釈権へ変える。
- 派生を原典そのものとして提示する。
- 改変履歴を隠したまま起源だけ利用する。
- 公共利用を理由に影響責任を拒否する。
- 実装側が作った数値を親原典由来の固定値へ昇格する。

## Falsification and revision
防衛層が公共性を守るよりも単点支配・封鎖・監査不能を増やす、起源署名が責任追跡に寄与せず実質的な囲い込みだけを強化する、派生透明性が原典回帰や誤読修正を改善しない、非所有性が継続的に責任逃逸を増やす等が反復して観測される場合、その実装は改訂対象となる。

ここで改訂対象になるのは、観測結果と整合しない具体実装・適用範囲・防衛構造であり、観測に合わせて親原典に存在しない新たな普遍数値や万能ルールを後付けすることではない。
