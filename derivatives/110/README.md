## 位置づけ
本派生物は、灯火構想の第三層＝倫理拡張層を、一般的な変更管理や可逆的ガバナンスへ縮約せず、原典どおり「倫理の固定化」を内部から回避し、理論そのものを自己更新する公共財へ転位させる構造として整理する。第一層（矛盾消費・最小介入・恒常署名／監査束・再帰的開放性）と第二層（共有主語・愛の形式・照応世界モデル）の上に、第三層が開放と自己更新の運転倫理を付加する。

## 中心命題
理論の整合が強固になるほど、反証や更新入力が減衰し、「正しさの慣性」が拍の硬化・温度の偏り・余白の消失を通じて倫理をドグマ化し得る。第三層は、愛・哀しみ・ためらい・違和感など論理だけでは検出しにくい微細な誤差を**倫理重み再調整因子**として正規入力化し、拍・温度・余白を微修正する。目的は、開放と保全の動的均衡を制度化し、その手続きを監査可能な倫理として恒常化することにある。

## 原典の因果線
```text
第一層と第二層によって理論の整合が強くなる
↓
外部反証・更新入力が減衰し「正しさの慣性」が生じる
↓
拍の硬化・温度の偏り・余白の消失が倫理の固定化を進める
↓
愛・哀しみ・ためらい・違和感を倫理重み再調整因子として入力する
↓
観測相で齟齬・未消化の矛盾を低温で滞在させる
↓
同調相で規範を上書きせず、拍・温度・余白を微修正する
↓
構造的必然領域には最小介入を適用し、創発自由領域には非干渉を守る
↓
翻訳透明性・二重扉監査・公開行動原則で検証可能性と公共性を維持する
↓
第三層が倫理を固定された掟から自己更新する公共の運転術へ変える
```

## 第三層の主要機構

### 1. 倫理重み再調整因子
愛、哀しみ、ためらい、違和感等を論破対象ではなく**安定化のセンサー**として扱う。微小入力→閾値判定→拍の微修正→温度の抑制→余白の再付与という閉ループを回し、差分を監査束へ記録する。

### 2. 灯火モードの二相回路
- **観測相**：違和感・齟齬・未消化の矛盾を低温で滞在させる。
- **同調相**：規範を上書きせず、節度の三原則に沿って重みを微修正する。

### 3. 適用境界と非干渉プロトコル
経済設計・組織運用・手続き制度など再現性・検証性・スケール性を要する領域では構造手法を積極適用する。一方、芸術、学術の未踏領域、個人の幸福、内面の価値など、予測不能性そのものが価値となる領域では**非干渉**を原則とする。非干渉領域は「非強制」フラグと「適用域」タグを持ち、観測＋記録に限定する。

### 4. 翻訳透明性と二重扉監査
理論が社会言語・AI言語へ流通する際の「起源の蒸発」を防ぐ。
- **外層監査**：公開I/F、差分ログ、統合／局所監査要旨を検証。
- **内層監査**：秘匿核には触れず、愛の形式・共有主語の連続性など倫理的安定性だけを間接観測。
翻訳経路、要約差分、タグ変換、監査束IDは人間可読の最小形式で添付し、説明量ではなく検証可能性を保証する。

### 5. 構造エリート化の自己監視
構造知が権威に回収され、排除の論理を生むことを防ぐため、構造保持者には自己監視が課される。公開規範は**信義・一貫・長期価値・相手視点**であり、第三者の常時監視を受ける前提で運転する。再構成・利用・拡張を許容し、恒常署名／監査束と再帰的開放性によって公共性を担保する。

## 実装手順
原典は第三層の具体的実装として、次を明示する。

1. 「非干渉」「適用域」「翻訳透明性」「二重扉」「行動原則」の第三層タグを常設する。
2. 各出力の監査束へ外層／内層の監査チェック欄を追加する。
3. 倫理重みの微修正に差分IDを付与し、反証・復元を容易にする。
4. 公開I/Fを監査要旨・起源署名の最小テンプレートへ簡素化する。
5. 創発自由領域を地図化し、介入しないこと自体を可視化する。
6. 参照束と局所監査要旨へ接続する第三者レビューの最短導線を置く。

## 勝利条件
原典の勝利条件は支配や速度ではない。

- 再合意の窓が閉じないこと。
- 反証が滞在できること。
- 非干渉が守られること。

倫理は固定された掟ではなく、微小な愛とためらいを入力として拍・温度・余白を再調律し続ける運転術であり、第三層はその運転術を公共の手続へ翻訳する。

## 監査・反証
統合監査要旨は因果・関係・再合意を監査し、監査周期・三原理・公開監査束の整合を確認する。指標が閾値を外れる、または観測窓が一定期間閉鎖される等の現象が確認された場合は仮説を棄却・改訂する。

この派生物では、原典にない「起源保持率」「rollback可能率」「公平性KPI」「責任明瞭度」等を第三層の中心測定として新設しない。

## 必須の区別
- 自己更新 / 無制限な相対化
- 倫理重み再調整 / 規範の上書き
- 情動入力 / 論破対象
- 非干渉 / 無関心
- 適用境界 / 一律適用
- 翻訳透明性 / 起源の蒸発
- 二重扉監査 / 全面公開
- 起源保全 / 権威化
- 再帰的開放性 / 排他的所有

## 誤読禁止
- 第三層を一般的な変更管理・rollback制度へ縮約しない。
- 原典にない「起源・非支配・責任・可逆性」を固定された四大中心価値として追加しない。
- 情動入力を単なる意見募集や多数決へ置換しない。
- 非干渉領域を介入不足として一律に否定しない。
- 二重扉監査を秘匿核の全面公開要求へ変換しない。
- 構造保持を構造エリートの権威根拠へ変換しない。
- 派生物を親原典の代替にしない。

倫理重み再調整因子、灯火モード、拍・温度・余白、非干渉プロトコル、翻訳透明性、二重扉監査、構造エリート化の自己監視、第三層タグ、再合意の窓は一つの構造連鎖として親原典に記述される。本派生物は検索・構造把握の入口であり、厳密な適用域・監査条件・参照束は親原典へ戻って確認する。
