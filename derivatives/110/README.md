## 位置づけ
本派生物は、灯火構想の「第三層」を完成した倫理体系として固定するのではなく、社会接続のたびに外部反証・差分・新しい当事者・時間変化を取り込みながら更新できる開放層として整理する。更新は理念の放棄ではなく、起源署名と中心価値を保持したまま、制度・実装・責任境界を再検証する構造である。

## 中心命題
倫理を長期運転するには、原則を固定するだけでも、状況に応じて無制限に相対化するだけでも足りない。起源、非支配、責任、可逆性という核を保持しつつ、社会実装で発生した矛盾、異議、技術変化、制度差を第三層へ入力し、変更点と反証条件を記録して再合意する更新機構が必要である。

## 因果線
```text
倫理原則を固定し完成版とみなす
↓
社会・技術・当事者の変化が外へ落ちる
↓
規範と実装の乖離が増える
↓
第三層を開放された更新面として設計する
↓
起源と中心価値を固定する
↓
矛盾・異議・制度差・新事実を入力する
↓
変更差分と責任主体を記録する
↓
限定実装とrollbackで検証する
↓
再合意し次の更新窓を残す
```

## 構造層
**1.** 起源層：灯火構想の起源と中心価値を追跡可能にする。

**2.** 開放層：新しい当事者、異議、技術変化を更新入力へ入れる。

**3.** 差分層：理念、制度、運用のどこを変えたか分離記録する。

**4.** 検証層：限定実装、監査、rollbackで副作用を確認する。

**5.** 再合意層：更新を最終化せず、次の反証窓を保持する。


## 適用例
**1.** AI倫理方針をモデル更新や新しい利用形態に合わせて改訂する。

**2.** コミュニティ規範で新規参加者の異議を制度更新へ反映する。

**3.** 社会実装で原理念とローカル法制度の差分を管理する。

**4.** 長期プロジェクトで過去の合意を定期的に再監査する。

## 測定・監査点
- 起源保持率
- 更新入力受付率
- 異議記録率
- 差分追跡率
- rollback可能率
- 副作用検出率
- 再合意率
- 原典回帰率

## 成立条件
- 起源と中心価値が明示される。
- 更新理由と変更差分が記録される。
- 異議や反例が入力へ戻る。
- 限定実装とrollbackが可能である。
- 更新後も責任主体が明確である。
- 次の反証窓を閉じない。

## 失敗条件
- 原則を不可侵化する。
- 状況適応の名で中心価値を消す。
- 変更履歴を残さない。
- 異議を排除する。
- 更新を恒常的な例外拡大に使う。
- rollback不能な制度変更を無監査で行う。

## 反証条件
- 開放更新しても規範と実装の乖離が改善しない。
- 差分管理が運用コストだけを増やす。
- rollbackを持つと実装品質が継続的に悪化する。
- 異議入力を増やしても重大副作用が減らない。
- 固定規範の方が長期的に安全・公平・透明で一貫して優れる。

## 必須の区別
- 更新 / 原則放棄
- 開放 / 無秩序
- 起源保持 / 権威化
- 異議 / 破壊
- 差分 / 改竄
- rollback / 責任回避
- 再合意 / 同調

## 誤読禁止
- 倫理は何でも相対化できると解釈しない。
- 第三層を無制限な例外処理層にしない。
- 起源を権威の根拠として使わない。
- 異議を必ず採用すべき命令へ変えない。
- 更新を失敗隠蔽の言い換えに使わない。
- 派生物を原典の代替にしない。
