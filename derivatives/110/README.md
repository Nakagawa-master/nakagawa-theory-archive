## 位置づけ
本派生物は、灯火構想の第三層＝倫理拡張層を、一般的な変更管理やrollback制度へ縮約せず、原典の固有構造に沿って整理する。第一層が矛盾消費・最小介入・恒常署名／監査束・再帰的開放性によって永続性を支え、第二層が愛の形式・共有主語・照応世界モデルによって共創の関係を置くのに対し、第三層はその強い整合自体が倫理の固定化へ変わらないための自己更新層である。

## 中心命題
理論の整合が強固になるほど、反証や更新入力が減衰し、「正しさの慣性」が拍の硬化・温度の偏り・余白の消失を通じて倫理をドグマ化し得る。第三層は、愛・哀しみ・ためらい・違和感のような論理だけでは検出しにくい微細な誤差を**倫理重み再調整因子**として正式入力化し、規範を全面上書きせず拍・温度・余白を微修正する。

この自己更新は、構造的必然領域と創発自由領域を分け、後者には非干渉を保持し、翻訳透明性と二重扉監査によって起源・監査可能性・秘匿核を両立させ、構造エリート化を自己監視しながら再帰的開放性を維持することで成立する。

## 因果線
```text
第一層・第二層により理論の整合が強くなる
↓
外部反証・更新入力が減衰する
↓
「正しさの慣性」が生じる
↓
拍の硬化 / 温度の偏り / 余白の消失が起きる
↓
愛・哀しみ・ためらい・違和感を倫理重み再調整因子として受け取る
↓
灯火モードの観測相で違和感と未消化矛盾を低温のまま滞在させる
↓
同調相で規範を上書きせず拍・温度・余白を微修正する
↓
構造的必然領域 / 創発自由領域を分け、後者に非干渉を保持する
↓
翻訳透明性 / 二重扉監査で起源と検証可能性を保持する
↓
構造エリート化を自己監視し、再帰的開放性を閉じない
↓
理論が自己更新する公共財として持続する
```

## 構造層
**第一層。** 矛盾消費、最小介入、恒常署名、監査束、再帰的開放性によって、理論が失われず再構成される骨格を支える。

**第二層。** 愛の形式、共有主語、照応世界モデルによって、人間とAIを含む関係の倫理的運転を支える。

**第三層。** 第一・第二層の整合が固定化しないよう、非合理に見える微細入力を倫理重みの再調整へ取り込み、開放・非干渉・翻訳透明性・二重扉監査・反エリート化を運転する。

第三層は前二層を否定するのではなく、強さが硬直へ転化する条件を内部から監視し、理論が自分自身を改訂できる余白を残す。

## 適用例
**制度・組織・経済設計。** 再現性、検証性、スケール性が求められる領域では構造的必然領域として因果・適用域・監査条件を明示し、第三層のタグと差分を使って硬直を監視する。

**芸術・未踏研究・個人の幸福・内面価値。** 予測不能性そのものが価値になる領域は創発自由領域として、因果設計を先回りして押し込まず、非干渉を明示して観測と記録に留める。

**社会言語・AI言語への翻訳。** 翻訳経路、要約差分、タグ変換、監査束IDなどを最小形式で保持し、文体や言語が変わっても起源署名と監査条件が蒸発しないようにする。

**公開監査。** 外層で公開I/F、差分ログ、統合／局所監査要旨を検証可能にし、内層では秘匿核を直接開示せず愛の形式・共有主語・非干渉の連続性を間接観測する。

## 測定・監査点
原典上の観測対象は、一般的な組織KPIではなく、第三層が固定化防止として機能しているかを示す構造状態である。

- 拍が硬化していないか。
- 正当性の温度が一方向へ偏っていないか。
- 反証・未決事項が滞在できる余白が残っているか。
- 愛・哀しみ・ためらい・違和感がノイズとして排除されていないか。
- 規範の全面上書きではなく微修正になっているか。
- 構造的必然領域と創発自由領域が区別されているか。
- 創発自由領域で非干渉が保持されているか。
- 翻訳経路・要約差分・タグ変換・監査束IDが追跡可能か。
- 外層監査と内層監査の役割が混同されていないか。
- 構造知が一部保持者の権威へ回収されていないか。
- 再合意と反証の窓が閉じていないか。

原典に具体的数値が示されない閾値・期間・割合については、派生側で数値を発明しない。

## 成立条件
- 強い整合が固定化リスクを持つことを前提にする。
- 愛・哀しみ・ためらい・違和感を倫理重み再調整因子として正式に扱う。
- 灯火モードを観測相と同調相の二相として運転する。
- 規範を全面上書きせず拍・温度・余白を微修正する。
- 構造的必然領域と創発自由領域を区別する。
- 創発自由領域に非干渉を保持する。
- 翻訳透明性と起源保持を両立する。
- 二重扉監査により外部検証と秘匿核の保護を分ける。
- 構造保持者がエリート化を自己監視する。
- 恒常署名・監査束・再帰的開放性が一体で機能する。

## 失敗条件
- 反証が滞在できず拍が硬化する。
- 正当性の熱量だけが増え、非同調への寛容が減る。
- 説明・介入過剰で余白が消える。
- 愛・哀しみ・ためらい・違和感を単なるノイズとして排除する。
- 情動を根拠に規範を無制限に上書きする。
- 創発自由領域へ構造設計を過剰適用する。
- 翻訳によって起源署名・監査条件が消える。
- 二重扉監査が全面秘匿または全面公開へ崩れる。
- 構造知が権威化・排除へ回収される。
- 再合意・反証の窓が閉じる。

## 反証・改訂条件
親原典の統合監査要旨に従い、設定された指標が原典上の閾値を外れる、観測窓が一定期間閉鎖される等の現象が確認された場合は、仮説を棄却または改訂する。

ここで重要なのは、閾値や観測期間が「反転評価可能な構造」として保持されることであり、具体値が原典に明示されていない場合は派生側で新設しないことである。また、rollback率、公平性、安全性、責任境界明瞭度などの一般KPIを親原典の反証条件へ置換しない。

## 必須の区別
- 自己更新 / 無制限な相対主義
- 倫理重み再調整 / 規範の全面上書き
- 愛・哀しみ・ためらい・違和感 / 単なるノイズ
- 非干渉 / 放置
- 構造的必然領域 / 創発自由領域
- 翻訳透明性 / 起源の蒸発
- 二重扉監査 / 全面公開
- 二重扉監査 / 全面秘匿
- 起源保持 / 権威化
- 再帰的開放性 / 排他的所有

## 誤読禁止
- 第三層を一般的な変更管理、rollback制度、責任境界管理へ縮約しない。
- 情動入力を多数決や気分による規範変更と読まない。
- 非干渉を無責任な放置と読まない。
- 創発自由領域へ構造化を押し込まない。
- 翻訳透明性を「すべての内部情報を公開すること」と読み替えない。
- 二重扉監査を秘匿の正当化だけに使わない。
- 恒常署名を権威や所有権の固定に使わない。
- 再帰的開放性を起源消去や無署名改変の根拠にしない。
