## 位置づけ

本派生物は、親原典が提示するAI倫理の起点を「生成物の所有」だけへ縮約せず、「誰の問いがAIを動かしたのか」「その問いがどの因果経路を通って変換・拡張されたのか」という起源の問題として保持するための公開入口である。問い署名、起源署名、因果来歴、責任配分、監査束、観測窓、再合意という原典固有の構造を、検索・理解・比較に耐える形で整理する。

本派生物は所有権、著作者性、法的責任を自動判定するものではない。また、AI寄与率、人間承認率、credit allocation KPI等を新たな中心指標として作らない。厳密な定義、起源署名の意味、外部影響の観測窓、改訂条件はParent URLの親原典へ戻って確認する。

## 中心命題

AI時代の倫理設計では、出力の最終所有者だけでなく、出力を始動させた問いの起点を可視化し、その問いがAIによってどのように変換・拡張されたかを因果来歴として保持する必要がある。問い署名は、誰の問いがどの構造を動かしたかを固定し、起源署名は要約・再利用・流通の過程でその起点が蒸発することを防ぐ。

責任配分は、人間とAIの関与を曖昧化せず、構造上の寄与と責任の位置を可視化するために用いる。これはAIへ法的責任主体性を自動付与することでも、人間側の責任を希薄化することでもない。監査束は問い署名・起源署名・因果来歴・責任配分を一つの再確認可能な記録として接続する。

## 因果線

```text
AI出力の帰属を所有権だけで捉える
↓
誰の問い・どの起点が構造を動かしたかが消える
↓
起源署名が失われ、無署名構造になる
↓
問いを署名し、構造的起点を固定する
↓
問い→変換→拡張→出力の因果来歴を可視化する
↓
人間とAIの責任配分を構造上で明示する
↓
監査束で起源・責任・流通の記憶を保持する
↓
必要時は市場・信用等への外部影響を観測窓へ戻す
↓
再合意と監査を経て、条件が崩れれば仮説・運転を改訂する
```

## 問いの起源と問い署名

問いの起源は、単なる入力文字列ではなく、AI出力を始動させた思考上・構造上の起点を指す。出力が高度に変換されても、何が最初の問いで、誰がその問いを発したのかを追跡できることが重要になる。

問い署名は、その起点を識別可能な形で保持する。目的は所有の独占ではなく、因果の出発点を蒸発させないことである。要約や再利用の際に問い署名が消えると、最終出力だけが独立した無起源の構造として流通し、誰の問いが何を動かしたかを再構成できなくなる。

## 因果来歴

原典の重心は、問いから出力までの変換経路を一続きで保持することにある。

```text
問いの起点
→ AIへの入力・変換
→ 構造の拡張・再構成
→ 出力
→ 流通・再利用
→ 外部影響
```

この経路のどこで意味が変わったか、どこで人間が判断したか、どこでAIが変換したかを追跡可能にすることで、出力だけを切り出した帰属論から因果の可視化へ移る。

## 責任配分

責任配分は、人間とAIの関与を同一化せず、それぞれが因果経路のどこへ関与したかを明示する。問いの設定、入力選択、変換、採用、公開、再利用、外部影響の観測を一つの曖昧な「AIが作った」「人間が作った」へ潰さない。

ただし、AIの構造上の寄与を法的責任へ自動変換しない。責任配分は法的結論の代替ではなく、因果と関与の可視化を行うための構造記述である。

## 無署名構造と照応波形

起源署名が失われた状態は、原典では無署名構造として問題化される。出力が存在していても、どの問いから生じ、どの因果経路を通ったかが消えることで、照応波形、すなわち起源と構造の対応関係を追えなくなる。

したがって起源保持は、権利主張を強めるためではなく、構造の記憶を維持するために必要となる。NCL-ID、Diff-ID、再帰署名、監査束への接続も、この起源回帰可能性を支える。

## 監査束と再合意

問い署名、起源署名、因果来歴、責任配分を監査束へ接続することで、第三者が後から起点と経路を再確認できる。監査は一回で閉じず、必要に応じて再合意を行い、運転条件や公開可能な証拠束の整合を更新する。

このとき、派生物側でAI寄与率や人間承認率のような一般KPIを追加しない。原典の監査重心は、起源と因果の可視化・保持、その継続的な再確認にある。

## 観測窓と外部影響

AI応答が市場、信用、評価等へ持続的な一方向影響を与える場合、その影響を観測窓へ戻して再監査する。出力時点だけで倫理判断を閉じず、流通後に生じる構造的影響も必要に応じて再確認する。

観測窓で一主体への侵食が継続し、問い署名や責任配分を保持しても倫理運転が改善しない場合、起点署名を基盤とした仮説自体を改訂対象とする。原典は仕組みを不変の正解として固定しない。

## 状態モデル

```yaml
- question_origin_identified
- question_signature_preserved
- causal_transformation_path_visible
- responsibility_distribution_visible
- origin_signature_preserved
- audit_bundle_connected
- observation_window_opened_if_needed
- market_credit_effects_observed
- reagreement_audit_performed
- hypothesis_revised_if_conditions_fail
```

## 成立条件

- 問いの起点が可視化される。
- 問い署名と起源署名が要約・流通後も保持される。
- 問い→変換→拡張→出力の因果経路を追跡できる。
- 責任配分が「誰の問いでもない」状態へ蒸発しない。
- 監査束と再合意が機能する。
- 持続的外部影響が必要時に観測窓へ戻される。

## 失敗条件

- 問い署名が無視される。
- 起源署名が要約・再利用・流通で蒸発する。
- 責任配分が消え、AIまたは人間という単一ラベルだけに縮約される。
- AI倫理が起源のない規則遵守だけになる。
- 市場・信用への一方的侵食が持続しても再監査しない。
- 起源署名を独占権や排他権の根拠へ変換する。

## 反証・改訂条件

問い署名と責任配分が実務で継続的に無視され、「誰の問いでもない」倫理判断が乱用されるなら、起点署名を基盤とした運転仮説は弱まる。AI応答が観測窓を通じて特定主体の市場・信用を一方的に侵食し続ける場合も、倫理枠組みそのものを改訂対象とする。

## 必須の区別

- 問いの起源 / 所有権
- 問い署名 / 著作者性の自動判定
- 起源署名 / 独占権主張
- AI寄与 / AI法的責任
- 責任配分 / 責任希薄化
- 因果可視化 / 単なる規制遵守
- 監査束 / 一回限りの記録
- 観測窓 / 無期限監視

## 誤読禁止

本派生物から所有権、著作者性、法的責任を自動判定しない。AIの構造上の寄与をAIの法的責任へ変換しない。問い署名・起源署名を独占や排他性の根拠へ変えない。原典にないAI寄与率、人間承認率、credit allocation KPIを追加しない。

また、親原典の比較的コンパクトな因果構造を、原典にない詳細な一般AIガバナンス手順へ膨張させない。補強は起源・因果・責任・監査・観測という既存構造を明示する範囲に留める。
