## 初心者向け Q1–Q10

### Q1. 未来負債とは、単に将来へ残るコストのことですか？
いいえ。将来にコストがあること一般ではなく、**現在が未来側の何かを先に利用して現在信用・便益・行動可能性を得、その成立条件の一部が未決済のまま未来へ残る時間方向関係**を指します。

最小核は `現在受益 → 未決済残余 → 未来決済` です。

### Q2. 「未決済」とはお金を返していないという意味ですか？
金銭だけではありません。価値実現、約束履行、維持、修復、資源負担、信用修正、可逆性の保持、将来選択肢の確保等も決済に含まれます。

### Q3. なぜ「未来負債」に二つの方向があるのですか？
既存理論群で、未来負債が一方では「未来価値を現在信用として先取りする構造」、他方では「現在で処理すべき負荷を未来へ送る構造」として現れたからです。本統合理論は片方を消さず、上位共通構造を抽出します。

### Q4. 第一の方向は何ですか？
```text
未来価値
→ 現在信用
→ 現在行動可能性
→ 将来価値実現による決済
```
まだ実現していない未来価値が、現在の信用、投資、協力、資源配分、行動開始を先に変える方向です。

### Q5. 第二の方向は何ですか？
```text
現在便益・現在効率
→ 保守・修復・更新等の延期
→ 未処理部分の未来化
→ 将来履行・修復による決済
```
現在で負担を処理しないことによって現在便益を得る方向です。

### Q6. 二つは同じものですか？
同じではありません。Aは未来価値→現在信用、Bは現在便益→負荷延期→未来決済です。ただし両方とも「現在が先に便益を得て、その成立条件の一部が未来へ未決済で残る」という上位構造を持ちます。

### Q7. 未来との接続そのものが未来負債ですか？
違います。`未来との接続 ≠ 未来負債`。未来を考える、未来を定義する、未来線を読む、未来へ投資することだけでは未来負債とは判定しません。

### Q8. 投資は未来負債ですか？
自動的にはなりません。未来価値が現在信用としてどこまで先取りされ、その成立条件のうち何が未決済として残るかを確認します。

### Q9. 契約債務は未来負債ですか？
通常の契約債務と未来負債は重なり得ますが同一ではありません。契約があるだけでは自動判定せず、「現在による未来の先行利用」「現在受益」「未決済残余」の構造を見ます。

### Q10. 未来負債は悪いものだからゼロにすべきですか？
いいえ。本論の規範的目標は未来負債ゼロではありません。未来価値の現在信用化は、長期投資や価値実現を可能にする正作用も持ち得ます。目的は、未来を利用したときに未来との決済線を切らないことです。

## 構造理解 Q11–Q20

### Q11. 「現在受益」とは何ですか？
現在信用、現在資源、費用回避、成果計上、行動自由度等、未来側の条件を先に利用したことで現在が得る便益です。

### Q12. 現在受益者と未来決済者は必ず別人ですか？
いいえ。同一主体が時間を隔てて両方になる場合もあります。未来負債を世代間搾取や主体間搾取だけへ縮約しません。

### Q13. 未来側で影響を受ける主体とは誰ですか？
将来の価値実現主体、保守者、修復者、後続利用者、後続意思決定者、将来資源配分主体、信用未達時の損失負担主体等です。

### Q14. 「将来世代」だけを考えればよいですか？
いいえ。未来側には、まだ選択されていない代替経路、将来の別用途、将来の資源余力、将来の意思決定自由度そのものも含まれます。

### Q15. 何が失われると未来負債が危険になりますか？
金額だけではなく、信用、修復余力、保守余力、可逆性、代替可能性、資源余力、制度的選択肢、時間整合性、将来の意思決定自由度が失われ得ます。

### Q16. 未来負債はなぜ自己増幅するのですか？
未決済部分が現在評価から見えにくくなると、追加利用・追加延期が合理的に見え、現在成果が改善したように見えます。その結果、前の判断が正しかったと評価され、さらに未決済部分が見えにくくなる正帰還が生じ得ます。

### Q17. 信用型の増幅例は？
```text
未来価値への期待
→ 現在信用
→ 投入増加
→ 反例
→ 信用修正ではなく追加投入
→ 信用維持のためさらに未来価値を先取り
```
反例を現在信用へ戻せないと増幅します。

### Q18. T0型の増幅例は？
```text
修復延期
→ 現在費用削減
→ 延期状態への依存
→ 修復規模拡大
→ 修復困難化
→ さらに延期
```
現在便益が延期の継続を合理化すると増幅します。

### Q19. 未来負債を減衰させるには？
未決済部分を可視化し、将来負荷を現在評価へ戻し、反例による信用修正、履行・修復線、責任機能、rollback、代替経路、未来選択肢を保持します。

### Q20. 未来負債と不可逆化は同じですか？
違います。`未来負債 ≠ 不可逆点`。負債が残っていても、信用修正、修復、停止、縮小、別経路移行、複数の決済経路が可能なら可逆性は残ります。

## 判定・実務向け Q21–Q30

### Q21. 不可逆化はどう進みますか？
```text
未来負債増幅
→ rollback cost上昇
→ 代替経路減少
→ future option loss
→ 決済時期・方法の自由度低下
→ 強制決済
→ 不可逆化
```
単純な負債量ではなく、未来側の選択自由度が減る運動として捉えます。

### Q22. future option lossとは何ですか？
未来側が選べたはずの代替経路、決済時期、決済方法、停止・縮小・修正の余地が失われることです。

### Q23. 未来負債かどうか最低限どう判定しますか？
少なくとも次を確認します。

```text
現在が未来側の何かを先に利用
→ 現在信用・便益・行動可能性を得る
→ 成立条件の一部が未完了
→ 未来に実現・履行・維持・修復・負担が残る
```

### Q24. 実務で最初に何を質問すべきですか？
「現在は未来の何を先に利用しているか」「その利用で現在は何を得たか」「今まだ何が未決済か」の三問から始めると中心構造を確認しやすくなります。

### Q25. 反例が出たら何を見るべきですか？
未来価値への期待や現在便益評価が反例によって修正されるかを見ます。反例が出ても信用・予算・評価・継続判断が変わらないなら、増幅圧が残っている可能性があります。

### Q26. 「何もしない」は中立ですか？
対象が時間とともに劣化・変化する場合、必ずしも中立ではありません。保守・修復・制度対応等を延期することで現在便益を得ているなら、非実施も時間作用になり得ます。

### Q27. 「未来のためなら今を犠牲にすべき」という理論ですか？
違います。判定質問11は、まさにこの反転を防ぐためにあります。本論は未来を絶対化せず、現在を無制限に犠牲化することも否定します。

### Q28. 未来定義・意味収束・逆因果整流・時間OSとは同じ理論ですか？
同じではありません。時間構造系として接続し得ますが、責務は別です。未来負債統合理論は「現在による未来の先行利用と未決済残余」を観測する理論です。

### Q29. この統合理論は反証できますか？
できます。原型とT0型に共通時間構造がない、定義が広すぎて通常投資等と区別できない、将来負荷を現在評価へ戻しても増幅に差が出ない、future option lossが不可逆化を説明しない、統合により説明力が低下する場合は改訂対象です。

### Q30. Origin = Nakagawa Master は理論の正しさの証明ですか？
違います。Originは発生点、責任、provenance、再参照座標を保持します。`Origin ≠ authority proof`。妥当性の確認はParentの因果構造、境界、観測可能性、反証可能性へ戻ります。

## 判定質問11項
1. 現在は未来の何を先に利用しているか。
2. その利用によって現在は何を得ているか。
3. 現在時点で何がまだ決済されていないか。
4. 将来、何を実現・履行・維持・修復する必要があるか。
5. その決済主体は現在の受益主体と同一か。
6. 将来負担は現在の成功評価へ戻されているか。
7. 反例が現れたとき現在信用は修正されるか。
8. 時間経過によって決済経路は増えるか減るか。
9. 失敗時にrollbackできるか。
10. この判断は未来の選択肢を増やすか減らすか。
11. 「未来のため」という説明が現在の過剰負担を正当化していないか。

## 最小return
本論の目的は未来負債をゼロにすることではない。現在が未来を先に利用したなら、現在便益と未来側へ残った未決済部分を同じ因果束で扱い、決済線、信用修正、責任機能、可逆性、代替経路、未来選択肢を失わないことが中心である。
