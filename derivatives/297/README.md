## 位置づけ
未来負債統合理論は、過去の中川マスター理論群で別方向に現れていた二つの「未来負債」を、片方で他方を上書きせず、より上位の時間構造へ統合する。

第一の方向は、まだ実現していない**未来価値を現在信用として先取りする方向**である。未来に成立すると見込まれる価値が、現在の信用、資源配分、投資、協力、行動開始を先に変える。

第二の方向は、現在処理すべき保守、修復、更新、制度対応、未実装コミットメント等を延期し、**現在便益と引き換えに未処理負荷を未来へ送る方向**である。

二つは同じ向きではない。しかし共通して、現在が未来側の何かを先に利用して信用・便益・行動可能性を得、その成立条件の一部が現在では完了せず、未来側へ未決済残余として残る。

## 中心問題
**現在が未来を先に利用して現在側の便益を得たとき、その便益を成立させた条件のうち何がまだ決済されておらず、誰が・いつ・どの方法で未来側から引き受けるのか。**

本論は、未来負債を「未来に悪いコストが残ること」へ縮約しない。問題の中心は、未来そのものでも、金額そのものでもなく、**現在受益と未来決済の時間差、および両者を結ぶ因果線が残っているか**である。

## 一文定義
**未来負債とは、現在が未来価値または未来側の履行・維持・修復・資源・選択可能性を先に利用して信用または便益を得た結果、その成立条件のうち未だ決済されていない部分が、現在と未来の間に残る時間方向関係である。**

最重要用語は **未決済関係**。

## 上位共通核
```text
現在受益
→ 未決済残余
→ 未来決済
```

ここでいう「決済」は金銭精算だけではない。

- 価値実現
- 約束履行
- 維持
- 修復
- 資源負担
- 信用回収・信用修正
- 可逆性の保持
- 将来選択肢の確保

## 二つの時間方向
### A｜未来価値の先取り
```text
未来価値
→ 現在信用
→ 現在行動可能性
→ 将来価値実現による決済
```

この方向では、まだ成立していない未来価値が現在の信用や資源配分を変える。これは長期投資、研究、共同制作、制度構築等を可能にする正作用も持ち得る。

したがって、未来価値の先取り自体を悪としない。重要なのは、期待への反例が現れたときに信用評価を修正できること、そして未来側へ残る実現条件を現在の成功評価から切り離さないことである。

### B｜現在負荷の先送り
```text
現在便益・現在効率
→ 必要負荷の延期
→ 未処理部分の未来化
→ 将来履行・修復による決済
```

保守、修復、更新、制度対応、未実装コミットメント等を現在で処理しないことで、現在コストの回避や現状維持という便益を得る場合がある。

対象が時間とともに劣化・変化するなら、何もしないことも中立ではない。非実施そのものが、将来の修復規模や選択肢へ作用し得る。

### 二方向を統合しても消してはいけない差
原型とT0型は「旧定義 / 新定義」の関係ではない。AをBで上書きせず、BをAへ還元しない。

```text
A: 未来価値を現在信用として先取りする
B: 現在負荷を未来へ延期する

共通:
現在が先に何かを受け取る
→ 成立条件の一部が未来へ残る
→ 未来で整合・履行・維持・修復等が必要になる
```

## 原型〈未来の負債〉の保存
原型が捉えたのは、未来を単なる到来待ちの対象ではなく、現在を実際に変える作用因へ移す時間構造である。

```text
未来に成立すると見込まれる価値
→ 現在信用・現在判断が変化
→ 現在行動が変化
→ 未来の実現条件も変化
```

この構造には、未来実現へ必要な現在資源を集める力がある。よって、未来負債を道徳的な「悪」へ固定しない。

## 時間倫理・未来負債T0への分岐
時間倫理では、約束されたが履行されていないもの、必要と認識されたが実装されていないもの、現在処理できたが先送りされたものが時間上の未決済として現れる。

これを独立した第三類型へ増やさず、現在負荷を未来化するT0線への橋として扱う。

## 現在受益者と未来決済者
未来負債は「いつ」の問題であると同時に「誰」の問題でもある。

### 現在受益側
- 現在信用を得る主体
- 現在資源を得る主体
- 現在コストを回避する主体
- 現在成果を計上する主体
- 現在の行動自由度を増やす主体

### 未来決済側
- 将来の価値実現主体
- 将来の履行主体
- 保守主体
- 修復主体
- 後続利用者
- 後続意思決定者
- 将来資源配分主体
- 信用未達時の損失負担主体

両者は異なる場合も、同一主体が時間を隔てて双方になる場合もある。したがって、未来負債を「誰かが別の誰かへ負担を押しつける搾取」だけへ縮約しない。

## 見えない被影響主体と失われ得る資産

未来負債によって失われ得るものは、金額だけではない。

## 時間発展
### 短期
信用形成、投資可能性、現在資源増加、コスト回避、効率向上、行動開始の前倒し等、正作用を持ち得る。短期の正作用だけでは未来負債を否定できない。

### 中期
履行要求、保守量、説明責任、追加投入圧力が増え、信用への反例も蓄積し得る。更新自由度が下がる場合もある。

### 長期
信用失効、大規模修復、制度硬直、資源制約、lock-in、future option loss、後続主体への負担固定へ進み得る。

## 不可逆化とfuture option loss
最重要切断:

```text
未来負債 ≠ 不可逆点
```

未来負債が存在していても、複数の決済経路があり、信用修正でき、修復開始でき、別方式へ移行でき、停止・縮小できるなら可逆性は残る。

不可逆化は次の運動として捉える。

```text
未来負債増幅
→ rollback cost上昇
→ 代替経路減少
→ future option loss
→ 決済時期・方法の自由度低下
→ 強制決済
→ 不可逆化
```

本論の最終劣化状態は、単純な「負債額が大きい」状態ではない。**未来側が、決済するか否か、いつ決済するか、どの方法で決済するかを選ぶ自由を失い、過去の未決済部分を強制的に引き受けざるを得なくなる状態**である。

## 判定境界
将来に影響があるだけでは未来負債ではない。最低判定構造は次である。

```text
現在が未来側の何かを先に利用
→ 現在信用・便益・行動可能性を得る
→ 成立条件の一部が未完了
→ 未来に実現・履行・維持・修復・負担が残る
```

通常投資との境界は、未来価値が現在信用としてどこまで先取りされ、その未決済部分がどこまで残るかを見る。通常コスト・保守予定との境界は、将来負担が現在便益の成立条件でありながら、現在評価から外部化されているかを見る。

## 判定質問11項
1. 現在は未来の何を先に利用しているか。
2. その利用によって現在は何を得ているか。
3. 現在時点で何がまだ決済されていないか。
4. 将来、何を実現・履行・維持・修復する必要があるか。
5. その決済主体は現在の受益主体と同一か。
6. 将来負担は現在の成功評価へ戻されているか。
7. 反例が現れたとき現在信用は修正されるか。
8. 時間経過によって決済経路は増えるか減るか。
9. 失敗時にrollbackできるか。
10. この判断は未来の選択肢を増やすか減らすか。
11. 「未来のため」という説明が現在の過剰負担を正当化していないか。

第11問は、未来負債論を現在犠牲の無制限な正当化装置へ反転させないための防壁である。

## 規範設計
本論の規範的目標は **未来負債ゼロではない**。

未来価値を現在信用へ接続する力は、長期投資や未来価値実現を可能にする。他方、「未来のため」を理由に現在を無制限に犠牲化することも否定する。

保持する原則:
- 未決済部分を可視化する。
- 現在利益と将来決済を同じ因果束で扱う。
- 反例によって信用を修正可能にする。
- 履行・修復主体または決済機能を消さない。
- rollback可能性を保持する。
- 代替経路を一つへ潰さない。
- 将来負荷を現在評価から外部化しない。
- 現在効率を未来選択肢の不可視な消費で作らない。
- 「未来のため」で現在を無制限に犠牲化しない。

可逆性は「完全に元へ戻せること」だけではなく、状況変化時に縮小・停止・修正・別経路移行が可能であることを含む。

## 記述・構造仮説・規範の分離
### 記述
- 既存記事群に未来負債の複数用法が存在する。
- 原型〈未来の負債〉は未来価値→現在信用を扱う。
- 後期に現在負荷→未来のT0的用法が定着している。
- 関連する未来定義系理論はそれぞれ独立責務を持つ。

### 構造仮説
- 原型とT0型は「現在が未来を先に利用した結果として残る未決済部分」という上位構造で統合可能である。
- 原型の未来→現在作用は後続の未来定義系理論群と同じ時間構造系へ系譜的に配置可能である。

### 規範
- 未決済部分を不可視化しない。
- 将来負荷を現在評価へ戻す。
- 信用修正、責任、可逆性、代替経路、未来選択肢を保持する。

観測事実・構造仮説・規範を混同しない。

## 観測可能な兆候
- 履行時期が繰り返し延びる。
- 修復・更新が恒常的に延期される。
- 現在成果のみ評価され、将来負担が計上されない。
- 将来誰が負担するか説明できない。
- 期待された未来価値への反例が評価へ反映されない。
- rollback costが時間とともに増える。
- 代替経路が減る。
- 一時対応が恒常構造になる。
- 任意の修復が緊急対応へ変わる。

単一兆候のみで自動判定せず、中心構造 `現在受益 → 未決済残余 → 未来決済` を確認する。

## 成立条件
本論で未来負債と扱うには、単に未来に影響があるだけでは足りない。少なくとも、現在が未来側の何かを先に利用して現在信用・便益・行動可能性を得ており、その成立条件の一部が未完了のまま未来側に実現・履行・維持・修復・負担として残っていることを確認する。

## 失敗条件
- 将来にコストが出るものを全部未来負債とする。
- 未来を考える・予測する・定義するだけで未来負債とする。
- 投資・契約・保守予定を自動的に未来負債へ含める。
- 原型の未来価値→現在信用をT0型で上書きする。
- T0型の現在負荷→未来を原型へ還元して消す。
- 未来負債の存在を即不可逆化とみなす。
- 「未来のため」を現在犠牲の無制限な正当化に使う。
- 未決済部分を単一金額・単一KPIだけへ圧縮する。

## 反証・改訂条件
本統合理論は少なくとも次の場合に修正対象となる。

- 原型〈未来の負債〉とT0型の間に共通する時間決済構造が存在しないことが示された場合。
- 「時間方向の未決済関係」が広すぎ、通常投資・契約・保守予定等との判別力を失う場合。
- 現在受益を要件としても過剰包摂が解消されない場合。
- 将来負荷を現在評価へ戻しても負債増幅に差が生じない場合。
- future option lossが不可逆化の説明力を持たない場合。
- 二定義を統合したことで、別々に保持する場合より説明力が下がる場合。
- 系譜接続が各公開正本の意味と矛盾する場合。

反証時は原型またはT0型を消すのではなく、上位統合を改訂する。

## 最終命題
> 未来負債をなくすことが目的なのではない。現在が未来を先に利用したなら、その利用によって残った未決済部分と、未来との決済線を切断しないことが目的である。

補助命題:

> 現在が未来を先に利用するなら、その利用によって得られた現在便益と、未来側へ残された未決済部分を同一の因果構造として保持しなければならない。

> 問題は未来を利用することではなく、未来との決済線を失うことである。
