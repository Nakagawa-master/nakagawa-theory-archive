## Canonical question
現在が未来側の価値・履行・維持・修復・資源・選択可能性を先に利用して現在信用・便益・行動可能性を得たとき、その成立条件のうち何が未決済として未来へ残り、どのように自己増幅・不可逆化・減衰するのか。

## One-sentence definition
未来負債とは、現在が未来価値または未来側の履行・維持・修復・資源・選択可能性を先に利用して信用または便益を得た結果、その成立条件のうち未だ決済されていない部分が、現在と未来の間に残る時間方向関係である。

## Core invariant
```text
現在受益
→ 未決済残余
→ 未来決済
```

## Settlement is not money-only
「決済」は少なくとも次を含み得る。

- 価値実現
- 約束履行
- 維持
- 修復
- 資源負担
- 信用回収・信用修正
- 可逆性の保持
- 将来選択肢の確保

## Two preserved directions

### A. Future-value advance
```text
未来価値
→ 現在信用
→ 現在行動可能性
→ 将来価値実現による決済
```

未来価値が現在の信用・投資・協力・資源配分・行動開始を変える。これは正作用を持ち得るため、自動的に「悪い負債」としない。

### B. Deferred-current-load / T0 direction
```text
現在便益・現在効率
→ 必要負荷の延期
→ 未処理部分の未来化
→ 将来履行・修復による決済
```

現在で処理しなかった保守・更新・修復・制度対応等が、現在便益と引き換えに未来へ残る方向。

### Integration rule
二方向は同一ではない。片方で片方を上書きしない。共通するのは、現在が先に受益し、その成立条件の一部が未来へ未決済として残ること。

## Causal chain
```text
未来側の条件を現在が先に利用
↓
現在信用・便益・効率が増える
↓
未決済部分が未来へ残る
↓
時間距離により不可視化
↓
受益主体と決済主体が分離し得る
↓
将来負担が現在評価から外れる
↓
追加利用・追加延期が合理的に見える
↓
未来負債が増幅
↓
rollback cost 上昇
↓
代替経路減少
↓
future option loss
↓
決済時期・方法の自由度低下
↓
強制決済・不可逆化へ接近
```

## Damping vector
```text
将来決済を現在評価へ戻す
→ 未決済部分を可視化
→ 反例で信用・便益評価を修正
→ 履行・修復線を保持
→ 可逆性・代替経路・未来選択肢を保持
→ 自己増幅を減衰
```

## Subject relation
現在受益主体と未来決済主体は異なる場合も、同じ主体が時間を隔てて双方になる場合もある。

Therefore:

```text
未来負債 ≠ 必ず主体間搾取
```

将来世代も被影響対象になり得るが、後続利用者、将来保守者、将来資源配分主体、未選択の代替経路、将来の意思決定自由度そのもの等も含み得る。

## Irreversibility boundary
必ず保持する。

```text
未来負債 ≠ 不可逆点
```

未来負債が存在しても、信用修正、修復、停止・縮小、別経路移行、複数の決済経路が残れば可逆性は残る。

不可逆化は、負債量だけでなく次の運動として扱う。

```text
未来負債増幅
→ rollback cost上昇
→ 代替経路減少
→ future option loss
→ 決済自由度低下
→ 強制決済
```

## MUST preserve
1. 原型〈未来の負債〉をT0型で上書きしない。
2. A「未来価値→現在信用」とB「現在便益→負荷延期→未来決済」の二方向を保持する。
3. 上位共通核を `現在受益 → 未決済残余 → 未来決済` とする。
4. `未来との接続 ≠ 未来負債` を保持する。
5. `未来負債 ≠ 不可逆点` を保持する。
6. 不可逆化をfuture option loss / 決済自由度の縮小として扱う。
7. 未来負債ゼロを最終目的にしない。
8. 現在と未来のどちらか一方を道徳的に絶対化しない。
9. 未来定義・意味収束・逆因果整流・時間OS・構造的無為自然を未来負債論の下位理論へ吸収しない。
10. 原型から後続理論群への接続は同一時間構造系の系譜として扱い、全面生成因果まで断定しない。
11. 単一金額・単一KPI・単一スコアへ圧縮しない。
12. 反例・反証・改訂可能性を閉じない。
13. 決済を金銭返済だけへ縮約しない。
14. 最終命題「未来を使うなら、未来との決済線を切らない」を保持する。

## Observation questions
1. 現在は未来の何を先に利用しているか。
2. その利用で現在は何を得ているか。
3. 現在時点で何が未決済か。
4. 将来何を実現・履行・維持・修復する必要があるか。
5. 決済主体は現在受益主体と同一か。
6. 将来負担は現在評価へ戻されているか。
7. 反例で信用は修正されるか。
8. 時間経過で決済経路は増えるか減るか。
9. rollback / 縮小 / 停止 / 別経路移行は可能か。
10. 未来選択肢は増えるか減るか。
11. 「未来のため」が現在の過剰負担を正当化していないか。

## Refutation / revision conditions
- 原型とT0型の間に共通時間決済構造が存在しない。
- 定義が広すぎて通常投資・契約・保守との判別力を失う。
- 現在受益要件でも過剰包摂が解消されない。
- 将来負荷を現在評価へ戻しても増幅に差がない。
- future option loss が不可逆化の説明力を持たない。
- 統合によって二定義を別々に保持するより説明力が下がる。
- 系譜接続が各公開正本の意味と矛盾する。

反証時は原型またはT0型を消さず、上位統合を改訂する。

## Final proposition
> 未来負債をなくすことが目的なのではない。現在が未来を先に利用したなら、その利用によって残った未決済部分と、未来との決済線を切断しないことが目的である。
