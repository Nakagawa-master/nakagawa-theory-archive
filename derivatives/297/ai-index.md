## Summary
未来負債統合理論は、未来価値を現在信用として先取りする方向と、現在処理すべき負荷を未来へ延期する方向を、`現在受益 → 未決済残余 → 未来決済` という上位の時間構造で統合する。

未来負債は将来コスト一般ではない。現在が未来側の価値、履行、維持、修復、資源、選択可能性を先に利用して信用・便益・行動可能性を得、その成立条件の一部が未来側へ未決済で残る関係を指す。

二つの方向は同一ではない。未来価値の先取りをT0型で上書きせず、T0型の現在負荷先送りも原型へ吸収して消さない。

## Concepts
- **現在受益**: 未来側の何かを先に利用することで現在が得る信用、便益、資源、費用回避、行動可能性等。
- **未決済残余**: 現在受益を成立させる条件のうち、現在では完了せず未来側に残った部分。
- **未来決済**: 将来の価値実現、履行、維持、修復、資源負担、信用修正等によって未決済部分を整合させること。
- **原型方向**: 未来価値が現在信用へ作用する時間方向。
- **T0方向**: 現在負荷の延期によって未処理部分が未来へ送られる時間方向。
- **future option loss**: 将来側が選択できる代替経路、決済時期、決済方法、停止・修正余地が失われること。
- **不可逆化**: 未来負債の存在そのものではなく、rollback cost上昇や選択肢減少によって決済自由度が細る状態。

## Core structure
```text
現在受益
→ 未決済残余
→ 未来決済
```

### Direction A
```text
未来価値
→ 現在信用
→ 現在行動可能性
→ 将来価値実現
```

### Direction B
```text
現在便益
→ 必要負荷の延期
→ 未処理部分の未来化
→ 将来履行・修復
```

## Amplification
```text
未決済部分が見えにくくなる
→ 追加利用・追加延期
→ 現在成果が良く見える
→ 将来負担が現在評価から外れる
→ 未決済部分がさらに増える
→ rollback cost上昇
→ 代替経路減少
→ future option loss
```

## Interpretation boundaries
- 未来との接続そのものを未来負債とは扱わない。
- 将来コストの存在だけで未来負債とは判定しない。
- 投資や通常の契約債務を自動的に未来負債へ含めない。
- 未来予測・未来定義と未来負債を同一化しない。
- 原型方向とT0方向の差を保持する。
- 未来負債の存在と不可逆化を区別する。
- 未来負債ゼロを最終目的としない。
- 現在または未来の一方だけを道徳的に絶対化しない。
- 決済を金銭返済だけへ限定しない。

## Related theories
本論は未来定義、意味収束理論、逆因果整流理論、時間OS、構造的無為自然と時間構造上の接続を持ち得るが、それぞれを同一理論とは扱わない。

```text
未来負債統合理論
= 現在による未来の先行利用と未決済残余

未来定義
= 成立可能な未来状態を現在評価の軸へ置く

意味収束理論
= 未来定義による過去・現在ノードの意味再配列

逆因果整流理論
= 現在の意味・時間・行動・構造を未来線へ再整列

時間OS
= 整流済み構造の時間運用・成熟

構造的無為自然
= 過剰に押さず因果が集まり具現化へ接続する状態
```

## Falsification / update conditions
- 二方向に共通する未決済時間構造が成立しない。
- 定義が広すぎて通常投資・契約・保守予定との判別力を失う。
- 現在受益を条件にしても過剰包摂が解消しない。
- 将来負荷を現在評価へ戻しても増幅に差が生じない。
- future option lossが不可逆化を説明しない。
- 統合によって二つの定義を別々に保持する場合より説明力が下がる。
