## 15秒説明
未来負債とは、「未来にコストが残ること」一般ではありません。

**現在が未来側の価値・履行・維持・修復・資源・選択可能性を先に使って信用や便益を得たのに、その成立条件の一部が未来へ未決済のまま残ること**を扱います。

```text
現在受益
→ 未決済残余
→ 未来決済
```

## 二つの方向
本論は、向きの違う二つの未来負債を統合します。

### 1. 未来価値を現在信用として先取りする
未来に価値が生まれるという期待によって、現在の投資、協力、資源配分、行動開始が可能になる方向です。

```text
未来価値
→ 現在信用
→ 現在行動
→ 将来価値実現による決済
```

これは必ずしも悪いことではありません。研究や長期投資も未来価値への信用によって始められます。重要なのは、期待への反例が出たときに現在信用を修正できることです。

### 2. 現在負荷を未来へ送る
保守、修復、更新、制度対応などを今行わず、現在の費用や負担を軽くする方向です。

```text
現在便益
→ 必要負荷を延期
→ 未処理部分が未来へ残る
→ 将来の履行・修復
```

対象が時間とともに劣化する場合、「今は何もしない」ことも完全な中立ではありません。

## 何が共通しているのか
二方向に共通するのは、現在が先に何かを受け取っていることです。

そして、その受益を成立させる条件の一部が、未来側にまだ残っています。

だから見るべきなのは、

- 現在は何を先に受け取ったか
- その受益を成立させるために何が未完了か
- 将来は誰が何を決済するのか
- 反例や負担が現在の評価へ戻るか

です。

## なぜ見えにくくなるのか
未来負債は時間差によって見えにくくなります。

現在受益者と将来決済者が別の人・部署・世代になる場合もあります。同じ主体でも、担当交代や情報断絶によって「過去の受益」と「今の負担」が別問題に見えることがあります。

```text
未決済部分が見えにくい
→ 追加利用・追加延期
→ 現在成果が良く見える
→ 判断が正しかったように見える
→ さらに未決済部分が見えにくくなる
```

この循環が未来負債の増幅につながります。

## 不可逆化とは別の問題
未来負債が存在することと、不可逆になっていることは同じではありません。

修正、縮小、停止、別経路への移行ができるなら、決済方法を選ぶ余地は残っています。

危険が高まるのは、

```text
rollback costが上がる
→ 代替経路が減る
→ future optionが失われる
→ 決済時期・方法の自由が減る
```

と進むときです。

## 実務で見る11の質問
1. 現在は未来の何を先に利用しているか。
2. その利用によって現在は何を得ているか。
3. 今、何がまだ決済されていないか。
4. 将来、何を実現・履行・維持・修復する必要があるか。
5. 決済主体は現在受益者と同じか。
6. 将来負担は現在の成功評価へ戻されているか。
7. 反例が出たとき信用は修正されるか。
8. 時間が経つほど決済経路は増えるか減るか。
9. 失敗時に縮小・停止・修正・別経路移行ができるか。
10. この判断は未来の選択肢を増やすか減らすか。
11. 「未来のため」という説明が、現在の過剰負担を正当化していないか。

## よくある誤読
### 将来コストがあれば全部未来負債？
違います。現在が未来側の何かを先に利用して受益したことと、未決済部分が残ったことが必要です。

### 投資は未来負債？
自動的にはなりません。投資がどの未来価値を現在信用として使い、何がまだ未決済かを見ます。

### 未来負債は悪だからゼロにすべき？
違います。未来価値の先取りは長期的な価値創出を可能にする場合があります。目的は未来利用を禁止することではなく、決済線を切らないことです。

### 未来のためなら現在を犠牲にすべき？
違います。本論は未来を絶対化しません。現在の過剰負担を「未来のため」で無制限に正当化することも避けます。

## 最後に
本論が問うのは、未来を使ってよいか悪いかではありません。

**現在が未来を先に利用したなら、その受益によって何が未決済として残ったのかを見失わず、未来との決済線を保てるか。**
