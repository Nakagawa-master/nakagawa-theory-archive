## 核心问题
当“现在”提前使用属于“未来侧”的价值、履行能力、维护能力、修复能力、资源或选择可能性，从而先获得信用、便利或行动能力时，哪些成立条件仍以“未结算”状态留在未来？这些未结算关系如何放大、减衰，并可能接近不可逆化？

## 一句话定义
未来负债，是一种时间方向上的未结算关系：现在通过提前使用未来价值，或未来侧的履行、维护、修复、资源、选择可能性等，先取得信用或便利；但使该便利成立的部分条件尚未完成，因此仍留在未来侧等待实现、履行、维护、修复、承担、信用修正或选择权保持。

## 上位共通核
```text
现在受益
→ 未结算残余
→ 未来结算
```

这里的“结算”不只指金钱偿还，也可包括：价值实现、承诺履行、维护、修复、资源承担、信用修正、可逆性保持、未来选项保持。

## 必须保留的两个时间方向

### A｜提前使用未来价值
```text
未来价值
→ 现在信用
→ 现在行动能力
→ 通过未来价值实现完成结算
```

尚未实现的未来价值，可以先改变现在的信用、投资、合作、资源配置与行动启动。这一方向可能产生正作用，因此不能自动等同于“坏负债”。

必须保留的边界：

```text
未来价值对现在产生作用 ≠ 坏负债
信用预付 ≠ 结算完成
期待 ≠ 固定保证
```

若出现反例，当前信用应能够被修正。

### B｜把当前负荷延后到未来
```text
现在便利 / 当前效率
→ 必要负荷延期
→ 未处理部分未来化
→ 将来履行 / 修复 / 维护
```

维护、更新、制度响应、修复、未完成承诺等，可能因为当前不处理而带来费用回避或现状维持等现在便利。

当对象会随时间变化或劣化时：

```text
什么都不做 ≠ 永远中立
```

### 统合规则
A 与 B 方向不同。不能用后者覆盖前者，也不能把二者混成一个方向。

它们的共同结构是：现在先取得某种利益，而使其成立的部分条件仍作为未结算残余留在未来。

## 主要因果链
```text
现在提前使用未来侧条件
↓
现在信用 / 便利 / 效率增加
↓
未结算部分留在未来
↓
时间距离使其变得不可见
↓
现在受益者与未来结算者可能分离
↓
未来负担被排除在现在评价之外
↓
追加提前使用 / 追加延期看起来更合理
↓
未来负债放大
↓
rollback cost 上升
↓
替代路径减少
↓
future option loss
↓
选择结算时间与方法的自由降低
↓
接近强制结算 / 不可逆化
```

## 减衰方向
```text
把未来结算重新带回现在评价
→ 可视化未结算部分
→ 出现反例时修正信用与便利评价
→ 保留履行与修复路径
→ 保留可逆性、替代路径、未来选项
→ 减弱自我放大
```

## 受益主体与结算主体
现在受益者与未来结算者可能不同，也可能是同一主体在不同时间承担两个角色。

因此：

```text
未来负债 ≠ 必然是不同主体之间的剥削
```

未来侧受影响者可能包括后续使用者、未来维护者、未来资源配置者、后续决策者、尚未被选择的替代路径，以及未来决策自由本身。

本理论不单独确认“未来世代”的法律主体性。

## 不可逆边界
必须始终保留：

```text
未来负债 ≠ 不可逆点
```

只要仍存在信用修正、修复、停止、缩小、迁移到其他路径、多个结算路线等，未来侧仍保有可逆性。

不可逆化应理解为以下运动：

```text
未来负债放大
→ rollback cost 上升
→ 替代路径减少
→ future option loss
→ 结算自由度下降
→ 强制结算
```

关键并不只是“负债量变大”，而是未来侧逐渐失去“是否结算、何时结算、用什么方法结算”的选择自由。

## MUST preserve
1. 不用 T0 方向覆盖原型“未来价值 → 现在信用”。
2. 同时保留 A 与 B 两个不同方向。
3. 上位共通核保持为 `现在受益 → 未结算残余 → 未来结算`。
4. 保持 `连接未来 ≠ 未来负债`。
5. 保持 `未来负债 ≠ 不可逆点`。
6. 以 future option loss / 结算自由度下降来解释不可逆化，而不是只看负债数量。
7. 不把“未来负债归零”设为最终规范目标。
8. 不把现在或未来任一方道德绝对化。
9. 不把未来定义、意义收敛理论、逆因果整流理论、时间OS、结构性无为自然吸收成未来负债理论的下位理论。
10. 原型与后续理论的联系只能作为同一时间结构系中的谱系联系，不断言原型生成了所有后续理论。
11. 不压缩为单一金额、单一 KPI、单一分数。
12. 保留反例、可证伪性与可修订性。
13. 不把“结算”缩减为金钱偿还。
14. 保留最终规范核心：如果现在提前使用未来，就不能切断与未来之间的结算线。

## 观察问题
1. 现在提前使用了未来的什么？
2. 因此现在获得了什么？
3. 现在仍有什么尚未结算？
4. 将来必须实现、履行、维护、修复或承担什么？
5. 未来结算主体是否与现在受益主体相同？
6. 未来负担是否被重新带回现在的成功评价？
7. 出现反例时，现在信用能否修正？
8. 随时间推移，结算路径增加还是减少？
9. 能否 rollback、缩小、停止、修正或迁移到其他路径？
10. 这一判断增加还是减少未来选项？
11. “为了未来”是否正在被用来合理化对现在的无限牺牲？

## 反证 / 修订条件
以下情况至少应触发对上位统合的修订：

- 原型与 T0 方向之间不存在有意义的共同时间结算结构；
- “时间方向上的未结算关系”过于宽泛，无法区分普通投资、契约或计划维护；
- 加入“现在受益”条件后仍不能解决过度包含；
- 把未来负担带回现在评价后，对放大过程没有差异；
- future option loss 无法解释不可逆化；
- 统合后反而比保留两个定义分别使用时解释力更弱；
- 与相关理论的谱系连接歪曲了各 canonical Parent 的意义。

反证时应修订上位统合，而不是删除原型或 T0 其中一方。
