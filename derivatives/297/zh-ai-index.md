## Summary
未来负债统合理論把两个方向不同的“未来负债”放在同一个上位时间结构中观察，但不把二者混为一谈。

第一方向是 **未来价值 → 当前信用**：尚未实现的未来价值，提前影响当前的信用、资源配置、投资、合作或行动。

第二方向是 **当前受益 → 负荷延期 → 未来结算**：维护、修复、更新、制度应对等当前应处理的负荷被延期，当前先获得成本回避或其他便利，而未处理部分留给未来。

两者的共同结构是：

```text
当前受益
→ 未结算残余
→ 未来结算
```

因此，未来负债并不是所有“未来会发生的成本”。它强调的是：当前已经先使用了未来侧的价值、履行能力、维护能力、修复能力、资源或选择可能性，并因此得到信用或便利，但支撑这些当前受益的部分条件仍未完成。

## Concepts
- **当前受益**：当前因提前使用未来侧条件而取得的信用、便利、资源、成本回避或行动能力。
- **未结算残余**：支撑当前受益的条件中，仍未实现、履行、维护、修复或解决的部分。
- **未来结算**：以后通过价值实现、履行、维护、修复、资源承担、信用修正等，使未结算部分重新取得整合。
- **原型方向**：未来价值在真正实现以前先影响当前信用。
- **T0方向**：当前负荷被延期，并作为未来侧负荷继续存在。
- **future option loss**：未来侧可选择的替代路径、结算时间、结算方法、停止、缩小或修正空间减少。

## Core structures
### Direction A
```text
未来价值
→ 当前信用
→ 当前行动能力
→ 将来价值实现
```

### Direction B
```text
当前受益
→ 必要负荷延期
→ 未处理部分进入未来
→ 将来履行 / 修复
```

### Shared structure
```text
当前受益
→ 未结算残余
→ 未来结算
```

## 放大与不可逆化
当未结算部分从当前评价中消失时，进一步的提前使用或继续延期会显得更加合理，从而可能让未来负债继续放大。

```text
未结算部分变得不易看见
→ 继续提前使用 / 继续延期
→ 当前成果看起来更好
→ 未来负担进一步脱离当前评价
→ rollback cost 上升
→ 替代路径减少
→ future option loss 增加
```

未来负债的存在与不可逆化并不相同。如果仍能修正、缩小、停止、修复或切换路径，就仍保有一定的结算自由。

## 解读边界
- 与未来发生连接，并不自动等于未来负债。
- 仅仅存在未来成本，不足以认定未来负债。
- 投资不自动等于未来负债。
- 一般合同债务不自动等于未来负债。
- 未来预测、未来定义与未来负债属于不同问题。
- 原型方向与 T0 方向保持区分。
- 未来负债不等于不可逆点。
- 未来负债归零不是本论的最终目的。
- 结算不限于金钱偿还。
- 当前与未来的任何一方都不被道德绝对化。

## 反证与修订条件
如果两个方向之间不存在有意义的共同未结算时间结构；如果定义无法与通常投资、合同或维护计划区分；如果把未来负荷重新纳入当前评价并不会改变放大过程；如果 future option loss 无法解释走向不可逆化的过程；或者统合后的解释力反而低于分别保留两个定义时的解释力，则上位统合需要修订。
