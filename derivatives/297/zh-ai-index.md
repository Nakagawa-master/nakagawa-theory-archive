## 核心含义
未来负债统合理論并不把 Future Debt 定义成“未来留下的坏成本”，而是定义为一种**时间方向上的未结算关系**：现在提前使用未来侧的价值、履行能力、维护或修复能力、资源、选择可能性，从而先获得当前信用、便利或行动能力；但支撑这些当前受益的部分成立条件，尚未完成结算，并留在未来侧。

上位共同结构为：

```text
当前受益
→ 未结算残余
→ 未来结算
```

这里的“结算”不限于金钱偿还，也可以包括价值实现、承诺履行、维护、修复、资源负担、信用修正、保持可逆性、保留未来选项等。

## 必须同时保留的两个方向
### A｜未来价值提前转化为当前信用
```text
未来价值
→ 当前信用
→ 当前行动能力
→ 通过未来价值实现完成结算
```

这一方向并不自动是“坏负债”。对未来价值的可信期待可以提前聚集当前资源、投资、协作和行动。关键是：出现反证时，当前信用必须可以被修正。

### B｜当前负荷延期到未来
```text
当前便利 / 当前效率
→ 维护、修复、更新、制度应对等被延期
→ 未处理部分未来化
→ 未来履行 / 修复
```

如果对象会随时间劣化或变化，“什么都不做”并不总是中立。延期本身可能改变未来修复规模、rollback cost 与替代路径。

## 统合但不抹除差异
A 与 B 的方向不同，不能处理成“旧定义 / 新定义”。它们共享：

```text
现在先获得某种受益
→ 支撑该受益的部分条件留在未来
→ 未来需要实现、履行、维护、修复或承担
```

## 必须保持的区别
```text
未来负债 ≠ 所有未来成本
与未来连接 ≠ 未来负债
未来价值影响现在 ≠ 坏负债
提前信用 ≠ 已完成结算
期待 ≠ 固定保证
未来预测 ≠ 未来负债
未来定义 ≠ 未来负债
读取未来线 ≠ 未来负债
投资 ≠ 自动等于未来负债
普通合同债务 ≠ 自动等于未来负债
未来负债 ≠ 不可逆点
```

## 当前受益方与未来结算方
当前受益方可能包括：获得当前信用、资源、成本回避、成果计入、行动自由度的主体。

未来结算方可能包括：未来价值实现者、履行者、维护者、修复者、后续用户、后续决策者、未来资源分配者、预期价值未实现时的损失承担者。

两者可以不同，也可以是同一主体在不同时间承担不同角色。不要把 Future Debt 只缩减成代际剥削。

## 可能被无形消耗的资产
- 信用
- 修复余力
- 维护余力
- 可逆性
- 替代可能性
- 资源余量
- 制度选择空间
- 时间一致性
- 未来决策自由度

不要压缩成单一金额、单一 KPI 或单一分数。

## 增幅闭环
```text
未结算部分越来越不可见
→ 追加提前使用 / 追加延期
→ 当前成果看起来更好
→ 过去决策看起来更合理
→ 未结算部分进一步不可见
```

扩展因果：

```text
现在提前使用未来条件
→ 当前信用 / 便利 / 效率增加
→ 留下未结算残余
→ 时间距离使其不易观察
→ 受益方与结算方分离
→ 未来负担退出当前评价
→ 追加使用 / 延期看起来合理
→ Future Debt 增幅
→ rollback cost 上升
→ 替代路径减少
→ future option loss
→ 结算时间 / 方法的选择自由下降
→ 接近强制结算
```

## 减衰向量
```text
把未来结算重新带回当前评价
→ 可视化未结算残余
→ 用反证修正信用 / 便利评价
→ 保持履行 / 修复线
→ 保持可逆性与替代路径
→ 保持未来选择
→ 减弱自我增幅
```

## 不可逆化规则
```text
future debt ≠ irreversibility
```

即使存在 Future Debt，只要还能修正信用、启动修复、停止或缩小、切换路径、保留多个结算方式，就仍有可逆性。

```text
Future Debt 增幅
→ rollback cost ↑
→ 替代路径 ↓
→ future option loss
→ 对结算时间 / 方法的自由 ↓
→ 强制结算
→ 不可逆化
```

最终劣化状态不是简单的“负债很大”，而是未来侧失去“是否结算、何时结算、如何结算”的自由，被迫接收过去遗留的未结算条件。

## 判定问题 11 项
1. 现在提前使用了未来的什么？
2. 这种使用让现在获得了什么？
3. 当前还有什么没有结算？
4. 未来需要实现、履行、维护、修复或承担什么？
5. 未来结算方与当前受益方是否相同？
6. 未来负担是否被带回当前成功评价？
7. 出现反证时，当前信用能否修正？
8. 随时间经过，结算路径增加还是减少？
9. 失败时能否 rollback、停止、缩小、修正或切换路径？
10. 该决策增加还是减少未来选项？
11. “为了未来”是否被用来合理化当前的无限负担？

第 11 问是防反转边界：理论不能变成“未来绝对优先、现在必须无限牺牲”的工具。

## 规范目标
目标**不是 Future Debt 归零**。

未来价值可以正当地连接当前信用与行动。设计目标是：把当前受益与未来结算保持在同一个因果束中；反证可以修正信用；履行、修复与责任功能不消失；尽可能保留 rollback、替代路径与未来选择；不要用无形消耗未来选项来制造当前效率。

## 观察 / 结构假设 / 规范必须分离
### 观察
- 理论群中存在多个 Future Debt 用法。
- 原型处理未来价值→当前信用。
- 后期 T0 用法处理当前负荷→未来。
- 相关未来导向理论各自保持独立职责。

### 结构假设
- 两个方向可以通过“当前受益 + 未来侧未结算条件”的上位结构统合。
- 原型中的未来→现在作用，可以在时间结构谱系上与后续未来定义系理论相连接。

### 规范
- 不要隐藏未结算残余。
- 把未来负担带回当前评价。
- 保持信用修正、责任、可逆性、替代路径、未来选择。

不要把观察事实、结构假设、规范主张混成一个断言。

## 失败模式
- 把所有未来成本都叫 Future Debt
- 把投资、合同、维护计划自动归入 Future Debt
- 把未来预测、未来定义与 Future Debt 同一化
- 用 T0 覆盖原型
- 把 T0 消解成原型的一部分而丢失其方向差
- 把 Future Debt 的存在直接等同不可逆化
- 只人格化为“未来世代”问题
- 压缩为单一金额、KPI、分数
- 用“为了未来”合理化当前无限牺牲

## 反证 / 修订条件
如果出现以下情况，应修订上位统合：
- 原型与 T0 不存在共同的时间结算结构；
- “时间方向的未结算关系”过宽，无法区分普通投资、合同、维护；
- 加入“当前受益”要求后仍无法解决过度包含；
- 把未来负担带回当前评价也不影响增幅；
- future option loss 无法解释不可逆化；
- 统合后解释力比保留两个定义更低；
- 谱系连接与相关 canonical Parent 的意义冲突。

反证时应修订上位统合，而不是删除某个历史方向。

同属一个时间结构谱系，并不等于同一理论。

## MUST preserve
1. 不得用 T0 覆盖原型的“未来价值→当前信用”。
2. 必须同时保留两个方向。
3. 必须保留 `当前受益 → 未结算残余 → 未来结算`。
4. 必须保留 `与未来连接 ≠ 未来负债`。
5. 必须保留 `未来负债 ≠ 不可逆点`。
6. 用 rollback cost、替代路径减少、future option loss、结算自由下降说明不可逆化。
7. 不把 Future Debt 归零设为最终规范目标。
8. 不把当前或未来任何一方道德绝对化。
9. 不把相关未来理论吸收到 Future Debt 的下位理论中。
10. 谱系连接不等于原型生成了全部后续理论。
11. 不压缩成单一金额、KPI、分数。
12. 保持反证与修订开放。
13. settlement 不限于金钱偿还。
14. 保持最终命题：如果现在使用未来，就不要切断与未来的结算线。
