## 親原典から保持する中心構造
### 一文定義
未来負債とは、現在が未来価値または未来側の履行・維持・修復・資源・選択可能性を先に利用して信用または便益を得た結果、その成立条件のうち未だ決済されていない部分が、現在と未来の間に残る時間方向関係である。

### 上位共通核
```text
現在受益
→ 未決済残余
→ 未来決済
```

### 二つの時間方向
```text
A｜原型
未来価値
→ 現在信用
→ 現在行動可能性
→ 将来価値実現による決済

B｜T0
現在便益・現在効率
→ 必要負荷の延期
→ 未処理部分の未来化
→ 将来履行・修復による決済
```

AとBは同一化しない。原型をT0で上書きせず、T0を原型へ還元して消さない。

## 主要意味範囲
この派生セットがParentから保持する主要範囲は次である。

- 未来負債の上位定義としての未決済関係
- 原型〈未来の負債〉の未来価値→現在信用
- 未来負債T0の現在負荷→未来
- 現在受益者と未来決済者の時間差・主体差
- 見えない被影響主体と将来の意思決定自由度
- 信用、修復余力、保守余力、可逆性、代替可能性、制度的選択肢等の非金銭的資産
- 未決済残余の不可視化による増幅閉路
- 未決済部分の可視化、信用修正、責任線、代替経路による減衰方向
- 短期・中期・長期の時間発展
- `未来負債 ≠ 不可逆点`
- rollback cost、代替経路減少、future option loss、決済自由度低下による不可逆化
- 通常投資、契約、将来コスト、未来予測、未来定義との判定境界
- 11項の判定質問
- 未来負債ゼロを目的としない規範設計
- 観測、構造仮説、規範の分離
- 反証・改訂可能性
- 未来定義、意味収束、逆因果整流、時間OS、構造的無為自然との系譜的接続と理論差
- 最終命題「未来を使うなら、未来との決済線を切らない」

- 同一時間構造系 / 同一理論

## Related-theory boundary
```text
未来負債統合理論
= 現在による未来の先行利用と未決済残余の観測

未来定義
= 成立可能な未来状態を現在評価の軸へ置く

意味収束理論
= 未来定義による過去・現在ノードの意味再配列

逆因果整流理論
= 現在の意味・時間・行動・構造を未来線へ再整列

時間OS
= 整流済み構造の時間運用・成熟

構造的無為自然
= 過剰に押さず因果が集まり具現化へ接続する状態
```

同じ時間構造系へ接続できることと、同一理論であることは別である。原型〈未来の負債〉が後続五理論すべてを全面的に生成した親理論とも扱わない。
