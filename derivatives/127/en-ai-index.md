## Summary
Memory is treated as reconstructive rather than a fixed recording. Recall can be influenced by present context, emotion, purpose and later information, but this does not make testimony worthless. Ethical truth-seeking separates memory from records, compares multiple witnesses, preserves timestamps, confidence, discrepancies and correction history, and avoids converting either subjective certainty or institutional records into automatic truth. A shared memory is an auditable bundle that can retain unresolved differences.

## Measurements and audit

## Validity conditions
Respect the remembering subject while separating memory from records and preserving uncertainty and revision paths.

## Failure conditions
Treating memory as infallible, treating all memory as false, majority-vote truth, record infallibility, retrospective projection, deletion of contradictions.

## Falsification conditions
If reconstructive models do not outperform fixed-memory models and cross-checking does not reduce error, weaken the framework.

## Required distinctions
memory/record; confidence/fact; reconstruction/fabrication; correction/denial; subjectivity/falsehood; shared memory/majority vote; correspondence/conformity.

## Interpretation constraints
Do not use this framework to automatically dismiss victim testimony or replace legal and clinical procedures. Do not equate human memory with AI storage mechanisms.
