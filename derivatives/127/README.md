## 位置づけ
記憶を固定された録画ではなく、現在の文脈・感情・他者との照応によって再構成される構造として扱う。再構成可能性は「何でも相対的」という意味ではなく、起源資料、複数証言、差分、確信度、訂正可能性を残す倫理を要求する。

## 中心命題
人間や組織の記憶は検索のたびに再編集され得るため、真実への接近は一つの記憶を絶対化することではなく、記録と記憶、現在解釈と当時資料、自己証言と他者証言を区別し、差分が生じた経路を監査可能にすることで強くなる。照応の倫理は、記憶者を否定せず、同時に記憶だけを事実確定の唯一根拠にしない。

## 因果線
記憶が出来事を保持 → 現在文脈で想起 → 感情・目的・他者情報が再編集 → 確信が事実性と混同 → 記憶衝突が起きる → 記録・証言・時点を分離 → 差分と不確実性を保持 → 相互訂正 → より監査可能な共有記憶へ。

## 構造層
1. 出来事層：当時の観測と一次資料。
2. 記憶層：主体内に保持された再構成可能な表象。
3. 文脈層：現在の感情・目的・関係。
4. 照応層：他者証言・記録との突合。
5. 倫理層：否定・断定を避け訂正経路を残す。

## 適用例
1. 事故・会議の事後検証で記憶とログを分ける。
2. 家族史・地域史で複数証言を並置する。
3. AI要約で後代解釈と原記録を別レイヤーにする。
4. 組織監査で「そう記憶している」を唯一の証拠にしない。

## 測定・監査点
一次資料保持率、証言差分記録率、時点ラベル率、訂正履歴率、確信度表示率、複数証言coverage、原典回帰率。

## 成立条件
記憶者の尊厳を保つ。記録と記憶を区別する。複数証言を許す。時点差を記録する。不確実性を表示する。訂正可能性を残す。

## 失敗条件
記憶を録画のように扱う。逆に記憶を全面無価値化する。権威者の記憶だけを採用する。訂正を人格否定にする。現在解釈を過去事実へ投影する。差分を消す。

## 反証条件
再構成モデルより固定記憶モデルが一貫して説明・予測に優れる。記録突合が誤差低減に寄与しない。複数証言化が真実接近を悪化させる。確信度表示が誤認防止に寄与しない。訂正経路が信頼を改善しない。

## 必須の区別
記憶/記録、確信/事実、再構成/捏造、訂正/否定、主観/虚偽、共有記憶/多数決、照応/同調。

## 誤読禁止
「記憶は全部嘘」としない。被害証言を自動否定しない。多数証言を真実の自動確定にしない。記録を無謬としない。心理診断へ転用しない。派生を原典代替にしない。
