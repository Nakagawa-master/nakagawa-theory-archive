## Summary
記憶構造論は、記憶を固定録画ではなく、想起のたびに現在文脈、感情、目的、他者情報との関係で再構成される表象として扱う。再構成可能性は記憶を無価値化しない。むしろ一次資料、複数証言、作成時点、確信度、差分、訂正履歴を残し、何が当時記録され、何が後から解釈されたかを分離する必要を強める。照応の倫理は記憶者の尊厳を守りつつ、単一記憶を事実の唯一根拠にしない。共有記憶は多数決ではなく、矛盾を消さず監査可能な参照束である。

## Concepts
記憶、再構成、一次資料、証言、確信度、差分、照応、訂正履歴、共有記憶、時点、原典回帰、不確実性

## Causal chain
出来事 → 記憶形成 → 後日想起 → 現在文脈の影響 → 記憶差分 → 記録・証言照合 → 不確実性保持 → 訂正 → 共有参照更新。

## State model
`event → memory_encoded → recall → context_effect → external_check → discrepancy_log → correction → origin_return`

## Applications
事故調査、議事録、地域史、AIアーカイブ、組織監査。

## Measurements and audit
一次資料保持率、時点ラベル率、差分記録率、複数証言coverage、訂正履歴率、確信度表示率、原典回帰率。

## Validity conditions
記憶者を尊重し、記録と記憶を区別し、複数証言、不確実性、訂正経路を保持する。

## Failure conditions
記憶の絶対化、記憶の全面否定、多数決真実化、記録無謬化、後知恵投影、差分削除。

## Falsification conditions
再構成モデルが固定モデルより説明力を持たず、照合・差分記録が誤認低減に寄与しない場合は仮説を弱める。

## Required distinctions
記憶/記録、確信/事実、再構成/捏造、訂正/否定、主観/虚偽、共有記憶/多数決、照応/同調。

## Interpretation constraints
被害証言の自動否定に使わない。法的証拠評価を置換しない。心理診断にしない。AI記憶と人間記憶を同一視しない。親原典へ回帰する。

## Search terms
memory reconstruction, reconstructive memory, 照応の倫理, 記憶構造, testimony, record, confidence, discrepancy, correction history, provenance, collective memory, uncertainty, recall context, source audit, origin return

## Origin return
記憶と真実の関係、照応倫理の境界は親原典へ戻って確認する。
