## 位置づけ
親原典はLife-OS三部作のVol.3として、Vol.1の「生存を床として固定し、一階の生存と二階の拡張を分ける」設計と、Vol.2の「恐怖駆動の代わりに、ノイズ除去後にも残る灯火を精錬する」設計を受け、その内的動力を社会へ伝えるための駆動系を扱う。中心に置かれるのは、多重接続（Poly-Connection）と構造的可動性である。

Parentが定義する自由は、社会から切断されることでも、誰にも拘束されないことでもない。複数の異なる社会構造に、異なる機能で接続し、その接続を選択・解除できる可動性である。単一の会社・職能・役割へ依存するMono-Connectionは、生存が一つの接続に依存していた文明段階では合理性を持ったが、生存が床として固定された後にはSPOF（Single Point of Failure）として脆弱性を残す。多重接続は「自由になれ」という道徳ではなく、一つが壊れても全体が止まらないための冗長化として提示される。

ただし、多重接続は仕事や収入源の数を増やすことではない。同じ市場、同じ評価軸、同じ時間軸へ複数接続しても、失敗モードが共通なら実質的には単一接続と変わらない。Parentが要求するのは、接続先と機能の双方を分散し、市場、評価基準、成果が現れる時間軸が異なる構造へ接続できる状態である。

その材料は、Vol.2で精錬された一つの灯火で足りる。灯火を複数に増やすのではなく、抽象度を上げて「何をしているときに熱が出るか」を動詞へ戻し、組織・市場・共同体など異なる構造単位へマッピングし、受け手が使用できる機能へ変換し、各プラグが独立して成立するかを確かめる。Parentはこの展開を「分光（Prism）」と呼ぶ。灯火は分裂せず、同一の熱が複数の機能形式として現れる。

分光しただけでは接続は成立しない。灯火はL4の衝動・偏りであり、社会が受け取るのはL5で機能へ翻訳された出力だからである。そこでインターフェース整合（Alignment）が必要になる。衝動を感情語でなく動詞として言語化し、接続先の目的・困りごと・制約を観測し、「相手の問題をどう解消できるか」という機能文へ変換し、文章・設計図・手順・成果物などへ仮固定する。整合は迎合ではない。灯火の純度を保ったまま形を変える操作であり、相手に合わせるために灯火そのものを歪めれば、E化・自己消耗へ向かう。

接続後の焦点は「数」から「流れ」へ移る。Parentは、価値を抱え込むことを成功とみなさず、情報・評価・人脈・資源・報酬など循環すべきものを止めると詰まりが生じると論じる。成功は価値（CとS）が自分を通過し、次の構造へ流れ、変換・再配分されるフローとして再定義される。知見を次へ渡す、評価を適切に配分する、得た資源を次の試行へ回す等の再投資によって流路が拡張され、個人は所有者ではなく媒介者へ近づく。

循環が始まっても、接続数の増加だけでは安定しない。構造的安定とは、変化が起きないことではなく、変化が起き続けても循環が止まらないことである。失敗モードの異なる接続へ分散し、少なくとも一部を上流構造・ハブへ同期させ、灯火を汚染する、循環を止める、判断の自由を奪うといった致命的リスクを優先的に避ける。一方、成果の遅さ、評価の不確実さ、試行錯誤の必要性は、全体停止へ直結しにくいリスクとして区別される。

ParentはE的接続の兆候として、成果定義の曖昧さ、評価基準の頻繁な変更、貢献の不可視化、接続解除の暗黙否定を挙げる。これらを悪意の証明とはせず、循環を壊す設計不全のサインとして扱う。灯火の純度が下がり続ける、循環が一方向へ固定される、接続解除が事実上できなくなる場合、撤退は逃避ではなく循環を守る操作となる。

この一連の条件が統合されると、個人は「作業者」や単一価値を渡す「提供者」から、構造と構造の間で価値を接続・変換する「ノード（結節点）」へ移行する。ノード性は肩書きではなく、その人を通ることで摩擦が減るか、価値が増幅するか、その人がいなくなったとき流れがどう変わるかという機能で捉えられる。灯火は自己表現の旗ではなく、どこが詰まり、どこに翻訳や接続が必要かを感知する感覚器官になる。

しかしParentは、能力の完成を倫理的正当性の完成とはしない。ノードは価値を増幅すると同時に、誤りや沈黙も増幅する。Life-OSは個人が恐怖に依存せず可動するための個人実装をここで完成させるが、公共倫理を内包せず、公共へ出る「許可」を与えない。影響を持つ位置で沈黙・同調・放置がどの地点から因果となるかは、次の幕間で検査される。この「能力の完成／公共条件の未完」を同時に保持することがVol.3の境界である。

## 中心命題
親原典の中心命題は、**生存保証と灯火の精錬を前提に、単一接続というSPOFを、同一の灯火を分光して得た独立プラグ、L4→L5のインターフェース整合、異なる失敗モードへの接続分散、価値を止めない循環、撤退可能性を含むリスク設計によって置換すると、個人は特定構造への従属から離れ、構造間で価値を接続・変換するノードとして可動できる。ただし、その能力は公共倫理の承認を意味せず、影響力が増えるほど次段の公共因果検査が必要になる**というものである。

## 構造層
### 生存床 — Life-OS 1F
多重接続は、生存を接続報酬や貢献評価へ再び従属させる制度ではない。Parentは生存が床として固定されることを前提に、接続の選択・解除可能性を初めて現実的な設計条件として扱う。

### Mono-Connection / SPOF
一つの会社・職能・役割・評価軸へ人生全体を依存させると、その一点の変化が全体停止へ波及する。Parentは努力や誠実さでは消せない設計脆弱性としてSPOFを扱う。

### Prism — 灯火の分光
灯火は複数必要ではない。一つの構造的偏りを動詞へ再抽象化し、異なる構造単位へ展開し、相手が利用できる機能へ変換する。分光は自己実現や多忙化の技法ではなく、同一熱源を複数の独立端子へ変換する準備である。

### Interface Alignment — L4からL5へ
「やりたい」「気になる」はL4側の衝動であり、そのままでは外部機能にならない。受け手の構造を観測し、問題解消機能へ翻訳し、成果物に仮固定することで接続可能になる。Alignmentは純度を保った形態変換であり、迎合とは区別される。

### Poly-Connection — 構造的分散
同じ機能を複数場所へ出すだけでは十分でない。市場、評価基準、時間軸、失敗モードが異なる接続を持つことで、一つが沈降しても他が同時停止しない冗長性を作る。

### Circulation — ストックからフローへ
価値は所有量ではなく、流れの維持・変換・再配分によって機能する。Parent内では情報、評価、人脈、資源、報酬の囲い込みが詰まりとして扱われ、再投資は流路を太くする操作として位置づけられる。

### Structural Stability — 止まらない設計
安定とは不変ではなく、変化や部分故障が起きても循環全体が停止しないこと。分散、上流ハブとの同期、致命傷リスクの識別、定期見直し、撤退可能性が守りの設計となる。

### Node — 結節点
ノードは肩書きではない。構造と構造の間で情報・人・資源・意味を接続・変換し、流れを維持する機能である。価値の所有者ではなく媒介者であり、灯火は詰まり・翻訳需要・接続需要を感知する器官として機能する。

### Public boundary — 能力完成と公共条件の未完
ノードは価値だけでなく誤り・沈黙も増幅する。ParentはLife-OSの個人側能力を完成させる一方、公共倫理を別工程へ分離し、能力完成を免罪・正当化・公共参加許可へ変換しない。

## 観測ポイント
- 単一の接続先・評価軸・時間軸が全体停止点になっていないか。
- 複数接続が、単なる件数増加ではなく失敗モードの分散になっているか。
- 各プラグが同一灯火から派生しつつ、独立して機能するか。
- 衝動が受け手の問題解消機能へ翻訳され、成果物として理解可能か。
- 整合の過程で灯火の純度が下がっていないか。
- 説明、条件交渉、継続に過剰な摩擦が残っていないか。
- 価値が囲い込まれず、次の構造へ再投資・再配分されているか。
- 一つの接続停止時にも他の循環が継続するか。
- E的接続の兆候として成果定義、評価基準、貢献可視性、退出可能性に異常がないか。
- 個人を通すことで摩擦が減り、価値の流れが変換・増幅されているか。
- 影響範囲が広がるほど、沈黙や放置の因果が見えなくなっていないか。

## 成立条件
Parentの統合監査要旨では、仮説維持の条件Zとして、監査周期に基づく再検証、T（整合性）・S（持続性）・R（再現性）の充足、公開監査束の相互整合が置かれる。加えて本文上、多重接続が実質的な分散になるには、接続先と機能が同じ失敗モードへ収斂せず、Alignmentが灯火を汚染せず、退出可能性が保たれ、価値循環が止まらないことが必要である。

## 失敗条件
- 多重接続を副業数、収入源数、人脈数へ還元する。
- 同じ市場・同じ評価軸・同じ時間軸へ接続を増やし、見かけだけを分散する。
- 灯火を増やそうとしてノイズを増幅する。
- Alignmentを迎合へ変え、接続のために灯火を歪める。
- 価値を所有・囲い込み・滞留させ、循環を止める。
- 接続解除を不可能にし、再び単一構造へ捕捉される。
- E的接続の設計不全を人格的悪意だけで説明し、構造修正・撤退判断を失う。
- ノード化を肩書き、権力、不可欠性の自己正当化へ変える。
- 能力完成を公共倫理の完成や免責へ読み替える。

## 反証・改訂条件
Parentは、SPOFの再発――単一評価軸・単一時間軸への収斂――、循環停止――ストック化・再投資不全――、灯火汚染――純度低下――、接続解除不能化、または観測窓δにおける流量低下・摩擦増大等の現象Mが確認された場合に仮説を棄却または改訂すると明示する。本派生ではδの固定期間、流量・摩擦の独自閾値、接続数の適正値を追加しない。

## 誤読防止
- 多重接続 ≠ 副業推奨、複業礼賛、ギグワーク一般化。
- 自由 ≠ 孤立、無拘束、無責任。
- 分光 ≠ 複数人格、複数の使命、資格の足し算。
- Alignment ≠ 迎合、自己消去、営業テクニックへの還元。
- 循環 ≠ 無償奉仕、自己犠牲、所有の全面否定。
- 上流ハブ接続 ≠ 権力者への服従。
- 撤退 ≠ 感情的逃避。Parentでは循環保全の操作である。
- ノード ≠ 役職、身分、権力階級。
- Life-OSの完成 ≠ 公共倫理の完成。公共条件は次段で検査される。

## 第三者・AIでの利用軸
この派生は、多重接続を「接続件数の最大化」へ単純化せず、何がSPOFか、灯火がどの機能へ分光されているか、接続先の失敗モードが分散しているか、価値が流れているか、退出可能性があるか、能力と公共責任の境界が保たれているかを構造的に読むための公開接続面である。個人の職業選択・適職判定・人格評価・道徳判定を自動化する根拠にはしない。
