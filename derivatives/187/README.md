## 位置づけ
親原典はLife-OS三部作の完結編として、Vol.1で置かれた「生存の床」と、Vol.2で精錬された「灯火」を、社会構造へ実際に伝達する駆動系へ接続する。扱うのは人生訓や自由の賛美ではなく、単一接続をSPOFとして診断し、一つの灯火を複数の独立プラグへ分光し、L4の衝動をL5の機能へ翻訳し、異なる失敗モードへ接続を分散し、価値を循環させることで、個人が構造間を可動できる能力を設計する理論である。

親原典が定義する自由は、社会から切断されることでも無拘束に振る舞うことでもない。複数の異なる社会構造に異なる機能で接続し、その接続を選択・解除できる「構造的可動性」である。多重接続は副業数や人脈数の増加ではなく、接続先と機能の双方を分散し、市場・評価基準・成果時間軸などの失敗モードを異質化する設計として置かれる。

同時に親原典は、能力の完成と公共倫理の完成を分離する。ノードとなった個人は価値だけでなく誤りや沈黙も増幅し得るため、Life-OS Vol.3は個人側能力を完成させる一方、その能力の公共域での使用条件を次の幕間へ残す。この「完成と未完の同時成立」が終点の境界である。

## 中心命題
親原典の中心命題は、**生存が床として固定され、灯火が精錬されたというLife-OS内部の前提に立つとき、単一接続というSPOFを、多重接続・灯火の分光・インターフェース整合・価値循環・失敗モード分散・撤退可能性によって置換することで、個人は特定構造への固定依存から離れ、複数構造の間で価値を接続・変換するノードとして可動できる**という設計命題である。

ここで多重接続は単なる「複数化」ではない。同じ市場、同じ評価軸、同じ時間軸へ接続を増やしても、同じ障害で同時に沈降するなら構造的分散ではない。自由は接続数ではなく、失敗モードの異質性と、接続を選択・解除できることによって成立する。

また、能力完成は免罪ではない。親原典は、ノードが複数構造へ影響を通すほど、発言だけでなく選択・放置・沈黙も増幅されるとし、公共倫理をVol.3の完成条件へ混ぜず、次段の検査対象として明示的に分離する。

## 構造層
**1. 生存床。** Life-OS Vol.1が置く前提。生存を一つの接続先の評価へ直結させないことで、接続の選択・解除を設計可能にする。

**2. Mono-Connection / SPOF。** 一つの会社・職能・役割等への固定依存。親原典は、本人の努力や誠実さに関係なく一点故障が全体停止へ波及する工学的脆弱性として扱う。

**3. 灯火 / Prism。** 灯火はノイズ除去後にも残る構造的偏りであり、複数の灯火を足すのではなく、一つの熱源を再抽象化して複数の社会的機能へ展開する。分光は分裂ではなく展開である。

**4. Plug / Interface Alignment。** 灯火は内的衝動のままでは社会的機能にならない。受け手の目的・困りごと・制約を観測し、問題解消機能へ翻訳し、文章・設計図・手順書などの成果物へ仮固定する。整合は迎合ではなく、純度を保った形態変換である。

**5. Poly-Connection。** 複数の異なる社会構造に、異なる機能で接続する状態。市場・評価基準・成果時間軸等の失敗モードを分散し、一つの沈降が全体沈降にならない冗長性を作る。

**6. Circulation / Flow。** 情報、評価、人脈、資源、報酬など循環すべき価値を止めず、変換・再配分・再投資する。親原典は成功を、大量の価値（CとS）が自分を通過していく状態として再定義する。

**7. Structural Stability / Risk Control。** 安定は無変化ではなく、変化が続いても循環が止まらないこと。失敗モード分散、ハブ（上流構造）との同期、致命リスク選別、E的接続の検知、撤退、定期見直しによって維持する。

**8. Node / Public boundary。** ノードは価値の所有者や肩書きではなく、複数構造の間で接続と変換を担う存在機能である。価値だけでなく誤りや沈黙も増幅するため、能力完成は公共倫理の完成を意味しない。

## 適用例
**1. 単一接続の診断。** 一社、一職、一役割、一つの評価軸を失うだけで生活・機能全体が停止するなら、その接続をSPOFとして可視化する。本人の根性や忠誠心の問題へ還元しない。

**2. 灯火の分光。** 「構造が乱れていると整えたくなる」という一つの灯火を、業務フロー改善、文章構造編集、教育設計、複雑な議論の翻訳など、異なる構造が使用できる複数のプラグへ展開する。親原典の例では、すべて同一の灯火から派生することが重要である。

**3. インターフェース整合。** 「整理が好き」のようなL4の表現を、受け手の問題を解消できるL5の機能へ変換し、具体的な成果物にする。接続のために灯火そのものを歪めない。

**4. 接続分散の検査。** 複数の接続があっても、同業界・同評価軸・同短期時間軸に集中していないかを見る。市場、評価基準、成果時間軸が異なる接続を持ち、一つが沈降しても他が同時沈降しない構造を目指す。

**5. 循環と再投資。** 知見を次へ渡す、評価を適切に配分する、得た資源を次の試行へ回すなど、価値を止めず流路を太くする。所有一般を否定するのではなく、循環すべき価値の詰まりを除く。

**6. E的接続と撤退。** 成果定義が曖昧、評価基準が頻繁に変わる、貢献が可視化されない、接続解除が暗黙に否定される等を設計不全の兆候として観測する。灯火の純度低下、一方向循環、退出不能が続くなら、撤退を循環保全の操作として扱う。

## 測定・監査点
- 一つの接続喪失が全体停止へ波及するSPOFが残っていないか。
- 接続数ではなく、市場・評価基準・成果時間軸など失敗モードの異質性があるか。
- 灯火が複数の外部ノイズへ分裂せず、一つの構造的偏りから複数プラグへ展開されているか。
- 各プラグが他のプラグへ依存せず、独立した機能として成立するか。
- L4の衝動がL5の問題解消機能・成果物へ翻訳されているか。
- Alignmentの過程で灯火の純度が低下していないか。
- 説明量、相手の理解、条件交渉、継続発生に過剰な摩擦が残っていないか。
- 情報・評価・人脈・資源・報酬が恒常的に滞留せず、再配分・再投資されているか。
- 一つの接続が停止しても他の循環が継続するか。
- 少なくとも一つの接続が、情報・方針・価値の流れの源に近い上流構造と同期しているか。
- E的接続の兆候と、接続解除可能性が観測できるか。
- その人が不在のときの流れ、通過時の摩擦、価値増幅の変化からNode性を観測できるか。
- 統合監査要旨の条件Z、T（整合性）・S（持続性）・R（再現性）、公開監査束の相互整合が維持されているか。

## 成立条件
- 生存床と拡張接続を混同せず、Life-OS内部の前提として保持する。
- Mono-Connectionを精神論ではなくSPOFとして診断する。
- Poly-Connectionを単なる接続件数ではなく、接続先と機能、失敗モードの分散として扱う。
- 灯火を複数化せず、一つの灯火を分光して独立プラグへ展開する。
- L4の衝動をL5の機能へ翻訳し、Alignmentを迎合へ変えない。
- 循環すべき価値を滞留させず、再投資・再配分によって流れを維持する。
- 変化や部分故障を前提にし、それでも全体が停止しない構造的安定を設計する。
- 灯火汚染、循環停止、判断自由喪失を優先的に避け、致命傷になりにくい試行錯誤と区別する。
- E的接続を人格的悪意の証明へ変えず、設計不全として観測し、必要な撤退可能性を保つ。
- Nodeの能力完成と公共倫理の未完を同時に保持する。

## 失敗条件
- 多重接続を副業数、収入源数、人脈数の最大化へ還元する。
- 同じ市場、同じ評価軸、同じ時間軸へ接続を増やし、見かけだけを分散する。
- 複数の灯火・使命・資格を足し算し、分光を外部材料の収集へ置換する。
- 「やりたいこと」を機能翻訳せず、そのまま社会的価値とみなす。
- Alignmentを迎合へ変え、接続のために灯火の純度を下げる。
- ストック一般を否定する議論へ広げる、または循環すべき価値の詰まりを放置する。
- 接続数の増加を構造的安定と同一視する。
- E的接続の兆候を無視し、灯火の摩耗・一方向循環・退出不能を固定化する。
- Nodeを肩書き、身分、権力の正当化へ変える。
- 能力完成を公共倫理の完成・免罪・無責任な自由へ読み替える。

## 反証・改訂条件
親原典の統合監査要旨では、条件Zとして監査周期に基づく再検証、T（整合性）・S（持続性）・R（再現性）の充足、公開監査束の相互整合を置き、それらを満たす限り仮説を維持する。

反証条件は、SPOFの再発（単一評価軸・単一時間軸への収斂）、循環停止（ストック化・再投資不全）、灯火汚染（純度低下）、接続解除不能化、または観測窓δ期間における流量低下・摩擦増大等の現象Mである。これらが確認された場合、仮説Aは棄却または改訂される。

## 誤読禁止 / 解釈制約（原典適合）
親原典の工学・流体・SPOF・分光という語彙は、社会構造を説明する設計言語として使われている。自然科学上の普遍法則や、個々人の人生結果を保証する固定式へ変換しない。

生存が床として固定されたという記述はLife-OSが置く文明段階の前提であり、現実の全個人について制度的生存保証がすでに達成済みだという外部事実の証明へ拡張しない。

多重接続を「もっと働く」「常時複数案件を持つ」「収入源を増やす」義務へ変えない。分光を新しいスキルや資格の収集へ、Alignmentを売り込みや迎合へ、循環を無償奉仕や自己犠牲へ、撤退を逃避へ置き換えない。

ノードは価値を独占する主体ではなく接続・変換を担う機能である。親原典が「不可欠性」と記述する部分を、権力・支配・身分の正当化へ変えない。また、能力完成は公共倫理の完成ではなく、公共域での振る舞いは次の幕間で検査されるという境界を保持する。
