## この原典が定義するもの

本稿は、営業を言葉の巧拙ではなく、沈黙・姿勢・呼吸・視線・声・焦点切替によって対話の張力を編集する営みとして定義する。

```text
重要な問い
→ 沈黙を保持する
→ 相手の思考が表面化する
→ 矛盾や不安を誠実な圧として直視する
→ 停滞時に焦点を切り替える
→ 緊張から共鳴、信頼へ移行する
→ 自然な意思決定条件が整う
```

## 中心構造

- 呼吸とリズムの同期
- 開かれた姿勢と沈黙
- 声量・速度・間の編集
- 矛盾を照らす誠実な圧
- 過去／未来、数字／文化、障害／第一歩の焦点切替
- 張力設計プレイブック

## 実務ルール

1. 重要な問いの直後は15秒待つ。
2. 違和感のある論点を一度は直視する。
3. 会話が停滞したら同じ説明を繰り返さず焦点を切り替える。

## 成立条件

- 沈黙を営業側の不安で埋めない。
- 圧を威圧や強制に変えない。
- 相手の反応を観測し、冷却・撤回・再配置できる。
- 非言語を属人的勘ではなく観測・訓練可能なものとして扱う。
- 顧客の尊厳と自己決定を保持する。

## 誤読禁止

```text
威圧や恐怖で契約させる方法
沈黙を罰や無視として使うこと
非言語で相手を無意識に操る万能技術
15秒を全場面に機械適用する規則
話術を不要とする主張
```

この046は張力設計の中心線を示す接続面である。沈黙の長さ、圧の具体例、焦点切替、教育法、監査指標、起源署名は親原典で確認する。
