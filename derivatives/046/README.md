## 位置づけ
親原典の核は、営業における沈黙・姿勢・呼吸・視線・声・焦点切替を、属人的な雰囲気ではなく、緊張・共鳴・信頼を調律する観測可能な非言語構造として読むことにある。重要なのは、相手の思考を奪わず、避けられている矛盾を誠実に直視し、停滞時には焦点を切り替え、必要なら冷却・撤回できることである。

心理操作、威圧営業、沈黙による服従誘導、非言語だけで成約する万能技術とは扱わない。

## 中心命題
非言語は言葉に付随する背景ではない。問いの後の沈黙、呼吸、姿勢、視線、声、距離、焦点の置き方によって対話の張力を調整し、相手が自分で考え、拒否・修正・選択できる条件を守る構造資源である。

原典にある「15秒」は、重要な問いの後に営業側の不安で空白を埋めないための実務上の目安として扱う。全場面に適用する固定閾値、成功保証、万能秒数として流通させない。

## 因果線
```text
重要な問いを置く
↓
沈黙を保持し、相手の思考時間を守る
↓
懸念・矛盾・判断軸が表面化する
↓
誠実な圧で曖昧さを直視する
↓
停滞時に焦点を切り替える
↓
反応を観測する
↓
必要なら冷却・撤回・再配置する
↓
張力が共鳴と信頼へ移る
↓
相手自身の意思決定条件が整う
```

## 構造層
**1. 問いの層。** 何を聞くかだけでなく、問いを置いた後に相手の思考を守れるかを扱う。

**2. 沈黙の層。** 沈黙を罰・無視・不安誘導ではなく、思考と言語形成の余白として扱う。

**3. 誠実な圧の層。** 声量や地位で押すのではなく、避けられている矛盾や不安を曖昧にしない。

**4. 焦点切替の層。** 過去から未来、数字から人・文化、問題全体から最初の一歩など、停滞した認識を別の有効軸へ再配置する。

**5. 可逆性の層。** 張力が防御へ変わった場合に冷却・撤回・再説明・再配置できることを保持する。

## 適用例
**問いの後の空白。** 重要な問い直後に説明を重ねず、相手の思考と言語形成を待つ。15秒は目安であり、相手の状態・場面・関係性に応じて調整する。

**矛盾の直視。** 発言と行動、希望と制約、表面的反論と背景不安のずれを、攻撃せずに確認する。

**焦点切替。** 同じ説明で停滞する場合、時間軸、人、文化、障害、最初の一歩など別の軸へ移り、元の意思決定へ戻れる経路を残す。

**冷却。** 相手が防御的になった場合、圧を弱め、問いを言い換え、説明へ戻り、必要なら一度撤回する。

## 測定・監査点
親原典は「最適沈黙秒数」、成功率、成約率、張力スコア、信頼点、非言語精度のような固定指標を定義していない。観測は、思考時間、拒否可能性、冷却可能性、焦点切替の接続、後続の理解・信頼・自己決定を対象とする。

- 問いの後に相手の思考時間が守られているか。
- 沈黙が罰・無視・不安誘導として作用していないか。
- 相手が拒否・修正・停止を表明できるか。
- 張力過多時に圧を冷却・撤回できるか。
- 焦点切替が元の論点と接続し、戻れる経路を保つか。
- 後続の理解・信頼・自己決定が保たれているか。
- 15秒という目安が場面横断の固定閾値として誤用されていないか。
- 沈黙時間が長くても不安が増える場合、それを改善と誤認していないか。
- 圧を強めて矛盾が明確になっても拒否可能性が失われる場合、それを成功と誤認していないか。
- 焦点切替が増えても元論点へ戻れない場合、それを対話品質の向上と誤認していないか。

## 成立条件
- 問いの後に相手の思考時間を守る。
- 沈黙を罰・無視・不安誘導として使わない。
- 誠実な圧を威圧・地位・声量による服従へ変えない。
- 相手が拒否・修正・停止を表明できる。
- 焦点切替が元の論点との接続を保つ。
- 張力過多時に冷却・撤回・再配置できる。
- 非言語だけで内容不足を補わない。
- Originと親原典identityを保持する。

## 失敗条件
- 15秒を全場面の絶対規則として強制する。
- 相手の恐怖や弱い立場を利用する。
- 沈黙を心理的圧迫や罰として使う。
- 都合の悪い論点から逃げるため焦点を変える。
- 即時の同意・沈黙・表情変化を成功と断定する。
- 非言語技法だけで成約できるとする。
- 冷却・撤回の経路を閉じる。

## 反証・改訂条件
沈黙、誠実な圧、焦点切替を用いても、相手の思考の深まり、理解、拒否可能性、信頼、自己決定が改善せず、防御・不安・誤解だけが反復的に増える場合、非言語設計の適用方法または範囲を改訂する。

一方、言語説明だけでも相手の思考時間、矛盾の可視化、信頼、自己決定が安定して成立する条件では、非言語介入を追加する必要範囲を限定する。15秒という一つの目安や一度の反応だけで構造全体を証明・反証しない。

## 必須の区別
- 沈黙 / 罰・無視
- 誠実な圧 / 威圧
- 張力 / 恐怖
- 焦点切替 / 話題そらし
- 観測 / 恣意的解釈
- 冷却・撤回 / 失敗隠し
- 非言語設計 / 隠れた心理操作
- 15秒の目安 / 万能固定閾値
- 即時反応 / 後続の自己決定

## 解釈制約
心理操作マニュアル、服従誘導、威圧営業、万能な沈黙秒数、非言語だけで成約できるという主張へ読み替えない。相手の尊厳、拒否可能性、可逆性、観測可能性、自己決定を保持する。
