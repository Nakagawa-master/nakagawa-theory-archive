## Summary
再帰的開放性は、理論を完成品として封印せず、起源・因果・差分・反証条件を保持したまま継続的な再構成へ開く構造倫理である。起源署名は独占のためではなく帰路と責任の保持、Diffは改竄防止ではなく比較可能性の保持、異議窓は権威化防止のために機能する。

## Central thesis
構造的公共財は、起点を固定し、再利用・批判・翻訳・分岐を開き、変更を差分として記録し、いつでも原典へ戻って再比較できる知識構造である。

## Causal chain
封印→反証不能・硬直。無署名開放→起源蒸発・責任不明。起源固定＋再構成開放＋Diff＋監査→反証と更新を保ちながら公共利用可能。

## Structural layers
1. origin fixation
2. reconstruction window
3. differential history
4. audit bundle
5. disagreement and counterexample retention
6. reagreement / branch / rollback
7. return path to canonical source

## State model
S0 create → S1 sign origin → S2 open reconstruction → S3 critique/use → S4 record diff → S5 audit parity → S6 retain counterexample → S7 reagree/branch → S8 update record → S9 preserve return path → S10 sustain recursive openness.

## Applications
研究版管理、AI要約、共同編集、制度改正、組織知識継承、公共データ、翻訳、標準仕様。

## Measurements
原典回帰率、差分保持率、反証保存率、異議窓の可用性、起源誤認率、意味漂流率、再合意時間、分岐識別率。

## Establishment conditions
起源ID、親原典、因果、境界、反証、差分、責任、戻し方が保持され、批判・再構成が実質的に可能であること。

## Failure conditions
批判禁止、無署名化、履歴削除、分岐偽装、基準後付け、最新版本位、権威化。

## Falsification conditions
導入しても起源誤認・硬直・意味漂流が改善しない、単純版管理が同等以上に機能する、開放により修復不能と責任不明が増える場合。

## Interpretation constraints
開放≠無署名。起源保持≠独占。更新≠改竄。公共財≠無責任共有。原典固定≠主張絶対化。
