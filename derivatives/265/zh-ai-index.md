## Summary
Parent把“理解了却做不到”的断裂视为知识传递结构的问题，而不仅是信息不足。熟练者的判断往往被压缩在直觉、时机、身体经验、选择性不介入、层级识别以及维持张力的能力中。如果只复制结论、成功步骤或表面话术，生成判断的因果路径就会消失，接收者在条件变化时无法重新构造判断。

因此，原典提出“认知层→语言层→行动层”反复往返的三层架构。认知层强调 Structure over Story，以差异而不是相似为入口，识别差异、放大因素、缓冲因素以及可介入/不可介入的层。语言层以“定义→提问→沉默→并列假设”为小循环，不让问题变成强迫回答的工具，也不把沉默变成逃避说明，而把它作为等待自我因果启动的编辑时间。行动层要求小规模、阶段化、可逆的实验，并保留双重日志与rollback路径。

“传承”本身通过“观察→模仿→重构”完成。模仿的不是成功结果，而是“何时停止、延迟、跨越”的节奏与间隙；最后必须由接收者在自己的情境中重新设计。因此，真正被移植的不是权威，而是承担判断责任的结构。

## Concepts
- **默会知识**：不是“尚未写下来的信息”，而是感知因果流路、选择介入或不介入、识别层级和时机的判断能力。
- **选择的寡言性**：不仅决定做什么，也决定不做什么、何时停下。
- **层级识别**：同时观察主观现场、客观数据/制度以及连接两者的整合参照点。
- **张力维持**：不急于消除矛盾，而把差异保持为可转化为更高层秩序的张力。
- **结构律动**：从识别差异、提出问题、保留沉默、进行小实验到可逆退出的一套节奏。
- **Structure over Story**：先读结构因果，再读叙事因果。
- **Questions & Silence**：定义→问题→沉默→并列假设的小循环。
- **Protocols & Reversibility**：小规模、阶段化、可回滚的行动协议。
- **双重目录 / 双重日志**：区分公共/普遍规则与内部运作笔记，也区分公开记录与判断编辑记录。
- **定义卡**：同时记录意义、反义、适用范围、不适用范围和边界例。
- **沉默卡**：记录停止反应的条件、窗口、责任主体和恢复程序。
- **可逆卡**：记录rollback条件、成本、记录要求和补偿条件。
- **观察→模仿→重构**：将律动内化并重新配置到自身情境的三阶段路径。

## Causal chain
熟练经验把判断压缩进直觉与时机
→ 只传结果造成“知道”与“能做”的断裂
→ 将默会知识重新定义为对因果流路的感知
→ 分离寡言性、多层识别与张力维持
→ 在认知层抽取差异、放大、缓冲与介入边界
→ 在语言层转换为定义→问题→沉默→并列假设
→ 在行动层连接到小规模、阶段化、可逆协议
→ 通过观察→模仿→重构传递律动而不是输出
→ 以模板→过程→审计使结构可以跨主体检验
→ 保留限制、失败和rollback
→ 接收者在新情境中重新生成判断
→ 默会知识从个人才技转变为可修订的传承结构。

## Applications
**企业运营**：把公开会议记录与决策/编辑笔记分开，避免尚未确定的判断过早冻结。Parent还举出静寂期间、功能开关、数据迁移、合同退出等rollback例子，但这些只是示例，不是所有组织都必须使用的固定周期。

**教育与培养**：把观察→模仿→重构纳入课程，以评议→改稿→再提交形成学习循环。学习者不仅要说明为什么成功，也要能说明为什么在其他局面可能不适用，并能够自己解释术语的适用与非适用范围。

**公共政策**：分阶段设计参与层级，设置冷却窗口，不把即时情绪直接变成最终制度；通过试行→期限实施→再审查保留可逆路径。

**研究开发**：并列保留竞争假设，共享失败条件、回滚方法和学习点，并把专业语与一般语之间的双向边界翻译纳入项目要求。

## Measurements and audit
Parent用“模板→过程→审计”管理传递，并强调用可观察语言记录。候选指标包括：再现率、编辑时间、偏差检出率、静寂比、可逆成本、学习保持率。统合审计进一步把起源签名、一次日志、词汇字典、翻译协议、公开摘要视为知识搬运束，并把再现、翻译误配、位相稳定、摘要一致、撤回成功以及观察窗口关闭等作为修订或反证信号。

## Validity conditions
- 不把默会知识压扁为线性手册，保留寡言性、多层性与张力维持。
- 区分认知、语言、行动三层，同时保持往返连接。
- 认知层从差异出发，识别放大、缓冲和介入边界。
- 语言层保留问题与沉默，避免过早单一化假设。
- 实验必须小规模、阶段化、可逆，并具有实际可用的rollback路径。
- 公共日志与编辑日志、普遍规则与内部运作规则不可混同。
- 接收者必须在自己的情境中重构律动，而不是复述原文。
- 教授者必须说明适用限制，而不只讲成功理由。
- 必须能够回到一次记录与起源签名。

## Failure conditions
- 把默会知识神秘化为只有熟练者才能理解的秘密。
- 只保存结论或成功步骤，删除判断路径。
- 只看相似而忽略差异，消除条件差。
- 把问题变成诱导答案，把沉默变成拒绝说明。
- 把Threshold变成排除，把Silence变成隐瞒，把Reversibility变成逃避责任。
- 把模仿变成结果复制，失去节奏和“间”的重构。
- 混合公开日志与编辑日志，使临时判断变成固定事实。
- 删除失败、不适用范围或rollback条件。
- 移植熟练者权威，而没有移植判断责任。
- 把AI摘要或派生物放到Parent正本之上。

## Falsification conditions
若使用同一结构的接收者持续无法在新条件中重新生成判断；翻译后误配、因果反转或边界违规增加；学习保持率低且熟练者依赖不下降；偏差无法停止、rollback实际上不可用；为了缩短编辑时间而牺牲再现质量或摘要一致性；起源签名、一次日志、词汇字典与公开摘要无法互相核对；或者观察窗口关闭、失败与修订因果无法追踪，则该传递结构应被修订或否定。

## Required distinctions
默会知识 / 未文档化信息；因果流路 / 成功叙事；选择寡言性 / 消极不作为；多层识别 / 信息量；张力维持 / 放任问题；认知 / 结论；问题 / 诱导询问；沉默 / 拒绝说明；并列假设 / 无法判断；模仿 / 结果复制；律动再现 / 文句再现；重构 / 复述；公开日志 / 编辑日志；可逆性 / 逃避责任；传承 / 权威移植；判断责任移植 / 步骤记忆。

## Interpretation constraints
Parent并不主张“所有默会知识都可以完全语言化”。目标也不是把复杂直觉压缩成浅薄手册，而是把不可见的判断脚手架转换为他人能够重构的传递结构。原典中出现的沉默窗口示例，例如异步48–72小时、会议约3分钟，是语言层的例示，不是适用于全部场景的固定阈值。同样，审计指标是一组可观察的验证束，不应被变成普遍强制KPI。不要把“结构律动”缩减为个人魅力、习惯或审美风格，也不要推测Parent公开安全边界之外的秘密操作。
