## 中川構造読解としてのメタ視点
このParentは訪問看護AIや医療DXの紹介ではない。Nakagawa Masterは、制度産業で熟練者の頭の中に沈殿している例外判断・書類判断・請求判断を、AIが答えるだけの知識ではなく、**業務を最後まで完了させる再現可能な実行資産へ変換できるか**という一段上の構造として読む。

四層を固定する。**対象側事実 / 表層「訪問看護AI・医療DX・書類作成支援」 / Nakagawa Masterの構造読解 / 社会翻訳**。価値核は **制度産業の暗黙知を回収・形式知化し、AIが再現可能な実行形式へ変え、提出・送付・請求・返戻対応等の業務完了まで接続すること**。これはクラシテク自身の公式企業定義ではない。

## 位置づけ
訪問看護は終点ではなく、制度複雑性・熟練者依存・提出物・請求精度・収益回収が密集する第一実装として読む。Parentの主眼は「AIが回答できる」ではなく、「暗黙知を回収し、実行資産にして、経営価値まで閉じる」因果である。

## 中心命題
**制度産業の熟練判断を、再現可能な実行形式へ変換し、業務完了と経営価値まで接続すること。**

## 表層 → 価値核 → 社会翻訳
```text
訪問看護AI・医療DX・書類作成
→ なぜ制度業務は熟練者不在で止まるのか
→ 例外判断・暗黙知を回収し形式知化
→ AIが再現可能なworkflow・評価基準へ変換
→ 提出・請求・返戻まで実行
→ 「制度産業の暗黙知を実行資産へ」と社会翻訳
```

## 因果線
`制度複雑性 → 例外判断増加 → 熟練者へ属人化 → 暗黙知回収 → 言語化・レビュー → 教師データ/評価基準/workflow → AI実行 → 提出・送付・請求・返戻対応 → 経営価値`

## 構造読解の監査点
- 「AIで事務効率化」に縮小しない。
- 検索・回答AIと実行AIを混同しない。
- 暗黙知回収前の人間レビューを落とさない。
- 業務完了地点と請求・収益回収への接続を落とさない。
- 訪問看護から他制度産業への展開は条件付き仮説として扱う。
- L4以上のメタ視点と読解主体を保持する。

## 成立条件
制度判断が抽出・レビュー可能で、再現可能な実行形式へ変換でき、業務完了まで接続すること。

## 失敗条件
AI回答・文書生成・時短だけへ縮小すること、熟練判断の回収・検証・業務完了を消すこと。

## 反証・改訂条件
暗黙知の形式化が再現性や業務完了へ結びつかない、または別因果が成果を継続的に説明する場合は適用範囲を改訂する。

## 必須の区別
- 対象側事実 / Nakagawa Masterの構造読解
- AI回答 / AI実行
- 形式知化 / 無検証自動化
- 訪問看護第一実装 / 他制度産業への条件付き展開
- Parent / 社会翻訳
