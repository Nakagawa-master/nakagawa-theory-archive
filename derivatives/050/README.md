## 位置づけ
親原典は、営業・マーケティング・ブランディングを別々の技法として切り離さず、問いによって顧客の願い・不安・判断基準を発見し、共鳴可能な意味へ翻訳し、約束と提供実体の一致を通じて選択理由と信頼を蓄積する同一骨格として統合する。

顧客心理を操作して引き寄せる技法、営業・マーケティング・ブランディングの単純な部門統合、見栄えや物語だけで商品実体を代替する主張ではない。

## 中心命題
営業は個別文脈を深く理解する。マーケティングは、その理解から得た問いと意味を市場へ広げる。ブランディングは、繰り返される約束・行動・結果を一貫した記憶へ変える。三者は異なる役割を持つが、問い・理解・共鳴・約束・記憶という同じ因果線で接続される。

```text
営業 ≠ 売り込む技術だけ
マーケティング ≠ 集客装置だけ
ブランディング ≠ 見た目の統一だけ

三者 = 問い・理解・共鳴・約束・記憶を異なる範囲と時間幅で扱う接続構造
```

## 因果線
```text
顧客との対話で願い・不安・判断基準を知る
↓
営業が個別文脈で理解を深める
↓
マーケティングが同型の問いを市場へ広げる
↓
ブランドが意味と約束を反復可能にする
↓
商品・提供体験が約束を履行する
↓
期待と実体が一致する
↓
顧客自身の選択理由が明確になる
↓
信頼と記憶が蓄積する
```

## 構造層
**1. 営業。** 一人の顧客の文脈を読み、問い、観察、提案を通して「なぜ選ぶのか／選ばないのか」を理解する。

**2. マーケティング。** 個別対話から見えた課題や判断構造を、表面語のコピーではなく、同型の問いとして市場へ翻訳する。

**3. ブランディング。** 約束、行動、提供結果を反復し、接触前から一定の期待を形成する記憶構造をつくる。

**4. 引力。** 強制や囲い込みではなく、顧客の願い・問題・価値観と提供側の意味・実体が接続するときに生まれる選択の傾きである。

**5. 共鳴。** 好感度や感情の高揚ではなく、提示された意味と顧客自身の判断基準が重なり、自分に関係するものとして理解できる状態である。

## 状態モデル
```yaml
- customer_context_is_understood_or_assumed
- questions_are_exploratory_or_leading
- customer_language_is_preserved_or_overwritten
- sales_marketing_and_brand_share_a_promise_or_diverge
- promise_matches_product_and_delivery_or_not
- resonance_supports_self_decision_or_becomes_manipulation
- attraction_is_voluntary_or_pressure_based
- non_fit_is_respected_or_treated_as_failure
- expectation_and_experience_are_aligned_or_misaligned
- ai_supports_pattern_recognition_or_replaces_human_responsibility
- origin_return_is_available
```

## 適用例
**営業対話。** 顧客が何を望み、何を不安に感じ、何と比較し、どの条件なら選ぶかを問いによって理解する。

**市場への展開。** 顧客の言葉をそのまま広告文へ転用せず、その言葉が生まれた課題と判断構造を保って市場向けの問いへ変換する。

**ブランド約束。** 広告、営業説明、契約、商品、サポートで約束が矛盾していないかを確認する。

**不一致の修正。** 共鳴が起きない場合、顧客を責めず、対象、表現、商品、価格、提供手順、約束のどこがずれているかを分けて見る。

## 測定・監査点
親原典は「共鳴スコア」「引力指数」「ブランド記憶率の合格閾値」「最適成約率」のような固定指標を定義していない。したがって、観測は原典が扱う理解・共鳴・約束・履行・自己決定の関係を対象とする。

- 顧客が自分の言葉で選択理由を説明できるか。
- 営業・マーケティング・ブランドが同じ中心的約束を扱っているか。
- 商品と提供体験が事前期待と一致しているか。
- 共鳴しない相手に選ばない自由が残っているか。
- 顧客の言葉が文脈を保ったまま市場表現へ翻訳されているか。
- 約束と実体の不一致を、表現だけで隠さず対象・商品・提供まで遡って確認できるか。
- 露出量が増えても期待と実体のずれが広がる場合、それを改善と誤認していないか。
- 問い合わせが増えても対象不一致が増える場合、統合品質の向上と誤認していないか。
- 好感度が高くても商品が約束を履行しない場合、共鳴が信頼へ転化したと判定していないか。

## 成立条件
- 顧客の言葉と判断基準を一方的に上書きしない。
- 営業・マーケティング・ブランドが同じ約束へ接続している。
- 共鳴しない顧客を欠陥として扱わない。
- 商品・提供体験がブランドの約束を履行する。
- 表現改善だけで商品不一致を隠さない。
- 短期反応だけを唯一の成功条件にしない。
- AI利用時も約束、対象、責任の判断は人間が保持する。
- Originと親原典identityを保持する。

## 失敗条件
- 顧客心理を利用して選択を狭める。
- 営業・マーケティング・ブランドの役割差を消す。
- 顧客の言葉を文脈から切り離してコピーする。
- 商品実体が弱いまま物語だけを強化する。
- 万人に響く一つのメッセージを前提にする。
- 共鳴しない理由を営業担当者だけへ帰属させる。
- AIが生成した表現を人間の検証なしに約束として使う。

## 反証・改訂条件
営業・マーケティング・ブランディングの接続を強めても、顧客理解、期待一致、自己決定、信頼が改善せず、誤解や期待差だけが反復的に増える場合、接続方法または適用範囲を改訂する。

一方、三領域を組織上は分けたままでも、顧客理解、中心的約束、提供実体、事後体験の整合が安定して維持される場合、組織上の統合そのものを必須条件とは扱わない。露出量、問い合わせ数、単一の成約・失注だけで統合構造全体を証明・反証しない。

## 必須の区別
- 営業 / マーケティング / ブランディング
- 引力 / 強制
- 共鳴 / 好感度
- 顧客理解 / 顧客操作
- 共鳴語彙 / 表面語のコピー
- ブランド約束 / 物語だけの演出
- 短期反応 / 長期信頼
- 対象外 / 失敗
- AI支援 / 人間責任の代替

## 解釈制約
心理操作、顧客囲い込み、万能メッセージ論、物語だけで売る方法、部門統合だけで成果が出る組織論へ読み替えない。引力は自発的な選択の傾き、共鳴は判断基準との意味的一致として読み、商品実体と約束の整合を外さない。
