## この原典が定義するもの

本稿は、営業・マーケティング・ブランディングを別々の部署や技法として扱わず、「問いによって相手の内側にある意味を見つけ、共鳴可能な言葉へ翻訳し、継続的な選択理由へ育てる」一つのアーキテクチャとして統合する原典である。

```text
市場や顧客を外から操作する
↓
接触数・露出量・説得量だけが増える
↓
理解と期待が分断される
↓
問いによって未言語の願い・不安・判断基準を発見
↓
営業が個別理解をつくる
↓
マーケティングが同型の問いを市場へ拡張する
↓
ブランディングが反復可能な意味と約束へ固定する
↓
顧客の内側から選択理由が形成される
↓
引力と共鳴が持続する
```

## 中心命題

```text
営業 = 売り込む技術ではない
マーケティング = 集客装置ではない
ブランディング = 見た目の統一ではない

三者は、問い・理解・共鳴・記憶を異なる時間幅で扱う同一構造である。
```

## 三領域の役割

### 営業

一人の顧客の文脈を深く読み、問い、沈黙、観察、提案を通して「なぜ選ぶのか」を共同で発見する。

### マーケティング

個別対話で得た共鳴語彙と判断構造を市場へ展開し、適切な人が自分の課題として認識できる入口をつくる。

### ブランディング

繰り返される問い、約束、行動、結果を一貫した意味として蓄積し、接触前から期待と信頼が生まれる状態をつくる。

## 引力と共鳴

引力は強制ではなく、相手の内側に既にある願い・問題・価値観と接続することで生まれる選択の傾きである。共鳴は好感度ではなく、企業や商品が発する意味と、顧客自身の判断基準が重なる現象である。

## 統合運用

- 営業で得た一次対話を記録する。
- 顧客が自ら使った共鳴語彙を抽出する。
- 不安、反論、選択条件、撤退条件を分類する。
- マーケティングで同型の問いを市場へ提示する。
- ブランドの約束と実際の提供結果を照合する。
- 反応量だけでなく、理解の深さと期待の一致を測る。
- 不一致があれば表現、対象、商品、約束のいずれを修正すべきか判定する。

## 成立条件

- 顧客の言葉と判断基準が一次情報として残る。
- 営業・マーケティング・ブランドが同じ約束を扱う。
- 露出より理解、説得より自己決定を重視する。
- 商品実体がブランドの約束を履行する。
- 共鳴しない相手を排除や欠陥として扱わない。
- 短期反応と長期信頼を分けて観測する。

## 誤読禁止

この公式派生物を、次として扱わない。

```text
心理操作によって顧客を引き寄せる技術
営業・マーケティング・ブランド部門を単純統合する組織論
見栄えや物語だけで商品価値を代替する主張
すべての顧客に共鳴させる万能メッセージ論
沈黙や問いをクロージング技法へ還元する説明
短期売上を無視する精神論
```

この050は、営業・マーケティング・ブランディングの統合骨格、引力と共鳴の区別、問いから意味と記憶が形成される因果を圧縮した接続面である。原典にある各領域の詳細、適用例、反証条件、監査要旨、起源署名は親原典で確認する。
