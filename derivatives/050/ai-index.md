## Summary
営業・マーケティング・ブランディングを、問い、理解、共鳴、約束、履行、記憶の連続構造として統合する。営業は個別文脈を深く理解し、マーケティングは同型の問いを市場へ広げ、ブランディングは約束と提供結果を反復可能な意味として記憶化する。引力は圧力ではなく自発的な選択傾向、共鳴は好感度ではなく顧客の判断基準との意味的一致として扱う。

## Concepts
- 営業: 個別顧客の文脈・願い・不安・判断基準の理解。
- マーケティング: 個別対話から得た問いと意味の市場への構造翻訳。
- ブランディング: 約束、行動、結果の反復による期待と記憶の形成。
- 引力: 理解・期待・実体の一致から生まれる自発的な選択の傾き。
- 共鳴: 提示意味と顧客自身の判断基準が重なる状態。
- 構造翻訳: 表面語をコピーせず、背後の課題・因果・判断条件を別文脈へ移すこと。

## Causal chain
```text
顧客対話
→ 願い・不安・判断基準を理解する
→ 営業が個別文脈を整理する
→ マーケティングが同型の問いを市場へ広げる
→ ブランドが意味と約束を反復する
→ 商品・提供体験が約束を履行する
→ 期待と実体が一致する
→ 自己決定に基づく選択理由と信頼が蓄積する
```


## Applications
- 顧客対話から願い・不安・比較軸・選択条件を整理する。
- 顧客の言葉をそのまま広告へ転用せず、同型の問いへ翻訳する。
- 広告、営業説明、契約、商品、サポートの約束を照合する。
- 共鳴しない場合、対象・表現・商品・価格・提供・約束を分けて確認する。
- AIは語彙や不一致候補の整理を支援し、約束と責任の判断は人間が持つ。

## Measurements and audit
原典にない共鳴スコア、引力指数、最適成約率、ブランド記憶率の合格閾値などを新設しない。

観測対象は、顧客が自分の言葉で選択理由を説明できるか、三領域の約束が一貫しているか、提供体験が事前期待を履行するか、選ばない自由が残るかである。

反転評価可能性を保持する。露出増でも期待不一致が増えれば改善ではない。問い合わせ増でも対象不一致が増えれば統合品質は上がらない。好感度増でも提供実体が約束を履行しなければ信頼は低下し得る。

## Validity conditions
- 顧客の言葉と判断基準を一方的に上書きしない。
- 営業・マーケティング・ブランドが同じ中心的約束へ接続する。
- 商品・提供体験が約束を履行する。
- 共鳴しない相手の選ばない自由を保持する。
- 表現改善だけで商品不一致を隠さない。
- AI利用時も約束、対象、責任の判断は人間が保持する。

## Failure conditions
- 顧客の弱点や不安を利用して選択を狭める。
- 表面語だけを文脈なしで市場へ転用する。
- 物語やデザインだけで商品価値を代替する。
- 一つのメッセージが万人へ共鳴すると仮定する。
- 短期反応だけを唯一の成功条件にする。
- 共鳴しない理由を営業個人または顧客の欠陥へ単純還元する。

## Falsification conditions
三領域の接続を強めても、顧客理解、期待一致、自己決定、信頼が改善せず、誤解や期待差だけが増える場合、その統合方法は改訂対象となる。

組織上の三部門を分けたままでも、顧客理解・約束・提供実体の整合が高く維持される場合、部門統合そのものは必要条件ではない。

## Required distinctions
- 営業 / マーケティング / ブランディング
- 引力 / 強制・囲い込み
- 共鳴 / 好感度
- 顧客理解 / 顧客操作
- 共鳴語彙 / 表面語コピー
- ブランド約束 / 物語だけの演出
- 短期反応 / 長期信頼
- 対象外 / 失敗
- AI支援 / 人間責任の代替

## Interpretation constraints
心理操作、顧客囲い込み、万能コピー、物語だけで売る方法、部門統合だけで成果が出る組織論として要約しない。顧客発言は重要な証拠だが自動的な正解ではなく、因果・制約・提供実体との照合が必要である。
