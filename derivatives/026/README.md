## 位置づけ

この公式派生物は親原典への公開入口であり、原典の代替ではない。

親原典の主語はAlgaleX／うま藻の商品説明そのものではなく、中川マスターがZEROICHI記事で、なぜ「美味しい藻」ではなく「魚食構造の社会実装入口」という切り口を採用したのかという構造読解である。

## 中心命題

魚を食べ続ける未来を考えるとき、魚そのものだけではなく、養殖、餌、天然魚資源への依存、食物連鎖の起点まで遡る必要がある。

AlgaleX／うま藻は、その上流構想が社会へ直接入るのではなく、まず食材市場と料理現場へ入り、味・用途・採用理由・反復可能性を得ることで、本丸である魚食・養殖構造の前提再設計へ接続する「社会実装入口」として読まれる。

```text
魚食を持続させたい
→ 養殖の重要性が上がる
→ 養殖魚の餌が天然魚由来である矛盾が残る
→ 食物連鎖の起点である藻へ遡る
→ ただし飼料市場へ直結するには価格・供給・採用条件の壁がある
→ まず食材市場・料理現場で味と用途を持つ
→ 採用理由と反復可能性が形成される
→ 社会実装の入口が開く
→ 魚食・養殖構造の前提再設計へ接続する
```

「美味しい」は軽い付加価値ではなく、構想を社会へ通す入口の成立条件として扱われる。ただし、美味しさだけで終わらせると珍味・調味料紹介へ縮小するため、親原典は味から魚食構造へ因果を戻す。

## 構造読解のメタ軸

親原典が記録するのは、対象の機能一覧ではなく、ZEROICHI記事で何を前面化し、何を抑えたかという記事化判断でもある。

保持すべき軸は、うま藻の「なぜ生まれたか」から「どう社会へ入り始めたか」への移行、美味しさを終点でなく入口として置くこと、料理現場で用途と採用理由が具体化されること、食材市場から本丸へ向かう段階設計である。

## 誤読禁止

単なる藻類食品紹介、実食レビュー、珍味・調味料紹介、一般的なフードテック論、サステナブル食品カタログ、企業PRへ縮約してはならない。

また、親原典をAlgaleXそのものの構造説明だけに戻してはならない。中川マスターがこの社会実装順序をどのように読み、外部媒体記事へ翻訳したかまで保持する。
