# 公式派生物013｜悪因果論 AKI-012｜同意なき成約要求

Parent: NCL-α-20260518-f38a1e / DIFF-20260518-0015 / Origin Nakagawa Master
Parent URL: https://master.ricette.jp/society/nakagawa-master-aki-012-consentless-closing-demand/
Derivative: DDIFF-20260812-DNCL-013-0000-0003; supersedes DDIFF-20260709-DNCL-013-0000-0002

## 位置づけ
公式派生物013は、悪因果論AKI-012「同意なき成約要求」を、原典へ戻るための公開接続面として整理する。営業そのものを否定するのではなく、接点や興味を購買意思・合意成熟へすり替えることで、成約要求が圧力化し、市場の相談可能性を毀損する悪因果を扱う。

## 中心命題
接点、興味、課題認識、検討意思、購買意思、合意成熟、成約要求は同じ段階ではない。相手が判断できる条件を持たない段階で、成約だけを要求すると、営業接点は相談の入口から防衛対象へ変わる。

## 原典の因果線
接点が生まれる。組織内でその接点が見込み・売上時期へ変換される。課題理解、必要性確認、価値接続、信頼形成、合意成熟が省略される。営業担当者は顧客理解より社内報告を優先し、顧客は「話すと売り込まれる」と学習する。結果として、市場の相談可能性が失われ、さらに接点量やクロージング圧が増える。

## 原典固有構造
- 接点は同意ではない。
- 興味は購買意思ではない。
- 課題認識・検討意思・購買意思・判断条件は段階として分ける。
- 合意成熟とは、課題・必要性・判断条件・価値接続・導入条件が相互に確認される方向へ進んだ状態である。
- 成約要求は合意成熟の後ろに置かれると意思決定確認になるが、前に置かれると圧力になる。
- 市場の相談可能性とは、まだ買うと決めていない段階でも課題や関心を安心して開示できる余地である。

## 判定の焦点
いま相手がどの段階にいるかを分ける。接点か、興味か、課題認識か、検討意思か、購買意思か。判断条件、価値接続、導入条件が揃っているか。これらが未成熟なのに売上時期・見込み確度・クロージングだけが問われるなら、同意なき成約要求が起きている。

## 非該当境界
営業、クロージング、売上責任、見込み管理そのものは否定しない。相手が十分な判断条件を持ち、価値接続と合意成熟が確認された後に行われる成約確認は、本論が批判する圧力とは異なる。

## 誤読防止
本論を営業マナー論、押し売り批判、KPI批判、契約法解説へ縮約しない。中心は、接点を購買意思へすり替える認識構造と、その結果として市場の相談可能性が失われる悪因果である。

## 親原典へ戻る理由
原典では、接点から合意成熟までの段階差と、営業不信が市場全体の相談可能性を削るまでの因果が連続して説明されている。このREADMEは入口であり、原典本文の代替ではない。
