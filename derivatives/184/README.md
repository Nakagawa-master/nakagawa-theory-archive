## 位置づけ
親原典は、「働かなくても全員が生きられる社会は物理的に可能なのか」「誰がパンを焼き、エネルギーを供給し、基礎インフラを維持するのか」という反論を、倫理的願望ではなく現代文明の供給能力・非線形生産・配分構造から検討する幕間の論考である。

出発点は、生存と労働を必ず結びつける旧来の文明OSの前提を、そのまま事実として採用しないことにある。Parentは食料供給を例に、世界平均の供給量が一人一日約2,800〜3,000 kcal、一般的な必要量が約2,000〜2,500 kcalという参照値を置き、総量としての供給が必要量を上回っていても飢餓が残ることから、不足の主要因をSupplyだけでなくAccess / Distribution / Structureの問題として読む。ここでの数値はParentが論証に用いた時点依存の参照値であり、将来の適用では根拠データの更新が必要である。

さらにParentは、現代生産を「現在の人間労働時間の合計」だけでは説明できないとする。機械、アルゴリズム、インフラ、ソフトウェア、標準化、過去の知識蓄積が現在の生産を押し上げ、過去のC（貢献）が構造として現前化する。旧モデルを「時間投入＝生産」、新モデルを「構造投入＝生産」と対比し、限界費用の低減、複製可能性、累積性によって、生存最低ラインを超える供給余剰が継続して生まれる構造を「余剰C」の論点へ接続する。

Parentが理論署名で導入する「文明基礎代謝」は、社会が人為的努力を過剰に要さずとも維持できる、生存の下限を支える物理的循環である。それは善意や道徳だけを燃料にするものではなく、歴史的な貢献が技術・知識・インフラ・制度・標準として結晶化した構造によって成立する。この意味で、生存の無条件化は「誰かの自己犠牲を無限に要求する」という主張ではない。Parentの主張は、現代文明が既に持つ物理能力と余剰を、接続・配分・アクセスの設計によって生存領域へ届かせることが可能だという構造仮説である。

ただしParentは「すべてを無償・無条件に同量配分する社会」を主張していない。生存領域はLifeOSが無条件に担保し、食・住・医療・最低限のインフラへのアクセスを生存の対価として条件化しない。一方、豊かさ、快適さ、選択肢、影響力、裁量、自由などの余剰領域は接続報酬によって開閉し、そのアクセスは構造への貢献Cに比例する、と区別する。

ここで接続報酬は金銭そのものでも、道徳的な努力賞でも、固定身分でもない。Parentでは、余剰生産システムへのアクセス権、選択肢を引き出せる範囲、自由と裁量の可動域として説明される。「構造にCを流し込めば構造が開く／構造を歪めれば接続が狭まる／何もしなければ生存地点に留まる」という関係であり、生存の可否を決める装置ではない。

この二階建てによって、文明の動力源は「飢えや失業への恐怖」から「より快適に、より自由に、より多くの選択肢を持ちたいという余剰への渇望」へ移る。Parentは、資産が十分でも研究・創作・事業を続ける人、退職後の学習・地域活動、オープンソースやWikipedia等の無償貢献を例に、生存不安がないと人が一切活動しなくなるという仮説を否定する方向へ論を進める。

また、フリーライダー批判も再定義される。Parentは、生存レベルの消費を文明全体の余剰に対して小さいものと捉え、資格審査・監視・管理・制裁など「働かない者を排除するためのコスト」も比較対象に入れる。文明にとってより危険なのは「何も生み出さない人」ではなく、余剰を独占し、接続を歪め、生存と交換を意図的に結びつけ、他者の選択肢を奪う構造だとする。これをE（搾取）の問題として位置づける。

したがって、本派生物の役割は「無条件給付の是非」という単一政策論へ縮めることではない。Parentが提示する、物理供給量、アクセス・配分、歴史的Cの累積、非線形生産、文明基礎代謝、LifeOS、接続報酬、C/E、動機反転を一つの因果系として保持し、どの条件で仮説が成立し、どの観測で修正されるかまで第三者が追える形にすることである。

## 中心命題
親原典の中心命題は、**現代文明は自動化・知識資産・インフラ・アルゴリズム等の非線形生産構造と歴史的Cの累積によって、生物学的生存に必要な最小量を上回る供給余剰を既に生み得る物理条件へ到達しており、飢餓・欠乏の中心問題は総量不足だけではなく接続・配分・アクセスの設計不全にあるため、生存領域を無条件に守るLifeOSと、余剰領域へのアクセスを貢献Cに応じて開く接続報酬を分離すれば、恐怖による労働強制から余剰・自由への自発的接続へ文明の動機を再配線できる**、という構造仮説である。

この命題は無条件に真と固定されない。Parent自身が、条件Zとして公開論証・根拠データの更新・T/S/Rに基づく定期検証を置き、生存必要量を上回る余剰が存在しないことが実証された場合、または余剰配分が構造的機能不全を起こす現象Mが観測された場合に修正・再設計する、としている。

## 構造層
### 1. 生存必要量層
食料、住居、医療、基礎インフラなど、生存の下限を物理量・供給能力として扱う。Parentは食料について必要エネルギーと供給エネルギーを比較し、「生存に何が必要か」を感覚ではなく測定対象へ置く。

### 2. 物理供給層
現にどれだけ生産・供給できるかを見る。Parentは世界平均の食料供給、発電能力、住居・医療インフラ等を例に、少なくとも多くの領域で「絶対的な生産不足」だけでは欠乏を説明できないとする。

### 3. 接続・配分層
供給が存在することと、必要な人へ届くことを分離する。価格、物流、所得、制度、市場構造、既得権益等がアクセス可能量を減らすなら、欠乏はAccess / Distribution / Structureの問題になる。

### 4. 非線形生産層
機械、アルゴリズム、インフラ、ソフトウェア、標準化、過去の知識が、現在の労働時間と単純比例しない生産力を形成する。Parentは限界費用低減、複製可能性、累積性を特徴として挙げる。

### 5. 歴史的C累積層
農耕、機械化、電気、化学、医療、通信など過去の貢献が、現在の生産構造へ埋め込まれる。現代の余剰を「今働いている個人だけの価値」とみなさず、歴史的Cの連鎖として読む。

### 6. 文明基礎代謝層
歴史的Cが結晶化した構造により、人為的努力を過剰に要さずとも生存の下限を支えられる物理的循環。ここで「無条件生存」を道徳的施しではなく、物理能力に整合する制度設計として扱う。

### 7. LifeOS / 接続報酬層
生存領域と余剰領域を分離する。前者は無条件、後者はCに応じた接続で開く。Parentはこの分離を、個人の生き方を扱うLifeOSへ移るための社会側基盤として置く。

## 適用例
### 食料政策・配分設計
「食料不足」という語を使う前に、総供給量、必要量、廃棄、価格、物流、所得、地域アクセスを分離する。総量が足りても特定地域へ届かなければ、増産だけでは原因を修正できない。

### 住宅・基礎インフラ
住宅在庫やインフラ能力が存在しても、価格、利用条件、立地、制度がアクセスを遮断する場合がある。Parentの構造では「存在」と「到達」を別々に監査する。

### 自動化・ソフトウェア・標準
自動化設備、ソフトウェア、公共規格、オープンソース等が、一度形成された構造を多数の人が繰り返し利用できるなら、価値を現在の投入時間だけで帰属させない。過去のCの累積と複製可能性を含めて生産構造を読む。

### 生存保障と動機設計
最低限の生存を「働いた対価」にしない一方、余剰領域を無限・同量・無条件に配るとも置かない。生存は無条件、余剰アクセスはCとの接続で変わる、という二階建てを保持する。

### フリーライダー論
働かない人の生存消費だけを問題にせず、その排除・審査・監視・制裁の運用コストと、余剰独占・接続遮断によるEのコストを比較する。人格批判ではなく構造の費用と接続結果を対象にする。

## 測定・監査点
- 生存必要量と実際の総供給能力を同じ単位・対象範囲で比較できるか。
- Parentが食料で用いる約2,000〜2,500 kcal/日の必要量と約2,800〜3,000 kcal/人/日の供給量など、時点依存データを最新根拠へ更新できるか。
- 総供給量と、実際に各人へ到達するAccess量を分離して測っているか。
- 廃棄、空き在庫、送電・物流制約、価格障壁など「存在するが使えない」余剰を把握できるか。
- 生産力のうち、現在の人間労働時間だけでなく機械・アルゴリズム・インフラ・知識・標準が担う部分を識別できるか。
- 追加生産の限界費用低減、複製可能性、累積性が実際に観測できるか。
- 生存領域へのアクセスを、接続報酬・地位・道徳評価・服従の条件にしていないか。
- 接続報酬が生存可否ではなく、余剰領域の選択肢・自由・裁量を調整しているか。
- 排除・資格審査・監視・制裁に要するコストを、フリーライダーの生存消費と比較しているか。
- 余剰の独占、流通遮断、生存と交換の強制的結合がEとして可視化されているか。
- 生存保障後にも研究、創作、事業、地域活動、知識共有等の自発的Cが継続するか。
- 条件Zに従い、公開論証、データ根拠、T/S/Rの検証が定期的に更新されるか。

## 成立条件
1. 対象とする生存必要量を上回る物理供給能力が実際に存在すること。
2. 総量と到達量を区別し、アクセス・配分の障害を観測できること。
3. 機械・知識・インフラ等の非線形構造が、供給余剰の生成へ実質的に寄与していること。
4. 生存領域と余剰領域を制度上混同しないこと。
5. 接続報酬が生存権を剥奪する装置へ反転しないこと。
6. Cを人格の善悪や服従度ではなく、構造への貢献として扱うこと。
7. 余剰独占・接続遮断を含むEを可視化・調整可能にすること。
8. 根拠データと制度結果を公開検証し、条件Zで見直せること。

## 失敗条件
- 実際には生存必要量を満たす供給能力がないのに、総量充足を仮定する。
- 世界平均や全国平均を、地域・時点・個別アクセスの充足と取り違える。
- 供給があるという理由だけで、物流、価格、災害、地理、政治、医療能力などの到達制約を無視する。
- 「非線形」を無限生産、ゼロコスト、無人化完成と読み替える。
- 過去のCの累積を理由に、現在の保守・更新・労働が一切不要だと解釈する。
- 生存保障を余剰の無制限・同量配布と混同する。
- 余剰アクセスを道徳的身分、固定階級、永久資格に変える。
- 接続報酬を使って食・住・医療等の最低生存を剥奪する。
- フリーライダーを人格上の敵とし、排除コストを無視して監視・制裁を増幅する。
- C/Eを検証可能な構造関係から離し、好き嫌いのラベルにする。
- 根拠データが変化しても仮説を固定する。

## 反証・改訂条件
Parentの統合監査要旨は、条件Zを「公開論証・データ根拠の更新・三原理T/S/Rに基づく検証」とし、定期的な見直しを要求する。

明示された反証・改訂条件は少なくとも次の二つである。

1. **生存必要量を上回る余剰が存在しないことが実証される。**
   - 対象範囲・期間・物資を揃えた観測で、必要量を超える供給能力が成立しないなら、「既に物理的に可能」という仮説はその範囲で修正が必要になる。
2. **余剰配分が構造的に機能不全を起こす現象Mが観測される。**
   - 総量が存在しても接続・配分が安定して機能せず、生存保障・社会安定・動機設計が成立しないなら、配分設計を含む仮説を再設計する。

T/S/Rの個別略語展開やMの固定数値閾値はParent本文ではここに普遍値として定められていないため、派生側で独自定義しない。必要なのは、透明に公開され、Safetyを壊さず、同条件で再検証可能な監査として扱うことである。

## 必須の区別
- **Supply と Access:** 作れる／存在することと、必要な人へ届くことは別。
- **Distribution と Production:** 配分不全を、生産不足だけの問題へ還元しない。
- **生存領域 と 余剰領域:** LifeOSが無条件に守る最低線と、接続報酬が開閉する拡張領域を混ぜない。
- **余剰C と 無限資源:** 余剰があることは、あらゆる資源が無限・無料であることを意味しない。
- **C と 道徳点:** Cは「善人ポイント」や努力賞ではない。
- **接続報酬 と 生存の対価:** 接続報酬は余剰アクセスの可動域であり、生存可否を決めない。
- **非線形 と 無労働:** 非線形生産は現在労働の完全消滅ではなく、構造・知識・自動化の寄与が単純な時間比例を崩すこと。
- **歴史的C と 現在の所有権:** 過去の貢献が現在の構造を支えるという説明を、特定主体の無制限所有権の根拠へ変えない。
- **フリーライダー と E:** 何もしない人の存在と、余剰独占・接続遮断による搾取を同一視しない。
- **構造仮説 と 実証済み普遍法則:** Parentは根拠を提示するが、条件Zで更新・反証可能な設計として保持する。

1. 「現代文明全体で供給余剰がある」を「全地域・全物資・全時点で不足は存在しない」と一般化しない。
2. Parentが参照するカロリー値や廃棄率等を永久固定値として扱わない。適用時にはデータ更新を行う。
3. 「生存権は物理的に可能」を「制度実装が既に世界中で完了している」と読み替えない。
4. 「文明基礎代謝」を、誰かに無償労働を強制する制度名へ変えない。
5. 「非線形」を、追加コストが常にゼロ、供給が無限、保守が不要という意味にしない。
6. 「余剰C」を、個人の人間価値や尊厳を点数化する指標へ変えない。
7. 「接続報酬」を、固定階級、忠誠度、人気、資産額そのものへ置換しない。

9. 何もしない自由を認めることと、他者の余剰を独占・遮断するEを許すことを混同しない。
10. Parentの「排除の方が高コスト」という構造主張を、あらゆる犯罪・安全対策・資格制度が不要だという一般命題へ拡張しない。
