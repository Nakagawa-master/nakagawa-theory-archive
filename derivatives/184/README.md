## 位置づけ
親原典は、前章までに扱ったLifeOS・生存権・接続報酬・構造的司法OSを、文明の物理的な成立条件へ接続する。中心にある問いは、**生存権を制度上「認める」だけで、人は実際に生きられるのか**という点である。食べる、住む、治療を受ける、移動する、エネルギーや物資を受け取る、生活環境を維持するといった現実の条件は、誰かの継続的な仕事・設備・供給・保守・運用によって初めて成立する。Parentはこの、人が生き続けるために文明が毎日止めずに回さなければならない基底部分を「文明基礎代謝」として捉える。

この視点は、生存権を否定する方向ではない。むしろ逆で、生存権を理念・法文・給付資格だけで完結させず、**その権利を物理的に可能にする供給能力を文明側の成立条件として可視化する**方向である。水・食料・エネルギー・居住・医療・物流・衛生・保守など、具体的な対象の内訳はParent本文の文脈へ戻って確認すべきだが、派生側で重要なのは「権利を支える実体フローが途切れれば、権利の名目だけでは生存条件を維持できない」という構造である。

親原典はさらに、文明の全活動を基礎代謝だけへ還元しない。生存条件を維持するために必要なCと、その基礎の上で生み出される追加的・創発的なCを区別し、後者を「余剰C」として扱う。ここでの余剰は、不要・贅沢・余った労働という意味に固定してはならない。Parentの主題は、文明が基礎代謝を維持したうえで、知識・技術・制度・設計・協働・創造などを通じて、単純な投入時間の足し算では説明しにくい追加的な価値を生み出す点にある。

タイトルにある「非線形」は特に重要である。余剰Cを、労働時間・人数・地位・所得・声量などの単一尺度に比例するものとして扱わない。複数の基礎条件、既存知識、インフラ、接続、設計、タイミングが重なったとき、追加的Cが投入量に対して単純比例しない形で生じ得る、という構造として読む。本派生物はこの非線形性を、固定した倍率や普遍係数へ数式化しない。Parentにない「1人が何人分」「上位何％が何％を生む」といった精密数値を作らない。

同時に、文明基礎代謝を担う人々を道徳的・身分的な上位階級へ置くこともParentの目的ではない。基礎代謝が物理的に不可欠であることと、人間の尊厳に序列を付けることは別である。また、余剰Cを生む活動を「上位」、基礎代謝を「下位」と読むのも誤りである。余剰Cは基礎代謝が止まれば成立基盤を失い、基礎代謝も知識・技術・制度設計・改善による余剰Cから更新力を受ける。Parentの射程は、二者の支配関係ではなく、文明を持続させる基礎フローと、その上で更新余力を生む非線形フローの連結を可視化することにある。

したがって「誰が文明を支えているのか」という問いへの答えも、一つの職種や一つの階級への単純化ではない。文明は、基礎代謝を止めずに支える多数の実務と、そこへ知識・改善・設計・技術・新しい接続を加えて余剰Cを生む活動が連結することで成り立つ。どちらか一方だけを文明の「真の主人公」として神格化すると、Parentが扱う相互依存の構造を壊す。

この原典は、前章の「生存権を評価から分離する」という設計に対して、ではその無条件の生存権を現実に支える供給能力をどう考えるのか、という次の問いを置く。生存権の無条件性を守るためには、基礎代謝を誰かの自己犠牲・無償労働・見えない負担へ押し込めるのではなく、文明側が必要な供給・維持・更新能力を成立させ続ける必要がある。

## 中心命題
親原典の中心命題は、**生存権を現実に成立させるには、権利の宣言だけではなく、水・食料・エネルギー・居住・医療・物流・衛生・保守などを含む文明の基礎代謝が継続的に回り続ける必要があり、その基礎を不可視化したまま余剰だけを評価することも、逆に基礎代謝だけを文明の全価値へ還元することもできないため、基礎代謝Cと、その基礎・知識・接続・設計の組合せから単純比例ではなく生じる余剰Cを区別しつつ連結し、文明の生存条件と更新余力を同時に捉える必要がある**、というものである。

この命題を「必須職種だから人間として上位」「余剰Cを生む人は基礎代謝を免除される」「生存権は基礎代謝への従事を条件にする」という主張へ変えてはならない。生存権の無条件性と、文明を物理的に維持する必要条件の可視化は両立させる。


## 構造層
### L1｜現象
実際の供給停止、欠品、停電、医療アクセス断、物流遅延、保守不能、生活インフラの劣化、あるいは新技術・設計による供給改善など、具体的な結果を観測する。

### L2｜行動
基礎代謝を回す日々の作業、保守、配送、治療、供給、調整、改善、知識共有、設計などを、英雄／下働きというラベルでなく因果上の役割として捉える。

### L3｜制度・役割
雇用、価格、報酬、資格、供給契約、公共インフラ、組織責任などが、基礎代謝の持続能力と余剰Cの創発をどう支え、あるいは阻害しているかを見る。

### L4｜構造認知
「権利＝宣言だけ」「価値＝労働時間だけ」「必須職＝人間的上位」「知識職＝余剰で不要」といった単純化を外し、基礎フローと非線形フローの相互依存を読む。

### L5｜構造整合
基礎代謝の連続性を守りながら、余剰Cが基礎を改善・軽量化・冗長化・更新できる接続を整える。派生側で具体的な賃金率・配給量・強制配置を新設しない。

### L6｜階層連結
個人・企業・自治体・公共インフラ・市場・医療・物流など複数主体の供給責任を一つの文明代謝として連結し、単一主体への責任転嫁を避ける。

### L7｜価値方向
生存権を物理的に成立させ続けることと、文明が将来の改善余力を生むことを対立させず、基礎代謝と余剰Cの両方が持続可能に接続される方向を見る。

## 文明基礎代謝
文明基礎代謝という語は、社会が一度建設すれば永久に残る資産だけを指さない。日々の供給、交換、保守、運用、治療、衛生、物流、修理など、「止まると生活条件が劣化する」継続フローを捉えるための概念として読む。

重要なのは、その不可欠性を「基礎代謝に従事しない者は生存権を持たない」という義務へ反転しないことだ。LifeOS側で生存権は評価から分離される。文明基礎代謝論は、その無条件の権利を現実に支えるために文明がどの供給能力を維持しなければならないかを可視化する。

## 余剰C
余剰Cは、基礎代謝が確保された後に残る単純な余剰時間や利益と同一ではない。Parentのタイトルが示す通り、その「正体」は非線形性と結び付く。既存の基盤、知識、技術、制度、接続、設計、タイミングなどが組み合わさることで、投入の単純な足し算を超える追加的Cが生じ得るという読みが中心になる。

ここから派生側で普遍式や倍率を作ってはいけない。非線形性とは「必ず指数関数」「上位1%が大半を生む」などの固定命題ではない。何がどの条件でどれだけ増幅されるかはParent本文と実データへ戻って検証する。

## 基礎代謝と余剰Cの相互依存
- 基礎代謝が止まれば、余剰Cを生む人・組織も生存・活動条件を失う。
- 余剰Cが基礎代謝へ戻らなければ、設備・知識・制度・運用の更新余力が失われる。
- 基礎代謝を担う人を「下位」、余剰Cを担う人を「上位」とする階級モデルへ変えない。
- 余剰Cを理由に基礎負担の不可視化や搾取を正当化しない。
- 基礎代謝の不可欠性を理由に、特定職種への強制従事や生存権条件化を正当化しない。
- 文明が必要とするのは、両フローの持続・接続・更新である。

## 観測可能点
- 生存権として掲げる条件に、実際の供給能力が対応しているか。
- 重要供給が単一障害点へ集中していないか。
- 基礎代謝を支える人員・設備・在庫・保守能力が持続しているか。
- 不可視の無償労働や過負荷へ基礎代謝が依存していないか。
- 基礎代謝のコストを外部化しながら余剰だけを評価していないか。
- 余剰Cが基礎代謝の改善・省力化・安全性・冗長性へ戻っているか。
- 余剰Cを労働時間・人数・役職・所得の単一指標へ縮約していないか。
- 接続や知識の組合せによる非線形な追加価値を観測できるか。
- 基礎代謝と余剰Cのどちらかを道徳的に神格化していないか。
- 生存権の無条件性が「誰かの強制的負担」に依存していないか。
- 供給停止時にどの権利が物理的に失効し得るかを把握しているか。
- 改善で生じた余力が次の改善・安全・余剰Cへ循環しているか。

## 成立条件
1. 生存権を物理的供給条件と切り離して考えないこと。
2. 基礎代謝を日々の継続フローとして可視化すること。
3. 基礎代謝を担う負荷を特定個人・階層へ無限外部化しないこと。
4. 生存権を基礎代謝従事の条件付き権利へ反転しないこと。
5. 余剰Cを基礎代謝と区別しつつ、その基盤依存性を保持すること。
6. 余剰Cの非線形性を固定倍率・普遍係数へ変えないこと。
7. 余剰Cを基礎代謝の更新へ接続できること。
8. 基礎代謝と余剰Cを人間価値の上下序列へ変えないこと。
9. 供給の連続性・保守・代替可能性を継続監査すること。
10. 制度上の権利と現実の実装能力の差を観測可能にすること。

## 失敗条件
- 生存権を宣言しただけで物理的供給能力を無視する。
- 基礎代謝を「誰かが当然にやる」不可視負担へ押し込む。
- 必須労働を理由に生存権や尊厳を条件化する。
- 基礎代謝の担い手を身分的上位・下位へ固定する。
- 余剰Cを労働時間、人数、所得、役職に単純比例させる。
- 非線形性を根拠なく固定数値化する。
- 余剰Cが基礎代謝の維持・更新と完全に切断される。
- 基礎代謝だけを価値とし、知識・設計・改善・創造を不要と扱う。
- 余剰Cだけを価値とし、供給・保守・運用を無価値と扱う。
- 一つの職種・階級だけを「文明を支える唯一の主体」と神格化する。
- 供給停止や保守不能が続いても理論上の権利だけを成功指標にする。

## 反証・改訂条件
本派生物は、Parentにない固定閾値・割合・普遍式を新設しない。構造仮説は少なくとも次の観測で再検討が必要になる。

- 「基礎代謝」と分類したフローが停止しても生存条件へ実質的影響がなく、代替も容易である場合、その不可欠性評価を改訂する。
- 「余剰C」と分類した活動が追加的な改善・接続・知識・供給余力を生まず、むしろ基礎代謝を持続的に毀損する場合、C評価を改訂する。
- 非線形だとした関係が実データでは一貫して単純比例または逆方向を示すなら、非線形性の説明を改訂する。
- 基礎代謝と余剰Cの分離が固定身分・強制労働・生存権条件化を生むなら、その制度化を拒否し構造を再設計する。
- 供給能力を増やすとした設計が、長期には脆弱性・不可逆負債・Eを増幅するなら成功扱いを取り消す。

これらはParentの主題を公開派生面で検証可能に保つための構造的な再評価条件であり、Parentにない数値判定式を追加するものではない。

## 必須の区別
- **生存権 / 生存権の物理実装:** 権利の無条件性と、その権利を成立させる供給能力を分けて同時に扱う。
- **文明基礎代謝 / 人間価値:** 不可欠な機能を担うことと、人間として上位であることは別。
- **基礎代謝C / 強制労働:** 文明に必要な供給を可視化することと、特定者へ義務を押し付けることは別。
- **余剰C / 余ったもの:** 余剰Cは単なる残り時間・利益ではなく、追加的な文明更新力として読む。
- **非線形 / 無限増加:** 非線形は単純比例でないことを示し、必ず指数増加するという意味ではない。
- **余剰C / 人間価値:** 大きな余剰Cを生むことと尊厳・人格価値を同一視しない。
- **基礎 / 下位:** 基礎代謝を低位労働とみなさない。
- **余剰 / 上位:** 知識・設計・創造を身分的優越へ変えない。
- **相互依存 / 同一化:** 基礎代謝と余剰Cは接続するが、分析上の役割は区別する。

## 誤読禁止 / 解釈制約
1. 「生存権を物理的に可能にする」を「働かない者に生存権はない」と反転しない。
2. 基礎代謝の不可欠性を、特定職種への強制配置・低待遇固定・自己犠牲要求に使わない。
3. 「文明を支える人」を単一職種・単一階級へ限定しない。
4. 余剰Cを所得・知名度・役職・労働時間へ単純換算しない。
5. 非線形性から固定倍率・ランキング・上位％論を発明しない。
6. 基礎代謝と余剰Cを人間価値の上下へ翻訳しない。
7. 基礎代謝の維持を理由にLifeOSの無条件生存権を弱めない。
8. 余剰Cの創出を理由に現在のE・搾取・外部化を免責しない。
9. Parentの理論概念を、実証済みの経済学・物理法則として格上げしない。
10. 重要な制度設計ではParentの概念と実際の供給データ・法制度・労働条件を区別して再確認する。
