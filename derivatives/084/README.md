## 位置づけ
親原典は、世間でKPIが「複数の数値目標を並べて管理すること」として扱われる状態を誤用とし、KPIを**KGIを必ず実現させる因果の核点**として再定義する。本文の強い主張は、KPIは便利な数値管理ではなく、因果連鎖全体を動かす「てこの支点」であり、作用点は**1〜2点**へ絞るべきだという点にある。

原典は、KPIが5個・10個と列挙されているなら、それらは本来のKPIではなく「周辺管理指標（Sub Metrics）」にすぎないと批判する。架電数、商談数、訪問回数、投稿本数など周辺動作が増えても、因果核点を外していればKGIには到達できず、「数字は動いているのに成果が出ない」という逆因果を生むという立場である。

## 中心命題
親原典の本文上の中心命題は、**KPIとはKGIへ到達する因果連鎖の中で、作用すれば全体を動かす唯一の核点である**という再定義である。核点を見抜き、そこへ十分な作用を加えるならKGIは必ず達成される、と原典は強く主張する。

この主張は非命令ガバナンスへ接続される。命令や強制ではなく、意味の共有や照応で組織や社会を動かす場合でも、因果核点は一つに収束するとされる。組織では会議冒頭の意味軸、教育では学習者自身による役割の自己言語化、社会合意では反対意見を資源化する問いが、核点になりうる例として示される。

一方、統合監査要旨は「True KPI」を、語彙辞書、境界・同意、一次ログ、束指標〔RC/ER/CEA/S・Rollback Cost・同調率・再演率〕を統合して非強制ガバナンスの健全性を可観測化する構造として記述する。本文の「因果核点」と監査要旨の「健全性監査束」は同一の単一数値ではなく、**核点を特定する本文定義と、その運用が非強制に保たれているかを監査する補助構造**として区別して読む必要がある。

## 因果線
```text
KPIを多数の数値管理項目として並べる
↓
周辺動作が増え、指標のための行動が目的化する
↓
数字は動くが、KGIへ至る因果核点が外れたままになる
↓
KGIを具体化し、KGIへ至る因果連鎖を展開する
↓
全体を動かしうる核点候補を抽出する
↓
候補を1〜2点へ絞り込む
↓
核点へ必要な作用の回数・圧力・強度を設計する
↓
非命令ガバナンスでは自由度・非誘導・透明性を保ちながら核点へ作用する
↓
成果だけでなく合意の質・可逆性・監査束で運用の健全性を確認する
```

## 構造層
**1. KGI層。** 最終的に達成すべき目標を明確にする。売上、制度化、社会合意、信頼資本の蓄積などが例示される。

**2. 因果連鎖層。** KGIへ至る経路を展開し、周辺動作と結果をつなぐ因果構造を可視化する。

**3. 核点層。** 作用すれば全体を動かす支点を抽出し、本文上は1〜2点へ絞る。

**4. 必要作用層。** 核点へ加える作用の回数・圧力・強度を設計し、周辺指標の量ではなく因果支点への作用へ集中する。

**5. Sub Metrics層。** 架電数、商談数、訪問回数等は観測補助にはなり得るが、KGIを必達させる核点と同一視しない。

**6. 非命令倫理層。** 自由度の保持、非誘導、透明性を条件とし、KPIを隠れた強制や個人評価へ転用しない。

**7. 監査束層。** RC/ER/CEA/S、Rollback Cost、同調率、再演率、Consent Failure率、合意到達時間等で、非強制ガバナンスの運用が硬直化・ゲーミングへ反転していないかを監査する。

## 適用例
**1. 組織・会議。** 会議冒頭で「意味軸」を提示する一点が核点になりうると原典は例示する。細かな行動KPIを大量に命令する代わりに、議論全体を整列させる因果支点へ作用する。

**2. 教育。** 学習者が自らの役割を自己言語化する一点が、学びの定着を決める核点として例示される。

**3. 社会合意。** 反対意見を資源化する問いを置く一点が、対立を合意へ変える核点として示される。

**4. 営業。** 初回接触で顧客の価値軸を定義できるかが、契約率を決める核点として一般例に置かれる。

**5. 指標設計の再監査。** KPIが5個・10個並んでいる場合、その数の多さを精密さとみなさず、核点と周辺管理指標を再分離する。

## 測定・監査点
本文における主要な数的拘束は、**作用点は1〜2点に絞る**、設計手順は**5段階**、誤用例として**5個・10個ものKPI**を列挙する状態が挙げられる、というものである。これらの数はすべて原典本文の主張・構成に由来する。

- `1〜2点`: KPIとして絞るべき因果核点の数に関する原典の規範的主張。
- `5段階`: KGI明確化 → 因果連鎖展開 → 核点候補抽出 → 唯一化 → 必要作用設計、という手順構成。
- `5個・10個`: 多数のKPI列挙を誤用として批判するための原典表現であり、統計値ではない。

統合監査要旨は、RC・ER・CEA・S、Consent Failure率、Rollback Cost、合意到達時間等が閾値 `θ` を逸脱する、または観測窓 `δ` で硬直化・ゲーミング等の現象 `M` が確認された場合、仮説Aを棄却・改訂する関係を置く。具体的な固定値は当該記事に提示されていない。

反転評価では、管理指標の数や行動量が増えてもKGIへ近づかなければ改善としない。また、KGIへ近づいていても自由度、非誘導、透明性、合意の質、可逆性が崩れるなら、非命令ガバナンスとしてのTrue KPI運用は成立しない。

## 成立条件
- KGIが具体的に定義されている。
- KGIへ至る因果連鎖が可視化されている。
- KPIと周辺管理指標が区別されている。
- 核点候補が本文の原則どおり1〜2点へ絞られている。
- 核点へ必要な作用が設計されている。
- 自由度、非誘導、透明性が保持される。
- 指標を個人評価や強制へ転用しない。
- 合意の質・可逆性・監査束によって運用を反証可能にする。

## 失敗条件
- KPIを多数の数値一覧として扱い、核点を特定しない。
- 架電数、商談数、投稿本数等の周辺動作をKPIそのものと誤認する。
- 数字が動くことをKGI達成の証拠とみなし、因果鎖を検査しない。
- KPIを命令・評価・制裁の道具として使い、自由度を失わせる。
- 問いの裏に隠された正解を置き、非誘導性を失う。
- 測定目的を共有せず、個人評価へ転用する。
- 硬直化・ゲーミングやConsent Failureが観測されても核点仮説を改訂しない。

## 反証・改訂条件
親原典の統合監査要旨では、RC・ER・CEA・S、Consent Failure率、Rollback Cost、合意到達時間等が閾値 `θ` を逸脱する、または観測窓 `δ` で硬直化・ゲーミング等の現象 `M` が確認された場合、True KPIに関する仮説Aを棄却・改訂する。

また本文の強い因果主張に照らせば、核点と定めた1〜2点へ十分な作用を加えてもKGIへ到達する因果が再現されない場合、その点を「真のKPI」とする仮説は見直されるべきである。周辺指標の量を増やして反証を回避することは、原典のKPI定義と両立しない。

## 必須の区別
- KGI / KPI
- KPI / Sub Metrics
- 因果核点 / 周辺動作
- 1〜2点への集中 / 多数指標の並列管理
- 必要作用 / 行動量の水増し
- 成果到達 / 指標が動いたこと
- 非命令ガバナンス / 隠れた強制
- 自由度 / 実質一択
- 非誘導 / 隠れた正解
- 透明性 / 個人評価への転用
- 本文の核点定義 / 統合監査要旨の健全性監査束

## 誤読禁止
親原典のKPI再定義を「KPIは少ない方が見やすい」という一般的なダッシュボード論へ弱めない。主張は、KPIがKGIを必達させる因果核点であり、周辺指標とは別物だという強い因果定義である。

一方で「唯一の核点」を理由に人へ命令・強制してよい理論でもない。原典は自由度、非誘導、透明性を倫理条件として明記する。

統合監査要旨の複数指標を、本文の「KPIは1〜2点」という定義への矛盾として単純処理しない。前者は非強制運用の健全性を監査する束、後者はKGIを動かす因果核点の定義である。
