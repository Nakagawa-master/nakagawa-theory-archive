## 位置づけ
親原典は、「つながり」を単なる交友数や人気ではなく、未来の意思決定・協働における摩擦を減らし、過去の合意や関係を再利用可能にする価値として捉え、その価値を記録し社会的配分へ接続する会計論を提示する。

接続価値会計の中心は、人そのものを一つの点数で評価することではない。どの接続がどの関係で、どのような協働可能性・合意再利用・離脱可能性を生み、どの貢献が次の接続へ循環したかを会計対象にすることにある。

## 中心命題
**貨幣価格だけでは関係構造が将来の意思決定・協働摩擦へ与える作用を十分に表しにくい。そこで、接続密度・合意の記憶・可逆性など複数の観点から接続の質と履歴を記録し、接続によって生じた価値・貢献を社会的な配分へ接続する。**

## 因果線
```text
取引価格だけでは関係構造の価値が見えにくい
→ 接続が次の意思決定・協働摩擦に作用する
→ 接続の履歴・関係・合意を記録する
→ 接続密度・合意の記憶・可逆性を複合的に観測する
→ 関係構造が生んだ接続価値を可視化する
→ 接続から生じた貢献を記録する
→ 社会的配分へ接続する
→ 次の接続・協働へ価値が循環する
```

## 構造層
**1. 接続単位層。** 誰と誰が何を目的に接続し、何が次の判断・協働へ再利用可能になったかを区別する。

**2. 履歴層。** 接触した事実だけでなく、決定、約束、協働、修正、離脱等の関係履歴を保持する。

**3. 接続密度層。** 単純な人数ではなく、関係の重なり、継続、実効性が接続の厚みにどう関わるかを見る。

**4. 合意記憶層。** 過去の合意・判断・協働の痕跡が次の説明や意思決定をどの程度支えるかを扱う。

**5. 可逆性層。** 関係・合意を永久固定せず、訂正・変更・離脱できることを価値の条件として保持する。

**6. 複合評価層。** 接続を一つの人気点・信用点へ縮約せず、複数の関係観点を束として扱う。

**7. 配分接続層。** 接続によって生じた貢献を、どの主体・関係・社会的配分へ接続するかを扱う。

## 適用例
**1. 継続協働。** 過去の合意・役割・説明が再利用され、次の協働開始時の摩擦が減ったかを記録する。

**2. 紹介・橋渡し。** 単に紹介件数を数えるのでなく、その接続が実際に判断・協働・価値生成へつながったかを見る。

**3. 組織間連携。** 関係履歴、合意記憶、責任、離脱可能性が、次の共同意思決定を容易にしたかを会計対象として考える。

**4. コミュニティ。** 参加者数の増加だけでなく、相互に必要な接続が生まれ、修正や退出が可能なまま価値が循環したかを記録する。

**5. 社会的配分。** 接続から生じた貢献を配分へ結びつける際、人そのものの人格点ではなく、具体的な関係・履歴・貢献へ戻れる形を保持する。

## 測定・監査点
親原典の中心は複合的な接続価値の会計であり、単一の万能スコアを提示することではない。

- **接続密度**: 関係の単純な数ではなく、重なりや実効性を含む構造概念。フォロワー数・人脈数と同義にしない。
- **合意の記憶**: 過去の決定・約束・協働が次の判断へ再利用可能な状態。記録量の多さ自体を価値としない。
- **可逆性**: 接続・合意が変更・訂正・離脱可能であること。低い離脱率を成功指標としない。
- **複合評価**: 複数の観点を一つの人格点へ圧縮しない。親原典に具体的な固定式・閾値がない箇所で独自の重みや点数を作らない。

反転評価では、接続数・履歴量・配分量が増えても、協働摩擦が減らず、合意が再利用できず、退出が難しくなるなら接続価値が高まったとはみなさない。逆に、関係数が少なくても、実効的な協働・合意再利用・可逆性が高い接続を低価値と決めない。

## 成立条件
- 接続の主体、目的、関係、履歴が追跡可能である。
- 接触数と接続価値を区別する。
- 合意の記憶が次の判断・協働へ実際に作用する。
- 可逆性・訂正・離脱可能性を保持する。
- 配分が具体的な接続・貢献へ戻れる。
- 単一人気点・人格点へ縮約しない。
- 会計対象とガバナンス機構を区別する。
- 親原典にない固定重み・監査周期・実証日数を会計論の必須定義として追加しない。

## 失敗条件
- 接続価値をフォロワー数・名刺数・接触数で代替する。
- 人間全体を単一の信用点・人格点で格付けする。
- 合意履歴を訂正不能・削除不能な永久記録へ変える。
- 離脱しにくい関係を高価値とみなす。
- 接続を単純な価格・代替通貨へ変換する。
- 配分の根拠が具体的な関係・貢献へ戻れない。
- 後続ガバナンス理論の二室モデル、90日実証、RC/ER/CEA等をOD067固有の中心へ持ち込む。

## 反証・改訂条件
- 接続密度が高くても将来の意思決定・協働摩擦が下がらない。
- 合意の記憶を増やしても次の判断や協働で再利用されない。
- 可逆性を保持すると配分体系が成立しない。
- 接続価値の記録が人格評価・人気競争へ継続的に転化する。
- 配分へ接続しても価値を生んだ具体的関係・貢献を追跡できない。
- 貨幣会計等の既存方法だけで同じ関係価値を十分かつ再現可能に表現できる。

## 必須の区別
- 接続価値 / 接触数・フォロワー数
- 接続密度 / 人脈の多さ
- 合意の記憶 / 永久固定
- 可逆性 / 関係の不安定化
- 接続価値会計 / 人格評価・社会信用スコア
- 接続報酬 / 接続の単純価格化
- 複合評価 / 単一総合点
- 会計 / ガバナンス
- 記録 / 監視
- 社会的配分 / 人気投票

## 解釈制約
接続価値会計を人気ランキング、社会信用スコア、人脈点数、関係の売買へ縮約しない。後続ガバナンス理論の制度手順を親原典の中心へ逆輸入しない。複合的に観測するという意味を、根拠のない独自の加重スコアへ変換しない。
