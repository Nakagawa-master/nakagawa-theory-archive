## この原典が定義するもの
Brain Vaultのcanonical indexが保持する中心命題は、**「つながりを評価単位として記録・配分し、接続価値を社会会計へ実装する」**である。

接続価値とは、単なる接触数や人気ではなく、関係構造が未来の意思決定や協働における摩擦を減らす力である。接続価値会計は、その価値を貨幣価格へただ置き換えるのではなく、接続の密度、合意の記憶、可逆性など複数の指標で記録し、社会的な配分へつなげる会計体系として位置づく。

## 中心因果
```text
貨幣だけでは関係構造の価値を十分に捉えにくい
→ 接続そのものが未来の協働可能性と意思決定摩擦に作用する
→ 接続の質と履歴を記録する
→ 接続密度・合意記憶・可逆性などを複合的に観測する
→ 接続価値を会計単位として可視化する
→ 貢献と接続を社会的な配分へ結びつける
```

## 意味核
- **接続価値**: 接続そのものが持つ、未来の意思決定や協働における摩擦を減らす力。
- **接続価値会計**: 貨幣ではなく接続を基軸に価値を測定・記録する会計体系。
- **接続密度**: 関係の数だけでなく、重なりや実効性を含めた接続の厚み。
- **合意の記憶**: 過去の決定・約束・協働の痕跡を再利用可能な形で保持すること。
- **可逆性**: 接続や合意を一方的に固定せず、変更や離脱の余地を保つこと。
- **複合評価**: 一つの人気点や信用点ではなく、複数の束指標によって構造的価値を見ること。

## 接続価値を会計する理由
貨幣会計は取引価格を記録することには強いが、関係が将来の協働をどれだけ容易にしたか、過去の合意がどれだけ再利用できるか、接続がどれだけ意思決定摩擦を減らしたかをそのまま表すものではない。

接続価値会計は、こうした関係構造の価値を「見えないまま」にせず、記録可能な社会会計へ持ち込む。その目的は人間を順位づけることではなく、**どの接続が社会的な価値を生み、どの貢献が次の接続へ循環したかを捉えること**にある。

## 原典から区別するもの
OD067は接続価値を「測る・記録する」会計論である。隣接する接続ガバナンス論の「守る」技術を、OD067固有の中心命題として取り込まない。

したがって、次の要素はOD067の中心定義から外す。
- 公開理念／非公開重みの二室モデルを必須とすること
- 分散監査、月次・四半期審査など固定ガバナンス手順
- Goodhart耐性・反ゲーミング制度を会計論そのものの中心に置くこと
- 90日実証、RC/ER/CEA/S/Rollback Cost等をOD067固有の反証条件に固定すること
- 個人情報・プライバシー運用をこの原典固有の制度設計として拡張すること

これらは接続価値会計と関連するが、会計論とガバナンス論の役割を混同しない。

## 必須の区別
```text
接続価値 ≠ 接触数・フォロワー数
接続価値会計 ≠ 人格評価・社会信用スコア
接続報酬 ≠ 接続を単純に価格化すること
接続の記録 ≠ 関係の永久固定
会計（測る・記録する） ≠ ガバナンス（歪みを守る）
```
