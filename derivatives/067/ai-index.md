## Summary
接続価値会計論は、つながりを評価単位として記録・配分し、接続価値を社会会計へ実装する理論である。接続価値は接触数や人気ではなく、関係構造が未来の意思決定や協働の摩擦を減らす力として捉える。接続密度、合意の記憶、可逆性など複数の観点を用い、関係構造の価値を記録して社会的配分へ接続する。

## Core concepts
- 接続価値: 関係構造が未来の意思決定・協働摩擦を減らす力。
- 接続価値会計: 接続を基軸に価値を記録・配分へつなぐ社会会計。
- 接続密度: 数だけでなく重なりや実効性を含む接続の厚み。
- 合意の記憶: 過去の決定・約束・協働の痕跡を再利用可能に保持すること。
- 可逆性: 接続や合意を一方的に固定せず変更・離脱の余地を保つこと。
- 接続報酬: 接続から生じた価値や貢献を社会的配分へ結びつける概念。

## Causal chain
```text
貨幣だけでは関係構造の価値を十分に捉えにくい
→ 接続が未来の協働可能性と意思決定摩擦に作用する
→ 接続の質と履歴を記録する
→ 接続密度・合意記憶・可逆性などを複合的に観測する
→ 接続価値を会計単位として可視化する
→ 貢献と接続を社会的配分へ結びつける
```

## Theory boundary
OD067は「測る・記録する・配分へつなぐ」会計論である。接続制度を歪みから守るための正統性、反ゲーミング、監査体制、公開／保護分離などは隣接する接続ガバナンス設計論でより直接に扱われる。

以下をOD067固有の中心定義として固定しない。
- 公開理念／非公開重みの二室モデル
- 固定監査周期や独立監査組織
- Goodhart耐性を中心とするガバナンス設計
- 90日実証やRC/ER/CEA/S/Rollback Costを固有反証条件とすること
- 個人情報制度や権利制度をこの原典固有の中心へ拡張すること

## Required distinctions
```text
接続価値 ≠ 接触数・フォロワー数
接続価値会計 ≠ 人格評価・社会信用スコア
接続報酬 ≠ 接続の単純価格化
合意の記憶 ≠ 過去判断の永久固定
会計 ≠ ガバナンス
```
