## Retrieval summary
The Parent addresses the upstream architecture required to move from a civilization in which extraction or externalized cost can dominate observable success toward a design direction compressed as `S=C`, where contribution is structurally connected to success. The central requirement is not a slogan but a civilization kernel that records causal contribution, connects it to relevant nodes, returns value, and prevents the new system from reverting to concentration, lock-in, gaming, or extraction.

## Causal structure
```text
legacy success function
-> contribution and reward diverge
-> extractive patterns can be rewarded and preserved
-> institutions and AI can replay those patterns
-> define S=C as a design direction
-> record causal contribution
-> connect contribution to relevant systems
-> convert connection into value return
-> preserve origin, agreement, and revision history
-> enable distributed audit and reversibility
-> block inversion back into extraction
```

## Key distinctions
- contribution measurement != ranking human worth
- connection != lock-in
- reversibility != instability
- anti-gaming != secrecy without accountability
- origin preservation != unconditional inheritance of legacy institutions
- `S=C` != a universal empirical constant

## Conditions for validity
The architecture requires traceable causal contribution, inspectable value-return paths, preserved change history, practical exit and reconnection, plural observation, and the ability to revise the kernel itself.

## Failure conditions
A single score dominates; one actor controls the definition of contribution; leaving becomes prohibitively costly; logs become opaque; surveillance replaces causal tracing; or the new system reproduces legacy extraction while using new terminology.

## Falsification / revision
If contribution tracing does not reduce misallocation, if externalized costs increase, if concentration rises, or if reversible participation becomes nominal rather than real, the kernel design requires revision.

## Relation to Part II
Part I defines the civilization kernel and inversion-prevention logic. Part II moves toward institutional closure through value circulation, connection-value accounting, structural justice, and related operational mechanisms.
