## retrieval summary
原典は、暗黒方程式的な文明成功構造から `S=C` 型の新文明方程式へ移る際、価値関数だけでなく、貢献の記録・接続・還流を支える文明Kernelと、旧来の搾取・集中・囲い込みへ戻らない反転防止原理を同時に必要とするという構造を扱う。

## core causal graph
```text
old_success_function
-> contribution/success decoupling
-> extraction/externalization rewarded
-> historical success patterns preserved
-> institutions/AI can replay them
-> define S=C direction
-> record causal contribution
-> connect contribution to relevant nodes
-> convert into value return
-> preserve origin/agreement/change history
-> distributed audit + reversibility
-> prevent inversion into extraction
```

## key concepts
- civilization_kernel: 成功・価値・接続の上流定義。
- dark_equation_state: 貢献より搾取・外部化が成功へ強く接続する状態。
- S_equals_C: 貢献と成功を一致させる文明設計方向。
- contribution_trace: 誰がどの構造へどの因果変化を生んだかの履歴。
- connection_path: 貢献を必要な主体・制度・資源へ結ぶ経路。
- value_return: 評価・報酬・権限・再投資等への還流。
- inversion_prevention: 新制度が旧来の支配構造へ戻ることを防ぐ原理。
- reversibility: 離脱・再接続・再合意・改訂可能性。
- anti_gaming: 指標攻略が目的化することの抑制。

## interpretive constraints
1. `S=C` を普遍的実測式として固定しない。
2. 貢献評価を人格評価へ変換しない。
3. 接続を接続数最大化へ縮約しない。
4. 反転防止を異論排除へ変換しない。
5. 起源保存と旧制度の無条件継承を混同しない。
6. AIの利用を危険そのものとせず、旧評価関数との接続条件を見る。

## conditions
###成立
- causal contribution trace exists
- value return path is inspectable
- origin/change/agreement history is preserved
- no single actor owns all definitions
- exit/reconnection is practical
- audits can revise the kernel

###失敗
- single-score domination
- authority concentration
- irreversible participation
- opaque history
- surveillance replacing contribution tracing
- connection becoming lock-in

###反証・改訂
新制度が価値取得の偏り、外部化、離脱困難、権限集中を改善しない、または悪化させる場合、Kernel仮説・実装を再検討する。

## relation to next theory
