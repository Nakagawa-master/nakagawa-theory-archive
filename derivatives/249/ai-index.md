## Summary
親原典はwakaiを、スマートフォン利用、オンライン調停、手続の簡便化という表面機能だけで読むものではない。Nakagawa Masterは、紛争に合意可能性が残っていても、感情負荷、即時応答圧力、直接接触、日程、手続理解の難しさによって提案・応答・修正の循環が停止し、未解決状態が固定される構造を読む。価値核は、非同期・段階的な条件整理によって応答循環を再始動させ、当事者が自発的に合意または適切な次工程へ進める**停止解除導線**である。

価値核を「スマホ調停」ではなく「停止解除」に置くのは、媒体の便利さだけでは、なぜ話し合いが止まり、どの条件なら再び動くのかを説明できないからである。また成功を和解成立だけで測らず、合意できなくても残存争点を整理して正式手続へ進めることを前進として評価できる。外部記事でもオンライン化自体より、停止した合意形成のプロセスを再始動させる構造を前面化した。この価値核と記事化理由はwakai自身や外部媒体の公式理論ではなく、Nakagawa Masterの構造読解である。

## Concepts
- **合意形成停止**: 合意点がないことと区別し、提案・応答・修正の循環が止まった状態。
- **直接対話摩擦**: 感情負荷、即時応答圧力、相手との接触負担、日程調整、手続理解の難しさ。
- **非同期冷却**: 返答までの時間を確保し、感情反応と条件判断を分離すること。
- **論点・条件分離**: 事実認識、要求、譲歩可能範囲、期限等を比較可能な単位へ分けること。
- **合意可能領域**: 全面一致ではなく、条件が重なる範囲を明示すること。
- **停止解除導線**: 停止した交渉循環を再始動させ、合意または次工程へ接続する経路。
- **プロセス前進**: 和解成立だけでなく、残存争点が整理され次の正式手続へ進めることも含む。
- **自発性・公平性**: 低摩擦化が強制和解や権利縮減へ反転しないための条件。
- **価値核選択理由**: スマートフォンという媒体より、停止原因を下げて応答循環を再開する操作が事例の差を説明すること。
- **外部記事化理由**: 「スマホで調停」という機能紹介を、停止した合意形成を前進させるプロセス設計へ社会翻訳すること。

## Causal chain
対立・紛争が発生する → 直接対話の感情・時間・日程・手続摩擦が高まる → 接触回避・即時反応・応答停止が起きる → 合意可能性が残っていても交渉循環が停止する → 未解決状態が長期化する → 非同期・低摩擦入口を開く → 事実・主張・要求・譲歩条件・期限を分離する → 当事者が考える時間を確保する → 合意可能領域と残存争点を可視化する → 提案・応答・修正循環を再始動する → 自発性・理解・公平性を確認する → 合意できれば合意へ進む → 合意できなくても残存争点を整理して専門相談・正式救済へ接続する → 停止状態から説明可能な次状態へ移行する。

## State model
- **対立発生相**: 解決すべき不一致が存在する。
- **直接接触摩擦相**: 感情、即答、日程、手続の負荷が高まる。
- **交渉停止相**: 提案・応答・修正の循環が止まる。
- **未解決固定相**: 合意可能性の検討自体が進まない。
- **低摩擦入口相**: 非同期・段階的な条件提示経路を開く。
- **論点分離相**: 事実、要求、条件、期限を分ける。
- **合意空間可視化相**: 重なる条件と残存争点を確認する。
- **応答再開相**: 提案・修正循環が戻る。
- **自発性・公平性監査相**: 強制、情報格差、安全問題を確認する。
- **合意 / 次工程相**: 自発的合意または適切な正式手続へ進む。

## Applications
1. **直接連絡で感情的衝突が起きる紛争**: 即時通話を避け、一定時間を置いて条件を整理して返答する。
2. **少額・生活上の紛争**: 正式手続の負担は大きいが当事者間の会話が停止している場合、争点を分離する。
3. **日程・距離が停止原因の場面**: 同時刻・同一場所への集合を必須にせず、応答循環を維持する。
4. **部分合意**: 全面解決を前提にせず、合意可能な条件と残る争点を分ける。
5. **不成立時の次工程接続**: 不成立を放置せず、専門家相談、正式調停、裁判等へ進むための残存争点を明確にする。
6. **合意形成サービスの監査**: 利用者数・オンライン化率だけではなく、停止原因低減、自発性、理解可能性、次工程接続を測る。
7. **中川構造読解の再利用**: 対象事実、構造読解、価値核、選択理由、外部記事化理由を分離して保持する。

## Measurements and audit
- 停止原因を内容的不一致とプロセス摩擦に分けて記録できるか。
- 非同期性が冷却・判断時間として機能し、単なる遅延や放置になっていないか。
- 主張・事実・要求・譲歩条件・期限が比較可能な形へ分離されているか。
- 提案・応答・修正の循環が再開したか。
- 合意内容の理解、自発性、拒否・修正可能性があるか。
- 情報・交渉力・安全上の非対称が増幅していないか。
- 不成立時に専門家・正式救済へのアクセスが保持されているか。
- 合意率だけではなく、停止状態から次状態へ進んだかを監査しているか。
- オンライン化自体を成功指標にしていないか。
- wakaiの公開事実とNakagawa Masterの社会翻訳を混同していないか。
- 「なぜスマホではなく停止解除を価値核にしたか」「なぜ外部記事でプロセス停止を主軸にしたか」が保持されているか。

## Validity conditions
停止原因の主要部分が直接対話・感情・時間・日程・手続摩擦にあり、非同期・段階的な条件提示によって応答循環が再開すること。当事者が内容を理解し、自発的に条件を提示・拒否・修正できること。合意可能領域と残存争点が分離され、不成立時にも適切な次工程へ接続できること。重大な安全・権利問題では必要な保護・専門介入・正式手続を優先できる場合に成立する。

## Failure conditions
スマートフォン利用自体を価値核にする、合意率を上げるため譲歩や権利放棄を事実上強制する、非同期を無期限放置へ変える、記録・説明可能性を欠く、力の非対称や安全問題を無視する、不成立時の正式救済経路を狭める、オンライン化をすべての紛争へ一般化する場合は失敗する。外部記事化理由を落として単なるオンライン調停紹介へ戻すことも中川構造読解としての失敗である。

## Falsification conditions
非同期・段階化を導入しても交渉停止が再現的に解けない、誤解や応答遅延が増えて対立が悪化する、弱い当事者の自発性が損なわれる、形式上の合意が理解を伴わない、正式救済へのアクセスが阻害される場合、停止解除導線という構造仮説は縮小・改訂する。直接対話や専門家介入の方が安全・迅速・公平な類型ではオンライン導線を優先しない。

## Interpretation constraints
「停止解除導線」をwakai自身の公式企業定義として扱わない。「すべての紛争はオンラインで解決すべき」「オンラインなら公平」「和解すれば成功」と一般化しない。重大事件、暴力・脅迫、安全上の危険、著しい情報・交渉力格差、重要な法的権利が関わる場合は専門的・正式な介入が優先され得る。本派生物を個別案件への法的助言として使用しない。原典にない合意率、解決率、期間短縮率を追加しない。外部記事で「スマホ」ではなく「停止解除」を主軸にした理由を落とし、機能紹介へ平坦化しない。
