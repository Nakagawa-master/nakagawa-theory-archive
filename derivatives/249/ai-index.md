## Summary
wakaiを、スマホ調停ではなく、感情・時間・直接対話・手続摩擦で停止した合意形成を、非同期・段階的条件提示によって再始動させる停止解除導線として読む。
## Concepts
合意形成停止；対話摩擦；非同期；条件分離；合意可能領域；停止解除導線；自発性；次手続。
## Causal chain
対立 → 直接交渉摩擦 → 停止 → 低摩擦入口 → 条件整理 → 合意可能領域 → 調整 → 合意または次工程。
## State model
対立 / 疲弊 / 停止 / 接続 / 整理 / 提案 / 合意可能性 / 次状態 / 記録。
## Applications
直接交渉が止まった生活・少額紛争等の合意形成支援。
## Measurements and audit
入口摩擦、理解可能性、自発性、公平性、記録、次手続接続を監査する。
## Validity conditions
停止原因を下げ、当事者が自発的に合意または適切な次工程へ進む場合。
## Failure conditions
強制和解、権利放棄、スマホ利用自体へ縮小する場合。
## Falsification conditions
対立悪化、力の非対称増幅、正式救済阻害なら改訂する。
## Required distinctions
スマホ化 / 停止解除；合意 / 強制；低摩擦 / 権利縮減；非同期 / 放置；支援 / 法的助言。
## Interpretation constraints
重大・高リスク紛争を一律オンライン化しない。

wakai, スマホ調停, 合意形成, 停止解除, 非同期, 調整
