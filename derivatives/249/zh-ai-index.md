## 检索摘要
原典讨论从一种“贡献与成功脱节、提取与外部化可能更容易获得成功”的文明状态，转向以 `S=C` 压缩表达的新文明设计方向时，最上游需要什么样的文明Kernel。重点不是更换口号，而是建立贡献记录、连接、价值回流、起源保存、审计与可逆机制，并防止新制度重新滑回权力集中、锁定、指标游戏化与提取结构。

## 因果结构
```text
旧成功函数
-> 贡献与回报分离
-> 提取型成功模式被保存
-> 制度与AI可能重复利用
-> 定义 S=C 的设计方向
-> 记录因果贡献
-> 连接到相关主体与制度
-> 形成价值回流
-> 保存起源、合意与修订历史
-> 分布式审计与可逆性
-> 阻止重新反转为提取结构
```

## 关键区分
- 贡献测量 ≠ 人格等级化
- 连接 ≠ 围堵与锁定
- 可逆性 ≠ 无秩序
- 反游戏化 ≠ 不受监督的黑箱
- 保存起源 ≠ 无条件继承旧制度
- `S=C` ≠ 普遍经验常数

## 成立条件
必须能够追踪贡献的因果来源、检查价值回流路径、保存变更与合意记录、实际执行退出与再连接，并由多个观察点监督，而且Kernel本身必须可被修订。

## 失败条件
单一分数统治全部评价；贡献定义权集中于单一主体；退出成本过高；记录不透明；监视替代因果追踪；或者新术语之下继续维持旧式价值吸收。

## 反证与修订
如果制度上线后价值错配没有改善、外部化负担上升、权力更加集中、退出和再连接只是形式存在，则Kernel设计应被重新检验。

## 与第II部的关系
第I部处理文明Kernel与反转防止；第II部进一步处理价值循环、连接价值会计、结构性司法OS等制度闭环。
