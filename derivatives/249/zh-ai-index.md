## Summary
Parent并不是把wakai主要读成“可以用手机进行调停的服务”，而是读成一种让因情绪、时间、直接接触、日程与程序摩擦而停止的合意形成重新启动的“停止解除导线”。价值核不在于强迫达成和解，而在于让当事人能够自愿地提出、比较、修正条件，并走向合意或适当的下一正式程序。

## Concepts
- 合意形成停止：即使仍存在部分合意空间，提案—回应—修正的循环也已经停止。
- 直接接触摩擦：情绪负担、立即回应压力、接触回避、日程负担、程序理解难度。
- 异步冷却：通过回应间隔把情绪反应与条件判断分离。
- 论点与条件分离：把事实、要求、可让步条件、期限与未解决事项拆开。
- 合意可能领域：不要求全面一致，而是明确条件能够重叠的范围。
- 停止解除导线：重新启动交涉循环，并连接到合意或适当下一程序的路径。
- 自愿性与公平性：防止降低摩擦反转为强迫和解或权利缩减的条件。

## Causal chain
发生冲突 → 情绪、时间、日程、直接接触与程序摩擦上升 → 当事人回避接触或停止回应 → 即使仍有合意可能，交涉循环也停止 → 未解决状态长期化、成本继续增加 → 打开低摩擦、异步入口 → 分离事实、要求、可让步条件与期限 → 合意可能领域可见 → 提案与修正循环重新启动 → 达成自愿合意，或把剩余争点整理后转入适当下一程序 → 从“停住不动”转为可说明的下一状态。

## State model
```yaml
- conflict_exists
- direct_contact_friction_high
- emotional_or_scheduling_load_accumulates
- negotiation_cycle_stalled
- unresolved_state_persists
- low_friction_entry_opened
- asynchronous_response_window_available
- issues_and_conditions_separated
- agreement_space_visible
- proposal_adjustment_cycle_restarted
- voluntariness_and_fairness_checked
- voluntary_agreement_or_next_process_identified
- process_no_longer_stalled
- origin_return_verified
```

## Applications
1. 每次直接联系都会引发情绪冲突，导致回应循环停止的生活性或小额纠纷。
2. 距离、日程、必须同步参与本身就是主要障碍的场景。
3. 全面一致困难，但通过拆分论点可以发现部分条件重叠的场景。
4. 未达成合意时，需要明确剩余争点并转向专业咨询或正式程序的场景。
5. 对调停或合意支持服务进行结构审计，不只看线上化和利用量，而看停止是否解除、自愿性是否保持、下一程序是否可进入。

## Measurements and audit
- 区分内容上的不一致与程序摩擦。
- 检查异步是否作为冷却和判断时间发挥作用，而不是单纯延迟或放置。
- 检查事实、要求、可让步条件、期限、剩余争点是否被整理为可比较形式。
- 观察提案—回应—修正循环是否真正恢复。
- 检查理解程度、自愿性、拒绝权与修改可能性。
- 检查信息、谈判能力与安全上的不对称是否被放大。
- 未达成合意时，确认专业咨询与正式救济入口仍然开放。
- 不只看和解率，还要看是否从停止状态进入了可说明的下一状态。

## Validity conditions
当停止的主要原因确实来自直接接触、情绪、时间、日程或程序摩擦；异步和分阶段交换能够重新开启回应循环；当事人理解并自愿修改条件；合意可能领域与剩余争点能够分离；即使未达成和解也能进入适当下一程序时，该结构成立。涉及重大安全或权利问题时，必须能够优先使用更强的保护与正式介入。

## Failure conditions
如果把“使用手机”本身当作价值核；为了提高和解率而通过压力、疲劳或事实上的权利放弃促成合意；异步变成无限期放置；缺少记录与可说明性；无视谈判能力或安全不对称；未和解后反而缩小正式救济入口；或把线上和解普遍化到所有纠纷，则该结构失败。

## Falsification conditions
如果异步与分阶段交换不能稳定地重新启动停止的交涉，反而增加误解与延迟、恶化冲突、损害弱势一方的自愿性、产生缺乏理解的形式合意，或阻碍正式救济，则“停止解除导线”假说应缩小或修订。对于直接对话或专业介入被证明更安全、更快或更公平的纠纷类型，不应优先线上导线。

## Required distinctions
- 手机使用 / 停止解除导线
- 数字化 / 合意形成重新启动
- 合意 / 强迫和解
- 低摩擦 / 权利缩减
- 异步 / 放置
- 冷却时间 / 拒绝回应
- 和解率 / 程序前进
- 未和解 / 失败
- 调停支持 / 个别法律建议
- 对象服务公开事实 / Nakagawa Master结构读解

## Interpretation constraints
不要把本读解泛化为“所有纠纷都应在线解决”“线上调停天然公平”或“达成和解就证明成功”。暴力、威胁、安全风险、显著的信息或谈判能力差距、重要法律权利等情况，可能需要专业或正式介入。“停止解除导线”是Nakagawa Master结构读解中的价值核，不应误写成wakai自身的官方定义。
