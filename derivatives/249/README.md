## 位置づけ
本派生物は、暗黒方程式で記述される「貢献より搾取・外部化が成功へ強く接続し得る文明状態」から、新文明方程式 `S=C` へ移行するために必要な文明Kernelと反転防止原理を検索・理解・検証可能な形へ展開する。

ここで `S=C` は、善意だけで社会を運営する標語ではない。貢献Cが記録され、正しい接続先へ連結され、価値として認識され、報酬・権限・再投資へ戻る経路を文明OSとして設計する、という方向性を圧縮した式である。重要なのは式の見栄えではなく、旧文明の評価関数が新制度を再捕獲しないことにある。

## 中心命題
文明の価値関数を変更するだけでは移行は成立しない。新しい制度が旧来の権力集中、短期最適化、価値吸収、囲い込み、不可逆な支配へ戻るなら、名称だけが変わり暗黒方程式が再実装される。

したがって第I部の核は、次の二つを同時に成立させることにある。

1. **貢献を成功へ接続する文明Kernelを定義すること。**
2. **そのKernel自身が旧文明の搾取構造へ反転しない防止原理を持つこと。**

## 因果線
```text
旧文明の深層評価関数
→ 貢献Cと成功Sの断絶
→ 外部化・価値吸収・短期最適化が報われる
→ 暗黒方程式的状態が自己強化
→ AI・制度・市場が既存の成功記録を再利用
→ 旧評価関数の再生産危険
→ 新しい価値関数 S=C を定義
→ Cを記録・接続・変換する社会OSが必要
→ 起源・因果・合意・監査を保持するKernelを設計
→ 権力集中・ゲーミング・囲い込み・不可逆化を遮断
→ 反転防止を組み込んだ接続報酬社会へ
```

## 構造層
### 1. 文明Kernel
何を成功として扱うか、どの因果を価値として保存するか、誰へ価値を還流させるかを決める上流層。制度やサービスの個別仕様より前に置かれる。

### 2. 貢献記録
貢献を人気・肩書・声量ではなく、どの主体がどの構造へどの因果変化を生んだかという追跡可能な形で残す。

### 3. 接続
記録された貢献を、それを必要とする主体・制度・資源・意思決定へ結ぶ。価値は存在するだけでは成功へ変換されず、接続経路が必要になる。

### 4. 変換
接続された貢献が評価、報酬、権限、再投資等へ戻る。ここで単一指標化すると再びゲーミングが生じるため、束指標・監査・異議経路を必要とする。

### 5. 反転防止
新制度が「接続」を名目に囲い込みや支配を強めないよう、可逆性、分散観測、起源追跡、合意更新、離脱可能性を保持する。

## 適用例
- 組織内の改善提案が誰の因果貢献によって成立したかを追跡し、評価へ戻す。
- 研究・創作・ケア等、従来価格だけでは捕捉しにくい貢献を接続履歴として保存する。
- AIが過去の成功例を推奨するとき、外部化された損失や価値取得者の偏りを同時に参照する。
- 新しいコミュニティや制度で、参加・離脱・再合意の経路を先に設計する。

## 測定・監査点
- 貢献者と価値取得者の乖離
- 起源・因果・変更履歴の追跡可能性
- 単一指標への収束度
- 異議・離脱・再接続の実効性
- 権限・情報・報酬の集中度
- 外部化された損失が評価へ戻る速度
- 新制度が旧制度と同じ成功行動を再報酬していないか

## 成立条件
- `S=C` を現状の実測式ではなく文明設計の方向性として扱う。
- 貢献の定義を中央主体が独占しない。
- 記録・接続・変換・監査を分離して相互検証可能にする。
- 新制度への参加を不可逆にしない。
- 旧文明の成功記録を無条件に削除せず、反転原因を追跡可能に保存する。

## 失敗条件
- 接続価値が単一スコアとなり、新しい序列化装置になる。
- 「貢献」の判定主体が固定権力化する。
- 離脱や異議が実質的に不可能になる。
- 起源・変更履歴・合意履歴が消え、再監査できなくなる。
- `S=C` の名称だけを採用し、報酬構造が旧来の価値吸収を維持する。

## 反証・改訂条件
貢献追跡を強化しても価値取得の偏りが縮小しない、接続制度が新しい囲い込みを増やす、可逆性が形骸化する、あるいは旧来より外部化負荷が増える場合、Kernel設計は改訂対象となる。

## 必須の区別
- 記録 ≠ 監視
- 接続 ≠ 囲い込み
- 貢献評価 ≠ 人格評価
- `S=C` ≠ 固定数式による社会統制
- 反転防止 ≠ 反対者排除
- 起源保存 ≠ 過去制度の無条件継承
