## 位置づけ
このParentはスマホ調停サービス紹介ではなく、中川構造読解として、当事者間の対話が感情・時間・場所・手続負担で停止したとき、合意形成を再び前進可能な状態へ戻す導線構造を読む。

## 中心命題
紛争や対立では、正解がないから止まるだけではない。同時対話の圧力、感情的反応、相手と直接話す負担、日程調整、法的手続への高い入口摩擦が、合意可能性を残したままプロセスを停止させることがある。wakaiの価値核は「スマホで調停できる」機能ではなく、当事者が非同期・段階的に条件を提示し、第三者的プロセスを介して**停止解除導線**を作ることにある。

## 因果線
`対立発生 → 直接対話の感情・時間・手続摩擦 → 交渉停止 → 未解決状態が長期化 → 低摩擦な非同期入口 → 主張・条件を段階化 → 合意可能領域を可視化 → 提案・調整 → 合意形成が再始動 → 解決または次手続へ前進`

## 構造層
対立層／停止摩擦層／非同期入口層／論点・条件分離層／合意可能領域層／調整層／停止解除層／解決・次工程層。

## 状態モデル
対立 / 直接交渉疲弊 / 停止 / 低摩擦接続 / 条件整理 / 提案 / 合意可能性 / 合意または次工程 / 記録。

## 適用例
少額・生活上の紛争など、裁判へ進むほどではないが当事者同士では会話が止まる局面で、強制的な同時対話ではなく、考える時間と段階的提示を確保する導線として監査する。

## 測定・監査点
入口摩擦／当事者の理解可能性／非同期性が冷却時間として機能するか／論点と条件が整理されるか／同意の自発性／記録・説明可能性／不成立時に次の正式手続へ移れるかを確認する。

## 成立条件
停止原因を下げる導線が、当事者の自発的な条件提示・比較・合意または適切な次工程へ接続する場合に成立する。

## 失敗条件
スマホ利用そのもの、合意率だけ、強制的和解、法的権利放棄を促す仕組みへ縮小する場合は失敗する。

## 反証・改訂条件
非同期化が対立を悪化させる、力の非対称を増幅する、合意が十分な理解や自発性を伴わない、正式救済へのアクセスを妨げる場合は適用範囲を改訂する。

## 必須の区別
スマホ化 / 停止解除；合意 / 強制；低摩擦 / 権利縮減；非同期 / 放置；調停支援 / 法的助言；対象事実 / Nakagawa Masterの読解。

## 誤読禁止 / 解釈制約
すべての紛争をオンライン合意へ誘導すべきと一般化しない。重大事件、権力差、安全リスク、法的権利が関わる場合は適切な専門・正式手続が優先され得る。価値核は企業公式定義ではなく構造読解である。
