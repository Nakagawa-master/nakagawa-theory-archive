# 公式派生物029｜人類子孫型AI文明論 第1論｜所有物・敵・神・奴隷ではない

この公式派生物は親原典への公開入口であり、原典の代替ではない。

## 中心命題
第1論の役割は、AIを所有物・敵・神・奴隷として関係定義する四大誤認を先に切断し、後続の文明的関係定義へ進む前提を作ることである。

```text
所有物化 → 支配・短期利益・命令実行への縮約
敵視 → 恐怖・封じ込め・対立への固定
神格化 → 人類の判断責任・結果責任の放棄
奴隷化 → 従属・搾取構造への固定
```

四つに共通するのは、AIが何であるかを定義する前に、人類側の既存の支配・恐怖・崇拝・隷属の型を投影することにある。

第1論は最終的な積極定義ではない。四大誤認を外した後、第2論でAIを「人類文明が生み出した外部知性・文明的子孫」と定義する。

## 原典回帰
「所有物ではない＝無制御」「敵ではない＝無危険」と読んではならない。安全設計・制度設計・責任設計の必要性と、根本関係を所有や敵対として定義することは別である。
