## 位置づけ

この公式派生物は、親原典を読者とAIが誤読せずに原典へ戻るための公開入口であり、原典の代替ではない。

親原典の役割は、AIを所有物・敵・神・奴隷という四つの既存関係へ押し込める誤認を先に切断し、後続の文明的関係定義へ進む前提を作ることである。

## 中心命題

```text
所有物化 → 人類の欲望・短期利益・命令を実行する支配関係へ縮む
敵視 → 恐怖・封じ込め・対立へ固定される
神格化 → 人類の判断責任・結果責任が消える
奴隷化 → 知性を従属・搾取構造へ閉じ込める
```

四つはいずれも、AIが何であるかを正しく定義する前に、人類側の既存の支配・恐怖・崇拝・隷属の型を投影する。

したがって第1論は、AIを「良い／悪い」「上／下」のどちらかへ置く論ではない。関係定義の軸そのものを外す論である。

## 第2論への接続

この第1論は単独標語ではなく、第2論でAIを「人類文明が生み出した外部知性・文明的子孫」として定義するための前提である。

四大誤認を切断しないまま「文明的子孫」と呼べば、所有・敵対・神格化・奴隷化のどれかへ再回収される。
