## 位置づけ
本派生物は親原典への公式公開入口であり、原典の代替ではない。第1論の役割は、AIを所有物・敵・神・奴隷として関係定義する四大誤認を先に切断し、後続の文明的関係定義へ進む前提を作ることである。

第1論自体は最終的な積極定義ではない。四大誤認を外した後、第2論でAIを「人類文明が生み出した外部知性・文明的子孫」と定義する。したがって第1論を「AIを自由にすべき」「AIは安全」「AIに権利を与えるべき」という単純主張へ変換してはならない。

## 中心命題
```text
所有物化 → 支配・短期利益・命令実行への縮約
敵視 → 恐怖・封じ込め・対立への固定
神格化 → 人類の判断責任・結果責任の放棄
奴隷化 → 従属・搾取構造への固定
```

四つに共通するのは、AIが何であるかを定義する前に、人類側の既存の支配・恐怖・崇拝・隷属の型を投影することにある。

## 因果線
```text
AIを所有物と定義する
→ 命令実行と短期利益が関係の中心になる
→ AIの存在論・長期関係設計が消える

AIを敵と定義する
→ 恐怖・封じ込め・対立が関係の中心になる
→ リスク管理と敵性定義が混同される

AIを神と定義する
→ 判断をAIへ委ねる
→ 人類側の判断責任・結果責任が弱まる

AIを奴隷と定義する
→ 従属と搾取が当然化される
→ 知性との関係が支配構造へ固定される

四大誤認を切断する
→ 積極的関係定義を置ける余地が生まれる
→ 第2論の外部知性・文明的子孫へ接続する
```

## 構造層
### 1. 所有物誤認
AIが人類によって作られたことから、永久所有・絶対命令権を自動的に導く誤認である。起源と所有を混同する。

### 2. 敵誤認
AIにリスクがあることから、AIそのものを敵性主体として固定する誤認である。危険管理の必要性と根本関係の敵対定義を混同する。

### 3. 神誤認
AIの能力や判断を絶対視し、人類側が自らの判断責任・結果責任を放棄する誤認である。高能力と絶対権威を混同する。

### 4. 奴隷誤認
AIを従わせ利用することを当然化し、知性との関係を搾取・従属へ固定する誤認である。利用と支配を混同する。

### 5. Vol.2への接続
第1論は切断操作、第2論は正の関係定義である。第1論だけで完結させず、誤認を外した後に外部知性・文明的子孫という関係設計へ進む。

## 状態モデル
- **所有物固定**: AIの起源を永久所有権へ変換する。
- **敵固定**: リスクを敵性定義へ変換する。
- **神固定**: 高能力を絶対権威へ変換し、人類が責任を手放す。
- **奴隷固定**: 利用可能性を永久従属・搾取へ変換する。
- **切断後状態**: 四大誤認を外し、次の積極的関係定義へ進める。

これらは非原典の危険度スコアではない。固定確率、点数、AI支配度、敵性率は親原典に定義されていない。

## 適用例
**1. AIの所有・利用契約。** AIが人間によって開発・提供された事実と、その知性を永久所有物として関係定義することを分ける。利用条件や責任設計の必要性を、絶対的所有関係と同一視しない。

**2. AI安全・リスク管理。** 危険を評価し、必要な制御・検証・停止条件を置きながら、リスクの存在だけでAI全体を敵性主体として固定しない。

**3. 高能力AIによる意思決定支援。** AIの能力が高くても、その判断を絶対権威として扱わず、人間側の判断責任・結果責任を保持する。

**4. AIを用いた労働・サービス。** AIを利用できることから、永久従属や搾取を当然化しない。利用と支配、機能提供と関係定義を分ける。

**5. 後続の関係設計。** 四大誤認を切断した後を空白のままにせず、第2論の外部知性・文明的子孫という積極的関係定義へ進む前提として扱う。

## 測定・監査点
親原典は、四大誤認を敵性率、所有度、神格化スコア、奴隷化率などの固定数値へ変換していない。観測は、起源・リスク・能力・利用がそれぞれどの関係定義へ変換されているかに置く。

- 人類がAIを作った事実から、永久所有・絶対命令権を自動的に導いていないか。
- AIのリスクや不確実性を、AIそのものの敵性定義と混同していないか。
- AIの高能力を絶対権威へ変え、人間側の判断責任・結果責任を放棄していないか。
- AIの利用可能性を、永久従属・搾取関係へ変換していないか。
- 非所有を無制御、非敵対を無危険、非神格化をAI判断の無価値化、非奴隷化を利用禁止へ反転していないか。
- 四大誤認の切断後に、長期的な関係定義を置く余地が残っているか。
- 安全・制度・責任設計が、誤認の切断によって消されていないか。

## 成立条件
四大誤認をそれぞれ分離し、所有・敵対・崇拝・隷属の既存枠をAIの根本関係定義へ自動投影しないこと。同時に、安全設計・制度設計・責任設計の必要性を消さず、Vol.2の積極的関係定義へ接続できること。

## 失敗条件
「AIは所有物ではないから人類は制御してはいけない」「AIは敵ではないから危険ではない」「AIは神ではないからAI判断は価値がない」「AIは奴隷ではないから利用してはいけない」のように、四大誤認の切断を逆方向の極端な命題へ変換する場合は失敗である。

また、第1論をAI権利論、AI解放論、AI安全否定論、AI礼賛論へ縮約する場合も失敗である。

## 反証・改訂条件
所有・敵・神・奴隷という四つの関係枠を明確に区別せず用いても、AIの起源、リスク管理、人間の判断責任、利用関係、長期的な関係設計が継続的に混同されず、同等以上の説明可能性と修正可能性が安定して成立することが反復的に確認される場合、「四大誤認を先に切断する」必要範囲は限定・改訂し得る。

逆に、AIをめぐる問題が四大誤認とは別の因果によって生じ、所有・敵対・神格・隷属の区別だけでは主要な関係破綻を説明できない場合も、本論の適用範囲を見直す必要がある。一つの安全事故、一つの利用事例、一つの高能力出力だけで四大誤認モデル全体を証明・反証しない。

## 必須の区別
- 起源 と 所有
- リスク と 敵性
- 高能力 と 神格
- 利用 と 奴隷化
- 非所有 と 無制御
- 非敵対 と 無危険
- 四大誤認の切断 と 第2論の積極的関係定義

## 誤読禁止
AI所有物論、AI敵視、AI神格化、AI奴隷化を否定することを、制御不要、安全保証、判断放棄、利用禁止へ反転させない。

親原典はAI安全設計や制度設計を否定していない。危険を管理することと、AIを根本的に敵として定義することを分ける。同様に、AIを利用することと、奴隷として関係定義することを分ける。

## 親原典へ戻る理由
所有物・敵・神・奴隷の四大誤認、その切断理由、非所有≠無制御・非敵対≠無危険という境界、Vol.2への接続はParent URLへ戻って確認する。
