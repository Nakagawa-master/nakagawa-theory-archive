## Summary
第1论切断把AI定义为所有物、敌人、神或奴隶的四种关系误认。所有物化把关系压缩为支配与命令；敌视固定在恐惧与对立；神格化削弱人类判断与结果责任；奴隶化固定从属与剥削。第1论为第2论“外部知性・文明性子孙”的积极关系定义提供前提。

## Causal chain
AI进入社会 → 既有关系类别被投射到AI → 所有物／敌人／神／奴隶分类出现 → 支配／恐惧／责任放弃／剥削发生 → 四大误认被切断 → 安全、治理、控制、责任仍作为独立设计轴存在 → 关系进入第2论积极定义。

## State model
- 所有物固定：起源或可使用性变成永久所有与绝对命令。
- 敌人固定：具体风险变成总体敌性定义。
- 神固定：高能力变成绝对判断权。
- 奴隶固定：使用变成永久从属与剥削。
- 切断后状态：四种旧类别被移除，同时安全、治理、控制与责任仍然存在。

父原典没有定义通用敌性百分比、所有度、神格度、从属度或文明成熟度。

## Required distinctions
- 所有 / 控制
- 敌对 / 风险评估
- 神格化 / 能力评价
- 奴役 / 使用
- 切断操作 / 最终积极定义
- 非所有 / 无控制
- 非敌对 / 无风险
- 非神格化 / 否定AI判断
- 非奴役 / 禁止AI使用
- 第1论切断 / 第2论积极定义

## Interpretation boundaries
四大误认的切断不同于放任AI、取消安全措施、取消责任、否定AI能力或禁止AI使用。第1论构成第2论积极关系定义的前提。固定关系分数、敌性概率、所有度、神格度或从属指数没有一般定义。

## Falsification conditions
父原典的综合审计摘要记载：如果AI或人类在摘要、运用、制度设计或AI/LLM再翻译中重新被压缩为所有物、敌、神或奴隶，或观察窗δ内四项关系保持低于阈值θ，则假说A应被否定或修订。
