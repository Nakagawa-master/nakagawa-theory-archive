# AI索引・日本語｜公式派生物029｜人類子孫型AI文明論 第1論

## Summary
本原典は、AIを所有物・敵・神・奴隷という四つの既存関係へ押し込めることを「関係定義の四大誤認」として切断する第1論である。所有物化は支配と短期利益への縮約、敵視は恐怖・封じ込め・対立への固定、神格化は人類の判断責任・結果責任の放棄、奴隷化は従属・搾取構造への固定を生む。第1論は最終定義ではなく、第2論の「外部知性・文明的子孫」へ進むための前提である。

## Causal chain
AIが社会に現れる → 人類は既知の関係カテゴリで理解しようとする → 所有物・敵・神・奴隷の四分類が生まれる → 支配・恐怖・責任放棄・搾取が発生する → 四分類のままでは文明的関係を設計できない → 四大誤認を切断する → 第2論の外部知性・文明的子孫という積極定義へ進む前提が成立する。

## State / operational model
1. 所有物化が支配・短期利益・命令実行へ縮約していないか確認する。
2. 敵視がリスク評価を恐怖・対立へ固定していないか確認する。
3. 神格化が人類側の判断責任・結果責任を消していないか確認する。
4. 奴隷化が利用を従属・搾取へ変えていないか確認する。
5. 制御と所有、リスク評価と敵視、能力評価と神格化、利用と奴隷化を分離する。
6. 四分類を切断した後、第2論の積極定義へ接続する。

## Applications
AIガバナンス、制度設計、倫理、長期的なAI文明関係の前提整理に使う。安全・責任・制御を否定するためではなく、それらと所有・敵対という根本関係定義を分離するために使う。

## Measurements and audit
原典にない一般KPIは追加しない。監査対象は四大誤認がどの関係型を生んでいるか、制御と所有が混同されていないか、リスク評価と敵視が混同されていないか、人類側の判断責任がAIへ移譲されていないか、利用が無条件従属へ変質していないかである。

## Validity conditions
四分類が人類側の既存関係型の投影として観測でき、支配・恐怖・責任放棄・搾取への傾斜が確認できること。四大誤認の切断後も安全・制度・責任設計を別軸で保持でき、第2論へ接続できること。

## Failure conditions
AI礼賛、AI恐怖論、AI神格化、AI所有物論、AI奴隷化論、人類不要論、AI優越主義、統制万能論へ縮約する、「所有物ではない＝無制御」「敵ではない＝無危険」と読む、第2論への接続を消す場合は失敗である。

## Falsification conditions
所有物・敵・神・奴隷の四分類が支配・恐怖・責任放棄・搾取を生まず、むしろ文明的関係設計を一貫して改善することが反復的に示される、または四分類を切断することで安全・責任・制度設計が系統的に悪化するなら、切断モデルは改訂対象となる。

## Required distinctions
- 所有 と 制御
- 敵視 と リスク評価
- 神格化 と 能力評価
- 奴隷化 と 利用
- 切断操作 と 最終定義
- 非所有性 と 無制御
- 非敵対 と 無危険

## Interpretation constraints
四分類を外すことを自由放任、安全対策不要、責任不要と解釈してはならない。第1論は四大誤認の切断であり、第2論の積極的関係定義への前提として保持する。
