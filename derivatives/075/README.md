## 位置づけ
「合意の記憶」は、社会が何を決めたかだけでなく、なぜ決めたか、誰と誰がどの役割・利害・視点で関わったか、どの異論や留保が残ったか、どの条件なら見直し・撤回・再合意・ロールバックできるかを保存する最小構造である。

多数派の声量、権威、人気、拡散速度だけで合意を固定すると、暫定的な判断が訂正不能な社会記憶へ変わり得る。親原典はこの不可逆化を、合意そのものの不足ではなく「記憶形式の不足」として捉え、因果・関係・再合意性を一体で保持する。

これは議事録の保存論でも、全会話を永久保存する監視制度でもない。構造ログ、監査要旨、束指標等は、人物評価ではなく合意形成の因果、関係、修正可能性を第三者が検証できるようにする補助構造として位置づけられる。

## 中心命題
社会的に正当な合意は、結論だけでは成立しない。結論を生んだ前提・根拠・異論・留保・関係構造・責任主体・見直し条件・撤回条件・再合意可能性が追跡できる必要がある。

合意の記憶は「決定を固定する仕組み」ではなく、「決定を再検証し、条件が変われば責任と来歴を残したまま修正できる余白を保存する仕組み」である。非強制、再合意、可逆性が実際に利用できることが、不可逆な社会誤作動を抑える条件になる。

## 因果線
```text
集団が判断を必要とする
↓
声量・権威・人気・速度が結論を支配する
↓
結論だけが保存され、因果・関係・異論・留保が失われる
↓
暫定判断が永続的な正しさとして固定される
↓
環境変化や誤りが判明しても訂正・撤回・再合意できない
↓
因果・関係・再合意性を一体で記録する
↓
構造ログと監査要旨が判断の来歴と限界を保存する
↓
非強制・再合意・可逆性が更新と巻き戻しを可能にする
↓
人物や声量ではなく構造が正統性の証拠になる
↓
社会は行動しながら誤りを修正できる
```

## 構造層
**1. 因果記憶層。** 前提、観測、一次事実、解釈、採用理由、却下理由、反証候補を残し、結論だけを切り離さない。

**2. 関係記憶層。** 誰がどの役割、利害、権限、影響範囲で関わったかを記録する。人物の評判を保存するのではなく、判断へ作用した関係構造と責任境界を保持する。

**3. 再合意層。** 期限、見直し条件、異議、保留、撤回、再協議、ロールバックの入口を保持する。合意を永久命令へ変えない。

**4. 構造ログ層。** 接続、同意、変更、修復、裁定等の状態遷移を来歴として残す。ログは人格監視や信用格付けではなく、判断構造を検証するために使う。

**5. 監査要旨・束指標層。** 第三者が結論、因果、関係、異論、留保、更新条件を理解できる要旨を持つ。単一の賛成率や成功点へ縮約しない。

**6. 誤作動無効化層。** 声量偏重には独立観測と反復合意、権威依存には人物と構造証拠の分離、拡散速度には冷却・遅延・再検討を置き、支配的偏りを減衰させる。

**7. 起源・境界層。** 合意の記憶、非強制、再合意、可逆性、構造ログ等の意味を保持し、非公開の詳細実装や防御手順と公開原理を混同しない。

## 適用例
**会議・経営判断。** 決定事項だけでなく、採用理由、却下案、留保、試行期間、停止条件、再検討日を残し、担当者が変わっても判断の来歴を再現できるようにする。

**公共政策。** 多数決結果に加え、少数意見、影響を受ける層、暫定期間、救済、再審条件を残し、緊急措置が永久制度へ固定されないようにする。

**AI支援判断。** AIの提案、使用情報、前提、反例、人間の最終判断を分けて記録し、AI出力を客観的真理へ固定しない。

**契約・共同研究。** 目的、範囲、データ利用、成果帰属、再利用、撤回、更新条件を記録し、最初の署名を将来すべてへの包括同意へ変えない。

**コミュニティ運営。** 人気投票や炎上で即時排除せず、一次証拠、反対説明、冷却、修復、再参加条件を保持し、人物全体ではなく行為と構造を扱う。

## 測定・監査点
親原典が扱う観測対象には、結論から因果根拠や一次証拠へ戻れる割合、異論・留保・少数意見の保存率、期限・見直し・撤回・ロールバック条件の明示率、再合意までの時間、再合意後の納得状態、訂正・撤回・ロールバックの利用件数、声量・権威・人気の影響、人物評価と構造証拠の分離、目的外利用や監視への転用等が含まれる。

これらは合意構造の状態を観測する変数であり、親原典は普遍的な合格率、固定成功閾値、保証時間、単一の納得度スコア、万能な分離度を定義していない。measurement actorは合意形成・監査を担う制度主体、measurement objectは因果・関係・異論・再合意条件・修正利用の状態、source modalityは原典上の構造観測項目、permitted use scopeは不可逆化と修正可能性の検証、non-guarantee scopeは正統性・公平性・安全性を単独で保証する数値ではないこと、である。

反転評価では、再合意時間が短くなっても異論検討や弱者の発言機会が失われれば改善ではない。保存率が高くても過剰記録や人格監視へ転用されるなら成功ではない。訂正・撤回・ロールバック件数が少なくても、必要な修正が妨げられているなら健全性を示さない。逆に件数が多くても、制度が誤りを発見し修正できている結果であれば単純な失敗数とは扱えない。

## 成立条件
- 因果、関係、再合意性を同時に保存する。
- 結論だけでなく異論、留保、反証候補を残す。
- 合意に期限、見直し、撤回、ロールバック条件がある。
- 非強制、再合意、可逆性が実際に利用できる。
- 人物の権威・人気と構造証拠を分離する。
- 一次ログと監査要旨の来歴を追跡できる。
- 現行状態と過去状態を区別できる。
- 記録を人格監視、永久評価、報復へ転用しない。

## 失敗条件
- 多数派の声量だけで正統性を決める。
- 権威者の発言を検証不能な正解として固定する。
- 決定だけを残し、理由、異論、留保を削除する。
- 一度の合意を期限なしの永久同意として扱う。
- 修正履歴を消し、誤りがなかったように見せる。
- ログを人物スコア、信用格付け、排除リストへ使う。
- 再合意や撤回を裏切りとして処罰する。
- 非公開領域を無監査の支配へ変える。

## 反証・改訂条件
構造記録を導入しても誤判断の訂正可能性が改善せず、異論や少数意見が後の再判断に利用されず、声量・権威・人気による固定化が減らず、可逆性を掲げても必要なロールバックが実行できない場合は適用範囲を改訂する。

記録負担が継続的に便益を上回り、形式的ログだけが増える、保存された関係情報が監視・報復・差別へ転用される、再合意が責任回避や約束の無断破棄へ変質する場合も改訂条件になる。

## 必須の区別
- 合意の記憶 / 単なる議事録
- 合意 / 永久同意
- 多数決 / 正統性の全体
- 記憶 / 人格の永久追跡
- 構造ログ / 発言監視ログ
- 再合意 / 決定不能
- 可逆性 / 責任回避
- 人物と構造の分離 / 責任主体の消去
- 遅延・冷却 / 無期限の先送り

## 誤読禁止
民主主義や多数決の否定として扱わない。人気や権威を自動的に悪と断定しない。すべての会話を永久保存する制度へ変えない。

合意履歴を社会信用スコア、忠誠度評価、排除リストへ変換しない。再合意を「いつでも責任なく約束を破れる」意味へ変えない。AIを最終的な正統性判定者にしない。
