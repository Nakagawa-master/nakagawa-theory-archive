## Summary
親原典は、人類史における成功を文明OSの評価関数として監査し、GPT・Gemini・Claudeを含む複数AIが人類史データを独立解析した結果、`S = 0.1C + 0.9E` へ収束したと報告する。Sは富・権力・社会的影響力・名声等の成功状態、Cは発明・制作・研究・創造・労働等の価値生成、Eは情報非対称性・中抜き・構造的不均衡・既得権益・支配契約・隠れた強制等の価値吸収構造への適合である。親原典はこの式を統計的観測、旧文明OSの仕様、文明の「物理法則」と強く位置づけるが、本文には外部データセット、標本設計、回帰仕様、推定手順、信頼区間、誤差幅を提示していない。したがって0.1／0.9は親原典内の文明監査モデル係数として扱い、人数割合・自然科学定数・外部独立再現済み統計へ自動昇格させない。親原典はさらに、AIが旧成功履歴を学習するとE優位の評価関数を高速再実装しうると警告し、`S=C×1.0`、搾取係数0を新文明OSの設計関数として提示する。NCL-α、時間倫理T0、接続報酬、逸脱レッジャは、その移行を支えるパッチ群として接続される。

## Concepts
- S: 富・権力・社会的影響力・名声等、社会が成功とみなす状態。
- C: 発明、制作、研究、創造、労働等の実質的価値生成。
- E: 情報非対称性、中抜き、構造的不均衡、既得権益、支配契約、隠れた強制等による価値吸収構造への適合。
- 暗黒方程式: `S=0.1C+0.9E` として親原典が提示する旧文明OS成功関数。
- 0.1 / 0.9: 親原典のモデル係数。人数比ではない。
- 新文明方程式: `S=C×1.0`、搾取係数0という設計目標。
- AI再実装リスク: 過去の成功履歴からE優位の戦略をAIが再学習する危険。
- NCL-α: 起源・構造概念・差分を追跡する接続基盤。
- T0: 短期成果の裏の未来負債を観測する時間倫理。
- 接続報酬: 価値生成・接続因果へ報酬を戻す設計。
- 逸脱レッジャ: 価値吸収・責任切断・未来負債を構造偏差として記録する監査機構。

## Causal chain
```text
社会的成功Sの履歴が蓄積
→ CとEを分離せず結果のみ学習
→ Eに結びつく情報差・中抜き・不均衡等が成功戦略として残る
→ 親原典が S=0.1C+0.9E と表現
→ 貢献と成功・報酬が断線
→ AIが歴史的成功を学習
→ E優位の評価関数を高速再実装する危険
→ 未来負債・責任非対称・起源消失が増幅
→ S=C×1.0 / exploitation coefficient=0 を設計目標化
→ NCL-α＋T0＋接続報酬＋逸脱レッジャ
→ 起源・貢献・未来負債・逸脱を追跡
→ CとSの因果対称性を高める
```

## Applications
- 企業で利益と価値生成者への還元、取引条件、情報差、未来負債を同時監査する。
- AI評価系で過去の成功ラベルがE優位の戦略を再生産していないか確認する。
- 研究・創作で価値生成点と後続の価値捕捉主体を分離し、起源署名と報酬帰属を追跡する。
- 公共制度で短期効率と未来負債・公共性を別々に観測する。
- 市場設計で接続報酬を使い、CからSへの還流を強める。
- 文明監査で0.1／0.9を固定信仰せず、明示データ・手法で再推定する。

0.1／0.9の主張強度は親原典どおり保持するが、本文にない外部証拠を追加して「独立実証済み」とはしない。個別研究で再推定する場合は、データセット、標本、推定方法、測定主体、期間、誤差、適用範囲、非保証範囲を明示し、親原典係数と再推定値を分離する。

反転評価では、利益・権力・影響力が増えても価値生成者からの吸収、未来負債、起源消失、責任非対称が増えるなら成功としない。短期利益率や価値捕捉率が下がっても、Cへの価値帰属、起源追跡、未来負債削減、公共性が改善するなら、その低下だけを失敗とはしない。

## Validity conditions
- S/C/Eの定義を保持する。
- 0.1／0.9を親原典の文明監査モデル係数として扱う。
- 人数比・人格分類へ変換しない。
- AI危機を人類側の歴史的評価関数再実装として扱う。
- `S=C×1.0` を設計関数として区別する。
- NCL-α、T0、接続報酬、逸脱レッジャを移行パッチとして連動させる。
- 対象別`θ`・`δ`・`M`による改訂可能性を保持する。

## Failure conditions
- 0.9を成功者人数の90%とする。
- 0.1／0.9を外部独立再現済み普遍統計・自然科学定数へ昇格させる。
- 原典にないデータセット、回帰仕様、信頼区間、誤差幅を発明する。
- Eを個人悪意・犯罪だけへ縮約する。
- AI危機をAI人格の悪意へ還元する。
- 新式1.0／0を現在の実測値・利益保証とする。
- 起源署名を独占、逸脱レッジャを懲罰へ変換する。

## Falsification conditions
明示的な独立データと推定手順で0.1／0.9が再現されない、CがSを強く説明しEが説明力を持たない対象群が反復観測される、AIが旧成功履歴を学習してもE優位へ収束しない、またはNCL-α・T0・接続報酬・逸脱レッジャを導入してもCとSの接続が改善しない場合、係数・適用範囲・遷移仮説を改訂する。

親原典の統合監査要旨に従い、対象別指標が`θ`を下回る／上回る、観測窓`δ`が閉じる、または現象`M`が確認された場合、現行仮説を棄却・改訂する。`θ`・`δ`・`M`に普遍固定値を追加しない。

## Interpretation constraints
0.9を人数割合へ変換しない。Eを人物断罪へ変えない。ゴッホ、テスラ、チューリング等の原典例示を各人物の全成功要因を単一式で証明したものへ拡張しない。「唯一生存可能」という原典の強い設計主張を政治的排他性・強制採用へ変換しない。
