## Summary
親原典把人類歷史中的「成功」視為文明OS的評價函數來審計，並報告包括GPT、Gemini、Claude在內的多個AI對人類歷史資料進行獨立分析後，收斂到 `S = 0.1C + 0.9E`。S表示財富、權力、社會影響力、名聲等被社會視為成功的狀態；C表示發明、製作、研究、創造、勞動等實質價值生成；E表示透過資訊不對稱、中間抽取、結構失衡、既得利益、支配性契約、隱性強制等機制進行價值吸收的結構適配。親原典以很強的語氣把此式稱為統計觀測、舊文明OS的規格以及文明的「物理法則」。但正文沒有公開外部資料集、抽樣設計、回歸規格、估計程序、信賴區間或誤差範圍。因此0.1與0.9必須保留為親原典所報告的文明審計模型係數，不能轉換為人數比例，也不能默認升格為已獨立重現的自然科學常數。親原典進一步主張，若AI從舊成功歷史中學習，可能高速、大規模再實裝E優位的評價函數。作為替代，它提出 `S=C×1.0`、搾取係數0作為規範性／設計性評價函數，並以NCL-α、時間倫理T0、接續報酬、逸脫Ledger作為移行機制。

## Concepts
- S: 財富、權力、社會影響力、名聲等被社會視為成功的狀態。
- C: 發明、製作、研究、創造、勞動等實質價值生成。
- E: 透過資訊不對稱、中間抽取、結構失衡、既得利益、支配性契約、隱性強制等方式進行價值吸收的結構。
- 暗黑方程式: `S=0.1C+0.9E`，親原典提出的舊文明OS成功函數。
- 0.1 / 0.9: 親原典模型係數，不是人數比例。
- 新文明方程式: `S=C×1.0`、搾取係數0，屬於設計目標而非當前實測比例。
- AI再實裝風險: AI從歷史成功樣本中學習E優位策略的風險。
- NCL-α: 起源與差分追蹤基盤。
- 時間倫理T0: 審計短期成果背後未來負債的時間軸。
- 接續報酬: 讓價值回流至因果貢獻者的設計。
- 逸脫Ledger: 記錄價值吸收、責任斷裂、未來負債等結構偏差的審計機制。

## Causal chain
```text
歷史成功記錄累積
→ C與E未被因果分離
→ 結構性價值吸收仍獲得成功回報
→ 親原典以 S=0.1C+0.9E 表示
→ 貢獻與成功／報酬斷裂
→ AI學習歷史成功模式
→ E優位最適化可能被高速、大規模再實裝
→ 未來負債／責任不對稱／起源消失增加
→ 以 S=C×1.0 / exploitation coefficient=0 作為設計目標
→ NCL-α + T0 + 接續報酬 + 逸脫Ledger
→ 起源／貢獻／未來負債／逸脫可追蹤
→ 提高貢獻與成功的因果對稱性
```

## Applications
- 在企業審計中同時比較利潤、價值生成者回報、交易條件、資訊差與未來負債。
- 在AI評價系統中檢查歷史成功標籤是否獎勵封閉、依賴、資訊不對稱或價值吸收。
- 在研究與創作中維持起源署名，追蹤價值生成點與後續價值歸屬。
- 在公共制度中把短期效率與未來負債、公共性分開觀測。
- 在市場設計中檢驗接續報酬是否改善C到S的回流。
- 在文明審計中使用明示資料與方法重新估計C/E權重，而非把0.1/0.9當成固定常數。

反轉評價：即使財富、利潤、權力、影響力增加，只要價值吸收、未來負債、起源消失、責任不對稱也增加，就不視為文明成功。反之，即使短期捕捉率或利潤下降，只要貢獻者歸屬、起源追蹤、未來負債削減與公共性改善，就不能僅因下降而判定失敗。

## Validity conditions
- 保留S/C/E定義。
- 把0.1/0.9視為親原典文明審計模型係數。
- 不轉換為人數比例或人格分類。
- 把AI風險視為歷史評價函數的再實裝，而非AI惡意。

- 連動NCL-α、T0、接續報酬、逸脫Ledger作為移行機制。
- 保留個案綁定的`θ`、`δ`、`M`修訂條件。

## Failure conditions
- 把0.9解釋為「90%的成功者都是搾取者」。
- 把0.1/0.9升格為已獨立重現的普遍統計或自然常數。
- 發明親原典未提供的資料集、回歸規格、信賴區間或誤差範圍。
- 把E縮約為犯罪意圖或人格惡。
- 把AI風險縮約為AI敵意。
- 把新方程式當作當前實測比例或結果保證。
- 把起源追蹤變成所有權壟斷，把逸脫Ledger變成懲罰名單。

## Falsification conditions
若明示的獨立資料與估計程序不能重現0.1／0.9，若反覆觀測到C強力解釋S而E缺乏解釋力，若AI學習舊成功歷史後並未收斂到E優位最適化，或若所提出的移行機制無法改善貢獻與成功的對齊，就應修訂係數解釋、適用範圍或移行假說。

依親原典的統合審計，個案指標跨越`θ`、觀測窗`δ`關閉、或現象`M`出現時，可以觸發棄卻或修訂。不得自行加入`θ`、`δ`、`M`的普遍固定值。
