## 接続順
```text
接続と共鳴の成立
→ 信頼資本・接続報酬
→ 市場形成
→ 共創秩序・構造翻訳・構造組織
→ 貨幣社会の限界
→ 接続価値の制度会計
→ 正統性・監査・反ゲーミングによる保護
→ ID・同意・記憶・可逆性の相互運用標準
→ 権利・義務・手続による上位保障
→ 移行・裁定・公共圏運用
→ 合意の記憶と視座可動域
→ 束指標による多軸観測
→ 接続イベント単位の接続価値会計
→ 監査・訂正・撤回・再合意・ロールバック
```

## 誤読禁止
- 接続報酬を紹介件数や人気へ縮約しない。
- 接続価値を人格評価、社会信用スコア、代替通貨へ変えない。
- 束指標を総合点やランキングへ再圧縮しない。
- 接続価値会計を人や組織の信用点数にしない。
- ガバナンスを中央集権や常時監視へ変えない。
- 保護された重み・閾値を独立監査の免除にしない。
- 各派生面を親原典の代替にしない。
