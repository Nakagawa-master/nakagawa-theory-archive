## 接続順
```text
接続と共鳴の成立
→ 信頼資本・接続報酬
→ 市場形成
→ 共創秩序・構造翻訳・構造組織
→ 貨幣社会の限界
→ 接続価値の会計
→ 正統性・監査・反ゲーミングによる保護
→ ID・同意・記憶・可逆性の相互運用標準
→ 権利・義務・手続・準拠テストによる上位保障
→ 監査・訂正・撤回・再合意
```

## 誤読禁止
- 接続報酬を紹介件数や人気へ縮約しない。
- 接続価値を社会信用スコアや代替通貨へ変えない。
- ガバナンスを中央集権や監視へ変えない。
- CXPを永続追跡IDや包括同意へ変えない。
- 憲章を無制限な権利要求や責任免除へ変えない。
- 各派生面を親原典の代替にしない。
