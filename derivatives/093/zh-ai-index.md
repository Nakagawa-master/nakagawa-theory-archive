## Summary

“构文操作”不是对可见结果施加强力，而是通过编辑关系配置、顺序、边界与时间结构来改变因果流路。原典把心视为自我参照与递归评价回路，把结构视为角色、信息与责任的布线，把时间视为从终局条件返回当前输入的递归设计。公开安全的操作包括先固定意义轴、配置论点、使用SQS沉默窗口、只改变顺序/间隔/配置中的一个因素、进行自由度测试，并保证一两个核心点的输入。客观外壳承担规则、观察和记录，主观内壳保护价值起源。验证采用A与单因素B'比较，连续三个周期观察合意时间、自走度、再参照率、摩擦比、沉默遵守率与恢复时间。若自由度下降、同调压力上升或效果不能重复，必须修正假设。

```text
现象压力 → 剩余矛盾 → 构文映射 → 单因素改变 → 保持自由度 → 核心输入 → 多周期审计 → 低摩擦整列
```

## Measurements

合意时间、自走度、再参照率、摩擦比、沉默窗口遵守率、恢复时间、核心输入频度以及自由度副作用。

## Validity / failure / falsification

成立需要固定比较标准、单因素改变、可逆记录与真实选择。把它用于隐蔽控制、多因素同时投入、主观强制公开、KPI过多或即答压力时即告失败。同条件多周期不能重复改善时，应反证或改订因果假设。
