## 1. Summary
父原典区分“现象操作”与“构文操作”。前者直接对可见现象施力，后者编辑关系配置、顺序、边界与时间设计，从而改变因果流路本身。三项统合原理是心与结构的连接、通过顺序／间隔／配置调律结构摩擦、以及从期望终局条件反向更新当前规格和过去解释的时间递归设计。

公开实施结构包含2/5/5/5/3分钟的20分钟协议、客观外壳／主观内壳双重结构、将KPI收敛到1～2个核点、以日次保证输入并以周次评价输出的原典运行示例、七项指标、单因子A/B’比较、连续三个周期与副作用记录。这些数字不能泛化为普遍成功阈值或人物评分。

## 3. Causal chain
```text
直接对现象施力
→ 结构矛盾仍然残留
→ 制度疲劳、信任下降、学习不能累积
→ 把心、结构、时间映射为同一构文
→ 保护主观核心并前置客观规格与责任边界
→ 一次只编辑顺序、间隔、配置中的一个因素
→ 从未来条件递归更新当前规格与过去解释
→ 用20分钟框架和A/B’比较验证
→ 检查三个周期方向与副作用
→ 只整合可再现的构文变化
```

## 5. Applications
在组织、制度、教育与人机协作中，先重新设计边界、规格、信息流和提问顺序，而不是把失败直接归因于个人能力。不要不断增加短期KPI，而应优先保证直接连接KGI的核点输入。客观外壳向公共开放，主观内壳只在条件成立时限定披露。

## 6. Measurements and audit
合意时间 / 自走度 / 再参照率 / 摩擦比 / 沉默遵守率 / 限定披露遵守率 / 恢复时间。把传统A与只改变一个因素的B’在相同条件下比较，确认同方向效果是否连续三个周期出现，并记录自由度下降与同调压力等副作用。更短时间或更高比例不能被单调高评价。

## 7. Validity conditions
心、结构、时间位于同一因果线上；主观核心与客观外壳角色分离；介入保持单因子；核点输入与周边指标不混淆；执行三个周期方向检查；选择自由仍然存在。

## 8. Failure conditions
多因子同时投入 / 主观广告化 / 边界溶解 / 说明主义 / KPI过多 / 不执行沉默窗。还包括把构文操作改写成隐蔽诱导、把未来设计改写成预测、把日次／周次运行周期变成普遍规则。

## 9. Falsification conditions
单因子改变不能在七项指标上产生可再现差异、撤销B’后结果不变、三个周期方向不稳定、效果依赖特定执行者、自由度下降或同调压力持续恶化时，应修改构文假设。

## 10. Required distinctions
现象操作 vs 构文操作 / 调律 vs 隐蔽诱导 / 沉默窗 vs 压制发言 / 客观外壳 vs 否定主观 / 1～2个核点 vs 任意单指标化 / 日次输入周次评价 vs 普遍周期 / 自然整列 vs 同调压力 / 时间递归 vs 未来预测

## 11. Interpretation constraints
不要把2/5/5/5/3分钟、20分钟、1～2个核点、日次、周次、三个周期扩张为普遍成功阈值。不要自动把更高再参照率、沉默遵守率、自走度或更短合意时间判为更好。父原典把数字视为学习之窗，而不是人物价值尺度。
