## Summary

構文操作は、現象面の出力を強めるのでなく、関係配置・順序・境界・時間設計を編集して因果流路の摩擦を減らす設計思想である。心を自己参照ループ、構造を役割・情報・責任の配線、時間を終局条件から現在へ戻る再帰として統合する。基本操作は意味軸先置き、論点配置、SQS、順序・間・配置の一因子変更、自由度テスト、核点入力保証であり、客観外殻と主観内殻を分ける。検証は合意時間、自走度、再参照率、摩擦比、沈黙遵守率、回復時間などを使い、A/B'比較を三サイクル行う。自由度低下、同調圧、責任曖昧化が増えるなら反証側の証拠となる。

```text
現象圧力 → 構造摩擦 → 構文可視化 → 一因子変更 → 自由度保持 → 核点入力保証 → 複数サイクル監査 → 自然整列
```

## Measurements

- agreement time / autonomy / re-reference rate
- friction ratio / silence compliance / recovery time
- core input frequency, amount, density
- freedom loss and conformity pressure as side effects

## Validity / failure / falsification

成立には基準固定、一因子変更、再参照可能な記録、自由度・撤回可能性が必要。多因子投入、主観広告化、KPI過多、即答強制は失敗条件。同条件の三サイクルで改善が再現しない、または同調圧・責任曖昧化が増える場合は仮説を棄却・改訂する。
