## 1. Summary
構文操作は、現象へ直接力を加える現象操作ではなく、関係配置・順序・境界・時間設計を編集して因果流路そのものを変える設計者の思考様式である。三統合原理は心と構造の接続、摩擦の調律、時間構造の再帰設計。主観核を保護する内殻と、規格・観測・責任境界を公共化する外殻を二重化し、順序・間・配置を一因子ずつ調整する。

公開実装型は2/5/5/5/3分の20分プロトコル、核点1〜2点、日次入力保証・週次出力評価、七指標、A/B’比較、三サイクル連続、副作用併記を含む。これらは原典固有の仕様で、普遍成功閾値や人物評価へ一般化しない。

## 2. Concepts

## 3. Causal chain
```text
現象へ直接力を加える
→ 構造矛盾が残る
→ 制度疲労・信頼低下・学習不能性が累積する
→ 心・構造・時間を一つの構文として捉える
→ 主観核を守り客観規格・責任境界を先置きする
→ 順序・間・配置を一因子ずつ編集する
→ 未来条件から現在規格と過去解釈を再帰更新する
→ 20分型とA/B’で検証する
→ 三サイクルと副作用で判定する
→ 再現した構文を運用へ統合する
```

## 5. Applications
組織・制度・教育・AI協働等で、人物能力への直接介入より、境界・規格・情報流路・問いの順序を設計する。短期KPIを多項目化せず、KGIへ直結する核点入力を優先する。二重構造では外殻を公共化し、内殻は条件付き限定開示とする。

## 6. Measurements and audit
合意時間 / 自走度 / 再参照率 / 摩擦比 / 沈黙遵守率 / 限定開示遵守率 / 回復時間。A/B’では従来Aと一因子変更B’を同条件比較し、三サイクル連続の同方向効果を確認する。自由度低下・同調圧増大を副作用として併記する。短い時間や高い率を単調評価しない。

## 7. Validity conditions
心・構造・時間が同じ因果線で接続されること、主観核と客観外殻の役割が分かれること、介入が一因子であること、核点と周辺指標を混同しないこと、三サイクルで方向性を確認すること、自由度を保持すること。

## 8. Failure conditions
多因子同時投入 / 主観の広告化 / 境界の溶解 / 説明主義 / KPIの過多 / 沈黙窓の不履行。加えて、構文操作を見えない誘導へ変える、未来設計を予言へ変える、日次・週次周期を普遍標準へ変える場合。

## 9. Falsification conditions
一因子変更で七指標に再現可能な差がない、変更を戻しても差がない、三サイクルで方向が安定しない、担当者依存でしか成立しない、自由度低下・同調圧増大が継続する場合、構文仮説を改訂する。

## 10. Required distinctions
現象操作 vs 構文操作 / 調律 vs 隠れ誘導 / 沈黙窓 vs 発言抑制 / 客観外殻 vs 主観否定 / 核点1〜2点 vs 恣意的一本化 / 日次入力・週次評価 vs 普遍周期 / 自然整列 vs 同調圧力 / 時間再帰 vs 未来予言

## 11. Interpretation constraints
2/5/5/5/3分、20分、核点1〜2点、日次、週次、三サイクルを一般的成功閾値へ拡張しない。高い再参照率・沈黙遵守率・自走度、短い合意時間を自動高評価しない。数値は原典Q&Aがいう「学習の窓」であり人物査定ではない。
