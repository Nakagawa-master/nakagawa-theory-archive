## 位置づけ
このParentはマンション修繕管理ツール紹介ではなく、理事会メンバーが交代する共同所有組織で、長期修繕の判断根拠・経緯・資料をどう継承するかという管理ガバナンスを読む中川構造読解である。

## 中心命題
マンション修繕は長期なのに、意思決定主体である理事会は短い周期で交代する。この時間スケールの不一致により、なぜ過去にその判断をしたか、何を保留したか、どの資料を根拠にしたかが失われ、同じ検討が繰り返される。リノプラの価値核は、単なる修繕記録のデジタル化ではなく、**修繕判断継続インフラ**として、世代交代を越えて判断コンテキストを保持することにある。

## 因果線
`長期修繕課題 → 理事会は短期交代 → 判断理由・資料が断絶 → 再調査・再議論 → 意思決定コスト増 → 判断経緯・資料・未決事項を構造化保存 → 次期理事会へ継承 → 継続的修繕判断 → 管理ガバナンス安定`

## 構造層
長期資産層／短期主体交代層／記憶断絶層／判断記録層／引継ぎ層／継続意思決定層／ガバナンス層。

## 状態モデル
属人的記憶 / 交代 / 断絶 / 記録構造化 / 引継ぎ / 継続判断 / 修繕実行 / 再評価。

## 適用例
マンション管理だけでなく、自治会、非営利組織、委員会など、資産・課題の寿命より役員任期が短い場面で「資料保存」ではなく「判断理由の継承」を監査する。

## 測定・監査点
判断理由、採用・不採用案、資料、未決事項、次回条件、責任範囲が次期主体に再構成可能かを確認する。

## 成立条件
次期理事会が過去判断を再現・検証し、ゼロからやり直さず次の判断へ進める場合に成立する。

## 失敗条件
文書保管、予定表、修繕履歴のデジタル化だけへ縮小する場合は失敗する。

## 反証・改訂条件
主体交代が判断断絶を生まない、または保存情報が次の判断に利用されない場合は価値核の適用範囲を改訂する。

## 必須の区別
資料保存 / 判断継承；履歴 / 判断理由；担当者交代 / ガバナンス断絶；対象事実 / Nakagawa Masterの読解。

## 誤読禁止 / 解釈制約
デジタル化だけでガバナンスが改善すると断定しない。情報の質、更新、引継ぎ利用まで見る。
