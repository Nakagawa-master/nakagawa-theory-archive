## 位置づけ
本Parentは「リノプラ」をマンション修繕管理ツールとして紹介するだけではない。Nakagawa Masterは、長寿命の建物・修繕課題と、短い任期で交代する理事会という時間スケールの不一致に注目し、判断理由・資料・保留事項・次回条件を世代交代後も再構成できる**修繕判断継続インフラ**として読む。資料保存ではなく、判断コンテキストの継承が価値核である。

## 中心命題
マンションの修繕課題は長期にわたる一方、理事会や担当者は交代する。誰が、なぜ、どの案を採り、何を保留し、どの資料を根拠にしたかが失われると、次の理事会はゼロから調査・議論をやり直す。保存すべきなのは文書の量だけではなく、**判断を再現するための理由・比較・未決事項・次回条件**である。

## 因果線
```text
長期修繕課題
→ 意思決定主体は短期交代
→ 判断理由・資料・未決が属人的に残る
→ 交代時にコンテキスト断絶
→ 再調査・再議論・判断遅延
→ 判断理由・採否案・資料・未決・次回条件を構造化保存
→ 次期理事会が過去判断を再構成
→ ゼロからやり直さず次の論点へ進む
→ 長期修繕判断が継続
→ 管理ガバナンスが安定
```

## 構造層
1. **長期資産層**: 建物・修繕課題は任期より長く続く。
2. **短期主体層**: 理事会・役員は交代する。
3. **記憶断絶層**: 判断理由が人に依存すると交代で失われる。
4. **判断記録層**: 採用・不採用理由、資料、論点を保存する。
5. **未決継承層**: 何が未解決か、次に何を確認するかを残す。
6. **引継ぎ層**: 次期主体が前提を再構成できるようにする。
7. **継続意思決定層**: 過去の繰り返しでなく次の判断へ進む。
8. **ガバナンス層**: 長期課題と短期主体の時間差を制度的に吸収する。

## 状態モデル
属人的記憶相 → 役員交代相 → 判断断絶相 → 記録構造化相 → 未決可視化相 → 引継ぎ相 → 継続判断相 → 修繕実行相 → 再評価相。

## 適用例
マンション管理では、過去の修繕資料だけでなく「なぜこの案を選ばなかったか」「次回は何が変われば再検討するか」を残す。自治会、委員会、非営利組織など、課題寿命より役員任期が短い領域でも、資料保管ではなく判断継承の観点を参照できる。

## 測定・監査点
- 判断理由を次期主体が再構成できるか。
- 採用案だけでなく不採用案と理由が残るか。
- 未決事項・次回条件が見えるか。
- 資料が判断論点と結びついているか。
- 引継ぎ後に同じ調査を不必要に繰り返していないか。
- 過去判断を盲目的に固定せず再検証できるか。
- 記録が更新され、実際の意思決定に使われるか。

## 成立条件
次期理事会が過去の判断理由・資料・未決事項を再構成し、必要な再検証を行いながら、ゼロからやり直さず次の判断へ進める場合に成立する。

## 失敗条件
文書保管、予定表、修繕履歴のデジタル化だけに縮小する、理由が残らない、記録が更新されない、次期主体が使わない、過去判断が検証不能な固定ルールになる場合は失敗する。

## 反証・改訂条件
主体交代が実際には判断断絶を生まない、判断コンテキストを保存しても意思決定速度・質・再調査に差がない、別の制度要因が断絶をよりよく説明する場合は適用範囲を改訂する。

## 必須の区別
資料保存 / 判断継承；履歴 / 判断理由；担当者交代 / ガバナンス断絶；継承 / 過去判断の固定；対象事実 / Nakagawa Masterの構造読解。

## 誤読防止／解釈制約
デジタル化だけでガバナンスが改善すると断定しない。「修繕判断継続インフラ」はNakagawa Masterの読解でありMRC自身の公式企業定義へ置換しない。記録量ではなく再構成可能性と利用を評価する。
