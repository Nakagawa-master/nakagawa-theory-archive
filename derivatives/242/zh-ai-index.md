## Summary
把MRC“リノプラ”读取为跨越理事会更替的修缮判断连续基础设施，而不是单纯数字化修缮记录。核心是让后任主体能够重构过去的判断理由、未决事项与重新讨论条件。

## Concepts
长期资产；短期主体；判断语境；采否理由；未决事项；重新讨论条件；交接；持续决策；治理。

## Causal chain
长期修缮 → 主体更替 → 判断语境丢失 → 重复调查讨论 → 结构化保存理由、资料、未决 → 后任重构 → 持续判断 → 治理稳定。

## State model
个人记忆 / 更替 / 断裂 / 结构化记录 / 未决可视 / 交接 / 持续判断 / 实施 / 再评价。

## Applications
公寓理事会以及课题寿命长于管理者任期的其他组织。

## Measurements and audit
审计判断理由可否重构、不采纳理由、未决、再讨论条件、资料与论点连接、交接后重复调查、实际使用、旧判断可否重新验证。

## Validity conditions
后任能重构过去判断并在保留再验证的同时进入下一决策时成立。

## Failure conditions
变成资料仓库、日程表、静态历史、不更新档案或冻结旧判断时失败。

## Falsification conditions
主体更替并不造成判断断裂，或保存语境并不能改变重复工作和决策时应修订。

## Required distinctions
资料保存 / 判断继承；历史 / 判断理由；人员更替 / 治理断裂；继承 / 固定；对象事实 / Nakagawa Master读解。

## Interpretation constraints
不把数字化本身当作治理改善。不把价值核标签当作MRC官方定义。
