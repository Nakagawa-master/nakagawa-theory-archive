## Summary
MRC「リノプラ」を、長期修繕と短期理事会任期の時間差による判断記憶断絶を補い、理由・資料・未決事項を次期主体へ渡す修繕判断継続インフラとして読む。
## Concepts
理事会交代；長期修繕；判断記憶；理由継承；未決事項；修繕判断継続インフラ。
## Causal chain
長期課題 → 主体交代 → 記憶断絶 → 再議論 → 判断記録構造化 → 引継ぎ → 継続判断。
## State model
属人記憶 / 交代 / 断絶 / 構造化 / 引継ぎ / 継続 / 実行 / 再評価。
## Applications
マンション管理、委員会、自治組織など長期課題と短期任期が交差する領域。
## Measurements and audit
決定理由、不採用案、未決、資料、次回条件の再構成可能性を監査する。
## Validity conditions
次期主体が過去判断の続きから判断できる場合。
## Failure conditions
文書保存・予定管理だけへ縮小する場合。
## Falsification conditions
交代が断絶を生まない、保存情報が利用されない場合は改訂する。
## Required distinctions
資料保存 / 判断継承；履歴 / 理由；交代 / 断絶；事実 / 読解。
## Interpretation constraints
デジタル化だけで統治改善を断定しない。
