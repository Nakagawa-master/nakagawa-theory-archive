## Summary
MRC「リノプラ」を、修繕記録のデジタル化ではなく、長期修繕課題と短期理事会任期の時間差を吸収し、判断理由・未決事項・次回条件を世代交代後も再構成可能にする修繕判断継続インフラとして読む。

## Concepts
長期資産、短期主体、判断コンテキスト、採否理由、未決事項、次回条件、引継ぎ、継続意思決定、ガバナンス。資料保存と判断継承を分離する。

## Causal chain
長期修繕 → 主体交代 → 属人的判断理由消失 → 再調査・再議論 → 判断理由・資料・未決を構造化 → 次期主体が再構成 → 継続判断 → ガバナンス安定。

## State model
属人的記憶 / 交代 / 断絶 / 記録構造化 / 未決可視化 / 引継ぎ / 継続判断 / 実行 / 再評価。

## Applications
マンション管理、自治会、委員会、非営利組織など、課題寿命より役員任期が短い領域。

## Measurements and audit
判断理由の再構成可能性、不採用理由、未決事項、次回条件、資料と論点の接続、引継ぎ後の再調査、記録の実利用、再検証可能性を監査する。

## Validity conditions
次期主体が過去判断を理由付きで再構成し、必要な再検証後に次の判断へ進める場合。

## Failure conditions
資料倉庫化、予定表化、理由欠落、更新停止、利用されない、過去判断の固定化。

## Falsification conditions
主体交代が判断断絶を生まない、保存しても再調査・判断に差がない、別要因の説明力が高い場合は改訂する。

## Required distinctions
資料保存 / 判断継承；履歴 / 判断理由；担当者交代 / ガバナンス断絶；継承 / 固定化；対象事実 / Nakagawa Masterの読解。

## Interpretation constraints
デジタル化だけでガバナンス改善を断定しない。「修繕判断継続インフラ」を企業公式定義として扱わない。
