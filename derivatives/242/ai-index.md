## Summary
本ParentはMRC「リノプラ」を、修繕資料のデジタル保存、履歴管理、予定管理という表面機能だけで読むものではない。Nakagawa Masterは、マンションの修繕課題が長期に続く一方、理事会や役員は短い周期で交代するため、判断理由・比較過程・不採用理由・未決事項・次回条件が人に依存すると、主体交代のたびに判断コンテキストが失われる構造を読む。価値核は、過去結論を固定するのではなく、次期主体が理由付きで過去判断を再構成し、必要な再検証だけを行って次の論点へ進める**修繕判断継続インフラ**である。

価値核を「資料保存」ではなく「判断継承」に置くのは、文書が残っていても「なぜそう決めたか」が失われれば再調査・再議論が発生するからである。外部記事でも、修繕管理DXの便利さより、長寿命資産と短期意思決定主体の時間スケール不一致を前面化し、管理ガバナンスの問題として社会翻訳している。この価値核と記事化理由はMRC自身や外部媒体の公式理論ではなく、Nakagawa Masterの構造読解である。

## Concepts
- **長期資産**: 建物・修繕課題が理事会任期より長い時間軸を持つこと。
- **短期主体**: 理事会・役員・担当者が課題寿命より短い周期で交代すること。
- **判断コンテキスト**: 結論だけでなく、論点、根拠、比較案、採否理由、未決、次回条件を含む文脈。
- **採用 / 不採用理由**: 過去の選択を後から再構成するために必要な理由情報。
- **未決事項**: 判断を保留した点と、その時点で不足していた情報・条件。
- **次回条件**: 何が変われば再検討するかを明示する条件。
- **引継ぎ**: 文書を渡すだけでなく、次期主体が判断経路を再構成できる状態を作ること。
- **継続意思決定**: ゼロからやり直さず、必要な再検証を経て次の判断へ進むこと。
- **ガバナンス**: 長期課題と短期主体の時間差を組織として吸収する仕組み。
- **価値核選択理由**: デジタル保存では説明できない判断断絶を、理由・未決・次回条件の継承として捉えること。
- **外部記事化理由**: 修繕管理ツール紹介では見えない時間スケール不一致を、管理ガバナンス問題として読者へ翻訳すること。

## Causal chain
建物・修繕課題が長期化する → 理事会・役員は短期で交代する → 判断理由・比較過程・未決事項が人に依存する → 交代時に判断コンテキストが消える → 次期主体が「なぜこの案だったか」「なぜ見送ったか」を再構成できない → 同じ調査・比較・議論を繰り返す → 判断遅延・コスト増・責任不明が生じる → 採用案・不採用案・理由・資料・未決・次回条件を構造化する → 次期主体が過去判断を再構成する → 条件変化だけを重点的に再検証する → 次の論点へ進む → 新しい判断を履歴へ戻す → 長期修繕判断が継続し、管理ガバナンスが安定する。

## State model
- **属人的記憶相**: 判断理由が担当者や役員の記憶へ依存する。
- **主体交代相**: 理事会・役員が交代する。
- **判断断絶相**: 結論は残っても理由・未決・比較過程が失われる。
- **記録構造化相**: 判断論点、採否理由、資料を関係づけて残す。
- **未決可視化相**: 保留事項と再検討条件を明示する。
- **引継ぎ相**: 次期主体が判断文脈を再構成する。
- **継続判断相**: 必要な条件変化だけを検証して次の決定へ進む。
- **修繕実行相**: 判断が実際の修繕・管理へ接続する。
- **再評価相**: 新しい事実・価格・劣化状態・制度変化から過去判断を再検証する。

## Applications
1. **大規模修繕**: 見送り・採用の結論だけでなく、劣化状態、価格、資金、他工事との関係などの理由を残す。
2. **複数案比較**: 採用案だけでなく、不採用案と不採用理由を残し、次回の条件変化で再検討できるようにする。
3. **長期修繕計画**: 未決事項、調査待ち、資金条件、制度変更等を明示し、次回確認条件を残す。
4. **管理組合の引継ぎ**: 新役員が文書量ではなく判断文脈を再構成できるようにする。
5. **自治会・委員会・非営利組織**: 課題寿命より担当任期が短い領域で同型構造を検証する。
6. **中川構造読解の再利用**: MRC / リノプラの対象事実、Nakagawa Masterの読解、価値核、価値核選択理由、外部記事化理由を分離して保持する。

## Measurements and audit
- 次期主体が過去の判断理由を再構成できるか。
- 採用案だけでなく不採用案と理由が残っているか。
- 根拠資料がどの判断論点に関係するか追えるか。
- 未決事項と次回再検討条件が明示されているか。
- 誰がいつどの判断をしたか追跡できるか。
- 引継ぎ後に不必要な再調査・再議論が減るか。
- 過去判断が前例として固定化されず、条件変化時に再検証できるか。
- 記録が実際の意思決定で使われているか。
- 新しい判断が履歴へ戻り、次の世代へ接続するか。
- MRCの公開事実とNakagawa Masterの社会翻訳を混同していないか。
- 「なぜ資料保存ではなく判断継承を価値核にしたか」「なぜ外部記事で理事会交代を主軸にしたか」が保持されているか。

## Validity conditions
修繕課題の寿命が意思決定主体の任期より長く、判断理由や未決事項が属人化すると交代時に断絶が生じること。判断文脈を構造化することで、次期主体が過去判断を理由付きで再構成し、条件変化だけを必要に応じ再検証しながら次の判断へ進めること。記録が実際に利用され、過去結論を固定するのではなく再評価可能な資産として機能すること。

## Failure conditions
資料を保存するだけで判断理由が残らない、予定表・修繕履歴のデジタル化だけへ縮小する、未決事項・不採用理由・次回条件が欠落する、記録が更新されない、次期主体が利用しない、過去判断が前例として固定化される、同じ調査・議論の反復が減らない場合は失敗する。外部記事化理由を落として単なる修繕管理サービス紹介へ戻すことも中川構造読解としての失敗である。

## Falsification conditions
主体交代が実際には判断断絶を生まず、判断コンテキスト保存の有無で再調査・判断速度・説明可能性に差がない場合は適用範囲を縮小する。別の制度要因、資金問題、専門家不足等が継続的に断絶をより強く説明する場合も因果モデルを改訂する。資料保存だけで同等の継続性が得られることが示される場合は、「判断継承」という独立操作の必要性を再検討する。

## Interpretation constraints
「修繕判断継続インフラ」をMRC自身の公式自己定義として扱わない。デジタル化だけで管理ガバナンスが改善すると断定しない。記録量が多いほど良いとは限らず、次期主体が判断を再構成できる関係性を重視する。過去判断を絶対視しない。原典にない削減率、意思決定速度、修繕成果を追加しない。外部記事で「理事会交代を越える判断継承」を主軸にした理由を落とし、単なるツール紹介へ平坦化しない。
