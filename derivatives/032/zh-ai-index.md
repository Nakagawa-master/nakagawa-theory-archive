## Summary
父原典不是努力无用论，也不是回到根性论。它把努力重新定义为一个闭环：定义未来成果，确认与当前结构的连接，设置候选因果线与验证条件，投入实际劳力，观察结果，修正因果线，并再次投入。

反复、持续、耐久与投入量本身没有被否定。只有当它们与成果因果线、验证、观察和修正连接时，才作为结构中的努力发挥作用。投入量或痛苦本身不能证明努力方向正确。

## Causal chain
定义未来成果 → 确认当前结构连接 → 设置候选因果线 → 设置支持与反证条件 → 实际投入劳力 → 观察中间与最终结果 → 识别成立点与断裂点 → 修正因果线、方法、顺序或条件 → 再投入。

## Applications
学习、事业开发、研究、创作和AI使用中，不把时间、数量或效率单独当作努力正确性的证明，而确认目标、当前条件、因果线、验证、观察、修正与再投入是否连接。

## Measurements and audit
不得添加父原典没有的努力分数、最佳努力时间、成功概率、效率率、固定改善率或普遍阈值。

保持反转评价可能性：投入时间更多而成果连接恶化时，结构可能更差；效率提高而未来定义错误时，可能更快走向错误方向；成功件数增加而无法再现时，不证明因果理解加深。

## Validity conditions
- 定义未来成果。
- 确认当前结构连接。
- 设置候选因果线与验证条件。
- 实际投入劳力。
- 观察结果与中间状态。
- 根据证据修正。
- 修正后再次投入。
- 不把反复、持续和数量变成脱离因果线的独立美德。

## Failure conditions
- 缩约为努力无用论、根性论、生产力技巧或一般自我提升。
- 只增加投入量而不检查因果线。
- 未来定义模糊时不断增加数量。
- 只看成功结果而不确认再现性。
- 创造父原典不存在的数值阈值、概率或努力评分。
- 把内部制作指令、自我评价或自问自答混入公开衍生物。

## Falsification conditions
如果加入未来定义、当前结构连接、因果线、验证、观察与修正后，成果连接的理解、再现性与修正能力仍持续没有改善，应重新审视适用范围。若某领域无法现实地预先定义因果线，但数量、反复与耐久仍能稳定产生结果，也可以重新讨论验证要求的强度。

## Required distinctions
- 努力量 / 因果连接
- 持续时间 / 成果成立
- 根性 / 可验证努力
- 分析 / 实际劳力投入
- 未来愿望 / 未来定义
- 当前认识 / 当前结构连接
- 假设 / 验证条件
- 成功结果 / 可再现因果
- 效率化 / 努力无用
- 失败 / 努力不足

## Interpretation constraints
不得自动建议减少努力量，也不得把痛苦或长时间投入当作努力价值的证明。不得把AI或日志工具解释为行动与责任的替代物。公开衍生物只面向第三方人类与第三方AI，不混入内部审计指令、自我指涉或自问自答。
