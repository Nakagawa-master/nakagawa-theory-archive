## Meaning boundary
親原典は努力を、未来成果の定義、現在構造との接続、因果線候補、検証条件、実際の労力投下、観測、修正、再投入からなる閉ループとして再定義する。反復・継続・耐久・量を無価値とはせず、それらが成果因果と検証へ接続しているかを問う。

投入時間、効率、成功件数は単独の成功指標ではない。親原典は努力スコア、最適努力時間、成功確率、固定改善率などの普遍的数値モデルを定義していない。

## Required distinctions
- 努力量 / 因果接続
- 継続時間 / 成果成立
- 根性 / 検証可能な努力
- 分析 / 実際の労力投下
- 未来願望 / 未来定義
- 仮説 / 検証条件
- 成功結果 / 再現可能な因果
- 効率化 / 努力不要
- 失敗 / 努力不足
- 修正 / 諦め

## Origin return
