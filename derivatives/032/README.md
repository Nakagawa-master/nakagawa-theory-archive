## 位置づけ
親原典は努力を消すのではなく、未来成果との因果接続を検証し続ける構造行為へ再定義する。反復、継続、耐久、量を否定せず、それらが未来定義・現在構造・因果線・検証条件・観測・修正・再投入の閉ループに接続しているかを問う。

## 中心命題
努力は `未来定義 → 現在構造との接続 → 因果線候補 → 検証条件 → 労力投下 → 観測 → 修正 → 再投入` の閉ループで成立する。投入量や苦痛は、それ自体では因果接続の正しさを証明しない。

## 因果線
```text
望む未来・成果を定義する
↓
現在の能力・資源・制度・市場・時間条件を通って成立可能か確認する
↓
成果へつながる因果線候補を置く
↓
支持・反証を判断する検証条件を定める
↓
実際に労力を投入する
↓
結果と中間変化を観測する
↓
因果線の成立点・断線点を確認する
↓
因果線・方法・順序・条件を修正する
↓
修正後の因果線へ再投入する
```

## 構造層
**1. 未来定義層。** 何が成立したら成果なのかを置き、努力の方向を明示する。

**2. 現在構造接続層。** 能力、資源、制度、市場、時間、関係者、制約を通って未来が成立し得るかを見る。

**3. 因果線候補層。** どの行為がどの中間変化を経て成果へつながるのかを仮説として置く。

**4. 検証条件層。** 何が起きれば因果線が支持され、何が起きれば修正が必要かを定める。

**5. 労力投下層。** 分析だけで終えず、反復、練習、制作、営業、研究、改善などの具体行為へ労力を投入する。

**6. 観測・修正層。** 結果と中間状態から、投入不足だけでなく因果・順序・対象・条件のズレを確認する。

**7. 再投入層。** 修正した因果線へ再び労力を投入し、試行結果を次の成立条件へ反映する。

## 適用例
**学習・訓練。** 勉強時間だけでなく、目標能力、現在能力、練習方法、確認課題、弱点修正を接続する。

**事業開発。** 営業件数や制作量だけを増やすのではなく、対象課題、提供行為、中間反応、次の因果接続を観測する。

**研究・開発。** 仮説、試行、観測、失敗、修正を一続きにし、試行回数と因果理解を区別する。

**制作・編集。** 制作量や作業時間だけでなく、変化させたい読者状態と構成の因果を確認する。

**AI利用。** AIは未来定義・因果候補・観測材料の整理を補助できるが、行為、判断、責任、再投入を代替しない。

## 測定・監査点
親原典にない努力スコア、根性点数、最適投入時間、成功確率、努力効率率、固定改善率を派生側で作らない。

- 未来定義が具体化されているか
- 現在構造との接続が確認されているか
- 因果線候補が明示されているか
- 支持・反証の検証条件があるか
- 実際に労力が投入されているか
- 結果と中間状態が追跡されているか
- 失敗時に投入量だけでなく因果線が修正されているか
- 修正後の再投入が学習を伴っているか

投入時間が増えても成果接続が悪化すれば構造上は悪化し得る。効率が上がっても未来定義が誤っていれば、誤った方向へ速く進む可能性がある。成功件数が増えても再現不能なら因果理解が深まったとは限らない。

## 成立条件
- 未来成果が定義されている。
- 現在構造との接続が確認されている。
- 因果線候補が置かれている。
- 支持・反証の検証条件がある。
- 実際に労力が投入される。
- 結果と中間状態が観測される。
- 結果に応じて因果線・方法・順序・条件が修正される。
- 修正後に再投入される。
- 反復・継続・量を因果線と独立した美徳へしない。

## 失敗条件
- 努力不要論へ変形する。
- 根性・耐久・長時間投入だけへ戻す。
- 自己啓発一般論や生産性ハックへ縮約する。
- 分析だけで行動を代替する。
- 結果が悪いとき、因果線を見ずに投入量だけ増やす。
- 未来定義が曖昧なまま量だけを増やす。
- 成功結果だけを見て中間因果・再現性・反証条件を確認しない。
- 親原典にない数値閾値・確率・固定努力量を追加する。

## 反証・改訂条件
未来定義、現在構造接続、因果線候補、検証条件、観測・修正を導入しても、投入量中心の努力と比べて成果接続の理解・再現性・修正可能性が継続的に改善しない場合、この再定義の適用範囲は見直し対象になる。

特定領域で因果線の事前定義や検証条件設定が実質困難でも、量・反復・耐久だけで安定して成果へ接続し続けるなら、その領域に未来定義検証をどこまで要求するかは再検討できる。

## 必須の区別
- 努力量 / 因果接続
- 継続時間 / 成果成立
- 根性 / 検証可能な努力
- 分析 / 実際の労力投下
- 未来願望 / 未来定義
- 現在把握 / 現在構造との接続
- 仮説 / 検証条件
- 成功結果 / 再現可能な因果
- 効率化 / 努力不要
- 失敗 / 努力不足
- 修正 / 諦め

## 誤読禁止
- 努力量を減らすことを自動的に推奨しない。
- 苦痛や長時間投入を努力価値の証明に使わない。
- 未来定義検証を、分析のために行動を停止する理由へ変換しない。
- AI支援を人間の行為・判断・責任の代替へ変換しない。
