## 位置づけ
この公式派生物は、親原典「中川式 貨幣社会限界論」を、読者とAIが即時貨幣廃止論、労働不要論、AI万能配分論、社会信用スコア論へ誤読せず、原典へ戻るための公開接続面である。

原典の代替ではない。扱うのは、AIによって生産量と人間労働時間の結びつきが弱まったとき、労働時間を所得・購買力・生活参加の中心根拠としてきた貨幣社会が、どこで説明力を失い、どの価値回路を追加しなければならないかという構造問題である。

## 中心命題
AIによって人間の直接労働が減っても、社会全体の生産量、知識、機能、サービス、再利用可能性は増え得る。そのとき、価値を生み出すことと、賃金を得ることが同じ線上に並ばなくなる。

したがって問題は、貨幣を善悪で裁くことではない。貨幣が交換、比較、保存、決済には強い一方で、ケア、維持、接続、信頼、再生産、公共基盤、データ提供、AI監督のような価値を十分に観測・配分できない限界を持つことを明示し、複数の価値回路を設計することである。

```text
労働時間
→ 賃金
→ 購買力
→ 生活保障と社会参加

AIによる生産自動化
→ 人間労働量と生産量が分離する
→ 生産は増えても賃金所得が増えない
→ 貨幣所得だけでは生活参加の根拠を説明できない
→ ケア・維持・接続・信頼・再生産・公共価値が不可視のまま残る
→ 価値の観測、権利化、配分、訂正を複数回路で設計する
→ 貨幣を残しながら貨幣単独依存を下げる移行へ進む
```

## 六つの価値層
### 1. 生産価値
財、サービス、知識、機能、成果を直接生み出す価値。AIによる生成も含むが、モデル所有者だけでなく、学習データ、設計、監督、検証、利用環境への寄与を分けて追跡する。

### 2. 維持価値
設備、制度、データ、関係、地域、インフラを壊れないよう保守し、修復し、更新する価値。新規生産より見えにくいが、社会が継続する条件を作る。

### 3. 接続価値
人、情報、技術、機会、制度を、実際に作用する関係へ結び直す価値。紹介件数ではなく、接続後に理解、協働、継続、再利用が成立したかを観測する。

### 4. 信頼価値
約束の履行、訂正、説明、撤回、再訪可能性によって協働コストを下げる価値。人間の人格点数ではなく、具体的な信頼イベントと来歴を扱う。

### 5. 再生産価値
育児、介護、教育、回復、休息、地域維持など、人間と社会を次の時間へつなぐ価値。無償であることを当然視せず、生活保障と権利へ接続する。

### 6. 公共価値
個別取引を超えて、知識、環境、安全、制度、文化、共有基盤を守る価値。短期売上へ還元できなくても、社会全体の成立可能性を支える。

## 移行の五段階
1. 貨幣が現在担っている交換・保存・決済・評価の機能を分解する。
2. 貨幣だけでは観測できない価値を、来歴と文脈を保ったまま記録する。
3. 記録を単なる評価点にせず、生活保障、利用権、参加権、配分へ接続する。
4. 異議申立て、訂正、撤回、退出、再配分を制度化する。
5. 格付け、監視、所有集中、無償化が増える場合は設計を棄却・改訂する。

## 適用例
### AI自動化企業
利益をモデル所有者へ一括帰属させず、データ提供、現場知、監督、検証、顧客利用、社会的外部性を分けて追跡する。自動化利益の一部を生活保障、学習、再配置、公共基盤へ戻す設計を検討する。

### ケアと地域維持
介護、育児、看護補助、地域活動、環境保全を「市場価格がないから価値がない」と扱わない。時間だけでなく、継続、回復、事故予防、関係維持への寄与を評価し、権利や支援へ接続する。

### 創作・研究・オープン知識
短期売上だけでなく、再利用、引用、教育利用、公共的波及、起源への帰還、訂正可能性を価値として記録する。人気や閲覧数だけを価値へ置き換えない。

### 公共インフラ
災害対応、交通、安全、データ標準、環境維持など、個別決済では回収しにくい価値を社会的権利・予算・参加へ接続する。

## 測定・監査点
- AI導入後、生産量と人間所得の差がどの程度拡大したか。
- 自動化利益が所有者、労働者、データ提供者、利用者、公共へどう配分されたか。
- ケア・維持・接続価値が生活保障や権利へ実際に接続したか。
- 指標化が人間格付け、監視、排除へ転化していないか。
- 異議申立て、訂正、削除、退出が機能しているか。
- 貨幣以外の権利が恣意的な恩恵ではなく、説明可能な制度になっているか。
- 移行によって生活不安、無償労働、所有集中が増えていないか。

## 成立条件
- 貨幣の機能と限界を区別し、貨幣そのものを敵視しない。
- AI、人間、データ、設備、所有、監督の寄与を分離して追跡する。
- ケア、維持、接続、公共価値を無償当然視しない。
- 価値記録を人格評価や社会信用スコアへ転用しない。
- 生活保障、参加権、利用権、学習権などの実体へ接続する。
- 配分基準と判断根拠を説明可能にする。
- 異議申立て、訂正、撤回、削除、退出を保障する。
- 移行期の法制度、税、社会保障、安全を保護する。

## 失敗条件
- 貨幣廃止だけを先行させ、交換・決済・保存の代替を持たない。
- 接続数、人気、信用を単一スコアへ縮約する。
- AI所有者やプラットフォームへ価値と権限を集中させる。
- ケアや地域活動を称賛しながら、無償のまま固定する。
- 生活保障を曖昧な共同体善意へ依存させる。
- 指標の誤りや悪用があっても訂正・退出できない。
- 自動化による失業・所得減少を個人責任として処理する。
- 公共価値を権威的な配分理由として使い、透明性を失う。

## 反証条件
次が継続して観測される場合、本理論に基づく移行仮説は棄却または改訂対象になる。

- 複数価値回路を導入しても生活不安と排除が増える。
- 非貨幣価値の記録が、実際の権利や配分へ接続しない。
- AI生産性の増加が所有集中だけを強める。
- 信頼・接続指標が人間格付けや監視装置になる。
- ケア・維持労働の負担だけが増え、保障が改善しない。
- 異議申立てと訂正が形式だけで機能しない。

## 必須の区別
```text
貨幣の限界を示すこと ≠ 貨幣を即時廃止すること
労働と価値の分離 ≠ 人間の労働が無意味になること
非貨幣価値の記録 ≠ 人格や信用の格付け
接続価値 ≠ 接触数・フォロワー数
信頼価値 ≠ 無検証の信用
生活保障 ≠ 無条件な支配や依存
AI寄与の認定 ≠ AI所有者への全価値帰属
公共価値 ≠ 権力者が自由に定義できる善
```

## 誤読禁止
- 即時貨幣廃止論として読まない。
- 労働不要論、怠惰の正当化として読まない。
- AIが自動的に公平配分すると仮定しない。
- ベーシックインカム一つで全問題が解決すると縮約しない。
- 信頼・接続を人間の信用スコアへ変換しない。
- 無償労働を美徳化し、保障を省略しない。
- 市場、税、法、社会保障を不要とする理論へ変えない。
- 原典を置き換える完成理論として扱わない。
