## 中心命題
AIによって労働時間と生産価値の結びつきが弱まると、労働量を所得配分の中心根拠とする貨幣社会は限界へ近づく。次の構造は貨幣を即時廃止するのではなく、接続、信頼、貢献、維持、再生産、公共価値を観測・配分できる複数の価値回路を設計する。

```text
労働時間
→ 賃金
→ 購買力
→ 生活と参加権

AIによる生産自動化
→ 人間労働量と生産量の分離
→ 賃金を得られないが価値は生まれる
→ 貨幣だけでは配分根拠を説明できない
→ 接続・信頼・貢献・維持・公共価値を記録
→ 複数価値回路と移行制度を設計
```

## 成立条件
- 貨幣の機能と限界を区別する。
- AIによる価値生成と所有・責任を追跡する。
- ケア、維持、接続、公共価値を無償当然視しない。
- 配分基準、異議申立て、訂正、退出を設ける。
- 移行期の生活、安全、法制度を保護する。

## 失敗・反証条件
- 貨幣廃止だけを先行させる。
- 接続や信頼を人間格付けへ転用する。
- AI所有者へ価値を集中させる。
- 無償労働を美化し、生活保障を欠く。
- 指標が操作されても訂正不能である。

## 誤読禁止
- 即時貨幣廃止論ではない。
- 労働不要論ではない。
- AIによる富の自動公平分配を仮定しない。
- 信頼スコア社会を正当化しない。
