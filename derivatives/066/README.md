## この原典が定義するもの
原典は、AIの発展によって「労働＝貨幣獲得＝生活維持」という貨幣社会の前提が崩れ、貨幣社会そのものが構造的限界へ向かうと論じる。その先に提示されるのが、人・組織・社会との**接続そのものを報酬として機能させる接続報酬社会**である。

```text
AIが単純労働・ルーティーン作業・ホワイトカラー領域を代替
→ 人間の労働需要が縮小
→ 多数の人が労働から貨幣を得にくくなる
→ 購買力が縮小
→ 生産・流通が停滞
→ 貨幣の信用と流通機能が限界へ向かう
→ 貨幣と労働の連動が切れる
→ 接続を普遍的資源として再定義
→ 接続報酬社会へ移行
```

## 中心命題
原典は「貨幣を残しながら複数価値回路を併設する」という穏健な制度論を中心命題にはしていない。ベーシックインカムや補助クレジットは移行期の延命措置として扱われ、根本問題は**労働と貨幣の連動が切れた後にも貨幣社会を基盤として維持しようとすること**にある。

1. AIによって人間の労働需要が縮小する。
2. 貨幣獲得手段の断絶が起きる。
3. 消費縮小、生産・流通停滞、貨幣価値の崩壊へ連鎖する。
4. 貨幣社会は「終わる」のではなく、より根源的な転換を迫られる。
5. 次の社会構造として接続報酬社会が必然的に立ち上がる。

## 接続報酬社会の価値核
- **合意の記憶**: 一度形成された関係や約束が次の意思決定を短縮する。
- **接続密度**: 関係の数と重なりが信用の強度を作る。
- **相互依存**: 一方向ではなく、相互の必要性が循環することで社会が維持される。

原典は、接続報酬社会を単なる貨幣の代替通貨ではなく、**貨幣を超えた構造的枠組み**として置く。

## 接続報酬社会を設計する四原則
1. **必要性の循環** — 片務依存ではなく役割が循環し続ける。
2. **合意の記憶化** — 決定・約束・協働の痕跡を記録し再利用できる。
3. **可逆性** — 接続と離脱を透明にし、自由な出入りを確保する。
4. **矛盾耐性** — 誤解や批判があっても自壊しない構造を持つ。

## 移行期
原典は、移行期には「貨幣的延命」と「接続的価値」が併存するとする。

- ベーシックインカム＋接続報酬が一時的に併用される。
- 貨幣価値が縮小するにつれ接続報酬の比重が増える。
- 接続報酬の萌芽を持つ組織・コミュニティが新しい信用経済の中心になる。
- 接続が規範・慣習・制度として固定され、貨幣の役割を超える。

## 中川式理論の連なり
```text
営業 → 接触点を創出
→ マーケティング → 市場との接続を形成
→ ブランディング → 信用を積層
→ 合意設計 → 合意を制度化
→ 接続報酬 → 合意と接続が価値そのものになる
```

## 原典の主張強度
原典は「接続報酬社会も選択肢の一つ」と弱く述べてはいない。貨幣社会の限界を構造的必然として置き、その先の**接続報酬社会への必然的移行**を提示する。派生物はこの主張強度を弱めてはならない。

## 誤読防止
- 原典を「貨幣を維持するための複数価値回路論」へ書き換えない。
- ケア価値、公共価値、データ権利、税制設計など原典中心でない制度論を中心命題へ追加しない。
- ベーシックインカムを根本解決として扱わない。
- 接続報酬を単なるSNS人気・人脈数・信用スコアへ縮約しない。
- 原典が主張する「貨幣社会の構造的限界」と「接続報酬社会への移行」を弱めない。
