## 15秒説明
AIが人間の労働を広く代替すると、「働く→貨幣を得る→生活する」という貨幣社会の前提が崩れます。原典は、その限界の先に、接続そのものが価値と報酬になる**接続報酬社会**への移行を提示します。

## なぜ貨幣社会が限界へ向かうのか
原典はAIの影響を三段階で描きます。

- 単純労働の代替
- ルーティーン作業の代替
- ホワイトカラー領域の侵食

これによって人間の労働需要が縮小すると、多くの人が労働から貨幣を得ることが難しくなります。すると、購買力の低下、需要縮小、生産・流通停滞、貨幣信用の低下へ連鎖します。

```text
AI発展
→ 人間労働需要の縮小
→ 貨幣獲得手段の断絶
→ 消費縮小
→ 生産・流通停滞
→ 貨幣価値の機能不全
→ 貨幣社会の構造的転換
```

## ベーシックインカムは解決か
原典では、ベーシックインカムやクレジット付与は移行期の延命措置として扱われます。生活を支える意味はありますが、**労働と貨幣の連動が切れた**という根本問題そのものを解決するものではない、という位置づけです。

## 次に来る構造
原典が提示するのは接続報酬社会です。

**接続報酬**とは、人・組織・社会とのつながりそのものが報酬として機能する仕組みです。

接続が価値を生む理由として、原典は次を挙げます。

- **合意の記憶**: 一度形成した関係や約束が次の意思決定を短縮する。
- **接続密度**: 関係の数と重なりが信用の強度になる。
- **相互依存**: 必要性が一方向ではなく循環することで社会が維持される。

## 四つの設計原則
1. 必要性の循環
2. 合意の記憶化
3. 可逆性
4. 矛盾耐性

特に可逆性は、接続と離脱が透明で、強制や囲い込みではなく自由な出入りを持つことを意味します。

## 移行は一気に起きるのか
原典では移行期に貨幣と接続報酬が併存します。

```text
貨幣的延命 + 接続的価値
→ 接続報酬の比重が増える
→ 組織・コミュニティが新しい信用経済の中心になる
→ 接続が規範・慣習・制度として固定される
→ 貨幣の役割を超える
```

## 中川式理論の最終段
原典は、営業→マーケティング→ブランディング→合意設計という理論の連なりを社会スケールへ拡張します。

- 営業: 接触点を作る
- マーケティング: 市場との接続を形成する
- ブランディング: 信用を積層する
- 合意設計: 合意を制度化する
- 接続報酬: 合意と接続そのものを価値にする

## 誤読防止
- 「貨幣を残し続ける複数価値回路論」へ弱めない。
- ケア、公共価値、税、データ権利などを原典の中心命題として追加しない。
- ベーシックインカムだけで解決すると読まない。
- 接続報酬を人気投票やフォロワー数と同一視しない。
- 原典が主張する貨幣社会の限界と接続報酬社会への移行を保持する。
