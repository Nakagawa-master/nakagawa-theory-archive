## 1. Summary
父原典提出一个强结构假设：当AI替代广泛压缩人类劳动需求时，以劳动取得货币的路径会受压，并通过购买力、需求、生产流通与货币信用形成连锁压力。原典随后把以合意记忆、连接密度、相互必要性为价值核心的“连接报酬社会”作为结构性后继形态，并以强主张描述其转移。

## 2. Concepts
- 劳动—货币脱钩：劳动不再稳定承担主要货币取得路径。
- 货币社会结构限界：以工资参与为中心的社会基础受到结构压力。
- 连接报酬社会：连接本身发挥价值与报酬功能。
- 合意记忆：关系与合意历史支持后续判断。
- 连接密度：连接数量与重叠和信用强度之间的结构概念。
- 相互必要性：相互循环的必要关系，而非单向依赖。
- 四原则：必要性循环 / 合意记忆化 / 可逆性 / 矛盾耐性。
- 过渡延命：基本收入等桥接措施，不是父原典的最终结构答案。

## 3. Causal chain
```text
AI替代扩大
→ 人类劳动需求缩小
→ 通过劳动取得货币的路径缩小
→ 购买力缩小
→ 市场需求缩小
→ 生产与流通放缓
→ 货币信用与流通功能承压
→ 货币社会结构限界
→ 连接价值制度化
→ 父原典主张向连接报酬社会转移
```

## 5. Applications
- 劳动市场：把AI生产率与收入取得、需求共同观察。
- 过渡政策：区分桥接支持与结构价值转移。
- 社群：观察合意记忆、相互必要性和自由退出，而不是人气。
- 组织：读取销售→营销→品牌→合意设计→连接报酬的理论链。
- 社会假设检验：观察劳动需求、收入、需求与货币信用之间的关系是否成立。

## 7. Validity conditions
- AI替代实际连接到人类劳动需求缩小。
- 劳动收入缩小可观察地传导到购买力、需求和生产流通。
- 延命措施与结构价值转移保持区分。
- 连接报酬包含合意记忆、互惠和可逆性，而非人气评分。
- 连接与退出透明。
- 父原典的强未来主张与外部已确定事实保持区分。

## 8. Failure conditions
- AI替代扩大却不结构性降低人类劳动需求、货币收入路径或购买力。
- 劳动—货币脱钩后货币社会通过其他机制长期稳定。
- 连接报酬缩减为人气、粉丝数或中央社会信用评分。
- 连接成为强制、不可逆或单向依赖。
- 把基本收入提升为父原典的根本解决方案。
- 其他制度理论取代父原典中心因果。

## 9. Falsification conditions
- AI替代与人类劳动需求缩小的关系持续不成立。
- 劳动收入缩小后购买力、需求、货币信用仍长期稳定。
- 合意记忆、相互必要性、可逆性无法使连接价值产生社会功能。
- 连接增加反而与信用或社会功能恶化一致。
- 货币与连接价值长期稳定共存的证据削弱“必然转移”假设。

## 10. Required distinctions
- 父原典的必然转移主张 / 已确定未来事实
- AI替代三领域 / 性能分数或固定时间线
- 四原则 / 四分评价
- 连接密度 / 粉丝数
- 连接报酬 / 替代货币或人气积分
- 基本收入 / 根本解决
- 过渡共存 / 永久多价值回路理论
- 相互必要性 / 单向依赖
- 可逆性 / 锁定

## 11. Interpretation constraints
不得把父原典弱化成永久保留货币的多价值回路理论，也不得把“必然性”强化成派生物独立认证的预言。不得把连接报酬缩减为人气或信用评分，也不得把税制、数据权利、照护价值等其他制度理论添加为父原典中心主张。
