## 位置づけ
本派生物は、現在の便益のために将来世代へ押し出される環境・財政・制度・信頼の負債を可視化し、将来への整合行動を「信用資本」として評価する時間倫理の構造を整理する。将来価値を口実に現在の権利を犠牲にするのではなく、現在と将来の双方へ説明可能な負担配分を設計する。

## 中心命題
社会の信用は現在の履行だけでなく、未来へどの負債を残し、どの回復可能性を残したかによって形成される。将来コストを不可視化すると短期最適化が報酬され、負債が累積する。将来負債を測定し、責任主体、期限、回復経路、可逆性を付与し、将来整合的な行動を評価・報酬することで、時間をまたぐ信用資本へ転換できる。

## 因果線
短期便益を優先 → 将来コストを外部化 → 負債が見えないまま累積 → 現在の成果だけが評価 → 将来の選択肢が縮小 → 将来負債を計測 → 責任・期限・回復路を割当 → 長期整合行動を信用として評価 → 将来世代の可動域を回復。

## 構造層
1. 時間配分層：現在便益と将来負担を分離する。
2. 負債層：財政・環境・制度・信頼の残存負担を可視化する。
3. 責任層：誰がいつまでに何を回復するかを定義する。
4. 信用層：将来整合的な行動を評価資本へ変換する。
5. 監査層：世代間の権利・可逆性・実績を再評価する。

## 適用例
1. インフラ更新で建設費と将来維持費を同じ意思決定表に載せる。
2. 気候政策で排出削減と移行負担を世代別に監査する。
3. 企業経営で短期利益と技術負債・人材負債を別台帳化する。
4. 公共財政で将来世代の可動域を予算評価に組み込む。

## 測定・監査点
将来負債残高、回復期限遵守率、可逆性、世代別負担差、信用改善率、将来選択肢保持率、是正実行率。

## 成立条件
将来負債を具体化する。現在の権利も保護する。責任主体を明示する。期限と回復経路を持つ。複数シナリオを置く。定期再監査する。

## 失敗条件
未来を理由に現在を無制限犠牲にする。将来コストを無主語化する。単一割引率で倫理判断を終える。責任期限を置かない。回復不能な施策を無監査で進める。信用指標を宣伝に使う。

## 反証条件
将来負債の可視化が意思決定改善に寄与しない。長期整合評価が実際の負債低減と相関しない。より単純な財務指標で同等以上に将来選択肢を保てる。信用資本評価が操作される。世代間公平を悪化させる。

## 必須の区別
未来配慮/現在犠牲、負債/費用、信用資本/評判、予測/確定、可逆性/先送り、世代間公平/同額負担、長期/無期限。

## 誤読禁止
未来世代の代理人を絶対化しない。財政赤字をすべて悪としない。環境問題だけに限定しない。短期成果を全面否定しない。信用資本を通貨と同一視しない。派生を政策決定の代替にしない。
