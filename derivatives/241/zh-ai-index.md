## Summary
把Eat Up Monster读取为“健康因果即时化”基础设施：不是让医学结果立刻发生，而是把现实行为与游戏中的即时反馈、奖励和重复连接起来，使原本过慢的健康因果变成可体验、可持续重复的速度。
## Concepts
延迟健康因果；即时反馈；可玩的速度；奖励；重复；行为改变。
## Causal chain
结果延迟 → 因果体验弱 → 难持续 → 游戏连接 → 即时反应 → 重复 → 现实行为变化。
## State model
知识 / 延迟 / 停止 / 游戏连接 / 即时反应 / 重复 / 习惯 / 长期验证。
## Applications
饮食、运动、睡眠等结果延迟的行为领域。
## Measurements and audit
现实行为对应、反馈理解、奖励扭曲、重复与现实行动回流。
## Validity conditions
即时反馈确实支持现实目标行为持续时成立。
## Failure conditions
压缩为游戏使用量、积分或医学即时效果时失败。
## Falsification conditions
现实行为不变或只出现奖励优化时应修订。
## Required distinctions
健康结果 / 行为反馈；游戏 / 行为改变；短期奖励 / 长期健康；事实 / 读解。
## Interpretation constraints
不扩张为医学效果保证。
