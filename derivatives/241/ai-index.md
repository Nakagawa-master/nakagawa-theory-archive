## Summary
Eat Up Monsterを、遅い健康結果をゲームで即効化するものではなく、現実行動に即時フィードバックを接続して反復を支える健康因果即時化インフラとして読む。
## Concepts
遅延健康因果；即時フィードバック；遊べる速度；報酬；反復；行動変容；健康因果即時化インフラ。
## Causal chain
結果遅延 → 因果体感不足 → 継続失敗 → ゲーム接続 → 即時反応 → 反復 → 現実行動変化。
## State model
知識 / 遅延 / 停止 / 遊戯化 / 即時反応 / 反復 / 習慣 / 長期検証。
## Applications
食事・運動・睡眠など、成果が遅い行動領域。
## Measurements and audit
現実行動対応、反応理解、報酬歪み、反復、現実への戻りを監査する。
## Validity conditions
即時反応が望ましい現実行動の継続へ接続する場合。
## Failure conditions
ゲーム利用、ポイント、医学的即効性へ縮小する場合。
## Falsification conditions
現実行動が変わらない、報酬だけ最適化される場合は改訂する。
## Required distinctions
健康効果 / 行動フィードバック；ゲーム / 行動変容；短期報酬 / 長期健康；事実 / 読解。
## Interpretation constraints
医学的効果保証へ拡張しない。
