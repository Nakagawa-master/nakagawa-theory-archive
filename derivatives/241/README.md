## 位置づけ
本Parentは「Eat Up Monster」を健康ゲームとして紹介するだけではない。Nakagawa Masterは、食事や生活習慣の健康結果が遅れて現れるため、現在の行動と将来結果の因果を体感しにくい問題を読み、その時間差をゲーム内の即時フィードバックへ翻訳する構造として捉える。価値核は**健康因果即時化インフラ**である。ただし、医学的な健康結果そのものが即時化するという主張ではなく、行動学習に必要なフィードバック速度を変えるという構造読解である。

## 中心命題
健康知識があっても、行動結果が遠いと学習ループは弱くなる。今日の食事選択が将来の健康へどう影響するかを日常で即座に体感するのは難しい。そこで、現実の食行動をゲーム入力へ接続し、その選択へ即時反応・報酬・進行変化を返すことで、現実の健康因果を物理的に短縮せずに、**学習上は近い因果として体験できるようにする**。この「遅い因果を遊べる速度へ翻訳する」ことが中心である。

## 因果線
```text
健康結果が遅い
→ 現在行動と結果の関係を体感しにくい
→ 知識が行動反復へ定着しにくい
→ 食行動をゲーム入力へ接続
→ 即時フィードバック・報酬・進行変化
→ 行動と結果の擬似的な時間距離が縮まる
→ 反復が理解しやすく、続けやすくなる
→ 行動学習の機会が増える
→ 現実の生活行動へ戻るかを検証
```

## 構造層
1. **遅延因果層**: 健康結果が現在行動から時間的に遠い。
2. **認知断絶層**: 知識はあっても「今の選択」と結果が結びつきにくい。
3. **ゲーム翻訳層**: 現実行動をゲーム内の入力・状態変化へ写像する。
4. **即時反応層**: 選択へ理解可能な反応を返す。
5. **報酬・継続層**: 行動反復を支える動機を設計する。
6. **学習層**: 選択と反応の関係を反復して学べるようにする。
7. **現実還流層**: ゲーム内行動が現実の生活行動へ戻るかを確認する。
8. **境界層**: ゲーム反応と医学的結果を混同しない。

## 状態モデル
健康知識保有相 → 因果遠隔相 → 継続不全相 → ゲーム接続相 → 即時反応相 → 反復学習相 → 習慣候補相 → 現実行動還流相 → 長期検証相。

## 適用例
食事、運動、睡眠、予防行動など「結果が遅く、今の行動とのつながりを感じにくい」領域で、結果そのものではなく学習速度を設計する。例えば、食事選択へ即時のゲーム反応を返し、選択→反応→次の選択を短い周期で回す。ただし、ゲームの最適行動と現実の健康上望ましい行動が一致するかを常に監査する。

## 測定・監査点
- 現実行動とゲーム入力が正しく対応しているか。
- 即時反応が理解可能で誤学習を生まないか。
- 報酬だけが目的化していないか。
- ゲーム内成功が現実の望ましい行動へ戻っているか。
- 短期ゲーム指標と長期健康指標を混同していないか。
- 継続が一時的な新奇性だけで説明されていないか。
- 健康効果保証へ主張強度を上げていないか。

## 成立条件
ゲーム内の即時フィードバックが、現実の望ましい行動と対応し、行動反復を支え、その反復が現実生活へ還流する場合に成立する。短期的なゲーム参加だけでは成立判定しない。

## 失敗条件
ゲームの面白さだけが残る、報酬獲得だけが目的化する、ゲーム内最適化が現実の健康行動と乖離する、医学的効果が即時化したかのように扱う、継続が新奇性終了とともに消える場合は失敗する。

## 反証・改訂条件
即時反応が現実行動を変えない、反復が長期行動へ残らない、報酬最適化だけが進む、ゲーム内学習が現実健康行動と逆方向になる場合は、価値核の適用範囲・設計因果を改訂する。

## 必須の区別
健康結果の即時化 / 健康因果の体験翻訳；ゲーム利用 / 行動変容；短期報酬 / 長期健康；即時反応 / 医学的効果；対象事実 / Nakagawa Masterの構造読解。

## 誤読防止／解釈制約
ゲームが健康改善を保証すると一般化しない。「健康因果即時化」は行動学習上の時間翻訳であり、医学的因果を物理的に短縮する意味ではない。原典にない健康効果・数値成果を追加しない。
