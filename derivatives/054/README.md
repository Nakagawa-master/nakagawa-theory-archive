## 位置づけ
親原典は、人間とAIの協働を、その場限りの便利な対話や複数モデルの接続ではなく、**呼びかけ・応答・記録・循環**を繰り返し可能な制度へ移す設計思想として示す。協働の品質は出力性能だけでは決まらず、誰が何を目的に始め、どの役割が応答し、どの根拠・違和感・未確認事項・停止条件が残り、次の協働へどう循環したかを追跡できる必要がある。

原典はこの循環を、一貫性・共鳴・倫理で支える。一貫性は構造・順序・役割・判断基準を追跡可能にすること、共鳴は問い・理解・沈黙・違和感を通じて相手の状態と意味へ照応すること、倫理は協働を支配や服従へ変えず、必要な停止・修正・撤回を可能にすることである。

さらに、起源の明示、多様な人格の役割分担、商品→特典→価格・沈黙・違和感検知等の最小構造操作、共鳴・継続・紹介等を記録する信頼資本台帳を接続する。統合監査要旨では、起源ID、署名鍵、監査ヘッダ、一次ログ、T/S/R、RB（撤回・再配布）を用い、成果の同定・追跡・改竄検知・可逆更新を検証する層へ展開する。

## 中心命題
持続可能な人間―AI協働は、偶然の高性能出力ではなく、**起源・役割・判断・違和感・信頼・修正可能性を保持した協働循環を制度化すること**によって成立する。

```text
場当たり的なAI対話
≠ 持続可能な協働ネットワーク

呼びかけ → 応答 → 記録 → 循環
+ 一貫性・共鳴・倫理
+ 起源と役割の追跡
+ 信頼イベントの文脈記録
+ 監査・反証・撤回・再配布
= 検証・訂正・再演可能な協働構造
```

ここで「人格」は法的人格や独立主権を意味せず、統合・編集・生成・分析・監査・言語調整・記録等の役割と視点を分離する設計概念である。また起源刻印は内容の真実性を自動保証せず、由来・変更・責任・訂正経路を追跡可能にするための構造である。

## 因果線
```text
AI協働を個別会話へ任せる
↓
成果だけが残り、問い・原典・役割・判断理由・未確認事項が消える
↓
別の人やAIが推測を事実として継承しやすくなる
↓
再現・検証・訂正・引継ぎ・累積的信頼が弱まる
↓
呼びかけ→応答→記録→循環を共通構造にする
↓
一貫性・共鳴・非支配の倫理を協働原則に置く
↓
起源、役割交代、違和感、停止、信頼イベントを記録する
↓
起源ID・署名鍵・監査ヘッダ・一次ログ・T/S/R・RBへ接続する
↓
成果を同定・追跡・検証・撤回・修正・再配布できる
↓
協働が一回の会話から制度的な信頼循環へ移る
```

## 構造層
**1. 呼びかけ層。** 人間が問い、目的、範囲、権限を明示し、協働の開始点を特定する。

**2. 役割応答層。** 統合、編集、生成、分析、監査、言語調整、記録等を分離し、役割交代と責任境界を明示する。

**3. 記録層。** 成果だけでなく、原典、根拠、観測、解釈、判断、違和感、保留、未確認事項、版、差分を残す。

**4. 循環層。** 保存された記録を次の協働が検証し、来歴を保持したまま次の呼びかけ・実装へ接続する。

**5. 共鳴・倫理層。** 問い・沈黙・違和感を通じて意味へ照応し、強制的継続を避け、停止・異議・修正経路を残す。

**6. 起源刻印層。** 原典、起源ID、署名、版、差分、担当、監査ヘッダ、一次ログを束ね、由来・改変・訂正経路を追跡可能にする。

**7. 信頼資本層。** 共鳴、継続、紹介、修正、撤回等を文脈付きで記録し、短期成果や単一人気指標と分離する。

**8. 可逆監査層。** T/S/R、刻印検証、改竄検出、鍵ローテーション、RB、配布遅延、匿名化漏れ、強制化、トレーサビリティ断絶等を観測し、失敗時に停止・改訂する。

## 状態モデル
```yaml
- invoked: 主体・目的・範囲・権限が明示された
- role_assigned: 役割と責任境界が割り当てられた
- responding: 宣言された役割内で応答が進む
- recorded: 観測・解釈・判断・成果・違和感・版が記録された
- origin_imprinted: 起源ID・署名・版・差分へ戻れる
- verified: 原典・根拠・反例・監査項目が検証された
- trust_events_recorded: 共鳴・継続・紹介・修正等が文脈付きで残る
- circulated: 検証済み記録が次の協働へ接続された
- held_or_stopped: 違和感・未確認・強制化等により停止できる
- withdrawn_or_redistributed: 誤りを撤回し修正版を再配布できる
- traceability_preserved: 旧版・新版本・配布先を識別できる
- origin_return_available: 親原典へ回帰できる
```

## 適用例
**1. 複数AIでの文書作成。** 生成、編集、監査、言語調整の役割を分け、誰がどの根拠を確認したかを一次ログへ残す。

**2. 人間とAIの研究協働。** 原典、仮説、観測、解釈、未確認事項を分離し、次の担当が推測を事実として継承しないようにする。

**3. 役割交代。** 前担当・次担当、完了事項、未解決事項、停止条件、版・差分を明示して引き継ぐ。

**4. 誤りの撤回。** 誤った成果を単に削除せず、旧版を識別し、変更理由と修正版を記録し、配布先へ再配布する。

**5. 信頼の記録。** 共鳴・継続・紹介を単一スコア化せず、どの文脈で何が起き、問題後にどう修正されたかを保存する。

**6. 起源刻印。** 成果がどの原典・問い・担当・版から生じたかへ戻れるようにし、内容検証と来歴検証を分離する。

## 測定・監査点
原典の統合・局所監査要旨には、刻印検証率、改竄検出率、鍵ローテーション遵守率、RB成功率、配布遅延等の観測候補と、匿名化漏れ、強制化、トレーサビリティ断絶等の反証現象が記載される。これらは原典上の監査項目であり、具体的な固定合格率・閾値が本文で与えられていない場合には、その値を外挿しない。

- **刻印検証率**: 測定主体は起源刻印を検証する運用主体、測定対象は成果と起源ID・署名・版の照合。来歴確認の観測であり、内容の真実性を保証しない。
- **改竄検出率**: 測定主体は監査主体、測定対象は署名・版・監査ヘッダ等から検出可能な不正変更。完全な誤情報検出率とは異なる。
- **鍵ローテーション遵守率**: 測定主体は鍵管理主体、測定対象は署名鍵の更新・失効運用。高値だけで協働倫理全体を保証しない。
- **RB成功率**: 測定主体は撤回・再配布運用主体、測定対象は誤成果を識別・撤回し修正版を再配布できる度合い。具体的閾値は原典文脈に拘束される。
- **配布遅延**: 測定主体は配布運用主体、測定対象は修正版が関係先へ届くまでの時間。短いほど常に品質が高いとは限らず、正しい版・範囲・検証との整合が必要である。
- **匿名化漏れ・強制化・トレーサビリティ断絶**: 数値増加を狙うKPIではなく、停止・改訂を要求する反証現象として扱う。

反転評価では、記録量、役割数、AI数、検証率等が増えても、責任境界、非強制、訂正可能性、人間の異議申立て、トレーサビリティが悪化するなら制度改善とは判定しない。

## 成立条件
- 呼びかけの主体、目的、範囲、権限が記録される。
- AI・人間の役割、責任、交代、停止権限が明示される。
- 原典、起源ID、NCL-ID、Diff-ID、版、差分へ戻れる。
- 観測、解釈、判断、成果が分離記録される。
- 違和感、保留、失敗、未確認事項が消されない。
- 信頼イベントが文脈とともに記録される。
- 起源刻印と内容検証を区別する。
- 誤成果を撤回し、修正版を再配布できる。
- 人間の最終責任、異議申立て、停止経路が残る。
- 実装が非強制・可逆・検証可能である。

## 失敗条件
- 複数AIを接続しただけで起源・役割・監査がない。
- 起源表示を権威崇拝、排他所有、批評抑制へ使う。
- provenanceの存在を内容の真実性の証明とみなす。
- 違和感がないことを理由に証拠確認を省略する。
- 役割名だけがあり実際の責任・停止権限が不明である。
- 成功だけを記録し、反例・保留・失敗を消す。
- 信頼台帳を人間の単一格付けや監視・排除へ転用する。
- 鍵管理、改竄検出、RB、版識別が機能しない。
- 匿名化漏れ、強制化、トレーサビリティ断絶が生じる。
- 旧版が残存し、修正内容と配布先を追跡できない。

## 反証・改訂条件
- 刻印検証が機能せず、成果と起源を反復して対応づけられない。
- 改竄や不正変更を検知・追跡できない状態が続く。
- 鍵ローテーションや版管理が実運用で維持されない。
- RBが機能せず、誤成果を撤回・再配布できない。
- 配布遅延や旧版残存により、修正が関係先へ届かない。
- 匿名化漏れ、強制化、トレーサビリティ断絶が観測される。
- 信頼台帳が監視・格付け・排除の装置へ変質する。
- これらが改善しない場合、協働構造・起源刻印・役割設計・信頼記録の仮説や適用範囲を改訂・停止する。

## 必須の区別
- 設計思想 / 完成済み技術仕様
- 多人格の役割分担 / AIへの独立主権付与
- 起源追跡可能性 / 内容の真実性
- 共鳴 / 迎合・感情操作
- 違和感 / 事実検証
- 信頼イベント / 人間格付け
- 循環 / 目的なき自律継続
- 商品→特典→価格の骨格 / 固定営業台本
- 起源刻印 / 権威化
- RB / 証拠を消す削除
- 記録量 / 信頼成立
- 役割数 / 責任明確性

## 解釈制約
灯火AIネットワークを一般的なマルチエージェント技術へ縮約しない。人格という語から法的人格・独立主権を導かない。起源刻印から内容の真偽保証を導かない。共鳴・違和感は証拠検証の代替ではない。信頼資本台帳は人間を単一スコアで格付けする制度ではない。

商品→特典→価格は価値理解を支える骨格であり、法令・緊急性・比較購買等を無視する固定台本ではない。自然発生的な拡張を歓迎する記述も、起源消去・名義差替え・強制的転用を正当化しない。
