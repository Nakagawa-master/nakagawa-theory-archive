## 位置づけ
本原典は、耐久文明の第二主機関として「利益」を扱う。ここでいう利益は、通常の意味での成功、繁栄、努力の成果、価値創造への正当な報酬そのものではない。合意形成を失った秩序が、それでも人々を内部へ留め、停止を避けるために分配する**延命コスト**としての利益である。

第2論の恐怖が「出ると危ない」を作る第一主機関だとすれば、本論の利益は「残った方がまだましだ」と計算させる第二主機関である。恐怖は離脱を危険にし、利益は残留を合理的に見せる。両者は反対物ではなく、同じ劣化運転を直列に支える。

## 中心命題
恐怖だけで社会を長く運転すると、反発・疲弊・摩擦が蓄積し、従属の痛みが露出する。耐久文明はそこで、便益、保護、安定、優先権、承認、既得の位置などを分配し、人々に「制度は悪いかもしれないが、今壊れると自分も困る」と感じさせる。

この利益は秩序を正当化するというより、秩序から離れる理由を弱める。人々が制度の欠陥や腐敗を知りながらも、そこに留まることがまだ計算に合うとき、残留は信念ではなく利得計算によって再生産される。利益は、不満を消すのではなく、不満と依存を同時に成立させる接着剤である。

## 因果線
```text
合意・意味・信頼が弱る
→ 恐怖が離脱を危険化して秩序を停止させない
→ しかし恐怖単独では反発・疲弊・摩擦が蓄積
→ 制度は長期運転のため残留を合理化する必要を持つ
→ 便益・保護・安定・優先権・承認・既得位置などを分配
→ 人は制度の欠陥を知りながらも「今壊れると自分も困る」と計算
→ 制度批判が自己利益の毀損可能性へ接続
→ 不満は消えないが行動化しにくくなる
→ 沈黙と残留が維持される
→ 制度は支持されているように見える
→ 腐敗・劣化が安定へ見え替わる
→ 恐怖の粗い圧力が日常運転へ翻訳される
→ 利益が文明の接着剤・第二主機関として定着
```

## 構造層
### 1. 恐怖摩耗層
恐怖は即効性が高いが、露出し続ければ反発・疲弊・摩擦を増やす。人を逃げにくくすることはできても、積極的協力を柔らかく調達するには不足する。

### 2. 延命報酬層
利益は成長への報酬から、壊れた制度を壊さないための延命報酬へ位相転換しうる。価値創造への正当な利益と、残留を調達する延命利益を区別する必要がある。

### 3. 接着層
便益や安定が制度内部に留まる利点を作ることで、制度への信念がなくても残留が合理化される。利益は「飴」ではなく、痛みを鈍らせながら人を秩序へ接着する装置として働く。

### 4. 否定・依存共存層
「このままではいけない」と「今壊れると困る」が同時に成立する。不満があることと、制度から離脱しないことは矛盾しない。

### 5. 沈黙買収層
利益が直接買収するのは理性そのものではなく、異議を最後まで押し通す意志である。批判は残っていても、自己利益を傷つける可能性が行動化を止める。

### 6. 安定擬態層
人々が残留し制度を再生産すると、外からは支持や安定に見える。しかしその残留が信念によるのか、利益計算によるのかは別に観測しなければならない。

### 7. 第二主機関層
恐怖が「出ると危ない」、利益が「残る方が得」を作ると、従属は自発的選択のように見え始める。利益は恐怖を日常化し、耐久文明をより静かに長く運転させる第二主機関になる。

## 適用例
**組織。** 方針への不満が共有されていても、昇進、福利厚生、案件配分、肩書、報酬、所属による便益を失うことが異議の行動化を止めるなら、支持と残留を分けて観測する。

**制度。** 制度の欠陥を認識している利用者や受益者が、給付、資格、保護、優先権、既得位置への依存から制度維持へ回る場合、価値創造への報酬と延命分配を分ける。

**市場・産業。** 問題のある構造を関係者が認識していても、取引、補助、既存顧客、規制優位、サプライチェーン上の地位などが残留を合理化していないかを見る。

**社会観測。** 制度が広く利用され、関係者が維持へ協力している外形だけから「支持されている」と結論せず、残留利益と離脱不利益の組み合わせを確認する。

## 測定・監査点
- 利益は価値創造への報酬か、制度を壊さないための延命報酬か。
- 人々は制度を支持して残るのか、壊れると損をするため残るのか。
- どの便益・保護・安定・優先権・承認・既得位置が残留を支えているか。
- 制度への批判が自己利益の毀損可能性によって行動化を止められていないか。
- 「このままではいけない」と「今壊れると困る」が同時に存在するか。
- 沈黙は同意か、利益依存による自己抑制か。
- 利益分配が制度の痛みや腐敗を見えにくくしていないか。
- 利用・協力・再生産が信念か利得計算か。
- 利益が枯渇した場合、恐怖や反発が再露出する構造になっていないか。
- 利益が正当な参加報酬として機能している領域と、延命接着剤へ変質した領域を分けられるか。

## 成立条件
- 恐怖だけでは摩耗が大きく、長期運転に残留合理化が必要になる。
- 制度に欠陥・劣化・不正への認識があっても、内部に留まる便益が残る。
- 制度崩壊や離脱が自己利益・生活・地位・取引等の毀損へ接続する。
- 不満が存在しても異議の行動化が弱まり、沈黙・残留・制度再生産が続く。
- 利益が豊かさの証明より、非崩壊を選ばせる接着コストとして機能する。

## 失敗条件
- あらゆる利益や報酬を耐久文明の腐敗装置とみなす。
- 利益を単純な「飴」や道徳的買収だけとして扱う。
- 利益を受ける人を堕落者、与える人を買収者と人物評価だけで分類する。
- 制度利用や協力をそのまま制度への信念・支持とみなす。
- 不満が存在するなら制度はすぐ崩壊すると考える。
- 恐怖と利益を反対物とみなし、直列の主機関としての関係を見ない。
- 正当な価値創造への利益と延命接着剤としての利益を区別しない。

## 反証・改訂条件
利益が耐久文明の第二主機関として支配的だと判定した対象で、分配が価値創造と透明に対応し、便益を失う可能性があっても異議が自由に行動化され、制度批判が自己利益毀損へ自動反転せず、参加者が残留利得とは別に制度の意味・正当性・未来価値を説明でき、制度修正が実際に進むなら、延命接着剤としての利益依存判定は改訂すべきである。

また、利益分配を減らしても残留・協力・制度再生産が意味・信頼・合意によって持続し、恐怖の再露出や離脱増加が起きない場合、第二主機関モデルの適用範囲を見直す必要がある。

## 必須の区別
- 利益 ≠ 豊かさの証明。
- 正当な成果報酬 ≠ 延命報酬。
- 残留 ≠ 支持。
- 沈黙 ≠ 同意。
- 利用継続 ≠ 制度信念。
- 不満 ≠ 即時離脱。
- 便益 ≠ 正当化。
- 「残る方が得」 ≠ 「制度が正しい」。
- 恐怖と利益 ≠ 反対物。
- 第二主機関 ≠ 耐久文明全体系。

## 誤読禁止 / 解釈制約
本論は利益そのものを悪と断定するものではない。利益は本来、価値創造と参加を支える正当な回路になりうる。観測対象は、合意形成を失った秩序の内部で、その利益が価値創造への報酬から非崩壊のための接着コストへ変質しているかどうかである。

また、本論を個人の堕落や買収の道徳劇へ還元しない。重要なのは、制度の欠陥を認識した人々がなぜ残留し、批判を行動へ移さず、結果として制度を再生産し続けるのかという運転構造である。
