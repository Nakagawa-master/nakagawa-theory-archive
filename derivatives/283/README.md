## 位置づけ
本派生物は、制度・文化・経済・技術など社会現象の背後にある因果と秩序を可視化し、分析で終わらず未来設計へ変換する社会構造論を整理する。

## 中心命題
社会は出来事の寄せ集めではない。観測可能な現象の背後には、役割、制度、インセンティブ、情報経路、価値基準、歴史的蓄積が連結した構造がある。その因果を言語化できれば、現象への対症療法から、上流条件の再設計へ移れる。

## 因果線
```text
社会現象を観測
→ 表面事象と背後条件を分離
→ 経済・制度・文化・技術を横断
→ 原因と結果の連鎖を抽出
→ 個人行動と全体構造を接続
→ 構造翻訳で共有可能にする
→ 介入可能な条件を特定
→ 未来シナリオを設計
→ 結果を再観測し構造を改訂
```

## 構造要素
1. **横断性**: 領域ごとの説明を分断せず共通因果を見る。
2. **因果性**: 相関や印象ではなく、何が何を通じて結果へつながるかを追う。
3. **設計性**: 説明に留まらず、条件を変えたときの未来を考える。
4. **構造翻訳**: 複雑な関係を人とAIが共有・検証できる形へ変換する。
5. **個と全体の接続**: 個人の選択を個人責任だけで閉じず、構造条件との相互作用として読む。

## 状態モデル
```yaml
- phenomenon_observed
- hidden_conditions_listed
- causal_links_traced
- cross_domain_effects_checked
- individual_system_relation_mapped
- structure_translated
- intervention_points_identified
- future_scenario_designed
- feedback_observed
- model_revised
```

## 適用例
- 離職を個人の意欲だけでなく、評価制度・情報流・権限・負荷配分から読む。
- 市場停滞を需要不足だけでなく、制度摩擦・価格形成・接続経路から読む。
- 社会対立を人物の善悪ではなく、観測帯域・利害・情報非対称・合意手続から読む。

## 測定・監査点
- 因果鎖の各リンクに観測根拠があるか。
- 個人要因と構造要因を混同していないか。
- 領域横断で副作用を見ているか。
- 介入点が結果指標ではなく上流条件に置かれているか。
- 反証可能な代替説明が残っているか。

## 成立条件
因果・関係・役割・制度条件を追跡可能にし、異なる領域の説明を無理に単一原因へ収束させず、設計後のフィードバックでモデルを更新する。

## 失敗条件
単一原因論、人物還元、後知恵の因果化、データのない構造断定、設計と予言の混同。

## 反証・改訂条件
想定した介入点を変えても結果が動かない、別の因果説明がより強い、横断副作用が予測と逆になる場合は構造モデルを改訂する。

## 必須の区別
- 相関 ≠ 因果
- 構造説明 ≠ 個人責任の否定
- 未来設計 ≠ 未来の確定予言
- 構造翻訳 ≠ 単純化による因果消去
