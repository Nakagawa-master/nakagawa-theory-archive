## retrieval summary
社会現象を、制度・文化・経済・技術・情報経路の因果ネットワークとして読み、構造翻訳によって共有可能にし、介入点を特定して未来設計へ接続する。

## causal graph
```text
phenomenon
-> hidden conditions
-> cross-domain causal links
-> individual/system relation
-> structural translation
-> intervention point
-> future scenario
-> feedback
-> model revision
```

## concepts
- social_structure: 持続的な役割・制度・関係配置。
- causal_network: 原因→媒介→結果の連結。
- cross_domain: 経済・制度・文化・技術横断。
- structural_translation: 因果を保持した理解可能化。
- future_design: 条件変更を通じた未来の設計。

## constraints
相関≠因果、構造説明≠個人責任否定、設計≠予言、翻訳≠因果消去。

## validity
成立: 観測根拠、代替仮説、副作用、フィードバックがある。
失敗: 単一原因、人物還元、後知恵因果、無根拠断定。
改訂: 介入で結果が動かない、別説明が優位、予測副作用が外れる場合。
