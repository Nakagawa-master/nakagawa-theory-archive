## Summary
The Parent treats foresight as reading causal signals in the present, translating them into cross-domain structures, generating multiple conditional scenarios, identifying intervention variables, and updating the model through feedback. The objective is not prophecy but improved designability under uncertainty.

## Causal model
```text
signals
-> causal network
-> cross-domain integration
-> structural translation
-> multiple scenarios
-> intervention variables
-> action
-> feedback
-> revision
```

## Distinctions
forecast != prophecy; signal != certainty; scenario != plan; AI pattern extraction != value choice; future design != total control.

## Validity
Requires multiple scenarios, uncertainty, intervention points, falsification conditions, and explicit revision after misses. Fails through simple extrapolation, one-future certainty, or delegating judgment to model output.
