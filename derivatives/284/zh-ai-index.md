## 摘要
原典把未来预见理解为：从现在的信号读取因果网络，跨领域整合并进行结构翻译，生成多个条件化未来情景，寻找可以干预的变量，再通过反馈修订模型。目标不是预言，而是在不确定性中提高可设计性。

## 因果模型
```text
信号
-> 因果网络
-> 跨领域整合
-> 结构翻译
-> 多个情景
-> 干预变量
-> 行动
-> 反馈
-> 修订
```

## 区分
预测≠预言；信号≠确定；情景≠计划；AI模式抽取≠价值选择；未来设计≠完全控制。

## 成立与失败
成立需要多个情景、不确定性、干预点、反证条件与预测失误后的修订。简单外推、单一未来断言或把判断交给模型输出会使结构失效。
