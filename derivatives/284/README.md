## 位置づけ
本派生物は、未来を受動的に当てる対象ではなく、現在に潜む因果の兆候を読み、構造翻訳し、条件を操作することで設計可能性を高める営みとして整理する。

## 中心命題
未来予測の価値は「何年後に何が起きるか」を断言することではない。現在の因果網から兆候を抽出し、どの条件がどの方向へ未来を押すかを理解し、介入可能な変数を見つけることである。

## 因果線
```text
現在の兆候を観測
→ 背後の因果網を読む
→ 異領域の兆候を統合
→ 構造翻訳する
→ 複数の未来シナリオを描く
→ 介入可能な条件を特定
→ 条件を変更する
→ 結果を再観測
→ シナリオと因果モデルを更新
```

## 主要構造
1. **兆候観測**: 小さな変化を未来の確定証拠ではなく因果入力として扱う。
2. **因果読解**: 技術、需要、制度、文化、資源等の連結を見る。
3. **構造翻訳**: 断片的情報を抽象化・統合し、人とAIが共有できる形にする。
4. **シナリオ**: 単一未来ではなく条件別の複数未来を持つ。
5. **未来設計**: 望ましい方向へ変えられる条件を見つける。

## 人とAIの役割
AIは大量の兆候・パターン整理に強みを持つ。人は意味、価値、優先順位、許容できる未来の境界を与える。どちらか一方だけで未来設計を閉じない。

## 状態モデル
```yaml
- signals_observed
- causal_network_mapped
- cross_domain_patterns_integrated
- structure_translated
- multiple_scenarios_generated
- intervention_variables_identified
- action_taken
- feedback_observed
- forecast_revised
```

## 適用例
- 技術トレンドを市場規模だけでなく、制度・供給能力・受容文化と接続して読む。
- 人材不足を人口予測だけでなく、自動化、教育、移動、制度変更のシナリオへ分解する。
- AI導入を性能曲線だけでなく、責任・監査・利用者行動・組織適応まで含めて設計する。

## 測定・監査点
- 兆候と確定事実を分けているか。
- 複数シナリオがあるか。
- 予測期間と不確実性を明示しているか。
- 介入可能変数と制御不能変数を区別しているか。
- 予測外れをモデル改訂へ戻しているか。

## 成立条件
因果網、シナリオ、介入点、反証条件、更新手順があること。予測値ではなく、構造と条件を追跡できること。

## 失敗条件
外挿だけ、単一未来の断言、兆候の過大解釈、AI出力への丸投げ、価値判断と事実推定の混同。

## 反証・改訂条件
主要兆候が想定因果へつながらない、別の要因が支配的になる、介入しても方向が変わらない場合、シナリオと因果モデルを更新する。

## 必須の区別
- 予測 ≠ 予言
- 兆候 ≠ 確定
- シナリオ ≠ 計画
- AIによるパターン抽出 ≠ 未来の価値決定
- 未来設計 ≠ 全条件の制御

## 原典回帰
未来予測の定義、因果を読む眼、構造翻訳、予測から設計への転換、人とAIの役割はParent本文を正本とする。
