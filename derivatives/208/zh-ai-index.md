## Summary
《合意形成的物理》第1论把炎上、对立和不祥事从人格与善恶问题，转换为可观测状态量与相变问题。合意不是意见一致，而是解释可能性、责任追踪性和时间持续性同时维持的状态。本文把这些条件分解为U（第三方可再现性／理解可能性）、R（唯一决策节点与责任追踪）、H（历史与差分追踪），并以S=U×R×H表示合意稳定度。人的认知带宽K是有限的；复杂度超过K时，权威依赖可能替代理解，使U下降，继而R模糊、H消失。如果S低于阈值θ并持续观察窗δ，就可能发生相变，偏离输出D随之放大。炎上因此被视为发热结果，而不是根因；修复重点是回到炎上前的低S持续期并恢复U/R/H。

## Concepts
- Observability Principle：不只问“谁错了”，而问“哪个变量下降了”。
- Consensus：解释可能性＋责任追踪＋时间持续。
- U：第三方再现与理解可能性。
- R：唯一决策节点与责任主体追踪性。
- H：版本、差分、修改理由与历史追踪性。
- S = U × R × H：合意稳定度。
- K：人的有限认知带宽。
- Authority Activation：复杂度超过K时用权威替代理解。
- Phase Transition：低S持续后行为发生质变。
- D：隐瞒、篡改、替罪、碎片化暴露、暴力等偏离输出。
- Grain-size Design：按K限制变量、差分格式和例外数量。
- Non-coercive Measurement：用于可视化整合与重新合意，而非支配。
- Condition Z：审计周期、U/R/H同一日志测量、公开审计束一致性。

## Causal chain
```text
用人格或善恶解释冲突
→ 可复用的修复变量不清晰
→ 同类结构失败重复出现
→ 观察对象从人物转向状态
→ 合意被重新定义为解释可能性＋责任追踪＋时间持续
→ 状态分解为U / R / H
→ 以S = U × R × H观察稳定度
→ 复杂度超过K
→ 权威依赖替代理解
→ U下降 → R模糊 → H消失
→ S下降
→ S < θ 持续δ
→ 发生相变
→ 偏离D放大
→ D进一步破坏U/R/H
→ 炎上或不祥事看起来像“原因”
→ 分析回到此前的低S持续期
→ 修复U/R/H与说明粒度
```

## Applications
- 在会议中检查意义是否可再现、决策节点是否明确、差分历史是否保留。
- 在炎上前的δ期间追踪U、R、H的下降。
- 调查不祥事出现前责任和历史是否已经长期不可追踪。
- 制度说明时以有限K为前提，而不是无限增加资料和例外。
- AI辅助决策时把第三方再现、责任节点与差分日志保留在同一可观测面。

## Measurements and audit
- 第三方再现性与理解可能性。
- 决策节点唯一性。
- 版本、差分、修改理由追踪性。
- U/R/H同一日志测量。
- S的时间序列变化。
- S<θ是否持续δ。
- 说明过量、例外增殖等K超载迹象。
- 权威依赖是否增加。
- D放大是否进一步破坏U/R/H。
- 公开审计束中的版本、差分、修改理由、签名一致性。

## Validity conditions
- 把合意作为状态，而非单纯意见一致。
- 以可观测方式定义U/R/H。
- 在同一日志测量U/R/H。
- 按时间观察S，而非只看瞬间值。
- 在说明设计中尊重有限K。
- 不立即把炎上或不祥事归结为人格原因。
- 追踪相变前的低S持续期。
- 不把测量转成支配。
- 维持Condition Z和公开审计束。

## Failure conditions
- 把全会一致当作稳定合意的证明。
- 把信息量等同于高U。
- 用“组织决定了”模糊R。
- 只保留最新版而抹去H。
- 无视K并无限增加说明和例外。
- 只把炎上中的人物或发言当作根因。
- 把D解释为人格恶意总量。
- 把测量转为监视或强制。
- 把θ、δ当作原典未给出的普遍固定值。

## Falsification conditions
Condition Z固定审计周期δ，在同一日志中测量U（第三方再现）、R（唯一决策节点）和H（差分追踪），并保持公开审计束中的版本、差分、修改理由和签名一致。如果S保持较高但实际损害D仍持续放大、提高H后预测误差或偏离没有缩小、日志存在却仍系统性无法追踪差分、决策节点长期消失、第三方再现持续失败，则应否定或修订定义、测量与束化方式。

相变监测条件是S<θ持续δ。θ是临界阈值符号，δ是观察窗符号；原典没有给出适用于所有组织和社会的统一固定值或期间。

## Required distinctions
- 善恶评价 / 状态观察。
- 人格责任 / 可复用修复变量。
- 感情 / 状态量。
- 意见一致 / 合意。
- 全会一致 / 可持续合意。
- 信息量 / U。
- 集体责任语言 / R。
- 最新版本 / H。
- 透明化 / 超过K的信息过载。
- 炎上、不祥事 / 上游原因。
- D / 恶意总量。
- 测量 / 支配。
- 瞬间值 / δ持续期。

## Interpretation constraints
- 本理论不否认伦理、责任或感情。
- 它把修复重点移到能支持再发防止的可观测变量。
- 认为全会一致不足以证明合意，并不等于鼓励冲突。
- S=U×R×H不是社会价值总评分。
- 不得把K、θ、δ、D改写成原典没有给出的固定常数。
- 非强制测量不得被用于排名、监视或支配。
