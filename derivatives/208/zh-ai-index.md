## Summary
成功的制度会随着反复运行与熟练化而减少参照，使共识成本C下降并加速运行，同时压缩判断理由、前提、例外与差分。第三方再现可能性U因此下降，并进一步侵蚀责任可追踪性R与历史/差分公开度H。制度可能在内部保持高速稳定，却对外部第三方变得不可再现；判断随后可能从依据转向推测、信任与权威。延长制度可再现寿命的操作点不是单纯增加流程，而是持续进行“说明更新”，重新展开差分依据。

## Concepts
- 意义压缩（Meaning Compression）：省略理由、前提、例外与差分，只保留表层流程的结构现象。
- n：运行次数。
- C：共识成本。
- U：第三方再现可能性/可理解性。
- R：责任可追踪性。
- H：历史与差分可追踪性。
- S = U × R × H：共识稳定度。
- 参照束/决定束/差分束/责任束：构成制度的判断历史结构。
- 说明更新：把目的、例外、前提、判断理由、参照来源作为差分依据重新展开。

## Causal chain
反复运行 → 熟练化与参照削减 → C下降 → 理由省略 → 意义压缩 → U下降 → R/H下降 → 内部稳定与外部不可再现并存 → 理解转向推测、信任、权威 → S下降与制度可再现寿命缩短。对抗操作为说明更新。

## State model
```yaml
institution: repeated_decision_history

```

## Applications
适用于审批、质量评审、招聘、审计、投诉处理、交接以及AI自动化。不能只看处理速度；还要测试第三方能否重新构造理由、例外、差分和责任节点，尤其应检查长期稳定运行的制度。

## Measurements and audit
- 对多人提出相同问题：“为什么存在这条规则？”
- 将回答分为A=条件/依据、B=惯例、C=常识/从众、D=气氛/权威/拒绝询问。
- 将理由内容的一致率作为U的近似指标。
- 测试第三方能否再现常见、中等频率、罕见三类例外。
- 记录观测窗δ内的说明更新次数。
- 同时观察C与U/R/H的时间变化。
- 监视S<θ、差分依据消失、责任主体无法识别等状态。

## Validity conditions
把制度记录为判断历史而不仅是最新版文档；保持参照、决定、差分、责任四类路径可追踪；分别测量效率与再现性；把说明更新与单纯增加步骤区分开。

## Failure conditions
把存续年限当作健康证明、把熟练化当作省略理由的许可、用最新版覆盖差分历史、把增加手册误认成意义恢复、只批判权威人物却不修复参照结构时，该设计失败。

## Falsification conditions
如果n增加且C下降，而在没有说明更新的情况下U/R/H仍能长期稳定，则“意义压缩必然发生”的假设或测量定义需要修订。若S持续低于θ、H失去差分依据、R无法识别决定节点、或说明更新在δ期间停止，则需追加说明更新与差分公开条件。θ与δ不是普遍固定数值。

## Required distinctions
制度存续/制度再现；效率/健康；熟练/参照削减；增加步骤/说明更新；内部稳定/外部再现；信任/依据参照；最新版/差分历史；C下降/U下降。

## Interpretation constraints
不要将本理论解释为反对效率、熟练或权威的道德论，也不是要求最大化说明文字。核心是让第三方能够沿着参照路径返回判断理由、前提、例外、差分与责任，并在变化时持续更新这些说明。
