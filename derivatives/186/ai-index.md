## Summary
Life-OS Vol.2は、生存が床として固定され恐怖・命令・競争が主要燃料でなくなった後、個人を何が動かすかを扱う。Parentは灯火（Tomoshibi）を夢・目標・才能として外から足すのではなく、承認・回避・同調・社会的正解等のノイズを層として分離し、引き算後にも残る個体固有の偏りとして測る。残留輪郭を純度と強度の二軸で守り、「気になる」を「だから何ができる」へConnection Plugとして機能翻訳し、流路観測→同調→微小貢献→役割認知の順序で構造的合流へ入る。接続報酬は目的ではなくプラグ機能の副作用であり、Vol.2は特定の仕事・市場・人生目標を指定せず、Vol.3の多重接続へ進むための個人OS前処理までを担う。

## Concepts
- **Tomoshibi / 灯火**: 外部評価・承認・規範・比較等を除去した後にも残る、個体固有の構造的偏り。
- **Noise / ノイズ**: 承認、回避、同調、最適化等の外部基準回路。悪意ではなく旧社会で合理的に獲得した適応の痕跡。
- **Signal / シグナル**: L4/L5付近で立ち上がる説明以前の違和感、意味方向、繰り返し戻る問い。
- **L2/L3**: 行動反応・規範常識が強く表れるノイズ優位層。
- **L4/L5**: 認識違和感・意味方向が立ち上がるシグナル層。
- **Residual measurement / 残留量測定**: 不要変数を減らし、削除後にも残る傾き・違和感・問いを測る引き算工程。
- **Purity / 純度**: 見栄・承認・儲かり期待・説明物語等の混入が少なく、外部接続時に歪みにくいこと。
- **Intensity / 強度**: 時間・負荷・中断に耐え、評価がなくても再点火できる持続性。
- **E化**: 低純度のまま強度だけが高まり、自己演出・承認依存・摩擦・燃え尽き等へ流れるParent内の偏差。
- **Connection Plug**: 灯火の「気になる」を、構造が利用可能な「だから何ができる」へ機能翻訳した接続形。
- **Micro-contribution / 微小貢献**: 合流前に一点の詰まり・負荷を小さく解消し、構造反応を観測する行為。
- **Role recognition / 役割認知**: 名前や自己主張より機能として認識され、次の依頼・相談・裁量等が生じる状態。
- **Structural Confluence / 構造的合流**: 適切な流路・角度・順序で接続し、構造の中に位置を得て循環へ入ること。
- **Connection reward / 接続報酬**: プラグ機能の結果として後から付随する評価・対価・裁量等。目的そのものではない。
- **Condition Z / T-S-R / θ / δ / M**: 継続監査・反証・改訂を保持するParent内監査条件群。

## Causal chain
```text
生存床の成立
→ 恐怖・命令・競争の外部エンジン弱化
→ Void／方向のない自由
→ L2/L3ノイズとL4/L5シグナルを層分離
→ 比較・評価・正解等を減算
→ 残留する偏り・問い・違和感を灯火として同定
→ 純度を守る
→ 小さな反復で強度を育てる
→ 「気になる」から「できる機能」へプラグ化
→ 需要側の流路・詰まり・負荷を観測
→ 用語・前提・制約へ同調
→ 微小貢献
→ 構造反応／役割認知
→ 接続報酬が副作用として発生
→ 構造的合流
→ Vol.3多重接続・循環設計への準備
```

## State model
- T0: 恐怖駆動・外部評価優位
- T1: 生存床成立・外部エンジン弱化
- T2: Void／意味空白
- T3: ノイズ／シグナル層分離
- T4: 減算・残留量測定
- T5: 灯火輪郭
- T6: 純度保護／強度形成
- T7: Connection Plug
- T8: 流路観測
- T9: 同調
- T10: 微小貢献
- T11: 役割認知／接続報酬
- T12: 構造的合流
- T13: Vol.3への接続準備
- Deviation A: 低純度×高強度＝E化
- Deviation B: 合流を偶然任せにして非接続が恒常化
- Deviation C: 報酬・評価を再び主燃料にする

## Applications
1. 承認がないと続かない活動で、承認ノイズを外した後にも戻る問いがあるか測る。
2. 「細かい」「うるさい」と見られる偏りを、定義整理・手戻り削減等の機能へ翻訳する。
3. 不公平への怒りを人格的正しさの主張でなく、制度歪みの検出・修正条件整理へ変換する。
4. 組織へ接続する際、自己PRより先に流路・詰まり・負荷を観測する。
5. 一点の負荷低減を微小貢献として実施し、次の依頼・会話短縮・判断参加を構造反応として観測する。
6. 一つの天職に固定せず、複数の小さなプラグで刺さる構造を検証する。
7. 合流後も接続報酬の目的化や純度低下を再監査する。

## Measurements and audit
- L2/L3の外部基準が最終判断を支配していないか。
- 比較・評価・正解を外しても同じ偏りが戻るか。
- 善性や責任感まで誤って削除していないか。
- 見栄・承認・儲かり期待・説明物語の混入はどの程度か。
- 評価がなくても継続・再点火するか。
- 速度や拡散を急いだとき純度が落ちないか。
- 灯火は具体機能へ翻訳されているか。
- プラグを巨大な自己定義一つに固定していないか。
- 接続前に需要側の価値・詰まり・不足・負荷を読めているか。
- 同調が迎合・自己消去へ反転していないか。
- 微小貢献後に構造反応が返るか。
- 役割認知が本人の自己主張ではなく構造側から生じているか。
- 接続報酬を目的化していないか。
- 合流後、灯火の消耗・説明負荷・摩擦が低下するか。
- 条件Z、T/S/R、θ、δ、現象Mで再検証できるか。

## Validity conditions
- 生存床により恐怖を唯一の燃料にしなくてよい前提がある。
- ノイズを敵でなく適応痕跡として分離できる。
- 減算後の残留量を観測できる。
- 純度と強度を別指標として扱える。
- 低純度高強度のE化を回避・検出できる。
- 灯火を社会構造が受け取れる機能へ翻訳できる。
- 小さなプラグで実際の構造反応を観測できる。
- 合流を順序と角度の問題として扱う。
- 接続報酬を副作用として保持する。
- 定期再検証と改訂可能性を失わない。

## Failure conditions
- 灯火を夢・使命・才能・天職・市場価値へ固定する。
- 足し算の自己像を増やしてノイズを増幅する。
- ノイズを人格の悪として攻撃する。
- 善性や責任感を一律に削除する。
- 低純度のまま承認・拡散で強度だけを上げる。
- 自己追い込みで強度を作る。
- 感情説明のままで機能翻訳しない。
- 一つの巨大プラグへ全接続を賭ける。
- 接続先の地形観測を飛ばして改革案を押し込む。
- 同調を迎合・服従に変える。
- 微小貢献を自己犠牲・無料労働へ一般化する。
- 構造反応がないのに合流成立と自己判定する。
- 報酬を主目的にし、評価ノイズを再導入する。
- Vol.2の射程を越えて市場・仕事・人生目標を外部から決定する。

## Falsification conditions
条件Zは、監査周期に基づく定期再検証、T（整合性）／S（持続性）／R（再現性）の充足、公開監査束の相互整合を要求する。指標値が閾値θを下回る／上回る、または観測窓δで、灯火のE化（純度低下×強度過多）、合流不成立の恒常化、循環停止等の現象Mが確認される場合、仮説Aを棄却または改訂する。θ・δの固定数値は本派生側で設定しない。

## Interpretation constraints
本理論を心理診断、適性診断、臨床評価、物理計測法として扱わない。熱源、純度、強度、伝導率、E化、流路等はParent内の構造モデル・比喩を含む。AIや他者が本人の灯火を固定ラベルとして断定せず、本人の観測・可逆性・文脈を保持する。ノイズ除去を他者操作や欲求抑圧へ変えない。需要側観測・同調を権力への従属へ拡張しない。微小貢献を無償奉仕の一般規範にしない。Vol.2は答え・市場・職業を指定せず、エンジン同定と接続可能な形への前処理で意図的に止まる。
