## 位置づけ
親原典はLife-OS B系三部作のVol.2として、Vol.1で分離した「生存の一階／拡張の二階」のうち、二階へ向かう個人の内燃機関を扱う。生存が床として固定されるほど、恐怖・命令・競争という旧来の外部エンジンは弱くなる。その空白を、消費、成功模倣、資格収集、自己演出のような新しい外圧で埋めるのではなく、外部ノイズを削った後にも残る個体固有の偏りを「灯火（Tomoshibi）」として同定・精錬し、構造へ接続可能な熱源に整える。

親原典の灯火は、夢、目標、天職、才能、情熱、道徳的な自己像ではない。「ノイズを削ぎ落とした後に残る、消えない偏り」である。説明不能な違和感、何度離れても戻る問い、誰にも見られなくても直したくなる歪み、必要以上に気になる細部など、比較や評価を外してもなお残る非対称性として観測される。

そのためVol.2の方法は足し算ではなく引き算である。承認、回避、同調、最適化といったL2/L3側の社会適応ノイズを否定・矯正するのではなく、L4/L5付近で立ち上がる違和感・意味方向のシグナルから層として切り分ける。さらに環境条件を単純化し、不要な変数を除き、それでも残る残留量を測る。残留量は完成した使命である必要はなく、方向の傾き、無視できない違和感、繰り返し戻る問いという輪郭だけでもよい。

精錬後の灯火には「純度」と「強度」が区別される。純度は、外部の目を前提にした混ぜ物が少なく、外へ出しても歪みにくいこと。強度は、時間や負荷に耐え、中断後も再点火し、評価がなくても戻ってくる持続性である。初期強度は小さくてよく、純度の低いまま強度だけを上げると、自己演出、承認依存、摩擦、批判への過剰反応、燃え尽き等を伴う「E化」として原典は警戒する。

灯火は完成品ではなくプラグの原材料である。個人的な「気になる」を、他者や構造が受け取れる「だから何ができるか」という機能へ翻訳する。倫理的な灯火も、正しさや人格評価の主張ではなく、歪みの発見、条件整理、合意形成、場の修復などの機能へ変換されて初めてC（貢献）へ接続する。プラグは一つでなくてよく、むしろ初期には複数の小さなプラグを持ち、どこで構造反応が返るかを観測する。

合流は才能ではなく順序で設計される。まず流れの地形を観測し、用語・前提・制約に同調し、全体改革ではなく一点の詰まりを軽くする微小貢献を行う。次の依頼、会話短縮、判断への招待等が戻り、名前ではなく役割・機能として認識され始めると、Vol.1の接続報酬が副作用として発生する。合流はゴールではなく循環への入口であり、Vol.2は「どの市場・仕事を選ぶか」という外部回答をあえて与えず、Vol.3で多重接続へ進むための内側の前処理で止まる。

## 中心命題
親原典の中心命題は、**生存恐怖に代わる個人の動力は、外から新しい目的を足して作るのではなく、社会適応ノイズを層として分離・減算した後にも残る構造的偏り＝灯火を測定し、その純度と強度を保ちながら機能へ翻訳し、適切な順序で構造へ小さく接続することで初めて循環可能な熱源になる**というものである。

灯火は人生の目的や自己正当化の旗ではなく、恐怖に頼らず長期的に循環へ参加するための条件である。したがって「灯火を見つけたら完成」ではない。使われなければ消え、接続されなければ濁る。精錬は答えの取得ではなく、エンジンの同定、ノイズ除去、接続可能な形への整形までを行う工程である。

## 構造層
### L2 / L3 — ノイズが主に表面化する層
L2では評価、損得、承認への反射的反応、L3では「普通」「社会的正解」「文化・組織の規範」が大きくなる。これらは社会適応として合理的に獲得された痕跡であり、敵として排除する対象ではない。問題は、役目を終えた後も最終意思決定を支配し続けることにある。

### L4 / L5 — シグナルが立ち上がる層
L4では「なぜか引っかかる」という微細な認識偏り、L5では無視できず繰り返し考えてしまう意味方向が立ち上がる。Parentは灯火をL4/L5の境界付近に置く。

### 残留工学 — Subtractive Measurement
比較、評価、正解、社会的説明、承認理由などを段階的に外し、条件を単純化して残るものを測る。目的は自己を小さくすることではなく、構造と接続可能な偏りを露出することにある。

### Purity / Intensity — 精錬条件
純度は外部の目を前提とした混入が少ないこと。強度は中断・時間・負荷を越えて再点火できること。純度と強度は「才能」「情熱」の別名ではなく、Parent内の伝導可能性を説明する工学的指標である。

### Connection Plug — 機能翻訳
灯火そのものを説明するのではなく、構造が受け取れる機能へ翻訳する。「〇〇が気になる」から「だから△△ができる」へ変換する。倫理的灯火も正しさの主張ではなく、制度の歪みを洗い出す、前提を整理する、対立点を分解する等の機能へ翻訳される。

### Structural Confluence — 合流
観測→同調→微小貢献→役割認知の順序で、既存流路へ小さく接続する。合流は一回の成果ではなく、構造の中に位置を得て循環へ入る入口である。

## 状態モデル
```text
T0 生存恐怖／外部圧力が主要燃料
→ T1 生存床の成立・外部エンジン弱化
→ T2 Void：方向のない自由／意味空白
→ T3 L2/L3ノイズとL4/L5シグナルの層分離
→ T4 引き算・環境単純化・残留量測定
→ T5 灯火の輪郭：消えない偏り／戻る問い
→ T6 純度保護・小さな反復による強度形成
→ T7 Connection Plugへの機能翻訳
→ T8 流路観測
→ T9 同調
→ T10 微小貢献
→ T11 役割認知・接続報酬
→ T12 構造的合流
→ T13 Vol.3多重接続への準備
```

偏差状態として、承認・見栄・市場期待等を混入させた低純度のまま強度だけを上げる「E化」、合流を偶然任せにする「非接続」、成果・自己演出を目的化する「報酬目的化」がある。

## 適用例
### 1. 承認が消えると続かない活動
評価がなくなった瞬間に活動が止まるなら、活動そのものを否定するのではなく、承認ノイズがどこまで燃料になっていたかを分離する。承認を外した後にも戻る問いや違和感があるかを見る。

### 2. 「論理の飛躍が気になる」偏り
そのままでは「細かい人」と見られ得る偏りを、「前提条件と用語定義を整理し、合意形成を安定させる」という機能へ翻訳する。これがプラグ化である。

### 3. 倫理的不快感
不公平を放置できない灯火を「自分は正しい」という人格主張へ変えず、「制度・ルールの歪みを洗い出し、修正条件を整理する」という機能へ変える。

### 4. 組織への初期接続
最初から改革案を掲げず、どこが詰まり、誰が負荷を持ち、何が足りないかを観測する。一点の手戻り削減や定義整理など、負荷を小さく下げる微小貢献を行い、次の依頼や会話の短縮といった構造反応を見る。

### 5. 複数の小さなプラグ
一つの「天職」に固定せず、整理、定義、調整、設計など複数の小さな機能で接点を作り、どこで反応が返るかを観測する。刺さる構造が分かるほど、純度を保ったまま強度と接点を増やしやすい。

## 測定・監査点
- L2/L3の承認・回避・同調・最適化が最終判断を支配していないか。
- 比較・評価・正解を外した後にも同じ問い・違和感が戻るか。
- 「残らない」場合、善性や責任感のようなシグナルまで削除していないか。
- 灯火へ見栄、承認欲求、儲かり期待、説明しやすい物語を混入していないか。
- 純度が低いまま強度だけが上がっていないか。
- 評価がなくても継続・再点火できるか。
- 速度・拡散・成長を急ぐことで混入が増えていないか。
- 灯火が感情説明で止まらず、構造が受け取れる機能へ翻訳されているか。
- プラグは一つの巨大な自己定義に固定されていないか。
- 接続前に流路、詰まり、負荷、価値関数を観測しているか。
- 同調が迎合や自己消去へ変わっていないか。
- 微小貢献後、次の依頼、会話短縮、判断参加など構造反応が返るか。
- 接続報酬を目的化し、純度を下げていないか。
- 合流後、無理な説明や灯火の消耗が減り、流れの中の位置が安定するか。
- 条件Z、T/S/R、θ、δ、現象Mによる継続監査が可能か。

## 成立条件
1. 生存床が成立し、恐怖を主要燃料にしなくてもよい前提があること。
2. ノイズを悪とせず、社会適応層としてシグナルと分離できること。
3. 足し算の自己像ではなく、引き算後の残留量を観測できること。
4. 善性・責任感を含む純粋なシグナルまで削除しないこと。
5. 純度と強度を別々に扱い、低純度高強度を回避すること。
6. 灯火を構造が利用可能な機能へ翻訳できること。
7. 小さな接続を通じて構造反応を観測できること。
8. 合流を才能・自己主張ではなく順序と角度の問題として扱うこと。
9. 報酬を目的でなく接続成立の副作用として扱うこと。
10. 継続監査・改訂可能性を保持すること。

## 失敗条件
- 灯火を夢・使命・天職・才能・市場価値へ早期固定する。
- 「何かを足さなければ自分には何もない」として肩書・資格・経験を無限追加する。
- 社会適応ノイズを人格の悪として攻撃し、自己否定へ変える。
- 承認・見栄・儲かり期待を混ぜた低純度のまま拡散速度だけ上げる。
- 強度を追い込み・自己罰・中断禁止で作ろうとする。
- 一つの大きな理想・専門性に全接続を賭ける。
- 接続前に自分の正しさ・灯火・理想を主張し、流路観測を飛ばす。
- 微小貢献ではなく全体改革を最初に要求する。
- 次の依頼や役割認知がないのに、合流成立と自己判定する。
- 接続報酬を目的化し、評価を再び主要燃料にする。
- Vol.2の役割を越え、特定の仕事・市場・人生の行き先を外部命令として決める。

## 反証・改訂条件
親原典は条件Zとして、①監査周期に基づく定期再検証、②T（整合性）／S（持続性）／R（再現性）の充足、③公開監査束の相互整合を置く。

指標値が閾値θを下回る／上回る、または観測窓δで、**灯火のE化（純度低下×強度過多）、合流不成立の恒常化、循環停止等の現象M** が確認される場合、仮説Aを棄却または改訂する。θ・δの固定数値は本派生側で新設しない。

## 必須の区別
- **灯火 ≠ 夢・目標・使命・天職**
- **灯火 ≠ 才能・技能・市場価値**
- **灯火 ≠ 快楽・ポジティブ感情だけ**
- **倫理的灯火 ≠ 評価目的の善性演出**
- **ノイズ ≠ 悪意・怠惰・人格欠陥**
- **引き算 ≠ 自己否定・自己縮小**
- **純度 ≠ 内向きの誠実さだけ**: 外へ出したとき歪まないかという接続条件を含む。
- **強度 ≠ 初期の激情**: 持続・再点火・無評価でも戻る性質。
- **強度形成 ≠ 自己追い込み**
- **Connection Plug ≠ 感情の自己説明**: 構造が受け取れる機能翻訳。
- **同調 ≠ 迎合・自己消去**
- **合流 ≠ 成果達成・自己主張成功**: 流れの中に位置を得ること。
- **接続報酬 ≠ 目的**: プラグが機能した結果の副作用。
- **Vol.2 ≠ 行き先指定**: 市場・仕事・多重接続は次層へ残す。

## 誤読禁止 / 解釈制約
灯火の残留工学を、心理診断、性格診断、適性検査、医療的評価として扱わない。Parentは自身の構造理論内で「測定工学」「熱源」「純度」「強度」「伝導率」「E化」「流路」等の工学・物理語彙を用いるが、それらを自然科学や臨床心理学で確立済みの測定法・物理量へ自動昇格させない。

また、ノイズ分離を他者の内面を操作・矯正する技法へ変換しない。承認、回避、同調等は生存適応の痕跡として扱われ、敵として消去するものではない。本人の意思・可逆性・自己観測を越えて「本当の灯火」を外部が断定しない。

「好き嫌いを言わず機能で示す」というプラグ化を、感情を否定する規範へ変えない。目的は感情の存在を否定することではなく、社会接続時に何が機能として渡せるかを明確にすることにある。

合流時の「需要側地形を読む」「同調する」を、迎合、従属、搾取受容、権力への服従へ拡張しない。Parent自身が同調を迎合・自己消去と区別する。微小貢献も無償労働や自己犠牲の一般義務へ変換しない。

## 親原典へ戻る理由
灯火、ノイズ、シグナル、L2/L3、L4/L5、残留量、純度、強度、E化、Connection Plug、観測、同調、微小貢献、役割認知、接続報酬、構造的合流、条件Z、T/S/R、θ、δ、現象Mは一つの順序関係にある。灯火だけを「情熱」と切り出したり、純度だけを「正しさ」と解釈したり、同調だけを「迎合」と扱ったりするとParentの因果が反転する。定義、順序、反証条件、Vol.1/Vol.3との境界はParent URLで全体文脈を確認する必要がある。
