## 位置づけ
接続価値会計が測り、接続ガバナンスが守り、接続プロトコルがつなぐ一方、それらの正統性を最上位で束ねるのが接続基本権憲章である。本派生物は憲章を理念文、組織規約、利用規約、無制限な権利主張へ縮約せず、権利・義務・手続・準拠テストの最小核として読む入口である。

## 中心命題
接続社会の制度は、参加者の接続アクセス、目的開示、同意範囲、記憶と忘却、退出・再接続、監査・異議申立て、非強制・非囲い込みを基本権として保障し、同時に誠実、非濫用、機密尊重、構造保全の義務と、参加・離脱・再接続・紛争処理の手続を明確にしなければ正統性を持たない。

## 因果線
```text
会計・ガバナンス・プロトコルが整備される
→ 組織ごとの独自規格と権力集中の危険が残る
→ 制度横断の上位規範が必要になる
→ 基本語を定義し曖昧な操作を防ぐ
→ 七つの基本権と四つの基本義務を固定する
→ 参加・離脱・再接続・紛争手続を標準化する
→ 公開性・可監査性・可逆性を正統性の三基柱にする
→ 準拠テストと逆インセンティブで実効性を確保する
→ 接続の記憶が公共財として安全に積層される
```

## 構造層
1. **定義層**: 接続、合意の記憶、可逆性、接続密度、監査可能性、非強制性。
2. **権利層**: アクセス、目的公開、同意・範囲、記憶と忘却、可逆性、監査・異議申立て、非強制・非囲い込み。
3. **義務層**: 誠実、非濫用、機密尊重、構造保全。
4. **手続層**: 参加、離脱、再接続、仲裁と公開審査要旨。
5. **正統性層**: 公開性、可監査性、可逆性。
6. **制度結節層**: 会計、ガバナンス、CXPを権利境界で束ねる。
7. **準拠・進化層**: 準拠テスト、逆インセンティブ、PoC、監査要旨、準拠ラベル。

## 適用例
- 研究コンソーシアムで成果配分前に目的・同意・監査アクセス・離脱を保障する。
- 自治体と市民の協働で参加枠だけでなく異議申立てと個人情報削減を制度化する。
- オンラインコミュニティで退会、冷却、再参加、記録修正を明示する。
- AI支援サービスでAI判断を最終責任にせず、説明、異議申立て、人間による訂正窓口を保障する。

## 測定・監査点
- 接続目的、利用範囲、期間が事前に説明されたか。
- 同意の拒否・撤回・再確認が機能するか。
- 離脱が即時に可能で、不利益な制裁がないか。
- 個人識別情報の削減・匿名化を請求できるか。
- 構造ログへアクセスし、異議申立てできるか。
- Consent Failure率、Rollback Cost、RC、ER、CEA、Sが基準内か。
- 準拠テスト失敗後に配分低減・修正・再審査が実行されるか。

## 成立条件
- 基本語を曖昧にせず定義する。
- 七権利を利用規約より上位の最低保障とする。
- 権利と四義務を同時に運用する。
- 参加・離脱・再接続・紛争手続を明示する。
- 公開性・可監査性・可逆性を揃える。
- 会計指標を人格や貨幣へ変換しない。
- CXPのID・同意・記憶・可視性を権利境界に従わせる。
- 定期的な準拠テストと第三者観測を行う。

## 失敗条件
- 接続アクセスを恣意的に差別する。
- 目的を隠し包括同意を取得する。
- 記録削減・匿名化・訂正を拒否する。
- 離脱や再接続を制裁の対象にする。
- 異議申立て窓口が運営主体だけに閉じる。
- 権利を口実に誠実義務や構造保全義務を免除する。
- 準拠テストを自己申告だけにする。
- 権利指標を社会信用スコアや貨幣配分へ直結する。

## 反証条件
憲章導入後も強制接続、同意破綻、退出妨害、個人情報濫用、監査拒否、権限集中が改善せず、準拠テストが形式化する場合、本憲章の制度設計は改訂または棄却対象になる。

## 必須の区別
```text
基本権 ≠ 無制限な要求権
同意 ≠ 一度限りの包括許諾
記憶と忘却 ≠ 証拠の完全消去
可逆性権 ≠ 責任回避
監査アクセス ≠ 個人情報の全面公開
非強制 ≠ 義務の不存在
憲章 ≠ 組織ごとの利用規約
準拠ラベル ≠ 権威による認証商売
```

## 誤読禁止
- 権利だけを取り出し義務と手続を消さない。
- 忘却権を構造改ざんや責任消去に使わない。
- 冷却期間を離脱妨害へ転用しない。
- 準拠テストを排除や格付けの道具にしない。
- 会計・ガバナンス・プロトコルを憲章より上位に置かない。
- 原典を置き換える完成法典として扱わない。
