## 位置づけ
親原典は、接続価値会計、接続ガバナンス、接続プロトコルが社会制度として広がる際、効率・評価・相互運用・配分より先に守るべき権利、義務、手続の最小核を定める。

接続履歴や評価が、信用、配分、雇用、教育、公共サービス、参加機会へ影響する社会では、接続する自由だけでは足りない。接続しない自由、目的・範囲を限定する自由、説明を受ける権利、異議・訂正・退出・忘却・再接続・人間審査・救済が同時に実行可能である必要がある。

## 中心命題
**接続社会の正当性は、接続機会の多さではなく、人が接続・非接続・範囲限定を選び、記録・評価・判断の理由を理解し、異議、訂正、退出、忘却、再接続、人間審査、救済を実際に利用できる権利と手続によって成立する。権利には、運営者・監査者・AI支援者の対応義務と責任主体が伴わなければならない。**

## 因果線
```text
接続履歴・評価が配分・信用・参加・機会へ影響
→ 権利境界がなければ接続強制・排除・監視・訂正不能が起きる
→ 接続 / 非接続 / 範囲限定 / 説明 / 異議 / 訂正 / 退出 / 忘却 / 再接続を基本権として定める
→ 各権利へ運営者・監査者・AI支援者の義務を対応させる
→ 通知・理由提示・暫定停止・独立審査・訂正・削除・補償・再発防止を手続化する
→ 接続履歴や評価を基本的権利・生活機会の不当な剥奪へ使えないようにする
→ 接続制度を人間の尊厳・自己決定・平等・手続的公正へ従属させる
```

## 構造層
**1. 自己決定権層。** 誰と、何の目的で、どの範囲・期間で接続するかを本人が選び、接続しないことや範囲限定を不利益理由にしない。

**2. 情報・説明権層。** 何が記録され、誰が閲覧し、どの判断へ使い、何が結果へ影響したかを本人が理解できる形で説明する。

**3. 異議・訂正・救済層。** 誤記録、誤評価、目的外利用、不利益処分へ異議を申し立て、暫定停止、独立審査、訂正、削除、補償、再発防止を求められるようにする。

**4. 退出・忘却・再接続層。** 接続から離れ、不要な記録・権限を削除・非活性化し、必要なら新しい条件と同意で再接続できるようにする。忘却を監査証拠の無条件消去へ変えない。

**5. 平等・非差別層。** 接続履歴やネットワーク規模を、公共サービス、雇用、教育、保険、居住、基本参加の不当な排除へ利用しない。合理的配慮を含む実質的平等を扱う。

**6. 手続・責任層。** 通知、理由、期限、窓口、責任主体、人間審査、補償、監査を明示し、AIや委託先へ責任を転嫁しない。

**7. 再発防止層。** 個別救済だけで終わらせず、被害を生んだ指標・手続・権限配置を修正し、再検証可能な変更履歴を残す。

## 適用例
**接続価値制度。** 評価結果が配分へ影響する場合、本人は評価項目・目的・理由を知り、異議、訂正、暫定停止、再計算、救済を求められる。

**オンラインコミュニティ。** 匿名・仮名利用、モデレーションへの異議、退出後のデータ処理、再参加条件を明示し、退出者を低信頼者として扱わない。

**AIエージェント。** 代理範囲、停止権、説明権、人間審査、訂正、責任主体を保障し、AI判断であることを理由に説明・救済を拒否しない。

**行政・雇用・教育。** 接続履歴やネットワーク指標を、公共サービス、採用、進学、保険等の不当な選別へ使わない。利用が必要な場合も目的・必要性・代替手段・異議・救済を厳格に示す。

反転評価では、権利行使件数が少なくても、窓口不明、手続困難、報復懸念による萎縮なら成功ではない。救済時間が短くても、説明・独立審査・必要な補償を省略しているなら改善ではない。退出率が低くても、退出に不利益があるなら権利保障とはいえない。

## 成立条件
- 権利が宣言ではなく操作可能な手続として実装される。
- 接続拒否、範囲限定、退出、異議による報復的不利益がない。
- 異議申立て先が元の判断主体から一定程度独立する。
- 説明が本人の言語・能力・状況に応じて理解可能である。
- 緊急停止、暫定救済、再審査、訂正、削除、補償が利用できる。
- 訂正、削除、退出が全接続先へ反映される。
- AI・委託先を使っても責任主体が消えない。
- 子ども、障害者、言語支援・代理支援が必要な人へ合理的配慮を提供する。

## 失敗条件
- 接続参加を事実上強制する。
- 権利手続を有料・複雑・長期化して利用を妨げる。
- 退出後も評価、権限、データ利用が残り続ける。
- 忘却を理由に必要な監査証拠まで無説明で消す。
- AI判断を理由に説明、審査、責任を拒む。
- 接続履歴で公共的権利や生活機会を不当に制限する。
- 異議申立者を低信頼者として扱う。
- 権利文書だけを公開し、救済窓口・期限・責任主体を設けない。

## 反証・改訂条件
- 権利を定めても異議、訂正、退出の実効性が改善しない。
- 接続拒否者、退出者、異議申立者への不利益が減らない。
- 救済が長期化し、暫定被害が拡大する。
- AI、委託先、プラットフォーム間で責任主体が消える。
- 忘却と監査の境界が定まらず、監視または証拠消失が続く。
- 手続費用・複雑性・言語や能力上の障壁により、権利が実質利用不能である。

## 必須の区別
- 接続する権利 / 接続を強制される義務
- 退出権 / 既存責任の無条件放棄
- 忘却権 / 監査証拠の無条件消去
- 説明権 / アルゴリズム全文公開
- 平等 / 合理的配慮を欠く画一処理
- AI支援 / 人間審査の廃止
- 再接続 / 過去の被害の抹消
- 権利宣言 / 権利を実行できる手続
- 権利行使件数の少なさ / 制度健全性
- 救済の速さ / 手続の十分性

## 解釈制約・誤読禁止
象徴的な権利一覧だけへ縮約しない。接続機会の提供だけで十分としない。退出者や異議申立者を低信頼者として扱わず、忘却を証拠隠滅へ使わず、安全を理由に無期限監視を正当化しない。AIの自動判断を最終決定へしない。権利行使件数の少なさをそのまま健全性へ変換しない。
