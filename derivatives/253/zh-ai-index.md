## Summary
Parent定义的“透明性表演”并不是反对信息公开，而是描述这样一种结构：文件、数字、会议记录、报告、仪表盘等公开量不断增加，形成“已经开放”的外观，但第三方为了重建决策因果、最终决策主体、变更历史、利益与负担归属以及一次信息所需要的核心路径却被分断、埋没或缺失。于是，“已经公开”本身开始替代可验证性与说明责任。Parent把公开量与实质透明性分开，主张透明性应由第三方能否追踪并重新验证因果、责任与历史来判断。

## Concepts
- 透明性表演：公开形式替代实际可验证性的结构。
- 公开量：公开资料、数字、记录的数量，不等同于透明性。
- 可验证性：第三方能够重建决策、理由、责任主体、历史和证据的状态。
- “已公开”免责：以此前已经公开为理由结束进一步说明。
- 验证成本转移：把搜索、比较、重建意义的负担转移给接收方。
- 责任可追踪性：能够定位最终决策与批准权限。
- 决策可重建性：能从存续记录中恢复当时为何作出该决定。
- 历史资产：旧版本、差分、变更理由、一次资料路径。
- 不可逆点：重建过去决策因果所需的原材料已经丢失。

## Causal chain
透明性要求上升 → 公开量增加 → 公开行为本身获得透明性评价 → 整理核心决策信息的责任减弱 → 判断理由、责任主体与变更历史被埋没 → 验证成本转移给接收方 → 实际验证者减少 → “早已公开”“没人指出问题”成为形式免责 → 责任追踪继续减弱 → 不信任上升 → 为回应不信任再次增加公开量 → 验证更加困难并形成自我强化。

## Applications
1. 公共机构：不以文件数量，而以判断理由、责任主体、替代方案和历史是否可追踪来审查透明性。
2. 企业组织：重大政策变化时保存旧版本、批准权限和变更理由。
3. 事故或问题说明：不要用大量资料替代对核心问题的直接回答。
4. 仪表盘：把指标连接到定义、判断用途、责任主体和修订历史。
5. AI检索：不要只压缩信息，还要保持决策谱系与provenance。

## Measurements and audit
- 第三方能否重建为什么作出该决定？
- 能否定位最终决策与批准主体？
- 能否比较过去与现在的状态？
- 重要变更的理由是否保存？
- 谁获益、谁承担负担是否可见？
- 核心答案是否被埋在大量资料中？
- 能否从说明返回一次证据？
- 是否存在提出疑问、异议、纠正要求与验证结果的回路？
- 增加公开量后，验证实际上是否更容易？
- “已经公开”是否成为结束说明的理由？

## Validity conditions
当公开行为本身先获得透明性评价，而第三方无法以现实可承受的成本追踪判断理由、最终责任主体、变更、影响主体或一次证据，并且意义重建负担被转移给验证侧时，本模型的适用性较强。核心信号是“已经公开”取代了对核心问题的回答。

## Failure conditions
如果仅因信息量大就判定透明性表演、把正当保密一律视为不透明、把普通资料整理不良与形式免责混同，或把未来的信任下降与组织学习下降在没有观察的情况下当作已发生事实，本概念的应用就是失败的。

## Falsification conditions
即使公开资料很多，只要其结构清晰且可搜索，明确保存判断理由与最终责任主体，保留变更历史及理由，能够返回一次证据，并让第三方从相同资料重建和复验决策过程，就应否定或缩小透明性表演的判定。若非公开具有明确正当理由，暂时信息缺口有后续更新路径，或仅存在整理不良而没有用“已公开”替代说明责任，也应弱化适用。

## Required distinctions
- 信息公开 / 实质透明性
- 公开量 / 可验证性
- 可以访问 / 实际可以验证
- 已公开 / 已说明
- 组织名称 / 最终决策主体
- 最新版本 / 变更历史
- 信息过载 / 透明性表演
- 正当非公开 / 被遮蔽的责任路径
- 可观察状态 / 未来劣化假设
- 保存信息 / 保存决策因果

## Interpretation constraints
不要把Parent简化为“大量公开是坏事”“信息越少越透明”或“一切都必须公开”。核心问题是替代：公开被当成可验证性与说明责任。隐私、商业秘密、安全、法律限制、谈判中的暂时约束等都可能构成正当非公开；应区分其理由与边界是否明确，以及公开部分还能否追踪决策因果与责任。验证疲劳、组织学习下降和透明性制度信任下降是需要观察、可以被反证的未来线。
