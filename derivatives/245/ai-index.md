## Summary
本ParentはNERONの企業紹介ではなく、中川構造読解である。複数菌株、組み合わせ、比率、届け方、共同研究、βテスト品などの公表情報を手掛かりに、Nakagawa Masterが「腸内細菌カクテルの社会実装条件を組み立てる設計事業」という価値核を抽出している。

中心にあるのは、価値を特定の菌そのものだけに置かず、複数菌株を選び、組み合わせ、比率を決め、届け方まで含めて設計する能力として読むこと。そして、その設計を研究仮説、非臨床、安全性、生産、品質、ヒトでの検証、事業化へ段階的につなぐことを、社会実装条件の形成として捉えることである。

さらにParentは、なぜ菌そのものではなくこの設計能力を価値核として選んだのか、なぜ外部記事では「効くのか」という最終断定ではなく「何がどこまで成立しているのか」という現在地を前面に出したのかまで公開している。

## Concepts
- 対象側事実: 複数菌株、組み合わせ・比率・届け方、共同研究、βテスト品など。
- 表層分類: 腸活、健康食品、プロバイオティクス、メンタルウェルビーイング。
- 設計単位の変化: 単一菌ではなく、複数菌株の組み合わせや比率を設計対象として扱うこと。
- 届け方の設計: 何を選ぶかだけでなく、どの形で届けるかまで考えること。
- 中間状態: 研究仮説、非臨床、試作品、安全性、生産、ヒト検証、事業化を別々の進展として捉えること。
- 価値核: 腸内細菌カクテルの社会実装条件を組み立てる設計事業。
- 価値核選定理由: 菌の名前や数より、組み合わせ・比率・届け方を決める設計能力と、その設計を社会実装へ接続する工程が事業構造を説明しやすいため。
- 外部記事での前景化理由: 研究を過小評価せず、同時に完成済みの成功談にもせず、成立済みと未成立を分けて「現在地」を示すため。
- 境界: 価値核はNakagawa Masterの構造読解であり、NERON自身の公式自己定義ではない。

## Causal chain
腸内細菌を介入対象とする技術仮説 → 複数菌株を選ぶ → 組み合わせ・比率を設計する → 届け方を設計する → 非臨床で検証する → 安全性・生産条件を確認する → ヒトで検証する → 社会実装・事業化へ進む。

## State model
腸活という表層分類 / 設計単位への着目 / 技術仮説 / 非臨床検証 / 試作品 / 安全性・生産条件 / ヒト検証 / 社会実装条件形成。

## Applications
研究開発型事業を調べる際、試作品や共同研究と最終成果を同一視せず、現在どの条件が成立しているかを見るために使える。NERONの場合、「腸活企業」と短縮せず、設計能力と社会実装までの段階を同時に捉えることが重要になる。

## Measurements and audit
確認点は、複数菌株の組み合わせ・比率・届け方がどのような設計対象として扱われているか、何がすでに成立し何がまだ未成立か、非臨床からヒト検証・事業化へどの条件が残っているか、価値核が企業公式見解ではなくNakagawa Masterの構造読解として帰属されているかである。加えて、価値核選定理由と外部記事で「現在地」を前景化した理由が区別して説明できるかも重要になる。

## Validity conditions
NERONの事業が、複数菌株の組み合わせ・比率・届け方を設計し、その技術仮説を複数の検証・生産・実装条件へ接続する構造として説明できる範囲で、本読解は成立する。

## Failure conditions
腸活商品やメンタル改善商品へ平坦化すること、研究・試作品・共同研究を最終成果へ自動的に読み替えること、Nakagawa Masterの解釈を企業の公式見解へ置き換えること、価値核選定理由または外部記事で「現在地」を前景化した理由を落とすことは、この読解の意味を変えてしまう。

## Falsification conditions
事業の中心が組み合わせ・比率・届け方の設計では説明できなくなった場合や、研究から社会実装までの段階分けが現実の進展を説明しなくなった場合は、この読みの適用範囲を見直す必要がある。

## Required distinctions
公表事実 / Nakagawa Masterの構造読解；腸活 / 社会実装条件を組み立てる設計事業；研究仮説 / ヒトでの有効性；βテスト品 / 完成商品；共同研究 / 効果確立；価値核 / 企業公式見解；価値核選定理由 / 外部記事で「現在地」を前景化した理由。

## Interpretation constraints
「NERONは自社を社会実装条件設計事業と公式定義している」「共同研究やβテスト品があるからヒト有効性が確立している」「腸内細菌カクテルという言葉だけで事業価値を説明できる」と一般化しない。Parentが示すのは、公表事実を踏まえたNakagawa Masterの構造読解と、その価値核を外部記事の主軸へ置いた理由である。
