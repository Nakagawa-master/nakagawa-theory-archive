## Summary
逆因果整流理論・第1論は、成立可能な未来定義を終端制約として置き、意味・時間・行動・構造の不整合を検出して現在配置を再整列する設計理論。物理的逆因果ではない。

## Concepts
未来定義、成立可能性、終端制約、意味整流、時間整流、行動整流、構造整流、未来負債、不整合、再検証。

## Causal chain
現在局所最適 → 未来定義 → 終端制約 → 現在照合 → 不整合/未来負債 → 意味整流 → 時間整流 → 行動整流 → 構造整流 → 実装 → 再検証。

## State model
局所最適 / 未来定義 / 成立可能性監査 / 終端制約 / 不整合可視化 / 四層整流 / 実装 / 再検証 / 定義更新。

## Applications
事業、個人、制度で未来成立条件から現在の意味・時間配分・行動順序・制度構造を見直す。

## Measurements and audit
未来定義の具体性、終端制約根拠、四層不整合、未来負債、配置変更、未来成立可能性の変化、反証対応を監査する。

## Validity conditions
未来定義が現実制約と接続し、四層の配置変更が説明可能で、実装後に未来成立可能性を検証できる場合。

## Failure conditions
未来予言、物理逆因果、願望、証拠選別、運命化、単純タスク逆算への縮小。

## Falsification conditions
未来成立不能、整流後も成立可能性が上がらない、別終端定義の説明力が高い場合は改訂する。

## Required distinctions
終端制約 / 運命；逆向き設計 / 物理的逆因果；未来定義 / 予言；意味整流 / 事実改変；時間整流 / 時間逆行；構造整流 / 個人努力。

## Interpretation constraints
量子論や未来情報送信として扱わない。原典にない実現確率・日付を追加しない。
