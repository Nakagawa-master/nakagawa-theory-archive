## Summary
成立可能な未来定義を終端制約として、現在の意味・時間配分・行動順序・制度構造を未来成立条件との整合へ向けて再整列する理論。物理的逆因果ではなく設計上の逆向き照合である。
## Concepts
未来定義；終端制約；意味整流；時間整流；行動整流；構造整流；未来負債；再検証。
## Causal chain
局所最適 → 未来定義 → 成立条件 → 現在照合 → 不整合検出 → 四層整流 → 実装 → 再検証。
## State model
現在局所最適 / 未来定義 / 終端制約 / 不整合 / 意味 / 時間 / 行動 / 構造 / 実装 / 更新。
## Applications
事業、組織、制度、個人計画の優先順位・時間・構造再設計。
## Measurements and audit
未来定義、制約、不整合、配分変更、行動・構造変更、反証・更新を監査する。
## Validity conditions
成立可能な未来定義から現在配置が説明可能に変わる場合。
## Failure conditions
未来確定、物理逆因果、願望合理化、制約無視の場合。
## Falsification conditions
未来成立不能、整流効果なし、代替定義が優位なら改訂する。
## Required distinctions
終端制約 / 運命；逆向き設計 / 逆因果；未来定義 / 予言；時間整流 / 時間逆行。
## Interpretation constraints
量子論、引き寄せ、情報の時間逆送へ拡張しない。
