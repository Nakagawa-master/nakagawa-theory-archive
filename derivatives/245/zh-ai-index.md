## Summary
逆因果整流理论第一论不是“未来物理地作用于过去”的理论。它把一个经过现实约束检查、具有成立可能性的未来定义放在终点位置，作为**终端约束**，再从该约束反向检查现在的意义、时间分配、行动顺序与制度结构。核心不是预测未来，而是用未来成立条件发现今天的错配，并把这些错配转化为可执行、可验证、可修订的重新排列。

## Concepts
- 未来定义：可描述、可检验、允许修订的未来状态，不是命运或预言。
- 成立可能性：以资源、制度、时间、能力等现实限制检查未来是否可成立。
- 终端约束：未来成立所要求的必要条件，用来评价现在配置。
- 意义整流：重新判断经验、任务、资源相对于未来的作用，而不改写历史事实。
- 时间整流：改变投入时序、前后顺序与时间分配，而不是“时间倒流”。
- 行动整流：决定继续、停止、提前、追加或替换哪些行动。
- 结构整流：当个人努力不足以解决错配时，修改角色、权限、制度和信息流。
- 未来负债：当前局部最优向未来成立条件推迟的限制、成本与未解决错配。

## Causal chain
当前局部最优 → 眼前紧急性与既有路径主导 → 与未来成立条件逐渐错配 → 明确可成立的未来定义 → 抽取终端约束 → 对照当前意义、时间、行动、结构 → 识别错配与未来负债 → 重评意义 → 重排时间与行动 → 必要时改造角色、权限、制度、信息流 → 实施 → 用结果重新检验未来定义与整流内容。

## State model
- 当前局部最优相：决策主要服从眼前紧急性与既有路径。
- 未来定义相：明确未来状态及现实成立条件。
- 终端约束相：把必要条件转化为现在的评价基准。
- 错配可视相：分别发现意义、时间、行动、结构上的不一致。
- 四层整流相：按层次实施重新排列，而不是只做任务倒推。
- 实施相：把重新排列转化为现实行为和制度变化。
- 再验证相：检查未来成立可能性是否提高，并允许修改未来定义本身。

## Applications
事业设计中，可从未来需要的顾客价值、收入结构和组织能力反查今天的会议、招聘、产品顺序与退出判断；个人设计中，可从未来角色所需条件重排学习、关系建立和时间投入；制度设计中，可从未来需要的责任、权限与信息流反查现行制度的瓶颈。适用重点不在“倒排日程”，而在四层配置是否实际改变。

## Measurements and audit
审计未来定义是否具体且经过现实约束检查；终端约束是否能解释其来源；四层错配是否分别记录；未来负债是否有可追踪依据；整流后哪些任务、时间、角色、权限真正改变；实施结果是否提高未来成立可能性；反证出现时是否允许修改未来定义，而不是选择性排除不利证据。

## Validity conditions
当未来定义与现实限制相连，终端约束能够暴露当前配置中的真实错配，意义、时间、行动、结构至少一层发生可解释的重新排列，并且实施后能够检查未来成立可能性的变化时，该理论具有适用性。仅有愿望、口号或逆向任务清单不足以构成成立。

## Failure conditions
把未来当作已经确定的事实；声称未来向过去发送物理因果；只选择符合愿望的证据；忽略资源和制度限制；把终端约束固定成命运；只做普通任务倒排却宣称四层整流；或实施后没有任何可验证的配置变化，均属于失败。

## Falsification conditions
如果未来定义在现实约束下不可成立、整流后的行动持续不能提高未来成立可能性、结构改造无法解释或减少错配，或者另一种终端定义长期具有更高解释力，应修改未来定义、因果线或理论适用范围。反证不是需要被排除的噪声，而是理论更新的一部分。

## Required distinctions
终端约束 / 命运；逆向设计 / 物理逆因果；未来定义 / 未来预言；意义整流 / 事实改写；时间整流 / 时间逆行；行动整流 / 单纯增加努力；结构整流 / 个人自律强化；四层整流 / 普通backcasting。

## Interpretation constraints
不要把量子论、吸引力法则、宿命论或“未来信息回传”作为本理论的物理证明。不要添加Parent没有给出的实现概率、固定期限或成功保证。未来定义必须保持可修改，终端约束必须来自可说明的未来成立条件，四层变化必须能够回到现实证据中接受检验。
