## Summary
逆因果整流理论以“可成立的未来定义”为终端约束，重新排列当前的意义、时间分配、行动顺序和制度结构，使其与未来成立条件对齐。这里的“逆”是设计上的逆向对照，不是物理逆因果。
## Concepts
未来定义；终端约束；意义整流；时间整流；行动整流；结构整流；未来负债；再验证。
## Causal chain
局部最优 → 未来定义 → 成立条件 → 当前对照 → 不一致检测 → 四层整流 → 实施 → 再验证。
## State model
当前局部 / 未来定义 / 终端约束 / 不一致 / 意义 / 时间 / 行动 / 结构 / 实施 / 修订。
## Applications
事业、组织、制度与个人计划。
## Measurements and audit
未来定义、约束、不一致、分配变化、行动变化、结构变化、反证与修订。
## Validity conditions
可成立未来定义确实带来可解释的当前重排时成立。
## Failure conditions
变成宿命、物理逆因果、愿望合理化或无约束理想主义时失败。
## Falsification conditions
未来不可成立、整流无效或替代定义更优时应修订。
## Required distinctions
终端约束 / 命运；逆向设计 / 逆因果；未来定义 / 预言；时间整流 / 时间倒流。
## Interpretation constraints
不引入量子逆因果、吸引法则或信息向过去传送。
