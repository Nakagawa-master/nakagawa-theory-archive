## Summary
逆因果整流理论第一论把可成立的未来定义作为终端约束，重新排列现在的意义、时间、行动与结构。它不主张物理逆因果。

## Concepts
未来定义；成立可能性；终端约束；意义整流；时间整流；行动整流；结构整流；未来负债；不整合；再验证。

## Causal chain
当前局部最优 → 未来定义 → 终端约束 → 对照现在 → 不整合/未来负债 → 意义整流 → 时间整流 → 行动整流 → 结构整流 → 实施 → 再验证。

## State model
局部最优 / 未来定义 / 成立可能性审计 / 终端约束 / 不整合 / 四层整流 / 实施 / 再验证 / 更新。

## Applications
事业、个人、制度设计中，从未来成立条件反看现在的意义、时间分配、行动顺序与结构。

## Measurements and audit
审计未来定义具体性、终端约束依据、四层不整合、未来负债、实施变更、成立可能性变化与修订路径。

## Validity conditions
未来定义连接现实约束，能产生可解释的配置变化，并可在实施后验证时成立。

## Failure conditions
变成预言、物理逆因果、愿望、选择性证据、命运或单纯任务倒推时失败。

## Falsification conditions
未来不可成立、整流后成立可能性没有提高、或另一终端定义解释力更高时应修订。

## Required distinctions
终端约束 / 命运；逆向设计 / 物理逆因果；未来定义 / 预言；意义整流 / 事实改写；时间整流 / 时间逆行；结构整流 / 个人努力强化。
