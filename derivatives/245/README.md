## 位置づけ
逆因果整流理論・第1論は、未来が物理的に過去へ作用するという逆因果を主張する理論ではない。成立可能な未来定義を**終端制約**として置き、その未来が成立するために必要な条件から現在を逆向きに照合し、意味・時間・行動・構造の不整合を検出して再整列する設計プロセスを記述する。未来は確定情報ではなく、現在の設計を評価するための変更可能な終端条件である。

## 中心命題
現在起点だけで意思決定すると、目前の緊急性、過去の経路依存、既存制度の局所最適が優先されやすい。そこで未来定義を終端制約として置き、「その未来が成立するには何が必要か」を現在へ戻して照合する。すると、現在の活動が未来に必要な意味を持つか、時間配分が正しいか、行動順序が適切か、個人努力ではなく制度・役割・情報流を変える必要があるかが見える。価値核は、**未来からの超自然的作用ではなく、未来定義を評価基準に現在の因果配置を整流すること**である。

## 因果線
```text
現在起点の局所最適
→ 目先の緊急性・経路依存が優先
→ 意味・時間・行動・構造が未来成立条件から分散
→ 成立可能な未来定義を明示
→ 終端制約として必要条件を抽出
→ 現在のノード・時間配分・行動・制度と照合
→ 不整合と未来負債を検出
→ 意味を再評価
→ 時間配分・順序を再設計
→ 行動を停止・前倒し・追加
→ 必要なら役割・制度・情報流を改修
→ 実装結果から未来定義と整流内容を再検証
```

## 構造層
1. **未来定義層**: 到達状態を検討可能な条件として記述する。
2. **成立可能性層**: 資源・制度・時間・能力等の現実制約と照合する。
3. **終端制約層**: 未来成立に必要な条件を現在評価の基準にする。
4. **意味整流層**: 活動・資源・経験の役割を未来との関係で再評価する。
5. **時間整流層**: 緊急度だけでなく未来成立条件から配分・順序を組み替える。
6. **行動整流層**: 継続・停止・前倒し・追加行動を再配置する。
7. **構造整流層**: 個人努力で解けない不整合を制度・権限・役割・情報流へ戻す。
8. **未来負債層**: 現在の局所最適が将来へ押し出す制約・コストを可視化する。
9. **検証層**: 整流が未来成立可能性を実際に高めたか確認する。

## 状態モデル
現在局所最適相 → 未来定義相 → 成立可能性監査相 → 終端制約化相 → 不整合可視化相 → 意味整流相 → 時間整流相 → 行動整流相 → 構造整流相 → 実装相 → 再検証・未来定義更新相。

## 適用例
事業では、将来成立させたい顧客価値・収益構造・組織能力を終端制約にし、現在の会議、採用、開発順序、撤退判断を見直す。個人では将来役割に必要な条件から今日の時間配分・学習・関係構築を再配置する。制度では、未来状態に必要な権限・情報・責任から現在制度のボトルネックを逆照合する。単なるタスク逆算ではなく、意味・時間・行動・構造の複数層が連動して変わることが重要である。

## 測定・監査点
- 未来定義が具体的で成立可能性を検討できるか。
- 終端制約が何を要求するか説明できるか。
- 現在不整合の根拠を追えるか。
- 意味・時間・行動・構造を区別して変更したか。
- 未来負債がどこで生まれているか追えるか。
- 整流後の行動が未来成立可能性を高めたか。
- 不都合な証拠を排除していないか。
- 反証時に未来定義自体を修正できるか。

## 成立条件
未来定義が現実制約と接続し、終端制約との照合によって意味・時間・行動・構造の少なくとも一部が説明可能に再整列され、実装後に未来成立可能性の変化を検証できる場合に成立する。

## 失敗条件
未来を確定事実とする、未来が過去へ物理作用すると読む、願望に合う証拠だけを選ぶ、現実制約を無視する、終端制約を運命へ固定する、単なるタスク逆算だけで四層整流を名乗る場合は失敗する。

## 反証・改訂条件
未来定義が成立不能、整流後の行動が未来成立可能性を上げない、構造変更をしても不整合が解消しない、別の終端定義がより高い説明力を持つ場合は定義・因果線・適用範囲を改訂する。

## 必須の区別
終端制約 / 運命；逆向き設計 / 物理的逆因果；未来定義 / 未来予言；意味整流 / 事実改変；時間整流 / 時間逆行；構造改修 / 個人努力の強化；整流 / 単純なタスク逆算。

## 誤読防止／解釈制約
量子論、宿命論、引き寄せ、未来からの情報送信へ圧縮しない。原典にない実現確率・日付・物理主張を追加しない。未来定義は変更可能な設計条件として保持する。
