## 位置づけ
逆因果整流理論・第1論は、未来が物理的に過去へ作用するという逆因果を主張する理論ではない。成立可能な未来定義を終端制約として置いたとき、現在の意味付与、時間配分、行動順序、制度・構造が、その未来との整合に向けて再整列されるプロセスを記述する。

## 中心命題
現在起点だけで意思決定すると、過去の経路依存、目前の緊急性、既存制度の局所最適が行動を支配しやすい。これに対し、成立可能な未来状態を終端制約として明示し、その成立に必要な条件を現在側へ戻して照合すると、意味、時間、行動、構造の不整合が見える。理論の中心は、未来からの超自然的作用ではなく、**未来定義を基準に現在の因果連鎖を整流する設計操作**にある。

## 因果線
`現在起点の局所最適 → 意味・時間・行動・構造が分散 → 成立可能な未来定義を置く → 未来成立条件を抽出 → 現在のノード・行動・制度と照合 → 不整合・未来負債を検出 → 優先順位・順序・構造を組み替える → 現在行動が未来定義と整列`

## 構造層
1. **未来定義層**: 到達状態を検討可能な条件として記述する。
2. **終端制約層**: 未来成立に必要な条件を、現在設計を評価する基準として置く。
3. **意味整流層**: 現在の活動・資源・経験の役割を未来との関係で再評価する。
4. **時間整流層**: 緊急度だけでなく、将来成立条件から時間配分と順序を見直す。
5. **行動整流層**: 必要行動、停止行動、前倒し行動を組み替える。
6. **構造整流層**: 個人努力だけで解けない不整合を、制度・役割・情報流・権限へ戻して改修する。
7. **検証層**: 終端制約が現実制約と矛盾しないか、行動が成立可能性を上げたかを再検証する。

## 状態モデル
現在局所最適 / 未来定義 / 終端制約化 / 不整合可視化 / 意味整流 / 時間整流 / 行動整流 / 構造整流 / 実装 / 再検証・未来定義更新。

## 適用例
事業では「来期売上」だけでなく、成立させたい顧客価値・組織能力・収益構造を終端制約にし、今の会議、採用、開発順序を見直す。個人では将来役割に必要な条件から、今日の時間配分、学習、関係、撤退判断を再構成する。制度では未来状態に必要な権限・情報・評価構造から現在制度のボトルネックを逆照合する。

## 測定・監査点
未来定義の具体性／成立可能性／終端制約の根拠／現在不整合の説明可能性／時間配分・行動順序・構造変更の有無／未来に先送りした負債の可視化／反証に応じた未来定義修正を記録する。

## 成立条件
未来定義が現実制約と接続し、終端条件から現在への照合によって意味・時間・行動・構造の少なくとも一部が説明可能に再整列される場合に成立する。

## 失敗条件
未来を確定事実とする、未来が過去へ物理作用すると読む、願望に合わせて証拠を選ぶ、現実制約を無視した理想像から現在を断罪する、終端制約を変更不能な運命へ固定する場合は失敗する。

## 反証・改訂条件
未来定義が成立不能、整流後の行動が未来成立可能性を上げない、別の終端定義がより高い説明力を持つ場合は定義・因果線・適用範囲を改訂する。

## 必須の区別
終端制約 / 運命；逆向き設計 / 物理的逆因果；未来定義 / 未来予言；意味整流 / 事実改変；時間整流 / 時間逆行；構造改修 / 個人努力の強化。

## 誤読禁止 / 解釈制約
量子論、宗教的宿命、引き寄せ、未来からの情報送信へ圧縮しない。理論が扱うのは、未来定義を評価基準として現在の配置を変える設計プロセスである。原典にない数値確率・実現日を追加しない。
