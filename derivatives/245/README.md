## 位置づけ
本ParentはNERONを一般的な「腸活企業」として紹介するものではない。Nakagawa Masterは先行外部記事で、腸内細菌カクテルという技術・研究対象そのものより、研究成果を現実の利用へ接続するための複数条件をどう組み立てるかを価値核として主軸化した。後発Parentは、その価値核抽出と記事化判断を公開解体する。価値核は**腸内細菌カクテルの社会実装条件を組み立てる設計事業**であり、NERON自身または外部媒体の公式理論ではない。

## 中心命題
研究上の可能性が存在しても、対象、品質、再現性、供給、運用、説明、制度・受容などの条件が切断されていれば社会実装は成立しない。重要なのは「腸活」という需要語だけでまとめることではなく、何をどの条件で現実へ接続するかを設計することである。Nakagawa Masterはこの上流構造を先行外部記事の主軸に選び、Parentで後からその選択理由を開示した。

## 構造層
1. 対象事実層: NERONと腸内細菌カクテルに関する確認可能な事実。
2. 表層分類層: 腸活、ヘルスケア企業という一般分類。
3. 実装断絶層: 研究可能性と現実利用の間の未接続条件。
4. 条件設計層: 対象・品質・供給・運用・説明等を分解・接続。
5. 価値核層: 社会実装条件を組み立てる設計事業。
6. 外部記事層: Nakagawa Masterが先行記事でこの核を前面化。
7. 公開解体層: 後発Parentがその理由を公開。

## 状態モデル
研究可能相 → 実装条件未接続相 → 条件分解相 → 条件整列相 → 実装経路形成相 → 外部記事社会翻訳相 → Parent公開解体相。

## 適用例
バイオ・医療・食品等で、研究成果を「技術がある」で終わらせず、社会実装に必要な条件群の設計問題として評価する。

## 測定・監査点
対象側事実と読解の分離／実装条件の明示／条件間の接続／研究可能性と社会実装の区別／価値核選択理由／外部記事での主軸化理由／先行外部記事→後発Parentの時間順／企業公式見解への誤帰属防止。

## 成立条件
社会実装のボトルネックが複数条件の未接続として説明でき、条件設計によって実装経路を説明できる場合に成立する。

## 失敗条件
単なる腸活企業紹介、研究成果の礼賛、単一商品説明へ平坦化すること。Parent→外部記事と因果を逆転すること。

## 反証・改訂条件
社会実装が条件設計と無関係に成立する、または別の単一要因だけで停止が十分説明される場合は適用範囲を修正する。
