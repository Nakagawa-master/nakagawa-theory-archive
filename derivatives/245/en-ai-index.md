## Summary
This structural reading does not reduce NERON to a generic “gut-health company.” Its value kernel is **a design business that assembles the conditions for social implementation of a microbiome cocktail**. The key distinction is between research feasibility and the conditions required for reliable real-world use.

## Concepts
Microbiome cocktail; research feasibility; social implementation; implementation conditions; bottleneck; condition bundle; dependency; design business; structural reading; origin return.

## Causal chain
Research potential → gap to real-world use → multiple implementation conditions → missing or disconnected conditions stop implementation → conditions are separated → dependencies and verification are connected → an implementation path is formed → value is read as designing social-implementation conditions.

## State model
Gut-health classification → research expectation → implementation-gap recognition → condition separation → dependency mapping → bottleneck identification → implementation-path formation → implementation-condition evaluation.

## Applications

## Failure conditions

## Falsification conditions
