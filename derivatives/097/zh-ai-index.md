## Summary
本原典把合意从说服和投票扩展为“不侵蚀自由的结构在时间中持续反复”。三个原则是时间同步、伦理不可侵犯、存在余白。结构律动、可观察性与反例耐性形成暂时完成认知，使合意从程序转为习惯，再转为共享地形。沉默绝不能自动等同于同意；异议、退出和再合意必须始终可用。只有在降低沟通压力后，协作、再参照和自走仍可持续时，非强制共鸣假设才得到支持。

## Concepts
沉默合意；共鸣；时间同步；伦理不可侵犯；存在余白；结构律动；暂时完成；社会地形。

## Causal chain
```text
说服依赖 → 压力上升 → 保护余白 → 结构反复 → 修复反例 → 暂时合意 → 习惯 → 地形
```

## State model
```yaml
- 保护余白
- 反复律动
- 保留异议
- 修复反例
- 增加再参照
- 形成习惯
- 形成地形
```

## Applications
会议、研究共同体、人类-AI共创、公共治理。

## Measurements
发言压力、异议使用、再参照、再合意、自走、修复时间。

## Validity / failure / falsification
必须保留异议与退出。把沉默当作同意、把共鸣变成忠诚评分、排除反对者都属于失败。若结构反复不能改善持续协作，应修正假设。

## Interpretation constraints
不得作为隐蔽说服、思想统一或未来合意决定论。
