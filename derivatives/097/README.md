## 位置づけ

親原典は、協業・共創を努力と妥協の産物としてではなく、理念・行為・記録の同位相反復がつくる「非言語の整合」から自然に立ち上がる非強制的共鳴として再定義する。沈黙の合意は、社会的記憶の更新を通じて未来の合意へ転位し、関係は偶然の一致ではなく構造的必然として生成される。この過程を原典は「照応の文明」と呼ぶ。

## 中心命題

照応は同調ではない。構造律動が共通の「地形」を先に作ることで、関係者は同じ前提に立ちながら異なる軌跡を歩ける。合意は都度の手続きから習慣へ、習慣から地形へ移行し、関係の調整コストが下がる。

原典の準構文は次の通り。

```text
構造律動（反復の整合）
× 観測可能性（痕跡の公開）
× 反例耐性（修復の拍）
＝ 仮完了の認知
→ 未来の合意（共鳴の基盤）
```

## 照応の三原則

### 1. 時間軸の同期（拍の一致）
出力・応答・更新・レビューが基準拍を共有する。臨時の増減があっても基準拍は崩さず、互いの時間感覚を侵さない。

### 2. 倫理的不可侵性（矛盾の排除）
都合で前提を差し替えず、過去→現在→未来で非矛盾を保つ。同じ前提に立ちながら異なる選択ができるため、意見一致より強い基盤となる。

### 3. 存在の余白（自律の保証）
語りすぎず、沈黙・距離・保留を関係の容器として設計する。余白は理解不足ではなく、自律を守り共鳴域を広げる構造である。

## 関係の自己生成

照応の文明では、目的達成後に関係が解散するのではなく、達成そのものが次の整合の証拠となる。拍・温度・余白が保たれる限り、関係は依存ではなく負荷を増やさない持続的照応として深まる。

原典は三つの抽象型を示す。

- 長波固定・短波可変
- 温度のグラデーション
- 痕跡の水平連結

これらは手順や秘匿アルゴリズムではなく、外部から拍と修復の仕方を観測できる姿勢である。

## 非強制的共鳴の倫理

原典は明示的に「関係に入る自由」と「離脱する自由」を同時に保証する。拍が合わないときに無理に周波数を上げないことが最良の倫理であり、整合は説得や権威では維持できないとする。

この原典は感情操作や相手の行動を変える具体手法へ踏み込まず、「関係の容器としての構造」を扱う。個別対話ログ・感情操作手順・内部関係運用ルール・個人特性依存方法は秘匿境界に置く。批判的観測と反例指摘は歓迎し、構造改善へ転化する。

## 実務への抽象カタログ

- 入口の均質化：招待・着席・初回説明の入口を同じ拍で整える。
- 終わらせ方の恒常性：合意・未了・宿題の区切り方を固定する。
- 余白の制度化：沈黙・保留・持ち帰りを制度として用意する。
- 記録の節度：見栄えより欠落の少なさを優先する。
- 転位の合図：新段階では頻度でなく、間・余白・終わらせ方の意匠を小さく変える。

## 統合監査要旨

原典末尾は、沈黙の合意を共鳴文明OSへ拡張し、共有主語・位相設計（拍・周期・温度）・語彙辞書・一次ログ・公開抄録をT/S/Rの境界で運用する。RC、CEA、位相安定S、LPI、撤回成功率等が閾値を逸脱する、または過熱・同調圧・有害ロックインが観測される場合、仮説を棄却・改訂する。

## 必須の区別

- 照応と同調を区別する。
- 沈黙の合意と情報不足による盲信を区別する。
- 非強制的共鳴と説得・権威による維持を区別する。
- 存在の余白と関心・説明の欠落を区別する。
- 関係の持続と依存を区別する。
- 原典自身が明示する離脱自由・秘匿境界・監査条件と、派生側が追加する一般ガードレールを区別する。

## 原典へ戻る理由

本派生物は検索・理解・構造照合面である。照応、沈黙の合意、構造的必然、三原則、入る自由／離脱する自由、実務カタログ、監査語彙は親原典を優先する。原典にない一般安全論へ置換せず、原典自身の非強制倫理は削らない。
