## Summary
親原典は、原始仏教を宗教体系として導入せず、認識OSの構造を透明化する補助言語として五蘊・非我・苦を限定的に参照する。五蘊を身体・物理条件、一次感覚、認知像、反応傾向、認識機能という経験OSの五レイヤーとして読み、中川OSの水底の地形、水面の揺れ、映る像、風・流れ、水面の透明度へ対応させる。非我は自己否定ではなく「五蘊＝私」という固定ラベルを外し、現象を観測対象へ戻す視座移動プロトコルである。苦は消去すべき敵ではなく、観測者が水面へ沈み込んだことを知らせる位置ズレの警告として読まれる。巻き込まれ→俯瞰→超俯瞰へ観測位置を移し、心身・呼吸・思考・自己ラベルを調整することで認識OSの透明度を高める。

## Concepts
- **五蘊:** 色・受・想・行・識からなる経験OSの五レイヤー。
- **色:** 身体・物理条件。水底の地形に対応する。
- **受:** 快・不快・中性等の一次感覚。水面の最初の揺れ。
- **想:** 記憶・予測・解釈・ストーリー。揺れに映る像。
- **行:** 習慣・衝動・自動反応。風・流れに相当する。
- **識:** 認識機能。水面の透明度と解像度。
- **非我:** 五蘊への固定自己ラベルを外す視座移動。
- **巻き込まれ:** 感情・思考と自己を同一化した観測状態。
- **俯瞰:** 水面状態を対象として観察する位置。
- **超俯瞰:** 内面と外界を同じ自然現象として観測する位置。
- **苦:** 誤同一化・位置ズレから発生する反応現象としての警告。
- **補助言語:** 認識OSを透明化する比較語彙であり、宗教的権威付けではない。

## Causal chain
```text
五蘊／水面現象を固定的な自己とみなす
→ 身体・感覚・思考・反応へ自己ラベルが貼られる
→ 観測者が現象へ巻き込まれる
→ 波・風・濁りを自己や世界の本質と誤認する
→ 苦・自動反応・構造誤読が持続する
→ 五蘊を経験OSのレイヤーへ分解する
→ 各現象を観測対象へ戻す
→ 自己ラベル生成自体を観測する
→ 巻き込まれから俯瞰へ移る
→ 内面と外界を同一観測面へ載せる
→ 超俯瞰の位置を確保する
→ 苦を位置ズレの警告として読む
→ 心身・呼吸・思考量を整える
→ 水面ノイズが減る
→ 構造認識の透明度が上がる
```

## Applications
- 怒りを「私」へ固定せず、身体反応・感覚・解釈・衝動・認識へ分解して観測する。
- 不安時に未来予測と恐怖を分離し、睡眠・呼吸・物語生成の影響を確認する。
- 組織対立で個人反応と役割・評価・情報経路等の外部構造を同時に観測する。
- 意思決定前に生理条件と認知ノイズを分離し、観測位置を回復してから判断する。
- 継続的な苦を、どこへ自己・所有ラベルを貼っているかを示す信号として読む。

## Measurements and audit
- 五蘊の各レイヤーを区別して観測できるか。
- 自己ラベル生成をラベルとして認識できるか。
- 巻き込まれ、俯瞰、超俯瞰の位置差を説明できるか。
- 苦を自己価値や世界全体へ即一般化していないか。
- 生理条件と観測位置の関係を再観測できるか。
- 観測位置修正後に自動反応・構造誤読が減るか。
- 補助言語が宗教的権威付けへ変質していないか。
- 外的危険や制度問題を認識問題へ還元していないか。
- 現実判断と責任遂行が改善しているか。

## Validity conditions
- 原始仏教語を補助言語へ限定する。
- 五蘊を観測可能な経験レイヤーとして扱う。
- 非我を自己否定ではなく視座移動として扱う。
- 苦を単純な悪へ還元しない。
- 内面現象と外部構造を両方観測する。
- 生理条件を認識精度から切り離さない。
- 構造的同期を全体系の同一性へ拡張しない。

## Failure conditions
- 原始仏教を中川OSの権威付けに使う。
- 五蘊を固定的性格分類へ変える。
- 非我を人格否定や責任放棄へ変える。
- 感情抑圧や苦の消失だけを成功とする。
- 超俯瞰を現実逃避や感情切断へ使う。
- 外部危険・損害・制度問題を無視する。
- 生理条件を無視して認知操作だけで解決しようとする。

## Falsification conditions
自己ラベルの外部化、観測位置移動、心身・呼吸・思考条件の調整を行っても、自動反応、構造誤読、現実判断、責任遂行が改善せず悪化するなら、五蘊対応や実装仮説を改訂する。補助言語が構造理解を透明化せず、宗教的権威付けや概念混同を増やす場合、その対応付けは弱めるか撤回する。
