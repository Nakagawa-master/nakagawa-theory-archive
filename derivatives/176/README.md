## 位置づけ
親原典は、原始仏教を宗教体系として中川OSへ取り込むことを目的とせず、認識OSで扱う構造をより鮮明に読むための補助言語として限定的に参照する。扱うのは信仰、救済、儀礼、教団制度ではなく、構造、認識の物理現象、観測者の位置、因果の動作という骨格である。

中心となる接続は五蘊である。色・受・想・行・識を、身体・物理条件、一次感覚、認知像、反応傾向、認識機能という「人間という経験OSの五レイヤー」として読み直し、中川OSの水底の地形、水面の揺れ、映る像、風・流れ、水面の透明度へ対応させる。原典は、この対応を通じて、五蘊を固定的な自己と見なす誤ラベリングと、水面の波や濁りへ観測者が沈み込む状態が同型であると論じる。

非我は自己否定や自我破壊として扱われない。五蘊を「私そのもの」とするラベルを外し、身体・感情・思考・傾向性・認識機能を自然現象として観測対象へ戻す視座移動プロトコルとして読む。中川OSの巻き込まれ→俯瞰→超俯瞰という三段階では、感情＝自分、思考＝自分という巻き込まれから、水面状態を対象として見る俯瞰を経て、内面と外界を同じ自然現象として観測する超俯瞰へ移る。

苦も消去すべき敵として定義されない。原典では、五蘊や水面の現象へ「これは私だ」「これは私の問題だ」と誤同一化することで発火する反応現象として読み直される。したがって苦は、観測者の位置が水面の中へ沈み込んでいることを示す警告音として利用できる。苦そのものを叩くより、どの現象へどのラベルを貼り、どの位置から観測しているかを確認することが認識OSの修正につながる。

親原典は、心身、呼吸、思考、自己ラベル、内外界の配置を「水面から出るための構造条件」として具体化する。睡眠・栄養・呼吸・姿勢などの生理条件を整え、呼吸を静め、物語生成を間引き、「私」という自動ラベル自体を観測し、内面と外界を同じスクリーンへ載せる。これらは宗教儀式ではなく、観測者の位置を正しい場所へ戻すための物理的・認知的措置として扱われる。

## 中心命題
親原典の中心命題は、**五蘊・非我・苦という原始仏教の語を、認識OSの水面・地形・気象・観測者モデルを透明化する補助言語として用い、身体・感情・思考・傾向性・認識機能を固定的な自己から分離して観測対象へ戻し、巻き込まれから超俯瞰へ観測位置を移すことで、構造認識の歪みを減らすこと**にある。

この接続は宗教的一致の宣言ではない。原典が抽出するのは、二つの体系が異なる語彙で記述している認識構造の骨格的同期であり、原始仏教の全教説と中川OSが同一であるという一般化は含まれない。

## 構造層
**1. 色／物理条件層。** 身体、環境、経済状況等の与件を、水底の地形に相当する物理条件として扱う。

**2. 受／一次入力層。** 快・不快・中性等の感覚的受け取りを、水面に最初に生じる揺れとして観測する。

**3. 想／認知像層。** 記憶、予測、解釈、ストーリーを、揺れる水面に映る像として扱う。像を地形そのものと混同しない。

**4. 行／傾向性層。** 習慣、衝動、自動反応を、波を起こす風・流れとして読む。

**5. 識／認識機能層。** 何をどこまで見分けられるかという水面の透明度・解像度を扱う。

**6. 誤ラベリング層。** 五つの現象レイヤーへ固定的な「私」を貼り付けることで、観測者が現象へ沈み込む。

**7. 視座移動層。** 巻き込まれ→俯瞰→超俯瞰の順に、現象と観測者の関係を再配置する。

**8. 苦・警告層。** 苦を排除対象ではなく、誤同一化と観測位置ズレの存在を知らせる反応として読む。

**9. 物理・認知条件層。** 心身、呼吸、思考量、自己ラベル、内外界の置き方を観測位置回復の条件として調整する。

**10. 透明化層。** 補助言語の役割は信仰化ではなく、認識OSの構造を分解・観測しやすくすることである。

## 適用例
**1. 強い怒り。** 「私は怒っている」から「怒りという受・想・行が発生している」へ表現を分解し、怒りを否定せず観測対象へ戻す。反応前に身体感覚、解釈、衝動を分ける。

**2. 不安による未来予測。** 不安を未来そのものと扱わず、身体条件、感覚、物語、反応傾向、認識機能のどこで歪みが発生しているかを確認する。

**3. 組織内対立。** 「自分が否定された」という一体化から、事実、感覚、解釈、習慣的防御反応を分離し、構造上の役割・評価・情報経路へ観測を戻す。

**4. 重要意思決定。** 睡眠不足や呼吸の粗さ、連続的な物語生成が強い場合、それらを意思決定内容と混ぜず、観測位置が回復するまで入力面を整える。

**5. 継続的な苦。** 苦を敵として抑圧する前に、どの現象へ「私」「私の価値」「私の所有」を貼っているかを観測し、位置ズレを検出する。

## 測定・監査点
- 身体・感覚・認知像・反応傾向・認識機能を区別して観測できるか
- 「これは私だ」という自動ラベルを、ラベルとして認識できるか
- 巻き込まれ、俯瞰、超俯瞰のどの位置にいるかを説明できるか
- 苦を即座に自己価値や世界の本質へ一般化していないか
- 心身・呼吸・思考量の変化で観測位置がどう変わるかを再観測できるか
- 内面と外界をともに自然現象として観測する位置を維持できるか
- 五蘊対応を宗教的真理の証明ではなく補助言語として扱っているか
- 原始仏教全体と中川OS全体を同一体系として一般化していないか
- 観測位置の修正後、反応の自動性や構造誤読が減るか
- 構造仮説が後続事象と合わない場合に改訂できるか

## 成立条件
- 原始仏教の語を認識OS理解の補助言語へ限定する。
- 五蘊を固定的自己ではなく観測可能な経験レイヤーとして扱う。
- 非我を自己否定ではなく誤ラベリング解除と視座移動として読む。
- 苦を単純な悪や消去対象へ還元しない。
- 身体・感情・思考・傾向性・認識機能を分けて観測する。
- 巻き込まれから俯瞰、超俯瞰への位置差を保持する。
- 心身・呼吸・思考等の条件を観測位置と切り離さない。
- 二体系の「構造的同期」を全概念の完全同一性へ拡張しない。

## 失敗条件
- 原始仏教を中川OSの宗教的権威付けとして利用する。
- 五蘊を固定的な性格分類へ変える。
- 非我を自己否定、自己破壊、責任放棄へ変換する。
- 苦を感じないこと自体を成功とする。
- 強い感情を抑圧し、観測対象から外す。
- 「超俯瞰」を現実逃避や当事者責任の放棄へ使う。
- 生理条件を無視し、認知だけで常時観測位置を維持できるとする。
- 原始仏教と中川OSの全体系が完全一致すると一般化する。

## 反証・改訂条件
五蘊分解、自己ラベルの外部化、観測位置の移動、心身・呼吸・思考条件の調整を行っても、対象状況で反応の自動性、構造誤読、苦の誤帰属が改善せず、むしろ現実判断や責任遂行が悪化する場合、対応関係や実装仮説を改訂する。補助言語が構造理解を透明化せず、宗教的権威付けや概念混同を増やすなら、その対応付けは弱めるか撤回する。

- 五蘊という経験レイヤー / 固定的な自己。
- 非我 / 自己否定。
- 苦の観測 / 苦の抑圧。
- 巻き込まれ / 俯瞰 / 超俯瞰。
- 自然現象としての感情 / 自分の本質としての感情。

- 構造的同期 / 全体系の完全同一。

## 誤読禁止 / 解釈制約
- 原典の「完全一致」「同じ構造」という強い表現は、本文で抽出された認識骨格の対応範囲に閉じ、歴史的・宗教的・哲学的全体系の同一性へ一般化しない。
- 五蘊や非我の説明を、原始仏教研究全体についての学術的コンセンサスの代替にしない。
- 非我を人格否定、自尊感情の否定、法的・倫理的責任の否定へ展開しない。
- 超俯瞰を解離、麻痺、感情切断の推奨へ変えない。
- 心身条件の調整を医学的治療の代替とみなさない。
- 苦を位置ズレの警告として読むことを、外部の損害や危険が存在しないという意味へ拡張しない。

## 親原典へ戻る理由
五蘊と水面モデルの個別対応、巻き込まれ・俯瞰・超俯瞰の三段階、心身・呼吸・思考・自己ラベルの具体条件、苦を誤帰属と警告音として読む論証、原始仏教を補助言語に限定する射程は、Parent Post 1908の本文文脈に依存する。宗教的主張と構造的比喩の境界を誤らないため、重要判断では親原典へ戻る必要がある。
