## 位置づけ
接続価値会計が接続を測り配分する技術であるのに対し、本論はその測定・配分が権力集中、指標ハック、囲い込み、声量競争へ歪むことを防ぐ「守る技術」を扱う。公式派生物068は、接続ガバナンスを管理強化や秘密主義へ誤読せず、正統性・監査・反ゲーミング・可逆性を一体で読むための原典回帰面である。

## 中心命題
接続社会は、価値を測るだけでは持続しない。目的の公開性、手続の可監査性、利害の非集中、参加・退出・再接続の可逆性を制度化し、複数観測点、複合指標、外乱耐性、二室モデル、紛争処理を通じて、接続価値を歪みから守る必要がある。

## 因果線
```text
接続が価値単位になる
→ 指標最適化・囲い込み・権限集中の誘因が生じる
→ 会計だけでは価値の健全性を保証できない
→ 正統性の四条件を先に固定する
→ What / Who / How / Whenで監査を構成する
→ 複合指標・移動標的・逆インセンティブ・外乱テストでゲーミングを抑える
→ 公開室と機関室を分離し透明性とプライバシを両立する
→ 参加・離脱・再接続・仲裁を可逆手続として保障する
→ 接続報酬社会を持続可能な制度へ変える
```

## 構造層
1. **正統性層**: 目的公開、可監査性、利害非集中、可逆性。
2. **監査層**: 対象、主体、方法、頻度を分離し、独立観測点で交差検証する。
3. **反ゲーミング層**: 複合指標束、移動標的、逆インセンティブ、外乱注入。
4. **透明性・保護層**: 理念・集計・監査要旨を公開し、算式・重み・個人情報を保護する。
5. **紛争・可逆層**: 参加、退出、再接続、仲裁、公開審査要旨。
6. **進化管理層**: 半年レビュー、目的変位監視、外部ベンチマーク、モデルドリフト対策。

## 適用例
- **B2B研究連携**: MAIによる再合意短縮を成果配分に参照し、第三者を含む四半期監査を行う。
- **市民協働**: CDIを参加枠設計に使う一方、退出自由と異議申立てを先に保障する。
- **コミュニティ運営**: 声量や囲い込みを逆インセンティブで抑え、再接続可能性を評価する。
- **AI支援制度**: モデルの判断を責任主体にせず、ログ、説明、訂正、外部監査を必須にする。

## 測定・監査点
- 目的、判断過程、利益相反が説明可能か。
- RC、ER、CEA、S、Rollback Cost、ゲーミング検出率が基準内か。
- 単一主体へ権限・データ・評価が集中していないか。
- 退出、再接続、訂正、削除が実際に機能するか。
- 指標上昇と関係品質改善が一致するか。
- 公開室と機関室の境界が越権や隠蔽に使われていないか。
- 月次・四半期・半年レビューで目的変位を発見できるか。

## 成立条件
- 正統性の四条件を運用開始前に固定する。
- 複数の独立観測点を置く。
- 単一指標による配分を禁止する。
- 指標の重みと個人情報を適切に保護する。
- 監査要旨と変更履歴を公開可能にする。
- 参加・退出・再接続・異議申立てを保障する。
- 利益相反を開示し、監査主体を交代可能にする。
- 目的変位とモデルドリフトを定期検証する。

## 失敗条件
- 指標を貨幣化・投機化する。
- 声量や接続数だけを価値とみなす。
- 非公開手順を特定主体の恣意的支配に使う。
- 監査主体と運営主体が実質同一である。
- 退出や訂正を形式だけにする。
- 短期キャンペーンの成果を制度の健全性と誤認する。
- 個人を信用点数で格付けする。
- 公開性を理由に個人情報や防御手順を露出する。

## 反証条件
RC・ER・CEA・Sが継続的に閾値を外れる、Rollback Costが増大する、ゲーミング検出率が上がる、監査後も権限集中・囲い込み・疲弊・退出困難が改善しない場合、本設計は棄却または改訂対象となる。

## 必須の区別
```text
ガバナンス ≠ 管理強化
透明性 ≠ 全情報公開
非公開重み ≠ 無監査の秘密主義
接続密度 ≠ 人気・フォロワー数
可逆性 ≠ 無責任な離脱
監査 ≠ 監視
反ゲーミング ≠ 利用者への敵対
正統性 ≠ 権威者の承認
```

## 誤読禁止
- 接続社会の中央集権化として読まない。
- AIやアルゴリズムへ統治責任を移さない。
- 指標の非公開を説明責任免除に使わない。
- 監査ログを個人監視や広告最適化へ流用しない。
- 可逆性を履歴抹消や責任回避と同一視しない。
- 原典を置き換える完成制度として扱わない。
