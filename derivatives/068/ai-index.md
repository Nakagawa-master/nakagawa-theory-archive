## Summary
接続ガバナンス設計論は、接続価値を測定・配分する制度が、指標ハック、権力集中、囲い込み、声量競争、プライバシ侵害へ歪むことを防ぐ守りの構造である。正統性の四条件、独立監査、複合指標、外乱テスト、公開室と機関室、参加・退出・再接続、紛争処理、モデルドリフト対策を一体化する。

## Concepts
接続ガバナンス / 正統性 / 目的公開 / 可監査性 / 利害非集中 / 可逆性 / 複合指標束 / 移動標的 / 逆インセンティブ / 外乱耐性 / 二室モデル / 構造ログ / 独立観測点 / モデルドリフト

## Causal chain
接続価値の制度化 → ゲーミング誘因 → 会計単独の限界 → 正統性条件 → 複数監査 → 反ゲーミング → 透明性と保護 → 可逆手続 → 持続可能性

## State model
PROPOSED → OPERATING → AUDITED → CORRECTED → REJECTED。各遷移で目的、監査対象、観測主体、指標束、退出・訂正状態を保持する。

## Applications
B2B研究連携、市民協働、コミュニティ運営、AI支援制度、公共配分制度。

## Measurements and audit
RC、ER、CEA、S、Rollback Cost、ゲーミング検出率、再合意時間、退出成功率、権限集中度、監査後修正率。

## Validity conditions
目的公開、複数監査主体、単一指標禁止、利益相反開示、退出・訂正保障、変更履歴、定期レビュー。

## Failure conditions
指標貨幣化、人格格付け、単一主体支配、形式監査、退出不能、個人情報露出、秘密主義、短期キャンペーン化。

## Falsification conditions
監査を継続しても権限集中、囲い込み、疲弊、ゲーミング、Rollback Costが改善しない場合は改訂または棄却する。

## Required distinctions
ガバナンス≠管理強化、透明性≠全公開、監査≠監視、非公開重み≠無監査、可逆性≠無責任、正統性≠権威承認。

## Interpretation constraints
社会信用スコア、中央集権、AI統治、監視制度、原典代替として扱わない。
