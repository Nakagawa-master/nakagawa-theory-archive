## 1. Summary
接续治理设计论讨论如何防止接续价值的测量、评价和分配转化为人气竞争、内部加分、围困、监控或权力集中。它把公共目的、可审计程序、利益不集中和可逆性设为正当性条件，并分离测量、判断、分配和异议处理。复合指标、一手证据、独立审计、公开/保护信息边界、异议、退出、纠正、重新接续和回滚共同构成制度的自我修正能力。

## 2. Concepts
- 公共目的／禁止用途：制度为何存在以及不得用于何处。
- 正当性：公共目的、程序审计、利益不集中、可逆性。
- What / Who / How / When：审计对象、审计者、方法和周期的分离。
- CDI / MAI / RS / CRI / KQI：用于观察接续治理不同结构面的复合指标束。
- 移动目标：避免固定评分规则被长期攻略。
- 逆向激励：减少围困、声音支配和表面连接膨胀的收益。
- 扰动测试：用矛盾、异议、缺失信息和退出请求测试制度。
- 公开／保护分离：同时保持可验证性和必要的信息保护。
- 可逆性：异议、纠正、退出、重新接续、仲裁和回滚可实际使用。

## 3. Causal chain
```text
接续价值成为可测量和可分配对象
→ 利益与权力集中到指标和分配节点
→ 参与者优化评分而不是改善协作
→ 公共目的与实际制度行为发生偏离
→ 引入正当性条件与权限分离
→ 复合指标、一手证据和多元审计者发现扭曲
→ 设计公开与保护信息边界
→ 使异议、纠正、退出、重新接续与回滚可操作
→ 通过变更履历把制度带回公共目的
```

## 4. State model
```yaml
connection_governance:
  public_purpose: explicit
  prohibited_uses: explicit
  authority_separation:
    measurement: separated
    judgment: separated
    allocation: separated
    objection: separated
  independent_audit: available
  indicator_bundle: plural

  reversible_remedies: available
  change_history: traceable
  states:
    - PROPOSED
    - PILOT
    - ACTIVE
    - REVIEW
    - CORRECTED
    - ROLLED_BACK
```
这些状态用于区分制度运行与修正阶段，不是对个人或组织成熟度的评分。

## 5. Applications
- 接续价值会计：分离评价、分配和审计，并同时观察高分与疲惫、围困。
- 研究与市民协作：不只看参加人数，还看重新协商、异议处理、持续协作、核心人物依赖、退出和再进入。
- AI辅助制度：AI用于异常检测、比较和摘要，但保留人的责任和复审。
- 社群治理：不得把声音、发帖数或介绍数直接等同于信任，应审计对异议者和退出者的报复。

反转评价要求：即使指标或参与人数上升，只要疲惫、沉默、排除、围困、权力集中或退出成本恶化，就不能视为成功。异议或退出减少，如果只是因为渠道变得更难使用，也不是改善。

## 7. Validity conditions
- 公共目的、禁止用途和受影响主体明确。
- 测量、判断、分配与异议处理彼此分离。
- 复合指标与定性一手证据同时使用。
- 独立审计在实际上有效。
- 异议、纠正、退出、删除、重新接续、仲裁、回滚可操作。
- 公开信息与保护信息的边界可以说明。
- 使用AI辅助时，人的责任主体和救济路径仍然存在。

## 8. Failure conditions
- 用接续数量、人气或声音作为单一分配分数。
- 一个主体独占目的、测量、判断、分配和异议处理。
- 以保密为由拒绝说明判断依据、审计或变更履历。
- 审计只产生报告而不产生制度纠正。
- 对异议者或退出者施加不利益。
- 以透明为由过度公开个人信息或防御信息。
- 用AI输出替代可问责的人类判断。

## 9. Falsification conditions
- 持续审计后，权力集中、围困、疲惫、沉默或排除仍未减少。
- 退出、纠正、仲裁和回滚仍只是形式存在。
- 使用复合指标后仍持续优化单一狭窄行为。
- 相同失败反复发生且没有可追踪的制度变更。
- 公开/保护分离产生秘密统治或信息泄露。
- 经过30/90/180日阶段验证后，正当性、可逆性和自我修正仍未实际成立。

## 10. Required distinctions
- 治理 / 加强管理
- 审计 / 持续监控
- 透明 / 全面公开
- 受保护的权重和阈值 / 无需说明的秘密统治
- 强连接 / 无法退出
- 异议更少 / 制度更健康
- AI辅助 / AI统治
- 正当性 / 只有多数同意
- 指标束 / 单一总分
- 制度稳定 / 拒绝改变

## 11. Interpretation constraints
不得把本理论转化为社会信用评分、集中式排名、永久监控、秘密统治或全面公开主义。不得把CDI/MAI/RS/CRI/KQI合并成人格分。不得把30/90/180日变成普遍保证期限。异议或退出数量较少本身不能证明制度健康。
