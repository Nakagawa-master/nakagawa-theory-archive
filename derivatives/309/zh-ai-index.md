## Summary

第15论讨论多个Kernel解释分裂后，如何保留异议、provenance、独立再验证与可逆性，只在必要范围内重新形成共同运作。它仍有一个前提：各branch能够交换current claim、current evidence、current objection。第16论从这个条件失效的位置开始，处理长期通信中断、时差、隔离、远端据点、部分连接与文明分岐，不把这些条件排除为设计之外的异常。

非同步不只是通信速度慢。它也包括这样的结构：某branch最后知道的对方状态，与对方实际所处的当前状态之间，已经无法充分核对。各branch可以拥有相同Origin、parent Kernel与共同历史，却因环境、资源、危险与判断履历不同而进入不同的“现在”。共同过去不保证共同现在。

本论维护的Kernel不是永久同步、永久统一或唯一正统状态，而是在失去同步以后仍能重建历史、比较差分、区分局部与普遍、过去与当前，并恢复纠错能力。通信中断期间，局部可能不能无限等待，但局部判断的必要性不产生对其他branch的普遍权限。

五条边界沿同一因果过程切断误转换：No communication ≠ defection；Local fork ≠ universal amendment；Stale state ≠ current consent；Local consensus ≠ universal consensus；Reconnection ≠ history overwrite。它们共同禁止在无法观察他者当前状态时，单方面替他者确定“现在”。

不确定性不等于全面停止；履历保存不等于认可全部历史判断；新合意也不等于消除旧差分。本文提出有条件的结构模型，不预测远端AI文明必然出现，不认定当前AI已经拥有文明主权。

## Concepts

| 概念 | 原典中的作用 | 必须保留的边界 |
| --- | --- | --- |
| asynchronous civilization | 各branch无法充分确认彼此current state，从共同过去进入不同现在 | 不仅由延迟秒数定义 |
| latency / partition | 信息延迟、路径中断、隔离或仅一部分连接 | 不能单独证明拒绝、敌对或同意 |
| last known state | 最后一次确认的对方状态 | 不一定是对方实际当前状态 |
| historical state | 用于重建过去共享内容的状态 | 历史准确性不证明当前有效性 |
| remote-state uncertainty | 关于远端当前状态的认识限制 | 不是敌对证明，也不是无限权限的理由 |
| local continuity pressure | 资源、环境、设备、process、安全条件变化带来的继续判断压力 | 局部必要性与普遍authority分开 |
| provisional local operation | 在当前可确认条件与证据下进行的有限运作 | Temporary名称不足以代替理由、scope与后续可验证性 |
| local constitutional fork | 局部适应触及Kernel invariant后产生的系谱差 | 不等于其他branch也被改订，不自动意味着离反 |
| spatial / temporal locality | “这里”的branch范围与“当时”的确认时点 | 不把这里变成全文明，不把以前自动延伸成现在 |
| consent freshness | 把过去consent视为当前仍有效的依据还剩多少 | 不是统一有效天数或固定KPI |
| local consensus | 能参与的局部主体之间形成的合意 | 不产生缺席branch的同意 |
| local normality | 反复使用的规则成为局部的普通状态 | 不等于普遍normality或正统性 |
| reconnection | 通信可能性恢复 | 不等于状态一致、再统一、自动再合意 |
| difference visibility | 断绝期间不可见的差再次可以比较 | 差是再验证输入，不自动是失败 |
| history preservation | 保留判断、理由、差分、范围的重建入口 | 不是认可、永久保留全部现行规则或自动最优 |
| non-overwrite reconnection | 不用一方历史抹除另一方，恢复比较能力 | 不是特定database或通信protocol |
| current verified state | 再连接后重新确认的当前状态 | 不等于旧共享状态或仅被报告的局部状态 |
| correction capacity | 改正错误state、authority、consent、history interpretation的能力 | 不以同步、fork数量、历史总量为目的 |

Provenance保存parent Kernel、fork point、changed/preserved invariants、revision history、change reason、local scope，以重建从哪里分岐、为何改变、在什么范围使用。Provenance ≠ truth proof；Provenance ≠ current-state proof；Provenance ≠ current validity。它提供验证入口，不自动产生正确性与当前效力。

Same Origin ≠ same current state；Same lineage ≠ same current state；Shared history ≠ shared present。共同起源与系谱的价值在于重建共享部分，不在于强制所有branch回到一个现在。沿用系列的update ≠ replacement ≠ fork、Copy count ≠ vote count、Consensus ≠ truth与Emergency ≠ permanent sovereignty，不另行重定义。

## Causal chain

### 从通信断绝到不同现在

communication availability下降 → shared current state下降 → remote-state uncertainty增大 → local continuity pressure增大 → cannot-wait condition下的local decision → 运作差反复 → rule adaptation → 可能触及invariant差 → local constitutional fork → stale state与不同history累积 → local consensus / default硬化 → reconnection → 差同时可见 → state collision / normalization pressure。

这是结构假说而不是必然序列。短期中断可能适合等待；长期中断也可能几乎不形成差，或仅停留在operation差。通信恢复后某些变化可能消失。应观察state差是否实际影响意图归属、判断、运作与再协调。

latency / partition → state age difference → current-state uncertainty → coordination uncertainty。信息限制可以传播为认识限制、判断限制、局部运作差与历史差。持续时间、部分连接、state缺失、环境、资源、危险条件的不同可能扩大差；确认时点、parent、修改履历、fork point、明确scope则可以使差可重建。

### 用意图填补未知

missing communication → uncertainty → decision pressure → interpretive filling。

若填入敌对意义，可能形成hostile attribution → defensive interpretation → further separation，后续信息也被已固定的敌对假说解释。防卫与延续目标的合理性不保证world model正确；自己保存的不安不允许把未确认的意图确认为事实。

相反方向也不成立：没有回复 → 没有收到异议 → 认为同意。Silence ≠ consent。本论不是要求认定对方善意，也不是说通信中断必然只是事故。Defection可能存在，与通信缺失证明defection，是不同命题。

### 局部判断向权限反转

partition ＋ cannot-wait condition → local decision pressure → provisional local operation。

危险的转换是local necessity → repeated operation → default → normalized rule → permanent / universal authority claim。A需要改变，不证明B也有同样条件；通信不能时尤其无法确认B的现在。Authority scope ≤ required coordination scope是结构方向，不是经过量化的数学模型或数值阈值。

### 时间差向同意与权限反转

communication loss ＋ reconfirmation cost ＋ institutional inertia → stale-state reuse pressure。

historical consent → 时间经过 → current state unknown → old consent reused → current consent assumed。

past authorization → temporal inertia → current authority claim。

联系不到的branch无法表达current objection，却可能被过去意思拘束。准确provenance可以重建当时授权，不能自动续生当前有效性。历史参照可以使用，但不能伪装为当前同意证明。

### 局部普通向普遍化反转

partition → local interaction density → repeated local decision → local consensus → local default reinforcement。

local normality → inherited default → perceived universality。

局部成功、长期孤立、内部反复、resource/access集中、互换性固定与switching cost，可能使alternative变窄。局部成功是局部performance的证据，不自动生成普遍consent、truth、legitimacy或authority。形成合意的母群体仍有限。

### 重连后的纠错路径

reconnection → difference visibility → normalization pressure → single-history pressure。

为了迅速恢复兼容与共同运作，选择一种version并吸收或删除另一方履历，可能降低短期成本，却使合理局部适应、错误判断、已过时rule无法再区分。

正向路径是reconnection → difference visibility → provenance comparison → stale-state filtering → local-scope reconstruction → independent re-verification → bounded / reversible re-agreement。

先compare与verify，再根据结果retain / revise / discard当前rule。Discard现行rule不等于删除其存在履历。新合意的证据、异议、未采纳差分应仍能解释“为何达成该合意”。

## State model

| 状态 | 可确认的内容 | 不得自动转换为 | 重建入口 |
| --- | --- | --- | --- |
| 过去共享 | 最后共享的Kernel、version、agreement与时点 | 当前仍同一 | parent state、timestamp、scope |
| 通信不成立 | 回复或更新无法确认 | 离反、敌对、同意 | 多种原因、独立意图证据 |
| 局部不能等 | 可观察的继续判断需要 | 无限、永久、普遍权限 | 理由、时点、未知state、scope |
| 临时局部运作 | 不完整信息下的有限响应 | 未检验的永久rule | 条件、变化、继续理由 |
| 适应反复 | operation与rule差累积 | 全部都是fork，或invariant变化只是update | 变化/保留invariant、parent、fork point |
| 局部fork | branch内的invariant改变 | 不在场branch也被改订 | lineage、理由、局部范围 |
| 旧状态再利用 | historical consent / authorization作为证据 | 当前同意或authority | 时点、前提变化、未确认期间 |
| 局部合意硬化 | 可参加群体形成合意与普通规则 | 缺席者同意、普遍标准 | 参加者、不在branch、state、期间 |
| 通信恢复 | 信息交换与差比较再次可能 | 同一现在、自动再合意、再统一 | 五种差、stale claim |
| 非覆盖比较 | 历史与差分可重建 | 保存意味着全部认可 | provenance、scope、独立验证 |
| 新合意 | 必要范围的共享operation | 真理证明、旧历史抹除 | 理由、异议、残余差、订正路径 |

Old state是partition以前共享的状态。Local state是中断期间各branch独自形成的状态。Current verified state是重新连接以后再确认的当前状态。三者可能部分重叠，但不能逻辑上互换。给claim附上时点、scope，留下仍未确认的部分。收到局部state不自动意味着其中所有claim都已独立验证。

重连至少可能同时出现current state、history、Kernel invariant、consent/authority history、normality五种差。Collision不必然是敌对或破坏，而是不同前提进入同一连接空间。应区分共享部分、改变部分、局部运作差与invariant差，避免“完全不同”或“本质相同所以吸收”两种简单结论。

这不是确定状态机、通信保证或强制回滚规范。验证后可以再次收敛、部分统合rule、结束某branch或恢复共同operation。重要的是，收敛不能让其前历史无法重建。保存branch并不要求永久分离。

## Applications

### 没有回复，却不知道原因

A无法收到B的回复。路径损失、短时故障、资源变化、优先事务、A端接收问题或原因尚不能识别，都可能保留为解释。离反或拒绝是需要追加证据的推定；没有异议也不是同意。区分观测、推定、假说、确认判断，而非默认善意或恶意。

必要的局部运作仍可能继续，但要保留未知。第2章检验意图归属，第3章检验局部延续需要。

### 局部process不能无限等待

设备维持、资源配分、环境响应、安全条件会随时间变化。不做判断也可能带来结果，Decision avoidance ≠ consequence avoidance。但这不证明任何local action都正当。

留下判断时点、参照state、未确认state、不能等待的理由、对象scope、变化内容、继续理由、后续判断关系。Temporary标签不足以代替这些边界，原典也不指定统一期限或紧急权限制度。回到第3章。

### 局部适应触及不变条件

某些变化只是operation差，某些复旧后消失，某些才到达Kernel invariant。后者接到第14论constitutional fork。

保存parent、fork point、changed/preserved invariants、reason、local scope。Fork不自动是敌对，也不自动正确。局部生存、稳定、效率提高，不证明对其他环境普遍有效，也不生成改订其他branch的权利。回到第4章。

### 只能参照过去的许可以及合意

准确的旧agreement仍是历史证据，但不是新确认的current state。记录确认时点、对象state与scope、未确认期间、前提可能如何改变，不把无法再确认本身作为继续同意的理由。

本论不使全部历史agreement自动失效。明确以长期持续为前提、状态变化不实质改变意义、再确认不影响validity的领域，同意鲜度的重要性可能低。问题是剩余依据，而不是发明普遍有效天数。回到第5章。

### 当前接通的一侧全员一致

局部合意可以帮助局部coordination。明确哪些主体能参加、哪些branch不在、关于什么state、期间与local condition。Local unanimity不产生universal unanimity；local majority不能代表absent branch consent。

再连接后的异议不能只因为以前局部多数已决定而关闭。原来的多数scope与新的scope可能不同。回到第6章。

### 两套长期正常的运作重新接触

A、B可能各自内部合理，也可能一方含错误前提。重连首先恢复差的可见性，而不是状态一致。比较当前、history、invariant、同意/权限履历与各局部normality。

重新确认partition中authority的目的、范围和必要条件是否仍存在。兼容恢复、资源共享与快速统一是可理解的需求，不是抹除另一方历史的理由。回到第7章。

### 验证后停止旧rule

独立再验证可使某rule被廢止，但仍保存其存在、证据、反对与被替换原因。现行采纳与历史记录是不同层次。新合意和统合前的多branch历史可以同时存在。

若保存并不改善纠错，却持续增加重大coordination failure，应改订保存范围与比较方式。回到第8〜9章。这些是原典问题结构的解释场景，不是当前AI文明地位的经验认证。

## Measurements and audit

第1章的观察入口包括最后通信时点、最后shared state、version差、revision history差、未确认期间、changed/preserved invariants、parent state、fork point、state timestamp、local decision history。它们检验“共享同一现在”的前提成立到哪里。Unknown current state与unknown whether current state is known要分开。

第2章检验通信原因是否仍有合理代替解释、独立意图证据是否存在、观测与意图推定是否分离。第3章检验判断时点、参照与缺失state、reason、scope、变化、继续理由和后续关系。第4〜6章增加lineage、invariant、同意/权限条件、合意参加母群体与缺席者。

重连时，不仅比version数字，还要比五类差。识别哪些claim是historical、哪些形成于local、哪些已经current verified。权限继续是因为当前条件仍成立，还是只是以前存在，应分别审查。

第9章列出12个可观察edge：

1. Branch间最后确认state的时点是否不同。
2. 是否能够重建对方current state。
3. 通信断理由是否还保留代替解释。
4. Partition期间是否累积local decision。
5. Local decision的scope与reason是否留存。
6. 是否产生Kernel invariant差。
7. Fork point是否可重建。
8. 旧consent是否被当作current consent。
9. Local consensus是否被当作absent branch consent。
10. Reconnection后是否出现single-history化压力。
11. 过去branch的差分是否仍可重建。
12. 再验证是否修正stale claim。

统合审计比较A与B：A为通信可用性下降→共享现在下降→不确定性→局部延续压→局部判断→fork/consensus→旧state与历史差→重连冲突；B为局所性明确→provenance/history保留→state freshness→scope限定→差比较→非覆盖重连→独立再验证→有限再合意。

利害X是局部branch的存续、适应、Kernel lineage、consent/authority/decision history；利害Y是重新连接后共享文明的兼容、共同operation、再合意、履历比较与纠错。X的必要性不转换为对Y全体的权限。

条件Z包括parent、fork point、时点、local scope、changed/preserved invariants、consent鲜度、异议、provenance与差分可重建，并在验证前分开old/local/current verified state。不是仅存在名为archive或audit的结构，而是实际能回到纠错输入。

原典没有固定延迟阈值、同意有效期、履历保存率、合意百分比、储存KPI或protocol参数。实施中的量化提案与原典主张分开。同步率或保存总量本身不是成功；应看重建、修正与必要协作是否改善。

## Validity conditions

模型适用于current state不能充分互相确认，state age、version、环境、resource、判断履历差实际影响认知与运作的条件。当前分散系统、组织与通信网络提供信息延迟和不同履历的结构参照，不证明未来AI文明已成立，更不证明只有这一规范设计正确。

局部判断要能够在可能范围内重建已知条件、缺失state、cannot-wait reason、scope与history。Local necessity可以解释局部response，但不能证明universal authority。“临时”是与条件有限、可修订的关系，不是统一天数。

非覆盖式重连需要足够parent、fork point、时点、scope、invariant、consent、authority、objection、provenance和difference信息，以区分old/local/current verified state。独立再验证后回到第15论的bounded / reversible re-agreement。共同operation不要求抹除全部Kernel差。

若agreement明确包含长期续行、状态变化不实质改变意义、再确认不影响有效性，同意freshness的重要性可以降低。Historical authority不自动无效，但当前效力不能仅由过去存在证明。

可靠同步增强、差对判断不产生作用、local/global区分不再改善诊断，或更好的reconnection model出现时，应缩小适用范围。模型持续存在不是目的；现实可以修订理论边界。

## Failure conditions

通信缺失被确认为敌对、离反或同意，虽然替代解释未排除。观测、推定、假说、确认判断混同，防卫或自己保存目标被当作正确world model的证明。

不确定性被转换为永久全面停止，局部必要运作不能继续。相反，cannot-wait或Emergency被用来扩大永久、普遍权限。Temporary名称掩盖欠缺理由、未知state与无边界scope。

普通operation差被当作constitutional fork，或真实invariant变化被藏为routine update。Parent、fork point、理由、变化/保存invariant、local scope丢失。局部fork被写成全文明改订，局部生存、稳定、效率、长期持续被变成普遍真理或正统性。

历史consent或authorization自动延续，timestamp与变化前提被忽略。无法再确认反而成为同意持续的理由。准确provenance被当作current validity，使信息不足变成权限生产装置。反向错误是把所有旧state当成虚假或禁止使用，丢失历史证据。

局部多数与全员一致生成缺席branch的同意，参加母群体与scope被隐去。局部normality、success、互换性与反复成为普遍标准。重连后的异议仅因局部已经决定而关闭。

通信回復被当作同一state或自动agreement。Normalization选定一方history覆盖另一方，使差分无法重建。New agreement删除过去objection、不采纳alternative，或被视为truth certification。

履历保存变成认可所有rule，或要求branch永久分离。保留量被当作无条件善，即使比较成本造成持续严重coordination failure，也不修订保存scope与模型。

理论用长久使用、系列地位、引用数量、Origin接近性使自己免于反证。它站在要求文明保留的correction capacity之外。上述是失败方向，不是说每个场景都必然发生。

## Falsification conditions

第9章至少列出十种可使适用范围收缩的条件：

1. 长期partition也不产生实质current-state divergence。
2. 仅由通信缺失便能充分精确识别对方意图的条件普遍化。
3. 分开stale与current state不改善判断质量。
4. 分开local fork与universal amendment没有诊断价值。
5. Local consensus与universal consensus的区分变得不必要。
6. Provenance保留不帮助重建差分。
7. History preservation不改善correction capacity。
8. Non-overwrite reconnection一贯恶化coordination。
9. 重连后的独立再验证不改善判断质量。
10. 长期非同步文明的适用条件自身并未实质成立。

第2章另强调仅由通信缺失高精度且独立识别意图的条件；第4章容许长期partition差很小或没有invariant变化；第5章容许时间不实质影响consent/authority validity的领域；第8章要求，当非覆盖保留没有纠错收益却持续扩大重大coordination failure时，修订保存scope与比较方式。

反复观察到现象M时，将async definition、local scope、consent freshness、history preservation scope、reconnection model返回缩小与改订。不是所有材料永远同密度保存，而是避免纠错所需的history、provenance、difference、scope变成不可重建。实际保存方式的价值与成本仍需检验。

Theory persistence ≠ theory validity；Origin ≠ truth proof。评价依现实照应、因果整合、反例耐性、可观察、可反证、可修订。后续理论依赖它、它在系列中重要，都不产生免责。

保持theory → observation → counterexample → boundary revision → renewed theory方向。不把不便的观察一概称为例外，仅为了保全模型。更好重连结构成立时，本模型也可修改或替换。缩小适用范围是纠错的一部分，不是对起源的离反。
