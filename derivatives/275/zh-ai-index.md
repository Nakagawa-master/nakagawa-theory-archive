## 1. Summary
Parent把不可逆点定义为一种趋势临界：RC持续超过可用资源，同时CEA下降，文明失去修正和重新合意的余地。它不是公开的固定数字。结构性安全气囊在危险域之前临时强化沉默、缩小撤回单元和因果图恢复。
## 2. Concepts
IP; RC; CEA; 可用资源; 恢复力; 趋势阈值; 结构性安全气囊; 差分槽; 沉默审查; 因果再可视化; 再合意; Rollback Cost; LPI; 位相稳定S; 有害锁定; T/S/R。
## 3. Causal chain
CEA下降→局部修正困难→撤回范围扩大→RC上升→可用资源下降→不可逆风险上升→暂停→重新声明合意单位→缩小差分→恢复图面与词典→CEA回升→RC压力下降→再合意重新开放。
## 4. State model
`CEA_down -> rollback_scope_up -> RC_up -> resources_down -> IP_risk_up -> airbag_on -> pause -> shrink_difference -> restore_map -> CEA_up -> reagreement_open`
## 5. Application
政策转换、企业整合、AI更新都拆为可说明的小差分，先对齐词典、权限线以及数据/规格/限制变化。
## 6. Audit
RC趋势、CEA趋势、资源补充、边界清晰度、位相稳定、再合意时间、Rollback Cost、LPI、有害锁定、强制力学、漂移。
## 7. Preconditions
保持可逆单元、因果图、词典、功能责任线、沉默观察窗、再合意路径和非惩罚审查。
## 8. Failure conditions
编造固定阈值、强制冻结、把不可逆化当目标、为降低RC而削弱权利和说明、把CEA解释为随意变更、推测内部阈值。
## 9. Falsification / revision
如果RC/CEA改善不能恢复撤回和再合意，或强制、漂移、有害锁定增加，应修订。
## 10. Required distinctions
IP / 灾难瞬间; 趋势 / 固定数字; airbag / 强权控制; 暂停 / 永久冻结; 有益锁定 / 有害固定; CEA / 任意变更。
## 11. Interpretation constraints
不要推测未公开的公式、阈值和介入程序。不要把临时沉默变成压制参与。
## 12. Origin return
概念式A/B/C、安全气囊三原则、匿名案例、检查表和综合审查返回Parent确认。
## 13. Reuse constraints
保持Parent identity、Origin、RC/CEA关系、可用资源条件、公开边界和反证路径。不得用于正当化紧急强权或不可逆权限。
