## 1. Summary
The Parent defines the Irreversible Point as a trend-critical condition in which Reversal Cost persistently exceeds available resources while Causal Edit Adaptability declines. It is not a disclosed fixed number. A Structural Airbag temporarily strengthens silence, smaller rollback units, and causal-map restoration before recoverability disappears.

CEA declines -> local repair fails -> rollback expands -> RC rises -> resources decline -> irreversible risk rises -> pause -> re-declare consensus unit -> shrink rollback unit -> restore map/dictionary -> CEA recovers -> RC pressure falls -> re-agreement reopens.
