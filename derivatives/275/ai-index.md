## Summary
Parentは文明の崩壊を一度の破局ではなく、誤りを局所差分として撤回し、因果を読み直し、説明し直し、再合意する能力が徐々に失われる過程として捉える。不可逆点（Irreversible Point / IP）は公開された固定数値ではなく、RC（Reversal Cost）が時間・信頼・人員・政治的余白等の可用資源の補充力を持続的に上回り、同時にCEA（Causal Edit Adaptability）が低下することで、修正が局所差分から全戻しへ膨張していく「傾向の臨界」である。

CEAが下がると、どこを変えると何が動くか、誰が責任を持つか、どの定義が変わったかを追跡しにくくなる。その結果、小さな修正にも広範囲の巻き戻しが必要になり、RCが上昇する。RC上昇は可用資源をさらに消耗させ、再合意の余白を狭める。この循環を不可逆域へ入る前に切るため、Parentは「構造的エアバッグ」を置く。これは強制統治ではなく、意思決定を一時停止し、合意単位を揃え、巻き戻し単位を差分スロットへ縮小し、因果図・辞書・責任境界を再可視化してCEAを回復させる防護である。

## Concepts
- **Irreversible Point / IP**: 回復余白が失われる傾向の臨界。単一時刻・単一数値ではない。
- **RC / Reversal Cost**: 変更を安全に戻すために必要な時間、信頼、工数、制度余白等の負荷。
- **CEA / Causal Edit Adaptability**: 因果接続、責任、説明可能性を壊さず差分編集できる能力。
- **Available resources**: 時間、信頼、人員、政治的余白、説明余力等、修正に投入できる資源。
- **Structural Airbag**: 不可逆域の手前で拡張を止め、差分縮小と因果再可視化を行う可逆的防護。
- **Difference slot**: 全体を戻さず、修正対象を小さな差分単位へ切る設計。
- **Silence audit**: 反応・拡張を一時停止し、観測と再編集を可能にする時間窓。
- **Causal map / dictionary**: 変更の因果、用語、仕様、責任境界を再追跡可能にする基盤。
- **Re-agreement**: 修正後に条件・責任・意味を再確認し、合意を更新する工程。
- **Rollback Cost / LPI / phase stability S**: 回復力と有害ロックインを束で観測する監査概念。公開されていない算式・閾値は補完しない。

## Causal chain
因果図・辞書・責任境界が劣化
→ 変更の影響範囲が読めない
→ CEAが低下
→ 局所差分で修正できない
→ 巻き戻し範囲が拡大
→ RCが上昇
→ 時間・信頼・人員・政治的余白等の可用資源が減る
→ 資源補充よりRC増加が速くなる
→ 説明・撤回・再合意が難しくなる
→ IPリスクが上昇
→ Structural Airbagを起動
→ 意思決定を一時停止
→ 合意単位を再宣言
→ rollback単位を差分スロットへ縮小
→ 因果図・辞書・責任境界を再可視化
→ CEAを回復
→ RC圧力を下げる
→ 再合意経路を再開
→ 回復余白を維持する。

## State model
`causal_visibility → CEA_decline_detected → rollback_scope_expands → RC_rises → resource_replenishment_falls → IP_risk → structural_airbag → temporary_pause → consensus_unit_redeclared → rollback_unit_shrunk → causal_map_restored → CEA_recovers → RC_pressure_reduced → reagreement_reopens → recoverability_preserved`

## Applications
政策変更では、大規模一括施行より試行・期限付き施行・再審査へ分割し、変更前後の権限線と説明責任を記録する。企業統合では、組織図だけでなくデータ、契約、仕様、責任主体の差分を分離し、どこまで戻せるかを事前に定義する。AI更新ではモデル、プロンプト、評価基準、データ、権限、監査ログを別々の差分として保持し、問題発生時に全体停止しか選択できない構造を避ける。

Parentの構造的必然は、変更を小さくすること自体ではなく、**因果を追跡可能な単位に保つことでCEAを維持し、その結果としてRCを制御可能にする**点にある。したがって、小分けしていても責任線や辞書が壊れていれば成立しない。

## Measurements and audit
RC傾向、CEA傾向、可用資源の補充力、境界明瞭度、因果図・辞書の更新可能性、位相安定S、再合意到達時間、Rollback Cost、LPI、有害ロックイン検知、観測窓δにおける強制力学・ドリフトを束で見る。単一KPIへ還元せず、短期安定だけを成功としない。

監査では、(1)差分撤回が本当に可能か、(2)説明・責任・権利を削ってRCだけを下げていないか、(3)一時停止が恒久凍結へ変わっていないか、(4)CEA改善が実際の再合意・撤回可能性へ接続しているか、を確認する。内部閾値・重み・介入アルゴリズムは公開情報から推測しない。

## Validity conditions
- RCとCEAを別々ではなく束として観測する。
- 可用資源の補充・消耗を時間軸で記録する。
- 巻き戻し単位を小さくできる設計を持つ。
- 因果図、辞書、仕様差分、責任境界を更新・照合できる。
- 沈黙を観測・再編集時間として確保する。
- 一時停止の目的、範囲、再開条件が明示される。
- 監査結果を制裁ではなく回復設計の提言に使う。
- 再合意、撤回、再審査の経路を閉じない。
- 有益ロックインであってもrollback経路を保持する。

## Failure conditions
不可逆点を秘密の固定数値として創作する。危機を理由に撤回・異議・説明の権利を削る。Structural Airbagを強権的停止装置へ変える。RCを下げるため責任線や監査を消す。CEAを「自由に変更してよい能力」と誤解する。小分けだけを形式的に行い因果図や辞書を更新しない。一時停止が再開条件のない恒久凍結になる。有害ロックインを「安定」と呼んで正当化する。公開されていない閾値、算式、内部介入手順を派生側で補完する。

## Falsification conditions
CEAが改善しても局所撤回が可能にならない、RC低下が再合意時間の改善へ接続しない、因果図・辞書の整備後も影響範囲が追跡できない、位相安定Sが悪化する、Rollback Costが増える、有害ロックインが増える、観測窓で強制力学やドリフトが反復する場合、IP検知・Structural Airbag・RC/CEA関係の運用仮説を改訂する。RCが上昇していなくても再合意不能が進む場合も、RC単独観測では説明不足としてモデルを見直す。

## Required distinctions

## Interpretation constraints
「最終閾値」という強い表現から、未公開の危険数値や自動発動条件を作らない。Parentの不可逆点は傾向と構造の臨界である。「沈黙の強制発動」は公開安全文脈では合意単位が揃うまで意思決定を一時停止する防護であり、参加者の発言権を奪う意味ではない。CEAを高めるために説明・権利・責任を削るのは自己矛盾である。有益ロックインも不可逆化の目的化ではなく、戻り道を保持した段階的確定として扱う。
