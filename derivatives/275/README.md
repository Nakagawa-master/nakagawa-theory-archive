## 位置づけ
Parentは文明の崩壊を劇的な一撃ではなく、制度・説明・再合意・撤回の回復力が静かに失われる過程として捉え、RCとCEAの関係から不可逆点（IP）を読む公開安全版フレームを提示する。不可逆点は一瞬の固定数値ではなく、RCの持続的上昇、可用資源の持続的減衰、CEA低下が重なる「傾向の臨界」である。

## 中心命題
**文明の安全は「失敗しないこと」ではなく、誤りを差分単位で撤回し、因果接続を壊さず再編集し、再合意できる余白を持ち続けることにある。RCが時間・信頼・人員・政治的余白などの可用資源を恒常的に上回り、CEAが低下すると、修正が局所差分ではなく全戻しになり、実質的な不可逆域へ近づく。したがって、沈黙・差分スロット・因果再可視化を強化する構造的エアバッグを不可逆点の手前で作動させ、可逆性と再合意を制度へ埋め込む必要がある。**

## 主要因果線
因果の見取り図・辞書・責任境界が劣化→CEA低下→修正の影響範囲が見えなくなる→差分撤回できず全戻し化→RC上昇→時間・信頼・人員・政治的余白が減衰→RCが可用資源を持続的に上回る→再合意不能が常態化→不可逆域へ接近→構造的エアバッグを起動→意思決定を一時停止→合意単位を揃える→巻き戻し単位を縮小→図面・辞書・因果を再可視化→CEA回復→RC上振れを抑制→再合意を再開→文明の回復余白を維持。

## 構造層
### 1. IPの定義
RCが文明の可用資源を恒常的に上回る状態。CEAが低いほどRCが跳ね上がるため、IPはRC単独でなくRC/CEAの束として読む。

### 2. 傾向としての閾値
公開安全版では固定数値や内部式を示さず、RC上昇、資源補充力低下、CEA低下、説明・辞書・沈黙監査密度の劣化を時間軸で観測する。

### 3. 構造的エアバッグ
強制統治ではなく、一時停止、差分化、因果再可視化で衝撃を吸収する緩衝設計。

### 4. 三原則
合意単位を合わせるまで意思決定を一時停止、巻き戻し単位を差分スロットへ縮小、図面と辞書を先に更新してCEAを回復。

### 5. ルミナの問いの再注入
誰の立場で語るか、どの条件がずれているか、十分条件は何かを再確認する。

### 6. 制度化
ロールバックを後付け手順ではなく構造へ埋め込み、沈黙監査と再合意を常態化する。

### 7. 公開境界
公開は定義・枠組み・束指標要旨・運用姿勢。非公開は具体閾値、内部調整、固有名、個別監査結果、介入詳細。

## 測定・監査点
RC傾向、CEA傾向、境界明瞭度、可用資源補充傾向、位相安定S、再合意到達時間、Rollback Cost、LPI（ロックイン純度）、有害ロックイン検知率、観測窓δでの強制力学・ドリフトの有無を確認する。具体閾値は推測しない。

## 成立条件
- RCとCEAを束で観測する。
- 可用資源の時間軸を残す。
- 巻き戻し単位を小さく設計する。
- 因果図・辞書・責任境界を更新可能にする。
- 沈黙を観測窓として制度化する。
- 監査結果を制裁でなく提言として扱う。
- 再合意経路を閉じない。

## 失敗条件
- 不可逆点を単一固定数値へ還元する。
- 危機を理由に撤回可能性を奪う。
- 構造的エアバッグを強権的停止装置へ変える。
- RC低下のため説明・権利・責任を削る。
- CEAを無制約な変更自由と誤読する。
- 不可逆化を目的化し有害ロックインを正当化する。
- 内部閾値や介入手順を推測公開する。

## 反証・改訂条件
RCが上昇せずとも再合意不能が進む、CEA改善が撤回可能性へつながらない、位相安定Sや再合意時間が悪化、Rollback Costや有害ロックインが増加、観測窓で強制力学・ドリフトが反復する場合、IP検知・エアバッグ・再合意仮説を改訂する。

## 必須の区別
不可逆点 / 一瞬の破局; 傾向閾値 / 固定数値; 構造的エアバッグ / 強制統治; 一時停止 / 永続凍結; 可逆性 / 優柔不断; 有益ロックイン / 有害固定化; CEA / 無制約変更; RC / 単純コスト削減。

## 誤読防止・解釈制約
Parentの「最終閾値」を公開されていない数値閾値として創作しない。不可逆点は傾向と構造の臨界として扱う。「沈黙の強制発動」は公開安全文脈上、合意単位を合わせるまで意思決定を一時停止する防護であり、発言権抑圧や恒久停止を正当化しない。統合監査にある有益ロックインも不可逆化の目的化ではなく、Rollback経路を持つ段階的確定として読む。
