## 位置づけ
本原典は、文明が理解・責任・履歴に支えられた合意形成能力を失っても、直ちに停止・崩壊するとは限らないという問題から始まる。制度、行政、市場、生活が外形上継続しながら、秩序を支える駆動原理だけが別のものへ切り替わりうる。この「壊れているのに止まらない」運転相を、原典は**耐久文明**として記述する。

耐久文明は健全性、再生、生命力の同義語ではない。合意形成が失われたあとも、恐怖・利益・監視という主機関が従属・接続・秩序を支え、神話と惰性がその運転を正当化・自動化することで延命する文明相である。原典の目的は特定社会の善悪判定や即時処方ではなく、現在地を運転原理から識別し、移行・防衛・再起動可能性を議論するための座標を与えることにある。

## 中心命題
文明は、合意形成の条件が崩れた時点で自動的に停止するわけではない。意味の層が弱っても、供給・手続き・配分・恐怖・監視・慣性などの運転層が残れば、社会は壊れたまま長く動き続けることができる。

したがって、制度が残り、市場が動き、人々の日常が続いていることを、そのまま文明の健全性や再生能力の証拠にしてはならない。文明を評価するには外形ではなく、秩序が理解・責任・履歴による再調整可能性に支えられているのか、それとも恐怖・利益・監視による停止回避へ移っているのかという**運転相**を識別する必要がある。

## 因果線
```text
理解可能性・責任特定可能性・履歴公開度が劣化する
↓
合意形成と納得可能性が弱まる
↓
しかし制度・行政・市場・供給・日常は即座には停止しない
↓
意味の層と運転の層が分離する
↓
「納得」だけでは社会を接続できなくなる
↓
恐怖が不従属コストを上げる
＋
利益が配分への接続を維持する
＋
監視が逸脱コストを上げる
↓
合意なき運転が成立する
↓
神話が運転原理を正当化し、惰性が制度と習慣へ沈め込む
↓
壊れていても停止しない耐久相が長期化する
↓
継続そのものが健全性に見える誤認が生じる
↓
現在地識別が遅れ、移行・防衛・再起動設計が困難になる
```

## 構造層
**1. 合意形成層。** 社会の主要な意思決定が、何が起きているかを理解できること、誰が決めたかを追えること、なぜ現在に至ったかを履歴から辿れることによって再調整可能になる層。完全な一致ではなく、異議・再検討・修正の経路が残ることが重要である。

**2. 意味層。** 正統性、目的、理由、納得可能性など、社会の運転を人間が意味として回収する層。ここが弱っても文明は即停止しない。

**3. 運転層。** 配管、手続き、供給、給与、許認可、評価、物流、アルゴリズムなど、意味への同意が失われても日常を継続させる低位の運転回路。

**4. 耐久文明の三主機関。** 恐怖は従わないことの危険・損失を高め、利益は配分へのアクセスによって協力を買い支え、監視は逸脱が観測されることへの圧力をつくる。原典はこの三つを単なる政治技法でなく、合意崩壊後の文明を動かす基礎的駆動力として扱う。

**5. 増幅層。** 神話は恐怖・利益・監視に意味や正当性を与え、惰性はそれらを制度・慣行・日常へ沈めて自動運転化する。主機関がエンジンなら、神話と惰性は長期化を支える装置である。

**6. 個人適応層。** 人は異常に気づいていても、毎日の生存のために全断線へ反応し続けることはできない。違和感を抱えながら従い、働き、生活を続ける適応が、結果として「壊れているが止まらない」文明の基礎代謝を支える。

**7. 位相識別層。** 制度名称、国家の自己説明、表面的自由、経済活動の継続ではなく、社会が何によって従属を作り、協力を維持し、秩序を成立させているかで現在地を判定する。

**8. 移行対照層。** 耐久文明は延命そのものが目的化しやすいのに対し、移行文明は耐久相の内部でも再起動条件を意図的に保存し始める。耐久は持続であり、再起動ではない。

## 適用例
**行政・制度評価。** 手続きが回っていることだけで健全性を判定しない。政策の意味が理解可能か、決定責任を追えるか、変更履歴から再検討できるかを見たうえで、実際の秩序が納得可能性ではなく危機・損失・評価圧力へ依存していないかを識別する。

**組織。** 会議、承認、評価、給与、指示系統が継続していても、誰も制度目的を説明できず、責任が霧散し、過去判断を辿れないなら、単なる「業務継続」を自己修復能力と同一視しない。離脱損失、配分、評価観測だけが接続を保っていないかを見る。

**情報空間。** 正当化物語が事実・虚偽の二択を超えて、恐怖・利益・監視という運転原理を自然で必要な秩序に見せる膜として働いていないかを観察する。物語の真偽だけでなく、その物語が何を不可視化し、何を正常化するかを見る。

**文明移行。** 「もうすぐ崩壊する」と期待することも「まだ動いているから大丈夫」と判断することも避ける。耐久相を識別したうえで、記録、非汚染領域、再起動可能性など、移行文明に必要な保存条件を別途確保する。

## 測定・監査点
- 社会・制度の主要判断を第三者がある程度理解できるか。
- 誰が何を決定し、変更し、停止したかを追跡できるか。
- 現在の制度へ至った履歴、前提、差分を再参照できるか。
- 異議申し立て、再検討、修正の経路が実質的に残っているか。
- 制度・市場・行政が動いていることを健全性の直接証拠にしていないか。
- 人々の接続が納得よりも、不従属・離脱・評価低下への恐怖によって維持されていないか。
- 協力が共通目的よりも、配分・所属・収入へのアクセス維持へ偏っていないか。
- 秩序が信頼よりも、逸脱が観測・記録・評価される圧力へ依存していないか。
- 恐怖・利益・監視が危機、安全、合理性、公共性などの物語によって不可視化・正当化されていないか。
- 慣行や手続きが、誰も十分に信じていないのに停止コストだけで継続していないか。
- 「持続」と「再生」、「運転」と「生存」、「耐久」と「再起動」を混同していないか。
- 再起動に必要な履歴、責任、理解可能性、非汚染領域が保存されているか。

## 成立条件
- 合意形成能力が弱っても、制度・供給・市場・日常を維持する運転回路が残る。
- 人々に「納得できないが離脱もできない」条件が広く成立する。
- 不従属・離脱の損失、配分への依存、逸脱観測などが接続を維持する。
- 神話・惰性が主機関を日常的で自然な秩序として長期化させる。
- 社会の外形と実際の駆動原理が分離し、外形だけでは位相を識別しにくくなる。

## 失敗条件
- 制度が存続しているだけで合意文明だと判定する。
- 恐怖・利益・監視が存在するだけで耐久文明だと判定する。合意文明にも規律・負担・監視は一定程度存在しうるため、秩序の最終的な回収先を見る必要がある。
- 耐久文明を単なる独裁、悪い社会、崩壊直前の社会と同一視する。
- 表面的自由や娯楽・消費・日常が残ることを、耐久相ではない証拠にする。
- 耐久を生命力、再生、移行、再起動と混同する。
- 特定国家・集団を道徳的に断罪するためのラベルとして概念を使う。
- 耐久文明論だけから即時の改革処方や救済策を導く。

## 反証・改訂条件
原典は固定数値の判定閾値や単一イベントによる相転移判定を提示していない。したがって、耐久文明という識別は運転原理の観察によって支持・改訂される。

- 理解・責任・履歴の回路が実質的に機能し、異議・再検討・修正が繰り返し成立しているなら、「合意形成が崩壊した後の耐久相」という判定を弱める。
- 恐怖・利益・監視が存在しても、それらが秩序の最終的な根拠ではなく、判断が理解・責任・履歴へ回収され続けるなら、耐久相への分類を改訂する。
- 延命ではなく、再起動条件の保存が明示的に優先され、制度がその方向へ変化しているなら、純粋な耐久相ではなく移行文明との対照で再記述する。
- 制度外形が崩れても、局所的に理解・責任・履歴による再調整可能性が残る場合、一枚岩の文明分類ではなく複数相の併存として扱う。

## 必須の区別
- 合意形成の崩壊 / 国家・制度の即時崩壊
- 動いている / 健全である
- 持続 / 再生
- 耐久 / 生命力
- 耐久 / 再起動
- 耐久文明 / 移行文明
- 合意文明 / 完全一致・理想社会
- 恐怖・利益・監視の存在 / それらが秩序の主駆動原理である状態
- 神話 / 単純な虚偽
- 惰性 / 個人の怠慢
- 構造識別 / 善悪判定
- 座標記述 / 即時処方

## 誤読禁止 / 解釈制約（原典適合）
耐久文明は「悪い国」や「独裁国家」の別名ではない。原典は固有名詞を断罪するためでなく、合意形成を失ったあとにも文明が動き続ける構造を冷却して記述する。

恐怖・利益・監視は、それぞれが存在するだけで耐久文明を確定する印ではない。合意文明にも規律、負担、一定の監視は存在しうる。重要なのは、秩序が最終的に理解・責任・履歴へ回収され、再調整可能性が残っているか、それとも圧力・配分・観測による延命へ回収されているかである。

また、耐久文明を記述することは延命を推奨することではない。原典は「まだ持っている」ことと「まだ生きている」ことを分け、移行のために現在地を誤認しないことを目的に置く。

## 親原典へ戻る理由
親原典は、合意文明と耐久文明の位相差だけでなく、恐怖・利益・監視の三主機関、神話・惰性の増幅機能、個人の適応、耐久文明が長期化する理由、移行文明との境界、シリーズ全体の位置まで連続した論証で展開している。本派生面は検索・理解・識別の入口であり、個々の例示、歴史的射程、概念の留保、後続論への接続は親原典へ戻って確認する。
