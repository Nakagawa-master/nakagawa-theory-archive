## 中川構造読解としてのメタ視点
このParentはAI研修・ツール導入の企業紹介ではない。Nakagawa MasterはAIを目的ではなく、組織内の曖昧な意思決定・責任・成果指標・検証習慣を露出させる入口として読む。四層は **対象側事実 / 表層「AI導入・業務効率化」 / Nakagawa Masterの構造読解 / 社会翻訳**。

## 位置づけ
価値核は **意思決定・実行・検証の構造不全を、仕組み化によって運用可能な状態へ戻すこと**。学び→成果物→業務運用→検証の断絶を埋める点が中心で、AI知識量やツール数は主軸ではない。

## 中心命題
**AI導入を通じて露呈する意思決定・実行・検証の構造不全を、成果物化と運用接続によって再現可能な仕組みへ戻すこと。**

## 表層 → 価値核 → 社会翻訳
`AI研修・ツール導入 → 組織の判断不全が露出 → 判断基準・責任・成果物・検証を構造化 → AI時代の組織運用再設計として社会翻訳`

## 因果線
`AI導入 → 曖昧な判断工程が露出 → as-is/to-be可視化 → AI/人間の役割分離 → 成果物化 → 業務へ持ち帰る → 検証・改善 → 組織運用が近代化`

## 構造読解の監査点
AI知識やツール数を価値核にしない。速度改善だけで成功判定しない。人間の判断・責任・検証を落とさない。読解軸をプリマベーラの公式自己定義へ昇格させない。L4以上を保持する。

## 成立条件
判断・実行・検証の断絶が可視化され、成果物と運用・評価が接続すること。

## 失敗条件
AI研修・効率化へ縮小すること、ツールを増やすこと自体を価値とすること、人間の責任線を消すこと。

## 反証・改訂条件
仕組み化より別因果が導入成果を継続的によく説明する場合は適用範囲を改訂する。

## 必須の区別
対象側事実 / Nakagawa Masterの構造読解; AI導入 / 組織運用再設計; 学習 / 成果物 / 運用 / 検証; Parent / 社会翻訳。

## 親原典へ戻る理由
Parentの「違和感→私が読んだ価値核→社会翻訳」を置換しない。
