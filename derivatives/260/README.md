## 位置づけ
本公式派生物は、親原典「現象の因果律」の発見・理解・機械読解・誤読防止を支援し、必ず原典へ戻るための公開接続面である。親原典の代替ではない。

原典が扱う中心課題は、主観を排除して客観だけに寄せることでも、主観を絶対化することでも、第三の超越的人格へ判断を委ねることでもない。**主観・客観・真我という異なる役割の三層を、混ぜず、競わせず、相互参照させながら一つの運用へ統合すること**である。

ここでいう「真我」は、宗教的・人格的な超越主体を意味しない。運用上、価値核、境界条件、例外規範、優先順位の最上位整合を担う**統合参照フレーム**として扱われる。また「観測」は自然科学・量子論の厳密な観測問題を主張する語ではなく、社会運用上、期待・恐れ・評価基準・語彙・沈黙などが制度や関係の方向づけへ作用することを説明するための比喩である。この境界を外すと原典の意味が大きく変わる。

## 中心命題
現象は、単一の視座だけで適切に扱えない。主観は方向を与えるが暴走しうる。客観は検証可能性と制動を与えるが、何を優先すべきか自体を自動で決めるわけではない。統合参照フレームは価値核・境界・例外・優先順位を束ねるが、それ単独で現場情報を代替しない。

したがって必要なのは、三層を一つへ溶かすことではなく、それぞれの役割を明示して往還させることである。

```text
主観層
期待・恐れ・意味・語彙・沈黙・選好
→ 何を見るか / 何を重要とみなすかの方向づけ

客観層
公開基準・事実・監査・第三者検証・再現可能な条件
→ 主観の過熱を冷却し、因果追跡可能性を与える

真我層 / 統合参照フレーム
価値核・境界条件・例外規範・優先順位
→ 主観と客観のどちらを、どの範囲で、どう接続するかを整合

三層を混ぜない
→ 相互参照する
→ 現象を方向づけ・検証・統合の三機能で扱う
→ 誤読・暴走・責任曖昧化を減らす
```

## 三層の役割
### 1. 主観層
主観層は、感情・経験・期待・恐れ・価値判断・語彙選択など、当事者が世界へ与える方向性を担う。原典における主観は「排除すべきノイズ」ではない。何に注意を向け、何を尊いと感じ、何を問題として切り出すかという起点である。

ただし主観だけで運用すると、確信が事実に置換され、自己物語が現実条件を上書きしやすい。そのため主観は必要だが、単独では完結しない。

### 2. 客観層
客観層は、公開基準、記録、審査、監査、第三者レビューなどによって、主観の主張を条件・証拠・因果へ戻す役割を担う。ここでの客観は「多数派だから正しい」ことでも「感情を持たないこと」でもない。

重要なのは、誰が見ても同じ結論になるという単純化ではなく、**どの条件・証拠・定義に基づいて判断したかを追跡できること**である。客観層は主観を消すのではなく、主観が現実へ作用する時の制動・検証面となる。

### 3. 真我層 / 統合参照フレーム
真我層は、主観と客観の間に立つ「第三者人格」ではない。価値核、境界条件、例外規範、公開範囲、優先順位などを上位で整合するための参照点である。

たとえば、主観的には強く望ましい案があり、客観的にも一定の効果が確認できるとしても、守るべき権利や長期価値を毀損するなら採用しないという判断が必要になる。逆に、公開基準だけでは扱えない関係文脈をどこまで内部で保持するかも統合対象になる。

## 観測の因果
原典は、観測を単なる受動的な情報取得として扱わない。期待、恐れ、評価関数、語彙、問い、沈黙は、どの現象を前景化し、どの選択肢を見えやすくするかへ影響する。

ただしこれは自然科学の観測問題の説明ではない。**社会制度・組織・対話・意思決定における方向づけを説明する運用上の比喩**である。

たとえば同じ出来事でも、「失敗」と呼ぶか「検証結果」と呼ぶかで、次に許容される行動は変わる。「誰が悪いか」と問うか「どの条件が不足したか」と問うかで、収集される情報も異なる。つまり語彙や問いは現実を魔法的に変えるのではなく、制度上の注意・責任・行動経路を変える。

## 二重構文
三層運用を現場へ落とす際、原典は外部層と内部層を混ぜずにつなぐ二重構文を重視する。

### 外部層
- 法・規程・標準
- 公開基準
- 説明責任
- 監査
- 第三者が検証できる記録

### 内部層
- 信頼
- 合意履歴
- 役割交代
- 関係固有の暗黙知
- 情動・機微情報の保護
- 例外運用の文脈

内部情報をすべて公開すると、関係密度や安全性が壊れる。逆に内部を完全に閉じると、責任や妥当性を外部から検証できない。したがって、二層は同一化せず、外部層が妥当性を監査し、内部層が普遍基準を現場文脈へ翻訳する。

## 因果線
```text
主観だけで現象を扱う
→ 自己物語・期待・恐れが条件確認を上書きしやすい

客観だけへ寄せる
→ 何を守るか / 何を優先するかという価値判断が不可視化しやすい

統合層を人格化する
→ 権威への丸投げが起こる

そこで
主観 = 方向づけ
客観 = 検証・制動
真我 = 価値核・境界・優先順位の統合参照
と役割分離する

さらに
外部の透明性 / 内部の文脈密度を二重構文で保持
→ 相互参照
→ 閾値・沈黙・可逆性・反証窓を持たせる
→ 異質な視座を消さずに運用整合を作る
```

## 実装の七原則
### 1. 価値核の一句化
この場で絶対に毀損しないものを短く言語化する。価値核が曖昧だと、客観指標が改善しても目的そのものを失う。

### 2. インターフェース分離
公開基準と関係固有基準を分ける。どこまで外部検証可能にし、どこから内部文脈として保護するかを決める。

### 3. 多元ログ
一つの語彙だけで意思決定履歴を残さない。当事者、専門家、利用者、AIなど複数の言葉で判断経路を残し、単一視座の支配を防ぐ。

### 4. 反証窓
決定後も一定期間、反証や異議を受け付ける。決定を終点にせず、現実との不一致を発見できる余白を保持する。

### 5. 小さく検証
PoC、限定運用、段階拡張の順で試す。正しさを宣言してから広げるのではなく、戻せる範囲で現実へ当てる。

### 6. 沈黙の役割化
即応しないことを怠慢とみなさない。情報不足、感情過熱、関係緊張時には、誰がどの場面で一拍置くかを役割として設計する。

### 7. 閾値の可視化
どの条件で介入・停止・切替・再審査を行うかを明示する。定量条件だけでなく、未解消異議や責任境界の不明瞭さなど定性条件も扱う。

## 状態モデル
```text
STATE A: 主観優位
意味・願望・恐れが先行し、検証面が弱い

STATE B: 客観化
条件・証拠・第三者検証を追加し、因果追跡可能性を回復

STATE C: 統合
価値核・境界・例外・優先順位と客観条件を接続

STATE D: 二重構文運用
外部透明性と内部文脈密度を分離して相互参照

STATE E: 検証・更新
反証窓、閾値、沈黙、rollbackを使い、現実とのズレを修正
```

これは一方向に一度だけ進む成熟段階ではない。新しい事象や異議が生まれれば主観・客観・統合の往還へ戻る。

## 適用例
### 組織意思決定
経営者の直感を排除せず、直感を仮説として客観層へ渡し、データ・現場記録・異議で検証する。そのうえで企業の価値核や長期境界と照合し、採否を決める。

### AI利用
AIの出力を客観そのものと扱わない。AIは構造化・比較・矛盾検出を支援できるが、入力データ、評価条件、語彙選択自体に方向づけが入る。人間側の価値核・責任境界と、外部検証可能な証拠を分けて保持する。

### 公共制度
多数派意見をそのまま客観とみなさず、事実条件、少数者権利、長期価値、例外規範を分ける。公開基準と非公開の個別事情を二重構文で扱い、説明責任と文脈保護を両立する。

### 対話・紛争
「誰が正しいか」だけを競わず、各当事者の主観、共有可能な事実、守るべき境界・優先順位を別々に出す。これにより人格対立を構造問題へ戻しやすくなる。

## 測定・監査点
本派生物では、原典にない単一スコアや閾値を新設しない。監査では少なくとも以下を確認する。
- 主観的主張と検証可能な事実が混同されていないか
- 使用語の定義と前提が明示されているか
- 重要判断の証拠・条件・責任主体を追跡できるか
- 価値核と優先順位が後付けで変更されていないか
- 外部公開情報と内部文脈の境界が説明できるか
- 異議・反証を受け付ける経路があるか
- 変更がrollback可能か
- 閾値の変更理由を追跡できるか

## 成立条件
- 三層を優劣ではなく役割差として扱う
- 主観を排除せず、客観へ接続する
- 客観を価値判断の代替にしない
- 真我を人格・権威として扱わない
- 観測を社会運用上の比喩として限定する
- 外部層と内部層を混同しない
- 相互参照、反証、監査、可逆性を残す

## 失敗条件
- 主観を事実扱いする
- 多数派やAI出力を客観そのものとみなす
- 「真我」を最終権威や超越主体へ変える
- 量子論・自然科学の観測問題として誤って一般化する
- 二重構文を秘密主義へ変える
- 公開性を理由に内部文脈をすべて露出する
- 内部文脈を理由に説明責任を拒否する
- 不可逆な判断を一度に広げる

## 反証・改訂条件
三層分離を導入しても意思決定の追跡可能性が改善しない、価値核が権威の口実になる、二重構文が責任分断を増やす、反証窓が実質機能しない、沈黙が単なる回避になる、閾値が現場変化を取り逃す場合は、役割境界・公開範囲・統合条件・発火条件を再設計する必要がある。

この原理は、現実に合わなくても守るべき教義ではない。**異質な視座を保持したまま、検証可能で可逆的な運用整合を作れるか**によって評価される。

## 必須の区別
- 主観 ≠ 誤り
- 客観 ≠ 多数派
- 客観 ≠ AI出力
- 真我 ≠ 人格的超越主体
- 統合 ≠ 混合
- 観測因果 ≠ 量子観測の主張
- 内部層 ≠ 無監査領域
- 外部層 ≠ 全面公開
- 沈黙 ≠ 放置
- 可逆性 ≠ 決断回避

## 誤読防止・解釈制約
本稿を「主観を捨てて客観になれ」という自己啓発へ縮約しない。また「真我」という語だけを切り出し、宗教的・形而上学的実在の断定へ変えない。自然科学用語との類似を根拠に物理学的事実として扱わない。

原典の価値は、主観・客観・統合参照フレームを役割分離し、外部透明性と内部文脈密度を二重構文で接続し、閾値・沈黙・反証・可逆性を通じて運用可能にした点にある。
