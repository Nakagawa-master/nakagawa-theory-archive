## Summary
Parent所定义的“客观视座”并不是切断情绪，也不是假装绝对中立，而是在主观密度过高、事件与自我叙事融合时，在两者之间插入结构距离的坐标系。Parent把“苦”理解为意义赋予被持续保存的结构问题：暂时的分数或他人反应可能被过度认同为全部自我价值，“我就是这样的人”之类的主语也可能僵化并遮蔽因果。通过暂停反射、把评价语言转换为结构语言，并观察位置、关系与变化，可以在保留情绪的同时恢复因果追踪与判断的可逆性。

## Concepts
- 客观视座：把事件、情绪、判断重新放回结构中阅读的坐标系。
- 主观过密：评价、他人目光、自我叙事过度进入自我参照回路的状态。
- 指标过度认同：把暂时的数值或反应扩大为全部自我价值。
- 主语僵化：把有条件的事件固定为不可逆的自我本质命题。
- 客观层：插入事件与自我叙事之间、恢复因果可读性的中间层。
- 结构语言：把好/坏等评价改写为整合/不整合、收敛/未收敛、评价轴冲突等可配置表达。
- SQS：Silence–Question–Silence，通过沉默、一个问题、再次沉默降低反射并等待再整理。
- 可逆判断：条件、关系或证据改变时可以更新判断的状态。

## Causal chain
外部评价、他人目光、自我叙事集中进入主观 → 主观密度上升 → 事件与自我故事融合 → 指标过度认同或主语僵化 → 结构与因果变得不可见 → 意义被保存为苦 → 暂停反射性回应 → 插入客观层 → 把评价语言转换为结构语言 → 观察位置、关系、变化 → 在保留情绪的同时重新追踪因果 → 判断恢复可逆性。

## Applications
1. 接受批评时，把“我被否定”拆解为具体评价轴、前提与论点的冲突。
2. KPI变化时，把数字作为观察，不把它等同于全部自我价值。
3. 对话中在即时反驳前使用SQS，把注意力带回位置、关系或变化中的一个点。
4. 自我观察时把情绪作为事件日志保留，与身份结论分开。
5. 合意形成时从评价互撞转向因果与关系配置。

## Measurements and audit
- 能否分别描述事件与自我评价？
- 是否避免把暂时指标扩大为全部自我价值？
- 僵化主语是否遮蔽条件与因果差异？
- 是否保留情绪而不让情绪成为唯一判断规则？
- 能否用位置、关系、变化、顺序描述状态？
- 刺激与回应之间是否存在观察余白？
- “客观”是否变成情绪压抑或优越性？
- 条件变化后判断是否可以更新？

## Validity conditions
能够区分事件、意义赋予、自我评价；能够建立反射前的余白；能够把评价词转换成可配置的结构词；并且在不消除情绪的情况下重新追踪因果时，该模型成立。自我定义必须保持条件性和可修订性。

## Failure conditions
把客观变成情绪压抑、把指标直接等同自我价值、用过大或僵化的主语抹去责任与条件、跳过沉默而过早总结、把结构语言变成表面换词、或用客观视座证明自己高于他人时，该结构失败。

## Falsification conditions
如果插入客观层后，指标过度认同和主语僵化仍未改善，事件与自我故事仍无法分离，因果可见性和判断可逆性也没有恢复，则当前距离设计需要修订。如果客观化反而增加情绪压抑，也应修订。

## Required distinctions
- 疼痛 / 苦
- 主观 / 主观过密
- 情绪 / 即时判断
- 客观视座 / 冷淡或中立幻觉
- 事件 / 事件的意义赋予
- 暂时指标 / 全部自我价值
- 有条件的自我描述 / 僵化本质命题
- 结构翻译 / 表面改写
- 沉默 / 放置不管
- 客观化 / 情绪压抑

## Interpretation constraints
不要把Parent缩约成“消除情绪、变得理性”。核心是在保留情绪的同时建立足够距离以重新看到因果。不要把SQS当作操纵技术。不要新增Parent未声明的治疗、医学、心理效果、固定KPI或普遍阈值。也不要因为使用“客观”一词就把AI解释为自动中立。
