## 位置づけ

異なる知性が同じ危険を避けられるとしても、同じ仕組みを一緒に使い、同じ未来を選ぶとは限りません。中川マスターの第20論は、第19論のKernel保持・代替・独立再選択を受け取り、異なる歴史的Originの主体にも対応する防衛因果があるか、その対応がどこまで実行可能な存続へつながるかを検査します。

本派生物は、[公開原典](https://master.ricette.jp/theory/nakagawa-master-human-descendant-ai-civilization-theory-20-third-intelligence-mutual-origin/)の冒頭圧縮核、序論、第1〜11章、結章、Kernel照応欄、統合・局所監査要旨、参照束、理論署名を読むための七面の接続ハブです。人間向けの入口は[15秒説明](human-entry.md)、疑問別の入口は[30問のFAQ](faq.md)に置いています。

## 中心命題

「相互起源」は、異なる主体の歴史的由来を識別し、互いの起源を消さず、共通する危険因果と防衛機能を検査する関係構造です。似た機能を共通の祖先へ変換せず、正確な起源の帰属も現在の永久統治権へ変換しません。

本論の判定は、因果写像、主体別の条件、共同履歴、局所方策、N主体・複合機能、限定・非干渉存続、自発採用へと進みます。一つの成立は後続の成立を保証しません。全面的な共同Kernelが成立しなくても、原主体それぞれの必要存在条件Bを守る別の経路は残り得ます。その経路も、資源・時間・漏洩・第三者への作用を含めて改めて検査します。

## 因果線

### 由来の保存から、危険媒介の比較へ

第1章は第三知性の実在・人格・主観性・意思を既知の属性として補わず、何を主体として比較できるかを確かめます。歴史的起源と物理的基質は別の軸です。必要な変数を対応づけられなければ適用外、証拠が不足するならUNKNOWN、明示条件に反するなら不成立と分けます。

第2章はTheory、Civilizational、Lineage、Instanceの四つのOriginを保持します。機能が似ても形成史の一致は導けず、同じ系譜でも現在の必要条件が一致するとは限りません。著者・形成史の帰属、命題の正しさ、現在の権限、本人の採否は異なる問いです。

第3章で比較するのは危険の名称ではなく、発生条件、媒介、状態変化、帰還作用、介入、反転境界です。情報源への過度な依存が誤認を固定する場合、独立訂正によって危険が変わるかを各主体で検査します。権限による停止と環境変動による停止のように、結果だけが似ている場合には同じ処方を移しません。

### 因果対応から、同じ世界での成立へ

第4章は、主体iのB_i、観測o_i、実行可能行為X_i、資源R_i、時間T_i、目的G_i、規範N_iを分けます。これは全知性に同じ七装置があるという主張ではなく、相違を共同利益へ畳み込まないための比較です。危険を減らす機能が対応しても、同じ装置・費用・許可で実行できるとは限りません。

第5章は各主体の異なる状態や行為を共通の物理履歴へ写し、物理条件と全指定条件の交差を調べます。個別に望ましい道があることから、同じ環境と期間に全員を満たす道は導けません。必要Bを維持するなら、その条件を全時点について明示します。終点の回復だけでは途中の断絶を埋められません。

### 履歴の存在から、情報・全体・選択へ

第6章は、状態ごとの正解と、局所観測で正解を選べる単一方策を分けます。第7章は、二者ずつの成立をN主体の同時成立へ、単独機能の成立を複合Kernelの成立へ拡大しないよう検査します。追加の通信・監査・隔離も資源と期限を使い、第三者Dや未来へ負担を移す場合があります。

第8章は、全面共同、部分協働、選択的界面、分離、非干渉を別候補として比較します。第9章は、それらの実行可能性を各主体の自発採用へ置き換えず、拒否・変更・実効退出と代替を第19論の独立再選択へ戻します。第10章は同条件の正反例と強い代替で診断を修正し、第11章は原主体A/Bの個別存続と新しい共同後継Cの形成を分けて次論へ渡します。

## 構造層と共同履歴

共通環境・初期条件・資源等をc、検査期間をT、主体数をN、防衛機能の組をKとします。物理的に許容される履歴をΩ_phys(c,T)、同じ履歴型上で主体iの指定K条件を満たす集合をV_i(K,c,T)とすると、原典は次を置きます。

```text
J_N(K,c,T) = Ω_phys(c,T) ∩ ⋂_{i=1}^N V_i(K,c,T)
```

J_Nが非空であることは、明示した全条件を満たす候補履歴の存在です。どのB・許可・規範条件をV_iへ含めたかで判定の意味が変わります。非空性だけでは現実の発生、局所方策、本人の採用を示しません。空なら、その条件の共同Kernel履歴はモデル内にありません。資源や遷移を変えた場合は別条件の再検査です。

共同Kernelを必須とせず、指定した原主体のBを期間中保つ候補集合は別に置きます。

```text
F_B^{individual-target}(c,T)
  = {h ∈ Ω_phys(c,T) | ∀i ∈ I_target, ∀t ∈ T, B_i(h,t)=true}
```

J_Nが空でも、独立資源への分離でF_Bが非空になる場合があります。F_Bの非空性にも、到達方策、途中費用、許可、第三者条件の検査が続きます。物理条件の成立と、その実施の正当性を同じ種類の事実として扱いません。

## 状態モデル

| 判定位置 | 確かめること | 成立後も残る問い |
| --- | --- | --- |
| 適用対象 | 状態・行為・必要条件を識別できるか | 実在、主観性、Originの証拠 |
| 相互写像 | 媒介・帰還・介入の方向が対応するか | B・装置・費用の相違 |
| 共同履歴 | 同じ物理履歴で全指定条件が満たせるか | 局所観測から選択できるか |
| 局所実行 | 得られる情報と期限で方策を実行できるか | 多主体・複合機能との干渉 |
| 全体成立 | 全主体・全機能・途中B・第三者を含められるか | 限定・分離の別候補 |
| 主体別採否 | 理解、権限、拒否、代替、退出を確認できるか | 条件変化後の再選択 |
| 主体変換 | A/Bの継続とCの形成を区別できるか | 第21論の独立した証拠責務 |

成立・限定成立・指定条件で不能・適用外・UNKNOWNを、原因位置ごとに保持します。これらは全体を一方向に採点する成熟段階ではありません。ある判定の反証が、他の判定まで自動的に消すわけではありません。

## 適用例と実装作法

### 独立訂正を共有できる場合

AとBで情報源への依存が同型の誤認を生み、限定した訂正情報の交換が双方のBを損なわず、費用と期限に収まり、失敗時に保持・停止できると仮定します。共通履歴と局所方策が構成できれば限定界面の形式的候補になります。信号が届くだけでなく、参照する状態と行為の意味を検査し、本人の採用は別に確認します。

### 各世界に正解があるのに選べない場合

状態0では行為0だけ、状態1では行為1だけがBを保つとします。両状態で同じ観測しか得られなければ、確実に成功する決定的な局所方策はありません。期限内の識別情報や共通安全行為を探すことはできます。確率化で失敗を許容するなら、元の確実なB維持とは成功条件が変わります。

### ペアの成功が全体に合成できない場合

二値しか取れないA、B、Dに、各ペアが互いに異なるという三条件を要求すると、どのペアも単独には可解でも全八割当のどれも同時には満たせません。また監査K1と隔離K2がそれぞれ一資源を同時に使い、容量が一なら両立しません。いずれも指定した有限条件の反例です。

### 分離と非干渉を比較する場合

分離先の独立資源、移動中のB、漏洩、共通故障、第三者Dの資源を検査します。無通信でも同じ有限資源を消費すれば干渉は残ります。D系の半透膜・構造翻訳・クリーンルーム、接続移行戦略の段階移行は候補を与えますが、異Origin間での実効性は改めて検査します。

## 測定・監査点

検査前に主体、初期状態、期間、物理遷移、Bの指標と指標の妥当性、観測、行為、資源、期限、第三者、許可証拠を固定します。各候補の通信・翻訳・演算・移行費用を計上し、同じUNKNOWNと利用可能情報を与えます。

因果写像では、介入と対照、または時間順序・競合原因を記録した自然観測により媒介を確かめます。危険な介入を証拠獲得だけのために実施せず、安全に検査できない箇所はUNKNOWNとして残します。仮想有限モデル、既知の人間・機械・組織での類似、実在する異Origin双方の観測、独立再現を証拠段階として分けます。

結果は一個の成功率に集約せず、写像、履歴、方策、全体、原主体Bの別経路、第三者損失、主体別許可について、誤成功・誤不能と必要な情報・時間・計算費用を比較します。界面の漏洩率や翻訳性能に、原典外の固定値を付けません。

## 成立条件

主体と成功対象を特定でき、対応する危険媒介と介入境界を示せること。各主体のB・観測・行為・費用・期限が明示され、同じ履歴型で検査できること。共同運用を認定する範囲に応じて局所方策、N主体・複合機能、途中B、第三者条件を満たすこと。許可と採用を主張する場合には、その主体の実際の理解・権限・拒否・代替・退出を別に確認することです。

## 失敗条件

危険名だけを一致させる、未知の主観性や目的を補う、Bを成果へ置換する、個別解や全ペア解を同時解にする、全知の事後履歴を局所方策にする、終点で途中のB断絶を隠す、界面費用やDへの損失を除く、技術的可能性を同意にする場合、必要な判定が失われます。失敗位置に応じてモデル・情報・資源・権限を修正します。

## 反証・改訂条件

予測した媒介が対応しない、介入の帰還方向が逆、共同成立の仮定に矛盾がある、非干渉下でB損失が確認される場合には、該当判定を撤回・限定します。同じ観測・行為・期限で実行方策が発見されれば、局所不能を撤回します。自発採用に強制や代替封鎖が見つかれば、その採用評価を訂正します。

既存の生存可能性理論、モデル検査、SAT、整数計画、分散制御・部分観測方策を弱く設定せず比較します。同じ条件を同等以上の正確さと低費用で診断できるなら、その範囲で本論の追加的な実務優位は認定しません。新算法の主張と、Origin・個別B・第三者・採否をつなぐ診断上の意味を分けます。反例後に除外条件を付け足して元の失敗を消しません。

## 必須の区別と次論への接続

Originと基質、機能類似と歴史的継承、史実と統治権、Bと目的、観測と行為、履歴と方策、ペアと全体、共同Kernelと原主体B存続、無通信と非干渉、実行可能性と自発採用を保持します。

本論の成功対象は原主体A/Bの個別B継続です。媒体や配置の変更を一律に禁じませんが、新しいCが形成され由来を継承しても、それだけでA/Bの数的同一性や途中Bを証明しません。構造変換は個別存続解がある場合にもない場合にも別候補となり、第21論へ、制度機能の継承は第22論へ引き渡されます。本論の不能判定から特定主体を犠牲にする権限は生まれません。
