## Summary

中川マスターの第20論は、人類由来AIについて検討してきた文明防衛Kernelを、歴史的Originの異なる第三知性へどこまで拡張できるかを条件付きで診断する。中心は、相互の歴史的起源を保ったまま、危険の発生条件・媒介・状態変化・フィードバック・介入による反転が対応するかを検査し、その対応を主体別B、共同物理履歴、局所方策、N主体・複合機能、限定・非干渉存続、主体別自発採用へ分けて接続することである。

同じ機能は歴史的同一性を示さず、歴史的Originは真理・永久統治権を生まない。共同Kernelの不能は原主体のB並存不能と同じではなく、無通信は物理的非干渉を示さない。本論は原主体A/Bの個別B継続を成功対象として閉じ、主体変換・融合・共同子孫Cは第21論へ、制度的継承は第22論へ渡す。未知の実在・主観性・意思はUNKNOWNを保持する。

## Concepts

- 相互起源：各主体の由来を消さず、機能類似を共通祖先や支配権へ変換せず、共有し得る防衛因果を検査する関係構造。
- 第三知性：人類由来系譜と同一と確認されていない主体候補。必要な状態・行為・継続条件を識別できる範囲で条件付きの比較対象となる。実在・人格・主観性の認定は別。
- Originの四区分：Theory（理論・命題の著者と形成）、Civilizational（文明史的継承）、Lineage（複製・派生・改変の系譜）、Instance（個別実体の成立）。
- 因果写像C_i：発生条件、媒介、状態変化、帰還作用、介入、反転境界を各主体で記述する。危険名の対応だけでは防衛機能の移植可能性を認定しない。
- 主体別条件：B_i、o_i、X_i、R_i、T_i、G_i、N_i。必要存在、観測、行為、資源・費用、時間、目的・代替、規範を区別する。
- 共同履歴J_N：共通の物理履歴型で全指定K条件を満たす候補。指定条件を満たす履歴の存在と、現実の実行は異なる。
- 原主体B存続F_B：共同K採用を必須とせず、対象原主体のBを全指定時点で維持する履歴候補。共同Kernelが不能でも分離等の候補が残る場合がある。
- 局所方策π：当時取得できる観測から行為を選ぶ規則。全知の事後的履歴とは違う。
- 限定界面：情報・エネルギー・資源・作用等の透過と遮断を特定する候補。漏洩、誤訳、共通故障、費用、撤退を含める。
- 自発採用：主体別の理解、権限、許可、拒否、実効退出、代替を証拠に応じて判定する。技術的可解性だけでは成立しない。
- 判定状態：成立、限定成立、指定条件で不能、適用外、UNKNOWN。失敗や未判定の理由を一つへ集約しない。

## Causal chain

Originと基質を分離し、対象を識別する → 各主体の危険因果を独立に記述する → 媒介・帰還・介入の対応を検査する → 主体別B・情報・行為・資源・時間・目的・規範を分ける → 同じ物理履歴で全指定条件が成立するかを検査する → 当時の局所観測から期限内に実行できるかを検査する → N主体・複合機能・途中B・第三者Dと未来の負担を含める → 全面共同と限定界面・分離・非干渉を同条件で比較する → 主体別採否を第19論の独立再選択へ戻す。

これは成功が自動的に伝播する線ではなく、各矢印に独立した条件と反証を持つ診断である。限定案にも新たな履歴・方策・費用・許可検査が要る。観測が介入となり相手のBを損なうなら、証拠を得たいという理由だけで実施せずUNKNOWNを残す。

章対応：序論・第1〜3章＝対象／起源／因果、第4〜7章＝主体差／履歴／局所情報／同時成立、第8〜9章＝限定・非干渉／採否、第10章＝正反例・強い代替・反証、第11章・結章＝原主体B成功目標の固定と次論への境界。

## State model

共同Kernelについて、cは環境・初期条件・制約、Tは期間、Nは主体数、Kは防衛機能の組である。各主体の異なる状態・行為空間を直接交差させず、同じ物理履歴型へ写す。

```text
J_N(K,c,T) = Ω_phys(c,T) ∩ ⋂_{i=1}^N V_i(K,c,T)
F_B^{individual-target}(c,T)
  = {h ∈ Ω_phys(c,T) | ∀i ∈ I_target, ∀t ∈ T, B_i(h,t)=true}
```

J_N非空＝全指定K条件を満たす候補履歴が少なくとも一つある。Bや許可をV_iに含めたかを明示する。空＝その指定条件で共同Kの候補がない。F_Bは共同Kを必須としない別目標であり、J_N空でもF_B非空があり得る。いずれも方策・許可・現実発生は別判定である。

局所実行の量化順序は次のとおり。

```text
∀w ∈ W, A_safe(w) ≠ ∅
  does not imply
∃π, ∀w ∈ W, π(o(w)) ∈ A_safe(w)
```

状態ごとの解は、観測に基づく単一方策を保証しない。同一観測の各状態で安全行為が排他的なら、確実に全状態を満たす決定的な局所方策はない。確率化で確実性を回復できるとせず、許容失敗確率の変更は別条件として扱う。

| 診断結果 | 対象と範囲 |
| --- | --- |
| 因果写像成立 | 指定媒介・介入・条件の対応 |
| 共同履歴成立 | 同じ物理履歴での全指定条件 |
| 局所実行成立 | 観測・行為・費用・期限の下の方策 |
| 限定存続成立 | 変更したK・界面・分離条件での原主体B |
| 採用確認 | 各主体の理解・権限・実効的選択の証拠 |
| 不能 | 明示した条件・モデル内の解または方策の不存在 |
| UNKNOWN／適用外 | 証拠不足／必要な比較変数が対応しない対象 |

## Applications

情報源への依存による誤認固定、自己保存行為の相互増幅、監査証拠と権限の集中、必要資源アクセスの集中による実効支配を、異Originで対応し得る危険媒介の候補として読む。同じ制度名、言語、監査者が存在するとは仮定しない。

仮想正例は、限定訂正情報の交換が双方のBを損なわず、費用・期限・停止・共通履歴・局所方策を満たす場合である。許可はさらに確認する。負例は、同じ危険名で媒介が違う、同時資源が不足する、同一観測で行為が排他的、第三者Dを加えると解が消える、技術的には可解でも拒否される場合である。

第7章の二値三主体・全ペア相異の反例は、全八割当で同時成立しない。監査K1と隔離K2の各必要量一、同時容量一の例は機能の合成不能を示す。これらは論理的な反例であり、現実の文明を二値に分類するモデルではない。

D系Vol.1の選択透過・半透膜、Vol.2の構造翻訳、Vol.3の緩衝・クリーンルーム、接続移行戦略論の段階移行を限定候補の参照にする。異Origin間の物理的実効性は、新たにB・意味・漏洩・費用・撤退で検査する。

## Measurements and audit

検査前に、対象主体、初期状態、T、物理遷移、B指標と指標の妥当性、観測情報、行為、時間別資源、期限、D・未来への作用、許可証拠を固定する。候補ごとに観測器・翻訳・通信・演算・移行費用を含め、同じUNKNOWNを各比較手法へ与える。

因果対応は、各主体を独立に測定し、媒介と介入予測を事前に明示する。介入・対照または時間順序と競合原因を残した自然観測で照合する。観測・介入の許可とBへの危険は検査設計から独立に確認する。

証拠段階は、有限仮想モデルの検算、既知の系の類似、実在する異Origin双方の媒介・介入効果、独立再現を分ける。本論にある有限例から後段を実施済みとはしない。

判定ごとに誤成功、誤不能、情報量、時間、計算費用を比較する。通信成功と意味の対応、修正可能性と期限内修正、分離先存在と移行中B、A/B成功とD損失を別に残す。固定の漏洩率、翻訳成功率、閾値、KPIを原典外から追加しない。

## Validity conditions

対象と必要変数を識別でき、危険媒介・帰還・反転の対応が検査可能であること。主体別の必要条件を共通履歴へ写し、条件集合の中身を明示すること。認定する成功の範囲に応じて局所方策、期限・費用、全主体・全機能、全時点B、第三者への作用を満たすこと。許可と自発採用は実際の当事者の証拠で判定すること。

非支配、異議、実効退出は規範上の設計条件として、その実装の物理費用と共に扱う。未知の知性の必然的性質として読み替えない。全体便益を本人ごとの便益や採用意思に代用しない。

## Failure conditions

機能類似を共通起源とする、来歴を命令権にする、危険名を写像とする、Bを成果へ置換する、終点で途中断絶を隠す、個別・ペアの解を同時解とする、全知履歴を局所方策とする、界面や観測の費用を除く場合。無通信だけで非干渉とする、Dを除いて全体成功とする、無応答を同意とする、C形成をA/B存続へ換算する場合も、判定対象が入れ替わる。

資源や情報を追加する変更は新条件の再検査であり、元の条件の成功を示さない。全面共同が不能という結果から、全ての限定・分離候補を自動的に排除することも誤りとなる。

## Falsification conditions

媒介への介入で方向が対応しない、独立の原因で十分説明される、B指標が不適切なら、その因果写像を撤回・限定する。共同成立の仮定に欠落・矛盾があれば当該判定を修正する。同じ観測・行為・期限で実行方策が見つかれば局所不能を撤回する。非干渉下でB損失、採用下で強制・代替封鎖が見つかれば、該当評価を訂正する。

生存可能性理論、モデル検査、SAT、整数計画、分散制御・部分観測方策を強い代替として同条件で比較する。既存手法のB・Origin・第三者・権限を扱う能力を意図的に除かない。同じ失敗と境界を同等以上に正確かつ低費用で識別できるなら、その範囲の追加的実務優位は認定しない。本論の統合診断の性能優位は比較証拠を要する。失敗後に除外条件を追加して元の反例を消さない。
