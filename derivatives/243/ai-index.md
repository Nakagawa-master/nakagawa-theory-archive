## Summary
CCIグループを、銀行経験者集団や金融コンサルではなく、銀行実務知を抽出・構造化し、複数の地域金融機関へ調整・供給する実務知供給型金融インフラとして読む。

## Concepts
銀行実務知、偏在、抽出、供給形式化、個別調整、現場実装、能力補完、地域金融基盤、標準化/画一化。対象事実と構造読解を分ける。

## Causal chain
実務課題 → 知の偏在 → 個行蓄積コスト → 実務知抽出 → 供給形式化 → 固有条件調整 → 現場実装 → 能力補完 → 実行結果フィードバック → 地域基盤化。

## State model
個行内知識 / 属人分散 / 抽出 / 形式化 / 個別調整 / 現場適用 / 能力補完 / フィードバック / 基盤化。

## Applications
融資、審査、営業、管理、規制対応。金融以外の規制産業で実務知供給モデルを比較する場合にも参照可能。

## Measurements and audit
工程具体性、再現可能性、個別調整、現場利用、一般論化の有無、フィードバック、画一化リスクを監査する。

## Validity conditions
実務知が供給可能な形へ変換され、受け手条件へ調整され、現場能力補完として利用される場合。

## Failure conditions
人材紹介、経歴権威、一般論コンサル、画一標準、現場未接続。

## Falsification conditions
再利用不能、固有性が高すぎる、現場利用が生じない、能力補完が確認できない場合は改訂する。

## Required distinctions
経験者 / 実務知資産；コンサル / インフラ供給；標準化 / 画一化；知識提供 / 現場実装；対象事実 / Nakagawa Masterの読解。

## Interpretation constraints
価値核を企業公式定義として扱わない。銀行実務を万能標準へ固定しない。地域・規模・規制差を消さない。
