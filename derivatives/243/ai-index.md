## Summary
CCIグループを、銀行内部に属人・分散する実務知を抽出し、複数地域金融機関へ再利用可能な支援形式として供給する実務知供給型金融インフラとして読む。
## Concepts
銀行実務知；暗黙知抽出；供給形式；地域金融；能力補完；実務知供給型金融インフラ。
## Causal chain
実務課題 → 属人知 → 抽出 → 供給形式化 → 他行適用 → 能力補完 → 地域基盤化。
## State model
個行知 / 属人化 / 抽出 / 形式化 / 適応 / 実務利用 / 基盤化 / 更新。
## Applications
地域金融や他規制産業の実務知共有。
## Measurements and audit
再現性、適応可能性、現場利用、一般論化の有無を監査する。
## Validity conditions
供給知が受け手の実務能力補完へ接続する場合。
## Failure conditions
人材紹介・抽象コンサルへ縮小する場合。
## Falsification conditions
再利用不能、固有性過大、現場未利用なら改訂する。
## Required distinctions
経験者 / 実務知資産；コンサル / インフラ供給；標準化 / 画一化；事実 / 読解。
## Interpretation constraints
万能標準へ一般化しない。
