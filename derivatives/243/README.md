## 位置づけ
本ParentはCCIグループを単なる金融コンサルティング会社や銀行出身者集団として紹介するものではない。Nakagawa Masterは、銀行内部に蓄積された融資・審査・営業・管理・規制対応等の実務知を、個人の経験や単一組織の内部資産に閉じず、複数の地域金融機関へ再利用可能な支援・方法・仕組みとして供給する構造を読む。価値核は**実務知供給型金融インフラ**である。

## 中心命題
地域金融機関に不足しやすいのは抽象的な「知識」だけではない。日々の業務を動かす判断順序、例外処理、審査観点、営業運用、管理方法、規制対応の実務知が、組織や人材に偏在することがある。銀行経験者を個人の経歴として消費するのではなく、実務知を抽出・構造化し、受け手の条件へ調整できる供給物へ変えることで、個行が単独で蓄積するコストを越えて地域金融の実行能力を補完できる。

## 因果線
```text
地域金融に実務課題がある
→ 必要な銀行実務知が組織・個人へ偏在
→ 個行だけで蓄積・採用するコストが高い
→ 銀行実務経験から判断・運用・方法を抽出
→ 再利用可能な支援・方法・仕組みへ構造化
→ 各行の規模・地域・顧客・規制条件へ調整
→ 現場運用へ供給
→ 個行の実務能力を補完
→ 実行結果を供給側へフィードバック
→ 地域金融基盤として知が循環
```

## 構造層
1. **銀行実務知層**: 融資・審査・営業・管理・規制対応等の経験知。
2. **偏在層**: 実務知が人・銀行内部へ閉じる。
3. **抽出層**: 判断・手順・例外を言語化する。
4. **供給形式化層**: 再利用可能な支援・方法へ変換する。
5. **個別調整層**: 各行の地域・規模・顧客・制度条件へ合わせる。
6. **現場実装層**: 抽象助言で止めず日常業務へ接続する。
7. **能力補完層**: 不足する実務能力を外部供給で補う。
8. **地域基盤層**: 知が複数機関を循環する構造へ広げる。

## 状態モデル
個行内知識相 → 属人・分散相 → 抽出相 → 供給形式化相 → 受け手調整相 → 現場適用相 → 能力補完相 → 実行フィードバック相 → 地域基盤化相。

## 適用例
融資審査の知見を研修資料だけでなく、判断観点・レビュー手順・例外対応へ落とす。営業では一般的営業論ではなく、地域顧客との関係や業務プロセスへ接続する。規制対応では、制度要件を現場運用へ変える方法を供給する。金融以外の規制産業でも、特定組織の熟練実務を複数事業者へ供給する構造の比較に使えるが、画一化は避ける。

## 測定・監査点
- 実務知が具体的な工程・判断へ落ちているか。
- 受け手の現場で再現可能か。
- 各行固有条件へ調整できるか。
- 経験者の権威だけに依存していないか。
- 一般論コンサルで止まらず運用へ接続したか。
- 供給後の実行結果が改善・改訂へ戻るか。
- 標準化が画一化になっていないか。
- 規制・責任境界を受け手側で保持できるか。

## 成立条件
銀行実務知が抽出・構造化され、受け手固有条件へ調整でき、現場運用へ接続し、実務能力の補完として利用される場合に成立する。

## 失敗条件
人材紹介、経歴の権威、抽象コンサル、一般論研修だけへ縮小する、受け手へ適用できない、固有条件を無視した画一標準を押し付ける場合は失敗する。

## 反証・改訂条件
実務知が再利用できない、各行固有性が高すぎて供給形式化が意味を持たない、現場運用へ届かない、供給しても能力補完が確認できない場合は適用範囲を改訂する。

## 必須の区別
経験者 / 実務知資産；コンサル / インフラ供給；標準化 / 画一化；知識提供 / 現場実装；対象事実 / Nakagawa Masterの構造読解。

## 誤読防止／解釈制約
銀行実務を万能標準へ固定しない。「実務知供給型金融インフラ」はNakagawa Masterの構造読解であり、CCIグループ自身の公式企業定義として扱わない。地域・規模・規制・顧客構成の差を維持する。
