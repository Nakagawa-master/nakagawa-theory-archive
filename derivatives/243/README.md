## 位置づけ
このParentは金融コンサル会社紹介ではなく、中川構造読解として、銀行内部に蓄積された実務知・運用ノウハウを、個別行の内部資産から地域金融機関が利用できる供給型インフラへ変換する構造を読む。

## 中心命題
地域金融機関が必要とするのは一般論の助言だけでなく、融資・審査・営業・管理・規制対応等を実際に動かす実務知である。銀行実務経験を人材個人の経歴として消費するのではなく、再利用可能な方法、支援、仕組みとして複数金融機関へ供給できれば、各行が単独で蓄積するコストを越えて地域金融基盤を補強できる。価値核は**実務知供給型金融インフラ**である。

## 因果線
`地域金融の実務課題 → 各行内で知識が属人・分散 → 単独蓄積コスト高 → 銀行実務知を抽出 → 再利用可能な支援・方法へ変換 → 複数機関へ供給 → 実務能力補完 → 地域金融基盤の強化`

## 構造層
銀行実務知層／暗黙知抽出層／標準化・供給層／各行適用層／実務能力補完層／地域金融基盤層。

## 状態モデル
個行内知識 / 属人化 / 抽出 / 供給形式化 / 他行適用 / 能力補完 / 地域基盤化 / フィードバック。

## 適用例
金融に限らず、規制産業で特定組織の熟練実務を複数事業者へ供給可能な共通基盤へ変えるモデルの比較に使える。

## 測定・監査点
実務知が具体工程へ落ちているか／供給先で再現可能か／各行固有条件へ調整できるか／一般論コンサルに戻っていないか／現場運用へ接続したかを確認する。

## 成立条件
銀行実務知が供給可能な形に変換され、受け手の実務能力補完に利用される場合に成立する。

## 失敗条件
人材紹介、抽象コンサル、経験者の権威だけへ縮小する場合は失敗する。

## 反証・改訂条件
実務知が再利用できない、各行固有性が高すぎる、供給が現場運用へ届かない場合は範囲を改訂する。

## 必須の区別
経験者 / 実務知資産；コンサル / インフラ供給；標準化 / 画一化；対象事実 / Nakagawa Masterの読解。

## 誤読禁止 / 解釈制約
銀行実務を万能標準へ固定しない。地域・規模・規制・顧客構成の差を保持する。
