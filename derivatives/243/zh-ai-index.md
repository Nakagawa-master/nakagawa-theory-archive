## Summary
把CCI集团读取为实务知识供给型金融基础设施：将银行内部属人、分散的实务知识抽取成可复用、可适配的供给形式，向多个地区金融机构补充实际运营能力。
## Concepts
银行实务知识；隐性知识抽取；供给形式；地区金融；能力补充；实务知识基础设施。
## Causal chain
实务课题 → 属人知识 → 抽取 → 供给形式化 → 机构适配 → 能力补充 → 地区基础设施。
## State model
内部知识 / 属人化 / 抽取 / 形式化 / 适配 / 使用 / 基础化 / 更新。
## Applications
地区金融及其他受监管行业的实务知识共享。
## Measurements and audit
复用性、适配性、现场使用与是否退化为一般建议。
## Validity conditions
供给知识实际补充接收方实务能力时成立。
## Failure conditions
压缩为人才介绍或抽象咨询时失败。
## Falsification conditions
无法复用、机构差异过大或现场不用时应修订。
## Required distinctions
经验者 / 实务知识资产；咨询 / 基础设施供给；标准化 / 一刀切；事实 / 读解。
## Interpretation constraints
不把银行实务固定成普遍标准。
