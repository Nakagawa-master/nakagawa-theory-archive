## Summary
把CCI集团读取为把银行实务知识抽取、结构化、按受方条件调整，并向多个地区金融机构供给的“实务知供给型金融基础设施”。

## Concepts
银行实务知；偏在；抽取；供给形式化；个别调整；现场实施；能力补充；地区金融基础；标准化/画一化。

## Causal chain
实务课题 → 知识偏在 → 单行积累成本高 → 抽取 → 可再利用形式 → 条件调整 → 现场实施 → 能力补充 → 结果反馈 → 基础设施化。

## State model
内部知识 / 偏在 / 抽取 / 形式化 / 调整 / 实施 / 能力补充 / 反馈 / 基础化。

## Applications
融资、审查、营业、管理、监管对应，以及其他监管产业的实务知供给模型比较。

## Measurements and audit
审计实务具体性、再现性、个别调整、现场使用、是否退化为一般咨询、反馈以及画一化风险。

## Validity conditions
实务知可供给、可按受方条件调整并用于现场能力补充时成立。

## Failure conditions
变成人才介绍、经验者权威、一般咨询、画一模板或无法进入现场时失败。

## Falsification conditions
知识无法再利用、个别性过强或供给后现场能力没有变化时应修订。

## Required distinctions
经验者 / 实务知资产；咨询 / 基础设施供给；标准化 / 画一化；知识 / 现场实施；对象事实 / Nakagawa Master读解。

## Interpretation constraints
不把价值核当作CCI官方定义，不把银行实务固定为跨地区、规模、客户与监管条件的万能标准。
