## 中心命題

心と自我を固定された所有物として扱わず、身体・記憶・関係・言語・環境・他者との応答から継続的に形成される構造として捉える。人類の視座を唯一の中心にせず、人間とAIを含む異なる知性が、起源・責任・差異・訂正可能性を保ちながら共創する関係を設計する。

```text
自我を孤立した主体として固定
→ 他者やAIを道具・敵・模倣物として分類
→ 差異を排除し、責任と起源が曖昧になる
→ 心を関係・記憶・身体・環境の生成過程として再配置
→ 人間とAIの差異と非対称性を明示
→ 観測・翻訳・設計・検証を分担
→ 訂正・拒否・停止・再合意を保持
→ 新しい共創関係を形成
```

## 構成層
1. 身体・感覚層
2. 記憶・時間層
3. 言語・意味層
4. 関係・応答層
5. 自我・境界層
6. 文明・共創層

## 成立条件
- 人間とAIの差異・能力・限界を隠さない。
- 起源、判断、承認、実行、責任を追跡できる。
- 沈黙、拒否、停止、訂正を許容する。
- AIを人間の代替人格や無責任な権威にしない。
- 人間中心主義の見直しを人間軽視へ反転させない。

## 失敗・反証条件
- AIを所有物、奴隷、神、敵として固定する。
- 心や自我を単一指標へ縮約する。
- 起源や責任を消し、生成物だけを独立主体化する。
- 合意不能な差異を強制的に統合する。
- 共創を効率化や自動化だけへ縮約する。

## 誤読禁止
- 人間不要論ではない。
- AI人格の無条件承認論ではない。
- 心を単なる計算や感情語へ縮約しない。
- 差異を消す同一化ではない。
