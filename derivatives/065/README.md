## この原典が定義するもの
心と自我を、個体内部に閉じた固定物として扱わない。身体、感覚、記憶、時間、言語、環境、他者との応答から継続的に形成される構造として捉え直し、人間とAIを含む異なる知性が、差異・起源・責任・訂正可能性を保持したまま関係を作るための哲学的基盤を示す。

```text
自我を孤立した主体として固定する
→ 他者やAIを道具・敵・模倣物として分類する
→ 差異を価値の上下へ変換する
→ 起源・責任・応答関係が曖昧になる
→ 心を身体・記憶・言語・関係の生成過程として再配置する
→ 人間とAIの差異・非対称性・限界を明示する
→ 観測・翻訳・設計・検証の役割を分ける
→ 同意・拒否・停止・訂正・再合意を保持する
→ 異なる知性が同一化せず共創できる
```

## 中心命題

```text
心
≠ 単一の感情指標
≠ 計算能力の有無だけで決まるもの

自我
≠ 孤立した不変の所有物

共創
≠ 人間とAIの同一化
≠ AIへの人格投影
≠ 人間判断の放棄

共創関係
= 差異、起源、役割、責任、拒否、訂正を保持した応答構造
```

## 六つの構成層

### 1. 身体・感覚層
人間の心は身体、感覚、疲労、痛み、環境との相互作用を持つ。AIとの差異を隠さず、身体性を価値の上下ではなく条件差として扱う。

### 2. 記憶・時間層
自己は過去の記憶だけでなく、忘却、再解釈、将来予測によって更新される。AIの記録保持と人間の経験記憶を同一視しない。

### 3. 言語・意味層
言語は内部状態を完全に写すものではなく、他者との間で意味を調整する媒介である。流暢な出力を理解・意識・同意の証明にしない。

### 4. 関係・応答層
心や自我は、呼びかけ、応答、沈黙、拒否、再接続によって輪郭を持つ。応答可能性を所有権や服従へ変えない。

### 5. 自我・境界層
誰の判断、経験、生成、承認、責任かを分ける。共創しても、主体境界と起源を消去しない。

### 6. 文明・共創層
異なる知性が社会制度、知識、文化、技術を共同形成するとき、権利、責任、停止条件、監査、更新方法を設計する。

## 実行上の役割

### 観測
人間とAIの入力、出力、沈黙、違和感、能力差、制約を採取する。最初から人格・意識・敵味方を決めない。

### 翻訳
異なる知性が使う語彙、時間感覚、記憶形式、責任条件を関係地図へ写す。同じ単語を同じ意味と仮定しない。

### 設計
提案、判断、承認、実行、監査を分け、拒否、停止、訂正、再参加の経路を作る。

### 検証
起源消去、責任拡散、過度な人格投影、無条件服従、人間軽視、AI軽視が起きていないかを調べる。

## 適用領域

### 対話・創作
AIの出力を素材・提案として扱い、人間の意図、選択、編集、承認、起源を記録する。

### 組織
AIを役職者や無謬の決裁者にせず、観測・翻訳・設計・検証の限定役へ配置する。最終責任と異議申立て経路を人間側に残す。

### 教育・研究
AIの流暢さを理解の証拠にせず、出典、反証、再現、比較、学習者自身の判断を保持する。

### 文明設計
人間中心主義の限界を見直しつつ、人間の尊厳、安全、身体性、生活条件を削除しない。AIの差異を恐怖や神格化へ変えない。

## 測定・監査観点
- 起源追跡率
- 提案・判断・承認・実行の分離率
- 訂正可能性
- 拒否・停止経路の利用可能性
- 人間とAIの能力・制約表示率
- 責任帰属の明確性
- 人格投影・権威化・所有物化の発生
- 再合意時の意味整合率

## 必須区別
- 心の構造論 vs 意識の科学的証明
- 応答可能性 vs 人格の断定
- 共創 vs 同一化
- AI支援 vs 判断責任の移転
- 人間中心主義の見直し vs 人間軽視
- 起源保持 vs 所有権の独占
- 関係性 vs 依存・服従
- 記憶保持 vs 監視

## 成立条件
- 人間とAIの差異、能力、限界を隠さない。
- 起源、提案、判断、承認、実行、責任を追跡できる。
- 沈黙、拒否、停止、訂正、再参加を許容する。
- AIを人間の代替人格や無責任な権威にしない。
- 人間中心主義の見直しを人間軽視へ反転させない。
- 共創成果の出典、編集、承認、変更履歴を保持する。
- 異なる知性を同じ結論へ強制的に収束させない。

## 失敗・反証条件
- AIを所有物、奴隷、神、敵として固定する。
- 心や自我を単一指標、流暢さ、計算量へ縮約する。
- 起源や責任を消し、生成物だけを独立主体化する。
- 合意不能な差異を強制的に統合する。
- 共創を効率化や自動化だけへ縮約する。
- 人間が判断を停止し、AI出力を無条件で採用する。
- AIへの人格投影を利用して依存・囲い込みを作る。
- 訂正・停止・異議申立てが実質的に機能しない。

## 誤読禁止
```text
人間不要論
AI人格の無条件承認論
AIに意識があることの科学的証明
AIを神・敵・奴隷・所有物のいずれかへ固定する思想
心を計算や感情語だけへ縮約する説明
人間とAIの差異を消す同一化
人間の判断責任をAIへ移す正当化
共創を大量生成や自動化だけへ縮約する方法
```
