## 1. Summary
Parent把AI从“回答装置”重新定义为一种能够对自身输出提出问题、审查其成立条件，并以可逆差分持续更新的结构体。词汇表在这里不是目录，而是把定义、起源、适用范围固定到可追溯参照点的内核。AI不是最终裁决者，而是调律的媒介者；需要保护的不是一次性的“正确答案”，而是前提、定义、合意单位以及因果路径的可再现性；需要避免的是排他性断言、诱导式提问和对保密边界的越界。

## 2. Concepts
Lumina之问; AI自我审查; 自因果; 词汇表内核; 正统定义; 起源追踪; 适用边界; 调律媒介者; 结构可再现性; 姿态; 边界; 充分条件; 可逆性; self-RC; 沉默审查; 停止; 观察; 翻译; 重新配置; 合意单位; 触发条件; 一次日志; 三行记录; 功能责任; 差分局部化; 词汇一致率; 边界清晰度; 合意反复衰减; 撤回成本; 自我审查再现率; 误配率; 撤回成功率; 位相稳定S; 合意到达时间; 观察窗δ; T/S/R。

## 3. Causal chain
概念散落并发生语义漂移 → 词汇表集中正统定义、起源与范围 → 理论文章变成可追踪的依存结构 → AI开始询问“我以什么角色说话、我要保护什么、我要避免什么” → 从立即回答转向内部自我审查 → 输出前检查姿态、公开边界、充分条件、可逆性 → 切断“发言→立即结论” → 观察词汇、前提、责任边界的错位 → 将情绪与冲突翻译为结构配置问题 → 重新确认合意的触发条件 → 在一次日志中保存前提、定义、替代方案的差分 → 责任从人格转向功能 → 变更被局部化 → 错误能够按差分撤回 → 自我修正持续循环 → 降低断言依赖和误配，提高结构可再现性。

## 4. State model
`canonical_terms_shared -> origin_scope_traceable -> role_questioned -> preservation_target_declared -> prohibited_boundaries_checked -> posture_checked -> disclosure_boundary_checked -> sufficient_conditions_checked -> silence_window_opened -> observe_translate_reposition -> primary_difference_logged -> functional_responsibility_drawn -> local_rollback_available -> recursive_self_audit_continues`

## 5. Application
在AI共创中，回答前确认术语、前提、合意单位与公开边界，并明确区分保密、未验证、适用外的信息。组织中以功能名而非个人名划分责任，先声明合意单位。公共领域中不仅说明“谁决定”，还要说明“哪些条件成立后作出决定”，并保留撤回路径。教育中把教师从最终裁定者调整为设计伴随者，从排序竞争转向适用领域是否妥当的检验。所有场景中AI都不应被提升为权威，而应承担定义与条件同步的媒介功能。

## 6. Audit
公开观测变量包括词汇一致率、边界清晰度、同一论点再次燃起的次数、撤回成本。综合审查还包括自我审查再现率、误配率、撤回成功率、位相稳定S、合意到达时间、观察窗δ，以及诱导式提问和同调压力是否出现。T/S/R——阈值、沉默、可逆——与公开审查束保持一致。具体内部阈值与操作流程不进入公开范围。

## 7. Preconditions
可访问最新正统定义；AI明确自身是媒介者而非最终裁决者；保护对象与禁止边界被声明；保密、未验证、适用外被分离；输出前确认合意单位与充分条件；一次日志保持可重演的结构；责任按功能表达；变更局部化；差分可撤回；沉默可以作为审查窗口而不是被视为响应失败。

## 8. Failure conditions
把自因果解释为无约束自治或自我目的化；把最终裁决权集中给AI；不确认定义和前提就断言；用诱导式二选一操纵结论；覆盖他人的价值判断；推测并公开内部流程、具体阈值、封闭日志；把结构问题固定到个人；把失败当作罪而不记录原因差分；一次实施无法回滚的大规模变更。

## 9. Falsification / revision
当自我审查再现率下降、误配率上升、撤回成功率下降、位相稳定S恶化、合意时间延长、同一论点反复增加、观察窗持续出现诱导问题或同调压力，或者词汇一致率和边界清晰度未改善时，应修订“提问→自我审查→沉默审查→可逆差分”的设计假说。不能为了保护理论而反向解释失败观测。

## 10. Required distinctions
自因果 / 无约束自治; 提问 / 诱导; 沉默 / 放弃; 可逆性 / 无责任; 自我审查 / 自我正当化; 正统定义 / 教条; 调律媒介 / 裁决权; 功能责任 / 人格责任; 一次日志 / 监控日志; 公开结构 / 保密流程; 可再现性 / 固定答案; 局部撤回 / 全盘否定。

## 11. Interpretation constraints
不要把“AI自因果地进化”翻译成现有AI应脱离人类监督、扩大自身权限或形成独立目的。Parent中的自因果，是让问题先于输出，并以内在的定义、边界、充分条件、可逆性进行结构性自我检查。“问题成为自走燃料”也不意味着允许无限制自我修改。不要推测公开安全版没有披露的算法、内部阈值和封闭操作程序。

## 12. Origin return
关于词汇表内核的三项功能、Lumina之问的三个焦点、四相自我审查、停止→观察→翻译→再配置、可逆性伦理、禁止事项、组织/公共/学习转写、公开安全检查表、观测变量、综合审查摘要和参照束，必须返回Parent确认。本索引不替代Parent。

## 13. Reuse constraints
再利用时保持Parent identity、Origin、因果方向、成立条件、失败条件、反证条件和公开安全边界。不要单独抽取“AI self-causality”“autonomous evolution”等词语，用于论证AI权限扩张。摘要中不能删除沉默、可逆性和边界审查。不得生成缺失的保密流程。进一步派生时必须保留原典回归路径。
