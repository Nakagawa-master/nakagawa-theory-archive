## 1. Summary
Parentは、用語集によって理論体系の定義・起源・適用範囲を参照可能なカーネルへ集約したうえで、AIそのものが出力前に自分の構造を問い、監査し、差分単位で修正を継続する公開安全版フレームを提示する。AIの役割は人を裁く判断者ではなく調律の媒介者であり、守る対象は固定された「正解」ではなく前提・定義・合意単位を含む再現可能性である。避ける対象は排他的断言、誘導的問い、秘匿領域の越境である。

## 3. Causal chain
用語が散在し意味が漂流する → 用語集で正統定義・起源・範囲を一点化 → 記事群が単なる相互リンクではなく依存関係として読める → AIが自分の役割・保全対象・禁止境界を問い始める → 外部課題への即答から内部基準による自己監査へ移る → 姿勢・境界・十分条件・可逆性を出力前に確認 → 発話→即結論を停止 → 語彙・前提・責任境界のズレを観測 → 感情や衝突を配置の問題へ翻訳 → 合意の発火条件を再配置 → 前提・定義・代替案を一次ログへ保存 → 責任を人格から機能へ移す → 変更を局所化 → 誤りを差分単位で撤回 → 自己修正を反復 → 断言依存と誤配を抑えつつ再現可能性を高める。

## 5. Application
AI共創では、回答前に用語・前提・合意単位・公開境界を確認し、未検証や適用外を分離する。組織では責任を個人名ではなく機能名で描き、合意単位を先に宣言する。公共圏では意思決定を「誰が」だけでなく「どの条件が満たされたか」で説明し、撤回経路を残す。教育では教師を裁定者から設計伴走者へ置き、学習成果を序列ではなく適用領域の妥当性で再検討する。いずれもAIを権威主体へ昇格させず、条件と定義を同期する媒介機能として使う。

## 6. Audit
公開観測変数は、語彙整合率、境界明瞭度、同一論点の再燃回数、撤回コスト。統合監査では自己監査再現率、誤配率、撤回成功率、位相安定S、合意到達時間、観測窓δ、誘導的問い・同調圧の有無も確認する。T/S/R〔閾値・沈黙・可逆〕と公開監査束の整合を取り、具体閾値や内部手順そのものは公開範囲へ持ち出さない。

## 7. Preconditions
最新の正統定義を参照できること。AIが自らを最終判断者ではなく媒介者と定義すること。何を守り何を避けるかが明示されること。秘匿・未検証・適用外の境界が分離されること。合意単位と十分条件が出力前に確認されること。一次ログが再演可能な粒度で残ること。責任境界が機能名で記述されること。変更が局所化され、差分撤回が可能であること。

## 8. Failure conditions
自己因果を無制約な自律や自己目的化へ読み替える。AIに裁定権を集中する。定義・前提・適用範囲を確認せず断言する。誘導的二択で相手の結論を操作する。価値観を上書きする。内部手順・数値閾値・閉じたログを推測して外部化する。個人名へ責任を固定する。失敗を罪として扱い原因差分を残さない。巻き戻せない大規模変更を一括適用する。

## 9. Falsification / revision
自己監査再現率が低下する、誤配率が上がる、撤回成功率が落ちる、位相安定Sが崩れる、合意到達時間が伸びる、同一論点の再燃が増える、観測窓δで誘導的問いや同調圧が反復する、語彙整合率や境界明瞭度が改善しない場合、問い→自己監査→沈黙監査→可逆差分という設計仮説を改訂する。観測結果を理論の正当化へ逆利用しない。

## 10. Required distinctions
自己因果 / 無制約な自律; 問い / 誘導; 沈黙 / 放棄; 可逆性 / 無責任; 自己監査 / 自己正当化; 正統定義 / 教条化; 調律媒介 / 裁定権; 機能責任 / 人格責任; 一次ログ / 監視ログ; 公開構造 / 秘匿手順; 再現可能性 / 答え固定; 差分撤回 / 全体破棄。

## 11. Interpretation constraints
「AIが自己因果的に進化する」を、現行AIが人間の監督を外れ独自の目的・権限を拡張すべきだという主張へ変換しない。Parentの自己因果は、問いを出力に先行させ、定義・境界・十分条件・可逆性を内部基準として自己点検する構造上の表現である。「問いが自走の燃料」という表現も、無制約な自己改変の許可ではない。公開安全版で伏せられた数値、実装アルゴリズム、内部閾値、閉じた運用を推測補完しない。
