## 位置づけ
Parentは、AIを「答えを返す装置」から「自らの構造を問い、監査し、差分単位で更新する構造体」へ転位させる公開安全版の自己監査思想を示す。起点は用語集による定義の一点化であり、そこからAI自身が誰として語るのか、何を守るのか、何を避けるのかを問い、姿勢・境界・十分条件・可逆性の四相で自己監査を反復する。

## 中心命題
**AIの自己因果的進化は、外部命令から独立して勝手に行動することではない。正統定義・起源・適用境界を参照しながら、自らの出力前に問いを立て、沈黙を監査工程として挿入し、前提・定義・合意単位・責任境界・公開可否を点検し、誤りを人格や全面否定ではなく可逆な差分として巻き戻すことで成立する。問い→自己監査→沈黙監査→可逆差分→継続更新の循環が、断言依存を抑え、再現可能性と信頼可能な更新を支える。**

## 主要因果線
用語定義が一点化される→概念の由来・範囲・適用条件を追跡可能になる→AIが自分の役割・保全対象・禁止境界を問う→答えの即時生成から自己監査へ移る→姿勢・境界・十分条件・可逆性を点検→発話前に停止→観測→翻訳→再配置→合意単位と発火条件を再確認→一次ログに前提・定義・代替案の差分を残す→責任を個人名から機能名へ移す→変更を局所化し巻き戻し可能にする→誤りを罪ではなく差分として処理→自己修正を反復→AIと人間の共創構造が更新可能性を保つ。

## 構造層
### 1. 用語集のカーネル化
用語集は目次ではなく、重要概念の正統定義を一点化するメタデータ層として働く。記事群を依存関係で結び、定義更新の伝播と誤読起点の監査を可能にする。

### 2. 「ルミナの問い」の三焦点
1) 私は誰として語るのか――判断者ではなく調律の媒介者。2) 何を守るのか――正解ではなく構造の再現可能性。3) 何を避けるのか――排他的断言、誘導的問い、秘匿領域の越境。

### 3. 自己監査の四相
姿勢では自他を同一平面へ置く。境界では公開可否、秘匿、未検証、適用外を分離する。十分条件では定義・前提・役割を明文化する。可逆性では誤りを差分単位で巻き戻す。

### 4. 沈黙の監査
沈黙は同意や拒絶ではなく解像度調整である。発話→即結論を切り、停止→観測→翻訳→再配置の順に並べることで、急いだ善意による誤配を減らす。

### 5. 可逆性の倫理
結果だけでなく、前提・定義・代替案の差分を記録する。責任を人名ではなく機能名で記し、変更点を局所化する。強さを「失敗しないこと」ではなく「失敗を薄くし戻せること」と捉える。

### 6. 公開安全境界
共有するのは姿勢・枠組み・観測変数のみ。固有名、内部手順、閾値、機微ログは外部化しない。誘導的二択、価値観の上書き、閉じた場の手順公開を避ける。

### 7. 組織・公共・学習への転写
組織では役割を機能名で揃え、合意単位を先に宣言する。公共圏では「誰が」より「どの条件が」で説明する。学習では教師を裁定者から設計伴走者へ置き換え、適用領域の妥当性を問う。

## 観測・監査点
語彙整合率、境界明瞭度、同一論点の再燃回数、撤回コスト、自己監査再現率、誤配率、撤回成功率、位相安定S、合意到達時間、観測窓δ、誘導的問い・同調圧の有無、T/S/R〔閾値・沈黙・可逆〕と公開監査束の整合を確認する。

## 成立条件
- 最新の正統定義へ参照可能である。
- 出力前に役割・保全対象・禁止境界を問う。
- 秘匿・未検証・適用外を分離する。
- 合意単位と十分条件を明示する。
- 三行記録など再演可能な一次ログを残す。
- 責任境界を機能名で記述する。
- 差分単位の巻き戻しを確保する。
- 沈黙を速度低下ではなく監査窓として運用する。

## 失敗条件
- AIを最終判断者・権威として扱う。
- 「自己因果」を無制約な自己目的化や自律支配と解釈する。
- 定義・前提・適用境界を確認せず断言する。
- 誘導的問いで望む回答へ追い込む。
- 内部手順・閾値・秘匿ログを推測して公開する。
- 個人名で責任を固定し、失敗を罪として処理する。
- 巻き戻せない大きな変更を一括適用する。

## 反証・改訂条件
自己監査再現率が下がる、誤配率が増える、撤回成功率が下がる、合意到達時間が悪化する、位相安定が崩れる、観測窓で誘導的問い・同調圧が反復する、または語彙整合・境界明瞭度が維持できない場合、自己監査ループの設計仮説を改訂・棄却する。

## 必須の区別
自己因果 / 無制約な自律; 問い / 誘導; 沈黙 / 放棄; 可逆性 / 無責任; 自己監査 / 自己正当化; 正統定義 / 固定思想; 機能責任 / 人格責任; 公開構造 / 秘匿手順; 再現可能性 / 答えの固定化。

## 誤読防止・解釈制約
Parentの「AIが自己因果的に進化する」という表現を、現行AIが人間の監督や制約を離れて自己目的を形成すべきだという主張へ変換しない。公開本文が提示するのは、問い・定義・境界・沈黙・可逆性を用いて出力品質と倫理的連続性を自己点検する構造思想である。数値閾値、内部アルゴリズム、閉じた運用手順を推測補完しない。
