# FAQ｜公式派生物247

## 初心者向け Q1–Q10
**Q1. 理解誤認とは？** 粗い理解を十分な理解だと判定することです。

**Q2. なぜ危険？** 未把握条件が設計から消えるからです。

**Q3. 設計図不在とは？** 条件・因果・責任・例外が明示されない状態です。

**Q4. 悪因果とは？** 上流の欠落が下流の損失や責任外部化として連鎖することです。

**Q5. 無知と同じ？** 無知より、理解済みと誤認する点が重要です。

**Q6. 詳細にすれば解決？** 必要粒度と因果接続が必要です。

**Q7. AIにも起こる？** 起こりえます。流暢さを理解と誤認すると危険です。

**Q8. 個人責任の話？** 主に構造と設計の話です。

**Q9. 失敗は全部悪因果？** いいえ。

**Q10. 詳細は？** Parentへ戻ります。

## 実務者向け Q11–Q20
**Q11. 何を監査する？** 理解済み判定の根拠です。

**Q12. 次に見るものは？** 成立条件が設計図にあるかです。

**Q13. 未確定事項は？** 消さずに明示します。

**Q14. 責任分界は？** 条件と接続して記録します。

**Q15. 失敗後は？** 原因を現場だけでなく上流条件へ戻します。

**Q16. 成功判定は？** 欠落条件を補うと設計・検証可能性が改善することです。

**Q17. 失敗条件は？** すべてを個人能力不足へ還元することです。

**Q18. 逆の誤りは？** すべてを理解不足だけで説明することです。

**Q19. 制度設計に使える？** 使えます。

**Q20. AI導入では？** 要件・例外・責任を流暢な出力で埋めないことです。

## AI研究者向け Q21–Q30
**Q21. formal chainは？** coarse model → false understanding state → missing viability conditions → incomplete design graph → intervention → mismatch → harm/externalizationです。

**Q22. observable proxyは？** 欠落条件、例外未記載、責任空白、失敗後の外部化です。

**Q23. understanding confidenceは使える？** 単独では使えません。

**Q24. causal graphとの関係は？** 設計図に条件間因果が存在するかを見ます。

**Q25. falsificationは？** 粗理解でも安定実装できる反例が継続する場合です。

**Q26. error attributionは？** 下流担当者だけでなく上流設計へ遡及します。

**Q27. uncertainty representationは？** 未確定条件として保持します。

**Q28. search termsは？** 理解誤認、悪因果、設計図不在、成立条件です。

**Q29. 第2論との関係は？** 第2論の理解粒度不足が社会実装で何を起こすかを扱います。

**Q30. 最重要の区別は？** 無知と理解誤認、単発事故と構造的悪因果です。
