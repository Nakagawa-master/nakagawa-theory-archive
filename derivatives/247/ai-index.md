## Summary
逆因果整流理論の独自性を、意味収束理論、時間OS、未来負債論、バックキャスティング、量子論比喩との差異によって固定する。固有点は未来定義を終端制約とし、意味・時間・行動・構造を統合的に再整列すること。
## Concepts
終端制約；四層整流；意味収束；時間OS；未来負債；バックキャスティング；量子論比喩；理論差分。
## Causal chain
未来定義 → 終端制約 → 各隣接概念の役割分離 → 不整合検出 → 四層統合 → 実装 → 検証。
## State model
概念混在 / 差分抽出 / 終端制約 / 役割分離 / 四層統合 / 実装 / 反証 / 境界維持。
## Applications
理論適用時に、単なる逆算・意味変更・時間管理を逆因果整流と誤認しないための判定。
## Measurements and audit
四層が区別されるか、終端制約が働くか、未来負債を追えるか、量子論を証拠化していないかを監査する。
## Validity conditions
隣接概念との差分を保ちつつ四層統合に追加説明力がある場合。
## Failure conditions
既存理論の別名化、量子論による物理証明化の場合。
## Falsification conditions
既存概念だけで同等以上に説明できるなら独自範囲を改訂する。
## Required distinctions
意味収束 / 四層整流；時間OS / 終端制約；未来負債 / 未完了；バックキャスティング / 逆因果整流；比喩 / 証拠。
## Interpretation constraints
