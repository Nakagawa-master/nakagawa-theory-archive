## Summary
逆因果整流理論・第2論は、理論を隣接概念へ溶かさず、同時に無関係化もしないための差分固定論である。意味収束理論は未来定義による過去・現在ノードの意味・接続再配置、時間OSは時間認識・配分・順序、未来負債論は現在の局所最適が将来へ押し出す制約・コスト、バックキャスティングは未来から現在へ計画を逆算する方法を主に扱う。逆因果整流理論はそれらと接点を持つが、成立可能な未来定義を**終端制約**として置き、意味・時間・行動・構造の四層を一つの整流プロセスとして扱う点を固有軸とする。

第2論は量子論的な語彙や逆因果の比喩が、物理学的証明へ誤読されることも遮断する。未来条件が現在の判断を変えるという設計関係を、未来から情報が送信される、時間が逆行する、量子力学が理論を証明する、という主張へ変換しない。固有説明力が既存概念だけで十分代替されるなら、逆因果整流理論の独自範囲自体を縮小・改訂する。

## Concepts
- **差分固定**: 共通点を認めながら、各理論の主対象・操作・境界を明示すること。
- **意味収束理論**: 未来定義によって過去・現在ノードの意味・接続が再配置される構造を主対象とする。
- **時間OS**: 時間認識、配分、優先順位、順序の設計を主対象とする。
- **未来負債論**: 現在の局所最適・先送りが将来へ押し出す制約・コストを扱う。
- **バックキャスティング**: 将来状態から現在へ必要工程を逆向きに設計する方法。
- **終端制約**: 成立可能な未来条件を現在の四層配置を評価する基準として使うこと。
- **四層整流**: 意味・時間・行動・構造を分けつつ、同一終端制約の下で連動させて再配置すること。
- **量子論比喩**: 説明上の類似表現であり、理論の物理的証明ではない。
- **独自説明力**: 終端制約と四層統合が、隣接概念単独では説明しにくい実装差を生むこと。

## Causal chain
隣接理論と共通語彙が多い → 概念境界が曖昧になる → 逆因果整流理論が意味収束・時間設計・未来負債・バックキャスティングの別名として読まれる → 量子論比喩まで物理証拠へ誤拡張される → 各隣接理論の主対象を分離する → 成立可能な未来定義を終端制約として明示する → 意味の再評価を分離する → 時間配分・順序の再設計を分離する → 将来へ押し出された未来負債を特定する → 現在行動を再配置する → 必要なら制度・権限・役割・情報流を改修する → バックキャスティングに相当する逆向き実装を区別する → 四層統合が追加する説明力を検証する → 量子比喩を物理主張から切り離す → 固有差がなければ理論範囲を改訂する。

## State model
- **概念混在相**: 隣接理論との共通部分だけが見え、境界が曖昧になる。
- **役割分離相**: 意味、時間、未来負債、計画逆算等の主対象を分ける。
- **終端制約相**: 成立可能な未来条件を統一評価基準として置く。
- **意味整流相**: ノード意味・接続を再評価する。
- **時間整流相**: 配分・順序を再設計する。
- **未来負債可視化相**: 将来へ押し出された制約を特定する。
- **行動整流相**: 継続・停止・前倒し・追加を再配置する。
- **構造整流相**: 制度・権限・役割・情報流を改修する。
- **逆向き実装相**: 未来条件から現在工程へ戻す部分を実装する。
- **境界再検証相**: 四層統合の独自説明力と隣接概念との差を再評価する。

## Applications
1. **理論比較**: 未来起点の方法をすべて同一視せず、各理論が何を操作対象にするかを比較する。
2. **単純な計画逆算の判定**: 期限・タスクだけを未来から逆算した場合はバックキャスティングとして説明可能かを先に確認する。
3. **意味変更の判定**: 過去・現在ノードの意味だけが変わる場合、意味収束理論の範囲で十分かを検討する。
4. **四層統合**: 意味変更が時間配分、行動順序、制度・権限変更まで連動する場合に逆因果整流の統合範囲を検討する。
5. **未来負債監査**: 残タスクではなく、現在の局所最適が将来成立条件へ押し出す制約を特定する。
6. **量子比喩の監査**: 説明上の比喩を未来情報送信・時間逆行・物理的逆因果の証明へ転用していないか確認する。
7. **理論の縮小判定**: 既存概念だけで十分説明できるケースを無理に独自理論へ回収しない。

- 共通部分と差分を同時に示せるか。
- 成立可能な未来定義が終端制約として実際に評価基準になっているか。
- 意味・時間・行動・構造の変更点を別々に追跡できるか。
- 未来負債を単なる未完了タスクと区別できるか。
- バックキャスティングだけで十分説明できるケースを過剰包含していないか。
- 四層統合が実装上の追加差を生んでいるか。
- 量子論比喩を物理証明として使っていないか。
- 未来情報送信、時間逆行、確定未来など原典外の主張を追加していないか。
- 固有説明力がなければ理論範囲を縮小できるか。

## Validity conditions
意味収束理論、時間OS、未来負債論、バックキャスティングとの接点を保持しながら、各概念の主対象を分離できること。逆因果整流理論では、成立可能な未来定義が終端制約となり、意味・時間・行動・構造の複数層へ一貫した再配置を生むこと。その四層統合が既存概念単独では不足する説明・実装差を持ち、量子論等の物理主張へ依存せず反証可能である場合に成立する。

## Failure conditions
意味収束理論と同義にする、時間OSだけへ縮める、未来負債を残タスクと同一視する、バックキャスティングの別名にする、四層のうち一層だけの変更を無条件に逆因果整流と呼ぶ、量子論を物理的証明として使う、未来からの情報送信や時間逆行を追加する場合は失敗する。差異を示すために隣接理論との実際の接点まで否定することも失敗である。

## Falsification conditions
終端制約という操作と四層統合が、既存の意味収束・時間設計・未来負債・バックキャスティングの組合せ以上の固有説明力を継続的に持たない場合、独自理論としての範囲を縮小する。四層整流を行っても実装結果に差がない、または隣接概念だけで同じ予測・判断・再配置を十分説明できる場合も改訂する。量子論比喩を除いても理論構造が成立することが境界であり、物理比喩が不可欠なら理論の位置づけを再検討する。

## Interpretation constraints
「似ているから同じ」「違うから無関係」のどちらにも寄せない。量子論、時間逆行、未来情報送信を理論の物理根拠として扱わない。原典にない物理法則、実現確率、時間モデルを追加しない。バックキャスティングと重なる逆向き設計部分を認めつつ、四層統合の有無を確認する。既存概念だけで十分説明できる場合は、逆因果整流理論の固有範囲を無理に広げない。
