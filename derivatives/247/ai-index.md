## Summary
本論は、単なる無知ではなく「理解していないのに理解したと思うこと」を問題にする。粗い理解がそのまま設計や判断へ使われると、必要な成立条件が抜け落ち、その不足を現場の追加労働、例外対応、属人的判断などが補うことになる。

その結果、表面上は一時的に動いているように見えても、実際には設計の欠落が現場負荷によって隠されている場合がある。さらに、その結果だけを見て「設計は正しかった」と学習すると、同じ粗い理解が再利用され、悪因果が繰り返される。

## Concepts
- 粗い理解: 一部の情報や成功例だけで全体を理解したように感じる状態。
- 理解誤認: 成立条件を十分に把握していないのに、理解したと認識すること。
- 設計図の欠損: 必要条件、例外、責任、依存関係などが設計へ入っていない状態。
- 補填負荷: 設計で欠けた条件を、現場の追加労働や属人的対応で補うこと。
- 責任外部化: 構造上の欠落が個人の能力不足や努力不足として扱われること。
- 悪因果: 誤った理解が設計欠落を生み、現場負荷と責任移転を経て、同じ誤った理解が再生産される循環。

## Causal chain
一部の情報や成功例 → 粗い理解 → 理解したという認識 → 成立条件の確認不足 → 設計から条件が抜ける → 現場で不足が生じる → 属人的対応や追加負荷で補う → 一時的に結果が出る → 設計欠落が見えにくくなる → 責任が個人へ移る → 同じ粗い理解が再利用される。

## State model
情報接触 / 粗い理解形成 / 理解誤認 / 条件不可視化 / 設計図欠損 / 現実不整合 / 現場補填 / 責任外部化 / 誤学習 / 悪因果再生産。

## Applications
制度設計、業務運用、組織改善、AI導入などで、「一度動いた」「説明できた」という事実と、再現可能な成立条件が設計されていることを区別するために使える。

## Measurements and audit
確認点は、どの成立条件が見落とされたのか、その欠落を誰が現場で補っているのか、表面上の成功が過剰労働や属人対応に支えられていないか、失敗の責任が個人へ移されていないかである。さらに、結果が出たことだけを根拠に同じ粗い理解が再利用されていないかを見る。

## Validity conditions
粗い理解が設計や判断へ使われ、必要条件が落ち、その不足を現実側の追加負荷が補う構造が確認できる範囲で、本論の説明は成立する。

## Failure conditions
「理解が浅い個人が悪い」という個人批判へ縮めること、すべての失敗を理解不足だけで説明すること、一度動いたことを再現可能な成立と同一視すること、現場の努力を設計の完成度と混同することは、本論の趣旨とは異なる。

## Falsification conditions
理解誤認や設計欠落と、現場負荷、責任移転、再発との関係が確認できない場合や、別の因果が継続的により強く説明する場合は、この読みの適用範囲を見直す必要がある。

## Required distinctions
無知 / 理解誤認；一度の成功 / 再現可能な成立；現場の努力 / 設計の完成度；個人ミス / 構造的条件欠落；結果が出ること / 因果を理解していること。

## Interpretation constraints
本論を「理解不足の人を責める理論」とする理解では、個人の能力ではなく設計へ入った条件欠落を扱う中心論点が失われる。中心にあるのは、理解誤認が設計へ入り、設計欠落が現実の負荷や責任移転を生むという構造である。また、すべての不具合をこの因果だけで説明する見方も、本論の範囲を超える。
