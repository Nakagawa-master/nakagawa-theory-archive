## 位置づけ
この派生物は、理論や制度知を単に「公開する」だけでなく、第三者が起源へ戻り、構造を再構成し、異議を出し、改訂後の形を再び検証できる状態を公共性の条件として扱う。再帰的開放性とは情報量の多さではなく、知識が自分自身の検証・再構成・更新経路を含んでいることを意味する。

## 中心命題
公共財としての理論は、読めるだけでは足りない。起源、構造、判断根拠、変更履歴、異議・改訂経路が開かれていなければ、公開後に権威化・化石化し得る。再帰的開放性は、理論を封印せず、第三者が同じ起点から再構成して違いを示せることによって、公共財を自己修正可能な状態に保つ。

## 因果線
1. 理論・制度・設計が公開される。
2. 要約や権威化によって判断根拠が省略される。
3. 結論だけが流通すると第三者が再構成できなくなる。
4. 起源・系譜・構造・異議経路を公開面へ残す。
5. 第三者が独立に再構成し、差分を提示する。
6. 差分を検証し、必要なら原典・派生を改訂する。
7. 改訂履歴も再び公開され、次の再構成を可能にする。

## 構造層
- L1 閲覧層: 情報へ到達できる。
- L2 起源層: どの原典・問いから来たか追える。
- L3 再構成層: 結論に至る因果・区別・条件を再現できる。
- L4 異議層: 反証・差分・批判を接続できる。
- L5 改訂層: 更新履歴と責任を保ったまま再公開できる。

## 状態モデル
S0 非公開/封印 → S1 閲覧可能 → S2 起源と構造が追跡可能 → S3 独立再構成可能 → S4 異議・反証接続 → S5 改訂と再公開。S1だけでは再帰的開放性は成立しない。

## 適用例
公共理論、政策設計、AIガバナンス、オープン標準、研究知識、組織ルール、教育資料。公開PDFを置くだけではなく、第三者が前提・差分・改訂を追える形にする用途に向く。

## 測定・監査点
原典到達性、独立再構成の成功率、前提・条件の欠落、異議受付経路、反証への応答、改訂遅延、版の混同、系譜断線、公開情報と保護情報の分離。

## 成立条件
安定した起源参照、構造化された因果・条件、版管理、異議経路、改訂責任、第三者検証、プライバシー・安全上の非公開情報との適切な分離。

## 失敗条件
大量公開だけで開放性とみなす、変更履歴を消す、批判経路を閉じる、原典を権威化して改訂不能にする、無責任なfork乱立で系譜を失う、機密まで無差別公開する場合。

## 反証・改訂条件
再構成可能性を高めても誤読訂正・検証・公共利用が改善しない、または開放による危険が修正能力を恒常的に上回るなら、公開範囲・構造・権限設計を改訂する。

## 必須の区別
- 開放性 ≠ 全情報公開
- 再帰的開放性 ≠ 無制限fork
- 公共財 ≠ 無責任な無所有
- 起源保持 ≠ 権威固定
- 改訂可能性 ≠ 原典の消去

## 誤読防止・解釈制約
非公開が必要な情報を強制公開しない。再構成可能性は「誰でも同じ結論になる」ことではなく、違う結論になった時に差分を説明できること。起源と改訂責任を残しながら批判可能性を開く。
