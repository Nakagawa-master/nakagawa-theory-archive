## 位置づけ
第2論は、逆因果整流理論を隣接概念へ溶かさないための差分固定論である。意味収束理論、時間OS、未来負債論、バックキャスティングと接点を持ちながら、それぞれが扱う主対象と、逆因果整流理論が統合する範囲を区別する。また量子論は比喩的連想として参照され得ても、本理論の物理的証明として使用しない。中心は、**成立可能な未来定義を終端制約とし、意味・時間・行動・構造の複数層で不整合を検出し再整列する統合プロセス**である。

## 中心命題
意味収束理論は、未来定義によって過去・現在ノードの意味ベクトルが再配列される構造に焦点を置く。時間OSは、時間認識・配分・順序の設計を扱う。未来負債論は、現在の局所最適が将来へ押し出す制約・コストを扱う。バックキャスティングは、望ましい未来から計画を現在へ戻す方法である。逆因果整流理論はこれらと重なるが、固有点は、未来定義を単なる目標ではなく**終端制約**として置き、意味・時間・行動・構造の不整合を同一プロセス内で検出・整流する点にある。

## 因果線
```text
成立可能な未来定義
→ 終端制約として必要条件を固定
→ 現在との不整合を複数層で検出
→ 意味収束理論の観点でノード役割を再評価
→ 時間OSの観点で時間配分・順序を再設計
→ 未来負債として将来へ押し出した制約を可視化
→ 行動を継続・停止・前倒し・追加
→ 必要なら制度・権限・役割・情報流を改修
→ バックキャスティングを含む逆向き実装
→ 実装結果を終端制約と再照合
→ 反証に応じ未来定義・整流内容を改訂
```

## 構造層
1. **未来定義・終端制約層**: 未来を目標以上の評価条件として置く。
2. **意味収束接続層**: ノードの役割・意味ベクトルを再配列する。
3. **時間OS接続層**: 時間認識、配分、順序を再設計する。
4. **未来負債層**: 先送りされた制約・コスト・未整合を可視化する。
5. **行動整流層**: 現在の行動順序・停止・前倒しを変更する。
6. **構造整流層**: 制度・権限・役割・情報流を改修する。
7. **バックキャスティング接続層**: 未来から実装順序を戻す。
8. **四層統合層**: 意味・時間・行動・構造を一つの整流プロセスとして扱う。
9. **境界層**: 量子論比喩を物理的根拠へ転用しない。

## 状態モデル
類似概念混在相 → 差分抽出相 → 未来定義相 → 終端制約固定相 → 各理論役割分離相 → 四層不整合検出相 → 統合整流相 → 実装相 → 再検証相 → 境界維持・改訂相。

## 適用例
未来からタスクを逆算しただけなら、それはバックキャスティングとして説明でき、直ちに逆因果整流とは呼ばない。未来定義を置いたことで、過去・現在資源の意味が変わり、時間配分が変わり、具体行動が変わり、さらに制度・権限配置まで変わるなら、四層整流の射程に入る。未来負債も「残タスク」ではなく、現在の局所最適が未来成立条件へ押し出している制約として扱う。

## 測定・監査点
- 未来定義が終端制約として働いているか。
- 意味・時間・行動・構造を区別しているか。
- 意味収束理論だけで説明できる範囲と、追加の四層整流を分けているか。
- 時間OSを単なるスケジュール管理にしていないか。
- 未来負債を未完了タスクと混同していないか。
- バックキャスティングだけを理論全体と呼んでいないか。
- 量子論を物理証明として使っていないか。
- 四層統合に独立した説明力があるか。

## 成立条件
隣接概念との境界を維持しつつ、未来定義→終端制約→複数層不整合検出→意味・時間・行動・構造の再整列→実装→再検証という一貫した因果線が成立する場合に有効である。

## 失敗条件
意味収束理論と同義にする、時間OSだけへ縮小する、未来負債を単なる未完了タスクにする、バックキャスティングの別名にする、量子論を物理証明に使う、四層のうち一層しか変わらないのに統合理論として扱う場合は失敗する。

## 反証・改訂条件
四層統合が独立した説明力を持たず、意味収束理論やバックキャスティング等の既存概念だけで十分説明できる場合、または終端制約という操作が実装結果に固有の差を生まない場合は、独自概念としての範囲を改訂する。

## 必須の区別
意味収束 / 四層整流；時間OS / 終端制約；未来負債 / 未完了タスク；バックキャスティング / 逆因果整流；量子比喩 / 物理証拠；類似性 / 同一性。

## 誤読防止／解釈制約
「量子だから未来が過去を変える」という説明をしない。隣接理論との共通部分を認めつつ差分を消さない。原典にない物理主張、実現確率、時間逆行を追加しない。
