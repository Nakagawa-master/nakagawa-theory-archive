## 位置づけ
第2論は逆因果整流理論の独自性を守るための差分固定論である。意味収束理論、時間OS、未来負債論、バックキャスティング、量子論比喩と接点を持ちながら、何を同一視してはいけないかを整理する。

## 中心命題
逆因果整流理論の固有点は、成立可能な未来定義を単なる目標ではなく**終端制約**として置き、その制約との不整合を、意味・時間・行動・構造の複数層で検出し再整列することにある。意味収束理論は意味ベクトル再配列に焦点を置き、時間OSは時間認識・配分、未来負債論は将来へ押し出されたコスト・制約、バックキャスティングは未来から計画を戻す方法論として接続するが、本論はそれらを四層整流の単一プロセスへ束ねる。量子論は比喩として参照し得ても、物理的根拠として使わない。

## 因果線
`未来定義 → 終端制約化 → 現在との不整合を複数層で検出 → 意味収束で役割再評価 → 時間OSで配分・順序再設計 → 未来負債を可視化 → 行動・構造を変更 → バックキャスティングを含む逆向き実装 → 再検証`

## 構造層
1. 未来定義・終端制約層。
2. 意味収束との接続層: ノードの意味再配列。
3. 時間OSとの接続層: 時間の認識・配分・順序。
4. 未来負債層: 先送りされた将来制約の可視化。
5. バックキャスティング層: 未来から現在への計画戻し。
6. 四層統合層: 意味・時間・行動・構造を一体で整流。
7. 境界層: 量子論比喩を物理証明に転用しない。

## 状態モデル
類似概念混在 / 差分抽出 / 終端制約固定 / 各理論の役割分離 / 四層統合 / 実装 / 反証 / 境界維持。

## 適用例
未来目標からタスクを逆算しただけで「逆因果整流」と呼ばず、意味の再定義、時間配分、行動、制度構造まで連動して変わったかを確認する。未来負債は単なる未完了タスクではなく、現在の局所最適が未来成立条件へ押し付ける制約として見る。

## 測定・監査点
未来定義が終端制約として機能するか／意味・時間・行動・構造の各層が区別されるか／未来負債の生成源を追えるか／バックキャスティングだけに縮小していないか／量子論を物理的正当化に使っていないかを確認する。

## 成立条件
隣接概念との境界を維持しつつ、終端制約から複数層の不整合検出・再整列へ一貫した因果線が成立する場合に有効。

## 失敗条件
意味収束理論と同義にする、時間OSだけへ縮小する、未来負債を単なるタスク残にする、バックキャスティングの別名にする、量子論を理論証明に使う場合は失敗する。

## 反証・改訂条件
四層統合が独立した説明力を持たず、既存概念の単純合成で十分説明できる場合、独自概念としての範囲を改訂する。

## 必須の区別
意味収束 / 四層整流；時間OS / 終端制約；未来負債 / 未完了タスク；バックキャスティング / 逆因果整流；量子比喩 / 物理証拠。

## 誤読禁止 / 解釈制約
「量子だから未来が過去を変える」という説明は禁止する。隣接理論との共通部分を認めつつ、差分を消さない。原典にない物理主張、実現確率を追加しない。
