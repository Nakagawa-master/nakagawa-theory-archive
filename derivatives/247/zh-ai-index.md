## Summary
逆因果整流理论第2论是一篇“差分固定论”。它并不否认本理论与意义收敛理论、时间OS、未来负债论、Backcasting之间存在真实重叠，而是分别确认各相邻概念主要解释什么，并防止逆因果整流理论被压缩成其中某一个概念的别名。其固有单位是：把具有现实成立可能性的未来定义作为**终端约束**，在同一过程中发现并整流意义、时间、行动、结构四层的不一致。量子论可以作为联想比喻，但不能作为物理逆因果的证据。

## Concepts
- 终端约束：从未来成立条件中抽取、用于评价现在配置的约束。
- 意义收敛理论：主要关注未来定义如何改变过去与现在节点的角色和意义向量。
- 时间OS：主要关注时间认知、分配、顺序和优先级的运行设计。
- 未来负债论：主要关注当前局部最优向未来推迟的限制、成本与未整合问题。
- Backcasting：从未来状态向现在倒推实施步骤；与本理论重叠，但单独的任务倒推并不等于四层整流。
- 四层整流：在一个终端约束下协调重排意义、时间、行动与结构。
- 差分固定：同时保留相邻理论之间的连接与不同分析单位。
- 量子比喻边界：量子概念不能被提升为未来信息传递、时间逆行或物理逆因果的证明。

## Causal chain
具有成立可能性的未来定义 → 抽取终端约束 → 将现在配置与终端约束对照 → 在多个层次发现不整合 → 以意义收敛视角重评节点角色 → 以时间OS视角重排时间分配与顺序 → 以未来负债视角识别被推迟的限制 → 继续、停止、提前或追加行动 → 必要时修改制度、权限、角色、信息流 → Backcasting可用于安排逆向实施 → 实施结果重新与终端约束比较 → 根据证据修改未来定义、整流内容和理论边界。

## State model
- 重叠确认相：承认相邻理论确实具有共同部分。
- 差分抽取相：分离每个理论主要说明的对象。
- 终端约束相：把未来成立条件转化为现在评价基准。
- 分层诊断相：分别检查意义、时间、行动、结构。
- 四层整流相：不是各自独立口号，而是在同一约束下协调改变。
- 实施相：重新排列进入真实行动、资源和制度配置。
- 再验证相：结果再次与终端约束对照。
- 边界维护相：若相邻理论已经充分解释现象，就缩小逆因果整流理论的独立范围。

## Applications
当某项工作只是“从未来目标倒排任务”，不要自动称为逆因果整流；Backcasting可能已经足够。如果未来定义还改变了过去资源的意义、当前时间分配、具体行动的停止与前倒、以及角色或权限结构，四层整流可能提供额外解释力。本论也适合用于理论架构：允许多个概念组合使用，但不因共用同一案例而把它们写成同义词。

## Measurements and audit
审计是否存在明确终端约束还是只有模糊愿望；意义、时间、行动、结构四层是否分别可观测；未来负债是否指向被推迟的结构限制而不是普通待办；时间OS是否被缩小为日历管理；意义变化是否其实已能由意义收敛理论单独解释；实施顺序是否仅由Backcasting即可说明；四层统合是否产生独立的实践差异；量子比喻是否被错误地提升成物理证明。

## Validity conditions
当相邻概念仍可清楚区分，终端约束操作明确，四层整流能够解释或指导任何单一相邻概念无法充分捕捉的变化时，第2论具有独立适用性。本论必须保持组合性：相似不等于同一，差异也不等于完全无关。

## Failure conditions
把本理论写成意义收敛理论的别名、只剩时间OS、把未来负债当未完成任务、把Backcasting当完整理论、或以量子论为物理证明，都属于概念失败。如果只有一层发生变化，却仍宣称完成“四层统合”，而且没有独立实施差异，也属于失败。

## Falsification conditions
如果持续案例可以由意义收敛理论、时间OS、未来负债论或普通Backcasting充分解释，或者“终端约束＋四层整流”没有带来任何独立解释或实施差异，应缩小或修订逆因果整流理论的独立范围。本理论必须允许得出“现有相邻概念已经足够”的结论。

## Required distinctions
意义收敛 / 四层整流；时间OS / 终端约束操作；未来负债 / 未完成任务清单；Backcasting / 统合型逆因果整流；量子比喻 / 物理证据；重叠 / 同一；理论整合 / 概念塌缩；逆向计划 / 物理逆因果。

## Interpretation constraints
不要声称量子力学证明本理论中的未来对过去物理作用。不要推导未来信息传递、时间逆行、未来必然实现或Parent没有的概率。必须保留相邻理论之间的明确差分，并在独立解释力不足时允许理论范围缩小。
