## Summary
把粗略理解误判为“已经理解”，会使尚未掌握的成立条件从设计图中消失。缺失的条件、因果、例外和责任边界，会在实装后以不整合、失败、摩擦、损失和责任外部化的形式出现，并形成恶因果。

## Concepts
理解误认；粗略理解；必要粒度；成立条件；设计图缺失；条件遗漏；现实不整合；恶因果；责任外部化；更新循环。

## Causal chain
概要认知 → 理解感 → 误判为已理解 → 条件不可见 → 设计图缺损 → 粗糙实装 → 现实不整合 → 失败/摩擦/损失 → 原因外部化 → 恶因果再生产。

## State model
概要 / 理解误认 / 条件缺失 / 设计图缺失 / 粗实装 / 不整合 / 恶因果 / 外部化 / 修正或继承。

## Applications
用于AI导入、制度、业务、合同和安全系统，检查“过早认为已经理解”删掉了哪些成立条件。

## Measurements and audit
已理解判定依据；条件覆盖；必要粒度；因果图；例外；责任边界；不确定性；失败归因；修正循环。

## Validity conditions
能够追踪“理解粒度不足→条件遗漏→设计缺损→现实不整合”，且恢复条件后设计与验证能力改善。

## Failure conditions
把所有失败归因于个人能力，或反过来把所有失败只归因于理解不足。

## Falsification conditions
若粗略理解也能持续稳定实装而不发生条件缺失型失败，或失败与理解粒度无关，应缩小范围。

## Required distinctions
无知 / 理解误认；概要 / 必要粒度；说明 / 设计图；条件遗漏 / 实装不整合；单次事故 / 恶因果。

## Interpretation constraints
不是要求所有人都成为专家。目标是保留不确定性并使必要条件可验证，避免单一原因论。
