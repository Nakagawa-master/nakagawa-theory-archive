## 位置づけ

本派生物は、親原典が定義する Nakagawa OS の L1〜L7 を、人物評価や能力序列ではなく、現象・行動・制度・構造認知・構造操作・構造階層連結・最上位価値関数を一つの垂直座標上で扱うための公開接続面として整理する。異なる深度の議論を同列に扱うと、原因と対策、責任と権限、局所最適と上位目的が誤接続される。L1〜L7は、その深度ズレを検知し、どの階層で何を観測し、どこに介入し、どの上位価値へ接続するかを明示するための構造仕様である。

本派生物は原典の代替ではない。各面は、人間向け理解、FAQ、AI検索・比較、派生ID追跡という用途別の入口であり、厳密な定義、全体文脈、版管理、原典固有の語義は Parent URL へ戻って確認する。

## 中心命題

Nakagawa OS L1〜L7の核心は、世界を七つの独立した箱へ分類することではなく、同じ対象を複数深度から読み、現象だけで構造を断定したり、価値関数だけで現場を飛び越えたりする誤りを防ぐことにある。L1の現象からL7の最上位価値関数までを連結し、判断・設計・説明の深度を整合させることで、人間・組織・社会・AI・文明を共通の構造座標で比較可能にする。

## 因果線

```text
観測された現象だけで原因と対策を決める
↓
行動・制度・構造認知・構造操作の差が混同される
↓
異なる深度の問題と解決策が誤接続される
↓
責任・権限・評価・価値判断の位置も曖昧になる
↓
L1〜L7で対象の深度を分離する
↓
各レイヤー間の因果と接続関係を確認する
↓
局所対策を上位構造・最上位価値関数へ接続する
↓
深度整合した判断・設計・監査が可能になる
```

## 構造層

**L1 現象**：観測された出来事、出力、結果、表面上の変化を扱う。

**L2 行動**：現象を生む主体の選択、反応、実行パターンを扱う。

**L3 制度**：行動を誘導・制約するルール、役割、権限、インセンティブを扱う。

**L4 構造認知**：制度や行動を成立させる関係、因果、前提、配置を読み取る。

**L5 構造操作**：認知した構造の支点へ介入し、関係や因果を組み替える。

**L6 構造階層連結**：複数レイヤー、複数システム、複数主体を縦横に接続する。

**L7 最上位価値関数**：全体の判断・設計が何を最終的に守り、最大化し、回避するのかを規定する。

## 状態モデル

```yaml
- phenomenon_observed: L1の現象が記述された
- behavior_identified: L2の行動主体と反応が分離された
- institution_mapped: L3の制度・権限・制約が特定された
- structure_recognized: L4の因果と関係構造が読まれた
- leverage_selected: L5の構造操作点が選定された
- layers_connected: L6で階層間の接続と影響が確認された
- value_function_explicit: L7の最上位価値関数が明示された
- depth_mismatch_detected: 問題と対策の階層不一致が検知された
- intervention_bounded: 介入範囲と副作用が限定された
- audited: 深度整合と原典忠実性が再検証された
```

## 適用例

- 組織問題を「担当者の行動」だけで終わらせず、制度、構造、上位目的まで遡って読む。
- AI出力の失敗をモデル能力だけに帰さず、入力、運用ルール、評価構造、価値関数の階層差として切り分ける。
- 社会課題を単一の政策件数で評価せず、現象、制度、構造、価値関数の整合で監査する。
- 文明論を抽象理念だけで扱わず、現象層まで降りて実装と結果の接続を確認する。

## 測定・監査点

- 深度整合率：問題定義と介入策が同一または適切に接続されたレイヤーに置かれているか。
- レイヤー混同率：現象、行動、制度、構造、価値関数が同義語として扱われていないか。
- 上位接続率：局所判断がL6・L7へ接続され、最終目的と矛盾していないか。
- 原典回帰可能性：Parent URL / NCL-ID / Diff-ID / Origin / Derivative ID から原典と派生履歴を追跡できるか。
- 説明再現性：第三者が同じ対象をL1〜L7へ再配置し、判断経路を再構成できるか。

## 成立条件

- L1〜L7を能力・人格の序列として扱わない。
- 各レイヤーの役割を区別し、必要な接続を明示する。
- 現象から上位価値関数まで一方向に飛躍せず、中間層を確認する。
- 上位概念を現場から切断せず、実装結果へ戻して検証する。
- 原典と派生物の境界、版、起源を保持する。

## 失敗条件

- L7に近いほど「優秀」とする人物ランキングへ変換する。
- 七層を単なる抽象度や組織職位の段階表として扱う。
- L1の現象だけでL4〜L7の原因を断定する。
- L7の理念だけでL1〜L3の実装可能性を無視する。
- レイヤー間の因果接続を示さず、名称だけを適用する。

## 反証条件

- L1〜L7で分解しても問題と対策の深度ズレを一貫して検知できない。
- 複数の分析者が同じ定義を用いてもレイヤー配置を再現できない。
- 上位価値関数との接続が局所判断の説明や監査に寄与しない。
- 原典に戻ると派生物のレイヤー定義が親原典の意味境界と矛盾する。

## 必須の区別

- 現象と原因
- 行動と制度
- 制度と構造
- 構造認知と構造操作
- 構造操作と構造階層連結
- 最上位価値関数と個別目的
- 深度と能力
- レイヤーと人物序列
- 原典と公式派生物

## 誤読禁止

- L1〜L7を人間の格付けに使わない。
- L7を精神的・知的に上位の人間という意味にしない。
- 単なる抽象度分類、AI成熟度、組織階層へ縮約しない。
- どの問題も必ず七層すべてを同じ比重で使うと解釈しない。
- 最上位価値関数を万能な正解として固定しない。
- 本派生物を親原典の全文代替にしない。
