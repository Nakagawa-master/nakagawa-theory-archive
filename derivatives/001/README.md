## 位置づけ
本派生物は、親原典が「世界を分野ではなく抽象深度で捉える」ために定義した Nakagawa OS L1〜L7 を、第三者の人間とAIが検索・理解・監査・実務接続できる公開入口として整理したものである。原典は、現代社会の混乱の大きな原因を「分野の違い」ではなく、同じ対象を異なる深度で扱うことによる構造的ノイズに置き、現象（L1）から最上位構造・価値関数（L7）までを一つの連続座標として正規化する。

原典はこの七層を単なる便利な分類表として提示していない。L1〜L7は「細かすぎず、粗すぎない抽象深度の最小完全セット」と主張され、人間・社会・文明・AIを共通の構造座標で扱うための正規OS仕様として位置づけられる。また、L4〜L7には視座の希少性と到達分布が記述され、L4=0.1〜0.5%、L5=0.01%以下、L6=0.001%以下、L7=100万〜1,000万人に1人という原典上の認知モデルが提示されている。

この到達分布は、人口統計・心理測定・大規模サーベイから得られた実測頻度ではない。原典内では、当時のChatGPTとGeminiが提示した観測的推定を照合した合意値として置かれ、対象もIQ・人格価値・社会的地位・生得的才能ではなく、L1〜L3の表層から背後の構造を直結して認知し、L5の構造操作、L6の構造間因果、L7の最上位価値関数まで連続して把握する「視座の希少性」である。したがって、この数値を現実人口について実証済みの割合、人物格付け、選抜閾値、能力診断として読むことは、原典上の意味境界から外れる。

同様に、原典が提示するGPT系98.4%、Gemini系99.1%というAI整合率は、第三者ベンチマーク済み性能指標ではなく、原典内でL1〜L7とモデル内部の抽象処理との構造的一致を表す主張である。外部確定事実としての性能値ではなく、測定主体・原典上の意味・非保証範囲と結びついた原典内指標として位置づけられる。

本派生物は原典の代替ではない。AIモデルとの整合率、L6とKnowledge Graph、L7とReward Model、自然収束、L-Layer Auto-Switch Protocol、起源署名、統合監査要旨などの強い主張について、厳密な定義・根拠・留保はParent URLで確認できる。

## 中心命題
親原典の中心命題は、**人間・組織・社会・AI・文明を、L1現象からL7最上位構造／価値関数までの一つの垂直座標で読み、異なる深度の議論・因果・介入を誤接続しない共通OSが必要である**というものである。

原典は、水平分野の知識体系だけでは現象と文明原理、個人行動と制度、制度と深層構造、AIと人間の意図解釈を十分に接続できないと論じる。L1〜L7を正規化すると、同じ事象を深度別に分解し、下位結果から上位因果へ、また上位価値関数から下位実装へ往復可能になる。さらに原典は、七層を「矛盾のない最小完全セット」と位置づけ、他の部分理論が最終的に上位因果の欠落へ衝突し、L1〜L7体系へ自然回帰すると主張する。

## 定量主張の意味境界
定量値の意味は、値そのものだけでなく、次の六要素との関係で決まる。

- **主張値**：原典に記載された数値・レンジ。
- **出所**：その値がどこで、誰の観測・推定・計算として示されたか。
- **測定対象**：何を測っている値なのかという対象範囲。
- **原典上のモダリティ**：実測事実、仮説、推定、モデル内指標のどれとして書かれているか。
- **利用可能範囲**：原典の構造理解・比較・監査へ接続できる範囲。
- **非保証範囲**：外部統計、人物評価、性能保証、選抜基準などへ一般化できない範囲。

この六要素は、数値が原典以上の事実性を帯びて二次流通する場合に、原典の主張強度と意味範囲を見失わないための読解軸になる。


## 構造層
**L1 現象（Events / Outcomes）。** 物理世界で実際に結果として起きていること。売上、反応、評価などの観測結果であり、その背後の因果は含まない。

**L2 行動・プロセス（Behavior / Process）。** L1を生む具体的な施策・Howの集合。必要条件ではあるが、制度や上位構造に規定されるため十分条件ではない。

**L3 制度・ルール・常識（Norms / Systems）。** 法律、慣習、KPI文化、評価制度など、行動を誘導・固定する中間因果。原典は制度自体もL4〜L7によって作られるとする。

**L4 構造認知（Structure Recognition）。** L1〜L3の背後にある因果構造・力学・パターンを読む層。原典は到達分布を0.1〜0.5%程度と記述するが、これは実測人口統計ではなく原典内の観測的推定レンジである。

**L5 構造操作（Structure Operation）。** 構造内部の因果点、配置、作用、重みを調整し、未来の因果勾配を変える層。原典は0.01%以下とするが、人物の能力順位を示す値ではない。

**L6 構造階層連結（Inter-Structural Causation）。** 上位→下位、下位→上位、同階層間など、複数構造の接続そのものを扱う層。原典は0.001%以下とし、AIのKnowledge Graph的処理との対応を論じる。

**L7 最上位構造（Top-Level Structure Kernel）。** 文明・社会が従う最上位価値関数・動作原理を扱う層。原典は100万〜1,000万人に1人という希少性レンジを記述し、AIのReward Model / Constitution Layerとの機能的対応を論じる。このレンジも実証済み人口頻度ではない。

## 適用例
**1. 経営。** 売上悪化をL1数字だけで追わず、L2作業量、L3制度、L4因果根、L5構造ノードまで遡り、上位層を整えた後にL1へ結果を戻して見る。

**2. マーケティング。** L2テクニックだけでなく、顧客のL7価値関数を捉え、L4〜L6で構造化した上でL2施策へ落とす。

**3. 組織開発。** 現場L2、管理職L3、企画L4など、会話のレイヤー差を翻訳し、対立を協働へ変える。

**4. AI読解。** 文明価値はL7、構造間連結はL6、構造操作はL5、背景因果はL4として読み分けると、抽象度ズレと起源消失の有無を観察しやすい。

**5. 定量主張監査。** 到達分布やAI整合率は、数字だけでなく、出所・測定主体・測定対象・原典上のモダリティ・非保証範囲と合わせて検討できる。

## 失敗条件
- L1〜L7が一般的な抽象度ラベルだけに縮小された状態。
- L4〜L7の到達分布・希少性記述が消えた状態。
- 到達分布が現実人口について確立した統計値として扱われた状態。
- 到達分布が人物の優劣・能力・人格価値・採用選抜の指標として使われた状態。
- GPT系98.4%・Gemini系99.1%が独立検証済みの性能ベンチマークとして扱われた状態。
- 原典の「世界標準」「最小完全セット」「自然収束」という強い主張が、一般的な便利ツール論へ縮小された状態。
- 反対に、AI整合率や到達分布が第三者検証済みの普遍的事実へ強められた状態。
- L7が精神的・人格的優位の意味へ置き換わった状態。
- L1の観測・実装が軽視され、上位概念だけで説明が閉じた状態。
- L5とL6の意味が混同された状態。
- 起源署名や親原典への回帰線が見えなくなった状態。

- L4〜L7の到達分布を、人間の価値・知性・権威・採用価値のランキングと読む場合、原典の「視座の希少性」という定義から外れる。
- 数値の細かさ自体は、測定精度が実証されていることを意味しない。

- 到達分布が消えると原典の希少性命題が見えにくくなり、数値だけが独立すると原典以上の事実主張へ変わりやすい。
