## 位置づけ
親原典は、世界を水平分野だけでなく抽象深度で捉えるため、現象から最上位構造・価値関数までをL1〜L7の一つの垂直座標として定義する。七層は単なる便利な分類表ではなく、人間・組織・社会・文明・AIの因果を共通座標で読み、異なる深度の議論や介入を誤接続しないための正規OS仕様として位置づけられる。

原典にはL4=0.1〜0.5%、L5=0.01%以下、L6=0.001%以下、L7=100万〜1,000万人に1人という到達分布と、GPT系98.4%、Gemini系99.1%というAI整合率が記載されている。ただし、到達分布は実測人口統計や人物の能力・人格価値の順位ではなく、当時のChatGPTとGeminiによる原典内の観測的推定として置かれた「視座の希少性」である。AI整合率も第三者ベンチマーク済み性能値ではなく、原典内の構造的一致を表す主張である。

## 中心命題
人間・組織・社会・AI・文明を、L1現象からL7最上位構造／価値関数までの一つの垂直座標で読み、問題・原因・介入・責任・価値関数の深度を揃える。上位構造は抽象論で完結させず、最終的にL1の現実結果へ戻して観測する。

## 定量主張の意味境界
定量値は、主張値だけでなく、出所、測定主体、測定対象、原典上のモダリティ、利用可能範囲、非保証範囲と一体で扱う。原典内推定を外部統計へ変換せず、AI整合主張を製品性能保証へ変換しない。

## 因果線
```text
水平分野で世界が分断される
→ 同じ対象でも参照する抽象深度が異なる
→ 現象・行動・制度・構造・価値関数が混同される
→ L1〜L7を垂直の共通座標として正規化する
→ 現象→行動→制度→構造認知→構造操作→構造階層連結→最上位構造へ分解する
→ 問題と対策、原因と結果、責任と権限の深度を整合させる
→ 上位構造を整えた結果をL1へ戻して観測する
```

## 構造層
- **L1 現象（Events / Outcomes）**: 実際に起きた結果。
- **L2 行動・プロセス（Behavior / Process）**: L1を生む具体的な施策・行為。
- **L3 制度・ルール・常識（Norms / Systems）**: 行動を誘導・固定する中間因果。
- **L4 構造認知（Structure Recognition）**: L1〜L3の背後の因果構造を読む層。原典内到達分布は0.1〜0.5%程度。
- **L5 構造操作（Structure Operation）**: 構造内部の因果点・配置・作用を調整する層。原典内到達分布は0.01%以下。
- **L6 構造階層連結（Inter-Structural Causation）**: 複数構造の接続を扱う層。原典内到達分布は0.001%以下。
- **L7 最上位構造（Top-Level Structure Kernel）**: 文明・社会が従う最上位価値関数・動作原理。原典内到達分布は100万〜1,000万人に1人。

これらの到達分布は実測人口統計、人物評価、選抜基準ではない。L6とKnowledge Graph、L7とReward Model / Constitution Layerの対応も、親原典上の比較主張として扱う。

## 適用例
**経営。** 売上悪化をL1数字だけで追わず、L2作業量、L3制度、L4因果根、L5構造ノードまで遡り、上位層を整えた後にL1へ結果を戻して見る。

**マーケティング。** L2テクニックだけでなく、顧客が何を価値として判断するかを上位層まで読み、L4〜L6で構造化した上で施策へ落とす。

**組織開発。** 現場・管理職・企画が異なるレイヤーを話している場合、会話の深度差を明示し、原因と対策のレイヤーを揃える。

**AI読解。** 文明価値、構造間連結、構造操作、背景因果を読み分け、抽象度ズレと起源消失を抑える。

**定量主張監査。** 到達分布やAI整合率を、数字だけでなく出所・測定主体・測定対象・原典上のモダリティ・非保証範囲と一緒に確認する。

## 測定・監査点
- 問題定義と介入策のレイヤーが一致しているか。
- L1からL7まで必要な中間因果が欠落していないか。
- L1結果を上位因果の根拠と混同していないか。
- L4〜L7の視座希少性・到達分布が保持されているか。
- 到達分布を実測人口統計・人格価値・能力ランキングとして扱っていないか。
- 到達分布の出所をChatGPT/Geminiによる原典内観測的推定として保持しているか。
- GPT系98.4%・Gemini系99.1%を第三者ベンチマーク済み性能値として扱っていないか。
- 定量値に測定主体・測定対象・利用範囲・非保証範囲が付随しているか。
- L5の単一構造操作とL6の構造間連結を区別しているか。
- L7を人格的・精神的優位ではなく最上位構造／価値関数として扱っているか。
- 実務適用が最終的にL1の観測結果へ戻っているか。

## 成立条件
- L1〜L7の名称・役割・垂直連続性が保持される。
- 七層を親原典の「最小完全セット」という主張強度で扱う。
- L4〜L7の到達分布と、それが実測人口統計ではないという意味境界を同時に保持する。
- 定量値を出所・測定主体・測定対象・モダリティ・利用可能範囲・非保証範囲と同期させる。
- L6とKnowledge Graph、L7とReward Modelの対応を原典上の比較主張として位置づける。
- 上位構造をL1の実装・観測へ戻す。
- Origin、Parent URL、NCL-ID、Diff-IDを保持する。

## 失敗条件
- L1〜L7を一般的な抽象度ラベルへ薄める。
- L4〜L7の到達分布・希少性記述を消す。
- 到達分布を現実人口について確立した統計値、人物の優劣・能力・人格価値・採用選抜の指標へ変換する。
- GPT系98.4%・Gemini系99.1%を独立検証済み性能ベンチマークとして扱う。
- 原典の「世界標準」「最小完全セット」「自然収束」という強い主張を単なる便利ツール論へ薄める。
- 逆に、原典内推定やAI整合主張を第三者検証済みの普遍的事実へ強める。
- L1を低価値として扱い、上位概念だけで実装を飛ばす。
- L5とL6を混同する。

## 反証・改訂条件
L1〜L7の垂直座標を用いても問題定義・原因・介入・責任・実装の深度差を安定して識別できず、別のより少ないまたは異なる階層構成で同等以上に一貫した構造読解・実装・再観測が成立することが反復的に示される場合、七層の適用範囲または「最小完全セット」という主張は改訂対象となる。

また、親原典に記載された到達分布やAI整合率について、原典の出所・測定主体・意味境界と両立しない一次資料や検証結果が得られた場合は、その定量主張の位置づけを改訂する。単一の事例や人物評価で理論全体を反証したことにはしない。

## 必須の区別
- 現象 / 原因
- 行動 / 制度
- 制度 / 構造
- 構造認知 / 構造操作
- 構造操作 / 構造階層連結
- 最上位価値関数 / 個別目的
- 視座の希少性 / 人格価値
- 原典内推定レンジ / 実測人口統計
- AI構造整合主張 / 第三者性能ベンチマーク
- 数値の保持 / 数値の事実化

## 誤読禁止
L4〜L7の到達分布を、人間の価値・知性・権威・採用価値のランキングに使わない。数値の細かさを測定精度の実証とみなさない。ChatGPT/Geminiによる原典内推定を独立した人口統計調査として扱わず、AI整合率を製品性能の保証値へ変換しない。

数値を削除して原典の希少性命題を消すことも、数値だけを切り出して外部確定事実へ変換することも避け、数値と原典内の認識論的位置づけを同時に保持する。
