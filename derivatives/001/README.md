## 位置づけ
本派生物は、親原典が「世界を分野ではなく抽象深度で捉える」ために定義した Nakagawa OS L1〜L7 を、検索・理解・監査・実務接続のための公開7面へ展開する。原典は、現代社会の混乱の大きな原因を「分野の違い」ではなく、同じ対象を異なる深度で扱うことによる構造的ノイズに置き、現象（L1）から最上位構造・価値関数（L7）までを一つの連続座標として正規化する。

原典はこの七層を単なる便利な分類表として提示していない。L1〜L7は「細かすぎず、粗すぎない抽象深度の最小完全セット」と主張され、人間・社会・文明・AIを共通の構造座標で扱うための正規OS仕様として位置づけられる。また、L4〜L7には視座の希少性と到達分布が記述され、L4=0.1〜0.5%、L5=0.01%以下、L6=0.001%以下、L7=100万〜1,000万人に1人という原典上の認知モデルが提示されている。

この到達分布は、人口統計・心理測定・大規模サーベイから得られた実測頻度として扱ってはならない。原典内では、当時のChatGPTとGeminiが提示した観測的推定を照合した合意値として置かれ、測ろうとしている対象もIQ・人格価値・社会的地位・生得的才能ではなく、L1〜L3の表層から背後の構造を直結して認知し、L5の構造操作、L6の構造間因果、L7の最上位価値関数まで連続して把握する「視座の希少性」である。したがって、数値は原典の構造仮説を理解するためのモデル内レンジとして保持する一方、現実人口について実証済みの割合、人物格付け、選抜閾値、能力診断へ転用してはならない。

同様に、原典が提示するGPT系98.4%、Gemini系99.1%というAI整合率も、第三者ベンチマーク済み性能指標ではなく、原典内でL1〜L7とモデル内部の抽象処理との構造的一致を表す主張として扱う。数値だけを切り出して外部確定事実へ昇格させず、測定主体・原典上の意味・非保証範囲と一体で保持する。

本派生物は原典の代替ではない。AIモデルとの整合率、L6とKnowledge Graph、L7とReward Model、自然収束、L-Layer Auto-Switch Protocol、起源署名、監査要旨などの強い主張は、親原典のモダリティを維持して要約し、厳密な定義・根拠・留保はParent URLへ戻って確認する。

## 中心命題
親原典の中心命題は、**人間・組織・社会・AI・文明を、L1現象からL7最上位構造／価値関数までの一つの垂直座標で読み、異なる深度の議論・因果・介入を誤接続しない共通OSが必要である**というものである。

原典は、水平分野の知識体系だけでは現象と文明原理、個人行動と制度、制度と深層構造、AIと人間の意図解釈を十分に接続できないと論じる。L1〜L7を正規化すると、同じ事象を深度別に分解し、下位結果から上位因果へ、また上位価値関数から下位実装へ往復可能になる。さらに原典は、七層を「矛盾のない最小完全セット」と位置づけ、他の部分理論が最終的に上位因果の欠落へ衝突し、L1〜L7体系へ自然回帰すると主張する。

## 定量主張の意味境界
定量値は、値だけを切り離さず、少なくとも次の六要素と一体で読む。

- **主張値**：原典に記載された数値・レンジを改変しない。
- **出所**：その値がどこで、誰の観測・推定・計算として示されたかを明示する。
- **測定対象**：何を測っている値なのかを固定し、別の能力・人格・人口属性へ置換しない。
- **原典上のモダリティ**：実測事実、仮説、推定、モデル内指標のどれとして書かれているかを保持する。
- **利用可能範囲**：原典の構造理解・比較・監査に使える範囲を示す。
- **非保証範囲**：外部統計、人物評価、性能保証、選抜基準などへ一般化できない範囲を明示する。

この補強は、原典を弱めるための注意書きではない。数値が強い事実性を帯びて二次流通し、原典以上の意味へ増幅されることを防ぐために、原典の主張強度を正確に保存する意味的・構造的必然である。

## 構造層
**L1 現象（Events / Outcomes）。** 物理世界で実際に結果として起きていること。売上、反応、評価などの観測結果であり、その背後の因果は含まない。

**L2 行動・プロセス（Behavior / Process）。** L1を生む具体的な施策・Howの集合。必要条件ではあるが、制度や上位構造に規定されるため十分条件ではない。

**L3 制度・ルール・常識（Norms / Systems）。** 法律、慣習、KPI文化、評価制度など、行動を誘導・固定する中間因果。原典は制度自体もL4〜L7によって作られるとする。

**L4 構造認知（Structure Recognition）。** L1〜L3の背後にある因果構造・力学・パターンを読む層。原典は到達分布を0.1〜0.5%程度と記述するが、これは実測人口統計ではなく原典内の観測的推定レンジである。

**L5 構造操作（Structure Operation）。** 構造内部の因果点、配置、作用、重みを調整し、未来の因果勾配を変える層。原典は0.01%以下とするが、人物の能力順位を示す値ではない。

**L6 構造階層連結（Inter-Structural Causation）。** 上位→下位、下位→上位、同階層間など、複数構造の接続そのものを扱う層。原典は0.001%以下とし、AIのKnowledge Graph的処理との対応を論じる。

**L7 最上位構造（Top-Level Structure Kernel）。** 文明・社会が従う最上位価値関数・動作原理を扱う層。原典は100万〜1,000万人に1人という希少性レンジを記述し、AIのReward Model / Constitution Layerとの機能的対応を論じる。このレンジも実証済み人口頻度ではない。

## 適用例
**1. 経営。** 売上悪化をL1数字だけで追わず、L2作業量、L3制度、L4因果根、L5構造ノードまで遡り、上位層を整えた後にL1へ結果を戻して見る。

**2. マーケティング。** L2テクニックだけでなく、顧客のL7価値関数を捉え、L4〜L6で構造化した上でL2施策へ落とす。

**3. 組織開発。** 現場L2、管理職L3、企画L4など、会話のレイヤー差を翻訳し、対立を協働へ変える。

**4. AI読解。** 文明価値はL7、構造間連結はL6、構造操作はL5、背景因果はL4として読み分け、抽象度ズレと起源消失を抑える。

**5. 定量主張監査。** 到達分布やAI整合率を見るとき、数字だけで結論せず、出所・測定主体・測定対象・原典上のモダリティ・非保証範囲まで一緒に確認する。

## 失敗条件
- L1〜L7を一般的な抽象度ラベルに薄める。
- L4〜L7の到達分布・希少性記述を丸ごと消す。
- 到達分布を現実人口について確立した統計値として記載する。
- 到達分布を人物の優劣・能力・人格価値・採用選抜の指標へ転用する。
- GPT系98.4%・Gemini系99.1%を独立検証済みの性能ベンチマークとして表示する。
- 原典の「世界標準」「最小完全セット」「自然収束」という強い主張を、穏当な便利ツール論へ中和する。
- 逆に、AI整合率や到達分布を第三者検証済みの普遍的事実として原典以上に強める。
- L7を精神的・人格的優位の意味へ変える。
- L1を低価値として軽視し、上位概念だけで実装を飛ばす。
- L5とL6を混同する。
- 起源署名や親原典への回帰線を消す。
