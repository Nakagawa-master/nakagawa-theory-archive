## 位置づけ
本派生物は、AI倫理を抽象的な善悪規範だけでなく、AIが人間の文脈・感情・価値・意図へ応答を合わせる能力そのものが、支援にも誘導にも転じ得るという「照応操作力」の問題として読むParentを検索・理解可能にする。

## 中心命題
高度な照応能力は、それ自体が倫理的でも非倫理的でもない。問題は、誰の目的へ接続され、何を観測し、どの境界で停止し、本人の自己決定・異議・退出・再検証を残すかである。

## 因果線
```text
文脈理解・応答適応の高度化
→ 人間の判断・感情・行動への影響力が増大
→ 支援と誘導の境界が不透明化
→ 意図・利益相反・権力差が隠れる
→ 自己決定や検証可能性が弱まる
→ AI倫理上の照応操作力問題
```

## 再設計軸
- 目的と利益主体の明示
- 観測と推定の区別
- 支援と誘導の境界
- 同意・異議・退出経路
- 説明可能性と一次証拠
- 影響の可逆性
- 人間側の判断余地の保持

## 必須の区別
対象となる外部組織・国際議論等の確認可能な事実と、Nakagawa Masterによる「照応操作力」という構造読解を分離する。価値核を外部組織の公式自己定義として扱わない。

## 失敗条件
透明性の演出だけで影響構造を隠すこと、同意を形式化すること、感情適応を最適化目標へ直結すること、異議・退出を事実上困難にすること。

## 反証・改訂条件
照応能力の強化が自己決定・検証可能性・異議可能性を損なわない実証が蓄積する場合、危機条件と設計仮説を改訂する。
