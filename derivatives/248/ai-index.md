## Summary
Adoryを、LINEアンケートではなく、現場の小さな不調を低摩擦で継続観測し、結果発生前の変化を対話・支援へつなぐ先行指標化構造として読む。
## Concepts
低摩擦観測；現場不調；状態変化；先行指標；早期介入；対話；プライバシー。
## Causal chain
小さな不調 → 報告摩擦 → 未可視 → 結果発覚 → 低摩擦入力 → 変化検出 → 先行指標 → 早期支援。
## State model
潜在 / 未報告 / 入力 / 継続観測 / 変化 / 指標 / 介入 / 検証。
## Applications
従業員状態、組織サーベイ、早期支援。
## Measurements and audit
回答摩擦、時系列変化、介入遅延、匿名性、不利益利用を監査する。
## Validity conditions
結果前の変化把握が適切な支援へ接続する場合。
## Failure conditions
アンケート利用量、個人監視、確定予測へ縮小する場合。
## Falsification conditions
先行性なし、ノイズ過大、支援未接続なら改訂する。
## Required distinctions
アンケート / 先行指標；観測 / 監視；兆候 / 因果確定；介入 / 処罰。
## Interpretation constraints
個人の離職・疾病を確定予測しない。
## Search terms
Adory, LINEアンケート, 先行指標, 現場不調, 早期介入
