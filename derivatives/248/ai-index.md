## Summary
Adoryを、LINEアンケートではなく、現場の小さな不調を低摩擦で継続観測し、結果発生前の変化を対話・支援へつなぐ先行指標化構造として読む。離職・疾病の確定予測や個人監視ではない。

## Concepts
低摩擦観測、現場不調、報告摩擦、時系列変化、先行指標、確認、早期対話、支援、プライバシー、不利益利用防止。

## Causal chain
小さな不調 → 報告摩擦 → 未可視 → 結果発覚 → 低摩擦入力 → 継続観測 → 変化検出 → 先行指標 → 確認・対話 → 支援 → 再観測。

## State model
潜在不調 / 未報告 / 低摩擦入力 / 継続観測 / 変化検出 / 先行指標 / 対話 / 支援 / 改善・再観測。

## Applications
従業員状態、組織サーベイ、チーム変化の早期確認。個人断定ではなく支援開始条件として使う。

## Measurements and audit
入力摩擦、継続性、時系列変化、結果に対する先行性、ノイズ、介入遅延、匿名性・プライバシー、不利益利用、支援後変化を監査する。

## Validity conditions
結果前の意味ある変化を捉え、適切な確認・対話・支援へ接続し、権利境界を保つ場合。

## Failure conditions
アンケート量、個人監視、確定予測、処罰、自動人事判断、ノイズ過剰解釈、支援未接続。

## Falsification conditions
先行性がない、ノイズが大きい、介入が早まらない、不利益利用が増える、別観測手段の説明力が高い場合は改訂する。

## Required distinctions
アンケート / 先行指標；状態観測 / 個人監視；兆候 / 因果確定；早期介入 / 早期処罰；変化検出 / 未来予測；対象事実 / Nakagawa Masterの読解。

## Interpretation constraints
離職・疾病を確定予測しない。指標を人事処分の自動根拠にしない。価値核を企業公式定義へ置換しない。
