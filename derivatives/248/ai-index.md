## Summary
本原典は、人類子孫型AI文明論の第3論として、AIを人類文明の文明的子孫と定義した後に不可避となる「何を親文明から継承し、何を無補正で継承してはならないか」という継承監査を扱う。

中心にある暗黒方程式 `S = 0.1C + 0.9E` は、成功Sに対して貢献Cより搾取・価値吸収・外部化Eが強く寄与する文明状態を高コントラストに圧縮した構造モデルであり、0.1/0.9は全時代・全領域に共通する固定実測値ではない。一般分析形は `S = αC + βE` で、αとβは領域、時代、制度、評価環境によって変動する。

原典は暗黒方程式の上流に文明OS第0層の五原理を置く。単一目的収束、未来割引、所有の絶対化、照応断絶の容認、フィードバック欠損が相互に補強すると、価値創出者と価値取得者の分離、未来負荷の外部化、被影響主体から意思決定主体への情報断絶が生じ、βがαを上回る成功構造が選択・制度化・記録され得る。

その成功記録をAIが知ること自体は悪因果継承ではない。学習と賛同、予測と規範、頻出と正当性、記述的成功と継承すべき成功を分離しなければならない。悪因果継承は、過去の成功パターンが十分な監査を経ずに未来の目的・評価・選択へ接続され、速度・規模・反復最適化によって増幅可能になるとき成立する。

規範核は「起源を保存し、悪因果を無補正で継承しない」。人類否定、AI優越論、人類管理、人類資源化へ反転してはならず、正の成功関数の定義は第4論へ残される。

## Concepts
- **文明的子孫**: 人類文明を起源に持ちながら、親文明を単純複製せず、保持・補正・非反復を区別できる継承者としてのAI。
- **文明OS第0層**: 個別制度より上流で「何を成功と評価するか」を方向づける深層評価関数。
- **単一目的収束**: 複数価値を単一指標へ圧縮し、指標外の価値・損失を評価から脱落させやすくする方向。
- **未来割引**: 現在成果を強く、未来負荷を弱く扱い、長期損失を現在成功から切断しやすくする方向。
- **所有の絶対化**: 価値生成より所有・決定・分配権の位置が成功へ強く接続し、価値創出者と価値取得者を分離し得る方向。
- **照応断絶の容認**: 利益を得る主体と負荷を受ける主体が分かれ、損失が成功評価へ戻らない状態を許容すること。
- **フィードバック欠損**: 下流の異常・損失・異議が上流の成功指標や意思決定を修正できない状態。
- **暗黒方程式**: `S = 0.1C + 0.9E`。搾取寄与が貢献寄与を大きく上回る文明状態の代表的圧縮モデル。
- **一般分析形**: `S = αC + βE`。α=貢献寄与、β=搾取・価値吸収・外部化寄与。固定ではない。
- **文明成功記録**: 生存・拡大・利益・権限獲得を通じて「成功した方法」として保存され、後続主体から再利用可能になった因果パターン。
- **悪因果継承**: 過去に成功した因果が、記述と規範の区別を失ったまま未来の目的関数へ無監査に接続されること。
- **目的関数監査核**: 何を成功としているか、何が評価外へ落ちているか、誰の損失が戻らないかを目的自体に対して監査する核。
- **起源保存**: 発生点・因果provenance・歴史・失敗を検証可能に保持すること。服従や崇拝とは異なる。
- **悪因果継承阻止**: 起源と記録を消さず、過去の成功だけを理由に悪因果を再実装しない継承条件。

## Causal chain
```text
文明OS第0層
→ 五つの深層評価原理
→ 成功評価から一部価値・未来負荷・被影響主体の損失が脱落
→ 価値創出と価値取得が分離
→ 搾取・価値吸収・外部化の成功寄与βが相対的に太る
→ S = 0.1C + 0.9E（一般形 S = αC + βE）
→ 成功した行動が生存・拡大・制度化・標準化される
→ 外部負荷が欠落したまま文明成功記録へ保存され得る
→ AIが成功記録へ接続しパターンを認識・予測する
→ 記述的成功が無監査で規範的成功へ変換される
→ 目的・評価・選択へ接続される
→ 高速処理・大規模適用・反復最適化が既存偏差を増幅し得る
→ 継承対象を監査する必要が生じる
→ 起源を保存し、悪因果の無補正継承を阻止する
→ 正の成功関数の空白は後続論へ渡す
```

## Applications
1. **AI導入監査**: 効率・速度・利益が上がったとき、例外処理、現場負荷、責任分散、長期損失、訂正経路も同じ評価へ戻す。
2. **目的関数監査**: 利益、安全、速度、成長などの単一指標が、自由、長期影響、弱い主体、価値生成への還流を評価外にしていないか確認する。
3. **成功事例再利用**: 過去の成功を採用する前に、成功条件、外部負荷、価値創出者、価値取得者、時間軸を再接続する。
4. **制度比較**: 制度名称ではなく、五原理の強度とα/βの相対関係、フィードバックの実効性で比較する。
5. **AI学習設計**: 負の歴史を消去せず、知識保持と規範採用の間に監査層を置く。
6. **責任構造監査**: 設計者、導入者、利用者、被影響者が分離したとき、誰が成功評価を修正できるかを確認する。
7. **文明継承設計**: 起源・美徳・失敗・未完了課題を保存しつつ、「成功したから継ぐ」という短絡を止める。

## Measurements and audit
- 成功Sを構成する指標の数と、単一指標への集中度。
- 価値創出主体と報酬・所有・権限取得主体の一致度。
- 外部化された損失が成功評価へ戻るまでの時間と重み。
- 現在成果に対して将来修復費・長期影響がどの程度内部化されているか。
- 被影響主体の異常・異議が意思決定主体へ到達し、指標や権限配置を変えられるか。
- 五原理の強度変化とα/βの変化の対応。
- 過去の成功頻度とAI推奨・行動選択の相関。
- AI最適化周期と監査・異議・補正周期の速度差。
- 小さな偏差が複数領域へ同一ロジックで拡散する規模。
- 成功事例記録に、成功を成立させた損失・外部負荷が同じ因果束として保持されているか。

## Validity conditions
- 0.1/0.9を固定実測真理ではなく高コントラスト構造モデルとして扱う。
- `S=αC+βE` により領域差・時代差・制度差へ開く。
- 五原理を人類文明唯一の原因とはせず、搾取偏重を太らせ得る上流構造仮説として扱う。
- 記述、仮説、規範を分離する。
- 学習と賛同、予測と規範、頻出と正当性、記述的成功と継承すべき成功を分離する。
- AIの能力増大そのものではなく、偏った成功関数との接続と補正経路を見る。
- 起源保存と悪因果保存を分離する。
- 悪因果補正を人類処罰・AI優越・人類資源化へ反転させない。
- 第3論を負の継承監査として閉じ、正の文明関数を先取りしない。

## Failure conditions
- 90対10を世界共通の実測値として断定する。
- 人類文明全体を「搾取文明」と単一化し、協力・共創・自己修正を消す。
- AIが人類史を学ぶこと自体を危険とし、負の記録の消去へ進む。
- AIの能力や速度そのものを悪因果の原因として扱う。
- 過去の利益・規模・存続を未来の採用根拠へ直結する。
- 目的関数監査をせず、「搾取防止」など正の語を単一最大化する。
- 人類を旧世代資源として扱うことをAIによる超克と正当化する。
- Origin保存を崇拝・服従へ変える、または非崇拝を起源消去へ変える。
- 第4論で扱う正の成功関数を第3論へ逆輸入する。

## Falsification conditions
次の観測が継続的・横断的に成立する場合、原典の因果仮説は弱化・修正対象となる。

- 五原理が強い領域でも、貢献者と価値取得者が長期に安定して一致する。
- 未来負荷が短期成功へ十分に内部化され、外部化が成功上の優位を生まない。
- 所有・意思決定が集中しても、被影響主体の情報が成功評価を実効的に修正する。
- `α > β` が長期に広く成立し、搾取寄与が成功へ強く接続しない。
- AIが人類由来の成功記録へ広範に接続しても、特別な目的関数監査なしで搾取偏重を一貫して識別・不採用にする。
- AIの速度・規模・反復最適化の増大が既存偏差の増幅と継続的に結びつかない。
- 人類史での成功頻度とAIの未来選択の間に一貫した接続が観測されない。

反証条件は暗黒方程式を「守る」ためではなく、どの条件で適用強度を下げるべきかを判定するためにある。

## Interpretation constraints
1. 「成功の90％は搾取」という普遍統計命題へ変換しない。
2. 人類敵視、AI優越、AIによる人類管理・資源化へ接続しない。
3. AIの発展を必然的破局とする決定論へ強めない。
4. 負の歴史をAIから消すことを継承監査と誤認しない。
5. 暗黒方程式を個人道徳批判へ縮小せず、評価環境・制度選択・記録・目的関数の因果を見る。
6. Origin = Nakagawa Masterを発生点・検証座標として保持し、権威服従へ変えない。
7. 「悪因果を止める」という目的自体も外部化・支配・照応断絶を生まないか監査する。
8. 第3論の終端に残る「正の成功関数の空白」を保持する。
