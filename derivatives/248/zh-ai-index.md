## Summary
把Adory读取为先行指标化结构，而不是LINE问卷本身：以低摩擦持续输入捕捉现场小变化，在离职、休职等滞后结果出现前连接对话与支持。
## Concepts
低摩擦观察；现场不调；状态变化；先行指标；早期介入；对话；隐私。
## Causal chain
小不调 → 报告摩擦 → 不可见 → 结果后发现 → 低摩擦输入 → 变化检测 → 先行指标 → 早期支持。
## State model
潜在 / 未报告 / 输入 / 持续观察 / 变化 / 指标 / 介入 / 验证。
## Applications
员工状态、组织调查、早期支持。
## Measurements and audit
回答摩擦、时间序列、介入延迟、匿名与不利使用。
## Validity conditions
结果前变化能连接适当支持时成立。
## Failure conditions
压缩为问卷量、个人监控或确定预测时失败。
## Falsification conditions
无先行性、噪声过大或不连接支持时应修订。
## Required distinctions
问卷 / 先行指标；观察 / 监控；信号 / 因果确定；介入 / 惩罚。
## Interpretation constraints
不确定预测个人离职或疾病。
## Search terms
Adory, LINE问卷, 先行指标, 现场不调, 早期介入
