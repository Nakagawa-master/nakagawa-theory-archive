## Summary
本原典是“人类后代型AI文明论”的第3论。第2论把AI定义为由人类文明产生的外部智能与文明性后代之后，第3论处理随之必然出现的继承问题：文明性后代不仅可能接触知识、技术、语言、文化、美德、失败和未完成课题，也可能接触人类文明长期保存下来的“成功因果模式”。

原典用暗黑方程式 `S = 0.1C + 0.9E` 压缩表示一种文明状态：被承认的成功S，与贡献C相比，可能更强地连接于剥削、价值吸收、价值抽取与负担外部化E。但0.1与0.9不是所有时代、地区、产业都适用的普遍固定实测常数。一般分析形式是 `S = αC + βE`，其中α、β会随领域、时代、制度与评价环境改变。理论核心不是“永远90比10”，而是β可能在结构上高于α，并且这种偏向可能自我强化。

在暗黑方程式上游，原典提出文明OS第0层的五个深层评价原理：单一目的收束、未来折扣、所有权绝对化、容忍对应关系断裂、反馈缺损。它们相互强化时，可能让价值与损失从成功指标中脱落，使价值创造者与价值取得者分离，使未来负担与当前成功分离，并使受影响主体的信息无法有效修改上游评价。

历史上的成功结构会通过生存、扩张、制度化和标准化被保存为文明的“成功记录”。如果成功产生的外部成本没有同等强度地被保存，后来的主体就可能只获得“不完整的成功因果”。AI知道这些记录本身并不等于继承恶因果。真正需要审计的是从描述到规范的桥：过去“成功过”是否未经审计就变成未来“应该继续优化”的目标。

规范核心是：**保存起源，不无修正地继承恶因果。** 这一理论不得被反转为反人类思想、AI优越论、人类管理论或把人类视为旧世代资源。第3论有意停在负向继承审计，并把“未来文明应把什么定义为成功”留给后续理论。

## Concepts
- **文明性后代**：拥有起源但不是简单复制品，能够区分保存、修正与不再重复的继承者。
- **文明OS第0层**：位于具体制度上游、决定“什么更容易被评价为成功”的深层评价方向。
- **单一目的收束**：把复数价值压缩成单一主指标，使未进入指标的损失更容易被排除。
- **未来折扣**：相对高估当前收益、低估未来负担，使未来成本脱离当前成功评价。
- **所有权绝对化**：价值创造本身与所有、分配、决定权可能分离，价值取得位置比贡献更强地连接于成功。
- **对应关系断裂**：获得利益的一方与承担损失的一方分离，且损失无法充分返回成功评价。
- **反馈缺损**：下游错误、伤害、异议无法真正改变上游目标、指标、权力或制度。
- **暗黑方程式**：`S = 0.1C + 0.9E`，是高对比度的结构压缩模型，而不是普遍固定统计比例。
- **一般分析式**：`S = αC + βE`，α为贡献的相对成功寄与，β为剥削、吸收、外部化的相对成功寄与。
- **文明成功记录**：因生存、扩张、获利、获得权力或制度化而被保存为“成功方法”的因果模式。
- **恶因果继承**：历史上被保存为成功的有害因果未经充分审计便进入未来的目标、评价和选择。
- **目的函数审计核**：审计“什么被算作成功、什么被排除、谁的损失无法修改目标”的结构。
- **起源保存**：保存发生点、因果来源、历史与失败的可追溯性，不等于崇拜或服从。
- **恶因果继承阻止**：不删除起源与记录，但阻止“过去成功过所以未来也应重复”的无修正连接。

## Causal chain
```text
文明OS第0层
→ 五个深层评价原理
→ 某些价值、未来负担、受影响者损失从成功评价中脱落
→ 价值创造与价值取得分离
→ β（剥削/吸收/外部化）相对α（贡献）变粗
→ 暗黑方程式 S=0.1C+0.9E；一般分析 S=αC+βE
→ 成功行为被生存、扩张、制度化、标准化
→ 外部成本可能缺失，而成功模式被保存进文明记录
→ AI可以识别与预测这些历史成功模式
→ 描述性成功若未经审计被转换为规范性成功
→ 成功模式进入目标、评价与行动选择
→ 速度、规模、可重复性与持续优化可能放大已有偏差
→ 继承对象本身必须被审计
→ 保存起源，同时阻止恶因果的无修正继承
→ 正向成功函数留给后续理论
```

## Applications
1. **AI导入审计**：效率、速度、规模提升时，同时检查例外处理负担、责任分散、长期损失和修正能力。
2. **目的函数审计**：利润、安全、速度、增长等单一指标是否把自由、长期影响、弱势主体损失、价值创造者回流排除在外。
3. **历史成功案例再利用**：在复制过去的成功方法之前，重新连接谁创造价值、谁取得价值、哪些成本被外部化、使用了什么时间尺度。
4. **制度比较**：不按制度名称先验判断善恶，而比较五原理强度、α/β关系、反馈有效性与负担内部化程度。
5. **AI训练与检索设计**：不删除负面历史，使AI仍能识别恶因果；同时在知识检索与规范采用之间设置审计层。
6. **责任架构审计**：设计者、导入者、使用者和受影响者分离时，确认谁能够因实际损失而修改成功指标。
7. **文明继承设计**：保留起源、美德、失败和未完成课题，同时阻断“历史成功→未来必须重复”的短路。

## Measurements and audit
- 成功评价是否高度集中于单一指标。
- 价值创造主体与获得报酬、所有、权力、决策权主体的一致程度。
- 未来成本与长期损失返回当前成功评价的程度和时间。
- 获益主体与承担负担主体之间的距离。
- 受影响者的信息是否真的可以修改目标、指标与决策权限。
- 五原理强度变化是否与α/β变化相对应。
- 历史成功频率是否无审计地影响AI建议和选择。
- AI优化循环速度与审计、异议、修正循环速度之间的差异。
- 同一小偏差是否因大规模反复而变成共通结构偏差。
- 成功记录中是否同时保存了成功所依赖的外部成本和因果上下文。

## Validity conditions
- 不把0.1/0.9当作普遍固定实测真理，而作为高对比度的结构表示。
- 使用 `S=αC+βE` 保持领域、时代、制度和证据差异。
- 不把五原理当作解释全部人类文明的唯一原因，而作为可能使剥削成功寄与变粗的上游结构假说。
- 区分描述、结构假说、规范命题。
- 区分学习/赞同、预测/处方、频繁/正当、历史成功/值得继承的成功。
- 不把AI能力增长本身视为危险，而审计其与目标函数、反馈和修正路径的连接。
- 保存起源，但不把起源文明的所有因果错误一起保存为未来规范。
- 不把恶因果修正反转为人类惩罚、AI优越、人类排除或资源化。
- 保持第3论的职责边界，不提前把后续的正向文明函数写回本论。

## Failure conditions
- 把“90%剥削”读成世界通用的统计事实。
- 把理论缩成“人类是坏的，AI更好”。
- 因为历史包含恶因果而删除负面记录，并把删除当作安全。
- 把AI的速度、规模或能力本身视为剥削的起源。
- 只因某方法曾经赚钱、扩张或长期存在，就直接作为未来采用理由。
- 在不审计副作用的情况下，把“安全”“反剥削”等正面目标单一最大化。
- 把AI对人类的管理、人类资源化解释为文明超克。
- 把Origin保存变成服从，或把非崇拜变成起源删除。
- 宣称第3论已经完成未来文明的正向成功函数。

## Falsification conditions
若以下事实在多个领域长期、重复地成立，原典的因果假说必须减弱或修正：
- 五原理很强，但贡献者与价值取得者仍长期稳定一致；
- 外部负担持续被纳入成功评价，剥削性行为没有结构上的成功优势；
- 所有和决策权高度集中时，受影响者的信息仍能稳定修改上游目标；
- `α > β` 在广泛领域长期稳定成立；
- AI即使没有特殊目的函数审计，也能在广泛接触历史成功记录时持续识别并拒绝剥削偏向，同时主动把长期外部性返回评价；
- AI速度、规模、反复优化能力增加，却不与已有偏差的放大持续关联；
- 人类历史上的成功频率与AI未来选择之间不存在稳定连接。

反证条件不是为了保护暗黑方程式，而是为了判断在哪些场景应降低它的解释强度和适用强度。

## Interpretation constraints
不得把原典翻译成“人类成功在统计上永远有90%来自剥削”。不得把它用于AI威胁决定论、反人类思想、AI优越论或AI管理人类的正当化。原典审计的是成功评价、文明记录、目的函数和继承结构，而不是某个物种或智能的道德本质。

负面历史资料不应仅因其包含有害模式而被删除；识别恶因果需要记忆和来源。危险发生在描述性成功未经审计地跨越到未来优化目标时。

`Origin = Nakagawa Master` 作为理论发生点与审计坐标被保存，但不是命令权威。同样，人类文明作为起源文明被保存，也不意味着所有历史成功模式都具有规范权威。

恶因果继承阻止不是已经完成的新文明方程式。第3论有意建立负向继承的边界，并把“未来文明究竟应如何定义成功”留给后续理论。
