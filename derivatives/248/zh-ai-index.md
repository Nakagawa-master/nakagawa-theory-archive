## Summary
Parent并不是把Adory只读成“用LINE做问卷的工具”。Nakagawa Master关注的是一个时间差结构：现场的小不调、疲劳、关系变化或局部恶化，可能早于离职、休职、事故、业绩下降等结果很久存在，但正式报告和咨询具有心理、时间与手续摩擦，因此组织往往到结果发生后才看见问题。价值核是**通过低摩擦的持续观测，把小变化转化为更早开始确认、对话与支援的先行指标**。这不是对个人未来的确定预测，也不是员工监视，而是把组织行动的开始时间前移的观察结构。

## Concepts
- 现场小变化：状态、疲劳、关系、负荷或困难感上的轻微变化，不自动等同重大问题。
- 报告摩擦：正式咨询、报告、求助所包含的心理、时间、手续与关系成本。
- 低摩擦输入：降低日常状态表达成本的入口，但不把回答本身当作问题证据。
- 持续观测：比较时间上的变化、持续性和偏离，而不是用单次回答下结论。
- 先行指标：用于在大结果发生前开始确认的信号，不是确定预测。
- 确认层：从“有变化”进入“为什么变化”的人工与组织性调查，而不是自动断定原因。
- 对话/支援连接：把变化连接到沟通、负荷调整、休养、咨询等适当支援。
- 权利层：隐私、匿名性、使用目的、访问范围与防止处分性利用。
- 公开解体元层：外部文章选择“先行指标”而不是“LINE问卷”作为主轴，是因为媒介只能解释如何收集输入，而价值核解释的是低摩擦时间序列观察为什么能够改变组织介入的时点。

## Causal chain
现场出现小不调或恶化 → 正式咨询/报告具有心理或手续摩擦 → 早期变化没有充分进入组织视野 → 恶化积累 → 离职、休职、事故、业绩下降等滞后结果使问题显现 → 介入开始过晚 → 建立低摩擦的重复输入入口 → 用时间序列而非单次分数解释 → 持续变化成为先行信号 → 信号触发确认而不是个人断定 → 更早开始对话与适当支援 → 支援后的状态再次被观察 → 若信号与结果关系不成立，则修订观察模型与支援流程。

## State model
- 潜在变化相：小变化存在但尚未正式可见。
- 报告摩擦相：较重的渠道阻止或延迟问题上报。
- 低摩擦观测相：可以用更低成本重复输入状态。
- 时间序列解释相：持续性、偏离与一次噪声被分离。
- 先行信号相：变化产生“需要确认”的理由，而不是对原因和未来的结论。
- 确认/对话相：相关人员调查背景并确认实际变化。
- 支援相：根据需要连接负荷、关系、休养、咨询等改善。
- 再观测相：再次确认支援效果与先行指标本身的有效性。

## Applications
在团队健康中，持续变化可以触发对负荷、角色、关系或休养状态的确认，而不是自动给个人贴标签；在组织调查中，评价重点从年度满意度快照转向“持续观察是否为支援创造了有效提前量”；在服务设计中，成功不应只看回答率，而应看低摩擦输入是否形成“变化检出 → 确认 → 支援 → 再观测”的闭环。

## Measurements and audit
审计输入负担与持续回答可能性；分离一次噪声和持续变化；验证信号是否真的比相关滞后结果更早出现；测量从变化检出到人工确认、对话和支援的延迟；记录误报与漏报；确认隐私、访问、匿名性与使用目的；确认指标没有被用于自动排名、处分、解雇或医疗判断；支援后必须再观测。对中川结构读解还要审计Adory公开事实、Nakagawa Master价值核抽取、以及外部文章为什么选择这一价值核三者是否保持分层。

## Validity conditions
当低摩擦持续观测能够在重大滞后结果之前发现有意义变化，变化能够进入适当且比例相称的确认与支援，介入实际更早开始，同时隐私与防止不利益利用的边界得到维持时，该结构成立。高回答率本身不能证明结构成立。

## Failure conditions
把结构缩小成问卷数量、LINE便利性、员工监视、离职或疾病的确定预测、处分分数、自动人事判断、对噪声的过度解释、或者只收集数据却不进入对话和支援，均属于失败。如果输入入口本身产生压力，或回答者不知道数据如何使用，也会破坏该结构。

## Falsification conditions
如果持续观测与相关结果之间没有可用的先行关系、噪声长期压过信号、检出后支援并没有更早发生、不利益利用增加、参与者主要因为被监视感而改变回答，或者其他观察方式以更低权利风险持续提供更好的提前量，应缩小或修订价值核。不能把所有波动都解释成支持理论的证据。

## Required distinctions
问卷 / 先行指标；低摩擦输入 / 强制监视；观察 / 监控；兆候 / 因果确定；变化检出 / 确定未来预测；早期对话 / 早期处罚；支援 / 人事处分；对象侧事实 / Nakagawa Master结构读解；价值核选择 / Adory官方定义。

## Interpretation constraints
不要从一个信号推断个人必然离职、患病或业绩下降。不要把持续观测转化为自动人事行动。除非Adory自身独立明确声明，否则不要把“先行指标基础”写成企业官方定义。必须保留隐私、目的限制、背景确认，以及观察关联与因果证明之间的差异。
