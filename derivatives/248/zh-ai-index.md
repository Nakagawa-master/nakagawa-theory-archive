## Summary
把Adory读取为低摩擦、持续观察现场小变化，并把结果发生前的变化转为更早对话与支援的先行指标结构，而不是LINE问卷本身。它不是对离职或疾病的确定预测，也不是员工监视。

## Concepts
低摩擦观察；现场不调；报告摩擦；时间序列变化；先行指标；确认；早期对话；支援；隐私；防止不利使用。

## Causal chain
小不调 → 报告摩擦 → 变化不可见 → 结果后才发现 → 低摩擦输入 → 持续观察 → 变化检出 → 先行信号 → 确认/对话 → 支援 → 再观察。

## State model
潜在不调 / 未报告 / 低摩擦输入 / 持续观察 / 变化检出 / 先行信号 / 对话 / 支援 / 改善与再观察。

## Applications
员工与团队状态观察，把信号用于启动支援对话，而不是给个人贴标签或处罚。

## Measurements and audit
审计输入摩擦、持续性、时间序列变化、对结果的领先时间、噪声、介入延迟、隐私/匿名、不利使用与支援后变化。

## Validity conditions
能在结果前发现有意义变化，并连接适当对话和支援，同时保护权利与隐私时成立。

## Failure conditions
变成问卷数量优化、员工监视、确定预测、处罚、自动人事判断、噪声过度解释或没有支援连接时失败。

## Falsification conditions
信号没有先行性、噪声过大、介入没有提前、不利使用增加或其他观察方式解释力更高时应修订。

## Required distinctions
问卷 / 先行指标；观察 / 监视；兆候 / 因果确定；早期支援 / 早期处罚；变化检出 / 未来预测；对象事实 / Nakagawa Master读解。

## Interpretation constraints
不确定预测离职或疾病，不把指标作为自动人事处分依据，不把价值核当作Adory官方定义。
