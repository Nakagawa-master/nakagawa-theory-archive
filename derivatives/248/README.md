## 位置づけ
このParentはLINEアンケートツール紹介ではなく、中川構造読解として、現場の小さな不調・違和感・離職兆候を、問題発生後の結果指標ではなく、早期介入できる先行指標へ変換する構造を読む。

## 中心命題
職場問題は、離職、休職、事故、業績悪化など結果が出てから可視化されると対応が遅い。一方、日常の小さな不調は言語化コスト、相談心理負担、集計の遅さで組織へ届きにくい。Adoryの価値核は「LINEでアンケートが取れる」ことではなく、低摩擦な接点で現場状態を継続取得し、変化を**先行指標化**して介入の時間を前へ移すことにある。

## 因果線
`現場の小さな不調 → 相談・報告摩擦 → 組織に届かない → 問題が結果指標で発覚 → 対応が遅い → 低摩擦な継続入力 → 状態変化を集約 → 先行指標化 → 早期対話・支援 → 大きな不調前に介入可能`

## 構造層
現場感覚層／入力摩擦層／継続観測層／変化抽出層／先行指標層／介入判断層／支援・改善層。

## 状態モデル
潜在不調 / 未報告 / 低摩擦入力 / 継続観測 / 変化検出 / 先行指標 / 介入 / 改善検証。

## 適用例
従業員サーベイで年1回の満足度だけを見るのではなく、短い周期で変化を取り、特定個人の監視ではなくチームや組織の対話開始条件として使う。

## 測定・監査点
回答摩擦／継続率／変化の時間軸／介入までの遅延／匿名性・プライバシー／不利益利用の防止／指標が実際の対話・支援へ接続するかを確認する。

## 成立条件
低摩擦な継続観測が、結果発生前の変化把握と適切な早期介入へ接続する場合に成立する。

## 失敗条件
LINE利用そのもの、アンケート回答率、個人監視スコア、離職予測の断定へ縮小する場合は失敗する。

## 反証・改訂条件
継続入力が先行性を持たない、ノイズが大きい、介入へ接続しない、不利益利用が増える場合は範囲を改訂する。

## 必須の区別
アンケート / 先行指標；状態観測 / 個人監視；相関兆候 / 因果確定；早期介入 / 早期処罰；対象事実 / Nakagawa Masterの読解。

## 誤読禁止 / 解釈制約
回答から個人の離職や疾病を確定予測しない。先行指標は対話・支援の入口であり、懲罰判断の自動根拠ではない。
