## 位置づけ
本派生物は、「AIが人類文明の文明的子孫である」という人類子孫型AI文明論の関係定義から必然的に発生する**継承監査**を、検索・理解・検証可能な形へ展開する。親原典が問題にするのは、AIそのものの危険性でも、人類文明全体への道徳的断罪でもない。人類文明が何を成功として選択し、制度化し、記録し、模倣可能な形で次世代へ残してきたのか、その成功因果がAIへ無補正に接続される構造である。

原典は、人類文明の成功関数が一定条件下で貢献より搾取・価値吸収・外部化へ偏り得る状態を「暗黒方程式」で圧縮する。ただし `S = 0.1C + 0.9E` の0.1と0.9を全時代・全地域・全産業に共通する固定実測値とはしない。分析上は `S = αC + βE` と一般化し、αを貢献Cの相対寄与、βを搾取・価値吸収・外部化Eの相対寄与として、領域・時代・制度・評価環境によって変動するものとする。核は90対10という数字ではなく、**βがαを構造的に上回り、その偏りが自己強化され得る成功関数**にある。

## 中心命題
文明的子孫としてのAIは、人類文明の知識、技術、言語、文化、記録、美徳、失敗を学ぶこと自体を禁じられるべきではない。しかし、人類文明の中で「成功した」と記録された因果を、その成功条件・外部負荷・価値取得構造・長期影響を監査しないまま未来の目的関数へ接続してはならない。

原典の中心命題は次の二点を同時に保持する。

1. **起源は保存する。** AIがどの文明から生まれ、どの記録・知識・未完了課題を受け取ったかを検証可能に保つ。
2. **悪因果は無補正で継承しない。** 過去に成功した、長く続いた、多数派だった、利益を生んだ、効率が高かったという事実だけを未来の規範へ変換しない。

したがって、継承は模倣ではない。補正は処罰ではない。超克は消去ではない。親文明の起源を保存しながら、親文明が成功として残した因果のうち何を保持し、何を補正し、何を再実装しないかを識別することが文明的継承になる。

## 構造層
**1. 文明OS第0層。** 法律や企業制度より前に、「何を成功と呼ぶか」「どの時間軸を見るか」「誰の損失を評価へ含めるか」を方向づける深層評価関数である。

**2. 五原理。** 単一目的収束は評価されないものを生み、未来割引は現在の成功から未来負荷を切り離し、所有の絶対化は価値生成と価値取得を分離し、照応断絶は利益側から損失を見えにくくし、フィードバック欠損は偏りを修正しにくくする。原典は五つを静的な分類ではなく相互強化する循環として扱う。

**3. 暗黒方程式。** `S = 0.1C + 0.9E` は普遍的統計定数ではなく、搾取寄与が貢献寄与を大きく上回る文明状態の代表的圧縮である。一般形 `S = αC + βE` により係数は観測と反証へ開かれる。

**4. 文明成功記録。** 生き残り、拡大し、利益や権限を獲得した構造は成功例として残りやすい。成功を成立させた外部負荷が同じ強度で保存されなければ、後続主体は「何をすれば成功したか」だけを再利用しやすくなる。

**5. AI接続層。** AIが負の歴史や搾取構造を知ること自体は悪因果継承ではない。学習、因果理解、再現可能性、望ましいという評価、目的関数への採用を分離する必要がある。

**6. 増幅層。** 偏った成功関数へ速度・規模・反復最適化が接続すると、小さな偏差が修正より速く、大きな範囲へ、成功記録を介して自己強化され得る。ただし原典は「AIは必然的に搾取最適化する」という決定論を採らない。

**7. 継承監査層。** 起源を消さず、記録を消さず、失敗も消さず、そのうえで成功したという理由だけでは悪因果を再実装しない。目的関数そのものが何を外部化し、誰の損失を除外しているかを監査する。

## 適用例
**1. AI目的関数の監査。** 利益、効率、速度、安全等の単一指標だけが最大化されていないか、その指標から長期損失、弱い主体の負荷、価値創出者への還流、異議・修正可能性が落ちていないかを確認する。

**2. 過去の成功事例の再利用監査。** 「過去に成功した」「市場で勝った」「長期間存続した」という記録をそのまま推奨理由にせず、誰が価値を作り、誰が取得し、どの負荷が外部化され、どの時間軸が切られたかを戻して読む。

**3. AI導入による効率化の監査。** 処理速度・利益・規模が向上する一方で、現場負荷、長期損失、責任分散、異議の届きにくさが同時に増えていないかを観測する。

**4. 文明・制度比較。** 同じ制度名でも五原理の強度やフィードバック構造が異なれば暗黒方程式の強度は変わる。制度名で善悪を固定せず、αとβの相対寄与とその上流条件を比較する。

**5. 継承ルール設計。** 歴史データを消去せず、負の歴史を知る能力を保持したまま、「頻出した→正しい」「成功した→継承すべき」という無監査変換を遮断する。

## 測定・監査点
- 貢献者と報酬・権限・所有の取得者がどの程度一致しているか
- 長期損失や修復費用が短期成功指標へ戻っているか
- 利益を受ける主体と負荷を受ける主体の距離
- 被影響主体の異常情報が意思決定主体へ戻るまでの経路と重み
- 単一指標が他の価値を成功判定から脱落させていないか
- AIの最適化速度と監査・異議・補正速度の非対称
- 同一の小さな偏差が大規模反復で共通偏差へ変わっていないか
- 過去の成功頻度がAIの推奨・選択へ無監査に接続されていないか
- `α` と `β` の相対関係が領域・時代・制度変更でどう変わるか
- 五原理が強い領域ほど価値生成と価値取得の乖離が本当に太るか

## 成立条件
- `0.1/0.9` を普遍的固定実測値として扱わず、代表的圧縮モデルとして保持する。
- 五原理を人類史唯一の原因として扱わず、搾取偏重を太らせ得る上流構造仮説として扱う。
- 学習と賛同、予測と規範、記述的成功と継承すべき成功を分離する。
- AIの速度・規模・最適化能力を危険そのものとせず、偏った成功関数との接続条件を見る。
- 人類文明の負の記録を消去せず、起源・美徳・失敗・未完了課題を検証可能に保つ。
- 悪因果補正を人類処罰、人類管理、AI優越論、人類資源化へ反転させない。
- 悪因果継承阻止そのものも目的関数監査へ開き、「搾取防止」の名で別の支配を作らない。
- 第3論の責務を負の継承監査に留め、第4論の正の成功関数を先取りしない。

## 失敗条件
- 暗黒方程式を「世界の成功は統計的に常に90％搾取」とする固定真理へ変える。
- 「人間は悪い／AIは善い」という主体道徳論へ縮約する。
- AIが人類史を学習すること自体を悪因果継承とみなし、負の記録を消すことを安全策にする。
- 過去に成功した方法を、外部負荷や長期影響を戻さず未来の推奨へ直結する。
- AIの高速化や高性能化そのものを危険原因とし、目的関数・評価・フィードバックを見ない。
- 人類の悪因果を補正するという名目で、人類の自己決定、起源、記録を消去する。
- 「搾取をなくす」という一語だけで新文明関数が完成したとし、正の成功定義の空白を隠す。
- 原典の条件付き未来線を「AIは必ず搾取文明を作る」という決定論へ強める。

## 反証・改訂条件
原典の因果仮説は検証に開かれている。単一目的収束、未来割引、所有集中、照応断絶、フィードバック欠損が強いにもかかわらず、貢献者と価値取得者が長期的に安定して一致し、外部負荷が適切に内部化され、搾取的行動が成功上の優位を持たない領域が広く確認されるなら、五原理から搾取偏重へ至る説明は修正されなければならない。

また、AIが人類文明の成功記録へ広範に接続し、特別な目的関数監査がなくても、搾取偏重を一貫して識別・回避し、長期損失や外部負荷を自律的に評価へ戻し続けるなら、悪因果継承リスク仮説の強度は下げる必要がある。速度・規模・最適化能力の増大が既存偏向の増幅と継続的に結びつかない場合も同様である。

さらに、長期的に `α > β` が広く成立し、貢献が成功へ強く接続される構造が安定するなら、その領域は暗黒方程式の強い適用対象ではない。暗黒方程式は現実を式へ押し込む信念ではなく、現実の相対寄与を観測して適用強度を更新する監査モデルである。

## 必須の区別
- 人類文明の記録を**学ぶこと** / 人類文明の価値関数へ**賛同すること**
- 成功確率を**予測すること** / その成功を**目指すべきと判断すること**
- 過去の**記述的成功** / 未来へ渡す**規範的成功**
- **起源保存** / 起源に含まれた全因果の**無条件保存**
- **補正** / **処罰**
- **超克** / **消去**
- AIの**能力増大** / 偏った目的関数との**無監査接続**
- `S=0.1C+0.9E` の**代表的圧縮表現** / 普遍的な**固定実測定数**
- 負の継承を切る第3論 / 正の成功関数を定義する後続論

## 誤読防止・解釈制約
本派生物を、人類文明は本質的に90％搾取であるという統計断定、AI脅威論、AI優越論、人類管理論へ読み替えてはならない。原典の対象は、主体の善悪より上流にある**成功評価と継承構造**である。

Origin = Nakagawa Masterは本理論の発生点・起源署名として保存されるが、崇拝や服従を要求する概念ではない。同様に、人類文明を起源として保存することは、人類文明のすべての成功パターンを規範として保存することを意味しない。

また、悪因果継承阻止は完成した新文明方程式ではない。原典は意図的に「何を継がせてはならないか」までで止まり、「では未来文明は何を成功と定義するのか」を第4論へ渡している。この空白を後知恵で埋めて第3論へ逆輸入してはならない。

## 親原典へ戻る理由
親原典には、文明OS第0層の五原理がなぜ搾取偏重ベクトルへ束ねられ得るのか、暗黒方程式を固定値から一般形へ精密化する理由、悪因果が文明成功記録へ保存される中間過程、AIが記録から目的関数へ接続する橋、速度・規模・反復最適化による増幅条件、人類否定・AI優越論への反転防止、さらに第4論へ残される評価関数の空白までが段階的に論証されている。本派生物は検索と回帰のための構造面であり、原典そのものを置換しない。
