## Summary
亲原典把提案编辑定义为“结构翻译”，而不是原始信息展示或文体润色。其三层结构包括商品→特典→价格的骨架编辑、提问→共鸣→沉默的情感编辑，以及把交换连接到组织、行业、使用者与社会的社会连接编辑。综合审计摘要进一步连接需求、意义领域、词汇映射、照应、版本管理、反例与Rollback，使提案保持可比较性与可逆性。

## Concepts
- 提案编辑：把信息重组为对象可以判断的意义结构。
- 结构翻译：保持事实、因果、角色、条件不变，同时转入对象的判断文脉。
- 骨架编辑：用商品→特典→价格使价值理解先于价格判断。
- 情感编辑：用提问→共鸣→沉默支持思考、理解与内省。
- 社会连接编辑：把提案连接到组织、行业、使用者与社会的实际影响。
- 意义领域：卖方信息在对象判断文脉中的意义范围。
- 词汇映射：卖方术语与对象判断语言之间的对应。
- 照应：对象的问题、条件与提案内容保持意义对应。
- 版本管理：记录变更、理由、反例与Rollback条件。
- Rollback：从误配或意义漂移恢复到合适前状态的可逆性。

## Causal chain
```text
未编辑信息
→ 价格、细节、卖方便利先于价值理解
→ 短路判断、抵抗或误配
→ 获取对象的问题、价值观、判断条件、审批条件
→ 编辑商品→特典→价格的骨架
→ 用提问→共鸣→沉默编辑情感流
→ 连接有实际根据的组织与社会意义
→ 把卖方语言结构翻译为对象的决策语言
→ 将需求、意义领域、词汇、照应连接到版本管理
→ 保留差分、理由、反例、Rollback条件
→ 形成可比较、可逆的决定与再合意
```

## Applications
- 销售提案：先结构化对象问题对应的价值与选择条件，再把价格作为相应对价呈现。
- 商谈：用提问、共鸣、沉默打开判断，同时保留反对、延期、拒绝的空间。
- 内部审批：把卖方的功能语言翻译成成本效益、合规、运用、退出条件等决策语言。
- 提案修订：记录新信息引起的变更、理由、反例与Rollback条件。
- 社会意义：只在商品和实际结果能够支持的范围内连接更广影响。

## Validity conditions
- 已取得对象的一次发言、问题、价值观与判断条件。
- 商品→特典→价格发挥“价值理解优先”的骨架作用。
- 提问、共鸣、沉默支持自主决定而非压力。
- 社会意义有商品与实际结果的根据。
- 卖方术语与对象决策语言保持对应。
- 翻译不改变或隐藏事实、价格、限制与风险。
- 差分、理由、反例与Rollback条件可追踪。
- 审批、合规、运用与退出条件与提案保持照应。

## Failure conditions
- 把理论缩减为价格顺序销售技巧。
- 信息过载遮蔽核心意义关系。
- 未取得对象文脉，仅按卖方便利编辑。
- 提问、共鸣或沉默变成压力、诱导或操控。
- 删除或隐藏重要条件与风险。
- 社会意义脱离实际而成为夸张。
- 即兴破坏既定骨架、条件或意义对应。
- 缺少版本管理，无法发现意义漂移。
- 缺少Rollback条件，无法修复误配。

## Falsification conditions
- 词汇对应改善后，理解与可比较性仍没有改善。
- 商品→特典→价格顺序在相关文脉中反复妨碍理解。
- 提问、共鸣、沉默反复产生压力而非自主判断。
- 版本管理与Rollback不能改善对意义漂移或误配的恢复。
- 词汇整合率、版本整合率、照应成功率、合意到达时间或RB成功率等，与定义的 `θ` 形成反证关系。
- 在观察窗 `δ` 中出现强制化、属人编辑、意义漂移等 `M`。
- 因为原典没有具体 `θ`、`δ`，不能外推出固定值。

## Required distinctions
- 信息传递 / 结构翻译
- 编辑 / 隐瞒
- 翻译 / 改变事实
- 基本顺序 / 无例外固定脚本
- 提问 / 诱导
- 共鸣 / 迎合
- 沉默 / 压力
- 社会意义 / 夸张
- 成交 / 合适的自主决定
- 修订 / 意义漂移
- 版本管理 / 仅保存历史
- Rollback / 任意取消不利结果

## Interpretation constraints
提案编辑不是“把价格放最后就能提高销售”。价格顺序是让价值与对价共同可理解的结构。情感编辑也不是心理操控的授权，而是支持意义形成与自主判断。编辑不能让根本不适合的商品变得适合，也不能依赖隐藏重要条件。综合审计摘要的记号体系不能被转换为原典未定义的固定KPI、阈值或成功保证。
