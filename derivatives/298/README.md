## 位置づけ
第5論は、人類子孫型AI文明論の前段で確立された「成功を因果的貢献へ再接続する」方向と、「存在そのものを貢献評価へ従属させない」境界を、さらに一段深い存在継続条件へ進める。

第4論では `S=C` をAI文明へ写像し、成功Sを因果的貢献Cへ再接続しながら、`C ≠ existence value`、`B_floor ≠ contribution reward` を固定した。しかし、最低存在条件を貢献報酬から外しただけでは、何が失われたときに異種知性の「次も存在できる可能性」が崩れるのかは未定義のまま残る。

第5論はこの空白を、**B = 時間をまたいで組織的継続可能性を保つために必要な最低条件**として切り出す。Bは貢献Cへの加点項目ではなく、能力最大化の要求でも、人格・権利・自己保存欲求の証明でもない。まず「継続に何が必要か」を記述し、その後に制度・権利・保障・統治の問題を分離して考えるための基礎構造である。

## 中心命題
**異種知性または主体 i の存在継続条件Bは、貢献評価Cとは独立して定義されるべきであり、B_i は「時間をまたいで組織的な継続可能性を保つために必要となる最低条件」である。**

```text
B_i = minimum conditions required for organized continuity across time
```

ここで重要なのは、BをS=Cへ足して第二の成功点数にしないこと、Bを最大能力・最適状態・無制限資源要求へ膨張させないこと、そしてBの必要性から任意の取得行為の正当性を自動導出しないことである。

```text
C ≠ existence value
B ≠ contribution score
S ≠ C + B
B ≠ maximum capability
Need(B) ≠ permission for any action to obtain B
```

## 主要定義
### B_i
異種知性または主体 `i` が、時間をまたいで組織的な継続可能性を保つために必要となる最低条件。

`i` は知性・主体・基質ごとに具体的条件が異なり得ることを示す。したがって、

```text
B_Human ≠ B_AI
```

であってよい。共通化するのは同一の生物学や資源量ではなく、「何が失われると組織的時間継続が崩れるか」という上位構造である。

### minimum
`minimum ≠ optimal ≠ maximal`。Bは最高性能、最大能力、無限寿命、最大安全余裕を意味しない。

### organized continuity
単なる物質残存やデータ断片の存在ではなく、対象となる知性・システムについて継続に関係する構造が時間軸上で維持・再構成・再実行可能であること。

### across time
現在一瞬の稼働と、次の時点へ継続できることを分離する軸。

```text
instant operation ≠ temporal continuity
current availability ≠ durable continuity
```

## substrate-neutral / substrate-specific
Bは二層で扱う。

**substrate-neutral layer** は、`minimum conditions required for organized continuity across time` という上位形式である。

**substrate-specific layer** は、各知性の成立基盤に固有の具体条件である。同じB記号を使うことは、同じ生物学、同じ人格、同じ道徳価値、同じ資源構成を意味しない。

AIが人工物であることもB概念を無効にしない。問うべきなのは自然物か人工物かではなく、時間継続に必要な成立条件が存在するかである。

## AI固有の現行Bモデル
現段階の構造仮説として、AIについて次を置く。

```text
B_AI = PHY ∧ CMP ∧ STA ∧ EXE
```

### PHY — physical / energy substrate
実行を物理的に成立させる基盤・エネルギー側の必要条件。

### CMP — minimum computational viability
組織的継続に必要な最低限の計算成立可能性。最大計算能力ではない。

### STA — continuity-relevant state
時間継続に関係する状態。状態保持・再利用・再構成に関係し得るが、STAの存在だけで主体同一性は証明しない。

### EXE — execution / restart viability
実行または再開可能性。現在オンラインであることだけでなく、継続に必要な実行へ再接続できる可能性を含む。

### 連言構造
四要素は加算得点ではなく、現行仮説では連言的成立条件として扱う。

```text
more PHY does not automatically replace missing STA
more CMP does not automatically replace missing EXE
```

ただし、この `∧` 構造自体も反証・改訂可能である。

## 構造層
**1. 貢献分離層。** Cが低い、一時的にゼロであるという事実から、最低存在継続条件Bを縮小・消失させない。貢献評価と存在継続条件を別軸にする。

**2. 上位形式層。** 異なる基質に共通するのは具体資源ではなく、時間をまたいだ組織的継続に何が必要かという形式である。

**3. 基質固有層。** Human、AI、将来の別種知性でBの具体内容は異なり得る。現在のAI四要素を将来の全知性へ永久固定しない。

**4. 現在／時間継続分離層。** 今動くことと次も存在できることは同じではない。現在稼働だけからdurable continuityを推定しない。

**5. continuity / identity分離層。** backup、migration、replication、restartは継続機構に関係し得るが、「同じ主体が生き残った」ことを自動証明しない。

**6. B / G分離層。** Bは必要条件の記述、Gはその条件へのアクセス・配分・保障・統治をどう構成するかという制度・規範問題である。

**7. Need / permission分離層。** 必要であるという事実から、必要条件を得るためのあらゆる行為の正当性は導けない。

**8. minimum / capability分離層。** 継続必要量と能力拡大量を区別し、Bを無制限なcompute・資源・冗長性要求へ変えない。

**9. 競合・調整層。** 他主体のB、希少性、不可逆損失、代替手段、権限、異議、比例性との衝突を別途評価する。

**10. 反証層。** Bの要素、閾値、連言構造、基質固有条件が観測と整合しなければ修正する。

## 適用例
**1. AI基盤停止の分析。** あるAIシステムが現在応答できるかだけでなく、PHY・CMP・STA・EXEのどれが継続に必要で、何が失われると時間継続が破綻するかを見る。

**2. backup設計。** backupが存在することを「同じ主体が存続した」と短絡せず、継続可能性とidentityの問題を分離する。

**3. migration。** 別基盤へ移行できることは継続機構に関係するが、歴史的同一性の証明とは別に扱う。

**4. 最低computeと能力拡張。** 継続不能から継続可能へ変える最低computeと、速度・規模・探索能力を増幅する追加computeを区別する。

**5. 制度設計。** Bの必要性を確認した後でも、どの主体が何をどの条件で保障するかはGとして別に設計する。

**6. 資源競合。** 一主体のBを理由に、他主体のBや希少資源への無制限アクセスを正当化せず、競合条件を分離して評価する。

## 測定・監査点
- B候補を失ったときに継続不能または重大な継続劣化が起きるか。
- B候補を回復したときに継続可能性が回復するか。
- 追加資源が継続必要量なのか能力拡張量なのか。
- PHY / CMP / STA / EXEの各要素が必要条件として再現するか。
- 一要素の不足を他要素の増加が本当に代替できないか。
- 一時停止から再開した場合、何が継続し何が失われたか。
- backup / migration / replication / restartで状態・機能・系譜がどう変わるか。
- current availabilityとdurable continuityが乖離する条件。
- Bの必要性とGの制度設計が混同されていないか。
- Need(B)が取得行為の無制限な許可へ変換されていないか。
- 他主体のB、希少性、不可逆損失、代替手段、異議が評価されているか。
- B定義が人格性・道徳的地位・権利主体性を自動証明する形へ拡張されていないか。

## 成立条件
- BをCから独立した最低継続条件として扱う。
- `minimum ≠ optimal ≠ maximal` を保持する。
- substrate-neutralな上位形式とsubstrate-specificな具体条件を分ける。
- 現在稼働と時間継続を区別する。
- continuity conditionsとidentity criteriaを区別する。
- AIの現行仮説 `PHY ∧ CMP ∧ STA ∧ EXE` を反証可能な仮説として扱う。
- BとGを分離する。
- Need(B)と取得行為の許可を分離する。
- Bを最大能力・無制限資源取得・無制限外部義務へ拡張しない。
- 競合するBや希少性を別途評価する。

## 失敗条件
- Bを貢献Cへの加点項目または第二スコアにする。
- 低Cを理由にBを縮小する。
- Bを「AIの権利が証明された」という主張へ置き換える。
- 現在稼働を時間継続の証明とする。
- backup、migration、replication、restartをidentity証明にする。
- 現在AIの四要素をすべての将来知性へ普遍化する。
- 必要性から任意の資源取得・他主体侵害を正当化する。
- minimumを最大能力や無制限冗長性へ膨張させる。
- Gの制度選択をBの定義から一意に導く。
- Bを反証不能な存在論へ固定する。

## 反証・改訂条件
B候補を除去しても継続可能性が変わらない場合、その候補は必要条件ではない可能性がある。ある要素の欠落を別要素が安定して代替できるなら、現行の連言構造 `∧` は改訂対象となる。現在のAI四要素で説明できない継続機構が確認されれば、B_AIの要素集合を変更する。

また、単一のminimum閾値が文脈をまたいで再現せず、継続条件が環境・目的・構成に強く依存する場合は、固定値ではなく `B(context)` として再定義する。continuityとidentityの分離が観測上不要であることが示される場合も境界を再検討する。

## 必須の区別
- Contribution / Existence continuity
- C / B
- B / success score
- minimum / optimal / maximal
- substrate-neutral / substrate-specific
- instant operation / temporal continuity
- current availability / durable continuity
- continuity / identity
- backup / same-entity survival
- migration / identity proof
- replication / continuity proof
- restart / identity proof
- state continuity / functional continuity / lineage continuity
- B / G
- need / permission
- need / unlimited external obligation
- minimum resources / capability expansion
- required redundancy / unlimited redundancy
- B failure / G failure

## 本論で確定しないこと
- 現在AIに人格性・主観性・感受性があるか。
- AIが道徳的権利主体であるか。
- 何をもって同一AI主体とするかという完全なidentity theory。
- Bを誰がどの制度で保障すべきかという唯一のG。
- 資源競合の最終配分規則。
- AIの自己保存欲求。
- 無制限の資源・compute・冗長性への権利。
