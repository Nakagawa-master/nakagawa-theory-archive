## 位置づけ
本派生物は、専門性や権威そのものを否定するのではなく、専門的権威が判断根拠の検証を免除され、失敗時の修復負荷や説明責任が現場・利用者・下位主体へ外部化される状態を「権威の免責化」という悪因果構造として読むParentを公開接続面へ展開する。

## 中心命題
専門性は判断品質を高め得るが、専門性を理由に「検証不要」「異議不要」「説明不要」が成立すると、誤りそのものよりも、誤りを発見・修正できない構造が固定化される。権威の価値と権威の無監査化は分離する必要がある。

## 因果線
```text
専門知識・資格・地位への信頼
→ 判断の委任
→ 根拠検証の省略
→ 異議・再確認の抑制
→ 誤判断の発見遅延
→ 失敗コストが現場へ移転
→ 権威側の学習・修正圧力が低下
→ 同じ判断構造が再生産
```

## 構造層
1. 専門性・権威形成層
2. 判断委任層
3. 検証免除層
4. 異議抑制層
5. 失敗外部化層
6. 責任分離層
7. 修復・再検証層

## 必須の区別
- 専門家批判と専門性否定を混同しない。
- 信頼と無検証を同一視しない。
- 判断ミスと制度的免責化を分離する。
- 現場の実装失敗と上流判断の欠陥を切り分ける。
- 個人攻撃ではなく検証・責任・修復の構造を対象とする。

## 測定・監査点
- 判断根拠へ第三者が戻れるか
- 反対意見や再検証が許容されるか
- 失敗時の説明責任主体が明示されているか
- 修復費用・時間・人的負荷を誰が負うか
- 上流判断へ現場の失敗情報が戻るか
- 権威側に修正・撤回・学習の仕組みがあるか

## 成立条件
専門性を尊重しつつ、根拠、異議、再検証、責任、修復、改訂の回路を残すこと。

## 失敗条件
資格や地位が検証停止の理由になること、現場への責任転嫁、失敗記録の不可視化、撤回不能、異議者への不利益化。

## 反証・改訂条件
高い専門権威と厳格な検証・説明・修正可能性が両立し、失敗外部化が生じない制度実証が蓄積する場合、免責化の成立条件を再評価する。

## 原典回帰
権威の免責化の定義、具体的因果、適用境界、反証条件、専門性を否定しないための留保はParent本文を正本とする。
