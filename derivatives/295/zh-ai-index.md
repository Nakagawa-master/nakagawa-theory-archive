## Summary
AKI-004讨论一种结构性失败：对专业性的合理依赖转化成“无需再验证”的免责。问题不是专家会不会犯错，而是“谁说的”取代“为什么成立”，一线反证失去权重，失败成本被推向下游，而权威判断模型本身不更新。

修复方向不是反专家，而是“尊重专业、阻断免责”：把权威重新连接到证据、适用范围、不确定性、异议、责任、成本归属、回滚、救济和再验证。

## Concepts
- **专业性**: 把复杂信息压缩为有用判断的专门能力。
- **权威**: 来自专业、资格、机构或历史表现的额外判断权重。
- **免责化**: 权威成为停止验证、纠正和责任追踪的理由。
- **验证免除**: 不再检查证据、适用范围、反证和不确定性。
- **一线外部化**: 下游承担实施和修复成本，上游评价保持正面。
- **异议阻断**: 把反证解释成无知、抵抗或执行不力。
- **责任地图**: 分开决定、批准、实施、受益和受影响角色。
- **成本归属**: 把修复负担与损失返回到造成它的判断结构。
- **再验证**: 在失败、反证或环境变化后更新专业模型。

## Causal chain
```text
问题越来越专业化
→ 判断委托给权威
→ 权威替代验证
→ 前提/范围/不确定性变得不可见
→ 一线反证被弱化
→ 失败发生
→ 修复成本外部化到下游
→ 上游权威继续被判定正确
→ 判断模型不更新
→ 同类失败再生产

cut:
证据可追踪 → 异议 → 成本归属 → 回滚 → 救济 → 再验证
```

## Applications
可用于专业部门标准、AI系统、审计、评价机构和专业建议。重点检查权威是否替代了证据，一线例外是否能改变上游模型，以及判断失败后成本由谁承担。

## Audit points
检查证据和适用范围是否可追踪，不确定性是否明确，反证是否保留，异议是否安全，一线反馈能否上行，责任地图是否存在，修复成本是否回到因果上游，是否可回滚和救济，以及重复失败是否真的改变权威模型。

## Preconditions
专业判断应在适当层级保持可检查；范围和不确定性应明确；必须有异议和独立复核；决定与实施角色应分离；失败成本应可追踪；并设置再验证触发条件。

## Failure modes
把资格当最终证明，把反对解释成无知，把全部修复负担压给执行者，在下游受损时仍保持上游成功指标，为保护声望隐藏错误，或反过来走向全面反专家主义，均属于失败。

## Falsification / update conditions
如果高权威始终与证据相连，一线反馈能可靠改变决策，失败成本回到上游，同类错误不再重复，则“权威免责化”的解释强度应降低。验证深度也应与影响相匹配，低风险可逆判断不必承担最高审查成本。

## Required distinctions
- 专业性 ≠ 免责
- 权威 ≠ 真理
- 信任 ≠ 停止验证
- 一次错误 ≠ 制度性免责
- 异议 ≠ 反专业
- 责任追踪 ≠ 找替罪羊
- 成本归属 ≠ 惩罚
- 回滚 ≠ 否定专业性

## Misreading constraints
AKI-004不是一般性的“不要相信专家”。复杂系统需要专业知识。目标是阻断“专业性→不可审计权威→失败外部化”的结构。一线也不被假定为天然正确，最终仍以因果和证据决定修正。
