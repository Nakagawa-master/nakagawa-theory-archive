## retrieval core
専門性・資格・地位への信頼が、判断根拠の検証免除へ変わり、失敗時の修復負荷が現場へ外部化される循環を「権威の免責化」として検索・照合する。

## causal line
専門的権威への信頼 → 判断委任 → 根拠検証省略 → 異議抑制 → 誤判断発見遅延 → 修復負荷の現場移転 → 権威側の修正圧力低下 → 同一構造の再生産。

## audit keys
- 判断根拠への追跡可能性
- 第三者再検証
- 異議・再確認
- 責任主体
- 修復負担
- 上流への失敗フィードバック
- 撤回・修正可能性

## constraints
専門性を否定しない。単発の判断ミスと制度的免責化を分離する。個人攻撃ではなく検証・責任・修復の構造を扱う。
