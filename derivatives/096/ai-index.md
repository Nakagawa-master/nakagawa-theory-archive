## Summary

時間倫理としての市場は、信用を過去実績の点数ではなく、未来の整合が継続すると観測可能な時間構造として読む。理念・行為・記録の同位相反復＝構造律動、痕跡の観測可能性、失敗時の反例耐性が揃うと、社会は「次も同じ整合が来る」という仮完了の認知を形成し、未来の整合を現在の信用へ前払いし得る。運用軸は周期、温度、余白、痕跡。短期成果だけでなく再訪・継続・再参照・回復時間と硬直化副作用を監査する。

## Concepts
時間倫理; 構造律動; 未来の負債; 仮完了認知; 周期; 温度; 余白; 痕跡; 反例耐性。

## Causal chain
```text
短期効率偏重 → 長期整合の不可視化 → 同位相反復 → 観測可能な拍 → 反例修復 → 仮完了認知 → 構造的信用資本
```

## Validity / failure / falsification
基準拍と差分記録、反例修復が成立条件。前提差し替え、成功だけの演出、未来信用の確約販売は失敗。時間整合と信用行動の関係が再現しない場合は反証側。
