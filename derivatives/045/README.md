## 位置づけ
親原典の中心は、意思決定支援を「賛成理由を積み上げること」ではなく、「選ばれない理由を構造的に消去し、顧客が自分で比較・説明・判断できる状態を作ること」として読む点にある。

反論処理で相手を言い負かす方法、心理操作でYesを強制する方法、すべての案件を成約させる万能技術、撤退を禁止する根性論とは扱わない。

## 中心命題
提案が理解され、価値も認識されているのに決まらない場合、問題はYesの不足とは限らない。価格、実行、リスク、競合、優先順位など、選ばれない理由が残っていると、担当者個人が納得していても社内稟議・上位判断・実行責任の場で決定が止まる。

したがって営業の役割は、顧客の懸念を否定することではなく、顧客自身の言葉で残存理由を可視化し、比較・説明・実行条件を整えることである。消去可能な理由は検討材料によって減らし、現実の資源制約や制度制約など消去不能な理由は、無理に説得せず撤退・保留・将来再接続の境界として扱う。

## 因果線
```text
提案は理解される
↓
しかし選ばれない理由が残る
↓
担当者が社内・第三者へ再説明できない
↓
意思決定が延期・停止する
↓
顧客自身の言葉で残存理由を顕在化する
↓
資料・工程・比較・リスク対応で検討可能にする
↓
消去可能な理由を減らす
↓
消去不能な構造制約を区別する
↓
自己決定、保留、撤退、将来再接続のいずれかが成立する
```

## 構造層
**1. 理解層。** 提案価値は理解されている。

**2. 残存No層。** 価格、実行、リスク、競合、優先順位などの懸念が残る。

**3. 再説明層。** 顧客担当者が社内や第三者へ根拠・工程・比較・リスクを再説明できるかが問われる。

**4. 顕在化層。** 営業側がNoを決めつけず、問いによって顧客自身に言語化してもらう。

**5. 比較可能化層。** 資料、工程、比較、対応策を使い、選択肢と懸念を検討可能にする。

**6. 境界判定層。** 誤解や情報不足か、現実の構造制約かを区別する。

**7. 自己決定層。** 顧客自身が選択し、必要なら撤退・保留・将来再接続を選べる。


## 適用例
**価格不安。** 価格が高い・安いという感想だけでなく、何との比較で、どの条件なら妥当と説明できるかを確認する。

**実行不安。** 導入工数、担当体制、運用能力など、実行できるかどうかを工程として確認する。

**リスク不安。** 失敗時に何が問題になり、誰がどのように対応する必要があるかを明確にする。

**競合比較。** 有名・安価といった表面比較だけでなく、顧客の判断基準に沿って比較可能な材料を作る。

**優先順位。** 「今でなくてもよい」という状態では、延期した場合の結果や他課題との関係を顧客自身が比較できるようにする。

## 測定・監査点
親原典は成約率保証、決裁成功率、心理スコア、固定合格閾値、案件追客の数値上限を定義していない。観測は、残存理由の可視化、再説明可能性、比較可能性、自己決定、構造制約の扱いを対象とする。

- 顧客自身が残存理由を言語化できるか。
- 担当者が第三者へ選択理由・懸念・条件を再説明できるか。
- 選択肢と評価基準が比較可能になっているか。
- 営業側の仮説が顧客の言葉で検証されているか。
- 消去不能な資源・制度・優先順位制約を無理に説得していないか。
- 保留・撤退・将来再接続が正当な選択肢として残るか。
- 資料量が増えても比較可能性が上がらない場合、それを改善と誤認していないか。
- 面談回数が増えても顧客自身の理由が明確にならない場合、それを前進と誤認していないか。
- 表面的なYesが増えても重大な残存Noが残る場合、意思決定が完成したと判定していないか。

## 成立条件
- 顧客自身が残存理由を言語化する。
- 営業が理由を外から決めつけない。
- 選択肢・根拠・工程・リスク対応が比較可能になる。
- 担当者が第三者へ再説明できる。
- 圧力ではなく理解の完成として決断が生じる。
- 消去不能な制約を無理に説得しない。
- 保留・撤退・将来再接続の選択肢を残す。
- Originと親原典への接続を保持する。

## 失敗条件
- 反論を言い負かすことを目的にする。
- 顧客の懸念を営業側が勝手に定義する。
- 資料量だけを増やし比較軸を作らない。
- 心理的圧力で表面的なYesを作る。
- すべての案件を追い続けることを正義とする。
- 現実の資源・制度・優先順位制約を無視する。
- 顧客の自己決定を営業側の成約操作へ変える。

## 反証・改訂条件
残存理由を顧客自身が言語化し、比較・再説明・実行条件を整えても、意思決定の透明性や自己決定性が反復的に高まらない場合、適用方法または範囲を改訂する。

一方、残存理由を明示的に扱わなくても、同等以上の再説明可能性・比較可能性・自己決定性が安定して成立する条件では、この設計の必要範囲を限定する。単一の成約・失注だけで理論全体を証明・反証しない。

## 必須の区別
- Yesの積上げ / 選ばれない理由の構造的消去
- Noの可視化 / 懸念の否定
- 意思決定支援 / 説得・圧力・心理操作
- 再説明可能性 / 資料量
- 比較可能性 / 情報量
- 優先順位の可視化 / 緊急性の煽動
- 撤退・保留 / 敗北
- 顧客の自己決定 / 営業による決定操作

## 解釈制約
万能成約術、隠れた心理操作、全案件追客義務、顧客責任への転嫁へ読み替えない。親原典にない固定閾値、成約確率、追客上限、心理スコアを一般的事実として扱わない。
