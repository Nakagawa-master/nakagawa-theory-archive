## Structural summary
意思決定支援を、賛成理由の加算ではなく、価格・実行・リスク・競合・優先順位に関する残存Noの可視化と消去として定義する。決断は営業による操作ではなく、比較可能性と理解が完成したときに生じる。消去不能な資源制約は撤退境界として扱い、理由を記録して再接続可能性を残す。

## Causal chain
```text
提案理解
→ 残存Noの検出
→ 顧客自身による言語化
→ 資料・工程・比較・リスク対応で検討可能化
→ 消去可能なNoの解消
→ 消去不能条件の撤退判定
→ 自己決定または将来再接続
```

## Core concepts
- 意思決定支援
- 選ばれない理由の排除
- 価格不安 / 実行不安 / リスク不安 / 競合比較 / 優先順位不明
- 排除マトリクス
- 理由メモ
- 撤退設計
- 比較可能性

## Required distinctions
- Noの消去 ≠ 懸念の否定
- 意思決定支援 ≠ 説得・圧力
- 撤退 ≠ 敗北
- 顧客の自己決定 ≠ 営業による決定操作
