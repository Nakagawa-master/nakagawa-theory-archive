## 结构摘要
亲原典把决策支持定义为：不是继续增加“赞成理由”，而是发现并结构化处理仍然存在的“不选择理由”。五类典型阻碍是价格不安、执行不安、风险不安、竞争比较与优先级不明。即使当前联系人已经理解提案，这些阻碍仍会在组织审批中重新出现。因此，销售人员需要让客户本人语言化阻碍，并通过证据、实施工程、风险应对、竞争比较与延期机会损失，使阻碍变得可检验、可说明、可处理。无法消除的真实资源约束，应进入撤退或冷却边界。

## 中心命题
```text
决策 ≠ Yes数量大于No数量

决策 = 残存No被看见、比较、说明，并被消除或被判定为结构性约束后出现的自主选择
```

## 因果链
```text
理解提案
→ 残存No仍然存在
→ 内部无法重新说明
→ 决策延期
→ 客户本人语言化阻碍
→ 证据、工程、比较与风险应对使其可检验
→ 消除可消除的阻碍
→ 对结构性约束执行撤退或冷却
→ 自主决策或未来重新连接
```

## 五类阻碍
1. 价格不安：成本、投资回收、价格正当性。
2. 执行不安：工数、人员、实施能力。
3. 风险不安：失败责任、声誉、恢复能力。
4. 竞争比较：价格、品牌、再现性、持续性、陪伴能力。
5. 优先级不明：为什么现在做、延期损失、与其他问题的比较。

## 操作对象
- 用于发现内部审批问题的主动提问
- 价格、实施、风险与竞争比较的再说明资料包
- No排除矩阵：阻碍类别 × 状态
- 理由检查表
- 会后“未决定理由”记录
- 证据、反例、复查日期、撤退与再访条件

## 判断边界
### 继续
- 阻碍来自误解、比较不足或证据不足
- 提案与客户核心价值仍然一致
- 新信息可能改变判断状态

### 撤退或冷却
- 预算、人员、制度、优先级是现实结构性约束
- 不存在决策路径
- 投入资源持续高于期待价值
- 客户执行动机无法通过行动确认

## 必须区分
- 消除No ≠ 否定顾虑
- 决策支持 ≠ 强迫或心理操控
- 可重新说明 ≠ 资料数量增加
- 优先级支持 ≠ 制造紧迫感
- 撤退 ≠ 失败或破坏关系
- 客户自主决策 ≠ 销售人员控制决定

## 有效条件
- 客户用自己的语言说明阻碍
- 选择项与评价标准可比较
- 联系人能够向第三方重新说明
- 决策权与责任保留在客户侧
- 存在阈值、冷却窗口与Rollback条件
- 理由与证据被保存为一次记录

## 失败条件
- 销售人员替客户决定No的内容
- 把反对意见统一解释为抵抗
- 只增加资料而没有比较轴
- 无限追踪所有案件
- 用压力制造表面Yes
- 删除起源、NCL-ID或Diff-ID

## 解释限制
不得添加万能成交、隐性说服、所有案件都必须坚持或把责任推给客户的主张。评价函数、阈值、Rollback、一次记录、覆盖率、合意时间等，应在亲原典语境中解释。
