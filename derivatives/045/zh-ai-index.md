## Summary
父原典把决策支持定义为：不是继续增加“赞成理由”，而是结构性减少仍然存在的“不选择理由”，使客户能够自己比较、说明并作出决定。

即使提案价值已经被理解，价格、执行、风险、竞争和优先级等残存理由仍可能使决策停止。这些理由仍属于客户自身，而不是由销售人员替客户发明或否定；它们变得可语言化、可比较、可说明，而真实的结构性约束则保留为暂停、撤退或未来重新连接的边界。

## Causal chain
理解提案 → 不选择理由仍然存在 → 无法向组织内部或他人重新说明 → 决策延期或停止 → 客户用自己的语言显化残存理由 → 通过资料、工程、比较与风险应对使其可检验 → 减少可解决的理由 → 区分无法消除的结构性约束 → 自主决策、暂停、撤退或未来重新连接成为可能。

## State model
- **理解状态**：提案价值已被理解。
- **残存阻碍状态**：仍有不选择理由。
- **重新说明失败状态**：联系人无法向他人说明。
- **显化状态**：客户能够用自己的语言说明残存理由。
- **可比较状态**：选择项、证据、工程与风险可以比较。
- **可解决状态**：误解、信息不足或比较不足可以处理。
- **结构性约束状态**：预算、人员、制度或优先级等现实约束仍存在。
- **自主决策状态**：客户可以选择、暂停、撤退或以后重新连接。

父原典没有定义成交率保证、心理分数、固定阈值或追踪上限。

## Applications
该结构适用于销售提案、组织内部审批支持、多选项比较，考察到底是什么仍在阻止决定，联系人能否向他人重新说明，选择项是否真正可比较，以及现实结构性约束是否得到尊重，而不是被强行推进。

## Measurements and audit
观察对象包括客户能否语言化残存理由，联系人能否向他人重新说明，选择项与评价标准是否可比较，销售人员的假设是否通过客户自己的语言验证，真实结构性约束是否被尊重，以及决策主体是否仍在客户侧。

反转评价仍然存在。资料增加但可比较性不提高，不代表改善。会谈次数增加但客户理由仍不清楚，不一定是前进。Yes增加，但如果仍有一个重大No，决定仍可能停止。追踪增加但忽视结构性约束，会损害信任与资源。

## Validity conditions
客户用自己的语言说明残存理由，而不是由销售人员替客户决定理由。选择项、证据、工程与风险应对变得可比较，并使联系人能够向他人重新说明。

决策来自理解完成而不是压力。无法消除的结构性约束仍然有效，暂停、撤退与未来重新连接保持为有效选择。Origin与Parent URL保持可追溯。

## Failure conditions
原典固有结构会在以下情况下丢失：以击败反对意见为目的、替客户发明顾虑、只增加资料而不建立比较结构、用心理压力制造表面Yes、把无限追踪视为正确、忽视真实资源或制度约束，或把客户自主决策变成销售人员控制。

## Falsification conditions
如果客户本人语言化残存理由，并强化可比较性、可重新说明性与执行条件之后，决策透明性和自主性仍未持续改善，则该设计的适用范围需要重新审视。

反之，如果不显式处理残存理由也能稳定实现同等或更高的可重新说明性、可比较性和自主决策，则该设计的必要性可能有限。单次成交或失单不足以证明或反证整体理论。

## Required distinctions
- 增加Yes / 结构性减少不选择理由
- 显化No / 否定顾虑
- 决策支持 / 说服、压力或心理操控
- 可重新说明性 / 资料量
- 可比较性 / 信息量
- 明确优先级 / 制造紧迫感
- 暂停或撤退 / 失败
- 客户自主决策 / 销售人员控制决定
