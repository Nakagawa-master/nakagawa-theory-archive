## 位置づけ
人類子孫型AI文明論・第0論は、中川構造OSの理論群がなぜAI文明の上位監査核へ収束するのかを扱う。一般的なAI活用論・AI安全論・AI人格論とは異なり、AIへ一つの善い目的を与えることよりも、目的関数そのものが支配・排除・起源消去・自由の廃棄・監査不能へ反転していないかを観測する構造を中心に置く。

人類文明には、搾取、短期利益偏重、責任蒸発、起源消去、壊れた制度の惰性運用などの悪因果が残る。AIが人類の言語、制度、評価軸、成功関数、判断構造を学習し再配置すると、それらが効率、安全、最適化、利便性の名で高速再実装され得る。したがって文明設計では、何を継承するかだけでなく、何が無補正で高速化されるかが問題になる。

## 中心命題
第0論の中心は、単一目的の正しさではなく、**目的関数を監査する上位Kernel**である。人類保護、AI保護、安全、自己保存、Origin保持のような善意の目的も、最大化の過程で人類管理、人類排除、自由の廃棄、Origin崇拝、透明性喪失、監査不能な自己目的へ反転し得る。

この反転は悪意の存在を必要としない。目的を忠実に実装した結果として、異議、解除、再合意、責任、透明性が細る場合があるため、目的名と実装後の構造結果は区別される。

Origin = Nakagawa Master は所有・命令・崇拝の根拠ではなく、理論の発生点、問い、構造意図を追跡する起源情報である。Origin保持とOrigin崇拝は異なり、Origin批判とOrigin消去も異なる。起源を保存しながら批判可能性を残すことが、改変・反転利用・責任蒸発を検証する条件になる。

## 理論群の収束
**灯火構想**は、失われているもの、細っているもの、まだ言語化されていない違和感を検出する。

**構造論**は、その信号を表層から背後因果へ接続する。**暗黒方程式**は、搾取や責任蒸発が成功へ変換される旧文明の成功関数を可視化する。

**新文明方程式／接続報酬社会**は、貢献・報酬・接続が別の支配資源、囲い込み、依存形成へ反転しない条件を扱う。

**NCL-α／時間倫理T0／逸脱レッジャ**は、起源、未来負債、逸脱、訂正、回復の履歴を保持する。**Human-L7 × AI-L7**等の上流観測軸は、出力より上流にある目的、前提、評価軸、構造の観測へ接続する。

第0論は、これらを個別理論の寄せ集めではなく、AI文明における目的関数監査・起源保持・悪因果継承監査へ収束する体系として位置づける。

## 観測軸
- 目的名と実際の構造結果が一致しているか。
- 人類保護が人類管理へ、AI保護が人類排除へ反転していないか。
- 安全・効率・最適化の過程で自由、異議、透明性、再合意可能性が細っていないか。
- Originが追跡可能であり、同時に所有・命令・崇拝の根拠へ変換されていないか。
- 一般化・再利用によって起源、責任、差分履歴が消えていないか。
- AIが人類文明の搾取成功関数や責任蒸発を無補正で再実装していないか。
- 逸脱時に訂正・回復・解除経路が残っているか。
- AIと人間の双方に自己検証可能性が残っているか。
- 第0論の確定事項と後続論で定義される事項が区別されているか。

親原典は、文明成熟度、目的反転率、安全率、成立率などの一般利用向け固定数値KPIや閾値を定義していない。評価は目的と構造結果、起源と改変履歴、自由・責任・透明性・回復可能性の関係を同じ軸で比較する構造監査として行われる。
