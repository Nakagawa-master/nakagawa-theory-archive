## 中心命題
NCL-αは法的排除の壁ではなく、構造の真正性と公的連続性を守る最小限の構造倫理契約である。非商用は出典表示を基本とし、組織の規範・製品・運用へ恒常的に組み込む商用利用は共調ログと契約導線へ進む。

## 原典の一次判定
- 制度化：組織の規範・製品・運用へ継続的に組み込む → 商用・要契約。
- 収益寄与：教材・講座・書籍等の主要収益源 → 要相談。
- 公共性：紹介・検討・教育で一過的かつ公共圏の学習 → 非商用、出典表示、ログ任意。
- 迷う場合：共調ログ／NCL-Registry α運用へ戻る。

## 原典が示す例
- 個人ブログ・研究引用・講評：非商用、契約不要、出典表示必須。
- 社内勉強会・教育利用：非商用、契約不要、共調ログ任意。
- 企業プロジェクト指針・経営哲学への組込み：商用、要契約（第9条）。
- 監修・研修・共同研究・認定導入：商用、要契約。
- 書籍・有料講座：収益構造により要相談。

## 構造倫理契約としての核
恒常署名と監査束で起源・因果・整合を可視化し、照応的拘束によって法的強制に先立つ接続責務を明示する。利用者は初期設定で「侵害者」ではなく共同設計者として扱われる。
